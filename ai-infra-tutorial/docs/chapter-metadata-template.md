# 章节头元数据模板

每章 H1 后加入一个紧凑元数据块，用于让读者在进入正文前判断阅读条件、学习产出和验证入口。字段名保持一致，内容尽量短，避免替代正文。

```markdown
> **前置知识**：<读本章前最好已经掌握的概念、章节或实践经验。>
> **读完能判断什么**：<读者应能做出的工程判断，强调决策而不是记忆。>
> **关键指标**：<本章会反复使用的 3-6 个指标、信号或证据对象。>
> **相关章节**：<2-4 个前后依赖章节，使用相对链接。>
> **常见误区**：<最容易误判的 1-3 个点。>
> **验证/练习入口**：<本章练习题、附录答案、实验或检查清单入口。>
```

## 编写约束

- 放在 H1 标题之后、正文第一个二级标题之前。
- 使用同一组字段名：前置知识、读完能判断什么、关键指标、相关章节、常见误区、验证/练习入口。
- 每个字段 1-2 句即可；章节样例优先紧凑，不展开成新小节。
- 相关章节必须使用有效的本地相对链接。
- 不在元数据块里重复目录、长定义或完整学习大纲。
