## Task 1: A 公式表（2500-3500 字）

`chuzhong_math/appendix/A-formula-sheet.md`

按 part 顺序归类全部公式/定理。每条形式：**结论 + 一句话使用条件 + 来源章节链接**。

分组（markdown 章节）：
- **基础概念**：两点确定一直线、两点间线段最短
- **角**：度分秒换算、互余/互补、对顶角相等
- **平行线**：判定 3 条 + 性质 3 条（同位/内错/同旁内）
- **三角形**：
  - 三边关系、内角和 $180°$、外角定理
  - 全等判定 SSS/SAS/ASA/AAS/HL
  - 相似判定 AA/SAS/SSS；相似比 → 周长/面积关系
  - 勾股定理 + 逆定理 + 三类判定（直/锐/钝）
  - 30-60-90 边比 $1:\sqrt{3}:2$；45-45-90 边比 $1:1:\sqrt{2}$
  - 等腰性质：等边对等角、三线合一
  - 等边性质：内角 $60°$、面积 $\frac{\sqrt{3}}{4}a^2$、高 $\frac{\sqrt{3}}{2}a$
  - 四心定义 + 重心分中线 $2:1$、直角三角形外心 = 斜边中点
- **四边形**：
  - 多边形内角和 $(n-2) \times 180°$、外角和 $360°$
  - 平行四边形 4 性质 5 判定
  - 矩形/菱形/正方形 性质与判定要点
  - 梯形辅助线 3 种
  - 三角形中位线 / 梯形中位线公式
  - 中点四边形 → 平行四边形（特殊情形）
- **圆**：
  - 弦/弧/圆心角/圆周角关系
  - 垂径定理
  - 圆周角定理 + 推论（直径所对 $90°$、内接四边形对角互补）
  - 切线判定与性质、切线长定理
  - 切割线 $PA^2 = PB \cdot PC$
  - 内切圆 $S = pr$、直角内切圆 $r = \frac{a+b-c}{2}$
  - 弧长 $\frac{n}{360}\cdot 2\pi r$、扇形面积 $\frac{n}{360}\pi r^2$
- **变换**：
  - 平移 / 旋转 / 对称的性质要点
  - 坐标变换表（8 行：$x$ 轴对称等）
- **三角函数**：
  - 定义 $\sin\alpha=对/斜$ 等
  - 特殊角值表 $30°, 45°, 60°$
  - $\sin^2+\cos^2=1$
  - $\sin(90°-\alpha) = \cos\alpha$
- **解析几何**：
  - 距离公式 $AB = \sqrt{(x_2-x_1)^2+(y_2-y_1)^2}$
  - 中点公式 $\left(\frac{x_1+x_2}{2}, \frac{y_1+y_2}{2}\right)$

- 题号
- **思路标签**（如"手拉手 + SAS"、"勾股 + 设元方程"）

设已知角为 $\angle 1 = 40°$，对顶角 $\angle 3 = 40°$，邻补角 $\angle 2 = \angle 4 = 180° - 40° = 140°$。
