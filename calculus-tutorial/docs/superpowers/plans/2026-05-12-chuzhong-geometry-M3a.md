## Task 1: 01 多边形内角和与外角和（模板 C，1800-2500 字）

Title: `# 多边形的内角和与外角和`

- **图形特征**：$n$ 条线段首尾相连的封闭图形（$n \geq 3$）
- **核心定理**：
  - **内角和 = $(n-2) \times 180°$**
  - **外角和 = $360°$**（与 $n$ 无关）
  - **正多边形每内角 $= \frac{(n-2) \times 180°}{n}$，每外角 $= \frac{360°}{n}$**
- **内角和证明**：从一顶点出发把 $n$ 边形分成 $n-2$ 个三角形 → 内角和 $= (n-2) \times 180°$
- **外角和证明**：每外角 + 对应内角 $= 180°$，$n$ 个内外角对总和 $= 180n$，减去内角和 $(n-2) \times 180$，剩外角和 $= 360°$
- **典型应用** 3 例：
  - 例 1：内角和 $1440°$ 的多边形是几边形（$10$ 边形）
  - 例 2：正八边形每内角度数（$135°$）
  - 例 3：边数从 $3$ 增加 $1$，内角和增加 $180°$；外角和不变
- **易错点**：外角和恒为 $360°$；正多边形不要求边数特殊
- **自测题** 4 题。

## Task 2: 02 平行四边形（模板 C，2200-3000 字）

Title: `# 平行四边形`

- **图形特征**：两组对边分别平行的四边形
- **性质**：
  1. 两组对边分别平行且相等
  2. 两组对角分别相等
  3. 对角线互相平分
  4. 中心对称图形（对称中心为对角线交点）
- **判定**：
  1. 两组对边分别平行 → ▱
  2. 两组对边分别相等 → ▱
  3. 一组对边平行且相等 → ▱
  4. 两组对角分别相等 → ▱
  5. 对角线互相平分 → ▱
- **性质 3 证明**：用 ASA 全等（$\triangle AOB \cong \triangle COD$，对边平行给同位角，对边相等给夹边）
- **典型应用** 3 例：
  - 例 1：基础——求未知角或边
  - 例 2：用对角线互相平分构造全等
  - 例 3：思路题——题目里给"对角线互相平分"，立刻反推这是平行四边形
- **易错点**：判定 3 必须"**一组**对边平行**且**相等"（缺一不可）；不是"两组都相等"等价于"两组都平行"
- **自测题** 5 题。

## Task 3: 03 矩形（模板 C，1800-2500 字）

Title: `# 矩形`

- **图形特征**：有一个角是直角的平行四边形（等价定义：四个角都是直角的四边形）
- **性质**（继承平行四边形 + 特有）：
  - 四个角都是直角
  - **对角线相等且互相平分**
- **判定**：
  1. 有一个角是直角的平行四边形 → 矩形
  2. 对角线相等的平行四边形 → 矩形
  3. 三个角是直角的四边形 → 矩形
- **典型应用** 3 例：
  - 例 1：基础——矩形对角线长度（用勾股）
  - 例 2：**直角三角形斜边中线 = 斜边一半**——矩形对角线在斜边中点处，呼应 special/03 外心结论
  - 例 3：折叠矩形求边长（前置勾股）
- **易错点**：矩形对角线"相等且互相平分"（缺一不构成矩形）；判定 2 需先确认是平行四边形
- **自测题** 4 题。

## Task 4: 04 菱形（模板 C，1800-2500 字）

Title: `# 菱形`

- **图形特征**：四条边都相等的四边形（也是一组邻边相等的平行四边形）
- **性质**（继承平行四边形 + 特有）：
  - 四条边都相等
  - **对角线互相垂直平分且每条对角线平分一组对角**
  - 是轴对称图形（两条对称轴为对角线所在直线）
- **判定**：
  1. 一组邻边相等的平行四边形 → 菱形
  2. 四条边都相等的四边形 → 菱形
  3. 对角线互相垂直的平行四边形 → 菱形
- **关键计算**：菱形面积 = $\frac{1}{2} \times d_1 \times d_2$（两对角线乘积一半）
- **典型应用** 3 例：
  - 例 1：基础——求菱形面积（已知对角线）
  - 例 2：菱形对角线分成 4 个全等直角三角形 → 内含 30-60-90 或 45-45-90
  - 例 3：菱形 + 角度求边长
- **易错点**：菱形≠正方形（不要求角直角）；对角线垂直但不一定相等
- **自测题** 4 题。

## Task 5: 05 正方形（模板 C，1500-2200 字）

Title: `# 正方形`

- **图形特征**：四条边相等且四个角都是直角的四边形（既是矩形又是菱形）
- **性质**（继承矩形与菱形）：
  - 四边相等，四角直角
  - 对角线**相等、互相垂直平分、平分对角**（$45°$）
  - 四条对称轴
- **判定**：
  1. 邻边相等的矩形 → 正方形
  2. 有一直角的菱形 → 正方形
  3. 对角线相等的菱形 → 正方形
  4. 对角线垂直的矩形 → 正方形
- **典型应用** 3 例：
  - 例 1：正方形对角线长 = 边 $\times \sqrt{2}$（呼应 45-45-90）
  - 例 2：正方形中"半角模型"经典出现地（呼应 cong/04）
  - 例 3：正方形 + 旋转 90° → 手拉手特例（呼应 cong/03）
- **易错点**：正方形是矩形与菱形的"交集"
- **自测题** 4 题。

## Task 6: 06 梯形与等腰梯形（模板 C，2000-2800 字）

Title: `# 梯形与等腰梯形`

- **图形特征**：一组对边平行、另一组不平行的四边形
- **定义与术语**：上底、下底（两条平行边）、腰（不平行的两边）、高
- **特殊梯形**：
  - **直角梯形**：一腰垂直于底
  - **等腰梯形**：两腰相等
- **等腰梯形性质**：
  1. 两腰相等
  2. 同一底上两底角相等
  3. 对角线相等
  4. 是轴对称图形（对称轴为两底中点连线所在直线）
- **等腰梯形判定**：
  1. 两腰相等的梯形 → 等腰梯形
  2. 同底两角相等的梯形 → 等腰梯形
  3. 对角线相等的梯形 → 等腰梯形
- **梯形辅助线**（呼应 toolkit/02 B 类）：
  - **过一腰端点作另一腰的平行线**：分成平行四边形 + 三角形
  - **过两底端点作两条高**：分成矩形 + 两个直角三角形
  - **延长两腰相交**：构造大三角形 + 相似（A 字模型）
- **典型应用** 3 例：
  - 例 1：等腰梯形 + 角度求边
  - 例 2：延长两腰构造 A 字（呼应 sim/02）
  - 例 3：作两高分解为矩形 + 直角三角形求高
- **易错点**：梯形必须"一组对边平行 + 一组不平行"（两组都平行就成了平行四边形）
- **自测题** 5 题。

## Task 7: 07 三角形与梯形中位线（模板 C，1800-2500 字）

Title: `# 中位线定理`

- **三角形中位线**：连接三角形两边中点的线段
- **三角形中位线定理**：
  - **中位线平行于第三边**
  - **中位线长 = 第三边长的一半**
- **证明**（用倍长中线，呼应 cong/06）：把中位线倍长后构造平行四边形
- **梯形中位线**：连接梯形两腰中点的线段
- **梯形中位线定理**：
  - 平行于两底
  - 长 = 两底之和的一半 $= \frac{a+b}{2}$
- **典型应用** 3 例：
  - 例 1：基础——求中位线长
  - 例 2：用中位线证两段相等或平行
  - 例 3：综合——多次中位线嵌套（中位线的中位线...）
- **易错点**：中位线必须连接的是"中点"，不是任意点；梯形中位线连接的是"两腰中点"而非"两底中点"
- **自测题** 4 题。

## Task 8: 08 中点四边形模型（模板 D，2500-3200 字）

Title: `# 中点四边形模型`

**一图速记**:
> **一图速记**：任意四边形四边中点连接，构成的"中点四边形"必是**平行四边形**。原四边形特殊（矩形/菱形/正方形）→ 中点四边形也是相应特殊形。

### 一、引入
> 任意四边形 $ABCD$，$E, F, G, H$ 分别是 $AB, BC, CD, DA$ 的中点。证明 $EFGH$ 是平行四边形。如果原四边形是矩形，结论变什么？菱形呢？正方形呢？

### 二、思维路径还原 (10-12 行)
> "四个中点连四边形，要证平行四边形——首选思路：证'一组对边平行且相等'。
> 看 $EF$：$E, F$ 是 $AB, BC$ 的中点 —— 这是 $\triangle ABC$ 的中位线！由中位线定理（part4/07）：$EF \parallel AC$ 且 $EF = \frac{1}{2}AC$。
> 看 $HG$：$H, G$ 是 $DA, DC$ 的中点 —— 这是 $\triangle ACD$ 的中位线。同理：$HG \parallel AC$ 且 $HG = \frac{1}{2}AC$。
> 两对结论合起来：$EF \parallel HG$ 且 $EF = HG$ —— 一组对边平行且相等 → **$EFGH$ 是平行四边形**！
> 关键：对角线 $AC$ 在两次中位线推导中是'桥梁'——同一条对角线让上下两个中位线都与它平行且半长。
> 那如果原四边形是**矩形**？矩形对角线相等（$AC = BD$），由中位线 $EF = \frac{1}{2}AC$、$EH = \frac{1}{2}BD$（看 $\triangle ABD$）→ $EF = EH$ → 邻边相等的平行四边形 → **菱形**！
> 如果原是**菱形**？菱形对角线垂直 → $EF \parallel AC, EH \parallel BD$ → $EF \perp EH$ → 有直角的平行四边形 → **矩形**！
> 如果原是**正方形**？两条性质都满足 → 中点四边形是正方形。"

### 三、抽象成模型
- 原四边形 → 中点四边形 的"形态映射"由原四边形**对角线**的性质决定：
  - **任意四边形** → 平行四边形（无附加条件）
  - **矩形**（对角线相等）→ 菱形
  - **菱形**（对角线垂直）→ 矩形
  - **正方形**（对角线相等且垂直）→ 正方形
  - **等腰梯形**（对角线相等）→ 菱形
- 关键工具：三角形中位线定理（part4/07）

### 四、模型变形
- 对**中点四边形**再求中点四边形 → 嵌套模型（每嵌套一层，形态在某些情形循环）
- 三维推广（不要求初中）

### 五、思考路标
- 看到四边形四个中点连四边形 → 中点四边形模型
- 想知道中点四边形是什么 → 看**原对角线的性质**
- 对角线相等 → 中点四边形是菱形
- 对角线垂直 → 中点四边形是矩形
- 对角线相等且垂直 → 中点四边形是正方形

### 六、应用例题 (2-3 例)
- 例 1：证任意四边形的中点四边形是平行四边形
- 例 2：原是矩形，证中点四边形是菱形
- 例 3：综合——给中点四边形是正方形，反推原四边形对角线满足什么条件

### 七、自测题 4 题。
