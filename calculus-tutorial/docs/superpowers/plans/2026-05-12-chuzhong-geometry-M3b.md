## Task 1: 01 圆基本概念（模板 C，1800-2500 字）

Title: `# 圆的基本概念`

- **图形特征**：到定点距离等于定长的所有点的集合（动态：旋转一线段一端定）
- **基本术语**：
  - **圆心 $O$、半径 $r$**
  - **弦**（连接圆上两点的线段）、**直径**（过圆心的弦，最长的弦 $= 2r$）
  - **弧**：圆上任意两点间的部分；劣弧（$<$ 半圆）、优弧（$>$ 半圆）、半圆
  - 记号：弧 $\overarc{AB}$
  - **圆心角**（顶点在圆心的角）
  - **同心圆 / 等圆**（半径相等的圆全等）
- **基本性质**：
  - 圆是轴对称图形——任一条直径所在直线都是对称轴（无数条对称轴）
  - 圆是中心对称图形——圆心是对称中心
  - **圆心角、弧、弦的关系**：在同圆或等圆中，相等的圆心角对应相等的弧、相等的弦（"三量同变")
- **典型应用** 3 例每带【思路】:
  - 例 1：基础——圆 $O$ 直径 $10$，弦 $AB = 6$，求弦心距（用勾股，结果 $4$）
  - 例 2：圆心角相等 → 弧相等 → 弦相等的链式推理
  - 例 3：求弧长（用比例 $\frac{n}{360°}$）和扇形面积（$\frac{n}{360°}\pi r^2$）
- **易错点**：直径必须经过圆心；弦不经过圆心；弧分劣弧/优弧；圆心角与圆周角是两个不同的角概念（圆周角在下一章）
- **自测题** 4 题。

## Task 2: 02 垂径定理（模板 C，1800-2500 字）

Title: `# 垂径定理`

- **图形特征**：圆 + 一条不经过圆心的弦 + 过圆心垂直于该弦的直径（或半径、直线）
- **垂径定理**：垂直于弦的直径**平分**弦，并且**平分**弦所对的两条弧
- **逆定理（4 条等价）**：在以下五个条件中，**任两个**成立都能推出其余三个：
  1. 直线（过圆心，含直径）
  2. 直线 ⊥ 弦
  3. 平分弦（不是直径）
  4. 平分劣弧
  5. 平分优弧
- **证明垂径定理**：连半径 $OA, OB$（$A, B$ 是弦端点），过 $O$ 作 $OD \perp AB$ 于 $D$。$\triangle OAD$ 与 $\triangle OBD$：$OA = OB$（半径），$OD$ 公共，两个直角 → HL → 全等 → $AD = BD$（平分弦）+ 对应弧相等（由圆心角相等→弧相等）
- **典型应用** 3 例每带【思路】:
  - 例 1：圆 $O$ 半径 $5$，弦 $AB = 8$，求圆心到弦的距离（**弦心距**，结果 $3$）
  - 例 2：**赵州桥模型** —— 已知拱跨度 $36$ 米、拱高 $7.2$ 米，求拱所在圆半径（设半径 $r$，用 $r^2 = (r-7.2)^2 + 18^2$ 解得 $r$）
  - 例 3：综合——已知两条平行弦的长度和圆半径，求两弦之间的距离（注意分两种情况：两弦在圆心同侧或异侧）
- **易错点**：
  - "过圆心"是关键前提
  - 弦心距 = 圆心到弦的**垂线段**长度
  - 两平行弦的距离要**分类讨论**（同侧/异侧）
- **自测题** 4 题。

## Task 3: 03 圆周角定理（模板 C，2200-3000 字）

Title: `# 圆周角定理`

- **图形特征**：顶点在圆上、两边都是弦的角
- **圆周角定理**：一条弧所对的**圆周角是它所对圆心角的一半**（$\angle ACB = \frac{1}{2} \angle AOB$）
- **推论 1**：同弧（或等弧）所对的**圆周角相等**
- **推论 2**：**直径所对的圆周角是直角**（$90°$ 圆周角）；反之，$90°$ 圆周角对的弦是直径
- **推论 3**：圆内接四边形对角互补
- **圆周角定理证明**（分三种情形）：
  - 情形 1：圆心 $O$ 在 $\angle ACB$ 的一边上（如 $OC$ 在 $CB$ 上）—— 用 $\triangle OAC$ 等腰（$OA = OC$ 半径）+ 外角定理直接推
  - 情形 2：圆心在角内部 —— 作辅助线 $CO$ 延长交圆于 $D$，分成情形 1 两次相加
  - 情形 3：圆心在角外部 —— 同样作 $CD$，分成情形 1 两次相减
- **典型应用** 3 例每带【思路】:
  - 例 1：基础——同弧所对圆周角相等，求未知角
  - 例 2：直径 + 90° 圆周角 —— $\triangle ABC$ 内接于圆 $O$，$AB$ 是直径，求 $\angle ACB$（$90°$）
  - 例 3：圆内接四边形 —— $ABCD$ 内接于圆，$\angle A = 80°$，求 $\angle C$（互补 → $100°$）
- **易错点**：
  - 圆周角顶点必须在**圆上**，两边都是**弦**
  - 推论 2 是直径所对，不是一般弦
  - "同弧" vs "等弧" 要严格区分（同弧是同一条；等弧是不同但相等的弧）
- **自测题** 5 题。

## Task 4: 04 位置关系（模板 C，2000-2800 字）

Title: `# 点、直线、圆与圆的位置关系`

- **点与圆**（设点到圆心距 $d$，半径 $r$）：
  - $d < r$ → 点在圆内
  - $d = r$ → 点在圆上
  - $d > r$ → 点在圆外
- **直线与圆**（设圆心到直线距离 $d$，半径 $r$）：
  - $d < r$ → **相交**（两个交点，直线是圆的**割线**）
  - $d = r$ → **相切**（一个交点，直线是圆的**切线**，交点是**切点**）
  - $d > r$ → **相离**（没有交点）
- **两圆位置关系**（圆心距 $d$，两半径 $r_1, r_2$，设 $r_1 \geq r_2$）：
  - **外离**：$d > r_1 + r_2$
  - **外切**：$d = r_1 + r_2$
  - **相交**：$r_1 - r_2 < d < r_1 + r_2$
  - **内切**：$d = r_1 - r_2$
  - **内含**：$d < r_1 - r_2$（特殊：$d = 0$ 即同心）
- **典型应用** 3 例：
  - 例 1：判断点与圆位置
  - 例 2：直线与圆相切的临界条件（求半径或距离）
  - 例 3：两圆位置 + 圆心距范围
- **易错点**：内切与外切都"切"，但圆心距公式不同；内含时两圆没有交点
- **自测题** 4 题。

## Task 5: 05 切线的判定与性质（模板 C，2000-2800 字）

Title: `# 切线的判定与性质`

- **切线性质**：圆的切线**垂直于过切点的半径**
- **切线判定（三个角度）**：
  1. **定义法**：与圆只有一个公共点 → 切线
  2. **距离法**：圆心到直线距离 $= r$ → 切线
  3. **判定定理（最常用）**：经过半径**外端**且**垂直**于这条半径的直线是圆的切线
- **判定定理与性质互为逆**
- **重要技巧（切线证明的"两手准备"）**：
  - 若直线**已与圆相交于已知点** $P$ → 连圆心与该点 $OP$，证 $OP \perp$ 直线（"**连半径证垂直**"）
  - 若直线**未明确与圆的交点** → 过圆心作 $OD \perp$ 直线，证 $OD = r$（"**作垂线证半径**"）
- **典型应用** 3 例：
  - 例 1：基础——给"半径垂直于直线"证切线
  - 例 2：**连半径证垂直** —— $\triangle ABC$ 中 $AB = AC$，圆 $O$ 与 $BC$ 相切于 $D$，$D$ 是 $BC$ 中点。证 $AB$ 与圆 $O$ 也相切的条件
  - 例 3：**作垂线证半径** —— 直角三角形 $\triangle ABC$ 中 $\angle C = 90°$，以 $AB$ 为直径的圆是否与 $BC$ 相切？过 $O$ 作 $OD \perp BC$，由 $O$ 是 $AB$ 中点 + 中位线性质 $OD = \frac{1}{2}AC$；只有 $AC = AB$ 时才相切，所以一般不相切。
- **易错点**：
  - 性质中"垂直"是切线 ⊥ 过切点的半径，不是任意半径
  - 用判定定理时必须确认"半径外端"且"垂直"
- **自测题** 5 题。

## Task 6: 06 切线长定理与内切圆（模板 C，2000-2800 字）

Title: `# 切线长定理与三角形的内切圆`

- **切线长定义**：从圆外一点引圆的切线，该点到切点之间线段的长度
- **切线长定理**：从圆外一点引圆的两条切线，**切线长相等**，且**圆心与该点的连线平分两切线的夹角**
- **证明**：用 HL 全等（两半径相等，斜边公共，两直角 → HL → 两切线长相等 + 对应角相等）
- **三角形的内切圆**：
  - 与三角形三边都相切的圆 = 内切圆
  - 内切圆圆心 = **内心**（三条角平分线交点，呼应 special/03）
  - 内切圆半径 $r$ 与三角形面积 $S$、半周长 $p = \frac{a+b+c}{2}$ 的关系：**$S = pr$**
  - 直角三角形（直角边 $a, b$、斜边 $c$）内切圆半径公式：$r = \frac{a+b-c}{2}$
- **典型应用** 3 例：
  - 例 1：圆外一点 $P$ 引两切线 $PA, PB$，$\angle APB = 60°$，$PA = 4$，求 $AB$ 长度（用切线长定理 + 等腰 + 60° → 等边 → $AB = 4$）
  - 例 2：求直角三角形 $3, 4, 5$ 的内切圆半径（$r = \frac{3+4-5}{2} = 1$）
  - 例 3：综合——给三角形三边求内切圆半径用 $S = pr$
- **易错点**：切线长是"线段"不是"直线"；内切圆与外接圆不要混淆（内切圆在内部，外接圆过三顶点）
- **自测题** 5 题。

## Task 7: 07 切割线模型（模板 D，2500-3200 字）

Title: `# 切割线模型`

**一图速记**:
> **一图速记**：圆外一点 $P$ 引一条切线 $PA$（$A$ 是切点）和一条割线 $PBC$（依次交圆于 $B, C$）→ $PA^2 = PB \cdot PC$（**切割线定理**）。

### 一、引入
> 圆 $O$ 外一点 $P$，$PA$ 切圆于 $A$，过 $P$ 的割线交圆于 $B, C$（$B$ 在 $P$ 与 $C$ 之间）。已知 $PA = 6, PB = 4$，求 $PC$。

### 二、思维路径还原 (10-12 行)
> "圆外一点引切线 + 割线 —— 经典切割线结构，先记着结论 $PA^2 = PB \cdot PC$，但要懂为什么。
> 怎么证？看图：连 $AB, AC$。要证 $PA^2 = PB \cdot PC$ ⇔ $\frac{PA}{PB} = \frac{PC}{PA}$ —— 这是两条线段成**比例**，立刻想到相似。
> 找相似：$\triangle PAB$ 与 $\triangle PCA$（注意字母顺序）。
> 共角：$\angle P$ 公共（两三角形都有 $\angle APB$，也就是 $\angle APC$，是同一个角）。
> 还差一对角。$\angle PAB$ 是什么？$PA$ 切圆于 $A$，$AB$ 是弦——**弦切角**！由**弦切角定理**：弦切角 $= $ 它所夹弧所对的圆周角。$\angle PAB$ 所夹的是 $\overarc{AB}$（不含 $C$），它所对的圆周角是 $\angle ACB$（同弧）。
> 所以 $\angle PAB = \angle ACB = \angle PCA$（$\angle PCA$ 就是 $\angle ACB$）。
> 两对角相等 → AA → $\triangle PAB \sim \triangle PCA$（注意对应：$P \leftrightarrow P, A \leftrightarrow C, B \leftrightarrow A$）。
> 由对应边比例：$\frac{PA}{PC} = \frac{PB}{PA}$ → **$PA^2 = PB \cdot PC$**。证毕。
> 回到题目：$6^2 = 4 \cdot PC \Rightarrow PC = 9$。"

### 三、抽象成模型
- 图形特征：圆 $O$ 外一点 $P$ + 一条切线 + 一条割线
- 核心结论：**$PA^2 = PB \cdot PC$**（切线长平方 = 割线两段乘积）
- 本质：圆**幂**的应用——$P$ 关于圆 $O$ 的"幂"是 $PA^2 = PB \cdot PC = d^2 - r^2$（$d$ 是 $P$ 到圆心距）
- 证法依赖**弦切角定理 + AA 相似（共角共边）**

### 四、模型变形
- **两割线版本**：两条割线 $PBC$ 与 $PDE$ → $PB \cdot PC = PD \cdot PE$（割线-割线定理）
- **两弦相交（点在圆内）**：圆内一点 $P$ 处两弦 $AB, CD$ 相交 → $PA \cdot PB = PC \cdot PD$（**相交弦定理**，呼应 sim/04 例 3）
- 切割线、割线-割线、相交弦三条等式**本质上都是圆幂定理的不同位置版本**

### 五、思考路标
- 看到圆外一点 + 切线 + 割线 → **切割线定理**
- 看到圆外一点 + 两条割线 → **割线-割线定理**
- 看到圆内一点 + 两弦相交 → **相交弦定理**
- 出现 $PA^2 = PB \cdot PC$ 形式 → 切割线背景
- 想证两段乘积相等 → 找圆幂结构

### 六、应用例题 (3 例)
- 例 1：基础切割线（同引入题）
- 例 2：两割线 —— $PA = 4, PB = 9$（$A$ 是第一条割线上靠近 $P$ 的点，$B$ 是远端），$PC = 3$ 第二条割线靠近端，求第二条远端 $PD$。【思路】$4 \times 9 = 3 \times PD$ → $PD = 12$
- 例 3：相交弦 —— 圆内 $P$，弦 $AB$ 过 $P$ 被分为 $PA = 2, PB = 6$；另一弦 $CD$ 过 $P$ 且 $PC = 3$，求 $PD$。【思路】$2 \times 6 = 3 \times PD \Rightarrow PD = 4$

### 七、思路自测题 4 题。

## Task 8: 08 四点共圆模型（模板 D，2500-3200 字）

Title: `# 四点共圆模型`

**一图速记**:
> **一图速记**：四个点在同一圆上 ⇔ 它们构成的四边形对角互补，或同侧两等角对同一段，或直角对斜边端点。识别后即可使用圆周角定理"传递角"。

### 一、引入
> 已知点 $A, B, C, D$ 中 $\angle ABD = \angle ACD$（且 $B, C$ 在 $AD$ 同侧）。证 $A, B, C, D$ 四点共圆，并由此推出 $\angle BAC = \angle BDC$。

### 二、思维路径还原 (10-12 行)
> "题目里两个等角 $\angle ABD = \angle ACD$，且这两个角'看着同一段 $AD$'——这是**四点共圆**判定 3 的标准形态（同弧/同侧等角）。
> 想象：如果 $A, B, C, D$ 在一个圆上，且 $B, C$ 同侧看 $AD$ —— 那么 $\angle ABD$ 与 $\angle ACD$ 都是 $\overarc{AD}$（同侧）所对的圆周角，由圆周角定理（part5/03）必然相等。
> 现在反过来：题目给了'两个角相等且看同一段'，这是**逆**事实——必然存在一个圆经过 $A, D$ 且让 $B, C$ 都在这个圆上。
> 严格证明：设过 $A, D, B$ 三点的圆为 $\omega$。$C$ 是否在 $\omega$ 上？反证：若 $C$ 不在 $\omega$ 上，设 $AC$ 与 $\omega$ 交于 $C'$（$\neq C$）。由圆周角 $\angle AC'D = \angle ABD = \angle ACD$。但 $\angle AC'D$ 与 $\angle ACD$ 是 $\triangle DC'C$ 的内外角关系（或对顶等），导致 $C = C'$ 矛盾。所以 $C$ 在 $\omega$ 上 → 四点共圆。
> 一旦共圆，所有同弧圆周角都相等：$\overarc{BC}$ 同侧的 $\angle BAC = \angle BDC$。证毕！
> 关键收益：识别出四点共圆后，可以**传递角度**——把一处的角'搬到'另一处。"

### 三、抽象成模型
- **判定 4 条（满足任一即四点共圆）**：
  1. 四点到某定点距离相等（直接给定）
  2. **对角互补的四边形** $\angle A + \angle C = 180°$ → 四点共圆（圆内接四边形性质的逆）
  3. **同侧等角看同一段** $\angle ABD = \angle ACD$（$B, C$ 在 $AD$ 同侧）→ 四点共圆
  4. **直角对斜边端点**：以一段为斜边的所有直角顶点都在同一圆上（斜边中点为圆心）—— part5/04 直角三角形外心
- **共圆后的红利**：所有同弧（或同侧等角看同段）的圆周角都相等 → 可以**任意搬动角度**

### 四、模型变形
- 直角三角形斜边为定线段时，多个直角顶点共圆（part5/03 推论 2 + 本节判定 4）
- 圆内接四边形可与正方形/矩形/等腰梯形结合（特殊四边形天然内接圆——矩形/正方形/等腰梯形）
- 在更高综合题里，"凑共圆"是隐藏的钥匙

### 五、思考路标
- 看到题目里有"两个相等角看同一段" → **四点共圆**
- 看到四边形"对角互补" → **四点共圆**
- 多个直角共一条斜边 → 直角顶点共圆
- 想"传递角度"——把角搬到远处 → 找四点共圆桥梁
- 圆内接四边形性质（对角互补）是反向使用的常用工具

### 六、应用例题 (3 例)
- 例 1：基础 —— 给同侧等角，证四点共圆（同引入题）
- 例 2：**对角互补 → 共圆** —— 四边形 $ABCD$ 中 $\angle BAD + \angle BCD = 180°$，证四点共圆，进而证某角等关系
