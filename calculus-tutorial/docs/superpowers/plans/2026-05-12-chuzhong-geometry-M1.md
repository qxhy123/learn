## Task 1: part1/01 点、线、面、体；直线/射线/线段

**File:** `chuzhong_math/part1-foundations/01-point-line-plane.md`

必须涵盖：

- **一、图形特征**：什么是点（位置抽象，无大小）、线（一维延伸）、面（二维）、体（三维）
- **二、定义**：
  - 直线：两端无限延伸，由两点确定（公理"两点确定一条直线"）
  - 射线：一端有端点、另一端无限延伸
  - 线段：两端都有端点
  - 表示法：直线 $l$ / 直线 $AB$；射线 $OA$（端点写前面）；线段 $AB$ 或 $\overline{AB}$
  - 长度：仅线段有长度概念
- **三、基本事实**：
  - 两点确定一条直线
  - 两点之间，线段最短（公理）
  - 两点间线段长度 = 两点间距离
- **四、典型应用**：
  - 例 1：判断"过一点能作多少条直线"——无数条；过两点——一条
  - 例 2：从 A 到 B 三种走法（直线/折线/弧），用"两点间线段最短"比较长短
  - 例 3：在数轴上，已知 A 坐标为 $-2$，B 坐标为 $5$，求 AB 长度（结果 $|5-(-2)|=7$）
- **五、易错点**：
  - 直线无端点、射线一个端点、线段两个端点——表示法不能混
  - 射线 $OA$ 与射线 $AO$ 不是同一条
  - 直线 $AB$ 与直线 $BA$ 是同一条
- **六、自测题**：5 题，覆盖定义辨析、长度计算、表示法

## Task 2: part1/02 角

**File:** `chuzhong_math/part1-foundations/02-angles.md`

必须涵盖：

- **一、图形特征**：从一点引出的两条射线构成的图形
- **二、定义与度量**：
  - 角的两种定义：①静态——两条有公共端点的射线 ②动态——一条射线绕端点旋转
  - 表示法：$\angle ABC$（顶点写中间）/ $\angle B$（无歧义时）/ $\angle 1$（标号）
  - 度量：1 周角 = $360°$，1° = 60′，1′ = 60″
  - 分类：锐角（$<90°$）、直角（$=90°$）、钝角（$>90°, <180°$）、平角（$=180°$）、周角（$=360°$）
- **三、为什么这么分**：分类的依据是与直角和平角的关系，便于后续讨论
- **四、典型应用**：
  - 例 1：度分秒换算——把 $32°25'48''$ 化成度（$\approx 32.43°$）
  - 例 2：角度加减——$48°36'27'' + 25°48'45''$ 注意进位
  - 例 3：钟面问题——3 点 20 分，时针与分针的夹角（结果 $20°$）
- **五、易错点**：
  - 度分秒进位是 60 进制，不是 100
  - $\angle ABC$ 顶点必须在中间字母位置
  - 钟面问题要算时针的"额外移动"
- **六、自测题**：5 题

## Task 3: part1/03 角平分线

**File:** `chuzhong_math/part1-foundations/03-angle-bisector.md`

必须涵盖：

- **一、图形特征**：从角的顶点引出的、把角分成两个相等部分的射线
- **二、定义与性质**：
  - 定义：$\angle AOB$ 内部一条射线 $OC$，若 $\angle AOC = \angle COB$，则 $OC$ 是 $\angle AOB$ 的平分线
  - 等价表达：$\angle AOC = \angle COB = \frac{1}{2}\angle AOB$
  - **核心性质（重要）**：角平分线上任一点到角两边的距离相等
  - **逆定理**：到角两边距离相等的点在角平分线上
- **三、性质证明**：用两个三角形全等（HL 或 AAS）证明性质定理
  - 设 $P$ 在 $\angle AOB$ 平分线上，过 $P$ 分别向 $OA, OB$ 作垂线 $PM, PN$
  - $\triangle OPM$ 与 $\triangle OPN$：$\angle MOP = \angle NOP$（平分），$\angle PMO = \angle PNO = 90°$，$OP$ 公共
  - AAS → $\triangle OPM \cong \triangle OPN$ → $PM = PN$
- **四、典型应用**：
  - 例 1：已知 $OC$ 平分 $\angle AOB$，$\angle AOB = 70°$，求 $\angle AOC$
  - 例 2：在 $\triangle ABC$ 中，AD 是 $\angle BAC$ 的平分线，过 D 作 $DE \perp AB, DF \perp AC$，证 $DE = DF$
  - 例 3：经典——三角形内角平分线交于一点（内心），到三边距离相等
- **五、易错点**：
  - 角平分线是"射线"，不是"直线"
  - 性质讲的是"到两边的距离"，不是"到顶点的距离"
  - 平分线只在角内部
- **六、自测题**：4 题，包括一个需要构造辅助线（过点作垂线）的题

## Task 4: part1/04 余角与补角

**File:** `chuzhong_math/part1-foundations/04-complementary-supplementary.md`

必须涵盖：

- **一、图形特征**：两个角之和等于 $90°$ → 互余；等于 $180°$ → 互补
- **二、定义与性质**：
  - 互余：$\angle 1 + \angle 2 = 90°$，则 $\angle 1$ 与 $\angle 2$ 互为余角
  - 互补：$\angle 1 + \angle 2 = 180°$，则 $\angle 1$ 与 $\angle 2$ 互为补角
  - **关键性质 1**：同角（或等角）的余角相等
  - **关键性质 2**：同角（或等角）的补角相等
- **三、性质证明**：
  - 设 $\angle 1 + \angle 3 = 90°$ 且 $\angle 2 + \angle 3 = 90°$，则 $\angle 1 = 90° - \angle 3 = \angle 2$
- **四、典型应用**：
  - 例 1：已知 $\angle A = 35°$，求 $\angle A$ 的余角和补角
  - 例 2：一个角的补角比它的余角大多少？（答：$90°$，恒定）
  - 例 3：在 $\triangle ABC$ 中，$\angle C = 90°$，则 $\angle A$ 与 $\angle B$ 互余（直角三角形锐角性质）
  - 例 4：思路题——若 $\angle 1$ 与 $\angle 2$ 互余，$\angle 2$ 与 $\angle 3$ 互补，且 $\angle 1 = 30°$，求 $\angle 3$（答：$120°$）
- **五、易错点**：
  - 互余/互补只与角的度数有关，与角的位置无关——两个角可以"远在天涯"也能互余
  - 互余必有两个锐角；互补可以是两个锐角与钝角，或两个直角
  - "同角的余角相等"是后续证明两角相等的常用桥梁
- **六、自测题**：4 题

## Task 5: part2/01 对顶角与邻补角

**File:** `chuzhong_math/part2-parallel-lines/01-vertical-and-adjacent-angles.md`

必须涵盖：

- **一、图形特征**：两条直线相交，产生 4 个角。其中"位置对面"的两角 → 对顶角；"相邻共边"的两角 → 邻补角
- **二、定义**：
  - **邻补角**：两个角有公共顶点、公共边，另一边互为反向延长线
  - **对顶角**：两个角有公共顶点，且一个角的两边分别是另一个角的两边的反向延长线
  - **核心定理**：对顶角相等；邻补角互补（和为 $180°$）
- **三、证明对顶角相等**：
  - 设直线 AB 与 CD 交于 O。$\angle AOC$ 与 $\angle BOD$ 是对顶角
  - $\angle AOC + \angle AOD = 180°$（邻补角）
  - $\angle BOD + \angle AOD = 180°$（邻补角）
  - 同角的补角相等 → $\angle AOC = \angle BOD$
- **四、典型应用**：
  - 例 1：两直线相交，已知 $\angle 1 = 70°$，求其他三个角
  - 例 2：三条直线交于一点，已知 $\angle 1 = 50°, \angle 2 = 60°$，求其他角（共 6 个角）
  - 例 3：思路题——若邻补角中其中一角等于另一角的 2 倍，求各角度数（$60°, 120°$）
- **五、易错点**：
  - 对顶角必须是两直线相交而成——三条线交于一点时要小心配对
  - 邻补角不仅相邻还必须满足"另一边为反向延长线"，否则只是相邻不是邻补
  - 对顶角相等 是后续证明两角相等的最常用桥梁之一
- **六、自测题**：4 题

## Task 6: part2/02 垂线、点到直线距离

**File:** `chuzhong_math/part2-parallel-lines/02-perpendicular-line.md`

必须涵盖：

- **一、图形特征**：两条直线相交成直角
- **二、定义与性质**：
  - 垂直：两直线相交，其中一个角为 $90°$，记作 $l_1 \perp l_2$
  - 垂足：垂直时的交点
  - **垂线公理**：过直线外一点（或直线上一点）有且只有一条直线与已知直线垂直
  - **垂线段最短**：直线外一点与直线上各点连线中，垂线段最短
  - **点到直线距离**：垂线段的长度
- **三、为什么垂线段最短**：
  - 由斜边大于直角边（勾股定理推论）。设 P 是直线 $l$ 外一点，$PA \perp l$ 于 A，$B$ 是 $l$ 上另一点
  - 在 $\triangle PAB$ 中，$\angle PAB = 90°$，则 $PB$ 是斜边 → $PB > PA$
- **四、典型应用**：
  - 例 1：尺规作图——过直线外一点作直线的垂线（描述步骤）
  - 例 2：在 $\triangle ABC$ 中，$\angle C = 90°, AC = 3, BC = 4$，求点 $C$ 到 $AB$ 的距离（用面积法：$\frac{1}{2}\cdot AC \cdot BC = \frac{1}{2} \cdot AB \cdot h$，$AB = 5$，$h = 12/5$）
  - 例 3：思路题——在公路 $l$ 旁建一个供电站，使两村 A、B 到供电站距离之和最小（引出"将军饮马"萌芽）
- **五、易错点**：
  - "距离"特指垂线段的长度，不是任一连线
  - 垂线公理强调"有且只有"
  - 直角三角形面积法是求点到直线距离的实用工具
- **六、自测题**：4 题

## Task 7: part2/03 三线八角

**File:** `chuzhong_math/part2-parallel-lines/03-three-line-eight-angles.md`

必须涵盖：

- **一、图形特征**：两条直线 $a, b$ 被第三条直线 $l$（截线）所截，产生 8 个角
- **二、三类角的定义**：
  - **同位角**：截线同侧、被截两直线同方向（"F 形"）—— 4 对
  - **内错角**：截线两侧、被截两直线内侧（"Z 形"）—— 2 对
  - **同旁内角**：截线同侧、被截两直线内侧（"U 形"）—— 2 对
- **三、识别口诀**：
  ```
  同位 F，内错 Z，同旁内 U（或 C）
  ```
  - 同位角：在截线同一侧，且在被截直线同一方向 → 形如 F
  - 内错角：在截线两侧，且在被截两直线之间 → 形如 Z
  - 同旁内角：在截线同一侧，且在被截两直线之间 → 形如 U
- **四、典型应用**：
  - 例 1：给定一个三线八角的标号图（文字描述：$\angle 1$ 到 $\angle 8$ 位置），列出所有同位角、内错角、同旁内角对
  - 例 2：在复杂图中识别——一条线段同时充当截线和被截线时的辨别
  - 例 3：已知 $\angle 1$ 和 $\angle 2$ 是内错角，$\angle 1 = 50°$，**仅根据"内错角"这个位置关系**能确定 $\angle 2$ 吗？（不能；位置关系不蕴含数量关系，需要两直线平行才能推出相等）
- **五、易错点**：
  - 三线八角是"位置关系"，**不蕴含任何数量关系**——只有当两直线平行时才出现相等/互补
  - 识别时先找截线（即第三条线）
  - 同一对角，名称随你选哪条做截线而变化
- **六、自测题**：4 题，重点是识别

**说明**：本节是为后续 04（判定）和 05（性质）做铺垫，本节只讲"是什么"，不讲"相等/互补"。

## Task 8: part2/04 平行线的判定

**File:** `chuzhong_math/part2-parallel-lines/04-parallel-criteria.md`

必须涵盖：

- **一、图形特征**：两条直线 $a, b$ 被第三条直线所截，某对角满足特定数量关系 → $a \parallel b$
- **二、判定定理（三条）**：
  - **判定 1**：同位角相等，两直线平行
  - **判定 2**：内错角相等，两直线平行
  - **判定 3**：同旁内角互补，两直线平行
  - **基本事实（平行公理）**：过直线外一点，有且只有一条直线与已知直线平行
  - **推论**：两条直线都与第三条平行，则这两条直线平行
- **三、证明判定 2 用判定 1**（理解判定之间的关系）：
  - 设内错角 $\angle 1 = \angle 2$
  - 设 $\angle 3$ 是 $\angle 1$ 的对顶角，则 $\angle 3 = \angle 1$（对顶角相等）
  - 所以 $\angle 3 = \angle 2$（$\angle 3$ 与 $\angle 2$ 是同位角）
  - 由判定 1 → 两直线平行
- **四、典型应用**：
  - 例 1：基础——已知图中某对内错角相等，证两直线平行
  - 例 2：思路题——证两直线平行需要先识别截线和角的位置关系，再选定理。给一道需要先找截线的题
  - 例 3：思路题——题目里没有给出明显的角相等条件，但给了两对垂直关系（$a \perp l, b \perp l$），证 $a \parallel b$（用"垂直于同一直线的两直线平行"，是判定 1 的推论）
- **五、易错点**：
  - 判定与性质是双向的关系——判定是"角关系 ⇒ 平行"，性质是"平行 ⇒ 角关系"，方向不能搞反
  - 用判定前必须先找清楚截线和被截直线
  - "同旁内角互补"中"互补"易误写为"相等"
- **六、自测题**：4 题

## Task 9: part2/05 平行线的性质与应用

**File:** `chuzhong_math/part2-parallel-lines/05-parallel-properties.md`

必须涵盖：

- **一、图形特征**：两直线平行 + 一条截线 → 8 个角之间有固定数量关系
- **二、性质定理（三条）**：
  - **性质 1**：两直线平行，同位角相等
  - **性质 2**：两直线平行，内错角相等
  - **性质 3**：两直线平行，同旁内角互补
  - **推论**：两条平行线之间的距离处处相等
- **三、性质 1 的地位**（平行公理的推论，作为最基础）：
  - 性质 1 在课本里通常作为基本事实
  - 性质 2 可由性质 1 + 对顶角证明：内错角 $\angle 1 = \angle 3$（对顶角），$\angle 3 = \angle 2$（同位角，由性质 1），所以 $\angle 1 = \angle 2$
  - 性质 3 同理：同旁内角 $\angle 1 + \angle 4 = 180°$，因 $\angle 4$ 与 $\angle 2$ 是同位角等 → $\angle 1 + \angle 2 = 180°$
- **四、判定 vs 性质 对比表**（必须包含）：

  | 名称 | 已知 | 结论 |
  |---|---|---|
  | 判定 | 角的关系 | 两直线平行 |
  | 性质 | 两直线平行 | 角的关系 |

- **五、典型应用**：
  - 例 1：经典——平行线间转折角问题。$AB \parallel CD$，中间有一点 $P$，求证 $\angle APC = \angle BAP + \angle DCP$（**思路**：过 $P$ 作 $PE \parallel AB$，利用内错角）
  - 例 2：思路题——平行线 + 角平分线：$AB \parallel CD$，$\angle BAE$ 和 $\angle DCE$ 的平分线交于 $F$，证 $AF \parallel CF$ 或类似结论（用性质把角传递过去）
  - 例 3：综合——三角形内角和定理可由平行线性质证明（过顶点作底边平行线，引出内错角拼成平角）
- **六、易错点**：
  - 用性质前先确认"已经有平行"，不能 mit "想证平行"用性质
  - "拐角处过点作平行线"是处理平行线间折线最常见的辅助线（呼应 toolkit 02）
  - 性质 3 的"互补"易误用为"相等"
- **七、自测题**：5 题，至少一题需要作辅助线
