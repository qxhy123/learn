- 用一个对比例子说明：同一道题，新手看到的是"一堆条件"，高手看到的是"两个共顶点等腰三角形 → 手拉手"

4. 跳步证明：思路对但写不严谨，丢分严重

**小节 4：怎么读这本书最有效**

## Task 3: 何时该作辅助线

**Files:**
- Create: `chuzhong_math/thinking-toolkit/01-when-to-draw-auxiliary-line.md`

- [ ] **Step 1: 创建目录与文件**

需先创建目录 `chuzhong_math/thinking-toolkit/`。

文件必须按以下结构组织，每节内容要点必须全部覆盖：

**一、辅助线不是灵光一闪**
- 反驳"辅助线靠悟性"的迷信
- 辅助线 = 条件还没用完时的补丁。你之所以卡住，是因为某个条件还没被"激活"

**二、识别"该作辅助线"的 6 类信号**

每类必须给出：信号特征 + 一个最简短的图示描述（文字描述图形即可，本节暂不画 TikZ）+ 通常的辅助线做法。

1. **出现中点** → 想"中线倍长" / "斜边中线" / "中位线" / "中点四边形"
2. **出现角平分线** → 想"过角平分线上一点作两边垂线"（构造等腰、构造全等）/ "翻折"
3. **出现等腰三角形** → 想"三线合一"（作底边中线/高/顶角平分线）
4. **出现直角** → 想"构造直角三角形用勾股" / "斜边中线 = 斜边一半"
5. **出现圆 + 弦** → 想"过圆心作弦的垂线"（垂径定理）/ "连半径" / "连圆心与切点"
6. **出现需要证明的等量关系但找不到全等/相似** → 想"截长补短" / "旋转构造" / "平移构造"

**三、辅助线作完之后**
- 做完辅助线，必须能说出"为什么要作它"——目的是构造哪个模型 / 利用哪个定理
- 如果作完发现没用上新条件，说明这条辅助线作错了，回退

**四、一个完整的思考演示**
给出一道简单例题（描述题目，不需要图）：
> 在 △ABC 中，D 是 BC 中点，求证：AD < (AB+AC)/2

完整演示作辅助线的内心独白：
- 看到中点 D → 信号 1 → 试"中线倍长"
- 延长 AD 到 E 使 DE = AD → 构造出 △ABD ≅ △ECD（SAS）→ 得 EC = AB
- 在 △AEC 中用三边关系：AE < AC + EC = AC + AB → 2AD < AB + AC → 得证

**五、自检 checklist（作辅助线前问自己）**
- 题目里哪些条件我还没用上？
- 这个条件通常对应哪类辅助线？（对照上面 6 类信号）
- 作完后我想构造哪个模型？

## Task 5: 模型识别速查

**Files:**
- Create: `chuzhong_math/thinking-toolkit/03-model-recognition.md`

- [ ] **Step 1: 创建文件并写入完整内容**

本篇是**反射弧训练手册**：看到什么图形特征 → 立刻想到什么模型。

文件结构：

**一、什么是"模型"**
- 模型 = 一个反复出现的图形组合 + 它的固定结论
- 认出模型 = 把"陌生题"翻译成"我见过的图"
- 本节只做识别速查，模型的证明留到对应章节

**二、必背模型清单（每个模型给出：图形特征 / 结论 / 关键词）**

按模型分组，每组用统一格式：

**全等类模型**
1. **手拉手模型**
   - 特征：两个共顶点的等腰三角形（顶角相等）
   - 结论：两腰端点连线相等；旋转角 = 顶角
   - 关键词：共顶点等腰、共顶点等边、共顶点等腰直角

2. **一线三等角（K 字模型）**
   - 特征：一条直线上有三个相等的角
   - 结论：直线两侧两个三角形相似（或全等）

3. **半角模型**
   - 特征：正方形 / 等腰直角三角形 + 顶点处一个等于半顶角的角
   - 结论：通过旋转把分散的两段折合为一段

4. **倍长中线**
   - 特征：题目出现中线或中点
   - 结论：延长一倍构造全等

5. **角平分线 + 垂线**
   - 特征：角平分线上一点向两边作垂线
   - 结论：构造两个全等直角三角形

**相似类模型**
6. **A 字 / X 字 / 8 字模型**
   - 特征：两平行线被两直线所截
   - 结论：对应三角形相似

7. **母子相似（射影定理）**
   - 特征：直角三角形斜边上的高
   - 结论：三个三角形两两相似；$h^2 = pq$, $a^2 = pc$, $b^2 = qc$

8. **共角共边相似**
   - 特征：两三角形共一个角，且夹这个角的两边成比例
   - 结论：相似

**圆类模型**
9. **四点共圆**
   - 特征：①对角互补的四边形 ②直角对斜边端点 ③同侧等角对同一线段
   - 结论：四点共圆 → 利用圆周角

10. **切割线模型**
    - 特征：圆外一点引切线与割线
    - 结论：切线长² = 割线两段乘积

**变换类模型**
11. **将军饮马（最值）**
    - 特征：定直线 + 两定点，求到两定点距离之和最小
    - 结论：作对称点 → 共线最短

12. **胡不归 / 阿氏圆（最值进阶）**
    - 特征：带系数的距离和（如 PA + k·PB）求最小
    - 结论：构造相似把系数"转化"掉

13. **翻折模型**
    - 特征：折叠题
    - 结论：折痕是对称轴；对应边/角相等；折痕 ⊥ 对应点连线

14. **旋转构造模型**
    - 特征：题中出现 60°、90°、120° 或等边/等腰直角
    - 结论：旋转对应角度，把分散条件集中

**三、识别口诀（便于记忆）**

## Task 6: 转化思想

**Files:**
- Create: `chuzhong_math/thinking-toolkit/04-conversion-techniques.md`

- [ ] **Step 1: 创建文件并写入完整内容**

本篇讲**转化思想**——几何里最高层的方法论。

文件结构：

**一、为什么需要转化**
- 题目给的条件往往不能直接用
- 解题 = 把陌生 / 分散 / 难处理的条件，转化为熟悉 / 集中 / 易处理的形式
- 转化思想贯穿初中几何始终

**二、五类核心转化**

**1. 动 → 静**
- 场景：动点题
- 方法：抓住"运动的瞬间"或"运动的极端位置"；把动点用参数表示
- 举例（文字描述）：动点 P 在线段 AB 上运动，求 △CPD 面积最大时 P 的位置 → 设 AP = t，用 t 表示面积，再求最值

**2. 形 → 数**
- 场景：坐标系中的几何题
- 方法：把图形条件翻译成坐标关系（距离公式、斜率、点的对称）
- 举例：求三角形顶点轨迹 → 设点 (x,y)，把条件写成方程

**3. 数 → 形**
- 场景：纯代数题但有几何意义
- 方法：把代数式翻译成图形语言
- 举例：求 $\sqrt{x^2 + 4} + \sqrt{(8-x)^2 + 9}$ 的最小值 → 看成两段距离之和 → 将军饮马

**4. 未知 → 已知**
- 场景：要证 / 要求的量没有直接条件
- 方法：找它与已知量的关系——通过全等 / 相似 / 等量代换搭桥
- 举例：证 AB = CD，但 AB 和 CD 不在同一三角形 → 找一条中间线段 EF，证 AB = EF 且 EF = CD

**5. 分散 → 集中**
- 场景：条件散落在图的不同位置
- 方法：通过辅助线 / 旋转 / 平移 / 翻折，把分散条件拼到一起
- 举例：两段线段不在同一直线 → 旋转其中一段，使两段共线

**三、转化的总思路图**

```
卡住了 → 检查：我能不能把这个东西换种形式？
  ├── 是动的吗？ → 动→静
  ├── 是图形吗？  → 形→数 或 用坐标
  ├── 是代数式吗？→ 数→形
  ├── 是未知量吗？→ 未知→已知（搭桥）
  └── 是分散的吗？→ 分散→集中（辅助线/变换）
```

**四、一个完整的转化演示**

题目（文字描述）：
> 求 $\sqrt{x^2+1} + \sqrt{(x-3)^2 + 4}$ 的最小值。

转化过程的内心独白：
- 第一反应：纯代数式，求导？太难
- 应用"数→形"：$\sqrt{x^2+1}$ 是点 (x, 0) 到 (0, 1) 的距离；$\sqrt{(x-3)^2+4}$ 是 (x, 0) 到 (3, 2) 的距离
- 原式 = x 轴上一点到 (0,1) 与 (3,2) 距离之和
- 应用"将军饮马"：两点同侧 → 作 (0,1) 关于 x 轴的对称点 (0,-1)
- 距离之和最小 = (0,-1) 到 (3,2) 的距离 = $\sqrt{9+9} = 3\sqrt{2}$

**五、练习建议**
- 每做完一道题，问自己：我用了哪类转化？
- 如果发现自己"凭直觉"做出来了，强迫自己事后用上面 5 类去归类
- 长期训练后，转化会从"刻意操作"变成"本能反应"

## Task 7: 开题前的自检清单

**Files:**
- Create: `chuzhong_math/thinking-toolkit/05-checklist-before-solving.md`

- [ ] **Step 1: 创建文件并写入完整内容**

本篇是**最实用的一篇**：拿到一道几何题，开做之前的 5 分钟该问自己什么。

文件结构：

**一、为什么需要"开题清单"**
- 大多数人卡住的真正原因：开始动笔太早，没看清图
- 5 分钟的思考远胜 30 分钟的乱试

**二、开题 7 问**

按顺序，每问必须给出：为什么问 + 怎么问 + 典型例子。

**Q1. 已知条件有哪些？我有没有把每一条都标到图上？**
- 为什么：条件没标到图上 = 没真正"看见"
- 怎么做：用不同颜色 / 符号标长度相等、角相等、平行、垂直
- 例子：题目说 AB = CD，立刻在图上的 AB 和 CD 标同一种短横线

**Q2. 要求的是什么？最终目标用什么形式表达？**
- 为什么：搞错目标 = 白做
- 怎么做：把要证 / 要求的写在草稿纸最上方，时刻盯着
- 区分：求值题、证明题、存在性题、最值题 —— 思路差异很大

**Q3. 这张图里有没有我熟悉的模型？**
- 为什么：模型识别是几何思维的第一性能指标
- 怎么做：对照思维工具箱 03 篇的 14 个模型逐一扫一遍
- 例子：看到两个共顶点等腰三角形 → 手拉手 → 立刻有方向

**Q4. 有哪些条件我还没用上？**
- 为什么：题目里给的每个条件几乎都有用——没用上的条件就是突破口
- 怎么做：列清单，逐项检查
- 例子：题目特意说"D 是中点"，但你的证明里没出现 D 的中点性质 → 一定漏了什么

**Q5. 如果直接证不出来，我能不能转化？**
- 为什么：见 04 篇五类转化
- 怎么做：对照"动→静 / 形→数 / 数→形 / 未知→已知 / 分散→集中"逐一试

**Q6. 要不要作辅助线？作哪条？**
- 为什么：辅助线是激活闲置条件的开关
- 怎么做：对照思维工具箱 01 篇的 6 类信号
- 例子：图里有中点但没用上 → 试中线倍长 / 中位线

**Q7. 如果是综合题，能不能拆成几步？**
- 为什么：综合题的每一小问通常是后续小问的"垫脚石"
- 怎么做：第(1)问几乎一定要在第(2)、(3)问中被引用，明确"第(1)问给我留下了什么有用结论"
- 例子：第(1)问证了 △ABC ≅ △DEF → 第(2)问大概率要用到对应边/角相等

**三、清单使用示范**

给出一道中等难度的虚拟题（文字描述图形即可），完整走一遍 7 问：

> 在正方形 ABCD 中，E 是 BC 边上一点，F 在 CD 延长线上，且 BE = DF。AE 交 BD 于 G，求证：AG = GE。

逐问演示：
- Q1：标条件——正方形、BE = DF
- Q2：求证 AG = GE
- Q3：模型扫描——正方形 + 等量线段 → 可能旋转构造（半角模型？手拉手？）
- Q4：BE = DF 还没用 → 一定要用
- Q5：能不能转化？AG = GE → 证 G 是 AE 中点 → 等价于证某种对称
- Q6：辅助线？连 AF？连 EF？
- Q7：本题非综合题，跳过

最终思路（简述）：连 AF → 证 △ABE ≅ △ADF（SAS，正方形提供边和角，BE=DF）→ AE = AF → △AEF 等腰 → ...

**四、把清单内化**
- 刚开始可以纸上写"7 问"标题逐项回答
- 训练 2-3 周后，过这一遍只需要 30 秒
- 这 30 秒能救回 80% 卡题

**结尾**：呼应序言——几何不靠天赋，靠习惯。
