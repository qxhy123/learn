## Task 1: 01 线上动点（模板 D，2800-3500 字）

Title: `# 线上动点问题`

**一图速记**:
> **一图速记**：动点 $P$ 在某条线段上滑动 → 把动点位置用**参数**（如 $AP = t$）表示，再把目标量（角、边、面积、最值）用 $t$ 的代数式写出来——把"动"翻译成"静"。

**引入题**：
> 矩形 $ABCD$ 中 $AB = 6, BC = 4$。动点 $P$ 从 $A$ 出发沿 $AB$ 向 $B$ 匀速运动，速度 $1$ 单位/秒。设运动时间 $t$ 秒。
> (1) 用 $t$ 表示 $\triangle DPC$ 的面积；
> (2) $t$ 为何值时 $\triangle DPC$ 是等腰三角形？

**思维路径还原** 要点（10-15 行）：
- 看到"动点 + 运动时间" → 立刻设参数 $t$
- 把 $P$ 坐标 / 位置用 $t$ 表示
- 面积用底高公式（$\triangle DPC$ 底 $DC = 6$，高 $= BC = 4$？不对……重看图）
- 实际：底是 $DP$ 或 $PC$，高是 $BC = 4$
- 等腰要**分类讨论**：$PD = PC$ / $PD = DC$ / $PC = DC$，每种列方程
- 解方程时注意 $t$ 的取值范围 $0 \leq t \leq 6$，舍掉不合理解

**抽象成题型**：
- 设参数（运动时间 $t$ 或长度 $x$）
- 把所求量用参数代数式表达
- 列方程或函数
- 检查参数范围

**模型变形**：
- 多动点同时运动（用同一参数）
- 折返运动（分段讨论）
- 动点在多条边上转折（分段函数）

**思考路标**：
- 看到"动点 + 速度 + 时间" → 设参数 $t$
- 看到等腰/直角/平行四边形等"特殊形状成立" → 分类讨论 + 列方程
- 看到面积 / 周长求最值 → 用配方法或二次函数顶点
- **不要忘记验证 $t$ 的取值范围**

**应用例题** 3 例：基础面积 + 等腰分类 / 直角分类 / 多动点联动

**自测题** 4 题。

## Task 2: 02 抛物线动点（模板 D，3000-3800 字）

Title: `# 抛物线 / 坐标系动点问题`

**一图速记**:
> **一图速记**：动点 $P$ 在抛物线（或一次函数图象）上滑动 → 把 $P$ 设为 $(x, f(x))$，再把题目要求的几何条件（距离、角、面积、平行/垂直等）翻译为关于 $x$ 的方程或函数。这是"形→数"的极致应用（呼应 toolkit/04 转化 2）。

**引入题**：
> 抛物线 $y = x^2 - 2x - 3$ 与 $x$ 轴交于 $A, B$（$A$ 在左），与 $y$ 轴交于 $C$。设 $P$ 是抛物线上一动点，问 $P$ 在何处时 $\triangle PBC$ 的面积最大？

**思维路径还原** 要点：
- 先求 $A(-1,0), B(3,0), C(0,-3)$
- 设 $P(x, x^2 - 2x - 3)$，注意 $P$ 应在 $B$、$C$ 之间或符合题意区段
- $\triangle PBC$ 面积怎么求？常用"水平线 / 竖直线分割法"——过 $P$ 作 $x$ 轴垂线，或用底 $BC$ 配高
- **最佳套路**：底取 $BC$，高 $= P$ 到直线 $BC$ 的距离
- 用点到直线距离公式 / 或者更巧：用"$x$ 轴上一点到直线 $BC$ 的距离"作参考，再用 $\triangle PBC$ 面积 = "竖直距离" $\times \frac{1}{2} \times |x_B - x_C|$ 等
- 写出面积 $S(x)$ 是 $x$ 的二次函数 → 配方求顶点

**抽象成题型**：
- 设动点坐标（用函数表达式表示纵坐标）
- 把几何条件翻译为方程或表达式
- 求最值用配方法或二次函数顶点公式
- 求存在性用分类讨论列方程

**思考路标**：
- 动点在抛物线上 → 设 $P(x, ax^2+bx+c)$
- 求三角形面积最值 → 用"竖直距离 / 水平底"分割法或点到直线距离
- 求与定点距离最值 → 距离公式 → 二次函数最值（注意根号下函数变化趋势）
- 求"使为等腰/直角/平行四边形"的 $P$ → 分类 + 列方程
- **数形结合**：可能需要画函数图象辅助判断

**应用例题** 3 例：面积最值 / 等腰存在性 / 平行四边形存在性

**自测题** 4 题。

## Task 3: 03 几何最值（将军饮马、胡不归、阿氏圆）（模板 D，3000-3800 字）

Title: `# 几何最值：将军饮马、胡不归、阿氏圆`

**一图速记**:
> **一图速记**：求**距离之和**或**带系数距离之和**的最小值时，用对称、构造等手段把"分散的两段或带系数的距离"转化为"一条直线"。三大经典模型：将军饮马（PA+PB）、胡不归（PA + k·PB，$0<k<1$）、阿氏圆（k·PA + PB）。

**引入题**：
> （将军饮马）已知直线 $l$ 和 $l$ 同侧两点 $A, B$。在 $l$ 上找一点 $P$，使 $PA + PB$ 最小。

**思维路径还原** 要点（10-15 行）：
- 看到"两段距离之和的最小值" → 立刻想"共线最短"
- 但 $A, B$ 同侧 $l$，直接连 $AB$ 不在 $l$ 上 → **作对称**
- 作 $A$ 关于 $l$ 的对称点 $A'$，$PA = PA'$
- 现在求 $PA' + PB$ 最小：$A', B$ 在 $l$ 异侧 → 连 $A'B$ 与 $l$ 的交点就是 $P$，最小值 = $|A'B|$
- 推广到 $A, B$ 异侧：直接连 $AB$ 即可，无需对称
- 这就是**将军饮马**

**抽象成题型**：

三大模型对比（必须用 markdown 表格）：

| 模型 | 形式 | 关键技巧 | 转化为 |
|---|---|---|---|
| 将军饮马 | $PA + PB$ 最小 | 作 $A$（或 $B$）关于直线的对称 | $A'B$ 直线段 |
| 胡不归 | $PA + k \cdot PB$ ($0<k<1$) | 把 $k \cdot PB$ 用相似 / sin 转化为"另一段距离" | 转化后两段距离之和 |
| 阿氏圆 | $\frac{PA}{PB}$ 为定值，求 $PA + PB$ 等 | 用阿波罗尼斯圆找到 $P$ 的轨迹 | 圆 + 两定点最值 |

**胡不归详解**：
- 形式：$PA + k \cdot PB$，$P$ 在直线 $l$ 上，$0 < k < 1$
- 技巧：把 $k \cdot PB$ 用"作角 $\sin \alpha = k$"转化为 $B$ 到一条新直线的距离
- 几何意义：$P$ 到 $A$ 的距离 + $B$ 到一条直线的"投影距离"——共线时最小

**阿氏圆详解**：
- 阿波罗尼斯圆：到两定点 $A, B$ 距离之比为定值 $k$（$k \neq 1$）的点的轨迹是**一个圆**
- 应用于 $PA + k \cdot PB$ 类型（$P$ 在某圆上）—— 通过相似找到"$k \cdot PB$ 等于另一段距离 $PB'$"，化为 $PA + PB'$ 共线最短

**思考路标**：
- "两段距离和最小" + "$P$ 在直线上" → 将军饮马
- "$PA + k \cdot PB$ 最小" + $0<k<1$ + $P$ 在直线上 → 胡不归
- "$P$ 在圆上 + $\frac{PA}{PB}$ 关系" → 阿氏圆
- 看到题目里出现"$k$ 倍距离" → 想能否用相似把系数"转化"掉

**应用例题** 3 例：纯将军饮马 / 胡不归 / 阿氏圆基础

**自测题** 4 题。

## Task 4: 04 存在性问题（模板 D，2800-3500 字）

Title: `# 存在性问题`

**一图速记**:
> **一图速记**：题目问"是否存在某点 $P$ 使图形是特殊形状（等腰/直角/平行四边形等）" → **分类讨论 + 列方程**。一个特殊形状通常对应 2-4 种情形，遗漏任一情形都丢分。

**引入题**：
> 抛物线 $y = -x^2 + 2x + 3$ 与 $x$ 轴交于 $A, B$（$A$ 左），与 $y$ 轴交于 $C$。在 $x$ 轴上是否存在点 $P$ 使 $\triangle APC$ 是等腰三角形？若存在求 $P$ 坐标，不存在说明理由。

**思维路径还原** 要点：
- 求出 $A(-1, 0), B(3, 0), C(0, 3)$
- $P$ 在 $x$ 轴上设 $P(t, 0)$
- 等腰三角形 = "至少两边相等"，**三种情况**：
  - $PA = PC$（$P$ 在 $AC$ 中垂线上）
  - $PA = AC$（以 $A$ 为顶点的等腰）
  - $PC = AC$（以 $C$ 为顶点的等腰）
- 每种情形用距离公式列方程，解出 $t$（注意舍掉 $P$ 与 $A$ 重合的解）
- 一般得到 3-4 个不同的 $P$（极少情形某些方程无解或解被排除）

**抽象成题型**：

四种常见存在性问题（用 markdown 表格汇总）：

| 类型 | 分类标准 | 情形数 |
|---|---|---|
| 等腰三角形 | 哪两边相等 | 通常 3 种 |
| 直角三角形 | 哪个角是直角 | 通常 3 种 |
| 平行四边形（已知 3 点找第 4 点） | 哪两点是对角线 | 通常 3 种 |
| 相似三角形（与已知三角形相似） | 对应关系 | 2 种或更多 |

**思考路标**：
- "是否存在" → 必定分类讨论
- 等腰：考虑 3 种（哪两边相等）
- 直角：考虑 3 种（哪个角是直角）
- 平行四边形：考虑 3 种（按对角线配对）
- 写完所有 $P$ 后**回头检查**：是否漏情况？是否有舍去解？

**应用例题** 3 例：等腰存在性 / 直角存在性 / 平行四边形存在性

**自测题** 4 题。

## Task 5: 05 折叠综合（模板 D，2800-3500 字）

Title: `# 折叠综合问题`

**一图速记**:
> **一图速记**：折叠 = **轴对称**（呼应 part6/06）。折叠综合题往往结合矩形 / 正方形 / 三角形 + **未知量设元** + 勾股方程。关键三步：①标折痕 ②写折前 = 折后等量 ③设元用勾股或相似列方程。

**引入题**：
> 矩形 $ABCD$ 中 $AB = 8, AD = 6$。把 $\triangle ABD$ 沿 $BD$ 折叠，$A$ 落到 $A'$。设 $A'C = x$。
> (1) 用 $x$ 表示 $A'B$ 或其他线段；
> (2) 若 $A'$ 恰好落在 $BC$ 上，求 $A'B$。

**思维路径还原** 要点：
- 折叠 → 轴对称（$BD$ 是对称轴）
- $A' \leftrightarrow A$ 关于 $BD$ → $BA' = BA = 8$、$DA' = DA = 6$、$\angle DBA' = \angle DBA$
- 题目要求"$A'$ 落在 $BC$ 上"——设 $A' \in BC$，则 $BA' = $ 某值
- 在直角 $\triangle BCA'$（或类似）中用勾股列方程

**抽象成题型**：
- 标出折痕 → 确定对称轴
- 写出折前 = 折后的对应等量（线段等、角等）
- 引入未知数（通常是某线段长）
- 用勾股 / 相似列方程

**思考路标**：
- "沿某线折叠" → 轴对称的所有性质
- "某点落到某线 / 某点上" → 等量代入定位置
- 折叠题中**勾股 + 设元**是标配
- 折痕本身的长度——常用面积法或勾股求

**应用例题** 3 例：矩形折叠求长度 / 折叠求面积 / 正方形折叠综合（结合半角）

**自测题** 4 题。

## Task 6: 06 旋转综合（模板 D，2800-3500 字）

Title: `# 旋转综合问题`

**一图速记**:
> **一图速记**：旋转综合题 = 旋转 + 全等 / 相似 + 勾股。看到等腰 / 等边 / 正方形 + 旋转 → 立刻想手拉手、半角、旋转构造（呼应 part3/cong/03, 04 与 part6/07）。

**引入题**：
> 正方形 $ABCD$ 中，把 $\triangle ABE$（$E$ 在 $BC$ 上）绕 $A$ 逆时针旋转 $90°$ 至 $\triangle ADE'$。若 $BE = 3$、$EC = 5$，
> (1) 求 $E'D$；
> (2) 求 $\triangle AEE'$ 的形状与面积。

**思维路径还原** 要点：
- 正方形 + 绕 $A$ 旋转 $90°$ —— $B \to D$，$E \to E'$
- 旋转后所有对应：$AE = AE'$、$\angle EAE' = 90°$、$BE = DE'$（旋转保距）
- $\triangle AEE'$ 是**等腰直角三角形**（两腰 $AE = AE'$ + 顶角 $90°$）
- $E'D = BE = 3$
- $E'C = E'D + DC = 3 + 8 = 11$？要看正方形边长。设边长为 $BC = BE + EC = 8$
- 在 $\triangle AEC$ / $\triangle AE'C$ 里用勾股算 $AE$、$AE'$
- 进而 $EE' = AE \cdot \sqrt{2}$，面积 $= \frac{1}{2}AE^2$

**抽象成题型**：
- 识别图中"等长边 + 特定角"结构 → 用旋转
- 旋转后利用全等 / 等腰直角等性质求几何量
- 综合 = 旋转 + 勾股 + 等腰直角

**思考路标**：
- 正方形/等腰直角/等边 + 旋转 → **必有特殊三角形产生**
- 正方形 + 旋转 $90°$ → **等腰直角三角形**（两腰是对应边，夹角 $90°$）
- 等边 + 旋转 $60°$ → **等边三角形**（手拉手）
- 旋转构造后用勾股算未知边

**应用例题** 3 例：正方形 + $90°$ 旋转 / 等边 + $60°$ 旋转 / 多步旋转综合
