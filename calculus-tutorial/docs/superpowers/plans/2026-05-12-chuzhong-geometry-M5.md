## Task 1: part8/01 三视图（模板 C，1800-2500 字）

Title: `# 三视图`

- **图形特征**：从三个互相垂直方向（正面、上方、左侧）观察立体图形所得的平面图
- **定义**：
  - **主视图**（正视图）：从正面看
  - **俯视图**：从上面看
  - **左视图**（侧视图）：从左面看
- **三视图位置约定**：主视图在左上，俯视图在主视图正下方，左视图在主视图右侧
- **三视图原则**：
  - **长对正**：主视图与俯视图长度相同
  - **高平齐**：主视图与左视图高度相同
  - **宽相等**：俯视图与左视图宽度相同
- **常见几何体三视图**：长方体、正方体、圆柱、圆锥、球、棱锥、棱柱
- **典型应用** 3 例每带【思路】:
  - 例 1：基础——给一个长方体（或简单组合体），画三视图
  - 例 2：**逆向问题**——根据三视图还原立体图形
  - 例 3：根据三视图求体积或表面积
- **易错点**：
  - 看不见的轮廓用**虚线**表示
  - 长对正、高平齐、宽相等三原则必须同时满足
  - 圆柱主视/左视都是矩形，俯视是圆
- **自测题** 4 题。

## Task 2: part8/02 平行投影与中心投影（模板 C，1200-1800 字，简短）

Title: `# 平行投影与中心投影`

- **投影定义**：光线照射物体在平面上留下的影子 → 投影
- **平行投影**：光线**平行**（如太阳光下的影子）
  - 影子与物体**形状相似**（在地面上是位似关系，特殊情况下相等）
- **中心投影**：光线**从一点发出**（如灯泡光下的影子）
  - 影子与物体**位似**（位似中心 = 光源）
- **两者区别**：
  - 平行投影：光线方向一致；不同高度物体影子比例与高度比例相同
  - 中心投影：影子随光源位置和物体位置变化大；离光源越远影子越大或越小（视位置而定）
- **常见情境**：
  - 太阳光下两个物体（如旗杆和小棍）→ 平行投影 → 用相似三角形求实际高度
  - 路灯下两个人 → 中心投影
- **典型应用** 2 例每带【思路】:
  - 例 1：阳光下旗杆高度——已知小棍长度、影长，旗杆影长，用相似比求旗杆高
  - 例 2：路灯下人影——给灯柱高度、人到灯柱距离、人身高，求影长（中心投影相似比）
- **易错点**：平行投影下物体与影子的相似比可能 $\neq 1$（取决于光线角度，但同一时间相同方向下不同物体的比例**相等**）
- **自测题** 3 题。

## Task 3: part8/03 立体图形的展开图（模板 C，1500-2000 字）

Title: `# 立体图形的展开图`

- **概念**：把立体图形沿某些棱（或母线）剪开**展平**得到的平面图
- **常见展开图**：
  - **正方体**：共有 **11 种** 不同的展开图（不要求全记，但要会判断是否能折成正方体）
  - **长方体**：6 个矩形
  - **圆柱**：一个矩形（侧面）+ 两个圆（底面）；侧面矩形的长 = 底周长 $2\pi r$，宽 = 圆柱高
  - **圆锥**：一个扇形（侧面）+ 一个圆（底面）；扇形半径 = 圆锥母线长，扇形弧长 = 底周长 $2\pi r$
- **关键公式**：
  - 圆柱侧面积 $= 2\pi r h$
  - 圆锥侧面积 $= \pi r l$（$l$ 是母线长）
  - 圆锥侧面展开扇形圆心角 $\alpha = \frac{r}{l} \times 360°$
- **典型应用** 3 例每带【思路】:
  - 例 1：给一个平面图形，判断能否折成正方体（用"1-4-1"、"2-3-1"等口诀，或反面验证）
  - 例 2：圆柱底半径 $3$、高 $5$，求侧面积
  - 例 3：**蚂蚁爬行问题**——圆柱表面两点间最短路径，展开侧面后用勾股
- **易错点**：圆锥侧面是扇形不是三角形；蚂蚁路径必须**沿表面**爬行，要展开
- **自测题** 4 题。

## Task 4: part9/01 坐标与图形变换（模板 C，2000-2800 字）

Title: `# 坐标与图形变换`

- **平面直角坐标系基础**：
  - $x$ 轴（横）、$y$ 轴（纵）、原点 $O$、四个象限
  - 点的坐标 $(x, y)$
  - 横纵坐标符号决定象限（第一象限 $(+,+)$；第二 $(-,+)$；第三 $(-,-)$；第四 $(+,-)$）
- **坐标变换汇总**（必须用 markdown 表格）：

  | 变换 | 点 $(x, y)$ 变到 |
  |---|---|
  | 关于 $x$ 轴对称 | $(x, -y)$ |
  | 关于 $y$ 轴对称 | $(-x, y)$ |
  | 关于原点对称（中心对称） | $(-x, -y)$ |
  | 平移 $(a, b)$ | $(x+a, y+b)$ |
  | 关于直线 $y = x$ 对称 | $(y, x)$ |
  | 绕原点逆时针旋转 $90°$ | $(-y, x)$ |
  | 绕原点顺时针旋转 $90°$ | $(y, -x)$ |
  | 关于原点位似（比 $k$） | $(kx, ky)$ |
- **典型应用** 3 例每带【思路】:
  - 例 1：基础——点 $(3, -2)$ 关于 $x$ 轴的对称点（$(3, 2)$）
  - 例 2：把 $\triangle ABC$ 绕原点逆时针旋转 $90°$，求三顶点新坐标
  - 例 3：**综合变换**——先平移再对称（变换的复合，注意顺序）
- **易错点**：对称是反号一个坐标，不是两个都反号（除原点对称外）；旋转 $90°$ 时坐标值会**交换并反号一个**
- **自测题** 5 题。

## Task 5: part9/02 两点间距离公式（模板 C，1500-2200 字）

Title: `# 两点间距离公式`

- **公式**：两点 $A(x_1, y_1)$ 与 $B(x_2, y_2)$ 之间的距离 $$AB = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}$$
- **来源**：构造直角三角形——以 $AB$ 为斜边，两直角边分别为 $|x_2 - x_1|$ 和 $|y_2 - y_1|$ —— 由勾股直接推出（呼应 rt/01）
- **特殊情形**：
  - 横坐标相同（$x_1 = x_2$）：$AB = |y_2 - y_1|$
  - 纵坐标相同：$AB = |x_2 - x_1|$
  - 到原点距离：$OA = \sqrt{x_1^2 + y_1^2}$
- **中点公式**：$AB$ 中点坐标 $M = \left(\frac{x_1+x_2}{2}, \frac{y_1+y_2}{2}\right)$
- **典型应用** 3 例每带【思路】:
  - 例 1：基础——求 $A(1,2), B(4,6)$ 间距离（$5$）
  - 例 2：判断三角形形状——给三顶点坐标，分别求三边长度，再用勾股逆定理（part3/rt/02）
  - 例 3：动点问题预告——在 $x$ 轴上找一点 $P$ 使 $PA + PB$ 最小（呼应将军饮马 + 距离公式）
- **易错点**：根号下是平方差，不是差的绝对值；中点公式分子是和不是差
- **自测题** 4 题。

## Task 6: part9/03 坐标几何中的常见模型（模板 C，2200-3000 字）

Title: `# 坐标几何中的常见模型`

- **图形特征**：题目里出现"坐标系中的几何图形"——把图形条件**翻译**为坐标关系（呼应 toolkit/04 转化 2）
- **常用工具汇总**：
  1. **距离公式** + **中点公式**（part9/02）
  2. **坐标变换汇总表**（part9/01）
  3. 直线方程 $y = kx + b$ 的斜率与平行/垂直关系
  4. **过坐标轴作垂线**（呼应 toolkit/02 E 类）——把斜线段拆为水平 + 竖直
- **关键策略**：
  - **求坐标 → 列方程**：把"等于某长度""平行""垂直""中点"等条件翻译为坐标方程
  - **作辅助垂线**：把斜距离拆成横坐标差与纵坐标差的勾股组合
  - **特殊三角形识别**：用边长公式判断等腰、等边、直角等
- **典型应用** 4 例每带【思路】:
  - 例 1：**等腰存在性** —— 已知 $A(0, 3), B(4, 0)$，在 $x$ 轴上找点 $C$ 使 $\triangle ABC$ 等腰。【思路】分三种情况：$CA = CB$、$CA = AB$、$CB = AB$，每种列方程求 $C$ 的横坐标
  - 例 2：**直角存在性** —— 同上结构，找 $C$ 使 $\triangle ABC$ 直角；分别考虑直角顶点在 $A, B, C$ 的三种情况
  - 例 3：**动点最值** —— 给定点 $A, B$ 在直线 $l$ 同侧，在 $l$ 上找 $P$ 使 $PA + PB$ 最小。【思路】将军饮马（part6/01 + toolkit/03 模型 11）+ 距离公式
  - 例 4：**平行四边形存在性** —— 三定点 + 第四点，求第四点坐标使构成平行四边形。【思路】平行四边形对角线互相平分 → 用中点公式；注意分类讨论（哪两点是对角线端点）
- **易错点**：
  - **存在性问题必须分类讨论**——等腰/直角/平行四边形都有多种情形
  - 数轴上的距离与平面上的距离要区分
  - 求坐标时容易漏掉负值情形
- **自测题** 5 题，至少 2 题是分类讨论的存在性问题。
