## Task 1: similarity/01 相似判定（模板 C，2200-3000 字）

涵盖：
- **图形特征**：两三角形形状相同（对应角相等、对应边成比例）
- **定义与判定**：
  - 相似：$\triangle ABC \sim \triangle DEF$，对应角相等，对应边比相等（相似比 $k$）
  - 判定 1 **AA**：两角对应相等 → 相似
  - 判定 2 **SAS**：两边对应成比例且夹角相等 → 相似
  - 判定 3 **SSS**：三边对应成比例 → 相似
  - 直角三角形：一组锐角相等 → 相似（AA 推论）
- **关键性质**：
  - 相似比 $k$ → 周长比 $k$、面积比 $k^2$
  - 相似比与对应高/中线/角平分线之比相等
- **AA 为何足以**：第三角由内角和自动确定
- **典型应用** 3 例：
  - 例 1：基础 AA 判定 + 求线段长
  - 例 2：用面积比求线段比（已知相似比）
  - 例 3：相似与全等的区别（相似是全等的推广，全等是相似比 $k=1$ 的特例）
- **易错点**：
  - 对应关系要严格按字母顺序
  - SSA 同样不能用于相似
  - 周长比 = 相似比，但面积比 = 相似比平方
- **自测题** 5 题

## Task 2: similarity/02 A/X/8 字模型（模板 D，2500-3500 字）

**一图速记**：两平行线被两直线所截 → 构成 A 字 / X 字 / 8 字三角形对，必相似。

### 一、引入
$\triangle ABC$ 中 $DE \parallel BC$，$D \in AB, E \in AC$。证 $\triangle ADE \sim \triangle ABC$，并探究 $\frac{AD}{AB} = \frac{AE}{AC} = \frac{DE}{BC}$。

### 二、思维路径还原（10 行内心独白）
> "$DE \parallel BC$ 让我立刻想到**同位角**：$\angle ADE = \angle ABC$、$\angle AED = \angle ACB$（平行线性质）。
> 加上公共顶角 $\angle A$——两组角已经够了。
> AA → 相似 → 对应边成比例。
> 形状像字母 A：两条平行线 $DE, BC$ + 一个共顶点 $A$。
> 如果 $DE$ 在 $A$ 反向延长线侧呢？图形像字母 X（或 8）：仍然 $\angle ADE = \angle ABC$（这次是**内错角**），仍然相似。"

### 三、抽象成模型
- **A 字模型**：两平行线截两直线，共顶点在同侧
- **X 字 / 8 字模型**：共顶点在两平行线之间，对顶角连接 → 对顶角 + 内错角 → 相似
- 结论：对应边成比例（**比例线段定理**）

### 四、模型变形
- 平行截直线时的"截相等线段" → 比例不变
- 三平行线截两直线 → 对应线段成比例（平行线分线段成比例定理）

### 五、思考路标
- 看到**平行线 + 两条横线** → **A 字 / X 字**
- 看到三角形 + 一边平行线 → A 字相似 + 比例
- 看到要求比例线段 → 找平行线
- 看到"两组对边平行" → 多 A 字结构

### 六、应用例题 3 例
- 例 1：A 字基础，求 $DE$
- 例 2：X 字——两直线交于 $O$，过 $O$ 作直线交两平行线，求比例
- 例 3：综合——梯形中找 A 字（延长两腰交于一点）

## Task 3: similarity/03 母子相似（射影定理）（模板 D，2200-3000 字）

**一图速记**：直角三角形斜边上的高把它分成三个两两相似的三角形——大三角形与两小三角形构成"母子相似"。

### 一、引入
直角 $\triangle ABC$，$\angle C = 90°$，$CD \perp AB$ 于 $D$。证 $\triangle ACD \sim \triangle CBD \sim \triangle ABC$。

### 二、思维路径还原
> "$\triangle ACD$ 与 $\triangle ABC$：都是直角三角形（$\angle ADC = 90°$、$\angle ACB = 90°$），且共一个锐角 $\angle A$。两组角相等 → AA → 相似。
> 同理 $\triangle CBD$ 与 $\triangle ABC$ 也共 $\angle B$，相似。
> 三个三角形彼此相似 → 各种对应边成比例。
> 设 $AD = p, BD = q, AB = c, AC = b, BC = a, CD = h$。
> 由 $\triangle ACD \sim \triangle ABC$：$\frac{AC}{AB} = \frac{AD}{AC}$ → $AC^2 = AD \cdot AB$ → $b^2 = pc$
> 由 $\triangle CBD \sim \triangle ABC$：$a^2 = qc$
> 由 $\triangle ACD \sim \triangle CBD$：$\frac{CD}{BD} = \frac{AD}{CD}$ → $h^2 = pq$
> 三条等式合称**射影定理**。"

### 三、抽象成模型
- 图形特征：直角三角形 + 斜边上的高
- 结论：$h^2 = pq$、$b^2 = pc$、$a^2 = qc$（射影定理）
- 推论：$b^2 + a^2 = pc + qc = (p+q)c = c^2$（**这是勾股定理的另一证法**）

### 四、模型变形
- 任意角变直角后均可用；非直角时退化为一般相似
- 嵌入圆中：直径上的圆周角是直角，恰好构成此结构

### 五、思考路标
- 看到**直角三角形 + 斜边上的高** → 母子相似 + 射影定理
- 求 $h$、$p$、$q$ 中任意一个 → $h^2 = pq$
- 求直角边 → $b^2 = pc$ 或 $a^2 = qc$
- 圆周角为直角的情形 → 自动出现母子相似

### 六、应用例题 3 例
- 例 1：求 $h$、$p$、$q$
- 例 2：用射影定理证勾股
- 例 3：嵌入圆——直径 $AB$，$C$ 在圆上，$CD \perp AB$

### 七、自测题 4 题

## Task 4: similarity/04 共角共边相似（模板 D，2000-2800 字）

**一图速记**：两三角形共一个角且夹这个角的两边成比例 → 相似（SAS 相似的图形化版）。

### 一、引入
$\triangle ABC$ 中 $D$ 在 $AB$ 上、$E$ 在 $AC$ 上，已知 $\frac{AD}{AC} = \frac{AE}{AB}$（注意是**交叉**比例）。证 $\triangle ADE \sim \triangle ACB$。

### 二、思维路径还原
> "看到题目里有两个三角形共顶点 $A$，且涉及四条线段的比例——共角共边的信号。
> 但是这个比例是 $\frac{AD}{AC} = \frac{AE}{AB}$，不是 $\frac{AD}{AB} = \frac{AE}{AC}$（那个是 A 字模型）。
> 这种**交叉比例**意味着对应关系是 $D \leftrightarrow C$、$E \leftrightarrow B$，而不是 $D \leftrightarrow B$、$E \leftrightarrow C$。
> 即 $\triangle ADE \sim \triangle ACB$（注意字母顺序与 A 字不同）。
> 验证：公共角 $\angle A = \angle A$；夹这个角的两边比 $\frac{AD}{AC} = \frac{AE}{AB}$ → SAS 相似 → 成立。"

### 三、抽象成模型
- 图形特征：两个三角形共一个顶角，且夹角的两边成比例（注意可能是直接比例或交叉比例）
- 结论：相似（SAS 相似的可视化版本）
- 关键：判断对应关系——比例方向决定相似的对应

### 四、模型变形
- 直接比例 $\frac{AD}{AB} = \frac{AE}{AC}$ → A 字模型，$\triangle ADE \sim \triangle ABC$
- 交叉比例 $\frac{AD}{AC} = \frac{AE}{AB}$ → 本节模型，$\triangle ADE \sim \triangle ACB$
- 两种本质都是 SAS 相似，区别只在对应关系

### 五、思考路标
- 共顶点 + 比例线段 → **共角共边相似**
- 比例是**直接**型 → A 字相似
- 比例是**交叉**型 → 本节模型（对应顶点反转）
- 求线段乘积关系 $AB \cdot AD = AC \cdot AE$ → 共角共边的等价表达

### 六、应用例题 3 例
- 例 1：基础——证明相似
- 例 2：用相似导线段乘积 $AB \cdot AC = AD \cdot AE$ 类型
- 例 3：圆中——圆幂定理萌芽（相交弦定理可由共角共边推出）

### 七、自测题 4 题

## Task 5: right-triangle/01 勾股定理（模板 C，2000-2800 字）

涵盖：
- **图形特征**：直角三角形 + 直角边、斜边
- **定理**：$a^2 + b^2 = c^2$（$c$ 为斜边）
- **证明**（至少给出 2 种）：
  1. **赵爽弦图**：四个直角三角形 + 中央小正方形 = 大正方形。$(a+b)^2 = 4 \cdot \frac{1}{2}ab + c^2$ → 展开整理 → $a^2 + b^2 = c^2$
  2. **射影定理推导**（呼应 similarity/03）：$a^2 = qc, b^2 = pc$，相加得 $a^2 + b^2 = (p+q)c = c^2$
- **典型应用** 4 例：
  - 例 1：基础——求斜边或直角边
  - 例 2：折叠题——一长方形纸条折叠后求线段长
  - 例 3：建模——梯子靠墙问题
  - 例 4：勾股数（$3,4,5$；$5,12,13$；$8,15,17$；$7,24,25$ 等）——常见组合记忆
- **易错点**：必须先确认有直角；找清楚谁是斜边；勾股数都是整数解
- **自测题** 5 题

## Task 6: right-triangle/02 勾股定理逆定理（模板 C，1500-2200 字）

涵盖：
- **逆定理**：若三角形三边 $a, b, c$ 满足 $a^2 + b^2 = c^2$，则 $c$ 所对角为直角
- **证明**：构造已知两直角边为 $a, b$ 的直角三角形，其斜边为 $\sqrt{a^2+b^2}=c$，由 SSS 与原三角形全等 → 对应角相等 → 原三角形也有直角
- **判定**：
  - $a^2 + b^2 = c^2$ → 直角三角形
  - $a^2 + b^2 > c^2$ → 锐角三角形（$c$ 是最长边）
  - $a^2 + b^2 < c^2$ → 钝角三角形
- **典型应用** 3 例：
  - 例 1：判断三边 $5, 12, 13$ 是否构成直角三角形
  - 例 2：实际应用——古代测直角的"三四五绳法"
  - 例 3：综合——已知三边，判断三角形类型
- **易错点**：$c$ 必须是最长边；逆定理只确定是否直角，不能定其他属性
- **自测题** 4 题

## Task 7: right-triangle/03 特殊直角三角形（模板 C，2000-2800 字）

涵盖两种最常考的特殊直角三角形：
- **30°-60°-90° 三角形**：边比 $1 : \sqrt{3} : 2$（短直角边 : 长直角边 : 斜边）
  - 来源：等边三角形 + 高（呼应 special/02）—— 把等边三角形从顶点向底边作高，分成两个 30-60-90
  - 关键：30° 对的边 = 斜边 / 2
- **45°-45°-90° 三角形（等腰直角）**：边比 $1 : 1 : \sqrt{2}$
  - 关键：斜边 = 直角边 × $\sqrt{2}$
- **应用** 3 例：
  - 例 1：30-60-90 求边长
  - 例 2：45-45-90 求斜边
  - 例 3：综合——含 $15°$、$75°$ 等特殊角的题目，通过分解为 30-60-90 + 45-45-90 求解
- **易错点**：
  - 30° 对的是**短**直角边，不要搞反
  - $\sqrt{3}$ vs $\sqrt{2}$ 别记反
  - 这两类三角形是后续解直角三角形章节（part7）和三角函数特殊值的基础

## Task 8: special/01 等腰三角形（模板 C，2200-3000 字）

涵盖：
- **定义**：两条边相等的三角形；相等的两边称"腰"，另一边称"底"
- **核心性质**：
  - **等边对等角**（两底角相等）
  - **三线合一**：顶角平分线、底边上的中线、底边上的高 三线重合
  - 等腰三角形的对称轴是顶角平分线所在的直线
- **判定**：
  - **等角对等边**：若一三角形两角相等，则两角对的边相等（等腰）
- **三线合一的证明**：用 SAS 全等（$\triangle ABD \cong \triangle ACD$，$D$ 是底边中点）
- **典型应用** 3 例：
  - 例 1：等腰三角形底角为 $50°$，求顶角（$80°$）。注意**讨论分类**：若已知是底角 vs 顶角
  - 例 2：用三线合一证明（如证两段相等或证垂直）
  - 例 3：等腰三角形 + 角平分线 / 中线 / 高 的综合题
- **易错点**：
  - 顶角与底角分类讨论
  - "三线合一"是等腰的**性质**，但前提是"底边对应的三条线"——别用错位置
- **自测题** 5 题

## Task 9: special/02 等边三角形（模板 C，1500-2200 字）

涵盖：
- **定义**：三边相等的三角形
- **核心性质**：
  - 三个内角都是 $60°$
  - 是等腰三角形的特殊情形——继承所有等腰性质
  - 三条高 / 中线 / 角平分线 / 中垂线**全部重合**
  - 三条对称轴
- **判定**：
  - 三边相等 → 等边
  - 三内角都是 $60°$ → 等边
  - 等腰三角形 + 一个 $60°$ 角 → 等边（不论是顶角还是底角）
- **典型应用** 3 例：
  - 例 1：基础——已知一边求面积（$S = \frac{\sqrt{3}}{4}a^2$，由 30-60-90 推出）
  - 例 2：等边三角形 + 外接圆 / 内切圆（半径与边长关系）
  - 例 3：综合——等边三角形 + 旋转 $60°$ 自然出现手拉手（呼应 cong/03）
- **易错点**：等腰 + 60° = 等边（即使该 $60°$ 是顶角或底角）；等边的高 $h = \frac{\sqrt{3}}{2}a$
- **自测题** 4 题

## Task 10: special/03 三角形的四心（模板 C，2200-3000 字）

涵盖三角形四个特殊点：
- **重心 (Centroid)**：三条**中线**的交点
  - 性质：分中线为 $2:1$（顶点到重心 : 重心到对边中点）
  - 物理意义：重心
- **内心 (Incenter)**：三条**内角平分线**的交点（呼应 part1/03 例 3）
  - 性质：到三边距离相等 = 内切圆半径
- **外心 (Circumcenter)**：三条**边的中垂线**的交点
  - 性质：到三顶点距离相等 = 外接圆半径
  - 直角三角形外心在斜边中点
- **垂心 (Orthocenter)**：三条**高**的交点
  - 锐角 → 内部；直角 → 直角顶点；钝角 → 外部
- 简表对比：

| 名称 | 三线 | 距离关系 | 特例 |
|---|---|---|---|
| 重心 | 中线 | 分中线 2:1 | — |
| 内心 | 角平分线 | 到三边等距 | 内切圆圆心 |
| 外心 | 边中垂线 | 到三顶点等距 | 外接圆圆心；直角→斜边中点 |
| 垂心 | 高 | — | 位置依三角形类型 |

- **典型应用** 3 例：
  - 例 1：求重心坐标（设三顶点坐标，用 $\frac{x_1+x_2+x_3}{3}$）
  - 例 2：直角三角形斜边中线等于斜边一半（外心 = 斜边中点的推论）
  - 例 3：综合——等边三角形四心重合于一点
- **易错点**：四心定义易混（哪个对应哪三线）；垂心位置随三角形形状变化
- **自测题** 5 题
