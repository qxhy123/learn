## Task 1: part6/01 轴对称（模板 C，1800-2500 字）

Title: `# 轴对称`

- **图形特征**：一个图形沿一条直线翻折后能完全重合 → 该图形关于这条直线轴对称
- **核心概念**：
  - **轴对称图形**（如等腰三角形、矩形、菱形、正方形、等腰梯形、圆）vs **两个图形关于某直线对称**
  - **对称轴**：翻折所沿的直线
  - 对应点连线被对称轴**垂直平分**；对应线段、对应角相等
- **性质**：
  - 对应点到对称轴距离相等
  - 任意一对对应点的连线 ⊥ 对称轴
- **判定**：两图形对应点连线都被同一直线垂直平分 → 关于该直线轴对称
- **典型应用** 3 例：
  - 例 1：作图——给一个点和对称轴，作对称点
  - 例 2：列举常见轴对称图形及对称轴条数（圆有无数条；等腰三角形 1 条；等边 3 条；矩形 2 条；正方形 4 条；圆 ∞ 条）
  - 例 3：**将军饮马引入**——直线 $l$ 同侧两点 $A, B$，在 $l$ 上找点 $P$ 使 $PA + PB$ 最小。【思路】作 $A$ 关于 $l$ 的对称点 $A'$，$PA' + PB$ 最短即 $A'B$ 直线段（呼应 toolkit/03 模型 11）
- **易错点**："轴对称图形" vs "两图形成轴对称" 概念不同；对称轴可以有多条
- **自测题** 4 题。

## Task 2: part6/02 平移（模板 C，1500-2200 字）

Title: `# 平移`

- **定义**：在平面内，把图形沿某方向移动一定的距离 → 平移
- **要素**：方向 + 距离
- **性质**：
  - 平移后的图形与原图形**全等**
  - 对应点连线**平行且相等**（或共线）
  - 对应线段平行且相等；对应角相等
- **坐标系中的平移**：点 $(x, y)$ 沿 $x$ 轴向右平移 $a$、向上平移 $b$ → $(x+a, y+b)$
- **典型应用** 3 例：
  - 例 1：基础——已知一点坐标和平移方向距离，求平移后坐标
  - 例 2：用平移构造平行四边形（一段线段平移后，原线段与平移后线段 + 对应点连线 → 平行四边形）
  - 例 3：综合——平移辅助线（呼应 toolkit/02 D 类）—— 把分散的两段线段平移到一起
- **易错点**：平移不改变形状大小、方向（不是旋转/翻折）
- **自测题** 4 题。

## Task 3: part6/03 旋转（模板 C，2000-2800 字）

Title: `# 旋转`

- **定义**：在平面内，把图形绕一个定点 $O$ 按某方向转过一定角度 → 旋转
- **要素**：**旋转中心 $O$** + **旋转方向**（顺/逆时针）+ **旋转角**
- **性质**：
  - 旋转后的图形与原图形**全等**
  - 对应点到旋转中心的**距离相等**
  - 对应点与旋转中心的连线所成角 = 旋转角
- **典型应用** 3 例：
  - 例 1：基础——给一个点和旋转中心、角度，求旋转后坐标（特殊：$90°$ 与 $180°$ 旋转）
  - 例 2：旋转构造全等——把分散的图形元素旋转到一起（呼应 cong/03 手拉手、cong/04 半角）
  - 例 3：等边三角形 + 60° 旋转 → 手拉手；正方形 + 90° 旋转 → 半角模型
- **易错点**：旋转中心可以在图形内、外或图形上；旋转角与旋转方向都重要
- **自测题** 4 题。

## Task 4: part6/04 中心对称（模板 C，1500-2200 字）

Title: `# 中心对称`

- **定义**：一个图形绕一个点旋转 $180°$ 能与另一图形（或自己）重合 → 中心对称（绕的点 = 对称中心）
- **关键认识**：中心对称 = 旋转的特殊情况（旋转角 $= 180°$）
- **性质**：
  - **对称中心是对应点连线段的中点**
  - 对应线段平行（或共线）且相等
- **中心对称图形**：自身关于一点中心对称（如平行四边形、矩形、菱形、正方形、圆、正六边形等"偶数边正多边形"）
- **典型应用** 3 例：
  - 例 1：作中心对称图形（已知一点，作对应点）
  - 例 2：判断哪些常见图形是中心对称（平行四边形是；等腰三角形通常不是；圆是；正三角形不是）
  - 例 3：综合——平行四边形是中心对称图形 → 对角线交点是对称中心
- **易错点**：等腰三角形是轴对称但不是中心对称（与平行四边形相反）；矩形/菱形/正方形既是轴对称又是中心对称
- **自测题** 4 题。

## Task 5: part6/05 位似（模板 C，2000-2800 字）

Title: `# 位似`

- **定义**：两个相似多边形对应顶点的连线**相交于一点**（**位似中心**），且对应点到位似中心的距离比等于相似比 → 位似图形
- **关键：位似是特殊的相似**（多了"对应点连线共点"的条件）
- **性质**：
  - 位似图形相似（继承相似的所有性质）
  - 对应点连线过位似中心
  - 对应点到位似中心距离比 = 相似比
- **位似与坐标**：以原点为位似中心，相似比 $k$ → 点 $(x, y)$ 对应位似点 $(kx, ky)$ 或 $(-kx, -ky)$（取决于位似中心同侧或异侧）
- **典型应用** 3 例：
  - 例 1：判断两图形是否位似（必须相似 + 对应点连线共点）
  - 例 2：以原点为位似中心，相似比 $2$，求位似图形顶点坐标
  - 例 3：综合——位似变换在中考中常与坐标系结合（part9 预告）
- **易错点**：位似图形必定相似，但相似不一定位似（必须对应点连线共点）；位似分"正向"和"反向"（异侧）
- **自测题** 4 题。

## Task 6: part6/06 翻折模型（模板 D，2500-3200 字）

Title: `# 翻折模型`

**一图速记**:
> **一图速记**：将图形沿一条直线（折痕）翻折后，原图与折后图形关于折痕**轴对称**——折痕 ⊥ 对应点连线、对应边/角相等。常出现在矩形折叠、三角形折叠、正方形折叠等题型。

### 一、引入
> 矩形 $ABCD$ 中，$AB = 8, BC = 6$。把 $\triangle ABC$ 沿对角线 $AC$ 翻折，$B$ 落到 $B'$。求 $\triangle AB'D$ 的面积（或 $B'D$ 长度）。

### 二、思维路径还原 (10-12 行)
> "折叠题第一反应：找到**折痕**——这里是对角线 $AC$。
> 折叠 = 轴对称（part6/01）—— $B$ 关于 $AC$ 的对称点是 $B'$。立刻得到：$AC \perp BB'$、$BB'$ 被 $AC$ 平分；$AB' = AB = 8$、$CB' = CB = 6$、$\angle ACB' = \angle ACB$。
> 还有一个关键：折叠后的图形与原图**全等** —— $\triangle ACB' \cong \triangle ACB$。
> 现在的问题转化为：在已知 $AB' = 8, CB' = 6$ 的情况下，$B'$ 与矩形里其他点的关系。
> 先确定坐标：设 $A=(0,0), B=(8,0), C=(8,6), D=(0,6)$。$AC = \sqrt{64+36} = 10$。
> $B'$ 在 $AC$ 关于 $B$ 的对称侧——可以用'到 $A$ 距离 $=8$、到 $C$ 距离 $=6$'两条圆方程联立求出 $B'$ 坐标。
> 或者更简单：设 $BB'$ 与 $AC$ 交于 $E$，$BE \perp AC$。由 $\triangle ABC$ 面积 $24 = \frac{1}{2}\cdot AC\cdot BE \Rightarrow BE = 4.8$；$B'$ 是 $B$ 关于 $E$ 的对称 → $BB' = 9.6$。
> 折叠题的关键套路：① 标出折痕、② 写出'折前 = 折后'的等量、③ 设未知数列方程（常需勾股）。"

### 三、抽象成模型
- 图形特征：题目里出现"沿某直线折叠"
- 折叠 = **轴对称**（part6/01）—— 立刻获得对称的所有性质：
  - 折痕 ⊥ 对应点连线
  - 折痕**平分**对应点连线
  - 折前折后的对应线段相等、对应角相等
- 解题三步走：①标折痕 ②列等量 ③（多用）勾股方程或相似

### 四、模型变形
- **矩形折叠**：把一角折到对角线、对边上
- **三角形折叠**：把一顶点折到对边上
- **正方形折叠**：常与"半角模型"结合（呼应 cong/04）
- **多次折叠**：每次都是一次轴对称

### 五、思考路标
- 看到题目里"沿某线折叠" → 翻折模型 = 轴对称
- 折后某点落到指定位置 → 设折后位置为未知，列等量
- 折叠题中**勾股 + 设方程**是最常用工具
- 折痕的性质：折痕 ⊥ 对应点连线 + 平分

### 六、应用例题 (3 例)
- 例 1：基础矩形对角线折叠（同引入题）
- 例 2：**折到对边上** —— 矩形 $ABCD$ 中 $AB=4, BC=3$，把矩形折叠使 $C$ 落到 $AB$ 上的点 $C'$，求折痕长。【思路】$C' \in AB$，$DC' = DC = 4$；设 $BC' = x$，则 $AC' = 4-x$；由直角三角形 $ADC'$（$\angle A = 90°$，$AD=3$）：$AD^2 + AC'^2 = DC'^2 \Rightarrow 9 + (4-x)^2 = 16 \Rightarrow x = 4 - \sqrt{7}$。折痕长用更多步骤求出
- 例 3：**正方形折叠 + 半角** —— 正方形 $ABCD$ 边长 $1$，把 $\triangle ABD$ 沿 $BD$ 折起后某点位置求解

### 七、思路自测题 4 题。

## Task 7: part6/07 旋转构造模型（模板 D，2500-3200 字）

Title: `# 旋转构造模型`

**一图速记**:
> **一图速记**：题中出现等腰、等边、正方形（即"等长边"结构）+ 特定角度（$60°$/$90°$/$120°$）→ 把一个三角形绕某顶点旋转特定角度，把**分散的条件集中**到一个三角形。这是手拉手、半角模型的统一本质。

### 一、引入
> 正方形 $ABCD$ 内一点 $P$，已知 $PA = 1, PB = 2, PC = 3$。求 $\angle APB$ 的度数。

### 二、思维路径还原 (10-12 行)
> "已知 $PA, PB, PC$ 三段长度但分散在不同三角形里——典型'分散→集中'信号（呼应 toolkit/04 转化 5）。
> 正方形中有 90° 旋转的天然支持（$BA = BC$，绕 $B$ 旋转 $90°$ 可把 $C$ 转到 $A$）。
> 把 $\triangle BPC$ 绕 $B$ 顺时针旋转 $90°$：$C \to A$，$P \to P'$。
> 旋转后：$BP' = BP = 2$、$AP' = CP = 3$、$\angle PBP' = 90°$。
> 关键：$\triangle PBP'$ 是**等腰直角三角形**（两直角边 $BP = BP' = 2$）！所以 $PP' = 2\sqrt{2}$、$\angle BPP' = 45°$。
> 现在看 $\triangle APP'$：三边 $AP = 1, AP' = 3, PP' = 2\sqrt{2}$。验证：$1^2 + (2\sqrt{2})^2 = 1 + 8 = 9 = 3^2$ → 这是直角三角形，$\angle APP' = 90°$！
> 所以 $\angle APB = \angle APP' + \angle P'PB = 90° + 45° = 135°$。
> 关键收益：通过 90° 旋转，把分散的三段 $PA, PB, PC$ 集中到一个由 $A, P, P'$ 构成的可计算三角形里。"

### 三、抽象成模型
- 图形特征：有"等长边" + 特定旋转角（旋转 $\alpha$ 后两端点能重合）
- 操作：把含有部分条件的三角形整体旋转 $\alpha$
- 效果：原本散落在不同位置的条件被集中到一个三角形里，能用勾股或全等收尾
- **核心思想**：这是手拉手（cong/03，旋转 $\alpha$ 等于顶角）和半角（cong/04，正方形里旋转 $90°$）的统一抽象

### 四、模型变形
- 等边三角形内一点的距离问题 —— 用 $60°$ 旋转
- 等腰直角三角形 / 正方形里一点的距离问题 —— 用 $90°$ 旋转
- 等腰顶角 $\alpha$ 的三角形里 —— 用 $\alpha$ 旋转
- 综合题中**多次旋转**：把多个分散条件依次集中

### 五、思考路标
- 看到等腰/等边/正方形 + 一内点分别到几个顶点距离 → **绕一顶点旋转**
- 旋转角 = 等腰的顶角（等边 $60°$，正方形 $90°$）
- 看到 $1, 2, 3$ 或 $3, 4, 5$ 的距离组合 → 旋转后可能拼出勾股数
- "分散三段长度求一个角" → 旋转 + 勾股

### 六、应用例题 (3 例)
- 例 1：正方形 + 内点三距离求角（同引入题）
- 例 2：等边三角形 + 内点 —— $\triangle ABC$ 等边，$P$ 内一点，$PA=5, PB=4, PC=3$，求 $\angle APB$。【思路】绕 $B$ 旋转 $60°$，$A \to C$，$P \to P'$。$\triangle PBP'$ 等边，$PP' = 4$；$\triangle CPP'$ 三边 $5, 4, 3$ → 直角 → 综合求得 $\angle APB = 90° + 60° = 150°$
- 例 3：综合 —— 给一个不规则图形，通过旋转构造规则图形求面积

### 七、思路自测题 4 题。

## Task 8: part7/01 锐角三角函数（模板 C，2500-3200 字）

Title: `# 锐角三角函数：正弦、余弦、正切`

- **图形特征**：直角三角形 + 一个锐角 $\alpha$
- **定义**（设直角三角形锐角 $\alpha$ 的对边 $a$、邻边 $b$、斜边 $c$）：
  - **正弦** $\sin \alpha = \frac{a}{c}$（对边/斜边）
  - **余弦** $\cos \alpha = \frac{b}{c}$（邻边/斜边）
  - **正切** $\tan \alpha = \frac{a}{b}$（对边/邻边）
- **核心性质**：
  - 三角函数值只与锐角度数有关，与三角形大小无关（由相似保证）
  - 在 $0° < \alpha < 90°$ 范围内：$\sin \alpha, \tan \alpha$ 都**随 $\alpha$ 增大而增大**；$\cos \alpha$ **随 $\alpha$ 增大而减小**
  - $\sin^2 \alpha + \cos^2 \alpha = 1$（由勾股直接推）
  - $\tan \alpha = \frac{\sin \alpha}{\cos \alpha}$
  - 互余角的关系：$\sin(90° - \alpha) = \cos \alpha$，$\cos(90° - \alpha) = \sin \alpha$
- **典型应用** 3 例：
  - 例 1：基础——给直角三角形三边，求 $\sin, \cos, \tan$
  - 例 2：已知 $\sin \alpha = \frac{3}{5}$（且 $\alpha$ 锐角），求 $\cos \alpha, \tan \alpha$（用 $\sin^2+\cos^2=1$）
  - 例 3：思路题——用三角函数证明全等（同弦角 + 同斜边 → 同 $\sin$ → 全等的另一种判定本质）
- **易错点**：三角函数只在直角三角形中定义（初中）；分清对边、邻边、斜边
- **自测题** 5 题。

## Task 9: part7/02 特殊角的三角函数值（模板 C，1500-2200 字）

Title: `# 特殊角的三角函数值`

- **必记三角函数表**（必须用 markdown 表格）：

  | 角度 | $\sin$ | $\cos$ | $\tan$ |
  |---|---|---|---|
  | $30°$ | $\frac{1}{2}$ | $\frac{\sqrt{3}}{2}$ | $\frac{\sqrt{3}}{3}$ |
  | $45°$ | $\frac{\sqrt{2}}{2}$ | $\frac{\sqrt{2}}{2}$ | $1$ |
  | $60°$ | $\frac{\sqrt{3}}{2}$ | $\frac{1}{2}$ | $\sqrt{3}$ |

- **来源**：从特殊直角三角形（30-60-90 与 45-45-90，呼应 rt/03）的边比直接读出
- **记忆口诀**（必含）：
  ```
  正弦：1/2、√2/2、√3/2  （分母 2 不变，分子 √n 中 n 从 1 到 3）
  余弦：√3/2、√2/2、1/2  （正弦的倒序）
  正切：√3/3、1、√3
  ```
- **互余 / 互补关系**：$\sin 30° = \cos 60°$，$\sin 60° = \cos 30°$（呼应 part7/01 中互余关系）
- **典型应用** 3 例：
  - 例 1：求 $\sin 30° + \cos 45° + \tan 60°$
  - 例 2：$\frac{\sin 60°}{\cos 30°}$（结果 $1$）
  - 例 3：判断三角形形状——若 $\sin \alpha = \frac{\sqrt{3}}{2}$，求 $\alpha$（$60°$）
- **易错点**：$\sin$ 和 $\cos$ 容易记反；$\tan 60° = \sqrt{3}$ 不是 $\frac{\sqrt{3}}{3}$（后者是 $\tan 30°$）

## Task 10: part7/03 解直角三角形的应用（模板 C，2200-3000 字）

Title: `# 解直角三角形的应用`

- **解直角三角形**：已知直角三角形若干元素（边或角），求其余元素
- **解的依据**：
  - 锐角互余（两锐角和为 $90°$）
  - 勾股定理（$a^2 + b^2 = c^2$）
  - 三角函数（连接边与角）
- **常用配方**：
  - 已知一锐角 + 一边 → 用三角函数求其他边
  - 已知两边 → 用勾股 + 三角函数求角
- **实际应用术语**：
  - **仰角**：视线在水平线**上方**与水平线的夹角
  - **俯角**：视线在水平线**下方**与水平线的夹角
  - **方位角**：从正北方向（或正南）顺时针（或逆时针）测量到目标方向的角度，如"北偏东 $30°$"
  - **坡度（坡比）**：坡面铅直高度与水平距离的比，$i = \tan \alpha$（$\alpha$ 是坡角）
- **典型应用** 4 例：
  - 例 1：基础——已知 $\angle B = 30°$，斜边 $c = 10$，求两直角边
  - 例 2：**仰角问题**——某人离塔 $50$ 米，仰望塔顶仰角 $30°$，求塔高（用 $\tan 30°$）
  - 例 3：**方位角**——两船分别在港口北偏东 $30°$ 和北偏西 $60°$ 方向，距离港口各 $4$ 海里、$3$ 海里，求两船间距（用勾股，注意 $30° + 60° = 90°$）
  - 例 4：**坡度**——堤坝坡度 $1:2$，求坡角（$\tan \alpha = 0.5$，约 $26.57°$）；坡顶到坡底水平距离为 $20$ 米，求坡高
- **易错点**：
  - 仰角/俯角都是与**水平线**的夹角
  - 方位角通常以"北/南"为基准
  - 坡度是"高 : 水平距离"，不是"高 : 斜面长"
