# 平行线的性质与应用

## 一、图形特征

判定研究的是"角的关系 $\Rightarrow$ 两直线平行"，而**性质**研究的是反过来的方向：在**两直线已经平行**的前提下，再被第三条直线（截线）所截，所形成的 8 个角之间会有**固定的数量关系**。

换句话说，"三线八角"的图形结构与判定一节中完全相同，但出发点不同：

- **判定**：图中已经标出某对角相等或互补，要由此推出"两条直线平行"。
- **性质**：图中已经给出"两条直线平行"这一事实，要由此推出"某对角相等或互补"。

因此，每当题目里出现 $AB \parallel CD$ 这样的条件时，就要立刻在脑中调用"性质"工具箱：同位角、内错角、同旁内角，三组关系任选其一。

## 二、性质定理

设直线 $l_1 \parallel l_2$，被第三条直线 $l_3$ 所截，则：

- **性质 1（同位角）**：两直线平行，**同位角相等**。
- **性质 2（内错角）**：两直线平行，**内错角相等**。
- **性质 3（同旁内角）**：两直线平行，**同旁内角互补**（和为 $180°$）。

**推论（平行线间距离）**：两条平行线之间的**距离处处相等**。也就是说，若 $l_1 \parallel l_2$，在 $l_1$ 上任取两点 $A$、$B$，分别向 $l_2$ 作垂线，则两条垂线段长度相等。这一推论是后续梯形、平行四边形面积计算的几何基础。

## 三、由性质 1 推出性质 2、3

在初中体系中，**性质 1**（同位角相等）作为基本事实直接由平行公理推出，无需证明。性质 2、性质 3 则可由性质 1 严格推导。

设 $l_1 \parallel l_2$，被 $l_3$ 所截，截点分别为 $A$（在 $l_1$ 上）、$B$（在 $l_2$ 上）。

**推出性质 2**：取一对内错角 $\angle 1$（在 $B$ 处、$l_2$ 上方靠 $l_3$ 左侧）与 $\angle 2$（在 $A$ 处、$l_1$ 下方靠 $l_3$ 右侧）。再考虑 $\angle 1$ 在 $B$ 处的对顶角 $\angle 3$，则 $\angle 1 = \angle 3$（对顶角相等）。而 $\angle 3$ 与 $\angle 2$ 是一对同位角，由性质 1 有 $\angle 3 = \angle 2$。于是 $\angle 1 = \angle 2$，性质 2 得证。

**推出性质 3**：取一对同旁内角 $\angle 1$（在 $B$ 处）与 $\angle 4$（在 $A$ 处，与 $\angle 1$ 在 $l_3$ 同侧）。考虑 $\angle 4$ 在 $A$ 处的邻补角 $\angle 2$，则 $\angle 2 + \angle 4 = 180°$。而 $\angle 1$ 与 $\angle 2$ 是同位角，由性质 1 有 $\angle 1 = \angle 2$。代入得 $\angle 1 + \angle 4 = 180°$，性质 3 得证。

这一推导链条体现了"基本事实 $\to$ 推论"的几何公理化精神：所有性质最终都建立在性质 1 之上。

## 四、判定 vs 性质 对比表

| 名称 | 已知 | 结论 |
|---|---|---|
| 判定 | 角的关系（同位角相等 / 内错角相等 / 同旁内角互补） | 两直线平行 |
| 性质 | 两直线平行 | 角的关系（同位角相等 / 内错角相等 / 同旁内角互补） |

一句话总结：**判定是"造平行"，性质是"用平行"**。

做题时，第一步要判断手头掌握的条件属于哪一类：如果题目要"证两直线平行"，用判定；如果题目里"已经写明 $\parallel$"再问角度，用性质。两者方向相反，绝不能混用。

## 五、典型应用

**例 1（经典折线问题）**：已知 $AB \parallel CD$，$P$ 是 $AB$ 与 $CD$ 之间的一点（折点），求证：

$$
\angle APC = \angle BAP + \angle DCP.
$$

【思路】这是一个折线夹在两平行线之间的标准模型。直接看 $\angle APC$ 与左右两角并没有直接联系，需要**作辅助线**：过 $P$ 作 $PE \parallel AB$。由于 $AB \parallel CD$，由平行的传递性也有 $PE \parallel CD$。
- 因 $PE \parallel AB$，由内错角相等（性质 2）：$\angle BAP = \angle APE$。
- 因 $PE \parallel CD$，由内错角相等：$\angle DCP = \angle CPE$。

两式相加：$\angle BAP + \angle DCP = \angle APE + \angle CPE = \angle APC$，命题得证。这正是 toolkit/02 中"在拐角处作平行线"的代表用法。

**例 2（平行 + 角平分线）**：已知 $AB \parallel CD$，$AE$ 平分 $\angle BAC$，$CE$ 平分 $\angle ACD$，求证：$AE \perp CE$。

【思路】由 $AB \parallel CD$，$AC$ 是截线，$\angle BAC$ 与 $\angle ACD$ 是一对同旁内角，由性质 3：

$$
\angle BAC + \angle ACD = 180°.
$$

两边同除以 2：$\frac{1}{2}\angle BAC + \frac{1}{2}\angle ACD = 90°$。由于 $AE$、$CE$ 分别平分两角，即 $\angle EAC = \frac{1}{2}\angle BAC$，$\angle ECA = \frac{1}{2}\angle ACD$，于是 $\angle EAC + \angle ECA = 90°$。在 $\triangle AEC$ 中，由三角形内角和：$\angle AEC = 180° - 90° = 90°$，故 $AE \perp CE$。

**例 3（三角形内角和）**：用平行线性质证明 $\triangle ABC$ 中 $\angle A + \angle B + \angle C = 180°$。

【思路】过顶点 $A$ 作直线 $l \parallel BC$。则：
- $AB$ 是 $l$ 与 $BC$ 的截线，由内错角相等：$l$ 在 $A$ 处与 $AB$ 所成的左侧内错角 $= \angle B$。
- $AC$ 是 $l$ 与 $BC$ 的截线，由内错角相等：$l$ 在 $A$ 处与 $AC$ 所成的右侧内错角 $= \angle C$。

这两个角与 $\angle BAC$（即 $\angle A$）共在直线 $l$ 同侧，恰好拼成一个平角，故

$$
\angle A + \angle B + \angle C = 180°.
$$

这是初中几何中"过顶点作对边的平行线"这一经典辅助线的源头，将在 part3 三角形章节中反复使用。

## 六、易错点

- **方向不能反**：用性质前必须先确认"两直线已经平行"。不能反过来用性质去"证明"两直线平行——那是判定的工作。判定与性质是一对互逆命题，混用是入门阶段最常见的逻辑错误。
- **辅助线套路**："拐角处过点作平行线"是处理平行折线最常见的辅助线（例 1 即典型），呼应 toolkit/02 中"过顶点作对边的平行线"思想。看到平行线之间出现折点、拐角，第一反应就应该是作平行辅助线，把折角拆成两个内错角之和。
- **性质 3 的"互补"易误用为"相等"**：同位角、内错角是**相等**关系，而同旁内角是**互补**（和为 $180°$）关系。三者口诀务必区分清楚，写步骤时同旁内角要写 $\angle 1 + \angle 2 = 180°$，而不是 $\angle 1 = \angle 2$。
- 利用"两平行线间距离处处相等"时，必须保证测量的是**垂线段**长度，斜线段并不相等。

## 七、思路自测题

1. 已知 $AB \parallel CD$，截线 $EF$ 与 $AB$、$CD$ 分别交于 $G$、$H$。若 $\angle AGE = 65°$，求 $\angle GHD$、$\angle GHC$ 的大小，并说明依据。
2. 已知 $AB \parallel CD$，$P$ 在两线之间，$\angle BAP = 40°$，$\angle DCP = 30°$。求 $\angle APC$。（提示：参考例 1，过 $P$ 作平行辅助线。）
3. 已知 $l_1 \parallel l_2$，一条截线与它们所成的同旁内角之差为 $40°$。求这一对同旁内角的度数。
4. 在 $\triangle ABC$ 中，过 $A$ 作 $BC$ 的平行线 $l$，若 $\angle B = 50°$、$\angle C = 70°$，求 $\angle BAC$。（要求写出用到的性质名称。）
5. 已知 $AB \parallel CD$，$AE$ 平分 $\angle BAC$，$CE$ 平分 $\angle ACD$。若 $\angle BAC = 100°$，求 $\angle AEC$ 的度数；并思考：若把"$AE$、$CE$ 是角平分线"中的"平分"改为"三等分（取靠 $AC$ 的一份）"，结论会变成什么？（需作辅助线或借助例 2 的思路）
