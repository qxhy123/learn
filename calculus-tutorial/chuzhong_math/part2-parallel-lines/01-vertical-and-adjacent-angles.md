# 对顶角与邻补角

## 一、图形特征

当两条直线相交时，会在交点处形成 $4$ 个角。这 $4$ 个角之间存在两种基本的几何关系：

- **位置对面**的两角（不相邻、隔着交点遥相呼应）——称为**对顶角**；
- **相邻共边**的两角（共用一条边，另一边方向相反）——称为**邻补角**。

观察直线 $AB$ 与 $CD$ 相交于点 $O$ 所得的四个角 $\angle AOC$、$\angle BOD$、$\angle AOD$、$\angle BOC$：

- 对顶角共有两对：$\angle AOC$ 与 $\angle BOD$；$\angle AOD$ 与 $\angle BOC$；
- 邻补角共有四对：$\angle AOC$ 与 $\angle AOD$；$\angle AOC$ 与 $\angle BOC$；$\angle BOD$ 与 $\angle AOD$；$\angle BOD$ 与 $\angle BOC$。

掌握"两直线相交 → 4 个角 → 2 对对顶角 + 4 对邻补角"这条主线，是后续讨论平行线判定与性质的基础。

## 二、定义

**邻补角**：如果两个角有**公共顶点**、有**一条公共边**，且它们的另一边**互为反向延长线**，那么这两个角叫做邻补角。

**对顶角**：如果两个角有**公共顶点**，并且**一个角的两边分别是另一个角两边的反向延长线**，那么这两个角叫做对顶角。

**核心定理**：

- 对顶角相等；
- 邻补角互补，即和为 $180°$。

定义中的关键词是"反向延长线"。仅"有公共顶点和公共边"还不够，例如墙角处共顶点共边的两角，未必构成邻补角。判定时务必检查：剩下的一边是否在同一条直线上、方向是否相反。

## 三、证明"对顶角相等"

**已知**：直线 $AB$ 与直线 $CD$ 相交于点 $O$，$\angle AOC$ 与 $\angle BOD$ 是对顶角。

**求证**：$\angle AOC = \angle BOD$。

**证明**：

因为 $A$、$O$、$B$ 三点共线，所以 $\angle AOC$ 与 $\angle AOD$ 构成邻补角，故

$$\angle AOC + \angle AOD = 180°. \quad (1)$$

又因为 $C$、$O$、$D$ 三点共线，所以 $\angle BOD$ 与 $\angle AOD$ 也构成邻补角，故

$$\angle BOD + \angle AOD = 180°. \quad (2)$$

由 $(1)(2)$ 两式，$\angle AOC$ 与 $\angle BOD$ 都是 $\angle AOD$ 的补角，由**同角的补角相等**（呼应 part1/04 节）即得

$$\angle AOC = \angle BOD.$$

同理可证另一对对顶角 $\angle AOD = \angle BOC$。证毕。

这是几何课本中最早出现的"完整两步推理"之一，请务必能默写。

## 四、典型应用

### 例 1

如图，直线 $AB$ 与 $CD$ 相交于 $O$，已知 $\angle 1 = 70°$，求其余三个角。

**解**：设 $\angle 1 = \angle AOC = 70°$。

- 由邻补角互补：$\angle AOD = 180° - 70° = 110°$；
- 由对顶角相等：$\angle BOD = \angle AOC = 70°$；
- 由对顶角相等：$\angle BOC = \angle AOD = 110°$。

故其余三个角为 $110°$、$70°$、$110°$。

### 例 2

三条直线 $\ell_1$、$\ell_2$、$\ell_3$ 交于同一点 $O$，把平面分成 $6$ 个角。已知其中相邻的两个角 $\angle 1 = 50°$，$\angle 2 = 60°$。求其余 $4$ 个角的度数。

**思路**：三线共点时，六个角的和为 $360°$；并且每条直线两侧形成一个平角，三条直线 → 三个 $180°$ 关系。利用对顶角与邻补角即可逐一确定。

**解**：设六个角依次为 $\angle 1, \angle 2, \angle 3, \angle 4, \angle 5, \angle 6$，且 $\angle 4$、$\angle 5$、$\angle 6$ 分别与 $\angle 1$、$\angle 2$、$\angle 3$ 是对顶角。

- 同一条直线上：$\angle 1 + \angle 2 + \angle 3 = 180°$，故 $\angle 3 = 180° - 50° - 60° = 70°$；
- 对顶角相等：$\angle 4 = \angle 1 = 50°$，$\angle 5 = \angle 2 = 60°$，$\angle 6 = \angle 3 = 70°$。

故其余四个角为 $70°, 50°, 60°, 70°$。

### 例 3

两个角互为邻补角，其中一个角是另一个角的 $2$ 倍。求这两个角的度数。

**【思路】**：邻补角的本质是"两角之和等于 $180°$"。设较小的角为 $x$，则较大的角为 $2x$，列方程 $x + 2x = 180°$，一元一次方程便可解决。

**解**：设较小角为 $x$，则较大角为 $2x$。由邻补角互补：

$$x + 2x = 180°,$$

解得 $x = 60°$，故两角分别为 $60°$ 与 $120°$。

## 五、易错点

1. **对顶角必须由两直线相交而成**。仅"有公共顶点、两边方向相反"还不够，如果四条射线不来自两条完整的直线，则不是对顶角。判定时一定要确认"两条直线"。
2. **邻补角不仅相邻，还必须满足"另一边互为反向延长线"**。否则只是普通的相邻角，不一定互补。例如三角形内一顶点处的两个邻角通常并不互补。
3. **对顶角相等是后续证两角相等最常用的"桥梁"之一**。在涉及"X 形相交""蝴蝶模型"以及平行线截图中的角度搬运时，第一步往往就是"由对顶角相等"。
4. 书写时务必注明依据，例如"由对顶角相等"或"由邻补角互补"，不要直接给出等量关系而省略理由。
