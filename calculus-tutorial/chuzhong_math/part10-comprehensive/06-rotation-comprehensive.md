# 旋转综合问题

> **一图速记**：旋转综合题 $=$ **旋转 + 全等 / 相似 + 勾股**。看到等腰 / 等边 / 正方形 $+$ 旋转——立刻在心里点名三种"老搭档"：**手拉手**（呼应 part3/cong/03）、**半角**（呼应 part6/06）、**旋转构造**（呼应 part3/cong/04 与 part6/07）。旋转最爱做的事情就是把"两条等长边 $+$ 它们的夹角"原地转一个固定角度，**对应顶点连出来的两段会变成一对全等三角形的对应边**——这正是"手拉手"的灵魂。

---

## 一、引入

> **旋转原型题**：正方形 $ABCD$ 中，$E$ 是边 $BC$ 上一点。把 $\triangle ABE$ 绕 $A$ 逆时针旋转 $90°$，得到 $\triangle ADE'$。已知 $BE = 3$、$EC = 5$。
> (1) 判断 $\triangle AEE'$ 的形状并求其面积；
> (2) 求 $E'C$ 的长；
> (3) 若把"正方形 $+$ 绕 $A$ 转 $90°$"替换为"等边 $\triangle ABC$ $+$ 绕 $A$ 转 $60°$"，并把 $E$ 从 $BC$ 取到 $E$、对应 $E'$ 落到 $AC$ 的延长线上，再问 $\triangle AEE'$ 的形状。

题目里出现**两个关键词**就足够触发"旋转思路"：

1. **正方形 / 等边 / 等腰**——保证图里存在 $AB = AD$（或 $AB = AC$）这类"等长边"。
2. **旋转 $90°$ / $60°$**——告诉你旋转角恰好等于"两条等长边的夹角"，旋转后**对应边重合**。

这两个条件凑齐，**旋转后 $\triangle AEE'$ 必为特殊三角形**（$90°$ 配等腰直角，$60°$ 配等边）。第 1 问问"$\triangle AEE'$ 的形状"，几乎就是在送分。下一节把这个思路一行一行写给你看。

---

## 二、思维路径还原

> 看到"正方形 $+$ 绕 $A$ 旋转 $90°$"——我脑子里先把旋转的**对应关系**列清楚：$B \to D$（因为 $\angle BAD = 90°$，$AB = AD$，正好旋转到位）；$E$ 落到 $E'$；连出来的图就是 $\triangle ABE \xrightarrow{\text{旋转 }90°} \triangle ADE'$。
>
> **旋转保距、保角**——所以 $AE = AE'$、$\angle EAE' = 90°$（旋转角）。**等腰 $+$ 直角顶角 $\Rightarrow \triangle AEE'$ 是等腰直角三角形**。这就是第 (1) 问的"形状"部分，**不到三秒**。
>
> 求面积要先算 $AE$。$\triangle ABE$ 里 $\angle ABE = 90°$（正方形角），$AB = BE + EC = 3 + 5 = 8$，$BE = 3$，勾股得 $AE^2 = 64 + 9 = 73$。$\triangle AEE'$ 等腰直角，**两腰** $= AE = \sqrt{73}$，面积 $= \dfrac{1}{2} \cdot AE^2 = \dfrac{73}{2}$。
>
> (2) 求 $E'C$。$E'$ 在哪？由 $B \to D$、$E \to E'$，旋转保对应边：$DE' = BE = 3$。$E'$ 落在 $\triangle ADE'$ 里、$D$ 的"外侧"——把 $\triangle ABE$ 整体绕 $A$ 转 $90°$，$DE'$ 与 $DC$ 在 $D$ 同侧（$AD$ 的"远 $B$ 一侧"）。如果 $E'$ 在线段 $DC$ 的**延长线**上：$E'D = 3$，$DC = 8$，故 $E'C = DC + DE' = 8 + 3 = 11$。
>
> （这里有一个**易错点**：$E'$ 究竟在 $DC$ 上还是延长线上？只要画图：$B$ 在 $A$ 的右下，逆时针 $90°$ 后到 $A$ 的左下方向；但**$D$ 已经在 $A$ 的正下**，所以 $E$ 的像 $E'$ 必然在 $D$ 的**外侧**——也就是 $CD$ 的延长线方向。**画准坐标系再下笔**。）
>
> 这道题也可以**不旋转**——直接坐标硬算。建系 $A(0,0), B(8,0), C(8,8), D(0,8)$（边长 $8$），$E(8, 3)$。但**那样不优雅**：用旋转思路，"$\triangle ABE \cong \triangle ADE'$"一行就把所有对应量都拉出来了，比硬算坐标快得多。
>
> (3) 等边 $+$ 旋转 $60°$。同样路数：旋转角 $= 60°$ 等于顶角 $\angle BAC$，$AB = AC$，**$B \to C$**；$E \to E'$；$AE = AE'$、$\angle EAE' = 60°$——**等腰 $+$ 顶角 $60° \Rightarrow$ 等边三角形**。$\triangle AEE'$ 是**等边三角形**。$EE' = AE$。这正是"**手拉手**"模型的标准结论。
>
> 提取规律：**等长边 $+$ 夹角 $=$ 旋转角** $\Rightarrow$ 旋转后产生特殊三角形（$90°$ $\Rightarrow$ 等腰直角；$60°$ $\Rightarrow$ 等边；$120°$ $\Rightarrow$ 顶角 $120°$ 的等腰；$\theta$ $\Rightarrow$ 顶角 $\theta$ 的等腰）。下一节抽象成统一流程。

---

## 三、抽象成题型：旋转五步法

旋转综合 $=$ **找等长边** $+$ **确定旋转中心** $+$ **写对应关系** $+$ **用产生的特殊三角形** $+$ **勾股 / 相似收口**。统一流程：

| 步骤 | 操作 | 关键工具 |
|---|---|---|
| ① **找等长边** | 在图里找 $AB = AC$（或 $AB = AD$ 等） | 等腰 / 等边 / 正方形必有 |
| ② **定旋转中心** | 等长边的公共端点 | 例 $A$ 是中心 |
| ③ **定旋转角** | 旋转角 $=$ 两等长边的夹角 | $\angle BAC$ 或 $\angle BAD$ |
| ④ **写对应** | $B \to C$、其他点 $P \to P'$；$AP = AP'$、$\angle PAP' =$ 旋转角 | 旋转保距、保角 |
| ⑤ **用结论** | $\triangle APP'$ 是等腰，顶角 $=$ 旋转角；常配勾股 / 相似 | 等腰直角、等边、$120°$ 顶角 |

**为什么旋转角必须等于"两等长边的夹角"？** —— 因为只有这样 $B$ 才能恰好旋转到 $C$，**两个三角形才会刚好拼起来**。一旦角度对上，"$\triangle ABE \cong \triangle ACE'$"是免费的，全等三对应边、三对应角直接拿去用。

**手拉手模型回忆**（part3/cong/03）：以 $A$ 为公共顶点，$\triangle ABE$ 和 $\triangle ACE'$ 满足 $AB = AC$、$AE = AE'$、$\angle BAE = \angle CAE'$，则 $\triangle ABE \cong \triangle ACE'$ 且 $BE = CE'$。旋转就是手拉手的"动态生成器"——把一个三角形绕 $A$ 转一下，**立刻造出"手拉手"的另一只手**。

**半角模型回忆**（part6/06）：正方形里 $\angle EAF = 45°$ 时，$EF = BE + DF$。证明思路就是"把 $\triangle ABE$ 绕 $A$ 转 $90°$"——这本质上是**旋转构造**。所以**半角 $=$ 旋转 $+$ 拼接**。

## 四、模型变形

旋转题的"花样"基本可以归到下面 $5$ 种母型：

**① 正方形 $+$ 绕顶点 $90°$ 旋转**（引入 (1)(2)）：最常见。等长边是正方形的两条邻边，夹角 $90°$，旋转角也是 $90°$，**产物是等腰直角三角形**。
- 应用：求 $\triangle AEE'$ 面积；求"绕一圈"后某线段长；半角模型的证明。
- 题眼：图里有正方形 $+$ 题目谈"$\triangle ABX$ 绕 $A$ 转 $90°$"或"$BE = DF$"这类等量。

**② 等边三角形 $+$ 绕顶点 $60°$ 旋转**（引入 (3)）：经典手拉手。$AB = AC$、$\angle BAC = 60°$，旋转角 $60°$，**产物是等边三角形**。
- 应用：费马点、$PA + PB + PC$ 最小值（把其中一段旋转 $60°$ 化为共线最短）。
- 注：费马点的经典做法就是"把 $\triangle APB$ 绕 $B$（或 $A$）旋转 $60°$"，把折线 $PA + PB + PC$ 拉成一条共线段。

**③ 等腰直角三角形 $+$ 绕直角顶点 $90°$ 旋转**：和 ① 类似，但常考"双等腰直角"叠加（一个套在另一个里）。
- 应用："两个等腰直角三角形共直角顶点"——必有一对全等。

**④ 任意等腰三角形 $+$ 绕顶角顶点旋转**（顶角 $\theta$、旋转 $\theta$）：产物是顶角 $\theta$ 的等腰三角形。
- 应用：$\theta = 120°$ 时常配"$30°$ 一$60°$ 一$90°$"小三角形和勾股。

**⑤ 正方形 $+$ 半角 $+$ 旋转拼接**：正方形里 $\angle EAF = 45°$（即顶角的一半），**把 $\triangle ABE$ 绕 $A$ 转 $90°$ 到 $\triangle ADE''$**，将 $E''$、$F$、$E$ 拼到一条线上，得 $EF = BE + DF$。半角的本质就是旋转。

**关于"旋转后图形跑到哪里"**：旋转有方向（顺时针 / 逆时针），**画图前要先标好方向**。一个常见错法是"逆时针转 $90°$"画成顺时针，结果 $E'$ 跑到了相反一侧，所有计算反号。**做法**：在旋转中心画一段"短弧 $+$ 箭头"，把方向标死。

**"绕外部点 $P$ 的旋转"**：少数题里旋转中心**不在已有顶点上**，而是某个特殊点（比如等边三角形的中心、矩形的对角线交点）。识别方法：题目里若有"将某图形绕某中心旋转使某点落到某点"，**反推旋转中心**——它就是"原点和像点连线"的垂直平分线交点（与所有"对应点对"的中垂线交于一点）。

**"半周旋转 $180°$" = 中心对称**：旋转角 $180°$ 时，旋转 $=$ 中心对称（呼应 part6/05）。这是旋转的特例，常出现在"$M$ 是中点，证 $\triangle ABM \cong \triangle CDM$"类题目里——把一个三角形绕 $M$ 转 $180°$ 即得另一个。

**"旋转 $+$ 相似"**：少数题里两个三角形不全等而是**相似**（对应边成比例 $\neq 1$），这叫**旋转相似**——旋转 $+$ 缩放的复合。常出现在与位似结合的题型里（呼应 part6/05 位似）。

## 五、思考路标

- 看到"**正方形 / 等边 / 等腰** $+$ 旋转" → 立刻在心里走"五步法"：找等长边 $\to$ 定中心 $\to$ 定旋转角 $\to$ 写对应 $\to$ 用特殊三角形。
- 看到"$\angle EAF =$ 顶角的一半"（如正方形里的 $45°$、等边里的 $30°$）→ 这是**半角模型**的入口，证明思路一定是**旋转拼接**。
- 看到"**$PA + PB + PC$ 最小值**"、"**费马点**" → 把其中一段绕一个顶点旋转 $60°$，化"折线"为"直线"。
- 旋转后**画准方向**，逆时针 / 顺时针搞反会导致 $E'$ 跑到错的一侧。建议在中心画 $90°$ 弧 $+$ 箭头。
- 旋转后**对应量立刻抄一遍**：$AE = AE'$、$BE = $ 对应边、$\angle EAE' =$ 旋转角。这一行是"步骤分"，省不得。
- 旋转后**$\triangle AEE'$ 是顶角 $=$ 旋转角的等腰三角形**——这是几乎所有旋转题求面积 / 长度的"中间产物"。
- 几何画图！正方形 $+$ $90°$ 旋转的图很容易把 $E'$ 画到错位置——**先标 $B \to D$ 的对应**，再标 $E$ 沿同一旋转量到 $E'$。
- 旋转 $180°$ $=$ 中心对称，遇到"$M$ 是中点"类型先试这一招。
- 题目若有"绕某点转某角"但**没说哪个图形**，要主动**识别哪两个三角形对应**——通常是题目里"等长边相关的两个三角形"。
- 旋转 $+$ 全等的标准书写：先写"由旋转性质" $\Rightarrow$ 写对应边角等 $\Rightarrow$ 写两三角形全等的判定（SAS）$\Rightarrow$ 引用对应量。**这套话术每步都给分**。
- 如果旋转后的图与原图**有公共部分**（如重叠的小三角形），先**画交线**——常会得到一对相似或全等的小三角形作"副产品"。

## 六、应用例题

### 例 1（正方形 $+$ $90°$ 旋转：经典半角证明）

正方形 $ABCD$ 边长为 $a$。$E$ 在 $BC$ 上，$F$ 在 $CD$ 上，$\angle EAF = 45°$。证明 $EF = BE + DF$。

**解**：

**第 ① 步找等长边**：$AB = AD = a$。

**第 ② 步定中心**：$A$。

**第 ③ 步定旋转角**：$\angle BAD = 90°$。把 $\triangle ABE$ 绕 $A$ 顺时针旋转 $90°$，$B \to D$，$E \to E'$（$E'$ 在 $CD$ 延长线上即 $D$ 的下方）。

**第 ④ 步写对应**：$AE = AE'$、$\angle BAE = \angle DAE'$、$BE = DE'$。

**第 ⑤ 步用结论**：$\angle E'AF = \angle DAE' + \angle DAF = \angle BAE + \angle DAF = \angle BAD - \angle EAF = 90° - 45° = 45° = \angle EAF$。

又 $AE = AE'$、$AF = AF$，由 **SAS** 得 $\triangle AEF \cong \triangle AE'F$，故 $EF = E'F = E'D + DF = BE + DF$。$\blacksquare$

（小结：**半角 $=$ 旋转 $90°$ $+$ 拼接 $+$ SAS** 的经典三段式。把 $BE$ 这一段"搬到 $DF$ 那一侧"，再用 SAS 把 $EF$ 写成"$BE + DF$"，思路非常直白。）

### 例 2（等边 $+$ $60°$ 旋转：费马点雏形）

等边 $\triangle ABC$ 内一点 $P$，$PA = 3$、$PB = 4$、$PC = 5$。求 $\triangle ABC$ 的边长。

**解**：

**关键构造**：把 $\triangle APB$ 绕 $B$ 顺时针旋转 $60°$，$A \to C$（因 $BA = BC$、$\angle ABC = 60°$），$P \to P'$。

**第 ④ 步对应**：$BP = BP' = 4$、$\angle PBP' = 60°$、$AP = CP' = 3$。

**第 ⑤ 步用结论**：$\triangle BPP'$ 顶角 $60°$ $+$ 等腰 $\Rightarrow$ **等边**，故 $PP' = 4$。

现在看 $\triangle PCP'$：三边 $PC = 5$、$CP' = 3$、$PP' = 4$。验勾股 $3^2 + 4^2 = 25 = 5^2$ $\Rightarrow$ $\angle PP'C = 90°$。

于是 $\angle BP'C = \angle BP'P + \angle PP'C = 60° + 90° = 150°$。

在 $\triangle BP'C$ 中由余弦定理：

$$BC^2 = BP'^2 + CP'^2 - 2 \cdot BP' \cdot CP' \cdot \cos 150° = 16 + 9 - 2\cdot 4 \cdot 3 \cdot (-\tfrac{\sqrt{3}}{2}) = 25 + 12\sqrt{3}.$$

$$BC = \sqrt{25 + 12\sqrt{3}}.$$

（小结：等边 $+$ 旋转 $60°$ 把"等边内一点到三顶点的距离"拼成一个三边已知的三角形——这是费马点和"$PA + PB + PC$ 最小"题的核心套路。**$3, 4, 5$ 凑成直角**是巧合，更一般的题里你会得到一般的三角形。）

### 例 3（正方形 $+$ $90°$ 旋转：多步综合）

正方形 $ABCD$ 边长 $4$。$E$ 在 $BC$ 上、$F$ 在 $CD$ 上，使 $\angle EAF = 45°$。若 $BE = 1$，求 $\triangle CEF$ 的面积。

**解**：

由例 1 的结论 $EF = BE + DF$。设 $DF = x$，则 $EF = 1 + x$。

正方形里 $CE = BC - BE = 3$、$CF = CD - DF = 4 - x$，$\angle ECF = 90°$。

在 Rt $\triangle CEF$ 中由勾股：

$$EF^2 = CE^2 + CF^2 \Rightarrow (1 + x)^2 = 9 + (4 - x)^2.$$

展开：$1 + 2x + x^2 = 9 + 16 - 8x + x^2$，$10x = 24$，$x = \dfrac{12}{5}$。

$CF = 4 - \dfrac{12}{5} = \dfrac{8}{5}$，$CE = 3$。

$$S_{\triangle CEF} = \dfrac{1}{2}\cdot CE \cdot CF = \dfrac{1}{2}\cdot 3 \cdot \dfrac{8}{5} = \dfrac{12}{5}.$$

**答**：$S_{\triangle CEF} = \dfrac{12}{5}$。

（小结：这道题"旋转 $+$ 半角"提供等量 $EF = BE + DF$；"$\angle ECF = 90°$" 提供勾股方程；联立解 $x$。**旋转用一次提供等量、勾股用一次列方程**——多步综合题的拼装感非常典型。）

## 七、思路自测题

> 💡 提示：五步法雷打不动——**找等长边** → **定中心** → **定旋转角** → **写对应** → **用特殊三角形 $+$ 勾股 / 相似**。

1. 正方形 $ABCD$ 中，$E$ 在 $BC$ 上、$F$ 在 $CD$ 上，$\angle EAF = 45°$。若正方形边长 $6$、$DF = 2$，求 $BE$。
   > 💡 提示：由半角模型 $EF = BE + DF$。设 $BE = y$，则 $EF = y + 2$、$CE = 6 - y$、$CF = 4$。Rt $\triangle CEF$ 勾股 $(y+2)^2 = (6-y)^2 + 16$，化简解 $y$。

2. 等边 $\triangle ABC$ 内一点 $P$，$PA = 5$、$PB = 12$、$PC = 13$。求 $\angle APB$。
   > 💡 提示：把 $\triangle APC$ 绕 $A$ 顺时针旋转 $60°$（$C \to B$），$P \to P'$。则 $AP = AP'$、$\angle PAP' = 60°$ $\Rightarrow$ $\triangle APP'$ 等边 $\Rightarrow$ $PP' = 5$。又 $BP' = CP = 13$、$BP = 12$，验 $5^2 + 12^2 = 13^2$ $\Rightarrow \angle BPP' = 90°$。故 $\angle APB = \angle APP' + \angle BPP' = 60° + 90° = 150°$。

3. 正方形 $ABCD$ 中，$E$、$F$ 分别在 $BC$、$CD$ 上，$BE = DF$。$AE$、$AF$ 与对角线 $BD$ 分别交于 $M$、$N$。证明 $\triangle AMN$ 为等腰直角三角形。
   > 💡 提示：先证 $\triangle ABE \cong \triangle ADF$（$AB = AD$、$\angle ABE = \angle ADF$、$BE = DF$，SAS）$\Rightarrow$ $\angle BAE = \angle DAF$ 且 $AE = AF$。再绕 $A$ 把 $\triangle ABM$ 旋转 $90°$ 至 $\triangle ADM'$；利用 $\angle MAN = 45°$（$\angle BAE + \angle FAD = 45°$）得到半角配置 $\Rightarrow \triangle AMN$ 顶角 $\angle MAN = 45°$ $+$ 两腰 $AM, AN$ 由对称等长 $\Rightarrow$ 等腰；再用 $BD \perp AC$ 推出底角为 $\dfrac{180° - 45°}{2}$？此处方向错——直接做：$\triangle ABM \cong \triangle ANM$？建议建坐标 $A(0,0), B(1,0), C(1,1), D(0,1)$ 验证。

4. 等边 $\triangle ABC$ 边长 $6$，$D$ 在 $BC$ 上且 $BD = 2$。把 $\triangle ABD$ 绕 $A$ 逆时针旋转 $60°$ 得 $\triangle ACD'$。求 $DD'$。
   > 💡 提示：$AD = AD'$、$\angle DAD' = 60°$ $\Rightarrow$ $\triangle ADD'$ 等边 $\Rightarrow$ $DD' = AD$。先在 $\triangle ABD$ 里用余弦定理（或勾股 + 高）：$AD^2 = AB^2 + BD^2 - 2\cdot AB \cdot BD \cdot \cos 60° = 36 + 4 - 12 = 28$，$AD = 2\sqrt{7}$。故 $DD' = 2\sqrt{7}$。

5. 正方形 $ABCD$ 边长 $a$。$P$ 是正方形内一点且 $PA = 1$、$PB = 2$、$PC = 3$。求 $a$。
   > 💡 提示：把 $\triangle APB$ 绕 $B$ 顺时针旋转 $90°$，$A \to C$，$P \to P'$。则 $BP = BP' = 2$、$\angle PBP' = 90°$ $\Rightarrow$ $\triangle BPP'$ 等腰直角 $\Rightarrow$ $PP' = 2\sqrt{2}$。又 $CP' = AP = 1$、$CP = 3$，验 $1^2 + (2\sqrt 2)^2 = 1 + 8 = 9 = 3^2$ $\Rightarrow \angle CP'P = 90°$。$\angle BP'C = 45° + 90° = 135°$。在 $\triangle BP'C$ 中由余弦定理 $BC^2 = 4 + 1 - 2\cdot 2 \cdot 1 \cdot \cos 135° = 5 + 2\sqrt{2}$。故 $a = \sqrt{5 + 2\sqrt 2}$。
