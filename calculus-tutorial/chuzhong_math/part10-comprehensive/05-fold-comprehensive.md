# 折叠综合问题

> **一图速记**：折叠 $=$ **轴对称**（呼应 part6/06）。折叠题往往把矩形 / 正方形 / 三角形 + **未知量设元** + 勾股方程**拧成一团**。三步必走：① **标折痕**（对称轴） ② 写"**折前 $=$ 折后**"的等量（边等、角等） ③ 设元 + 用勾股或相似列方程。会标对称轴、会写对应等量、会列勾股——折叠题就赢了一半。

---

## 一、引入

> **折叠原型题**：矩形 $ABCD$ 中 $AB = 8$，$AD = 6$。把 $\triangle ABD$ 沿对角线 $BD$ 翻折，点 $A$ 落到 $A'$。
> (1) 求 $A'$ 到 $BC$ 的距离；
> (2) 若把折叠规则改为"沿 $BD$ 折叠时 $A'$ 恰好落在 $BC$ 上"——能否做到？为什么？
> (3) 若改为"把 $\triangle ABE$ 沿 $BE$ 折叠（$E$ 在 $AD$ 上），使 $A$ 落到对角线 $BD$ 上的 $A'$"，求 $AE$ 的长。

题目用了**折叠**两个字，立刻可以心里念两遍口诀：

1. **折前 $=$ 折后**（对应线段相等、对应角相等）。
2. **折痕是对称轴**——折痕**垂直平分**对应点连线。

引入题三问的难度递进刚好覆盖折叠题的三种问法：**求位置**（第 1 问）/ **判存在性**（第 2 问）/ **求未知量**（第 3 问），下面用思路还原把"为什么这样做"摊开。

---

## 二、思维路径还原

> 看到"沿 $BD$ 翻折"——我第一反应：**$BD$ 是对称轴**，$A$ 和 $A'$ 关于 $BD$ 对称。立刻把对应等量写下来：$BA' = BA = 8$、$DA' = DA = 6$、$\angle DBA' = \angle DBA$、$\angle BDA' = \angle BDA$。
>
> (1) 求 $A'$ 到 $BC$ 的距离。第一步要"定位 $A'$"。$A'$ 在哪儿？$BA' = 8, DA' = 6$——以 $B$、$D$ 为圆心的两弧的交点，**两交点**：一个是原来的 $A$，另一个是 $A'$（在 $BD$ 的另一侧）。
>
> 用面积法或坐标法都行。我选坐标：$B(0,0), C(8,0), D(8,6), A(0,6)$。$A'$ 满足 $|A'B| = 8, |A'D| = 6$。$BD$ 长 $\sqrt{8^2+6^2} = 10$。$A'$ 到 $BD$ 的距离 $h$ 等于 $A$ 到 $BD$ 的距离（对称！）。$A$ 到 $BD$ 距离 $= \dfrac{|AB||AD|}{|BD|} = \dfrac{8\cdot 6}{10} = 4.8$。
>
> 接下来 $A'$ 的坐标怎么定？$A'$ 在 $BD$ 关于 $A$ 的对称侧，且到 $BD$ 距离 $4.8$。算一下投影：$A$ 在 $BD$ 上的投影 $H$，$BH = \dfrac{AB^2}{BD} = \dfrac{64}{10} = 6.4$。$A'$ 关于 $H$ 与 $A$ 对称。$BD$ 方向单位向量 $\vec{u} = (0.8, 0.6)$，法向量 $\vec{n} = (-0.6, 0.8)$（指向 $A$ 一侧）。$H = 6.4\vec{u} = (5.12, 3.84)$；$A = H + 4.8\vec{n} = (5.12 - 2.88,\ 3.84 + 3.84) = (2.24, 7.68)$？这不对——$A = (0, 6)$，怎么对不上？换一下符号：$\vec{n} = (-0.6, 0.8)$，$H + 4.8(-0.6, 0.8) = (5.12 - 2.88,\ 3.84 + 3.84) = (2.24, 7.68)$ ≠ $(0, 6)$。说明法向量选错方向：取 $\vec{n}' = (0.6, -0.8)$？$H + 4.8(0.6, -0.8) = (5.12+2.88, 3.84-3.84) = (8, 0)$ ≠ $A$ 也不对。换思路：$A$ 在 $BD$ **左上侧**，$\vec{n}$ 应指向左上。重算：$BD$ 方向 $(8,6)/10 = (0.8, 0.6)$，左转 $90°$ 得 $(-0.6, 0.8)$——$H + 4.8(-0.6, 0.8) = (5.12-2.88, 3.84+3.84) = (2.24, 7.68)$，但 $A=(0,6)$，所以 $A$ 不在 $H$ 法距 $4.8$ 处？错在哪？查 $|H - A| = \sqrt{5.12^2 + 2.16^2} = \sqrt{26.21 + 4.67} = \sqrt{30.88} \approx 5.56 \neq 4.8$。$A$ 到 $BD$ 距离真是 $4.8$ 吗？$BD$ 直线方程：$3x - 4y = 0$；$A(0,6)$ 到它距离 $= \dfrac{|0 - 24|}{5} = 4.8$。**没错**。那 $|H - A|$ 应该等于 $4.8$；我算错了。重算 $H$：$H$ 是 $A$ 在 $BD$ 上的垂足，$\vec{BA} = (0,6)$，$\vec{BD}/|BD| = (0.8, 0.6)$，投影长 $= 0\cdot 0.8 + 6\cdot 0.6 = 3.6$。所以 $H = 3.6\vec{u} = (2.88, 2.16)$。再验：$|HA| = \sqrt{2.88^2 + 3.84^2} = \sqrt{8.29+14.75} = \sqrt{23.04} = 4.8$ ✓。$A' = $ $H$ 关于 $A$ 反向 $= 2H - A = (5.76 - 0,\ 4.32 - 6) = (5.76, -1.68)$。$A'$ 到 $BC$（$x$ 轴）距离 $= 1.68$。
>
> （上面这一段是真实"算错—回查—改正"的过程：折叠题最容易把投影长度算错，**老老实实用向量投影公式或勾股法**才稳。）
>
> (2) "$A'$ 恰好落在 $BC$ 上"——$A'$ 落 $BC$ 上意味着 $A'$ 的纵坐标为 $0$。可上面算出 $A'$ 纵坐标 $-1.68 < 0$，**没办法落到 $BC$ 上**，反而落到 $BC$ 下方。因此**不能**做到（在这组数据下）。
>
> (3) 改为"沿 $BE$ 折叠（$E$ 在 $AD$ 上），使 $A$ 落到 $BD$ 上的 $A'$"。新的对称轴是 $BE$，$BA' = BA = 8$，$A' \in BD$ 且 $BD = 10$，所以 $A'$ 在 $BD$ 上距 $B$ 为 $8$ 的点。$EA' = EA$（折叠），$\angle BA'E = \angle BAE = 90°$。设 $AE = x$，则 $A'E = x$、$DA' = BD - BA' = 10 - 8 = 2$、$DE = AD - AE = 6 - x$。在 Rt $\triangle DA'E$ 中（$\angle DA'E = 180° - \angle BA'E = 90°$）：$DA'^2 + A'E^2 = DE^2$，即 $4 + x^2 = (6-x)^2 = 36 - 12x + x^2$，$12x = 32$，$x = \dfrac{8}{3}$。
>
> 总结这道题用到的全部套路：**写对应等量** → **设元** → **找出垂直 $90°$（折前直角必然保留）** → **勾股列方程**。下一节把它做成通用流程。

## 三、抽象成题型：折叠四步法

折叠综合 $=$ **轴对称 + 设元 + 勾股 / 相似 + 验范围**。统一流程：

| 步骤 | 操作 | 关键工具 |
|---|---|---|
| ① **标折痕** | 找出对称轴（折叠时所沿的线） | 折痕 $\perp$ 平分对应点连线 |
| ② **写等量** | 折前 $=$ 折后：对应**边**等、对应**角**等 | 对应线段、对应角全部抄一遍 |
| ③ **设元** | 取一个未知线段为 $x$（通常是折痕端点到顶点的距离） | 用 $x$ 把图中所有线段都"标完" |
| ④ **列方程** | 在某个直角三角形里用**勾股**；或用**相似 / 三角函数** | $a^2 + b^2 = c^2$ 是主力 |
| ⑤ **验取值** | $x$ 是线段长 $\Rightarrow x > 0$；$x$ 应小于所在边长 | 剔除超界 / 负数解 |

**为什么勾股是主力？** —— 折叠时**直角往往会被保留**（矩形 / 正方形的直角折过去仍然是直角；折前直角顶点折后仍直角）。一旦图里出现"折后的直角顶点"，就**几乎必然要在那个顶点周围找直角三角形列勾股**。

**为什么相似也常用？** —— 折叠产生的一对对应角相等 + 顶角公用，**很多时候自然得到一对相似三角形**（典型：矩形折叠把一个角折到对边上，产生"A 字形"或"X 字形"相似——呼应 part6/05）。

## 四、模型变形

折叠题虽然花样多，但都从下面 $5$ 种"母型"派生：

**① 矩形沿对角线折**（引入 (1)）：$\triangle ABD$ 折成 $\triangle A'BD$，$A'$ 在矩形外部或内部。常考"$A'$ 到某边距离"或"折叠后重叠部分面积"。
- 重叠部分（折叠后 $A'$ 落在矩形内时）通常是一个**等腰三角形**——这是因为折叠等量 + 矩形对边平行给出"角相等 → 等腰"。

**② 矩形沿一条折痕把一个顶点折到对边上**（引入 (3) 的变体）：把 $A$ 沿 $BE$（$E$ 在 $AD$ 上）折到 $BC$ 上的 $A'$。
- 关键等量：$BA' = BA$、$EA' = EA$、$\angle BA'E = 90°$。
- 设 $AE = x$，在 Rt $\triangle BCA'$ 和 Rt $\triangle EDA'$（或类似）里列勾股。
- 这类题**几乎一定能转化为关于 $x$ 的一元二次方程**。

**③ 矩形沿一条折痕把一个顶点折到对角线上**（引入 (3)）：把 $A$ 折到 $BD$ 上 $A'$。
- 关键：$BA' = BA$（折前折后等）、$\angle BA'E = 90°$。
- 由 $BD$ 已知长度，可直接算 $DA' = BD - BA'$。
- 再用勾股。

**④ 正方形折叠 + 半角模型**：正方形 $ABCD$ 中，把角 $A$ 沿一条过 $A$ 的折痕折下来，使 $AB$ 落到 $AC$ 上之类——折叠产生"$45°$ 半角"，常与 part6/06 半角模型联动。
- 折痕 $=$ 角平分线；折叠后形成等腰直角小三角形。
- 列方程时常要"绕一圈"用勾股 + 等腰。

**⑤ 三角形折叠（中位线方向）**：等腰 / 直角三角形沿中位线方向折，产生**两层重叠**——常考重叠部分面积、折后某顶点到某边距离。
- 常用面积法（重叠部分 = 原 - 翻出去那部分）。
- 折痕长 = 中位线 ⇒ $\dfrac{1}{2}\times$ 对应边（这点要记牢）。

**特别提醒——折痕长度**：折痕长度也是高频考点，常用 **面积法**（折前折后两个全等三角形拼起来，公共边即折痕；用整体面积 / 折痕长 = 高 来反推）或**勾股**（折痕端点都已经在边上时直接勾股）。还有一招"**中垂线定位**"：若题目说"折叠后 $A$ 与 $C$ 重合"，那么折痕就是 $AC$ 的**垂直平分线**，直接画中垂线找折痕与各边的交点即可，省掉冗长的设元过程（见例 2）。

**判断"能否落上"**：题目里若问"将某点折到某边上是否可行"，这是**存在性判断**——只要看"折前折后等距"的限制是否在那条边的允许范围内。例如将矩形 $ABCD$ 中的 $A$ 沿某折痕折到 $BC$ 上 $A'$，必有 $BA' = BA$，故只要 $BA \leq BC$ 就能落上，否则必落到 $BC$ 的延长线上。引入题 (2) 的"不能"就是这个判据失败的例子。

**折叠的"两类不变量"**：折叠前后**线段长度**和**角的大小**都不变，但**点的相对位置**会变（折前在内可能折后到外）。做题时一定要分清"哪些量必相等"和"哪些量需要重新计算"——前者抄一遍，后者列方程算。

## 五、思考路标

- 看到"**沿 ... 折叠**" → 立刻在心里写口诀：**对称轴 + 折前折后等**。所有对应**边、角**先抄一遍才动手。
- 看到"**$A$ 落到某条线 / 某条对角线上**" → 这条信息给出"折后某线段等于某值"，是**列方程的钥匙**。
- 折叠题里出现的**直角**九成保留（矩形顶点直角折过去还是直角），**用勾股**。
- 如果折痕未知且要算 → 想想**面积法**：折叠前后图形面积不变，公共部分 + 翻出去部分 = 原图。
- 折叠 + 相似：折叠常制造"角相等"，与公共角合作产生**相似三角形**——出现"一组对应角相等"要立刻试相似。
- 解出 $x$ 后**两道关**：① $x > 0$；② $x$ 不超过所在边长度。
- 几何画出来！折叠题如果不画图，几乎不可能算对（折痕的位置、折后点位置都得画出来才不混乱）。建议**用两种颜色**：折前用一种、折后用另一种，一眼就能看清谁对应谁。
- "$A$ 和 $C$ 重合" 这类对称信息 → **折痕 = $AC$ 中垂线**，省掉所有设元。
- 题目里如果连续两次折叠（先沿 $l_1$ 再沿 $l_2$），就把它当成**两次轴对称的复合**——若两轴相交，等价于绕交点的**旋转**（旋转角 $=$ 两轴夹角的 $2$ 倍）；若两轴平行，等价于**平移**（呼应 part6 中变换的合成）。
- 答题书写时记得交代"由折叠得 $XX = YY$"，写出这一步可以拿"步骤分"，省掉就容易扣分。

## 六、应用例题

### 例 1（矩形折叠求长度 — 角折到对边）

矩形 $ABCD$ 中 $AB = 6$、$BC = 8$。将 $\triangle ABE$ 沿 $BE$ 折叠（$E$ 在 $AD$ 上），使点 $A$ 落到对角线 $BC$ 上的 $A'$。求 $AE$ 的长。

**解**：

**第 ① 步标折痕**：折痕 $BE$，对称变换 $A \leftrightarrow A'$。

**第 ② 步写等量**：$BA' = BA = 6$；$EA' = EA$；$\angle BA'E = \angle BAE = 90°$。

**第 ③ 步设元**：设 $AE = x$，则 $A'E = x$、$DE = AD - AE = 8 - x$。$BA' = 6$，故 $A' \in BC$ 且 $A'C = BC - BA' = 8 - 6 = 2$。$DA'$ 怎么算？$A'$ 在 $BC$ 上，$D = (6, 8)$？设坐标 $B(0,0), C(0,8), D(6,8), A(6,0)$（注意 $AB = 6$ 为短边）——这里**坐标系要重设**：取 $A(0,0), B(6,0), C(6,8), D(0,8)$。$A' \in BC$，$BA' = 6 \Rightarrow A'(6, 6)$。$E \in AD \Rightarrow E(0, x)$。

**第 ④ 步列方程**：$EA' = EA$ ⟺ $\sqrt{36 + (x-6)^2} = x$，平方：$36 + x^2 - 12x + 36 = x^2$，$72 = 12x$，$x = 6$。

**第 ⑤ 步验范围**：$0 < 6 \leq 8$，合格。

**答**：$AE = 6$。

（小结：注意"$AB$ 是短边、$BC$ 是长边"的设置——$BA' = AB = 6 \leq BC = 8$，所以 $A'$ 确实能落在 $BC$ 上；若 $AB > BC$，问题就**无解**。这正是模型 ② 中的"能否落上"问题。）

### 例 2（矩形折叠求重叠面积）

矩形 $ABCD$ 中 $AB = 4$、$AD = 8$。沿 $EF$ 折叠（$E$ 在 $AD$ 上、$F$ 在 $BC$ 上），使 $A$ 与 $C$ 重合。求折痕 $EF$ 的长。

**解**：

**关键观察**：$A$ 和 $C$ 关于 $EF$ 对称 ⟺ $EF$ 是 $AC$ 的**垂直平分线**。

$AC = \sqrt{16 + 64} = \sqrt{80} = 4\sqrt{5}$。

设 $AC$ 中点 $O$，$EF \perp AC$ 且过 $O$。建坐标 $A(0,0), B(4,0), C(4,8), D(0,8)$。$O = (2, 4)$。$AC$ 方向 $(4, 8)/\sqrt{80} = (1, 2)/\sqrt{5}$，法向 $(-2, 1)/\sqrt{5}$。

$E$ 在 $AD$（$y$ 轴）上，由 $E = O + t(-2, 1)/\sqrt{5}$ 且 $x_E = 0$ 得 $2 - 2t/\sqrt{5} = 0 \Rightarrow t = \sqrt{5}$，$E = (0, 4 + 1) = (0, 5)$。

$F$ 在 $BC$（$x = 4$）上，由 $F = O - t'(-2, 1)/\sqrt{5}$ 且 $x_F = 4$ 得 $2 + 2t'/\sqrt{5} = 4 \Rightarrow t' = \sqrt{5}$，$F = (4, 4 - 1) = (4, 3)$。

$EF = \sqrt{16 + 4} = 2\sqrt{5}$。

**答**：折痕 $EF = 2\sqrt{5}$。

（小结：**"$A$ 与 $C$ 重合" $\Rightarrow$ 折痕是 $AC$ 的中垂线**——这是折叠题里高频出现的"对称转化"。掌握这个就不必再去设元列勾股。）

### 例 3（正方形折叠 + 半角联动）

正方形 $ABCD$ 边长 $6$。$E$ 在 $CD$ 上，$F$ 在 $BC$ 上。沿 $AE$ 折叠 $\triangle ADE$ 使 $D$ 落到 $D'$；沿 $AF$ 折叠 $\triangle ABF$ 使 $B$ 落到 $B'$。若 $D'$ 与 $B'$ 重合（记为点 $P$），且 $P$ 落在对角线 $AC$ 上，求 $DE + BF$。

**解**：

**对应等量**：$AD' = AD = 6$、$AB' = AB = 6$。$D'$ 与 $B'$ 重合于 $P \in AC$，所以 $AP = AD' = AB' = 6$。

正方形对角线 $AC = 6\sqrt{2}$，$AP = 6 < 6\sqrt{2}$，$P$ 在 $AC$ 上靠近 $A$ 一侧。

**找 $\angle EAF$**：$\angle EAP = \angle EAD$（折叠保角），$\angle FAP = \angle FAB$（折叠保角）。$\angle DAB = 90°$，且 $\angle EAD + \angle EAF + \angle FAB = 90°$（如果 $E, F$ 在 $\angle DAB$ 的内部分段）——同时 $\angle EAP + \angle FAP = \angle EAF$，故

$$\angle EAF = \angle EAP + \angle FAP = \angle EAD + \angle FAB.$$

又 $\angle EAD + \angle EAF + \angle FAB = 90°$，代入得 $2\angle EAF = 90°$，$\boxed{\angle EAF = 45°}$。

**正中半角模型**（part6/06）！正方形里 $\angle EAF = 45°$ 当且仅当 $EF = DE + BF$。

**求 $EF$**：$EF$ 由 $E \in CD, F \in BC$ 通过 $P = D' = B'$ 联系。注意：折叠后 $PE = DE$（$P = D'$）、$PF = BF$（$P = B'$）；故 $DE + BF = PE + PF \geq EF$，等号成立 ⟺ $P, E, F$ 共线。**$P$ 是否在 $EF$ 上？** 折叠后 $\angle APE = \angle DAE$？更直接地：$\angle APE = \angle ADE = 90°$、$\angle APF = \angle ABF = 90°$，所以 $\angle EPF = 180°$，即 $E, P, F$ 共线！

故 $DE + BF = EF$。再用半角模型 $EF = DE + BF$（已得到，自洽）。

**算具体值**：设 $DE = m, BF = n$，$EC = 6 - m, FC = 6 - n$。$EF^2 = EC^2 + FC^2 = (6-m)^2 + (6-n)^2$，又 $EF = m + n$。再用 $AP = 6$ 等信息……此处简化：因 $E, P, F$ 共线、$AP \perp EF$（折叠时 $\angle APE = 90°$ 表明 $AP \perp$ 折后的 $EP$，即折后 $\perp EF$），故 $AP$ 是 $\triangle AEF$ 的高 $= 6$，$EF$ 是底，面积 $= \dfrac{1}{2} \cdot EF \cdot 6 = 3EF$。

同时 $S_{\triangle AEF} = S_{ABCD} - S_{\triangle ADE} - S_{\triangle ABF} - S_{\triangle CEF}$
$= 36 - \dfrac{1}{2}\cdot 6 m - \dfrac{1}{2}\cdot 6 n - \dfrac{1}{2}(6-m)(6-n)$
$= 36 - 3m - 3n - \dfrac{1}{2}(36 - 6m - 6n + mn)$
$= 36 - 3m - 3n - 18 + 3m + 3n - \dfrac{1}{2}mn$
$= 18 - \dfrac{1}{2}mn$.

故 $3(m+n) = 18 - \dfrac{1}{2}mn$，即 $6(m+n) + mn = 36$。

由 $EF^2 = (m+n)^2$ 且 $EF^2 = (6-m)^2 + (6-n)^2 = 72 - 12(m+n) + m^2 + n^2$，代入 $(m+n)^2 = m^2 + n^2 + 2mn$，得 $m^2 + n^2 + 2mn = 72 - 12(m+n) + m^2 + n^2$，化简 $2mn = 72 - 12(m+n)$，$mn = 36 - 6(m+n)$。

代回 $6(m+n) + mn = 36$：$6(m+n) + 36 - 6(m+n) = 36$ ✓（恒等式！说明只要 $\angle EAF = 45°$，关系总成立，不能唯一定 $m+n$）。

**需要补充约束**：题目给的"$P$ 在 $AC$ 上"才是定 $m+n$ 的关键。$P$ 在 $AC$ 上意味着 $\angle DAP = 45°$（$AC$ 是对角线），即 $\angle DAE + \angle EAP = 45°$ 而 $\angle DAE = \angle EAP$，故 $\angle DAE = 22.5°$，同理 $\angle BAF = 22.5°$。

$DE = AD \tan 22.5° = 6(\sqrt{2} - 1)$，$BF$ 同。$\boxed{DE + BF = 12(\sqrt{2} - 1)}$。

**答**：$DE + BF = 12(\sqrt{2} - 1)$。

（小结：这道题集成了**折叠 + 半角 + 对角线对称**——折叠产生半角，$P$ 落对角线限制半角再二分，最终用 $\tan 22.5°$ 收口。复杂题的特点就是"几个模型套娃"，每层都按本章四步法剥。）
