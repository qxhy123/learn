# 存在性问题

> **一图速记**：题目问"是否存在某点 $P$ 使图形是特殊形状（等腰 / 直角 / 平行四边形 / 相似）" → **分类讨论 + 列方程**。一个特殊形状通常对应 $2$–$4$ 种情形，**遗漏任一情形都丢分**。先穷尽分类，再逐一列方程，最后回头检查取值范围与重合解。

---

## 一、引入

> **存在性原型题**：抛物线 $y = -x^2 + 2x + 3$ 与 $x$ 轴交于 $A, B$（$A$ 在左），与 $y$ 轴交于 $C$。在 $x$ 轴上是否存在点 $P$，使 $\triangle APC$ 是等腰三角形？若存在，求出 $P$ 的坐标；若不存在，说明理由。

题目以"是否存在"开头，已经把考点和盘托出：**找点 + 满足特殊形状**。难点不在计算，而在**分类的完整性**——少考虑一种情形就少一组解。中考压轴第三问九成都是这个套路。

先把基本量求出来：令 $y = 0$ 得 $-x^2 + 2x + 3 = 0$，即 $x = -1$ 或 $x = 3$，所以 $A(-1, 0)$、$B(3, 0)$；令 $x = 0$ 得 $C(0, 3)$。

---

## 二、思维路径还原

> 我先盯住关键词："**是否存在**"——这五个字一出现，几乎不用想，就是**分类讨论 + 列方程**的套路。
>
> 然后看目标：让 $\triangle APC$ 是**等腰三角形**。等腰意味着"三条边里有两条相等"，但**哪两条**相等并没说，所以分类不可避免。
>
> 列出来：$PA = PC$、$PA = AC$、$PC = AC$，共 **3** 种情形。每种情形对应一个等式，等式里设一个未知数就能解。
>
> $P$ 在 $x$ 轴上 → 设 $P(t, 0)$（这是"动点用参数表达"的标准动作，呼应 part10/01）。
>
> 先把三条边用 $t$ 表达：$PA = |t-(-1)| = |t+1|$；$PC = \sqrt{t^2 + 9}$；$AC = \sqrt{1+9} = \sqrt{10}$。
>
> 逐一列方程：
> - 情形 ①：$PA = PC$ → $(t+1)^2 = t^2 + 9$，展开 $2t + 1 = 9$，$t = 4$。
> - 情形 ②：$PA = AC$ → $|t+1| = \sqrt{10}$，$t = -1 \pm \sqrt{10}$。
> - 情形 ③：$PC = AC$ → $t^2 + 9 = 10$，$t = \pm 1$。其中 $t = -1$ 与 $A$ 重合，三点共线无三角形，**舍去**。
>
> 收齐 $P$：$(4, 0)$、$(-1 + \sqrt{10}, 0)$、$(-1 - \sqrt{10}, 0)$、$(1, 0)$，共 $4$ 个。
>
> 检查：每个 $P$ 都不与 $A$、$C$ 共线？$C$ 不在 $x$ 轴上、$A$ 在 $x$ 轴上，所以只要 $P \neq A$ 即可——已排除。

## 三、抽象成题型：四类存在性问题

存在性问题 = **设元 + 分类 + 列方程 + 验解**。四种最常考的"特殊形状"汇总如下：

| 类型 | 分类标准 | 情形数 | 列方程的工具 |
|---|---|---|---|
| **等腰三角形** | 哪两边相等 | 通常 $3$ 种（$PA=PB$ / $PA=AB$ / $PB=AB$） | 距离公式 + 平方 |
| **直角三角形** | 哪个角是直角 | 通常 $3$ 种（$\angle A = 90°$ / $\angle B = 90°$ / $\angle P = 90°$） | 勾股定理 或 斜率乘积 $= -1$ |
| **平行四边形** | 哪两点是对角线端点 | 通常 $3$ 种（按 $3$ 种对角线配对） | 对角线互相平分 → 中点公式 |
| **相似三角形** | 对应顶点关系 | 通常 $2$ 种（顺序 / 反序） | 对应边成比例 |

**统一流程**（四步法）：
1. **设元**：动点坐标用一个参数表示。$x$ 轴上 → $P(t, 0)$；抛物线上 → $P(t, at^2+bt+c)$；线段上 → 用比例 $t : (1-t)$。
2. **分类**：穷举所有"哪两个相等 / 哪个角直 / 哪条对角线"。
3. **列方程**：用距离公式 / 勾股 / 中点公式翻译成关于参数的方程。
4. **验解**：解出参数后，剔除**三点共线**、**与已知点重合**、**超出取值范围**的解。

## 四、模型变形

**① 等腰直角三角形 / 等边三角形**：在"等腰"基础上加一个角条件——往往只剩 $1$–$2$ 种情形。
- 等腰直角：先按等腰分 $3$ 类，再叠加 $90°$ 的约束（哪个角是直角与哪两边相等要匹配）。
- 等边：三边都相等，方程组 $PA = PB = AB$ 同时成立，往往**至多 $2$ 个解**（在 $AB$ 中垂线上找）。

**② 直角的处理**：列直角条件有两种常用工具——
- **勾股定理**：哪个是斜边，写 $a^2 + b^2 = c^2$（一定先确定斜边！）。
- **斜率乘积 $= -1$**：仅当两直线都不与坐标轴平行时可用；遇到铅直线要单独讨论。

**③ 平行四边形找第 4 点**：已知三点 $A, B, C$ 找 $D$ 使 $ABCD$（或其它顺序）是平行四边形——三种情形对应三种对角线：
- $AB$ 与 $CD$ 是对角线 → $D = A + C - B$（中点公式）。
- $AC$ 与 $BD$ 是对角线 → $D = A + C - B$？不对，应是 $D = B + C - A$ 之类……正确写法：**对角线互相平分** ⟺ 对角线中点重合。设对角线为 $XY$ 与 $ZD$，则中点相等给出 $D = X + Y - Z$。三种配对：$D_1 = B + C - A$、$D_2 = A + C - B$、$D_3 = A + B - C$。
- 答案是三个 $D$（除非有共线情形需舍）。

**④ 相似三角形 $\triangle PMN \sim \triangle ABC$**：对应关系有两种——
- $P \leftrightarrow A, M \leftrightarrow B, N \leftrightarrow C$（顺序对应）
- $P \leftrightarrow A, M \leftrightarrow C, N \leftrightarrow B$（颠倒对应）

每种对应给一组比例方程。注意：若题目只说"$\triangle PMN$ 与 $\triangle ABC$ 相似"而不规定对应，**两种都要写**。

**⑤ 矩形 / 菱形 / 正方形**：在平行四边形基础上叠加约束。
- 矩形 = 平行四边形 + 一个直角 → 先按 PFG 找 $D$，再筛"有一个角是直角"的解。
- 菱形 = 平行四边形 + 邻边相等 → 类似筛选。
- 正方形 = 菱形 + 直角 → 同时筛。

## 五、思考路标

- 关键词"**是否存在**" → 立刻进入分类 + 设元 + 列方程模式，**先穷尽分类再算**。
- "等腰" → 分 **$3$ 种**：哪两边相等。
- "直角" → 分 **$3$ 种**：哪个角直角。**先想清楚斜边！**
- "平行四边形" → 分 **$3$ 种**：哪两点是对角线端点，用中点公式 $D = X+Y-Z$。
- "相似" → 分 **$2$ 种**（或更多）：对应顺序 / 颠倒。
- 含根号的距离方程 → **两边平方**（结果方程不要忘了回代检验，平方可能引入增根）。
- 解出参数后**三道关**：
  - 是否使三点共线？（共线则不构成三角形 / 退化为线段，舍）
  - 是否与已知点重合？
  - 是否在题目允许的取值范围内（如线段上、抛物线第一象限段等）？
- **数完个数再写答**：等腰一般 $3$–$4$ 解、直角一般 $2$–$3$ 解、平行四边形通常 $3$ 解（多于 $3$ 或少于 $3$ 都要重新检查）。

## 六、应用例题

### 例 1（等腰存在性 — 抛物线 + $x$ 轴）

抛物线 $y = x^2 - 4x + 3$ 与 $x$ 轴交于 $A, B$（$A$ 在左），与 $y$ 轴交于 $C$。问 $y$ 轴上是否存在点 $P$ 使 $\triangle PAB$ 是等腰三角形。

**解**：$A(1, 0), B(3, 0)$，$AB = 2$；$C(0, 3)$（虽未直接用）。设 $P(0, t)$。三边：$PA = \sqrt{1 + t^2}$、$PB = \sqrt{9 + t^2}$、$AB = 2$。

- **情形 ①** $PA = PB$：$1 + t^2 = 9 + t^2$，化简得 $1 = 9$，**无解**（$P$ 在 $y$ 轴上，与 $AB$ 中垂线 $x = 2$ 平行不相交）。
- **情形 ②** $PA = AB$：$1 + t^2 = 4$，$t = \pm \sqrt{3}$。$P_1(0, \sqrt{3})$、$P_2(0, -\sqrt{3})$。
- **情形 ③** $PB = AB$：$9 + t^2 = 4$，**无解**（左边 $\geq 9 > 4$）。

**存在**，共 $2$ 个：$P(0, \pm\sqrt{3})$。

（小结：情形 ① 无解是因为 $P$ 的运动轨迹（$y$ 轴）与 $AB$ 的中垂线**平行**——分类不能省略，无解也是答案的一部分。）

### 例 2（直角存在性 — 抛物线上找点）

抛物线 $y = -\dfrac{1}{2}x^2 + \dfrac{3}{2}x + 2$ 与 $x$ 轴交于 $A(-1, 0), B(4, 0)$，与 $y$ 轴交于 $C(0, 2)$。问抛物线上（除 $A, B, C$ 外）是否存在点 $P$ 使 $\triangle PBC$ 是直角三角形。

**解**：设 $P(t, -\frac{1}{2}t^2 + \frac{3}{2}t + 2)$。$BC$ 斜率 $k_{BC} = \dfrac{2-0}{0-4} = -\dfrac{1}{2}$。

- **情形 ①** $\angle PBC = 90°$（在 $B$ 处直角）：$PB \perp BC$，故 $k_{PB} = 2$。
  $$k_{PB} = \dfrac{-\frac{1}{2}t^2 + \frac{3}{2}t + 2}{t - 4} = 2.$$
  化简：$-\frac{1}{2}t^2 + \frac{3}{2}t + 2 = 2(t-4)$，即 $-\frac{1}{2}t^2 + \frac{3}{2}t + 2 = 2t - 8$，整理 $-\frac{1}{2}t^2 - \frac{1}{2}t + 10 = 0$，$t^2 + t - 20 = 0$，$t = 4$ 或 $t = -5$。$t = 4$ 与 $B$ 重合，舍。$P_1(-5, -18)$。
- **情形 ②** $\angle PCB = 90°$（在 $C$ 处直角）：$PC \perp BC$，故 $k_{PC} = 2$。
  $$k_{PC} = \dfrac{-\frac{1}{2}t^2 + \frac{3}{2}t + 2 - 2}{t - 0} = \dfrac{-\frac{1}{2}t^2 + \frac{3}{2}t}{t} = -\dfrac{1}{2}t + \dfrac{3}{2} = 2,$$
  即 $-\frac{1}{2}t = \frac{1}{2}$，$t = -1$。但 $t = -1$ 对应点 $A$（也是抛物线上点），坐标 $(-1, 0)$ ≠ $C(0,2)$——不是与 $C$ 重合，可以保留。验证：$P_2 = A(-1, 0)$，但题目要求"除 $A, B, C$ 外"，**舍去**。
- **情形 ③** $\angle BPC = 90°$（在 $P$ 处直角）：$PB \perp PC$，即 $k_{PB}\cdot k_{PC} = -1$。代入：
  $$\big(-\tfrac{1}{2}t + \tfrac{3}{2}\big)\cdot \dfrac{(-\frac{1}{2}t^2 + \frac{3}{2}t + 2) - 0}{t - 4} = -1.$$
  分子可因式分解 $-\frac{1}{2}t^2 + \frac{3}{2}t + 2 = -\frac{1}{2}(t+1)(t-4)$，故
  $$k_{PB} = \dfrac{-\frac{1}{2}(t+1)(t-4)}{t-4} = -\dfrac{1}{2}(t+1)\quad(t\neq 4).$$
  同理 $k_{PC} = -\frac{1}{2}t + \frac{3}{2} = -\frac{1}{2}(t - 3)$。乘积：$\frac{1}{4}(t+1)(t-3) = -1$，即 $(t+1)(t-3) = -4$，$t^2 - 2t - 3 + 4 = 0$，$t^2 - 2t + 1 = 0$，$t = 1$（**二重根**）。$P_3(1, 3)$。

综上 $P_1(-5, -18)$、$P_3(1, 3)$，共 **$2$ 个**。

（小结：抛物线含 $A, B$ 因式 $(t+1)(t-4)$ 时，$k_{PB}$ 自动消去 $(t-4)$，斜率变成 $t$ 的一次式，运算大幅简化——值得记住的小技巧。）

### 例 3（平行四边形存在性 — 找第 4 点）

已知 $A(-1, 0), B(3, 0), C(0, 3)$。问平面上是否存在点 $D$ 使 $A, B, C, D$ 四点为平行四边形的顶点？若存在求所有 $D$。

**解**：四点构成平行四边形，按对角线配对分 $3$ 种：

- **情形 ①** $AB$ 与 $CD$ 为对角线，即 $AB, CD$ 中点重合：
  $$\dfrac{A+B}{2} = \dfrac{C+D}{2} \Rightarrow D = A + B - C = (-1+3-0,\ 0+0-3) = (2, -3).$$
- **情形 ②** $AC$ 与 $BD$ 为对角线：$D = A + C - B = (-1+0-3,\ 0+3-0) = (-4, 3)$。
- **情形 ③** $AD$ 与 $BC$ 为对角线：$D = B + C - A = (3+0+1,\ 0+3-0) = (4, 3)$。

三个 $D$ 都是合法解（验证三点不共线 → 不退化）：$D_1(2, -3), D_2(-4, 3), D_3(4, 3)$。

**存在 $3$ 个 $D$**。

（小结：三点找第四点构成平行四边形，**永远是 $3$ 解**——只要原三点不共线。万能公式 $D = X + Y - Z$ 一定要会用。）

## 七、思路自测题

> 💡 提示：判断特殊形状种类（等腰 / 直角 / 平行四边形 / 相似），按表格分类数列方程，最后筛掉共线 / 重合 / 越界解。

1. 直线 $y = -x + 4$ 与 $x$ 轴、$y$ 轴分别交于 $A, B$。在 $x$ 轴上是否存在点 $P$ 使 $\triangle ABP$ 是等腰三角形？
   > 💡 提示：$A(4,0), B(0,4)$，设 $P(t, 0)$。$AB = 4\sqrt{2}$。分三类：$PA=PB$（$P$ 在 $AB$ 中垂线上） / $PA=AB$ / $PB=AB$。每类列方程解 $t$，注意 $t = 4$ 与 $A$ 重合时舍去。

2. 抛物线 $y = x^2 - 2x - 3$ 与 $x$ 轴交于 $A(-1, 0), B(3, 0)$，与 $y$ 轴交于 $C(0, -3)$。抛物线上是否存在点 $P$ 使 $\triangle PBC$ 是以 $BC$ 为直角边的直角三角形？
   > 💡 提示：题目限定 $BC$ 是**直角边**——故直角必在 $B$ 或 $C$，只有 $2$ 种情形。用斜率乘积 $= -1$ 或勾股都行。$k_{BC} = 1$，故所求边斜率 $= -1$。

3. 已知 $A(0, 0), B(4, 0), C(2, 3)$。是否存在 $D$ 使 $A, B, C, D$ 是平行四边形顶点？若是菱形呢？
   > 💡 提示：平行四边形 → $D = A+B-C, A+C-B, B+C-A$ 给出三个候选。菱形要再筛"有一组邻边相等"：依次检验三个 $D$ 与对应顶点构成的邻边长度是否相等。

4. 抛物线 $y = -x^2 + 4x$ 上是否存在点 $P$（不与原点 $O$ 重合）使 $\triangle OBP$ 与 $\triangle OAB$ 相似？其中 $A(0, 4), B(4, 0)$。
   > 💡 提示：先看 $\triangle OAB$ 是等腰直角（$OA = OB = 4$，$\angle AOB = 90°$）。"相似"要分对应顺序两类，但等腰直角的对称性下两类会合并。列比例 $\dfrac{OP}{OA} = \dfrac{OB}{OB}$ 或 $\dfrac{OP}{OB} = \dfrac{OB}{OA}$，结合 $P(t, -t^2+4t)$ 求 $t$。注意舍去 $t = 0$（与 $O$ 重合）和 $t = 4$（与 $B$ 重合）。
