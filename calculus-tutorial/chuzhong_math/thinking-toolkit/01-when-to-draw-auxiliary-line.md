# 何时该作辅助线

## 一、辅助线不是灵光一闪

很多同学迷信"辅助线靠悟性"，做对了归功于"突然想到"，做错了归咎于"没灵感"。这是把几何当成了玄学。

请记住一句话：**辅助线 = 条件还没用完时的补丁**。

你之所以卡在某道题上，几乎从来不是因为"想不到那根线"，而是因为**题目给你的某个条件还没被激活**。中点没用上、角平分线没用上、直角没用上、圆心没用上——这些"沉睡的条件"在向你招手，辅助线只是把它们叫醒的工具。

所以正确的思维顺序是：

> 先盘点条件 → 找出"还没用上的条件" → 对照信号表 → 决定作哪条线。

而不是反过来"先盯着图发呆，等灵感降临"。

## 二、识别"该作辅助线"的 6 类信号

下面 6 类信号，是初中几何里 90% 以上需要作辅助线的题目的入口。每一条都对应着一类典型作法。

### 信号 1：出现"中点"

**特征**：题目里写了"$D$ 是 $BC$ 的中点"、"$M$ 是 $AB$ 中点"、"中线 $AD$"等。

**图形描述**：线段中间有一个小点被特别标出。

**典型作法**：
- **中线倍长**：延长中线一倍，构造全等。
- **斜边中线**：直角三角形中，斜边中点到三顶点距离相等。
- **中位线**：两个中点连起来，得到平行且等于第三边一半。
- **中点四边形**：四边形各边中点顺次连接，恒为平行四边形。

### 信号 2：出现"角平分线"

**特征**：题目里写了"$AD$ 平分 $\angle BAC$"。

**图形描述**：一个角被一条线从中间劈开成两个相等的角。

**典型作法**：
- **过角平分线上一点向两边作垂线**：构造两个全等直角三角形，得到两段相等。
- **翻折**：把角的一边沿角平分线翻过去，构造等腰或全等。

### 信号 3：出现"等腰三角形"

**特征**：题中已知 $AB = AC$，或者要证某三角形等腰。

**图形描述**：两条边相等的三角形，顶角在上、底边在下。

**典型作法**：
- **三线合一**：作底边上的中线（=高=顶角平分线），瞬间得到两个全等直角三角形。

只要看到等腰，就先问自己："顶角的那条三线合一，我作不作？"

### 信号 4：出现"直角"

**特征**：题中标出 $90^\circ$，或出现"$AB \perp CD$"。

**图形描述**：两条线交叉处有一个小方块标记。

**典型作法**：
- **构造直角三角形用勾股定理**：补足第三边，列 $a^2 + b^2 = c^2$。
- **斜边中线 = 斜边一半**：直角 + 斜边中点几乎一定一起用。

### 信号 5：出现"圆 + 弦"

**特征**：图中有圆，并出现一条弦、或一条切线。

**图形描述**：一个圆，圆内有一段弦；或者圆外一条直线和圆只接触一点。

**典型作法**：
- **过圆心作弦的垂线**：垂径定理，立即得到弦被平分、弧被平分。
- **连半径**：把圆心与弦端点连起来，构造等腰三角形。
- **连圆心与切点**：切线 $\perp$ 半径，构造直角。

### 信号 6：要证等量关系，却找不到全等/相似

**特征**：题目要证 $AB + CD = EF$，或 $AB - CD = EF$，但图里没有现成的全等/相似可用。

**图形描述**：要证的几段线段散落在图的不同位置，凑不到一个三角形里。

**典型作法**：
- **截长补短**：在长线段上截一段等于短的，或把短的延长补成长的。
- **旋转构造**：把某个三角形绕某点旋转（手拉手、半角、$K$ 字模型常用）。
- **平移构造**：把一段线段平移过去，让分散的量集中到一个图形中。

## 三、辅助线作完之后

作辅助线不是终点，是手段。作完之后必须能回答两个问题：

1. **为什么作它？**——我是想构造哪个模型（手拉手 / 一线三等角 / 半角 / 将军饮马 / 阿氏圆 / 中线倍长 / 中位线 / 截长补短 / 三线合一 / 垂径定理……），或者想用哪个定理（勾股、相似、圆幂、全等判定……）。
2. **它有没有让新条件被用上？**——如果作完之后，你发现新图里并没有用到"中点 / 角平分线 / 直角 / 圆心"等原本沉睡的条件，那这条辅助线大概率作错了，**立刻回退**，别硬撑。

## 四、一个完整的思考演示

**例题**：在 $\triangle ABC$ 中，$D$ 是 $BC$ 中点，求证：$AD < \dfrac{AB + AC}{2}$。

下面是我的内心独白：

- **盘点条件**：$D$ 是 $BC$ 中点；要证的式子里有 $AD$、$AB$、$AC$。
- **找沉睡的条件**：中点 $D$ 现在还只是个标记，没参与任何三角形。它就是那个"还没被激活的条件"。
- **对照信号表**：中点 → **信号 1** → 首选"中线倍长"。
- **动手作**：延长 $AD$ 到 $E$，使 $DE = AD$，连 $EC$。
- **看看构造出了什么**：在 $\triangle ABD$ 与 $\triangle ECD$ 中，$BD = CD$、$AD = ED$、$\angle ADB = \angle EDC$（对顶角），所以 $\triangle ABD \cong \triangle ECD$（SAS），从而 $EC = AB$。
- **回到目标**：现在 $AB$、$AC$ 被"搬"到了同一个 $\triangle AEC$ 里：$EC = AB$，$AC$ 是另一边，$AE = 2AD$ 是第三边。
- **用三角形三边关系**：$AE < AC + EC$，即 $2AD < AC + AB$，所以 $AD < \dfrac{AB + AC}{2}$。$\blacksquare$

回头看：辅助线之所以"该作"，是因为中点这个条件不作辅助线根本没法用；之所以"作得对"，是因为它把分散的 $AB$、$AC$ 集中到了一个三角形里，让三边关系可用。

## 五、自检 checklist（作辅助线前问自己）

在落笔之前，把下面三个问题在心里过一遍：

1. **题目里哪些条件我还没用上？**（中点？角平分线？等腰？直角？圆心？切点？）
2. **这个条件通常对应哪类辅助线？**（对照上面 6 类信号）
3. **作完之后我想构造哪个模型 / 用哪个定理？**（说不出来就别动笔）

三个问题都能答上来，再下笔。这样画出来的辅助线，不靠灵感，靠的是流程。
