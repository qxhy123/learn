# 常见辅助线总目录

本篇是一份**速查目录**，按图形特征索引。前篇 01 讲"何时该作辅助线"，本篇默认你已经判断出"该作了"，回答的是"作哪一条"。每条只给一句用途和它通向的模型/定理，便于在解题时快速对位。

## A. 三角形中

1. **中线倍长（延长中线一倍）** —— 把"两边 + 一中线"集中到一个三角形中，构造全等。
2. **作高** —— 把一般三角形拆为两个直角三角形，便于用勾股定理或三角函数。
3. **作角平分线的垂线** —— 由角平分线性质得到等腰，或构造一对全等三角形。
4. **截长补短** —— 处理 `AB + CD = EF` 这种线段和差关系：在长线段上截一段等于短线段，或在短线段后补一段等于另一短线段。
5. **三线合一** —— 在等腰三角形中作底边的中线/高/角平分线，三条合而为一，同时获得三组结论。
6. **作中位线** —— 出现两个中点（或一中点 + 平行需求）时，连接中点得平行且为底边一半。

## B. 平行四边形 / 梯形中

1. **过顶点作对角线的平行线** —— 把对角线"平移"出来，构造新的平行四边形，转移线段或角。
2. **过梯形一腰端点作另一腰的平行线** —— 将梯形分解为一个平行四边形 + 一个三角形，把两腰之差集中到该三角形中。
3. **作梯形的两条高** —— 把梯形切成一个矩形 + 两个直角三角形，便于求高、求面积、用勾股。
4. **延长两腰至相交** —— 将梯形补成一个大三角形，利用相似（小三角形 ∽ 大三角形）求比例。
5. **连对角线** —— 把四边形拆成两个三角形，转化为三角形问题。

## C. 圆中

1. **连半径** —— 半径处处相等，自动得到等腰三角形。
2. **过圆心作弦的垂线** —— 垂径定理：平分弦、平分弧。
3. **连圆心与切点** —— 切线 ⊥ 半径，立即得到一个直角。
4. **作直径所对的圆周角** —— 直径所对圆周角为 90°，凭空获得一个直角三角形。
5. **作弦切角对应的弦** —— 应用弦切角定理，将切线与弦的夹角转为同弧所对圆周角。
6. **连接圆心与弦的两端** —— 构造等腰三角形，配合圆心角—圆周角关系使用。

## D. 变换构造类

1. **旋转构造** —— 常见旋转 60°（等边三角形相关）、90°（正方形相关）：实现"手拉手模型""半角模型"，把分散的等长线段或等角拼到一处。
2. **翻折构造** —— 沿一条对称轴翻折，把远处的已知条件折到目标附近，常用于"角平分线 = 对称轴"。
3. **平移构造** —— 把分散在不同位置的等长线段平移到一起首尾相接，便于看出长度和或夹角关系。
4. **位似/相似构造** —— 通过比例延长或缩短，使两个相似图形共点，便于建立比例式。

## E. 坐标几何中

1. **过点作坐标轴的垂线** —— 立即得到一个直角三角形，水平边、竖直边长度直接由坐标差读出，斜边用勾股。
2. **作平行于坐标轴的辅助线** —— 把任意方向的斜距离/斜线段拆为水平分量 + 竖直分量，便于计算长度与斜率。
3. **连接特殊点（中点、定点）** —— 将动点问题转化为定线段，配合中点公式或斜率公式。

## 速查表

| 图形特征 | 优先尝试的辅助线 | 通向的模型/定理 |
|---|---|---|
| 中点 | 中线倍长 / 中位线 | 全等、中位线定理 |
| 角平分线 | 过角平分线上点作两边垂线 | 全等、等腰 |
| 等腰三角形 | 三线合一 | 等腰性质 |
| 圆 + 弦 | 过圆心作弦的垂线 | 垂径定理 |
| 圆 + 切点 | 连圆心与切点 | 切线 ⊥ 半径 |
| 圆 + 直径 | 作直径所对的圆周角 | 90° 圆周角 |
| 共顶点等腰 | 连两腰端点 | 手拉手模型 |
| 60°/90° 角 | 旋转 60° / 90° | 旋转构造全等 |
| 线段和差 (AB+CD=EF) | 截长补短 | 全等 |
| 梯形 | 平移一腰 / 作两高 / 延长两腰 | 平行四边形 + 三角形、相似 |
| 坐标系中两点距离 | 过点作坐标轴垂线 | 勾股定理 |

> 使用方法：先在图上找"特征"（中点？切点？等腰？60° 角？），再到表里查"优先尝试的辅助线"，最后顺着"模型/定理"列写证明。这是 80% 中考几何压轴题的通用入口。
