# 切线的判定与性质

## 一、图形特征

切线是直线与圆"刚好接触"的状态——直线与圆有且仅有一个公共点。它处在"相交"（两个交点）与"相离"（没有交点）的临界处。正因为是临界状态，切线带来一条非常**刚性**的几何约束：

- **圆心到切线的距离恰好等于半径**（位置关系角度，呼应 part5/04）；
- **切点处的半径与切线互相垂直**（角度关系，本章核心）。

这两条等价的描述，是切线一切证明的发动机。本章要把"切线"这件事从三个角度反复审视：**定义、距离、判定定理**；同时把"切线的性质"和"切线的判定"看作一对**互逆命题**，证明时要清晰区分自己当前用的是哪一个方向。

> 直观感受：把一条直线想象成一根细棍。从远处推向圆——先是"相离"（碰不到），推到刚刚触到圆的瞬间是"相切"（一个公共点、垂直于过这个公共点的半径），再推就"相交"（穿进圆里、有两个公共点）。"切"是一个**临界瞬间**，几何上的体现就是"$d = r$ 且半径 $\perp$ 切线"。

## 二、切线的性质

> **切线性质定理**：圆的切线**垂直于过切点的半径**。
>
> 用符号：若直线 $\ell$ 切 $\odot O$ 于点 $A$，则 $OA \perp \ell$。

**为什么**：直线 $\ell$ 与圆相切意味着 $d(O, \ell) = r$。设圆心 $O$ 到 $\ell$ 的垂足为 $H$，则 $OH = r$，$H$ 在圆上；又 $\ell$ 与 $\odot O$ 只有一个公共点，所以这个公共点必为 $H$，即切点 $A = H$。因此 $OA = OH \perp \ell$。

这条性质有两条常用**推论**：

1. **过切点的半径所在直线与切线必然垂直**——所以一旦看到"切线"，立刻想到"画半径成直角"，这是解题的本能反应。
2. **过切点且垂直于切线的直线必经过圆心**——这条逆向用法在"求圆心、求半径"类题里很关键：只要找到两条切线，分别过切点作垂线，两垂线的交点就是圆心。

> 切线性质用一句话总结：**切线 $\perp$ 过切点的半径，三者构成一个直角结构**。看到切线题，第一步先把这个直角"画出来"。

## 三、切线的判定（三个角度）

判定一条直线是不是切线，初中阶段有三种思路，对应三个角度：

> **判定 1（定义法）**：直线与圆**有且仅有一个**公共点 $\Leftrightarrow$ 这条直线是圆的切线。
>
> **判定 2（距离法）**：**圆心到直线的距离等于半径**（$d = r$）$\Leftrightarrow$ 这条直线是圆的切线。
>
> **判定 3（判定定理，最常用）**：经过半径**外端**且**垂直**于这条半径的直线，是圆的切线。

判定 1 是**定义本身**；判定 2 用 part5/04 的 $d = r$ 准则；判定 3（判定定理）是**性质定理的逆命题**：性质说"切线 $\Rightarrow$ 半径 $\perp$ 切线"，判定说"半径 $\perp$ 直线且外端在直线上 $\Rightarrow$ 切线"。

**判定定理的两个前提缺一不可**：

- **"外端"**：垂直的脚（即直线与半径的交点）必须是半径在圆上的那一端——也就是说，这个交点必须**恰在圆上**。如果交点在圆内（半径的中段），那么这条直线会穿进圆里成为割线，不是切线。
- **"垂直"**：这条直线与该半径互相垂直。少了垂直，即使过圆上一点也只是普通过点直线。

把这两条前提画在图上：从圆心 $O$ 出发画半径到圆上一点 $A$，过 $A$ 画一条与 $OA$ 垂直的直线——这条直线就是切线。

## 四、判定与性质互为逆命题

把判定定理与性质定理写成一行就看得很清楚：

- **性质**：直线是切线 $\Rightarrow$ 它与过切点的半径垂直。
- **判定（定理 3）**：直线过半径外端且与该半径垂直 $\Rightarrow$ 它是切线。

两条几乎是同一句话反过来读。这意味着在**做证明**时一定要**明确自己在用哪一个方向**：

- **题目"已知切线"** → 用性质（拿出那个直角）；
- **题目"求证某直线为切线"** → 用判定（构造那个直角）。

判定与性质是初中圆几何最常考的一对，识别清楚方向就解决了一半。

## 五、证明切线的"两手准备"

切线证明题千变万化，但本质只有两种格局，对应两套套路。看清题目属于哪一种，证明就一气呵成。

> **情形 A：直线已经经过圆上一个已知点 $P$**（题目已经把切点告诉你了，或者很容易看出来）
>
> 套路：**"连半径证垂直"**——连 $OP$（$O$ 是圆心、$P$ 是切点候选），然后证 $OP \perp$ 直线。证完即得切线（判定定理）。

> **情形 B：直线与圆的交点没有明确给出**（不知道切点在哪儿，甚至不知道有没有公共点）
>
> 套路：**"作垂线证半径"**——过圆心 $O$ 向直线作垂线 $OD \perp$ 直线、垂足为 $D$，然后证 $OD = r$。证完即得相切（距离判定）。

**如何区分情形 A 与 B**：看题目里**直线和圆的交点是否被点名**。如果点名了（"直线 $\ell$ 与圆 $\odot O$ 交于 $P$"或者构图上明显有一个交点），用 A；如果题目只说"直线 $\ell$"而没指明哪个点在圆上，用 B。

> 实战记号：A 是"**点已知 → 连半径**"，B 是"**点未知 → 作垂线**"。两套都熟练，切线证明几乎没有死角。

## 六、典型应用

### 例 1（基础：直接用判定定理）

> 如图，$\odot O$ 的半径为 $r$，$A$ 是圆上一点，过 $A$ 作直线 $\ell$，使得 $OA \perp \ell$。证明 $\ell$ 是 $\odot O$ 的切线。

**思路**：题目把判定定理的两个前提"半径外端 + 垂直"都直接给了。$A$ 在圆上（即 $OA$ 的外端），且 $OA \perp \ell$，由判定定理立刻得 $\ell$ 是 $\odot O$ 的切线。证毕。

> 这是判定定理的"裸用"，无需任何辅助构造——任何更复杂的切线证明，归根结底都要把图归化成"半径 + 外端 + 垂直"这个最小结构。

### 例 2（连半径证垂直：情形 A）

> 如图，$\triangle ABC$ 中 $AB = AC$，$\odot O$ 是以 $BC$ 为直径的圆，圆心 $O$ 是 $BC$ 中点。过 $A$ 作 $AD \perp BC$ 于 $D$，已知 $D$ 在线段 $BC$ 上、即 $D = O$。证明：直线 $AD$ 与 $\odot O$ 相切于 $D$。

**思路**：先看是哪种情形。直线 $AD$ 与圆显然过 $D$，而 $D$ 在 $BC$ 上、$BC$ 是直径——$D$ 就是圆心 $O$？等一下：题目说 $\triangle ABC$ 是**等腰**（$AB = AC$），所以等腰三角形的高 $AD$ 必落在底边 $BC$ 中点处，而底边中点就是 $O$。这样 $D = O$，"切线"的说法不成立（直线过圆心是割线）。

修正题意：取 $\odot O$ 是以 $D$ 为圆心、$DA$ 为半径的圆。重新陈述：

> **改述**：$\triangle ABC$ 中 $AB = AC$，$D$ 为 $BC$ 中点。以 $D$ 为圆心、$DA$ 为半径作 $\odot D$。证明 $BC$ 是 $\odot D$ 的切线。

**思路**（情形 A：$BC$ 与 $\odot D$ 的公共点候选是 $D$，但 $D$ 是圆心不是圆上的点——再修正）：换一个干净的版本：

> **干净版本**：$\triangle ABC$ 中 $AB = AC$，$AD \perp BC$ 于 $D$。以 $A$ 为圆心、$AD$ 为半径作 $\odot A$。证明：$BC$ 是 $\odot A$ 的切线。

**思路**：直线 $BC$ 与 $\odot A$ 是否有已知公共点？$D$ 在 $BC$ 上，且 $AD$ 是 $\odot A$ 的半径，$AD$ 的外端 $D$ 在圆上——所以 $D$ 就是切点候选。这是**情形 A**。

**连半径证垂直**：半径 $AD$ 已经画好。要证 $AD \perp BC$——这正是题目给的条件 $AD \perp BC$！所以 $AD$ 是 $\odot A$ 过外端 $D$ 且垂直于 $BC$ 的半径，由判定定理 $BC$ 切 $\odot A$ 于 $D$。证毕。

> 这是连半径证垂直的最干净示例：**找到候选切点 → 连圆心到该点 → 证垂直**，三步走完。

### 例 3（作垂线证半径：情形 B）

> 直角三角形 $\triangle ABC$ 中 $\angle C = 90°$，$AC = 3, BC = 4, AB = 5$。以 $AB$ 为直径作 $\odot O$（圆心 $O$ 是 $AB$ 中点，半径 $r = \tfrac{5}{2}$）。问：直线 $BC$ 是否与 $\odot O$ 相切？若不相切，是相交还是相离？

**思路**：直线 $BC$ 与 $\odot O$ 的交点没明确给出（$B$ 在直径上即在圆上，$C$ 不一定在圆上）——其实 $B$ 在圆上是显然的，所以这里也可以走情形 A：候选切点 $B$，连半径 $OB$，看是否 $OB \perp BC$。$O$ 是 $AB$ 中点、$OB$ 沿 $AB$ 方向，$\angle ABC$ 是 $\triangle ABC$ 在 $B$ 处的内角，不是直角（$\angle C = 90°$ 才是直角），所以 $OB \not\perp BC$，**$BC$ 不是切线**。

要进一步判断相交还是相离，用情形 B 的距离法：过 $O$ 作 $OD \perp BC$ 于 $D$。$O$ 是 $AB$ 中点，$D$ 在 $BC$ 上，$OD \parallel AC$（因为 $OD \perp BC$、$AC \perp BC$），且 $OD$ 是 $\triangle ABC$ 的**中位线**（$O$ 是 $AB$ 中点、$OD \parallel AC$ → $D$ 是 $BC$ 中点）。所以 $OD = \tfrac{1}{2} AC = \tfrac{3}{2}$。

比较 $d = OD = \tfrac{3}{2}$ 与 $r = \tfrac{5}{2}$：$d < r$，由 part5/04 直线与圆**相交**。

> 这是**作垂线证半径**思路的完整示范：找不到现成的切点候选时，主动构造 $OD \perp$ 直线，转化为 $d$ 与 $r$ 的比较。这一思路也能立即给出"何时相切"的反向条件：只要把 $r$ 改成 $\tfrac{3}{2}$（或把 $\triangle ABC$ 改成 $AC = AB$ 的等腰直角），就达到 $d = r$ 的相切临界。

## 七、易错点

1. **性质中"垂直"的对象是过切点的半径，不是任意半径**：切线只与**通过切点**的那条半径垂直；与圆心连其他点的半径夹角不一定是 $90°$。
2. **判定定理的两个前提缺一不可**：必须"半径外端"（即垂足在圆上）+ "垂直"（直线与该半径垂直）。少了任一个，结论都不成立。例如过圆内一点垂直于半径中段画直线，这条直线是**割线**而不是切线。
3. **判定与性质用反了**：题目让你**证明**一条直线是切线却去用"切线 $\perp$ 半径"，那是在循环论证。要先确认题目里"切线"出现在**已知**还是**结论**里：已知 → 用性质；结论 → 用判定。
4. **情形 A / B 错选**：明明已经有公共点却去作垂线（绕远路）、明明没有公共点却乱连半径（连不到切点）。**只看题目有没有明确公共点即可决定路线**。
5. **"过圆上一点的直线"不一定是切线**：还得满足"垂直于这点的半径"。常见错误是写成"$\ell$ 过 $A$ 且 $A$ 在圆上，所以 $\ell$ 是切线"——遗漏垂直条件。
6. **切点必经过圆心和切点的直线 $\perp$ 切线**：这一条在求圆心、求圆方程时极为关键。两条切线的切点连圆心都垂直于各自切线，因此**两切点处的法线交点 $=$ 圆心**。
7. **"切线长"与"切线"的区别**：切线是**直线**，切线长是从圆外一点到切点的**线段长度**，下一章 part5/06 才会用到。本章先把"判定切线"做扎实。

## 八、自测题

1. 已知 $\odot O$ 的半径为 $r = 6$，直线 $\ell$ 上一点 $P$ 满足 $OP = 10$，且 $OP$ 与 $\ell$ 的夹角为 $\angle OPH = 30°$（$H$ 是 $O$ 到 $\ell$ 的垂足）。判断 $\ell$ 与 $\odot O$ 的位置关系。
   - 💡 提示：先算 $d = OH = OP \sin 30° = 10 \times \tfrac{1}{2} = 5$。$d = 5 < 6 = r$ → **相交**。要改为"相切"需 $d = 6$，即 $\sin\angle OPH = \tfrac{6}{10} = 0.6$ 时。

2. 如图，$AB$ 是 $\odot O$ 的直径，$C$ 是圆上一点（$C \ne A, B$），过 $C$ 作直线 $\ell \perp OC$。证明 $\ell$ 是 $\odot O$ 的切线。
   - 💡 提示：情形 A。$C$ 在圆上即 $OC$ 是半径、$C$ 是外端；$OC \perp \ell$ 由已知。判定定理直接得 $\ell$ 切 $\odot O$ 于 $C$。

3. $\triangle ABC$ 中 $\angle ACB = 90°$，$AC = 6, BC = 8$。以 $C$ 为圆心、半径 $r$ 作圆。问 $r$ 取何值时 $AB$ 是 $\odot C$ 的切线？
   - 💡 提示：情形 B。过 $C$ 作 $CD \perp AB$ 于 $D$，则 $CD = \tfrac{AC \cdot BC}{AB} = \tfrac{6 \times 8}{10} = 4.8$。相切 $\Leftrightarrow d = r \Leftrightarrow r = 4.8$。

4. 如图，$PA$ 是 $\odot O$ 的切线，$A$ 为切点，$OP$ 交圆于 $B$。若 $OA = 3, OP = 5$，求 $PA$ 的长度。
   - 💡 提示：用性质，$OA \perp PA$ → $\triangle OAP$ 在 $A$ 处为直角。勾股 $PA = \sqrt{OP^2 - OA^2} = \sqrt{25 - 9} = 4$。

5. 已知 $\odot O$ 半径为 $r$，$AB$ 是 $\odot O$ 的一条弦，$M$ 是弦 $AB$ 的中点，过 $M$ 作直线 $\ell \perp OM$。证明 $\ell$ 与 $\odot O$ 不相切，除非 $M$ 在 $\odot O$ 上（即 $OM = r$）。
   - 💡 提示：直线 $\ell$ 过 $M$ 且 $\ell \perp OM$，所以 $O$ 到 $\ell$ 的距离 $d = OM$。$\ell$ 切 $\odot O$ $\Leftrightarrow d = r \Leftrightarrow OM = r \Leftrightarrow M$ 在圆上。而 $M$ 是弦 $AB$ 的中点，由垂径定理（part5/02）$OM \perp AB$ 且 $OM < r$（除非 $AB$ 退化为一个点，此时 $M$ 在圆上）。所以一般情况下 $OM < r$，$\ell$ 与 $\odot O$ **相交**而非相切——这恰是垂径定理刻画"过弦中点的垂线（即弦心距方向）穿过圆内部"的几何含义。
