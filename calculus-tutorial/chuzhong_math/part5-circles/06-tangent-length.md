# 切线长定理与三角形的内切圆

## 一、图形特征

上一章（part5/05）我们已经把"一条切线"的判定与性质讲透。本章把视角放大到**两条切线**——以及把切线"长度"作为研究对象。

> **核心图形**：圆 $\odot O$ 外有一点 $P$，过 $P$ 引 $\odot O$ 的两条切线 $PA, PB$（$A, B$ 是切点）。连 $OA, OB, OP$。

这个图形里同时藏着五个关键事实：

- $OA = OB = r$（半径）；
- $OA \perp PA$，$OB \perp PB$（切线性质，呼应 part5/05）；
- $OP$ 是 $\triangle OAP$ 与 $\triangle OBP$ 的公共斜边；
- $PA, PB$ 都是"圆外一点到切点"的线段；
- $\angle APO$ 与 $\angle BPO$ 是两条切线与 $OP$ 的夹角。

把这五点拼起来，立刻能看到**两个直角三角形 $\triangle OAP$ 与 $\triangle OBP$ 共斜边、两直角边一对相等**——这是 HL 全等的标准触发条件，也是本章一切结论的来源。

> 直观理解：从圆外一点 $P$"望"向圆，左右两侧各看到一个切点；这个图形天然左右对称，对称轴就是 $OP$。所有"两切线相关"的结论，都是这条对称性的不同写法。

## 二、切线长的定义

> **切线长**：从圆外一点 $P$ 引圆的切线，$P$ 与切点之间**线段**的长度，称为这一点到圆的**切线长**。

这里要紧紧抓住两个区别：

- **切线**是**直线**（无限延伸）；**切线长**是**线段**（有限长度）。两者不能混用。
- 切线长是从**圆外一点**算起：圆内的点引不出切线，圆上的点切线长为 $0$。

切线长的几何意义：它是直角三角形 $\triangle OAP$ 中**与半径垂直的那条直角边**（$OA \perp PA$，$OA = r$，$OP$ 是斜边）。由勾股定理：

$$PA^2 = OP^2 - OA^2 = OP^2 - r^2.$$

这一式子表明：**切线长由圆外点到圆心的距离 $OP$ 与半径 $r$ 唯一决定**。$OP$ 越远，切线长越长；$OP = r$（点在圆上）时切线长为 $0$；$OP < r$（点在圆内）时根号下为负，没有实数切线长——这正对应"圆内点引不出切线"。

## 三、切线长定理

> **切线长定理**：从圆外一点引圆的两条切线，**两条切线长相等**，且**圆心与该点的连线平分两条切线的夹角**。
>
> 用符号：$P$ 在 $\odot O$ 外，$PA, PB$ 切 $\odot O$ 于 $A, B$，则
> $$PA = PB, \qquad \angle APO = \angle BPO.$$
> 进一步：$OP$ 也平分 $\angle AOB$，即 $\angle AOP = \angle BOP$。

**证明**：在 $\triangle OAP$ 与 $\triangle OBP$ 中，

- $OA = OB = r$（半径），
- $\angle OAP = \angle OBP = 90°$（切线性质：半径 $\perp$ 切线），
- $OP$ 公共。

由 **HL**（直角三角形斜边和一直角边对应相等）得 $\triangle OAP \cong \triangle OBP$。于是对应边 $PA = PB$、对应角 $\angle APO = \angle BPO$ 以及 $\angle AOP = \angle BOP$。证毕。

> 用一句话记：**"两切线长相等、两夹角相等"——一对 HL 全等就把一切结论都装进去了**。这是初中圆几何中最高频的全等触发点之一。

切线长定理的推论结构非常清晰：

1. $PA = PB$（**线段相等**）；
2. $\angle APO = \angle BPO$（$OP$ **平分外角** $\angle APB$）；
3. $\angle AOP = \angle BOP$（$OP$ **平分圆心角** $\angle AOB$）；
4. $OP \perp AB$ 且 $OP$ **垂直平分**弦 $AB$（由对称性，或由 $PA = PB$ + $OA = OB$ 直接得 $OP$ 是 $AB$ 的中垂线）。

第 4 条最易被忽略却最实用：**两条切线的切点连线被 $OP$ 垂直平分**——它让"两切点 + 圆心 + 外部点"四个点构成一个对称的"风筝形 $OAPB$"。

## 四、三角形的内切圆

把"圆外一点引两切线"的图形向纵深推一步：如果圆外有**三条直线**（即一个三角形的三条边）都与圆相切呢？这就是**内切圆**。

> **三角形的内切圆**：与三角形的**三条边都相切**的圆称为这个三角形的**内切圆**；圆心称为三角形的**内心**。

**为什么内心存在且唯一**：内心要同时与三条边距离相等（都等于内切圆半径 $r$）。"到两条相交直线距离相等"的点轨迹是这两直线的**角平分线**（呼应 special/03）。所以：

- 到 $AB, AC$ 距离相等 → 在 $\angle A$ 的平分线上；
- 到 $AB, BC$ 距离相等 → 在 $\angle B$ 的平分线上；
- 到 $AC, BC$ 距离相等 → 在 $\angle C$ 的平分线上。

三条角平分线**交于一点**（special/03 内心存在定理），这一点就是内心。内心一定在三角形**内部**（因为是三个内角平分线的交点）。

> 一句话记：**内心 = 三条内角平分线交点 = 到三边等距点 = 内切圆圆心**。这四种身份是等价的。

### 内切圆与外接圆不要混淆

| 名称 | 圆心位置 | 圆的位置 | 圆心特征 |
|------|----------|----------|----------|
| **内切圆** | 三角形**内部**（内心） | 圆**在三角形内**，与三边相切 | 三条**角平分线**交点 |
| **外接圆** | 不一定（锐角三角形在内部，直角在斜边中点，钝角在外部） | 圆**包住**三角形，过三顶点 | 三条**边的中垂线**交点（外心）|

内切圆"被三角形包住"，外接圆"包住三角形"——一里一外，刚好相反。

## 五、内切圆半径的两个关键公式

设 $\triangle ABC$ 三边长 $a = BC, b = CA, c = AB$，面积 $S$，**半周长** $p = \dfrac{a+b+c}{2}$，内切圆半径 $r$。

> **面积公式（任意三角形通用）**：
> $$S = p \cdot r, \qquad \text{即} \qquad r = \dfrac{S}{p} = \dfrac{2S}{a+b+c}.$$

**推导**：设内心为 $I$，内切圆半径为 $r$。连 $IA, IB, IC$，把 $\triangle ABC$ 分割成三个小三角形 $\triangle IBC, \triangle ICA, \triangle IAB$。每个小三角形以一条边为底、以 $I$ 到该边的距离 $r$（内切圆半径）为高：

$$S_{\triangle IBC} = \tfrac{1}{2} a r, \quad S_{\triangle ICA} = \tfrac{1}{2} b r, \quad S_{\triangle IAB} = \tfrac{1}{2} c r.$$

相加得 $S = \tfrac{1}{2}(a+b+c) r = p r$。

> **直角三角形专用公式**：若 $\triangle ABC$ 直角顶点为 $C$（$\angle C = 90°$），两直角边 $a, b$、斜边 $c$，则
> $$r = \dfrac{a + b - c}{2}.$$

**推导**：在直角三角形里，设内切圆与 $BC, CA, AB$ 分别切于 $D, E, F$。

由切线长定理的对称性：从顶点 $C$ 引 $\odot I$ 的两条切线 $CD, CE$ 长度相等；又 $ID \perp BC, IE \perp CA$、$ID = IE = r$，所以四边形 $CDIE$ 有三个直角且邻边相等——它是**正方形**。因此 $CD = CE = r$。

类似地，$BD = BF$（从 $B$ 引的两切线长），$AE = AF$（从 $A$ 引的两切线长）。把三边写成切线长之和：

- $a = BC = BD + DC = BF + r$；
- $b = CA = CE + EA = r + AF$；
- $c = AB = AF + FB = AF + BF$。

由 $a + b = (BF + r) + (r + AF) = (AF + BF) + 2r = c + 2r$，所以 $r = \dfrac{a + b - c}{2}$。

> 直角三角形的内切圆半径只与三边长度有关，不必再求面积——记住 $r = \dfrac{a+b-c}{2}$ 这个"和减斜边、再除以 $2$"的口诀，几乎是必考送分题。

## 六、典型应用

### 例 1（切线长定理：等腰 + $60°$ → 等边）

> 圆 $\odot O$ 外一点 $P$ 引两条切线 $PA, PB$（$A, B$ 是切点），$\angle APB = 60°$，$PA = 4$。求 $AB$ 的长度。

**思路**：典型"两切线"图形——立刻调用切线长定理。由定理，$PA = PB$。所以 $\triangle PAB$ 是**等腰三角形**（$PA = PB = 4$），顶角 $\angle APB = 60°$。等腰 + 顶角 $60°$ → 三个角都是 $60°$（底角 $= (180° - 60°)/2 = 60°$）→ $\triangle PAB$ 是**等边三角形**。所以 $AB = PA = 4$。

> 一招到位：**两切线 $\Rightarrow$ 等腰**，配合任何特殊角（$60°$、$90°$）都会触发熟悉的特殊三角形。

### 例 2（直角三角形内切圆半径：直接套公式）

> $\triangle ABC$ 中 $\angle C = 90°$，$AC = 3, BC = 4, AB = 5$。求 $\triangle ABC$ 的内切圆半径 $r$。

**思路**：典型直角三角形 $3$-$4$-$5$，直接套公式 $r = \dfrac{a+b-c}{2} = \dfrac{3 + 4 - 5}{2} = 1$。

**验证**（用面积公式交叉检验）：$S = \tfrac{1}{2} \times 3 \times 4 = 6$，半周长 $p = (3+4+5)/2 = 6$，$r = S/p = 6/6 = 1$。两种方法同一答案，公式记牢即可秒杀。

### 例 3（一般三角形用 $S = p r$）

> $\triangle ABC$ 中 $AB = AC = 5$，$BC = 6$。求其内切圆半径 $r$。

**思路**：等腰三角形不是直角三角形，不能用 $\dfrac{a+b-c}{2}$，要用通用公式 $S = pr$。

**第一步求面积**：作 $BC$ 上的高 $AD$。等腰三角形 $D$ 是 $BC$ 中点，$BD = 3$，$AD = \sqrt{AB^2 - BD^2} = \sqrt{25 - 9} = 4$。所以 $S = \tfrac{1}{2} \times 6 \times 4 = 12$。

**第二步算半周长**：$p = (5 + 5 + 6)/2 = 8$。

**第三步**：$r = S/p = 12/8 = \dfrac{3}{2}$。

> 三角形内切圆半径几乎总有"两条路"：直角三角形优先用 $r = (a+b-c)/2$；非直角三角形回到 $S = pr$。两条路掌握后，任何三角形内切圆半径问题都可一步搞定。

## 七、易错点

1. **"切线"与"切线长"混淆**：切线是**直线**（要写"是直线"或"过 ... 的直线"），切线长是**线段长度**（要写具体数或"线段 $PA$ 的长度"）。问"求切线"和"求切线长"是两类问题。

2. **切线长定理的前提是"圆外一点"**：圆上点的"切线"只有一条、切线长为 $0$；圆内点根本没有切线。用切线长定理之前先确认点的位置。

3. **HL 全等里的"H"指斜边、"L"指一直角边**：在切线长定理证明里，"H"是公共斜边 $OP$、"L"是相等半径 $OA = OB$。少写一个直角条件（$\angle OAP = \angle OBP = 90°$）就不是 HL 而变成 SSA，不能直接全等。

4. **内切圆 vs 外接圆混用**：内切圆在三角形内、切三边、圆心是**角平分线**交点（内心）；外接圆在三角形外（或正好覆盖三角形）、过三顶点、圆心是**中垂线**交点（外心）。"内"切的是边、"外"接的是顶点——一字之差，几何意义完全不同。

5. **直角三角形内切圆半径公式 $r = (a+b-c)/2$ 仅限直角三角形**：$a, b$ 必须是**两直角边**、$c$ 必须是**斜边**。代入一般三角形会得到错误结果。识别"直角三角形"是用这条公式的前提。

6. **$S = pr$ 中 $p$ 是半周长不是周长**：周长是 $a+b+c$，半周长是 $\dfrac{a+b+c}{2}$。漏掉 $\dfrac{1}{2}$ 会让半径算大一倍。

7. **从一点引两切线 → $OP$ 垂直平分 $AB$**：这条"对称性红利"经常被忽略；只要图里有"圆外一点 + 两切线"，立刻把"$OP \perp AB$"画上去，往往是后续解题的关键桥梁。

## 八、自测题

1. $\odot O$ 半径 $r = 5$，$P$ 在圆外，$OP = 13$。求从 $P$ 到 $\odot O$ 的切线长 $PA$。
   - 💡 提示：用 $PA^2 = OP^2 - r^2 = 169 - 25 = 144$，所以 $PA = 12$（这是 $5$-$12$-$13$ 直角三角形的体现，$OA \perp PA$）。

2. 圆 $\odot O$ 外一点 $P$ 引两切线 $PA, PB$（切点 $A, B$），$\angle APB = 90°$，$PA = 6$。求 $\odot O$ 的半径 $r$ 与弦 $AB$ 的长度。
   - 💡 提示：$\angle APB = 90°$ 且 $PA = PB = 6$ → $\triangle PAB$ 是等腰直角三角形 → $AB = 6\sqrt{2}$。又由切线长定理 $OP \perp AB$、$OAPB$ 是有两直角的"风筝"——由 $OA \perp PA, OB \perp PB$ 且 $\angle APB = 90°$ → $\angle AOB = 360° - 90° - 90° - 90° = 90°$。所以 $\triangle OAB$ 是等腰直角三角形（$OA = OB = r$）→ $AB = r\sqrt{2}$。由 $AB = 6\sqrt{2}$ 得 $r = 6$。

3. 直角三角形两直角边长分别为 $5$ 和 $12$，求斜边长度及其内切圆半径。
   - 💡 提示：斜边 $c = \sqrt{25 + 144} = 13$（经典 $5$-$12$-$13$）；$r = (5 + 12 - 13)/2 = 2$。

4. 三角形三边长为 $a = 13, b = 14, c = 15$，求其内切圆半径。
   - 💡 提示：先求面积。用海伦公式或直接做高：作 $a = 14$ 边上的高 $h$，设高的脚距 $b = 13$ 顶点为 $x$，则 $x^2 + h^2 = 13^2$、$(14 - x)^2 + h^2 = 15^2$，相减得 $14 \cdot 2x - 14^2 = 13^2 - 15^2 = -56$，$28x = 140$，$x = 5$，$h = 12$。$S = \tfrac{1}{2} \times 14 \times 12 = 84$；$p = (13+14+15)/2 = 21$；$r = S/p = 84/21 = 4$。

5. 在 $\triangle ABC$ 中，$AB = AC$，内切圆 $\odot I$ 与 $BC$ 切于 $D$。证明 $D$ 是 $BC$ 中点。
   - 💡 提示：等腰三角形 $AB = AC$ → $\angle B = \angle C$（等边对等角）。又从 $B$ 引两切线 $BD$（在 $BC$ 上）和 $BF$（在 $AB$ 上）→ $BD = BF$（切线长定理）；从 $C$ 引两切线 $CD$ 和 $CE$（在 $CA$ 上）→ $CD = CE$。再由"对称性"：$\triangle ABC$ 关于过 $A$ 与 $I$ 的轴对称（$AB = AC$、$IB = IC$ 因 $I$ 在 $\angle A$ 的平分线上），所以 $BD$ 与 $CD$ 互为对称像 → $BD = CD$，$D$ 是 $BC$ 中点。也可以直接用 $BF = BD, CE = CD, AF = AE$ 及 $AB = AC$ 推 $BF = CE \Rightarrow BD = CD$。
