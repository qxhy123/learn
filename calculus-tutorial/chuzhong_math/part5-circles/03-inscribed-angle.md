# 圆周角定理

## 一、图形特征

本章关注的是**圆周角**——顶点在**圆上**、两边都是**弦**的角。设 $\odot O$ 上有三点 $A, B, C$，连接弦 $CA, CB$，那么以 $C$ 为顶点、$CA$ 与 $CB$ 为两边的角 $\angle ACB$ 就是一个圆周角。$\angle ACB$ 的两边所截下的弧 $\overarc{AB}$（不含 $C$ 那一侧）称为**它所对的弧**。

与圆周角并列出现的，是同一段弧 $\overarc{AB}$ 所对的**圆心角** $\angle AOB$（顶点在圆心 $O$、两边是半径 $OA, OB$，开口方向与弧 $\overarc{AB}$ 一致）。一段弧同时对应一个圆心角和无数个圆周角——只要把顶点 $C$ 在弧 $\overarc{AB}$ 之外的那段弧（含 $C$ 的一段，称为**优弧侧**或与 $\overarc{AB}$ 互补的另一段弧）上滑动，圆周角 $\angle ACB$ 的两边在变，可它的大小却不变。本章的核心定理就是要刻画"圆周角与圆心角"和"同弧圆周角彼此"之间的关系。

> 直观感受：把圆周角想象成一只"眼睛"，从圆上不同位置看同一段弧 $\overarc{AB}$。无论站在弧 $\overarc{AB}$ 那一侧的哪一点，看到的"张角"都是相同的——这就是同弧圆周角相等。再把这只眼睛挪到圆心，圆心看 $\overarc{AB}$ 张的角恰好是圆周角的**两倍**。这两条规律是本章一切应用的根基。

## 二、圆周角定理

> **圆周角定理**：在同一个圆中，**一条弧所对的圆周角等于它所对的圆心角的一半**。

记号化：若 $\overarc{AB}$ 所对的圆心角是 $\angle AOB$，所对的圆周角是 $\angle ACB$（$C$ 在 $\overarc{AB}$ 的另一侧），则

$$\angle ACB = \frac{1}{2} \angle AOB.$$

### 证明（三种情形）

证明的关键是注意 $C$ 与圆心 $O$ 的相对位置不同时，图形结构略有差别，需要分三种情形讨论。三种情形的共同工具是：$\triangle OAC, \triangle OBC$ 均为等腰三角形（$OA = OC = OB = r$），加上三角形**外角定理**（一个外角等于不相邻两内角之和）。

**情形 1：圆心 $O$ 落在 $\angle ACB$ 的一条边上。**

不妨设 $O$ 在边 $CB$ 上（即 $CB$ 过圆心，$CB$ 是直径）。连接 $OA$。$\triangle OAC$ 中，$OA = OC = r$，所以 $\angle OAC = \angle OCA = \angle ACB$。由外角定理，$\angle AOB$ 是 $\triangle OAC$ 在 $O$ 处的外角：

$$\angle AOB = \angle OAC + \angle OCA = 2\angle ACB.$$

即 $\angle ACB = \frac{1}{2}\angle AOB$。

**情形 2：圆心 $O$ 在 $\angle ACB$ 的内部。**

连接 $CO$ 并延长交圆于 $D$。$CD$ 把 $\angle ACB$ 分成 $\angle ACD$ 与 $\angle DCB$，把 $\angle AOB$ 分成 $\angle AOD$ 与 $\angle DOB$。对 $\angle ACD, \angle AOD$ 和 $\angle DCB, \angle DOB$ 分别套用情形 1（每一对都"圆心在一边上"）：

$$\angle ACD = \frac{1}{2}\angle AOD,\quad \angle DCB = \frac{1}{2}\angle DOB.$$

相加：$\angle ACB = \angle ACD + \angle DCB = \frac{1}{2}(\angle AOD + \angle DOB) = \frac{1}{2}\angle AOB$。

**情形 3：圆心 $O$ 在 $\angle ACB$ 的外部。**

同样连 $CO$ 延长交圆于 $D$。这时 $CD$ 不在 $\angle ACB$ 内部，而在某一边的外侧，于是 $\angle ACB = \angle ACD - \angle BCD$（或 $\angle BCD - \angle ACD$，看 $D$ 偏哪一侧）。对每一部分用情形 1，然后**相减**而非相加，同样得到 $\angle ACB = \frac{1}{2}\angle AOB$。

证毕。

## 三、三条核心推论

**推论 1（同弧/等弧圆周角相等）**：在同一个圆（或两个等圆）中，**同一条弧所对的所有圆周角彼此相等**；**相等的弧所对的圆周角也相等**。

理由：同一条弧 $\overarc{AB}$ 对应的圆心角 $\angle AOB$ 是确定的，由定理，所有圆周角都等于它的一半，所以两两相等。

> 注意区分：**同弧**指同一条弧（同一段 $\overarc{AB}$）；**等弧**指不同位置但度数相等的两段弧。前者必须在一个圆中，后者可以在同圆或等圆中。

**推论 2（直径所对的圆周角是直角）**：直径所对的圆周角等于 $90°$；反之，圆周角为 $90°$ 时它所对的弦是直径。

理由：直径所对的圆心角是 $180°$（平角），由定理，圆周角 $= 90°$。反向同理：圆周角 $90°$ ⇒ 圆心角 $180°$ ⇒ 所对弦是直径。

> 这条推论是直角三角形与圆的桥梁：**直角三角形斜边的中点就是其外接圆圆心，斜边就是直径**——这与 part3 直角三角形"斜边中线 = 斜边一半"是同一回事。

**推论 3（圆内接四边形对角互补）**：若四边形 $ABCD$ 的四个顶点都在同一个圆上（称为**圆内接四边形**），则

$$\angle A + \angle C = 180°,\quad \angle B + \angle D = 180°.$$

理由：$\angle A$ 与 $\angle C$ 分别对着 $\overarc{BCD}$ 与 $\overarc{BAD}$，这两段弧合起来恰好是整个圆周（$360°$），它们对应的圆心角之和 $= 360°$，所以两个圆周角之和 $= \frac{1}{2}\times 360° = 180°$。

> 推论 3 的逆命题（"对角互补的四边形四点共圆"）将在 part5/08 用到，是隐藏的常用工具。

## 四、典型应用

### 例 1（基础：同弧圆周角相等）

> 圆 $O$ 中弦 $AB, CD$ 相交于圆内一点 $P$。已知 $\angle ACD = 40°$，求 $\angle ABD$。

**思路**：$\angle ACD$ 与 $\angle ABD$ 都是圆周角，它们所对的弧分别是 $\overarc{AD}$（$\angle ACD$ 对的）和 $\overarc{AD}$（$\angle ABD$ 对的，且 $B, C$ 都在 $\overarc{AD}$ 的同一侧——含 $B, C$ 的优弧侧）——同弧。

由推论 1，$\angle ABD = \angle ACD = 40°$。

**答案**：$\angle ABD = 40°$。

> 通用结构：看到"两个角的顶点都在圆上，所夹弦的两个端点一致"——立刻识别为"同弧圆周角"，二者相等。

### 例 2（直径与 $90°$ 圆周角）

> $\triangle ABC$ 内接于圆 $O$，$AB$ 是圆 $O$ 的直径。求 $\angle ACB$。若进一步给出 $AC = 6, BC = 8$，求圆 $O$ 的半径。

**思路**：由推论 2，直径 $AB$ 所对的圆周角 $\angle ACB = 90°$。所以 $\triangle ACB$ 是直角三角形，直角顶点在 $C$。

由勾股定理，$AB = \sqrt{AC^2 + BC^2} = \sqrt{36 + 64} = 10$。$AB$ 是直径，所以半径 $r = \frac{AB}{2} = 5$。

**答案**：$\angle ACB = 90°$，$r = 5$。

> 这道题反过来也常考——"已知 $\triangle ABC$ 中 $\angle C = 90°$，求它的外接圆半径"，答案就是 $\frac{AB}{2}$，因为 $AB$ 必为直径。

### 例 3（圆内接四边形对角互补）

> 圆内接四边形 $ABCD$ 中，$\angle A = 80°$，$\angle B = 110°$。求 $\angle C$ 与 $\angle D$。

**思路**：由推论 3，$\angle A + \angle C = 180° \Rightarrow \angle C = 100°$；$\angle B + \angle D = 180° \Rightarrow \angle D = 70°$。

**答案**：$\angle C = 100°$，$\angle D = 70°$。

> 圆内接四边形最有用的两条性质：(i) 对角互补；(ii) 任一外角等于不相邻的内角（由对角互补直接推出）。后者在更高综合题中被频繁使用。

## 五、易错点

1. **圆周角的定义要严格**：顶点必须**在圆上**，两边必须**都是弦**。顶点在圆内、圆外或边不是弦，都不是圆周角，不能用定理。
2. **推论 2 是"直径"所对**：只有**直径**所对的圆周角才是 $90°$；一般弦所对的圆周角不是 $90°$。
3. **同弧 vs 等弧**：同弧是**同一条**弧；等弧是不同位置但度数相等的两条弧。推论 1 二者都成立，但在书写步骤时要写清楚是哪种情况。
4. **同弧圆周角相等的前提是"在同一侧"**：弦 $AB$ 把圆分成两段弧，两侧的圆周角并不相等，而是**互补**（两个圆周角对应的两段弧合起来是整个圆）。例如弦 $AB$ 一侧的圆周角是 $50°$，另一侧就是 $130°$。
5. **圆心角与圆周角"二倍关系"只在对应同一段弧时成立**：不能把任意圆心角与任意圆周角拿来配对——必须确认它们对的是**同一段弧**。
6. **圆内接四边形对角互补是"对角"，不是"邻角"**：邻角之和并无固定关系；只有 $\angle A$ 与 $\angle C$、$\angle B$ 与 $\angle D$ 这两对（隔一个顶点）互补。

## 六、自测题

1. 圆 $O$ 中，圆心角 $\angle AOB = 120°$，求 $\overarc{AB}$（劣弧）所对的圆周角 $\angle ACB$。
   - 💡 提示：由圆周角定理，$\angle ACB = \frac{1}{2}\angle AOB = 60°$。

2. $\triangle ABC$ 内接于圆 $O$，$\angle BAC = 30°$。求圆心角 $\angle BOC$。
   - 💡 提示：$\angle BAC$ 与 $\angle BOC$ 对同一段弧 $\overarc{BC}$，$\angle BOC = 2\angle BAC = 60°$。

3. 圆 $O$ 的直径 $AB = 10$，$C$ 是圆上一点，$AC = 6$。求 $BC$。
   - 💡 提示：由推论 2，$\angle ACB = 90°$；在直角 $\triangle ACB$ 中用勾股 $BC = \sqrt{10^2 - 6^2} = 8$。

4. 圆内接四边形 $ABCD$ 中，$\angle A = 75°$，$\angle B = 95°$。分别求 $\angle C, \angle D$ 以及 $\angle D$ 的外角（与 $\angle B$ 的关系）。
   - 💡 提示：对角互补 → $\angle C = 105°$，$\angle D = 85°$；$\angle D$ 的外角 $= 180° - 85° = 95° = \angle B$，即"内接四边形任一外角等于不相邻内角"。

5. （综合）$\triangle ABC$ 内接于圆 $O$，$AD$ 是 $BC$ 边上的高，$AE$ 是圆 $O$ 的直径。证 $\angle BAD = \angle CAE$。
   - 💡 提示：由推论 2，$\angle ACE = 90°$（直径 $AE$ 所对），所以 $\angle CAE = 90° - \angle AEC$。又 $\angle AEC = \angle ABC$（同弧 $\overarc{AC}$ 圆周角）。在 $\triangle ABD$ 中 $\angle BAD = 90° - \angle ABD = 90° - \angle ABC$。两式相等，证毕。
