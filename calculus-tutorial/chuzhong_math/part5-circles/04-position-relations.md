# 点、直线、圆与圆的位置关系

## 一、图形特征

平面上一旦给定一个圆 $\odot O$（圆心 $O$、半径 $r$），其他几何对象（点、直线、另一个圆）相对于这个圆就有了"远近"之分。本章关注三类对象的位置关系：

- **一个点与一个圆**：点要么在圆内、要么在圆上、要么在圆外。
- **一条直线与一个圆**：直线可能没有交点、只有一个交点、有两个交点。
- **两个圆**：两个圆之间可能完全分开、相切于一点、相交于两点、一个圆"含"在另一个圆里。

每一种位置关系，都可以用一个**距离数据**精确刻画——这正是本章的中心思想：**把"位置关系"翻译成"距离与半径的大小比较"**。一旦能这样翻译，所有几何问题就被化简为代数不等式问题，处理起来非常机械。

> 直观感受：把圆心 $O$ 当作"基准点"。一切"它与圆是什么关系"的问题，都归结为"它（或它身上离 $O$ 最近的点）距 $O$ 多远"。距离比半径小就在内部，相等就在圆上（或相切），大就在外部（或相离）。两个圆的关系略复杂一点，因为参与比较的量除了圆心距 $d$ 还有 $r_1 + r_2$ 和 $|r_1 - r_2|$ 两个临界值，但思路完全一致。

## 二、点与圆的位置关系

设点 $P$ 到圆心 $O$ 的距离为 $d = OP$，圆 $\odot O$ 半径为 $r$。

> **判定**：
>
> - $d < r \Leftrightarrow$ 点 $P$ 在 $\odot O$ **内部**；
> - $d = r \Leftrightarrow$ 点 $P$ 在 $\odot O$ **上**；
> - $d > r \Leftrightarrow$ 点 $P$ 在 $\odot O$ **外部**。

这三条互相排斥、并且穷尽所有可能。由圆的定义（到 $O$ 距离 $= r$ 的所有点的集合），$d = r$ 当且仅当 $P$ 在圆上；其余两种情形按 $d$ 与 $r$ 的大小自然区分。

> 反过来，这套判定也可以用来**构造圆**：要想让一个点在某圆上，只需控制它到圆心的距离等于半径；要想让点在圆外，控制 $d > r$ 即可。这种"用距离描述位置"的思想，会贯穿后面所有切线、轨迹、最值问题。

## 三、直线与圆的位置关系

设圆心 $O$ 到直线 $\ell$ 的距离为 $d$（即从 $O$ 向 $\ell$ 作垂线，垂足为 $H$，$d = OH$），圆 $\odot O$ 半径为 $r$。

> **判定**：
>
> - $d < r \Leftrightarrow$ 直线 $\ell$ 与 $\odot O$ **相交**（有两个公共点，$\ell$ 称为圆的**割线**）；
> - $d = r \Leftrightarrow$ 直线 $\ell$ 与 $\odot O$ **相切**（有唯一公共点，$\ell$ 称为圆的**切线**，公共点称为**切点**）；
> - $d > r \Leftrightarrow$ 直线 $\ell$ 与 $\odot O$ **相离**（没有公共点）。

直观地：$H$ 是直线上离圆心**最近**的点；如果连 $H$ 都还没碰到圆（$d > r$），整条直线都在圆外；如果 $H$ 恰好在圆上（$d = r$），就是相切；如果 $H$ 已经进圆内（$d < r$），那么从 $H$ 沿直线向两边走，必定从圆里穿出，形成两个交点。

> 切点处有一条关键性质：**切点 $H$ 也就是圆心到切线的垂足**，因此**圆心到切点的半径与切线垂直**。这条"切线 $\perp$ 过切点的半径"，是 part5/05 切线性质定理的几何根源，本节先记住、下一章再证。

切线与割线只是名字，本质都是直线，区别只在它们与圆的交点个数。

## 四、两圆的位置关系

设两圆 $\odot O_1, \odot O_2$ 半径分别为 $r_1, r_2$（不妨 $r_1 \geq r_2$），**圆心距** $d = O_1 O_2$。两圆的位置关系由 $d$ 与 $r_1 + r_2, r_1 - r_2$ 两个临界值的大小关系决定，共有五类：

> **判定**：
>
> - **外离**：$d > r_1 + r_2$ —— 两圆完全分开，没有公共点，且不相互包含。
> - **外切**：$d = r_1 + r_2$ —— 两圆有唯一公共点，切点在 $O_1 O_2$ **之间**（连心线上）。
> - **相交**：$r_1 - r_2 < d < r_1 + r_2$ —— 两圆有两个公共点。
> - **内切**：$d = r_1 - r_2$ —— 两圆有唯一公共点，切点在 $O_1 O_2$ 的**延长线**上（连心线的延长方向），小圆在大圆内部。
> - **内含**：$d < r_1 - r_2$（特别地 $d = 0$ 时为**同心圆**）—— 小圆完全在大圆内部，没有公共点。

把数轴想象一下：以 $r_1 - r_2$ 和 $r_1 + r_2$ 两个数为分隔点，$d$ 落在哪一段，对应哪种位置关系。$d$ 越大，两圆越"散开"；$d$ 越小，两圆越"嵌入"。两个临界值（外切、内切）恰好是位置关系的"分水岭"。

> 几个常用结论：
>
> 1. **外切 $\Rightarrow d = r_1 + r_2$**：两圆心和切点共线（切点在它们之间）。
> 2. **内切 $\Rightarrow d = r_1 - r_2$**：切点也在连心线上（在 $O_1 O_2$ 的延长线、靠大圆远端的一侧）。
> 3. **公共点个数表**：外离 $0$，外切 $1$，相交 $2$，内切 $1$，内含 $0$。
> 4. **"相切"涵盖外切和内切两种情况**——做题时若题目只说"两圆相切"，**务必分两种情况讨论**，这是中考最常见的失分点之一。

## 五、典型应用

### 例 1（点与圆的位置判断）

> 已知圆 $\odot O$ 半径 $r = 5$，平面上三点 $A, B, C$ 到圆心 $O$ 的距离分别为 $OA = 3, OB = 5, OC = 7$。判断 $A, B, C$ 分别与 $\odot O$ 的位置关系。

**思路**：直接比较 $d$ 与 $r$：

- $OA = 3 < 5 = r$ → $A$ 在圆**内**；
- $OB = 5 = r$ → $B$ 在圆**上**；
- $OC = 7 > 5 = r$ → $C$ 在圆**外**。

**答案**：$A$ 在圆内、$B$ 在圆上、$C$ 在圆外。

> 通用结构：拿到"点到圆心距离"和"半径"两个数据，直接进入大小比较即可——这是最机械、最不容易错的一类题。

### 例 2（直线与圆相切的临界条件）

> 直线 $\ell$ 上一点 $P$ 到圆心 $O$ 的距离 $OP = 13$，$\angle OPH = 60°$（$H$ 为 $O$ 到 $\ell$ 的垂足）。若圆 $\odot O$ 的半径为 $r$，问 $r$ 取何值时直线 $\ell$ 与 $\odot O$ 相切？相交？相离？

**思路**：先把"圆心到直线的距离" $d$ 算出来。在直角 $\triangle OPH$ 中（$\angle OHP = 90°$，$\angle OPH = 60°$，$OP = 13$）：

$$d = OH = OP \cdot \sin 60° = 13 \times \frac{\sqrt{3}}{2} = \frac{13\sqrt{3}}{2}.$$

得到 $d$ 之后照表判断：

- 相切 $\Leftrightarrow d = r \Leftrightarrow r = \dfrac{13\sqrt{3}}{2}$；
- 相交 $\Leftrightarrow d < r \Leftrightarrow r > \dfrac{13\sqrt{3}}{2}$；
- 相离 $\Leftrightarrow d > r \Leftrightarrow r < \dfrac{13\sqrt{3}}{2}$。

> 这类题的固定套路：**先算 $d$，再与 $r$ 比较**。$d$ 通常要用直角三角形（或勾股、三角函数）从题目给的条件里推出来。

### 例 3（两圆位置 + 圆心距范围）

> 两圆半径分别为 $r_1 = 5, r_2 = 3$，圆心距 $d$ 满足下列条件时，分别判断两圆的位置关系。
>
> (1) $d = 9$；(2) $d = 8$；(3) $d = 4$；(4) $d = 2$；(5) $d = 1$。

**思路**：先算两个临界值：$r_1 + r_2 = 8$，$r_1 - r_2 = 2$。再把 $d$ 与 $8, 2$ 比较即可。

- (1) $d = 9 > 8 = r_1 + r_2$ → **外离**。
- (2) $d = 8 = r_1 + r_2$ → **外切**。
- (3) $2 < d = 4 < 8$ → **相交**。
- (4) $d = 2 = r_1 - r_2$ → **内切**。
- (5) $d = 1 < 2 = r_1 - r_2$ → **内含**。

> 反向题型也很常见：**已知两圆相切，求 $d$**。这时**必须分外切 $d = r_1 + r_2$ 和内切 $d = r_1 - r_2$ 两种情况**，写出两个答案，否则丢分。

## 六、易错点

1. **"相切"在中考语境里包含外切和内切两种情况**：题目若只说两圆相切而未指明哪种，必须分类讨论。直线与圆"相切"只有一种情形（即 $d = r$），不需分类。
2. **直线与圆相离/相交时的距离方向**：$d$ 始终指**圆心到直线的垂线段**长度，是非负数；$d$ 大于 $r$ 就相离，不要被题目中"直线在圆外"的措辞干扰。
3. **内切与外切都是"相切"，但圆心距公式截然不同**：外切 $d = r_1 + r_2$（圆心距很"大"，等于半径之和），内切 $d = r_1 - r_2$（圆心距很"小"，等于半径之差）。混淆这两个公式是高频错点。
4. **内含与内切别混**：内切是 $d = r_1 - r_2$（有公共切点），内含是 $d < r_1 - r_2$（**没有任何公共点**，小圆完全藏在大圆内部）。同心圆 $d = 0$ 是内含的特殊情况。
5. **半径之差要取非负**：在公式 $d = r_1 - r_2$、$d < r_1 - r_2$ 中，已经约定 $r_1 \geq r_2$；如果题目给的两半径大小关系不明，更稳妥的写法是 $d = |r_1 - r_2|$ 与 $d < |r_1 - r_2|$。
6. **点与圆位置不是"看图估计"，而是"距离计算"**：尤其在坐标系里给点和圆方程，先算 $d$ 再比较 $r$，不要凭直觉判断。
7. **切点必在连心线上**（两圆相切时）、**切点处半径 $\perp$ 切线**（直线与圆相切时）——这两条性质在后面切线判定与切割线模型中极为关键。

## 七、自测题

1. 圆 $\odot O$ 半径 $r = 4$，点 $P$ 到圆心距离 $OP = 4$。判断 $P$ 与圆的位置关系。
   - 💡 提示：$d = r$ → $P$ 在圆**上**。

2. 在 $\triangle ABC$ 中，$\angle C = 90°$，$AC = 3, BC = 4$。以 $C$ 为圆心、$r$ 为半径作圆。问 $r$ 取何值时，斜边 $AB$ 与圆 $\odot C$ 分别相离、相切、相交？
   - 💡 提示：先求 $C$ 到 $AB$ 的距离 $d$。$AB = 5$；由面积法 $d = \dfrac{AC \cdot BC}{AB} = \dfrac{12}{5} = 2.4$。所以：$r < 2.4$ 相离，$r = 2.4$ 相切，$r > 2.4$ 相交（在 $r$ 取到使 $\odot C$ 不超出三角形太多前，这种粗略分类即可应付选择题；如果要严格的"相交且交点都在线段 $AB$ 上"还需再加上 $r \leq CA, r \leq CB$ 等条件）。

3. 两圆半径分别为 $7$ 和 $4$，圆心距 $d = 11$。两圆是什么位置关系？若 $d$ 变为 $3$ 呢？若 $d = 2$ 呢？
   - 💡 提示：$r_1 + r_2 = 11, r_1 - r_2 = 3$。所以 $d = 11$ → **外切**；$d = 3$ → **内切**；$d = 2 < 3$ → **内含**。

4. 已知两圆半径分别为 $R$ 和 $r$（$R > r$），且两圆**相切**。设圆心距 $d$。求 $d$ 的所有可能取值。
   - 💡 提示："相切"含外切和内切两种情况，**必须分类**：外切 $d = R + r$，内切 $d = R - r$。所以 $d \in \{R + r,\ R - r\}$。
