# 三视图

## 一、图形特征与基本想法

**三视图**研究的是这样一类问题：把一个空间立体放在桌面上，从**三个互相垂直**的方向去观察，把每个方向所看到的"轮廓影像"画在平面上，就得到三张平面图。这三张平面图合在一起，就足以**唯一确定**一个立体的形状（在大多数中考题的尺度内）。

约定的三个观察方向是：

- **从正前方水平望过去** —— 得到**主视图**（也叫"正视图"）；
- **从正上方竖直向下看** —— 得到**俯视图**；
- **从正左方水平望过去** —— 得到**左视图**（也叫"侧视图"）。

为什么是这三个方向？因为空间里**互相垂直**的方向只有三组（前后、上下、左右），任何两组都不平行；只要三个方向各给一张投影图，立体在每条空间方向上的尺寸都被记录了下来。

## 二、定义与位置约定

**主视图（正视图）**：从立体的**正面**水平地向后看所得的平面图。它反映立体的**长**与**高**。

**俯视图**：从立体的**上方**竖直地向下看所得的平面图。它反映立体的**长**与**宽**。

**左视图（侧视图）**：从立体的**左侧**水平地向右看所得的平面图。它反映立体的**高**与**宽**。

把三张图按下面这个**固定位置**摆放，是国家标准（中考也遵循）：

```
   ┌────────────┐    ┌────────────┐
   │  主视图    │    │  左视图    │
   │ (长 × 高)  │    │ (宽 × 高)  │
   └────────────┘    └────────────┘
   ┌────────────┐
   │  俯视图    │
   │ (长 × 宽)  │
   └────────────┘
```

- **主视图**在左上；
- **俯视图**正好画在主视图**正下方**；
- **左视图**画在主视图**正右方**。

按此摆放后，三张图之间会自动产生下面三条对应关系。

## 三、三视图三大原则

三视图之所以"对得整齐"，靠下面三句口诀：

- **长对正**：主视图的**长**与俯视图的**长**对应相等。两张图在水平方向上要**对齐**。
- **高平齐**：主视图的**高**与左视图的**高**对应相等。两张图在竖直方向上要**对齐**。
- **宽相等**：俯视图的**宽**与左视图的**宽**对应相等（虽然画在不同位置，但**数值必须一样**）。

任何一张三视图，三原则若不同时满足，必定画错。这也是**检验**自己画的三视图是否合格的标准答案。

## 四、常见几何体的三视图

下表是中考最常见的几个立体（假设摆放成"标准姿态"）：

| 立体 | 主视图 | 左视图 | 俯视图 |
|---|---|---|---|
| 长方体 | 矩形 | 矩形 | 矩形 |
| 正方体 | 正方形 | 正方形 | 正方形 |
| 圆柱（轴线竖直） | 矩形 | 矩形 | 圆（带圆心） |
| 圆锥（轴线竖直） | 等腰三角形 | 等腰三角形 | 圆（带圆心） |
| 球 | 圆 | 圆 | 圆 |
| 正四棱锥（轴线竖直） | 等腰三角形 | 等腰三角形 | 正方形（带对角线） |
| 三棱柱（侧棱竖直） | 矩形 | 矩形 | 三角形 |

记忆要点：

- **圆柱**：主、左视图都是**矩形**（矩形的长 = 圆柱高，宽 = 底面直径 $2r$），俯视图是**圆**。
- **圆锥**：主、左视图都是**等腰三角形**（底 = $2r$，高 = 圆锥高），俯视图是**圆**且圆心要画出来（因为顶点投影在底面圆心）。
- **球**：三个视图都是**同一个圆**（半径 = 球半径）。
- 棱锥/棱柱的俯视图通常会出现**虚线**或**对角线**，表示从上往下能看见的"内部棱"。

## 五、典型应用

**例 1（基础：长方体的三视图）** 一个长方体，长 $4$、宽 $2$、高 $3$（单位：cm），按标准姿态摆放。画出它的三视图。

【思路】套定义：

- **主视图**反映长 $\times$ 高 $= 4 \times 3$ → 一个 $4 \times 3$ 的矩形；
- **左视图**反映宽 $\times$ 高 $= 2 \times 3$ → 一个 $2 \times 3$ 的矩形；
- **俯视图**反映长 $\times$ 宽 $= 4 \times 2$ → 一个 $4 \times 2$ 的矩形。

```
   ┌─────────┐   ┌────┐
   │ 4 × 3   │   │2×3 │
   └─────────┘   └────┘
   ┌─────────┐
   │ 4 × 2   │
   └─────────┘
```

验证三原则：主视图与俯视图的长都是 $4$（长对正 ✓）；主视图与左视图的高都是 $3$（高平齐 ✓）；俯视图与左视图的宽都是 $2$（宽相等 ✓）。

**例 2（逆向问题：由三视图还原立体）** 已知某立体的三视图如下：主视图为等腰三角形，左视图为同样的等腰三角形，俯视图为带圆心的圆。这个立体是什么？

【思路】先看**俯视图**——是圆，说明从上往下投影出圆，立体一定是"绕竖直轴对称"的旋转体（圆柱、圆锥、球或它们的组合）。再看**主视图**——是三角形而不是矩形，说明它不是圆柱；是三角形不是圆，说明它不是球；正好对应**圆锥**。

进一步：等腰三角形的底 = 俯视圆的直径 $2r$；等腰三角形的高 = 圆锥的高 $h$。还可由这两条算出**母线长** $l = \sqrt{r^2 + h^2}$（呼应 part7/rt 的勾股）。

**关键观察**：逆向还原时**先看俯视图**判断"是不是旋转体"或"底面形状"，再用主视/左视确定"竖直方向上的样子"。

**例 3（由三视图求体积）** 某几何体的三视图如下：主视图与左视图均为长 $4$、宽 $3$ 的矩形；俯视图为一个直径 $4$ 的圆。求这个几何体的体积。

【思路】

第 1 步：识别立体——俯视图是圆 → 旋转体；主/左视图都是矩形而不是三角形 → 是**圆柱**而不是圆锥。

第 2 步：读尺寸——俯视圆的直径 $= 4$，故底面半径 $r = 2$；主视矩形的高 $= 3$，故圆柱高 $h = 3$。

第 3 步：套体积公式（part8 之外的常识，圆柱体积 = 底面积 $\times$ 高）：
$$V = \pi r^2 h = \pi \times 2^2 \times 3 = 12\pi.$$

**别踩坑**：主视图与左视图的**宽**都是 $3$，这是"高平齐"在起作用——它们都表示圆柱的**高**；不要把矩形的另一条边 $4$（来自底面直径）当成圆柱高用。

## 六、易错点

1. **看不见的轮廓必须画成虚线**。比如带孔的零件，从主视方向看不见的内部轮廓线，按规范要用**虚线**绘制；中考通常不深究虚线细节，但题目要求时不可漏掉。
2. **三原则必须同时满足**。只对一两条不够——长对正、高平齐、宽相等是三视图自洽的最低要求。自查时把三张图按位置摆好，量一量水平方向、竖直方向、以及俯视/左视的**宽**是否各自相等。
3. **圆柱、圆锥的俯视图要画圆心**。圆心代表轴线在俯视面上的投影。带圆心和不带圆心，是"实心圆柱/圆锥"与"环面/其他"的常用区分提示。
4. **正四棱锥的俯视图要画对角线**。从上看正四棱锥，看到的是底面正方形 + 顶点（投影到正方形中心）+ 四条侧棱的投影（即正方形的两条对角线）。漏掉对角线就把它画成了"长方体的俯视图"。
5. **圆柱的主视图是矩形而不是椭圆**。投影是**正投影**（光线与投影面垂直），圆柱侧面投影成两条平行直线 + 上下两条线段构成的矩形；只有在斜投影下圆柱才出现椭圆。
6. **位置摆放固定**。主视左上、俯视正下、左视正右——这是中考默认。如果题目用了别的摆法（少数情况），会**明确标注**每张图的名字，否则按默认理解。
7. **左视方向是"从左向右看"**。许多同学误以为是"从右向左看"，导致左右镜像。判断方法：站在立体左侧，**面朝立体**，所见即为左视图。

## 七、自测题

1. 一个正方体的棱长为 $a$。画出它的三视图，并写出三视图中"长、宽、高"分别等于多少。
2. 一个圆柱底面半径 $r = 2$，高 $h = 5$（轴线竖直）。分别给出主视图、左视图、俯视图的形状与尺寸；并用三原则验证你的回答。
3. 某几何体的主视图与左视图都是底为 $6$、高为 $4$ 的等腰三角形，俯视图是直径为 $6$ 的圆（带圆心）。问：(a) 该立体是什么？(b) 它的母线长 $l = ?$ (c) 侧面展开图是什么形状？（呼应 part8/03）
4. 已知一个组合体的三视图：主视图为"上面一个小正方形，下面一个大长方形"上下相连的图形；左视图与主视图相同（轮廓一致）；俯视图为一个正方形里再画一个小正方形（同心，且对应主视的小正方形位置）。请猜想这个组合体是什么形状。【思路】俯视图给出底面与"叠加上去的部分"在水平面上的关系——上下两段都是棱柱，叠在一起；主视/左视的"上小下大"反映两段的截面尺寸。
