# 平行投影与中心投影

## 一、图形特征与基本想法

**投影**研究的是这样一类问题：把一个物体放在某个光源下，光线被物体挡住，物体后面（或下面）的平面上就会留下一片"影子"。我们关心的是**影子的形状、大小与位置**与**物体本身**之间的关系——这种关系本质上是一种"光线把物体的每个点连到投影面"的几何对应。

按**光源的种类**不同，初中阶段把投影分成两大类：

- **平行投影**：光线**互相平行**（如远处的太阳光）；
- **中心投影**：光线**从同一点发出**（如灯泡、手电筒、路灯等点光源）。

两者的核心差别就在**光线是平行的还是汇聚于一点**，由此推出影子与物体之间一整套不同的几何关系。

## 二、平行投影

**定义**：在**平行光线**照射下，物体在平面上留下的影子，叫作**平行投影**。

最常见的情景就是**太阳光下的影子**——太阳离地球极远，从太阳射来的光线在地表附近近似**完全平行**。在这种情形下，同一时刻、同一地点：

- **所有物体的光线方向都相同**；
- **竖直物体（如旗杆、电线杆、人、小棍）的影子方向也都相同**；
- **物体高度与影长之比是一个常数**（这个常数只跟太阳的高度角有关）。

正是最后这一条，使平行投影具有**比例性**：若两根竖直的物体高度分别是 $h_1, h_2$，影长分别是 $s_1, s_2$，则

$$\frac{h_1}{s_1} = \frac{h_2}{s_2}.$$

几何上，物体顶端、底端、影子顶端构成一个**直角三角形**（呼应 part3/rt），不同物体在同一时刻得到的这些直角三角形彼此**相似**（呼应 part6 相似三角形）。这就是"竿影测高"的原理。

## 三、中心投影

**定义**：在**从一点发出**的光线照射下，物体在平面上留下的影子，叫作**中心投影**。这一"点"就是**光源**（如灯泡），也称为**投影中心**。

在中心投影下，光线像一束从光源出发的"射线扇"，每条射线穿过物体上的一个点，最终落到投影面上。物体与影子之间是**以光源为中心的位似**关系（呼应 part6 位似）：

- 光源 $O$、物体上一点 $P$、影子上对应点 $P'$ **三点共线**；
- 不同物体上对应点的"位似比"由该物体到光源的距离决定，**距离越远比例越大**或**越小**（取决于物体在光源与投影面之间还是投影面的另一侧，初中只讨论物体处在光源与投影面之间的常见情形）。

最典型的情境是**路灯下的人影**：路灯灯泡是点光源，人站在灯下，灯泡顶端、人的头顶、人影顶端三点共线；灯柱顶端、人的头顶、人影顶端之间构成**相似三角形**，用相似比即可求出影长。

## 四、平行投影与中心投影的区别

| 比较项 | 平行投影 | 中心投影 |
|---|---|---|
| 光线 | 互相**平行** | 从一点**发散** |
| 光源举例 | 太阳光 | 灯泡、手电、路灯 |
| 影子与物体 | **相似**（特殊角度下相等） | **位似**（位似中心 = 光源） |
| 同一时刻不同物体 | 高/影 之比**相等** | 比例随到光源距离而变 |
| 几何工具 | 相似直角三角形 | 以光源为顶点的相似三角形 |

**口诀**：太阳光下"平行"，影子之比等于高之比；路灯之下"汇聚"，要把灯顶画进相似三角形。

## 五、典型应用

**例 1（平行投影：阳光下旗杆高度）** 某天上午，小明把一根 $1.5\,\text{m}$ 的竹竿竖直插在地面上，量得竹竿的影长为 $1\,\text{m}$；同一时刻测得旁边一根旗杆的影长为 $8\,\text{m}$。求旗杆的高度。

【思路】同一时刻同一地点，太阳光**平行**——这是典型的**平行投影**。竹竿与影子构成的直角三角形 $\sim$ 旗杆与影子构成的直角三角形（两组直角，光线方向相同 → 锐角相等，AA 相似）。

设旗杆高 $h$。由相似比

$$\frac{h}{8} = \frac{1.5}{1} \Rightarrow h = 12\,\text{m}.$$

旗杆高 **$12$ 米**。

**关键观察**：平行投影下，**所有竖直物体的"高 : 影长"相等**——一根竹竿就足以"标定"当时太阳的角度，再去测任何物体的高度。这是"竿影测高"在中考里的标准模型。

**例 2（中心投影：路灯下人影）** 一盏路灯的灯柱高 $AB = 6\,\text{m}$，灯泡看作位于 $A$ 处的点光源。某人身高 $CD = 1.5\,\text{m}$，站立时脚 $D$ 到灯柱底 $B$ 的距离为 $BD = 3\,\text{m}$。求此人在地面上的影长。

【思路】点光源是**中心投影**。灯泡 $A$、人的头顶 $C$、人影末端 $E$ **三点共线**；灯柱 $AB$ 与人 $CD$ 都**竖直**，所以 $AB \parallel CD$，进而 $\triangle EDC \sim \triangle EBA$（共顶点 $E$，DC、BA 平行 → 相似）。

设影长 $DE = x$，则 $BE = BD + DE = 3 + x$。由相似比

$$\frac{CD}{AB} = \frac{ED}{EB} \Rightarrow \frac{1.5}{6} = \frac{x}{3 + x}.$$

整理：$1.5(3 + x) = 6x \Rightarrow 4.5 = 4.5x \Rightarrow x = 1\,\text{m}$。

影长 **$1$ 米**。

**别踩坑**：中心投影里的相似三角形，**顶点是光源**而不是物体的脚——必须把"灯泡 $A$"也画进图里，三角形 $\triangle EBA$ 的"长直角边"是**灯柱高** $AB$ 而不是"人到灯柱的距离" $BD$。$BD$ 只是直角边的**一部分**，要再加上影长 $x$ 才是完整的底边 $BE$。

## 六、易错点

1. **平行投影下"高 : 影长 = 常数"只在同一时刻成立**。早上和中午太阳高度角不同，比例就不同——同一题里若涉及"不同时刻"必须分别处理。
2. **平行投影的相似比不一定是 $1$**。相似比 $= \dfrac{\text{物体高}}{\text{影长}}$，由太阳高度角决定；只有太阳恰好与地面成 $45°$ 时影长 $=$ 物体高。
3. **中心投影必须把光源画进图里**。不要忘了灯柱顶端就是光源 $A$；相似三角形的"大三角形"以 $A$ 为顶点、以**灯柱底到影末端**为底，而不是"人到灯柱"的距离。
4. **区分两种投影看光源**：题目里出现"太阳""阳光""同一时刻不同物体"等字眼 → 平行投影；出现"灯""路灯""手电""灯泡"等字眼 → 中心投影。
5. **方向问题**：平行投影下，**所有竖直物体的影子方向相同**（都指向背光方向）；中心投影下，影子方向因物体位置不同而**不同**（每个物体的影子都背向光源延伸）。
6. **位似中心 = 光源**：中心投影里物体与影子位似，**位似中心恰好是光源**——这是判断"物体与影子是不是位似"以及定位"位似中心"的最直接依据（呼应 part6 位似）。

## 七、自测题

1. 同一时刻，一根高 $2\,\text{m}$ 的木杆影长为 $1.6\,\text{m}$，一棵大树的影长为 $12\,\text{m}$。求这棵大树的高度。
2. 一盏路灯灯柱高 $4.5\,\text{m}$（灯泡看作点光源置于柱顶）。一个身高 $1.5\,\text{m}$ 的人沿直线**远离**灯柱行走，当他距灯柱底 $4\,\text{m}$ 时，他的影长是多少？再走 $2\,\text{m}$ 后，影长又是多少？比较两次影长，说明"中心投影下离光源越远影子越长"。
3. 判断下列情境属于**平行投影**还是**中心投影**，并说明理由：
   (a) 中午阳光下两根并排立着的旗杆的影子；
   (b) 教室里一盏吊灯下，讲桌投在地面上的影子；
   (c) 月光下一栋楼的影子；
   (d) 手电筒照射一只玩具熊在墙上留下的影子。
