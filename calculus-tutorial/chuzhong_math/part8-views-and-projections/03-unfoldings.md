# 立体图形的展开图

## 一、图形特征与基本想法

**展开图**研究的是这样一类问题：把一个立体图形沿着某些**棱**（多面体）或**母线**（旋转体）剪开，然后把它的各个面**摊平**到同一个平面上，得到的平面图形就叫作这个立体图形的**展开图**（也称**侧面展开图**）。

为什么要研究展开图？两条根本理由：

1. **算面积**：立体图形的"表面积"本质上就是它的**展开图的面积**。圆柱、圆锥的侧面是曲面，无法直接量算——但展开成矩形或扇形后，就变成了我们熟悉的平面图形（呼应 part4 四边形与 part5 圆），可以直接套公式。
2. **算最短路径**："蚂蚁沿表面爬行的最短路线"这种题目，物体表面是弯的，无法直接用"两点之间线段最短"。但只要把表面展开成平面，**沿表面的最短路径就变成了平面上的线段**——再用勾股定理（part3/rt）一算即可。

因此展开图的核心想法是**"把曲面/折面摊平成平面"——化立体为平面、化曲为直**，这是 toolkit 转化思想在立体几何中的典型应用。

## 二、常见立体图形的展开图

### 1. 长方体与正方体

**长方体**沿棱剪开，可以展成 **$6$ 个矩形**拼成的平面图（其中相对的两个面全等）。设长方体的长、宽、高分别为 $a, b, c$，则三对面的面积分别是 $ab, bc, ca$，于是

$$S_{\text{长方体}} = 2(ab + bc + ca).$$

**正方体**是长方体的特例（$a = b = c$），展开图是 **$6$ 个全等正方形**。沿不同的棱剪开，可得到 **$11$ 种**本质不同的正方体展开图，按形状可分四类：

- **"1-4-1"型**（共 $6$ 种）：中间一排 $4$ 个正方形，上下各挂 $1$ 个，挂的位置可变；
- **"2-3-1"型**（共 $3$ 种）：中间一排 $3$ 个，上面 $1$ 个、下面 $2$ 个（或相反）；
- **"2-2-2"型**（共 $1$ 种）：呈"Z"字形阶梯；
- **"3-3"型**（共 $1$ 种）：两排各 $3$ 个并排错开。

**反过来**：给一个由 $6$ 个正方形拼成的平面图，判断它能否折成正方体——可用上面四类口诀判断，也可用"反例排除法"（凡是出现"田字"$2\times 2$ 或"凹"形的都**不能**折成正方体）。

### 2. 圆柱

把一个底面半径为 $r$、高为 $h$ 的圆柱**沿一条母线**剪开侧面，再剪下两个底圆，可得到圆柱的展开图：

- **侧面**：展开成一个**矩形**。矩形的**长 $=$ 底面圆周长 $= 2\pi r$**，**宽 $=$ 圆柱的高 $h$**。
- **两个底面**：两个半径为 $r$ 的**圆**。

因此

$$S_{\text{侧}} = 2\pi r \cdot h, \qquad S_{\text{全}} = 2\pi r h + 2\pi r^2 = 2\pi r(h + r).$$

### 3. 圆锥

把一个底面半径为 $r$、母线长为 $l$（即圆锥顶点到底面圆周上任一点的距离）的圆锥**沿一条母线**剪开侧面，再剪下底圆，可得到圆锥的展开图：

- **侧面**：展开成一个**扇形**。扇形的**半径 $=$ 母线长 $l$**，扇形的**弧长 $=$ 底面圆周长 $= 2\pi r$**。
- **底面**：一个半径为 $r$ 的**圆**。

侧面展开扇形所对的圆心角 $\alpha$ 由"弧长 $=$ 半径 $\times$ 弧度"或"扇形弧长 $=$ 整圆周长的几分之几"得到：

$$\alpha = \frac{2\pi r}{2\pi l} \times 360° = \frac{r}{l} \times 360°.$$

侧面积可由"扇形面积 $= \frac{1}{2} \times$ 弧长 $\times$ 半径"直接得到：

$$S_{\text{侧}} = \frac{1}{2} \cdot 2\pi r \cdot l = \pi r l, \qquad S_{\text{全}} = \pi r l + \pi r^2 = \pi r(l + r).$$

注意 $l, r, h$ 三者满足 $l^2 = r^2 + h^2$（圆锥的母线、底半径、高构成直角三角形——呼应 part3/rt）。

## 三、关键公式速查

| 立体 | 侧面展开形状 | 侧面积 |
|---|---|---|
| 长方体 | $4$ 个矩形 | $2(a+b)c$（设 $c$ 为高） |
| 正方体 | $4$ 个正方形 | $4a^2$ |
| 圆柱 | 矩形（$2\pi r \times h$） | $2\pi r h$ |
| 圆锥 | 扇形（半径 $l$、弧长 $2\pi r$） | $\pi r l$ |

## 四、典型应用

**例 1（正方体展开图判断）** 下列由 $6$ 个全等正方形拼成的平面图形中，能折成正方体的是哪些？
(a) 中间一排 $4$ 个，第 $2$ 个上面挂 $1$ 个、第 $3$ 个下面挂 $1$ 个；
(b) "田字形" $2\times 2$ 再在右侧并排接 $2$ 个；
(c) "十字形"：中间 $1$ 个，上下左右各 $1$ 个，再在上方那个的上面再接 $1$ 个。

【思路】用"1-4-1 / 2-3-1 / 2-2-2 / 3-3"四类口诀判断；"田字形"出现就直接判否。

- (a) 中间 $4$ 个 + 上下各 $1$ 个，属 **"1-4-1"型** —— **能**折成正方体；
- (b) 含 $2\times 2$ "田字"——折时四个面会相互重叠——**不能**；
- (c) 中间 $1$ 个、上下左右各 $1$ 个再加最上方 $1$ 个，即"十字 + 顶"，相当于中间一列 $4$ 个 + 左右各挂 $1$ 个，属 **"1-4-1"型** —— **能**。

**关键观察**：判断能否折成正方体的最快方法是"找连续四格"——若图中含一排（或一列）**$4$ 个连续正方形**，且剩下的 $2$ 个分别挂在这排的不同行，多半能折；若出现 $2\times 2$ 的"田字"则必然不能。

**例 2（圆柱侧面积）** 一个圆柱底面半径 $r = 3$，高 $h = 5$。求它的侧面积与全面积。

【思路】侧面展开为矩形，长 $= 2\pi r$、宽 $= h$，套公式。

$$S_{\text{侧}} = 2\pi r h = 2\pi \cdot 3 \cdot 5 = 30\pi.$$

$$S_{\text{全}} = 2\pi r h + 2\pi r^2 = 30\pi + 2\pi \cdot 9 = 30\pi + 18\pi = 48\pi.$$

**例 3（蚂蚁爬行最短路径）** 一只蚂蚁在底面半径 $r = 2$、高 $h = 6\pi$ 的圆柱**侧面**上，从底面圆周上一点 $A$ 出发，沿圆柱**侧面**爬到正上方对面（即上底面圆周上、$A$ 的"正对面"——绕侧面走半圈）的点 $B$。求蚂蚁所走的最短路程。

【思路】蚂蚁只在**侧面**爬行，曲面上无法直接量"两点最短"。**把圆柱侧面沿过 $A$ 的母线剪开摊平**——侧面变成一个矩形（长 $= 2\pi r = 4\pi$、宽 $= h = 6\pi$）。点 $A$ 落在矩形一条短边的端点上；点 $B$ 是"正对面"——在原侧面上，$B$ 离 $A$ 沿底圆方向走半圈即 $\pi r = 2\pi$，所以 $B$ 在展开矩形里的位置是**距 $A$ 水平 $2\pi$、竖直 $6\pi$** 的一点。

展开后蚂蚁可走的"沿表面路径"对应展开矩形里**连接 $A, B$ 的折线**，其中**最短的就是线段 $AB$**（平面上两点之间，线段最短）。由勾股定理（part3/rt）：

$$AB = \sqrt{(2\pi)^2 + (6\pi)^2} = \sqrt{4\pi^2 + 36\pi^2} = \sqrt{40\pi^2} = 2\sqrt{10}\,\pi.$$

蚂蚁的最短路程为 **$2\sqrt{10}\,\pi$**。

**别踩坑**：

- "正对面"在底圆周上对应**半圈弧长** $\pi r$，**不是**直径 $2r$——因为蚂蚁只能沿侧面爬，不能从圆柱内部穿过；
- 必须**展开后**用勾股；如果直接对"立体"用勾股（高 $h$ 与直径 $2r$）会把蚂蚁"穿过"圆柱内部，得到错误结果。

## 五、易错点

1. **圆锥侧面是扇形不是三角形**。圆锥侧面展开后是一段**扇形**（弯弯的圆弧 + 两条母线），不是三角形——不要把"圆锥从正面看的轮廓是等腰三角形"和"侧面展开图"搞混。
2. **扇形的半径是母线 $l$，不是底半径 $r$ 也不是高 $h$**。展开后扇形的两条直边都是圆锥的母线 $l$，弧长才等于底周长 $2\pi r$。三者满足勾股 $l^2 = r^2 + h^2$。
3. **圆柱侧面矩形的两条边别记反**。"长 $= 2\pi r$，宽 $= h$"——长对应底周长（"绕一圈"的方向），宽对应高（"沿母线"的方向）。
4. **"田字形"与"凹形"绝对不能折成正方体**。若 $6$ 格图里出现任何 $2 \times 2$ 子块，立即判否；剩下的按"1-4-1 / 2-3-1 / 2-2-2 / 3-3"口诀套。
5. **蚂蚁爬行问题必须沿表面**，不能"穿透"。一定要先**展开**再连线段，再用勾股；不要直接拿圆柱的高与直径凑直角三角形。
6. **圆柱、圆锥的"全面积"包含底面**。侧面积 $S_{\text{侧}}$ 与全面积 $S_{\text{全}}$ 是两个量——圆柱全面积要再加**两个底圆**，圆锥全面积要再加**一个底圆**。
7. **圆心角公式 $\alpha = \dfrac{r}{l} \times 360°$ 中的 $r, l$ 不要弄反**。$r$ 是**底**半径（小），$l$ 是**母线**（大），$\alpha < 360°$。如果算出来 $\alpha > 360°$ 一定是把两者写反了。

## 六、自测题

1. 一个圆柱底面半径为 $4$，高为 $10$。求它的侧面积、底面积之和（全面积）。
2. 一个圆锥底面半径 $r = 3$，母线长 $l = 5$。求：(a) 它的侧面积；(b) 侧面展开扇形的圆心角；(c) 圆锥的高。
3. 判断下列由 $6$ 个全等正方形拼成的图形能否折成正方体：
   (a) 一排 $4$ 个，最左端上面挂 $1$ 个、最右端下面挂 $1$ 个；
   (b) 一排 $3$ 个，上面一排错开放 $3$ 个（形如阶梯"2-2-2"）；
   (c) 一排 $3$ 个，上面正中再叠 $1$ 个、上面正中那块上面再叠 $1$ 个、下面正中再挂 $1$ 个。
4. 一只蚂蚁在一个长方体盒子的一个顶点 $A$ 处，要爬到与 $A$ 体对角线相对的顶点 $B$ 处。盒子长 $a = 3$、宽 $b = 2$、高 $c = 1$。求蚂蚁沿表面爬行的最短路程。（提示：**展开两个相邻面**为一个大矩形，比较三种展开方式取最小值。）
