# 旋转构造模型

> **一图速记**：题中出现等腰、等边、正方形（即"等长边"结构）+ 特定角度（$60°$/$90°$/$120°$）→ 把一个三角形绕某顶点旋转特定角度，把**分散的条件集中**到一个三角形。这是手拉手、半角模型的统一本质。

---

## 一、引入

> **引例**：正方形 $ABCD$ 内一点 $P$，已知 $PA = 1, PB = 2, PC = 3$。求 $\angle APB$ 的度数。

题目把三段长 $PA, PB, PC$ 分别挂在三个不同的三角形上：$\triangle PAB$、$\triangle PBC$、$\triangle PAB$ 与 $\triangle PBC$ 通过 $B$ 点连接。直接列方程很难——三段长各自孤立。但是图中藏着两个"信号"：
- $BA = BC$（正方形相邻边）
- $\angle ABC = 90°$（正方形内角）

这正是"等长边 + 特殊角"组合——告诉我们：**绕 $B$ 旋转 $90°$，可以把 $C$ 转到 $A$**。一旦旋转，$\triangle BPC$ 整体被搬到一个含 $A$ 的位置——三段长就集中了。

---

## 二、思维路径还原

> "已知 $PA, PB, PC$ 三段长度但它们分散在不同三角形里——这是一个典型的'分散 → 集中'信号（呼应 toolkit/04 转化 5）。直接用余弦定理也能算，但初中没学，必须找几何办法。
>
> 正方形中有 $90°$ 旋转的天然支持：$BA = BC$、$\angle ABC = 90°$，绕 $B$ 旋转 $90°$ 后 $C$ 落到 $A$。这是模型启动按钮。
>
> 把 $\triangle BPC$ 绕 $B$ 顺时针旋转 $90°$：$C \to A$，$P \to P'$。
>
> 旋转后立刻得到一组等量：$BP' = BP = 2$、$AP' = CP = 3$、$\angle PBP' = 90°$。
>
> 关键发现：$\triangle PBP'$ 是**等腰直角三角形**（两直角边 $BP = BP' = 2$）！所以 $PP' = 2\sqrt{2}$、$\angle BPP' = \angle BP'P = 45°$。
>
> 现在看 $\triangle APP'$：三边 $AP = 1$、$AP' = 3$、$PP' = 2\sqrt{2}$。验证：$1^2 + (2\sqrt{2})^2 = 1 + 8 = 9 = 3^2$ → 勾股逆定理告诉我们这是直角三角形，且 $\angle APP' = 90°$！
>
> 所以 $\angle APB = \angle APP' + \angle P'PB = 90° + 45° = 135°$。
>
> 反思关键收益：通过 $90°$ 旋转，把分散在不同位置的三段 $PA, PB, PC$ 集中到由 $A, P, P'$ 构成的可计算三角形里——勾股一用，角就出来了。"

---

## 三、抽象成模型

**图形特征**（识别条件）：
- 出现"等长边"结构：等边三角形、等腰三角形、正方形、正三角形外/内一点
- 这对等长边的夹角是特殊角（$60°$、$90°$、$120°$ 等）
- 待求量涉及**分散的几条线段或角**

**操作流程**：
1. 选定**旋转中心**（通常是等长边的公共顶点）
2. 选定**旋转角**（= 那对等长边的夹角，让一端点旋转到另一端点）
3. 把**含部分条件的三角形**整体旋转该角度
4. 收集旋转产生的等量：旋转后线段 = 旋转前线段；旋转后角 = 旋转前角

**效果**：
- 原本散落在不同位置的条件被集中到一个三角形里
- 旋转中心 + 一对对应点构成的三角形必是**顶角 = 旋转角的等腰三角形**（常常是等边或等腰直角）
- 最后用**勾股逆定理**或**全等**收尾

**核心思想**：旋转构造是**手拉手模型**（cong/03，旋转 $\alpha$ 等于顶角）和**半角模型**（cong/04，正方形里旋转 $90°$）的统一抽象——所有这些模型的本质都是"在等长边支持下做旋转，把信息集中"。

---

## 四、模型变形

- **变形 1**：等边三角形内一点的距离问题 —— 用 $60°$ 旋转。旋转后产生**等边三角形**（顶角 $60°$ + 等腰）。
- **变形 2**：等腰直角三角形 / 正方形里一点的距离问题 —— 用 $90°$ 旋转。旋转后产生**等腰直角三角形**。
- **变形 3**：等腰顶角 $\alpha$ 的三角形里一点的距离问题 —— 用 $\alpha$ 旋转。旋转后产生**顶角 $\alpha$ 的等腰三角形**。
- **变形 4**：等边三角形**外**一点 —— 仍可旋转 $60°$，需注意方向。
- **变形 5**：综合题中**多次旋转**：把多个分散条件依次集中（高考与压轴常见）。
- **变形 6**：旋转 $+$ 翻折组合（呼应 part6/06）——先翻折制造等长边，再旋转集中条件。

---

## 五、思考路标

- 看到等腰/等边/正方形 + 一内点（或外点）分别到几个顶点的距离 → **绕一顶点旋转**
- 旋转中心选哪个？选"两条等长边的公共顶点"
- 旋转角等于多少？等于那对等长边的夹角（等边 $60°$，正方形 $90°$，等腰顶角 $\alpha$）
- 旋转方向？选能使分散条件集中到同一侧的方向
- 看到 $1, 2, 3$ 或 $3, 4, 5$ 这种数字组合 → 旋转后可能拼出**勾股数**
- "已知分散三段长度求一个角" → 旋转 + 勾股逆定理
- "已知分散三段长度求最值/面积" → 旋转 + 三角形不等式或勾股

---

## 六、应用例题

### 例 1（旋转 $90°$）

正方形 $ABCD$ 内一点 $P$，$PA = 1, PB = 2, PC = 3$，求 $\angle APB$。

**思路**：把 $\triangle BPC$ 绕 $B$ 顺时针旋转 $90°$（$BA = BC$、$\angle ABC = 90°$），$C \to A$，$P \to P'$。

**计算**：
- $BP' = BP = 2$，$AP' = CP = 3$，$\angle PBP' = 90°$。
- $\triangle PBP'$ 等腰直角，$PP' = 2\sqrt{2}$，$\angle BPP' = 45°$。
- $\triangle APP'$ 三边 $1, 2\sqrt{2}, 3$，验证 $1^2 + (2\sqrt{2})^2 = 3^2$ → 直角三角形，$\angle APP' = 90°$。
- $\angle APB = \angle APP' + \angle P'PB = 90° + 45° = \boxed{135°}$。

### 例 2（旋转 $60°$）

等边三角形 $\triangle ABC$ 内一点 $P$，$PA = 5, PB = 4, PC = 3$，求 $\angle BPC$。

**思路**：把 $\triangle BPA$ 绕 $B$ 顺时针旋转 $60°$（$BA = BC$、$\angle ABC = 60°$），$A \to C$，$P \to P'$。

**计算**：
- $BP' = BP = 4$，$CP' = AP = 5$，$\angle PBP' = 60°$。
- $\triangle PBP'$ 等腰（$BP = BP' = 4$）+ 顶角 $60°$ → **等边三角形**，$PP' = 4$，$\angle BPP' = 60°$。
- $\triangle CPP'$ 三边 $CP = 3$、$PP' = 4$、$CP' = 5$，$3^2 + 4^2 = 5^2$ → 直角三角形，$\angle CPP' = 90°$。
- $\angle BPC = \angle BPP' + \angle P'PC = 60° + 90° = \boxed{150°}$。

### 例 3（旋转构造规则图形求面积）

四边形 $ABCD$ 中，$\angle ABC = 60°$，$AB = BC$，$\angle BAD = \angle BCD = 90°$，$AD = 3$，$CD = 5$。求四边形 $ABCD$ 的面积。

**思路**：图形不规则（"风筝"形），但出现 $AB = BC$ + $\angle ABC = 60°$ → 等边信号。把 $\triangle ABD$ 绕 $B$ 旋转使 $A \to C$（旋转 $60°$）。

**计算**：
- 旋转后 $A \to C$、$D \to D'$。则 $\triangle ABD \cong \triangle CBD'$，$CD' = AD = 3$，$BD' = BD$，$\angle BCD' = \angle BAD = 90°$。
- 由于 $\angle BCD = 90°$ 且 $\angle BCD' = 90°$ → $D, C, D'$ **三点共线**，且 $DD' = DC + CD' = 5 + 3 = 8$。
- $\triangle BDD'$ 中 $BD = BD'$、$\angle DBD' = 60°$ → **等边三角形**，所以 $BD = 8$。
- 四边形 $ABCD$ 面积 = $\triangle ABD$ 面积 $+ \triangle BCD$ 面积 $= \triangle CBD'$ 面积 $+ \triangle BCD$ 面积 $= \triangle BDD'$ 面积 $= \dfrac{\sqrt{3}}{4} \cdot 8^2 = \boxed{16\sqrt{3}}$。

**关键**：旋转把不规则四边形整体"拼装"成一个等边三角形——面积秒得。

## 七、思路自测题

1. 正方形 $ABCD$ 内一点 $P$，$PA = \sqrt{2}, PB = 1, PC = \sqrt{2}$。求 $\angle APB$。【提示】绕 $B$ 旋转 $90°$，把 $\triangle BPC$ 转过去。

2. 等边三角形 $\triangle ABC$ 内一点 $P$，$PA = 3, PB = 4, PC = 5$。求 $\angle APB$。【提示】绕 $A$ 或 $B$ 旋转 $60°$，使 $3$-$4$-$5$ 勾股数集中到一个三角形里。

3. $\triangle ABC$ 中 $AB = AC$，$\angle BAC = 90°$，$P$ 为 $\triangle ABC$ 内一点，$PA = 1, PB = \sqrt{5}, PC = \sqrt{2}$。求 $\angle APC$。【提示】绕 $A$ 旋转 $90°$。

4. 等边 $\triangle ABC$ 边长为 $a$，$P$ 是平面内一点（不在边上），$PA = PB + PC$。问：$P$ 与 $\triangle ABC$ 的位置关系是什么？【提示】旋转 $60°$ 后利用三点共线条件。

---

**回顾**：旋转构造模型的核心是"等长边 + 特殊角 → 旋转 → 集中条件 → 勾股 / 等边 / 全等收尾"。它把 cong/03（手拉手）与 cong/04（半角）统一到同一思想下——只要看到"等长边 + 特定角度 + 分散的待求量"，就启动旋转。
