# 旋转

## 一、图形特征与定义

在平面内，把一个图形绕**一个定点**沿**某一方向**（顺时针或逆时针）**转过一定的角度**，得到的新图形与原图形形状、大小都不变，但位置、朝向通常会改变——这样的图形变换叫做**旋转**。

旋转由三个要素**唯一确定**：

- **旋转中心** $O$：图形围绕的那个定点，它在旋转过程中**位置保持不动**。
- **旋转方向**：顺时针或逆时针，二者方向相反。
- **旋转角**：原图形上任意一点 $A$ 与其对应点 $A'$ 分别和旋转中心 $O$ 连线后所夹的角 $\angle AOA'$，对图形上所有点都是同一个角度。

> 一句话定义：**旋转 = 一个中心 + 一个方向 + 一个角度**。给定 $O$、方向、角 $\alpha$ 三要素，整个图形上每一点 $A$ 都"绕 $O$ 转过 $\alpha$"得到 $A'$，所有这些 $A'$ 拼起来就是原图形的旋转像。

与平移（part6/02）、轴对称（part6/01）并列，**旋转同样属于"刚性运动"**——它保持图形的形状和大小，但与平移不同的是：旋转改变图形的**朝向**（每条线段都转了同一个角度）；与翻折也不同：旋转不会产生镜像（图形仍然"同手性"，不会出现"左右反转"）。

旋转中心 $O$ 可以在图形**内部**、**外部**或图形**之上**（如某顶点）；不同的中心、不同的角度，会得到完全不同的旋转效果。中考题里最常见的是"绕某顶点旋转 $60°$、$90°$、$120°$、$180°$"。

## 二、基本性质

设原图形上一点 $A$ 经旋转后落到点 $A'$，原图形上另一点 $B$ 经同一旋转落到点 $B'$，旋转中心为 $O$、旋转角为 $\alpha$。由定义可总结出：

1. **旋转后的图形与原图形全等**：旋转是刚性运动，对应线段相等、对应角相等、对应图形全等。
2. **对应点到旋转中心的距离相等**：$OA = OA'$、$OB = OB'$——每一对对应点都在以 $O$ 为圆心的同一个圆上。这是旋转最具识别度的"指纹"。
3. **对应点与旋转中心连线所成的角都等于旋转角**：$\angle AOA' = \angle BOB' = \alpha$，**方向**也一致（同为顺时针或同为逆时针）。
4. **对应线段相等、对应角相等，并且对应线段之间的夹角等于旋转角**：原图形里的线段 $AB$ 与它的像 $A'B'$ 之间的夹角恰为 $\alpha$（或其补角 $180° - \alpha$，看怎么测量）；这一性质在"旋转构造模型"里非常关键。

> 把这几条压成一句话记忆：**"绕 $O$ 旋转 $\alpha$ = 全等 + $OA = OA'$ + $\angle AOA' = \alpha$"**。其中"对应点到中心等距 + 张角等于旋转角"是判定与构造旋转的两条核心抓手。

反过来，这一组性质也给了我们一条**判定**：如果两个图形上的所有对应点 $A \leftrightarrow A'$ 都满足 $OA = OA'$ 且 $\angle AOA' = \alpha$（同一方向、同一角度），那么这两个图形就是绕 $O$ 旋转 $\alpha$ 的关系。

**特殊角的旋转**值得单独记忆：

- 旋转 $180°$ —— 等价于"中心对称"（part6/04 将专题讲解）。
- 旋转 $90°$ —— 在正方形、等腰直角三角形里出现频率最高，常和"半角模型"（cong/04）配合。
- 旋转 $60°$ —— 在等边三角形里出现频率最高，常和"手拉手模型"（cong/03）配合。

## 三、坐标系中的旋转（特殊情形）

中考阶段重点掌握**以原点 $O$ 为旋转中心**的三种特殊角度：

> 设 $P(x, y)$，则：
> - 绕 $O$ **逆时针**旋转 $90°$ 后得到 $P'(-y, x)$；
> - 绕 $O$ **顺时针**旋转 $90°$ 后得到 $P'(y, -x)$；
> - 绕 $O$ 旋转 $180°$ 后得到 $P'(-x, -y)$。

记忆办法：旋转 $90°$ 时坐标"交换 + 一个符号"；旋转 $180°$ 时坐标"两个都变号"（对应中心对称）。

可以用一个具体例子直接验证：$P(3, 1)$ 到原点的距离是 $\sqrt{10}$，逆时针 $90°$ 后变 $P'(-1, 3)$，到原点距离仍为 $\sqrt{10}$、$\vec{OP}$ 与 $\vec{OP'}$ 恰好垂直——既保等距、又保旋转角，性质 2、3 同时验证通过。

## 四、典型应用

### 例 1（基础：特殊角度的坐标旋转）

> 已知 $A(2, 3)$，求 $A$ 绕原点分别**逆时针旋转 $90°$**、**顺时针旋转 $90°$**、**旋转 $180°$** 后所得三个点 $A_1, A_2, A_3$ 的坐标。

**思路**：直接套用上一节的坐标公式。

- 逆时针 $90°$：$A_1(-3, 2)$。
- 顺时针 $90°$：$A_2(3, -2)$。
- 旋转 $180°$：$A_3(-2, -3)$。

**验证**：三者到原点距离都等于 $\sqrt{2^2 + 3^2} = \sqrt{13}$，与 $OA$ 等长，符合性质 2；同时 $\vec{OA} \cdot \vec{OA_1} = 2\cdot(-3) + 3\cdot 2 = 0$，$\vec{OA}$ 与 $\vec{OA_1}$ 垂直，符合"旋转角 $= 90°$"。

> 中考做题习惯：一旦看到"绕原点旋转 $90°/180°$"，先按公式秒写坐标，再用"到原点等距"做一遍快速验证。

### 例 2（旋转构造全等：把分散的元素集中）

> 在正方形 $ABCD$ 内一点 $P$，已知 $PA = 1, PB = 2$，且 $\angle APB = 135°$。求 $PD$ 的长度。

**思路**：典型"分散 → 集中"信号——三段长度落在不同三角形里。正方形里有"边长相等 + 直角"的天然结构，**绕 $A$ 把 $\triangle ABP$ 顺时针旋转 $90°$**：因为 $AB = AD$，所以 $B \to D$，$P \to P'$。

由旋转性质：
- $AP' = AP = 1$、$DP' = BP = 2$；
- $\angle PAP' = 90°$，所以 $\triangle PAP'$ 是**等腰直角三角形**，$PP' = \sqrt{2}$，$\angle AP'P = 45°$。

又 $\angle APB = 135°$，旋转把 $\angle APB$ 整体搬到 $\angle AP'D = 135°$（旋转保角）。所以
$$\angle PP'D = \angle AP'D - \angle AP'P = 135° - 45° = 90°.$$

在 $\triangle PP'D$ 中由勾股定理：
$$PD^2 = PP'^2 + P'D^2 = (\sqrt{2})^2 + 2^2 = 2 + 4 = 6,$$
所以 $PD = \sqrt{6}$。

> **收益**：通过一次 $90°$ 旋转，把原本散落在 $\triangle APB$ 和"目标段 $PD$"两处的条件集中到了一个可计算的 $\triangle PP'D$ 中。这正是 part6/07"旋转构造模型"将要系统抽象的核心套路（同时也是 cong/04 半角模型的来源）。

### 例 3（等边三角形 + $60°$ 旋转：手拉手的来源）

> 等边三角形 $\triangle ABC$ 外一点 $D$，连 $DA, DB, DC$。把 $\triangle ABD$ 绕 $A$ 逆时针旋转 $60°$，使 $B \to C$，$D \to D'$。说明 $\triangle ADD'$ 是等边三角形，并由此证明 $CD' = BD$、$DD' = DA$。

**思路**：旋转角恰为等边三角形的顶角 $60°$，所以 $B$ 转到 $C$。由旋转性质：

- $AD = AD'$（对应线段相等），$\angle DAD' = 60°$（张角等于旋转角）；
- $AD = AD'$ 加 $\angle DAD' = 60°$，即"两边相等、夹角 $60°$"——$\triangle ADD'$ 是**等边三角形**，于是 $DD' = AD = AD'$。
- $\triangle ABD \cong \triangle ACD'$（旋转得到的全等），所以 $CD' = BD$。

这一段构造**正是"手拉手模型"**（cong/03）的本质：等边三角形 + 一个 $60°$ 的旋转，自然制造出"$BD = CD'$、$DD' = DA$"两组等长。中考综合题里出现"等边三角形 + 外一点距三顶点距离"几乎都用这种思路。

> 类似地：**正方形 + $90°$ 旋转 → 半角模型**；**等腰顶角 $\alpha$ + 旋转角 $\alpha$ → 一般化的手拉手**。三者本质都是同一招：用旋转把"分散在多个三角形里的边和角"重新摆到一起。这条统一视角将在 part6/07 系统展开。

## 五、易错点

1. **旋转的三要素缺一不可**：旋转中心、旋转方向、旋转角度——三者中任何一个改变，旋转结果都不同。题目说"旋转 $60°$"必须再确认顺/逆时针。
2. **旋转中心位置不固定**：可以在图形内、外或图形上；做题时一定**先标出旋转中心**再分析对应点。
3. **旋转 $\neq$ 平移、$\neq$ 翻折**：旋转会改变线段的方向（每条线段转过同一个角度），但不会像翻折那样产生镜像；不要把"绕某点旋转 $180°$"误当成"沿某直线翻折"——两者对图形朝向的影响不同。
4. **旋转角 = 对应点张角，不是对应线段夹角**：定义中的旋转角是 $\angle AOA'$（点对中心的张角），不是 $AB$ 与 $A'B'$ 这两条**线段之间**的夹角（虽然后者也等于 $\alpha$，但容易混淆"角的位置"）。
5. **坐标公式只对"绕原点"成立**：若旋转中心不是原点，需要先把图形平移使旋转中心落到原点，旋转后再平移回去——这就是"平移 + 旋转"的组合，中考偶有出现。

## 六、自测题

1. 已知点 $P(-1, 4)$，将 $P$ 绕原点**顺时针旋转 $90°$** 得到点 $P_1$，再将 $P_1$ 绕原点**旋转 $180°$** 得到点 $P_2$。求 $P_2$ 的坐标。
   - 💡 提示：顺时针 $90°$ 公式 $(x, y) \to (y, -x)$，得 $P_1(4, 1)$；旋转 $180°$ 公式 $(x, y) \to (-x, -y)$，得 $P_2(-4, -1)$。验证：两次合成相当于"顺时针 $90°$ + $180°$ = 顺时针 $270°$ = 逆时针 $90°$"，直接用逆时针 $90°$ 公式 $(x, y) \to (-y, x)$ 代入 $P(-1, 4)$ 也得 $(-4, -1)$，一致。

2. 在 $\triangle ABC$ 中，$\angle BAC = 90°$，$AB = AC$。点 $D$ 在 $BC$ 上，将 $\triangle ABD$ 绕 $A$ 逆时针旋转 $90°$，使 $B \to C$。设 $D$ 的对应点为 $D'$，证明：$CD' \perp BC$，且 $CD' = BD$。
   - 💡 提示：由旋转性质 $AD = AD'$、$\angle DAD' = 90°$、$\triangle ABD \cong \triangle ACD'$。从而 $CD' = BD$；并由 $\angle ACD' = \angle ABD = 45°$，加上 $\angle ACB = 45°$，得 $\angle BCD' = \angle ACD' + \angle ACB = 90°$，即 $CD' \perp BC$。这道题的本质是"等腰直角三角形 + $90°$ 旋转"——为 part6/07 旋转构造模型铺垫。

3. 等边三角形 $\triangle ABC$ 内一点 $P$，满足 $PA = 3, PB = 4, PC = 5$。求 $\angle APB$ 的度数。
   - 💡 提示：等边 + 内点三距离，标准 $60°$ 旋转套路（呼应例 3）。绕 $B$ 把 $\triangle BPC$ 顺时针旋转 $60°$，$C \to A$，$P \to P'$。则 $BP' = BP = 4$、$\angle PBP' = 60°$ → $\triangle PBP'$ 等边，$PP' = 4$、$\angle BPP' = 60°$。又 $AP' = CP = 5$，在 $\triangle APP'$ 中三边为 $AP = 3, PP' = 4, AP' = 5$，恰为勾股数 → $\angle APP' = 90°$。所以 $\angle APB = \angle APP' + \angle P'PB = 90° + 60° = 150°$。

4. 把抛物线 $y = x^2$ 上的点 $A(1, 1)$ 绕原点逆时针旋转 $90°$，得到点 $A'$。判断 $A'$ 是否仍在该抛物线上；若不在，写出 $A'$ 应满足的轨迹（仍可以用一个简单的方程描述）。
   - 💡 提示：逆时针 $90°$ 公式 $(x, y) \to (-y, x)$，得 $A'(-1, 1)$。验证 $y = x^2$：当 $x = -1$ 时 $y = 1$ ✓，所以**仍在抛物线上**（这是因为 $y = x^2$ 关于 $y$ 轴对称，而绕原点逆时针 $90°$ 把第一象限点 $(1,1)$ 映到第二象限对应点；但一般来说，绕原点 $90°$ 旋转把抛物线 $y = x^2$ 整体变成了"开口向左"的抛物线 $x = -y^2$——本题中的两个点恰好同时在原抛物线和新抛物线上，是个有趣的巧合）。这道题用于让学生把"坐标旋转"与"函数图象"联系起来，为 part9 二次函数综合做铺垫。
