# 中心对称

## 一、图形特征与定义

把一个图形绕**平面内一个定点 $O$** 旋转 $180°$ 后，能与**另一个图形**完全重合——这两个图形就叫做关于点 $O$ **中心对称**，点 $O$ 叫做**对称中心**，对应的两个点互称**关于 $O$ 的对称点**。

如果把"另一个图形"换成"它自己"——也就是一个图形绕某点 $O$ 旋转 $180°$ 后能与**自身重合**——那么这个图形本身就叫做**中心对称图形**，$O$ 仍叫对称中心。

> 一句话定义：**中心对称 = 绕一个点旋转 $180°$ 能重合**。

把上一节学过的旋转拿来对照，就会发现一个关键认识：

> **中心对称是旋转的特殊情况——旋转中心 = 对称中心，旋转角恰好等于 $180°$**。

正因为如此，中心对称会继承"旋转"的所有性质（part6/03），同时由于角度被固定为 $180°$，又比一般旋转多出几条非常好用的"专属性质"。

并且要区分两个相似但不同的概念：

- **两个图形关于点 $O$ 中心对称**：讲的是两个分开的图形之间的位置关系。
- **中心对称图形**：讲的是**一个**图形自己的对称性——它自己跟自己关于某点中心对称。

这一对概念的区分，与 part6/01 里"两个图形关于一条直线轴对称" vs "轴对称图形"的二元结构完全平行。

## 二、基本性质

设点 $A$ 关于对称中心 $O$ 的对称点是 $A'$，点 $B$ 关于 $O$ 的对称点是 $B'$。

1. **对称中心是对应点连线段的中点**：$O$ 是 $AA'$ 的中点，也是 $BB'$ 的中点。换句话说，$OA = OA'$、$OB = OB'$，且 $A, O, A'$ 三点共线。
2. **对应线段平行（或共线）且相等**：原图形里的线段 $AB$ 与它的像 $A'B'$ **平行**（或共线）、并且**长度相等**，$AB = A'B'$。
3. **对应角相等**，对应图形**全等**（继承自旋转）。
4. **方向相反**：注意对应线段虽然平行且相等，但方向是"反着的"——这是中心对称区别于平移最显著的地方（平移的对应线段同向，中心对称反向）。

把性质 1、2 压成口诀：

> **"中心对称 = 对应点被对称中心平分 + 对应线段平行且反向相等"**。

性质 1 同时也给出一条**判定**：

> 若两图形上任意一对对应点的连线都**经过同一点 $O$** 并被 $O$ 平分，则这两个图形关于 $O$ 中心对称。

## 三、坐标系中的中心对称

把中心对称放进直角坐标系，最常用的情形是"对称中心是坐标原点"：

> 点 $P(x, y)$ 关于原点 $O(0, 0)$ 的对称点是
> $$P'(-x,\ -y).$$

直观地讲——绕原点旋转 $180°$，横纵坐标都"取相反数"。如果对称中心不是原点，而是某一般点 $M(a, b)$，则

$$P(x, y) \xrightarrow{\text{关于 } M \text{ 中心对称}} P'(2a - x,\ 2b - y),$$

因为 $M$ 是 $PP'$ 中点，由中点公式直接得出 $\frac{x + x'}{2} = a, \frac{y + y'}{2} = b$。

## 四、中心对称图形

满足"绕某点旋转 $180°$ 与自身重合"的图形就是**中心对称图形**。常见中心对称图形及其对称中心如下：

| 图形 | 是否中心对称 | 对称中心 |
|---|---|---|
| 平行四边形 | 是 | 两条对角线交点 |
| 矩形 | 是 | 两条对角线交点 |
| 菱形 | 是 | 两条对角线交点 |
| 正方形 | 是 | 两条对角线交点 |
| 圆 | 是 | 圆心 |
| 正六边形（一般地，偶数边正多边形） | 是 | 中心 |
| 等腰三角形（非等边） | 否 | —— |
| 等边三角形 | 否 | —— |
| 正五边形（一般地，奇数边正多边形） | 否 | —— |
| 等腰梯形 | 否 | —— |

> 一个常被记混的对比：
>
> - 等腰三角形：**是轴对称**（底边的垂直平分线），**不是中心对称**。
> - 平行四边形：**不是轴对称**（一般情形），**是中心对称**（对角线交点）。
>
> 两个例子刚好"互补"，很适合用来区分这两类对称。

矩形、菱形、正方形则**既是轴对称又是中心对称**——它们的对称中心都是对角线交点。

## 五、典型应用

### 例 1（作中心对称点）

> 已知点 $A(3, -2)$ 和对称中心 $O(1, 1)$。求 $A$ 关于 $O$ 的对称点 $A'$。

**思路**：用"$O$ 是 $AA'$ 中点"这条最核心的性质，套中点坐标公式：

$$A'(2 \cdot 1 - 3,\ 2 \cdot 1 - (-2)) = A'(-1,\ 4).$$

> 验证：$\frac{3 + (-1)}{2} = 1 = x_O$，$\frac{-2 + 4}{2} = 1 = y_O$，符合中点公式。

### 例 2（判断常见图形是否中心对称）

> 下列图形中，**既是轴对称图形又是中心对称图形**的是哪几个？
>
> ① 等腰三角形；② 平行四边形；③ 矩形；④ 等边三角形；⑤ 菱形；⑥ 正方形；⑦ 圆；⑧ 等腰梯形。

**思路**：把每个图形分别按"是否轴对称""是否中心对称"两栏过一遍。

| 图形 | 轴对称 | 中心对称 | 两者都是？ |
|---|---|---|---|
| ① 等腰三角形 | 是 | 否 | 否 |
| ② 平行四边形 | 否 | 是 | 否 |
| ③ 矩形 | 是 | 是 | **是** |
| ④ 等边三角形 | 是 | 否 | 否 |
| ⑤ 菱形 | 是 | 是 | **是** |
| ⑥ 正方形 | 是 | 是 | **是** |
| ⑦ 圆 | 是 | 是 | **是** |
| ⑧ 等腰梯形 | 是 | 否 | 否 |

**答案**：③ 矩形、⑤ 菱形、⑥ 正方形、⑦ 圆——共 4 个。

> 收益：这种"分类对照表"是中考选择题的常客，关键是不要把"等腰三角形" "平行四边形"两个"半成品"记混。

### 例 3（综合：平行四边形的对称中心是对角线交点）

> 证明：平行四边形 $ABCD$ 是中心对称图形，并指出它的对称中心。

**思路**：要证它是中心对称图形，就要找一个点 $O$，使得绕 $O$ 旋转 $180°$ 后图形与自身重合。最自然的候选——**两条对角线的交点 $O$**。

1. 由平行四边形性质（part4），对角线 $AC$ 与 $BD$ **互相平分**，所以 $O$ 既是 $AC$ 的中点，也是 $BD$ 的中点。
2. 由"中点"的含义——$O$ 是 $A, C$ 的对称中心：$A \to C, C \to A$；同样 $O$ 是 $B, D$ 的对称中心：$B \to D, D \to B$。
3. 绕 $O$ 旋转 $180°$ 后：$A \to C, B \to D, C \to A, D \to B$。整个平行四边形 $ABCD$ 变换为 $CDAB$——这与原图形完全是同一个平行四边形（顶点轮换、形状不变）。

所以 $ABCD$ 关于 $O$ 中心对称，**对称中心就是两条对角线的交点**。

> 这个例子还可以反过来"用"：在平行四边形里只要找到对角线交点 $O$，就立刻可以借中心对称把图形里一边的结构"对调"到另一边——例如把 $\triangle OAB$ 整体复制到 $\triangle OCD$ 上，从而把两个三角形里的条件汇总到一起（呼应 thinking-toolkit/04 转化 5 "分散→集中"）。

## 六、易错点

1. **中心对称 ≠ 轴对称**：等腰三角形是轴对称但不是中心对称；平行四边形是中心对称但不是轴对称——刚好"互补"，不要混淆。
2. **中心对称是绕"点"旋转 $180°$**：旋转中心是"一个点"，不是"一条线"——这与轴对称的"轴是一条直线"形成对照。
3. **对应线段平行且相等，但方向相反**：这是中心对称与平移的关键区别——平移对应线段同向，中心对称反向。
4. **判定要点**：必须验证**任意一对**对应点连线都过同一个 $O$ 并被 $O$ 平分；只看一对对应点是不够的。
5. **对称中心不一定在图形内部**：两个分开的图形关于某点中心对称时，对称中心可以在两个图形"中间"的空地上。

## 七、自测题

1. 已知点 $A(-3, 5)$，求 $A$ 关于原点 $O$ 的对称点 $A'$ 的坐标。
   - 💡 提示：横纵坐标都取相反数，$A'(3, -5)$。

2. 已知点 $B(4, -1)$ 关于点 $M(1, 2)$ 中心对称的对应点为 $B'$，求 $B'$ 的坐标。
   - 💡 提示：用中点公式反推：$B'(2 \cdot 1 - 4,\ 2 \cdot 2 - (-1)) = B'(-2, 5)$。

3. 下列说法中正确的是哪几个？
   ① 中心对称的两个图形一定全等；
   ② 全等的两个图形一定中心对称；
   ③ 中心对称的两个图形对应线段平行且相等；
   ④ 等腰三角形是中心对称图形；
   ⑤ 平行四边形既是轴对称图形又是中心对称图形。
   - 💡 提示：① 对（中心对称 = 旋转 $180°$ → 全等）；② 错（全等只保证形状大小相同，未必能用一次中心对称重合）；③ 对（中心对称的核心性质）；④ 错（等腰三角形只是轴对称）；⑤ 错（一般平行四边形只是中心对称、不是轴对称）。正确的是 ①③。

4. 在平行四边形 $ABCD$ 中，对角线 $AC$ 与 $BD$ 交于点 $O$，点 $P$ 在边 $AB$ 上。请在边 $CD$ 上指出 $P$ 关于 $O$ 的对称点 $P'$ 的位置，并说明 $\triangle OPB \cong \triangle OP'D$。
   - 💡 提示：由例 3，$O$ 是平行四边形的对称中心，绕 $O$ 旋转 $180°$ 后 $A \to C, B \to D$，所以 $AB \to CD$。$P$ 是 $AB$ 上一点 → $P'$ 是 $CD$ 上对应的点，且满足 $DP' = BP$（中心对称对应线段相等）。$\triangle OPB$ 与 $\triangle OP'D$：$OP = OP'$（$O$ 平分 $PP'$）、$OB = OD$（对角线互相平分）、$\angle POB = \angle P'OD$（对顶角），由 SAS 全等。也可以直接由"$\triangle OPB$ 整体绕 $O$ 旋转 $180°$ 重合到 $\triangle OP'D$"一步说明。
