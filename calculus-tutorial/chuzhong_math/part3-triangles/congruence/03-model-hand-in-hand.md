# 手拉手模型

> **一图速记**：两个等腰三角形共顶点（顶角相等）→ 两腰端点的连线相等，两条连线之间的夹角 = 顶角。这就是手拉手。

## 一、引入：一道让你卡住的题

> **题目**：$\triangle OAB$ 和 $\triangle OCD$ 都是等腰三角形，$OA = OB$，$OC = OD$，$\angle AOB = \angle COD = 50°$。点 $A, B, C, D$ 位置使得整个图形为标准"手拉手"形态（$\triangle OCD$ 在 $\triangle OAB$ 的内部或外部均可，$C$ 在 $\angle AOB$ 内部一侧）。求证：$AC = BD$。

请先停下来，自己动笔试一分钟。

大多数读者会卡在这里：**条件给的是 $OA=OB$、$OC=OD$，要证的却是 $AC$ 和 $BD$。$AC$ 和 $BD$ "看起来"不在同一个明显的三角形里**，于是不知道该选哪两个三角形去套全等。

这一卡，就是手拉手模型存在的全部意义。

## 二、思维路径还原（解题者的内心独白）

下面是一个"会做这道题的人"脑子里真正在跑的念头。请你跟着读一遍，体会**每一步是怎么自然冒出来的**：

> "看到要证 $AC = BD$，两段线段相等 —— 第一反应：**找两个全等三角形，让 $AC$ 和 $BD$ 作对应边**。这是初中几何的标准条件反射。
>
> 但 $AC$ 和 $BD$ 不在题目"明摆着"的两个三角形（$\triangle OAB$、$\triangle OCD$）里啊…… 怎么办？**别慌，自己去找。要证哪两段相等，就把这两段所在的三角形画出来。**
>
> $AC$ 在哪个三角形里？最自然的：$\triangle AOC$。$BD$ 在哪个三角形里？$\triangle BOD$。**好，候选目标锁定：证 $\triangle AOC \cong \triangle BOD$。**
>
> 现在去凑条件。手头有什么？$OA = OB$（等腰 $\triangle OAB$ 给的），$OC = OD$（等腰 $\triangle OCD$ 给的）。**两组对应边到手了**——分别是这两个候选三角形的两条边，太巧了。
>
> 还差一个。SAS 需要这两组边的**夹角**：$\angle AOC$（在 $\triangle AOC$ 里夹 $OA, OC$）和 $\angle BOD$（在 $\triangle BOD$ 里夹 $OB, OD$）。它们相等吗？
>
> 直接看：不一定。两个角分别长在两边，没办法用"对顶角""同位角"一类的现成结论。**但是它们可以拆。**
>
> 看图：$\angle AOC$ 是从 $OA$ 转到 $OC$ 的角，正好 $= \angle AOB + \angle BOC$（中间经过 $OB$）；$\angle BOD$ 是从 $OB$ 转到 $OD$ 的角，正好 $= \angle BOC + \angle COD$（中间经过 $OC$）。
>
> 两个等式右边都有 $\angle BOC$——**这是公共的那一段**。而 $\angle AOB = \angle COD = 50°$ 是已知的。所以 $\angle AOC = \angle BOD$。
>
> 这就是经典的**等量加同一项**：两个相等的角，各加上同一个角，结果仍然相等。
>
> 凑齐了：$OA = OB$、$\angle AOC = \angle BOD$、$OC = OD$，**SAS**！$\triangle AOC \cong \triangle BOD$，对应边 $AC = BD$。证毕。"

把这段内心独白读三遍。你会发现**真正难的不是写证明，而是**：
1. 敢于"自己去找"$AC$ 和 $BD$ 所在的三角形（$\triangle AOC$、$\triangle BOD$），而不是死盯题目给的那两个等腰三角形；
2. 看到差一个角时，知道用"**等量加同一项**"去凑。

## 三、抽象成模型

把上面这道具体题的"骨架"抽出来，就是**手拉手模型**。

**图形特征**（识别条件，三条全部满足才算）：

- 有**两个**等腰三角形：$\triangle OAB$（$OA = OB$）和 $\triangle OCD$（$OC = OD$）；
- 两个三角形**共顶点 $O$**（顶角的顶点重合）；
- 两个**顶角相等**：$\angle AOB = \angle COD$。

**核心结论**（看到上述特征就立刻有）：

- $\triangle AOC \cong \triangle BOD$（SAS）；
- $AC = BD$（对应边相等）；
- $AC$ 与 $BD$ 的**夹角** $= \angle AOB$（即两个等腰三角形的共同顶角，也叫"旋转角"）。

**为什么叫"手拉手"**：把 $A, B$ 想成一个人的两只手，$C, D$ 想成另一个人的两只手，$O$ 是他们靠在一起的肩膀；$AC$ 和 $BD$ 就是两人的"左手拉左手、右手拉右手"。

**证明骨架（一句话版）**：用"**等量加同一项**" $\angle AOB + \angle BOC = \angle BOC + \angle COD$，凑出 $\angle AOC = \angle BOD$；配合 $OA = OB$、$OC = OD$，套 SAS 即可。

## 四、模型变形

手拉手在中考里几乎从不"原样"出现，永远以下面这些**变形**面孔示人：

- **变形 1（等边版）**：两个等腰退化为**两个等边三角形**。此时顶角自动 $= 60°$，旋转角 $= 60°$。这是最常考的版本。
- **变形 2（等腰直角版）**：两个等腰退化为**两个等腰直角三角形**，顶角 $= 90°$，旋转角 $= 90°$。**重要副产品：$AC \perp BD$**（因为 $BD$ 是 $AC$ 绕 $O$ 转 $90°$ 得到的）。
- **变形 3（位置变化）**：$\triangle OCD$ 可以在 $\triangle OAB$ 的**外部**，也可以**部分嵌入**内部，甚至**翻转**到另一侧——只要"共顶点 + 顶角相等"满足，证法**一字不变**。
- **变形 4（隐藏版）**：题目不明说"等腰"，但通过其他条件（中点、角平分线、对称等）可以**推出** $OA = OB$、$OC = OD$。这种题考的就是"识别能力"。
- **本质**：手拉手 = "**旋转构造全等**"。把 $\triangle OCD$ 看成 $\triangle OAB$ 绕 $O$ 旋转某个角度——旋转保持长度和夹角，所以"两个等腰共顶点且顶角相等"才能拼起来。**理解到这一层，所有变形就是同一件事。**

## 五、思考路标（看到 X → 想到 Y）

这一节是本章的"反射弧训练"。把下面每一条都嚼到肌肉记忆为止——以后做题不用"想"，是"条件反射"。

- 看到**两个共顶点的等腰三角形**（且顶角相等）→ **手拉手**，立刻去证 $\triangle AOC \cong \triangle BOD$；
- 看到题中出现 $60°$ + 等边三角形（且两个共顶点）→ 手拉手 + 旋转 $60°$，两腰端点连线相等且夹角 $60°$；
- 看到题中出现 $90°$ + 等腰直角三角形（且两个共顶点）→ 手拉手 + 旋转 $90°$，**且 $AC \perp BD$**（这条经常作为题目要证的结论）；
- 要证**两段线段相等**，且图中有**共顶点的等腰结构** → 不要死盯题目给的三角形，**自己去找包含这两段的两个三角形**，用 SAS；
- 想用 SAS 但**差一个角**，且两个候选角都"夹着公共部分" → 试 **等量加同一项**（或等量减同一项）；
- 看到"**绕某点旋转**"得到新图形 → 旋转角 $\ne 0$ 时，原图与新图就构成天然手拉手；
- 看到题目要证 $\perp$（垂直）且图中有等腰直角共顶点结构 → 几乎一定走手拉手 + 旋转 $90°$ 这条路。

## 六、应用例题

下面三例不写完整证明，只演示"**怎么用路标识别 + 怎么把模型套上去**"，请你照着把证明补完。

**例 1（等边版）**：$\triangle OAB$ 和 $\triangle OCD$ 都是等边三角形，共顶点 $O$。求证：$AC = BD$，且 $AC$ 与 $BD$ 的夹角为 $60°$。

> **路标触发**："两个等边共顶点" → 手拉手（顶角 $60°$）。**思路**：$OA = OB$（等边），$OC = OD$（等边），$\angle AOC = \angle AOB + \angle BOC = 60° + \angle BOC = \angle COD + \angle BOC = \angle BOD$；SAS 得 $\triangle AOC \cong \triangle BOD$，故 $AC = BD$，夹角 $= \angle AOB = 60°$。

**例 2（等腰直角版）**：$\triangle OAB$ 和 $\triangle OCD$ 都是等腰直角三角形，$\angle AOB = \angle COD = 90°$，共顶点 $O$。求证：$AC = BD$ 且 $AC \perp BD$。

> **路标触发**："等腰直角共顶点 + 要证 $\perp$" → 手拉手 + 旋转 $90°$。**思路**：前半截同上，SAS 得 $\triangle AOC \cong \triangle BOD$，$AC = BD$。垂直怎么来？设 $AC$ 与 $BD$ 交于 $P$，由全等得 $\angle OAC = \angle OBD$；再在 $\triangle AOP$ 和 $\triangle BPQ$（$Q$ 为 $AC$ 与 $OB$ 的交点）中用"等角代换"得到夹角 $= \angle AOB = 90°$。

**例 3（综合识别题）**：$\triangle OAB$ 中 $OA = OB$，$M$ 是某条边上一点。把 $\triangle OBM$ 绕 $O$ 旋转某个角度得到 $\triangle OCN$（$B \to C$，$M \to N$）。问：旋转角取多少时，$\triangle OAB$ 和 $\triangle OMN$ 恰好构成手拉手模型？

> **路标触发**："旋转 + 共顶点 + 等腰" → 检查手拉手的三条件。**思路**：旋转保持 $OM = ON$（自动等腰）。要构成手拉手，还需"两顶角相等"，即 $\angle MON = \angle AOB$。而 $\angle MON$ 正是旋转角（$M$ 转到 $N$ 转过的角度）。所以**当旋转角等于 $\angle AOB$（即顶角）时**，恰好形成手拉手。这也反过来印证了"手拉手 = 旋转构造全等"的本质。

## 七、思路自测题

做下面四题，做之前先在脑中默念一遍第五节的路标。

**自测 1**：$\triangle OAB$、$\triangle OCD$ 均为等边三角形，共顶点 $O$，$B$、$C$、$D$ 不共线。设 $AC$、$BD$ 交于点 $P$。求 $\angle APB$。

> 💡 提示：先用手拉手得到 $\triangle AOC \cong \triangle BOD$；再把 $\angle APB$ 转化为三角形外角，用"对应角相等"代换。答案应该是顶角 $60°$。

**自测 2**：在 $\triangle ABC$ 外侧分别以 $AB$、$AC$ 为腰向外作等腰直角三角形 $\triangle ABD$（$\angle BAD = 90°$）和 $\triangle ACE$（$\angle CAE = 90°$），其中 $AD = AB$，$AE = AC$。求证：$BE = CD$ 且 $BE \perp CD$。

> 💡 提示：题目里**没有明说手拉手**，但你应当**一眼识别**出来——两个等腰直角三角形共顶点 $A$，且顶角都是 $90°$，这就是变形 2。$BE$、$CD$ 就是两腰端点的连线。

**自测 3（隐藏的手拉手）**：在正方形 $ABCD$ 中，$E$ 是 $BC$ 上一点。以 $AE$ 为边在正方形外作正方形 $AEFG$。连接 $DG$。求证：$DG = BE$，且 $DG \perp BE$。

> 💡 提示：图中**没有现成的等腰三角形**，需要你**自己造出共顶点的等腰直角**——把正方形对角线连一半，或注意到 $\triangle ABE$ 和 $\triangle ADG$（如果存在）会有 $AB = AD$、$AE = AG$、$\angle BAE = \angle DAG$（都等于 $90°$ 减去 $\angle DAE$）的结构。这正是手拉手的等腰直角变形——只是"等腰"是由正方形的边和正方形的边共同提供的。识别出 $\triangle ABE$ 与 $\triangle ADG$ 后，SAS 立得。

**自测 4**：$\triangle OAB$ 和 $\triangle OCD$ 都是顶角为 $\alpha$ 的等腰三角形，共顶点 $O$。求证：$AC$ 与 $BD$ 的夹角为 $\alpha$（用一般顶角验证旋转角结论）。

> 💡 提示：先证 $\triangle AOC \cong \triangle BOD$ 得 $\angle OAC = \angle OBD$；设 $AC$、$BD$ 交于 $P$，在 $\triangle APX$（$X$ 为 $OB$ 与 $AC$ 交点）里凑外角，最终发现夹角 $= \angle AOB = \alpha$。这印证了"夹角永远等于顶角"是模型的一般结论。

---

**回头看一眼"一图速记"**：

> 两个等腰三角形共顶点（顶角相等）→ 两腰端点的连线相等，两条连线之间的夹角 = 顶角。

如果现在你脑中能秒回这句话，并且能立刻在脑中画出 $\triangle AOC \cong \triangle BOD$ 的 SAS 三步——那么手拉手模型，你拿下了。
