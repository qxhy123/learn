# 勾股定理

## 一、图形特征

直角三角形 $ABC$，其中 $\angle C = 90^\circ$。

- 两条**直角边**：$a = BC$，$b = AC$。
- 一条**斜边**（即直角所对的边，也是三角形中最长的一条边）：$c = AB$。

直角三角形的三边之间存在一个非常优美的数量关系，这就是勾股定理。在中国古代算书中，较短的直角边称为"勾"，较长的直角边称为"股"，斜边称为"弦"，所以这个定理也叫"勾股弦定理"。

## 二、定理

**直角三角形两直角边的平方和等于斜边的平方**：

$$a^2 + b^2 = c^2 \quad (c\ \text{为斜边})$$

定理的逆命题也成立：如果三角形的三边 $a, b, c$ 满足 $a^2 + b^2 = c^2$，那么该三角形是以 $c$ 为斜边的直角三角形（称为**勾股定理的逆定理**）。

## 三、证明

### 证法 1：赵爽弦图（中国古代证法）

这是三国时期数学家赵爽给出的证法，因其图形被称为"弦图"，国学色彩浓厚。

**构造**：取 $4$ 个全等的直角三角形（两直角边为 $a, b$，斜边为 $c$，不妨设 $a < b$），将它们拼成一个大正方形，使每个三角形的斜边作为大正方形的内嵌小正方形的边。

- 大正方形的边长为 $a + b$，面积为 $(a+b)^2$。
- 大正方形也可以看作：$4$ 个直角三角形 + 中间一个小正方形（边长为 $b - a$，但也可以看作边长为 $c$ 的正方形，取决于拼法。这里采用经典拼法：四个三角形的斜边围成中间的小正方形，边长为 $c$）。
- 这种拼法下，大正方形面积 = $4 \cdot \dfrac{1}{2}ab + c^2 = 2ab + c^2$。

**列等式**：

$$(a+b)^2 = 2ab + c^2$$

展开左边：

$$a^2 + 2ab + b^2 = 2ab + c^2$$

两边同时减去 $2ab$，得到：

$$\boxed{a^2 + b^2 = c^2}$$

证毕。

### 证法 2：利用射影定理（呼应 similarity/03）

**构造**：在直角三角形 $ABC$ 中（$\angle C = 90^\circ$），过 $C$ 作斜边 $AB$ 上的高 $CD$，垂足为 $D$。设 $AD = p$，$BD = q$，则 $p + q = c$。

由射影定理（见相似一节）：

$$b^2 = AC^2 = AD \cdot AB = p \cdot c$$
$$a^2 = BC^2 = BD \cdot AB = q \cdot c$$

两式相加：

$$a^2 + b^2 = pc + qc = (p+q)c = c \cdot c = c^2$$

证毕。

这种证法体现了"高线—相似—射影—勾股"的知识链。

## 四、典型应用

### 例 1：求斜边

已知直角三角形两直角边 $a = 3$，$b = 4$，求斜边 $c$。

**【思路】**直接套用勾股定理 $c^2 = a^2 + b^2$，开方取正即可。

**【解】**

$$c^2 = 3^2 + 4^2 = 9 + 16 = 25$$
$$c = 5$$

### 例 2：求直角边

已知直角三角形斜边 $c = 13$，一直角边 $a = 5$，求另一直角边 $b$。

**【思路】**已知斜边和一条直角边，由 $b^2 = c^2 - a^2$ 求另一条直角边。

**【解】**

$$b^2 = c^2 - a^2 = 169 - 25 = 144$$
$$b = 12$$

### 例 3：折叠题

如图，长方形纸片 $ABCD$ 中，$AB = 6$，$BC = 8$。将矩形沿对角线 $BD$ 折叠，点 $A$ 落到点 $A'$ 处，$A'B$ 与边 $CD$ 相交于点 $E$。求重叠部分 $\triangle BDE$ 的面积。

**【思路】**折叠是轴对称变换，对应角、对应边相等：$\angle ABD = \angle A'BD$。又因为 $AB \parallel CD$，所以 $\angle ABD = \angle BDE$（内错角），从而 $\angle A'BD = \angle BDE$，于是 $\triangle BDE$ 是**等腰三角形**：$BE = DE$。设 $DE = x$，则 $CE = CD - DE = 6 - x$，$BE = x$。在 $\mathrm{Rt}\triangle BCE$ 中应用勾股定理列方程。

**【解】**设 $DE = BE = x$，则 $CE = 6 - x$。在 $\mathrm{Rt}\triangle BCE$（$\angle C = 90^\circ$）中：

$$BC^2 + CE^2 = BE^2$$
$$8^2 + (6-x)^2 = x^2$$
$$64 + 36 - 12x + x^2 = x^2$$
$$100 - 12x = 0$$
$$x = \frac{25}{3}$$

故重叠部分 $\triangle BDE$ 的面积：

$$S_{\triangle BDE} = \frac{1}{2} \cdot DE \cdot BC = \frac{1}{2} \cdot \frac{25}{3} \cdot 8 = \frac{100}{3}$$

### 例 4：勾股数

满足 $a^2 + b^2 = c^2$ 的**正整数三元组** $(a, b, c)$ 称为**勾股数**。常见的勾股数有：

- $(3, 4, 5)$：最小的勾股数
- $(5, 12, 13)$
- $(8, 15, 17)$
- $(7, 24, 25)$
- $(9, 40, 41)$
- $(20, 21, 29)$

**【思路】**记住这些常见组合，在题目中遇到时能立即识别直角三角形，不必每次都开方计算。

**【应用】**判断边长为 $9, 12, 15$ 的三角形是否为直角三角形。

由于 $(9, 12, 15) = 3 \cdot (3, 4, 5)$，是 $(3,4,5)$ 的 $3$ 倍，所以这是一个直角三角形，其中斜边为 $15$。验证：$9^2 + 12^2 = 81 + 144 = 225 = 15^2$。✓

## 五、易错点

1. **必须先确认是直角三角形**：勾股定理只在直角三角形中成立。在斜三角形中，三边关系由"余弦定理"刻画（高中内容）。
2. **找清楚哪条是斜边**：斜边是直角所对的边，也是三角形中**最长**的边。不要把直角边当成斜边代入公式，否则会算出负数或开方失败。例如已知两条边为 $5$ 和 $13$，要弄清 $13$ 是斜边还是直角边，结论完全不同。
3. **勾股数的倍数仍是直角三角形整数边**：$(3,4,5)$ 的整数倍如 $(6,8,10), (9,12,15), (12,16,20)$ 等都是直角三角形，记住这一点能快速识别。
4. **逆定理使用条件**：判断一个三角形是否为直角三角形，要先检验"两个较小数的平方和等于最大数的平方"，注意必须先排序找出最大边。
5. **折叠题中不要遗漏对称性**：折叠产生的等腰三角形、相等角度往往是解题关键，光列勾股关系不够，要结合相等关系列方程。

## 六、思路自测题

1. 直角三角形两直角边分别为 $6, 8$，求斜边长。说出运用了什么定理与公式。
2. 直角三角形斜边长为 $17$，一直角边为 $8$，求另一直角边。
3. 判断三边为 $7, 24, 25$ 的三角形是不是直角三角形？如果是，斜边是哪条？说说判断依据。
4. 长方形 $ABCD$ 中 $AB = 3$，$BC = 4$，沿对角线 $AC$ 折叠，求重叠三角形的面积。试说出"等腰三角形"在此题中如何被用到。
5. 已知一个直角三角形的两边长分别是 $5$ 和 $12$，求第三条边的长度。注意：本题为什么有两种可能的答案？

> **答案与提示**（仅供核对）：1. $10$；2. $15$；3. 是直角三角形，$25$ 为斜边（$7^2 + 24^2 = 49 + 576 = 625 = 25^2$）；4. 设折叠后重叠的等腰三角形腰长为 $x$，由勾股定理列方程 $x^2 = 3^2 + (4-x)^2$，解得 $x = \dfrac{25}{8}$，面积 $\dfrac{1}{2} \cdot \dfrac{25}{8} \cdot 3 = \dfrac{75}{16}$；5. 两种答案：若 $12$ 为斜边，则第三边为 $\sqrt{144-25} = \sqrt{119}$；若 $5, 12$ 都是直角边，则斜边为 $13$。题目未指明哪条是斜边，故有两解。
