# 特殊直角三角形（30°-60°-90° 与 45°-45°-90°）

## 一、图形特征

在所有直角三角形中，有两类"特殊"的直角三角形，它们的三个内角不仅都是常见的角度（含有 $30°$、$60°$ 或 $45°$），而且三条边的长度之间存在简洁、固定的比例关系。这两类三角形是几何题中最频繁出现的"基本模块"，也是后续三角函数中特殊角函数值（$\sin 30°$、$\cos 45°$ 等）的几何基础。

**两类特殊直角三角形**：

- **30°-60°-90° 直角三角形**：内角分别为 $30°$、$60°$、$90°$
- **45°-45°-90° 直角三角形**（即等腰直角三角形）：内角分别为 $45°$、$45°$、$90°$

掌握这两类三角形的边长比例，能让我们在不依赖三角函数的情况下，仅凭"看图"快速求出未知边长，是初中几何计算的核心技能之一。

---

## 二、两类特殊三角形的边长比

### 1. $30°$-$60°$-$90°$ 直角三角形

三边比为：
$$
\text{短直角边}：\text{长直角边}：\text{斜边} = 1 : \sqrt{3} : 2
$$

具体对应关系：

| 边 | 所对的角 | 比例 |
|---|---|---|
| 短直角边 | $30°$ | $1$ |
| 长直角边 | $60°$ | $\sqrt{3}$ |
| 斜边 | $90°$ | $2$ |

**关键结论（最常用）**：

> **在 $30°$-$60°$-$90°$ 直角三角形中，$30°$ 所对的直角边等于斜边的一半。**

记号化：若 $\angle A = 30°$，$\angle C = 90°$，则
$$
BC = \frac{1}{2} AB.
$$

### 2. $45°$-$45°$-$90°$ 直角三角形（等腰直角三角形）

三边比为：
$$
\text{直角边}：\text{直角边}：\text{斜边} = 1 : 1 : \sqrt{2}
$$

即两条直角边相等，斜边等于直角边乘以 $\sqrt{2}$：
$$
\text{斜边} = \text{直角边} \times \sqrt{2}.
$$

反过来：
$$
\text{直角边} = \frac{\text{斜边}}{\sqrt{2}} = \frac{\sqrt{2}}{2} \cdot \text{斜边}.
$$

## 三、来源（推导）

这两个比例不是凭空给出的，可以通过等边三角形和勾股定理推导。

### 1. $30°$-$60°$-$90°$ 的推导

**作图**：取一个边长为 $2$ 的等边三角形 $\triangle ABC$，从顶点 $A$ 向 $BC$ 作高 $AD$，垂足为 $D$。

**分析**：

- 等边三角形是特殊的等腰三角形（$AB = AC$），由"三线合一"，高 $AD$ 同时是 $BC$ 边上的**中线**与 $\angle BAC$ 的**角平分线**。
- 因此 $BD = CD = 1$，且 $\angle BAD = \dfrac{1}{2} \angle BAC = 30°$。
- 在 $\triangle ABD$ 中：$\angle ABD = 60°$（等边三角形的内角），$\angle ADB = 90°$（高），$\angle BAD = 30°$。

**计算**：在直角三角形 $\triangle ABD$ 中，$BD = 1$，$AB = 2$，由勾股定理：
$$
AD = \sqrt{AB^2 - BD^2} = \sqrt{4 - 1} = \sqrt{3}.
$$

所以三边比为：
$$
BD : AD : AB = 1 : \sqrt{3} : 2.
$$

其中 $BD$（对 $30°$）是短直角边，$AD$（对 $60°$）是长直角边，$AB$（对 $90°$）是斜边。

### 2. $45°$-$45°$-$90°$ 的推导

直接从等腰直角三角形出发。设两条直角边都为 $a$，由勾股定理：
$$
\text{斜边} = \sqrt{a^2 + a^2} = \sqrt{2a^2} = a\sqrt{2}.
$$

因此三边比为 $a : a : a\sqrt{2} = 1 : 1 : \sqrt{2}$。

## 四、典型应用

### 例 1（$30°$-$60°$-$90°$ 已知斜边）

**题目**：在 $\triangle ABC$ 中，$\angle C = 90°$，$\angle A = 30°$，$AB = 10$，求两直角边 $BC$ 与 $AC$。

**【思路】** 直接套用"$30°$ 对的边 = 斜边的一半"。$BC$ 是 $30°$ 角所对的短直角边，长度为斜边的一半；$AC$ 是 $60°$ 所对的长直角边，等于短直角边的 $\sqrt{3}$ 倍。

**解**：
$$
BC = \frac{1}{2} AB = \frac{1}{2} \times 10 = 5,
$$
$$
AC = BC \cdot \sqrt{3} = 5\sqrt{3}.
$$

### 例 2（$45°$-$45°$-$90°$ 已知直角边）

**题目**：在等腰直角三角形 $\triangle ABC$ 中，$\angle C = 90°$，$AC = BC = 3$，求斜边 $AB$。

**【思路】** 等腰直角三角形斜边 = 直角边 $\times \sqrt{2}$，直接代入。

**解**：
$$
AB = 3\sqrt{2}.
$$

### 例 3（含 $75°$ 的综合题：拆分为 $30° + 45°$）

**题目**：在 $\triangle ABC$ 中，$\angle B = 45°$，$\angle C = 75°$，$BC = 2 + 2\sqrt{3}$。从顶点 $A$ 向 $BC$ 作高 $AD$，垂足为 $D$。求高 $AD$ 的长。

**【思路】** $75°$ 不是特殊角，但 $75° = 30° + 45°$。作高 $AD$ 后，$\triangle ABD$ 是 $45°$ 直角三角形（$\angle B = 45°$），$\triangle ACD$ 是 $30°$-$60°$-$90°$ 直角三角形（$\angle C = 75°$，$\angle DAC = 15°$？不，重新思考——应让 $\angle C$ 在 $\triangle ACD$ 中保持，于是 $\angle CAD = 90° - 75° = 15°$，仍不是特殊角）。换思路：设 $AD = h$。在 $\triangle ABD$ 中由 $\angle B = 45°$ 得 $BD = h$。在 $\triangle ACD$ 中，$\angle ACD = 75°$。把 $\angle ACD$ 拆开：在 $AC$ 上找一点 $E$，使 $\angle ECD = 30°$。但更简便的拆法是：把高 $AD$ 替换为"在 $BC$ 上某点处构造 $60°$ 角"的辅助线。具体地，过 $A$ 作 $AE \perp AC$ 交 $BC$ 于 $E$，则 $\angle AEC = 90° - 75° = 15°$，仍未简化。最佳做法：**直接利用所作高 $AD$ 设 $AD = h$**，由 $\triangle ABD$（$45°$）得 $BD = h$；由 $\triangle ACD$，$\angle ACD = 75°$，这里改用另一种拆分——在 $\triangle ACD$ 内部，从 $D$ 出发作射线使其与 $DC$ 成 $30°$ 也不直接成立。我们改成下面这种更直接的"拼接"思路。

**改进思路**：在 $BC$ 上取一点 $E$，使 $\angle EAC = 45°$（即让 $\triangle AEC$ 含 $45°$）。由于 $\angle C = 75°$，则 $\angle AEC = 180° - 75° - 45° = 60°$；从而 $\angle AEB = 120°$，$\angle BAE = \angle A - 45° = (180° - 45° - 75°) - 45° = 15°$。

这样仍不够清爽。我们采用**最经典的拼接方式**：
- 作高 $AD \perp BC$，设 $AD = h$；
- 在 $\triangle ABD$ 中，$\angle B = 45°$，故 $BD = h$；
- 在 $\triangle ACD$ 中，$\angle ACD = 75°$，从 $D$ 沿 $DC$ 方向取点 $F$ 使 $\angle FAD = 30°$（即 $\angle ADF = 90°$，$\angle AFD = 60°$）。则 $\triangle ADF$ 是 $30°$-$60°$-$90°$ 三角形，$DF = \dfrac{h}{\sqrt{3}} = \dfrac{\sqrt{3}}{3} h$，$AF = \dfrac{2h}{\sqrt{3}}$。
- 此时 $\angle AFC = 180° - 60° = 120°$，$\angle FCA = 75°$，$\angle FAC = 180° - 120° - 75° \neq 45°$，未能拼齐。

**最直接做法（推荐）**——直接对高 $AD$ 用两段表达式：

在 $\triangle ABD$ 中：$BD = AD \cdot \cot 45° = h$。

在 $\triangle ACD$ 中：$DC = AD \cdot \cot 75°$。利用 $\cot 75° = \tan 15° = 2 - \sqrt{3}$，得 $DC = (2 - \sqrt{3}) h$。

由 $BD + DC = BC$：
$$
h + (2 - \sqrt{3}) h = 2 + 2\sqrt{3},
$$
$$
(3 - \sqrt{3}) h = 2 + 2\sqrt{3},
$$
$$
h = \frac{2 + 2\sqrt{3}}{3 - \sqrt{3}} = \frac{2(1 + \sqrt{3})(3 + \sqrt{3})}{(3 - \sqrt{3})(3 + \sqrt{3})} = \frac{2(3 + \sqrt{3} + 3\sqrt{3} + 3)}{9 - 3} = \frac{2(6 + 4\sqrt{3})}{6} = \frac{12 + 8\sqrt{3}}{6} = 2 + \frac{4\sqrt{3}}{3}.
$$

（此例中 $\tan 15° = 2 - \sqrt{3}$ 的来源恰恰是由 $15° = 45° - 30°$ 拼出来的特殊角组合——这正是"两类特殊直角三角形拼接"的核心思想。）

## 五、易错点

1. **$30°$ 所对的是短直角边，不要搞反**。常见错误是把 $30°$ 对的边写成 $\sqrt{3}$ 倍——记住：角度越小，所对的边越短，所以 $30°$ 对最短的直角边（比例 $1$），$60°$ 对较长的直角边（比例 $\sqrt{3}$），$90°$ 对最长的斜边（比例 $2$）。

2. **$\sqrt{3}$ 与 $\sqrt{2}$ 分别对应两类，别记反**。
   - $30°$-$60°$-$90°$ 三角形里出现的是 $\sqrt{3}$（来源：等边三角形高的勾股运算 $\sqrt{4-1}$）。
   - $45°$-$45°$-$90°$ 三角形里出现的是 $\sqrt{2}$（来源：$\sqrt{a^2 + a^2}$）。

3. **比例可以任意放缩**。三边比 $1 : \sqrt{3} : 2$ 不代表斜边一定等于 $2$。若斜边为 $k$，则三边为 $\dfrac{k}{2} : \dfrac{\sqrt{3}}{2} k : k$。

4. **是 part7 三角函数特殊值的几何基础**。本节得到的边长比，正对应 $\sin 30° = \dfrac{1}{2}$、$\cos 30° = \dfrac{\sqrt{3}}{2}$、$\sin 45° = \cos 45° = \dfrac{\sqrt{2}}{2}$ 等结论。提前理解这些"几何来源"，能让后续三角函数学习无须死记硬背。

## 六、思路自测题

**自测 1**：直角三角形中，一锐角为 $60°$，最短边为 $4$。求其余两边。

**【思路】** 最短边对最小锐角 $30°$，所以最短边即 $30°$ 所对的直角边。斜边 = 最短边 $\times 2 = 8$；长直角边 = 最短边 $\times \sqrt{3} = 4\sqrt{3}$。

---

**自测 2**：等腰直角三角形的斜边为 $6$，求直角边以及斜边上的高。

**【思路】** 直角边 = 斜边 $\div \sqrt{2} = 6/\sqrt{2} = 3\sqrt{2}$。斜边上的高在等腰直角三角形中等于斜边的一半（"三线合一"，且斜边上的中线 = 斜边/2 = 高），即 $3$。

---

**自测 3**：等边三角形 $\triangle ABC$ 的边长为 $a$，求它的高与面积。

**【思路】** 作高后得到 $30°$-$60°$-$90°$ 直角三角形，斜边 $= a$，短直角边 $= a/2$，高（长直角边）$= \dfrac{\sqrt{3}}{2} a$。面积 $= \dfrac{1}{2} \cdot a \cdot \dfrac{\sqrt{3}}{2} a = \dfrac{\sqrt{3}}{4} a^2$。

---

**自测 4**：在 $\triangle ABC$ 中，$\angle B = 30°$，$\angle C = 45°$，$AC = 2$。求 $AB$ 与 $BC$。

**【思路】** 作高 $AD \perp BC$ 于 $D$。在 $\triangle ACD$（$45°$ 直角三角形）中，$AC = 2$，故 $AD = CD = \sqrt{2}$。在 $\triangle ABD$（$30°$-$60°$-$90°$ 直角三角形）中，$\angle B = 30°$ 所对的直角边为 $AD = \sqrt{2}$，故斜边 $AB = 2\sqrt{2}$，长直角边 $BD = \sqrt{2} \cdot \sqrt{3} = \sqrt{6}$。所以 $BC = BD + DC = \sqrt{6} + \sqrt{2}$。这道题再次展示了"过一个顶点作高，把一般三角形拆成两个特殊直角三角形"的标准套路。
