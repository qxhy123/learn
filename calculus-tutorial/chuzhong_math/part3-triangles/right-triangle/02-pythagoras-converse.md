# 勾股定理的逆定理

勾股定理告诉我们：直角三角形的两条直角边的平方和等于斜边的平方。那么，反过来呢？如果一个三角形的三边长 $a, b, c$ 恰好满足 $a^2 + b^2 = c^2$，它一定是直角三角形吗？答案是肯定的。本节就来研究勾股定理的逆命题——它是判定一个三角形是否为直角三角形最常用、最直接的方法之一。

## 一、图形特征

设一个三角形的三边长分别为 $a, b, c$，并约定 $c$ 为三边中**最长**的一条。我们要研究的核心问题是：

$$
a^2 + b^2 \stackrel{?}{=} c^2
$$

之所以要先把 $c$ 取为最长边，是因为在直角三角形中斜边总是最长的。如果不先挑出最长边，盲目地把任意一条边代入等式右边，往往会得出错误结论。

直观上，可以把三边的平方理解为三个正方形的面积：以 $a, b$ 为边作两个小正方形，以 $c$ 为边作一个大正方形，若两小正方形面积之和恰好等于大正方形面积，则三角形为直角三角形。

## 二、逆定理

**勾股定理的逆定理**：如果三角形的三边长 $a, b, c$（其中 $c$ 为最长边）满足

$$
a^2 + b^2 = c^2,
$$

那么这个三角形是**直角三角形**，且 $c$ 所对的角为直角。

用符号语言写出来：

> 在 $\triangle ABC$ 中，若 $BC = a, CA = b, AB = c$，且 $a^2 + b^2 = c^2$，则 $\angle C = 90°$。

勾股定理和它的逆定理常常配合使用：勾股定理由"角"推"边"，逆定理由"边"推"角"。两者合起来构成了直角三角形最重要的边角关系。

## 三、证明（构造法）

证明逆定理的关键技巧是"构造一个已知是直角三角形的参照三角形"，再利用 SSS 全等把直角"搬"回来。

**已知**：$\triangle ABC$ 三边长为 $a, b, c$，且 $a^2 + b^2 = c^2$。

**求证**：$\angle C = 90°$。

**证明**：

第一步，另作一个三角形 $\triangle A'B'C'$，使得

$$
\angle C' = 90°, \quad B'C' = a, \quad C'A' = b.
$$

这是可以做到的：在平面上任取一点 $C'$，过 $C'$ 作两条互相垂直的射线，分别在两条射线上截取长度为 $a$ 和 $b$ 的线段，端点记为 $B'$ 和 $A'$，再连接 $A'B'$ 即得 $\triangle A'B'C'$。

第二步，在 $\triangle A'B'C'$ 中，因为 $\angle C' = 90°$，由**勾股定理**有

$$
(A'B')^2 = (B'C')^2 + (C'A')^2 = a^2 + b^2.
$$

第三步，根据已知 $a^2 + b^2 = c^2$，所以

$$
(A'B')^2 = c^2 \;\Longrightarrow\; A'B' = c.
$$

第四步，至此 $\triangle ABC$ 与 $\triangle A'B'C'$ 三边对应相等：

$$
BC = B'C' = a, \quad CA = C'A' = b, \quad AB = A'B' = c.
$$

由 **SSS 判定**，$\triangle ABC \cong \triangle A'B'C'$。全等三角形对应角相等，故

$$
\angle C = \angle C' = 90°.
$$

证毕。$\blacksquare$

这种"先构造一个满足结论的三角形，再用全等把结论搬回来"的思路，是几何里非常通用的方法，值得记牢。

## 四、按 $a^2 + b^2$ 与 $c^2$ 的大小关系判定三角形类型（重要扩展）

勾股定理的逆定理只回答"是不是直角三角形"，但等号两边的大小关系还能告诉我们更多信息。设 $c$ 为最长边，则有：

| 关系 | 三角形类型 | 几何解释 |
| :---: | :---: | :--- |
| $a^2 + b^2 = c^2$ | **直角三角形** | $c$ 所对角恰为 $90°$ |
| $a^2 + b^2 > c^2$ | **锐角三角形** | 最大角小于 $90°$ |
| $a^2 + b^2 < c^2$ | **钝角三角形** | $c$ 所对角大于 $90°$ |

记忆方法：把直角三角形想象成"标准状态"。如果两条短边的平方和"超出"了斜边的平方（$>$），说明 $c$ 所对的角被"压扁"了，比 $90°$ 小，三角形整体是"瘦"的——锐角三角形；反之如果"不够"（$<$），则 $c$ 所对的角被"撑开"超过 $90°$——钝角三角形。

要点：**判定时一定要先找出最长边作为 $c$**，否则上面的对应关系就乱了。

## 五、典型应用

**例 1**　已知三角形三边长为 $5, 12, 13$，判断它是什么三角形。

**【思路】** 先找最长边：$13$ 最长，取 $c = 13$，$a = 5, b = 12$。计算 $a^2 + b^2$ 与 $c^2$：

$$
5^2 + 12^2 = 25 + 144 = 169, \quad 13^2 = 169.
$$

两者相等，由勾股定理的逆定理，三角形为**直角三角形**，其中 $13$ 所对的角为直角。

---

**例 2**　判断下列三角形的类型：

（1）三边为 $6, 7, 9$；
（2）三边为 $6, 7, 10$。

**【思路】**

（1）最长边 $c = 9$，计算

$$
6^2 + 7^2 = 36 + 49 = 85, \quad 9^2 = 81.
$$

因为 $85 > 81$，即 $a^2 + b^2 > c^2$，所以三角形为**锐角三角形**。

（2）最长边 $c = 10$，计算

$$
6^2 + 7^2 = 85, \quad 10^2 = 100.
$$

因为 $85 < 100$，即 $a^2 + b^2 < c^2$，所以三角形为**钝角三角形**，且 $10$ 所对的角是钝角。

注意：这两个三角形只是把最长边从 $9$ 改成了 $10$，但三角形的"胖瘦"就发生了质的变化——这正是大小关系判定法的妙处。

---

**例 3（实际应用：古代测直角的"三四五绳法"）**

在古代，没有量角器和直角尺时，人们如何在地面上画出一个标准的直角呢？答案是用一根带等长结的绳子。

**做法**：取一条绳子，在上面打 $13$ 个间距相等的结（把绳分成 $12$ 段等长的小段）。把绳子首尾相接形成一个闭合的环，再选三个结点，把绳子拉成三段长度分别为 $3, 4, 5$ 段的三角形。

![三四五绳法：边长 3, 4, 5 的三角形，由 $3^2+4^2=5^2$ 知为直角三角形](../../figures/svg/thm-pythagoras-converse-345.svg)

**【思路】** 三角形的三边长之比为 $3:4:5$，由于

$$
3^2 + 4^2 = 9 + 16 = 25 = 5^2,
$$

满足勾股定理的逆定理，所以拉成的三角形是直角三角形，长度为 $3$ 段与 $4$ 段的两条边的夹角即为 $90°$。

这就是古埃及、古中国都广为流传的"三四五放线法"，至今仍被工匠用于木工放线、建筑施工中检测墙角是否方正——简单、可靠、不需要任何仪器。

## 六、易错点

1. **比较前必须先找出最长边作为 $c$。** 例如三边 $5, 12, 13$，若误把 $5$ 或 $12$ 当作 $c$ 去验证 $a^2 + b^2 = c^2$，就会得出不成立的错误结论。

2. **逆定理只能判定"是否为直角三角形"，不能用来确定边的具体比例。** 满足 $a^2 + b^2 = c^2$ 的三角形有无穷多个，比如 $3, 4, 5$ 与 $6, 8, 10$ 都是直角三角形，但形状不同（虽相似，比例不同的勾股数对也大量存在，如 $5,12,13$ 与 $3,4,5$）。

3. **不要遗漏"$c$ 所对的角才是直角"这一点。** 在书写结论时，应明确指出哪个顶点的角是直角，而不是笼统地说"这个三角形有直角"。

4. **对带根号或分数的三边，平方后再比较，不要直接比较边长本身。** 如三边为 $\sqrt{3}, 2, \sqrt{7}$：最长边 $\sqrt{7}$，$(\sqrt{3})^2 + 2^2 = 3 + 4 = 7 = (\sqrt{7})^2$，是直角三角形。

5. **大小关系判定法只对"三角形"成立。** 三条线段先要满足三角形的"两边之和大于第三边"，否则连三角形都构不成，谈不上判定类型。

## 七、思路自测题

**题 1**　判断三边长为 $9, 40, 41$ 的三角形是什么三角形。

**【思路提示】** 找最长边 $41$，计算 $9^2 + 40^2$ 与 $41^2$ 是否相等。$81 + 1600 = 1681 = 41^2$，是直角三角形。

---

**题 2**　三角形三边长为 $7, 24, 26$，它是锐角、直角还是钝角三角形？

**【思路提示】** 最长边 $26$，$7^2 + 24^2 = 49 + 576 = 625$，$26^2 = 676$。因为 $625 < 676$，是钝角三角形。

---

**题 3**　已知三角形三边长 $a, b, c$ 满足 $(a-3)^2 + |b - 4| + (c - 5)^2 = 0$，判断三角形的形状。

**【思路提示】** 非负数之和为零，每项都为零，得 $a = 3, b = 4, c = 5$。验证 $3^2 + 4^2 = 5^2$，是直角三角形。

---

**题 4**　一个三角形的三边长之比为 $1 : \sqrt{3} : 2$，判断它是什么三角形，并指出直角（若有）在哪个边所对的位置。

**【思路提示】** 设三边为 $k, \sqrt{3}k, 2k$，最长 $2k$。计算 $k^2 + (\sqrt{3}k)^2 = k^2 + 3k^2 = 4k^2 = (2k)^2$，满足逆定理。是直角三角形，且长度为 $2k$ 的边所对的角为直角。
