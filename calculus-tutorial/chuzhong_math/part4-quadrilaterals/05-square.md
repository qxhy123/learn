# 正方形

## 一、图形特征与定义

**正方形**是初中几何里"对称性最强"的四边形——**四条边都相等且四个角都是直角的四边形叫做正方形**。

从这个定义出发，可以立刻看出正方形的双重身份：

- 它满足"四个角都是直角"，所以**正方形是矩形**；
- 它满足"四条边都相等"，所以**正方形也是菱形**。

换句话说，**正方形 = 矩形 $\cap$ 菱形**——它处在矩形与菱形的"交集"上，既继承了矩形对"角"的强化（四角直角、对角线相等），也继承了菱形对"边"的强化（四边相等、对角线垂直且平分对角）。

这种"双重身份"决定了正方形的等价定义有多种说法：

- 有一组邻边相等的矩形 → 正方形（在矩形基础上补"边相等"）；
- 有一个角是直角的菱形 → 正方形（在菱形基础上补"角直角"）。

平行四边形 → 矩形 / 菱形 → 正方形 构成了一条清晰的"特殊化"链条，每升一级就多一组约束。正方形位于链条的顶端。

---

## 二、核心性质

由于正方形同时是矩形和菱形，它**继承两者的全部性质**，再叠加为一组极强的结构性质。

**性质 1：四条边都相等，四个角都是直角。**

这是定义本身，也是正方形最直观的外形特征。

**性质 2：对角线相等、互相垂直平分，且每条对角线平分一组对角。**

- "相等、互相平分" 来自矩形；
- "互相垂直、平分对角" 来自菱形；
- 两条性质合并后，对角线相交于一点 $O$，且 $OA = OB = OC = OD$，四个角都被对角线平分为 $45°$。

这意味着正方形对角线把它分成 **$4$ 个全等的等腰直角三角形**（$45°$–$45°$–$90°$）。

**性质 3：对角线与边的关系**

设正方形边长 $a$，对角线长 $d$，则

$$d = a\sqrt{2},\quad a = \tfrac{\sqrt{2}}{2}\, d.$$

证明：在以两条相邻边为直角边的直角三角形中，由勾股定理 $d = \sqrt{a^2 + a^2} = a\sqrt{2}$。这条结论与 special 章节里 $45°$–$45°$–$90°$ 三角形的边比 $1 : 1 : \sqrt{2}$ 完全一致。

**性质 4：正方形既是中心对称图形（对称中心为对角线交点），又是轴对称图形，共有 $4$ 条对称轴**——两条对角线所在直线，以及两条对边中点连线所在直线。这是初中阶段对称轴最多的常见四边形。

## 三、判定方法

判定一个四边形是正方形，常见有两条思路：**从矩形升级** 或 **从菱形升级**。

**判定 1：有一组邻边相等的矩形是正方形。**（矩形 + 边相等）

**判定 2：有一个角是直角的菱形是正方形。**（菱形 + 角直角）

**判定 3：对角线相等的菱形是正方形。**（菱形 + 对角线相等）

**判定 4：对角线互相垂直的矩形是正方形。**（矩形 + 对角线垂直）

四条判定可以总结为一句话：**已经是矩形 / 菱形的前提下，再补上对方独有的那一条性质，就升级为正方形**。

⚠️ **必须先确认是矩形或菱形**。例如：
- 只知道"四条边相等" → 是菱形，但未必是正方形；
- 只知道"对角线相等且互相垂直" → 还不够，需要先确认是平行四边形或矩形/菱形。

实际做题时，最常用的写法是先证平行四边形，再升级为矩形（或菱形），再升级为正方形——形成"三步走"的标准证明路径。

## 四、典型应用

### 例 1（对角线与边长的换算）

正方形 $ABCD$ 的边长 $AB = 6$。求对角线 $AC$ 的长，以及对角线交点 $O$ 到各顶点的距离。

**解**：由正方形对角线公式 $AC = AB \cdot \sqrt{2} = 6\sqrt{2}$。

对角线互相平分，故 $OA = OC = \dfrac{AC}{2} = 3\sqrt{2}$；同理 $OB = OD = 3\sqrt{2}$。

**评注**：正方形中只要给出边长，对角线长立刻可得（乘 $\sqrt{2}$）；反过来给对角线长，边长就是 $\dfrac{\sqrt{2}}{2}$ 倍。该换算呼应 special 章节中 $45°$–$45°$–$90°$ 三角形的边比，**务必背熟**。

---

### 例 2（正方形中的"半角模型"）

正方形 $ABCD$ 中，$E$ 在 $BC$ 上，$F$ 在 $CD$ 上，且 $\angle EAF = 45°$。证明：$EF = BE + DF$。

**思路（呼应 cong/04 半角模型）**：正方形的"$90°$ 顶角 + 顶点处 $45°$ 半角"是经典的半角模型场景。处理方法：**绕顶点 $A$ 把 $\triangle ADF$ 旋转 $90°$ 到 $\triangle ABF'$ 的位置**（其中 $F'$ 落在 $CB$ 延长线上），使 $AD$ 与 $AB$ 重合。

**证明**：

由于 $AB = AD$、$\angle ABF' = \angle ADF = 90°$、$AF = AF'$（旋转保距），且 $D, A, B$ 三点关系使 $F', B, E$ 共线。考察 $\triangle AEF$ 与 $\triangle AEF'$：

- $AE = AE$（公共边）；
- $AF = AF'$（旋转得）；
- $\angle EAF = 45°$，$\angle EAF' = \angle EAB + \angle BAF' = \angle EAB + \angle DAF = 90° - 45° = 45°$，故 $\angle EAF = \angle EAF'$。

由 SAS 得 $\triangle AEF \cong \triangle AEF'$，所以 $EF = EF' = BE + BF' = BE + DF$。$\quad\blacksquare$

**评注**：正方形是"半角模型"最经典的舞台——$90°$ 顶角天然适合旋转 $90°$，把分散在两条边上的两个线段"拼"到同一条直线上。一旦看到"正方形 + 顶角的一半 $45°$"，立刻想到"旋转 $90°$ 拼线段"。

---

### 例 3（正方形 + 旋转：手拉手特例）

正方形 $ABCD$ 与正方形 $AEFG$ 共顶点 $A$（$AEFG$ 由 $ABCD$ 绕 $A$ 旋转某个角度得到）。连接 $BE$、$DG$。证明：$BE = DG$ 且 $BE \perp DG$。

**思路（呼应 cong/03 手拉手模型）**：两个共顶点的正方形是"手拉手模型"的典型特例——$AB = AD$、$AE = AG$，且 $\angle BAE = \angle DAG$（都等于 $\angle BAD - \angle DAE = 90° - \angle DAE$ 或都等于 $90° + \angle DAE$，取决于旋转方向）。

**证明**：

在 $\triangle ABE$ 与 $\triangle ADG$ 中：

$$AB = AD,\quad AE = AG,\quad \angle BAE = \angle DAG.$$

由 SAS 得 $\triangle ABE \cong \triangle ADG$，所以 $BE = DG$，且 $\angle ABE = \angle ADG$。

延长 $BE$ 交 $DG$ 于 $P$，并设 $BE$ 交 $AD$ 于 $Q$。在 $\triangle ABQ$ 与 $\triangle PDQ$ 中：$\angle ABQ = \angle PDQ$（刚证）、$\angle AQB = \angle PQD$（对顶角），所以 $\angle BAQ = \angle DPQ$。又 $\angle BAQ = 90°$，故 $\angle DPB = 90°$，即 $BE \perp DG$。$\quad\blacksquare$

**评注**：两个共顶点的正方形 + 一对"拉手线段"$BE$、$DG$ → **必然全等且互相垂直**，这是中考压轴题里出现频率极高的结构。识别要点：**找到 "$AB = AD$、$AE = AG$、夹角相同" 这三个条件**，立刻 SAS 全等。

## 五、易错点提醒

- **正方形是矩形与菱形的"交集"**。判断一个图形是不是正方形，必须**两套性质都满足**——既要"四角直角"，也要"四边相等"；既要"对角线相等"，也要"对角线垂直"。任何一条单独成立都不够。
- **判定必须先有矩形或菱形作前提**。"邻边相等" 单独不够，"一个角直角" 单独也不够；必须先升一级到矩形 / 菱形，再补另一条性质。
- **对角线长 = 边长 $\times \sqrt{2}$**。这个换算常在不知不觉中被遗忘，特别是题目只给对角线时要反求边长（除以 $\sqrt{2}$，或乘 $\dfrac{\sqrt{2}}{2}$）。
- **对角线分出的四个三角形是等腰直角三角形**，不是一般的直角三角形——四个直角边都等于 $\dfrac{d}{2}$，每个三角形面积为 $\dfrac{d^2}{8}$。
- **"半角模型"与"手拉手模型"是正方形的两大经典图景**。考试中一看到"正方形 + $45°$" 想半角旋转；"两正方形共顶点" 想手拉手 SAS。

## 六、自测题

**1.** 正方形 $ABCD$ 的对角线 $AC = 4\sqrt{2}$。求边长与面积。

> 💡 **提示**：边长 $= \dfrac{AC}{\sqrt{2}} = 4$，面积 $= 4^2 = 16$。也可直接用对角线乘积：$S = \dfrac{1}{2} d^2 = \dfrac{1}{2} \times 32 = 16$。

---

**2.** 在四边形 $ABCD$ 中，$AB = BC = CD = DA$，且 $\angle A = 90°$。判断 $ABCD$ 的形状并说明理由。

> 💡 **提示**：四边相等 → 菱形（part4/04 判定 2）；菱形 + 一个角直角 → 正方形（本章判定 2）。请按"两步走"书写。

---

**3.** 矩形 $ABCD$ 中，对角线 $AC$、$BD$ 交于 $O$，且 $AC \perp BD$。判断 $ABCD$ 的形状并说明理由。

> 💡 **提示**：已经是矩形，再加上"对角线互相垂直"，由判定 4 直接得正方形。

---

**4.** 正方形 $ABCD$ 中，$E$ 在 $BC$ 上，$F$ 在 $CD$ 上，且 $BE = CF$。证明：$AE \perp BF$。

> 💡 **提示**：考察 $\triangle ABE$ 与 $\triangle BCF$。$AB = BC$、$\angle ABE = \angle BCF = 90°$、$BE = CF$，由 SAS 全等 → $\angle BAE = \angle CBF$。再由 $\angle BAE + \angle AEB = 90°$ 推出 $\angle CBF + \angle AEB = 90°$，进而 $AE \perp BF$。这是正方形里"旋转 $90°$ 全等"的微型版。
