# 梯形与等腰梯形

## 一、图形特征与定义

**一组对边平行而另一组对边不平行的四边形叫做梯形。**

注意定义中的两个并列条件：

- **一组对边平行**——这是梯形与"任意四边形"的区别；
- **另一组对边不平行**——这是梯形与"平行四边形"的区别。

两条限定缺一不可。如果"两组对边都平行"，那它就升级成了平行四边形；如果"两组对边都不平行"，那就只是一般的四边形。梯形恰好处在"一组平行、一组不平行"的中间位置上。

梯形的常用术语：

- **底**：互相平行的两条边，分别叫**上底**与**下底**（习惯上较短的为上底，较长的为下底，但本质上由位置而非长度决定）；
- **腰**：不平行的两条边；
- **高**：上、下底之间的垂直距离（即从上底任一点向下底所作的垂线段长度）。

记号上常把上底记作 $a$、下底记作 $b$、高记作 $h$，则梯形面积公式为

$$S = \frac{(a+b)\,h}{2}.$$

---

## 二、特殊梯形

按"腰"的特殊性，梯形又分成两类常见的特殊梯形：

### 1. 直角梯形

**有一条腰垂直于底的梯形叫做直角梯形。**

直角梯形里有两个直角（同一条腰的两个端点处），另一腰是斜的。它本质上是"矩形 + 直角三角形"的拼接：沿那条**斜腰**的较短端作底的垂线，整张图就被分成一个矩形与一个直角三角形。这种分解是直角梯形里几乎所有计算题的钥匙。

### 2. 等腰梯形

**两腰相等的梯形叫做等腰梯形。**

等腰梯形是中考重点考察的对象，它的对称性强、性质丰富，下面单独整理。

---

## 三、等腰梯形的性质

**性质 1：两腰相等。** 这是定义本身。

**性质 2：同一底上的两个底角相等。**

即 $\angle B = \angle C$（下底两角相等），$\angle A = \angle D$（上底两角相等）。

证明思路：过 $A$ 作 $AE \parallel CD$ 交 $BC$ 于 $E$，则 $AECD$ 是平行四边形，$AE = CD = AB$（两腰相等），所以 $\triangle ABE$ 是等腰三角形，$\angle B = \angle AEB = \angle C$。

**性质 3：对角线相等。**

即 $AC = BD$。

证明：在 $\triangle ABC$ 与 $\triangle DCB$ 中，$AB = DC$（两腰相等）、$\angle ABC = \angle DCB$（同底两底角相等）、$BC = CB$（公共边），由 SAS 得 $\triangle ABC \cong \triangle DCB$，故 $AC = BD$。

**性质 4：等腰梯形是轴对称图形，对称轴为两底中点连线所在直线。**

这条对称轴垂直于两底，并把整个梯形左右对折后完全重合。它也意味着等腰梯形的所有对称性最终都来自这条"中垂线"。

---

## 四、等腰梯形的判定

**判定 1（定义）：两腰相等的梯形是等腰梯形。**

**判定 2：同一底上两个底角相等的梯形是等腰梯形。**

**判定 3：对角线相等的梯形是等腰梯形。**

⚠️ **判定 2 和 3 都必须先确认"是梯形"**——即先有"一组对边平行、另一组不平行"。如果只知道"四边形里有两个相等的底角"或"对角线相等"，那它可能是矩形、可能是一般四边形，不能直接断言是等腰梯形。

实战中最常用判定 1：先证明两腰相等。次常用是判定 2：用同位角或内错角推两底角相等。

---

## 五、梯形的辅助线（核心方法）

梯形是"既不属于三角形也不属于平行四边形"的四边形，处理它的统一策略是**通过添辅助线把它转化为已熟悉的图形**——平行四边形、矩形、三角形。三种最经典的辅助线如下（呼应 toolkit/02 B 类方法）。

### 方法 A：平移一腰

**过上底一个端点，作一条腰的平行线。**

例如在梯形 $ABCD$（$AD \parallel BC$）中，过 $A$ 作 $AE \parallel DC$ 交 $BC$ 于 $E$。这样图形被分成：

- 四边形 $AECD$——两组对边分别平行，是**平行四边形**，$AE = DC$、$EC = AD$；
- $\triangle ABE$——一般三角形（或在等腰梯形里变成等腰三角形）。

**用途**：把"梯形里的两条腰"集中到一个三角形里，从而把对腰的研究转化为对三角形边角的研究。等腰梯形的性质 2 证明正是用这种平移。

### 方法 B：作两条高

**过上底两个端点向下底作垂线。**

把梯形分成"两个直角三角形 + 一个矩形"。两条高把上底的长度"拷贝"到下底上，剩下两段就是两个直角三角形的水平边。

**用途**：求高、求腰长、求面积——所有涉及"垂直距离"的题目首选此法。在等腰梯形里，两个直角三角形左右对称且全等，下底两端各被截出相等的一小段，长度为 $\dfrac{b-a}{2}$（$a$ 为上底，$b$ 为下底）。

### 方法 C：延长两腰

**把两腰分别延长，相交于一点 $P$。**

由于上、下底平行，$\triangle PAD \sim \triangle PBC$（A 字相似模型，呼应 sim/02），相似比等于 $\dfrac{AD}{BC} = \dfrac{a}{b}$。

**用途**：把梯形问题转化为相似三角形问题，特别适合处理"腰的延长线上某点的长度比"或"梯形内对角线相关"的问题。

> 💡 **辅助线选择口诀**：要研究腰 → 平移腰（A）；要研究高 / 直角关系 → 作两高（B）；要研究比例 / 相似 → 延长两腰（C）。

## 六、典型应用

### 例 1（等腰梯形 + 角度求边）

等腰梯形 $ABCD$ 中，$AD \parallel BC$，$AD = 4$，$BC = 10$，$\angle B = 60°$。求腰 $AB$ 与高 $h$。

**思路**：作两条高（方法 B）。

**解**：过 $A$、$D$ 分别向 $BC$ 作高 $AE$、$DF$，垂足分别为 $E$、$F$。则 $AEFD$ 是矩形，$EF = AD = 4$。

由等腰梯形左右对称，$BE = FC = \dfrac{BC - AD}{2} = \dfrac{10-4}{2} = 3$。

在 $\mathrm{Rt}\triangle ABE$ 中，$\angle B = 60°$，$BE = 3$，故

$$AB = \frac{BE}{\cos 60°} = \frac{3}{1/2} = 6,\qquad h = AE = BE \cdot \tan 60° = 3\sqrt{3}.$$

**评注**：等腰梯形里"作两高"是几乎所有求边、求高题目的标准动作。下底被截出的两小段各为 $\dfrac{b-a}{2}$——这条结论务必记牢。

---

### 例 2（延长两腰构造 A 字相似）

梯形 $ABCD$ 中，$AD \parallel BC$，$AD = 3$，$BC = 9$。延长 $BA$ 与 $CD$ 相交于点 $P$，$PA = 2$。求 $PB$ 的长。

**思路**：延长两腰（方法 C），用 A 字相似。

**解**：由 $AD \parallel BC$，$\triangle PAD \sim \triangle PBC$（A 字模型），相似比为

$$\frac{PA}{PB} = \frac{AD}{BC} = \frac{3}{9} = \frac{1}{3}.$$

故 $PB = 3 PA = 6$。

**评注**：梯形两腰延长后必交于一点（除非两腰也平行，但那就变成平行四边形了）。所得相似三角形相似比 = 上下底之比，这是处理梯形比例问题最有力的杠杆，呼应 sim/02 的 A 字模型。

---

### 例 3（综合：作两高求腰）

梯形 $ABCD$ 中，$AD \parallel BC$，$AD = 5$，$BC = 11$，高 $h = 4$，$AB = 5$。求腰 $CD$ 的长。

**思路**：作两条高（方法 B），把腰 $AB$、$CD$ 各放到一个直角三角形里。

**解**：过 $A$、$D$ 分别向 $BC$ 作高 $AE$、$DF$，垂足为 $E$、$F$。则 $AEFD$ 是矩形，$EF = AD = 5$，$AE = DF = h = 4$。

设 $BE = x$，$FC = y$，则 $x + 5 + y = 11$，即 $x + y = 6$。

在 $\mathrm{Rt}\triangle ABE$ 中，$AB^2 = AE^2 + BE^2$，即 $25 = 16 + x^2$，解得 $x = 3$。故 $y = 6 - 3 = 3$。

在 $\mathrm{Rt}\triangle DFC$ 中，$CD^2 = DF^2 + FC^2 = 16 + 9 = 25$，故 $CD = 5$。

**评注**：这道题"看上去"两腰相等的结论像是巧合，其实是因为左右两小段恰好都等于 $3$。一般的梯形（非等腰）这两小段未必相等，需要分别从勾股定理求出。**关键意识**：作两高之后，全部问题都归结到两个直角三角形 + 一个矩形上。

---

## 七、易错点提醒

- **梯形的定义需要两个条件——"一组对边平行 + 另一组对边不平行"**。两组都平行就成了平行四边形，不再是梯形。中考填空题里给"四边形 $ABCD$ 中 $AD \parallel BC$"并不直接告诉你这是梯形，还需要确认 $AB$ 与 $CD$ 不平行。
- **等腰梯形性质 2 是"同一底上的两底角相等"**，不是"四个角都相等"。上底两角相等、下底两角相等，但上底角与下底角不相等（它们互补：$\angle A + \angle B = 180°$）。
- **等腰梯形判定 3（对角线相等）必须先确认是梯形**——"对角线相等"对矩形也成立，所以单纯"对角线相等"不能推等腰梯形。
- **作两高时，下底被分成三段**：两端各 $\dfrac{b-a}{2}$（等腰梯形）或分别由勾股求出（一般梯形），中间一段等于上底 $a$。漏掉中间这段或对应错位置是常见错误。
- **延长两腰**得到的是相似三角形而**非**全等。相似比 $= \dfrac{a}{b}$，不要错记为 $1$。
- **直角梯形只有一条腰垂直于底**，另一腰是斜的。不要把直角梯形和矩形混为一谈。

## 八、自测题

**1.** 梯形 $ABCD$ 中 $AD \parallel BC$，$AD = 6$，$BC = 14$，高 $h = 6$。求梯形面积。

> 💡 **提示**：直接套面积公式 $S = \dfrac{(a+b)h}{2} = \dfrac{(6+14)\times 6}{2} = 60$。

---

**2.** 等腰梯形 $ABCD$ 中，$AD \parallel BC$，$AB = CD = 5$，$AD = 4$，$BC = 10$。求高 $h$。

> 💡 **提示**：作两高（方法 B）。下底两端各被截出 $\dfrac{10-4}{2} = 3$。在 $\mathrm{Rt}\triangle ABE$ 中用勾股：$h = \sqrt{AB^2 - 3^2} = \sqrt{25 - 9} = 4$。

---

**3.** 梯形 $ABCD$ 中 $AD \parallel BC$，$\angle B = \angle C$。证明：$ABCD$ 是等腰梯形。

> 💡 **提示**：这正是等腰梯形判定 2。可以用方法 A（过 $A$ 作 $AE \parallel CD$ 交 $BC$ 于 $E$），则 $AECD$ 是平行四边形，$AE = CD$；又 $\angle AEB = \angle C = \angle B$，故 $\triangle ABE$ 等腰，$AB = AE = CD$，两腰相等 → 等腰梯形。

---

**4.** 梯形 $ABCD$ 中 $AD \parallel BC$，$AD = 4$，$BC = 12$。延长 $BA$ 与 $CD$ 交于 $P$，且 $PA = 3$。求 $AB$ 的长。

> 💡 **提示**：A 字相似（方法 C），$\dfrac{PA}{PB} = \dfrac{AD}{BC} = \dfrac{4}{12} = \dfrac{1}{3}$，故 $PB = 9$，$AB = PB - PA = 6$。

---

**5.** 等腰梯形 $ABCD$ 中 $AD \parallel BC$，对角线 $AC \perp BD$，高 $h = 6$。求 $AD + BC$ 的值（即上下底之和）。

> 💡 **提示**：对角线相互垂直的等腰梯形是经典构造。利用对称性，设对角线交点 $O$，则 $\triangle BOC$、$\triangle AOD$ 都是等腰直角三角形（顶角在 $O$ 处为 $90°$，由对称性两条腰相等）。设 $AD = 2x$，$BC = 2y$，则 $\triangle AOD$ 中 $O$ 到 $AD$ 的距离为 $x$，$\triangle BOC$ 中 $O$ 到 $BC$ 的距离为 $y$，两距离之和等于高 $h$：$x + y = 6$，故 $AD + BC = 2x + 2y = 12$。
