# 求导套路系统化

> **一例速记**：求 $y = x^x$ 的导数。
> 见 $f^g$ 型（底数和指数都含 $x$）→ 对数求导法：
> $\ln y = x\ln x$，两边对 $x$ 求导：$\dfrac{y'}{y} = \ln x + 1$，
> 故 $y' = y(\ln x + 1) = x^x(\ln x + 1)$。
> **看到 $f^g$ 立刻取对数；看到复合函数立刻链式；看到乘积立刻乘积法则。**

---

## 一、为什么要"系统化"求导

初学微积分的同学往往"会算单个导数，但碰到组合式就乱"。根本原因是：求导规则有 6 条，但没有形成"根据函数结构自动选规则"的条件反射。

系统化的目标是建立一张**决策树**：看到 $f + g$ → 和法则；看到 $f \cdot g$ → 乘积法则；看到 $f/g$ → 商法则；看到 $f(g(x))$ → 链式法则；看到 $f^g$（$f$, $g$ 都含 $x$）→ 对数求导；看到隐函数 → 两边对 $x$ 求导。

本篇先给出 6 大规则和公式表，再讲隐函数、参数式、高阶导数、对数求导法，最后通过演示题展示完整决策链条。

## 二、6 大求导规则

设 $u = u(x)$ 和 $v = v(x)$ 均可导，$c$ 为常数。

| 规则名称 | 公式 | 注记 |
|---|---|---|
| **常数**法则 | $(c)' = 0$ | 常数导数为零 |
| **和差**法则 | $(u \pm v)' = u' \pm v'$ | 线性可加减 |
| **数乘**法则 | $(cu)' = cu'$ | 常数提出 |
| **乘积**（Leibniz）法则 | $(uv)' = u'v + uv'$ | 两项：各自求导，另一项不动 |
| **商**法则 | $\left(\dfrac{u}{v}\right)' = \dfrac{u'v - uv'}{v^2}$ | 分子减，分母平方，分母不为零 |
| **链式**法则 | $\dfrac{d}{dx}[f(g(x))] = f'(g(x))\cdot g'(x)$ | 外层导数（内层代入）× 内层导数 |

### 2.1 常用基本导数公式速查

| 函数 $f(x)$ | 导数 $f'(x)$ |
|---|---|
| $x^n$（$n\in\mathbb{R}$） | $nx^{n-1}$ |
| $e^x$ | $e^x$ |
| $a^x$（$a>0,a\neq1$） | $a^x\ln a$ |
| $\ln x$ | $\dfrac{1}{x}$（$x>0$） |
| $\log_a x$ | $\dfrac{1}{x\ln a}$ |
| $\sin x$ | $\cos x$ |
| $\cos x$ | $-\sin x$ |
| $\tan x$ | $\sec^2 x = \dfrac{1}{\cos^2 x}$ |
| $\cot x$ | $-\csc^2 x = -\dfrac{1}{\sin^2 x}$ |
| $\sec x$ | $\sec x\tan x$ |
| $\csc x$ | $-\csc x\cot x$ |
| $\arcsin x$ | $\dfrac{1}{\sqrt{1-x^2}}$ |
| $\arccos x$ | $-\dfrac{1}{\sqrt{1-x^2}}$ |
| $\arctan x$ | $\dfrac{1}{1+x^2}$ |

### 2.2 乘积法则的助记

**"一'冲'二不动，二'冲'一不动"**：$(uv)' = u'v + uv'$，即对第一个因子求导时第二个因子保持原状，然后加上第一个因子不动时对第二个求导的项。

三个函数的乘积：

$$(uvw)' = u'vw + uv'w + uvw'.$$

## 三、隐函数求导

### 3.1 概念

若函数关系以 $F(x, y) = 0$ 的形式给出（$y$ 没有显式写成 $x$ 的函数），则 $y$ 称为 $x$ 的**隐函数**。隐函数求导不需要解出 $y$，直接两边对 $x$ 求导，再解出 $y'$。

### 3.2 步骤

1. 对等式 $F(x, y) = 0$ 两边关于 $x$ 求导。
2. 凡含 $y$ 的项，用链式法则（$y$ 视为 $x$ 的函数）：$\dfrac{d}{dx}[f(y)] = f'(y)\cdot y'$。
3. 整理，解出 $y'$（通常含 $x$ 和 $y$）。

**例**：$y$ 满足 $x^2 + y^2 = 1$（单位圆），求 $y'$。

两边对 $x$ 求导：$2x + 2yy' = 0$，解得 $y' = -\dfrac{x}{y}$（$y\neq 0$）。

### 3.3 二阶隐函数导数

在 $y' = -\dfrac{x}{y}$ 基础上，再对 $x$ 求导（把 $y'$ 代入）：

$$y'' = -\frac{y - xy'}{y^2} = -\frac{y - x\cdot(-x/y)}{y^2} = -\frac{y^2 + x^2}{y^3} = -\frac{1}{y^3}.$$

（利用 $x^2+y^2=1$）

## 四、参数式求导

若 $x = x(t)$，$y = y(t)$（$t$ 为参数），则：

$$\frac{dy}{dx} = \frac{dy/dt}{dx/dt} = \frac{y'(t)}{x'(t)}\quad (x'(t)\neq 0).$$

二阶参数导数：

$$\frac{d^2y}{dx^2} = \frac{d}{dx}\left(\frac{dy}{dx}\right) = \frac{\dfrac{d}{dt}\!\left(\dfrac{dy/dt}{dx/dt}\right)}{dx/dt}.$$

**例**：$x = \cos t$，$y = \sin t$（圆的参数方程），$t = \pi/4$ 处的斜率：

$$\frac{dy}{dx} = \frac{\cos t}{-\sin t} = -\frac{\cos t}{\sin t} = -\cot t,\quad t=\pi/4\text{ 时} = -1.$$

## 五、高阶导数与 Leibniz 公式

### 5.1 记号

$f^{(n)}(x) = \dfrac{d^n f}{dx^n}$ 表示 $f$ 对 $x$ 求 $n$ 次导数。

常见高阶导数：

| 函数 | $n$ 阶导数 |
|---|---|
| $e^x$ | $e^x$ |
| $\sin x$ | $\sin\!\left(x + \dfrac{n\pi}{2}\right)$ |
| $\cos x$ | $\cos\!\left(x + \dfrac{n\pi}{2}\right)$ |
| $x^m$（$m\in\mathbb{N}$） | $m(m-1)\cdots(m-n+1)x^{m-n}$（$n\leq m$），$n>m$ 时为 $0$ |
| $\dfrac{1}{x}$ | $(-1)^n\dfrac{n!}{x^{n+1}}$ |
| $\ln x$ | $(-1)^{n-1}\dfrac{(n-1)!}{x^n}$（$n\geq 1$） |

### 5.2 Leibniz 公式（乘积的 $n$ 阶导数）

$$(uv)^{(n)} = \sum_{k=0}^{n}\binom{n}{k}u^{(k)}v^{(n-k)}.$$

类比二项式定理，$u$、$v$ 分别求 $0,1,\ldots,n$ 阶导数，系数为组合数 $\binom{n}{k}$。

**用途**：计算 $x^m e^x$、$x^m\sin x$ 等乘积的高阶导数（令 $u = x^m$——有限次后变零——$v = e^x$ 或 $\sin x$）。

## 六、对数求导法

### 6.1 适用场景

1. **幂指函数** $y = f(x)^{g(x)}$（底数和指数都含 $x$，如 $x^x$、$x^{\sin x}$）。
2. **多个因子的乘积**：$y = f_1\cdot f_2\cdots f_k$，取对数后化乘为加，求导更简。
3. **含根号的分式**：$y = \dfrac{\sqrt[n]{f_1}\cdot\sqrt[m]{f_2}}{g^p}$，对数化简后求导。

### 6.2 步骤

1. 两边取自然对数：$\ln y = [\text{含} x \text{的表达式}]$。
2. 两边对 $x$ 求导（左边 $\dfrac{1}{y}\cdot y' = (\ln y)' / 1$，用链式法则）：$\dfrac{y'}{y} = [\text{结果}]$。
3. 两边乘 $y$，还原 $y' = y\cdot[\text{结果}]$。

### 6.3 注意事项

- 取对数要求 $y > 0$。若 $y$ 可能为负，需先用 $|y|$ 或分情况处理（对负值区间，导数结论可扩展到 $y < 0$ 的情形）。
- 最终结果中 $y$ 要还原为原函数。

## 七、求导规则速查决策表

| 函数结构 | 识别特征 | 选用规则 |
|---|---|---|
| $f(x) \pm g(x)$ | 加减 | 和差法则 |
| $c \cdot f(x)$ | 常数 $\times$ 函数 | 数乘法则 |
| $f(x)\cdot g(x)$ | 乘积 | $(fg)' = f'g + fg'$ |
| $\dfrac{f(x)}{g(x)}$ | 分式 | $\dfrac{f'g - fg'}{g^2}$ |
| $f(g(x))$ | 复合（大函数套小） | 链式法则 |
| $F(x, y) = 0$ | 隐式方程 | 两边对 $x$ 求导 |
| $x(t), y(t)$ | 参数方程 | $\dfrac{dy}{dx} = \dfrac{y'(t)}{x'(t)}$ |
| $f^g$（$f,g$ 均含 $x$） | 幂指函数 | 对数求导法 |
| $(uv)^{(n)}$ | 乘积高阶 | Leibniz 公式 |

## 八、演示题：求 $y = x^x$ 的导数

> 拿到 $y = x^x$，我先判断结构：底数是 $x$，指数也是 $x$——这是**幂指函数** $f(x)^{g(x)}$ 形式。
>
> 幂指函数不能用幂函数法则（那个要求指数是常数），也不能用指数函数法则（那个要求底数是常数）。正确工具：**对数求导法**。
>
> **第一步：两边取对数。**
>
> $$y = x^x \implies \ln y = \ln(x^x) = x\ln x.$$
>
> **第二步：两边对 $x$ 求导。**
>
> 左边：$\dfrac{d}{dx}(\ln y) = \dfrac{1}{y}\cdot y'$（链式法则，$y$ 是 $x$ 的函数）。
>
> 右边：$\dfrac{d}{dx}(x\ln x) = 1\cdot\ln x + x\cdot\dfrac{1}{x} = \ln x + 1$（乘积法则）。
>
> 故：$\dfrac{y'}{y} = \ln x + 1$。
>
> **第三步：乘回 $y$，还原。**
>
> $$y' = y(\ln x + 1) = x^x(\ln x + 1).$$
>
> **验证（简单检验）**：当 $x = 1$ 时，$y = 1^1 = 1$，$y' = 1^1(\ln 1 + 1) = 1\cdot(0+1) = 1$。可以用数值验证：$\dfrac{(1+h)^{1+h} - 1}{h}\bigg|_{h\to 0} \to 1$ ✓。
>
> **结构链条**：看到 $f^g$ → 对数求导 → 两边取 $\ln$ → 右边用乘积法则 → 解出 $y'$ → 还原 $y$。

## 九、思考路标

1. **见复合函数 $f(g(x))$** → 立刻想链式法则：$\dfrac{d}{dx}[f(g(x))] = f'(g(x))\cdot g'(x)$。关键是"先对外层函数求导，内层原样代入；再乘以内层对 $x$ 的导数"。

2. **见乘积 $u(x)\cdot v(x)$** → 乘积法则：$(uv)' = u'v + uv'$。两项，各自轮流求导，不可只求一个。

3. **见商 $\dfrac{u}{v}$** → 商法则：$\dfrac{u'v - uv'}{v^2}$。注意分子是"上'冲'下不动减上不动下'冲'"，分母是 $v^2$（不是 $2v$）。

4. **见隐式方程 $F(x,y)=0$** → 两边对 $x$ 求导，凡含 $y$ 的项用链式：$[f(y)]' = f'(y)\cdot y'$。最后整理解出 $y'$（结果通常含 $x$ 和 $y$，不用消去 $y$）。

5. **见参数方程** → $\dfrac{dy}{dx} = \dfrac{y'(t)}{x'(t)}$，求二阶时还要 $\dfrac{d^2y}{dx^2} = \dfrac{(dy/dx)'_t}{x'(t)}$，别忘除以 $x'(t)$。

6. **见幂指函数 $f^g$（$f,g$ 都含 $x$）** → 立刻对数求导，不要硬用公式，对数法最简洁。

7. **见 $n$ 阶导数** → 先算几项找规律（如 $\sin x$ 每 4 次循环），或直接套高阶导数公式表。若是乘积型，用 Leibniz 公式（一个因子有有限次非零导数时特别好用）。

8. **求导链式是"由外到内"的** → 多层复合 $f(g(h(x)))$：先对 $f$ 求导（内层视为整体），再对 $g$ 求导，最后对 $h$ 求导，三者相乘。绝不要一步跳到最内层。

## 十、典型应用 3 例

### 例 1：隐函数求导——椭圆切线

**题目**：椭圆 $\dfrac{x^2}{4} + \dfrac{y^2}{9} = 1$，求点 $(1, \dfrac{3\sqrt{3}}{2})$ 处的切线方程。

**思路**：

两边对 $x$ 求导（隐函数方法）：

$$\frac{2x}{4} + \frac{2y}{9}y' = 0 \implies \frac{x}{2} + \frac{2y}{9}y' = 0.$$

解出 $y'$：

$$y' = -\frac{x}{2} \cdot \frac{9}{2y} = -\frac{9x}{4y}.$$

代入 $(1, \dfrac{3\sqrt{3}}{2})$：

$$y' = -\frac{9\times 1}{4\times\dfrac{3\sqrt{3}}{2}} = -\frac{9}{6\sqrt{3}} = -\frac{3}{2\sqrt{3}} = -\frac{\sqrt{3}}{2}.$$

切线方程（点斜式）：

$$y - \frac{3\sqrt{3}}{2} = -\frac{\sqrt{3}}{2}(x - 1) \implies y = -\frac{\sqrt{3}}{2}x + \frac{\sqrt{3}}{2} + \frac{3\sqrt{3}}{2} = -\frac{\sqrt{3}}{2}x + 2\sqrt{3}.$$

**结构链条**：见隐函数方程 → 两边对 $x$ 求导 → 解 $y'$ → 代入坐标 → 点斜式。

---

### 例 2：参数式求导——摆线

**题目**：摆线参数方程 $x = t - \sin t$，$y = 1 - \cos t$，求 $\dfrac{dy}{dx}$ 和 $\dfrac{d^2y}{dx^2}$（在 $t \neq 2k\pi$ 时）。

**思路**：

$$\frac{dy}{dx} = \frac{y'(t)}{x'(t)} = \frac{\sin t}{1-\cos t}.$$

求二阶：先对 $\dfrac{dy}{dx}$ 关于 $t$ 求导：

$$\frac{d}{dt}\left(\frac{\sin t}{1-\cos t}\right) = \frac{\cos t(1-\cos t) - \sin t\cdot\sin t}{(1-\cos t)^2} = \frac{\cos t - \cos^2 t - \sin^2 t}{(1-\cos t)^2} = \frac{\cos t - 1}{(1-\cos t)^2} = \frac{-(1-\cos t)}{(1-\cos t)^2} = \frac{-1}{1-\cos t}.$$

再除以 $x'(t) = 1-\cos t$：

$$\frac{d^2y}{dx^2} = \frac{-1/(1-\cos t)}{1-\cos t} = \frac{-1}{(1-\cos t)^2}.$$

摆线的 $y'' < 0$（当 $t \neq 2k\pi$），说明曲线在这些点处是凹弧（开口向下）。

---

### 例 3：Leibniz 公式——高阶导数

**题目**：设 $y = x^2 e^x$，求 $y^{(n)}$。

**思路**：

令 $u = x^2$，$v = e^x$，用 Leibniz 公式：

$$y^{(n)} = \sum_{k=0}^{n}\binom{n}{k}u^{(k)}v^{(n-k)}.$$

因为 $u = x^2$：$u^{(0)}=x^2$，$u^{(1)}=2x$，$u^{(2)}=2$，$u^{(k)}=0$（$k\geq 3$）。

$v = e^x$，$v^{(m)} = e^x$ 对所有 $m$。

故只有 $k = 0,1,2$ 项非零：

$$y^{(n)} = \binom{n}{0}x^2 e^x + \binom{n}{1}2x e^x + \binom{n}{2}\cdot 2\cdot e^x$$

$$= e^x\left[x^2 + 2nx + n(n-1)\right].$$

**验证（$n=2$）**：$y^{(2)} = e^x(x^2 + 4x + 2)$，直接计算：$y = x^2 e^x$，$y' = (2x+x^2)e^x$，$y'' = (2+2x)e^x + (2x+x^2)e^x = (x^2+4x+2)e^x$ ✓。

## 十一、自测题

**第 1 题**：求 $f(x) = \ln\sqrt{\dfrac{1+x}{1-x}}$ 的导数。

提示：$f(x) = \dfrac{1}{2}[\ln(1+x) - \ln(1-x)]$，$f'(x) = \dfrac{1}{2}\left(\dfrac{1}{1+x}+\dfrac{1}{1-x}\right) = \dfrac{1}{1-x^2}$。

---

**第 2 题**：曲线由方程 $e^y + xy = e$ 确定，求在点 $(0, 1)$ 处的切线方程。

提示：两边对 $x$ 求导：$e^y y' + y + xy' = 0$，$(e^y + x)y' = -y$，$y' = -\dfrac{y}{e^y+x}$。在 $(0,1)$：$y' = -\dfrac{1}{e+0} = -\dfrac{1}{e}$。切线：$y - 1 = -\dfrac{1}{e}(x-0)$，即 $y = -\dfrac{x}{e}+1$。

---

**第 3 题**：设 $x=a\cos^3 t$，$y=a\sin^3 t$，求 $\dfrac{d^2y}{dx^2}$（星形线）。

提示：$x'=-3a\cos^2 t\sin t$，$y'=3a\sin^2 t\cos t$，$\dfrac{dy}{dx}=-\tan t$。$(dy/dx)'_t = -\sec^2 t$，$\dfrac{d^2y}{dx^2} = \dfrac{-\sec^2 t}{-3a\cos^2 t\sin t} = \dfrac{1}{3a\cos^4 t\sin t}$。

---

**第 4 题**：用对数求导法求 $y = \left(\dfrac{x+1}{x-1}\right)^{x}$ 的导数。

提示：$\ln y = x[\ln(x+1)-\ln(x-1)]$，$\dfrac{y'}{y} = \ln\dfrac{x+1}{x-1} + x\left(\dfrac{1}{x+1}-\dfrac{1}{x-1}\right) = \ln\dfrac{x+1}{x-1} - \dfrac{2x}{x^2-1}$，$y' = y\cdot\left(\ln\dfrac{x+1}{x-1} - \dfrac{2x}{x^2-1}\right)$。
