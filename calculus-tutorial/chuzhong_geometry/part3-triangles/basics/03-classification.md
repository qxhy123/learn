# 三角形的分类

## 一、图形特征

三角形由三条边和三个内角组成。把若干三角形摆在一起观察，会发现它们之间存在显著的形态差异：有的三边长度互不相同，有的有两边一样长，有的甚至三边都相等；有的三个内角都很"尖"（都小于 $90°$），有的有一个角恰好是直角，有的则出现一个明显的"钝口"（大于 $90°$ 的角）。

这些差异并非杂乱无章，而是可以归纳为两条独立的分类线索：

- **边的相等情况**：关心三条边中有多少条彼此相等；
- **角的种类**：关心三个内角中是否出现直角、钝角。

由于边和角是三角形最基本的两类要素，因此对三角形最自然、最常用的分类方法就是"按边分"与"按角分"。两种分类彼此独立，可以叠加使用。

## 二、分类

### 1. 按边分类

- **不等边三角形**（也称"一般三角形" / "scalene"）：三边长度两两都不相等。
- **等腰三角形**：至少有两边长度相等。这两条相等的边叫做**腰**，第三边叫做**底**，两腰的夹角叫做**顶角**，腰和底的夹角叫做**底角**。
- **等边三角形**（也称"正三角形"）：三边长度都相等。

**注意：等边三角形是等腰三角形的特殊情形**——因为三边都相等显然满足"至少两边相等"，所以"等边 $\subset$ 等腰"。换言之，所有等边三角形都是等腰三角形，但等腰三角形不一定是等边三角形。

按边分类的关系可用集合图表示：

$$\{\text{三角形}\} = \{\text{不等边三角形}\} \cup \{\text{等腰三角形}\},\qquad \{\text{等边三角形}\} \subsetneq \{\text{等腰三角形}\}.$$

### 2. 按角分类

- **锐角三角形**：三个内角**都**小于 $90°$。
- **直角三角形**：恰有**一个**内角等于 $90°$；这个角叫做**直角**，夹直角的两边叫做**直角边**，直角所对的边叫做**斜边**。
- **钝角三角形**：恰有**一个**内角大于 $90°$（即"钝角"）。

由内角和定理（part3/basics/02）可知，三个内角之和恒为 $180°$，因此一个三角形中**至多有一个** $\geq 90°$ 的角；这就保证了"直角"和"钝角"出现时必定是唯一的，三种按角分类彼此互斥、且穷尽所有可能。

### 3. 综合分类

按边、按角两种分类是相互独立的，可以自由组合，例如：

- **等腰直角三角形**：两腰相等且夹角为 $90°$ 的三角形（两底角都是 $45°$）；
- **等腰钝角三角形**：两腰相等且顶角为钝角的三角形；
- **等腰锐角三角形**：两腰相等且三内角都小于 $90°$ 的三角形；
- **等边三角形必为锐角三角形**（见第三节关键结论）。

## 三、关键结论（链接其他章节）

下列结论会在本分类基础上反复使用，先在此汇总，详细证明见对应章节。

1. **直角三角形两锐角互余**：在直角三角形中，除直角外的两个内角之和等于 $90°$。证明见 part1/04，直接由内角和定理 $180°$ 减去直角 $90°$ 即得。
2. **等边三角形三个内角都是 $60°$**：设等边三角形三个内角为 $\angle A, \angle B, \angle C$。由"等边对等角"（后续 special/01 详证）得 $\angle A = \angle B = \angle C$；再由内角和 $\angle A + \angle B + \angle C = 180°$ 推出 $\angle A = \angle B = \angle C = 60°$。因此等边三角形必是锐角三角形。
3. **等腰三角形两底角相等**（"等边对等角"）：等腰三角形中，两条相等的腰所对的两个角（底角）也彼此相等。这是后续推理的核心工具，详证见 part3/special/01。

## 四、典型应用

### 例 1

已知某三角形的两个内角分别为 $30°$ 和 $60°$，判断该三角形按角分类属于哪一种。

【思路】用内角和定理求出第三个内角，再按定义分类。

**解**：设第三个内角为 $\angle C$。由内角和定理，
$$\angle C = 180° - 30° - 60° = 90°.$$
即该三角形恰有一个内角为 $90°$，故它是**直角三角形**。

### 例 2

已知三角形三边长为 $3, 4, 5$，问它按角分类属于哪一种？

【思路】观察 $3^2 + 4^2 = 9 + 16 = 25 = 5^2$，恰好满足"两短边平方和等于最长边平方"。由勾股定理的**逆定理**（详见 part3/right-triangle 章节）可知：若三边长 $a, b, c$ 满足 $a^2 + b^2 = c^2$，则该三角形是以 $c$ 为斜边的直角三角形。

**解**：因为 $3^2 + 4^2 = 5^2$，由勾股逆定理知该三角形为**直角三角形**，且 $5$ 所对的角是直角。又因为三边互不相等，所以它同时也是**不等边三角形**——综合分类为"不等边直角三角形"。

## 五、易错点

1. **等边与等腰的包含关系**：等边三角形是等腰三角形的特殊情形（即"等边 $\subset$ 等腰"），不要把它们当成并列的两类。说"这个三角形是等腰三角形"并**不**排除它是等边三角形的可能。
2. **钝角三角形只有一个钝角**：由内角和 $180°$ 知，若一个三角形已经有一个内角 $> 90°$，那么其余两角之和 $< 90°$，因此另两个角必然都是锐角，绝不可能再出现第二个 $\geq 90°$ 的角。
3. **直角三角形不可能再有第二个 $\geq 90°$ 角**：理由同上——直角 $90°$ 已经"用掉"一半内角和，剩下两角之和恰为 $90°$，两者都必须严格小于 $90°$（且互余）。
4. **不要把"按边分类"与"按角分类"混淆**：例如"等腰三角形"是按边分的概念，不能直接据此判断它是锐角、直角还是钝角；同样，"直角三角形"也不能直接判断三边是否相等。
5. **判断"是什么三角形"时要明确分类标准**：若只问"按角分类"或"按边分类"，回答相应一种即可；若问"综合分类"，则两种都要给出。

## 六、思路自测题

1. 某三角形的两个内角分别为 $50°$ 和 $70°$。它按角分类属于哪一类？是否可能是等腰三角形？若可能，请说明哪两条边相等。
2. 一个三角形的两边长分别为 $5$ 和 $5$，已知其中一个内角为 $120°$。问该三角形按边、按角综合分类应叫做什么三角形？另两个内角各是多少度？
3. 判断下列说法是否正确，并简要说明理由：
   (1) 等边三角形一定是锐角三角形；
   (2) 等腰三角形一定不是直角三角形；
   (3) 一个三角形如果有两个内角相等，那么它一定是等腰三角形（提示：此结论是"等边对等角"的逆命题，详见后续 special/01）。
