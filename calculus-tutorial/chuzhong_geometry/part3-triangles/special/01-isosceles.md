# 等腰三角形

## 一、图形特征

**等腰三角形**是有两条边相等的三角形。

- 相等的两条边称为**腰**；
- 另一条边（不一定与腰相等的那条）称为**底**（或底边）；
- 两腰所夹的角称为**顶角**；
- 腰与底边所成的两个角称为**底角**。

特别地，三条边都相等的三角形是**等边三角形**（正三角形），它是等腰三角形的特殊情形——此时"顶角"与"底角"概念退化，任何一个角都既是顶角也是底角，每个角都等于 $60°$。

记号约定：本节统一以 $\triangle ABC$ 表示等腰三角形，其中 $AB = AC$ 为两腰，$BC$ 为底边，$\angle A$ 为顶角，$\angle B, \angle C$ 为底角。

## 二、性质与判定

**核心性质 1（等边对等角）**：在同一个三角形中，两腰相等 $\Longrightarrow$ 这两腰所对的两个底角相等。
即：$AB = AC \Longrightarrow \angle B = \angle C$。

**核心性质 2（三线合一）**：等腰三角形顶角的平分线、底边上的中线、底边上的高，这三条线**互相重合**（即同一条线段）。

![等腰三角形三线合一：顶角平分线 = 底边中线 = 底边高（即图中 $AD$）](../../figures/svg/thm-isosceles-three-in-one.svg)

**对称性**：等腰三角形是**轴对称图形**，其对称轴是顶角平分线所在的直线（也即底边的中垂线）。

**判定（等角对等边）**：在同一个三角形中，若有两个角相等，则这两个角所对的两条边相等，即该三角形是等腰三角形。
即：$\angle B = \angle C \Longrightarrow AB = AC$。

"等边对等角"与"等角对等边"互为逆命题，两者都成立，是等腰三角形最常用的两个工具。

## 三、性质证明（完整推导）

### 1. 等边对等角

**已知**：$\triangle ABC$ 中 $AB = AC$。
**求证**：$\angle B = \angle C$。

**证明**：作底边 $BC$ 上的中线 $AD$，则 $BD = CD$。

在 $\triangle ABD$ 与 $\triangle ACD$ 中：

$$
\begin{cases}
AB = AC &\text{（已知）}\\
BD = CD &\text{（作图，} D \text{ 为 } BC \text{ 中点）}\\
AD = AD &\text{（公共边）}
\end{cases}
$$

由 **SSS**，得 $\triangle ABD \cong \triangle ACD$。

由全等三角形对应角相等，$\angle B = \angle C$。 $\blacksquare$

### 2. 三线合一

继续利用上面的全等 $\triangle ABD \cong \triangle ACD$：

- 对应角 $\angle BAD = \angle CAD$，故 $AD$ 是顶角 $\angle BAC$ 的**平分线**；
- 由作图，$AD$ 是底边 $BC$ 上的**中线**；
- 又对应角 $\angle ADB = \angle ADC$，而 $\angle ADB + \angle ADC = 180°$，故 $\angle ADB = \angle ADC = 90°$，即 $AD \perp BC$，$AD$ 是底边 $BC$ 上的**高**。

三者重合，即"三线合一"。 $\blacksquare$

### 3. 等角对等边（判定）

**已知**：$\triangle ABC$ 中 $\angle B = \angle C$。
**求证**：$AB = AC$。

**证明**：作 $\angle A$ 的平分线 $AD$ 交 $BC$ 于 $D$，则 $\angle BAD = \angle CAD$。

在 $\triangle ABD$ 与 $\triangle ACD$ 中：

$$
\begin{cases}
\angle BAD = \angle CAD &\text{（作图）}\\
\angle B = \angle C &\text{（已知）}\\
AD = AD &\text{（公共边）}
\end{cases}
$$

由 **AAS**，得 $\triangle ABD \cong \triangle ACD$，故 $AB = AC$。 $\blacksquare$

## 四、典型应用

### 例 1（分类讨论）

等腰三角形的一个内角为 $50°$，求其余两个内角。

**【思路】** 题目只说"一个内角"，未说明它是顶角还是底角，因此**必须分类讨论**。底角必须为锐角（两个底角相等，若 $\ge 90°$ 则三角形内角和超过 $180°$）；顶角对锐、钝、直均可。$50°$ 是锐角，两种情形均合法。

**解** 设此内角为 $\alpha = 50°$。

- 情形 1：$\alpha$ 是**顶角**。则两个底角相等且和为 $180° - 50° = 130°$，故每个底角为 $65°$。其余两角为 $65°, 65°$。
- 情形 2：$\alpha$ 是**底角**。则另一个底角也是 $50°$，顶角为 $180° - 50° - 50° = 80°$。其余两角为 $50°, 80°$。

综上，其余两角为 $65°, 65°$ 或 $50°, 80°$。

### 例 2（三线合一的应用）

如图，$\triangle ABC$ 中 $AB = AC$，$D$ 为 $BC$ 的中点，$E$ 在 $AD$ 上。求证：$EB = EC$。

**【思路】** 由 $AB = AC$ 且 $D$ 为 $BC$ 中点，由三线合一知 $AD \perp BC$，即 $AD$ 是 $BC$ 的中垂线；$E$ 在中垂线上，到 $B, C$ 两端距离相等。

**证明** 因 $AB = AC$，$D$ 为 $BC$ 中点，由三线合一，$AD \perp BC$，所以 $AD$ 是 $BC$ 的中垂线。$E \in AD$，由中垂线的性质，$EB = EC$。 $\blacksquare$

### 例 3（综合：等腰 + 角平分线）

$\triangle ABC$ 中，$AB = AC$，$\angle A = 36°$，$BD$ 平分 $\angle ABC$ 交 $AC$ 于 $D$。求证：$AD = BD = BC$。

**【思路】** 先算各角：底角 $\angle ABC = \angle ACB = (180° - 36°)/2 = 72°$。$BD$ 平分 $\angle ABC$，故 $\angle ABD = \angle DBC = 36°$。

- 在 $\triangle ABD$ 中，$\angle A = \angle ABD = 36°$，由"等角对等边"，$AD = BD$；
- 在 $\triangle BDC$ 中，$\angle DBC = 36°$，$\angle BCD = 72°$，故 $\angle BDC = 72°$，于是 $\angle BDC = \angle BCD$，由"等角对等边"，$BD = BC$。

合起来即 $AD = BD = BC$。 $\blacksquare$

> 说明：该图形即著名的"黄金三角形"，$AD/AB$ 之比正是黄金比。

## 五、易错点

1. **必须分类讨论的两种典型情形**：
   - 题目给定**某个角**，没说明是顶角还是底角时，需要分两种情形（注意底角不能 $\ge 90°$，若给出的角是钝角或直角，则它只能是顶角，自动排除"它是底角"这一支）。
   - 题目给定**某条边**（如"等腰三角形一边长 $3$，另一边长 $7$"），需要分"$3$ 是腰、$7$ 是底"和"$7$ 是腰、$3$ 是底"两种情形，并且**用三角形三边关系验证**是否能构成三角形（如腰为 $3$ 时，$3+3 = 6 < 7$，不能构成三角形，须舍去）。

2. **"三线合一"的前提是"底边对应的三条线"**：顶角的平分线、底边上的中线、底边上的高，这三条才合一。**腰上的高、腰上的中线、底角的平分线一般不重合**，绝不能套用。

3. **不要混淆"等边对等角"的范围**：必须在**同一个三角形**内，两边相等才能推出两角相等。不同三角形里两边相等推不出对应角相等。

4. 等边三角形是等腰三角形的特殊情形，但反之不一定。做证明题时若只得到"等腰"，不能直接当作"等边"用。

5. 推"等角对等边"时，相等的两个角对的边才是相等的腰，要看清是哪两条边相等，不要张冠李戴。

## 六、思路自测题

1. 等腰三角形的一个外角为 $100°$，求三个内角。**（分类讨论）**

2. 等腰三角形的一边长为 $4$，另一边长为 $9$，求其周长。**（分类讨论 + 三角形三边关系验证）**

3. $\triangle ABC$ 中 $AB = AC$，$AD$ 是 $BC$ 边上的高，$BC = 10$，$AD = 12$。求 $AB$ 的长。【提示：三线合一 + 勾股定理】

4. $\triangle ABC$ 中 $AB = AC$，点 $D$ 在 $BC$ 上，$\angle BAD = \angle CAD$。求证：$BD = CD$ 且 $AD \perp BC$。【提示：三线合一/全等三角形】

5. $\triangle ABC$ 中 $\angle B = \angle C$，$D, E$ 分别是 $AB, AC$ 上的点，且 $BD = CE$。求证：$\triangle DBC \cong \triangle ECB$，并由此说明 $\triangle BPC$（$P = BE \cap CD$）是等腰三角形。【提示：等角对等边 + SAS + 等边对等角】
