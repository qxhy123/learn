# 公式定理速查表

> 本表按教程章节顺序整理全部核心公式、定理与判定方法。每条形式：**结论** + 一句话使用条件 + （来源章节）。

## 一、基础概念（part1 / part2）

### 1.1 点与直线

| 结论 | 使用条件 | 来源 |
| :--- | :--- | :--- |
| 两点确定一条直线 | 已知不重合的两点 | part1/01 |
| 两点之间，线段最短 | 求"最短路径"或证不等式时使用 | part1/01 |
| 过直线外一点，有且仅有一条直线与已知直线垂直 | 作高/构造垂线时使用 | part2/02 |
| 垂线段最短 | 点到直线距离 = 垂线段长度 | part2/02 |

### 1.2 角与度量

- **度分秒换算**：$1°=60'$，$1'=60''$（part1/02）
- **互余**：$\angle 1+\angle 2=90°$；**互补**：$\angle 1+\angle 2=180°$（part1/04）
- **同角（等角）的余角相等，补角相等**——证两角相等的常用桥梁（part1/04）
- **对顶角相等**：两条直线相交时所成的对顶角（part2/01）
- **邻补角互补**：$\angle 1+\angle 2=180°$（part2/01）
- **角平分线性质**：平分线上的点到角两边距离相等；逆命题也成立（part1/03）

### 1.3 平行线（part2/04, part2/05）

**判定（同位角/内错角/同旁内角）**：

| 判定方法 | 条件 | 结论 |
| :--- | :--- | :--- |
| 同位角相等 | $\angle 1=\angle 2$ | $l_1 \parallel l_2$ |
| 内错角相等 | $\angle 3=\angle 4$ | $l_1 \parallel l_2$ |
| 同旁内角互补 | $\angle 5+\angle 6=180°$ | $l_1 \parallel l_2$ |

**性质**：两直线平行 $\Rightarrow$ 同位角相等 / 内错角相等 / 同旁内角互补。

判定与性质互为逆命题；做题先判断"已知是角的关系还是平行"再选用。

## 二、三角形（part3）

### 2.1 基本性质（part3/basics）

- **三边关系**：$|a-b| < c < a+b$——三边任意两边之和大于第三边（part3/basics/01）
- **内角和定理**：$\angle A+\angle B+\angle C=180°$（part3/basics/02）
- **外角定理**：三角形的一个外角等于不相邻的两个内角之和；外角大于任一不相邻内角（part3/basics/02）
- **按角分类**：锐角 / 直角 / 钝角三角形；**按边分类**：不等边 / 等腰 / 等边（part3/basics/03）

### 2.2 全等判定（part3/congruence/01, 02）

| 判定 | 条件 | 适用 |
| :--- | :--- | :--- |
| SSS | 三边对应相等 | 一般三角形 |
| SAS | 两边及其夹角相等 | 一般三角形 |
| ASA | 两角及其夹边相等 | 一般三角形 |
| AAS | 两角及一对边相等 | 一般三角形 |
| HL | 斜边和一直角边相等 | 仅直角三角形 |

> 注意 **SSA 不成立**（除直角三角形 HL 情形外）。
> 全等性质：对应边、对应角、对应中线、高、角平分线、周长、面积均相等。

### 2.3 相似判定（part3/similarity/01）

| 判定 | 条件 |
| :--- | :--- |
| AA | 两组对应角相等 |
| SAS | 两边对应成比例且夹角相等 |
| SSS | 三边对应成比例 |

**相似比 $k$ 的衍生关系**：

- 对应边、对应高、对应中线、对应角平分线之比均为 $k$
- 周长比 $=k$
- **面积比 $=k^2$**——压轴题最常考的换算

### 2.4 直角三角形（part3/right-triangle）

- **勾股定理**：直角三角形中 $a^2+b^2=c^2$（$c$ 为斜边）（part3/right-triangle/01）
- **逆定理**：若 $a^2+b^2=c^2$ 则为直角三角形（part3/right-triangle/02）
- **三类判定**：设 $c$ 为最长边
  - $a^2+b^2=c^2$：直角三角形
  - $a^2+b^2>c^2$：锐角三角形
  - $a^2+b^2<c^2$：钝角三角形
- **特殊直角三角形边比**（part3/right-triangle/03）：
  - $30°\text{-}60°\text{-}90°$：$1:\sqrt{3}:2$
  - $45°\text{-}45°\text{-}90°$：$1:1:\sqrt{2}$
- **斜边中线定理**：直角三角形斜边上的中线等于斜边的一半（part3/special/03）

### 2.5 等腰与等边（part3/special/01, 02）

**等腰三角形**：

- 等边对等角；等角对等边
- **三线合一**：顶角平分线、底边中线、底边上的高三线重合（仅对顶角而言）

**等边三角形**：

- 三内角均为 $60°$
- 边长为 $a$ 时：高 $h=\dfrac{\sqrt{3}}{2}a$，面积 $S=\dfrac{\sqrt{3}}{4}a^2$

### 2.6 四心（part3/special/03）

| 心 | 定义 | 关键性质 |
| :--- | :--- | :--- |
| 重心 | 三条中线交点 | 分中线为 $2:1$（顶点到重心 : 重心到对边中点） |
| 外心 | 三边垂直平分线交点 | 到三顶点距离相等；**直角三角形外心 = 斜边中点** |
| 内心 | 三条角平分线交点 | 到三边距离相等 $=$ 内切圆半径 $r$ |
| 垂心 | 三条高的交点 | 直角三角形垂心 = 直角顶点 |

## 三、四边形（part4）

### 3.1 多边形角度（part4/01）

- **内角和**：$(n-2)\times 180°$
- **外角和**：恒为 $360°$（与边数无关）
- **正 $n$ 边形每个内角** $=\dfrac{(n-2)\times 180°}{n}$，每个外角 $=\dfrac{360°}{n}$

### 3.2 平行四边形（part4/02）

**性质**：

1. 对边平行且相等
2. 对角相等，邻角互补
3. 对角线互相平分
4. 中心对称图形（绕对角线交点 $180°$ 重合）

**判定**（5 条，任选其一即可）：

1. 两组对边分别平行
2. 两组对边分别相等
3. 一组对边平行且相等
4. 两组对角分别相等
5. 对角线互相平分

### 3.3 矩形 / 菱形 / 正方形（part4/03–05）

| 图形 | 特征性质 | 关键判定 |
| :--- | :--- | :--- |
| 矩形 | 四角为直角；**对角线相等** | 平行四边形 + 一个直角 / 对角线相等 |
| 菱形 | 四边相等；**对角线互相垂直平分且平分对角** | 平行四边形 + 一组邻边相等 / 对角线互相垂直 |
| 正方形 | 兼具矩形与菱形所有性质 | 矩形 + 邻边相等 / 菱形 + 一个直角 |

> 面积：菱形 $S=\dfrac{1}{2}d_1d_2$；正方形 $S=a^2=\dfrac{1}{2}d^2$。

### 3.4 梯形（part4/06）

**常用辅助线 3 种**：

1. 平移一腰（构造平行四边形 + 三角形）
2. 作两条高（构造矩形 + 两直角三角形）
3. 延长两腰相交（构造大小相似三角形）

### 3.5 中位线（part4/07）

- **三角形中位线**：平行于第三边且等于第三边的一半 $\;\; MN=\dfrac{1}{2}BC$
- **梯形中位线**：平行于两底，长度等于两底之和的一半 $\;\;l=\dfrac{a+b}{2}$

### 3.6 中点四边形（part4/08，⭐️ 模型）

任意四边形各边中点顺次相连得到的四边形 **恒为平行四边形**；特殊情形：

| 原四边形 | 中点四边形 |
| :--- | :--- |
| 一般四边形 | 平行四边形 |
| 矩形 | 菱形 |
| 菱形 | 矩形 |
| 正方形 | 正方形 |
| 对角线相等的四边形 | 菱形 |
| 对角线垂直的四边形 | 矩形 |

## 四、圆（part5）

### 4.1 弦 / 弧 / 圆心角 / 圆周角（part5/01, 03）

- 在同圆或等圆中，**等弧、等弦、等圆心角、等圆周角四者两两等价**
- **垂径定理**（part5/02）：垂直于弦的直径平分弦及弦所对的两条弧；逆命题成立
- **圆周角定理**：同弧所对的圆周角等于圆心角的一半 $\;\;\angle ACB=\dfrac{1}{2}\angle AOB$
- **推论**：
  - 直径所对的圆周角是直角；$90°$ 圆周角所对的弦是直径
  - 圆内接四边形对角互补 $\angle A+\angle C=180°$

### 4.2 直线与圆位置关系（part5/04, 05）

设圆心到直线距离为 $d$，半径为 $r$：

| 关系 | 判定 | 公共点数 |
| :--- | :--- | :--- |
| 相离 | $d>r$ | 0 |
| 相切 | $d=r$ | 1 |
| 相交 | $d<r$ | 2 |

**切线判定** 3 法：

1. 与圆只有一个公共点（定义）
2. $d=r$（量化判定）
3. 过半径外端且垂直于该半径（最常用证明法）

**切线性质**：切线垂直于过切点的半径。

### 4.3 切线长与切割线（part5/06, 07）

- **切线长定理**：从圆外一点引两条切线，切线长相等，且该点与圆心的连线平分两切线夹角
- **切割线定理**（⭐️ part5/07）：自圆外点 $P$ 作切线 $PA$ 与割线 $PBC$，则 $\;PA^2=PB\cdot PC$
- **相交弦定理**：圆内两弦 $AB,CD$ 交于 $P$，则 $\;PA\cdot PB=PC\cdot PD$
- **四点共圆**（⭐️ part5/08）：常用判定——对角互补 / 同侧同弧等角 / 线段乘积相等

### 4.4 内切圆 / 弧长 / 扇形

- **三角形面积公式（含内切圆）**：$S=pr$（$p$ 为半周长，$r$ 为内切圆半径）
- **直角三角形内切圆**：$r=\dfrac{a+b-c}{2}$（$c$ 为斜边）
- **弧长**：$\;l=\dfrac{n\pi r}{180}=\dfrac{n}{360}\cdot 2\pi r$
- **扇形面积**：$\;S=\dfrac{n\pi r^2}{360}=\dfrac{1}{2}lr$
- **圆锥侧面积**：$S_{\text{侧}}=\pi r l$（$l$ 为母线），底面圆周长 $=$ 展开扇形弧长

## 五、图形变换（part6）

### 5.1 三种基本变换（part6/01–04）

| 变换 | 不变量 | 关键结论 |
| :--- | :--- | :--- |
| 平移 | 形状、大小、方向 | 对应点连线平行且相等 |
| 轴对称 | 形状、大小 | 对称轴垂直平分对应点连线 |
| 旋转 | 形状、大小 | 对应点到旋转中心距离相等；对应角等于旋转角 |
| 中心对称 | 形状、大小 | 是旋转 $180°$ 的特例 |

### 5.2 位似（part6/05）

- 位似 = 相似 + 对应点连线过同一点（位似中心）
- 位似比 $k$：对应边比 $|k|$，面积比 $k^2$；$k$ 可正可负（正向 / 反向位似）

### 5.3 坐标变换表（part9/01）

| 变换 | $(x,y)\to$ |
| :--- | :--- |
| 关于 $x$ 轴对称 | $(x,-y)$ |
| 关于 $y$ 轴对称 | $(-x,y)$ |
| 关于原点对称 | $(-x,-y)$ |
| 关于直线 $y=x$ 对称 | $(y,x)$ |
| 关于直线 $y=-x$ 对称 | $(-y,-x)$ |
| 平移 $(a,b)$ | $(x+a,\,y+b)$ |
| 绕原点逆时针 $90°$ | $(-y,x)$ |
| 绕原点顺时针 $90°$ | $(y,-x)$ |

### 5.4 折叠与旋转构造（⭐️ part6/06, 07）

- **折叠核心**：折痕是对应点连线的垂直平分线；折前折后图形全等
- **旋转构造**（手拉手 / 半角的本质）：将含公共顶点的两组等长线段绕公共点旋转，构造全等三角形

## 六、解直角三角形（part7）

### 6.1 三角函数定义（part7/01）

设 $\angle A$ 为直角三角形锐角，对边 $a$、邻边 $b$、斜边 $c$：

$$\sin A=\dfrac{a}{c},\quad \cos A=\dfrac{b}{c},\quad \tan A=\dfrac{a}{b}$$

### 6.2 特殊角值表（part7/02）

| 角度 | $30°$ | $45°$ | $60°$ |
| :--- | :--- | :--- | :--- |
| $\sin$ | $\dfrac{1}{2}$ | $\dfrac{\sqrt{2}}{2}$ | $\dfrac{\sqrt{3}}{2}$ |
| $\cos$ | $\dfrac{\sqrt{3}}{2}$ | $\dfrac{\sqrt{2}}{2}$ | $\dfrac{1}{2}$ |
| $\tan$ | $\dfrac{\sqrt{3}}{3}$ | $1$ | $\sqrt{3}$ |

### 6.3 基本恒等式

- $\sin^2\alpha+\cos^2\alpha=1$
- $\tan\alpha=\dfrac{\sin\alpha}{\cos\alpha}$
- **余角互化**：$\sin(90°-\alpha)=\cos\alpha,\;\cos(90°-\alpha)=\sin\alpha$

### 6.4 实际应用术语（part7/03）

- **仰角 / 俯角**：视线与水平线的夹角（向上 / 向下）
- **方向角**：从正北或正南起，向东 / 西旋转的角
- **坡度 / 坡比** $i=\tan\alpha=\dfrac{h}{l}$（铅直高 / 水平距）

## 七、解析几何（part9）

### 7.1 距离与中点

- **距离公式**（part9/02）：$\;AB=\sqrt{(x_2-x_1)^2+(y_2-y_1)^2}$
- **中点公式**：$\;M=\left(\dfrac{x_1+x_2}{2},\,\dfrac{y_1+y_2}{2}\right)$
- **三角形重心坐标**：$\;G=\left(\dfrac{x_1+x_2+x_3}{3},\,\dfrac{y_1+y_2+y_3}{3}\right)$

### 7.2 与轴距离

- 点 $(x_0,y_0)$ 到 $x$ 轴距离 $=|y_0|$，到 $y$ 轴距离 $=|x_0|$
- 与坐标轴平行的线段长度可直接取坐标之差的绝对值

## 八、三视图常识（part8）

- 三视图：主视图（正前方）、左视图（左侧）、俯视图（正上方）
- 长对正、高平齐、宽相等
- 由小正方体堆叠的几何体——主、左视图反映"高度分布"，俯视图反映"底面投影"

## 使用提示

1. **答题前先回忆"使用条件"**：很多失分来自把性质当判定（或反之）。
2. **公式族要成对记忆**：判定 ↔ 性质、定理 ↔ 逆定理。
3. **几何最值常用工具**：垂线段最短、两点之间线段最短、三角不等式、将军饮马（轴对称）、阿氏圆（圆 + 相似）。
4. 与本表配套使用：附录 B 模型图集（一图一结论）、附录 C/D/E 分档题库、附录 F 详解。
