# 三角形三边关系

## 一、图形特征

三角形是由三条**不在同一条直线上**的线段，**首尾顺次相连**所构成的**封闭**平面图形。它具有以下直观特征：

- 由三条线段（**边**）组成；
- 有三个顶点，相邻两边在顶点处相交；
- 有三个内角；
- 是一个封闭图形，能够把平面分成"内部"和"外部"两部分。

## 二、定义与定理

**定义（三角形）**：由不在同一直线上的三条线段首尾顺次相连所组成的图形，叫做三角形。

![三角形 ABC：边 a=BC（对顶点 A）、b=CA（对顶点 B）、c=AB（对顶点 C）](../../figures/svg/def-triangle-basics.svg)

**记号约定**：

- 三角形 $ABC$ 记作 $\triangle ABC$；
- 三个顶点用大写字母 $A, B, C$ 表示；
- 三条边用小写字母 $a, b, c$ 表示，其中 $a$ 表示顶点 $A$ 所**对**的边（即 $BC$），$b$ 表示顶点 $B$ 所对的边（即 $CA$），$c$ 表示顶点 $C$ 所对的边（即 $AB$）。

**三边关系定理**：三角形中，**任意两边之和大于第三边**。即对 $\triangle ABC$ 的三条边 $a, b, c$，有
$$a + b > c, \quad b + c > a, \quad c + a > b.$$

**推论**：三角形中，**任意两边之差的绝对值小于第三边**。即
$$|a - b| < c, \quad |b - c| < a, \quad |c - a| < b.$$

把两条结论合并，常用的判定式为
$$|a - b| < c < a + b.$$

## 三、证明

证明依据：**两点之间，线段最短**（见 part1/01 公理）。

在 $\triangle ABC$ 中，$A$ 和 $C$ 是平面上两个不同的点。从 $A$ 到 $C$ 有两条路径：

- 直接连接：线段 $AC$，长度为 $b$；
- 经过 $B$ 的折线：$A \to B \to C$，长度为 $AB + BC = c + a$。

由公理"两点之间线段最短"知，**折线长度大于线段长度**，即
$$AB + BC > AC, \qquad \text{即} \qquad c + a > b.$$

同理，把 $A, B$ 看作两点、$C$ 看作折线中点，得 $b + a > c$；把 $B, C$ 看作两点、$A$ 看作折线中点，得 $c + b > a$。

综上得到：任意两边之和大于第三边。$\blacksquare$

由 $a + b > c$ 移项得 $a > c - b$；同理由 $b + c > a$ 移项得 $b > a - c$，即 $c - a < b$。两式联合即 $|a - c| < b$，推论得证。

## 四、典型应用

**例 1**　判断下列每组线段能否构成三角形：(1) $3, 5, 7$；(2) $3, 5, 8$。

【思路】依据"任意两边之和大于第三边"，只需检查**最短两边之和**是否大于**最长边**即可。注意"$=$"对应退化为线段的情形，**不**构成三角形。

**解**：

(1) 最短两边之和 $3 + 5 = 8 > 7$（最长边），故 $3, 5, 7$ **能**构成三角形。

(2) 最短两边之和 $3 + 5 = 8$，与最长边 $8$ 相等，三点共线，退化为一条线段，故 $3, 5, 8$ **不能**构成三角形。

**例 2**　已知三角形两边长分别为 $4$ 和 $9$，求第三边 $x$ 的取值范围。

【思路】由三边关系定理及其推论，第三边必须同时满足"大于两边之差"和"小于两边之和"，即 $|9 - 4| < x < 9 + 4$。

**解**：由 $|9 - 4| < x < 9 + 4$ 得
$$5 < x < 13.$$

即第三边的取值范围是 $5 < x < 13$。

**例 3**　一个等腰三角形的周长为 $20\,\text{cm}$，腰长为整数厘米，求腰长的所有可能取值。

![等腰三角形：腰 $x$、底 $20-2x$](../../figures/svg/ex-p3b-01-3.svg)

【思路】设腰长为 $x$，则底边为 $20 - 2x$。需满足两个条件：(i) 底边大于 $0$；(ii) 三边关系——两腰之和 > 底边（这是唯一需要验证的不等式，因为"腰 + 底 > 腰"自动成立）。再由 $x$ 为整数筛选。

**解**：设腰长为 $x\,\text{cm}$，则底边为 $(20 - 2x)\,\text{cm}$。

由 $20 - 2x > 0$，得 $x < 10$；

由两腰之和大于底边：$2x > 20 - 2x$，得 $x > 5$。

故 $5 < x < 10$。又 $x$ 为整数，所以
$$x \in \{6, 7, 8, 9\}.$$

即腰长可能取 $6, 7, 8, 9$ 厘米。

## 五、易错点

1. **"任意"两个字不能漏**：三边关系定理要求**任意**两边之和大于第三边，而不是"某两边之和大于第三边"。例如 $3, 5, 8$ 中，$3 + 8 > 5$、$5 + 8 > 3$ 都成立，但 $3 + 5 = 8$ 不严格大于，所以不能构成三角形。

2. **实操简化**：理论上要检查三个不等式，但实际只需验证**最短两边之和 > 最长边**即可——因为最长边对应的不等式是"最紧"的，它成立其余两个自然成立。这两种说法**等价**，做判断题时用后者更高效。

3. **严格不等号**：定理中是"大于"，**不**包含"等于"。当最短两边之和恰好等于最长边时，三点共线，图形退化为一条线段，**不**构成三角形。

4. **求第三边范围必须用绝对值**：由两边 $a, b$ 求第三边 $x$ 时，结论是 $|a - b| < x < a + b$，**不可**只写 $x < a + b$ 而漏掉下界。

5. **等腰三角形的"腰底"分类讨论**：当题目仅说"两边为 $a, b$"而未说明哪条是腰时，需就"$a$ 为腰"与"$b$ 为腰"两种情况分别讨论，并用三边关系验证每种情况是否成立。

## 六、思路自测题

1. 下列各组线段能否构成三角形：(1) $2, 3, 6$；(2) $4, 4, 7$；(3) $5, 12, 13$？
   💡 提示：分别检查"最短两边之和 > 最长边"是否严格成立。

2. 三角形两边长为 $7$ 和 $10$，求第三边 $x$ 的取值范围；并写出 $x$ 为偶数时的所有可能取值。
   💡 提示：先用 $|10 - 7| < x < 10 + 7$ 得范围，再在范围内筛偶数。

3. 等腰三角形的一边长为 $4\,\text{cm}$，另一边长为 $9\,\text{cm}$，求其周长。
   💡 提示：分"$4$ 为腰"和"$9$ 为腰"两种情况，分别用三边关系检验是否成立，舍去不合理者。

4. 已知三角形三边长分别为 $x, x + 2, x + 4$（$x$ 为正整数），求 $x$ 的取值范围及最小值。
   💡 提示：把最长边和最短两边的和代入"两边之和 > 第三边"，得到关于 $x$ 的不等式后再取正整数。
