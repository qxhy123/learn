# 点、线、面、体

几何的世界由四类最基本的对象构成：点、线、面、体。它们就像建筑的砖、梁、墙、楼，再复杂的几何图形都是由这四类对象按一定关系搭建而成的。本节我们先建立"一眼认出"的直观感觉，再给出严格的定义和最基本的事实（公理），最后通过例题与易错点来巩固。

## 一、图形特征：怎么一眼认出

- **点（Point）**：表示位置的抽象记号，**没有大小、没有形状、没有长度**。在纸上画的"小黑点"只是它的示意图。常用大写字母 $A,B,C,\dots$ 命名，如点 $A$。直观例子：地图上的一座城市、坐标系中的原点。
- **线（Line）**：可以看作点沿某方向**连续运动**留下的轨迹，是**一维**的——只有"长短"而没有"宽窄"。线分**直线**和**曲线**两大类。直观例子：拉紧的绳子（近似直线）、河流的边界（曲线）。
- **面（Face / Surface）**：可以看作线沿某方向连续运动留下的轨迹，是**二维**的——既有长又有宽，但**没有厚度**。面分**平面**和**曲面**。直观例子：黑板表面、桌面（平面）；球的外壳、圆柱的侧面（曲面）。
- **体（Solid）**：可以看作面沿某方向连续运动留下的轨迹，是**三维**的——有长、宽、高。所有的实际物体都是几何体的实例。直观例子：粉笔（圆柱体）、骰子（正方体）、足球（球体）。

一个口诀：**点动成线，线动成面，面动成体**。维度逐级升高：$0 \to 1 \to 2 \to 3$。反过来：**体的表面是面，面的边界是线，线的端点是点**。

## 二、定义

### 1. 直线（Straight Line）

**两端都可以无限延伸**的笔直的线，没有端点，没有长度。

- **基本性质**：经过两个不同的点，**有且只有一条**直线。也就是说，**两点确定一条直线**。
- **表示方法**：
  - 用一个小写字母：直线 $l$、直线 $m$。
  - 用直线上任意两点：直线 $AB$ 或直线 $BA$（**两种写法表示同一条直线**）。

### 2. 射线（Ray）

直线上**一点及其一侧**的部分叫做射线。射线**有且只有一个端点**，另一端无限延伸。

- **表示方法**：射线 $OA$，**端点字母必须写在前面**。
- **重要区别**：射线 $OA$ 与射线 $AO$ **不是同一条射线**——它们的端点不同，延伸方向也不同。

### 3. 线段（Line Segment）

直线上**两点及其之间**的部分叫做线段。线段**有两个端点**。

- **表示方法**：线段 $AB$，或写作 $\overline{AB}$。线段 $AB$ 与线段 $BA$ 是同一条线段。
- **长度**：线段是这三者中**唯一有长度**的（直线、射线都无限长，不谈长度）。线段 $AB$ 的长度记作 $AB$（或 $|AB|$）。

![直线 / 射线 / 线段三者对比：端点数 0 / 1 / 2，延伸方向各异](../figures/svg/def-line-ray-segment.svg)

### 4. 三者的对比表

| 名称 | 端点个数 | 是否有长度 | 能否延伸 |
| :--: | :------: | :--------: | :------: |
| 直线 | $0$ | 无 | 两端都可 |
| 射线 | $1$ | 无 | 一端可 |
| 线段 | $2$ | 有 | 不可 |

## 三、基本事实（公理）

下面三条是几何中关于"点和线"的最基本事实，**无需证明，直接作为推理的起点**：

1. **两点确定一条直线**：经过两个不同的点，有且只有一条直线。
2. **两点之间，线段最短**：连接两点的所有路径（线段、折线、曲线……）中，**线段的长度最小**。
3. **两点间的距离**：连接两点的**线段的长度**，叫做这两点之间的距离。注意，"距离"是一个数，而"线段"是一个图形，二者不要混淆。

## 四、典型应用

### 例 1　过定点的直线有多少条？

问：(1) 平面内过一个已知点 $A$，可以画多少条直线？(2) 过两个已知点 $A,B$，可以画多少条直线？

【思路】回顾公理"两点确定一条直线"。一个点不足以"锁定"方向，因此直线可以朝任意方向；而两个不同的点则唯一地确定了方向。

**解**：(1) 过一点 $A$ 可以画**无数条**直线（方向任意）。(2) 过两点 $A,B$ 有且只有**一条**直线。

### 例 2　三种走法谁最短？

从 $A$ 地到 $B$ 地有三条路线：(i) 沿线段 $AB$ 直走；(ii) 先到 $C$ 再到 $B$，即走折线 $A\to C\to B$；(iii) 沿一条弧线从 $A$ 走到 $B$。比较三种走法的长度。

【思路】"两点之间，线段最短"是直接可用的公理。任何折线或曲线的长度都不会小于连接两端点的线段长度。

**解**：设三种路径长度分别为 $L_1,L_2,L_3$。由公理"两点之间，线段最短"，立即得
$$L_1 \le L_2,\qquad L_1 \le L_3.$$
即沿线段 $AB$ 直走最短。当 $C$ 不在线段 $AB$ 上时（折线真折），有严格不等号 $L_1 < L_2$；同理弧线只要不退化成线段，就有 $L_1 < L_3$。

### 例 3　数轴上的距离

在数轴上，点 $A$ 的坐标为 $-2$，点 $B$ 的坐标为 $5$。求线段 $AB$ 的长度。

【思路】数轴上两点间的距离等于两点坐标之差的**绝对值**，与谁减谁的顺序无关。

![数轴上 $A=-2$、$B=5$，$AB=|5-(-2)|=7$](../figures/svg/ex-p1-01-3.svg)

**解**：
$$AB = |\,5 - (-2)\,| = |7| = 7.$$
即线段 $AB$ 的长度为 $7$。也可写为 $AB = |(-2) - 5| = |-7| = 7$，结果一致。

## 五、易错点 & 反例

1. **三种"线"的端点个数不能混**。直线 $0$ 个端点，射线 $1$ 个，线段 $2$ 个。常见错误：把"直线 $AB$"理解成"以 $A,B$ 为端点的一段"——错了，直线没有端点，$A,B$ 只是用来**标识**直线的两个点，直线仍向两端无限延伸。
2. **射线 $OA$ 与射线 $AO$ 不是同一条射线**。射线的端点字母必须写在前面。反例：从 $O$ 出发沿东向延伸的射线是 $OA$（$A$ 在东侧）；从 $A$ 出发沿西向延伸的射线是 $AO$，它们端点不同、方向不同，是两条**不同**的射线。
3. **直线 $AB$ 与直线 $BA$ 是同一条直线**。直线无端点也无方向，$AB$、$BA$ 只是两种命名方式。把射线的"前后顺序敏感"错误地推广到直线，是常见失误。
4. **"距离"和"线段"不是一回事**。线段是图形，距离是一个非负实数（等于线段的长度）。不能说"距离 $AB$ 与距离 $BA$ 是两个不同的图形"——它们其实是同一个数。
5. **只有线段才能谈长度**。说"直线 $l$ 的长度是 $10\,\text{cm}$"在初中几何里是错误表述：直线无限长，不存在有限长度。

## 六、思路自测题

1. 在同一平面内有 $4$ 个点，任意三点不共线。问：以这些点中的两点为端点的线段共有多少条？经过其中两点能画多少条直线？  
   💡 提示：每两个点确定一条线段，也确定一条直线。所求为从 $4$ 个点中选 $2$ 个的方法数 $C_4^2$，即 $\dfrac{4\times 3}{2}=6$。

2. 一条直线上依次有 $A,B,C,D$ 四点。图中共有几条线段？几条射线？  
   💡 提示：线段由两个端点决定，共 $C_4^2 = 6$ 条；射线必须指明端点，每个点都能向两个方向各发出一条射线，共 $4\times 2 = 8$ 条。

3. 在数轴上，点 $P$ 的坐标为 $x$，点 $Q$ 的坐标为 $-3$，且 $PQ = 5$。求 $x$ 的所有可能值。  
   💡 提示：由 $|x-(-3)| = 5$ 得 $x+3 = \pm 5$，分两种情形讨论。

4. 小明说："过任意三点都能确定一条直线。"小华说："不一定。"谁对？请举例说明。  
   💡 提示：小华对。**三点共线**时只能确定一条直线；**三点不共线**时则不能确定唯一的直线（任何两点都给出一条，共三条不同直线）。

5. 已知 $C$ 是线段 $AB$ 上一点，$AC = 3$，$CB = 4$。线段 $AB$ 的长度是多少？若 $C$ 在直线 $AB$ 上但不在线段 $AB$ 内部呢？  
   💡 提示：第一种情形 $AB = AC + CB = 7$。第二种情形 $C$ 落在线段的延长线上，需要分"$C$ 在 $A$ 外侧"和"$C$ 在 $B$ 外侧"两种情况，分别用 $AB = |AC - CB|$ 或几何位置关系算得 $AB = 1$。
