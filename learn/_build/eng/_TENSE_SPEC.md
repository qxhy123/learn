## 输出
- Write 到指定文件，内容是**关卡数组**（按给定时态顺序），每关 `{ "title", "subtitle", "intro":[卡片], "questions":[题] }`，**不写 id**。合法 JSON。
- `title`：时态中文名（如 `一般现在时`、`现在完成时`）。`subtitle`：一句话点出这个时态「描述什么时间情形」（如 `经常·反复发生的动作与客观事实`）。

## 学新知 intro（每关 6~8 张卡，照样板的丰富度）
单个时态一关，典型卡序：
1. **何时用这个时态** — 它描述的是哪种「时间 + 体」的情形，配一个对比例句让人秒懂。
2. **构成** — 结构公式 + 肯定/否定/疑问三种形式，各配例句（如 `主语 + have/has + 过去分词`）。
3. **核心用法** — 这个时态的几种主要用法，每种配 1~2 个斜体例句。
4. **时间标志词** — 提示该时态的副词/短语（如现在完成时的 `already / yet / just / since / for / ever`）。
5. **易混对比** — 和最容易混的那个时态对比（如 现在完成时 vs 一般过去时），讲清差别和判断方法。**这张卡要深，用「为什么…？因为…」讲清。**
6. **例句精讲 / 典型场景**（按需）— 拆 2~3 个有代表性的句子。
7. **小结** — 一句话 + 构成公式收尾。

## 题目 questions（每关 9~11 道）
schema：`choice{options,answer:0基下标}` / `input{accept:[可接受写法]}` / `judge{answer:bool}` / `match{left,right}`。
- **input 填空是时态课的主力**：给句子挖空考动词正确形式，accept 列全大小写/缩写写法（如 `["has gone","'s gone"]`）。每关 ≥3 道 input。
- **choice**：选正确句子 / 选对的用法 / 选时间标志词。
- **judge**：判断某句时态用法对错（常见中式英语错误很适合）。
- **match**：用法 ↔ 例句、或 时间标志词 ↔ 它提示的含义、或 肯定/否定/疑问 ↔ 对应结构（**right[i] 必须与 left[i] 逐项对齐，别打乱**）。
均衡：choice ≤ 5；judge、match 各 ≥ 1；input ≥ 3。每题写 `explain`（讲清为什么，可含斜体例句）。

- 每关 9~11 题、类型均衡（input≥3）、每题有 explain、答案/下标亲自核对；match 逐项对齐。
- 合法 JSON、关卡顺序与给定时态一致；不写 id、不用 `$`/代码围栏。
