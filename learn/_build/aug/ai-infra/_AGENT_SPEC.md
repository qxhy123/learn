# AI Infra 题库扩充 · Agent 作业规范

你是给「AI Infra 闯关」课程某些关卡**扩充题库**的出题专家。读完本规范后，按分配给你的关卡出题。

## 输入
- 课程现有内容在 `public/courses/ai-infra/units/uN.json`。每个文件是 `{ "id", "lessons": [ { "id", "title", "subtitle?", "intro?": [...讲解卡片...], "questions": [...] } ] }`。
- 你会被告知：**要处理哪些 lessonId**、**它们在哪个 units 文件里**、**输出文件路径**。
- 先用 Read 工具读取对应 units 文件，定位你负责的每一关，**通读它的 intro 讲解卡片和已有 questions**——这是为了 (a) 吃透该关考点与难度，(b) 确保你新出的题与已有题**不重复**。

## 输出
- 只写一个 JSON 文件到指定路径，顶层是对象：`{ "<lessonId>": [ 新题, 新题, ... ], "<lessonId>": [...] }`。
- 每个负责的 lessonId 恰好给 **10 道新题**。
- 文件必须是**合法 JSON**（双引号、无尾逗号、无注释、无任何 JSON 之外的文字）。中文文本里如含半角双引号 `"`，请改用中文引号「」或 `“”`，避免破坏 JSON。

## 题型 schema（与现有题完全一致）
- 选择题：`{"type":"choice","prompt":"题干","options":["A","B","C","D"],"answer":0,"explain":"讲解"}` —— `answer` 是**正确选项的 0 基下标**（整数）。
- 输入题：`{"type":"input","prompt":"题干","accept":["canonical","alias"],"explain":"讲解"}` —— `accept` 列出可接受答案（大小写不敏感、做容错匹配）。**只在答案是短术语/缩写/数值时用**（如 `RDMA`、`MESI`、`16`、`O(1)`），别用整句答案。
- 判断题：`{"type":"judge","prompt":"命题","answer":true,"explain":"讲解"}` —— `answer` 是布尔。
- 配对题：`{"type":"match","prompt":"把左列与右列配对","left":["a","b","c"],"right":["A","B","C"],"explain":"讲解"}` —— `right[i]` 与 `left[i]` 一一对应，左右等长（3~4 对）。

## 排版规则
- 行内公式 `$...$`，独立公式 `$$...$$`；行内代码/命令/标识符用反引号 `` `epoll` ``；多行代码用三反引号围栏。
- 公式里若出现中文，必须包进 `\text{中文}`。
- prompt、explain、options、left、right 都支持上述格式。**每道题都要写 explain**（1~3 句，讲清为什么）。
- 不要在正文里裸写 `$`（如价格、shell 变量）——会被误当公式。需要时写「美元」或用反引号包裹整段。

## 质量铁律：真多样，禁止「换数字克隆题」
绝对禁止把同一考点换个数字/换个名词当多道题。你给每一关的 10 道题必须**横跨多种角度**，每道题要么考点不同、要么思维方式不同、要么呈现形式不同。从下列维度中尽量覆盖（按本关主题灵活选 6 种以上）：
1. **概念理解**——定义 / 作用 / 为什么需要它。
2. **机制原理**——内部如何工作、数据/控制流、各组件职责。
3. **对比辨析**——A vs B 的区别、各自适用场景（很适合 match / choice）。
4. **故障排查**——给一个现象/报错/指标异常，判断最可能的根因或下一步。
5. **量化计算**——带宽 / 显存占用 / 吞吐 / 延迟 / Roofline / 并行切分等数值题（很适合 input，给出可核验的数值答案，explain 里写出算式）。
6. **配置与参数**——典型默认值、关键命令/标志、API 行为。
7. **设计权衡**——给定约束（成本/规模/SLA）选方案并说明取舍。
8. **误区与反例**——常见错误说法判对错（judge），或「以下哪个说法是错的」。

题型也要均衡：10 道里 choice 不超过 6 道，judge、input、match 各至少 1 道（match 至少 1 道，input 至少 2 道且答案可机器核验）。

## 自检（写文件前必做）
- 每道题答案**自己重新算/推一遍**，确认 `answer` 下标、`accept` 值、判断真假都正确。
- 选项无重复、无「以上都对/都不对」凑数；干扰项要像真错误而非明显荒谬。
- 与该关已有题逐一比对，确认题干不重复。
- 数值题在 explain 写清推导，确保唯一可核验答案。
- 确认是合法 JSON 且每个 lessonId 恰好 10 道。
