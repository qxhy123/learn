## 学新知 intro（7~10 张卡，按章灵活）
典型卡序（按内容取舍）：
1. **这一章在解决什么** — 一段话点出本章主题 + 它解决的建模/工程痛点（如「为什么不能一步生成、要一千步去噪」）。
2. **核心概念 / 直觉** — 关键机制的直觉解释（先白话，再上公式）。
3. **数学表达** — 关键公式用 `$...$` / `$$...$$`，最核心的一条可放卡片 `formula` 字段（纯 LaTeX，不含 $）。逐符号解释（$x_t,\beta_t,\bar\alpha_t,\epsilon$ 是什么、维度多少）。重要推导（如闭合形式 $q(x_t|x_0)$、ELBO 分解、DDIM 推广）要给出关键步骤，不能只丢结论。
4. **为什么这样设计** — 用「为什么…？因为…」自问自答讲透动机与取舍（如「为什么预测噪声 $\epsilon$ 而不是直接预测 $x_0$」「为什么 DDIM 可以跳步」「为什么 CFG 不需要单独训练分类器」「为什么 LDM 要先进潜在空间」）。**这是最该深的一张卡，不能省。**
5. **PyTorch 实现** — `body` 里放 Python 代码围栏（见代码规则），照原章节的从零实现，体现本关要点。
6. **关键对比 / 维度演算**（按需）— 如 DDPM vs DDIM、ε/x₀/v 三种预测目标、classifier guidance vs CFG、VP-SDE vs VE-SDE、张量形状逐步演算（很适合配 match 题）。
7. **易错点** — 列表 3~6 条，照原章节常见坑（如训练用 $\bar\alpha_t$ 采样却推理时调度不一致、CFG 尺度过大过饱和、EMA 忘了用在采样上）。
8. **小结** — 一句话收束本关要记住的东西。

## 口吻：正常、清楚的专业表达（务必照 ✅）
同一意思三档对照：
- ❌ **论文腔**：「定义 7.1：正向过程可形式化为马尔科夫核的复合……」「综上所述，证毕」
- ❌ **太大白话 / 俚语**：「这玩意儿说白了就是往图上糊噪声」「随便加点噪声搅一搅」
- ✅ **正常**：「为什么正向加噪能写成一步到位的闭合形式？因为每一步加的都是独立高斯噪声，而高斯的和仍是高斯——把 $t$ 步递推依次展开，方差会累乘出 $\bar\alpha_t$，于是 $q(x_t|x_0)=\mathcal{N}(\sqrt{\bar\alpha_t}\,x_0,(1-\bar\alpha_t)I)$，训练时就能任取一个 $t$ 直接采样，不必逐步模拟。」

要点：用「为什么…？因为…」组织推理；用词正经（重参数化、闭合形式、分数函数、概率流 ODE、无分类器引导）；不用编号定义体，也不用俚语；术语首次出现给中英对照 + 一句白话。深度不能因为口吻变白而下降。

## 公式与代码硬规则
- 行内公式 `$...$`、独立公式 `$$...$$`；**公式内中文必须包 `\text{}`**；不要在正文裸写 `$`。
- 代码只放卡片 `body` 或 `tip`。` ```python ` 起、` ``` ` 收。**代码内部不能有空行**（会把代码块切断）；4 空格缩进、不要 Tab；**代码里别用 `$`**。JSON 字符串里换行写 `\n`，单段 ≤ ~24 行。
- `steps`/`title`/`prompt`/选项 只支持行内 `code` 与 `$...$`，不能放围栏块。

## 题目 questions（每关 10~12 道，考理解不考记忆）
schema：
- `{"type":"choice","prompt","options":[...],"answer":0,"explain"}`（answer 是 0 基下标）
- `{"type":"input","prompt","accept":["epsilon","ε","噪声"],"explain"}`（accept 列全写法；可问公式成分、调度参数、术语、数值）
- `{"type":"judge","prompt","answer":true,"explain"}`
- `{"type":"match","prompt","left":[...],"right":[...],"explain"}`

深度题方向：为什么预测 ε / 为什么 DDIM 能跳步 / CFG 公式里 $w$ 起什么作用、闭合形式与 $\bar\alpha_t$ 演算（给 $\beta$ 调度问某步信噪比/形状）、区分相似概念（DDPM vs DDIM vs Flow Matching、classifier guidance vs CFG、VP vs VE、ε/x₀/v 预测）、判断常见误解对错、给场景选采样器/引导方式/架构。
均衡：choice ≤ 6；judge、match 各 ≥ 1；input ≥ 2。每题都写 `explain`。

### 配对题铁律
`right[i]` 必须是 `left[i]` 的正确答案，**按下标对齐存放，绝对不要把 right 打乱**（前端会自己随机显示）。写完每道 match 逐项核对 left[i] ↔ right[i]。（很适合 符号 ↔ 含义、方法 ↔ 核心思想、采样器 ↔ 特点。）
