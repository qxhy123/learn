1. 双指针是什么

双指针算法，是使用两个下标、两个迭代器、两个节点引用，或者两个边界来共同控制搜索过程的一类技巧。它们可能相向而行，也可能同向而行；可能分别指向左右边界，也可能分别是读指针和写指针、快指针和慢指针。

本质
不是“两个 for 循环”，而是两个位置变量在规则控制下协同移动。
核心价值
减少重复扫描，利用单调性或局部状态，让每个元素最多被访问常数次。
典型场景
有序数组找和、删除重复、移动零、回文判断、合并有序数组、链表找环、最长不重复子串等。

双指针常见载体

数据结构双指针表现形式典型题目
数组左右边界、读写指针、两路归并两数之和 II、删除重复、盛水容器、颜色分类
字符串左右字符、窗口边界回文判断、最长无重复子串、反转字符串
链表快慢指针、前后指针中点、环检测、删除倒数第 N 个结点
区间窗口左右端点最短覆盖、最小子数组长度
注意： 双指针不是万能。它通常依赖某种“结构性信息”，比如有序性、局部单调性、窗口合法性、访问后可丢弃的信息等。如果问题没有这些性质，强上双指针往往会错。

2. 第一性原理：为什么双指针能降复杂度

先看一个最经典的场景：在有序数组中找两数之和等于 target。

暴力法

for i in range(n):
    for j in range(i + 1, n):
        if nums[i] + nums[j] == target:
            return [i, j]

这是枚举所有二元组，复杂度 O(n²)。

双指针法

l, r = 0, n - 1
while l < r:
    s = nums[l] + nums[r]
    if s == target:
        return [l, r]
    elif s < target:
        l += 1
    else:
        r -= 1

为什么这样移动不会漏

  • 如果 nums[l] + nums[r] < target，说明左值太小。由于数组有序，固定 l 时，任何 r' ≤ r 的和都不会更大，因此这一整行都没希望，必须增大 l。
  • 如果 nums[l] + nums[r] > target，说明右值太大。固定 r 时，任何 l' ≥ l 的和都不会更小，因此要减小 r。
核心洞察： 一次比较，不只是判断当前这对元素，还能排除一大片组合。这就是双指针比暴力法快的原因。

4. 相向双指针：两端逼近

这是最经典的一类。通常用于 有序数组、回文判断、区间收缩。两个指针分别位于左右两端，根据当前状态向中间移动。

例 1：两数之和 II（有序数组）

def two_sum(numbers, target):
    l, r = 0, len(numbers) - 1
    while l < r:
        s = numbers[l] + numbers[r]
        if s == target:
            return [l + 1, r + 1]
        if s < target:
            l += 1
        else:
            r -= 1

例 2：判断回文串

def is_palindrome(s):
    l, r = 0, len(s) - 1
    while l < r:
        while l < r and not s[l].isalnum():
            l += 1
        while l < r and not s[r].isalnum():
            r -= 1
        if s[l].lower() != s[r].lower():
            return False
        l += 1
        r -= 1
    return True

例 3：盛最多水的容器

def max_area(height):
    l, r = 0, len(height) - 1
    ans = 0
    while l < r:
        ans = max(ans, min(height[l], height[r]) * (r - l))
        if height[l] < height[r]:
            l += 1
        else:
            r -= 1
    return ans

为什么移动较短边

面积由 min(height[l], height[r]) * (r-l) 决定。宽度每次都会缩小，所以想让面积变大，只能尝试提高短板。移动长板没有意义，因为短板不变，宽度还变小，只会更差或相同。

相向双指针适用信号： 当你从两端看数据更自然，且一次比较后可以明确排除一侧时，优先考虑它。

时序图：相向双指针如何收缩搜索空间

相向双指针的效率来自“收缩区间”，每次移动都意味着某个边界之外的区域彻底失去意义。

5. 同向双指针：读写覆盖与区间扫描

同向双指针中，两个指针都从左向右移动，但职责不同。最常见的是：

  • 读指针：负责扫描原数据；
  • 写指针：负责把保留下来的结果写回前面。

例 1：删除有序数组中的重复项

def remove_duplicates(nums):
    if not nums:
        return 0

    slow = 1
    for fast in range(1, len(nums)):
        if nums[fast] != nums[fast - 1]:
            nums[slow] = nums[fast]
            slow += 1
    return slow

解释

  • fast 负责扫描每个元素；
  • slow 指向“下一个可写位置”；
  • 当前元素如果是新的，就写到 slow，然后 slow += 1。

例 2：移动零

def move_zeroes(nums):
    slow = 0
    for fast in range(len(nums)):
        if nums[fast] != 0:
            nums[slow], nums[fast] = nums[fast], nums[slow]
            slow += 1

这里 slow 表示下一个“非零元素应放置的位置”。一遍扫描后，所有非零都被稳定地移动到前面。

同向双指针常见语义： “读到哪儿了”和“写到哪儿了”，或者“窗口左边界”和“窗口右边界”。

流程图：同向双指针的读写覆盖模型

删除重复、移动零、按条件过滤等问题，经常都能抽象成“fast 读、slow 写”的同向双指针。

6. 快慢指针：链表与环检测

快慢指针本质上也是同向双指针，只不过两者速度不同。最典型的用途是链表，因为链表无法随机访问，不适合下标法，但非常适合用指针追及。

例 1：找链表中点

def middle_node(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
    return slow

当快指针走到尾部时，慢指针正好走到中点。

例 2：判断链表是否有环（Floyd 判圈）

def has_cycle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow == fast:
            return True
    return False

为什么能判环

如果链表无环，快指针会先到 None；如果有环，快指针每轮都比慢指针多走一步，相当于在环上追及，最终一定相遇。

例 3：找到环入口

def detect_cycle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow == fast:
            p = head
            while p != slow:
                p = p.next
                slow = slow.next
            return p
    return None
快慢指针适用信号： 链表、循环结构、追及问题、找中点、找第 k 个相对位置。

时序图：快慢指针在环中追及相遇

快慢指针的本质是速度差。只要存在闭环，快者终会追上慢者。

7. 滑动窗口：动态维护一个合法区间

滑动窗口是双指针中非常重要的一支。你可以把它看作“有约束的同向双指针”：右指针负责扩张窗口，左指针负责在必要时收缩窗口，以保持窗口满足条件。

例 1：最长无重复子串

def length_of_longest_substring(s):
    seen = set()
    left = 0
    ans = 0
    for right, ch in enumerate(s):
        while ch in seen:
            seen.remove(s[left])
            left += 1
        seen.add(ch)
        ans = max(ans, right - left + 1)
    return ans

例 2：长度最小的子数组（和至少为 target）

def min_sub_array_len(target, nums):
    left = 0
    curr = 0
    ans = float('inf')

    for right, x in enumerate(nums):
        curr += x
        while curr >= target:
            ans = min(ans, right - left + 1)
            curr -= nums[left]
            left += 1

    return 0 if ans == float('inf') else ans

滑动窗口为什么通常是 O(n)

因为左右指针都只会单调向右移动，每个元素最多进窗口一次、出窗口一次，所以总移动次数是线性的。

滑动窗口适用信号： 题目要求“连续子数组/连续子串”上的最值、计数或可行性，且窗口合法性可以增量维护。

流程图：滑动窗口的标准控制逻辑

固定模式：先扩张，再判断，满足时更新答案并尽量收缩，不满足则继续扩张。

8. 分区指针：原地划分与交换

这类双指针用于把数组按某种条件拆成几个区域，常常原地完成，节省空间。典型代表是快速排序的 partition、颜色分类、奇偶分组等。

例：按奇偶分组（奇数在前，偶数在后）

def sort_array_by_parity(nums):
    l, r = 0, len(nums) - 1
    while l < r:
        while l < r and nums[l] % 2 == 1:
            l += 1
        while l < r and nums[r] % 2 == 0:
            r -= 1
        nums[l], nums[r] = nums[r], nums[l]
    return nums

例：颜色分类（荷兰国旗问题）

def sort_colors(nums):
    low = mid = 0
    high = len(nums) - 1

    while mid <= high:
        if nums[mid] == 0:
            nums[low], nums[mid] = nums[mid], nums[low]
            low += 1
            mid += 1
        elif nums[mid] == 1:
            mid += 1
        else:
            nums[mid], nums[high] = nums[high], nums[mid]
            high -= 1

关键思想

维护几个区域的含义。例如在颜色分类中：

  • [0, low) 全是 0；
  • [low, mid) 全是 1；
  • (high, n-1] 全是 2；
  • [mid, high] 是待处理区间。
分区指针最重要的不是交换本身，而是“区间语义”——每个指针左边、右边分别表示什么。

9. 归并双指针：两个有序序列协同前进

归并双指针常见于合并两个有序数组、求交集、比较两个流。两个指针分别扫描两个序列，每次取更小者或更符合条件者前进。

例：合并两个有序数组

def merge(nums1, m, nums2, n):
    i, j, k = m - 1, n - 1, m + n - 1
    while i >= 0 and j >= 0:
        if nums1[i] > nums2[j]:
            nums1[k] = nums1[i]
            i -= 1
        else:
            nums1[k] = nums2[j]
            j -= 1
        k -= 1

    while j >= 0:
        nums1[k] = nums2[j]
        j -= 1
        k -= 1

为什么从后往前填

因为 nums1 后面预留了空间，如果从前往后覆盖，会把还没比较的有效元素冲掉；从后往前填，未处理数据始终安全。

例：两个有序数组的交集

def intersection(a, b):
    i = j = 0
    ans = []
    while i < len(a) and j < len(b):
        if a[i] == b[j]:
            ans.append(a[i])
            i += 1
            j += 1
        elif a[i] < b[j]:
            i += 1
        else:
            j += 1
    return ans
归并型双指针的本质： 两个有序来源像两条传送带，谁更小谁先处理，不需要回头。

用例图：双指针算法适合处理的问题

一看到“有序、连续、原地、链表、窗口、合并”这些词，就该高度警觉：可能是双指针。

10. 三数之和：排序 + 双指针

很多中高级题不是“纯双指针”，而是“排序 + 枚举一个维度 + 双指针解决剩余部分”。三数之和是最经典例子。

def three_sum(nums):
    nums.sort()
    ans = []
    n = len(nums)

    for i in range(n - 2):
        if i > 0 and nums[i] == nums[i - 1]:
            continue

        l, r = i + 1, n - 1
        while l < r:
            s = nums[i] + nums[l] + nums[r]
            if s == 0:
                ans.append([nums[i], nums[l], nums[r]])
                l += 1
                r -= 1
                while l < r and nums[l] == nums[l - 1]:
                    l += 1
                while l < r and nums[r] == nums[r + 1]:
                    r -= 1
            elif s < 0:
                l += 1
            else:
                r -= 1
    return ans

为什么复杂度是 O(n²)

  • 外层枚举 i：O(n)
  • 内层双指针 l,r：对每个 i 最多线性移动一次
  • 总复杂度：O(n²)
推广： 很多 k-sum 问题都能靠“排序 + 固定一维 + 双指针解决 2-sum 子问题”来降复杂度。

11. 双指针设计四件套：状态、不变量、移动规则、终止条件

真正能让你稳定做题的不是背题，而是统一框架。任何一道双指针题，优先回答下面四个问题：

1）两个指针分别表示什么状态？

  • 左端点 / 右端点？
  • 读指针 / 写指针？
  • 快指针 / 慢指针？
  • 序列 A 的当前位置 / 序列 B 的当前位置？

2）不变量是什么？

不变量就是循环过程中始终成立的性质，是写对双指针的核心。

题目不变量示例
删除有序数组重复项nums[0:slow] 始终是已去重结果
移动零[0:slow) 始终是已经整理好的非零前缀
滑动窗口[left, right] 始终是当前被维护的窗口
颜色分类low 左边全是 0，high 右边全是 2

3）为什么移动这个指针不会漏解？

这是证明正确性的关键。你必须能说清楚“移动左指针时，哪部分解被整体排除了；移动右指针时，哪部分解失效了”。如果说不清，通常说明双指针还没想透。

4）什么时候停？

  • 相向双指针常是 l < r；
  • 滑动窗口常是 right 扫完整个序列；
  • 链表快慢指针常是 fast and fast.next；
  • 归并常是某一方先走完。
一句话框架： 先定义指针语义，再写不变量，再写移动规则，最后写终止条件。代码自然就长出来了。

总流程图：如何判断一道题能不能用双指针

判断题型的关键不是记名称，而是看“结构信号”：有序、连续、原地、链表、多路合并。

12. 复杂度分析与适用边界

为什么很多双指针题是 O(n)

因为两个指针通常都只单调移动，不会来回震荡。即使有嵌套的 while，总移动次数也受两个指针总步数限制。

模式复杂度特点原因
相向双指针常见 O(n)每轮至少移动一个边界，总共最多 n 次
同向双指针常见 O(n)fast 扫一遍，slow 不会倒退
滑动窗口常见 O(n)left、right 各自最多走 n 步
快慢指针常见 O(n)链表一次线性追及
排序 + 双指针常见 O(n log n) 或 O(n²)排序或外层枚举占主导

什么时候不适合双指针

  • 问题没有顺序结构，移动某个指针无法排除任何搜索空间。
  • 目标不是连续区间，却硬要用窗口。
  • 判断条件无法增量维护，每次都要重新统计整段区间。
  • 答案依赖复杂全局状态，两个局部指针不足以表达。
非常重要： 看到 while 套 while 别立刻认为是 O(n²)。要看指针是否会回退。只要两个指针都只前进，通常还是线性的。

13. 常见坑与排障方法

坑 1：指针语义不清
不知道 slow 是“最后一个合法位置”还是“下一个可写位置”，导致边界错位。
坑 2：终止条件写错
例如相向双指针该写 l < r 却写成 l <= r。
坑 3：移动规则无证明
只知道“网上都这么写”，但说不清为什么不会漏答案。
坑 4：窗口收缩时状态没同步
left 移动了，但计数器、哈希表、sum 没更新。
坑 5：重复元素处理不完整
例如三数之和漏写去重，结果重复答案一堆。
坑 6：原地覆盖顺序错误
合并有序数组若从前往后写，会覆盖未处理数据。
坑 7：链表空指针
快慢指针前必须判断 fast 和 fast.next。
坑 8：把滑动窗口误用在非连续问题上
窗口只适用于连续子串/子数组。

排障方法

  1. 先用自然语言写清楚两个指针分别代表什么。
  2. 在纸上画 5~8 个元素的小例子，模拟每步移动。
  3. 写出循环开始前和结束后的不变量。
  4. 打印每轮的 left/right 或 slow/fast 和关键状态。
  5. 对边界样例做专项测试：空数组、单元素、全重复、全不重复、全零、无解。
真正的错误根源： 大多数双指针 bug，不是代码细节，而是“指针语义”和“不变量”没先想清楚。

14. 刷题路线与练习建议

建议学习顺序

阶段建议题型训练目标
入门反转字符串、回文判断、两数之和 II理解相向双指针
基础删除重复、移动零、合并有序数组理解同向读写与归并
窗口最长无重复子串、最小子数组长度理解滑动窗口的扩张与收缩
链表中点、环检测、删除倒数第 N 个结点理解快慢指针与前后关系
进阶盛水容器、颜色分类、三数之和理解区间排除、分区和去重
综合最小覆盖子串、接雨水、四数之和综合运用不变量与复杂状态

建议训练方式

  • 每道题先不用代码，先说清“两个指针各自是谁”。
  • 再说清“为什么移动这个指针”。
  • 最后写代码，并在代码注释中写出不变量。
最有效的训练法： 把一道题的“暴力法”和“双指针法”并排写出来，对比到底省掉了哪些重复枚举。

最终总结：双指针算法的核心心法

  1. 双指针的本质是两个位置变量协同扫描，不是固定模板。
  2. 它高效的根源是：一次比较能够排除一整片无意义区域。
  3. 优先识别题目属于哪类：相向、同向、快慢、窗口、分区、归并。
  4. 写代码前必须先定义两个指针分别表示什么。
  5. 循环中必须维护不变量，不变量是正确性的核心。
  6. 必须能解释“为什么移动这个指针不会漏解”。
  7. 很多看似双层循环的窗口题，其实仍然是 O(n)，因为指针只前进不回退。
  8. 排序 + 双指针是处理中高级配对/多数组合题的重要套路。
  9. 数组、字符串、链表三大场景中，双指针都非常高频。

推荐复习主线：两数之和 II → 回文判断 → 删除重复 → 移动零 → 最长无重复子串 → 链表中点 → 环检测 → 盛最多水的容器 → 颜色分类 → 三数之和。
