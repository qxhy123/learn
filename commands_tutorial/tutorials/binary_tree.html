1. 二叉树是什么

二叉树（Binary Tree）是一种树形结构，其中每个节点最多有两个子节点，通常称为左孩子（left child）和右孩子（right child）。

核心结构
每个节点保存一个值，以及最多两个指针：left 和 right。
核心特点
具有天然的递归定义：一棵二叉树，要么为空，要么由根节点、左子树、右子树组成。
核心应用
表达层次关系、快速查找、表达式求值、编译器语法树、堆、文件系统组织等。

最常见的节点定义（Python）

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right
注意： 二叉树 ≠ 二叉搜索树。二叉树只是结构约束“最多两个孩子”，而 BST 还额外要求左子树值更小、右子树值更大。

信息图：二叉树的本质模型

二叉树最重要的不是“两个孩子”这件事本身，而是“左/右子树各自仍然是一棵树”，这让递归成为最自然的处理方式。

2. 第一性原理：为什么二叉树天然适合递归

二叉树问题之所以经常用递归，不是因为“大家都这么写”，而是因为它的结构本身就是递归的。

二叉树的递归定义

  • 一棵二叉树可以为空；
  • 如果不为空，它由一个根节点、一个左子树、一个右子树组成；
  • 左子树和右子树本身又是二叉树。

这意味着很多问题都可以写成：

solve(root):
    if root is None:
        return base_case

    left_result = solve(root.left)
    right_result = solve(root.right)

    return combine(root, left_result, right_result)

这个模板能解决什么

问题左子树结果右子树结果如何合并
树的高度左子树高度右子树高度1 + max(left, right)
节点总数左子树节点数右子树节点数1 + left + right
是否平衡左子树是否平衡/高度右子树是否平衡/高度同时检查高度差
最近公共祖先左边是否找到目标右边是否找到目标按存在情况判断
关键认识： 二叉树题里，“递归函数的定义”比代码技巧更重要。你必须先说清楚：这个函数究竟返回什么。

3. 基本术语：节点、边、深度、高度、层

术语含义直观理解
根节点（root）整棵树的起点最上面的节点
父节点 / 子节点上下级关系A 是 B 的父节点，B 是 A 的子节点
叶子节点（leaf）没有孩子的节点树的末端
深度（depth）从根到该节点的边数离根有多远
高度（height）从该节点到最深叶子的边数下面还能延伸多深
层（level）按深度分层同一层的节点深度相同
度（degree）孩子数量二叉树节点度最多为 2
容易混淆： 深度通常从上往下看，高度通常从下往上看。面试里一定要先和对方对齐定义。

结构图：深度、高度、层次关系

很多二叉树题，本质上就是围绕这些基础量展开：深度、高度、路径、父子关系和层次结构。

4. 二叉树的常见类型

类型定义特点
普通二叉树每个节点最多两个孩子无额外顺序约束
满二叉树每个节点要么 0 个孩子，要么 2 个孩子没有“只有一个孩子”的节点
完全二叉树除最后一层外都满，最后一层从左到右连续适合数组存储，堆就是这种结构
完美二叉树所有非叶子都有两个孩子，所有叶子在同一层非常规整
平衡二叉树任意节点左右子树高度差不超过 1避免退化，查询效率更稳定
二叉搜索树 BST左子树值小于根，右子树值大于根中序遍历有序
容易混淆： “满”“完全”“完美”“平衡”是四个不同概念。面试里经常拿它们做概念辨析。

信息图：几种常见二叉树类型对比

把这些概念分清楚之后，很多题目就不容易混了：它们讨论的分别是“结构是否规整”“高度是否受控”“值是否有序”。

5. 二叉树的存储方式

1）链式存储（最常见）

每个节点单独存储，包含值和两个指针。这是绝大多数算法题使用的方式。

2）顺序存储（数组）

主要用于完全二叉树，尤其是堆。若根节点下标为 0，则：

  • 左孩子下标：2*i + 1
  • 右孩子下标：2*i + 2
  • 父节点下标：(i - 1) // 2
方式优点缺点适合场景
链式存储灵活、直观、适合任意树形结构节点分散，指针额外开销大多数二叉树题
数组存储索引访问快，空间紧凑非完全树会浪费空间堆、完全二叉树

6. 深度优先遍历：前序、中序、后序

DFS（Depth-First Search）就是沿着树往下走。二叉树的 DFS 遍历有三种经典顺序：

遍历方式顺序记忆方式
前序遍历根 → 左 → 右先访问自己
中序遍历左 → 根 → 右自己夹在中间
后序遍历左 → 右 → 根最后访问自己

递归模板

def preorder(root):
    if not root:
        return
    visit(root)
    preorder(root.left)
    preorder(root.right)

def inorder(root):
    if not root:
        return
    inorder(root.left)
    visit(root)
    inorder(root.right)

def postorder(root):
    if not root:
        return
    postorder(root.left)
    postorder(root.right)
    visit(root)

它们分别适合什么

  • 前序： 常用于复制树、序列化、表达“先处理根再下探”。
  • 中序： 在 BST 中会得到有序序列。
  • 后序： 常用于删除树、计算高度、路径汇总，因为需要先知道左右子树结果。
记忆诀窍： 三种遍历唯一的区别，就是“访问根节点”的时机不同。

遍历示意图：前序 / 中序 / 后序 一图对比

遍历顺序和“访问根节点”的位置对应：前序最早，中序居中，后序最晚。

7. 广度优先遍历：层序遍历

层序遍历（Level Order Traversal）按层从上到下、从左到右访问节点，本质是 BFS（广度优先搜索），通常用队列实现。

from collections import deque

def level_order(root):
    if not root:
        return []

    res = []
    q = deque([root])

    while q:
        size = len(q)
        level = []
        for _ in range(size):
            node = q.popleft()
            level.append(node.val)
            if node.left:
                q.append(node.left)
            if node.right:
                q.append(node.right)
        res.append(level)

    return res

为什么要先取 size = len(q)

因为队列中此时保存的正是“当前层”的所有节点。固定这个长度，就能一层一层地处理，而不会把下一层混进来。

层序遍历常见扩展： 锯齿层序、每层最大值、右视图、最小深度、层平均值，都可以在这个模板上改。

流程图：层序遍历（BFS）如何逐层展开

层序遍历的关键是“队列”和“按层固定长度”。这两件事把树的层级信息保留下来了。

8. 递归遍历与迭代遍历的关系

递归本质上是系统帮你维护调用栈。迭代遍历则是你自己用栈或队列来模拟这件事。

前序遍历的迭代写法

def preorder_iter(root):
    if not root:
        return []
    res = []
    stack = [root]
    while stack:
        node = stack.pop()
        res.append(node.val)
        if node.right:
            stack.append(node.right)
        if node.left:
            stack.append(node.left)
    return res

中序遍历的迭代写法

def inorder_iter(root):
    res = []
    stack = []
    cur = root
    while cur or stack:
        while cur:
            stack.append(cur)
            cur = cur.left
        cur = stack.pop()
        res.append(cur.val)
        cur = cur.right
    return res

后序遍历的一个常见迭代技巧

def postorder_iter(root):
    if not root:
        return []
    res = []
    stack = [root]
    while stack:
        node = stack.pop()
        res.append(node.val)
        if node.left:
            stack.append(node.left)
        if node.right:
            stack.append(node.right)
    return res[::-1]
本质联系： 递归 DFS = 隐式栈；迭代 DFS = 显式栈；层序遍历 BFS = 队列。

时序图：递归访问节点的调用顺序

理解递归的关键不是背代码，而是明白“什么时候深入子树，什么时候在返回时合并结果”。

9. 二叉搜索树 BST

BST（Binary Search Tree）是一种具有“值有序”性质的二叉树：

  • 左子树所有节点值 < 根节点值；
  • 右子树所有节点值 > 根节点值；
  • 左右子树本身也都是 BST。

BST 最重要的性质

中序遍历 BST，得到的是一个递增序列。

BST 查找

def search_bst(root, val):
    if not root or root.val == val:
        return root
    if val < root.val:
        return search_bst(root.left, val)
    return search_bst(root.right, val)

BST 插入

def insert_into_bst(root, val):
    if not root:
        return TreeNode(val)
    if val < root.val:
        root.left = insert_into_bst(root.left, val)
    elif val > root.val:
        root.right = insert_into_bst(root.right, val)
    return root

BST 删除：最重要也最容易出错

删除节点情况处理方式
没有孩子直接删除
只有一个孩子用孩子顶替自己
有两个孩子常用后继节点（右子树最小值）或前驱节点（左子树最大值）替代
BST 的缺点： 如果插入顺序很差，它可能退化成链表，查找复杂度从 O(log n) 变成 O(n)。这就是为什么需要平衡树。

示意图：BST 的查找、插入、删除逻辑

BST 操作的统一逻辑：根据大小关系不断向左或向右缩小问题规模。

10. 平衡树、完全树、堆的理解

平衡二叉树

如果 BST 退化成链表，性能会很差。平衡树（如 AVL、红黑树）通过旋转等机制控制高度，使查找、插入、删除维持在 O(log n) 级别。

堆（Heap）

堆通常是完全二叉树，并满足堆序性质：

  • 大顶堆：父节点值 ≥ 子节点值
  • 小顶堆：父节点值 ≤ 子节点值
BST 的关注点
强调全局有序搜索：左边小，右边大。
堆的关注点
强调局部最值：根最大或最小，但左右子树之间不要求整体有序。
一个非常重要的区别： 堆不能像 BST 那样高效搜索任意元素，但能高效得到最大/最小值。

11. 经典问题：路径、对称、翻转、直径、LCA

1）最大深度

def max_depth(root):
    if not root:
        return 0
    return 1 + max(max_depth(root.left), max_depth(root.right))

2）翻转二叉树

def invert_tree(root):
    if not root:
        return None
    root.left, root.right = invert_tree(root.right), invert_tree(root.left)
    return root

3）判断是否对称

def is_symmetric(root):
    def mirror(a, b):
        if not a and not b:
            return True
        if not a or not b or a.val != b.val:
            return False
        return mirror(a.left, b.right) and mirror(a.right, b.left)

    return mirror(root.left, root.right) if root else True

4）二叉树直径

def diameter_of_binary_tree(root):
    ans = 0

    def depth(node):
        nonlocal ans
        if not node:
            return 0
        left = depth(node.left)
        right = depth(node.right)
        ans = max(ans, left + right)
        return 1 + max(left, right)

    depth(root)
    return ans

5）最近公共祖先（LCA）

def lowest_common_ancestor(root, p, q):
    if not root or root == p or root == q:
        return root

    left = lowest_common_ancestor(root.left, p, q)
    right = lowest_common_ancestor(root.right, p, q)

    if left and right:
        return root
    return left if left else right
统一视角： 很多经典二叉树题，都可以归到两类：① 遍历型——一路收集信息；② 分治型——让子树返回结果，再在父节点合并。

用例图：二叉树算法常用来解决什么问题

你可以把二叉树题分成“遍历采集信息”“分治返回信息”“利用 BST 性质”“利用层次结构”四大类。

12. 构造、序列化与反序列化

1）由前序 + 中序构造二叉树

前序给你根节点出现顺序，中序告诉你左右子树的划分边界。

def build_tree(preorder, inorder):
    idx = {v: i for i, v in enumerate(inorder)}
    pre_i = 0

    def helper(l, r):
        nonlocal pre_i
        if l > r:
            return None

        root_val = preorder[pre_i]
        pre_i += 1
        root = TreeNode(root_val)

        mid = idx[root_val]
        root.left = helper(l, mid - 1)
        root.right = helper(mid + 1, r)
        return root

    return helper(0, len(inorder) - 1)

2）序列化与反序列化

本质就是把树变成一个线性表示，再从线性表示恢复回来。最常见的做法是前序遍历 + 空节点标记。

def serialize(root):
    vals = []
    def dfs(node):
        if not node:
            vals.append("#")
            return
        vals.append(str(node.val))
        dfs(node.left)
        dfs(node.right)
    dfs(root)
    return ",".join(vals)

def deserialize(data):
    vals = iter(data.split(","))

    def dfs():
        val = next(vals)
        if val == "#":
            return None
        node = TreeNode(int(val))
        node.left = dfs()
        node.right = dfs()
        return node

    return dfs()
本质理解： 序列化不是神秘操作，它只是“用一种固定遍历顺序把结构信息编码出来”。空节点标记是关键，否则树形结构丢失。

流程图：由前序 + 中序构造二叉树

构造题的关键不在代码，而在理解：一种遍历给“根出现顺序”，另一种遍历给“左右边界划分”。

13. 复杂度分析与常见坑

常见复杂度

操作时间复杂度空间复杂度说明
DFS 遍历整棵树O(n)O(h)h 为树高，递归栈深度
BFS 层序遍历O(n)O(w)w 为树的最大层宽
BST 搜索O(h)O(h)平衡时约 O(log n)，退化时 O(n)
计算树高O(n)O(h)每个节点访问一次

二叉树常见坑

坑 1：base case 写错
递归最常见错误。空节点返回值必须和函数定义一致。
坑 2：没搞清函数返回什么
返回高度？返回节点？返回布尔值？返回路径和？必须先定义清楚。
坑 3：前中后序混淆
本质是访问根节点的时机不同，不要死背。
坑 4：层序遍历漏掉按层处理
没固定 size 会导致层信息混乱。
坑 5：BST 删除最难
尤其是两个孩子的情况，别忘了用前驱或后继替换。
坑 6：全局变量污染
做直径、路径和时，返回值和全局最优值要分清。
坑 7：空树边界没处理
根为 None 时，很多题需要直接返回空结果或 0。
坑 8：深度和高度定义混用
写题前先统一术语。

排障方法

  1. 先画一棵 5~7 个节点的小树，用手模拟。
  2. 写出递归函数的“语义说明”：dfs(node) 到底返回什么。
  3. 确认空节点返回值是否合理。
  4. 打印前序遍历结果，看树结构是否符合预期。
  5. 对空树、单节点树、只有左链、只有右链做专项测试。
最底层的错误来源： 大多数二叉树题做错，不是不会写代码，而是“函数定义不清”和“递归返回值不清”。

14. 刷题路线与练习建议

阶段推荐题型目标
入门前中后序遍历、层序遍历、最大深度掌握 DFS/BFS 和递归基础
基础翻转树、对称树、相同树、路径和掌握递归比较和路径处理
进阶平衡二叉树、二叉树直径、最近公共祖先掌握分治返回值设计
BST 专项搜索、插入、删除、验证 BST掌握值有序性质
构造专项由遍历序列构造、序列化/反序列化掌握结构还原思路
综合树形 DP、路径问题、最大路径和掌握“子树返回信息”的高级写法

建议练习顺序

  1. 先彻底掌握前/中/后/层序四种遍历。
  2. 再练“高度、节点数、路径和”这种基础递归题。
  3. 然后练 BST、对称树、翻转树、LCA。
  4. 最后上构造、序列化、树形 DP。
最有效的训练法： 对每道题先回答两个问题——① 这是遍历题还是分治题？② dfs(node) 返回什么？如果这两点清楚，代码通常就不难了。

最终总结：二叉树的核心心法

  1. 二叉树最核心的性质是：左子树和右子树本身仍然是树，所以递归天然成立。
  2. 前序、中序、后序的本质区别只是“访问根节点的时机”。
  3. 层序遍历用队列，深度优先遍历用递归或栈。
  4. 做二叉树题前，先定义清楚递归函数到底返回什么。
  5. BST 的核心性质是左小右大，中序遍历有序。
  6. 完全树强调结构位置，平衡树强调高度差，堆强调局部最值。
  7. 很多经典题都能归结为“遍历采集信息”或“左右子树返回结果后在根处合并”。
  8. 空节点如何返回，是写对递归的关键。
  9. 构造和序列化题，本质是在“树”和“线性表示”之间相互转换。

推荐复习主线：前中后序 → 层序 → 最大深度 → 翻转树 → 对称树 → 路径和 → 平衡树 → 直径 → LCA → 验证 BST → 搜索/插入/删除 BST → 构造树 → 序列化。
