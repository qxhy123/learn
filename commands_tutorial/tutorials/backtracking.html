1. 回溯算法是什么

回溯算法是一种系统枚举解空间的方法。它通常用于“需要找所有解、找一个可行解、或在约束下找最优解”的问题。你可以把它理解为“带撤销能力的 DFS”。

它解决什么
排列、组合、子集、棋盘放置、数独、括号生成、路径搜索、字符串分割、约束满足问题。
它的本质是什么
枚举所有可能路径，但在每一步维护当前路径和候选选择；遇到不合法或无希望的分支就剪掉。
它不是什么
不是一种降低到多项式复杂度的魔法。很多回溯问题本质仍是指数级，只是通过剪枝和约束减少搜索量。

回溯适合的问题特征

特征说明例子
需要枚举所有结果答案不是一个数，而是一批方案全排列、所有子集、所有组合
每一步有多个选择搜索树每层代表一次选择N 皇后每行选择一列
存在约束某些选择会让路径非法数独行列宫不能重复
可以逐步构造解完整解由多个局部选择组成括号生成、IP 地址分割
可以提前判断失败越早剪枝越高效组合总和超过 target 就停止
关键认识： 回溯不是“递归写法”本身。递归只是实现方式；回溯的本质是搜索树上的“选择—探索—撤销”。

信息图：回溯算法的本质模型

回溯的核心不是代码长什么样，而是：把问题变成一棵搜索树，然后按 DFS 方式尝试每条路径。

2. 第一性原理：搜索空间与选择树

从最底层看，回溯解决的是“搜索空间太大但仍需要枚举”的问题。所谓搜索空间，就是所有可能选择序列组成的集合。搜索树的每一层代表一次决策，每条从根到叶子的路径代表一个候选解。

例子：从 [1,2,3] 中生成排列

  • 第 1 层：选择第一个数字，可选 1、2、3。
  • 第 2 层：选择第二个数字，不能再选已用数字。
  • 第 3 层：选择第三个数字。
  • 叶子节点：路径长度为 3，形成一个排列。
搜索树中的一条路径：
[] → [1] → [1,2] → [1,2,3]

另一条路径：
[] → [2] → [2,3] → [2,3,1]
第一性原理问题： “我每一步在做什么选择？选择之后剩下什么？什么时候形成答案？什么时候应该提前停止？” 这四个问题回答清楚，回溯就写出来了。

搜索树图：全排列 [1,2,3]

全排列搜索树中，路径就是当前排列，选择列表就是还没使用的数字，叶子节点就是答案。

3. 回溯三要素：路径、选择、结束条件

回溯题可以统一问三个问题：

要素含义例子：全排列例子：组合
路径 path已经做出的选择当前已选数字序列当前组合
选择列表 choices当前还能选什么未使用数字从 start 到 n 的候选数
结束条件什么时候收集答案或停止path 长度等于 npath 长度等于 k

额外两个关键点

约束条件
判断当前选择是否合法。例如 N 皇后不能同列、同对角线；数独不能同行列宫重复。
剪枝条件
判断继续搜索是否还有意义。例如组合中剩余数字不够 k 个，就可以提前停止。
固定表达式： 回溯函数的参数，就是为了描述“当前已经走到搜索树的哪个节点”。

4. 核心模板：做选择 → 递归 → 撤销选择

所有回溯模板都可以抽象成下面这段伪代码：

result = []

def backtrack(path, choices):
    if 满足结束条件:
        result.append(path 的拷贝)
        return

    for choice in choices:
        if choice 不合法:
            continue

        做选择
        backtrack(新的 path, 新的 choices)
        撤销选择

Python 通用骨架

def backtrack(...):
    if should_stop(...):
        ans.append(path.copy())  # 注意拷贝
        return

    for choice in candidates:
        if not valid(choice):
            continue

        path.append(choice)      # 做选择
        mark(choice)             # 标记状态，例如 used[i] = True

        backtrack(...)

        unmark(choice)           # 撤销标记
        path.pop()               # 撤销选择
最常见 bug： 收集答案时没有拷贝 path，而是直接 ans.append(path)。由于后续还会 pop 修改同一个列表，最终答案会全部变空或全都一样。

流程图：回溯模板的控制流

回溯的关键是撤销选择。没有撤销，就不是在搜索树中回到父节点，而是在污染后续分支。

5. 递归栈与回溯时序

回溯很容易写错，是因为你同时要理解两个东西：搜索树的路径变化，以及函数调用栈的进入/退出。

以路径 [] → [1] → [1,2] → [1,2,3] 为例

path = []
choose 1       -> path = [1]
  choose 2     -> path = [1,2]
    choose 3   -> path = [1,2,3]
    collect answer
    undo 3     -> path = [1,2]
  undo 2       -> path = [1]
  choose 3     -> path = [1,3]
  ...
undo 1         -> path = []
递归不是魔法： 每一层函数调用负责一个搜索树节点；函数返回时，必须把当前层做过的选择恢复掉，让兄弟分支看到干净状态。

时序图：做选择、递归、撤销选择

回溯的时序是对称的：进入下一层前做选择，下一层返回后撤销同一个选择。

6. 回溯、DFS、暴力搜索、动态规划的区别

方法核心是否枚举路径是否缓存状态典型问题
暴力搜索枚举所有可能是否小规模枚举
DFS深度优先遍历图/树不一定通常不缓存最优子结构图遍历、树遍历
回溯DFS + 路径构造 + 撤销选择是通常不缓存排列组合、数独、N 皇后
动态规划复用重叠子问题答案通常不枚举完整路径是最值、计数、可行性
边界判断： 如果你需要列出所有方案，通常是回溯；如果只求最优值且存在大量重叠子问题，通常考虑 DP；如果只是遍历图结构，普通 DFS/BFS 就够了。

7. 排列问题：顺序敏感

排列问题的核心是：同一组元素的不同顺序算不同答案。例如 [1,2,3] 和 [1,3,2] 是两个排列。

无重复元素全排列

def permute(nums):
    ans = []
    path = []
    used = [False] * len(nums)

    def backtrack():
        if len(path) == len(nums):
            ans.append(path.copy())
            return

        for i, x in enumerate(nums):
            if used[i]:
                continue

            used[i] = True
            path.append(x)

            backtrack()

            path.pop()
            used[i] = False

    backtrack()
    return ans

状态解释

变量含义
path当前已经排列好的前缀
used[i]第 i 个数是否已经在当前路径中使用
len(path) == len(nums)排列完成，收集答案
排列题特征： 每一层都从所有元素里选，只是不能选已经在当前路径里的元素，所以通常需要 used。

8. 组合问题：顺序不敏感

组合问题中，顺序不重要。例如 [1,2] 和 [2,1] 是同一个组合。为了避免重复，通常引入 start，只允许从后面的数字继续选。

从 1..n 中选 k 个数

def combine(n, k):
    ans = []
    path = []

    def backtrack(start):
        if len(path) == k:
            ans.append(path.copy())
            return

        # 剪枝：剩余数字不够
        need = k - len(path)
        for x in range(start, n - need + 2):
            path.append(x)
            backtrack(x + 1)
            path.pop()

    backtrack(1)
    return ans

为什么要 start

如果每层都从 1 开始选，就会生成 [1,2] 和 [2,1] 两个重复组合。start 的含义是：当前层只能从上一次选择之后的元素继续选。

组合题特征： 一般不需要 used，而是用 start 控制搜索方向，避免顺序重复。

对比图：排列 vs 组合

排列用 used 防止同一元素重复使用；组合用 start 防止不同顺序重复表示同一个集合。

9. 子集问题：选或不选

子集问题的核心是：每个元素都有“选”或“不选”两种可能。子集可以用回溯写，也可以用二进制枚举写。

回溯写法：每个节点都是答案

def subsets(nums):
    ans = []
    path = []

    def backtrack(start):
        ans.append(path.copy())  # 每个节点都是一个子集

        for i in range(start, len(nums)):
            path.append(nums[i])
            backtrack(i + 1)
            path.pop()

    backtrack(0)
    return ans

另一种写法：选或不选

def subsets(nums):
    ans = []
    path = []
    n = len(nums)

    def dfs(i):
        if i == n:
            ans.append(path.copy())
            return

        # 不选 nums[i]
        dfs(i + 1)

        # 选 nums[i]
        path.append(nums[i])
        dfs(i + 1)
        path.pop()

    dfs(0)
    return ans
子集题特征： 如果题目要求所有子集，通常搜索树中每个节点都是答案；如果要求固定大小子集，则叶子或满足条件时才收集。

10. 剪枝：提前停止无意义搜索

剪枝就是在搜索树上提前判断某个分支不可能产生合法答案或更优答案，于是停止继续向下搜索。

常见剪枝类型

剪枝类型含义例子
合法性剪枝当前选择已经违反约束N 皇后同列/对角线冲突
边界剪枝剩余元素不足以完成答案组合中剩余数量不够 k
排序剪枝排序后发现后续只会更差组合总和超过 target 后 break
最优性剪枝当前分支不可能超过已知最优分支限界、搜索最优解
重复剪枝跳过会生成重复解的分支含重复元素排列/组合

组合总和剪枝

def combination_sum(candidates, target):
    candidates.sort()
    ans = []
    path = []

    def backtrack(start, remain):
        if remain == 0:
            ans.append(path.copy())
            return

        for i in range(start, len(candidates)):
            x = candidates[i]
            if x > remain:
                break  # 排序后，后面更大，直接剪枝

            path.append(x)
            backtrack(i, remain - x)  # 可重复选，所以还是 i
            path.pop()

    backtrack(0, target)
    return ans
剪枝心法： 剪枝必须基于“可证明这个分支不需要搜”。不能因为“感觉没必要”就剪，否则会漏解。

剪枝图：无效分支如何被提前砍掉

剪枝本质上是在搜索树中删除不可能产生有效解的子树。

11. 去重：树层去重与树枝去重

含重复元素的回溯题最容易错。去重前通常需要先排序，让相同元素相邻。

全排列 II：含重复元素

def permute_unique(nums):
    nums.sort()
    ans = []
    path = []
    used = [False] * len(nums)

    def backtrack():
        if len(path) == len(nums):
            ans.append(path.copy())
            return

        for i, x in enumerate(nums):
            if used[i]:
                continue

            # 树层去重：同一层不能重复选择相同值作为分支起点
            if i > 0 and nums[i] == nums[i - 1] and not used[i - 1]:
                continue

            used[i] = True
            path.append(x)

            backtrack()

            path.pop()
            used[i] = False

    backtrack()
    return ans

去重规则怎么理解

概念含义例子
树层去重同一层不能选出等价分支组合/排列中跳过相同起点
树枝允许重复一条路径里如果有多个相同值的不同元素，可能是合法的[1,1,2] 的排列中可以包含两个 1
排序让重复元素相邻方便通过 nums[i] == nums[i-1] 判断重复
去重常见 bug： used[i-1] 的条件方向写错，会导致漏解或重复解。要先想清楚你是在“树层去重”还是“树枝去重”。

信息图：树层去重 vs 树枝去重

排序后，树层去重通常通过“当前值等于前一个值，且前一个值没有在当前路径中使用”来跳过。

12. N 皇后：约束搜索

N 皇后是回溯的经典约束满足问题：在 n×n 棋盘上放 n 个皇后，使任意两个皇后不在同一行、同一列、同一对角线。

搜索建模

  • 每一层表示一行。
  • 选择列表是当前行可放置的列。
  • 路径是已经放置的皇后位置。
  • 约束是列、主对角线、副对角线不能冲突。
def solve_n_queens(n):
    ans = []
    board = [["."] * n for _ in range(n)]

    cols = set()
    diag1 = set()  # r - c
    diag2 = set()  # r + c

    def backtrack(r):
        if r == n:
            ans.append(["".join(row) for row in board])
            return

        for c in range(n):
            if c in cols or (r - c) in diag1 or (r + c) in diag2:
                continue

            board[r][c] = "Q"
            cols.add(c)
            diag1.add(r - c)
            diag2.add(r + c)

            backtrack(r + 1)

            board[r][c] = "."
            cols.remove(c)
            diag1.remove(r - c)
            diag2.remove(r + c)

    backtrack(0)
    return ans
关键技巧： 对角线用 r-c 和 r+c 标识。主对角线上的格子 r-c 相同，副对角线上的格子 r+c 相同。

示意图：N 皇后的列与对角线约束

用集合记录列和两类对角线，可以把合法性判断降为 O(1)。

13. 数独：候选集与约束传播

数独也是约束搜索。每个空格要填 1~9，约束是同一行、同一列、同一 3×3 宫不能重复。

基础回溯写法

def solve_sudoku(board):
    rows = [set() for _ in range(9)]
    cols = [set() for _ in range(9)]
    boxes = [set() for _ in range(9)]
    blanks = []

    for r in range(9):
        for c in range(9):
            ch = board[r][c]
            if ch == ".":
                blanks.append((r, c))
            else:
                rows[r].add(ch)
                cols[c].add(ch)
                boxes[(r // 3) * 3 + c // 3].add(ch)

    def backtrack(idx):
        if idx == len(blanks):
            return True

        r, c = blanks[idx]
        b = (r // 3) * 3 + c // 3

        for num in map(str, range(1, 10)):
            if num in rows[r] or num in cols[c] or num in boxes[b]:
                continue

            board[r][c] = num
            rows[r].add(num)
            cols[c].add(num)
            boxes[b].add(num)

            if backtrack(idx + 1):
                return True

            board[r][c] = "."
            rows[r].remove(num)
            cols[c].remove(num)
            boxes[b].remove(num)

        return False

    backtrack(0)

优化思路

  • 优先填候选数字最少的空格，减少分支。
  • 用 bitmask 代替 set，提高判断速度。
  • 在每一步动态计算候选集，而不是盲目尝试 1~9。
数独回溯的本质： 每个空格是一层决策，候选数字是选择列表，行列宫集合是约束状态。

用例图：回溯算法适合解决哪些问题

回溯最适合“逐步构造答案，并且每一步有约束”的问题。

14. 字符串分割：回文分割、IP 地址复原

字符串分割类回溯的搜索树，每一层通常代表“切出下一段”。选择是当前起点之后的某个结束位置。

回文分割

def partition(s):
    ans = []
    path = []

    def is_pal(l, r):
        while l < r:
            if s[l] != s[r]:
                return False
            l += 1
            r -= 1
        return True

    def backtrack(start):
        if start == len(s):
            ans.append(path.copy())
            return

        for end in range(start, len(s)):
            if not is_pal(start, end):
                continue

            path.append(s[start:end + 1])
            backtrack(end + 1)
            path.pop()

    backtrack(0)
    return ans

复原 IP 地址

def restore_ip_addresses(s):
    ans = []
    path = []

    def valid(seg):
        if len(seg) > 1 and seg[0] == "0":
            return False
        return 0 <= int(seg) <= 255

    def backtrack(start):
        if len(path) == 4:
            if start == len(s):
                ans.append(".".join(path))
            return

        # 剪枝：剩余长度必须能填满剩余段
        remain_chars = len(s) - start
        remain_parts = 4 - len(path)
        if remain_chars < remain_parts or remain_chars > remain_parts * 3:
            return

        for length in range(1, 4):
            if start + length > len(s):
                break
            seg = s[start:start + length]
            if not valid(seg):
                continue
            path.append(seg)
            backtrack(start + length)
            path.pop()

    backtrack(0)
    return ans
字符串分割题套路： 回溯参数常用 start 表示下一段从哪里开始；循环枚举 end 或段长度。

15. 括号生成、电话号码、单词搜索

括号生成

生成 n 对合法括号。约束：左括号数量不能超过 n，右括号数量不能超过左括号数量。

def generate_parenthesis(n):
    ans = []
    path = []

    def backtrack(left, right):
        if len(path) == 2 * n:
            ans.append("".join(path))
            return

        if left < n:
            path.append("(")
            backtrack(left + 1, right)
            path.pop()

        if right < left:
            path.append(")")
            backtrack(left, right + 1)
            path.pop()

    backtrack(0, 0)
    return ans

电话号码字母组合

def letter_combinations(digits):
    if not digits:
        return []

    mp = {
        "2": "abc", "3": "def", "4": "ghi", "5": "jkl",
        "6": "mno", "7": "pqrs", "8": "tuv", "9": "wxyz"
    }

    ans = []
    path = []

    def backtrack(i):
        if i == len(digits):
            ans.append("".join(path))
            return

        for ch in mp[digits[i]]:
            path.append(ch)
            backtrack(i + 1)
            path.pop()

    backtrack(0)
    return ans

单词搜索

def exist(board, word):
    m, n = len(board), len(board[0])

    def dfs(r, c, i):
        if i == len(word):
            return True
        if r < 0 or r >= m or c < 0 or c >= n:
            return False
        if board[r][c] != word[i]:
            return False

        tmp = board[r][c]
        board[r][c] = "#"  # 标记已访问

        found = (
            dfs(r + 1, c, i + 1) or
            dfs(r - 1, c, i + 1) or
            dfs(r, c + 1, i + 1) or
            dfs(r, c - 1, i + 1)
        )

        board[r][c] = tmp  # 回溯恢复
        return found

    for r in range(m):
        for c in range(n):
            if dfs(r, c, 0):
                return True
    return False

16. 复杂度、排障、常见坑与刷题路线

复杂度怎么估算

回溯复杂度通常看搜索树规模：

题型大致复杂度说明
全排列O(n · n!)有 n! 个排列，复制答案需要 O(n)
子集O(n · 2^n)有 2^n 个子集，复制路径有成本
组合 C(n,k)O(k · C(n,k))答案数量本身就是组合数
N 皇后指数级剪枝后远小于 n^n，但仍是搜索问题
数独最坏指数级实际依赖空格数和候选集大小

常见坑

坑 1：忘记撤销选择
导致后续分支被污染，答案错乱。
坑 2：答案没拷贝
ans.append(path) 会保存同一个列表引用。
坑 3：排列组合混淆
排列通常用 used，组合通常用 start。
坑 4：去重条件写反
含重复元素题容易漏解或重复。
坑 5：剪枝不严谨
剪掉了可能产生答案的分支。
坑 6：递归参数含义不清
start、idx、remain 没定义清楚就写代码。
坑 7：共享状态恢复不完整
棋盘、set、visited、计数器必须恢复。
坑 8：复杂度超过限制
回溯本质常是指数级，必须看输入规模。

排障流程

  1. 画出前两层搜索树，看路径和选择是否正确。
  2. 打印递归入口：depth, path, choices。
  3. 确认结束条件是否过早或过晚。
  4. 确认每个 append 都有对应 pop，每个 mark 都有 unmark。
  5. 确认答案收集时使用拷贝。
  6. 含重复元素时，先排序，再检查去重发生在树层还是树枝。
  7. 剪枝前先跑无剪枝版本验证正确性，再逐步加剪枝。

最终总结：回溯算法核心心法

  1. 回溯不是模板，而是搜索树上的 DFS。
  2. 每道题先明确：路径、选择列表、结束条件。
  3. 排列看顺序，通常用 used；组合不看顺序，通常用 start。
  4. 每次做选择后必须撤销选择。
  5. 收集答案时必须拷贝路径。
  6. 剪枝必须有逻辑依据，不能凭感觉剪。
  7. 含重复元素先排序，再做树层去重。
  8. 棋盘/网格题要恢复 visited、board、set 等共享状态。
  9. 复杂度通常是指数级，要结合输入规模判断是否可行。

推荐练习顺序：子集 → 组合 → 全排列 → 组合总和 → 子集 II → 全排列 II → 括号生成 → 回文分割 → N 皇后 → 数独 → 单词搜索。
