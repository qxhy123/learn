# Chapter 04: Functions and Decomposition

## What You Will Build

Extract reusable functions from one long script into smaller units.

## Core Concepts

- parameters
- return values
- local scope
- decomposition

## Code Walkthrough

Split one long task-processing script into small functions for parsing input,
formatting output, and updating task data.

## Common Mistakes

- extracting functions without giving them a clear responsibility
- passing too much shared state instead of narrowing inputs and outputs

## Drills

- concept check: explain how parameters and return values shape a function
- code reading: identify the responsibility of each function in a split script
- hands-on change: extract one repeated code path into a named helper

## Checkpoint

Explain how functions reduce duplication in a CLI tool.

## Glossary

| English | 中文 | Meaning |
| --- | --- | --- |
| parameter | 参数 | An input received by a function. |
| decomposition | 拆分 | Breaking a larger problem into smaller focused functions. |
