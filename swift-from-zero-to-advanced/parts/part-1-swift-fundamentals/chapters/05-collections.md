# Chapter 05: Collections

## What You Will Build

Store and update task items using arrays, dictionaries, and sets.

## Core Concepts

- arrays
- dictionaries
- sets
- iteration over collections

## Code Walkthrough

Track tasks in a few small collections and compare how each structure changes
lookup, ordering, and uniqueness behavior.

## Common Mistakes

- choosing a collection based on habit instead of access pattern
- forgetting that sets remove duplicates and arrays preserve order

## Drills

- concept check: choose the right collection for a small scenario
- code reading: inspect how collection updates affect stored task data
- hands-on change: replace one collection with a better fit and explain why

## Checkpoint

Compare array ordering with set uniqueness.

## Glossary

| English | 中文 | Meaning |
| --- | --- | --- |
| array | 数组 | An ordered collection of values. |
| dictionary | 字典 | A collection of key-value pairs for lookup by key. |
