# Chapter 01: Swift Setup and First Program

## What You Will Build

A tiny Swift command-line program that prints output and reads command-line arguments.

## Core Concepts

- toolchain
- source file
- compilation vs execution

## Code Walkthrough

Start with a single-file Swift program, run it with `swift`, and then inspect
how command-line arguments reach `main.swift`.

## Common Mistakes

- confusing script execution with building an executable
- assuming command-line arguments include the program name automatically

## Drills

- concept check: identify the role of `swift` in the toolchain
- code reading: trace where a printed line and its arguments come from
- hands-on change: add one extra argument and print it clearly

## Checkpoint

Explain what happens between source code and program output.

## Glossary

| English | 中文 | Meaning |
| --- | --- | --- |
| toolchain | 工具链 | The compiler, runtime, and commands used to build and run Swift code. |
| command-line argument | 命令行参数 | Input provided to the program when it starts. |
