# Chapter 02: Constants, Variables, and Types

## What You Will Build

A tiny model of task data using constants, variables, and explicit types.

## Core Concepts

- `let`
- `var`
- type inference
- annotations

## Code Walkthrough

Model a task title, completion flag, and priority value to compare inferred and
explicitly declared types.

## Common Mistakes

- using `var` when a value should stay immutable
- adding type annotations everywhere instead of where they improve clarity

## Drills

- concept check: explain the semantic difference between `let` and `var`
- code reading: predict the inferred type of each sample property
- hands-on change: refactor one value from inferred to explicit typing

## Checkpoint

Explain when explicit type annotations improve clarity.

## Glossary

| English | 中文 | Meaning |
| --- | --- | --- |
| constant | 常量 | A value declared with `let` and not reassigned. |
| type inference | 类型推断 | Swift infers a type from the value and context. |
