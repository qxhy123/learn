## Task 1: part14/01 多种函数综合 ⭐

**File:** `chuzhong_algebra/part14-comprehensive/01-functions-comprehensive.md`

Title: `# 多种函数综合`

**一例速记**：一道题里出现一次函数 + 反比例 / 一次 + 二次 / 反比例 + 二次同时存在 → 联立求交点、利用图象比较大小、综合求解析式/参数。**钥匙：联立方程 + 数形结合**。

### 引入题
> 已知一次函数 $y_1 = -x + 4$ 与反比例函数 $y_2 = \frac{k}{x}$ 相交于 $A(1, 3), B$ 两点。求 $k$、点 $B$、以及 $y_1 > y_2$ 的 $x$ 范围。

### 思维路径还原（12-18 行）
> "$A(1, 3)$ 在反比例上 → $k = 1 \times 3 = 3$，故 $y_2 = \frac{3}{x}$  
> 求另一交点 $B$：联立 $-x + 4 = \frac{3}{x}$ → $-x^2 + 4x = 3$ → $x^2 - 4x + 3 = 0$ → $x = 1$ 或 $x = 3$  
> 已知 $x = 1$ 对应 $A$ → $B$ 对应 $x = 3$，代入 $y_1$ 得 $y = 1$ → $B(3, 1)$  
> 求 $y_1 > y_2$ 的范围 = 一次函数图象在反比例图象**上方**的 $x$ 范围  
> 看图（数形结合）：两图象交于 $A(1,3)$ 和 $B(3,1)$ → 一次函数在两交点之间区域**下方**，区间外…  
> 严格分析：$x < 0$ 反比例在三象限 $< 0$，一次函数 $4 - x > 0$（$x < 4$）→ $y_1 > y_2$  
> $0 < x < 1$ 反比例陡升 $> y_1$ → $y_1 < y_2$  
> $1 < x < 3$ 反比例下降，一次函数也下降但更慢 → $y_1 > y_2$  
> $x > 3$ 反比例靠近 0，一次函数 $< 1$ → $y_1 < y_2$  
> 合并：$y_1 > y_2$ 的解集是 $x < 0$ 或 $1 < x < 3$  
> **关键反射**：多函数综合 → 联立方程 + 数形结合，必画图 + 必标交点。"

### 抽象成方法
**3 类题型**：
1. **求交点**：联立两函数方程消 $y$ 得关于 $x$ 的方程
2. **大小比较**：化为图象高低关系（呼应 toolkit/09 数形结合）
3. **参数求范围**：含参函数 + 约束条件 → 求参数范围

**关键技能**：
- 一次 + 反比例联立 → 二次方程
- 二次 + 反比例联立 → 三次方程（少见，可避开）
- 二次 + 一次联立 → 二次方程

### 模型变形
- 三函数同图
- 函数交点恰为某特殊点（如 $x$ 轴上）
- 含参函数与函数交点个数讨论（用判别式）

### 思考路标（≥6 条）
- 见多函数综合 → 必画图 + 必标交点
- 求交点 → 联立消 $y$
- 求大小关系 → 图象高低
- 含参题 → 判别式 + 韦达
- 求面积 → 选好底 + 求高（铅垂高法）
- 答案常为区间或离散点集

### 应用例题 3 例
1. 一次 + 反比例联立（同引入题）
2. **一次 + 二次综合** —— 一次 $y_1 = -x$ 与二次 $y_2 = x^2 - 2x$ 交点
3. **求面积** —— 一次 + 反比例围成区域的面积（用铅垂高法）

## Task 2: part14/02 二次函数与几何综合 ⭐

**File:** `chuzhong_algebra/part14-comprehensive/02-quadratic-fn-with-geometry.md`

Title: `# 二次函数与几何综合`

**一例速记**：二次函数压轴题"标配三件套"——抛物线 + 直线 + 动点。常考：求解析式 / 求面积 / 求等腰直角三角形 / 求平行四边形。

### 引入题
> 抛物线 $y = -x^2 + 2x + 3$ 与 $x$ 轴交于 $A, B$（$A$ 左），与 $y$ 轴交于 $C$。$P$ 是抛物线 $BC$ 段上动点。  
> (1) 求 $A, B, C$ 坐标和直线 $BC$ 解析式  
> (2) 求 $\triangle PBC$ 面积最大值（呼应 part10/08 铅垂高法）  
> (3) 是否存在 $P$ 使 $\triangle OPC$ 是等腰三角形？若存在求 $P$

### 思维路径还原（12-18 行）
> "**(1)** 与 $x$ 轴：$-x^2+2x+3=0$ → $x=-1, 3$ → $A(-1,0), B(3,0)$；与 $y$ 轴：$C(0, 3)$  
> 直线 $BC$：经过 $(3,0), (0,3)$ → $y = -x + 3$  
> **(2)** 设 $P(t, -t^2+2t+3)$（$0 < t < 3$），用铅垂高：  
> 过 $P$ 作 $x$ 轴垂线交 $BC$ 于 $Q(t, -t+3)$  
> 铅垂高 $h = (-t^2+2t+3) - (-t+3) = -t^2+3t$（$0<t<3$ 时正）  
> 水平宽 $|x_B - x_C| = 3$  
> $S = \frac{1}{2} \cdot 3 \cdot (-t^2+3t) = \frac{3}{2}(3t-t^2)$，配方 $= -\frac{3}{2}(t-\frac{3}{2})^2 + \frac{27}{8}$  
> $t = \frac{3}{2}$ 时最大值 $\frac{27}{8}$（呼应 part10/08）  
> **(3) 等腰三角形分类讨论**：$\triangle OPC$ 三种情形 $OP=OC$、$OP=PC$、$OC=PC$  
> 设 $P(t, -t^2+2t+3)$ 在抛物线 $BC$ 段，$O(0,0), C(0,3)$  
> 逐个情形列方程解，每个最多 2 个 $t$ 值  
> **关键反射**：二次函数 + 几何综合 → 三步：(1) 求基本元素 (2) 铅垂高求面积 (3) 分类讨论几何条件。"

### 抽象成方法
**3 类常考几何条件**：
1. **三角形面积**：铅垂高法
2. **等腰三角形**：三边距离公式 + 3 情形分类
3. **直角三角形**：勾股逆定理 + 3 情形分类
4. **平行四边形**：对角线互相平分（中点公式） + 3 情形分类

### 模型变形
- 抛物线 + 切线 / 切圆
- 含参抛物线 + 几何
- 多动点（如 $P$ 和 $Q$ 同时动）

### 思考路标（≥6 条）
- 见抛物线 + 几何 → 用铅垂高 / 中点公式 / 距离公式
- 面积最值 → 铅垂高 → 二次函数最值
- 等腰 → 3 情形
- 直角 → 3 情形
- 平行四边形 → 中点公式 + 3 配对情形
- 综合题先求基本元素，再分小问

### 应用例题 3 例
1. 面积 + 等腰（同引入题简化版）
2. 抛物线 + 直角三角形存在性
3. 抛物线 + 平行四边形存在性

## Task 3: part14/03 函数中的存在性问题 ⭐

**File:** `chuzhong_algebra/part14-comprehensive/03-existence-in-functions.md`

Title: `# 函数中的存在性问题`

**一例速记**：题问"是否存在 $P$ 使 ..." → **必分类讨论 + 必列方程 + 必检验**。"存在则求出，不存在说明理由"。

### 引入题
> 抛物线 $y = x^2 - 2x - 3$ 与 $x$ 轴交于 $A(-1, 0), B(3, 0)$。在抛物线上是否存在点 $P$ 使 $\triangle PAB$ 是等腰直角三角形？

### 思维路径还原（12-18 行）
> "存在性问题第一步：**列出所有可能性**。  
> 等腰直角三角形 = 等腰 + 一直角。$\triangle PAB$ 中 $AB = 4$  
> 三个可能的直角顶点：$P, A, B$（直角分别在 $P$, $A$, $B$）  
> 三个可能的等腰情形：$PA=PB$、$PA=AB$、$PB=AB$  
> 组合：等腰直角 → 直角顶点是斜边中点 → 三情形：  
>   情形 1：直角顶点 $A$ → $\triangle PAB$ 中 $\angle A = 90°, PA = AB = 4$  
>   情形 2：直角顶点 $B$ → $\angle B = 90°, PB = AB = 4$  
>   情形 3：直角顶点 $P$ → $\angle P = 90°, PA = PB$ → $P$ 在 $AB$ 中垂线（$x=1$）上且 $PA \perp PB$  
> 每种情形：设 $P(t, t^2-2t-3)$ 在抛物线上，列条件方程  
> 情形 1：$\angle A = 90°$ → $PA \perp AB$ → $P$ 在过 $A$ 垂直 $x$ 轴的直线上 → $t = -1$ → $P(-1, 0) = A$ 舍  
> 情形 2：$\angle B = 90°$ → 同理 $t = 3 = B$ 舍  
> 情形 3：$P$ 在 $x=1$ 上 → $t = 1$ → $P(1, -4)$；验证 $PA = PB = \sqrt{4 + 16} = \sqrt{20}$ ✓，$PA \perp PB$ 由对称性自然成立  
> 答：存在唯一 $P(1, -4)$  
> **关键反射**：存在性 → 列举所有情形 → 逐个列方程解 → 检验排除不合理解。"

### 抽象成方法
**4 步标准流程**：
1. **列出所有可能性**（哪两个量相等、哪个角直角、哪两点对角线）
2. **每种情形设元 + 列方程**
3. **解方程**（注意 $\Delta$ 与定义域）
4. **检验**（坐标是否在题目要求范围内、是否退化为已知点）

**5 类存在性**：等腰 / 直角 / 等腰直角 / 平行四边形 / 相似

### 思考路标（≥6 条）
- 见"是否存在 $P$" → 列举所有可能性
- 见"等腰" → 3 情形
- 见"直角" → 3 情形
- 见"等腰直角" → 3 情形（每种情形含 1 个直角 + 1 个等腰约束）
- 见"平行四边形" → 3 情形（按对角线配对）
- 不存在时必"说明理由"

### 应用例题 3 例
1. 等腰直角存在性（同引入题）
2. 平行四边形存在性
3. 相似三角形存在性

## Task 4: part14/04 函数图象上的动点 ⭐

**File:** `chuzhong_algebra/part14-comprehensive/04-moving-points-on-graph.md`

Title: `# 函数图象上的动点问题`

**一例速记**：动点 $P$ 在抛物线上 → 设 $P(t, f(t))$，把题目要求的几何量（面积/距离/线段长）用 $t$ 表达，再求最值/特殊值。**动 → 静用参数 $t$**。

### 引入题
> 抛物线 $y = x^2 - 2x$，$P$ 是抛物线上 $0 \leq x \leq 3$ 的动点。求 $P$ 到直线 $y = x$ 的距离最大值。

### 思维路径还原（12-18 行）
> "$P$ 在抛物线上 → 设 $P(t, t^2 - 2t)$，$0 \leq t \leq 3$  
> 点到直线 $y = x$（即 $x - y = 0$）的距离公式：$d = \frac{|x_P - y_P|}{\sqrt{2}} = \frac{|t - (t^2-2t)|}{\sqrt{2}} = \frac{|-t^2+3t|}{\sqrt{2}}$  
> 在 $0 \leq t \leq 3$ 范围内，$-t^2 + 3t = t(3-t) \geq 0$，所以 $|\cdot| = -t^2+3t$  
> $d(t) = \frac{-t^2+3t}{\sqrt{2}}$  
> 配方：$d(t) = \frac{1}{\sqrt{2}} \cdot \left[-(t - \frac{3}{2})^2 + \frac{9}{4}\right]$  
> $t = \frac{3}{2}$ 时最大，$d_{\max} = \frac{9}{4\sqrt{2}} = \frac{9\sqrt{2}}{8}$  
> 对应 $P(\frac{3}{2}, -\frac{3}{4})$  
> **关键反射**：动点最值 → 设参数表达目标 → 化为关于参数的二次函数 → 顶点法。"

### 抽象成方法
**4 步标准流程**：
1. **设参数**：动点在曲线上 → 用一个 $t$ 表达坐标
2. **几何量代数化**：用 $t$ 表达面积 / 距离 / 周长等
3. **化为函数**：通常变成关于 $t$ 的二次函数
4. **求最值**：配方 + 检验 $t$ 是否在定义域内

**常见目标量**：
- 三角形面积 → 铅垂高法
- 点到直线距离 → 距离公式
- 周长 → 距离之和
- 两距离之和（最值）→ 将军饮马思想

### 思考路标（≥6 条）
- 见"动点在曲线上" → 设 $P(t, f(t))$
- 见"求最值" → 化为参数的二次函数 + 顶点法
- 三角形面积 → 铅垂高法（part10/08）
- 点到直线距离 → 距离公式
- 两点距离 → 平方避根号
- **必检查 $t$ 范围**

### 应用例题 3 例
1. 距离最值（同引入题）
2. 三角形面积最值
3. 周长最值（点对称变换 + 共线最短）

## Task 5: part14/05 新定义型代数题 ⭐

**File:** `chuzhong_algebra/part14-comprehensive/05-new-definition.md`

Title: `# 新定义型代数题`

**一例速记**：题目给一个**新运算 / 新函数 / 新概念**（如 $a * b = a^2 - 2b$ 或 "$f(x)$ 的卡比函数"），考察对定义的**即时理解与运用**。**首要任务：读懂定义，再代公式**。

### 引入题
> 定义 $a \heartsuit b = 2a + b^2$。求 $3 \heartsuit (-2)$ 和方程 $x \heartsuit 1 = 10$ 的解。

### 思维路径还原（12-18 行）
> "**第一步：读懂定义**——'$a \heartsuit b$' 表示一个新运算，等于 $2a + b^2$  
> （不要被 $\heartsuit$ 唬住，它就是一个**两个变量到一个表达式的映射规则**）  
> **第二步：直接代入**  
> $3 \heartsuit (-2) = 2 \cdot 3 + (-2)^2 = 6 + 4 = 10$  
> **第三步：解方程**  
> $x \heartsuit 1 = 10$ → $2x + 1^2 = 10$ → $2x + 1 = 10$ → $x = \frac{9}{2}$  
> **关键反射**：新定义题 = '看定义 → 代符号 → 用已学方法解'。新符号不可怕，它只是给一个表达式起了个新名字。  
> 复杂版：'$f(x) = $ 关于 $x$ 的新函数' → 把 $f$ 当成已知函数，用已学的解析式 / 图象方法处理。  
> 求解关键：**别让新符号吓住，把它替换成具体表达式后用老方法解**。"

### 抽象成方法
**新定义题的 3 步策略**：
1. **读懂定义**：把陌生符号翻译成熟悉的式子
2. **直接代入**：按定义代入计算或求解
3. **不要被符号唬住**：实质是已学方法的运用

**3 类常见新定义**：
1. **新运算**（如 $a * b = $ 某表达式）
2. **新函数**（如 "$f(x) = $ ..."）
3. **新数 / 新集合**（如 "好数" 满足某性质）

### 思考路标（≥6 条）
- 见陌生符号 → 先读定义
- 把符号**翻译**成具体表达式
- 用已学的方法解（不是发明新方法）
- 多读 2-3 遍定义，画几个示意例子
- 实质：测试**即时学习能力**
- 答案要符合定义的限制（如新数有取值范围）

### 应用例题 3 例
1. 新运算（同引入题）
2. **新函数** —— 定义 $\{x\} = x - \lfloor x \rfloor$（小数部分），求 $\{3.7\}$ 和方程 $\{2x\} = 0.3$
3. **新数** —— 定义"$x$ 是数 $\sqrt{x}$ 的平方"，求满足某条件的 $x$

## Task 6: part14/06 含绝对值/分段题型 ⭐

**File:** `chuzhong_algebra/part14-comprehensive/06-piecewise-and-absolute.md`

Title: `# 含绝对值与分段函数题型`

**一例速记**：含绝对值 → **分类讨论**（$\geq 0$ 与 $< 0$）；含分段 → **按区间分别处理 + 拼接**。

### 引入题
> 解方程 $|x - 1| + |x - 3| = 4$。

### 思维路径还原（12-18 行）
> "含两个绝对值，要分类讨论。两个临界点：$x = 1$ 和 $x = 3$。  
> **情形 1：$x < 1$** → $|x-1| = 1-x$, $|x-3| = 3-x$  
> 方程 $(1-x) + (3-x) = 4$ → $4 - 2x = 4$ → $x = 0$ ✓（在 $x<1$ 范围内）  
> **情形 2：$1 \leq x \leq 3$** → $|x-1| = x-1$, $|x-3| = 3-x$  
> 方程 $(x-1) + (3-x) = 4$ → $2 = 4$ 矛盾，**无解**  
> **情形 3：$x > 3$** → $|x-1| = x-1$, $|x-3| = x-3$  
> 方程 $(x-1) + (x-3) = 4$ → $2x - 4 = 4$ → $x = 4$ ✓  
> **数轴几何解释（验证）**：$|x-1| + |x-3|$ 是数轴上 $x$ 到 1 和 3 的距离之和；当 $1 \leq x \leq 3$ 时恒为 2，矛盾 = 4 时无解；其他情形时距离和 = $2 \cdot$（$x$ 离区间中点的距离）+ 2  
> 答：$x = 0$ 或 $x = 4$  
> **关键反射**：含绝对值方程 → 按绝对值内表达式正负分类讨论；含分段函数 → 按区间分别处理后拼接。"

### 抽象成方法
**含绝对值的解题流程**：
1. **找临界点**（每个 $|\cdot|$ 内表达式 = 0 的点）
2. **分情形**（按临界点把数轴分成几段）
3. **每段去绝对值**（按内部正负去掉绝对号）
4. **解各段方程 + 检验是否在该段内**
5. **合并所有有效解**

**分段函数题**：
- 按定义域分段写出解析式
- 求值时**先判断 $x$ 在哪段**再代入
- 求图象时按段画并标清分界点

### 思考路标（≥6 条）
- 见 $|x - a|$ → 数轴距离意义
- 含一个绝对值 → 2 类讨论
- 含两个绝对值 → 3 类（按 2 个临界点切数轴）
