## Task 1: part3/01 函数定义（模板 C）

Title: `# 函数的概念与三要素`

涵盖：
- **函数定义**：设 $A, B$ 是两个非空数集，按某种确定的对应关系 $f$，对集合 $A$ 中任意一个元素 $x$，在 $B$ 中都有**唯一**确定的元素 $y$ 与之对应 → $f: A \to B$
- **三要素**：**定义域** $A$、**对应关系** $f$、**值域**（$\{f(x) \mid x \in A\}$，是 $B$ 的子集）
- **函数的判断**：① 一对多 → 不是函数；② 多对一 → 是函数（如 $y = x^2$）
- **同一函数判断**：定义域 + 对应关系 同时相同 → 同一函数（与字母无关 $f(x) = x^2$ 与 $f(t) = t^2$ 同）
- **三种表示法**：解析式、列表、图象
- **典型应用** 3 例：
  - 例 1：判断 $y = \sqrt{x-1} \cdot \sqrt{x+1}$ 与 $y = \sqrt{x^2-1}$ 是否同一函数（前者 $x \geq 1$，后者 $x \leq -1$ 或 $x \geq 1$，**定义域不同 → 不同**）
  - 例 2：求 $f(x+1) = x^2 - 2x$ 时 $f(x)$ 的解析式（令 $t = x+1$ → $f(t) = (t-1)^2 - 2(t-1) = t^2 - 4t + 3$）
  - 例 3：抽象函数题 —— $f(x) + 2 f(\frac{1}{x}) = x$，求 $f(x)$（构造方程组，呼应 toolkit/06）
- **易错点**：一对多不是函数；同一函数三要素都要核对；$f$ 是关系不是变量
- **自测题** 4 题

## Task 2: part3/02 定义域与值域（模板 C）

Title: `# 定义域与值域的求法`

涵盖：

**定义域求法**：
- 整式：$\mathbb{R}$
- 分式：分母 $\ne 0$
- 偶次根式：被开方数 $\geq 0$
- 对数：真数 $> 0$、底数 $> 0$ 且 $\ne 1$
- $\tan x$：$x \ne \frac{\pi}{2} + k\pi$
- 复合函数：所有限制取**交集**

**值域求法**（5 大方法）：
1. **观察法**：简单函数直接观察
2. **配方法**：二次函数
3. **单调性法**：用单调性求端点值
4. **换元法**：见 $\sqrt{ax+b}$ 设 $t = \sqrt{ax+b}$
5. **判别式法**：分式函数 $y = \frac{ax^2+bx+c}{dx^2+ex+f}$ 化为关于 $x$ 的二次方程，用 $\Delta \geq 0$

**典型应用** 3 例：
- 例 1：求 $f(x) = \sqrt{x-1} + \frac{1}{x-2}$ 的定义域（$x \geq 1$ 且 $x \ne 2$）
- 例 2：求 $f(x) = x^2 - 4x + 3$ 在 $x \in [0, 3]$ 的值域（配方求顶点 + 端点比较）
- 例 3：换元法 —— $y = x + \sqrt{1-2x}$（令 $t = \sqrt{1-2x}$）

**易错点**：忘记交集；含参时讨论；换元后注意 $t$ 范围

**自测题** 4 题

## Task 3: part3/03 单调性 ⭐（模板 D）

Title: `# 函数的单调性`

**一例速记**：
> 定义法：取 $x_1 < x_2$ 比较 $f(x_1)$ 与 $f(x_2)$ 的大小  
> **三步法**：①取值（$x_1 < x_2$ 在区间内）②作差 $f(x_1) - f(x_2)$ ③化简判号

### 一、引入题
> 用定义法判断 $f(x) = \frac{x}{x+1}$ 在 $(-1, +\infty)$ 上的单调性。

### 二、思维路径还原（15-20 行 `>` 引用）
> "$f(x) = \frac{x}{x+1}$，区间 $(-1, +\infty)$ 判单调性 → 定义法三步走  
> **第一步**：在区间内任取 $x_1 < x_2$（$x_1, x_2 > -1$）  
> **第二步**：作差 $f(x_1) - f(x_2) = \frac{x_1}{x_1+1} - \frac{x_2}{x_2+1}$  
> 通分：$= \frac{x_1(x_2+1) - x_2(x_1+1)}{(x_1+1)(x_2+1)} = \frac{x_1 - x_2}{(x_1+1)(x_2+1)}$  
> **第三步**：分析符号 —— 分子 $x_1 - x_2 < 0$（因 $x_1 < x_2$）；分母两因子都 $> 0$（因 $x_1, x_2 > -1$）→ 分母 $> 0$  
> 所以 $f(x_1) - f(x_2) < 0$，即 $f(x_1) < f(x_2)$ → $f$ 单调**递增**  
> **关键反射**：定义法是高考压轴题的"硬通货"，可在任何函数上用  
> 进阶：导数法（part3/03 之后才学）→ $f'(x) = \frac{1}{(x+1)^2} > 0$ → 增。导数法快但前提是 $f$ 可导  
> 验证：取特殊值 $x_1 = 0, x_2 = 1$ → $f(0) = 0, f(1) = 0.5$ ✓"

### 三、抽象成方法

**定义法 3 步标准流程**：
1. **取值**：$\forall x_1, x_2 \in I, x_1 < x_2$
2. **作差**：计算 $f(x_1) - f(x_2)$
3. **判号**：通过通分、因式分解等化简，判断符号
   - $f(x_1) - f(x_2) < 0$ → 增（即 $x_1 < x_2 \Rightarrow f(x_1) < f(x_2)$）
   - $f(x_1) - f(x_2) > 0$ → 减

**常见单调函数模板**（必背）：

| 函数 | 单调区间 |
|---|---|
| $y = kx + b$（$k > 0$）| 整个 $\mathbb{R}$ 增 |
| $y = ax^2 + bx + c$（$a > 0$）| $(-\infty, -\frac{b}{2a}]$ 减，$[-\frac{b}{2a}, +\infty)$ 增 |
| $y = \frac{k}{x}$（$k > 0$）| 每支单调减（注意"每支"）|
| $y = a^x$（$a > 1$）| 整个 $\mathbb{R}$ 增 |
| $y = \log_a x$（$a > 1$）| $(0, +\infty)$ 增 |

### 四、方法变形
- **含参单调性**：求参数使 $f$ 在某区间单调（如二次函数对称轴位置约束）
- **复合函数单调性**：呼应 toolkit/07 同增异减
- **用单调性证不等式**：单调增函数 + $x_1 < x_2$ → $f(x_1) < f(x_2)$
- **用单调性解方程 / 不等式**：单调函数 $\Rightarrow$ 单射 $\Rightarrow$ 唯一解

### 五、思考路标（≥8 条）
- 见判单调性 → 定义法或导数法
- 定义法三步：取值 → 作差 → 判号
- 作差不会判号 → 试通分 / 因式分解 / 配方
- 见 $\frac{x}{x+a}$ 等分式 → 通分判号常用 $(x_1 - x_2)$ 凑分子
- 复合函数 → 同增异减（toolkit/07）
- 含参 → 按参数分类讨论
- 用单调性解方程：$f(a) = f(b) \Rightarrow a = b$（在单射区间）
- 用单调性证不等式：直接代入函数值比较

### 六、应用例题 3 例
- 例 1：基础定义法 —— $f(x) = -x^2 + 2x$ 在 $[1, +\infty)$ 的单调性
- 例 2：含参 —— $f(x) = x^2 - 2ax + 3$ 在 $[2, +\infty)$ 上单调递增，求 $a$（对称轴 $x = a \leq 2$ → $a \leq 2$）
- 例 3：用单调性解不等式 —— $f(x) = x^3 + x$（严格增）解 $f(2x-1) > f(x+2)$ → $2x - 1 > x + 2$ → $x > 3$

## Task 4: part3/04 奇偶性 ⭐（模板 D）

Title: `# 函数的奇偶性`

**一例速记**：
> **奇函数**：$f(-x) = -f(x)$，图象关于**原点**对称  
> **偶函数**：$f(-x) = f(x)$，图象关于 **$y$ 轴**对称  
> 前提：**定义域关于原点对称**（不对称的函数没有奇偶性）

### 一、引入题
> 判断 $f(x) = x^3 - 2x$ 与 $g(x) = x^4 - x^2$ 的奇偶性。

### 二、思维路径还原（15-20 行）
> "判断奇偶性，**第一步看定义域**——必须关于原点对称（如 $\mathbb{R}, [-a, a]$ 等）  
> 两个函数定义域都是 $\mathbb{R}$，满足前提  
> **$f(x) = x^3 - 2x$**：  
>   - $f(-x) = (-x)^3 - 2(-x) = -x^3 + 2x = -(x^3 - 2x) = -f(x)$ ✓  
>   - 是**奇函数**，图象关于原点对称  
> **$g(x) = x^4 - x^2$**：  
>   - $g(-x) = (-x)^4 - (-x)^2 = x^4 - x^2 = g(x)$ ✓  
>   - 是**偶函数**，图象关于 $y$ 轴对称  
> **关键反射**：见各项次数全是**奇次** → 奇函数；全是**偶次**（含常数项） → 偶函数；混合 → 一般非奇非偶  
> 例外：$f(x) = 0$（定义域对称时）既奇又偶  
> 用法：  
>   - 奇函数 $f(0) = 0$（前提是 $0 \in D$）  
>   - 奇函数在原点两侧的单调性相同（增 + 增）；偶函数相反（增 + 减）  
>   - 偶函数 $f(|x|) = f(x)$ → 简化分类讨论"

### 三、抽象成方法

**判断奇偶性 2 步**：
1. **看定义域**：是否关于原点对称？不对称 → 非奇非偶
2. **算 $f(-x)$**：与 $f(x)$ 比较
   - $f(-x) = f(x)$ → 偶
   - $f(-x) = -f(x)$ → 奇
   - 都不是 → 非奇非偶

**口诀**：
- 多项式只含**奇次**项 → 奇函数（如 $x, x^3 - 2x$）
- 多项式只含**偶次**项（含常数）→ 偶函数（如 $x^2, x^4 - 1$）
- 混合奇偶次 → 一般非奇非偶（如 $x^2 + x$）

**奇偶性 + 单调性组合**：
- 奇函数在 $(-a, 0)$ 与 $(0, a)$ 单调性**相同**
- 偶函数在 $(-a, 0)$ 与 $(0, a)$ 单调性**相反**

### 四、方法变形
- **抽象函数奇偶性**：$f(x+y) = f(x) + f(y)$ → 代 $y = -x$ 推 $f(-x) = -f(x)$（奇）（呼应 toolkit/06）
- **含参题**：求参数使函数为奇/偶（如 $f(x) = \log_a(\sqrt{x^2+1} + x) + m$ 为奇 → 找 $m$）
- **奇偶性 + 周期性**：奇 + 关于 $x=a$ 对称 → 周期 $4a$（呼应 toolkit/09）

### 五、思考路标（≥8 条）
- 见判奇偶 → 第一看定义域是否对称
- 定义域不对称 → 立即"非奇非偶"
- 算 $f(-x)$ 与 $f(x)$ 比较
- 多项式：全奇次→奇；全偶次→偶
- $f(0) = 0$ 是奇函数（定义域含 0）的必要不充分条件
- 抽象函数 → 代特殊值（$x = 0$，$y = -x$）推奇偶
- 奇 + 单调 → 关于原点对称两侧同向
- 偶 + 单调 → 关于 $y$ 轴对称两侧反向

### 六、应用例题 3 例
- 例 1：判断 $f(x) = \frac{x^3 + x}{x^2 + 1}$（奇）
- 例 2：含参 —— $f(x) = \log_2(\sqrt{x^2+1} - ax)$ 是偶函数，求 $a$
- 例 3：奇偶 + 单调 —— 偶函数 $f$ 在 $[0, +\infty)$ 上增，解 $f(2x-1) < f(x+2)$（用 $|2x-1| < |x+2|$ 平方）

## Task 5: part3/05 分段函数与含绝对值（模板 C）

Title: `# 分段函数与含绝对值函数`

涵盖：
- **分段函数定义**：在不同区间上有不同表达式的函数（如 $f(x) = \begin{cases} x^2, & x \geq 0 \\ -x, & x < 0 \end{cases}$）
- **求分段函数值**：先判断 $x$ 落在哪段，再用对应表达式
- **画分段函数图**：每段画自己的图象
- **含绝对值的两种处理**：
  1. 分段去绝对值（按 $|f| = f$ 或 $-f$ 分情形）
  2. 几何意义（数轴距离）
- **典型应用** 3 例：
  - 例 1：求 $f(f(-1))$（先求 $f(-1) = 1$，再求 $f(1) = 1$）
  - 例 2：画 $y = |x-1| + |x+2|$ 的图象（分 $x < -2, -2 \leq x \leq 1, x > 1$ 三段）
  - 例 3：解 $|x-1| + |x+2| < 5$（呼应 toolkit/11 分类讨论）
- **易错点**：分段函数的连接处取值；含绝对值要按零点分段

## Task 6: part3/06 复合函数 ⭐（模板 D）

Title: `# 复合函数`

**一例速记**：
> $y = f(g(x))$ 是**复合函数**，$g$ 是内层，$f$ 是外层。  
> **定义域**：$g$ 的定义域 ∩ $\{x \mid g(x) \in D_f\}$（取交集）  
> **单调性**：**同增异减**（内外同向 → 整体增；异向 → 减）

### 一、引入题
> 求 $y = \log_2(x^2 - 4x + 3)$ 的单调递增区间。

### 二、思维路径还原（15-20 行）
> "$y = \log_2(x^2 - 4x + 3)$ 是复合函数 → 拆内外：内 $g(x) = x^2 - 4x + 3$，外 $f(t) = \log_2 t$  
> **第一步**：求定义域 —— 内 $g(x) > 0$（对数真数为正）  
> $x^2 - 4x + 3 > 0$ → $(x-1)(x-3) > 0$ → $x < 1$ 或 $x > 3$  
> 定义域：$(-\infty, 1) \cup (3, +\infty)$  
> **第二步**：分析内外单调性  
>   - 内 $g$：开口向上、对称轴 $x = 2$。在 $(-\infty, 2]$ 减，$[2, +\infty)$ 增  
>   - 外 $f$：$\log_2 t$ 在 $t > 0$ 时**增**  
> **第三步**：取交集 + 同增异减  
>   - 在 $(-\infty, 1)$：内减、外增 → 异向 → **整体减**  
>   - 在 $(3, +\infty)$：内增、外增 → 同向 → **整体增** ✓  
> 答：递增区间 $(3, +\infty)$  
> **关键反射**：复合函数 → 先求定义域 → 再分内外单调 → 取交集 → 同增异减"

### 三、抽象成方法

**复合函数 4 大原则**（用表格）：

| 性质 | 处理方法 |
|---|---|
| 定义域 | $\{x \in D_g \mid g(x) \in D_f\}$ |
| 值域 | 用内函数 $g$ 的值域作为 $f$ 的输入 |
| **单调性** | **同增异减** |
| 奇偶性 | 内偶 → 整体偶；内外都奇 → 整体奇 |

**"同增异减"详解**：
- 内 $\uparrow$ 外 $\uparrow$ → 整体 $\uparrow$
- 内 $\downarrow$ 外 $\downarrow$ → 整体 $\uparrow$
- 内 $\uparrow$ 外 $\downarrow$ → 整体 $\downarrow$
- 内 $\downarrow$ 外 $\uparrow$ → 整体 $\downarrow$

### 四、方法变形
- **三层复合**：$f(g(h(x)))$ → 从内到外逐层分析
- **含参复合**：定义域 / 单调区间含参 → 分类讨论
- **抽象复合**：已知 $f$ 性质求 $f(g(x))$ 的性质
- **复合函数的图象变换**：$y = f(x+a), f(ax), -f(x)$ 等

### 五、思考路标（≥8 条）
- 见嵌套函数 → 拆内外 $f(g(x))$
- 求定义域 → 内外约束**取交集**
- 求单调性 → **同增异减**口诀
- 内函数值域作为外函数输入
- 三层复合 → 从内到外
- 含参 → 分类讨论
- 奇偶判断：内偶 → 整体偶
- 验证：取特殊点检查方向

### 六、应用例题 3 例
- 例 1：求 $y = \sqrt{x^2 - 1}$ 的定义域与值域
- 例 2：求 $y = (\frac{1}{2})^{x^2 - 2x}$ 的单调区间（内 $g(x) = x^2-2x$ 在 $(-\infty, 1]$ 减、$[1, +\infty)$ 增；外 $f(t) = (1/2)^t$ 减；同增异减 → 整体在 $(-\infty, 1]$ 增、$[1, +\infty)$ 减）
- 例 3：抽象复合 —— $f(x)$ 在 $\mathbb{R}$ 上递增，求 $f(x^2 - 1)$ 的递增区间
