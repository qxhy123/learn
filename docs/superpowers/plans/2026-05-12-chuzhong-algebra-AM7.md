## Task 1: part11/01 数据收集与描述

**File:** `chuzhong_algebra/part11-statistics/01-data-collection.md`（模板 C，1500-2200 字）

Title: `# 数据的收集与描述`

- **统计三步**：收集数据 → 整理数据 → 描述数据
- **全面调查 vs 抽样调查**：
  - **普查**：考察总体每一个个体（如人口普查）—— 数据准但耗资源
  - **抽样**：从总体中抽取一部分作为样本，再推断总体（中考主流）
- **总体、个体、样本、样本容量**：
  - **总体**：研究对象全部数据
  - **个体**：每一个研究对象
  - **样本**：从总体中抽取部分
  - **样本容量**：样本中个体的数量（不带单位）
- **常见抽样方法**：简单随机抽样、分层抽样（按比例抽）、系统抽样
- **数据描述方式**：表格、统计图、特征数（呼应 part11/02, 03, 04）
- **典型应用** 3 例：
  - 例 1：判断"了解某市初中生视力情况"用普查还是抽样（抽样，总体太大）
  - 例 2：从 1000 名学生中抽取 50 名调查上学方式，指出总体/样本/样本容量
  - 例 3：分层抽样——一所学校初一 600 人、初二 500 人、初三 400 人，要抽 30 名学生开座谈会，每年级抽多少（按 6:5:4 比例 → 12, 10, 8）
- **易错点**：样本容量不带单位；分层抽样按比例；样本要随机抽取避免偏差
- **自测题** 4 题。

## Task 2: part11/02 统计图表

**File:** `chuzhong_algebra/part11-statistics/02-statistical-charts.md`（模板 C，1800-2500 字）

Title: `# 常见统计图表`

- **4 种基本统计图**（用表格对比）：

| 图 | 形式 | 用途 | 优势 |
|---|---|---|---|
| **条形图** | 长方形柱 | 比较各类别数量 | 直观比较 |
| **折线图** | 折线 | 看数据变化趋势 | 反映变化 |
| **扇形图** | 圆分扇形 | 看各部分占总体百分比 | 反映占比 |
| **直方图（频率分布）** | 矩形柱（无间隔）| 大量数据按区间分组 | 看分布形态 |

- **直方图的画法**：
  1. 求**极差**（最大 − 最小）
  2. 确定**组数**与**组距**
  3. 划分区间（用左闭右开）
  4. 统计**频数** + 计算**频率**（$=$ 频数 / 总数）
  5. 画矩形（横轴区间，纵轴**频数 / 频率 / 频率÷组距**）

- **典型应用** 3 例：
  - 例 1：扇形图——某班 50 人，其中数学 40+ 占 60%，求人数（30 人）
  - 例 2：直方图——给一组数据画频率分布直方图（10 个区间、50 个数据）
  - 例 3：图表选择——分析"某城市每月降水量变化"用哪种图（折线图）
- **易错点**：扇形图各扇形百分比加起来 = 100%；直方图区间用**左闭右开** $[a, b)$；频数 vs 频率
- **自测题** 4 题。

## Task 3: part11/03 平均数/中位数/众数

**File:** `chuzhong_algebra/part11-statistics/03-central-tendency.md`（模板 C，2000-2700 字）

Title: `# 数据的集中趋势：平均数、中位数、众数`

- **平均数 $\bar{x}$**：所有数据之和 ÷ 数据个数
  $$\bar{x} = \frac{x_1 + x_2 + \cdots + x_n}{n}$$
- **加权平均数**：当数据有不同权重时
  $$\bar{x} = \frac{x_1 w_1 + x_2 w_2 + \cdots + x_n w_n}{w_1 + w_2 + \cdots + w_n}$$
- **中位数**：将数据从小到大排序后位于**正中间**的数（偶数个时取中间两数平均）
- **众数**：数据中**出现次数最多**的数（可能有多个或没有）
- **三者的对比**：

| 名称 | 计算方法 | 抗干扰性 | 适用场景 |
|---|---|---|---|
| 平均数 | 求和除以个数 | 易受极端值影响 | 整体水平 |
| 中位数 | 排序取中 | 不受极端值影响 | 偏态分布、避免极端值 |
| 众数 | 出现次数最多 | 不受极端值影响 | 关心"最普遍"的值 |

- **典型应用** 3 例：
  - 例 1：5 个数据 $3, 5, 8, 5, 9$，求三个量（平均 6、中位 5、众数 5）
  - 例 2：**加权平均** —— 学生平时 70 分、期中 80 分、期末 90 分（权重 2:3:5），求学期总成绩（$\frac{2 \times 70 + 3 \times 80 + 5 \times 90}{10} = 83$）
  - 例 3：**选拔题** —— 招工要求"反应快"，公司用三名候选人 10 次反应时间数据求平均/中位/众数，决定看哪个指标
- **易错点**：偶数个数据的中位数取中间两数平均；众数可能多个或没有；平均数易被极端值"拉偏"
- **自测题** 4 题。

## Task 4: part11/04 方差与样本估计

**File:** `chuzhong_algebra/part11-statistics/04-variance.md`（模板 C，1800-2500 字）

Title: `# 数据的离散程度：方差`

- **极差**：最大 $-$ 最小（最简单的离散度量）
- **方差**：衡量数据围绕平均数的离散程度
  $$S^2 = \frac{1}{n}\left[(x_1 - \bar{x})^2 + (x_2 - \bar{x})^2 + \cdots + (x_n - \bar{x})^2\right]$$
- **标准差** $S = \sqrt{S^2}$（与原数据同单位，更直观）
- **方差的意义**：方差**越小** → 数据**越稳定**（波动越小）；方差**越大** → 数据波动大
- **用样本估计总体**：
  - 样本的平均数 ≈ 总体平均数
  - 样本的方差 ≈ 总体方差
  - 样本越大、估计越准
- **典型应用** 3 例：
  - 例 1：基础计算 —— 5 个数据 $1, 2, 3, 4, 5$，求平均数（3）和方差（$\frac{1}{5}(4+1+0+1+4) = 2$）
  - 例 2：**稳定性比较** —— 甲乙两人射击 5 次成绩：甲 $7,8,8,9,8$ 平均 $8$ 方差 $0.4$；乙 $5,8,9,9,9$ 平均 $8$ 方差 $2.4$。甲更稳定
  - 例 3：**用样本估计总体** —— 抽样测 10 个零件直径平均 5cm 方差 0.04，估计全部零件的直径平均与方差
- **易错点**：方差公式中是 $(x_i - \bar{x})^2$ 不是 $|x_i - \bar{x}|$；方差**单位是原数据单位的平方**；标准差与原数据同单位
- **自测题** 4 题。

## Task 5: part12/01 可能性与事件

**File:** `chuzhong_algebra/part12-probability/01-possibility-and-events.md`（模板 C，1500-2200 字）

Title: `# 可能性与随机事件`

- **三类事件**：
  - **必然事件**：一定发生（概率 = 1，如"太阳从东边升起"）
  - **不可能事件**：一定不发生（概率 = 0，如"掷骰子得到 7"）
  - **随机事件**：可能发生也可能不发生（概率 $0 < P < 1$）
- **概率的定义**：随机事件 $A$ 发生的可能性大小，记 $P(A)$，$0 \leq P(A) \leq 1$
- **古典概型**（等可能事件）：若试验有 $n$ 个等可能结果，事件 $A$ 包含 $m$ 个结果，则
  $$P(A) = \frac{m}{n}$$
- **典型应用** 3 例：
  - 例 1：判断三类事件 —— "掷一枚硬币正面朝上"（随机），"明天太阳从西边升起"（不可能），"两个负数相加得负数"（必然）
  - 例 2：**古典概型** —— 一个袋子里 5 个红球、3 个白球，随机摸一个，摸到红球的概率（$\frac{5}{8}$）
  - 例 3：**等可能结果** —— 同时掷两枚硬币，求两次都正面朝上的概率（$\frac{1}{4}$，4 种结果中 1 种）
- **易错点**：等可能事件才能用 $\frac{m}{n}$ 公式；列举所有可能结果时不重不漏
- **自测题** 4 题。

## Task 6: part12/02 列举法与树状图 ⭐（模板 D）

**File:** `chuzhong_algebra/part12-probability/02-counting-and-tree.md`（**模板 D**，3000-4000 字）

Title: `# 用列举法（列表/树状图）求概率`

**一例速记**：
> 求概率 = 数 $m$（有利结果）和 $n$（所有等可能结果）。**多步事件**用**列表法**（2 步）或**树状图**（多步）保证不重不漏。

### 一、引入题
> 同时掷两枚均匀骰子，求"点数之和等于 7"的概率。

### 二、思维路径还原（12-18 行 `>` 引用）
> "两枚骰子 → 两步随机事件 → 用**列表法**最直观  
> 横轴第一枚（1-6）、纵轴第二枚（1-6），共 **6×6 = 36** 种等可能结果  
> 找'和 = 7'的：$(1,6), (2,5), (3,4), (4,3), (5,2), (6,1)$ —— 共 **6** 种  
> $P = \frac{6}{36} = \frac{1}{6}$  
> **关键反射**：见'两步随机事件' → 列表法；'三步或更多' → 树状图  
> 注意：'有放回' vs '无放回'决定每步的可能数  
> **要点 1**：列表 / 树状图必须**不重不漏**枚举所有等可能结果  
> **要点 2**：判断每步独立的结果数（如骰子每步 6 种，无放回二选一时第 2 步少 1 种）  
> **要点 3**：先数总数 $n$，再数有利数 $m$，最后 $P = \frac{m}{n}$"

### 三、抽象成方法
**列举法的两种工具**：

1. **列表法**（适用：2 步随机事件）：
   - 横向是第一步的所有结果
   - 纵向是第二步的所有结果
   - 表格内是组合结果
   - 总数 = 横 $\times$ 纵；找有利结果数

2. **树状图法**（适用：3 步或以上）：
   - 每层对应一个随机步骤
   - 从根节点逐层展开各种可能
   - 末梢节点 = 所有等可能结果
   - 从根到叶的每条路径 = 一个结果

**"有放回" vs "无放回"判断**：
- 有放回：每步可能数相同
- 无放回：每步可能数 = 上一步剩余

### 四、方法变形
- **球颜色搭配**：袋子里几种颜色球，随机抽几个，求"同色"或"异色"概率
- **掷骰子组合**：求和、求积、求差等
- **生日 / 编号问题**：从某编号集中随机抽取

### 五、思考路标（≥6 条）
- 见"两步独立事件" → 列表法
- 见"三步或更多" → 树状图
- 见"放回 / 不放回" → 决定每步结果数
- 见"等可能" → 古典概型 $P = \frac{m}{n}$
- 列举要"不重不漏"
- 答案要化为最简分数 $\frac{m}{n}$

### 六、应用例题 3 例
- 例 1：两枚骰子和 = 7（同引入题）
- 例 2：**列表法** —— 袋中 3 红 2 白，**无放回**抽 2 球，求"两球颜色相同"概率（$\frac{C_3^2 + C_2^2}{C_5^2} = \frac{3+1}{10} = \frac{2}{5}$）。**用列表法验证**（5 × 4 / 2 = 10 种方式）
- 例 3：**树状图** —— 3 人去 3 地办事（每人不同地、不重复），求 3 人都正好去合适地的概率（$\frac{1}{6}$）

## Task 7: part12/03 用频率估计概率

**File:** `chuzhong_algebra/part12-probability/03-frequency-and-probability.md`（模板 C，1500-2200 字）

Title: `# 用频率估计概率`

- **频率**：$n$ 次试验中事件 $A$ 发生了 $m$ 次，则**频率** $= \frac{m}{n}$
- **大数定律**（直观版）：试验次数 $n$ 越大，频率**越接近**概率
- **用频率估计概率**：当概率难以用列举法直接算时，做大量试验，**用频率近似代替概率**
- **抛硬币实验**：抛 100 次得正面 51 次，频率 $\frac{51}{100} = 0.51$，可估计 $P(\text{正面}) \approx 0.5$
- **典型应用** 3 例：
  - 例 1：**频率 → 概率** —— 一袋子有红白球若干，摸 1000 次得红球 700 次，估计袋中红球占比（70%）
  - 例 2：**实验设计** —— 设计一个实验估计图钉头朝上的概率
  - 例 3：**估计种群** —— 标记重捕法估计湖中鱼的数量（标记 100 条放回，第二次捕 200 条有 5 条标记 → 估计湖中 $\frac{100 \times 200}{5} = 4000$ 条）
- **易错点**：频率随试验次数变化；只有大量试验后频率才接近概率；频率不等于概率（前者实验、后者理论）
- **自测题** 4 题。
