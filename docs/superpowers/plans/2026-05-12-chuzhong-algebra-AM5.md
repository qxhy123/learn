## Task 1: part8/01 函数概念

**File:** `chuzhong_algebra/part8-linear-functions/01-function-concept.md`（模板 C，1800-2500 字）

Title: `# 函数的概念`

- **函数定义**：在变化过程中，对于自变量 $x$ 在允许范围内每取一个值，因变量 $y$ 都有**唯一**确定的值与之对应，则 $y$ 是 $x$ 的函数
- **函数三要素**：自变量 $x$ / 因变量 $y$ / 对应关系
- **自变量取值范围**（**定义域**）：
  - 整式（无分母、无根号）：全体实数
  - 分式：分母 $\neq 0$
  - 二次根式：被开方数 $\geq 0$
  - 实际问题：符合实际意义（如人数 $\geq 0$ 且为整数）
- **函数的 3 种表示法**：解析式（公式）/ 列表（表格）/ 图象
- **典型应用** 3 例：
  - 例 1：求 $y = \frac{1}{x-1}$ 的自变量范围（$x \neq 1$）
  - 例 2：求 $y = \sqrt{x-2}$ 的自变量范围（$x \geq 2$）
  - 例 3：判断 $y$ 是否是 $x$ 的函数（如 $y^2 = x$ 不是——一个 $x$ 对应两个 $y$）
- **易错点**：函数定义中 $y$ **唯一**；定义域要综合所有限制；实际问题要加实际限制
- **自测题** 4 题。

## Task 2: part8/02 一次函数图象与性质

**File:** `chuzhong_algebra/part8-linear-functions/02-linear-function-basics.md`（模板 C，2200-3000 字）

Title: `# 一次函数图象与性质`

- **一次函数**：$y = kx + b$（$k \neq 0$）；$b = 0$ 时是**正比例函数** $y = kx$
- **图象**：一条直线
- **性质**（按 $k$ 符号分类）：
  - $k > 0$：图象**向右上**倾斜；$y$ 随 $x$ 增大**增大**
  - $k < 0$：图象**向右下**倾斜；$y$ 随 $x$ 增大**减小**
- **截距**：直线与 $y$ 轴交点的纵坐标 $= b$；与 $x$ 轴交点的横坐标 $= -\frac{b}{k}$
- **图象经过的象限**（按 $k, b$ 符号分类，用表格）：

| $k$ | $b$ | 经过象限 |
|---|---|---|
| $> 0$ | $> 0$ | 一、二、三 |
| $> 0$ | $< 0$ | 一、三、四 |
| $> 0$ | $= 0$ | 一、三 |
| $< 0$ | $> 0$ | 一、二、四 |
| $< 0$ | $< 0$ | 二、三、四 |
| $< 0$ | $= 0$ | 二、四 |

- **平移规律**：$y = kx + b$ 上移 $m$ → $y = kx + b + m$；左移 $m$ → $y = k(x+m) + b$
- **典型应用** 3 例：
  - 例 1：判断 $y = -2x + 3$ 图象经过象限（一、二、四）
  - 例 2：$y = kx + b$ 经过 $(1, 0)$ 和 $(0, -2)$，求 $k, b$（$k = 2, b = -2$）
  - 例 3：把 $y = 2x + 1$ 向下平移 3 个单位 → $y = 2x - 2$
- **易错点**：$k \neq 0$ 是一次函数必要条件；图象方向；象限判断要看 $k$ 和 $b$ 双重符号
- **自测题** 4 题。

## Task 3: part8/03 待定系数法 ⭐（模板 D）

**File:** `chuzhong_algebra/part8-linear-functions/03-finding-expression.md`（**模板 D**，3000-4000 字）

Title: `# 待定系数法求一次函数解析式`

**一例速记**：
> 设 $y = kx + b$，代入两个点 → 解二元一次方程组 → 求出 $k, b$。**两点定一线**。

### 一、引入题
> 已知一次函数图象经过 $(1, 3)$ 和 $(-1, -1)$，求函数解析式。

### 二、思维路径还原（12-18 行 `>` 引用）
> "已知**两点 + 函数类型**（一次函数 $y = kx + b$）→ 求解析式。  
> **第一步：设**——已经知道是一次函数，设 $y = kx + b$  
> **第二步：代点列方程组**：把两个点的坐标代入解析式  
> 代 $(1, 3)$：$3 = k \cdot 1 + b$ → $k + b = 3$  
> 代 $(-1, -1)$：$-1 = k \cdot (-1) + b$ → $-k + b = -1$  
> **第三步：解方程组**——两式相加 $2b = 2 \Rightarrow b = 1$；代回 $k = 2$  
> **第四步：写出解析式** $y = 2x + 1$  
> **第五步：验证**——代回两点检验 ✓  
> 关键反射：见'已知点 + 函数类型，求解析式' → **设元 → 代点列方程组 → 解出**。"

### 三、抽象成方法
**待定系数法 4 步流程**：
1. **设**：写出函数解析式的通式（一次设 $y = kx + b$，反比例设 $y = \frac{k}{x}$，二次设 $y = ax^2 + bx + c$）
2. **代**：代入已知点（点数 = 待定系数数）
3. **解**：方程组求未知系数
4. **写**：写出最终解析式 + 验证

### 四、方法变形
- **正比例函数**（设 $y = kx$）：只需 1 个点
- **斜率 + 一点**：题给"斜率 $k = 2$"+ 一个点，只需设 $b$
- **平行 + 一点**：题给"与 $y = 2x + 3$ 平行" → $k = 2$；再用一点求 $b$
- **垂直** + 一点：题给"与 $y = 2x$ 垂直" → $k = -\frac{1}{2}$（注意：初中"垂直"少考，但可类比）

### 五、思考路标（≥6 条）
- 见"求一次函数解析式" → 设 $y = kx + b$ + 待定系数法
- 见两点 → 列方程组求 $k, b$
- 见图象与坐标轴交点 → 提示截距（$x = 0$ 时 $y = b$；$y = 0$ 时 $x = -\frac{b}{k}$）
- 见"与某直线平行" → $k$ 相同
- 见正比例函数 → $b = 0$，只设一个未知
- 求 $b$ 时常用 $(0, b)$（$y$ 轴交点）

### 六、应用例题 3 例
- 例 1：基础两点（同引入题）
- 例 2：已知截距求解析式——直线与 $x$ 轴交于 $(2, 0)$、与 $y$ 轴交于 $(0, -4)$
- 例 3：平行 + 点——与 $y = 3x + 1$ 平行且经过 $(0, 5)$，求解析式（$y = 3x + 5$）

## Task 5: part8/05 一次函数与方程组的几何意义 ⭐（模板 D）

**File:** `chuzhong_algebra/part8-linear-functions/05-system-and-line.md`（**模板 D**，3000-4000 字）

Title: `# 一次函数与方程（组）的几何意义`

**一例速记**：
> **代数 ↔ 几何**桥梁：
> - 方程 $kx + b = 0$ 的解 = 直线 $y = kx + b$ 与 $x$ 轴交点的横坐标
> - 方程组的解 = 两条直线的交点坐标
> - 不等式 $kx + b > 0$ 的解集 = 图象在 $x$ 轴上方的部分

### 一、引入题
> 用图象法解方程组 $\begin{cases} y = 2x - 1 \\ y = -x + 5 \end{cases}$。

### 二、思维路径还原（12-18 行 `>` 引用）
> "方程组：$\begin{cases} y = 2x - 1 \\ y = -x + 5 \end{cases}$  
> **代数解法**：两式联立 → $2x - 1 = -x + 5$ → $x = 2, y = 3$  
> **几何解法**：每个方程是一条直线，方程组的解 = **两条直线的交点**！  
> 画 $y = 2x - 1$：经过 $(0, -1)$ 和 $(1, 1)$  
> 画 $y = -x + 5$：经过 $(0, 5)$ 和 $(5, 0)$  
> 看图：两线在 $(2, 3)$ 相交 → 方程组解 $x = 2, y = 3$  
> **关键反射**：'方程组的解 = 两图象的交点坐标' —— 这是数形结合在代数里的代表用法。  
> 反之：'两图象交点坐标' = '两方程联立的解'——两个方向都能用！"

### 三、抽象成方法
**核心对应关系**（用表格）：

| 代数对象 | 几何对应 |
|---|---|
| 方程 $kx + b = 0$ 的解 | 直线 $y = kx + b$ 与 $x$ 轴交点的横坐标 |
| 方程组 $\begin{cases} y = k_1 x + b_1 \\ y = k_2 x + b_2 \end{cases}$ 的解 | 两条直线的**交点坐标** |
| 不等式 $kx + b > 0$ 的解集 | 图象在 $x$ 轴**上方**的 $x$ 范围 |
| 不等式 $k_1 x + b_1 > k_2 x + b_2$ 的解集 | 图象 1 在图象 2 **上方**的 $x$ 范围 |
| 方程组**无解** | 两直线**平行**（同 $k$ 不同 $b$）|
| 方程组**无穷多解** | 两直线**重合** |

### 四、方法变形
- **判断方程组解的个数**：比较两直线 $k_1, k_2$（不同 → 唯一解；相同 + $b$ 不同 → 无解；都相同 → 无穷多）
- **图象法解不等式**：求 $kx + b > 0$ 等价于看图象与 $x$ 轴的相对位置
- **反向应用**：题给两直线相交于某点，可反推参数

### 五、思考路标（≥6 条）
- 见方程组 → 想象两直线，**交点 = 解**
- 见方程 $f(x) = g(x)$ → 想两图象交点
- 见不等式 $f(x) > g(x)$ → 想图象 1 在图象 2 上方的区间
- 见方程组无解 → 想两直线平行
- 见图象交点 → 想方程组联立
- 数形结合是中考填空 / 选择题的"加速器"

### 六、应用例题 3 例
- 例 1：图象法解方程组（同引入题）
- 例 2：**已知交点求参数** —— 直线 $y = 2x + a$ 与 $y = -x + 1$ 交于 $(1, 0)$？验证并求 $a$
- 例 3：**图象法解不等式** —— 已知 $y_1 = x - 1, y_2 = -2x + 5$，求 $y_1 > y_2$ 的 $x$ 范围

### 七、自测题 5 题

## Task 6: part8/06 含参一次函数 ⭐（模板 D）

**File:** `chuzhong_algebra/part8-linear-functions/06-parametric-linear-fn.md`（**模板 D**，3000-4000 字）

Title: `# 含参一次函数`

**一例速记**：
> 含参一次函数 $y = (k-1)x + 2k - 3$ —— 看到参数立刻问 3 个问题：① 何时是**一次函数**（$k \neq 1$）② 图象**经过哪些象限**（按 $k-1$ 和 $2k-3$ 符号讨论）③ 是否**经过定点**（与 $k$ 无关的点）

### 一、引入题
> 一次函数 $y = (k-2)x + 2k$，当 $k$ 为何值时图象经过 $(2, 4)$？图象经过哪些象限？

### 二、思维路径还原（12-18 行 `>` 引用）
> "$y = (k-2)x + 2k$ —— 含参一次函数  
> **第一问：经过 $(2, 4)$ 时 $k = ?$**  
> 代入：$4 = (k-2) \cdot 2 + 2k = 2k - 4 + 2k = 4k - 4$ → $4k = 8 \Rightarrow k = 2$？  
> 等下 $k = 2$ 时 $k-2 = 0$，不再是一次函数！  
> 检查：当 $k = 2$，函数退化为 $y = 4$（水平直线，常函数），过 $(2, 4)$ ✓  
> 但题目说'一次函数'前提 → $k \neq 2$  
> 代入再解：$4 = 4k - 4$ → $k = 2$ 矛盾 → **无满足的 $k$**  
> （回头看：本题可能题设的'一次函数'是宽松的"线性函数"含常函数 → 若严格则无解；若宽松则 $k = 2$）  
> **第二问：图象经过哪些象限？**  
> 一般含参题需要按 $k - 2$ 和 $2k$ 符号分类讨论：$k > 2, k = 2, 0 < k < 2, k = 0, k < 0$ 五种情形分别画图  
> **关键反射**：含参一次函数第一时间分类讨论参数。"

### 三、抽象成方法
**含参一次函数 3 类问题**：
1. **判断是否为一次函数**：$k \neq 0$ 是关键
2. **图象经过某点**：代入求参数
3. **图象经过哪些象限**：按 $k, b$ 双重符号分类（5-6 类情形）
4. **过定点问题**：找与参数无关的固定点（如 $y = kx + 2k - 1$，整理为 $y = k(x + 2) - 1$，定点 $(-2, -1)$）

### 四、方法变形
- **平行 / 重合关系**：含参 → 系数相同关系
- **图象与坐标轴交点的范围**：截距 = $b$ 含参 → 求 $b$ 的范围

### 五、思考路标（≥6 条）
- 见含参一次函数 → 首先看是否需 $k \neq 0$
- 见图象经过某点 → 代点 + 解参数
- 见"经过哪些象限" → 分类讨论 $k, b$ 双重符号
- 见"无论 $k$ 为何值都过定点" → 整理为 $y = k \cdot f(x) + g(x)$，找 $f(x) = 0$ 时定点
- 含参题答案常以"分类讨论"形式给出
- 验证总要回头：代回检查

### 六、应用例题 3 例
- 例 1：含参经过点（同引入题，但用 $k \neq$ 临界值的版本）
- 例 2：**过定点** —— 证明 $y = kx + 2k - 1$（$k$ 为任意值）必过 $(-2, -1)$
- 例 3：**两直线平行求参数** —— $y = (m+1)x - 2$ 与 $y = 3x + 1$ 平行，求 $m$（$m = 2$）

## Task 7: part9/01 反比例函数基础

**File:** `chuzhong_algebra/part9-inverse-proportional/01-inverse-basics.md`（模板 C，1800-2500 字）

Title: `# 反比例函数概念与图象`

- **定义**：$y = \frac{k}{x}$（$k \neq 0$），**$x$ 与 $y$ 不能为零**
- **图象**：双曲线（两支：$k > 0$ 在第一、三象限；$k < 0$ 在第二、四象限）
- **图象不与坐标轴相交**（$x = 0$ 时 $y$ 无定义）
- **性质**（按 $k$ 符号分类）：
  - $k > 0$：图象在一、三象限；**每支上** $y$ 随 $x$ 增大**减小**（注意"每支上"，整体并不单调）
  - $k < 0$：图象在二、四象限；每支上 $y$ 随 $x$ 增大**增大**
- **对称性**：图象关于**原点中心对称**；也关于 $y = x$ 和 $y = -x$ 轴对称
- **典型应用** 3 例：
  - 例 1：判断 $y = \frac{3}{x}, y = \frac{x}{3}, y = -\frac{2}{x}$ 哪些是反比例函数（第一三）
  - 例 2：图象经过 $(2, 3)$，求 $k$ 和解析式（$k = 6, y = \frac{6}{x}$）
  - 例 3：图象在第二、四象限，求 $k$ 取值范围（$k < 0$）
- **易错点**：定义中 $k \neq 0$；图象不过原点；单调性只在**每支上**
- **自测题** 4 题。

## Task 8: part9/02 反比例函数 k 的几何意义 ⭐（模板 D）

**File:** `chuzhong_algebra/part9-inverse-proportional/02-inverse-properties.md`（**模板 D**，3000-4000 字）

Title: `# 反比例函数 k 的几何意义`

**一例速记**：
> 反比例函数 $y = \frac{k}{x}$ 上任一点 $P(x_0, y_0)$ → **过 $P$ 作两坐标轴垂线，垂足分别 $A, B$，矩形 $PAOB$（$O$ 是原点）面积 = $|k|$**。

### 一、引入题
> 已知反比例函数 $y = \frac{k}{x}$ 经过 $P(2, 3)$，求过 $P$ 作 $x$ 轴和 $y$ 轴的垂线段围成的矩形面积。

### 二、思维路径还原（12-18 行 `>` 引用）
> "$P(2, 3)$ 在 $y = \frac{k}{x}$ 上 → $k = xy = 2 \times 3 = 6$  
> 函数即 $y = \frac{6}{x}$  
> 过 $P$ 作两坐标轴垂线：垂足 $A(2, 0)$ 在 $x$ 轴、$B(0, 3)$ 在 $y$ 轴  
> 矩形 $PAOB$：宽 $= |2|$、高 $= |3|$ → 面积 $= 6$  
> **关键**：面积 $= |x_0| \cdot |y_0| = |x_0 \cdot y_0| = |k|$  
> 这是反比例函数最重要的几何性质：**$|k|$ 是过点的矩形面积**！  
> 推广：图象上任意点 → 矩形面积都是 $|k|$ —— 与点的位置**无关**！  
> 进一步：过点向**一条**坐标轴作垂线（不是两条），垂足与原点构成的**三角形面积 = $\frac{|k|}{2}$**  
> 关键反射：见反比例函数 + 矩形/三角形面积 → 立即想 $|k|$ 或 $\frac{|k|}{2}$。"

### 三、抽象成方法
**$k$ 的几何意义（必背）**：
1. **矩形面积 $= |k|$**：过图象上任一点向两坐标轴作垂线，与坐标轴围成矩形，面积 $= |k|$
2. **三角形面积 $= \frac{|k|}{2}$**：过图象上任一点向**一条**坐标轴作垂线，**与原点和垂足**构成的三角形面积 $= \frac{|k|}{2}$

**逆向应用**：
- 已知矩形 / 三角形面积 → 求 $k$ 或函数解析式
- 见"图象上点 + 坐标轴 + 面积" → 立刻用 $|k|$

### 四、方法变形
- **结合一次函数与反比例函数交点**：求面积常涉及交点坐标
- **两个反比例函数同图**：两个 $|k|$ 的差或和题
- **k 含参**：通过面积条件求 $k$ 范围

### 五、思考路标（≥6 条）
- 见反比例函数 + 矩形面积 → $|k|$
- 见反比例函数 + 三角形面积（含原点 + 一垂线）→ $\frac{|k|}{2}$
- 求过点 → 代入 $k = xy$
- 见 $k > 0$ → 一三象限；$k < 0$ → 二四
- 含参反比例 → 用面积条件反推参数
- 反比例 + 一次函数 → 联立求交点（动点综合题）

### 六、应用例题 3 例

- 例 2：**三角形面积** —— 反比例函数过 $P$，过 $P$ 向 $x$ 轴作垂线 $PA$，连 $OP$（$O$ 是原点），$\triangle OPA$ 面积为 $4$。求 $k$（$|k| = 8$，结合象限定符号）
- 例 3：**反比例 + 一次函数综合** —— $y = \frac{6}{x}$ 与 $y = -x + 5$ 交于 $A, B$，求 $\triangle AOB$ 面积
