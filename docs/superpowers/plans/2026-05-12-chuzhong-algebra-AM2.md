## Task 1: part3/01 提公因式

**File:** `chuzhong_algebra/part3-factorization/01-common-factor.md`（模板 C，1500-2200 字）

Title: `# 提公因式法`

- **因式分解概念**：把多项式写成几个整式乘积形式（与"展开"互逆）
- **公因式**：每项都含的因式（含系数最大公因数 + 字母最低次幂）
- **提取步骤**：找公因式 → 提到括号外 → 括号内 = 原式 ÷ 公因式
- **典型应用** 3 例：
  - 例 1：$6a^2 b - 9 ab^2 = 3ab(2a - 3b)$
  - 例 2：$x(x-2) - 3(x-2) = (x-2)(x-3)$（**整体提公因式 $x-2$**）
  - 例 3：$-2x^2 + 4x - 6 = -2(x^2 - 2x + 3)$（提负号注意每项变号）
- **易错点**：公因式取系数 GCD + 字母**最低**次幂；提负号要每项变号；提完检查括号内不能再提
- **自测题** 4 题。

## Task 2: part3/02 公式法

**File:** `chuzhong_algebra/part3-factorization/02-formula-method.md`（模板 C，1800-2500 字）

Title: `# 公式法因式分解`

- **平方差公式逆用**：$a^2 - b^2 = (a+b)(a-b)$
- **完全平方公式逆用**：$a^2 \pm 2ab + b^2 = (a \pm b)^2$
- **识别**：
  - 两项 + 相减 + 都是平方 → 平方差
  - 三项 + 首末是平方 + 中间是 2 倍乘积 → 完全平方
- **典型应用** 3 例：
  - 例 1：$4x^2 - 9 = (2x+3)(2x-3)$
  - 例 2：$x^2 + 6x + 9 = (x+3)^2$
  - 例 3：$a^4 - 16 = (a^2-4)(a^2+4) = (a-2)(a+2)(a^2+4)$（**多次分解**）
- **易错点**：先看是否可提公因式（如 $2x^2 - 8 = 2(x^2-4) = 2(x+2)(x-2)$）；分解到不能再分解为止
- **自测题** 4 题。

## Task 3: part3/03 十字相乘 ⭐（模板 D）

**File:** `chuzhong_algebra/part3-factorization/03-cross-multiplication.md`（**模板 D**，3000-4000 字）

Title: `# 十字相乘法`

**一例速记**：
> $x^2 + 5x + 6 = (x+2)(x+3)$  
> 看十字：$\begin{array}{c}x \quad +2 \\ x \quad +3\end{array}$ → 交叉积之和 $2x + 3x = 5x$ ✓ → 分解完成

### 一、引入：一道二次三项式题
> 因式分解 $x^2 + 7x + 12$。直接试错费时；用十字相乘 5 秒。

### 二、思维路径还原（12-18 行 `>` 引用）
> "$x^2 + 7x + 12$ —— 标准二次三项式 $x^2 + bx + c$ 型  
> 找两个数 $p, q$ 使 $p \cdot q = 12$ 且 $p + q = 7$  
> 尝试 12 的因数对：(1, 12), (2, 6), (3, 4) ……  
> $3 + 4 = 7$ ✓ 命中  
> 所以 $x^2 + 7x + 12 = (x+3)(x+4)$  
> 关键反射：见 $x^2 + bx + c$ 立刻找'积 = $c$、和 = $b$'的两数。"

### 三、抽象成方法
**$x^2 + bx + c$ 型**：找 $p, q$ 使 $p \cdot q = c$，$p + q = b$，则 $x^2 + bx + c = (x+p)(x+q)$。

**$ax^2 + bx + c$ 型（$a \neq 1$）**：
- 设 $a = a_1 a_2$, $c = c_1 c_2$
- 十字相乘要求 $a_1 c_2 + a_2 c_1 = b$
- 例：$2x^2 + 5x + 3$，$2 = 1 \times 2$, $3 = 1 \times 3$，$1 \times 3 + 2 \times 1 = 5$ ✓
- 故 $2x^2 + 5x + 3 = (x+1)(2x+3)$

### 四、方法变形
- **$c < 0$ 情形**：两数异号（如 $x^2 - x - 6$ → $-3, 2$）
- **$b < 0, c > 0$**：两数同负（如 $x^2 - 5x + 6 = (x-2)(x-3)$）
- **含字母系数**：$x^2 + 3xy + 2y^2 = (x+y)(x+2y)$（按 $x$ 看作主元）

### 五、思考路标（≥6 条）
- 见 $x^2 + bx + c$ → 找"积 c 和 b"的两数
- 见 $ax^2 + bx + c$（$a \neq 1$）→ 拆 $a$ 和 $c$，交叉积凑 $b$
- $c > 0, b > 0$ → 两数同正
- $c > 0, b < 0$ → 两数同负
- $c < 0$ → 两数异号
- 试不出来 → 用配方或求根公式

### 六、应用例题 3 例
- 例 1：$x^2 - 8x + 15 = (x-3)(x-5)$
- 例 2：$2x^2 + 7x + 3 = (2x+1)(x+3)$
- 例 3：$3x^2 + 2x - 1 = (3x-1)(x+1)$

## Task 4: part3/04 分组分解

**File:** `chuzhong_algebra/part3-factorization/04-grouping.md`（模板 C，1800-2500 字）

Title: `# 分组分解法`

- **思路**：把多项式分成几组，每组提公因式后**再合并**
- **常见两种分组**：
  - **二二分组**（4 项）：$ax + ay + bx + by = a(x+y) + b(x+y) = (a+b)(x+y)$
  - **三一分组**（4 项）：$x^2 - 2xy + y^2 - 4 = (x-y)^2 - 4 = (x-y+2)(x-y-2)$（配方差）
- **典型应用** 3 例：
  - 例 1：$ax + ay + bx + by$（二二分组）
  - 例 2：$x^3 - x^2 - 4x + 4 = x^2(x-1) - 4(x-1) = (x-1)(x^2-4) = (x-1)(x+2)(x-2)$
  - 例 3：$a^2 - b^2 + 2bc - c^2 = a^2 - (b-c)^2 = (a+b-c)(a-b+c)$（**三一分组 + 平方差**）
- **易错点**：分组前先看是否能提公因式；分组要分出"能继续分解"的形式；提完后还要继续分解
- **自测题** 4 题。

## Task 5: part3/05 综合因式分解思路 ⭐（模板 D）

**File:** `chuzhong_algebra/part3-factorization/05-factor-strategy.md`（**模板 D**，3000-4000 字）

Title: `# 综合因式分解思路`

**一例速记**：
> 因式分解的"三步走"决策树：① 提公因式 → ② 用公式（平方差/完全平方）→ ③ 十字相乘 / 分组 → ④ 不能再分。每一步都要回头检查能否继续分解。

### 一、引入：一道综合分解题
> 因式分解 $2a^3 - 8a$。盲做容易漏；遵循三步走顺序 30 秒。

### 二、思维路径还原（12-18 行 `>`）
> "$2a^3 - 8a$ ——  
> **第一步：能提公因式吗？** 系数 GCD = 2，字母最低次幂 $a$，公因式 $2a$  
> 提出：$2a^3 - 8a = 2a(a^2 - 4)$  
> **第二步：括号内能继续吗？** $a^2 - 4$ → 平方差！  
> $a^2 - 4 = (a+2)(a-2)$  
> **第三步：检查每个因式不能再分**  
> 最终：$2a^3 - 8a = 2a(a+2)(a-2)$  
> 关键：**每一步都问'还能分吗?'** 直到不能。"

### 三、抽象成方法
**因式分解决策树**：
1. **优先提公因式**（系数 GCD + 字母最低次幂）
2. **公式法**：两项尝试平方差；三项尝试完全平方
3. **十字相乘**（三项二次式）：$x^2 + bx + c$ 找两数；$ax^2+bx+c$ 拆系数
4. **分组**（四项及以上）：二二分组或三一分组
5. **检查**：每个因式必须"不能再分"

**"分解到底"原则**：每个因式都要是不可再分的（在整数范围内）。

### 四、方法变形
- **多次分解**：$a^4 - 16 = (a^2-4)(a^2+4) = (a+2)(a-2)(a^2+4)$
- **特殊技巧**：
  - 添项拆项（如 $x^4 + 4 = (x^2+2)^2 - (2x)^2 = (x^2+2+2x)(x^2+2-2x)$）
  - 换元（高次方程时）

### 五、思考路标（≥6 条）
- 拿到任何多项式 → 先看公因式
- 提完公因式 → 看括号内项数
- 两项 → 平方差 / 立方和差（中考少用）
- 三项 → 完全平方 / 十字相乘
- 四项 → 分组分解
- 每分解一步 → 检查能否继续
- 系数有 GCD → 公因式优先
- 含 $a^2 + b^2$ 型 → 一般不可分解（整数范围内）

### 六、应用例题 3 例
- 例 1：$3x^2 - 12$
- 例 2：$x^4 - 5x^2 + 4$（先换元 $y=x^2$ 或直接十字相乘）
- 例 3：$a^3 - a + 2a^2 - 2$（分组）

## Task 6: part4/01 分式基础

**File:** `chuzhong_algebra/part4-fractions/01-fraction-basics.md`（模板 C，1800-2500 字）

Title: `# 分式的概念与基本性质`

- **分式定义**：$\frac{A}{B}$ 形式，$A, B$ 是整式，且 **$B$ 含字母**且 $B \neq 0$
- **有意义条件**：$B \neq 0$（含字母时需限定字母取值，如 $\frac{1}{x-1}$ 需 $x \neq 1$）
- **基本性质**：$\frac{A}{B} = \frac{A \cdot C}{B \cdot C} = \frac{A \div C}{B \div C}$（$C \neq 0$）
- **约分**：分子分母**同除以公因式**（先因式分解）
- **通分**：把异分母分式化为同分母（找最简公分母 = LCM）
- **典型应用** 3 例：
  - 例 1：判断 $\frac{x}{3}, \frac{1}{x}, \frac{x+1}{x-1}$ 哪些是分式（前者整式；后两是分式）
  - 例 2：求 $\frac{x+1}{x^2-4}$ 有意义条件（$x \neq \pm 2$）
  - 例 3：约分 $\frac{x^2-4}{x^2-4x+4} = \frac{(x+2)(x-2)}{(x-2)^2} = \frac{x+2}{x-2}$
- **易错点**：分母含字母才是分式；约分前要先因式分解；不能"约掉一项"（如 $\frac{x+2}{x+3}$ 不能约 $x$）
- **自测题** 4 题。

## Task 7: part4/02 分式运算

**File:** `chuzhong_algebra/part4-fractions/02-fraction-operations.md`（模板 C，1800-2500 字）

Title: `# 分式的四则运算`

- **加减法**：
  - 同分母：分子加减，分母不变
  - 异分母：先通分，化为同分母，再加减
- **乘法**：$\frac{A}{B} \cdot \frac{C}{D} = \frac{AC}{BD}$（先因式分解再约分）
- **除法**：$\frac{A}{B} \div \frac{C}{D} = \frac{A}{B} \cdot \frac{D}{C} = \frac{AD}{BC}$（除以分式 = 乘倒数）
- **混合运算顺序**：先乘除、后加减；有括号先括号
- **典型应用** 3 例：
  - 例 1：$\frac{2}{x-1} - \frac{1}{x+1}$（通分得 $\frac{x+3}{(x-1)(x+1)}$）
  - 例 2：$\frac{x^2 - 1}{x^2 - 2x + 1} \cdot \frac{x-1}{x+1}$（先因式分解后约分得 $1$）
  - 例 3：化简求值题，含三项相加
- **易错点**：通分要找最简公分母；除法要变倒数；运算结果要约分
- **自测题** 4 题。

## Task 8: part4/03 分式方程及增根 ⭐（模板 D）

**File:** `chuzhong_algebra/part4-fractions/03-fraction-equation.md`（**模板 D**，3000-4000 字）

Title: `# 分式方程及增根`

**一例速记**：
> 解分式方程"三步走"：① 去分母（乘最简公分母）② 解整式方程 ③ **代回原方程验根**（必须！防止增根）

### 一、引入：增根从哪来
> 解 $\frac{1}{x-2} = \frac{3}{x-2} - 2$。盲解会得到 $x=2$，但代回发现分母 $x-2 = 0$ —— 这是**增根**。

### 二、思维路径还原（12-18 行 `>`）
> "$\frac{1}{x-2} = \frac{3}{x-2} - 2$  
> **第一步：去分母**。两边乘 $(x-2)$：  
> $1 = 3 - 2(x-2)$  
> **第二步：解整式方程**。  
> $1 = 3 - 2x + 4 = 7 - 2x$  
> $2x = 6$ → $x = 3$  
> **第三步：验根**！代回原方程：分母 $x-2 = 1 \neq 0$ ✓，方程成立 ✓  
> 答：$x = 3$  
> **反思**：如果解出来 $x = 2$，会让原分母 = 0 → 这就是**增根**，必须舍去。  
> 增根产生原因：去分母时若公分母为零，会引入额外解。"

### 三、抽象成方法
**解分式方程的三步标准流程**：
1. **去分母**：两边同乘最简公分母（LCM），化为整式方程
2. **解整式方程**：通常是一元一次或一元二次
3. **验根**：代回**原方程的分母**，看是否为零；为零则**舍弃**（增根）

**增根的本质**：去分母时引入"分母 = 0"的情形，原本无意义现在被算出。

### 四、方法变形
- **含参分式方程**：参数取何值使方程有增根 / 无增根 / 有特定根
- **应用题分式方程**：行程问题（往返时间差）、工程问题（合作完成）
- **特殊技巧**：分式形式相同时可"整体换元"（如 $\frac{x+1}{x-1} = t$）

### 五、思考路标（≥6 条）
- 见"分母含未知" → 分式方程
- 解分式方程 → 三步走，**绝不忘验根**
- 增根 = 让原分母为零的解 → 舍弃
- 应用题"...比...多用 1 小时" → 时间差列分式方程
- 应用题"合作完成" → $\frac{1}{a} + \frac{1}{b} = \frac{1}{合作}$
- 含参题求"有增根" → 让原分母 = 0 反推参数

### 六、应用例题 3 例
- 例 1：解 $\frac{x}{x-3} - \frac{2}{x-3} = 1$
- 例 2：含参 $\frac{m}{x-1} - 1 = 0$ 有增根，求 $m$
- 例 3：行程题（如顺风/逆风速度，由飞行时间差列方程）

## Task 9: part4/04 分式化简技巧 ⭐（模板 D）

**File:** `chuzhong_algebra/part4-fractions/04-fraction-techniques.md`（**模板 D**，3000-4000 字）

Title: `# 分式化简技巧`

**一例速记**：
> 分式化简的 4 大武器：① 因式分解 + 约分 ② 通分合并 ③ 整体换元 ④ 裂项相消

### 一、引入：一道复杂化简题
> 化简 $\frac{x^2 - 1}{x^2 - 4x + 3} \cdot \frac{x-3}{x+1}$。看起来吓人，分解+约分后 = 1。

### 二、思维路径还原（12-18 行 `>`）
> "$\frac{x^2 - 1}{x^2 - 4x + 3} \cdot \frac{x-3}{x+1}$  
> 看到分式 + 多项式 → **第一步先因式分解**：  
> $x^2 - 1 = (x+1)(x-1)$  
> $x^2 - 4x + 3 = (x-1)(x-3)$（十字相乘：积 3 和 -4 → $-1, -3$）  
> 原式 = $\frac{(x+1)(x-1)}{(x-1)(x-3)} \cdot \frac{x-3}{x+1}$  
> 约分：$(x+1)$、$(x-1)$、$(x-3)$ 全约掉  
> $= 1$  
> 关键反射：**分式题先因式分解，约分能省 90% 计算**。"

### 三、抽象成方法
**4 大化简技巧**：

1. **因式分解 + 约分**（最常用）：分子分母都先分解，再约掉公因式
2. **通分合并**（异分母相加减）：找最简公分母，统一后合并
3. **整体换元**：见 $\frac{x+1}{x-1} = t$ 简化高次分式
4. **裂项相消**：$\frac{1}{n(n+1)} = \frac{1}{n} - \frac{1}{n+1}$（求和题用）

### 四、方法变形
- **嵌套分式**（繁分式）：$\frac{1 - \frac{1}{x}}{1 + \frac{1}{x}}$ → 上下乘 $x$ 化为 $\frac{x-1}{x+1}$
- **代入求值**：化简后代入条件值
- **条件代入**：题给 $x + \frac{1}{x} = 3$ 求 $x^2 + \frac{1}{x^2}$（用整体平方）

### 五、思考路标（≥6 条）
- 见分式 + 多项式 → **先因式分解再约分**
- 见异分母分式相加减 → **通分**
- 见高次分式 + 重复结构 → **整体换元**
- 见 $\frac{1}{n(n+1)}$ 求和 → **裂项**
- 见繁分式（分母含分式）→ 上下同乘消去内分母
- 化简求值 → 化到最简再代值，不要边算边代

### 六、应用例题 3 例
- 例 1：$\frac{1}{x-1} + \frac{1}{x+1} - \frac{2x}{x^2-1}$（通分得 0）
- 例 2：化简求值 $\frac{x^2 - 6x + 9}{x^2 - 9}$，当 $x = -1$（化简得 $\frac{x-3}{x+3}$，代入 $= 2$）
- 例 3：$\frac{1}{1\cdot 2} + \frac{1}{2\cdot 3} + \cdots + \frac{1}{9 \cdot 10}$（裂项 = $\frac{9}{10}$）
