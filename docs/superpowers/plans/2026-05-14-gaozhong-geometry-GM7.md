- 推导：用两距离和 + 平方化简
- 典型应用 3 例（已知焦点求方程 / 已知顶点求方程 / 用定义判断点是否在椭圆上）

## Task 2: part5/02 椭圆性质 ⭐（模板 D，4000-5500 字）

Title: `# 椭圆的几何性质`

**一例速记**：
> **基本性质**：① 关于 $x$ 轴、$y$ 轴、原点对称 ② 顶点 $(\pm a, 0), (0, \pm b)$（$x$ 轴长轴情形）③ 焦点 $(\pm c, 0)$  
> **离心率** $e = c/a$，$e \in (0, 1)$，$e$ 越大椭圆越"扁"  
> **焦半径**：$|PF_1| = a + ex_0$，$|PF_2| = a - ex_0$（$P(x_0, y_0)$ 在 $x$ 轴长轴椭圆上）  
> **通径** $= \dfrac{2b^2}{a}$（过焦点 $\perp$ 长轴的弦）

**引入题**：椭圆 $\dfrac{x^2}{9} + \dfrac{y^2}{5} = 1$，求长半轴、短半轴、焦距、离心率、顶点、焦点。

**思维路径还原** 15-20 行：直接套定义 + 公式。$a^2 = 9, b^2 = 5 \Rightarrow a = 3, b = \sqrt{5}, c = 2, e = 2/3$。

**抽象成方法**：椭圆 7 大性质 + 4 大公式（焦半径 / 通径 / 离心率 / 准线）

**方法变形**：
- 用 $e$ 反推椭圆方程
- 焦点弦的最短最长情形
- 离心率范围与椭圆形状关系

**思考路标 ≥8 条**：
- 看到"离心率" → $e = c/a$
- 看到"焦半径" → 用 $a \pm ex$（焦点在 $x$ 轴时）
- $0 < e < 1$ 是椭圆；$e = 0$ 退化为圆；$e = 1$ 抛物线；$e > 1$ 双曲线
- 看到"通径" → $2b^2/a$
- 椭圆上点 $P$ 满足 $|PF_1| + |PF_2| = 2a$（**定义恒成立**）

例题 3 例（求离心率 / 用焦半径解题 / 含参椭圆）+ 自测 5 题。

## Task 3: part5/03 直线与椭圆 ⭐（模板 D，4000-5500 字）

Title: `# 直线与椭圆的位置关系`

**一例速记**：
> **位置判别**：直线 $y = kx + m$ 代入椭圆 → 二次方程 → 判别式 $\Delta$。$\Delta > 0$ 相交，$\Delta = 0$ 相切，$\Delta < 0$ 相离。  
> **弦长公式**：$|AB| = \sqrt{1+k^2}\cdot|x_1-x_2| = \sqrt{1+k^2}\cdot\sqrt{(x_1+x_2)^2 - 4x_1 x_2}$（用韦达定理代入）。  
> **中点弦（点差法）**：设两交点 $(x_1, y_1), (x_2, y_2)$，相减消高次项，得**斜率与中点坐标关系** $k = -\dfrac{b^2 x_0}{a^2 y_0}$（椭圆 $\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}=1$，中点 $(x_0, y_0)$）

**引入题**：直线 $y = k(x-1)$ 与椭圆 $\dfrac{x^2}{4} + y^2 = 1$ 交于 $A, B$。若 $|AB| = \dfrac{8\sqrt{2}}{5}$，求 $k$。

**思维路径还原** 15-20 行（用 `>` 引用块）：
- 代入消 $y$：$\dfrac{x^2}{4} + k^2(x-1)^2 = 1$ → $(1+4k^2)x^2 - 8k^2 x + 4k^2 - 4 = 0$
- 由韦达：$x_1+x_2 = \dfrac{8k^2}{1+4k^2}, x_1 x_2 = \dfrac{4k^2-4}{1+4k^2}$
- 弦长公式 $|AB|^2 = (1+k^2)[(x_1+x_2)^2 - 4x_1 x_2]$
- 代入求 $k$

**抽象成方法**：
- 5 大套路：① 代入消元 ② 韦达定理 ③ 设而不求 ④ 弦长公式 ⑤ 中点弦点差法
- 含参讨论：斜率不存在的情形（直线 $\perp x$ 轴）

**方法变形**：
- 焦点弦（直线过焦点）
- 公共弦
- 弦中点轨迹

**思考路标 ≥8 条**：
- 看到"直线与椭圆" → 代入 → $\Delta$ 判位置
- 看到"弦长" → 韦达 + 弦长公式
- 看到"中点弦" → 点差法（不求 $x_1, x_2$）
- 直线过焦点 → 焦半径公式可能更便
- 含参 → 斜率不存在的情形单独讨论

例题 3 例 + 自测 5 题。
