**引入题**：（高考真题级别）已知 $f(x) = e^x - ax^2 - x - 1$，讨论 $f(x)$ 的单调性。

### Task 2: part13/02 含参导数的存在性 ⭐

Title: `# 含参导数与零点存在性`

**核心套路**：
- 含参时方程 / 不等式有解
- "存在 $x_0$ 使 $f(x_0) = 0$" → IVT + 单调性
- "对任意 $x$ 都成立" → 最值问题
- "存在 / 任意"互换的常见错误

**引入题**：（高考真题级别）已知 $f(x) = ax - \ln x$，证明存在 $a$ 使 $f(x) \geq 1$。

**思维路径还原** 15-20 行：求 $f(x)$ 最小值 → 求出 $\min f$ → 解 $\min f \geq 1$ 得 $a$ 的范围。

**3-4 类常见技巧**：
- 存在性 → 转最值
- 含参分离 + 极值定位
- 端点 / 极值的不等关系

### Task 3: part13/03 数列与归纳综合 ⭐

Title: `# 数列综合与数学归纳法`

**核心套路**：
- 数列与不等式综合（$\sum$ 与放缩）
- 数学归纳法（高中"广义"的）
- 数列与函数 / 导数交叉

**引入题**：求证 $\sum_{k=1}^n \frac{1}{k^2} < 2 - \frac{1}{n}$。

**思维路径还原** 15-20 行：用 $\frac{1}{k^2} < \frac{1}{k(k-1)} = \frac{1}{k-1} - \frac{1}{k}$ 裂项放缩。

**3-4 类常见技巧**：
- 放缩 + 裂项
- 数学归纳法
- 数列单调 + 有界 → 极限存在性

### Task 4: part13/04 用导数证明不等式 ⭐

Title: `# 用导数证明不等式`

**核心套路**：
- 构造 $f(x) = $ LHS $-$ RHS，证 $f(x) > 0$
- 经典不等式 $\ln(1+x) < x$、$e^x > 1+x$、$\sin x < x$（$x > 0$）的导数证法
- "高级"放缩：用导数找辅助函数

**引入题**：证明 $\ln(1+x) > \frac{x}{1+x}$（$x > 0$）。

**思维路径还原** 15-20 行：构造 $f(x) = \ln(1+x) - \frac{x}{1+x}$，求导 $f'(x) = \frac{x}{(1+x)^2} > 0$，$f(0) = 0$ → $f(x) > 0$。

**3-4 类常见技巧**：
- 构造法
- 单调性 + 端点值
- 切线放缩（如 $\ln(1+x) \leq x$）

例题 3 例 + 自测题 4 题。

### Task 5: part13/05 三角综合 ⭐

Title: `# 三角函数综合应用`

**核心套路**：

- 解三角形与正余弦定理 + 不等式
- 三角与向量（高中部分内容）

**引入题**：已知 $f(x) = \sin^2 x + 2\sin x \cos x + 3\cos^2 x$，求 $f$ 的最大值与单调递增区间。

**思维路径还原** 15-20 行：用倍角降幂 → 辅助角合并 → $f(x) = \sqrt{2}\sin(2x + \frac{\pi}{4}) + 2$ → 性质。

**3-4 类常见技巧**：
