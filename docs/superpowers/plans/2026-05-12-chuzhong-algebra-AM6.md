## Task 1: part10/01 二次函数概念与图象

**File:** `chuzhong_algebra/part10-quadratic-functions/01-quadratic-fn-basics.md`（模板 C，1800-2500 字）

Title: `# 二次函数的概念与图象`

- **定义**：$y = ax^2 + bx + c$（$a \neq 0$）；$a, b, c$ 称为系数
- **图象**：**抛物线**（开口向上 $a > 0$，向下 $a < 0$）
- **对称轴**：$x = -\frac{b}{2a}$（垂直于 $x$ 轴的直线）
- **顶点**：抛物线最高/最低点；横坐标 $-\frac{b}{2a}$，纵坐标 $\frac{4ac - b^2}{4a}$
- **图象画法**：列表→描点→连线（关键 5 点：顶点、对称轴左右两侧各 2 点）
- **特殊情形**：
  - $y = ax^2$（顶点在原点，对称轴 $x = 0$）
  - $y = a(x - h)^2$（顶点 $(h, 0)$）
  - $y = ax^2 + k$（顶点 $(0, k)$）
- **典型应用** 3 例：
  - 例 1：判断 $y = x^2, y = (x-1)^2, y = \frac{1}{x^2}, y = 2x^2 + 1$ 哪些是二次函数
  - 例 2：求 $y = 2x^2 - 4x + 1$ 的开口方向、对称轴、顶点
  - 例 3：图象题——已知抛物线与 $x$ 轴交点 $(1, 0)$, $(3, 0)$，求对称轴（$x = 2$）
- **易错点**：$a \neq 0$；对称轴公式不要漏负号；顶点纵坐标 = 把 $x = -\frac{b}{2a}$ 代回原式
- **自测题** 4 题。

## Task 2: part10/02 三种形式 ⭐（模板 D）

**File:** `chuzhong_algebra/part10-quadratic-functions/02-three-forms.md`（**模板 D**，3000-4000 字）

Title: `# 二次函数的三种形式`

**一例速记**：
> 一般式 $y = ax^2 + bx + c$ → 顶点式 $y = a(x-h)^2 + k$ → 交点式 $y = a(x-x_1)(x-x_2)$。**形式选对，解题秒杀**。

### 一、引入题
> 已知抛物线经过 $(0, -3)$、与 $x$ 轴交于 $(-1, 0), (3, 0)$，求解析式。用三种形式各试一次。

### 二、思维路径还原（12-18 行 `>` 引用）
> "三个点 + 已知交点位置 —— 注意：题目给的两点正好是 $x$ 轴交点 $(-1, 0), (3, 0)$！  
> **方法 1：一般式** $y = ax^2 + bx + c$，代 3 个点 → 解三元方程组（最复杂）  
> **方法 2：交点式** $y = a(x - x_1)(x - x_2)$，已知 $x_1 = -1, x_2 = 3$ → $y = a(x+1)(x-3)$  
> 代第三点 $(0, -3)$：$-3 = a \cdot 1 \cdot (-3) = -3a$ → $a = 1$  
> 解析式：$y = (x+1)(x-3) = x^2 - 2x - 3$  
> **方法 3：顶点式** —— 需要先求顶点，不直接，不优先  
> **关键反射**：见 $x$ 轴交点 → 交点式最快；见顶点 → 顶点式最快；都没有 → 一般式。"

### 三、抽象成方法
**三种形式 + 适用情形**（用表格）：

| 形式 | 公式 | 适用条件 |
|---|---|---|
| **一般式** | $y = ax^2 + bx + c$ | 已知任意三点 |
| **顶点式** | $y = a(x - h)^2 + k$（顶点 $(h, k)$）| 已知顶点 + 一点 |
| **交点式** | $y = a(x - x_1)(x - x_2)$（$x_1, x_2$ 是 $x$ 轴交点）| 已知 $x$ 轴交点 + 一点 |

**形式互换**：
- 一般式 → 顶点式：**配方法**（$h = -\frac{b}{2a}$，$k = \frac{4ac-b^2}{4a}$）
- 一般式 → 交点式：求 $x_1, x_2$（用求根公式或因式分解），需 $\Delta \geq 0$

### 四、方法变形
- **平移规律（顶点式视角）**：$y = a(x-h)^2 + k$ 是 $y = ax^2$ 右移 $h$ 上移 $k$
- **三形式之间快速识别**：见 $(x - 2)$ 平方项 → 顶点式；见 $(x-1)(x-3)$ → 交点式

### 五、思考路标（≥6 条）
- 已知顶点 → **顶点式**最快
- 已知 $x$ 轴交点 → **交点式**最快
- 已知三个任意点 → **一般式**
- 求最值 / 增减区间 → **顶点式**（顶点即最值点）
- 求与 $x$ 轴交点 → **交点式**（$x_1, x_2$ 直接读出）
- 配方 = 一般式 → 顶点式的桥梁

### 六、应用例题 3 例
- 例 1：用交点式求解析式（同引入题）
- 例 2：已知顶点 $(1, 4)$ 和过点 $(0, 3)$，求解析式（用顶点式 → $y = -(x-1)^2 + 4$）
- 例 3：一般式 $y = x^2 - 4x + 1$ 配方为顶点式 $y = (x-2)^2 - 3$

### 七、自测题 5 题

## Task 3: part10/03 二次函数性质

**File:** `chuzhong_algebra/part10-quadratic-functions/03-quadratic-fn-properties.md`（模板 C，2200-3000 字）

Title: `# 二次函数的性质：增减性、对称性、最值`

- **对称性**：抛物线关于**对称轴** $x = -\frac{b}{2a}$ 对称
  - 性质：对称轴两侧函数值关于对称轴**镜像**
  - 应用：$f(a) = f(2h - a)$（$h$ 是对称轴）
- **增减性**（按 $a$ 符号 + 对称轴左右分类）：
  - $a > 0$（开口向上）：
    - 对称轴**左侧**（$x < h$）：$y$ 随 $x$ 增大**减小**
    - 对称轴**右侧**（$x > h$）：$y$ 随 $x$ 增大**增大**
  - $a < 0$（开口向下）：反之
- **最值**：
  - $a > 0$：**最小值** $= k = \frac{4ac - b^2}{4a}$（顶点处）
  - $a < 0$：**最大值** $= k$
- **图象与 $a, b, c, \Delta$ 关系**（用表格）：

| 项 | 符号判断 |
|---|---|
| $a > 0$ vs $< 0$ | 开口向上 vs 向下 |
| $b$ 与 $a$ 同号 vs 异号 | 对称轴在 $y$ 轴左侧 vs 右侧 |
| $c > 0$ vs $< 0$ | 抛物线与 $y$ 轴交点在 $x$ 轴上方 vs 下方 |
| $\Delta > 0, = 0, < 0$ | 与 $x$ 轴 2 / 1 / 0 个交点 |

- **典型应用** 3 例：
  - 例 1：求 $y = 2x^2 - 8x + 3$ 的最值及对称轴
  - 例 2：用对称性求 $f(5)$（已知对称轴 $x = 2, f(-1) = 0$）→ 答 $0$
  - 例 3：图象题——给抛物线图象，判断 $a, b, c$ 符号
- **易错点**：增减性"分段描述"（左减右增或反之）；最值看 $a$ 符号定最大最小；
- **自测题** 5 题。

## Task 4: part10/04 待定系数求解析式

**File:** `chuzhong_algebra/part10-quadratic-functions/04-finding-expression.md`（模板 C，2000-2700 字）

Title: `# 二次函数的待定系数法`

- **待定系数法 4 步**（与一次函数相同套路）：
  1. **设**：根据已知信息选择三种形式之一（呼应 part10/02）
  2. **代**：代入已知点
  3. **解**：解方程组求未知系数
  4. **写**：写出解析式 + 验证
- **三种形式的设元**：
  - 任意三点 → 设一般式（3 个系数 $a, b, c$）
  - 顶点 + 1 点 → 设顶点式（3 个待定，但形式更紧凑）
  - 两 $x$ 轴交点 + 1 点 → 设交点式
- **典型应用** 3 例：
  - 例 1：经过 $(0, 1), (1, 0), (2, 3)$，设一般式 → 解出 $a, b, c$
  - 例 2：顶点 $(2, -3)$ + 过点 $(0, 5)$，设顶点式 $y = a(x-2)^2 - 3$ → $a = 2$
  - 例 3：与 $x$ 轴交于 $(1, 0), (-3, 0)$ + 过点 $(0, -6)$，设交点式 → $a = 2$
- **易错点**：根据信息选**最快**的形式；交点式必须验证 $\Delta \geq 0$；代入后小心算错
- **自测题** 4 题。

## Task 5: part10/05 二次函数应用

**File:** `chuzhong_algebra/part10-quadratic-functions/05-quadratic-fn-applications.md`（模板 C，2200-3000 字）

Title: `# 二次函数的应用`

- **3 类典型应用**：
  1. **拱桥 / 隧道 / 喷泉**：建立坐标系 + 设顶点式
  2. **利润 / 销售最值**：单价 $\times$ 销量 = 利润；销量与单价成一次关系 → 利润关于单价的二次函数
  3. **几何最值**：含动点的面积 / 周长最值
- **求最值的标准流程**：
  1. **建函数关系** $y = ax^2 + bx + c$（$a$ 必须为负数才有最大值）
  2. **配方求顶点**或用顶点公式
  3. **检验定义域**（实际意义）—— 若顶点在定义域外，最值在端点
- **典型应用** 3 例：
  - 例 1：**拱桥** —— 拱跨度 20 m、拱高 4 m，建坐标系（顶点在原点）→ $y = -\frac{1}{25}x^2 + 4$（顶点式）
  - 例 2：**利润最大** —— 某商品成本 50 元 / 件，售价 $x$ 元 / 件时月销量 $y = 300 - 10(x - 60)$。求月利润 $W$ 关于 $x$ 的函数，求最大利润对应的 $x$
  - 例 3：**几何最值** —— 用 100 m 篱笆围成靠墙矩形，求最大面积（铺垫 part14 二次函数与几何）
- **易错点**：建立坐标系要选好原点；实际意义检查（如 $x > 0$）；最值若在区间内取顶点值，在区间外取端点值
- **自测题** 5 题。

## Task 6: part10/06 二次函数与一元二次方程 ⭐（模板 D）

**File:** `chuzhong_algebra/part10-quadratic-functions/06-fn-and-equation.md`（**模板 D**，3000-4000 字）

Title: `# 二次函数与一元二次方程的关系`

**一例速记**：
> **抛物线与 $x$ 轴交点的横坐标 = 方程 $ax^2 + bx + c = 0$ 的根**。判别式 $\Delta$ 同时决定方程根的个数 + 图象交点个数。

### 一、引入题
> 已知抛物线 $y = x^2 - 4x + 3$，问与 $x$ 轴有几个交点？交点坐标？

### 二、思维路径还原（12-18 行 `>` 引用）
> "求抛物线与 $x$ 轴交点 = 求函数值 $y = 0$ 的 $x$ 值  
> 即解一元二次方程 $x^2 - 4x + 3 = 0$  
> **代数解法**：因式分解 $(x-1)(x-3) = 0$ → $x = 1$ 或 $x = 3$  
> **几何意义**：抛物线与 $x$ 轴交于 $(1, 0), (3, 0)$ 两点  
> **再深入**：判别式 $\Delta = 16 - 12 = 4 > 0$ → 方程有 2 个不等实根 → 抛物线与 $x$ 轴有 2 个交点  
> 三种情形（用 $\Delta$ 判别）：  
>   - $\Delta > 0$：抛物线与 $x$ 轴 2 个交点（方程 2 实根）  
>   - $\Delta = 0$：1 个切点（方程 1 重根）  
>   - $\Delta < 0$：无交点（方程无实根）  
> **关键反射**：抛物线与 $x$ 轴的关系 = 一元二次方程根的情况。代数与几何**完全对应**。"

### 三、抽象成方法
**核心对应关系**（用表格，模板 D 灵魂）：

| 二次函数 | 一元二次方程 |
|---|---|
| $y = ax^2 + bx + c$ 与 $x$ 轴交点横坐标 | 方程 $ax^2 + bx + c = 0$ 的根 |
| 抛物线与 $x$ 轴 2 个交点 | $\Delta > 0$，方程 2 实根 |
| 抛物线与 $x$ 轴 1 个切点 | $\Delta = 0$，方程 1 重根 |
| 抛物线与 $x$ 轴无交点 | $\Delta < 0$，方程无实根 |
| 抛物线在 $x$ 轴上方区域 | 不等式 $ax^2 + bx + c > 0$ 的解集 |
| 抛物线在 $x$ 轴下方区域 | 不等式 $ax^2 + bx + c < 0$ 的解集 |
| 两抛物线交点 | 两个二次方程联立的解 |

### 四、方法变形
- **抛物线与水平直线 $y = m$ 的交点**：等价方程 $ax^2 + bx + c = m$
- **抛物线与一次函数的交点**：联立 → 二次方程
- **韦达定理几何意义**：$x_1 + x_2 = -\frac{b}{a}$ 是两 $x$ 轴交点的横坐标之和

### 五、思考路标（≥6 条）
- 见抛物线与 $x$ 轴交点 → 方程 $y = 0$
- 见 $\Delta$ → 同时想方程根数 + 图象交点数
- 见 $y > 0$ 解集 → 抛物线在 $x$ 轴上方的 $x$ 范围
- 见两抛物线交点 → 联立两方程消 $y$
- 见 $y = mx + n$ 与抛物线交点 → 联立成二次方程
- 数形结合是二次函数压轴题的核心

### 六、应用例题 3 例
- 例 1：基础 —— 求 $y = x^2 - 4x + 3$ 与 $x$ 轴交点（同引入题）
- 例 2：**不等式应用** —— 解 $x^2 - 4x + 3 > 0$（解集 $x < 1$ 或 $x > 3$）
- 例 3：**含参** —— $y = x^2 + (2k-1)x + k^2$ 与 $x$ 轴有 2 个交点，求 $k$ 范围（$\Delta > 0$）

### 七、自测题 5 题

## Task 7: part10/07 含参二次函数最值 ⭐（模板 D）

**File:** `chuzhong_algebra/part10-quadratic-functions/07-parametric-quadratic-fn.md`（**模板 D**，3000-4000 字）

Title: `# 含参二次函数的最值与位置`

**一例速记**：
> 含参二次函数 $y = ax^2 + bx + c$ —— 看到参数要问 4 件事：① 是否仍是二次函数（$a \neq 0$）② 开口方向（$a$ 符号）③ 对称轴位置（$-\frac{b}{2a}$）④ 最值是顶点还是区间端点（讨论顶点是否在区间内）

### 一、引入题
> 求函数 $y = x^2 - 2ax + 3$ 在 $0 \leq x \leq 2$ 区间内的最小值（含参 $a$）。

### 二、思维路径还原（12-18 行 `>` 引用）
> "$y = x^2 - 2ax + 3$ → 配方 $y = (x - a)^2 + (3 - a^2)$ → 顶点 $(a, 3 - a^2)$  
> 开口向上 → 顶点是**全局最小值**点（顶点 $y$ 最小）  
> 但题目限制 $0 \leq x \leq 2$ —— 顶点 $x = a$ 是否在这个区间内？需要**分类讨论**！  
> **情形 1：$a < 0$**（顶点在区间左侧）→ 区间内 $y$ 单调递增 → 最小值在 $x = 0$ 处取 → $y_{\min} = 3$  
> **情形 2：$0 \leq a \leq 2$**（顶点在区间内）→ 最小值在顶点 → $y_{\min} = 3 - a^2$  
> **情形 3：$a > 2$**（顶点在区间右侧）→ 区间内 $y$ 单调递减 → 最小值在 $x = 2$ 处取 → $y_{\min} = 4 - 4a + 3 = 7 - 4a$  
> **关键反射**：含参二次函数在闭区间求最值 → **分类讨论对称轴位置**（与区间的相对位置）。"

### 三、抽象成方法
**含参二次函数 4 类问题**：
1. **判断是否仍是二次**：$a \neq 0$
2. **开口方向 + 对称轴位置**：依 $a$ 符号 + $b/a$ 比例
3. **闭区间最值**：**关键技术** —— 比较对称轴 vs 区间的位置
4. **图象经过点 / 经过象限**：代入条件 + 分类

**区间最值三情形**（$a > 0$ 开口向上时）：
- 对称轴在区间**左**：区间内单调增 → 最小值在左端、最大值在右端
- 对称轴在区间**内**：最小值在顶点、最大值在远离对称轴的端点
- 对称轴在区间**右**：单调减 → 最小值在右端、最大值在左端

### 四、方法变形
- **含参与含 x 的不等式综合**：如 "$y > 0$ 对所有 $x$ 成立" → $\Delta < 0$ + $a > 0$
- **抛物线过定点**：把解析式整理为 $a \cdot f(x) + g(x) = 0$，$f(x) = 0$ 时确定定点
- **抛物线开口大小**：$|a|$ 越大开口越窄

### 五、思考路标（≥6 条）
- 见含参二次 → 先看 $a$ 是否可为零
- 见区间最值 → 比较对称轴位置
- 见"对所有 $x$ 成立 $y > 0$" → $a > 0$ + $\Delta < 0$
- 见"过定点" → 整理为 $k \cdot f(x) + g(x)$ 找 $f(x) = 0$
- 见 $|a|$ 比较 → 开口大小
- 含参题答案常以参数范围给出

### 六、应用例题 3 例
- 例 1：闭区间最值（同引入题）
- 例 2：**过定点** —— 证 $y = ax^2 - 2ax + a + 1$（$a \neq 0$）必过 $(1, 1)$
- 例 3：**恒成立** —— $y = x^2 - 2mx + 4 > 0$ 对所有 $x$ 成立，求 $m$ 范围（$\Delta < 0$ → $|m| < 2$）

### 七、自测题 5 题

## Task 8: part10/08 二次函数中三角形面积 ⭐（模板 D）

**File:** `chuzhong_algebra/part10-quadratic-functions/08-quadratic-fn-area.md`（**模板 D**，3000-4000 字）

Title: `# 二次函数中三角形面积——铅垂高法`

**一例速记**：
> 二次函数图象上三角形面积求法：**铅垂高 $\times$ 水平宽 $\div 2$**。即 $S_{\triangle} = \frac{1}{2} \cdot |x_2 - x_1| \cdot h$（$h$ 是"铅垂高"）。中考压轴最常用。

### 一、引入题
> 抛物线 $y = -x^2 + 2x + 3$ 与 $x$ 轴交于 $A, B$ 两点，与 $y$ 轴交于 $C$。$P$ 是抛物线在第一象限内的动点。求 $\triangle PBC$ 面积的最大值。

### 二、思维路径还原（12-18 行 `>` 引用）
> "$y = -x^2 + 2x + 3$ → 求 $A, B, C$ 坐标：  
> 与 $x$ 轴交点（$y = 0$）：$-x^2 + 2x + 3 = 0$ → $x^2 - 2x - 3 = 0$ → $x = -1$ 或 $3$ → $A(-1, 0), B(3, 0)$  
> 与 $y$ 轴交点（$x = 0$）：$y = 3$ → $C(0, 3)$  
> 设 $P(t, -t^2 + 2t + 3)$（$0 < t < 3$，第一象限）  
> **求 $\triangle PBC$ 面积** —— 用**铅垂高法**：  
> 直线 $BC$：经过 $(3, 0), (0, 3)$ → $y = -x + 3$  
> 过 $P$ 作 $x$ 轴垂线交 $BC$ 于 $Q$ → $Q(t, -t + 3)$  
> 铅垂高 $h = |PQ| = |(-t^2 + 2t + 3) - (-t + 3)| = |-t^2 + 3t| = t(3-t)$（$0 < t < 3$ 时正）  
> 水平宽 = $|x_B - x_C| = 3$  
> $S = \frac{1}{2} \cdot 3 \cdot t(3-t) = \frac{3}{2}(3t - t^2) = -\frac{3}{2}(t - \frac{3}{2})^2 + \frac{27}{8}$  
> 当 $t = \frac{3}{2}$ 时，$S_{\max} = \frac{27}{8}$  
> **关键反射**：求二次函数中三角形面积 → **铅垂高 $\times$ 水平宽 $\div 2$**，避开点到直线距离公式。"

### 三、抽象成方法
**铅垂高法核心**：
1. 选一条边作为"底"（通常是已知端点的两个定点之间的连线）
2. 过另一顶点（动点）作 $x$ 轴垂线，与"底"直线相交
3. 这条垂直线段长度 = **铅垂高 $h$**
4. 水平宽 = 底两端点横坐标差的绝对值
5. **$S = \frac{1}{2} \cdot$ 水平宽 $\cdot$ 铅垂高**

**为什么这样？** —— 把斜三角形按 $x$ 轴方向"剪开"成上下两部分，等价为同底高三角形。

### 四、方法变形
- **不是 $x$ 轴垂直版**：可用水平宽（过动点作 $y$ 轴垂线，类比）
- **动点在曲线上 + 求面积最值** = 铅垂高代数式 + 二次函数最值（套路化）
- **三角形面积存在性问题**：给定面积反求动点位置

### 五、思考路标（≥6 条）
- 见"抛物线上三角形面积"→ **铅垂高法**
- 选定底（用两个定点连线作底）
- 过动点向 $x$ 轴作垂线交底
- 铅垂高 = $y_P - y_{Q}$（$Q$ 在底直线上）的绝对值
- 水平宽 = 两底端点 $x$ 差的绝对值
- 求最值 → 铅垂高表达式是二次函数 → 顶点法
