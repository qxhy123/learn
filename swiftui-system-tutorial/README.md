# SwiftUI 系统教程：从零到 Mac 创作工具工程

## 这套教程解决什么问题

- 它是独立 SwiftUI 产品，不是 `swift-tutorial` 的附录。
- 它围绕 `BoardFlow` 讲普通 UI、工作台、画布、绘制、文档与互操作。

## 谁适合读

- 已有基础 Swift 语法。
- 想系统学 SwiftUI，而不是只背组件。
