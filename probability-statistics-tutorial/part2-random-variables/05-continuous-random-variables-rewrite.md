> **一例速记**：
> **PDF 与 CDF**：$f(x) \geq 0$，$\int_{-\infty}^{+\infty} f(x)\,dx = 1$；$F(x) = \int_{-\infty}^x f(t)\,dt$，$F$ 单调不减、右连续、$F(-\infty)=0,F(+\infty)=1$。
> **区间概率**：$P(a < X \leq b) = F(b) - F(a) = \int_a^b f(x)\,dx$。**单点概率为零**：$P(X = a) = 0$。
> **期望方差**：$E(X) = \int x f(x)\,dx$，$\text{Var}(X) = E(X^2) - (EX)^2 = \int (x - \mu)^2 f(x)\,dx$。
> **函数变换**：$Y = g(X)$，$g$ 单调可微 → $f_Y(y) = f_X(g^{-1}(y)) \cdot \vert (g^{-1})'(y) \vert$（一维 Jacobian）。
> **三大姊妹**：标准正态 $Z \sim N(0,1)$；指数 $\text{Exp}(\lambda)$ 无记忆性；均匀 $U(a,b)$。

## 一、引入：一道反直觉的"单点概率"题

> **题目**：设 $X$ 服从 $U(0, 1)$（均匀分布）。求：
> (1) $P(X = 0.5)$；
> (2) $P(0.3 < X < 0.5)$；
> (3) $P(X \leq 0.5)$。

请先停下来想一想：**$P(X = 0.5)$ 等于什么？**

直觉答案：$1/\infty = 0$？或者就等于 $0.5$（"50% 概率"的错觉）？

正确答案：$P(X = 0.5) = 0$。这正是**连续与离散的本质差别**——连续随机变量的"单点概率必为零"，但**单点仍是可能取值**。这种"既不为零却也不取得概率"的现象是初学者最容易卡住的地方。下面把内心独白完整还原。

---

## 二、思维路径还原（解题者的内心独白）

> "看到 $X \sim U(0, 1)$，立刻想 PDF：$f(x) = 1$（$x \in [0,1]$），其他地方为 $0$。
>
> **第 (1) 问 $P(X = 0.5)$**：我要计算单点处的概率。在连续型场景，单点 $\{0.5\}$ 是**测度为零**的集合——它没有"长度"。
>
> 用积分定义验证：$P(X = 0.5) = \int_{0.5}^{0.5} f(x)\,dx = 0$。✓
>
> **但这不意味着 $X$ 不能取 $0.5$**——只是 $0.5$ 这一**点本身的概率密度** $f(0.5) = 1$，需要乘上一段"长度"才能变成概率。这是连续型的**反直觉之一**。
>
> **第 (2) 问 $P(0.3 < X < 0.5)$**：用 PDF 积分 $\int_{0.3}^{0.5} 1\,dx = 0.2$。✓
>
> **第 (3) 问 $P(X \leq 0.5)$**：用 CDF $F(0.5) = \int_0^{0.5} 1\,dt = 0.5$。注意由于 $P(X = 0.5) = 0$，所以 $P(X \leq 0.5) = P(X < 0.5)$——**离散型严格区分而连续型不区分**。
>
> **延伸思考**：如果题目改成"$P(X = 0.5 \text{ 或 } X = 0.7)$"，答案仍是 $0 + 0 = 0$。但"$P(X \in [0, 0.5] \cup [0.7, 1])$"则是 $0.5 + 0.3 = 0.8$。连续型的概率**只对'区间 / 集合'有意义**，单点是测度零。
>
> 这就是连续型概率论与勒贝格测度的桥梁——但在工程实践中，**只要记住"单点为零、区间积分"两条规则就够了**。"

## 三、抽象成方法

### 5 大核心公式

| 名称 | 公式 | 关键性质 |
|---|---|---|
| **PDF**（概率密度） | $f(x) \geq 0$，$\int_{-\infty}^{+\infty} f = 1$ | $f$ 可 $>1$（不是概率） |
| **CDF**（累积分布） | $F(x) = \int_{-\infty}^x f(t)\,dt$ | 单调不减，右连续，端点 0 与 1 |
| **区间概率** | $P(a < X \leq b) = F(b) - F(a) = \int_a^b f$ | **单点 $P(X=a)=0$** |
| **期望** | $E(X) = \int x f(x)\,dx$ | 线性 $E(aX+b)=aE(X)+b$ |
| **方差** | $\text{Var}(X) = E(X^2) - (EX)^2$ | $\text{Var}(aX+b)=a^2\text{Var}(X)$ |

### 函数变换标准 3 步（$Y = g(X)$）

1. **求 $Y$ 的取值范围**：根据 $X$ 范围和 $g$ 推出
2. **求 $F_Y(y) = P(Y \leq y) = P(g(X) \leq y)$**：化为 $X$ 的不等式
3. **求 $f_Y(y) = F_Y'(y)$**：求导得密度

**当 $g$ 严格单调可微**，可直接用公式：
$$f_Y(y) = f_X(g^{-1}(y)) \cdot \vert (g^{-1})'(y) \vert$$

## 四、方法变形

### 变形 1：分段 PDF

PDF 可以分段定义（如 $U(a,b)$ 的 $f(x) = 1/(b-a)$ 在区间内，外面为 0）。**积分时要按分段处理**，不要全区间积。

### 变形 2：含参数 PDF 求常数

题目给"$f(x) = c \cdot g(x)$ 在某区间，求 $c$" → 用归一化条件 $\int f = 1$ 解出 $c$。
**例**：$f(x) = c x$ 在 $[0, 2]$，则 $\int_0^2 cx\,dx = 2c = 1$，所以 $c = 1/2$。

### 变形 3：求中位数 / 分位数

中位数 $m$ 满足 $F(m) = 1/2$；$p$ 分位数 $x_p$ 满足 $F(x_p) = p$。
**例**：$X \sim \text{Exp}(1)$ 的中位数 = $\ln 2 \approx 0.693$（解 $1 - e^{-m} = 1/2$）。

### 变形 4：$Y = g(X)$ 的期望（LOTUS）

不必先求 $f_Y$。直接用 **Law of Unconscious Statistician**：
$$E(g(X)) = \int g(x) f_X(x)\,dx$$
**注意** $E(g(X)) \neq g(E(X))$ 一般（除非 $g$ 线性）。

## 五、思考路标（条件反射）

1. 看到"连续型"→ 想 PDF $f$ 和 CDF $F$，区分单点与区间
2. 看到"$P(X = a)$"对连续型 → 立刻为 $0$
3. 看到"$P(a < X < b)$" → 积分 $\int_a^b f\,dx$ 或 $F(b) - F(a)$
4. 看到 PDF 求常数 → 用归一化 $\int f = 1$
5. 看到 $E(X^2)$ → 不能写成 $(E(X))^2$，二者差一个 $\text{Var}$
6. 看到 $Y = g(X)$ 求分布 → CDF 法 3 步；$g$ 单调时可用 Jacobian 公式
7. 看到 $E(g(X))$ → 用 LOTUS $\int g \cdot f$，**不要**先求 $f_Y$
8. 看到"无记忆性" → 指数分布（$\text{Exp}(\lambda)$ 唯一具有此性质的连续分布）
9. 看到 $N(\mu, \sigma^2)$ 概率 → 标准化 $Z = (X-\mu)/\sigma$ 查正态表
10. 看到对称分布求 $P(X < -a)$ → 用 $\Phi(-a) = 1 - \Phi(a)$

## 六、典型应用

### 例 1：归一化求常数 + 算概率

> **题目**：设 $f(x) = \begin{cases} c x^2, & 0 \leq x \leq 2 \\ 0, & \text{其它} \end{cases}$。求 (1) $c$；(2) $P(1 < X < 1.5)$；(3) $E(X)$。

【思路】先用归一化求 $c$，再用积分算其它。

【解】
(1) $\int_0^2 c x^2\,dx = \frac{8c}{3} = 1 \Rightarrow c = 3/8$。
(2) $P(1 < X < 1.5) = \int_1^{1.5} \frac{3}{8} x^2\,dx = \frac{1}{8}[x^3]_1^{1.5} = \frac{1}{8}(3.375 - 1) = \frac{19}{64} \approx 0.297$。
(3) $E(X) = \int_0^2 x \cdot \frac{3}{8} x^2\,dx = \frac{3}{8}\int_0^2 x^3\,dx = \frac{3}{8} \cdot 4 = 1.5$。

【答案】$\boxed{c = 3/8,\ P = 19/64,\ E(X) = 3/2}$。

### 例 2：函数变换 $Y = X^2$

> **题目**：$X \sim U(0, 1)$，$Y = X^2$。求 $f_Y(y)$。

【思路】$g(x) = x^2$ 在 $[0,1]$ 上单调可微，可用 Jacobian 公式；也可用 CDF 法。

【解】（CDF 法）：$F_Y(y) = P(Y \leq y) = P(X^2 \leq y) = P(X \leq \sqrt{y}) = \sqrt{y}$（$y \in [0,1]$）。

求导得 $f_Y(y) = \frac{1}{2\sqrt{y}}$（$y \in (0,1]$）。

【验证】用 Jacobian 公式：$g^{-1}(y) = \sqrt{y}$，$(g^{-1})'(y) = \frac{1}{2\sqrt{y}}$，$f_X(\sqrt{y}) = 1$，故 $f_Y(y) = 1 \cdot \frac{1}{2\sqrt{y}}$ ✓。

【答案】$\boxed{f_Y(y) = \frac{1}{2\sqrt{y}},\ y \in (0, 1]}$。

【注】注意 $y \to 0^+$ 时 $f_Y(y) \to \infty$——**PDF 可以无界**，只要积分为 1 即可。

### 例 3：标准化 + 正态查表

> **题目**：$X \sim N(60, 100)$（均值 60、方差 100，即标准差 10）。求 $P(50 \leq X \leq 70)$ 和 $P(X > 80)$。

【思路】标准化 $Z = (X - 60)/10 \sim N(0, 1)$。

【解】
(1) $P(50 \leq X \leq 70) = P(-1 \leq Z \leq 1) = \Phi(1) - \Phi(-1) = 2\Phi(1) - 1 \approx 2(0.8413) - 1 = 0.6826$。

（即"$\pm 1\sigma$ 区间"包含 $\approx 68.26\%$ 概率——经验法则）

(2) $P(X > 80) = P(Z > 2) = 1 - \Phi(2) \approx 1 - 0.9772 = 0.0228$。

【答案】$\boxed{P_1 \approx 0.683,\ P_2 \approx 0.023}$。

## 七、自测题

**自测 1**　设 $f(x) = \begin{cases} kx, & 0 < x < 4 \\ 0, & \text{其它} \end{cases}$。求 $k$ 与 $E(X), \text{Var}(X)$。

> 💡 提示：归一化 $\int_0^4 kx\,dx = 8k = 1 \Rightarrow k = 1/8$。$E(X) = \int_0^4 \frac{x^2}{8}\,dx = \frac{8}{3}$。$E(X^2) = \int_0^4 \frac{x^3}{8}\,dx = 8$。$\text{Var}(X) = 8 - 64/9 = 8/9$。

**自测 2**　$X \sim \text{Exp}(2)$（即 $\lambda = 2$）。求 $P(X > 1)$ 和"已知 $X > 1$ 条件下 $X > 1.5$ 的概率"。

> 💡 提示：$P(X > 1) = e^{-2} \approx 0.135$。条件概率：$P(X > 1.5 \mid X > 1) = P(X > 0.5)$（无记忆性）$= e^{-1} \approx 0.368$。**关键**：指数分布无记忆性 $P(X > s+t \mid X > s) = P(X > t)$。

**自测 3**　$X \sim N(0, 1)$，$Y = X^2$。证明 $Y \sim \chi^2_1$（自由度 1 的卡方分布）。

> 💡 提示：用 CDF 法。$F_Y(y) = P(X^2 \leq y) = P(-\sqrt{y} \leq X \leq \sqrt{y}) = 2\Phi(\sqrt{y}) - 1$。求导 $f_Y(y) = \frac{1}{\sqrt{y}} \cdot \phi(\sqrt{y}) = \frac{1}{\sqrt{2\pi y}}e^{-y/2}$。这正是 $\chi^2_1$ 的 PDF（$\Gamma(1/2, 1/2)$）。

**自测 4**　$X$ 的 PDF 是 $f(x) = \frac{1}{\pi(1+x^2)}$（柯西分布）。求 $E(X)$。

> 💡 提示：$\int_{-\infty}^{+\infty} \frac{x}{\pi(1+x^2)}\,dx$ **不绝对收敛**（虽然 Cauchy 主值为 0），所以 **$E(X)$ 不存在**。柯西分布是著名的"无均值无方差"分布——CLT 不适用。

**自测 5**　$X \sim U(-1, 1)$，$Y = e^X$。求 $f_Y(y)$ 和 $E(Y)$。

> 💡 提示：$Y = e^X$ 单调，$g^{-1}(y) = \ln y$，$y \in (1/e, e)$。$f_Y(y) = f_X(\ln y) \cdot \frac{1}{y} = \frac{1}{2y}$。$E(Y) = \int_{-1}^{1} e^x \cdot \frac{1}{2}\,dx = \frac{e - e^{-1}}{2} = \sinh(1) \approx 1.175$。**注意** $e^{E(X)} = e^0 = 1 \neq E(e^X)$——非线性变换下期望不可换。
