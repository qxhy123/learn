# 概率公理与样本空间

> **一例速记**：已知均匀分布的圆盘上随机取点，落在直径为 $r$ 的内切圆内的概率是多少？
> 古典概型无法直接用（点的个数无穷），改用几何概型：
> $$P = \frac{\text{内切圆面积}}{\text{大圆面积}} = \frac{\pi (r/2)^2}{\pi r^2} = \frac{1}{4}.$$
> **识别"等可能 + 有限"用古典，识别"等可能 + 连续"用几何。**

---

## 一、为什么需要公理化概率

日常语言里的"概率"至少有三种截然不同的含义：掷硬币的正面概率 $1/2$ 是"对称性"，100 次试验出现 47 次正面说明频率约 $0.47$，气象预报"明天降雨概率 70\%"则是"主观信度"。

这三种含义表面上都叫"概率"，但它们的来源、计算方式、适用场景各不相同。如果不加以区分，就很容易混淆，产生逻辑矛盾。

**Kolmogorov 公理化体系**（1933 年）的意义在于：不管概率的"物理含义"是什么（频率？对称？主观？），只要满足三条公理，就能用同一套数学工具推导所有结论。这就像欧几里得几何：不管"点"和"线"在现实中指什么，只要满足公理，几何定理就成立。

本篇从样本空间和事件运算讲起，建立 Kolmogorov 三公理，引入 $\sigma$-代数的基本概念，对比四种概型，最后用古典概型和几何概型双解一道经典问题。

---

## 二、样本空间与事件

### 2.1 样本空间

**定义**：一次随机试验的所有可能结果组成的集合，称为**样本空间**，记作 $\Omega$。$\Omega$ 中的每个元素 $\omega$ 称为一个**样本点**（基本结果）。

| 试验 | 样本空间 $\Omega$ |
|---|---|
| 掷一枚硬币 | $\{H, T\}$ |
| 掷一颗骰子 | $\{1, 2, 3, 4, 5, 6\}$ |
| 测量一根棍子的长度（单位：cm）| $[0, +\infty)$ |
| 同时掷两枚骰子 | $\{(i,j) : i,j \in \{1,\ldots,6\}\}$，共 36 个点 |
| 记录电话呼叫到达时刻 | $[0, +\infty)$ |

**事件**是 $\Omega$ 的子集，通常用大写字母 $A, B, C$ 表示。例如"掷骰子出现偶数"对应 $A = \{2, 4, 6\}$。

- **必然事件**：$\Omega$ 本身——试验必然发生的结果。
- **不可能事件**：$\emptyset$——不可能发生的结果。
- **基本事件**：单元素集合 $\{\omega\}$。

### 2.2 事件运算

设 $A, B$ 是 $\Omega$ 上的两个事件：

| 运算 | 符号 | 集合含义 | 概率语言 |
|---|---|---|---|
| 并（和） | $A \cup B$ | $A$ 或 $B$ 中至少有一个发生 | $A$ 或 $B$ 发生 |
| 交（积） | $A \cap B$（简写 $AB$） | $A$ 和 $B$ 同时发生 | $A$ 且 $B$ 发生 |
| 补（余） | $\overline{A}$（或 $A^c$） | $A$ 不发生 | $A$ 的对立事件 |
| 差 | $A \setminus B$（或 $A - B$） | $A$ 发生但 $B$ 不发生 | $A$ 但非 $B$ |

**互斥（互不相容）**：若 $A \cap B = \emptyset$，称 $A$ 与 $B$ 互斥——两者不能同时发生。

**德摩根律**（集合 / 事件的对偶关系）：
$$\overline{A \cup B} = \overline{A} \cap \overline{B}, \qquad \overline{A \cap B} = \overline{A} \cup \overline{B}.$$

推广到有限个事件：
$$\overline{\bigcup_{i=1}^n A_i} = \bigcap_{i=1}^n \overline{A_i}, \qquad \overline{\bigcap_{i=1}^n A_i} = \bigcup_{i=1}^n \overline{A_i}.$$

**口诀**："非（A 或 B）= 非 A 且非 B；非（A 且 B）= 非 A 或非 B"——把"$\cup$"换成"$\cap$"，同时把"$-$"移进去。

## 三、$\sigma$-代数：概率的"域"

### 3.1 为什么需要 $\sigma$-代数

对于**有限**样本空间（如骰子），$\Omega$ 的所有子集都可以赋予概率，问题不大。但对于**连续**样本空间（如 $\Omega = \mathbb{R}$），并非所有子集都能被"测量"——Vitali 集等非可测集告诉我们，试图对所有子集定义概率会导致矛盾。

解决办法是：只对"足够好"的子集定义概率。这些"足够好"的子集组成一个集合族，叫做 **$\sigma$-代数**（也称 $\sigma$-域）。

### 3.2 $\sigma$-代数的定义

**定义**：设 $\Omega$ 是样本空间，$\mathcal{F}$ 是 $\Omega$ 的某些子集组成的集合族。若 $\mathcal{F}$ 满足以下三条，称 $\mathcal{F}$ 是 $\Omega$ 上的一个 $\sigma$-代数：

1. $\Omega \in \mathcal{F}$（包含全集）；
2. 若 $A \in \mathcal{F}$，则 $\overline{A} \in \mathcal{F}$（对补运算封闭）；
3. 若 $A_1, A_2, A_3, \ldots \in \mathcal{F}$，则 $\bigcup_{i=1}^\infty A_i \in \mathcal{F}$（对**可数**并封闭）。

由 1 和 2 可推出 $\emptyset \in \mathcal{F}$；由德摩根律和 2、3 可推出对可数交也封闭。

**最小例子**：$\mathcal{F} = \{\emptyset, \Omega\}$（平凡 $\sigma$-代数）。

**最大例子**：$\mathcal{F} = 2^\Omega$（$\Omega$ 的全部子集，适用于有限 $\Omega$）。

**实用最重要的例子**：$\mathcal{B}(\mathbb{R})$，即 $\mathbb{R}$ 上所有开区间生成的 $\sigma$-代数，称为 **Borel $\sigma$-代数**。实数直线上几乎所有"实际遇到"的集合（开集、闭集、区间、可数集等）都在 $\mathcal{B}(\mathbb{R})$ 中。

### 3.3 概率空间

三元组 $(\Omega, \mathcal{F}, P)$ 称为**概率空间**，其中：
- $\Omega$：样本空间；
- $\mathcal{F}$：$\sigma$-代数（可测事件族）；
- $P$：定义在 $\mathcal{F}$ 上满足 Kolmogorov 公理的概率测度。

**入门阶段**：只需知道 $\sigma$-代数是"允许赋予概率的事件的集合"，不必深入测度论。

## 四、Kolmogorov 三公理

### 4.1 公理表述

设 $(\Omega, \mathcal{F}, P)$ 是概率空间。**概率**是满足以下三条公理的实值函数 $P: \mathcal{F} \to \mathbb{R}$：

**公理 1（非负性）**：
$$\forall A \in \mathcal{F}: \quad P(A) \geq 0.$$

**公理 2（归一性）**：
$$P(\Omega) = 1.$$

**公理 3（可列可加性）**：若 $A_1, A_2, \ldots \in \mathcal{F}$ 两两互斥（$A_i \cap A_j = \emptyset$，$i \neq j$），则
$$P\!\left(\bigcup_{i=1}^\infty A_i\right) = \sum_{i=1}^\infty P(A_i).$$

### 4.2 由三公理推导的基本性质

以下性质全部由三条公理逻辑推出（不是新的假设）：

| 性质 | 公式 | 推导思路 |
|---|---|---|
| 不可能事件 | $P(\emptyset) = 0$ | 令所有 $A_i = \emptyset$，由公理 3 + 公理 2 |
| 有限可加性 | $P(A \cup B) = P(A) + P(B)$（$A, B$ 互斥） | 公理 3 的特例 |
| 互补律 | $P(\overline{A}) = 1 - P(A)$ | $\Omega = A \cup \overline{A}$，两者互斥，由公理 2、3 |
| 单调性 | $A \subseteq B \Rightarrow P(A) \leq P(B)$ | $B = A \cup (B \setminus A)$，有限可加性 |
| 概率上界 | $P(A) \leq 1$ | 由单调性 $A \subseteq \Omega$ |
| 加法公式 | $P(A \cup B) = P(A) + P(B) - P(AB)$ | $A \cup B = A \cup (B \setminus A)$，拆项 |

**容斥原理**（三个事件）：
$$P(A \cup B \cup C) = P(A) + P(B) + P(C) - P(AB) - P(AC) - P(BC) + P(ABC).$$

## 五、四种概型对比

| 概型 | 核心思想 | 适用条件 | 概率计算方式 |
|---|---|---|---|
| **古典概型** | 等可能性 | 样本空间有限且每个基本事件等可能 | $P(A) = \dfrac{|A|}{|\Omega|}$（事件 $A$ 的基本事件数 / 总数） |
| **几何概型** | 等可能性推广到连续 | 样本空间是某个几何区域，"随机"落点均匀分布 | $P(A) = \dfrac{\mu(A)}{\mu(\Omega)}$（$\mu$ 是面积/长度/体积等测度） |
| **频率概型** | 大数定律 | 可大量重复的试验 | 用频率 $f_n(A) = n_A / n$ 近似 $P(A)$（$n \to \infty$） |
| **主观概率** | 个人信度 | 不可重复的单次事件（选举、历史事件等） | 由专家或贝叶斯框架给出的主观信念 |

**关键辨析**：

- 古典概型要求"有限 + 等可能"，两个条件缺一不可。若样本点不等可能，不能用 $P(A) = |A|/|\Omega|$。
- 几何概型适用于"随机"点在某区域内均匀分布——"均匀"就是等可能的连续推广。
- 频率概型是客观的，依赖可重复实验；主观概率不依赖重复，但要满足 Kolmogorov 公理（一致性）。

## 六、演示题：古典概型与几何概型双解等公交问题

### 题目

某公交车每隔 $T = 10$ 分钟一班，乘客在站台随机到达（均匀分布）。问乘客等待时间不超过 3 分钟的概率。另外，若将问题改为：从 $\{1, 2, \ldots, 10\}$ 中随机取一个整数，该整数 $\leq 3$ 的概率。

**（后者为古典概型版本，前者为几何概型版本。）**

> 拿到这道题，我先判断属于哪种概型。
>
> **几何概型版本**：乘客到达时刻均匀分布在 $[0, 10)$ 分钟区间内。等待时间 = 下一班车到达时间 - 乘客到达时间。设乘客到达时刻为 $X \in [0, 10)$，下一班车在 $10$ 分钟时到（不妨视为周期开始），等待时间为 $10 - X$（若 $X \in [0, 10)$）。
>
> 等待时间 $\leq 3$ 分钟，即 $10 - X \leq 3$，即 $X \geq 7$。
>
> 样本空间：$\Omega = [0, 10)$，长度 $\mu(\Omega) = 10$。
> 满足条件的集合：$A = [7, 10)$，长度 $\mu(A) = 3$。
>
> $$P(\text{等待} \leq 3\text{分钟}) = \frac{\mu(A)}{\mu(\Omega)} = \frac{3}{10} = 0.3.$$
>
> **古典概型版本**：从 $\{1, 2, \ldots, 10\}$ 中等可能取一整数，问取到 $\leq 3$ 的概率。
>
> $\Omega = \{1, 2, \ldots, 10\}$，$|\Omega| = 10$；$A = \{1, 2, 3\}$，$|A| = 3$。
>
> $$P(A) = \frac{|A|}{|\Omega|} = \frac{3}{10} = 0.3.$$
>
> 两种模型给出同样答案，但路径不同：古典概型数点，几何概型量长度。若公交间隔变成连续实数 $t \in [0, 10]$ 而非整数，只有几何概型还能用。
>
> **回顾**：先判断样本空间是有限等可能（古典）还是连续均匀分布（几何），选对工具事半功倍。

## 七、蒲丰投针问题（几何概型经典）

### 题目

平面上画有间距为 $d$ 的平行线，将一根长度为 $l$（$l \leq d$）的针随机抛下，求针与某条平行线相交的概率。

### 分析

> 这是几何概型的典范。针的"随机"由两个独立的量决定：
>
> - 针的中点到最近一条平行线的距离 $x \in [0, d/2]$（利用对称性取半区间）；
> - 针与平行线所成的锐角 $\theta \in [0, \pi/2]$。
>
> 样本空间是矩形区域 $\Omega = \{(x, \theta): 0 \leq x \leq d/2,\; 0 \leq \theta \leq \pi/2\}$，面积 $\mu(\Omega) = \frac{d}{2} \cdot \frac{\pi}{2} = \frac{\pi d}{4}$。
>
> 针与最近平行线相交，当且仅当中点到该线的距离 $x \leq$ 针端点到最近线的投影长度，即：
> $$x \leq \frac{l}{2}\sin\theta.$$
>
> 满足条件的区域面积：
> $$\mu(A) = \int_0^{\pi/2} \frac{l}{2}\sin\theta\,d\theta = \frac{l}{2} \cdot [-\cos\theta]_0^{\pi/2} = \frac{l}{2}(0 - (-1)) = \frac{l}{2}.$$
>
> 因此：
> $$P(\text{相交}) = \frac{\mu(A)}{\mu(\Omega)} = \frac{l/2}{\pi d/4} = \frac{2l}{\pi d}.$$
>
> 这个结果的妙处在于含有 $\pi$，历史上被用来估算 $\pi$ 的值：大量投针，统计相交频率，由 $P \approx 2l/(\pi d)$ 反解 $\pi \approx 2l/(Pd)$。

**历史意义**：蒲丰投针（Buffon, 1777）是历史上最早用几何概率估计超越数的实验，也是 Monte Carlo 方法的先驱。

## 八、思考路标

1. **判断概型的第一步** → 问"样本空间是有限的还是连续的？" 有限且等可能 → 古典概型（数点）；连续且均匀分布 → 几何概型（量测度）；可重复大量试验 → 频率概型；不可重复 → 主观概率或贝叶斯框架。

2. **见"至少一个"或"至多一个"** → 用对立事件：$P(\text{至少一个}) = 1 - P(\text{一个都没有})$，往往更简单。德摩根律是计算对立事件的核心工具。

3. **见多事件的并 $P(A \cup B \cup C)$** → 用容斥原理展开。项的个数 = $\binom{n}{1} - \binom{n}{2} + \binom{n}{3} - \cdots$，记忆规律：奇数个事件的交前加，偶数个前减。

4. **几何概型中"随机"的精确含义** → 必须明确指定什么是"均匀"（即 $\mu$ 是什么）。不同的均匀性假设会给出不同概率（贝特朗悖论的教训）。面积均匀 $\neq$ 角度均匀 $\neq$ 半径均匀。

5. **$\sigma$-代数的直觉** → 它是"可以被观测到的事件的集合"。比粗糙的事件族（太少）到精细的全集（太多），$\sigma$-代数给出恰当的"可测性"边界。在有限样本空间里不用操心，在连续情形必须小心。

6. **由公理验证某函数是概率** → 检查三条：$P(A) \geq 0$，$P(\Omega) = 1$，互斥可列可加性。逐一验证，不能跳步。若某条不满足，该函数不是概率测度。

7. **加法公式应用时防止重复计数** → $P(A \cup B) = P(A) + P(B) - P(AB)$，中间的 $P(AB)$ 是防止重复计数的修正项。三个以上事件用容斥，系数交替正负。

8. **频率 $\neq$ 概率** → 频率是观测值，概率是理论值。频率会随样本量收敛到概率（大数定律），但有限次观测的频率会有随机波动。"频率等于概率"是理想极限，不是等式。

## 九、典型应用 3 例

### 例 1：古典概型——生日问题

**题目**：$n$ 个人中至少有两人生日相同的概率（假设每人生日等可能是 365 天中的任意一天）。

**思路**：

用对立事件："至少有两人生日相同"的对立是"所有人生日各不相同"。

样本空间：每人生日独立均匀选自 365 天，总样本点数 $|\Omega| = 365^n$。

所有人生日各不相同的方案数：$365 \times 364 \times 363 \times \cdots \times (365 - n + 1) = \dfrac{365!}{(365-n)!}$。

$$P(\text{至少两人同生日}) = 1 - \frac{365 \times 364 \times \cdots \times (365-n+1)}{365^n}.$$

当 $n = 23$ 时，$P \approx 0.507 > 1/2$——生日悖论：仅 23 人，有一半概率有两人同生日，远超直觉。

**关键技巧**：对立事件 + 乘法原理计算有序排列。

---

### 例 2：几何概型——约会问题（会面问题）

**题目**：甲乙两人约好在 $[0, 1]$ 小时内各自随机到达，先到者最多等 $1/4$ 小时。求两人能相遇的概率。

**思路**：

设甲到达时刻 $X$，乙到达时刻 $Y$，均匀分布在 $[0,1]$。样本空间 $\Omega = [0,1]^2$，面积 1。

相遇条件：$|X - Y| \leq 1/4$，即 $-1/4 \leq X - Y \leq 1/4$。

满足条件的区域面积 = 总面积 - 两个直角三角形（不满足条件的部分）：

$$\mu(A) = 1 - 2 \times \frac{1}{2}\left(\frac{3}{4}\right)^2 = 1 - \frac{9}{16} = \frac{7}{16}.$$

$$P(\text{相遇}) = \frac{7}{16} = 0.4375.$$

**识别链**：连续均匀 → 几何概型 → 二维平面区域面积比。

---

### 例 3：事件运算——容斥原理

**题目**：一批 100 件产品中，有缺陷 A 的 20 件，有缺陷 B 的 15 件，同时有 A 和 B 两种缺陷的 5 件。随机取 1 件，求至少有一种缺陷的概率。

**思路**：

$P(A) = 20/100 = 0.2$，$P(B) = 15/100 = 0.15$，$P(AB) = 5/100 = 0.05$。

由加法公式：
$$P(A \cup B) = P(A) + P(B) - P(AB) = 0.2 + 0.15 - 0.05 = 0.3.$$

若直接相加 $0.2 + 0.15 = 0.35$ 会重复计数同时有两种缺陷的 5 件，需减去一次。

**结论**：有缺陷的概率为 $0.3$，即 30 件有缺陷。

## 十、自测题

**第 1 题**：掷两枚骰子，求"点数之和为 7"的概率。

提示：样本空间 $\Omega$ 共 36 个等可能结果；点数之和为 7 的有 $(1,6),(2,5),(3,4),(4,3),(5,2),(6,1)$ 共 6 个。$P = 6/36 = 1/6$。

---

**第 2 题**：用德摩根律化简 $P(\overline{A} \cup \overline{B})$，并用 $P(A)$、$P(B)$、$P(AB)$ 表示。

提示：$\overline{A} \cup \overline{B} = \overline{A \cap B}$（德摩根律），所以 $P(\overline{A} \cup \overline{B}) = 1 - P(AB)$。

---

**第 3 题**：在正方形 $[0,1]^2$ 内随机取一点，求该点到原点的距离小于 $1/2$ 的概率。

提示：满足条件的区域是以原点为圆心、半径 $1/2$ 的圆与正方形的交集（即 $1/4$ 个圆），面积 $= \pi/4 \times (1/2)^2 = \pi/16$；样本空间面积 $= 1$；$P = \pi/16 \approx 0.196$。

---

**第 4 题**：验证 $P(A \setminus B) = P(A) - P(AB)$，并用它证明 $P(AB) \leq P(A)$。

提示：$A = (A \setminus B) \cup (A \cap B)$，两者互斥，由有限可加性 $P(A) = P(A \setminus B) + P(AB)$，故 $P(A \setminus B) = P(A) - P(AB)$。由非负性 $P(A \setminus B) \geq 0$，得 $P(A) \geq P(AB)$。

---

**第 5 题**：$n$ 件产品中有 $m$ 件次品，不放回抽 $k$ 件（$k \leq m$），求全部是次品的概率（古典概型）。

提示：从 $n$ 件中取 $k$ 件共 $\binom{n}{k}$ 种，全取次品的方法数 $\binom{m}{k}$，$P = \dbinom{m}{k}/\dbinom{n}{k}$。
