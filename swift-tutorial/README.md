# 从零到高阶的 Swift 教程

## 教程定位

这不是一份把 Swift 语法点按目录摊开的速记稿，也不是只服务于某个 Apple API 的碎片化上手笔记。这套教程把 Swift 当成一门有鲜明语义、有工程边界、有应用落点的现代语言来讲：先建立语言与工程本体，再进入 SwiftUI 与 Apple 平台专项，最后回到系统设计、性能、可靠性与综合重构。

教程围绕一个持续演进的任务管理领域展开。你不会在每一章都换一个临时 demo，而是会沿着同一条项目主线，把早期语言能力逐步沉淀成 CLI、核心模块和 SwiftUI 应用。这样“从零到高阶”指的不是题量变多，而是判断力变强：你能解释一个 Swift 设计为什么稳、为什么脆、为什么适合当前阶段。

## 读者画像

这套教程的默认读者不是完全不会编程的人，而是已经掌握过别的语言、但还没有系统学过 Swift 的程序员。你可能写过 Python、TypeScript、Go、Java、C++ 或 Kotlin，知道函数、类型、模块、测试、并发这些词，但一进入 Swift 就会被值语义、Optional、Protocol、Package、Actor、SwiftUI 状态流这些概念打断原有直觉。

如果你已经用过一点 Swift，但总觉得自己是“会写几段、不会整体判断”，这套教程同样适合你。它的目标不是让你尽快记住更多关键字，而是让你能把 Swift 的语言特性、工程组织、Apple 开发入口和高阶设计选择接成一条连续主线。

## 八部分主线地图

### 第一部分：语言基础与第一条 Swift 线（part1-language-foundations）

第一部分从工具链、`swift`/`swiftc`、值与可变性开始，尽快建立 Swift 的第一套稳定心智模型。这里不会停留在“打印 Hello World”，而是一路推进到字符串、集合、控制流、函数、Optional、枚举、结构体，并把这些能力收束到第一个可运行的小项目 `TaskCLI Lite v1`。目标不是功能多，而是让语法第一次真正落地。

### 第二部分：类型系统与建模判断（part2-type-system-and-modeling）

第二部分解决“会写 Swift”和“会设计 Swift”之间的断层。你会系统处理方法、属性、初始化器、类与结构体、值语义与引用语义、协议与协议扩展、泛型、关联类型、错误建模等主题，并持续回到任务管理领域判断 API 是否稳健。Part 2 的产出不是新项目名，而是更像工程代码的 CLI 模型层。

### 第三部分：包管理、测试与 CLI 工程化（part3-packages-testing-and-cli-engineering）

第三部分把此前的代码提升成真正的 Swift 工程：用 Swift Package Manager 组织模块边界，用 XCTest 锁定核心行为，用解析、渲染、存储接缝改善可测试性和可维护性，并把命令行入口组织得更清晰。到这里，项目会正式升级为 `TaskCore + TaskCLI`，Swift 不再只是语言练习，而是一个可被维护的代码库。

### 第四部分：并发、性能与可靠性（part4-concurrency-performance-and-reliability）

第四部分进入现代 Swift 工程最容易被轻描淡写、但真实项目最绕不过去的内容：`async`/`await`、`Task`、Actor、隔离与 Sendability、ARC、复制成本、性能测量心智、取消与失败面设计。这里的重点不是堆“高级知识点”，而是让你能看懂一段并发 Swift 代码哪里安全、哪里脆弱、哪里会在规模上出问题。产出仍然落在更强的 `TaskCore + TaskCLI` 运行时行为上。

### 第五部分：SwiftUI 基础（part5-swiftui-foundations）

第五部分才开始 SwiftUI，这个顺序是刻意的。你会先把 SwiftUI 当成建立在前面语言与工程能力之上的 UI 框架来理解，而不是把它误当成“会拖界面就算学会 Swift”。这一部分会讲 SwiftUI 心智模型、视图组合、状态、绑定、可观察模型、列表、表单和基础导航，并把项目线切换到 `TaskFlow v1`。

### 第六部分：SwiftUI 数据流与应用架构（part6-swiftui-dataflow-and-app-architecture）

第六部分继续把 `TaskFlow` 从“能跑”推进到“像样”。重点包括应用状态与数据流、持久化、模型集成、异步 UI 更新、预览、基础测试和应用结构判断。你会看到 SwiftUI 不是独立王国，而是 `TaskCore` 的一个客户端；好的应用结构来自边界清楚的共享核心，而不是把业务逻辑散进 View。

### 第七部分：高级 Swift 与系统设计（part7-advanced-swift-and-system-design）

第七部分用于收束更高阶的语言与系统设计判断：更复杂的泛型与协议设计、结果构建器与宏应放在什么位置、何时做系统 API 互操作、包边界怎样影响复用与演进、共享抽象何时值得提炼。这里不会为了“显得高级”而堆冷门技巧，而是把高级 Swift 放回真实系统设计背景下讨论。

### 第八部分：毕业项目与下一步路线（part8-capstone-and-next-steps）

第八部分不是简单总结，而是毕业层。你会基于前面所有内容做综合重构、架构复盘、可靠性与性能回顾、CLI/Core/UI 统一判断，并配合 part-level labs 做最终收束。课程最后给出的不是“你已经无敌了”的口号，而是一张清楚的下一步路线图，说明你已经具备哪些核心能力、还应往哪些方向继续深入。

## 持续项目主线

整套教程围绕同一个任务管理领域展开，项目主线始终连续，不会在中途突然换题。它分成四个阶段：

1. `TaskCLI Lite`：Part 1 的最小 CLI，把 Swift 基础语法真正落在输入、输出和状态变化上。
2. `TaskCore + TaskCLI`：Part 2 到 Part 4 的工程主线，把模型、边界、测试、并发、可靠性逐步沉淀为更成熟的包结构。
3. `TaskFlow`：Part 5 到 Part 6 的 SwiftUI 客户端，让 UI 站在共享核心之上，而不是复制一份新的业务世界。
4. Capstone：Part 7 到 Part 8 把 CLI、核心模块和 SwiftUI 应用重新统一起来，做系统层面的设计复盘。

这种设计有一个明确目的：让你在每个阶段都知道“我学的这件事正在改善项目的哪一段”，而不是把章节学成彼此孤立的知识卡片。

## 如何使用本教程

最推荐的读法是线性推进。默认顺序是 `00-preface.md` -> Part 1 -> Part 8，并在每完成一个 part 后进入对应的 `labs/` 综合实验。这样你能同时保留概念连续性和项目连续性。

如果你已经会一点 Swift，可以采用半线性路径：先快速扫过 README 的 8 部分地图，确认自己缺的是哪一层，再回到那一部分完整阅读。但不建议直接跳进 SwiftUI 或高级特性而跳过前四部分，因为本教程的 Apple 专项和高阶设计都建立在前面的 Swift 工程本体之上。

学习时建议同时维护三个观察面：当前章节在讲什么语义问题、当前项目哪一段在变强、当前部分的综合实验会验证哪些能力。读章节时先看为什么现在讲这个，再看它如何改变项目；做 labs 时则把分散的局部能力重新拼成一条完整工程路径。

## 教程特色

- 教程优先，不是词条堆积：每章都围绕“为什么现在需要这个能力、它如何让项目变强”来展开。
- 工程主线连续：`TaskCLI Lite -> TaskCore + TaskCLI -> TaskFlow -> Capstone` 贯穿全书。
- 强双语但不装饰化：中文负责解释与判断，英文保留 API、类型名、协议名、命令名和关键术语。
- 语言与工程先行：先把 Swift 学扎实，再进入 SwiftUI 与 Apple 平台专项，避免学成框架驱动的局部经验。
- part-level labs 与 appendix 配套：章节不是唯一训练面，综合实验、术语表、速查与答疑一起构成完整教程产品。
