# Labs：分部综合实验

## labs 的作用

`labs/` 是 part-level 的综合实验区。章节负责把一个能力讲清楚，labs 负责把这一部分分散的知识重新拼回一个真实工程问题里。你可以把它理解为“这一部学完之后，是否真的能把能力用起来”的检验面。

## 和章节内练习的区别

章节里的局部练习验证的是“这一章有没有看懂”；labs 验证的是“你能不能把这一部分里的多个能力一起用在同一个产品里”。所以 labs 更像真实工作：修状态 bug、扩功能、补测试、拆组件、调整数据流，而不是只填几个 API 空格。

## 每一部做什么类型的实验

- Part 1：基础状态与页面流
- Part 2：功能扩展、搜索和组件组织
- Part 3：模型、存储与共享核心边界
- Part 4：测试、包结构与 `focusctl`
- Part 5：并发、失败面与跨平台体验
- Part 6：发布前整理、回归检查与产品复盘
