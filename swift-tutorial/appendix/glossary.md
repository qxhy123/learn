# 术语表

## 状态与数据

| 术语 | 含义 |
| --- | --- |
| 局部状态 | 只属于当前页面或当前交互流的状态，例如输入框草稿、弹窗开关 |
| 共享状态 | 多个页面或多个表面都会依赖的产品状态 |
| 持久化状态 | 需要跨会话保存并恢复的数据 |
| 派生结果 | 从已有状态计算出来的结果，不需要额外存一份 |
| 草稿 | 用户正在编辑、但还没提交为正式产品数据的中间状态 |

## 产品与工程

| 术语 | 含义 |
| --- | --- |
| `FocusCore` | `FocusList` 的共享模型、规则和查询边界所在模块 |
| `focusctl` | 复用共享核心的命令行表面，用来验证边界是否真的清楚 |
| checkpoint | 某一阶段应达到的结构与能力说明 |
| verification | 用测试和脚本确认教程结构、starter 和 CLI 都成立 |
| 失败路径 | 某个动作未成功完成时，系统如何保留状态、提示用户、允许恢复 |

## SwiftUI 与测试

| 术语 | 含义 |
| --- | --- |
| rerender | 状态变化后界面重新求值与更新的过程 |
| `@State` | 视图拥有的局部状态 |
| `@Bindable` | 让可观察模型能在 `View` 中自然建立绑定 |
| `Swift Testing` | 现代 Swift 测试框架，本教程用它锁定核心行为 |
| Preview | 快速检查不同 UI 状态的可视化入口 |
