# Part 2 Checkpoint：产品化界面

## 这一阶段的目标状态

Part 2 结束时，`FocusList` 应该已经摆脱“单一列表 demo”的气质，开始拥有清楚的信息结构和更像产品的工作流。

## 你应该已经补上的能力

- 任务、项目、标签这些概念开始分开
- 编辑流拥有草稿、保存和取消语义
- 搜索与筛选有清楚的状态所有权
- 侧栏和详情区开始共同表达产品地图

## 代码层面的观察点

你应该能指出：

- 哪个组件开始值得抽成 `TaskRow`
- 哪些状态仍然留在页面层
- 哪些信息开始需要出现在任务行或侧栏里

## 手动检查路径

1. 新建任务并看到它的结构信息
2. 使用筛选或搜索找到这条任务
3. 进入编辑流并保存
4. 切换不同入口，确认产品上下文仍然清楚

## 如果还没准备好进入 Part 3，会表现成什么

- 搜索和筛选全混在共享状态里
- 编辑流没有草稿层
- 任务、项目、标签仍然说不清区别
