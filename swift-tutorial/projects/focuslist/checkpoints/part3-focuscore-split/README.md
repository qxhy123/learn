# Part 3 Checkpoint：抽出 FocusCore

## 这一阶段的目标状态

到了这里，共享核心不再只是名字，而应该已经承接了真正稳定的领域语义。Part 3 的目标不是“模块更多”，而是模型、存储和失败路径开始各归其位。

## 你应该已经看到的结构变化

- 任务、项目、计划等概念更稳定
- 持久化状态与页面交互状态开始分开
- 查询和失败翻译不再散落在页面里
- `FocusCore` 开始承接可复用规则

## 重点检查点

至少能回答：

- 哪些规则已经可以被 App 和 CLI 同时复用
- 哪些状态仍然必须留在 UI 层
- 哪类失败属于存储边界，而不是页面局部问题

## 手动检查路径

1. 创建或编辑一条任务
2. 模拟一次保存失败
3. 确认用户仍然能保留草稿并继续操作
4. 检查 CLI 是否已经能复用部分核心逻辑

## 进入 Part 4 前你应该清楚什么

如果现在共享核心还在依赖 UI，或者查询和失败仍然四散在页面里，那说明 Part 3 还没真正完成。
