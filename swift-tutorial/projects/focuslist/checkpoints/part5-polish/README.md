# Part 5 Checkpoint：并发与跨平台打磨

## 这一阶段的目标状态

Part 5 结束时，`FocusList` 应该已经不只是结构正确，还要在真实使用中显得可靠、顺手、可恢复，并且在 `iOS` 和 `macOS` 上都像自己平台上的自然产品。

## 你应该已经补齐的能力

- 刷新和搜索拥有清楚异步状态
- 取消、失败和空状态被明确区分
- 批量操作不会轻易放大刷新成本
- 跨平台共享边界与表达层差异已经清楚

## 手动检查路径

1. 连续输入搜索词，确认旧任务不会覆盖新结果
2. 模拟一次失败，确认用户能恢复
3. 做一次批量操作，观察是否有明显结构性卡顿
4. 在 `iOS` 与 `macOS` 上各走一遍核心路径

## 进入 Capstone 前应该准备好什么

你应该已经能回答：

- 异步任务归谁所有
- 哪些反馈应该静默，哪些应该提示
- 哪些平台差异属于 UI 表达层，不该拆散共享核心
