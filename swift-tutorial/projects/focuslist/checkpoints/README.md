# FocusList Checkpoints：阶段检查点

## checkpoints 的作用

这些文档不是“中间版本代码下载区”，而是每个阶段的结构对照表。它们帮助你确认三件事：

1. 当前阶段到底增加了哪些能力
2. 哪些边界已经变化，哪些还故意没动
3. 为什么下一阶段必须继续推进，而不是停在当前版本

## 如何使用 checkpoint

每完成一个 Part，就做这三步：

1. 对照正文回看本阶段目标
2. 打开对应 checkpoint，核对结构变化
3. 在 starter 里手动走一遍关键路径

如果你看 checkpoint 只是为了找“差不多长这样”的代码形状，价值会很低。真正应该对照的是能力和边界，而不是表面目录。
