# FocusList：项目线导览

## 这个目录解决什么问题

`swift-tutorial/` 的主线讲的是“为什么”，而 `projects/focuslist/` 负责给你一个持续可落地的工程切面。你在这里看到的不是成品快照堆积，而是一条围绕同一产品反复推进、校验和复盘的路径。

## 目录说明

- `starter/`：课程开始时手里的最小可运行基线
- `checkpoints/`：每个阶段应该达到的结构与能力说明
- `final/`：整条项目线结束后，你应该能交付和解释到什么程度

## 你应该如何使用这里的内容

### 先对照 starter 认代码

至少先熟悉这些路径：

- `Sources/FocusCore/`
- `Sources/FocusListApp/`
- `Sources/focusctl/`
- `Tests/FocusCoreTests/`

### 再用 checkpoint 做阶段复盘

checkpoint 的任务不是给你现成代码，而是帮你确认本阶段到底应该出现哪些能力、哪些边界变化，以及哪些复杂度现在故意还没引入。

### 最后用 final 做自测

当你走完整套教程后，`final/README.md` 应该像一份自查单：你是否真的已经具备了“从应用壳到工程闭环”的判断，而不只是读过所有标题。

## 一条重要提醒

这套项目线故意不把每个阶段都做成一份冻结代码快照，因为重点不是复制版本库历史，而是训练你自己推进、验证和解释每一步变化。
