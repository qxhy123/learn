# FocusList：项目总览

## 目标

`FocusList` 是整套教程唯一持续演进的产品主线。它从一个最小可运行的任务应用出发，逐步长出项目、标签、筛选、搜索、持久化、共享核心、测试和跨平台打磨。

## 目录结构

- `starter/`：起始工程，包含 `FocusListApp`、`FocusCore` 和最小 `focusctl`
- `checkpoints/`：每个阶段的结构和能力说明
- `final/`：教程结束时的产品总结

## 关键关系

前半段先让 `FocusList` 自己长起来；中段再抽出 `FocusCore`；后段通过 `focusctl` 和验证脚本把工程边界讲清楚。读者看到的是一个产品如何被做对，而不是多个互不相干的练习项目。
