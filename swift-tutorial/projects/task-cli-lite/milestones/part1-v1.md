# TaskCLI Lite v1 Milestone

## Part 1 到这里算完成了什么

`TaskCLI Lite v1` 是 Swift 教程第一部分的阶段性终点。它已经把 Part 1 最核心的语言能力压到一个真实可运行的 CLI 上：命令输入、字符串拼接、数组操作、条件分支、函数组织、结构体建模，以及用 XCTest 锁定最小行为。

这份 milestone 需要强调两点。第一，它不是“已经足够成熟”的意思，而是“对 Part 1 来说已经足够正确”。第二，它刻意保留了一些明显还会继续进化的地方，例如单目标结构、内存态数据、非常轻量的命令解析，因为这些正是 Part 2 之后继续推进的教学入口。

## 当前能力边界

Part 1 结束时，`TaskCLI Lite v1` 具备下面这些能力：

- 用 Swift Package Manager 构建一个可运行的 executable target `TaskCLILite`
- 支持最小命令：`list`、`add <title>`、`done <title>`
- 通过 `struct` 表达任务数据，通过函数组织渲染和命令分支
- 通过 XCTest 验证列表、添加、完成三个核心行为
- 保持代码足够直接，便于读者把语法点和程序行为一一对应

## 刻意没有解决的问题

`TaskCLI Lite v1` 还没有：

- 做磁盘持久化
- 把领域模型抽到独立模块
- 引入复杂命令解析库
- 设计更完整的错误类型体系
- 处理更丰富的任务身份标识

这些都不是遗忘项，而是教程节奏的结果。Part 1 的任务是让读者先形成 Swift 基础心智；如果这一阶段就把问题做得过满，读者会把注意力从语言判断移到工程噪音上。

## 为什么这个状态是对的

对很多已经会别的语言的程序员来说，真正稀缺的不是“再多一个待办清单 demo”，而是第一次用 Swift 写出一个虽小但完整的程序，并能解释自己为什么这么写。`TaskCLI Lite v1` 之所以成立，不是因为它功能多，而是因为它把 Swift 基础语义和一个最小项目落点绑在了一起。

这就是 Part 1 milestone 的意义：你不只是学过了 `struct` 或 `if`，而是已经把这些东西拼成了一个可以 build、可以 test、可以 run 的小系统。
