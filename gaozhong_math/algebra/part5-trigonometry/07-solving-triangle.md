# 解三角形：正弦定理与余弦定理

> **一例速记**：  
> **正弦定理**：$\dfrac{a}{\sin A} = \dfrac{b}{\sin B} = \dfrac{c}{\sin C} = 2R$（$R$ 为外接圆半径）  
> **余弦定理**：$c^2 = a^2 + b^2 - 2ab\cos C$（及其轮换形式）  
> **面积公式**：$S = \dfrac{1}{2}ab\sin C = \dfrac{1}{2}bc\sin A = \dfrac{1}{2}ca\sin B$  
> **选用原则**：知道两角一边（AAS/ASA）→ 正弦定理；知道两边一夹角（SAS）或三边（SSS）→ 余弦定理。

---

## 一、正弦定理

### 1.1 定理内容

在三角形 $ABC$ 中，角 $A, B, C$ 所对的边分别为 $a, b, c$，$R$ 为外接圆半径，则：

$$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$$

**等价形式**（三角形中两种用法）：
- 已知角求边：$a = 2R\sin A$
- 已知边求角：$\sin A = \dfrac{a}{2R}$，或 $\dfrac{\sin A}{\sin B} = \dfrac{a}{b}$

### 1.2 正弦定理的几何意义

正弦定理说明：三角形的三边与其对角正弦值之比相等，且等于外接圆直径 $2R$。这意味着大边对大角，小边对小角（$a > b \Leftrightarrow A > B$）。

### 1.3 推论与三角形判别

在三角形中，$A + B + C = \pi$，结合正弦定理可以：
- 已知两角 $A, B$ 求第三角：$C = \pi - A - B$
- 已知两边之比和一角，求另一角：$\sin B = \dfrac{b\sin A}{a}$（但需注意 $B$ 可能有两个值，见 ASS 情形）

---

## 二、余弦定理

### 2.1 定理内容

$$a^2 = b^2 + c^2 - 2bc\cos A$$

$$b^2 = a^2 + c^2 - 2ac\cos B$$

$$c^2 = a^2 + b^2 - 2ab\cos C$$

**逆用**（由三边求角）：

$$\cos A = \frac{b^2 + c^2 - a^2}{2bc}, \quad \cos B = \frac{a^2 + c^2 - b^2}{2ac}, \quad \cos C = \frac{a^2 + b^2 - c^2}{2ab}$$

### 2.2 余弦定理的几何意义

余弦定理是勾股定理的推广：当 $C = 90°$ 时，$\cos C = 0$，定理退化为 $c^2 = a^2 + b^2$（勾股定理）。  
$\cos C > 0$（锐角）时，$c^2 < a^2 + b^2$；$\cos C < 0$（钝角）时，$c^2 > a^2 + b^2$。

### 2.3 余弦定理判断三角形类型

已知三边 $a, b, c$，用 $\cos C = \dfrac{a^2+b^2-c^2}{2ab}$ 判断最大角 $C$（$c$ 为最长边）：
- $a^2 + b^2 > c^2$ → $\cos C > 0$ → 锐角三角形
- $a^2 + b^2 = c^2$ → $\cos C = 0$ → 直角三角形
- $a^2 + b^2 < c^2$ → $\cos C < 0$ → 钝角三角形

---

## 三、面积公式

三角形面积的三种等价表达：

$$S_{\triangle} = \frac{1}{2}ab\sin C = \frac{1}{2}bc\sin A = \frac{1}{2}ca\sin B$$

**推导**：底为 $c$，高为 $a\sin B$（从 $A$ 向 $BC$ 作垂线），故 $S = \dfrac{1}{2} \cdot c \cdot a\sin B = \dfrac{1}{2}ac\sin B$。

**与正弦定理的关联**：$S = \dfrac{1}{2}ab\sin C$，而 $a = 2R\sin A$，$b = 2R\sin B$，代入得：

$$S = 2R^2\sin A\sin B\sin C$$

---

## 四、解三角形的 4 类情形

### 4.1 已知三边（SSS）

**条件**：已知 $a, b, c$（需验证三角不等式 $a+b>c$ 等）。  
**方法**：用余弦定理逆用，求各角。

**步骤**：
1. 由 $\cos A = \dfrac{b^2+c^2-a^2}{2bc}$ 求 $A$
2. 由 $\cos B = \dfrac{a^2+c^2-b^2}{2ac}$ 求 $B$（或用正弦定理：$\sin B = \dfrac{b\sin A}{a}$）
3. $C = \pi - A - B$

**解的个数**：唯一（三边确定三角形全等，解唯一）。

### 4.2 已知两边和夹角（SAS）

**条件**：已知 $b, c$ 和夹角 $A$（$A$ 在 $b, c$ 之间）。  
**方法**：先用余弦定理求第三边 $a$，再用正弦定理求 $B$ 或 $C$，最后用角度和求最后一角。

**步骤**：
1. $a^2 = b^2 + c^2 - 2bc\cos A$，求 $a$
2. $\sin B = \dfrac{b\sin A}{a}$（或直接用余弦定理求 $B$）
3. $C = \pi - A - B$

**解的个数**：唯一（SAS 确定全等）。

**注意**：步骤 2 中用正弦定理求 $B$ 时，因为 $A$ 已知，若 $A$ 是钝角则 $B$ 只能是锐角（三角形内角和 $\leq \pi$），无需讨论；若 $A$ 是锐角且 $b$ 是已知的较大边，理论上 $B$ 可能有两值，但由于 SAS 已确定唯一三角形，$B$ 唯一确定（选与 $b > c$ 时 $B > C$ 一致的值）。

### 4.3 已知两角和一边（AAS 或 ASA）

**条件**：已知 $A, B, a$（或 $A, B, c$ 等）。  
**方法**：由 $C = \pi - A - B$ 求第三角，再用正弦定理求其余两边。

**步骤**（以 AAS: 已知 $A, B, a$）：
1. $C = \pi - A - B$（需验证 $A+B < \pi$，否则无解）
2. $b = \dfrac{a\sin B}{\sin A}$，$c = \dfrac{a\sin C}{\sin A}$

**解的个数**：唯一。

### 4.4 已知两边和非夹角（SSA / 海伦公式情形）

**条件**：已知 $a, b$ 和角 $A$（$A$ 是 $a$ 的对角，而 $a, b$ 中 $b$ 非 $A$ 的对边）。  
**方法**：先用正弦定理求 $\sin B = \dfrac{b\sin A}{a}$，再根据 $\sin B$ 的值讨论解的个数。

**分情况讨论**（$A$ 为锐角时，$A$ 为钝角可类比）：

设 $A$ 为**锐角**，$h = b\sin A$（$b$ 在 $A$ 角上的高）：

| 条件 | 解的情形 |
|------|----------|
| $a < h = b\sin A$ | $\sin B = \dfrac{b\sin A}{a} > 1$，**无解** |
| $a = h = b\sin A$ | $\sin B = 1$，$B = 90°$，**一个解**（直角三角形） |
| $h < a < b$（即 $b\sin A < a < b$）| $\sin B < 1$，$B$ 有锐角和钝角两个值，**两个解** |
| $a \geq b$ | $B \leq A$（大边对大角），$B$ 只取锐角值，**一个解** |

设 $A$ 为**钝角**（或直角）：
- 若 $a \leq b$：无解（钝角对边必须是最长边）
- 若 $a > b$：一个解

**注意**：SSA 是"两解问题"的唯一来源，务必判断解的个数！

---

## 五、易错点

1. **SSA 忘记讨论两解情形**：用正弦定理解 $B$ 时，$\sin B = k$ 在 $(0°, 180°)$ 内通常有两个解（$B$ 和 $180° - B$），要验证每个解是否使三角形合法。
2. **SAS 错用正弦定理求第三边**：已知两边一夹角，只能先用余弦定理求第三边，不能绕过这步（因为正弦定理需要知道一组边角对应关系）。
3. **角度和约束**：任何一步求出的角 $A, B, C$ 都必须满足 $A, B, C \in (0°, 180°)$ 且 $A + B + C = 180°$（或 $\pi$）。
4. **面积公式选择**：$S = \dfrac{1}{2}ab\sin C$ 中，$C$ 必须是 $a$ 和 $b$ 的**夹角**。如果已知的是非夹角的信息，需先求夹角。

## 六、典型例题

### 例 1：SAS 情形

**题目**：三角形 $ABC$ 中，$a = 7$，$b = 8$，$C = 60°$，求边 $c$ 和面积 $S$。

**【解答】**

**第一步：余弦定理求 $c$。**

$$c^2 = a^2 + b^2 - 2ab\cos C = 49 + 64 - 2 \times 7 \times 8 \times \cos 60°$$

$$= 113 - 112 \times \frac{1}{2} = 113 - 56 = 57$$

$$c = \sqrt{57}$$

**第二步：面积公式。**

$$S = \frac{1}{2}ab\sin C = \frac{1}{2} \times 7 \times 8 \times \sin 60° = 28 \times \frac{\sqrt{3}}{2} = 14\sqrt{3}$$

$$\boxed{c = \sqrt{57},\quad S = 14\sqrt{3}}$$

---

### 例 2：AAS 情形（含实际应用）

**题目**：从 $A$ 点测得山顶 $C$ 的仰角为 $30°$，沿水平方向向山走 $100$ m 到达 $B$ 点，从 $B$ 测得山顶仰角为 $60°$，求山高 $CD$（$D$ 为山脚，$ABDC$ 共面）。

**【解答】**

设山高 $CD = h$，$BD = x$。

由仰角信息：$\tan 60° = \dfrac{h}{x}$，即 $x = \dfrac{h}{\sqrt{3}}$。

由 $A$ 点：$\tan 30° = \dfrac{h}{100 + x}$，即 $100 + x = h\sqrt{3}$。

联立：$100 + \dfrac{h}{\sqrt{3}} = h\sqrt{3}$，$100 = h\sqrt{3} - \dfrac{h}{\sqrt{3}} = h\left(\sqrt{3} - \dfrac{1}{\sqrt{3}}\right) = h \cdot \dfrac{2}{\sqrt{3}}$。

$$h = \frac{100\sqrt{3}}{2} = 50\sqrt{3}$$

$$\boxed{CD = 50\sqrt{3} \approx 86.6 \text{ m}}$$

---

### 例 3：SSA 两解情形

**题目**：三角形 $ABC$ 中，$a = 5$，$b = 7$，$A = 45°$，求解三角形（若有多解，求所有解）。

**【解答】**

**第一步：正弦定理求 $\sin B$。**

$$\sin B = \frac{b\sin A}{a} = \frac{7 \times \frac{\sqrt{2}}{2}}{5} = \frac{7\sqrt{2}}{10}$$

$\dfrac{7\sqrt{2}}{10} = \dfrac{7 \times 1.414\ldots}{10} \approx \dfrac{9.899}{10} \approx 0.990 < 1$，有解。

**第二步：判断 $B$ 的值。**

$\sin B \approx 0.990$，则 $B_1 \approx \arcsin(0.990) \approx 81.9°$（锐角解）或 $B_2 = 180° - 81.9° = 98.1°$（钝角解）。

- **解 1**（$B_1 \approx 81.9°$）：$C_1 = 180° - 45° - 81.9° = 53.1° > 0°$，合法。  
  $c_1 = \dfrac{a\sin C_1}{\sin A} = \dfrac{5\sin 53.1°}{\sin 45°} \approx \dfrac{5 \times 0.800}{0.707} \approx 5.66$

- **解 2**（$B_2 \approx 98.1°$）：$C_2 = 180° - 45° - 98.1° = 36.9° > 0°$，合法。  
  $c_2 = \dfrac{a\sin C_2}{\sin A} \approx \dfrac{5 \times 0.600}{0.707} \approx 4.24$

**两解均合法**，三角形有两个解。

> 若将题目改为 $a = 8, b = 7, A = 45°$（$a > b$），则只有一解（因为 $B$ 只能取锐角值）。

## 七、思路自测题

**自测 1**　已知三角形三边 $a = 3, b = 4, c = 5$，用余弦定理验证最大角，判断是否为直角三角形。

> 💡 提示：$c = 5$ 最大，$\cos C = \dfrac{a^2+b^2-c^2}{2ab} = \dfrac{9+16-25}{24} = 0$，$C = 90°$，是直角三角形。

**自测 2**　三角形 $ABC$ 中，$B = 30°$，$b = 2$，$c = 2\sqrt{3}$，求解三角形。

> 💡 提示：$\sin C = \dfrac{c\sin B}{b} = \dfrac{2\sqrt{3} \times \frac{1}{2}}{2} = \dfrac{\sqrt{3}}{2}$，$C = 60°$ 或 $C = 120°$。$C = 60°$：$A = 90°$，$a = \dfrac{b\sin A}{\sin B} = \dfrac{2 \times 1}{\frac{1}{2}} = 4$；$C = 120°$：$A = 30°$，$a = 2$。两解均合法。

**自测 3**　在三角形 $ABC$ 中，$a = \sqrt{6}$，$b = 2$，$A = 45°$，求 $B$。

> 💡 提示：$\sin B = \dfrac{b\sin A}{a} = \dfrac{2 \cdot \frac{\sqrt{2}}{2}}{\sqrt{6}} = \dfrac{\sqrt{2}}{\sqrt{6}} = \dfrac{1}{\sqrt{3}} = \dfrac{\sqrt{3}}{3}$。$B = \arcsin\dfrac{\sqrt{3}}{3} \approx 35.3°$（还需验证钝角值是否合法）。$B' = 180° - 35.3° = 144.7°$，$A + B' = 190° > 180°$，不合法。故唯一解 $B \approx 35.3°$。

**自测 4**　三角形 $ABC$ 中，$S = 6\sqrt{3}$，$a = 4$，$B = 60°$，$b$ 为 $A$ 的对边，求 $b$。

> 💡 提示：先用面积公式求 $c$：$S = \dfrac{1}{2}ac\sin B = \dfrac{1}{2} \times 4 \times c \times \dfrac{\sqrt{3}}{2} = \sqrt{3}c = 6\sqrt{3}$，得 $c = 6$。再用余弦定理：$b^2 = a^2 + c^2 - 2ac\cos B = 16 + 36 - 2\times 4 \times 6 \times \dfrac{1}{2} = 52 - 24 = 28$，$b = 2\sqrt{7}$。

**自测 5**　证明：在三角形 $ABC$ 中，$\dfrac{a - b}{c} = \dfrac{\sin A - \sin B}{\sin C}$。

> 💡 提示：由正弦定理 $a = 2R\sin A$，$b = 2R\sin B$，$c = 2R\sin C$，代入左边 $\dfrac{a-b}{c} = \dfrac{2R\sin A - 2R\sin B}{2R\sin C} = \dfrac{\sin A - \sin B}{\sin C}$，等于右边，等式成立。
