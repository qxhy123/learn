# 基本不等式 $\dfrac{a+b}{2} \geq \sqrt{ab}$

> **一例速记**：  
> $a, b > 0$ 时，$\dfrac{a+b}{2} \geq \sqrt{ab}$（即 $a + b \geq 2\sqrt{ab}$），**当且仅当 $a = b$ 时取等**。  
> 算术平均数 $\geq$ 几何平均数（AM-GM 不等式）。  
> **三原则：一正（变量为正）、二定（积或和为常数）、三相等（取等条件可达）**。缺一不可。

---

## 一、引入：一道最值题

> **题目**：已知 $x > 0$，求函数 $f(x) = x + \dfrac{1}{x}$ 的最小值。

请先停下来，独立尝试。你会怎么做？

用导数？求导令 $f'(x) = 0$ 可以找到极值，但高中不总是允许用导数，而且——有一种更快、更漂亮的方法，不需要任何求导。

让我们来还原真正掌握这道题的人的内心思路。

---

## 二、思维路径还原（解题者的内心独白）

> "$x > 0$，求 $f(x) = x + \dfrac{1}{x}$ 的最小值。
>
> 看到 '$x + \dfrac{1}{x}$' 这种形式——**两项之和，两项之积 $= x \cdot \dfrac{1}{x} = 1$，是常数**！
>
> 立刻触发基本不等式：$x + \dfrac{1}{x} \geq 2\sqrt{x \cdot \dfrac{1}{x}} = 2\sqrt{1} = 2$。
>
> **在用基本不等式之前，自查三个条件**：
>
> ① **一正**：$x > 0, \dfrac{1}{x} > 0$ ✓  
> ② **二定**：两项之积 $x \cdot \dfrac{1}{x} = 1$（常数）✓  
> ③ **三相等**：取等条件是 $x = \dfrac{1}{x}$，即 $x = 1$（$x > 0$ 范围内可以达到）✓
>
> 三个条件都满足，结论：$f(x)_{\min} = 2$，在 $x = 1$ 时取到。
>
> **为什么三个条件缺一不可？**
>
> - 如果**一正**不满足（$x$ 可以为负）：$\sqrt{ab}$ 对负数无意义，基本不等式不成立。
> - 如果**二定**不满足（积不是常数）：不等式 $a + b \geq 2\sqrt{ab}$ 只给了 $a+b$ 的下界，但这个下界本身也在变化，无法得到 $a+b$ 的最小值。
> - 如果**三相等**不可达（取等条件在约束范围外）：不等式给出的是下界，但该下界可能取不到，函数的实际最小值高于此下界。
>
> **积非常数时怎么办？** 配凑，把 $a + b$ 改写，让积成为常数。
>
> 比如 $x + \dfrac{4}{x-1}$（$x > 1$）——分母是 $x-1$，不是 $x$，积不是常数。凑法：
>
> $$x + \frac{4}{x-1} = (x-1) + \frac{4}{x-1} + 1$$
>
> 令 $t = x - 1 > 0$，则变为 $t + \dfrac{4}{t} + 1 \geq 2\sqrt{t \cdot \dfrac{4}{t}} + 1 = 2\sqrt{4} + 1 = 5$。
>
> 取等：$t = \dfrac{4}{t}$，$t^2 = 4$，$t = 2$，即 $x = 3$ ✓（$x = 3 > 1$，可达）。
>
> **'1' 的代换**：当已知条件形如 $\dfrac{1}{x} + \dfrac{1}{y} = 1$ 时，把 $1$ 替换为这个和。
>
> 求 $x + 2y$ 的最小值：$(x + 2y) \cdot 1 = (x + 2y)\left(\dfrac{1}{x} + \dfrac{1}{y}\right)$ 展开后用基本不等式。
>
> **反向应用**：如果已知的是 $a + b$（和为常数），求 $ab$ 的最大值，同样用基本不等式：$ab \leq \left(\dfrac{a+b}{2}\right)^2$，等号当 $a = b$ 时成立。"

把这段内心独白读完。重点感受"三条件自查"是如何在一秒内完成的——不是死记，是真正理解了每个条件为什么不可缺。

## 三、抽象成方法

### 基本不等式的 4 大变形

设 $a, b > 0$：

$$\boxed{a + b \geq 2\sqrt{ab}} \quad \text{（和 $\geq$ 2倍积的方根）}$$

$$\boxed{\frac{a+b}{2} \geq \sqrt{ab}} \quad \text{（算术平均 $\geq$ 几何平均）}$$

$$\boxed{\sqrt{ab} \leq \frac{a+b}{2}} \quad \text{（同上，方向反写）}$$

$$\boxed{a^2 + b^2 \geq 2ab} \quad \text{（无需正数约束！等价于 $(a-b)^2 \geq 0$）}$$

**第 4 个变形的证明**：$a^2 + b^2 - 2ab = (a-b)^2 \geq 0$，等号当 $a = b$ 时。

额外变形：$\dfrac{a^2+b^2}{2} \geq \left(\dfrac{a+b}{2}\right)^2$（平方平均 $\geq$ 算术平均），可由第 4 式推出。

### "一正二定三相等"三原则

| 原则 | 含义 | 若违反 |
|------|------|--------|
| **一正** | $a, b > 0$ | 不等式不成立，$\sqrt{ab}$ 无意义 |
| **二定** | 积 $ab$（或和 $a+b$）为常数 | 下界随变量变化，无法确定最值 |
| **三相等** | 取等条件 $a = b$ 在约束范围内可达 | 只能得到下界，但该下界取不到，非最值 |

**验证取等条件的方法**：写出 $a = b$ 对应的方程，解出 $x$（参数），确认该 $x$ 值满足所有原始约束（如 $x > 0$，$x > 1$ 等）。

### 三大技巧

**技巧一：配凑法**

适用：积非常数，需要凑出让积为常数的结构。

$$x + \frac{c}{x - k} \xrightarrow{\text{凑}} (x-k) + \frac{c}{x-k} + k \quad (x > k)$$

令 $t = x - k$，对 $t + \dfrac{c}{t}$（$t > 0$）用基本不等式。

**技巧二："1" 的代换**

适用：已知 $\dfrac{a}{x} + \dfrac{b}{y} = 1$，求含 $x, y$ 的表达式的最值。

$$(x + y) = (x + y) \cdot 1 = (x + y)\left(\frac{a}{x} + \frac{b}{y}\right)$$

展开后利用基本不等式 $\dfrac{x}{y} + \dfrac{y}{x} \geq 2$。

**技巧三：反向应用（积为常数求和的最值）**

已知 $ab = k$（常数，$a, b > 0$），求 $a + b$ 的最小值：

$$a + b \geq 2\sqrt{ab} = 2\sqrt{k}$$

等号当 $a = b = \sqrt{k}$ 时成立。

## 四、方法变形

### 变形 1：直接型（积为常数）

$$x + \frac{c}{x} \geq 2\sqrt{c}, \quad x > 0, \quad \text{等号 } x = \sqrt{c}$$

### 变形 2：配凑型（平移后积为常数）

$$x + \frac{c}{x - k} = (x - k) + \frac{c}{x - k} + k \geq 2\sqrt{c} + k, \quad x > k$$

等号条件：$x - k = \sqrt{c}$，即 $x = k + \sqrt{c}$。

### 变形 3："1" 代换（条件约束型）

若 $\dfrac{2}{x} + \dfrac{1}{y} = 1$（$x, y > 0$），求 $x + 2y$ 最小值：

$$(x + 2y) = (x + 2y) \cdot 1 = (x + 2y)\left(\frac{2}{x} + \frac{1}{y}\right) = 2 + \frac{x}{y} + \frac{4y}{x} + 2 \geq 4 + 2\sqrt{\frac{x}{y} \cdot \frac{4y}{x}} = 4 + 2 \times 2 = 8$$

等号：$\dfrac{x}{y} = \dfrac{4y}{x}$，即 $x^2 = 4y^2$，$x = 2y$（正数）。代入 $\dfrac{2}{x} + \dfrac{1}{y} = 1$：$\dfrac{2}{2y} + \dfrac{1}{y} = 1$，$y = 2, x = 4$。验证取等条件可达 ✓，最小值为 $8$。

### 变形 4：柯西不等式（高考拓展）

$$(a^2 + b^2)(c^2 + d^2) \geq (ac + bd)^2$$

等号当 $\dfrac{a}{c} = \dfrac{b}{d}$ 时成立。常用于向量模长、距离最值等问题。

## 五、思考路标（条件反射训练）

读以下每条，直到"看到就自动触发操作"：

1. **见 $a + b$（两项之和）且 $ab$ 为常数** → 直接用 $a + b \geq 2\sqrt{ab}$，得和的最小值。

2. **见 $ab$（乘积）且 $a + b$ 为常数** → 用 $ab \leq \left(\dfrac{a+b}{2}\right)^2$，得积的最大值。

3. **见 $x + \dfrac{c}{x}$（$x > 0$）** → 直接套 $x + \dfrac{c}{x} \geq 2\sqrt{c}$，等号 $x = \sqrt{c}$。

4. **见 $x + \dfrac{c}{x-k}$（$x > k$）** → 配凑：分离出 $(x-k)$，令 $t = x-k$，转化为 $t + \dfrac{c}{t} + k$。

5. **见 $\dfrac{p}{x} + \dfrac{q}{y} = $ 常数，求含 $x, y$ 的线性式** → "1" 的代换。

6. **见 $a^2 + b^2$（平方和）** → 想到 $a^2 + b^2 \geq 2ab$；或用 $a^2 + b^2 = (a+b)^2 - 2ab$ 配合已知条件。

7. **用完不等式后，必须验证取等条件可达** → 解出取等时的 $x$ 值，检查是否满足所有约束（$> 0$，$> k$，等）。若不可达，该下界不是最值，需重新分析。

8. **三原则缺一不可** → 一正（$> 0$）、二定（积或和是常数）、三相等（取等可达）。每次用基本不等式前心里默念三遍。

## 六、应用例题

### 例 1：直接型

**题目**：$x > 0$，求 $f(x) = x + \dfrac{4}{x}$ 的最小值。

**【思路】** 两项，积 $= x \cdot \dfrac{4}{x} = 4$（常数），$x > 0$ ✓。

$$x + \frac{4}{x} \geq 2\sqrt{x \cdot \frac{4}{x}} = 2\sqrt{4} = 4$$

取等：$x = \dfrac{4}{x}$，$x^2 = 4$，$x = 2$（$x > 0$，取正值）✓。

**最小值为 $4$，在 $x = 2$ 时取到。**

---

### 例 2："1" 代换

**题目**：已知 $x, y > 0$，$\dfrac{2}{x} + \dfrac{1}{y} = 1$，求 $x + 2y$ 的最小值。

**【思路】** 利用 $\dfrac{2}{x} + \dfrac{1}{y} = 1$，将 $1$ 代入：

$$x + 2y = (x + 2y) \times 1 = (x + 2y)\left(\frac{2}{x} + \frac{1}{y}\right)$$

展开：

$$= \frac{2x}{x} + \frac{x}{y} + \frac{4y}{x} + \frac{2y}{y} = 2 + \frac{x}{y} + \frac{4y}{x} + 2 = 4 + \frac{x}{y} + \frac{4y}{x}$$

对 $\dfrac{x}{y} + \dfrac{4y}{x}$ 用基本不等式（$x, y > 0$ 时，$\dfrac{x}{y} > 0, \dfrac{4y}{x} > 0$；积 $= 4$，常数）：

$$\frac{x}{y} + \frac{4y}{x} \geq 2\sqrt{\frac{x}{y} \cdot \frac{4y}{x}} = 2\sqrt{4} = 4$$

所以 $x + 2y \geq 4 + 4 = 8$。

取等条件：$\dfrac{x}{y} = \dfrac{4y}{x}$，即 $x^2 = 4y^2$，$x = 2y$（正数）。代入约束：$\dfrac{2}{2y} + \dfrac{1}{y} = 1$，$\dfrac{1}{y} + \dfrac{1}{y} = 1$，$y = 2, x = 4$ ✓。

**最小值为 $8$，在 $x = 4, y = 2$ 时取到。**

---

### 例 3：配凑法

**题目**：$x > 1$，求 $f(x) = x + \dfrac{4}{x-1}$ 的最小值。

**【思路】** 分母是 $x - 1$，不是 $x$，需要配凑。

$$f(x) = x + \frac{4}{x-1} = \underbrace{(x-1)}_{\text{新变量} t} + \frac{4}{x-1} + 1$$

令 $t = x - 1 > 0$（因为 $x > 1$）：

$$f = t + \frac{4}{t} + 1 \geq 2\sqrt{t \cdot \frac{4}{t}} + 1 = 2\sqrt{4} + 1 = 4 + 1 = 5$$

取等：$t = \dfrac{4}{t}$，$t^2 = 4$，$t = 2$（$t > 0$），即 $x - 1 = 2$，$x = 3$ ✓（$x = 3 > 1$）。

**最小值为 $5$，在 $x = 3$ 时取到。**

## 七、思路自测题

**自测 1**　$x > 0$，求 $g(x) = 3x + \dfrac{12}{x}$ 的最小值。

> 💡 提示：积 $= 3x \cdot \dfrac{12}{x} = 36$，$3x, \dfrac{12}{x} > 0$。$3x + \dfrac{12}{x} \geq 2\sqrt{36} = 12$，等号 $3x = \dfrac{12}{x}$，$x^2 = 4$，$x = 2$。

**自测 2**　$x > 3$，求 $h(x) = x + \dfrac{9}{x-3}$ 的最小值。

> 💡 提示：配凑 $h = (x-3) + \dfrac{9}{x-3} + 3$，令 $t = x-3 > 0$：$t + \dfrac{9}{t} + 3 \geq 2\sqrt{9} + 3 = 6 + 3 = 9$。等号 $t = 3$，即 $x = 6$。

**自测 3**　已知 $a, b > 0$，$a + 2b = 4$，求 $\dfrac{1}{a} + \dfrac{2}{b}$ 的最小值。

> 💡 提示：$\dfrac{1}{a} + \dfrac{2}{b} = \dfrac{1}{4}(a + 2b)\left(\dfrac{1}{a} + \dfrac{2}{b}\right)$，展开：$\dfrac{1}{4}\left(1 + \dfrac{2a}{b} + \dfrac{2b}{a} + 4\right) = \dfrac{1}{4}\left(5 + \dfrac{2a}{b} + \dfrac{2b}{a}\right) \geq \dfrac{1}{4}(5 + 2\sqrt{4}) = \dfrac{9}{4}$。等号条件：$\dfrac{2a}{b} = \dfrac{2b}{a}$，$a = b$，代入 $a + 2b = 4$：$a = b = \dfrac{4}{3}$ ✓。

**自测 4**　$a > 0, b > 0$，$a + b = 1$，求 $\dfrac{1}{a} + \dfrac{4}{b}$ 的最小值。

> 💡 提示：$\dfrac{1}{a} + \dfrac{4}{b} = \left(\dfrac{1}{a} + \dfrac{4}{b}\right)(a + b) = 1 + \dfrac{4a}{b} + \dfrac{b}{a} + 4 = 5 + \dfrac{4a}{b} + \dfrac{b}{a} \geq 5 + 2\sqrt{4} = 9$。等号：$\dfrac{4a}{b} = \dfrac{b}{a}$，$b = 2a$，代入 $a + b = 1$：$a = \dfrac{1}{3}, b = \dfrac{2}{3}$。

**自测 5**　$x > 0$，$y > 0$，已知 $2x + 8y = 1$，求 $xy$ 的最大值。

> 💡 提示：由 $2x + 8y \geq 2\sqrt{2x \cdot 8y} = 2\sqrt{16xy} = 8\sqrt{xy}$（基本不等式，两项均正）。$1 \geq 8\sqrt{xy}$，$\sqrt{xy} \leq \dfrac{1}{8}$，$xy \leq \dfrac{1}{64}$。等号：$2x = 8y$，$x = 4y$，代入 $2x + 8y = 1$：$y = \dfrac{1}{16}, x = \dfrac{1}{4}$。
