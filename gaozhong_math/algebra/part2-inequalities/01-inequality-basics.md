# 不等式的性质

---

## 一、大小比较的三种方法

比较两个实数（或代数式）的大小，核心依据是**差的符号**或**商的大小**。

### 方法一：作差比较法

$$a > b \iff a - b > 0, \qquad a = b \iff a - b = 0, \qquad a < b \iff a - b < 0$$

**步骤**：
1. 作差：$a - b$
2. 化简或配方
3. 判断差的符号，得出结论

**标准格式**：

$$a - b = \cdots = (\text{非负数或明显正/负的表达式}) > 0 \implies a > b$$

### 方法二：作商比较法

当 $a, b$ **同号**时，可以比较 $\frac{a}{b}$ 与 $1$ 的大小：

$$\frac{a}{b} > 1 \iff a > b \quad (\text{同正时}); \qquad \frac{a}{b} > 1 \iff a < b \quad (\text{同负时})$$

**注意**：作商之前必须先确认 $b \ne 0$ 且 $a, b$ 同号，否则不能直接用。

### 方法三：利用函数单调性

在同一单调区间上，用函数性质比大小：

- $f(x) = x^2$（$x \geq 0$ 时单调递增）：$a > b \geq 0 \Rightarrow a^2 > b^2$
- $f(x) = \sqrt{x}$（$x \geq 0$ 时单调递增）：$a > b \geq 0 \Rightarrow \sqrt{a} > \sqrt{b}$

**三种方法的适用场景**：

| 方法 | 最适合 | 注意事项 |
|------|--------|----------|
| 作差 | 代数式比较、不确定符号时 | 化简要彻底，最后明确符号 |
| 作商 | 两数同号且都 $\ne 0$ | 先确认同号 |
| 函数 | 含根号、指数、对数时 | 确认定义域和单调性方向 |

## 二、不等式的八大性质

设 $a, b, c, d \in \mathbb{R}$。

### 性质 1：对称性

$$a > b \iff b < a$$

"大于"和"小于"可以互换，前提是同时交换左右两边。

### 性质 2：传递性

$$a > b \text{ 且 } b > c \implies a > c$$

不等号方向一致时，可以"穿越"中间量建立直接比较。

### 性质 3：同向不等式可以相加

$$a > b \text{ 且 } c > d \implies a + c > b + d$$

**两个同向不等式**（不等号方向相同）**可以对应相加**，方向不变。

推论（移项性）：

$$a > b \implies a + c > b + c$$

等式两边可以任意加减同一个数，不等式**同样**成立。

### 性质 4：同向不等式相减要注意

异向不等式可以相减（实际上是"减去反向的"）：

$$a > b \text{ 且 } c < d \implies a - c > b - d$$

**但同向不等式不能直接相减**——$a > b$ 且 $c > d$ 时，$a - c$ 与 $b - d$ 的大小关系不确定。

### 性质 5：乘以正数方向不变，乘以负数方向改变

$$a > b, \; c > 0 \implies ac > bc$$

$$a > b, \; c < 0 \implies ac < bc$$

**关键**：不等式两边乘以（或除以）**负数**，不等号方向**必须改变**。这是高考最常考的易错点。

### 性质 6：同向同号不等式可以相乘

$$a > b > 0 \text{ 且 } c > d > 0 \implies ac > bd$$

**必须同向且各边都为正数**（非负数不够，要严格为正）。

### 性质 7：正数的乘方与开方

$$a > b > 0 \implies a^n > b^n \quad (n \in \mathbb{N}^*, n \geq 1)$$

$$a > b > 0 \implies \sqrt[n]{a} > \sqrt[n]{b} \quad (n \in \mathbb{N}^*, n \geq 1)$$

对正数，平方/开方都是"保序"的（越大的数，平方和开方结果也越大）。

### 性质 8：正数取倒数，方向改变

$$a > b > 0 \implies \frac{1}{a} < \frac{1}{b}$$

$$a < b < 0 \implies \frac{1}{a} > \frac{1}{b}$$

**同号取倒数，方向改变**。若 $a, b$ 异号（一正一负），则 $a > 0 > b$ 时 $\frac{1}{a} > 0 > \frac{1}{b}$，方向不变。

### 八大性质速查表

| 编号 | 性质 | 条件 |
|------|------|------|
| 1 | $a > b \iff b < a$ | 无 |
| 2 | $a > b, b > c \Rightarrow a > c$ | 无 |
| 3 | $a > b, c > d \Rightarrow a+c > b+d$ | 同向 |
| 4 | $a > b, c < d \Rightarrow a-c > b-d$ | 异向 |
| 5 | $a > b, c > 0 \Rightarrow ac > bc$；$c < 0 \Rightarrow ac < bc$ | 注意符号 |
| 6 | $a > b > 0, c > d > 0 \Rightarrow ac > bd$ | 同向同正 |
| 7 | $a > b > 0 \Rightarrow a^n > b^n$，$\sqrt[n]{a} > \sqrt[n]{b}$ | 正数 |
| 8 | $a > b > 0 \Rightarrow \frac{1}{a} < \frac{1}{b}$ | 同号 |

## 三、典型应用例题

### 例 1：比较 $a^2 + b^2$ 与 $2ab$

**【思路】** 用作差比较法。

$$
(a^2 + b^2) - 2ab = a^2 - 2ab + b^2 = (a-b)^2
$$

由于 $(a-b)^2 \geq 0$ 对一切实数 $a, b$ 成立，有：

$$a^2 + b^2 \geq 2ab$$

等号成立当且仅当 $a - b = 0$，即 $a = b$。

**结论**：$a^2 + b^2 \geq 2ab$，等号当 $a = b$ 时成立。

这是基本不等式（均值不等式）的代数基础——后续章节会深入展开。

---

### 例 2：已知 $-1 < a + b < 3$，$2 < a - b < 4$，求 $2a$ 的范围

**【思路】** 同向不等式可以相加（性质 3）。

已知：
$$-1 < a + b < 3 \quad \cdots (1)$$
$$2 < a - b < 4 \quad \cdots (2)$$

$(1) + (2)$（同向，可以相加）：

$$-1 + 2 < (a+b) + (a-b) < 3 + 4$$

$$1 < 2a < 7$$

$$\frac{1}{2} < a < \frac{7}{2}$$

**注意**：用不等式相加时，要求两个不等式的方向完全相同（都是 $<$）。

---

### 例 3：判断命题"$a > b \Rightarrow ac > bc$"的真假

**【思路】** 找反例。

命题中没有给定 $c$ 的符号。取 $a = 2, b = 1, c = -1$：

- 条件：$a > b$，即 $2 > 1$ ✓
- 结论：$ac > bc$，即 $2 \times (-1) > 1 \times (-1)$，即 $-2 > -1$，**假** ✗

**反例成立**，命题为假。

正确版本：$a > b$ 且 $c > 0 \Rightarrow ac > bc$；$a > b$ 且 $c < 0 \Rightarrow ac < bc$。

## 四、易错点总结

1. **乘以负数必须变号**：$a > b$ 两边乘 $-1$ 得 $-a < -b$，不等号方向改变。

2. **作商比较必须先确认同号**：若 $a = 3, b = -2$，$\frac{a}{b} = -\frac{3}{2} < 1$ 但实际 $a > b$，所以异号时不能用 $\frac{a}{b}$ 与 $1$ 比。

3. **同向不等式可加不可减**：$a > b$ 且 $c > d$ 时，$a - c$ 与 $b - d$ 大小不定（可构造反例 $a = 5, b = 1, c = 4, d = 0$：$a-c=1 > b-d=1$ 不成立，这里差相等）。

4. **倒数变号只在同号时适用**：$a, b$ 异号时，正数的倒数仍大于负数的倒数，不变号。

5. **平方保序需要非负条件**：$a > b$（两者可能为负）时，**不能**直接推 $a^2 > b^2$。例如 $-1 > -3$，但 $(-1)^2 = 1 < (-3)^2 = 9$。

## 五、自测题

**自测 1**　用作差法比较 $\sqrt{6} + \sqrt{10}$ 与 $\sqrt{5} + \sqrt{11}$ 的大小。

> 💡 提示：作差 $(\sqrt{6}+\sqrt{10}) - (\sqrt{5}+\sqrt{11}) = (\sqrt{6}-\sqrt{5}) - (\sqrt{11}-\sqrt{10})$。注意 $f(x)=\sqrt{x}$ 是凹函数，相邻两数之差越来越小：$\sqrt{6}-\sqrt{5} < \sqrt{5}-\sqrt{4}$ 但这里比较 $\sqrt{6}-\sqrt{5}$ 与 $\sqrt{11}-\sqrt{10}$，后者更小。故差 $> 0$。

**自测 2**　已知 $0 < a < b$，判断下列各命题是否成立：  
(1) $a^2 < ab < b^2$　　(2) $\frac{1}{a} > \frac{1}{b}$　　(3) $a^2 - b^2 < 0$

> 💡 提示：(1) $a < b$ 且都正，可乘以 $a$ 或 $b$（注意用性质 6）；(2) 同正取倒数变号（性质 8）；(3) 作差。

**自测 3**　已知 $-3 < a < 0$，$1 < b < 4$，求 $a - b$ 的范围。

> 💡 提示：将 $1 < b < 4$ 变形为 $-4 < -b < -1$，再与 $a$ 的范围相加（同向不等式相加，性质 3）。

**自测 4**　已知 $a > b > 0$，$c > d > 0$，以下结论哪些正确？  
(1) $a + c > b + d$　　(2) $ac > bd$　　(3) $\frac{a}{d} > \frac{b}{c}$　　(4) $a - d > b - c$

> 💡 提示：(1) 同向相加 ✓；(2) 同向同正相乘 ✓；(3) $\frac{a}{d}$ 与 $\frac{b}{c}$ 比：交叉相乘 $ac$ 与 $bd$，再用 (2)；(4) 改写为 $a + c > b + d$，与 (1) 相同……等等，这里是 $-d$ 和 $-c$，方向要重新判断。
