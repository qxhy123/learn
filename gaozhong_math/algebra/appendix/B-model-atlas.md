# 附录 B：高一上代数模型图集

> 高一上代数（Part 1–5）共 12 个核心套路模型。每个模型包含触发条件、核心思路、关键步骤、示意图、典型题与关联章节。配合附录 A 公式表可快速识别题型。

## 模型 1：集合 Venn 图与运算

**触发条件**

题面出现 $A \cap B$、$A \cup B$、$\complement_U A$、"两条件均成立"、"满足其一即可"、"既不属于…也不属于"等关键词；含参集合的子集 / 相等 / 不相交关系；已知元素个数求范围。

**核心思路**

把每个集合画成一个圆，全集画一个矩形包住它们，按运算图标记阴影区域。复杂运算（如 $\complement_U(A \cup B)$）一律先画好图、再读出对应区域。

**关键步骤**

1. 画矩形 $U$，在其中画 $A$、$B$ 两圆，三种区域 $A \setminus B$、$A \cap B$、$B \setminus A$ 都标出；
2. 把题目所求的运算翻译成 Venn 图阴影区（如 $\complement_U(A \cup B)$ 是 $U$ 减去两圆并集）；
3. 把已知元素或区间填入对应区，逐个检验是否符合条件；
4. 若含参数（如 $A \cap B = A$），转化为子集关系 $A \subseteq B$，再分类讨论 $A = \varnothing$ 与 $A \ne \varnothing$。

**示意（ASCII）**

```
+----------- U -----------+
|     +------+            |
|     |  A   |  +------+  |
|     |   +--+--+  B   |  |
|     |   |  | A∩B  |  |  |
|     |   +--+--+      |  |
|     +------+  +------+  |
|                         |
+-------------------------+
```

**典型题**

已知 $A = \{x \mid 1 \le x \le 3\}$，$B = \{x \mid x \ge a\}$，若 $A \cap B = A$，求 $a$ 的取值范围。

> **一句话指引**：$A \cap B = A \Leftrightarrow A \subseteq B$；要 $A$ 完全装进 $B$，即 $a \le 1$。

**关联章节**：Part 1 / 01–03（集合基础、集合运算、子集幂集）

## 模型 2：一元二次不等式三态判别

**触发条件**

题面是 $ax^2 + bx + c > 0$（或 $\ge 0, < 0, \le 0$）形式；或含参 $kx^2 + \cdots$ 类题面需要"恒成立"、"有解"判定；最终目标是求解集或求参数范围。

**核心思路**

先把 $a$ 化为正系数（必要时两边乘 $-1$ 并翻转不等号），算 $\Delta$，按三种情形画抛物线，**用图象的"轴上方 / 轴下方"读解集**。

**关键步骤**

1. 化标准：使 $a > 0$；
2. 求 $\Delta = b^2 - 4ac$；
3. 分三态：
   - $\Delta > 0$：两根 $x_1 < x_2$，$> 0$ 取"两根之外"，$< 0$ 取"两根之间"；
   - $\Delta = 0$：重根 $x_0$，$> 0$ 为 $\mathbb{R} \setminus \{x_0\}$，$< 0$ 为 $\varnothing$；
   - $\Delta < 0$：无实根，$> 0$ 为 $\mathbb{R}$，$< 0$ 为 $\varnothing$；
4. 端点取舍：含 $=$ 时端点取，否则不取。

**示意**

```
   a>0, Δ>0      a>0, Δ=0      a>0, Δ<0
     ∪              ∪              ∪
   /   \          /   \          /   \
--*-----*--    --*--------    -----------
  x₁    x₂      x₀
> 0 在外      > 0 除 x₀ 外    > 0 处处成立
< 0 在内      < 0 无解        < 0 无解
```

**典型题**

解不等式 $-2x^2 + 5x - 3 \ge 0$。

> **一句话指引**：两边乘 $-1$ 翻转：$2x^2 - 5x + 3 \le 0$；$\Delta = 25 - 24 = 1$，根为 $1, \dfrac{3}{2}$；解集 $\left[1, \dfrac{3}{2}\right]$。

**关联章节**：Part 2 / 02（一元二次不等式）

## 模型 3：分式不等式标轴法（穿针引线）

**触发条件**

题面含分式 $\dfrac{f(x)}{g(x)} \gtrless 0$，或可化为分式形式（如 $\dfrac{1}{x - 1} > 2$ 需移项通分）；分子分母均可因式分解为一次或二次因子。

**核心思路**

将分式不等式等价转化为乘积不等式 $f(x) \cdot g(x) \gtrless 0$（同时保留 $g \ne 0$ 约束），把所有零点（根）标在数轴上，从最右上角开始"穿针引线"，遵循"**奇穿偶不穿**"。

**关键步骤**

1. 移项化为 $\dfrac{f(x)}{g(x)} \gtrless 0$ 标准形式（一边为零）；
2. 分子分母**各自因式分解**为一次因式；
3. 把所有根标在数轴上（含奇偶重数）；
4. 从最右上方画曲线穿过最右根（奇穿、偶不穿），依次穿过所有根；
5. 取曲线在上方部分（$> 0$）或下方部分（$< 0$），最后去掉使分母为零的点。

**示意**

```
   求 (x-1)(x-2) / (x-3) > 0
   
     -∞    1    2    3    +∞
      ──●────●────●────
        ↓    ↑    ↓
        从右上方进入，奇次根穿过，偶次根反弹
   
   解集：(1, 2) ∪ (3, +∞)
```

**典型题**

解不等式 $\dfrac{x - 1}{x + 2} \ge 0$。

> **一句话指引**：等价于 $(x-1)(x+2) \ge 0$ 且 $x \ne -2$；零点 $-2, 1$，穿针得 $x \le -2$ 或 $x \ge 1$；排除 $x = -2$：$x < -2$ 或 $x \ge 1$。

**关联章节**：Part 2 / 03（分式不等式）

## 模型 4：基本不等式"和定积大、积定和小"

**触发条件**

题面给定 $a + b = $ 定值或 $ab = $ 定值（或可整理成此结构），要求 $ab$ 最大值或 $a + b$ 最小值；含 $\dfrac{1}{a} + \dfrac{1}{b}$ 之类倒数和；"分式与一次式之和"的最值（如 $x + \dfrac{1}{x}$）。

**核心思路**

识别"和定 / 积定"结构后，套用 $a + b \ge 2\sqrt{ab}$；先验 **"一正二定三相等"** 三个前提，再写最值与等号条件。

**关键步骤**

1. 把目标整理为 $a + b$ 或 $ab$ 的形式（必要时用换元、配凑系数）；
2. 验证 $a, b > 0$（一正）；
3. 验证另一个量是定值（二定）；
4. 验证等号 $a = b$ 在定义域内可取（三相等）；
5. 等号成立时计算最值。

**示意**

```
   和定 a+b=S → ab ≤ (S/2)² = S²/4
   积定 ab=P → a+b ≥ 2√P
   
        ab
         │     峰值 S²/4
         │      ▲
         │    ╱ │ ╲
         │  ╱   │   ╲
         │╱   a=b=S/2 ╲
       ──┼─────────────→ a
              S/2          S
```

**典型题**

已知 $x > 0$，$y > 0$，且 $x + 2y = 1$，求 $\dfrac{1}{x} + \dfrac{1}{y}$ 的最小值。

> **一句话指引**：$\dfrac{1}{x} + \dfrac{1}{y} = (x + 2y)\left(\dfrac{1}{x} + \dfrac{1}{y}\right) = 3 + \dfrac{2y}{x} + \dfrac{x}{y} \ge 3 + 2\sqrt{2}$，等号当 $\dfrac{2y}{x} = \dfrac{x}{y}$ 即 $x = \sqrt{2} y$ 时取。

**关联章节**：Part 2 / 04（基本不等式）

## 模型 5：复合函数单调性"同增异减"

**触发条件**

函数形如 $y = f(g(x))$（外层 $f$，内层 $g$）；题目问复合函数的单调区间、是否单调；或已知一个单调性反推另一个的单调性。

**核心思路**

记内层 $u = g(x)$ 在区间 $I$ 上的单调性 $\sigma_g$，外层 $y = f(u)$ 在 $g(I)$ 上的单调性 $\sigma_f$；复合的单调性 $= \sigma_g \times \sigma_f$（增 $\times$ 增 $=$ 增，减 $\times$ 减 $=$ 增，增 $\times$ 减 $=$ 减）。**"同增异减"**。

**关键步骤**

1. 分解 $y = f(g(x))$ 为外层 $y = f(u)$ 与内层 $u = g(x)$；
2. 求内层 $u = g(x)$ 在定义域上的单调区间与值域；
3. 在内层值域上判断外层 $f(u)$ 的单调性；
4. 用"同增异减"得到复合函数在内层每个单调区间上的单调性。

**示意**

```
  内层 g(x)   外层 f(u)   复合 f(g(x))
   增           增          增  ↑↑
   增           减          减  ↑↓
   减           增          减  ↓↑
   减           减          增  ↓↓
   
   口诀：同方向→增，反方向→减
```

**典型题**

判断 $y = \log_{1/2}(x^2 - 4x + 3)$ 的单调区间。

> **一句话指引**：内层 $u = x^2 - 4x + 3$ 定义域 $x < 1$ 或 $x > 3$（保真数正），在 $x < 1$ 上减、$x > 3$ 上增；外层 $\log_{1/2} u$ 减；同增异减：$x < 1$（减 × 减 = 增）、$x > 3$（增 × 减 = 减）。

**关联章节**：Part 3 / 03（单调性）、Part 3 / 06（复合函数）

## 模型 6：奇偶性与图象对称

**触发条件**

题目出现 $f(-x) = f(x)$、$f(-x) = -f(x)$、"$f$ 的图象关于 $y$ 轴 / 原点对称"；或求带参函数 $f(x) = ax^3 + bx + c$ 为奇函数时的 $c$；或给定一半图象画另一半。

**核心思路**

奇 ↔ 中心对称（原点）；偶 ↔ 轴对称（$y$ 轴）。先验**定义域关于原点对称**（必要条件），再代入 $f(-x)$ 比较。

**关键步骤**

1. 写出函数定义域，检查是否关于 $0$ 对称；不对称直接判非奇非偶；
2. 计算 $f(-x)$ 表达式；
3. 比较 $f(-x)$ 与 $f(x)$：
   - $f(-x) = f(x)$ → 偶函数；
   - $f(-x) = -f(x)$ → 奇函数；
   - 两者均不成立 → 非奇非偶；
4. 利用奇函数 $f(0) = 0$（若 $0 \in$ 定义域）求参数。

**示意**

```
   偶函数（关于 y 轴对称）       奇函数（关于原点对称）
        │                                │
        │  ╲    ╱                       ╱ │
        │   ╲  ╱                       ╱  │
   ─────┼────●────         ───────────●───┼──────
        │   ╱  ╲                  ╱    │
        │  ╱    ╲                ╱     │
        │                              │
   f(-x) = f(x)                  f(-x) = -f(x)
   左右映像                       中心翻转
```

**典型题**

判断 $f(x) = \dfrac{2^x - 1}{2^x + 1}$ 的奇偶性。

> **一句话指引**：定义域 $\mathbb{R}$ 对称；$f(-x) = \dfrac{2^{-x} - 1}{2^{-x} + 1} = \dfrac{1 - 2^x}{1 + 2^x} = -f(x)$；奇函数。

**关联章节**：Part 3 / 04（奇偶性）

## 模型 7：含参一元二次方程根的分布

**触发条件**

题目形如"方程 $ax^2 + bx + c = 0$ 有两个正根 / 两负根 / 一正一负 / 两根都在区间 $(m, n)$ 内 / 一根在区间内一根在区间外"；含参数 $k$ 在系数中。

**核心思路**

把含参一元二次方程视为二次函数 $f(x) = ax^2 + bx + c$ 与 $x$ 轴的交点问题。结合判别式 $\Delta$、对称轴位置 $x = -\dfrac{b}{2a}$、区间端点值 $f(m), f(n)$ 的符号，写出不等式组。

**关键步骤**

1. 设 $f(x) = ax^2 + bx + c$（假定 $a > 0$，否则乘 $-1$）；
2. 写下 $\Delta \ge 0$（有实根的前提）；
3. 按题目要求的根分布画图：
   - **两正根**：$\Delta \ge 0$，对称轴 $-\dfrac{b}{2a} > 0$，$f(0) > 0$；
   - **两负根**：$\Delta \ge 0$，对称轴 $-\dfrac{b}{2a} < 0$，$f(0) > 0$；
   - **一正一负**：$f(0) < 0$（与判别式自动满足）；
   - **两根都在 $(m, n)$ 内**：$\Delta \ge 0$，对称轴 $m < -\dfrac{b}{2a} < n$，$f(m) > 0$，$f(n) > 0$；
   - **一根在 $(m, n)$ 内、一根在外**：$f(m) \cdot f(n) < 0$；
4. 联立不等式组求参数范围。

**示意**

```
  两正根                两负根              一正一负
     ∪                    ∪                 ∪
   ╱   ╲                ╱   ╲             ╱   ╲
──●─●───            ──●─●──●            ─●────●─
0 x₁ x₂            x₁ x₂  0            x₁ 0  x₂
f(0)>0,对称轴>0    f(0)>0,对称轴<0     f(0)<0
```

**典型题**

方程 $x^2 - mx + m + 3 = 0$ 的两实根都在区间 $(2, 4)$ 内，求 $m$ 的取值范围。

> **一句话指引**：设 $f(x) = x^2 - mx + m + 3$（$a = 1 > 0$）。联立四条件：
> - $\Delta = m^2 - 4(m + 3) \ge 0 \Rightarrow m \le -2$ 或 $m \ge 6$；
> - 对称轴 $\dfrac{m}{2} \in (2, 4) \Rightarrow 4 < m < 8$；
> - $f(2) = 7 - m > 0 \Rightarrow m < 7$；
> - $f(4) = 19 - 3m > 0 \Rightarrow m < \dfrac{19}{3}$。
>
> 取交集得 $m \in [6, \dfrac{19}{3})$。

**关联章节**：Part 3 综合（结合 Part 2 / 02 二次不等式）

## 模型 8：指数 / 对数函数 $a > 1$ 与 $0 < a < 1$ 对比

**触发条件**

题面涉及 $a^x$、$\log_a x$ 中底数 $a$ 含参未明确大小；或要比较 $a^{f(x)} > a^{g(x)}$、$\log_a f(x) > \log_a g(x)$ 等不等式；或讨论指对函数单调性。

**核心思路**

指 / 对数函数的单调性方向**完全由底数 $a$ 决定**：$a > 1$ 时增、$0 < a < 1$ 时减。题中底数不明时**必须双向讨论**。

**关键步骤**

1. 识别底数 $a$ 是否含参或不明大小；
2. 分两类讨论：
   - **$a > 1$ 情形**：函数单调递增；同底比较时"不等号同向"；
   - **$0 < a < 1$ 情形**：函数单调递减；同底比较时"不等号方向翻转"；
3. 在每类下解不等式，注意真数 $> 0$ 的定义域约束；
4. 综合两类结果。

**示意**

```
  指数函数 y = aˣ
    a > 1  (递增)        0 < a < 1  (递减)
        │                      │
        │   ╱                  │ ╲
        │  ╱                   │  ╲
       1┼─                    1┼─●╲
        │                      │   ╲
   ─────●─────            ─────●─────
        0                      0
   
  对数函数 y = logₐ x  (与指数关于 y=x 对称)
    a > 1  (递增)        0 < a < 1  (递减)
        │  ╱                  │ ╲
        │ ╱                   │  ╲
   ─────●●────           ──●──●────
        │1                    │1 ╲
        │                     │   ╲
```

**典型题**

解不等式 $\log_a(2x - 1) > \log_a(x + 3)$（$a > 0, a \ne 1$）。

> **一句话指引**：先要求 $2x - 1 > 0, x + 3 > 0$ 得 $x > \dfrac{1}{2}$。分情况：$a > 1$ 时 $2x - 1 > x + 3$ 得 $x > 4$；$0 < a < 1$ 时 $2x - 1 < x + 3$ 得 $x < 4$，结合 $x > \dfrac{1}{2}$ 得 $\dfrac{1}{2} < x < 4$。

**关联章节**：Part 4 / 01（指数函数）、Part 4 / 02（对数函数）

## 模型 9：三角函数单位圆与诱导公式

**触发条件**

要计算特殊角或非标准角（如 $\sin 210°$、$\cos \dfrac{7\pi}{4}$、$\tan(-300°)$）；化简 $\sin(\pi - \alpha) + \cos(\dfrac{\pi}{2} + \alpha)$ 等含 $\pi$ 倍数的式子；已知一个三角值反求其他。

**核心思路**

把任意角化为单位圆上对应锐角的三角值。诱导公式口诀：**"奇变偶不变，符号看象限"**——把 $\alpha$ 当锐角，看变形后所在象限的原函数符号。

**关键步骤**

1. 把角写成 $k \cdot \dfrac{\pi}{2} \pm \alpha$ 形式（$\alpha$ 取锐角）；
2. 判断 $k$ 是奇数还是偶数：
   - 偶数 → 函数名**不变**（$\sin$ 仍为 $\sin$）；
   - 奇数 → 函数名**互换**（$\sin \leftrightarrow \cos$）；
3. 把 $\alpha$ 当锐角，判断 $k \cdot \dfrac{\pi}{2} \pm \alpha$ 所在象限的原函数符号；
4. 写出最终化简结果。

**示意**

```
            π/2
       II   │   I       sin 正  全正
   ────────┼─────────
       III │   IV       tan 正  cos 正
            π
   单位圆口诀：
   一全二正弦三切四余弦（各象限为正的函数）
```

**典型题**

求 $\sin\left(-\dfrac{7\pi}{6}\right)$ 的值。

> **一句话指引**：$-\dfrac{7\pi}{6} = -\pi - \dfrac{\pi}{6}$；先用 $\sin(-x) = -\sin x$ 得 $-\sin\dfrac{7\pi}{6}$；$\dfrac{7\pi}{6} = \pi + \dfrac{\pi}{6}$，第三象限，$\sin$ 为负，$\sin\dfrac{7\pi}{6} = -\dfrac{1}{2}$；故 $\sin\left(-\dfrac{7\pi}{6}\right) = \dfrac{1}{2}$。

**关联章节**：Part 5 / 02（单位圆）、Part 5 / 04（诱导公式）

## 模型 10：$y = A\sin(\omega x + \varphi) + b$ 变换链

**触发条件**

题面涉及 $y = A\sin(\omega x + \varphi) + b$ 求振幅 / 周期 / 初相 / 单调区间 / 最值 / 对称轴；从 $y = \sin x$ 经过若干变换得到目标函数（"先平移再伸缩"或"先伸缩再平移"问题）；图象识别（看图反推 $A, \omega, \varphi, b$）。

**核心思路**

掌握四个参数的几何意义：$A$ 控制振幅，$\omega$ 控制周期 $T = \dfrac{2\pi}{\omega}$，$\varphi$ 控制水平平移，$b$ 控制垂直平移。变换的**顺序至关重要**：先伸缩再平移与先平移再伸缩，相位平移量不同。

**关键步骤**

1. 读出 $A, \omega, \varphi, b$：
   - $A$ = 振幅 = $\dfrac{y_{\max} - y_{\min}}{2}$；
   - $b$ = 中线 = $\dfrac{y_{\max} + y_{\min}}{2}$；
   - $T = \dfrac{2\pi}{\omega}$；
   - 由特殊点（最大点、零点）反推 $\varphi$；
2. 求单调区间：令 $\omega x + \varphi$ 落在 $\sin$ 的增 / 减区间 $\left[-\dfrac{\pi}{2} + 2k\pi, \dfrac{\pi}{2} + 2k\pi\right]$ 等，再解 $x$；
3. 求对称轴：$\omega x + \varphi = \dfrac{\pi}{2} + k\pi$；
4. 求对称中心：$\omega x + \varphi = k\pi$，中心 $(x_k, b)$；
5. 变换链：从 $y = \sin x$ 出发：
   - **先平移再伸缩**：$\sin x \to \sin(x + \varphi) \to \sin(\omega x + \varphi)$（平移 $\varphi$ 后再压缩 $\omega$ 倍）；
   - **先伸缩再平移**：$\sin x \to \sin\omega x \to \sin\omega\left(x + \dfrac{\varphi}{\omega}\right) = \sin(\omega x + \varphi)$（先压缩再平移 $\dfrac{\varphi}{\omega}$）。

**示意**

```
   y = sin x  ──A 倍─→  y = A sin x   (纵向拉伸)
              ──ω 倍─→  y = A sin(ωx)  (横向压缩 1/ω)
              ──左移 φ/ω─→  y = A sin(ω(x + φ/ω)) = A sin(ωx + φ)
              ──上移 b─→  y = A sin(ωx + φ) + b
   
   振幅 A    周期 T=2π/ω    初相 φ    垂直位移 b
```

**典型题**

已知 $f(x) = 2\sin\left(2x - \dfrac{\pi}{3}\right) + 1$，求其周期、最值与单调增区间。

> **一句话指引**：$A = 2, \omega = 2, \varphi = -\dfrac{\pi}{3}, b = 1$；$T = \pi$，最大值 $3$、最小值 $-1$；令 $2x - \dfrac{\pi}{3} \in \left[-\dfrac{\pi}{2} + 2k\pi, \dfrac{\pi}{2} + 2k\pi\right]$ 解得增区间 $\left[-\dfrac{\pi}{12} + k\pi, \dfrac{5\pi}{12} + k\pi\right]$。

## 模型 11：辅助角公式 $a\sin x + b\cos x = R\sin(x + \varphi)$

**触发条件**

题面是同周期的"正弦 + 余弦"线性组合（如 $\sqrt{3}\sin x + \cos x$、$3\sin 2x - 4\cos 2x$）；要求该函数的最值、值域、周期或单调区间；化为单一三角函数式以便分析。

**核心思路**

把 $a\sin x + b\cos x$ 整理为 $\sqrt{a^2 + b^2}\sin(x + \varphi)$，最值变为 $\pm\sqrt{a^2 + b^2}$。$\varphi$ 由 $\cos\varphi = \dfrac{a}{R}$、$\sin\varphi = \dfrac{b}{R}$ 唯一确定（即 $\tan\varphi = \dfrac{b}{a}$，并由 $a, b$ 符号定象限）。

**关键步骤**

1. 计算 $R = \sqrt{a^2 + b^2}$；
2. 提取 $R$：$a\sin x + b\cos x = R\left(\dfrac{a}{R}\sin x + \dfrac{b}{R}\cos x\right)$；
3. 令 $\cos\varphi = \dfrac{a}{R}, \sin\varphi = \dfrac{b}{R}$（由 $a, b$ 符号定 $\varphi$ 所在象限）；
4. 套和角公式：$R(\cos\varphi\sin x + \sin\varphi\cos x) = R\sin(x + \varphi)$；
5. 最值为 $\pm R$，周期与原同周期，单调区间用 $x + \varphi$ 反推。

**示意**

```
   几何意义：把向量 (a, b) 写成极坐标 (R, φ)
   
            b│
             │  ●(a, b)
             │ ╱
             │╱   R = √(a²+b²)
             │
     ────────┼────────→ a
             │  φ = atan2(b, a)
   
   a sin x + b cos x = R sin(x + φ)
   R 决定振幅,  φ 决定初相
```

**典型题**

求 $f(x) = \sqrt{3}\sin x + \cos x$ 的最大值与对应的 $x$。

> **一句话指引**：$R = \sqrt{3 + 1} = 2$；$\cos\varphi = \dfrac{\sqrt{3}}{2}, \sin\varphi = \dfrac{1}{2}$，故 $\varphi = \dfrac{\pi}{6}$；$f(x) = 2\sin\left(x + \dfrac{\pi}{6}\right)$，最大值 $2$，当 $x + \dfrac{\pi}{6} = \dfrac{\pi}{2} + 2k\pi$ 即 $x = \dfrac{\pi}{3} + 2k\pi$ 时取到。

**关联章节**：Part 5 / 05（和差倍半角公式）

## 模型 12：解三角形 ASS 情形二解判别

**触发条件**

已知三角形两边及其中一边对角（边边角 ASS），求另一对角；题面如"$\triangle ABC$ 中，$a = 4$，$b = 6$，$A = 30°$，求 $B$"；典型识别词："两边一角且角不是夹角"。

**核心思路**

由正弦定理 $\dfrac{a}{\sin A} = \dfrac{b}{\sin B}$ 解出 $\sin B = \dfrac{b\sin A}{a}$。由于 $\sin$ 函数在 $(0, \pi)$ 上不单调（$\sin B$ 与 $\sin(\pi - B)$ 相等），故 $B$ 可能有两个解。需根据三角形角度约束（$A + B < \pi$）和大边对大角原则筛选。

**关键步骤**

1. 由正弦定理求 $\sin B = \dfrac{b\sin A}{a}$；
2. 验证存在性：
   - 若 $\sin B > 1$：**无解**；
   - 若 $\sin B = 1$：唯一解 $B = \dfrac{\pi}{2}$；
   - 若 $\sin B < 1$：$B$ 有两个候选 $B_1 = \arcsin(\sin B)$ 和 $B_2 = \pi - B_1$；
3. 用 $A + B < \pi$ 筛选；
4. 用大边对大角原则筛选：$a > b \Leftrightarrow A > B$。

**判别表**：

| 关系 | 解的个数 | 几何理解 |
|---|---|---|
| $a < b\sin A$ | 无解 | $a$ 太短，构不成三角形 |
| $a = b\sin A$ | 1 解（直角） | $b$ 的足恰好等于 $a$ |
| $b\sin A < a < b$ | 2 解 | 圆弧与对边交两次 |
| $a \ge b$ | 1 解 | $a$ 是大边，大边对大角 |

**示意**

```
    锐角 A 已知,  以 A 为圆心, 半径 a 画弧
    与对边 AC 的延长线交两次 → 两解（B 锐 / 钝）
   
         C
        ╱│
       ╱ │ b
      ╱  │
   A●────●────●  ← a 画弧, 与对边交两次
         B₁    B₂
   B₁ 锐角解,  B₂ = π - B₁ 钝角解
```

**典型题**

$\triangle ABC$ 中，$a = 4$，$b = 4\sqrt{3}$，$A = 30°$，求 $B$。

> **一句话指引**：$\sin B = \dfrac{b\sin A}{a} = \dfrac{4\sqrt{3} \cdot \frac{1}{2}}{4} = \dfrac{\sqrt{3}}{2}$；候选 $B = 60°$ 或 $120°$；$A + B = 30° + 60° = 90°$ 或 $30° + 120° = 150°$ 均 $< 180°$，故**两解**：$B = 60°$ 或 $B = 120°$。

**关联章节**：Part 5 / 07（解三角形）

## 模型 13：复数共轭对称

**触发条件**

题面出现"$z$ 的共轭 $\overline{z}$"、"$|z| = $"、"复数方程"等关键词；含参复数等式 $z + \overline{z} = \cdots$、$z - \overline{z} = \cdots$；判定 $z$ 是实数 / 纯虚数；求复平面对应点的轨迹。

**核心思路**

设 $z = a + bi$，把"共轭"对应"虚部取反"、"模平方"对应 $z\overline{z}$。利用 $z + \overline{z} = 2a$（实部 2 倍）、$z - \overline{z} = 2bi$（虚部 2 倍）、$z\overline{z} = |z|^2$ 三大等式快速分离实虚部。

**关键步骤**

1. 设 $z = a + bi$（$a, b \in \mathbb{R}$）；
2. 利用共轭性质化简：$z + \overline{z}, z - \overline{z}, z\overline{z}$；
3. 把题目条件转化为关于 $a, b$ 的实数方程组；
4. 注意特判：$z \in \mathbb{R} \Leftrightarrow z = \overline{z}$；$z$ 纯虚数 $\Leftrightarrow z = -\overline{z}$ 且 $z \ne 0$；
5. 几何视角：$|z - z_0| = r$ 是以 $z_0$ 为圆心、$r$ 为半径的圆。

**示意**

```
       虚轴
        │   ●(a, b) = z
        │ ╱
        │╱ |z|
     ───●──────→ 实轴
        │╲
        │ ╲
        │   ●(a, -b) = z̄

   z + z̄ = 2a (实轴投影 ×2)
   z - z̄ = 2bi
   z·z̄ = |z|² = a² + b²
```

**典型题**

设复数 $z$ 满足 $z + 2\overline{z} = 3 - i$，求 $z$。

> **一句话指引**：设 $z = a + bi$，则 $z + 2\overline{z} = 3a - bi = 3 - i$；比较实虚部得 $a = 1, b = 1$；$z = 1 + i$。

## 模型 14：散点图 + 最小二乘 + 残差

**触发条件**

题面给出一组成对样本数据 $(x_i, y_i)$，要求作散点图、判断是否线性相关、写出回归方程 $\hat{y} = \hat{b}x + \hat{a}$、用回归方程预测某值；考察相关系数 $r$、残差 $e_i$、决定系数 $R^2$。

**核心思路**

最小二乘法找到使"误差平方和" $\sum (y_i - \hat{y}_i)^2$ 最小的直线。回归直线**必过样本中心** $(\bar{x}, \bar{y})$。残差越小、$R^2$ 越接近 1，拟合越好。

**关键步骤**

1. 算 $\bar{x}, \bar{y}$ 与各自方差、协方差；
2. 求斜率 $\hat{b} = \dfrac{\sum x_i y_i - n\bar{x}\bar{y}}{\sum x_i^2 - n\bar{x}^2}$；
3. 求截距 $\hat{a} = \bar{y} - \hat{b}\bar{x}$，写出回归直线；
4. 代入 $x_0$ 预测 $\hat{y}_0$；
5. 算残差 $e_i = y_i - \hat{y}_i$、残差平方和、$R^2$ 评估拟合度。

**示意**

```
   y │       ●         ●
     │       │       ╱
     │       │ e   ╱
     │   ●───┤   ╱  ŷ = b̂x + â
     │   ╱   │ ╱     (过 (x̄, ȳ))
     │ ╱     ●
     │●  e   │
     ●───────┼──────→ x
            x̄
   残差 e = y - ŷ; 平方和最小即最佳拟合
```

**典型题**

某变量 $x$ 与 $y$ 的 5 组数据 $\bar{x} = 3, \bar{y} = 7$，$\hat{b} = 1.5$，求回归方程，并预测 $x = 4$ 时 $\hat{y}$。

> **一句话指引**：$\hat{a} = 7 - 1.5 \times 3 = 2.5$；回归方程 $\hat{y} = 1.5 x + 2.5$；$x = 4$ 时 $\hat{y} = 8.5$。

## 模型 15：独立 vs 互斥辨析

**触发条件**

题面同时出现两个事件 $A, B$，需要判定它们是"独立""互斥""对立"还是其他关系；问"若 $A, B$ 独立则 $P(AB) = ?$"、"互斥则 $P(A \cup B) = ?$"；混淆"独立 = 互斥"的题型设置陷阱。

**核心思路**

**独立 → 互不影响概率**（数值关系）；**互斥 → 不能同时发生**（事件关系）。一般情况下两者**不重合**：若 $P(A), P(B) > 0$，独立则不互斥，互斥则不独立。

**关键步骤**

1. 仔细阅读题目，识别事件 $A, B$ 是否"互不影响"或"不能同时发生"；
2. 算 $P(AB)$ 与 $P(A) \cdot P(B)$ 比较：相等 → 独立；
3. 算 $P(AB)$ 是否为 $0$：是 → 互斥；
4. 写概率公式时分清两种情况：
   - 独立 → $P(AB) = P(A)P(B)$，$P(A \cup B) = P(A) + P(B) - P(A)P(B)$；
   - 互斥 → $P(AB) = 0$，$P(A \cup B) = P(A) + P(B)$；
5. 多事件独立时，**任意子集**事件也独立（不仅是两两独立）。

**示意**

```
   样本空间 Ω
   ┌─────────────────────────┐
   │     ┌────A────┐         │  独立: P(AB) = P(A)P(B)
   │     │  ┌──AB──┐ ┌──B──┐ │  (重叠面积按概率乘法分配)
   │     │  │      │ │     │ │
   │     │  └──────┘ │     │ │  互斥: AB = ∅
   │     └──────────┘└─────┘ │  (两圆不重叠)
   └─────────────────────────┘
   
   一般 P(A), P(B) > 0:
   独立 ⇒ 不互斥;  互斥 ⇒ 不独立
```

**典型题**

抛一枚均匀硬币 2 次，$A = $ 第 1 次正面，$B = $ 第 2 次正面。问 $A, B$ 独立还是互斥？

> **一句话指引**：$P(A) = P(B) = \dfrac{1}{2}$，$P(AB) = \dfrac{1}{4} = P(A)P(B)$ → **独立**；$AB \ne \varnothing$（两次都正面是可能的）→ **不互斥**。

**关联章节**：Part 8 / 03（独立性）

## 模型 16：贝叶斯反演（医学检验经典）

**触发条件**

题面给出"先验概率" $P(A_i)$ 与"条件概率" $P(B|A_i)$（如疾病发病率、检验灵敏度），要求"已知检验结果 $B$，反推患病概率 $P(A_k | B)$"；典型词汇："试剂阳性"、"已知考试通过反推认真复习概率"。

**核心思路**

把全概率公式与贝叶斯公式联用：先用全概率算 $P(B)$，再用贝叶斯算 $P(A_k | B)$。注意**先验概率的影响**——即使灵敏度高、若发病率极低，阳性结果仍可能更多源自健康人。

**关键步骤**

1. 设 $A_1, A_2, \ldots$ 为原因 / 类别（如"患病""未患病"），$B$ 为结果（如"阳性"）；
2. 列出先验：$P(A_i)$；
3. 列出条件：$P(B|A_i)$；
4. **全概率**算分母：$P(B) = \sum P(A_i) P(B|A_i)$；
5. **贝叶斯**算条件后验：$P(A_k | B) = \dfrac{P(A_k) P(B | A_k)}{P(B)}$。

**示意**

```
   原因 / 类别       结果
        ┌── P(B|A₁) ──→ B
   A₁ ──┤
        └── P(B̄|A₁) ─→ B̄
        ┌── P(B|A₂) ──→ B
   A₂ ──┤
        └── P(B̄|A₂) ─→ B̄
   
   "全概率"= 把所有到达 B 的路径概率相加
   "贝叶斯"= 你想要的那条路径 / 全部路径
```

**典型题**

某疾病发病率 $0.1\%$；试剂阳性率：患病者 $99\%$、未患病者 $5\%$。某人检测阳性，问真患病概率。

> **一句话指引**：$P(\text{患}) = 0.001$，$P(\text{阳} | \text{患}) = 0.99$，$P(\text{阳} | \text{未}) = 0.05$；$P(\text{阳}) = 0.001 \times 0.99 + 0.999 \times 0.05 \approx 0.051$；$P(\text{患} | \text{阳}) = \dfrac{0.001 \times 0.99}{0.051} \approx 1.94\%$。即使阳性仍不到 $2\%$，**先验占主导**。

**关联章节**：Part 8 / 05（贝叶斯与全概率）

## 模型 17：等差数列 $S_n$ 二次函数判据

**触发条件**

题面给出 $S_n = An^2 + Bn$（或 $S_n = An^2 + Bn + C$）形式，判断 $\{a_n\}$ 是否等差；已知 $S_n$ 求 $a_n$ 通项；含参 $S_n$ 求参数使 $\{a_n\}$ 等差。

**核心思路**

**核心判据**：$\{a_n\}$ 是等差数列 $\Leftrightarrow S_n$ 是关于 $n$ 的**无常数项**的二次函数（即 $S_n = An^2 + Bn$，$C = 0$）。利用 $a_n = S_n - S_{n-1}$ 求通项，**特别注意 $n = 1$ 单独验证**。

**关键步骤**

1. 若 $S_n = An^2 + Bn + C$，先看 $C$：$C = 0$ → 通项是等差；$C \ne 0$ → 不是等差（但从第 2 项开始可能是）；
2. 通项分段：$a_1 = S_1$；$a_n = S_n - S_{n-1}$（$n \ge 2$）；
3. 验证 $n = 1$ 是否符合通式：是 → 合并为统一公式；否 → 分段写；
4. 求出公差 $d = 2A$（$A$ 是 $n^2$ 系数）；
5. 含参时，让 $C = 0$（即 $S_n$ 无常数项）解出参数。

**示意**

```
   S_n = A n² + B n  (无常数项)
                     ↓
                等差数列, d = 2A
   
       Sₙ │           ●
          │        ●  
          │     ● 
          │  ●      抛物线状,
          ●─────────过原点 (n=0 时 S₀=0)
          0  1  2  3  4   n
   
   通项 aₙ = Sₙ - Sₙ₋₁ = 2An + (B - A)
   首项 a₁ = A + B,  公差 d = 2A
```

**典型题**

数列 $\{a_n\}$ 前 $n$ 项和 $S_n = 3n^2 - 2n$，求通项。

> **一句话指引**：$C = 0$ → 等差。$a_n = S_n - S_{n-1} = 6n - 5$（$n \ge 2$）；$a_1 = S_1 = 1 = 6 \times 1 - 5$ → 符合通式；故 $a_n = 6n - 5$（$n \ge 1$）。公差 $d = 6$。

**关联章节**：Part 9 / 02（等差数列）、Part 9 / 01（通项与 $S_n$ 关系）

## 模型 18：错位相减

**触发条件**

求形如 $\sum_{k=1}^n k \cdot q^k$ 或 $\sum (an + b) \cdot q^k$ 类"等差 × 等比"复合数列的和；典型识别词："$a_n b_n$ 求和" 其中 $\{a_n\}$ 等差、$\{b_n\}$ 等比。

**核心思路**

记 $T_n = \sum a_k b_k$（$a$ 等差、$b$ 等比公比 $q$）。**两边同乘 $q$**，错位**相减**消去等差部分，留下等比求和。

**关键步骤**

1. 写出 $T_n = a_1 b_1 + a_2 b_2 + \cdots + a_n b_n$；
2. 两边乘 $q$：$qT_n = a_1 b_2 + a_2 b_3 + \cdots + a_n b_{n+1}$；
3. 两式相减（**错位对齐**）：$T_n - qT_n$ 中间项化为等差公差 $d \cdot$ 等比和；
4. 整理：$(1 - q) T_n = a_1 b_1 - a_n b_{n+1} + d \sum_{k=2}^n b_k$；
5. 解出 $T_n$；**单独验证 $q = 1$ 与 $n = 1$**。

**示意**

```
   T_n  =     a₁b₁  + a₂b₂ + a₃b₃ + ... + aₙbₙ
   qT_n =              a₁b₂ + a₂b₃ + ... + aₙ₋₁bₙ + aₙbₙ₊₁
   
   两式错位排列后相减:
   T_n - qT_n = a₁b₁ + d·(b₂ + b₃ + ... + bₙ) - aₙbₙ₊₁
                ↑     ↑                        ↑
              首项   等差公差×等比和         尾项
```

**典型题**

求和 $S_n = 1 \cdot 2 + 2 \cdot 2^2 + 3 \cdot 2^3 + \cdots + n \cdot 2^n$。

> **一句话指引**：$a_n = n$（等差，$d=1$），$b_n = 2^n$（等比，$q=2$）。$2S_n = 1 \cdot 2^2 + 2 \cdot 2^3 + \cdots + n \cdot 2^{n+1}$；$S_n - 2S_n = 2 + 2^2 + \cdots + 2^n - n \cdot 2^{n+1} = 2^{n+1} - 2 - n \cdot 2^{n+1}$；$-S_n = (1 - n) \cdot 2^{n+1} - 2$；$S_n = (n - 1) \cdot 2^{n+1} + 2$。

**关联章节**：Part 9 / 05（数列求和）

## 模型 19：导数 4 步求单调

**触发条件**

求函数 $f(x)$ 的单调区间；判定 $f$ 在某区间是否单调；含参函数求使 $f$ 在指定区间单调的参数范围。

**核心思路**

求导 → 解不等式 → 与定义域取交 → 写区间。**写区间不能用 $\cup$**，多个区间用 "和" 连接（因为单调性在每个区间内部独立成立）。

**关键步骤**

1. **求导**：写出 $f'(x)$，化为乘积或分式形式；
2. **解不等式**：分别解 $f'(x) > 0$ 与 $f'(x) < 0$；
3. **取交集**：与 $f(x)$ 的定义域取交；
4. **写区间**：增 / 减区间分别列出，多区间用 "和"、不用 $\cup$。

**含参情形**：分类讨论参数对 $f'(x)$ 符号的影响（如系数正负、判别式 $\Delta$ 与 $0$ 的关系、根的位置）。

**示意**

```
   f'(x)          + + + + + - - - - + + + + +
                  ↓         ↓        ↓
   单调性         增        减       增
   
   ─────●─────────●─────────●─────────●────→ x
       a₁         x₁        x₂         a₂
   
   增区间: (a₁, x₁) 和 (x₂, a₂)  ← 不写 ∪
   减区间: (x₁, x₂)
```

**典型题**

求 $f(x) = x^3 - 3x^2 + 1$ 的单调区间。

> **一句话指引**：$f'(x) = 3x^2 - 6x = 3x(x - 2)$。$f' > 0 \Leftrightarrow x < 0$ 或 $x > 2$（增）；$f' < 0 \Leftrightarrow 0 < x < 2$（减）；增区间 $(-\infty, 0)$ 和 $(2, +\infty)$，减区间 $(0, 2)$。

**关联章节**：Part 10 / 02（导数运算）、Part 10 / 03（单调性）

## 模型 20：构造法证不等式

**触发条件**

证明不等式 $f(x) > g(x)$（或 $\ge$）在区间 $I$ 上恒成立；证 $\ln(1+x) < x$、$e^x > 1 + x$ 之类的"砖头不等式"；变量较多时构造一元辅助函数 $h(x) = f(x) - g(x)$。

**核心思路**

把"不等式"转化为"**单变量函数 $h(x) = f(x) - g(x)$ 在区间上的最值 $\ge 0$**"——这是导数处理不等式的核心套路。

**关键步骤**

1. **构造**：令 $h(x) = f(x) - g(x)$（移项使一边为 0）；
2. **求导**：写 $h'(x)$，化为可判号的形式；
3. **判单调**：解 $h'(x)$ 的符号，得 $h$ 的单调区间；
4. **找极值 / 端点**：定位 $h$ 在 $I$ 上的最小值点 $x_0$；
5. **算端点值**：验证 $h(x_0) \ge 0$（或 $> 0$），结合单调性得不等式成立。

**示意**

```
   待证: f(x) > g(x)  在 (a, b) 上恒成立
                       ↓ 构造
   h(x) = f(x) - g(x)
                       ↓ 求导
   h'(x) 在 (a, b) 内的符号
                       ↓
   h 单调性 + 端点 h(a) (或极小值 h(x₀))
                       ↓
   若 min h ≥ 0 → 不等式成立
   
       h(x)
        │  ╲     ╱
        │   ╲   ╱
        │    ╲ ╱
       ─┼─────●─────→ x
        │   min ≥ 0 即可
```

**典型题**

证：当 $x > 0$ 时，$e^x > 1 + x$。

> **一句话指引**：令 $h(x) = e^x - 1 - x$，$h'(x) = e^x - 1 > 0$（$x > 0$）→ $h$ 在 $(0, +\infty)$ 上单调递增；$h(0) = 0$；故 $x > 0$ 时 $h(x) > 0$，即 $e^x > 1 + x$。

**关联章节**：Part 10 / 07（导数应用）、Part 13 / 04（不等式证明）

## 模型 21：闭区间最值候选集

**触发条件**

求 $f(x)$ 在闭区间 $[a, b]$ 上的最大值 / 最小值；含参函数在闭区间上的最值问题；求值域。

**核心思路**

闭区间上**连续**函数的最值只可能在以下三类点取得：**驻点**（$f' = 0$）、**不可导点**、**端点**。把所有候选点的函数值算出来比较。

**关键步骤**

1. **找驻点**：解 $f'(x) = 0$ 在 $[a, b]$ 内的所有根 $x_1, x_2, \ldots$；
2. **找不可导点**：检查 $f'(x)$ 在 $[a, b]$ 内是否有间断点；
3. **算端点**：$f(a), f(b)$；
4. **比较所有候选值**：$\{f(x_1), f(x_2), \ldots, f(a), f(b), \ldots\}$；
5. **最大者**为最大值，**最小者**为最小值。

**含参情形**：讨论驻点是否落在区间内，分多种情形讨论。

**示意**

```
   闭区间 [a, b] 上的连续函数最值
   
      f(x) │      ●极大
           │   ╱ ╲ 
           │  ╱   ╲    ●端点b
           │ ╱     ╲  ╱
           ●端点a   ╲╱
           │      ●极小
           ────────────→ x
           a  x₁  x₂  b
   
   候选集 = {f(a), f(x₁), f(x₂), f(b)}  ← 4 个候选
   最大值 = max(候选集);  最小值 = min(候选集)
```

**典型题**

求 $f(x) = x^3 - 3x$ 在 $[-2, 3]$ 上的最值。

> **一句话指引**：$f'(x) = 3x^2 - 3 = 0 \Rightarrow x = \pm 1$（均在区间内）；候选 $f(-2) = -2$，$f(-1) = 2$，$f(1) = -2$，$f(3) = 18$；最大值 $18$（在 $x = 3$），最小值 $-2$（在 $x = -2$ 或 $x = 1$）。

**关联章节**：Part 10 / 04（极值与最值）

## 模型 22：二项式定理通项 $T_{k+1}$

**触发条件**

求 $(a + b)^n$ 展开式中某一项、某项系数、含 $x^k$ 项；求特定项的二项系数；通项分析（中间项最大、系数最大项）；展开式系数和 / 二项系数和。

**核心思路**

牢记通项公式 $T_{k+1} = C_n^k a^{n-k} b^k$（**第 $k+1$ 项对应 $C_n^k$**）。求"含 $x^m$ 项"时，把 $a, b$ 中的 $x$ 项收集起来，令幂次等于 $m$ 解 $k$。

**关键步骤**

1. **写通项**：$T_{k+1} = C_n^k a^{n-k} b^k$；
2. **化简幂次**：把 $x$ 的次方整理为 $x^{f(k)}$ 形式；
3. **解 $k$**：令 $f(k) = m$（题目要求的幂次），解出 $k$；
4. **代入**：把 $k$ 代回通项，算出具体的项 / 系数。

**辅助技巧**：
- **二项系数和**：$\sum_{k=0}^n C_n^k = 2^n$（令 $a = b = 1$）；
- **系数和**：令 $x = 1$ 代入原展开式；
- **奇偶项分**：令 $x = -1$ 代入，再与 $x = 1$ 联立。

**示意**

```
   (a + b)ⁿ = Σ Cₙᵏ a^(n-k) b^k    ← 通项 T_{k+1}
              k=0
   
   通项编号  T₁ = Cₙ⁰ aⁿ
            T₂ = Cₙ¹ aⁿ⁻¹ b
            T₃ = Cₙ² aⁿ⁻² b²
            ...
            T_{k+1} = Cₙᵏ a^(n-k) bᵏ   ← 注意 +1 偏移
   
   求含 xᵐ 项: 令幂次方程 → 解 k → 代回
```

**典型题**

求 $(x - \dfrac{1}{x})^{10}$ 展开式中 $x^4$ 项的系数。

> **一句话指引**：$T_{k+1} = C_{10}^k x^{10-k} (-1/x)^k = C_{10}^k (-1)^k x^{10 - 2k}$；令 $10 - 2k = 4 \Rightarrow k = 3$；系数 $C_{10}^3 (-1)^3 = -120$。

**关联章节**：Part 11 / 04（二项式定理）

## 模型 23：二项 / 超几何 / 正态选择树

**触发条件**

题面给出"$n$ 次试验"、"抽取 $n$ 件"、"测量值近似正态分布"等场景；要求识别分布类型并计算概率 / 期望 / 方差。

**核心思路**

按"有放回 / 不放回 / 连续 / 离散"四象限快速识别分布类型。每种分布有**固定的 $E, D$ 公式**，识别准了直接套。

**选择树**

```
                    随机变量 X
                       │
            ┌──────────┴──────────┐
         离散                   连续
            │                     │
   ┌────────┴────────┐         正态分布
   有放回         不放回         N(μ, σ²)
   独立同分布     总体有限     E = μ, D = σ²
      │              │         3σ 法则
   二项分布      超几何分布
   B(n, p)       (N, M, n)
   E = np        E = nM/N
   D = np(1-p)   D 较复杂
```

**关键步骤**

1. 读题：判定试验类型（次数、有无放回、是否连续）；
2. 选择分布：
   - **有放回 / 独立**：$X \sim B(n, p)$；
   - **不放回**：$X \sim H(N, M, n)$（超几何）；
   - **连续测量值**：$X \sim N(\mu, \sigma^2)$；
3. 直接套 $E, D$ 公式；
4. 正态分布利用 **3σ 法则**和**对称性**算概率。

**典型题**

100 件产品有 5 件次品，从中**不放回**抽 10 件，记次品数 $X$。求 $E(X)$。

> **一句话指引**：不放回 → 超几何 $H(100, 5, 10)$；$E(X) = \dfrac{nM}{N} = \dfrac{10 \times 5}{100} = 0.5$。

**关联章节**：Part 12 / 02-04（三大典型分布）

## 模型 24：决策 $E$ vs $D$

**触发条件**

题面给出两种方案（投资 / 抽奖 / 答题策略）的概率分布，要求"哪种方案更好"；含"风险"、"稳定"、"保守"、"进取"等词汇。

**核心思路**

**两层比较**：
- **第一层**：比 $E(X)$，期望大者收益高（首要考虑）；
- **第二层**（期望相同或相近时）：比 $D(X)$ 或 $\sigma(X)$，方差小者**风险低、更稳定**。

风险偏好：进取型 → 选大 $E$；保守型 → 在 $E$ 相近时选小 $D$。

**关键步骤**

1. **列分布表**：写出两个方案的概率分布；
2. **算 $E$**：分别算 $E(X_1), E(X_2)$；
3. **比较 $E$**：若 $E$ 差距大，直接选大者；
4. **若 $E$ 相近**：算 $D(X_1), D(X_2)$；
5. **结合题意**：稳定性 / 风险偏好做最终决策。

**示意**

```
   方案 A: E = 10, D = 4   ← 收益稳定
   方案 B: E = 10, D = 16  ← 收益波动大
   
   E 相同 ⇒ 比 D
   保守 → 选 A (D 小、风险低)
   进取 → 选 B (有机会赌大数额)
   
        方案 A         方案 B
        peak           peak
       ╱   ╲          ╱       ╲    ← 同峰高但 B 更宽
      ╱     ╲        ╱         ╲
     ╱       ╲      ╱           ╲
    ─●───●───●─    ●─────●─────●─
    8   10  12     5    10    15
```

**典型题**

A、B 两种投资期望收益均为 $10$ 万元，方差分别为 $D_A = 4$、$D_B = 16$。问保守投资者应选哪种？

> **一句话指引**：$E$ 相等 → 比 $D$；$D_A < D_B$ → A 方案波动小、风险低；**保守投资者选 A**。

**关联章节**：Part 12 / 05（期望与方差）、Part 13 / 06（概率综合）
