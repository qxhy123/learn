# 附录 B：高一上代数模型图集

> 高一上代数（Part 1–5）共 12 个核心套路模型。每个模型包含触发条件、核心思路、关键步骤、示意图、典型题与关联章节。配合附录 A 公式表可快速识别题型。

## 模型 1：集合 Venn 图与运算

**触发条件**

题面出现 $A \cap B$、$A \cup B$、$\complement_U A$、"两条件均成立"、"满足其一即可"、"既不属于…也不属于"等关键词；含参集合的子集 / 相等 / 不相交关系；已知元素个数求范围。

**核心思路**

把每个集合画成一个圆，全集画一个矩形包住它们，按运算图标记阴影区域。复杂运算（如 $\complement_U(A \cup B)$）一律先画好图、再读出对应区域。

**关键步骤**

1. 画矩形 $U$，在其中画 $A$、$B$ 两圆，三种区域 $A \setminus B$、$A \cap B$、$B \setminus A$ 都标出；
2. 把题目所求的运算翻译成 Venn 图阴影区（如 $\complement_U(A \cup B)$ 是 $U$ 减去两圆并集）；
3. 把已知元素或区间填入对应区，逐个检验是否符合条件；
4. 若含参数（如 $A \cap B = A$），转化为子集关系 $A \subseteq B$，再分类讨论 $A = \varnothing$ 与 $A \ne \varnothing$。

**示意（ASCII）**

```
+----------- U -----------+
|     +------+            |
|     |  A   |  +------+  |
|     |   +--+--+  B   |  |
|     |   |  | A∩B  |  |  |
|     |   +--+--+      |  |
|     +------+  +------+  |
|                         |
+-------------------------+
```

**典型题**

已知 $A = \{x \mid 1 \le x \le 3\}$，$B = \{x \mid x \ge a\}$，若 $A \cap B = A$，求 $a$ 的取值范围。

> **一句话指引**：$A \cap B = A \Leftrightarrow A \subseteq B$；要 $A$ 完全装进 $B$，即 $a \le 1$。

**关联章节**：Part 1 / 01–03（集合基础、集合运算、子集幂集）

## 模型 2：一元二次不等式三态判别

**触发条件**

题面是 $ax^2 + bx + c > 0$（或 $\ge 0, < 0, \le 0$）形式；或含参 $kx^2 + \cdots$ 类题面需要"恒成立"、"有解"判定；最终目标是求解集或求参数范围。

**核心思路**

先把 $a$ 化为正系数（必要时两边乘 $-1$ 并翻转不等号），算 $\Delta$，按三种情形画抛物线，**用图象的"轴上方 / 轴下方"读解集**。

**关键步骤**

1. 化标准：使 $a > 0$；
2. 求 $\Delta = b^2 - 4ac$；
3. 分三态：
   - $\Delta > 0$：两根 $x_1 < x_2$，$> 0$ 取"两根之外"，$< 0$ 取"两根之间"；
   - $\Delta = 0$：重根 $x_0$，$> 0$ 为 $\mathbb{R} \setminus \{x_0\}$，$< 0$ 为 $\varnothing$；
   - $\Delta < 0$：无实根，$> 0$ 为 $\mathbb{R}$，$< 0$ 为 $\varnothing$；
4. 端点取舍：含 $=$ 时端点取，否则不取。

**示意**

```
   a>0, Δ>0      a>0, Δ=0      a>0, Δ<0
     ∪              ∪              ∪
   /   \          /   \          /   \
--*-----*--    --*--------    -----------
  x₁    x₂      x₀
> 0 在外      > 0 除 x₀ 外    > 0 处处成立
< 0 在内      < 0 无解        < 0 无解
```

**典型题**

解不等式 $-2x^2 + 5x - 3 \ge 0$。

> **一句话指引**：两边乘 $-1$ 翻转：$2x^2 - 5x + 3 \le 0$；$\Delta = 25 - 24 = 1$，根为 $1, \dfrac{3}{2}$；解集 $\left[1, \dfrac{3}{2}\right]$。

**关联章节**：Part 2 / 02（一元二次不等式）

## 模型 3：分式不等式标轴法（穿针引线）

**触发条件**

题面含分式 $\dfrac{f(x)}{g(x)} \gtrless 0$，或可化为分式形式（如 $\dfrac{1}{x - 1} > 2$ 需移项通分）；分子分母均可因式分解为一次或二次因子。

**核心思路**

将分式不等式等价转化为乘积不等式 $f(x) \cdot g(x) \gtrless 0$（同时保留 $g \ne 0$ 约束），把所有零点（根）标在数轴上，从最右上角开始"穿针引线"，遵循"**奇穿偶不穿**"。

**关键步骤**

1. 移项化为 $\dfrac{f(x)}{g(x)} \gtrless 0$ 标准形式（一边为零）；
2. 分子分母**各自因式分解**为一次因式；
3. 把所有根标在数轴上（含奇偶重数）；
4. 从最右上方画曲线穿过最右根（奇穿、偶不穿），依次穿过所有根；
5. 取曲线在上方部分（$> 0$）或下方部分（$< 0$），最后去掉使分母为零的点。

**示意**

```
   求 (x-1)(x-2) / (x-3) > 0
   
     -∞    1    2    3    +∞
      ──●────●────●────
        ↓    ↑    ↓
        从右上方进入，奇次根穿过，偶次根反弹
   
   解集：(1, 2) ∪ (3, +∞)
```

**典型题**

解不等式 $\dfrac{x - 1}{x + 2} \ge 0$。

> **一句话指引**：等价于 $(x-1)(x+2) \ge 0$ 且 $x \ne -2$；零点 $-2, 1$，穿针得 $x \le -2$ 或 $x \ge 1$；排除 $x = -2$：$x < -2$ 或 $x \ge 1$。

**关联章节**：Part 2 / 03（分式不等式）

## 模型 4：基本不等式"和定积大、积定和小"

**触发条件**

题面给定 $a + b = $ 定值或 $ab = $ 定值（或可整理成此结构），要求 $ab$ 最大值或 $a + b$ 最小值；含 $\dfrac{1}{a} + \dfrac{1}{b}$ 之类倒数和；"分式与一次式之和"的最值（如 $x + \dfrac{1}{x}$）。

**核心思路**

识别"和定 / 积定"结构后，套用 $a + b \ge 2\sqrt{ab}$；先验 **"一正二定三相等"** 三个前提，再写最值与等号条件。

**关键步骤**

1. 把目标整理为 $a + b$ 或 $ab$ 的形式（必要时用换元、配凑系数）；
2. 验证 $a, b > 0$（一正）；
3. 验证另一个量是定值（二定）；
4. 验证等号 $a = b$ 在定义域内可取（三相等）；
5. 等号成立时计算最值。

**示意**

```
   和定 a+b=S → ab ≤ (S/2)² = S²/4
   积定 ab=P → a+b ≥ 2√P
   
        ab
         │     峰值 S²/4
         │      ▲
         │    ╱ │ ╲
         │  ╱   │   ╲
         │╱   a=b=S/2 ╲
       ──┼─────────────→ a
              S/2          S
```

**典型题**

已知 $x > 0$，$y > 0$，且 $x + 2y = 1$，求 $\dfrac{1}{x} + \dfrac{1}{y}$ 的最小值。

> **一句话指引**：$\dfrac{1}{x} + \dfrac{1}{y} = (x + 2y)\left(\dfrac{1}{x} + \dfrac{1}{y}\right) = 3 + \dfrac{2y}{x} + \dfrac{x}{y} \ge 3 + 2\sqrt{2}$，等号当 $\dfrac{2y}{x} = \dfrac{x}{y}$ 即 $x = \sqrt{2} y$ 时取。

**关联章节**：Part 2 / 04（基本不等式）

## 模型 5：复合函数单调性"同增异减"

**触发条件**

函数形如 $y = f(g(x))$（外层 $f$，内层 $g$）；题目问复合函数的单调区间、是否单调；或已知一个单调性反推另一个的单调性。

**核心思路**

记内层 $u = g(x)$ 在区间 $I$ 上的单调性 $\sigma_g$，外层 $y = f(u)$ 在 $g(I)$ 上的单调性 $\sigma_f$；复合的单调性 $= \sigma_g \times \sigma_f$（增 $\times$ 增 $=$ 增，减 $\times$ 减 $=$ 增，增 $\times$ 减 $=$ 减）。**"同增异减"**。

**关键步骤**

1. 分解 $y = f(g(x))$ 为外层 $y = f(u)$ 与内层 $u = g(x)$；
2. 求内层 $u = g(x)$ 在定义域上的单调区间与值域；
3. 在内层值域上判断外层 $f(u)$ 的单调性；
4. 用"同增异减"得到复合函数在内层每个单调区间上的单调性。

**示意**

```
  内层 g(x)   外层 f(u)   复合 f(g(x))
   增           增          增  ↑↑
   增           减          减  ↑↓
   减           增          减  ↓↑
   减           减          增  ↓↓
   
   口诀：同方向→增，反方向→减
```

**典型题**

判断 $y = \log_{1/2}(x^2 - 4x + 3)$ 的单调区间。

> **一句话指引**：内层 $u = x^2 - 4x + 3$ 定义域 $x < 1$ 或 $x > 3$（保真数正），在 $x < 1$ 上减、$x > 3$ 上增；外层 $\log_{1/2} u$ 减；同增异减：$x < 1$（减 × 减 = 增）、$x > 3$（增 × 减 = 减）。

**关联章节**：Part 3 / 03（单调性）、Part 3 / 06（复合函数）

## 模型 6：奇偶性与图象对称

**触发条件**

题目出现 $f(-x) = f(x)$、$f(-x) = -f(x)$、"$f$ 的图象关于 $y$ 轴 / 原点对称"；或求带参函数 $f(x) = ax^3 + bx + c$ 为奇函数时的 $c$；或给定一半图象画另一半。

**核心思路**

奇 ↔ 中心对称（原点）；偶 ↔ 轴对称（$y$ 轴）。先验**定义域关于原点对称**（必要条件），再代入 $f(-x)$ 比较。

**关键步骤**

1. 写出函数定义域，检查是否关于 $0$ 对称；不对称直接判非奇非偶；
2. 计算 $f(-x)$ 表达式；
3. 比较 $f(-x)$ 与 $f(x)$：
   - $f(-x) = f(x)$ → 偶函数；
   - $f(-x) = -f(x)$ → 奇函数；
   - 两者均不成立 → 非奇非偶；
4. 利用奇函数 $f(0) = 0$（若 $0 \in$ 定义域）求参数。

**示意**

```
   偶函数（关于 y 轴对称）       奇函数（关于原点对称）
        │                                │
        │  ╲    ╱                       ╱ │
        │   ╲  ╱                       ╱  │
   ─────┼────●────         ───────────●───┼──────
        │   ╱  ╲                  ╱    │
        │  ╱    ╲                ╱     │
        │                              │
   f(-x) = f(x)                  f(-x) = -f(x)
   左右映像                       中心翻转
```

**典型题**

判断 $f(x) = \dfrac{2^x - 1}{2^x + 1}$ 的奇偶性。

> **一句话指引**：定义域 $\mathbb{R}$ 对称；$f(-x) = \dfrac{2^{-x} - 1}{2^{-x} + 1} = \dfrac{1 - 2^x}{1 + 2^x} = -f(x)$；奇函数。

**关联章节**：Part 3 / 04（奇偶性）

## 模型 7：含参一元二次方程根的分布

**触发条件**

题目形如"方程 $ax^2 + bx + c = 0$ 有两个正根 / 两负根 / 一正一负 / 两根都在区间 $(m, n)$ 内 / 一根在区间内一根在区间外"；含参数 $k$ 在系数中。

**核心思路**

把含参一元二次方程视为二次函数 $f(x) = ax^2 + bx + c$ 与 $x$ 轴的交点问题。结合判别式 $\Delta$、对称轴位置 $x = -\dfrac{b}{2a}$、区间端点值 $f(m), f(n)$ 的符号，写出不等式组。

**关键步骤**

1. 设 $f(x) = ax^2 + bx + c$（假定 $a > 0$，否则乘 $-1$）；
2. 写下 $\Delta \ge 0$（有实根的前提）；
3. 按题目要求的根分布画图：
   - **两正根**：$\Delta \ge 0$，对称轴 $-\dfrac{b}{2a} > 0$，$f(0) > 0$；
   - **两负根**：$\Delta \ge 0$，对称轴 $-\dfrac{b}{2a} < 0$，$f(0) > 0$；
   - **一正一负**：$f(0) < 0$（与判别式自动满足）；
   - **两根都在 $(m, n)$ 内**：$\Delta \ge 0$，对称轴 $m < -\dfrac{b}{2a} < n$，$f(m) > 0$，$f(n) > 0$；
   - **一根在 $(m, n)$ 内、一根在外**：$f(m) \cdot f(n) < 0$；
4. 联立不等式组求参数范围。

**示意**

```
  两正根                两负根              一正一负
     ∪                    ∪                 ∪
   ╱   ╲                ╱   ╲             ╱   ╲
──●─●───            ──●─●──●            ─●────●─
0 x₁ x₂            x₁ x₂  0            x₁ 0  x₂
f(0)>0,对称轴>0    f(0)>0,对称轴<0     f(0)<0
```

**典型题**

方程 $x^2 - mx + m + 3 = 0$ 的两实根都在区间 $(2, 4)$ 内，求 $m$ 的取值范围。

> **一句话指引**：设 $f(x) = x^2 - mx + m + 3$（$a = 1 > 0$）。联立四条件：
> - $\Delta = m^2 - 4(m + 3) \ge 0 \Rightarrow m \le -2$ 或 $m \ge 6$；
> - 对称轴 $\dfrac{m}{2} \in (2, 4) \Rightarrow 4 < m < 8$；
> - $f(2) = 7 - m > 0 \Rightarrow m < 7$；
> - $f(4) = 19 - 3m > 0 \Rightarrow m < \dfrac{19}{3}$。
>
> 取交集得 $m \in [6, \dfrac{19}{3})$。

**关联章节**：Part 3 综合（结合 Part 2 / 02 二次不等式）

## 模型 8：指数 / 对数函数 $a > 1$ 与 $0 < a < 1$ 对比

**触发条件**

题面涉及 $a^x$、$\log_a x$ 中底数 $a$ 含参未明确大小；或要比较 $a^{f(x)} > a^{g(x)}$、$\log_a f(x) > \log_a g(x)$ 等不等式；或讨论指对函数单调性。

**核心思路**

指 / 对数函数的单调性方向**完全由底数 $a$ 决定**：$a > 1$ 时增、$0 < a < 1$ 时减。题中底数不明时**必须双向讨论**。

**关键步骤**

1. 识别底数 $a$ 是否含参或不明大小；
2. 分两类讨论：
   - **$a > 1$ 情形**：函数单调递增；同底比较时"不等号同向"；
   - **$0 < a < 1$ 情形**：函数单调递减；同底比较时"不等号方向翻转"；
3. 在每类下解不等式，注意真数 $> 0$ 的定义域约束；
4. 综合两类结果。

**示意**

```
  指数函数 y = aˣ
    a > 1  (递增)        0 < a < 1  (递减)
        │                      │
        │   ╱                  │ ╲
        │  ╱                   │  ╲
       1┼─                    1┼─●╲
        │                      │   ╲
   ─────●─────            ─────●─────
        0                      0
   
  对数函数 y = logₐ x  (与指数关于 y=x 对称)
    a > 1  (递增)        0 < a < 1  (递减)
        │  ╱                  │ ╲
        │ ╱                   │  ╲
   ─────●●────           ──●──●────
        │1                    │1 ╲
        │                     │   ╲
```

**典型题**

解不等式 $\log_a(2x - 1) > \log_a(x + 3)$（$a > 0, a \ne 1$）。

> **一句话指引**：先要求 $2x - 1 > 0, x + 3 > 0$ 得 $x > \dfrac{1}{2}$。分情况：$a > 1$ 时 $2x - 1 > x + 3$ 得 $x > 4$；$0 < a < 1$ 时 $2x - 1 < x + 3$ 得 $x < 4$，结合 $x > \dfrac{1}{2}$ 得 $\dfrac{1}{2} < x < 4$。

**关联章节**：Part 4 / 01（指数函数）、Part 4 / 02（对数函数）

## 模型 9：三角函数单位圆与诱导公式

**触发条件**

要计算特殊角或非标准角（如 $\sin 210°$、$\cos \dfrac{7\pi}{4}$、$\tan(-300°)$）；化简 $\sin(\pi - \alpha) + \cos(\dfrac{\pi}{2} + \alpha)$ 等含 $\pi$ 倍数的式子；已知一个三角值反求其他。

**核心思路**

把任意角化为单位圆上对应锐角的三角值。诱导公式口诀：**"奇变偶不变，符号看象限"**——把 $\alpha$ 当锐角，看变形后所在象限的原函数符号。

**关键步骤**

1. 把角写成 $k \cdot \dfrac{\pi}{2} \pm \alpha$ 形式（$\alpha$ 取锐角）；
2. 判断 $k$ 是奇数还是偶数：
   - 偶数 → 函数名**不变**（$\sin$ 仍为 $\sin$）；
   - 奇数 → 函数名**互换**（$\sin \leftrightarrow \cos$）；
3. 把 $\alpha$ 当锐角，判断 $k \cdot \dfrac{\pi}{2} \pm \alpha$ 所在象限的原函数符号；
4. 写出最终化简结果。

**示意**

```
            π/2
       II   │   I       sin 正  全正
   ────────┼─────────
       III │   IV       tan 正  cos 正
            π
   单位圆口诀：
   一全二正弦三切四余弦（各象限为正的函数）
```

**典型题**

求 $\sin\left(-\dfrac{7\pi}{6}\right)$ 的值。

> **一句话指引**：$-\dfrac{7\pi}{6} = -\pi - \dfrac{\pi}{6}$；先用 $\sin(-x) = -\sin x$ 得 $-\sin\dfrac{7\pi}{6}$；$\dfrac{7\pi}{6} = \pi + \dfrac{\pi}{6}$，第三象限，$\sin$ 为负，$\sin\dfrac{7\pi}{6} = -\dfrac{1}{2}$；故 $\sin\left(-\dfrac{7\pi}{6}\right) = \dfrac{1}{2}$。

**关联章节**：Part 5 / 02（单位圆）、Part 5 / 04（诱导公式）

## 模型 10：$y = A\sin(\omega x + \varphi) + b$ 变换链

**触发条件**

题面涉及 $y = A\sin(\omega x + \varphi) + b$ 求振幅 / 周期 / 初相 / 单调区间 / 最值 / 对称轴；从 $y = \sin x$ 经过若干变换得到目标函数（"先平移再伸缩"或"先伸缩再平移"问题）；图象识别（看图反推 $A, \omega, \varphi, b$）。

**核心思路**

掌握四个参数的几何意义：$A$ 控制振幅，$\omega$ 控制周期 $T = \dfrac{2\pi}{\omega}$，$\varphi$ 控制水平平移，$b$ 控制垂直平移。变换的**顺序至关重要**：先伸缩再平移与先平移再伸缩，相位平移量不同。

**关键步骤**

1. 读出 $A, \omega, \varphi, b$：
   - $A$ = 振幅 = $\dfrac{y_{\max} - y_{\min}}{2}$；
   - $b$ = 中线 = $\dfrac{y_{\max} + y_{\min}}{2}$；
   - $T = \dfrac{2\pi}{\omega}$；
   - 由特殊点（最大点、零点）反推 $\varphi$；
2. 求单调区间：令 $\omega x + \varphi$ 落在 $\sin$ 的增 / 减区间 $\left[-\dfrac{\pi}{2} + 2k\pi, \dfrac{\pi}{2} + 2k\pi\right]$ 等，再解 $x$；
3. 求对称轴：$\omega x + \varphi = \dfrac{\pi}{2} + k\pi$；
4. 求对称中心：$\omega x + \varphi = k\pi$，中心 $(x_k, b)$；
5. 变换链：从 $y = \sin x$ 出发：
   - **先平移再伸缩**：$\sin x \to \sin(x + \varphi) \to \sin(\omega x + \varphi)$（平移 $\varphi$ 后再压缩 $\omega$ 倍）；
   - **先伸缩再平移**：$\sin x \to \sin\omega x \to \sin\omega\left(x + \dfrac{\varphi}{\omega}\right) = \sin(\omega x + \varphi)$（先压缩再平移 $\dfrac{\varphi}{\omega}$）。

**示意**

```
   y = sin x  ──A 倍─→  y = A sin x   (纵向拉伸)
              ──ω 倍─→  y = A sin(ωx)  (横向压缩 1/ω)
              ──左移 φ/ω─→  y = A sin(ω(x + φ/ω)) = A sin(ωx + φ)
              ──上移 b─→  y = A sin(ωx + φ) + b
   
   振幅 A    周期 T=2π/ω    初相 φ    垂直位移 b
```

**典型题**

已知 $f(x) = 2\sin\left(2x - \dfrac{\pi}{3}\right) + 1$，求其周期、最值与单调增区间。

> **一句话指引**：$A = 2, \omega = 2, \varphi = -\dfrac{\pi}{3}, b = 1$；$T = \pi$，最大值 $3$、最小值 $-1$；令 $2x - \dfrac{\pi}{3} \in \left[-\dfrac{\pi}{2} + 2k\pi, \dfrac{\pi}{2} + 2k\pi\right]$ 解得增区间 $\left[-\dfrac{\pi}{12} + k\pi, \dfrac{5\pi}{12} + k\pi\right]$。

## 模型 11：辅助角公式 $a\sin x + b\cos x = R\sin(x + \varphi)$

**触发条件**

题面是同周期的"正弦 + 余弦"线性组合（如 $\sqrt{3}\sin x + \cos x$、$3\sin 2x - 4\cos 2x$）；要求该函数的最值、值域、周期或单调区间；化为单一三角函数式以便分析。

**核心思路**

把 $a\sin x + b\cos x$ 整理为 $\sqrt{a^2 + b^2}\sin(x + \varphi)$，最值变为 $\pm\sqrt{a^2 + b^2}$。$\varphi$ 由 $\cos\varphi = \dfrac{a}{R}$、$\sin\varphi = \dfrac{b}{R}$ 唯一确定（即 $\tan\varphi = \dfrac{b}{a}$，并由 $a, b$ 符号定象限）。

**关键步骤**

1. 计算 $R = \sqrt{a^2 + b^2}$；
2. 提取 $R$：$a\sin x + b\cos x = R\left(\dfrac{a}{R}\sin x + \dfrac{b}{R}\cos x\right)$；
3. 令 $\cos\varphi = \dfrac{a}{R}, \sin\varphi = \dfrac{b}{R}$（由 $a, b$ 符号定 $\varphi$ 所在象限）；
4. 套和角公式：$R(\cos\varphi\sin x + \sin\varphi\cos x) = R\sin(x + \varphi)$；
5. 最值为 $\pm R$，周期与原同周期，单调区间用 $x + \varphi$ 反推。

**示意**

```
   几何意义：把向量 (a, b) 写成极坐标 (R, φ)
   
            b│
             │  ●(a, b)
             │ ╱
             │╱   R = √(a²+b²)
             │
     ────────┼────────→ a
             │  φ = atan2(b, a)
   
   a sin x + b cos x = R sin(x + φ)
   R 决定振幅,  φ 决定初相
```

**典型题**

求 $f(x) = \sqrt{3}\sin x + \cos x$ 的最大值与对应的 $x$。

> **一句话指引**：$R = \sqrt{3 + 1} = 2$；$\cos\varphi = \dfrac{\sqrt{3}}{2}, \sin\varphi = \dfrac{1}{2}$，故 $\varphi = \dfrac{\pi}{6}$；$f(x) = 2\sin\left(x + \dfrac{\pi}{6}\right)$，最大值 $2$，当 $x + \dfrac{\pi}{6} = \dfrac{\pi}{2} + 2k\pi$ 即 $x = \dfrac{\pi}{3} + 2k\pi$ 时取到。

**关联章节**：Part 5 / 05（和差倍半角公式）

## 模型 12：解三角形 ASS 情形二解判别

**触发条件**

已知三角形两边及其中一边对角（边边角 ASS），求另一对角；题面如"$\triangle ABC$ 中，$a = 4$，$b = 6$，$A = 30°$，求 $B$"；典型识别词："两边一角且角不是夹角"。

**核心思路**

由正弦定理 $\dfrac{a}{\sin A} = \dfrac{b}{\sin B}$ 解出 $\sin B = \dfrac{b\sin A}{a}$。由于 $\sin$ 函数在 $(0, \pi)$ 上不单调（$\sin B$ 与 $\sin(\pi - B)$ 相等），故 $B$ 可能有两个解。需根据三角形角度约束（$A + B < \pi$）和大边对大角原则筛选。

**关键步骤**

1. 由正弦定理求 $\sin B = \dfrac{b\sin A}{a}$；
2. 验证存在性：
   - 若 $\sin B > 1$：**无解**；
   - 若 $\sin B = 1$：唯一解 $B = \dfrac{\pi}{2}$；
   - 若 $\sin B < 1$：$B$ 有两个候选 $B_1 = \arcsin(\sin B)$ 和 $B_2 = \pi - B_1$；
3. 用 $A + B < \pi$ 筛选；
4. 用大边对大角原则筛选：$a > b \Leftrightarrow A > B$。

**判别表**：

| 关系 | 解的个数 | 几何理解 |
|---|---|---|
| $a < b\sin A$ | 无解 | $a$ 太短，构不成三角形 |
| $a = b\sin A$ | 1 解（直角） | $b$ 的足恰好等于 $a$ |
| $b\sin A < a < b$ | 2 解 | 圆弧与对边交两次 |
| $a \ge b$ | 1 解 | $a$ 是大边，大边对大角 |

**示意**

```
    锐角 A 已知,  以 A 为圆心, 半径 a 画弧
    与对边 AC 的延长线交两次 → 两解（B 锐 / 钝）
   
         C
        ╱│
       ╱ │ b
      ╱  │
   A●────●────●  ← a 画弧, 与对边交两次
         B₁    B₂
   B₁ 锐角解,  B₂ = π - B₁ 钝角解
```

**典型题**

$\triangle ABC$ 中，$a = 4$，$b = 4\sqrt{3}$，$A = 30°$，求 $B$。

> **一句话指引**：$\sin B = \dfrac{b\sin A}{a} = \dfrac{4\sqrt{3} \cdot \frac{1}{2}}{4} = \dfrac{\sqrt{3}}{2}$；候选 $B = 60°$ 或 $120°$；$A + B = 30° + 60° = 90°$ 或 $30° + 120° = 150°$ 均 $< 180°$，故**两解**：$B = 60°$ 或 $B = 120°$。

**关联章节**：Part 5 / 07（解三角形）
