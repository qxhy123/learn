# 附录 C：高一上代数 80 题题库

> 共 **80 题**，覆盖高一上代数 Part 1–5（集合逻辑、不等式、函数概念、指对幂、三角函数）。
> 难度三档：**基础**（教材后习题水平）、**中档**（最常考的题型）、**提升**（综合方法 / 含参讨论 / 技巧性强）。
> 编号 C.01–C.80，按 Part 顺序连续编号。**不附答案**，详解见附录 F。

## Part 1 集合与逻辑（C.01–C.10，共 10 题）

**C.01** [基础] Part 1/01  
用列举法表示集合 $A = \{x \in \mathbb{N} \mid -2 < x \leq 3\}$，并写出 $A$ 的元素个数。

**C.02** [基础] Part 1/02  
已知 $A = \{1, 2, 3, 4\}$，$B = \{2, 4, 6\}$，求 $A \cup B$ 与 $A \cap B$。

**C.03** [基础] Part 1/03  
集合 $M = \{a, b\}$ 的所有子集是什么？真子集个数是多少？

**C.04** [基础] Part 1/04  
写出命题"$\forall x \in \mathbb{R}, x^2 \geq 0$"的否定。

**C.05** [中档] Part 1/02  
设全集 $U = \{1, 2, 3, 4, 5, 6\}$，$A = \{1, 3, 5\}$，$B = \{2, 3, 5, 6\}$，求 $\complement_U(A \cup B)$ 和 $(\complement_U A) \cap (\complement_U B)$，并验证它们相等。

**C.06** [中档] Part 1/03  
已知集合 $A = \{x \mid x^2 - 3x + 2 = 0\}$，$B = \{x \mid x^2 - ax + a - 1 = 0\}$，若 $B \subseteq A$，求实数 $a$ 的所有可能取值。

**C.07** [中档] Part 1/05  
设 $p$：$x^2 - x - 6 \leq 0$，$q$：$|x - 1| \leq m$（$m > 0$）。若 $p$ 是 $q$ 的必要不充分条件，求 $m$ 的取值范围。

**C.08** [中档] Part 1/02  
已知集合 $A = \{x \mid -1 \leq x \leq 4\}$，$B = \{x \mid x < a\}$，若 $A \cap B \neq \varnothing$，求 $a$ 的取值范围。

**C.09** [提升] Part 1/03  
已知集合 $A = \{x \mid x^2 - 5x + 6 = 0\}$，$B = \{x \mid mx - 1 = 0\}$，若 $B \subseteq A$，求实数 $m$ 的所有可能取值。

**C.10** [提升] Part 1/04+05  
已知 $p$：$x^2 - 8x - 20 \leq 0$，$q$：$x^2 - 2x + 1 - m^2 \leq 0$（$m > 0$）。若 $\neg p$ 是 $\neg q$ 的必要不充分条件，求 $m$ 的取值范围。

## Part 2 不等式（C.11–C.22，共 12 题）

**C.11** [基础] Part 2/01  
已知 $a > b$，比较 $-3a + 1$ 与 $-3b + 1$ 的大小，并说明理由。

**C.12** [基础] Part 2/02  
解一元二次不等式 $x^2 - 5x + 6 < 0$。

**C.13** [基础] Part 2/02  
解一元二次不等式 $-x^2 + 4x - 3 \geq 0$。

**C.14** [基础] Part 2/04  
已知 $x > 0$，求 $x + \dfrac{4}{x}$ 的最小值，并指出取等条件。

**C.15** [中档] Part 2/02  
解关于 $x$ 的不等式 $x^2 - (a+1)x + a < 0$（$a \in \mathbb{R}$）。

**C.16** [中档] Part 2/03  
解分式不等式 $\dfrac{x - 1}{x + 2} \geq 0$。

**C.17** [中档] Part 2/04  
已知 $x > 1$，求 $x + \dfrac{4}{x - 1}$ 的最小值，并指出此时 $x$ 的值。

**C.18** [中档] Part 2/04  
已知 $x > 0$，$y > 0$，且 $\dfrac{1}{x} + \dfrac{4}{y} = 1$，求 $x + y$ 的最小值。

**C.19** [中档] Part 2/02  
若不等式 $ax^2 + bx + 2 > 0$ 的解集为 $\left\{x \;\middle|\; -\dfrac{1}{2} < x < \dfrac{1}{3}\right\}$，求 $a + b$ 的值。

**C.20** [提升] Part 2/02  
解关于 $x$ 的不等式 $ax^2 - (a+1)x + 1 < 0$（$a \in \mathbb{R}$）。

**C.21** [提升] Part 2/04  
已知 $a > 0$，$b > 0$，$a + 2b = 1$，求 $\dfrac{1}{a} + \dfrac{1}{b}$ 的最小值。

**C.22** [提升] Part 2/03  
解关于 $x$ 的不等式 $\dfrac{x^2 - x - 2}{x^2 - 4x + 3} \leq 0$（并指出定义域）。

## Part 3 函数概念（C.23–C.40，共 18 题）

**C.23** [基础] Part 3/01  
判断下列对应是否为函数（说明理由）：（1）$f: \mathbb{R} \to \mathbb{R}$，$f(x) = x^2$；（2）$g: \mathbb{R} \to \mathbb{R}$，$g(x) = \pm\sqrt{x^2 + 1}$。

**C.24** [基础] Part 3/02  
求函数 $f(x) = \sqrt{x - 1} + \dfrac{1}{x - 3}$ 的定义域。

**C.25** [基础] Part 3/02  
求函数 $f(x) = x^2 - 2x + 3$ 在 $[0, 3]$ 上的值域。

**C.26** [基础] Part 3/04  
判断函数 $f(x) = x^3 - x$ 的奇偶性。

**C.27** [基础] Part 3/03  
用定义法证明 $f(x) = 2x + 1$ 在 $\mathbb{R}$ 上单调递增。

**C.28** [基础] Part 3/05  
已知 $f(x) = \begin{cases} 2x + 1, & x < 0 \\ x^2, & x \geq 0 \end{cases}$，求 $f(-2) + f(3)$。

**C.29** [中档] Part 3/02  
若函数 $f(x) = \dfrac{\sqrt{x + 1}}{x - 2}$ 的定义域为 $A$，写出 $A$ 并求 $f(3)$。

**C.30** [中档] Part 3/03  
用定义法证明 $f(x) = \dfrac{1}{x}$ 在 $(0, +\infty)$ 上单调递减。

**C.31** [中档] Part 3/03  
已知函数 $f(x) = x + \dfrac{a}{x}$（$x > 0$）在区间 $[2, +\infty)$ 上单调递增，求 $a$ 的取值范围。

**C.32** [中档] Part 3/04  
已知 $f(x)$ 是 $\mathbb{R}$ 上的奇函数，且当 $x > 0$ 时 $f(x) = x^2 - 2x$，求当 $x < 0$ 时 $f(x)$ 的表达式。

**C.33** [中档] Part 3/06  
设 $f(x) = x^2 + 1$，$g(x) = 2x - 3$。求 $f(g(x))$ 与 $g(f(x))$，并求 $f(g(2))$。

**C.34** [中档] Part 3/03+04  
已知函数 $f(x)$ 是定义在 $\mathbb{R}$ 上的偶函数，且在 $[0, +\infty)$ 上单调递增。若 $f(2a - 1) < f(3)$，求 $a$ 的取值范围。

**C.35** [中档] Part 3/05  
画出函数 $y = |x - 1| + |x + 2|$ 的图象（分段讨论），并写出函数最小值。

**C.36** [中档] Part 3/02+03  
求函数 $y = x - \sqrt{1 - 2x}$ 的值域。（提示：换元 $t = \sqrt{1 - 2x}$）

**C.37** [提升] Part 3/06  
若 $f(x) = x^2 - 4x + 3$，求 $f(f(x)) = 0$ 的所有实数解。

**C.38** [提升] Part 3/03  
已知函数 $f(x) = \dfrac{ax + b}{x^2 + 1}$（$a, b \in \mathbb{R}$）是定义在 $\mathbb{R}$ 上的奇函数，且 $f(1) = \dfrac{1}{2}$。  
（1）求 $a, b$；（2）判断 $f(x)$ 在 $[1, +\infty)$ 上的单调性并证明。

**C.39** [提升] Part 3/03+04  
已知 $f(x)$ 满足 $f(x + y) = f(x) + f(y)$（$x, y \in \mathbb{R}$），且当 $x > 0$ 时 $f(x) < 0$。  
（1）求 $f(0)$；（2）判断 $f(x)$ 的奇偶性；（3）判断 $f(x)$ 在 $\mathbb{R}$ 上的单调性。

**C.40** [提升] Part 3/07  
某商场对一种商品定价，进价为 40 元/件。市场调查显示，当售价为 50 元时，每天可售 500 件；售价每上涨 1 元，每天少售 10 件。设售价为 $x$ 元（$x \geq 50$），每日利润为 $W(x)$。  
（1）写出 $W(x)$ 表达式；（2）求每日最大利润及对应售价。

## Part 4 指数对数幂（C.41–C.50，共 10 题）

**C.41** [基础] Part 4/01  
计算 $\left(\dfrac{1}{8}\right)^{-\frac{2}{3}} + 16^{0.75}$。

**C.42** [基础] Part 4/02  
计算 $\log_2 8 + \log_3 \dfrac{1}{9} + \log_5 \sqrt{5}$。

**C.43** [基础] Part 4/02  
利用换底公式计算 $\log_2 3 \cdot \log_3 8$。

**C.44** [基础] Part 4/03  
比较 $0.6^{0.5}$、$0.5^{0.6}$、$0.6^{0.6}$ 的大小（按从小到大排列）。

**C.45** [中档] Part 4/01  
解方程 $2^{x+1} + 2^x = 12$。

**C.46** [中档] Part 4/02  
若 $\log_a 2 = m$，$\log_a 3 = n$，用 $m, n$ 表示 $\log_a 12$ 与 $\log_a \dfrac{9}{8}$。

**C.47** [中档] Part 4/01  
解关于 $x$ 的方程 $9^x - 3^{x+1} + 2 = 0$。

**C.48** [中档] Part 4/02  
若 $f(x) = \log_a(x^2 - ax + 3)$（$a > 0, a \neq 1$）在 $[2, +\infty)$ 上单调递增，求 $a$ 的取值范围。

**C.49** [提升] Part 4/01  
设 $a, b$ 满足 $2^a = 5^b = 10$，求 $\dfrac{1}{a} + \dfrac{1}{b}$ 的值。

**C.50** [提升] Part 4/02

## Part 5 三角函数（C.51–C.76，共 26 题）

**C.51** [基础] Part 5/01  
将 $\dfrac{2\pi}{3}$ 化为角度，将 $-150°$ 化为弧度（用 $\pi$ 表示）。

**C.52** [基础] Part 5/01  
扇形的半径为 $3$，弧长为 $\pi$，求扇形的圆心角（弧度）与面积。

**C.53** [基础] Part 5/02  
已知 $\sin\alpha = \dfrac{3}{5}$，$\alpha$ 在第二象限，求 $\cos\alpha$ 与 $\tan\alpha$。

**C.54** [基础] Part 5/04  
利用诱导公式化简 $\dfrac{\sin(\pi - \alpha)\cos(2\pi - \alpha)}{\cos\left(\dfrac{\pi}{2} + \alpha\right)}$。

**C.55** [基础] Part 5/03  
已知函数 $y = 2\sin\left(2x - \dfrac{\pi}{3}\right)$，写出它的振幅、周期、初相，并求最大值。

**C.56** [基础] Part 5/05  
计算 $\sin 75°$（用 $\sin 45°$ 与 $\sin 30°$、$\cos 45°$ 与 $\cos 30°$ 表示）。

**C.57** [基础] Part 5/07  
在 $\triangle ABC$ 中，$a = 2$，$b = \sqrt{3}$，$A = 60°$，求 $\sin B$。

**C.58** [基础] Part 5/07  
在 $\triangle ABC$ 中，$a = 2$，$b = 3$，$C = 60°$，求 $c$。

**C.59** [中档] Part 5/02  
已知 $\sin\alpha + \cos\alpha = \dfrac{1}{5}$，$\alpha \in (0, \pi)$，求 $\sin\alpha - \cos\alpha$ 与 $\sin\alpha\cos\alpha$。

**C.60** [中档] Part 5/04  
化简 $\dfrac{\cos\left(\dfrac{\pi}{2} + \alpha\right)\sin(\pi + \alpha)}{\cos(\pi - \alpha)\sin\left(\dfrac{3\pi}{2} - \alpha\right)}$。

**C.61** [中档] Part 5/05  
已知 $\sin\alpha = \dfrac{4}{5}$，$\alpha \in \left(\dfrac{\pi}{2}, \pi\right)$，求 $\sin\left(\alpha + \dfrac{\pi}{4}\right)$。

**C.62** [中档] Part 5/05  
已知 $\tan\alpha = 2$，求 $\tan\left(\alpha - \dfrac{\pi}{4}\right)$ 与 $\sin 2\alpha$。

**C.63** [中档] Part 5/05  
计算 $\cos 75° \cos 15° - \sin 75° \sin 15°$。

**C.64** [中档] Part 5/05  
化简 $\dfrac{\sin 2\alpha}{1 + \cos 2\alpha}$。

**C.65** [中档] Part 5/05  
将 $\sqrt{3}\sin x + \cos x$ 化为 $R\sin(x + \varphi)$ 形式（$R > 0$，$\varphi \in \left(-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right)$），并求 $\sqrt{3}\sin x + \cos x$ 的最大值。

**C.66** [中档] Part 5/03  
若函数 $y = \sin(\omega x + \varphi)$（$\omega > 0$，$|\varphi| < \dfrac{\pi}{2}$）的最小正周期为 $\pi$，图象过点 $\left(\dfrac{\pi}{6}, 1\right)$，求 $\omega$ 与 $\varphi$。

**C.67** [中档] Part 5/03  
求函数 $y = 2\sin\left(2x + \dfrac{\pi}{6}\right)$ 在 $\left[-\dfrac{\pi}{4}, \dfrac{\pi}{4}\right]$ 上的最大值与最小值。

**C.68** [中档] Part 5/06  
在 $[0, 2\pi]$ 内解方程 $2\sin x - 1 = 0$。

**C.69** [中档] Part 5/07  
在 $\triangle ABC$ 中，$a = 7$，$b = 5$，$c = 3$，求 $\cos A$。

**C.70** [中档] Part 5/07  
在 $\triangle ABC$ 中，$a = 2$，$b = 2\sqrt{2}$，$A = 30°$，判断该三角形是否存在；若存在，求 $B$ 的所有可能值。

**C.71** [提升] Part 5/05  
已知 $\cos\alpha + \cos\beta = \dfrac{1}{2}$，$\sin\alpha + \sin\beta = \dfrac{1}{3}$，求 $\cos(\alpha - \beta)$。

**C.72** [提升] Part 5/05  
化简并求值：$\dfrac{2\sin 50° + \sin 80°\left(1 + \sqrt{3}\tan 10°\right)}{\sqrt{1 + \cos 10°}}$。

**C.73** [提升] Part 5/03+05  
已知函数 $f(x) = \sin 2x + \sqrt{3}\cos 2x$。  
（1）化为 $A\sin(\omega x + \varphi)$ 形式；（2）求 $f(x)$ 的最小正周期与单调递增区间；（3）求 $f(x)$ 在 $\left[0, \dfrac{\pi}{2}\right]$ 上的最值。

**C.74** [提升] Part 5/07  
在 $\triangle ABC$ 中，内角 $A, B, C$ 对边为 $a, b, c$，且 $b^2 + c^2 - a^2 = bc$，$a = \sqrt{3}$。  
（1）求 $A$；（2）求 $\triangle ABC$ 面积的最大值。

**C.75** [提升] Part 5/05+07  
在 $\triangle ABC$ 中，已知 $\sin A = 2\sin B\cos C$，且 $a^2 - b^2 = bc$。求角 $A$（提示：综合正余弦定理）。

**C.76** [提升] Part 5/08  
某海上观测站测得船在北偏东 $60°$ 方向，距离 $10$ 海里处。船以 $10$ 海里/小时的速度向正南方向行驶。半小时后，求观测站到船的距离。

## 综合（C.77–C.80，共 4 题，跨 Part）

**C.77** [中档] Part 3+5  
已知函数 $f(x) = \sin x + \cos x$，$x \in \mathbb{R}$。  
（1）将 $f(x)$ 化为 $R\sin(x + \varphi)$ 形式；（2）判断 $f(x)$ 的奇偶性；（3）求 $f(x)$ 的单调递增区间。

**C.78** [中档] Part 2+4  
已知 $a > 0$，$b > 0$，且 $\log_2 a + \log_2 b = 3$，求 $a + b$ 的最小值。

**C.79** [提升] Part 3+4  
设 $f(x) = \log_2 (4^x + 1) - x$。  
（1）判断 $f(x)$ 的奇偶性；（2）证明 $f(x)$ 在 $[0, +\infty)$ 上单调递增；（3）求 $f(x)$ 的最小值。

**C.80** [提升] Part 1+3  
已知集合 $A = \{x \mid x^2 - 4x + 3 \leq 0\}$，$B = \{x \mid f(x) \geq 0\}$，其中 $f(x) = \log_{0.5}(x - 1)$。求 $A \cap B$。
