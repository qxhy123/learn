## 分组 1：高一上回顾（D.01–D.30，对应 Part 1–5）

**D.01** [中档] Part 1/02  
已知集合 $A = \{x \mid x^2 - 3x - 4 \leq 0\}$，$B = \{x \mid m \leq x \leq m + 3\}$。若 $B \subseteq A$，求实数 $m$ 的取值范围。

**D.02** [中档] Part 1/02  
设全集 $U = \mathbb{R}$，$A = \{x \mid x^2 - 5x + 4 < 0\}$，$B = \{x \mid x - a > 0\}$。若 $A \cap (\complement_U B) = A$，求 $a$ 的取值范围。

**D.03** [中档] Part 1/03  
已知集合 $A = \{x \mid -2 \leq x \leq 5\}$，$B = \{x \mid m+1 \leq x \leq 2m - 1\}$。若 $A \cap B = B$，求 $m$ 的取值范围。

**D.04** [中档] Part 1/02  
设 $A = \{x \mid x^2 + 4x = 0\}$，$B = \{x \mid x^2 + 2(a+1)x + a^2 - 1 = 0\}$。若 $A \cup B = A$，求 $a$ 的取值范围。

**D.05** [中档] Part 1/03  
已知非空集合 $A = \{x \mid 2a + 1 \leq x \leq 3a - 5\}$，$B = \{x \mid 3 \leq x \leq 22\}$。若 $A \subseteq B$，求 $a$ 的取值范围。

**D.06** [中档] Part 1/05  
设 $p$：$\dfrac{1}{2} \leq x \leq 1$，$q$：$(x - a)(x - a - 1) \leq 0$。若 $p$ 是 $q$ 的充分不必要条件，求 $a$ 的取值范围。

**D.07** [中档] Part 1/05  
已知 $p$：实数 $x$ 满足 $x^2 - 4ax + 3a^2 < 0$（$a > 0$）；$q$：$x^2 - x - 6 \leq 0$ 且 $x^2 + 2x - 8 > 0$。若 $\neg p$ 是 $\neg q$ 的充分不必要条件，求 $a$ 的取值范围。

**D.08** [中档] Part 1/04

**D.11** [中档] Part 2/02

**D.12** [中档] Part 2/02

**D.13** [中档] Part 2/04

**D.14** [中档] Part 2/04

**D.15** [中档] Part 2/04

**D.16** [中档] Part 3/03+04

**D.17** [中档] Part 3/03

**D.18** [中档] Part 3/03+04
