# 古典概型与基本概念

> **一例速记**：  
> 古典概型核心公式：$P(A) = \dfrac{n(A)}{n(\Omega)}$（"有利样本点数 ÷ 总样本点数"）  
> 使用前提：① **有限性**（样本点个数有限）② **等可能性**（每个样本点出现机会相同）  
> 加法公式：$P(A \cup B) = P(A) + P(B) - P(AB)$；**对立**事件：$P(\overline{A}) = 1 - P(A)$

---

## 一、概念引入：随机现象与事件

### 1.1 必然、不可能、随机现象

生活中遇到的现象可以分成两大类：

- **确定性现象**：在一定条件下结果**必然**出现或**必然**不出现。例如"标准大气压下水加热到 $100°\text{C}$ 沸腾"——结果可预知。
- **随机现象**：在一定条件下结果**可能**出现也**可能**不出现。例如"投一枚硬币，正面朝上"——单次结果不可预知，但大量重复出现一定**统计规律**。

概率论研究的正是后者。我们的目标：用一个介于 $0$ 和 $1$ 之间的数（**概率**）来刻画随机事件发生的可能性大小。

### 1.2 三类事件

设某随机试验在条件 $S$ 下进行：

- **必然事件**：在条件 $S$ 下**一定**会发生的事件，常记为 $\Omega$。例如"投骰子点数 $\le 6$"。
- **不可能事件**：在条件 $S$ 下**一定不会**发生的事件，常记为 $\varnothing$。例如"投骰子点数 $= 7$"。
- **随机事件**：在条件 $S$ 下**可能发生也可能不发生**的事件，一般用大写字母 $A, B, C, \ldots$ 表示。

必然事件和不可能事件是随机事件的两个"极端情形"。

## 二、样本空间与样本点

### 2.1 定义

> **样本点**（也称"基本事件"）：随机试验的每一种可能结果。  
> **样本空间** $\Omega$：所有样本点构成的集合。  
> **事件**：样本空间 $\Omega$ 的子集。事件 $A$"发生" $\iff$ 试验结果是 $A$ 中的某个样本点。

**例子**：投一枚骰子。

- 样本空间 $\Omega = \{1, 2, 3, 4, 5, 6\}$，共 $6$ 个样本点；
- 事件 $A =$"点数为偶数"$= \{2, 4, 6\}$；
- 事件 $B =$"点数大于 $4$"$= \{5, 6\}$。

### 2.2 事件之间的关系

把事件看作集合（$\Omega$ 的子集），就能用集合语言描述事件之间的关系：

| 集合记号 | 概率含义 |
|---|---|
| $A \subseteq B$ | 事件 $A$ 发生则 $B$ 一定发生（**$A$ 包含于 $B$**） |
| $A = B$ | $A, B$ 表示同一事件 |
| $A \cup B$（或 $A + B$）| **并事件**：$A, B$ 中**至少一个**发生 |
| $A \cap B$（或 $AB$）| **交事件**：$A, B$ **同时**发生 |
| $A - B$ | **差事件**：$A$ 发生但 $B$ 不发生 |
| $\overline{A}$（或 $A^c$）| **对立事件**：$A$ 不发生（$\Omega \setminus A$）|

### 2.3 互斥事件与对立事件（**重点辨析**）

> **互斥**（互不相容）：$A \cap B = \varnothing$，即 $A, B$ **不可能同时发生**。  
> **对立**：$A \cap B = \varnothing$ **且** $A \cup B = \Omega$。即 $A, B$ 既不可能同时发生，又必有一个发生。

**关键**：

- 对立 $\Rightarrow$ 互斥（对立比互斥"更强"）；
- 互斥 $\not\Rightarrow$ 对立（互斥可以"都不发生"）。

**例**：投骰子。$A =$"点数为 $1$"，$B =$"点数为 $2$"。互斥（不能同时为 $1$ 又为 $2$），但**不对立**（点数为 $3$ 时两者都不发生）。再设 $C =$"点数为偶数"，$D =$"点数为奇数"，则 $C, D$ 既互斥又对立。

## 三、古典概型的定义与计算公式

### 3.1 古典概型的两个条件

> **古典概型**（也称"等可能概型"）指满足下面两个条件的概率模型：  
> ① **有限性**：样本空间中样本点的个数有限；  
> ② **等可能性**：每个样本点出现的可能性相等。

历史上拉普拉斯把这种模型作为概率最基本的研究对象，故称"古典"。

### 3.2 古典概型的概率公式

在古典概型下，若样本空间 $\Omega$ 共有 $n$ 个样本点（即 $n(\Omega) = n$），事件 $A$ 中含有 $m$ 个样本点（即 $n(A) = m$），则

$$\boxed{P(A) = \frac{n(A)}{n(\Omega)} = \frac{m}{n}}$$

**推导**：由等可能性，每个样本点概率均为 $\dfrac{1}{n}$。事件 $A$ 包含 $m$ 个互斥的样本点，由概率的可加性，

$$P(A) = \underbrace{\frac{1}{n} + \frac{1}{n} + \cdots + \frac{1}{n}}_{m \text{ 项}} = \frac{m}{n}$$

### 3.3 概率的几个基本性质

由公式 $P(A) = m/n$ 立即可得：

1. $0 \le P(A) \le 1$；
2. $P(\Omega) = 1$，$P(\varnothing) = 0$；
3. **加法公式**：$P(A \cup B) = P(A) + P(B) - P(AB)$；
   - 特别地，$A, B$ **互斥**时，$P(A \cup B) = P(A) + P(B)$；
   - 多个两两互斥事件：$P(A_1 \cup A_2 \cup \cdots \cup A_n) = P(A_1) + P(A_2) + \cdots + P(A_n)$。
4. **对立公式**：$P(\overline{A}) = 1 - P(A)$。
   - 实战技巧：当**直接算 $A$ 困难、但算 $\overline{A}$ 简单**时，用 $P(A) = 1 - P(\overline{A})$。典型场景：题目中出现"至少……"。

## 四、典型应用例题

### 例 1：抽签问题（顺序无关）

**题目**：$3$ 张奖券中有 $1$ 张中奖券。甲、乙、丙三人依次不放回抽签，求乙中奖的概率。

**【解答】**

设中奖券为 $A$，两张未中奖券为 $B_1, B_2$。三人抽签的所有可能结果（按甲、乙、丙顺序排列）：

$$\Omega = \{(A, B_1, B_2), (A, B_2, B_1), (B_1, A, B_2), (B_2, A, B_1), (B_1, B_2, A), (B_2, B_1, A)\}$$

共 $n(\Omega) = 3! = 6$ 个样本点，每个等可能。

事件"乙中奖"$= \{(B_1, A, B_2), (B_2, A, B_1)\}$，$n = 2$。

$$P(\text{乙中奖}) = \frac{2}{6} = \frac{1}{3}$$

**注意**：甲、乙、丙抽到中奖券的概率都是 $\dfrac{1}{3}$。**抽签顺序不影响公平性**——这是古典概型最经典的结论之一。

---

### 例 2：投骰子（双骰点数和）

**题目**：同时投两枚骰子，求点数和等于 $7$ 的概率。

**【解答】**

样本空间：$\Omega = \{(i, j) \mid 1 \le i, j \le 6\}$（第一枚骰子点数 $i$，第二枚 $j$），共 $n(\Omega) = 6 \times 6 = 36$ 个等可能样本点。

事件 $A =$"点数和为 $7$"$ = \{(1,6), (2,5), (3,4), (4,3), (5,2), (6,1)\}$，$n(A) = 6$。

$$P(A) = \frac{6}{36} = \frac{1}{6}$$

**易错提醒**：很多同学想当然把"和"作为样本点，认为和的取值是 $2, 3, \ldots, 12$ 共 $11$ 种"等可能"——**错**！这些"和"的取值不是等可能的（$7$ 比 $2$ 更容易出现）。正确做法是以**两枚骰子的点数对**作为样本点，这样才满足等可能。

---

### 例 3：配对问题

**题目**：从 $4$ 双不同的鞋（共 $8$ 只）中任取 $2$ 只，求恰好配成一双的概率。

**【解答】**

从 $8$ 只中任取 $2$ 只，总样本点数 $n(\Omega) = \binom{8}{2} = 28$。

事件 $A =$"恰配成一双" $\iff$ 取到同一双中的两只。$4$ 双中任选 $1$ 双，即取法 $n(A) = 4$。

$$P(A) = \frac{4}{28} = \frac{1}{7}$$

**变式思考**：若问"不配对"的概率，可用对立：$P(\overline{A}) = 1 - \dfrac{1}{7} = \dfrac{6}{7}$。

## 五、易错点梳理

**易错 1**：**忘记验证"等可能性"**。

判断一个问题是否为古典概型，**两个条件缺一不可**。投两枚骰子若以"和"为样本点，"和 $= 2$"和"和 $= 7$"的可能性根本不相等，不能直接用 $P = m/n$。

**易错 2**：**把"互斥"当成"对立"**。

- 互斥：不能同时发生（$A \cap B = \varnothing$）；
- 对立：互斥**且**必有一发生（$A \cap B = \varnothing$ 且 $A \cup B = \Omega$）。

只有当 $A, B$ 占满了整个 $\Omega$ 时，互斥才升级为对立。

**易错 3**：**加法公式漏减交集**。

$$P(A \cup B) = P(A) + P(B) - P(AB)$$

只有在 $A, B$ 互斥时 $P(AB) = 0$，才能写成 $P(A \cup B) = P(A) + P(B)$。

**易错 4**：**对立事件公式用错对象**。

$P(\overline{A}) = 1 - P(A)$ 中 $\overline{A}$ 必须是 $A$ 在 $\Omega$ 中的补集，而不是某种"反面情况"。要小心确认 $\overline{A}$ 的具体内容。

**易错 5**：**有放回 vs 无放回 混淆**。

抽签、摸球等场景务必看清"是否放回"。两种情形样本空间的构造方式不同，样本点总数也不同。

**易错 6**：**忽略样本点的顺序/区分**。

例如"两人各抛硬币"，样本点为 $(\text{正,正}), (\text{正,反}), (\text{反,正}), (\text{反,反})$，共 $4$ 个，不是 $3$ 个（"一正一反"是 $2$ 个不同样本点）。

## 六、自测题

**自测 1**　袋中有 $5$ 个红球、$3$ 个白球，从中任取 $1$ 球。设 $A =$ "取到红球"，$B =$ "取到白球"。判断 $A, B$ 是否互斥？是否对立？并求 $P(A), P(B)$。

> 💡 提示：$A \cap B = \varnothing$（同一球不能既红又白），故互斥。$A \cup B = \Omega$（球非红即白），故还是对立。$P(A) = \dfrac{5}{8}$，$P(B) = \dfrac{3}{8}$，$P(A) + P(B) = 1$ 验证对立。

**自测 2**　投两枚均匀骰子，求"点数和大于 $9$"的概率。

> 💡 提示：样本空间 $36$ 个点对。和大于 $9$ 即和 $\in \{10, 11, 12\}$：和 $=10$ 有 $(4,6),(5,5),(6,4)$ 共 $3$；和 $=11$ 有 $(5,6),(6,5)$ 共 $2$；和 $=12$ 有 $(6,6)$ 共 $1$。合计 $6$。$P = \dfrac{6}{36} = \dfrac{1}{6}$。

**自测 3**　$10$ 件产品中有 $3$ 件次品。任取 $2$ 件，求**至少 $1$ 件次品**的概率。

> 💡 提示：用对立！$\overline{A}$ = "全为正品"，$P(\overline{A}) = \dfrac{\binom{7}{2}}{\binom{10}{2}} = \dfrac{21}{45} = \dfrac{7}{15}$。故 $P(A) = 1 - \dfrac{7}{15} = \dfrac{8}{15}$。

**自测 4**　将数字 $1, 2, 3, 4$ 随机排成一行，求"$1$ 在 $2$ 的左边"（不一定相邻）的概率。

> 💡 提示：总排列数 $4! = 24$。考虑 $1$ 和 $2$ 的相对位置，按对称性，"$1$ 在 $2$ 的左边"和"$1$ 在 $2$ 的右边"各占一半。所以 $P = \dfrac{1}{2}$。（或者直接数：$1, 2$ 两位置共 $\binom{4}{2} = 6$ 种，"左小右大"占 $1$ 种，其余 $2$ 位 $2!=2$ 种，故 $n(A) = 6 \times 2 = 12$，$P = 12/24 = 1/2$。）
