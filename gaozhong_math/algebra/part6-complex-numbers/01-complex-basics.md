# 复数的概念与几何意义

> **一例速记**：  
> 虚数单位 $i$ 满足 $i^2 = -1$；高次幂周期为 4：$i^{4k}=1,\ i^{4k+1}=i,\ i^{4k+2}=-1,\ i^{4k+3}=-i$  
> 复数 $z = a + bi$（$a, b \in \mathbb{R}$），实部 $\operatorname{Re}(z) = a$，虚部 $\operatorname{Im}(z) = b$  
> 模 $|z| = \sqrt{a^2 + b^2}$，共轭 $\overline{z} = a - bi$，且 $z \cdot \overline{z} = |z|^2$

---

## 一、概念引入：为什么要扩充到复数？

数学中数集的扩张，总是为了解决"原有数集中无法表达"的运算。

- 从 $\mathbb{N}$（自然数）到 $\mathbb{Z}$（整数）：为了让减法 $a - b$ 在 $b > a$ 时仍有解。
- 从 $\mathbb{Z}$ 到 $\mathbb{Q}$（有理数）：为了让除法 $a \div b$（$b \neq 0$）总有意义。
- 从 $\mathbb{Q}$ 到 $\mathbb{R}$（实数）：为了让 $\sqrt{2}$、$\pi$ 这种无理数有"位置"。
- 从 $\mathbb{R}$ 到 $\mathbb{C}$（复数）：为了让 $x^2 = -1$ 有解。

在实数范围内，$x^2 \geq 0$ 恒成立，因此方程 $x^2 + 1 = 0$ 无解。**于是引入一个全新的"数"，记作 $i$，并规定 $i^2 = -1$**——这就是虚数单位的诞生。

引入 $i$ 之后，所有形如 $a + bi$（$a, b \in \mathbb{R}$）的对象就构成了一个新的数集，称为**复数集 $\mathbb{C}$**。它满足下面的链式包含关系：

$$\mathbb{N} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R} \subset \mathbb{C}$$

至此，**任何一元多次方程在 $\mathbb{C}$ 内都有解**（代数基本定理，高中只需了解结论）。

---

## 二、虚数单位与复数的定义

### 2.1 虚数单位 $i$

> **定义**：规定一个"数" $i$，满足
> $$i^2 = -1$$
> 称 $i$ 为**虚数单位**（imaginary unit）。

注意：$i$ 不是任何实数，它是新增加进来的对象。在保证四则运算规则（加法/乘法的交换律、结合律、分配律）依然成立的前提下，由 $i^2 = -1$ 可以推出 $i$ 的高次幂规律。

### 2.2 $i$ 的高次幂周期性

由 $i^2 = -1$ 出发：

$$i^1 = i,\quad i^2 = -1,\quad i^3 = i^2 \cdot i = -i,\quad i^4 = (i^2)^2 = 1$$

接着 $i^5 = i^4 \cdot i = i$，周期回到起点。因此对任意 $k \in \mathbb{Z}$：

$$\boxed{i^{4k} = 1,\quad i^{4k+1} = i,\quad i^{4k+2} = -1,\quad i^{4k+3} = -i}$$

**速算法**：计算 $i^n$ 时，把 $n$ 除以 $4$，看余数（$0, 1, 2, 3$ 分别对应 $1, i, -1, -i$）。

### 2.3 复数的标准形式

> **定义**：形如
> $$z = a + bi \quad (a, b \in \mathbb{R})$$
> 的数叫做**复数**。其中 $a$ 称为 $z$ 的**实部**，记作 $\operatorname{Re}(z)$；$b$ 称为 $z$ 的**虚部**，记作 $\operatorname{Im}(z)$。

注意虚部 $b$ 是**实数**，不是 $bi$。

**复数的分类**：

- 当 $b = 0$ 时，$z = a$ 是**实数**；
- 当 $b \neq 0$ 时，$z$ 称为**虚数**；
  - 进一步，当 $a = 0$ 且 $b \neq 0$ 时，$z = bi$ 称为**纯虚数**。

可用图示表示：

```
        ┌── 实数（b = 0）
复数 ───┤
        └── 虚数（b ≠ 0）─── 纯虚数（a = 0）
                          └── 非纯虚数（a ≠ 0）
```

### 2.4 复数相等

> **复数相等的条件**：$a + bi = c + di$（$a, b, c, d \in \mathbb{R}$）当且仅当
> $$a = c \quad \text{且} \quad b = d$$

也就是**实部等于实部、虚部等于虚部**。这是把一个复数方程"拆解"为两个实数方程的常用工具。

特别地：$a + bi = 0 \Leftrightarrow a = 0$ 且 $b = 0$。

## 三、复数的几何意义

### 3.1 复平面

把复数 $z = a + bi$ 与**平面上的点** $Z(a, b)$ 一一对应，所建立的直角坐标平面叫做**复平面**（也称高斯平面）：

- $x$ 轴：**实轴**（实数 $a + 0\cdot i$ 都落在这条轴上）
- $y$ 轴：**虚轴**（纯虚数 $0 + bi$ 都落在这条轴上，但**原点既属实轴又属虚轴**）

**两种几何对应**：

1. **点的对应**：$z = a + bi \;\longleftrightarrow\; Z(a, b)$
2. **向量的对应**：$z = a + bi \;\longleftrightarrow\; \vec{OZ} = (a, b)$（$O$ 为原点）

向量观点很重要，因为它把"复数的加减运算"和"向量的加减运算"完全对应了起来——这是下一章的核心。

### 3.2 复数的模

> **定义**：复数 $z = a + bi$ 的**模**（modulus）定义为
> $$|z| = \sqrt{a^2 + b^2}$$

**几何意义**：$|z|$ 表示点 $Z(a, b)$ 到原点 $O$ 的距离，也是向量 $\vec{OZ}$ 的长度。

**基本性质**：

- $|z| \geq 0$，且 $|z| = 0 \Leftrightarrow z = 0$；
- 若 $z = a$（实数），则 $|z| = |a|$（与实数绝对值一致）；
- $|z| = |-z| = |\overline{z}|$。

### 3.3 共轭复数

> **定义**：复数 $z = a + bi$ 的**共轭复数**定义为
> $$\overline{z} = a - bi$$

**几何意义**：$\overline{z}$ 对应的点 $\overline{Z}(a, -b)$ 与 $Z(a, b)$ 关于**实轴对称**。

**关键恒等式**：

$$z \cdot \overline{z} = (a + bi)(a - bi) = a^2 - (bi)^2 = a^2 - b^2 i^2 = a^2 + b^2 = |z|^2$$

即：

$$\boxed{z \cdot \overline{z} = |z|^2}$$

这是复数除法实数化的核心——把分母乘以共轭，结果就化成了实数。

**其他性质**（下一章详证，这里先记结论）：

- $\overline{\overline{z}} = z$（共轭的共轭还是自己）
- $z = \overline{z} \Leftrightarrow z \in \mathbb{R}$（一个复数等于其共轭当且仅当它是实数）
- $z + \overline{z} = 2a = 2\operatorname{Re}(z)$，$z - \overline{z} = 2bi = 2i\operatorname{Im}(z)$

## 四、典型应用例题

### 例 1：根据复数分类求参数

**题目**：已知复数 $z = (m^2 - 3m - 4) + (m^2 - 5m - 6)\,i$（$m \in \mathbb{R}$）。求实数 $m$ 的值，使得：
(1) $z$ 是实数；(2) $z$ 是纯虚数；(3) $z = 0$。

**【思路】**  把题目"翻译"成实部、虚部的条件——这是分类问题的统一处理方法。

- 实数：虚部 = 0；
- 纯虚数：虚部 ≠ 0 且实部 = 0；
- $z = 0$：实部和虚部同时为 0。

**【解答】**

实部 $a = m^2 - 3m - 4 = (m - 4)(m + 1)$，虚部 $b = m^2 - 5m - 6 = (m - 6)(m + 1)$。

(1) $z$ 是实数 $\Leftrightarrow b = 0 \Leftrightarrow (m-6)(m+1) = 0 \Leftrightarrow m = 6$ 或 $m = -1$。

(2) $z$ 是纯虚数 $\Leftrightarrow a = 0$ 且 $b \neq 0$。由 $a = 0$ 得 $m = 4$ 或 $m = -1$；代入 $b$ 检验：$m = 4$ 时 $b = -10 \neq 0$；$m = -1$ 时 $b = 0$（舍去）。故 $m = 4$。

(3) $z = 0 \Leftrightarrow a = 0$ 且 $b = 0$。由 (1)(2) 取交集：$m = -1$。

---

### 例 2：利用 $i$ 的周期性化简

**题目**：计算 $i + i^2 + i^3 + \cdots + i^{2024}$。

**【思路】**  $i$ 的高次幂以 $4$ 为周期，且**连续 4 项之和**正好为 $i + (-1) + (-i) + 1 = 0$。把总项数按 $4$ 分组即可。

**【解答】**

$$i + i^2 + i^3 + i^4 = i - 1 - i + 1 = 0$$

$2024 = 4 \times 506$，恰好分成 $506$ 组，每组之和为 $0$。

因此原式 $= 506 \times 0 = 0$。

**变式**：$i + i^2 + \cdots + i^{2025}$。

$2025 = 4 \times 506 + 1$，前 $2024$ 项之和为 $0$，再加 $i^{2025} = i^{4 \times 506 + 1} = i$，原式 $= i$。

---

### 例 3：复数对应点的几何条件

**题目**：复数 $z = (m - 2) + (m + 1) i$（$m \in \mathbb{R}$）在复平面内对应的点 $Z$。
(1) 当 $m$ 为何值时，$Z$ 在第二象限？
(2) 当 $|z| = \sqrt{13}$ 时，求 $m$。

**【思路】**

(1) "第二象限"对应**实部 $< 0$ 且虚部 $> 0$**，列不等式组。
(2) "模 = $\sqrt{13}$"直接利用 $|z|^2 = a^2 + b^2$，列方程。

**【解答】**

(1) 第二象限需要 $a < 0$ 且 $b > 0$：

$$\begin{cases} m - 2 < 0 \\ m + 1 > 0 \end{cases} \Leftrightarrow \begin{cases} m < 2 \\ m > -1 \end{cases} \Leftrightarrow -1 < m < 2$$

(2) 由 $|z|^2 = (m - 2)^2 + (m + 1)^2 = 13$：

$$(m^2 - 4m + 4) + (m^2 + 2m + 1) = 13$$

$$2m^2 - 2m - 8 = 0 \Leftrightarrow m^2 - m - 4 = 0 \Leftrightarrow m = \frac{1 \pm \sqrt{17}}{2}$$

## 五、易错点梳理

**易错 1**：把 $i^2$ 错记成 $1$。  
$i^2 = -1$ 是虚数单位的**定义**。考试中常因笔误写成 $i^2 = 1$ 而导致整题失分，务必牢记。

**易错 2**：误用 $\sqrt{-a}\cdot\sqrt{-b} = \sqrt{ab}$。  
$\sqrt{}\,$ 的乘性 $\sqrt{a} \cdot \sqrt{b} = \sqrt{ab}$ 仅在 $a, b \geq 0$ 时成立。若 $a = b = 1$，错误地写 $\sqrt{-1}\cdot\sqrt{-1} = \sqrt{(-1)(-1)} = \sqrt{1} = 1$ 会得到 $i^2 = 1$，与定义矛盾。正确做法是先化为 $i$：$\sqrt{-a} = \sqrt{a}\, i$（$a \geq 0$），然后按复数规则相乘：$\sqrt{-1}\cdot\sqrt{-1} = i \cdot i = i^2 = -1$。

**易错 3**：分不清"虚部"与"虚部对应的项"。  
$z = a + bi$ 的虚部是**实数 $b$**，不是 $bi$。例如 $z = 3 - 2i$ 的虚部是 $-2$，不是 $-2i$ 也不是 $2i$。

**易错 4**：混淆"纯虚数"与"虚数"。  
**虚数** = 虚部不为零的复数（$b \neq 0$）；**纯虚数** = 实部为零、虚部不为零（$a = 0,\ b \neq 0$）。例如 $2 + 3i$ 是虚数但不是纯虚数；$3i$ 是纯虚数；$0$ **既不是**纯虚数也不是虚数（它是实数）。

**易错 5**：误以为复数能比较大小。  
在复数集 $\mathbb{C}$ 中，**只有相等与不等之分，没有大小之分**。诸如 $2 + i > 1 + i$ 这样的写法都是错的。只有当两个复数都是实数时，才能比较大小。**但是"模"是实数，可以比较大小**：$|z_1| > |z_2|$ 是合法的。

## 六、自测题

**自测 1**　设复数 $z = (2m^2 - 3m - 2) + (m^2 - 3m + 2)\,i$（$m \in \mathbb{R}$），分别求 $m$ 使得：(1) $z$ 是实数；(2) $z$ 是纯虚数。

> 💡 提示：实部 $a = 2m^2 - 3m - 2 = (2m + 1)(m - 2)$，虚部 $b = m^2 - 3m + 2 = (m - 1)(m - 2)$。  
> (1) $b = 0 \Rightarrow m = 1$ 或 $m = 2$。  
> (2) $a = 0$ 且 $b \neq 0$：$a = 0 \Rightarrow m = -\frac{1}{2}$ 或 $m = 2$；$m = 2$ 时 $b = 0$（舍）；故 $m = -\frac{1}{2}$。

**自测 2**　计算 $i^{2026} + i^{2027} + i^{2028} + i^{2029}$。

> 💡 提示：连续 4 个 $i$ 的幂之和为 $0$（无论从哪一项开始）。验证：$2026 = 4 \times 506 + 2$，故 $i^{2026} = -1, i^{2027} = -i, i^{2028} = 1, i^{2029} = i$，和为 $0$。

**自测 3**　已知 $z = (a + 1) + (a^2 - 1)\,i$（$a \in \mathbb{R}$）对应的点在第三象限，求 $a$ 的取值范围。

> 💡 提示：第三象限 $\Leftrightarrow$ 实部 $< 0$ 且虚部 $< 0$。$\begin{cases}a + 1 < 0 \\ a^2 - 1 < 0\end{cases} \Leftrightarrow \begin{cases}a < -1 \\ -1 < a < 1\end{cases}$ 无解。说明**不存在**这样的 $a$。

**自测 4**　已知复数 $z$ 满足 $|z| = 2$ 且 $z$ 对应的点在第一象限的角平分线上，求 $z$。

> 💡 提示：第一象限角平分线上的点形如 $(t, t)$（$t > 0$）。由 $|z|^2 = t^2 + t^2 = 4$ 得 $t = \sqrt{2}$。故 $z = \sqrt{2} + \sqrt{2}\,i$。
