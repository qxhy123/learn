# 函数的奇偶性

> **一例速记**：  
> **奇函数**：$f(-x) = -f(x)$，图象关于**原点**对称。  
> **偶函数**：$f(-x) = f(x)$，图象关于 **$y$ 轴**对称。  
> **前提**：定义域必须关于原点对称（即 $x \in D \Rightarrow -x \in D$），否则谈不上奇偶性。  
> **两步判断法**：①看定义域是否关于原点对称 ②算 $f(-x)$ 与 $f(x)$ 比较。

---

## 一、引入：判断两个函数的奇偶性

> **题目**：判断 $f(x) = x^3 - 2x$ 与 $g(x) = x^4 - x^2$ 的奇偶性。

请先停下来，试着自己判断。

很多同学会直接算 $f(-x)$，有时候算对了但不知道为什么，有时候会漏掉"定义域"这一前提检查。遇到更复杂的函数（如含对数、分式）时，就容易翻车。

下面我们来还原一个真正理解奇偶性的人，脑子里是怎么想的。

---

## 二、思维路径还原（解题者的内心独白）

> "判断奇偶性，**第一步先看定义域**——定义域必须关于原点对称，这是一切的前提，不满足就直接"非奇非偶"，省得后面白做功。
>
> 两个函数：$f(x) = x^3 - 2x$，$g(x) = x^4 - x^2$，都是整式，定义域为 $\mathbb{R}$，显然关于原点对称（$x \in \mathbb{R} \Rightarrow -x \in \mathbb{R}$）。前提满足，进行第二步。
>
> **判断 $f(x) = x^3 - 2x$**：
>
> 算 $f(-x)$：
>
> $$f(-x) = (-x)^3 - 2(-x) = -x^3 + 2x$$
>
> 与 $f(x) = x^3 - 2x$ 比较：$-f(x) = -(x^3 - 2x) = -x^3 + 2x$。
>
> 正好等于 $f(-x)$！所以 $f(-x) = -f(x)$，$f$ 是**奇函数**，图象关于原点对称。
>
> 直观记忆：$x^3$ 是奇次，$-2x$ 也是奇次，"全奇次"→ 奇函数。
>
> **判断 $g(x) = x^4 - x^2$**：
>
> 算 $g(-x)$：
>
> $$g(-x) = (-x)^4 - (-x)^2 = x^4 - x^2$$
>
> 正好等于 $g(x)$！所以 $g(-x) = g(x)$，$g$ 是**偶函数**，图象关于 $y$ 轴对称。
>
> 直观记忆：$x^4$ 是偶次，$x^2$ 也是偶次，"全偶次"→ 偶函数。
>
> **关键反射**：
> - 多项式各项全是奇次幂 → 奇函数
> - 多项式各项全是偶次幂（含常数，因为常数 $= x^0$，$0$ 是偶数）→ 偶函数
> - 混合奇偶次幂 → 通常非奇非偶（如 $x^2 + x$）
>
> **特殊情况**：零函数 $f(x) = 0$（定义域关于原点对称时）既是奇函数又是偶函数。
>
> 奇函数的一个推论：若 $0 \in D$，则 $f(0) = -f(0)$，故 $f(0) = 0$。可以用来检验。
>
> 偶函数的用法：知道 $x > 0$ 的部分，可以直接得到 $x < 0$ 的部分（对称）。
>
> 奇偶 + 单调：奇函数关于原点对称，若在正半轴递增，则在负半轴也递增（两侧单调性**相同**）；偶函数关于 $y$ 轴对称，若在正半轴递增，则在负半轴递减（两侧单调性**相反**）。"

把这段内心独白读两遍，内化"先看定义域 → 再算 $f(-x)$ → 比较"的节奏。

## 三、抽象成方法

### 3.1 奇函数与偶函数的定义

设函数 $f$ 的定义域为 $D$。

**前提**：$D$ 关于原点对称，即 $\forall\, x \in D,\, -x \in D$。

在此前提下：
- **奇函数**：若 $\forall\, x \in D$，$f(-x) = -f(x)$，则称 $f$ 是定义域 $D$ 上的**奇函数**
- **偶函数**：若 $\forall\, x \in D$，$f(-x) = f(x)$，则称 $f$ 是定义域 $D$ 上的**偶函数**
- 若两个等式都不成立，则称 $f$ 是**非奇非偶函数**
- **零函数**（$f(x) = 0$，$\forall x \in D$，$D$ 关于原点对称）**既是奇函数又是偶函数**

### 3.2 判断奇偶性的 2 步法

**步骤 1**：检查定义域是否关于原点对称。

- 常见的关于原点对称的定义域：$\mathbb{R}$，$[-a, a]$，$(-a, a)$，$(-\infty, +\infty)$
- 定义域**不关于原点对称**：立即得出结论——函数**非奇非偶**，不需继续计算

**步骤 2**：计算 $f(-x)$，与 $f(x)$ 和 $-f(x)$ 分别比较。

$$\text{若 } f(-x) = f(x) \Rightarrow \text{偶函数}$$
$$\text{若 } f(-x) = -f(x) \Rightarrow \text{奇函数}$$
$$\text{若以上两者都不成立} \Rightarrow \text{非奇非偶}$$

**书写格式**（高考规范）：
> $f$ 的定义域为 $\cdots$，关于原点对称（满足前提）。  
> $f(-x) = \cdots = \cdots$（化简过程）  
> 因为 $f(-x) = f(x)$（或 $= -f(x)$），所以 $f(x)$ 是偶函数（或奇函数）。

### 3.3 多项式奇偶性口诀

| 多项式类型 | 结论 | 示例 |
|------------|------|------|
| 各项次数**全为奇数** | 奇函数 | $x$，$x^3 - 2x$，$x^5 + 3x^3 - x$ |
| 各项次数**全为偶数**（含常数项 $x^0$）| 偶函数 | $x^2$，$x^4 - x^2 + 1$，$3$（常数函数） |
| 奇次与偶次**混合** | 一般非奇非偶 | $x^2 + x$，$x^3 + 1$ |

**注意**：常数项 $c$（$c \ne 0$）属于 $x^0$ 项（0 次，偶数），所以含非零常数项的多项式若同时含奇次项，则非奇非偶。例如 $f(x) = x^3 + 1$：$f(-x) = -x^3 + 1 \ne f(x)$ 且 $\ne -f(x)$，非奇非偶。

### 3.4 奇偶性与单调性的组合规律

设 $f$ 在 $[a, b]$（$a > 0$）上有单调性，则 $f$ 在 $[-b, -a]$ 上的单调性如下：

| $f$ 的奇偶性 | $f$ 在 $[a,b]$ 上 | $f$ 在 $[-b,-a]$ 上 | 原因 |
|---|---|---|---|
| 奇函数 | 递增 | 递增 | 图象关于原点对称，两侧方向相同 |
| 奇函数 | 递减 | 递减 | 同上 |
| 偶函数 | 递增 | 递减 | 图象关于 $y$ 轴对称，两侧方向相反 |
| 偶函数 | 递减 | 递增 | 同上 |

**口诀**：奇函数两侧单调性**相同**，偶函数两侧单调性**相反**。

## 四、方法变形与拓展

### 4.1 抽象函数奇偶性

**题型**：已知 $f$ 满足某个函数方程，判断或推导 $f$ 的奇偶性。

**常用手法**：代特殊值（令 $x = 0$、令 $y = -x$ 等）。

**经典例子**（呼应 thinking-toolkit/06）：

若 $f(x+y) = f(x) + f(y)$ 对所有 $x, y \in \mathbb{R}$ 成立，则 $f$ 是奇函数。

证明：令 $x = y = 0$：$f(0) = 2f(0)$，故 $f(0) = 0$。  
令 $y = -x$：$f(0) = f(x) + f(-x)$，即 $0 = f(x) + f(-x)$，故 $f(-x) = -f(x)$，$f$ 是奇函数。

### 4.2 含参数的奇偶性

**题型**：求参数值使函数为奇函数或偶函数。

**策略**：

- 目标是奇函数 → 令 $f(-x) + f(x) = 0$ 并化简，解参数。或直接令 $f(-x) = -f(x)$ 再利用 $f(0) = 0$（若 $0 \in D$）。
- 目标是偶函数 → 令 $f(-x) - f(x) = 0$ 并化简，解参数。
- **注意**：含参函数的定义域也可能含参，需先确保定义域关于原点对称。

### 4.3 奇偶性 + 周期性

若奇函数 $f$ 关于直线 $x = a$ 对称，则 $f$ 是以 $4a$ 为周期的周期函数。

若偶函数 $f$ 关于点 $(a, 0)$ 中心对称，则 $f$ 是以 $4a$ 为周期的周期函数。

这两个结论在后续周期函数章节（呼应 thinking-toolkit/09）有重要应用，此处只需了解。

## 五、思考路标（条件反射训练）

下面每条都要反复内化，直到看到条件就知道下一步：

1. **见"判断奇偶性"** → 第一步不是算 $f(-x)$，而是先看**定义域是否关于原点对称**。这一步漏了，后面全错。

2. **定义域不关于原点对称** → 立刻下结论"非奇非偶"，不用继续算。例如定义域是 $[0, 3]$，无论解析式多漂亮，函数都是非奇非偶的。

3. **算 $f(-x)$ 时遇到偶次幂** → $(-x)^{2n} = x^{2n}$，符号消去。遇到奇次幂：$(-x)^{2n+1} = -x^{2n+1}$，符号取反。这是多项式奇偶性口诀的来源。

4. **多项式函数** → 快速看各项次数：全奇次 → 奇，全偶次（含常数）→ 偶，否则非奇非偶。节省计算时间。

5. **$f(0) = 0$ 是奇函数的必要条件**（$0 \in D$ 时）：若 $f(0) \ne 0$，直接排除奇函数可能。但 $f(0) = 0$ 不是充分条件（如 $f(x) = 1 - |x|$，$f(0) = 1$，是偶函数；$f(x) = \sin x + \cos x$，$f(0) = 1 \ne 0$，非奇非偶）。

6. **抽象函数** → 优先代特殊值：$x = 0$（推 $f(0)$），$y = -x$（推 $f(-x)$ 与 $f(x)$ 的关系），$x = y$（推 $f(2x)$ 等）。

7. **奇函数 + 已知正半轴单调性** → 负半轴单调性**相同**（镜像对称原点，斜率方向不变）。偶函数 + 已知正半轴单调性 → 负半轴单调性**相反**（镜像对称 $y$ 轴，斜率方向反转）。

8. **解含奇偶性的不等式** → 化为关于 $|x|$ 的问题（偶函数满足 $f(|x|) = f(x)$），或利用对称性展开讨论正负两段。

## 六、应用例题

### 例 1：分式函数的奇偶性判断

**题目**：判断 $f(x) = \dfrac{x^3 + x}{x^2 + 1}$ 的奇偶性。

**【解答】**

**步骤 1**：求定义域。$f(x) = \dfrac{x^3 + x}{x^2 + 1}$，分母 $x^2 + 1 \geq 1 > 0$，对所有 $x$ 成立，故定义域为 $\mathbb{R}$，关于原点对称。前提满足。

**步骤 2**：化简（先注意到 $x^3 + x = x(x^2+1)$）：

$$f(x) = \frac{x(x^2+1)}{x^2+1} = x$$

哦！$f(x) = x$（定义域 $\mathbb{R}$），显然是奇函数（也可直接用定义验证）。

但我们用原始表达式走完规范步骤：

$$f(-x) = \frac{(-x)^3 + (-x)}{(-x)^2 + 1} = \frac{-x^3 - x}{x^2 + 1} = -\frac{x^3 + x}{x^2 + 1} = -f(x)$$

$f(-x) = -f(x)$，故 $f(x)$ 是**奇函数**，图象关于原点对称。$\blacksquare$

---

### 例 2：含参——求参数使函数为偶函数

**题目**：已知 $f(x) = \log_2\!\left(\sqrt{x^2+1} - ax\right)$ 是偶函数，求实数 $a$ 的值。

**【解答】**

**步骤 1**：确定定义域。需要真数 $\sqrt{x^2+1} - ax > 0$。由于 $\sqrt{x^2+1} \geq 1 > 0$，当 $a = 0$ 时真数恒正，定义域为 $\mathbb{R}$；当 $a \ne 0$ 时需具体分析，但题目给定其为偶函数，定义域须关于原点对称（一般假设成立，验证 $a$ 后再核查）。

**步骤 2**：令 $f(-x) = f(x)$（偶函数条件）：

$$\log_2\!\left(\sqrt{(-x)^2+1} - a(-x)\right) = \log_2\!\left(\sqrt{x^2+1} - ax\right)$$

$$\log_2\!\left(\sqrt{x^2+1} + ax\right) = \log_2\!\left(\sqrt{x^2+1} - ax\right)$$

对数相等且底数相同，真数相等：

$$\sqrt{x^2+1} + ax = \sqrt{x^2+1} - ax$$

$$2ax = 0$$

对所有 $x$ 成立，故 $a = 0$。

**验证**：$a = 0$ 时 $f(x) = \log_2\!\left(\sqrt{x^2+1}\right)$，$f(-x) = \log_2\!\left(\sqrt{x^2+1}\right) = f(x)$，确为偶函数 ✓。

$$\boxed{a = 0}$$

### 例 3：奇偶性与单调性综合——解不等式

**题目**：已知 $f(x)$ 是定义在 $\mathbb{R}$ 上的偶函数，且在 $[0, +\infty)$ 上单调递增，解不等式 $f(2x-1) < f(x+2)$。

**【解答】**

$f$ 是偶函数，故 $f(-t) = f(t)$，即 $f(|t|) = f(t)$（偶函数值只依赖 $|t|$）。

因此，$f(2x-1) < f(x+2)$ 等价于 $f(|2x-1|) < f(|x+2|)$。

又 $f$ 在 $[0, +\infty)$ 上单调递增，结合 $f$ 的偶函数性，$f$ 在 $(-\infty, 0]$ 上单调递减，整体来看 $f(t)$ 随 $|t|$ 的增大而增大（$f$ 在 $[0, +\infty)$ 上增）。

所以 $f(|2x-1|) < f(|x+2|)$ 等价于 $|2x-1| < |x+2|$。

**解 $|2x-1| < |x+2|$**：两边平方（两边均非负，等价）：

$$(2x-1)^2 < (x+2)^2$$

$$4x^2 - 4x + 1 < x^2 + 4x + 4$$

$$3x^2 - 8x - 3 < 0$$

$$(3x+1)(x-3) < 0$$

解得 $-\dfrac{1}{3} < x < 3$。

$$\boxed{-\frac{1}{3} < x < 3}$$

**验证**（取 $x = 0$）：$f(2 \cdot 0 - 1) = f(-1) = f(1)$，$f(0 + 2) = f(2)$。$f(1) < f(2)$ 当且仅当 $1 < 2$（$f$ 增），成立 ✓。

## 七、思路自测题

**自测 1**　判断 $f(x) = x \cdot |x|$ 的奇偶性。

> 💡 提示：定义域 $\mathbb{R}$，关于原点对称。$f(-x) = (-x)|-x| = (-x)|x| = -(x|x|) = -f(x)$，故 $f$ 是奇函数。（$x \geq 0$ 时 $f(x) = x^2$，$x < 0$ 时 $f(x) = -x^2$，图象关于原点对称。）

**自测 2**　判断 $f(x) = \lg\!\left(\sqrt{x^2+x+1} + \sqrt{x^2-x+1}\right)$ 的奇偶性，并求 $f(x) + f(-x)$ 的值。

> 💡 提示：定义域中需 $x^2+x+1 > 0$ 和 $x^2-x+1 > 0$，两者判别式均为负，全体实数上恒正，定义域为 $\mathbb{R}$，关于原点对称。计算 $f(-x) = \lg(\sqrt{x^2-x+1}+\sqrt{x^2+x+1}) = f(x)$（两项交换顺序），故 $f$ 是偶函数，$f(x) + f(-x) = 2f(x)$。

**自测 3**　已知奇函数 $f(x)$ 在 $(0, +\infty)$ 上满足 $f(x) = x^2 - x$，求 $f(-2)$ 和 $f(0)$。

> 💡 提示：$f$ 是奇函数，$f(-2) = -f(2) = -(4-2) = -2$。$0$ 在定义域内（奇函数定义域关于原点对称包含 $0$），$f(0) = -f(0) \Rightarrow f(0) = 0$。

**自测 4**　已知 $f(x)$ 是 $\mathbb{R}$ 上的偶函数，且 $f(x+2) = -f(x)$ 对所有 $x$ 成立，求 $f(5)$ 的值（已知 $f(1) = 3$）。

> 💡 提示：$f(x+2) = -f(x)$，用两次得 $f(x+4) = -f(x+2) = f(x)$，所以 $f$ 是以 $4$ 为周期的函数。$f(5) = f(5-4) = f(1) = 3$。（也可：$f(5) = f(1+4) = f(1) = 3$。）

**自测 5**　设 $f(x)$ 是奇函数，$g(x)$ 是偶函数，且 $f(x) + g(x) = \dfrac{1}{x-1}$（$x \ne 1$），求 $g(2)$。

> 💡 提示：用 $-x$ 替换：$f(-x) + g(-x) = \dfrac{1}{-x-1}$，即 $-f(x) + g(x) = -\dfrac{1}{x+1}$。两式相加：$2g(x) = \dfrac{1}{x-1} - \dfrac{1}{x+1} = \dfrac{2}{x^2-1}$，故 $g(x) = \dfrac{1}{x^2-1}$。$g(2) = \dfrac{1}{3}$。
