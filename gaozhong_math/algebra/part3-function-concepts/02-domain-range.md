# 定义域与值域的求法

> **一例速记**：  
> **定义域**：使解析式有意义的所有 $x$ 的集合，多个限制取**交集**。  
> **值域**：5 大方法——观察法、配方法、单调性法、换元法、判别式法。  
> 核心原则：先确定定义域，再在定义域约束下求值域。

---

## 一、定义域的求法

### 1.1 常见限制类型

在求自然定义域时，按照以下规则逐一列出约束，然后取**交集**：

| 函数类型 | 约束条件 |
|----------|----------|
| 整式（多项式）| 无限制，定义域为 $\mathbb{R}$ |
| 分式 $\dfrac{P(x)}{Q(x)}$ | 分母 $Q(x) \ne 0$ |
| 偶次根式 $\sqrt[2n]{f(x)}$ | $f(x) \geq 0$ |
| 奇次根式 $\sqrt[2n+1]{f(x)}$ | 无限制（奇次根可取负数），定义域为 $\mathbb{R}$ |
| 对数 $\log_a f(x)$ | $f(x) > 0$，且底数 $a > 0$，$a \ne 1$ |
| $\tan x$ | $x \ne \dfrac{\pi}{2} + k\pi$，$k \in \mathbb{Z}$ |
| 多个限制共存 | 各条件**同时**满足，取所有约束的**交集** |

### 1.2 操作步骤

1. 识别解析式中所有"危险点"（分母、根式、对数、三角等）
2. 对每个危险点列出不等式（或不等关系）
3. 解各不等式，取所有解集的**交集**

### 1.3 含参定义域

当函数中含参数时，需根据参数的取值范围**分类讨论**。例如 $f(x) = \sqrt{ax - b}$ 中，若 $a = 0$ 则定义域为 $\mathbb{R}$（若 $b \leq 0$）或 $\varnothing$（若 $b > 0$），若 $a \ne 0$ 则需按 $a$ 正负分别处理。

---

## 二、值域的 5 大求法

### 方法一：观察法

适用于结构简单、能直接看出范围的函数。

**原理**：利用已知函数的值域结论（如 $\sin x \in [-1, 1]$，$x^2 \geq 0$，$a^x > 0$ 等）直接得出。

**例**：$f(x) = 2\sin x + 1$，值域为 $[-1, 3]$（$\sin x \in [-1, 1]$，整体伸缩平移）。

---

### 方法二：配方法（完全平方法）

适用于**二次函数**（及可化为二次的函数），尤其当定义域有限制时。

**步骤**：
1. 将 $f(x) = ax^2 + bx + c$ 配方为 $a\left(x + \dfrac{b}{2a}\right)^2 + \left(c - \dfrac{b^2}{4a}\right)$
2. 确定 $\left(x + \dfrac{b}{2a}\right)^2$ 的范围（在定义域约束下）
3. 推导 $f(x)$ 的范围

**关键**：若定义域无限制（全体实数），二次项的最值在顶点取到；若定义域是有界区间，需比较**顶点值**和**端点值**（轴在区间外时，最值在较近端点）。

---

### 方法三：单调性法

适用于在定义域上具有**严格单调性**的函数。

**步骤**：
1. 判断函数在定义域上的单调性（第 03 章详述）
2. 若单调递增，值域从 $f(x_{\min})$ 到 $f(x_{\max})$（开 / 闭端点视定义域而定）
3. 若单调递减，类似但方向相反

**适用场景**：指数函数、对数函数、线性函数、单调区间上的二次函数。

---

### 方法四：换元法

适用于含**根式**（或其他可替换的复合结构）的函数。

**步骤**：
1. 令 $t = \sqrt{ax+b}$（或其他内层函数），确定 $t$ 的范围
2. 用 $t$ 表示原函数（$f$ 变成关于 $t$ 的函数）
3. 在 $t$ 的范围内求新函数的值域

**注意**：换元后，$t$ 的范围由原定义域决定，不可忽略。

---

### 方法五：判别式法（$\Delta$ 法）

适用于**分式函数** $y = \dfrac{ax^2 + bx + c}{dx^2 + ex + f}$ 求值域。

**步骤**：
1. 设 $y = k$（$k$ 为待确定的值域中的值）
2. 将 $y = k$ 整理为关于 $x$ 的方程 $k(dx^2 + ex + f) = ax^2 + bx + c$，即 $(kd - a)x^2 + (ke - b)x + (kf - c) = 0$
3. 方程有实数解当且仅当 $\Delta \geq 0$（当系数退化时单独讨论）
4. 解出 $k$ 的范围，即为值域

**本质**：$k$ 在值域中 $\Leftrightarrow$ $f(x) = k$ 有实数解 $\Leftrightarrow$ 关于 $x$ 的方程有实根 $\Leftrightarrow$ $\Delta \geq 0$（或退化方程有解）。

## 三、典型例题

### 例 1：多重限制求定义域

**题目**：求 $f(x) = \sqrt{x-1} + \dfrac{1}{x-2}$ 的定义域。

**【解题思路】**

两个限制：
- $\sqrt{x-1}$ 要求：$x - 1 \geq 0$，即 $x \geq 1$
- $\dfrac{1}{x-2}$ 要求：$x - 2 \ne 0$，即 $x \ne 2$

取交集：$x \geq 1$ 且 $x \ne 2$。

$$\boxed{D = [1, 2) \cup (2, +\infty)}$$

---

### 例 2：有界定义域上的二次函数值域（配方法）

**题目**：求 $f(x) = x^2 - 4x + 3$ 在 $x \in [0, 3]$ 上的值域。

**【解题思路】**

**配方**：$f(x) = (x-2)^2 - 1$，顶点为 $(2, -1)$，开口向上。

**分析对称轴与区间的关系**：对称轴 $x = 2$ 在 $[0, 3]$ 内（$0 < 2 < 3$）。

- 顶点处（$x = 2$）取得最小值：$f(2) = -1$
- 端点值：$f(0) = 3$，$f(3) = 9 - 12 + 3 = 0$
- 最大值在端点较远处取得：$|0 - 2| = 2$，$|3 - 2| = 1$，$x = 0$ 离轴更远 → $f(0) = 3$ 为最大值

$$\boxed{\text{值域} = [-1, 3]}$$

**规律口诀（二次函数有界定义域）**：
- 若对称轴在区间内 → 最小值（$a>0$）在顶点，最大值在**距轴更远**的端点
- 若对称轴在区间左侧 → 函数在区间上单调递增，最小值在左端点，最大值在右端点
- 若对称轴在区间右侧 → 函数在区间上单调递减，最小值在右端点，最大值在左端点

---

### 例 3：换元法求值域

**题目**：求 $y = x + \sqrt{1 - 2x}$ 的值域。

**【解题思路】**

**第一步，确定定义域**：$1 - 2x \geq 0$，即 $x \leq \dfrac{1}{2}$。

**第二步，换元**：令 $t = \sqrt{1-2x} \geq 0$，则 $t^2 = 1 - 2x$，解得 $x = \dfrac{1-t^2}{2}$。

**第三步，用 $t$ 表示 $y$**：

$$y = x + t = \frac{1-t^2}{2} + t = -\frac{t^2}{2} + t + \frac{1}{2} = -\frac{1}{2}(t^2 - 2t) + \frac{1}{2}$$

配方：$y = -\frac{1}{2}(t-1)^2 + 1$

**第四步，确定 $t$ 的范围及 $y$ 的范围**：

$t \geq 0$，$y = -\dfrac{1}{2}(t-1)^2 + 1$ 是关于 $t$ 的开口向下抛物线，顶点 $t = 1$ 时 $y = 1$。

- 对称轴 $t = 1$ 在 $[0, +\infty)$ 内
- 最大值：$y(1) = 1$
- $t = 0$ 时：$y = -\dfrac{1}{2}(0-1)^2 + 1 = \dfrac{1}{2}$
- 当 $t \to +\infty$ 时：$y \to -\infty$

所以 $y$ 的最大值为 $1$（$t = 1$ 时取到），$y$ 可以趋向 $-\infty$。

$$\boxed{\text{值域} = (-\infty, 1]}$$

## 四、易错点总结

1. **忘记取交集**：含多个限制时，各约束必须**同时**满足，解集取交集而非并集。

2. **含参时忘记分类讨论**：如 $f(x) = \sqrt{ax+1}$，当 $a = 0$ 时定义域是整个 $\mathbb{R}$；当 $a \ne 0$ 时需讨论 $a$ 的正负。不分类直接解往往漏情形。

3. **换元后忘记限制 $t$ 的范围**：$t = \sqrt{\cdot} \geq 0$ 是硬约束，用换元得到的新表达式里，$t$ 不能超出此范围，否则会多算值域。

4. **$\Delta$ 法漏讨论退化情形**：当 $kd - a = 0$ 时，方程从二次退化为一次甚至常数，需单独判断该 $k$ 是否在值域中。

5. **区分"定义域"和"值域"**：自变量 $x$ 的范围是定义域，函数值 $y$ 的范围是值域；求值域时要在定义域约束下进行，不能忽略 $x$ 的限制。

## 五、思路自测题

**自测 1**　求 $f(x) = \dfrac{1}{\sqrt{x-1}} + \lg(4-x)$ 的定义域。

> 💡 提示：两个限制：$\sqrt{x-1}$ 要求 $x-1 > 0$（注意是分母，所以严格大于）即 $x>1$；$\lg(4-x)$ 要求 $4-x>0$ 即 $x<4$。交集：$1 < x < 4$，即 $(1, 4)$。

**自测 2**　求 $f(x) = x^2 + 2x - 3$ 在 $x \in [-3, 1]$ 上的值域。

> 💡 提示：配方 $f(x) = (x+1)^2 - 4$，顶点 $x=-1$，最小值 $-4$。端点：$f(-3)=9-6-3=0$，$f(1)=1+2-3=0$。对称轴 $x=-1$ 在区间内，最大值取在距轴更远的端点：$|-3-(-1)|=2$，$|1-(-1)|=2$，距离相等，故两端点值相同都是 $0$，最大值为 $0$。值域 $[-4, 0]$。

**自测 3**　求 $y = \sqrt{x+1} + \sqrt{3-x}$ 的值域。

> 💡 提示：定义域：$x+1 \geq 0$ 且 $3-x \geq 0$，即 $-1 \leq x \leq 3$。令 $a = \sqrt{x+1} \geq 0$，$b = \sqrt{3-x} \geq 0$，则 $a^2 + b^2 = 4$，$y = a+b$。由 $y^2 = (a+b)^2 = a^2 + b^2 + 2ab = 4 + 2ab \geq 4$，故 $y \geq 2$（等号当 $ab=0$ 时）；又由柯西不等式 $(a+b)^2 \leq 2(a^2+b^2) = 8$，故 $y \leq 2\sqrt{2}$。值域 $[2, 2\sqrt{2}]$。

**自测 4**　用判别式法求 $y = \dfrac{x^2 - x + 1}{x^2 + x + 1}$ 的值域。

> 💡 提示：设 $y = k$，则 $k(x^2+x+1) = x^2-x+1$，整理为 $(k-1)x^2 + (k+1)x + (k-1) = 0$。若 $k=1$：$0+2x+0=0$，$x=0$，有解，$k=1$ 在值域中。若 $k \ne 1$：需 $\Delta = (k+1)^2 - 4(k-1)^2 \geq 0$，展开：$k^2+2k+1-4k^2+8k-4 \geq 0$，即 $-3k^2+10k-3 \geq 0$，$3k^2-10k+3 \leq 0$，$(3k-1)(k-3) \leq 0$，解得 $\dfrac{1}{3} \leq k \leq 3$。合并（含 $k=1$）：值域 $\left[\dfrac{1}{3}, 3\right]$。
