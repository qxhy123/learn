# 函数的概念与三要素

> **一例速记**：  
> 函数 $f: A \to B$ 由三要素构成——**定义域** $A$、**对应关系** $f$、**值域** $\{f(x) \mid x \in A\} \subseteq B$。  
> 判断是否是函数：$A$ 中每个元素在 $B$ 中有且**仅有**一个对应值（一对多不是函数，多对一是函数）。  
> 判断是否同一函数：**定义域相同**且**对应关系相同**，两者缺一不可。

---

## 一、函数的定义

设 $A$、$B$ 是两个**非空数集**，如果按照某种确定的对应关系 $f$，对集合 $A$ 中的**任意**一个元素 $x$，在集合 $B$ 中都有**唯一**确定的元素 $y$ 与之对应，那么就称 $f: A \to B$ 为从集合 $A$ 到集合 $B$ 的一个**函数**，记作

$$y = f(x), \quad x \in A$$

其中：
- $x$ 称为**自变量**，$y$ 称为**因变量**（或函数值）
- $A$ 称为该函数的**定义域**
- 所有函数值的集合 $\{f(x) \mid x \in A\}$ 称为该函数的**值域**，值域是 $B$ 的**子集**（不一定等于 $B$）

**注意**：$B$ 称为函数的"陪域"，值域 $\subseteq B$，但值域 $\ne B$（除非 $f$ 是满射）。高中阶段常把 $B$ 直接取为值域，此时值域 $= B$。

---

## 二、函数三要素详解

### 2.1 定义域

定义域是自变量 $x$ 所有允许取值的集合。它直接决定了这个函数"活在哪个范围内"。

**确定定义域的两种情形**：

**情形一：解析式给出，无附加说明**（称为"自然定义域"）

按照使解析式**有意义**的所有 $x$ 值：

| 限制来源 | 条件 |
|----------|------|
| 分式 | 分母 $\ne 0$ |
| 偶次根式 $\sqrt[2n]{\cdot}$ | 被开方数 $\geq 0$ |
| 对数 $\log_a(\cdot)$ | 真数 $> 0$ |
| 多个限制共存 | 取各条件的**交集** |

**情形二：明确给出定义域**（如 $f(x) = x^2$，$x \in [0, 3]$）

以题目所给为准，不另行扩大。

### 2.2 对应关系

对应关系 $f$ 是函数的"规则"，它告诉我们：给定 $x$，如何计算 $y$。

**关键理解**：
- $f$ 是一种**关系**，不是数（很多同学误把 $f$ 理解成"某个数"）
- 符号 $f(x)$ 表示 $x$ 在关系 $f$ 下的**像**（函数值）
- 可以用解析式、表格、图象等方式表达 $f$

**合法的对应关系**（满足函数定义）：
- 一对一（单射）：$A$ 中每个 $x$ 对应 $B$ 中唯一 $y$，且不同 $x$ 对应不同 $y$
- **多对一**：不同的 $x$ 对应同一个 $y$（完全合法！如 $f(x) = x^2$，$f(-1) = f(1) = 1$）

**不合法的对应关系**（违反函数定义）：
- **一对多**：一个 $x$ 对应多个 $y$ → **不是函数**（如 $y^2 = x$，当 $x = 1$ 时 $y = \pm 1$，不确定）

### 2.3 值域

值域是 $x$ 遍历整个定义域时，$f(x)$ 的所有取值构成的集合：

$$\text{值域} = \{f(x) \mid x \in A\}$$

值域的求法在第 02 章专门讨论，此处只需理解：值域是函数性质的综合体现，它由定义域和对应关系**共同决定**。

---

## 三、同一函数的判断

两个函数 $f$ 与 $g$ 是同一函数，当且仅当：

1. **定义域相同**：$D_f = D_g$
2. **对应关系相同**：对一切 $x \in D_f$，都有 $f(x) = g(x)$

**推论**：与所用字母（变量名、函数名）无关。$f(x) = x^2$ 与 $g(t) = t^2$（定义域均为 $\mathbb{R}$）是**同一函数**。

**常见误区**：只看解析式，不看定义域。以下两个函数解析式形式不同，实则相同；而下面例 1 两个函数解析式相近，却因定义域不同而不同。

---

## 四、函数的三种表示法

| 表示法 | 特点 | 适用场景 |
|--------|------|----------|
| **解析式法** | 给出计算公式 $y = f(x)$ | 大多数数学函数 |
| **列表法**（表格法）| 列出若干 $(x, y)$ 对 | 离散的、实验数据 |
| **图象法** | 在坐标系中画出函数图象 | 直观展示变化趋势 |

三种方法各有优势，可互相转化。高中考试中以解析式法为主，图象法辅助理解。

## 五、典型例题

### 例 1：判断是否是同一函数

**题目**：判断 $f(x) = \sqrt{x-1} \cdot \sqrt{x+1}$ 与 $g(x) = \sqrt{x^2-1}$ 是否是同一函数。

**【解题思路】** 先分别求定义域，再比较。

**$f(x)$ 的定义域**：含两个偶次根式，需同时满足：

$$\begin{cases} x - 1 \geq 0 \\ x + 1 \geq 0 \end{cases} \implies \begin{cases} x \geq 1 \\ x \geq -1 \end{cases} \implies x \geq 1$$

定义域 $D_f = [1, +\infty)$。

**$g(x)$ 的定义域**：$\sqrt{x^2-1}$ 要求 $x^2 - 1 \geq 0$，即 $x^2 \geq 1$，解得 $x \leq -1$ 或 $x \geq 1$。

定义域 $D_g = (-\infty, -1] \cup [1, +\infty)$。

**比较**：$D_f = [1, +\infty) \ne (-\infty, -1] \cup [1, +\infty) = D_g$。

**定义域不同**，所以 $f$ 与 $g$ **不是同一函数**。

> 虽然在 $x \geq 1$ 的部分，$f(x) = g(x)$（因为 $\sqrt{x-1}\sqrt{x+1} = \sqrt{(x-1)(x+1)} = \sqrt{x^2-1}$ 在此范围成立），但整个定义域不同，函数就不同。

---

### 例 2：由 $f(x+1)$ 求 $f(x)$ 的解析式

**题目**：已知 $f(x+1) = x^2 - 2x$，求 $f(x)$。

**【解题思路】** 换元：令 $t = x + 1$，则 $x = t - 1$，代入：

$$f(t) = (t-1)^2 - 2(t-1) = t^2 - 2t + 1 - 2t + 2 = t^2 - 4t + 3$$

用 $x$ 替换 $t$，得：

$$\boxed{f(x) = x^2 - 4t + 3}$$

等等，最后一步要用 $x$ 替换 $t$（$t$ 只是中间变量）：

$$\boxed{f(x) = x^2 - 4x + 3}$$

**验证**：$f(x+1) = (x+1)^2 - 4(x+1) + 3 = x^2 + 2x + 1 - 4x - 4 + 3 = x^2 - 2x$ ✓

**方法要点**：见 $f(\text{某式})$，就令 $t = \text{某式}$，用 $t$ 反解 $x$，代入右侧。

---

### 例 3：抽象函数——构造方程组

**题目**：已知 $f(x) + 2f\!\left(\dfrac{1}{x}\right) = x$，求 $f(x)$ 的解析式。

**【解题思路】** 这是经典的"构造方程组"题型（呼应 thinking-toolkit/06 抽象函数方程）。

**方程一**：原式

$$f(x) + 2f\!\left(\frac{1}{x}\right) = x \quad \cdots (1)$$

**方程二**：用 $\dfrac{1}{x}$ 替换 $x$（即令 $x \leftarrow \dfrac{1}{x}$）：

$$f\!\left(\frac{1}{x}\right) + 2f(x) = \frac{1}{x} \quad \cdots (2)$$

**解方程组**：$(2) \times 2 - (1)$：

$$2f\!\left(\frac{1}{x}\right) + 4f(x) - f(x) - 2f\!\left(\frac{1}{x}\right) = \frac{2}{x} - x$$

$$3f(x) = \frac{2}{x} - x$$

$$\boxed{f(x) = \frac{2}{3x} - \frac{x}{3}}$$

**验证**：代回方程 $(1)$：$\left(\dfrac{2}{3x} - \dfrac{x}{3}\right) + 2\left(\dfrac{2x}{3} - \dfrac{1}{3x}\right) = \dfrac{2}{3x} - \dfrac{x}{3} + \dfrac{4x}{3} - \dfrac{2}{3x} = x$ ✓

**方法要点**：若 $f$ 的表达式中含 $f(x)$ 与 $f\!\left(\dfrac{1}{x}\right)$（或 $f(x)$ 与 $f(-x)$），用原式和替换后的式子联立，消去其中一个。

## 六、易错点总结

1. **一对多不是函数**：$y^2 = x$ 不是 $y$ 关于 $x$ 的函数（一个 $x$ 对应两个 $y$）；但 $y = \pm\sqrt{x}$ 拆成两个分支，每支单独是函数。

2. **同一函数要核对两要素**：只看解析式不够，定义域也要相同。$f(x) = x$ 与 $g(x) = \dfrac{x^2}{x}$（$x \ne 0$）**不是同一函数**（后者定义域排除了 $0$）。

3. **$f$ 是关系，不是数**：$f(x) = 3$ 不是说"$f$ 等于 $3$"，而是说"$x$ 的像是 $3$"（常数函数）。写 $f = 3$ 是错误的。

4. **值域是 $B$ 的子集**：值域 $\subseteq B$，不一定等于 $B$。$f: \mathbb{R} \to \mathbb{R}$，$f(x) = x^2$，值域是 $[0, +\infty)$，不是整个 $\mathbb{R}$。

5. **换元求解析式时忘记替换变量名**：例 2 中最后必须将 $t$ 换回 $x$（或所求函数的自变量），否则写 $f(t) = \ldots$ 而不是 $f(x) = \ldots$，表述不完整。

## 七、思路自测题

**自测 1**　下列对应关系中，哪些是函数（$A \to B$）？

(1) $A = \{1, 2, 3\}$，$B = \{4, 5, 6\}$，对应：$1 \mapsto 4$，$2 \mapsto 4$，$3 \mapsto 5$  
(2) $A = \{1, 4\}$，$B = \{-2, -1, 1, 2\}$，对应：$1 \mapsto 1$ 且 $1 \mapsto -1$，$4 \mapsto 2$ 且 $4 \mapsto -2$  
(3) $A = \mathbb{R}$，$B = \mathbb{R}$，对应：$y = x^2$

> 💡 提示：(1) 是函数（多对一合法，$3$ 未对应 $6$ 但题目允许 $B$ 有元素未被对应）；(2) 不是函数（$1$ 对应了两个值，一对多）；(3) 是函数。

**自测 2**　判断 $f(x) = x + 1$（$x \in \mathbb{R}$）与 $g(x) = \dfrac{x^2 - 1}{x - 1} + 2$ 是否是同一函数。

> 💡 提示：$g(x)$ 的定义域是 $x \ne 1$ 的 $\mathbb{R}$；在 $x \ne 1$ 时 $g(x) = (x+1) + 2/\ldots$，注意化简 $\dfrac{x^2-1}{x-1} = x+1$（$x \ne 1$），所以 $g(x) = x+1+1$？重新算：$g(x) = \dfrac{x^2-1}{x-1}+2$，$x\ne1$ 时 $= (x+1)+2 = x+3$。与 $f(x) = x+1$ 对应关系也不同，不是同一函数。（若原题是 $g(x) = \dfrac{x^2-1}{x-1}$，则 $g(x)=x+1$ 但定义域仍不含 $1$，故仍不同。）

**自测 3**　已知 $f(2x - 1) = 4x^2 - 4x + 3$，求 $f(x)$。

> 💡 提示：令 $t = 2x-1$，则 $x = \dfrac{t+1}{2}$。代入：$f(t) = 4\cdot\dfrac{(t+1)^2}{4} - 4\cdot\dfrac{t+1}{2} + 3 = (t+1)^2 - 2(t+1) + 3 = t^2 + 2t + 1 - 2t - 2 + 3 = t^2 + 2$。故 $f(x) = x^2 + 2$。

**自测 4**　已知 $f(x) - f(-x) = 2x$，且 $f(1) = 3$，求 $f(-1)$ 和 $f(0)$。

> 💡 提示：令 $x = 1$：$f(1) - f(-1) = 2$，所以 $f(-1) = f(1) - 2 = 1$。令 $x = 0$：$f(0) - f(0) = 0$，无法直接定 $f(0)$，说明 $f(0)$ 需要其他条件；若已知 $f(0) = c$，则条件自动满足（$c - c = 0$）。实际上 $f(0) = 0$ 是可以单独验证的（代入 $x=0$，等式变为 $0=0$，对任何 $f(0)$ 都成立，故需额外信息或假设 $f$ 为奇函数得 $f(0)=0$）。
