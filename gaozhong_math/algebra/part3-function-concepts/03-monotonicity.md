# 函数的单调性

> **一例速记**：  
> 定义法判单调性，**三步走**：  
> ① **取值**：在区间 $I$ 内任取 $x_1 < x_2$  
> ② **作差**：计算 $f(x_1) - f(x_2)$（或 $f(x_2) - f(x_1)$）  
> ③ **判号**：通分 / 因式分解 / 配方，看差的符号  
> $f(x_1) - f(x_2) < 0 \Rightarrow$ 单调**递增**；$> 0 \Rightarrow$ 单调**递减**。

---

## 一、引入：一道用定义法判单调性的题

> **题目**：用定义法判断 $f(x) = \dfrac{x}{x+1}$ 在 $(-1, +\infty)$ 上的单调性。

请先停下来，自己想想：这道题从哪里下手？

初学者常犯的错误是"画个图看一下"——图象能给直觉，但**不是证明**。考试要求严格证明。还有人用导数，但定义法更基础，适用面更广，是高中阶段的"硬通货"。

下面我们来还原一个真正懂这道题的人，脑子里是怎么想的。

## 二、思维路径还原（解题者的内心独白）

> "题目是 $f(x) = \dfrac{x}{x+1}$，在 $(-1, +\infty)$ 上判单调性——用定义法，三步走。
>
> **第一步：取值。** 在 $(-1, +\infty)$ 内任取 $x_1, x_2$，满足 $x_1 < x_2$。
>
> 注意：$x_1, x_2$ 都在区间内，即 $x_1 > -1$ 且 $x_2 > -1$。这个条件之后判号会用到，先记下来。
>
> **第二步：作差。** 计算 $f(x_1) - f(x_2)$：
>
> $$f(x_1) - f(x_2) = \frac{x_1}{x_1+1} - \frac{x_2}{x_2+1}$$
>
> 通分（分母是 $(x_1+1)(x_2+1)$）：
>
> $$= \frac{x_1(x_2+1) - x_2(x_1+1)}{(x_1+1)(x_2+1)}$$
>
> 展开分子：$x_1 x_2 + x_1 - x_2 x_1 - x_2 = x_1 - x_2$。
>
> 所以：$f(x_1) - f(x_2) = \dfrac{x_1 - x_2}{(x_1+1)(x_2+1)}$
>
> **第三步：判号。** 分析这个式子的符号：
>
> - 分子：$x_1 - x_2$。由 $x_1 < x_2$ 知，$x_1 - x_2 < 0$。分子为负。
>
> - 分母：$(x_1+1)(x_2+1)$。由 $x_1 > -1$ 知 $x_1 + 1 > 0$；由 $x_2 > -1$ 知 $x_2 + 1 > 0$。两个正数相乘，分母 $> 0$。
>
> - 结论：负数除以正数，$f(x_1) - f(x_2) < 0$，即 $f(x_1) < f(x_2)$。
>
> **由定义得：** 对任意 $x_1 < x_2$（均在 $(-1, +\infty)$ 内），都有 $f(x_1) < f(x_2)$，故 $f(x)$ 在 $(-1, +\infty)$ 上**单调递增**。
>
> **关键反射：** 定义法的精髓是"取差判号"——把单调性的抽象定义，转化为一个具体的代数符号判断。
>
> 进一步思考：若改用导数法，$f'(x) = \dfrac{(x+1) - x}{(x+1)^2} = \dfrac{1}{(x+1)^2} > 0$，直接得单调增。导数法更快，但需要先学微积分；定义法无需前提，是"万能"的。
>
> 验证直觉：取 $x_1 = 0, x_2 = 1$：$f(0) = 0$，$f(1) = \dfrac{1}{2}$，$f(0) < f(1)$ ✓。再取 $x_1 = 1, x_2 = 9$：$f(1) = \dfrac{1}{2}$，$f(9) = \dfrac{9}{10}$，$f(1) < f(9)$ ✓。"

把这段内心独白读两遍，感受三步走的节奏：取值 $\to$ 作差 $\to$ 判号。

## 三、抽象成方法

### 3.1 单调性的严格定义

设函数 $f$ 在区间 $I$ 上有定义。

**单调递增**：若对 $I$ 内任意 $x_1 < x_2$，都有 $f(x_1) < f(x_2)$，则称 $f$ 在 $I$ 上**单调递增**（或"增函数"），$I$ 称为 $f$ 的一个**单调递增区间**。

**单调递减**：若对 $I$ 内任意 $x_1 < x_2$，都有 $f(x_1) > f(x_2)$，则称 $f$ 在 $I$ 上**单调递减**（或"减函数"），$I$ 称为 $f$ 的一个**单调递减区间**。

**注意**：
- 单调性是对区间而言的，不是对整个定义域；一个函数可以有多个单调区间
- 单调区间之间不能随意合并（除非交叉点处也满足单调性，且通常合并需验证）
- $y = \dfrac{k}{x}$（$k > 0$）在 $(-\infty, 0)$ 和 $(0, +\infty)$ 上分别单调递减，但**不能**写成"在 $(-\infty, 0) \cup (0, +\infty)$ 上递减"——因为这两个区间之间有断点，无法跨越

### 3.2 定义法三步标准流程

**前提**：已知区间 $I$，判断 $f$ 在 $I$ 上的单调性。

1. **取值**：$\forall\, x_1, x_2 \in I$，$x_1 < x_2$（这是假设，之后一切分析都在此前提下进行）

2. **作差**：计算 $\Delta = f(x_1) - f(x_2)$，展开、化简（常用通分、配方、因式分解）

3. **判号**：利用"$x_1 < x_2$ 且 $x_1, x_2 \in I$"给出的信息，确定 $\Delta$ 的符号
   - $\Delta < 0 \Rightarrow f(x_1) < f(x_2)$：$f$ 在 $I$ 上**单调递增**
   - $\Delta > 0 \Rightarrow f(x_1) > f(x_2)$：$f$ 在 $I$ 上**单调递减**

**书写规范**（高考答题格式）：
> 设 $x_1, x_2 \in I$ 且 $x_1 < x_2$，则  
> $f(x_1) - f(x_2) = \cdots = \cdots$（化简过程）  
> 因为 $x_1 < x_2$，所以 $\cdots > 0$（或 $< 0$）  
> 故 $f(x_1) - f(x_2) < 0$（或 $> 0$），即 $f(x_1) < f(x_2)$（或 $> f(x_2)$）  
> 由单调递增（递减）定义，$f$ 在 $I$ 上单调递增（递减）。

### 3.3 常见函数的单调性模板

| 函数 | 单调区间 | 备注 |
|------|----------|------|
| $y = kx + b$（$k > 0$）| $(-\infty, +\infty)$ 单调增 | 线性函数 |
| $y = kx + b$（$k < 0$）| $(-\infty, +\infty)$ 单调减 | |
| $y = ax^2 + bx + c$（$a > 0$）| $\left(-\infty, -\dfrac{b}{2a}\right]$ 减，$\left[-\dfrac{b}{2a}, +\infty\right)$ 增 | 顶点为分水岭 |
| $y = ax^2 + bx + c$（$a < 0$）| $\left(-\infty, -\dfrac{b}{2a}\right]$ 增，$\left[-\dfrac{b}{2a}, +\infty\right)$ 减 | |
| $y = \dfrac{k}{x}$（$k > 0$）| $(-\infty, 0)$ 减，$(0, +\infty)$ 减 | 每支单减，不能合并 |
| $y = a^x$（$a > 1$）| $(-\infty, +\infty)$ 单调增 | 指数增长 |
| $y = a^x$（$0 < a < 1$）| $(-\infty, +\infty)$ 单调减 | 指数衰减 |
| $y = \log_a x$（$a > 1$）| $(0, +\infty)$ 单调增 | |
| $y = \log_a x$（$0 < a < 1$）| $(0, +\infty)$ 单调减 | |

## 四、方法变形与拓展

### 4.1 含参单调性

**题型**：求参数使函数在某区间上单调。

**策略**：将单调性条件（如"对称轴在区间左侧"等）转化为参数不等式，再求解。

**核心**：二次函数 $f(x) = ax^2 + bx + c$ 在 $[p, q]$ 上单调递增，要求：$a > 0$ 且对称轴 $x = -\dfrac{b}{2a} \leq p$（轴在区间左侧或左端点处）。

### 4.2 复合函数的单调性（"同增异减"）

设 $y = f(g(x))$，则：
- 若 $g$ 在 $I$ 上单调增，$f$ 在 $g(I)$ 上单调增 → 整体在 $I$ 上单调**增**（同向 = 同增）
- 若 $g$ 在 $I$ 上单调减，$f$ 在 $g(I)$ 上单调减 → 整体在 $I$ 上单调**增**（异向 = 异减 = 增）
- 若 $g$ 在 $I$ 上单调增，$f$ 在 $g(I)$ 上单调减 → 整体在 $I$ 上单调**减**（异向 = 减）
- 若 $g$ 在 $I$ 上单调减，$f$ 在 $g(I)$ 上单调增 → 整体在 $I$ 上单调**减**（异向 = 减）

口诀：**同增异减**（内外同向则整体增，内外异向则整体减）。详见 thinking-toolkit/07。

### 4.3 用单调性证不等式

若 $f$ 在 $[a, b]$ 上单调递增，则 $x_1 < x_2$（均在 $[a,b]$ 内）$\Rightarrow f(x_1) < f(x_2)$。

反过来也成立：$f(x_1) < f(x_2) \Rightarrow x_1 < x_2$（仅限单调函数，因为单调函数是单射）。

### 4.4 用单调性解方程 / 不等式

严格单调函数是**单射**（不同 $x$ 对应不同 $y$）：
- $f(a) = f(b)$（$f$ 严格单调）$\Rightarrow a = b$（唯一解）
- 解 $f(\varphi(x)) > f(\psi(x))$：若 $f$ 单调增，则等价于 $\varphi(x) > \psi(x)$；若 $f$ 单调减，不等号方向反转

## 五、思考路标（条件反射训练）

下面每条都要反复内化，直到看到题目条件就知道该怎么做：

1. **见"判断单调性"** → 优先想定义法三步：取值 $\to$ 作差 $\to$ 判号。若函数可导且在高中范围，也可用导数法（$f' > 0$ 增，$f' < 0$ 减）。

2. **第一步"取值"的格式** → 固定写法："设 $x_1, x_2 \in I$ 且 $x_1 < x_2$"，不能省略区间归属，因为区间内的约束（如 $x > 0$，$x > -1$）是判号时的武器。

3. **第二步"作差"遇到分式** → 立即通分，凑出含 $(x_1 - x_2)$ 的分子，然后利用 $x_1 < x_2 \Rightarrow x_1 - x_2 < 0$ 判符号。

4. **分母符号怎么确定** → 用区间条件：若 $I = (a, +\infty)$，则 $x_1, x_2 > a$，从而 $x_1 - a > 0$，$x_2 - a > 0$，乘积为正。

5. **见复合函数求单调区间** → 口诀"同增异减"：先拆内外，分别求单调性，再合并（同向为增，异向为减），记得取各自范围的**交集**。

6. **含参求单调区间** → 把单调性条件转化为参数约束（如"对称轴 $\leq$ 区间左端点"），列不等式解参数，切记分类讨论（如 $a = 0$ 时退化情形）。

7. **用单调性解不等式 $f(\varphi) > f(\psi)$** → 第一步判 $f$ 的单调性，单调增则 $\varphi > \psi$，单调减则 $\varphi < \psi$（方向翻转）。同时要把 $\varphi$ 和 $\psi$ 的取值限制在 $f$ 的定义域内。

8. **写答案时的格式** → 单调区间写成区间形式（如 $[1, +\infty)$），不写"$x \geq 1$ 时单调递增"（后者不规范）。多个单调递增区间不能随意合并为并集。

## 六、应用例题

### 例 1：基础定义法——二次函数

**题目**：用定义法证明 $f(x) = -x^2 + 2x$ 在 $[1, +\infty)$ 上单调递减。

**【解答】**

设 $x_1, x_2 \in [1, +\infty)$，且 $x_1 < x_2$，则：

$$f(x_1) - f(x_2) = (-x_1^2 + 2x_1) - (-x_2^2 + 2x_2)$$

$$= x_2^2 - x_1^2 - 2x_2 + 2x_1$$

$$= (x_2^2 - x_1^2) - 2(x_2 - x_1)$$

$$= (x_2 - x_1)(x_2 + x_1) - 2(x_2 - x_1)$$

$$= (x_2 - x_1)(x_2 + x_1 - 2)$$

**分析符号**：
- $x_2 - x_1 > 0$（因 $x_1 < x_2$）
- $x_2 + x_1 - 2$：由 $x_1 \geq 1, x_2 > x_1 \geq 1$，知 $x_1 + x_2 > 2$，即 $x_1 + x_2 - 2 > 0$

两个正因子相乘，$f(x_1) - f(x_2) > 0$，即 $f(x_1) > f(x_2)$。

**由单调递减定义**，$f(x) = -x^2 + 2x$ 在 $[1, +\infty)$ 上单调递减。$\blacksquare$

> 解题要点：因式分解是关键——$(x_2-x_1)(x_2+x_1-2)$ 分别分析两个因子的符号，逐一击破。

---

### 例 2：含参——求参数使函数单调

**题目**：已知 $f(x) = x^2 - 2ax + 3$ 在 $[2, +\infty)$ 上单调递增，求实数 $a$ 的取值范围。

**【解答】**

$f(x) = x^2 - 2ax + 3 = (x - a)^2 + 3 - a^2$，是开口向上（$a_{\text{coeff}} = 1 > 0$）的抛物线，对称轴为 $x = a$。

二次函数在对称轴**右侧**（含对称轴）单调递增。要使 $f$ 在 $[2, +\infty)$ 上单调递增，需要 $[2, +\infty)$ 整体处于"递增段"，即对称轴不超过区间左端点：

$$a \leq 2$$

$$\boxed{a \leq 2}$$

**验证**（取 $a = 2$）：$f(x) = (x-2)^2 + 3 - 4 = (x-2)^2 - 1$，对称轴 $x = 2$，在 $[2, +\infty)$ 上递增 ✓。  
（取 $a = 3$）：对称轴 $x = 3$，在 $[2, 3]$ 上递减，在 $[3, +\infty)$ 上递增，不满足 $[2, +\infty)$ 上整体递增 ✓（确实违反条件）。

---

### 例 3：用单调性解不等式

**题目**：已知 $f(x) = x^3 + x$ 在 $\mathbb{R}$ 上严格递增，解不等式 $f(2x-1) > f(x+2)$。

**【解答】**

**第一步**：验证 $f$ 严格递增（题目已给出，可直接使用）。

实际上：$f'(x) = 3x^2 + 1 > 0$ 对所有 $x$ 成立，所以 $f$ 在 $\mathbb{R}$ 上严格递增。

**第二步**：由 $f$ 严格递增，不等式 $f(2x-1) > f(x+2)$ 等价于：

$$2x - 1 > x + 2$$

$$x > 3$$

**第三步**：检查定义域。$f$ 在 $\mathbb{R}$ 上都有定义，$2x-1$ 和 $x+2$ 对一切 $x \in \mathbb{R}$ 都有意义，无额外限制。

$$\boxed{x > 3}$$

> 方法要点：严格单调函数 $f(u) > f(v) \Leftrightarrow u > v$（增）或 $u < v$（减）。若换成 $f(2x-1) < f(x+2)$，则答案变为 $x < 3$。

## 七、思路自测题

**自测 1**　用定义法证明 $f(x) = \dfrac{1}{x}$ 在 $(0, +\infty)$ 上单调递减。

> 💡 提示：设 $x_1, x_2 \in (0,+\infty)$，$x_1 < x_2$。作差：$f(x_1) - f(x_2) = \dfrac{1}{x_1} - \dfrac{1}{x_2} = \dfrac{x_2 - x_1}{x_1 x_2}$。分子 $x_2 - x_1 > 0$，分母 $x_1 x_2 > 0$，故差 $> 0$，即 $f(x_1) > f(x_2)$，$f$ 单调递减。

**自测 2**　求 $f(x) = -2x^2 + 4x + 1$ 的单调递增区间和单调递减区间。

> 💡 提示：$f(x) = -2(x-1)^2 + 3$，开口向下，顶点 $x=1$。$(-\infty, 1]$ 单调增，$[1, +\infty)$ 单调减。

**自测 3**　$f(x) = x^2 + (a-1)x + b$ 在 $[3, +\infty)$ 上单调递增，求 $a$ 的取值范围。

> 💡 提示：对称轴 $x = \dfrac{1-a}{2}$，需 $\dfrac{1-a}{2} \leq 3$，即 $1-a \leq 6$，$-a \leq 5$，$a \geq -5$。故 $a \geq -5$。

**自测 4**　已知 $f(x)$ 在 $[1, 5]$ 上单调递增，$f(2m-1) < f(m+1)$，求 $m$ 的范围。

> 💡 提示：由 $f$ 单调增，$f(2m-1) < f(m+1) \Rightarrow 2m-1 < m+1$，即 $m < 2$。但还需两个自变量都在 $[1, 5]$ 内：$1 \leq 2m-1 \leq 5 \Rightarrow 1 \leq m \leq 3$；$1 \leq m+1 \leq 5 \Rightarrow 0 \leq m \leq 4$。三个条件取交集：$1 \leq m < 2$。

**自测 5**　$f(x) = \log_{\frac{1}{2}}(x^2 - 2x - 3)$ 的单调递增区间是什么？

> 💡 提示：拆复合。定义域：$x^2-2x-3 > 0$，即 $(x-3)(x+1) > 0$，$x < -1$ 或 $x > 3$。内 $g(x) = x^2-2x-3 = (x-1)^2-4$，对称轴 $x=1$，在 $(-\infty,1]$ 递减，$[1,+\infty)$ 递增。外 $\log_{1/2}$ 是递减函数。同增异减：内减 + 外减 = 整体增（异减 = 增）。取交集：内函数递减区间 $(-\infty, 1]$ 与定义域 $(-\infty,-1)$ 的交集是 $(-\infty,-1)$；内函数递增区间 $[1,+\infty)$ 与定义域 $(3,+\infty)$ 的交集是 $(3,+\infty)$。所以单调递增区间是 $(-\infty,-1)$ 和 $(3,+\infty)$。
