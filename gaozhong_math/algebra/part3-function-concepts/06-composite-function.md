# 复合函数

> **一例速记**：  
> $y = f(g(x))$ 是**复合函数**，$g$ 是**内层函数**，$f$ 是**外层函数**。  
> **定义域**：$g$ 的定义域与 $\{x \mid g(x) \in D_f\}$ 的**交集**（两层约束同时满足）。  
> **单调性**：**同增异减**——内外同向（同增或同减）→ 整体递增；内外异向 → 整体递减。

---

## 一、引入：一道单调区间题

> **题目**：求 $y = \log_2(x^2 - 4x + 3)$ 的单调递增区间。

先停下来，独立思考。你能马上看出这是一个复合函数吗？你知道该从哪里下手吗？

很多同学在这里犯的错误是：直接把 $\log_2$ 的增减性和 $x^2 - 4x + 3$ 的增减性搞混，或者忘了先求定义域。

让我们来还原一个真正掌握这道题的人的内心思路。

---

## 二、思维路径还原（解题者的内心独白）

> "$y = \log_2(x^2 - 4x + 3)$ ——看到这个函数，**第一个反应**：这是复合函数。
>
> **拆层**：内层 $g(x) = x^2 - 4x + 3$，外层 $f(t) = \log_2 t$。中间变量设为 $t$，整个函数是 $y = f(t) = f(g(x))$。
>
> **第一步：求定义域**——对数函数要求真数大于零。
>
> $g(x) > 0$，即 $x^2 - 4x + 3 > 0$
>
> 分解：$(x-1)(x-3) > 0 \Rightarrow x < 1$ 或 $x > 3$
>
> 定义域：$(-\infty, 1) \cup (3, +\infty)$
>
> **第二步：分析各层的单调性**
>
> 内层 $g(x) = x^2 - 4x + 3$：开口向上的抛物线，对称轴 $x = 2$。
>   - 在 $(-\infty, 2]$ 上**递减**
>   - 在 $[2, +\infty)$ 上**递增**
>
> 外层 $f(t) = \log_2 t$：以 $2 > 1$ 为底，在 $(0, +\infty)$ 上**递增**。
>
> **第三步：取交集 + 运用同增异减**
>
> 定义域是 $(-\infty, 1) \cup (3, +\infty)$，要在定义域内分析：
>
> - 在 $(-\infty, 1)$ 上：$g$ 递减（因为 $(-\infty, 1) \subset (-\infty, 2]$）；$f$ 递增。内外**异向** → 整体**递减**。
>
> - 在 $(3, +\infty)$ 上：$g$ 递增（因为 $(3, +\infty) \subset [2, +\infty)$）；$f$ 递增。内外**同向** → 整体**递增** ✓
>
> **答：单调递增区间为 $(3, +\infty)$。**
>
> **关键反射**：看到嵌套函数 → 立刻拆内外 → 先求定义域 → 再分析各层单调性 → 取定义域与单调区间的交集 → 用同增异减得结论。
>
> **自检**：取 $x_1 = 4, x_2 = 5$（均在 $(3, +\infty)$）验证：
> $g(4) = 16 - 16 + 3 = 3$，$g(5) = 25 - 20 + 3 = 8$，$g(4) < g(5)$；$\log_2 3 < \log_2 8$，所以 $y(4) < y(5)$。$x_1 < x_2$ 时 $y_1 < y_2$ ✓，确实递增。
>
> 还有一个陷阱：结论是"递增区间"而不是"定义域上的递增性"。函数在 $(-\infty, 1)$ 是递减的，所以不能说"整个定义域都递增"。"

把这段内心独白完整读一遍。感受"拆层 → 定义域 → 各层单调 → 交集 → 同增异减"这条流水线，在大脑里跑顺畅。

## 三、抽象成方法

### 复合函数 4 大原则

| 性质 | 处理方法 | 要点 |
|------|----------|------|
| **定义域** | $D = \{x \in D_g \mid g(x) \in D_f\}$ | 内层定义域 ∩ 使 $g(x)$ 落入 $D_f$ 的 $x$ 的集合 |
| **值域** | 先求内层 $g$ 的值域 $R_g$，再求 $f$ 在 $R_g$ 上的值域 | 内层值域是外层的"有效输入范围" |
| **单调性** | **同增异减**（见下详解） | 必须先在定义域内取交集 |
| **奇偶性** | 内层偶 → 整体偶；内外都奇 → 整体奇 | 其他情况逐一验证 |

### "同增异减"详解

设 $y = f(g(x))$，$I$ 是 $x$ 的某个区间：

| 内层 $g$ 在 $I$ 上 | 外层 $f$ 在 $g(I)$ 上 | 复合函数 $f \circ g$ 在 $I$ 上 |
|-------------------|--------------------|-------------------------------|
| 递增 $\uparrow$ | 递增 $\uparrow$ | **递增** $\uparrow$（同增→增） |
| 递减 $\downarrow$ | 递减 $\downarrow$ | **递增** $\uparrow$（同减→增） |
| 递增 $\uparrow$ | 递减 $\downarrow$ | **递减** $\downarrow$（异向→减） |
| 递减 $\downarrow$ | 递增 $\uparrow$ | **递减** $\downarrow$（异向→减） |

**记忆口诀**：同号得增，异号得减（类比乘法符号规则）。

**正式表述**：若 $g$ 在 $I$ 上单调递增，$f$ 在 $g(I)$ 上单调递增，则 $f(g(x))$ 在 $I$ 上单调递增。其余三种情形类似。

**注意**：取交集时，单调区间必须在**定义域内**——定义域之外无意义。

### 奇偶性组合规律

设 $y = f(g(x))$：

| 内层 $g$ | 外层 $f$ | 复合 $f \circ g$ |
|---------|---------|-----------------|
| 偶函数 | 任意 | **偶函数** |
| 奇函数 | 奇函数 | **奇函数** |
| 奇函数 | 偶函数 | **偶函数** |
| 非奇非偶 | — | 需单独验证 |

**证明"内偶 → 整体偶"**：若 $g(-x) = g(x)$，则 $f(g(-x)) = f(g(x))$，整体满足偶函数定义。

## 四、方法变形

### 变形 1：三层复合

$y = f(g(h(x)))$ ——从最内层到最外层，**逐层分析**。

定义域：先求 $h$ 的定义域，再要求 $h(x) \in D_g$，再要求 $g(h(x)) \in D_f$，三层取交集。

单调性：逐层分析 $h$、$g$、$f$ 的单调性，按同增异减逐步合并。

**例**：$y = \log_{\frac{1}{2}} \sqrt{2x - 1}$ 的单调区间。

拆层：$h(x) = 2x - 1$（线性，增），$g(t) = \sqrt{t}$（增，$t \geq 0$），$f(u) = \log_{\frac{1}{2}} u$（减，$u > 0$）。

定义域：$2x - 1 > 0 \Rightarrow x > \dfrac{1}{2}$，即 $\left(\dfrac{1}{2}, +\infty\right)$。

单调性：$h$ 增 × $g$ 增 → $g(h(x))$ 增；$g(h(x))$ 增 × $f$ 减 → 整体减。

结论：在 $\left(\dfrac{1}{2}, +\infty\right)$ 上单调递减。

### 变形 2：含参复合

定义域或单调区间含参数 → 分类讨论参数范围。

**例**：$y = (a^2 - a - 1)^x$ 是 $\mathbb{R}$ 上的增函数，求 $a$ 的范围。

指数函数 $y = b^x$ 增的条件：$b > 1$，即 $a^2 - a - 1 > 1 \Rightarrow a^2 - a - 2 > 0 \Rightarrow (a-2)(a+1) > 0 \Rightarrow a > 2$ 或 $a < -1$。

### 变形 3：抽象复合

已知 $f(x)$ 的某种性质（单调性/奇偶性等），求 $f(g(x))$ 的对应性质。

步骤：先用 $g$ 的性质，再用 $f$ 的性质，用同增异减或奇偶组合规律。

### 变形 4：图象变换视角

复合函数 $y = f(ax + b)$ 可视为对 $y = f(x)$ 进行图象变换：

- $y = f(x + b)$：水平平移 $|b|$ 个单位（$b > 0$ 向左，$b < 0$ 向右）
- $y = f(ax)$（$a > 0$）：横向缩放（$a > 1$ 压缩，$0 < a < 1$ 拉伸）
- $y = -f(x)$：关于 $x$ 轴对称
- $y = f(-x)$：关于 $y$ 轴对称

## 五、思考路标（条件反射训练）

读以下每条，直到"看到就自动触发操作"：

1. **见嵌套函数** → 立刻识别"这是复合函数"，拆出内层 $g$ 和外层 $f$，引入中间变量 $t = g(x)$

2. **求定义域** → 内层定义域 ∩ 使内层值落入外层定义域的 $x$ 集合——**两层约束取交集**

3. **求单调区间** → 先求各层单调区间 → 在定义域内取交集 → 用**同增异减**判方向

4. **同增异减口诀** → 同号得增，异号得减（内外单调方向乘积正→整体增，负→整体减）

5. **内层值域是外层的输入** → 求值域时先求 $g$ 的值域，再把它当作 $f$ 的自变量范围

6. **见内层是偶函数** → 整体一定是偶函数，可直接用对称性简化

7. **三层复合** → 从最内层开始，逐层分析，不要一下跳到结论

8. **用完同增异减必须验证** → 取特殊值检查 $x_1 < x_2$ 时 $y_1$ 与 $y_2$ 的大小关系（避免符号搞反）

## 六、应用例题

### 例 1：求定义域与值域

**题目**：求 $y = \sqrt{x^2 - 1}$ 的定义域与值域。

**【思路】** 拆层：$g(x) = x^2 - 1$（内），$f(t) = \sqrt{t}$（外，要求 $t \geq 0$）。

**定义域**：$g(x) \geq 0 \Rightarrow x^2 - 1 \geq 0 \Rightarrow x \leq -1$ 或 $x \geq 1$

即 $(-\infty, -1] \cup [1, +\infty)$。

**值域**：在定义域内，$g(x) = x^2 - 1 \geq 0$，故 $t = g(x) \in [0, +\infty)$；$f(t) = \sqrt{t}$，当 $t \in [0, +\infty)$ 时，$y \in [0, +\infty)$。

**答：定义域 $(-\infty, -1] \cup [1, +\infty)$，值域 $[0, +\infty)$。**

---

### 例 2：求单调区间（同增异减应用）

**题目**：求 $y = \left(\dfrac{1}{2}\right)^{x^2 - 2x}$ 的单调区间。

**【思路】** 拆层：内层 $g(x) = x^2 - 2x$，外层 $f(t) = \left(\dfrac{1}{2}\right)^t$。

**内层单调性**：$g(x) = x^2 - 2x = (x-1)^2 - 1$，对称轴 $x = 1$，开口向上。
- 在 $(-\infty, 1]$ 上**递减**
- 在 $[1, +\infty)$ 上**递增**

**外层单调性**：$f(t) = \left(\dfrac{1}{2}\right)^t$，底 $\dfrac{1}{2} < 1$，在 $\mathbb{R}$ 上**递减**。

**应用同增异减**（外层处处递减）：

- 在 $(-\infty, 1]$ 上：$g$ 减，$f$ 减，**异方向×异方向 = 同向** → 整体**递增**
- 在 $[1, +\infty)$ 上：$g$ 增，$f$ 减，**异方向** → 整体**递减**

**答：单调递增区间 $(-\infty, 1]$，单调递减区间 $[1, +\infty)$。**

**验证**：取 $x = 0, x = -1$（$0 > -1$，均在 $(-\infty, 1]$）：$g(0) = 0, g(-1) = 3$，故 $y(0) = (1/2)^0 = 1, y(-1) = (1/2)^3 = 1/8$。$x_1 = -1 < x_2 = 0$，$y(-1) = 1/8 < y(0) = 1$ ✓，确实递增。

---

### 例 3：抽象复合（已知 $f$ 求 $f(g(x))$ 的性质）

**题目**：已知 $f(x)$ 在 $\mathbb{R}$ 上严格递增，求 $y = f(x^2 - 1)$ 的单调递增区间。

**【思路】** 外层 $f$：递增。内层 $g(x) = x^2 - 1$：对称轴 $x = 0$，在 $(-\infty, 0]$ 递减，$[0, +\infty)$ 递增。

**定义域**：$f$ 在 $\mathbb{R}$ 上有定义，内层 $g(x) \in \mathbb{R}$ 对所有 $x$ 成立 → 定义域为 $\mathbb{R}$。

**同增异减**：

- 在 $(-\infty, 0]$ 上：$g$ 减，$f$ 增 → 异向 → 整体**递减**
- 在 $[0, +\infty)$ 上：$g$ 增，$f$ 增 → 同向 → 整体**递增**

**答：单调递增区间为 $[0, +\infty)$。**

## 七、思路自测题

**自测 1**　求 $y = \ln(4 - x^2)$ 的定义域与单调递减区间。

> 💡 提示：定义域：$4 - x^2 > 0 \Rightarrow x^2 < 4 \Rightarrow -2 < x < 2$。内层 $g(x) = 4 - x^2$ 在 $(-2, 0]$ 递增、$[0, 2)$ 递减；外层 $\ln t$ 递增。同增异减：递减区间为 $[0, 2)$（内减外增→异向→整体减）；递增区间为 $(-2, 0]$。

**自测 2**　求 $y = \left(\dfrac{1}{3}\right)^{2x-1}$ 的单调区间。

> 💡 提示：内层 $g(x) = 2x - 1$ 在 $\mathbb{R}$ 上递增；外层 $f(t) = (1/3)^t$ 在 $\mathbb{R}$ 上递减。内增外减→异向→整体**递减**。单调递减区间为 $\mathbb{R}$（即 $(-\infty, +\infty)$）。

**自测 3**　判断 $y = \sin(x^2)$ 在 $x \in [-1, 0]$ 上的单调性（提示：先分析内层，再查外层 $\sin$ 的单调性区间）。

> 💡 提示：内层 $g(x) = x^2$ 在 $[-1, 0]$ 递减，$g$ 的值域 $[0, 1]$；$\sin t$ 在 $[0, \pi/2]$ 递增，而 $[0, 1] \subset [0, \pi/2]$（因为 $1 < \pi/2 \approx 1.57$），外层递增。内减外增 → 异向 → 整体**递减**。

**自测 4**　已知偶函数 $f(x)$ 在 $[0, +\infty)$ 上递减，$g(x) = f(x^2 - 2x)$，求 $g(x)$ 的单调递增区间。

> 💡 提示：$g(x) = f(x^2 - 2x)$，$f$ 是偶函数 → $f(u) = f(|u|)$，$f$ 在 $[0, +\infty)$ 递减等价于 $f$ 在 $(-\infty, 0]$ 递增（偶函数对称性）。因此 $f$ 在 $(-\infty, 0]$ 递增、$[0, +\infty)$ 递减。令 $t = x^2 - 2x = (x-1)^2 - 1$：内层在 $(-\infty, 1]$ 递减，$[1, +\infty)$ 递增。要使 $g$ 递增：①内减外增（$t \leq 0$ 且 $x \in (-\infty,1]$）：$x^2-2x \leq 0 \Rightarrow 0 \leq x \leq 2$，与 $(-\infty,1]$ 取交集得 $[0,1]$；②内增外减（$t \geq 0$ 且 $x \in [1,+\infty)$）：$x^2-2x \geq 0 \Rightarrow x \leq 0$ 或 $x \geq 2$，与 $[1,+\infty)$ 取交集得 $[2, +\infty)$。递增区间：$[0, 1]$ 和 $[2, +\infty)$。

**自测 5**　证明：若 $f(x)$ 是奇函数，$g(x)$ 是偶函数，则 $h(x) = f(g(x))$ 是偶函数。

> 💡 提示：验证 $h(-x) = h(x)$。$h(-x) = f(g(-x)) = f(g(x))$（因为 $g$ 是偶函数，$g(-x) = g(x)$）$= h(x)$。所以 $h(-x) = h(x)$，$h$ 是偶函数。（这里 $f$ 的奇偶性并不影响结论，关键是内层 $g$ 是偶函数。）
