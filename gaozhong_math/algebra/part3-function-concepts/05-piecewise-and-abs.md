# 分段函数与含绝对值函数

> **核心要点**：  
> 分段函数是"同一个函数"，只是在不同区间用不同表达式——**先看 $x$ 落在哪段，再选对应公式**。  
> 含绝对值函数的本质是分段：$|f(x)| = \begin{cases} f(x), & f(x) \geq 0 \\ -f(x), & f(x) < 0 \end{cases}$，**绝对值的零点是分段点**。

---

## 一、引入：一道计算题

> **题目**：已知 $f(x) = \begin{cases} x^2 + 1, & x \leq 0 \\ 2x - 1, & x > 0 \end{cases}$，求 $f(f(-2))$。

先停下来，独立思考。这类题很多同学会出错——错在"忘记先算里层，再判断外层 $x$ 的范围"。

---

## 二、核心方法

### 分段函数的求值步骤

求 $f(a)$，分两步走：

1. **判断 $a$ 的范围**：看 $a$ 满足哪一段的条件
2. **代入对应表达式**：用那段的公式计算

**解题**（引入题）：

第一层：求 $f(-2)$

$$-2 \leq 0 \Rightarrow \text{用第一段} \Rightarrow f(-2) = (-2)^2 + 1 = 5$$

第二层：求 $f(f(-2)) = f(5)$

$$5 > 0 \Rightarrow \text{用第二段} \Rightarrow f(5) = 2 \times 5 - 1 = 9$$

**答：$f(f(-2)) = 9$。**

---

## 三、抽象成方法

### 分段函数的 3 类问题

**类型一：求函数值（复合值）**

口诀：**从里到外，每层判段**。

$$f(f(a)) \xrightarrow{\text{第一步}} \text{算} f(a) \xrightarrow{\text{第二步}} \text{以} f(a) \text{的值为新自变量，再次判段}$$

**类型二：已知函数值求自变量**

设 $f(x) = c$，按每段分别列方程，再验证解是否满足该段的条件。

**例**：$f(x) = \begin{cases} x^2 + 1, & x \leq 0 \\ 2x - 1, & x > 0 \end{cases}$，解 $f(x) = 5$。

- 在 $x \leq 0$ 段：$x^2 + 1 = 5 \Rightarrow x^2 = 4 \Rightarrow x = \pm 2$，检验：$x = -2 \leq 0$ ✓，$x = 2 > 0$ ✗（不满足该段条件）
- 在 $x > 0$ 段：$2x - 1 = 5 \Rightarrow x = 3$，检验：$3 > 0$ ✓

解为 $x = -2$ 或 $x = 3$。

**类型三：画分段函数图象**

每段在自己的区间内画对应函数的一部分，注意**端点是实心（含）还是空心（不含）**。

---

### 含绝对值函数：去绝对值的标准流程

**第一步：找零点**——令绝对值内部 $= 0$，解出临界点

**第二步：分段**——以零点为分界，讨论绝对值内的正负

**第三步：化简**——在每段区间上去掉绝对值符号

**化简规则**：
$$|A| = \begin{cases} A, & A \geq 0 \\ -A, & A < 0 \end{cases}$$

**例**：化简 $f(x) = |x - 1| + |x + 2|$

零点：$x = 1$（$x - 1 = 0$），$x = -2$（$x + 2 = 0$）

分三段讨论：

| 区间 | $x - 1$ 的符号 | $x + 2$ 的符号 | $f(x)$ |
|------|--------------|--------------|--------|
| $x < -2$ | $-$ | $-$ | $-(x-1) + (-(x+2)) = -2x - 1$ |
| $-2 \leq x \leq 1$ | $-$ | $+$ | $-(x-1) + (x+2) = 3$ |
| $x > 1$ | $+$ | $+$ | $(x-1) + (x+2) = 2x + 1$ |

$$f(x) = \begin{cases} -2x - 1, & x < -2 \\ 3, & -2 \leq x \leq 1 \\ 2x + 1, & x > 1 \end{cases}$$

**几何意义**：$|x - a|$ 表示数轴上 $x$ 与 $a$ 的距离。$|x-1| + |x+2|$ 是点 $x$ 到 $1$ 的距离加上到 $-2$ 的距离，在 $-2 \leq x \leq 1$ 之间取到最小值 $3$（两端点之间的距离）。

---

## 四、方法变形

### 变形 1：含绝对值的不等式（分类讨论法）

解 $|x - a| < b$（$b > 0$）：

$$|x - a| < b \Leftrightarrow -b < x - a < b \Leftrightarrow a - b < x < a + b$$

解 $|x - a| > b$（$b > 0$）：

$$|x - a| > b \Leftrightarrow x < a - b \text{ 或 } x > a + b$$

**含两个绝对值的不等式**：按零点分段后，逐段解不等式，取并集。

### 变形 2：含参数的分段函数

$f(x) = \begin{cases} ax + b, & x < c \\ \cdots \end{cases}$ 要求函数连续或单调 → 在 $x = c$ 处设等量关系。

**连续条件**：$\lim_{x \to c^-} f(x) = \lim_{x \to c^+} f(x)$，即两段在分段点的值相等。

### 变形 3：分段函数的单调性

- 每段内分别用定义法或导数法判断
- **跨段判断**：若两段在连接点处衔接（$f(c^-) \leq f(c^+)$ 对增函数），则可能全局单调

---

## 五、思考路标（条件反射训练）

1. **见分段函数求值** → 先判 $x$ 落哪段，再用对应表达式——不可直接代公式

2. **见 $f(f(a))$** → 从里到外，每层单独判断 $x$ 范围

3. **见已知函数值求 $x$** → 每段列方程，解完必须**验证 $x$ 是否满足该段约束**

4. **见含绝对值** → 找零点 → 分段 → 去绝对值（三步模板）

5. **见 $|x - a|$** → 联想"数轴距离"，几何直觉优先

6. **见 $|A| + |B|$ 求最小值** → 几何意义（三角不等式 $|A| + |B| \geq |A + B|$）或分三段讨论

7. **画分段函数图** → 端点实心/空心要标清（$\leq$ 或 $<$）

8. **见含参分段函数** → 分段点处检查连续性和单调性的衔接

## 六、应用例题

### 例 1：分段函数的复合值

**题目**：$f(x) = \begin{cases} 2^x, & x \geq 0 \\ x + 1, & x < 0 \end{cases}$，求 $f(f(-3))$。

**【思路】** 从里往外算。

**第一层**：$-3 < 0$，用第二段：$f(-3) = -3 + 1 = -2$

**第二层**：$f(f(-3)) = f(-2)$，$-2 < 0$，用第二段：$f(-2) = -2 + 1 = -1$

**答：$f(f(-3)) = -1$。**

---

### 例 2：含绝对值函数的图象与最小值

**题目**：画 $y = |x - 1| + |x + 2|$ 的图象，并求其最小值。

**【思路】** 按零点分三段。

零点：$x = 1, x = -2$，分三段（已在"三、抽象成方法"中化简）：

$$y = \begin{cases} -2x - 1, & x < -2 \\ 3, & -2 \leq x \leq 1 \\ 2x + 1, & x > 1 \end{cases}$$

**图象**：
- $x < -2$：斜率 $-2$ 的射线，向右下方
- $-2 \leq x \leq 1$：水平线段 $y = 3$（高度 3）
- $x > 1$：斜率 $2$ 的射线，向右上方

**最小值**：在 $-2 \leq x \leq 1$ 上 $y = 3$（常数），这是全局最小值。

**几何解释**：$-2$ 和 $1$ 之间的距离为 $3$，在两点之间时距离之和等于端点距离，达到最小值。

**答：最小值为 $3$，在 $-2 \leq x \leq 1$ 时取到。**

---

### 例 3：含绝对值不等式（呼应 toolkit/11 分类讨论）

**题目**：解不等式 $|x - 1| + |x + 2| < 5$。

**【思路】** 利用例 2 的分段结果，逐段解不等式。

在 $x < -2$ 时：$-2x - 1 < 5 \Rightarrow -2x < 6 \Rightarrow x > -3$

结合 $x < -2$：$-3 < x < -2$

在 $-2 \leq x \leq 1$ 时：$3 < 5$ 恒成立

所以 $-2 \leq x \leq 1$ 全部满足

在 $x > 1$ 时：$2x + 1 < 5 \Rightarrow 2x < 4 \Rightarrow x < 2$

结合 $x > 1$：$1 < x < 2$

取并集：$(-3, -2) \cup [-2, 1] \cup (1, 2) = (-3, 2)$

**答：解集为 $(-3, 2)$。**

**验证**：取 $x = 0$（在解集内）：$|0-1| + |0+2| = 1 + 2 = 3 < 5$ ✓；取 $x = 3$（在解集外）：$|3-1| + |3+2| = 2 + 5 = 7 \not< 5$ ✓

## 七、思路自测题

**自测 1**　已知 $f(x) = \begin{cases} x^2 - 2x, & x \leq 1 \\ x - 1, & x > 1 \end{cases}$，求 $f(f(3))$。

> 💡 提示：先算 $f(3)$：$3 > 1$，$f(3) = 3 - 1 = 2$；再算 $f(2)$：$2 > 1$，$f(2) = 2 - 1 = 1$。答：$f(f(3)) = 1$。

**自测 2**　化简 $f(x) = |2x - 3|$，写出分段形式，并求 $f(x) = 1$ 的解。

> 💡 提示：零点 $x = \dfrac{3}{2}$；$f(x) = \begin{cases} -(2x-3), & x < \dfrac{3}{2} \\ 2x-3, & x \geq \dfrac{3}{2} \end{cases}$。$f(x) = 1$：第一段 $-(2x-3)=1 \Rightarrow x=1$ ✓；第二段 $2x-3=1 \Rightarrow x=2$ ✓。解为 $x = 1$ 或 $x = 2$。

**自测 3**　解不等式 $|x + 1| - |x - 3| > 2$。

> 💡 提示：零点 $x = -1, x = 3$，分三段。$x < -1$：$-(x+1) - (-(x-3)) = -4 > 2$ 不成立；$-1 \leq x \leq 3$：$(x+1) - (-(x-3)) = 2x - 2 > 2 \Rightarrow x > 2$，结合区间得 $2 < x \leq 3$；$x > 3$：$(x+1) - (x-3) = 4 > 2$ 恒成立。解集：$(2, 3] \cup (3, +\infty) = (2, +\infty)$。

**自测 4**　已知 $f(x) = \begin{cases} -x + a, & x < 1 \\ x^2 - 2, & x \geq 1 \end{cases}$，若 $f(1) = f(0)$……等等，此题考查连续性。若要求 $f$ 在 $x = 1$ 处连续，求 $a$。

> 💡 提示：$f(1) = 1^2 - 2 = -1$（用第二段）；连续要求 $\lim_{x \to 1^-} f(x) = f(1)$，即 $-1 + a = -1$，解得 $a = 0$。
