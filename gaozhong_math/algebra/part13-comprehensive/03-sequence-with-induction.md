# 数列综合与数学归纳法

> **一例速记**：  
> **数学归纳法 3 步**：① 验证 $n = 1$ 基础情形 ② 假设 $n = k$ 成立 ③ 证明 $n = k + 1$ 也成立。  
> **数列不等式放缩**：$\dfrac{1}{k^2} < \dfrac{1}{k(k - 1)} = \dfrac{1}{k - 1} - \dfrac{1}{k}$（裂项放缩）；$\dfrac{1}{k^2} < \dfrac{1}{k(k+1)} \cdot ?$ 看方向。  
> **数列单调 + 有界 → 极限存在**（单调有界定理，高中只用结论）。

---

## 一、引入：证明 $\sum_{k=1}^n \frac{1}{k^2} < 2 - \frac{1}{n}$

> **题目**：求证：对任意 $n \geq 2$，$\displaystyle\sum_{k=1}^n \dfrac{1}{k^2} < 2 - \dfrac{1}{n}$。

请先停下来，自己想想：左边是 $1 + \dfrac{1}{4} + \dfrac{1}{9} + \cdots + \dfrac{1}{n^2}$，没有显式求和公式。右边是简洁表达。这种题，**两条主流路径**：

**路径 A：数学归纳法**。验 $n = 2$ 基础情形，假设 $n = k$ 成立，证 $n = k + 1$ 成立——但要找到一个能"启动归纳跨度"的手法。

**路径 B：放缩 + 裂项相消**。把每一项 $\dfrac{1}{k^2}$ 放大成一个"能裂项的"形式 $\dfrac{1}{k(k-1)} = \dfrac{1}{k-1} - \dfrac{1}{k}$，求和后大部分项相消。

路径 B 更有结构感。下面把内心独白完整还原。

---

## 二、思维路径还原（解题者的内心独白）

> "要证 $\displaystyle\sum_{k=1}^n \dfrac{1}{k^2} < 2 - \dfrac{1}{n}$。左边没有公式，右边长得像可以**裂项相消**得到的形式。**直觉**：$2 - \dfrac{1}{n} = 1 + \left(1 - \dfrac{1}{n}\right) = 1 + \sum_{k=2}^n \left(\dfrac{1}{k-1} - \dfrac{1}{k}\right)$（最后用了裂项展开 $\dfrac{1}{1} - \dfrac{1}{n}$）。
>
> **核心思路**：把 $\dfrac{1}{k^2}$ 放大成 $\dfrac{1}{k(k-1)}$（当 $k \geq 2$），即
>
> $$\frac{1}{k^2} < \frac{1}{k(k-1)} = \frac{1}{k-1} - \frac{1}{k}\quad (k \geq 2)$$
>
> **为什么这是放大？** $k(k-1) = k^2 - k < k^2$（当 $k \geq 2$ 时 $k > 0$），所以 $\dfrac{1}{k(k-1)} > \dfrac{1}{k^2}$。✓
>
> **裂项展开。**
>
> $$\sum_{k=2}^n \frac{1}{k^2} < \sum_{k=2}^n \left(\frac{1}{k-1} - \frac{1}{k}\right) = \left(\frac{1}{1} - \frac{1}{2}\right) + \left(\frac{1}{2} - \frac{1}{3}\right) + \cdots + \left(\frac{1}{n-1} - \frac{1}{n}\right)$$
>
> 中间项**完美相消**，剩下：$1 - \dfrac{1}{n}$。
>
> 即 $\displaystyle\sum_{k=2}^n \dfrac{1}{k^2} < 1 - \dfrac{1}{n}$。
>
> **单独处理 $k = 1$ 项**：$\dfrac{1}{1^2} = 1$。
>
> **合并**：$\displaystyle\sum_{k=1}^n \dfrac{1}{k^2} = 1 + \sum_{k=2}^n \dfrac{1}{k^2} < 1 + \left(1 - \dfrac{1}{n}\right) = 2 - \dfrac{1}{n}$。
>
> **证毕**。
>
> **关键反思**：为什么放缩成 $\dfrac{1}{k(k-1)}$ 而不是 $\dfrac{1}{k(k+1)}$？因为 $\dfrac{1}{k(k+1)} = \dfrac{1}{k} - \dfrac{1}{k+1}$ 是**缩小**（$\dfrac{1}{k(k+1)} < \dfrac{1}{k^2}$ 当 $k \geq 1$）。我要把和**放大**到上界 $2 - 1/n$，所以放大方向是 $\dfrac{1}{k^2} < \dfrac{1}{k(k-1)}$。
>
> **如果题目改为证下界** $\displaystyle\sum_{k=1}^n \dfrac{1}{k^2} > L$，方向要反过来，用 $\dfrac{1}{k^2} > \dfrac{1}{k(k+1)} = \dfrac{1}{k} - \dfrac{1}{k+1}$。
>
> **方向选择口诀**：证上界 → 用 $\dfrac{1}{k(k-1)}$（放大）；证下界 → 用 $\dfrac{1}{k(k+1)}$（缩小）。"

把这段内心独白读两遍，体会"目标决定放缩方向"的核心思想。

## 三、抽象成方法：3 类常见数列问题

### 3.1 第一类：数列不等式放缩 + 裂项相消

**典型形式**：求证 $\sum_{k=1}^n a_k$ 满足某不等式 $\leq$（或 $\geq$）某简洁表达。

**方法**：
1. **观察右边**：右边是否能写成裂项相消的累加 $\sum (b_{k-1} - b_k)$ 或类似。
2. **匹配放缩**：把 $a_k$ 放缩成形如 $b_{k-1} - b_k$（或 $c_k - c_{k+1}$）的差。
3. **求和相消**：累加后中间项消去，剩下首尾。
4. **单独处理边界项**：例如本节引例中 $k = 1$ 项需要单独加。

**经典放缩公式**：

$$\frac{1}{k^2} < \frac{1}{k(k-1)} = \frac{1}{k-1} - \frac{1}{k}\quad (k \geq 2)$$

$$\frac{1}{k^2} > \frac{1}{k(k+1)} = \frac{1}{k} - \frac{1}{k+1}\quad (k \geq 1)$$

$$\frac{1}{\sqrt{k}} > \frac{2}{\sqrt{k} + \sqrt{k+1}} = 2(\sqrt{k+1} - \sqrt{k})$$

$$\frac{1}{\sqrt{k}} < \frac{2}{\sqrt{k} + \sqrt{k-1}} = 2(\sqrt{k} - \sqrt{k-1})$$

$$\ln(1 + k) - \ln k = \ln\left(1 + \frac{1}{k}\right) < \frac{1}{k}$$

### 3.2 第二类：数学归纳法

**适用**：命题 $P(n)$ 对所有 $n \geq n_0$ 成立。

**第一数学归纳法 3 步**：

1. **基础（$n = n_0$）**：验证 $P(n_0)$ 成立。
2. **归纳假设**：假设 $P(k)$ 对某 $k \geq n_0$ 成立。
3. **归纳步骤**：在假设下证明 $P(k + 1)$ 成立。

**第二数学归纳法（强归纳）**：

1. 基础同上。
2. **强假设**：$P(n_0), P(n_0 + 1), \ldots, P(k)$ 都成立。
3. 证 $P(k + 1)$ 成立。

适用于递推依赖多个前项（如斐波那契、$a_{n+1} = a_n + a_{n-1}$ 类）。

**关键技巧**：在归纳步骤中，**只能使用归纳假设 $P(k)$（或更弱前项）**。绝不能用 $P(k+1)$（要证的）去推 $P(k+1)$（循环论证）。

### 3.3 第三类：数列单调 + 有界 → 极限存在

**单调有界定理**（高中只用结论）：

- $\{a_n\}$ 单调递增且**有上界** → $\{a_n\}$ 收敛（极限存在）。
- $\{a_n\}$ 单调递减且**有下界** → $\{a_n\}$ 收敛。

**典型应用**：递推数列 $a_{n+1} = f(a_n)$。

**步骤**：
1. **证单调**：归纳证 $a_{n+1} \geq a_n$（或 $\leq$）。
2. **证有界**：归纳证 $a_n \leq M$（或 $\geq L$）。
3. **求极限**：设 $\lim a_n = A$，在递推 $a_{n+1} = f(a_n)$ 两边取极限得 $A = f(A)$，解出 $A$。

## 四、方法变形：技巧汇总

### 4.1 放缩 + 裂项的"方向口诀"

**证 $\sum a_k \leq M$（上界）** → 把 $a_k$ **放大** 成可裂项的差。

**证 $\sum a_k \geq L$（下界）** → 把 $a_k$ **缩小** 成可裂项的差。

**常见两组互补放缩**：

| 项 | 放大（证上界） | 缩小（证下界） |
|---|---|---|
| $\dfrac{1}{k^2}$ | $\dfrac{1}{k(k-1)} = \dfrac{1}{k-1} - \dfrac{1}{k}$（$k \geq 2$） | $\dfrac{1}{k(k+1)} = \dfrac{1}{k} - \dfrac{1}{k+1}$ |
| $\dfrac{1}{\sqrt{k}}$ | $2(\sqrt{k} - \sqrt{k-1})$ | $2(\sqrt{k+1} - \sqrt{k})$ |
| $\dfrac{k!}{(k+m)!}$ | 看具体形式 | — |

### 4.2 数学归纳法的"凑形"技巧

归纳步骤中，从 $P(k)$ 推 $P(k+1)$ 时，**目标形式**是关键。常用技巧：

- **添加 / 减去**：把 $P(k+1)$ 的左右两边分别向 $P(k)$ 的形式靠拢。
- **代入 $P(k)$**：把假设 $P(k)$ 直接代入 $P(k+1)$ 的某个位置。
- **加强归纳**：有时 $P(n)$ 难证，但 $P(n) \wedge Q(n)$（更强命题）反而好归纳——加强后归纳假设更强，更容易推下一步。

**强归纳法示例**：求证 $a_n = 2^n - 1$ 满足某递推。可能需要 $a_{k-1}, a_k$ 一起用。

### 4.3 数列与函数 / 导数的交叉

**典型形式**：设 $a_n = f(n)$ 或 $a_n$ 由某函数 $f$ 递推。研究 $a_n$ 的性质，借助 $f$ 的单调性 / 极值。

**典型用法**：
- 证 $a_n$ 单调 → 看 $f$ 是否单调 / 利用归纳。
- 求 $\lim a_n$ → 用单调有界定理 + 不动点方程 $A = f(A)$。
- 数列不等式 → 转化为 $f$ 的不等式，用导数证。

### 4.4 错位相减 / 倒序相加

虽然不直接是放缩，但常常作为求和工具配合归纳 / 不等式：

- **错位相减**：求 $\sum a_n b_n$（$a$ 等差，$b$ 等比）。
- **倒序相加**：求对称型和 $\sum_{k=1}^n f(k/n)$ 等。

## 五、思考路标（条件反射训练）

下面每条都要反复内化：

1. **看到 $\sum \dfrac{1}{k^2}$、$\sum \dfrac{1}{k(k+1)}$、$\sum \dfrac{1}{\sqrt{k}}$ 等含 $k$ 的分式和** → 立即想"放缩 + 裂项"。

2. **看到"对任意 $n$ 成立"** → 优先归纳法或放缩法。

3. **归纳法 3 步**：验 $n_0$ → 假 $n = k$ → 证 $n = k + 1$。

4. **强归纳法**：当 $a_{n+1}$ 依赖 $a_n, a_{n-1}, \ldots$ 等多个前项时用。

5. **放缩方向口诀**：证上界 → 放大；证下界 → 缩小。

6. **裂项相消的经典对**：$\dfrac{1}{k(k+1)} = \dfrac{1}{k} - \dfrac{1}{k+1}$；$\dfrac{1}{k(k+2)} = \dfrac{1}{2}\left(\dfrac{1}{k} - \dfrac{1}{k+2}\right)$；$\dfrac{1}{\sqrt{k} + \sqrt{k+1}} = \sqrt{k+1} - \sqrt{k}$。

7. **看到递推数列 $a_{n+1} = f(a_n)$ + 问极限** → 证单调 + 证有界 → 用单调有界定理 + 不动点 $A = f(A)$。

8. **数列与导数交叉** → 把 $a_n$ 视为 $f$ 在 $n$ 上的取值，用 $f$ 的单调性 / 极值。

9. **加强归纳法**：原命题 $P(n)$ 难证 → 尝试加强 $P(n) \wedge Q(n)$，反而更易归纳。

10. **归纳步骤中绝不能用 $P(k+1)$ 推 $P(k+1)$**（循环论证），只能用 $P(k)$（或更弱前项）。

11. **看到 $a_n$ 是单调的、且 $a_n \leq M$ 的暗示** → 立即想极限存在。

12. **错位相减适用 $\sum$（等差 × 等比）**；倒序相加适用对称型和。

## 六、应用例题

### 例 1：放缩 + 裂项（证上界）

**题目**：求证：对任意 $n \in \mathbb{N}^*$，$\displaystyle\sum_{k=1}^n \dfrac{1}{(2k-1)(2k+1)} < \dfrac{1}{2}$。

**【解答】**

**思路**：看到 $\dfrac{1}{(2k-1)(2k+1)}$，标准裂项：

$$\frac{1}{(2k-1)(2k+1)} = \frac{1}{2}\left(\frac{1}{2k-1} - \frac{1}{2k+1}\right)$$

（验证：$\dfrac{1}{2k-1} - \dfrac{1}{2k+1} = \dfrac{(2k+1) - (2k-1)}{(2k-1)(2k+1)} = \dfrac{2}{(2k-1)(2k+1)}$ ✓）

**累加：**

$$\sum_{k=1}^n \frac{1}{(2k-1)(2k+1)} = \frac{1}{2}\sum_{k=1}^n \left(\frac{1}{2k-1} - \frac{1}{2k+1}\right)$$

中间项相消（$\dfrac{1}{3}, \dfrac{1}{5}, \ldots, \dfrac{1}{2n-1}$ 都出现两次且符号相反），剩下：

$$= \frac{1}{2}\left(\frac{1}{1} - \frac{1}{2n+1}\right) = \frac{1}{2} - \frac{1}{2(2n+1)}$$

由于 $\dfrac{1}{2(2n+1)} > 0$，故

$$\sum_{k=1}^n \frac{1}{(2k-1)(2k+1)} = \frac{1}{2} - \frac{1}{2(2n+1)} < \frac{1}{2}$$

证毕。

> 解题要点：① 此题严格等式相消，无需放缩。② 裂项系数 $\dfrac{1}{2}$ 不要漏。③ 中间项"两次"出现是相消机制。

### 例 2：数学归纳法（含不等式）

**题目**：求证：对任意 $n \in \mathbb{N}^*$，$\displaystyle\sum_{k=1}^n \dfrac{1}{2^k} < 1$。

**【解答】**

**思路**：左边是等比数列前 $n$ 项和，有公式：

$$S_n = \frac{1/2 \cdot (1 - (1/2)^n)}{1 - 1/2} = 1 - \frac{1}{2^n} < 1 \quad (\text{因 } \dfrac{1}{2^n} > 0)$$

直接公式法已证。**为练习归纳法，下面用归纳法。**

**第一步：基础 $n = 1$。** $S_1 = \dfrac{1}{2} < 1$ ✓。

**第二步：归纳假设。** 假设 $n = k$ 时 $S_k = \displaystyle\sum_{j=1}^k \dfrac{1}{2^j} < 1$。

**第三步：归纳步骤。** 证 $n = k + 1$ 时 $S_{k+1} < 1$。

$$S_{k+1} = S_k + \frac{1}{2^{k+1}}$$

由归纳假设 $S_k < 1$，但加上 $\dfrac{1}{2^{k+1}}$ 后未必 $< 1$——这是个**陷阱**。直接归纳失败。

**加强归纳法**：把命题加强为 $P(n)$："$S_n = 1 - \dfrac{1}{2^n}$"，比"$S_n < 1$"强得多。

**重做归纳。** 验 $n = 1$：$S_1 = 1/2 = 1 - 1/2$ ✓。假设 $S_k = 1 - 1/2^k$。则

$$S_{k+1} = S_k + \frac{1}{2^{k+1}} = 1 - \frac{1}{2^k} + \frac{1}{2^{k+1}} = 1 - \frac{2}{2^{k+1}} + \frac{1}{2^{k+1}} = 1 - \frac{1}{2^{k+1}}$$

形式正确，归纳完成。故 $S_n = 1 - \dfrac{1}{2^n}$，从而 $S_n < 1$。证毕。

> 解题要点：① 直接对不等式归纳常失败，因为 $P(k)$ 中信息不够强。② **加强归纳**：先证更强的等式（"$=$"形式），再推不等式。③ 这是归纳法的核心技巧。

### 例 3：数列 + 导数（单调 + 有界 → 极限）

**题目**：设 $a_1 = 1$，$a_{n+1} = \sqrt{2 + a_n}$（$n \geq 1$）。证明：
（1）$\{a_n\}$ 单调递增。
（2）$\{a_n\}$ 有上界 $2$。
（3）求 $\lim_{n \to \infty} a_n$。

**【解答】**

**（1）证 $\{a_n\}$ 单调递增。**

归纳证 $a_{n+1} > a_n$。

**基础 $n = 1$**：$a_2 = \sqrt{2 + 1} = \sqrt{3} \approx 1.732$，$a_1 = 1$。$a_2 > a_1$ ✓。

**归纳假设**：$a_{k+1} > a_k$。

**归纳步骤**：证 $a_{k+2} > a_{k+1}$。

$a_{k+2} = \sqrt{2 + a_{k+1}}$，$a_{k+1} = \sqrt{2 + a_k}$。由 $a_{k+1} > a_k$（假设），故 $2 + a_{k+1} > 2 + a_k$，开方（单调）：$\sqrt{2 + a_{k+1}} > \sqrt{2 + a_k}$，即 $a_{k+2} > a_{k+1}$ ✓。

**（2）证 $a_n < 2$。**

归纳证。

**基础**：$a_1 = 1 < 2$ ✓。

**归纳假设**：$a_k < 2$。

**归纳步骤**：$a_{k+1} = \sqrt{2 + a_k} < \sqrt{2 + 2} = 2$ ✓。

**（3）求 $\lim a_n$。**

由 (1) 和 (2)，$\{a_n\}$ 单调递增且有上界 $2$。由**单调有界定理**，$\{a_n\}$ 收敛。设 $\lim a_n = A$。

在递推 $a_{n+1} = \sqrt{2 + a_n}$ 两边取 $n \to \infty$ 的极限：

$$A = \sqrt{2 + A}$$

两边平方：$A^2 = 2 + A \iff A^2 - A - 2 = 0 \iff (A - 2)(A + 1) = 0 \iff A = 2$ 或 $A = -1$。

由于 $a_n > 0$ 故 $A \geq 0$，舍去 $A = -1$。**$\lim a_n = 2$**。

> 解题要点：① 单调 + 有界 → 极限存在（必须先证两条件）。② 极限值由**不动点方程** $A = f(A)$ 求得。③ 解方程时舍去不符合的根（如负根、不在区间内的根）。

## 七、思路自测题

**自测 1**　求证：对任意 $n \in \mathbb{N}^*$，$\displaystyle\sum_{k=1}^n \dfrac{1}{k(k+1)} < 1$。

> 💡 提示：$\dfrac{1}{k(k+1)} = \dfrac{1}{k} - \dfrac{1}{k+1}$。累加得 $S_n = 1 - \dfrac{1}{n+1} < 1$ ✓。直接相消，严格 $<$。

**自测 2**　求证：对任意 $n \geq 1$，$\displaystyle\sum_{k=1}^n \dfrac{1}{\sqrt{k}} > 2(\sqrt{n+1} - 1)$。

> 💡 提示：缩小 $\dfrac{1}{\sqrt{k}} > \dfrac{2}{\sqrt{k} + \sqrt{k+1}} = 2(\sqrt{k+1} - \sqrt{k})$（分母有理化：$\dfrac{2}{\sqrt{k} + \sqrt{k+1}} = \dfrac{2(\sqrt{k+1} - \sqrt{k})}{(\sqrt{k+1})^2 - (\sqrt{k})^2} = 2(\sqrt{k+1} - \sqrt{k})$；与 $\dfrac{1}{\sqrt{k}}$ 比较：$\dfrac{1}{\sqrt{k}}$ vs $\dfrac{2}{\sqrt{k} + \sqrt{k+1}}$，分子同为 $1$ vs $2$，分母 $\sqrt{k}$ vs $\dfrac{\sqrt{k} + \sqrt{k+1}}{2} > \sqrt{k}$，所以 $\dfrac{1}{\sqrt{k}} > \dfrac{2}{\sqrt{k} + \sqrt{k+1}}$ ✓）。累加 $\sum_{k=1}^n 2(\sqrt{k+1} - \sqrt{k}) = 2(\sqrt{n+1} - 1)$（裂项相消）。故左 $>$ 右。

**自测 3**　用数学归纳法证明：对任意 $n \in \mathbb{N}^*$，$1 + 2 + 3 + \cdots + n = \dfrac{n(n+1)}{2}$。

> 💡 提示：验 $n = 1$：$1 = 1 \cdot 2 / 2 = 1$ ✓。假设 $S_k = k(k+1)/2$。则 $S_{k+1} = S_k + (k+1) = k(k+1)/2 + (k+1) = (k+1)(k/2 + 1) = (k+1)(k+2)/2$ ✓。归纳完成。

**自测 4**　设 $a_1 = 2$，$a_{n+1} = \dfrac{1}{2}\left(a_n + \dfrac{3}{a_n}\right)$。证明 $\{a_n\}$ 收敛并求其极限。

> 💡 提示：**先猜极限**。不动点 $A = \dfrac{1}{2}(A + 3/A) \iff 2A = A + 3/A \iff A = 3/A \iff A^2 = 3 \iff A = \sqrt{3}$（取正根）。**证单调有界**。
> 
> **证 $a_n \geq \sqrt{3}$**（下界）：归纳。$a_1 = 2 \geq \sqrt{3} \approx 1.732$ ✓。假设 $a_k \geq \sqrt{3}$。$a_{k+1} = \dfrac{1}{2}(a_k + 3/a_k) \geq \sqrt{a_k \cdot 3/a_k} = \sqrt{3}$（均值不等式）✓。
> 
> **证 $\{a_n\}$ 单调递减**：$a_{n+1} - a_n = \dfrac{1}{2}(a_n + 3/a_n) - a_n = \dfrac{1}{2}(3/a_n - a_n) = \dfrac{3 - a_n^2}{2a_n}$。$a_n \geq \sqrt{3}$ 故 $a_n^2 \geq 3$，分子 $\leq 0$，分母 $> 0$，所以 $a_{n+1} - a_n \leq 0$，$\{a_n\}$ 递减。
> 
> 单调递减 + 有下界 $\sqrt{3}$ → 收敛。极限 $= \sqrt{3}$。
