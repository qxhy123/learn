# 单调性与极值思想

> **一例速记**：判断 $f(x) = \dfrac{x}{x+1}$ 在 $(-1, +\infty)$ 上是否单调。
> 取 $x_1 < x_2$（均大于 $-1$），$f(x_1) - f(x_2) = \dfrac{x_1-x_2}{(x_1+1)(x_2+1)}$。分子 $x_1 - x_2 < 0$，分母 $(x_1+1)(x_2+1) > 0$，故差 $< 0$，即 $f(x_1) < f(x_2)$。**严格单调递增。这是定义法判单调性的标准三步：作差、化简、判符号。**

---

## 一、单调性——函数行为的骨架

单调性是高中函数理论中最基础的性质，几乎所有函数题都以单调性为核心工具：

- **解方程**：若 $f$ 在区间上严格单调，则 $f(x) = a$ 最多一个解；
- **解不等式**：$f(x) > a$ 等价于 $x$ 在 $f(x) = a$ 解的左侧或右侧（取决于增减方向）；
- **求最值**：单调函数在闭区间上，最值在端点取到；
- **证明不等式**：构造辅助函数，用单调性从 $f(x) \geq f(0)$ 推出不等式。

高中单调性的四条主线：

| 主线 | 工具 | 核心思路 |
|---|---|---|
| **定义法** | 作差比较 | 取 $x_1 < x_2$，分析 $f(x_1) - f(x_2)$ 的符号 |
| **导数法** | $f'(x)$ 的符号 | $f'(x) > 0$ 在区间上 → 递增；$f'(x) < 0$ → 递减 |
| **复合函数法** | 同增异减 | 见 toolkit 07 |
| **单调性应用** | 比较大小、解方程/不等式 | 把问题转化为区间内函数值的比较 |

---

## 二、单调性的严格定义

**定义**：设 $f$ 在区间 $I$ 上有定义。

- 若对任意 $x_1, x_2 \in I$，$x_1 < x_2 \Rightarrow f(x_1) < f(x_2)$，称 $f$ 在 $I$ 上**严格单调递增**；
- 若对任意 $x_1, x_2 \in I$，$x_1 < x_2 \Rightarrow f(x_1) > f(x_2)$，称 $f$ 在 $I$ 上**严格单调递减**。

**要点**：
1. 单调性必须指定区间——同一函数在不同区间可以有不同的单调性；
2. 定义中的 $x_1, x_2$ 是任意的，证明时不能只举一个特例；
3. 严格单调函数的逆函数存在（单射）。

---

## 三、定义法：三步走

**标准格式**（以证递增为例）：

> **设 $x_1, x_2 \in I$ 且 $x_1 < x_2$**（"设"，规范开头）
>
> **计算 $f(x_1) - f(x_2)$**（"作差"，核心步骤）
>
> **化简并判断符号**（"判号"，得出结论）

**常用判号技巧**：

| 表达式形态 | 判号方法 |
|---|---|
| 分式 $\dfrac{P}{Q}$ | 分子分母分别判符号 |
| 差 $P - Q$（多项式） | 因式分解，或配方 |
| 含根式 | 有理化（乘共轭）后处理分子 |
| 含对数 | 用 $\ln$ 单调性转化比较 |

## 四、完整演示题：定义法判断单调性

**题目**：判断 $f(x) = \dfrac{x}{x+1}$ 在 $(-1, +\infty)$ 上的单调性，并加以证明。

> **设 $x_1, x_2 \in (-1, +\infty)$ 且 $x_1 < x_2$。**
>
> **作差：**
>
> $$f(x_1) - f(x_2) = \frac{x_1}{x_1+1} - \frac{x_2}{x_2+1} = \frac{x_1(x_2+1) - x_2(x_1+1)}{(x_1+1)(x_2+1)}$$
>
> 展开分子：$x_1 x_2 + x_1 - x_1 x_2 - x_2 = x_1 - x_2$。
>
> $$f(x_1) - f(x_2) = \frac{x_1 - x_2}{(x_1+1)(x_2+1)}.$$
>
> **判号：**
>
> 因为 $x_1 < x_2$，所以分子 $x_1 - x_2 < 0$。
>
> 因为 $x_1, x_2 > -1$，所以 $x_1 + 1 > 0$ 且 $x_2 + 1 > 0$，分母 $(x_1+1)(x_2+1) > 0$。
>
> 故 $f(x_1) - f(x_2) < 0$，即 $f(x_1) < f(x_2)$。
>
> **结论：$f(x)$ 在 $(-1, +\infty)$ 上严格单调递增。**

**导数验证**：$f'(x) = \dfrac{(x+1) - x}{(x+1)^2} = \dfrac{1}{(x+1)^2} > 0$（$x \neq -1$）→ 验证结论正确。

## 五、导数判单调性（高中阶段的核心工具）

对可导函数，导数判单调性更快捷：

$$f'(x) > 0 \text{ 在区间 } I \text{ 上} \Rightarrow f \text{ 在 } I \text{ 上单调递增}$$

$$f'(x) < 0 \text{ 在区间 } I \text{ 上} \Rightarrow f \text{ 在 } I \text{ 上单调递减}$$

$$f'(x_0) = 0 \text{ 且 } f' \text{ 在 } x_0 \text{ 两侧变号} \Rightarrow x_0 \text{ 是极值点}$$

**求单调区间的标准步骤**：

1. 求 $f'(x)$；
2. 令 $f'(x) = 0$，找出所有驻点（$f'=0$ 的点）；
3. 加上 $f'$ 不存在的点（如尖点、端点）；
4. 这些点把定义域分成若干区间；
5. 在每个区间上取一点，判断 $f'$ 的符号，即可确定增减。

**例**：求 $f(x) = x^3 - 3x + 2$ 的单调区间。

$f'(x) = 3x^2 - 3 = 3(x-1)(x+1)$，驻点 $x = \pm 1$。

分区间：$(-\infty, -1)$，$(-1, 1)$，$(1, +\infty)$。

- $x \in (-\infty, -1)$：取 $x = -2$，$f'(-2) = 3(3)(-1) = 9 > 0$，递增；
- $x \in (-1, 1)$：取 $x = 0$，$f'(0) = -3 < 0$，递减；
- $x \in (1, +\infty)$：取 $x = 2$，$f'(2) = 9 > 0$，递增。

单调递增区间：$(-\infty, -1)$，$(1, +\infty)$；单调递减区间：$(-1, 1)$。

## 六、极值与最值的区别

| | **极值**（local extremum） | **最值**（global maximum/minimum） |
|---|---|---|
| 定义 | 函数在某点邻域内的局部最大或最小值 | 函数在整个定义域（或给定区间）上的全局最大/最小值 |
| 来源 | 导数为零（驻点）且变号；或导数不存在的角点 | 极值点 + 区间端点，取全局最大/最小 |
| 是否唯一 | 可以有多个极大值和多个极小值 | 最大值和最小值各最多一个 |
| 关系 | 极大值不一定 $\geq$ 极小值 | 最大值 $\geq$ 所有极大值；最小值 $\leq$ 所有极小值 |

**闭区间上连续函数的最值**：在极值点 + 端点处逐一计算函数值，取最大/最小即可。

## 七、单调性的三大应用

### 应用一：用单调性比较大小

若能把两个数表达为同一函数在两个自变量处的值，利用单调性即可比较大小，无需计算具体数值。

**例**：比较 $\log_{0.3} 0.4$ 与 $\log_{0.3} 0.5$ 的大小。

$f(x) = \log_{0.3} x$ 底数 $0.3 < 1$，单调递减，$0.4 < 0.5$ 故 $f(0.4) > f(0.5)$，即 $\log_{0.3} 0.4 > \log_{0.3} 0.5$。

---

### 应用二：用单调性解方程、确定根的个数

$f(x) = a$ 在区间 $I$ 上的解的个数，等于 $y = f(x)$ 与水平线 $y = a$ 的交点个数。若 $f$ 在 $I$ 上严格单调，则至多一个交点，方程至多一个根。

**例**：证明 $e^x = x + 2$ 恰好有一个根。

令 $F(x) = e^x - x - 2$，$F'(x) = e^x - 1$，$F'(x) = 0$ 时 $x = 0$，极小值 $F(0) = 1 - 0 - 2 = -1 < 0$。

$F(x) \to +\infty$（$x \to +\infty$），$F(x) \to +\infty$（$x \to -\infty$），$F$ 先减后增，且极小值 $< 0$，恰好与 $y = 0$ 有**两个**交点（根在 $x < 0$ 和 $x > 0$ 各一个）。

（注：如果极小值恰好为零则一个根，极小值大于零则无根。）

---

### 应用三：用单调性证明不等式（构造辅助函数）

这是高中代数中最强大的技法之一（与 toolkit 03 构造法紧密相关）。

**方法**：要证 $f(x) \geq g(x)$，令 $F(x) = f(x) - g(x)$，证 $F$ 在相关区间上 $\geq 0$。步骤：
1. 构造 $F(x) = f(x) - g(x)$；
2. 求 $F'(x)$，找单调区间和极值点；
3. 利用端点值 / 极值，证明 $F(x) \geq 0$ 恒成立。

**例**：证明 $\ln(1+x) < x$（$x > 0$）。

令 $F(x) = x - \ln(1+x)$（$x > 0$）。$F(0) = 0$，$F'(x) = 1 - \dfrac{1}{1+x} = \dfrac{x}{1+x} > 0$（$x > 0$）。

$F$ 在 $(0, +\infty)$ 严格单调递增，$F(0) = 0$，所以 $x > 0$ 时 $F(x) > F(0) = 0$，即 $x - \ln(1+x) > 0$，即 $\ln(1+x) < x$。

## 八、思考路标

**路标 1**：见到"判断/证明单调性" → 用**定义法三步**（设 $x_1 < x_2$、作差、判符号）；若函数可导，优先用**导数法**（更快）。定义法适用于导数不适用的场合（证明题、非可导函数）。

**路标 2**：作差后出现复杂分式 → 通分后仔细**分析分子的符号**，利用 $x_1 < x_2$ 的大小关系，逐步判断。

**路标 3**：用导数求单调区间 → 不要忘记**列成表格**（驻点把数轴分段，每段分别判断 $f'$ 符号）；标准步骤：求导 → 令导数等零 → 分区间 → 逐区间验证符号。

**路标 4**：求闭区间最值 → **三点比较法**（极值点函数值 + 两端点函数值，取最大最小）；遗漏端点是最常见的失分原因。

**路标 5**：证明不等式 → 优先考虑**构造辅助函数 $F = f - g$**，用单调性证 $F \geq 0$；从端点出发（$F(0) = 0$ 或 $F(\text{边界}) = 0$），再用导数证明 $F$ 单调。

**路标 6**：判断方程根的个数 → **数形结合 + 单调性**：把方程 $f(x) = a$ 看成两图象的交点，利用单调性分析不同 $a$ 值时交点个数。

**路标 7**：对复合函数的单调区间，**先求整体定义域，再用同增异减**（不能直接把内函数的单调区间拿来用，必须与定义域取交集）。

## 九、典型应用例题

### 例 1：定义法证严格单调性

**题目**：证明 $f(x) = 2x + \dfrac{1}{x}$ 在 $(-\infty, 0)$ 上单调递减。

**证明**：

设 $x_1, x_2 \in (-\infty, 0)$ 且 $x_1 < x_2 < 0$。

$$f(x_1) - f(x_2) = \left(2x_1 + \frac{1}{x_1}\right) - \left(2x_2 + \frac{1}{x_2}\right) = 2(x_1 - x_2) + \frac{x_2 - x_1}{x_1 x_2}$$

$$= (x_1 - x_2)\left(2 - \frac{1}{x_1 x_2}\right).$$

因为 $x_1 < x_2 < 0$，故 $x_1 - x_2 < 0$。

因为 $x_1 < 0, x_2 < 0$，故 $x_1 x_2 > 0$，$\dfrac{1}{x_1 x_2} > 0$；又 $|x_1|, |x_2| < $ 什么？注意 $x_1 < x_2 < 0$，$x_1 x_2 = |x_1||x_2|$，无法直接确定与 $\frac{1}{2}$ 的大小。

重新计算：

$$f(x_1) - f(x_2) = 2(x_1-x_2) + \frac{x_2-x_1}{x_1 x_2} = (x_1-x_2)\!\left(2 - \frac{1}{x_1 x_2}\right).$$

实际上直接用导数更可靠：$f'(x) = 2 - \dfrac{1}{x^2}$，在 $x < 0$ 时不一定恒负。

令 $f'(x) < 0$：$2 - \dfrac{1}{x^2} < 0 \Rightarrow x^2 < \dfrac{1}{2} \Rightarrow x \in \left(-\dfrac{1}{\sqrt{2}}, 0\right)$。

所以 $f(x)$ 在 $(-\infty, 0)$ 上**不是**单调的，而是在 $\left(-\infty, -\dfrac{\sqrt{2}}{2}\right)$ 上递增，在 $\left(-\dfrac{\sqrt{2}}{2}, 0\right)$ 上递减。

**此例说明**：定义法之前，先用导数法预判单调区间，避免在错误的区间上"证明"单调性。

正确结论：$f(x)$ 在 $\left(-\infty, -\dfrac{\sqrt{2}}{2}\right)$ 上单调递减（此处需重新用定义法验证）。

---

### 例 2：用单调性证不等式

**题目**：证明 $e^x \geq x + 1$（$x \in \mathbb{R}$），等号成立当且仅当 $x = 0$。

**证明**：

令 $F(x) = e^x - x - 1$，$F'(x) = e^x - 1$。

$F'(x) = 0 \Leftrightarrow x = 0$；$F'(x) < 0$（$x < 0$）；$F'(x) > 0$（$x > 0$）。

$F$ 在 $(-\infty, 0]$ 上单调递减，在 $[0, +\infty)$ 上单调递增，极小值在 $x = 0$ 处：$F(0) = 1 - 0 - 1 = 0$。

故对所有 $x \in \mathbb{R}$，$F(x) \geq F(0) = 0$，即 $e^x \geq x + 1$，等号成立当且仅当 $x = 0$。

---

### 例 3：闭区间最值问题

**题目**：求 $f(x) = x^3 - 3x + 1$ 在 $[-2, 2]$ 上的最大值和最小值。

**解**：

$f'(x) = 3x^2 - 3 = 3(x-1)(x+1)$，驻点 $x = \pm 1 \in [-2, 2]$。

计算各候选点函数值：

- $f(-2) = -8 + 6 + 1 = -1$；
- $f(-1) = -1 + 3 + 1 = 3$；
- $f(1) = 1 - 3 + 1 = -1$；
- $f(2) = 8 - 6 + 1 = 3$。

最大值为 $3$（在 $x = -1$ 和 $x = 2$ 处取得），最小值为 $-1$（在 $x = -2$ 和 $x = 1$ 处取得）。

## 十、自测题

**第 1 题**：用定义法证明 $f(x) = 3x - x^3$ 在 $[-1, 1]$ 上单调递增。

💡 提示：设 $-1 \leq x_1 < x_2 \leq 1$，计算 $f(x_1) - f(x_2) = 3(x_1-x_2) - (x_1^3 - x_2^3)$，利用 $x_1^3 - x_2^3 = (x_1-x_2)(x_1^2+x_1x_2+x_2^2)$ 提取 $x_1 - x_2$，再判断 $3 - (x_1^2+x_1x_2+x_2^2)$ 在 $[-1,1]$ 上的符号（注意 $x_1^2 + x_1 x_2 + x_2^2 \leq 1+1+1 = 3$，用均值或配方）。

**第 2 题**：求 $f(x) = x + \dfrac{4}{x}$（$x > 0$）的最小值，并写出单调区间。

💡 提示：$f'(x) = 1 - \dfrac{4}{x^2}$，令 $f' = 0$ 得 $x = 2$；$f' < 0$（$0 < x < 2$），$f' > 0$（$x > 2$）；极小值 $f(2) = 2 + 2 = 4$；或用均值不等式 $x + \frac{4}{x} \geq 2\sqrt{4} = 4$。

**第 3 题**：已知 $f(x)$ 在 $[0, 2]$ 上单调递增，$f(a^2) < f(1-a)$，求 $a$ 的范围。

💡 提示：由 $f$ 单调递增，$f(a^2) < f(1-a) \Rightarrow a^2 < 1-a$；同时要保证两个自变量都在 $[0,2]$ 内：$0 \leq a^2 \leq 2$（第一个自动满足），$0 \leq 1-a \leq 2$（即 $-1 \leq a \leq 1$）；联立解不等式组。

**第 4 题**：证明不等式 $\ln x \leq x - 1$（$x > 0$），等号成立当且仅当 $x = 1$。

💡 提示：令 $F(x) = \ln x - (x-1) = \ln x - x + 1$，求 $F'(x) = \dfrac{1}{x} - 1$，在 $(0,1)$ 上 $F' > 0$，在 $(1, +\infty)$ 上 $F' < 0$，极大值 $F(1) = 0$，故 $F(x) \leq 0$。

**第 5 题**：函数 $f(x) = x^2 - 4x + a$ 在 $[0, 3]$ 上的最小值为 $-1$，求 $a$ 的值。

💡 提示：$f(x) = (x-2)^2 + a - 4$，顶点 $x = 2 \in [0,3]$，最小值 $= a - 4$；令 $a - 4 = -1$，得 $a = 3$。
