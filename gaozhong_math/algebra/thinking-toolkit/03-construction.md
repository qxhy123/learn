# 构造法

> **一例速记**：证明 $e^x \geq 1 + x$ 对所有实数 $x$ 成立。
> 不是"硬证"，而是**构造辅助函数** $f(x) = e^x - 1 - x$，
> 求导得 $f'(x) = e^x - 1$，分析符号：$x > 0$ 时 $f' > 0$，$x < 0$ 时 $f' < 0$，
> 故 $x = 0$ 是 $f$ 的全局最小值点，$f(0) = 0$，
> 所以 $f(x) \geq f(0) = 0$，即 $e^x - 1 - x \geq 0$。证毕。
> **构造一个辅助函数，把不等式证明变成求最值问题。**

---

## 一、构造法：高中代数的标志性思想

高中以前，大多数数学题的解法是"直接算"：方程直接移项解出，不等式直接放缩或倒推。这些方法的共同特点是**从题目的原始形式出发，朝答案直线推进**。

构造法完全不同。它的逻辑是：**原题直接做很难，但如果我人为引入一个新对象（函数、数列、辅助式），通过分析这个新对象的性质，再反推原题的结论，问题就迎刃而解。**

这个"新对象"就是**辅助工具**，构造它的过程就是"构造法"。

高中代数里，构造法有三大经典场景：

1. **构造函数，证不等式**：把"$A \geq B$ 恒成立"转化为"$f(x) = A - B$ 的最小值 $\geq 0$"，用导数分析函数的最小值（或用配方、单调性），得出结论。
2. **构造辅助数列，求通项**：面对线性递推 $a_{n+1} = pa_n + q$，令 $b_n = a_n - k$（选择合适的 $k$）把递推式化为等比数列，再求等比数列的通项，最后回代。
3. **构造对称式，求积分值**：对含有 $f(x) + f(1-x)$、$f(x) + f(-x)$ 等对称关系的求和或积分，构造两式相加的"对偶"，直接算出结果。

这三类构造几乎覆盖了高考中构造法的全部考查场景。本篇将逐一展开，并通过演示题展示完整的"内心独白"。

---

## 二、三类经典构造详解

### 构造 1：构造函数证不等式

**核心思路**：要证 $A(x) \geq B(x)$（对某范围内的 $x$ 恒成立），令 $f(x) = A(x) - B(x)$，问题转化为证明 $f(x) \geq 0$ 在该范围内恒成立，即证明 $f$ 的最小值不小于零。

**标准步骤**：
1. 构造 $f(x) = A(x) - B(x)$（或 $B(x) - A(x)$，视哪侧更大而定）。
2. 求 $f$ 的导数 $f'(x)$（高中二年级知识），判断 $f$ 的单调性，找极值/最小值点。
3. 计算最小值点处的函数值，证明其 $\geq 0$（或 $\leq 0$），得出原不等式。

**常见构造对象**：

| 要证的不等式 | 构造函数 | 关键步骤 |
|---|---|---|
| $\ln(1+x) < x$（$x > 0$） | $f(x) = x - \ln(1+x)$ | $f'(x) = 1 - \dfrac{1}{1+x} = \dfrac{x}{1+x} > 0$（$x>0$），$f$ 在 $(0,+\infty)$ 递增，$f(0)=0$，故 $f(x) > 0$ |
| $e^x \geq 1 + x$（全体 $x$） | $f(x) = e^x - 1 - x$ | $f'(x) = e^x - 1$，$x = 0$ 是最小值点，$f(0) = 0$ |
| $x - 1 \geq \ln x$（$x > 0$） | $f(x) = x - 1 - \ln x$ | $f'(x) = 1 - \dfrac{1}{x}$，$x = 1$ 是最小值点，$f(1) = 0$ |
| $\sin x < x$（$x > 0$） | $f(x) = x - \sin x$ | $f'(x) = 1 - \cos x \geq 0$，$f$ 递增，$f(0) = 0$ |

**不用导数的版本**：若不涉及超越函数（如证明 $a^2 + b^2 \geq 2ab$），可用配方：$a^2 + b^2 - 2ab = (a-b)^2 \geq 0$，配方本身就是一种构造——构造了 $(a-b)^2$ 这个非负量。

---

### 构造 2：构造辅助数列化等比

**触发信号**：递推式形如 $a_{n+1} = pa_n + q$（$p \neq 0, 1$，$q \neq 0$），不是等差也不是等比。

**核心思路**：设辅助数列 $b_n = a_n - k$（待定常数 $k$），令 $b_{n+1} = pb_n$（等比递推），解出 $k$，则 $\{b_n\}$ 是以 $b_1 = a_1 - k$ 为首项、$p$ 为公比的等比数列，写出 $b_n = b_1 \cdot p^{n-1}$，回代 $a_n = b_n + k$。

**确定 $k$ 的方法**：

$$b_{n+1} = a_{n+1} - k = p a_n + q - k = p(b_n + k) + q - k = pb_n + pk + q - k.$$

要使 $b_{n+1} = pb_n$，需 $pk + q - k = 0$，即 $k(p-1) = -q$，故 $k = \dfrac{q}{1-p}$（因 $p \neq 1$）。

**例**：$a_{n+1} = 2a_n + 3$，$a_1 = 1$。$p = 2, q = 3$，$k = \dfrac{3}{1-2} = -3$。令 $b_n = a_n + 3$，$b_1 = 1 + 3 = 4$，$b_{n+1} = 2b_n$，故 $b_n = 4 \cdot 2^{n-1} = 2^{n+1}$，所以 $a_n = b_n - 3 = 2^{n+1} - 3$。

**变体**：若递推式形如 $a_{n+1} = pa_n + qn + r$（线性项 + 常数），辅助数列改为 $b_n = a_n - (An + B)$，$A, B$ 待定，构造等比或等差，步骤类似但多一步联立。

---

### 构造 3：构造对称式

**触发信号**：函数 $f$ 满足 $f(a + x) = f(a - x)$（对称轴 $x = a$），或 $f(x) + f(1-x) = C$，或求和 $\displaystyle\sum_{k=0}^{n} f\!\left(\dfrac{k}{n}\right)$ 中含对称配对。

**核心思路**：构造"对偶表达式"——把原式与将某变量替换后的新式相加，利用对称关系消去困难部分，直接得到结果。

**典型场景 1**：已知 $f(x) + f\!\left(\dfrac{1}{x}\right) = 1$（$x > 0$），求 $f(2) + f(3) + f\!\left(\dfrac{1}{2}\right) + f\!\left(\dfrac{1}{3}\right)$。

$$\left[f(2) + f\!\left(\tfrac{1}{2}\right)\right] + \left[f(3) + f\!\left(\tfrac{1}{3}\right)\right] = 1 + 1 = 2.$$

不需要知道 $f$ 的解析式，对称性给出了答案。

**典型场景 2**：求 $S = \displaystyle\sum_{k=1}^{n-1} f\!\left(\dfrac{k}{n}\right)$，其中 $f(x) + f(1-x) = 1$。

$$S = \sum_{k=1}^{n-1} f\!\left(\frac{k}{n}\right) = \sum_{k=1}^{n-1} f\!\left(\frac{n-k}{n}\right).$$

两式相加：$2S = \displaystyle\sum_{k=1}^{n-1}\left[f\!\left(\dfrac{k}{n}\right) + f\!\left(\dfrac{n-k}{n}\right)\right] = \sum_{k=1}^{n-1} 1 = n-1$，故 $S = \dfrac{n-1}{2}$。

## 三、演示：构造函数证不等式

### 题目：证明对所有实数 $x$，$e^x \geq 1 + x$

> 看到这道题，我要证的是 $e^x \geq 1 + x$，对所有 $x \in \mathbb{R}$ 成立。
>
> 两者都是 $x$ 的函数，不等号要在所有 $x$ 处成立——这是**恒成立不等式**。
>
> **触发构造法**：令 $f(x) = e^x - (1 + x) = e^x - 1 - x$，目标变为证 $f(x) \geq 0$ 对所有 $x \in \mathbb{R}$ 成立。等价地，证明 $f$ 的最小值 $\geq 0$。
>
> **求导分析**：
> $$f'(x) = e^x - 1.$$
>
> 分析 $f'(x)$ 的符号：
> - $x > 0$ 时：$e^x > e^0 = 1$，故 $f'(x) = e^x - 1 > 0$，$f$ 单调递增。
> - $x < 0$ 时：$e^x < 1$，故 $f'(x) = e^x - 1 < 0$，$f$ 单调递减。
> - $x = 0$ 时：$f'(0) = e^0 - 1 = 0$，导数为零。
>
> **结论**：$f$ 在 $(-\infty, 0)$ 上递减，在 $(0, +\infty)$ 上递增，$x = 0$ 是全局最小值点。
>
> **计算最小值**：
> $$f(0) = e^0 - 1 - 0 = 1 - 1 - 0 = 0.$$
>
> 因此，对所有 $x \in \mathbb{R}$，$f(x) \geq f(0) = 0$，即 $e^x - 1 - x \geq 0$，即 $e^x \geq 1 + x$。
>
> 等号当且仅当 $x = 0$ 时成立。$\square$
>
> **回顾**：构造法的关键在于"想到构造 $f(x) = e^x - 1 - x$"。看到要证"$A \geq B$ 恒成立"，就把左边减右边设为一个新函数，分析其最小值——这是构造法证不等式的固定套路。

## 四、思考路标

1. **见"恒成立不等式"** → 先问：能不能把两侧相减构造一个新函数 $f(x) = A - B$，再证 $f(x) \geq 0$（即 $f$ 的最小值 $\geq 0$）？如果有导数工具，用导数分析单调性 + 最小值；否则用配方或已知的基本不等式。

2. **见线性递推 $a_{n+1} = pa_n + q$（$p \neq 1$）** → 立刻构造辅助数列：令 $b_n = a_n - k$（$k = \dfrac{q}{1-p}$），$\{b_n\}$ 是等比数列，写出通项后回代。如果 $p = 1$，则是等差数列，不需要构造。

3. **见 $f(x) + f(1-x) = C$ 或 $f(x) + f\left(\dfrac{1}{x}\right) = C$** → 构造对偶：把原求和中的 $x$ 换成"对称点"，两式相加得到 $2S = n \cdot C$，直接给出结果，不需要知道 $f$ 的解析式。

4. **构造函数时，"减"的方向不能错**：要证 $A \geq B$，令 $f = A - B$；要证 $A \leq B$，令 $f = B - A$。始终保证 $f(x) \geq 0$ 是目标。构造完之后先检验 $f$ 在"边界点"（通常是等号成立的点）的值是否为零，以确认构造方向正确。

5. **构造辅助函数后，验证等号成立的条件**：不等式 $f(x) \geq 0$ 的等号条件往往是题目要求的"最优点"。记录等号成立时 $x$ 的取值，既是对结论的补充，也是验算的一种方式。

6. **对称式构造的"奇偶性加速"**：若 $f$ 是奇函数（$f(-x) = -f(x)$），则 $f(a) + f(-a) = 0$；若 $f$ 是偶函数，则 $f(a) + f(-a) = 2f(a)$。这是构造对称式的最简情形，遇到时直接利用，不必重复推导。

7. **构造法的"猜-验-推"三步**：构造什么辅助对象不是凭空而来的，而是从结论"反推"——想到"如果有这样一个函数/数列，我能证什么"，然后验证猜测是否可行，最后严格书写推导过程。很多时候，草稿纸上的"瞎猜"比"严格推导"更先出现。

## 五、典型应用 3 例

### 例 1：构造函数证经典不等式

**题目**：证明 $\ln(1 + x) \leq x$ 对所有 $x > -1$ 成立。

**思路**：

令 $f(x) = x - \ln(1+x)$（$x > -1$），目标化为证 $f(x) \geq 0$。

$$f'(x) = 1 - \frac{1}{1+x} = \frac{x}{1+x}.$$

当 $x > 0$ 时 $f'(x) > 0$，$f$ 递增；当 $-1 < x < 0$ 时 $f'(x) < 0$，$f$ 递减。$x = 0$ 是最小值点。

$f(0) = 0 - \ln 1 = 0$。故 $f(x) \geq 0$，即 $\ln(1+x) \leq x$ 对所有 $x > -1$ 成立。等号当且仅当 $x = 0$ 时成立。$\square$

---

### 例 2：构造辅助数列求通项

**题目**：数列 $\{a_n\}$ 满足 $a_1 = 3$，$a_{n+1} = 3a_n - 4$，求 $a_n$。

**思路**：

识别线性递推（$p = 3, q = -4$）。构造辅助常数：$k = \dfrac{q}{1-p} = \dfrac{-4}{1-3} = 2$。

令 $b_n = a_n - 2$，则 $b_1 = 3 - 2 = 1$，$b_{n+1} = a_{n+1} - 2 = 3a_n - 4 - 2 = 3(a_n - 2) = 3b_n$。

故 $\{b_n\}$ 是首项为 $1$、公比为 $3$ 的等比数列：$b_n = 3^{n-1}$。

回代：$a_n = b_n + 2 = 3^{n-1} + 2$。

**验证**：$a_1 = 3^0 + 2 = 3$ ✓；$a_2 = 3 \times 3 - 4 = 5 = 3^1 + 2$ ✓。

---

### 例 3：构造对称式求和

**题目**：已知 $f(x) + f(1-x) = 2$ 对所有实数 $x$ 成立，求 $S = f\!\left(\dfrac{1}{10}\right) + f\!\left(\dfrac{2}{10}\right) + \cdots + f\!\left(\dfrac{9}{10}\right)$。

**思路**：

构造对偶：在求和式 $S = \displaystyle\sum_{k=1}^{9} f\!\left(\dfrac{k}{10}\right)$ 中，把每个 $\dfrac{k}{10}$ 换成 $1 - \dfrac{k}{10} = \dfrac{10-k}{10}$：

$$S = f\!\left(\frac{9}{10}\right) + f\!\left(\frac{8}{10}\right) + \cdots + f\!\left(\frac{1}{10}\right)$$

（求和顺序颠倒，值不变）。两式相加：

$$2S = \sum_{k=1}^{9}\left[f\!\left(\frac{k}{10}\right) + f\!\left(\frac{10-k}{10}\right)\right] = \sum_{k=1}^{9}\left[f\!\left(\frac{k}{10}\right) + f\!\left(1 - \frac{k}{10}\right)\right] = \sum_{k=1}^{9} 2 = 18.$$

故 $S = 9$。

全程无需知道 $f$ 的解析式，对称关系给出了全部信息。

## 六、自测题

**第 1 题**：证明 $x - 1 \geq \ln x$ 对所有 $x > 0$ 成立。

💡 提示：构造 $f(x) = x - 1 - \ln x$，求导得 $f'(x) = 1 - \dfrac{1}{x} = \dfrac{x-1}{x}$，$x = 1$ 是最小值点，$f(1) = 0$，故 $f(x) \geq 0$ 恒成立。

---

**第 2 题**：数列 $\{a_n\}$ 满足 $a_1 = 5$，$a_{n+1} = 2a_n - 3$，求通项公式 $a_n$。

💡 提示：$p = 2, q = -3$，$k = \dfrac{-3}{1-2} = 3$。令 $b_n = a_n - 3$，$b_1 = 2$，$b_{n+1} = 2b_n$，等比数列，$b_n = 2^n$，故 $a_n = 2^n + 3$。

---

**第 3 题**：已知 $g(x) + g(2-x) = x^2 - 2x + 3$，求 $g(0) + g(1) + g(2)$ 的值。

💡 提示：令 $x = 0$：$g(0) + g(2) = 3$；令 $x = 1$：$g(1) + g(1) = 1 - 2 + 3 = 2$，故 $g(1) = 1$。三式相加：$g(0) + g(1) + g(2) = 3 + 1 = 4$。

---

**第 4 题**：用构造辅助数列法求满足 $a_1 = 1$，$a_{n+1} = 4a_n + 3$（$n \geq 1$）的通项公式。

💡 提示：$p = 4, q = 3$，$k = \dfrac{3}{1-4} = -1$。令 $b_n = a_n + 1$，$b_1 = 2$，$b_{n+1} = 4b_n$，等比，$b_n = 2 \cdot 4^{n-1}$，故 $a_n = 2 \cdot 4^{n-1} - 1$。

---

**第 5 题**：利用构造法（配方）证明：对任意实数 $a, b, c$，有 $a^2 + b^2 + c^2 \geq ab + bc + ca$。

💡 提示：构造 $f = a^2 + b^2 + c^2 - ab - bc - ca$，注意 $2f = (a-b)^2 + (b-c)^2 + (c-a)^2 \geq 0$，等号当 $a = b = c$ 时成立。这里"构造"的是 $2f$ 以及三个平方和的分拆方式。
