# 分类讨论框架

> **一例速记**：解不等式 $ax > 1$，答案是"当 $a > 0$ 时 $x > \dfrac{1}{a}$；当 $a = 0$ 时无解；当 $a < 0$ 时 $x < \dfrac{1}{a}$"。
> 三行写完，不重不漏，每行都从"当……时"开始，末行之后写综合结论。
> **这是分类讨论的标准书写格式，一个字都不能省。**

---

## 一、分类讨论的本质

分类讨论是高中代数中最重要的思维方式之一，也是最容易丢分的地方。所谓"分类讨论"，本质上是：**当一个数学命题的结论依赖于某个参数（或条件）的不同取值时，我们必须分别处理每种情形，不能一概而论**。

最常见的失误有两种：

- **漏类**：忘记了某个边界情形，例如漏掉 $a = 0$ 的情形；
- **不知道何时需要分类**：把不需要分类的题也分了，浪费时间；或者需要分类的题没有分，导致答案错误。

本篇的核心目标是给出两个框架：

1. **触发器**——什么情形下必须分类讨论；
2. **规则**——如何做到不重不漏、标准书写。

---

## 二、分类讨论的 5 大触发器

**遇到以下任何一种情形，必须启动分类讨论流程。**

| 触发器 | 描述 | 典型例子 |
|---|---|---|
| **触发器 1：含参** | 参数 $a$（或 $m$、$k$）在不同取值时改变方程 / 函数的性质 | $ax^2 + bx + c = 0$：$a = 0$ 时退化为一次方程；$a \neq 0$ 时才是二次方程 |
| **触发器 2：含绝对值** | 绝对值 $\|f(x)\|$ 按 $f(x)$ 的正负分两段 | 解 $\|x - 2\| < 3$：按 $x \geq 2$ 和 $x < 2$ 分类去绝对值 |
| **触发器 3：奇偶** | 指数 $n$ 的奇偶性影响符号或单调性 | $x^n > 0$ 的解：$n$ 为奇数时所有 $x > 0$；$n$ 为偶数时 $x \neq 0$ 即可 |
| **触发器 4：区间端点位置** | 单调区间的端点（对称轴、极值点、零点）是否落在限定区间内 | 求 $f(x) = ax^2 - 2x + 1$ 在 $[0, 1]$ 上的最小值：需判断顶点 $x = \frac{1}{a}$ 是否在 $[0,1]$ 内 |
| **触发器 5：函数零点位置** | 含参方程的根相对于某区间的位置（根在区间内外） | 二次方程在给定区间内有多少个实根：需按判别式和顶点位置综合分类 |

**自查口诀**：**参绝奇偶端零点，五类触发要记全。**

---

## 三、分类的 5 条规则

### 规则 1：不重不漏

每一类情形应当**精确覆盖所有可能性**，各类情形之间既不重叠、也不遗漏。

**检验方法**：把所有情形的参数范围写出来，取并集应恰好等于参数的全集（如 $\mathbb{R}$，或题目限定的范围）。

| 正确写法 | 错误写法（遗漏 $a = 0$） |
|---|---|
| 当 $a > 0$，当 $a = 0$，当 $a < 0$ | 当 $a > 0$，当 $a < 0$ |

端点处的等号（$\leq$ 还是 $<$）必须明确，不能模糊处理。

### 规则 2：标准书写格式

每种情形用以下格式开头：

> **当 $[\text{参数条件}]$ 时，**……（处理该情形，得出结论）。

结尾写综合：**综合以上各情形，……**

**禁止**用"分两种情况……"这样的口语；**禁止**跳过"当……时"直接写结论。

### 规则 3：先分类，后综合

所有情形**全部处理完毕**之后，再写一行综合结论。综合结论中用"或"连接各情形的结论，并注明对应的参数范围。

### 规则 4：优先分决定结构的参数

如果有多个可以分类的量，**优先分影响方程次数或函数开口的那个**。

例：含参二次（或退化一次）方程，首先按 $a = 0$（一次退化）与 $a \neq 0$（真二次）分类，不要先讨论判别式——因为判别式只在 $a \neq 0$ 时才有意义。

### 规则 5：越简越好

能分 2 类不分 3 类，能分 3 类不分 5 类。**分类越多，出错的概率越高，也越容易漏情形**。优先寻找最简的分割点。

---

## 四、参数分类的完整流程

遇到含参题时，按以下四步走：

**Step 1** — **识别触发器**：从 5 大触发器中找到哪些触发了分类的需求。

**Step 2** — **确定分割点**：找到使各类情形边界的参数值（如 $a = 0$、$a = 1$、$\Delta = 0$ 对应的 $a$）。

**Step 3** — **逐情形处理**：按从大到小（或从小到大）的顺序，依次写出每种情形，独立推导结论。

**Step 4** — **综合检验**：合并所有情形，检验分割点本身的边界情形是否遗漏，最后写综合结论。

---

## 五、演示题

**题目**：解关于 $x$ 的不等式 $ax^2 - (a+1)x + 1 > 0$，其中 $a$ 为实数参数。

> **Q1. 扫触发器。**
>
> 含参数 $a$，且 $a$ 出现在 $x^2$ 的系数上——**触发器 1（含参）**触发，且特别要注意 $a = 0$ 时方程退化为一次不等式。

> **Q2. 尝试因式分解。**
>
> 先观察结构：$ax^2 - (a+1)x + 1$。注意 $x = 1$ 是原不等式的一个根：代入 $x=1$，得 $a - (a+1) + 1 = 0$，成立。这提示我们可以提取因子 $(x-1)$。
>
> 做多项式除法（或待定系数）：
>
> $$ax^2 - (a+1)x + 1 = (x-1)(ax - 1)$$
>
> 验证：$(x-1)(ax-1) = ax^2 - x - ax + 1 = ax^2 - (a+1)x + 1$ ✓
>
> 所以不等式等价于 $(x-1)(ax-1) > 0$。

> **Q3. 确定分割点。**
>
> 另一个因子 $ax - 1 = 0$ 的解是 $x = \dfrac{1}{a}$（$a \neq 0$）。所以需要比较 $\dfrac{1}{a}$ 与 $1$ 的大小，这又依赖于 $a$ 的取值。分割点：$a = 0$、$0 < a < 1$、$a = 1$、$a > 1$、$a < 0$。

> **情形一：$a = 0$。**
>
> 原不等式变为 $0 \cdot x^2 - (0+1)x + 1 > 0$，即 $-x + 1 > 0$，解为 $x < 1$。

> **情形二：$a > 0$，$a \neq 1$。**
>
> 不等式为 $(x-1)\!\left(x - \dfrac{1}{a}\right) > 0$（两边同乘 $a > 0$，不改变不等号方向，但要把 $ax-1$ 写成 $a\!\left(x - \dfrac{1}{a}\right)$）。
>
> 两个零点为 $x = 1$ 和 $x = \dfrac{1}{a}$。需比较两者大小：
>
> - 若 $a > 1$：$\dfrac{1}{a} < 1$，零点顺序为 $\dfrac{1}{a} < 1$；二次因子开口向上，解为 $x < \dfrac{1}{a}$ 或 $x > 1$。
> - 若 $0 < a < 1$：$\dfrac{1}{a} > 1$，零点顺序为 $1 < \dfrac{1}{a}$；解为 $x < 1$ 或 $x > \dfrac{1}{a}$。
>
> （$a = 1$ 时 $\dfrac{1}{a} = 1$，两个零点重合，不等式变为 $a(x-1)^2 > 0$，解为 $x \neq 1$，即 $x \in (-\infty, 1) \cup (1, +\infty)$。）

> **情形三：$a < 0$。**
>
> 不等式为 $(x-1)\!\left(x - \dfrac{1}{a}\right) > 0$，但注意此时 $ax - 1 = a\!\left(x - \dfrac{1}{a}\right)$，$a < 0$，所以 $(x-1)(ax-1) = a(x-1)\!\left(x-\dfrac{1}{a}\right)$，整体乘以负的 $a$ 后不等号**反向**：
>
> $(x-1)(ax-1) > 0$
>
> $\Leftrightarrow (x-1) \cdot a \cdot \!\left(x - \dfrac{1}{a}\right) > 0$
>
> 因 $a < 0$，等价于 $(x-1)\!\left(x - \dfrac{1}{a}\right) < 0$（除以负数 $a$ 后变号）。
>
> 当 $a < 0$ 时，$\dfrac{1}{a} < 0 < 1$，零点顺序为 $\dfrac{1}{a} < 1$；$(x-1)(x-\frac{1}{a}) < 0$ 的解为 $\dfrac{1}{a} < x < 1$。

> **Q4. 综合结论。**
>
> 综合以上各情形：
>
> - 当 $a = 0$ 时，解集为 $\{x \mid x < 1\}$；
> - 当 $0 < a < 1$ 时，解集为 $\left\{x \mid x < 1 \text{ 或 } x > \dfrac{1}{a}\right\}$；
> - 当 $a = 1$ 时，解集为 $\{x \mid x \neq 1\}$；
> - 当 $a > 1$ 时，解集为 $\left\{x \mid x < \dfrac{1}{a} \text{ 或 } x > 1\right\}$；
> - 当 $a < 0$ 时，解集为 $\left\{x \mid \dfrac{1}{a} < x < 1\right\}$。

## 六、思考路标

**路标 1**：含参题第一步永远是**检查最低次系数**——如果参数出现在最高次项系数上，必须先考虑该系数为零时方程/函数退化的情形。遗漏 $a = 0$ 是最经典的失分点。

**路标 2**：绝对值分类的规范写法：先明确 $f(x) = 0$ 的分界点，再分区间写 $f(x) \geq 0$ 和 $f(x) < 0$ 两种情形。每种情形内部不再含绝对值，照常求解。

**路标 3**：分类时，边界点（如 $a = 0$、$a = 1$、$a = -1$ 等）**必须单独写一类**，不能合并到相邻情形中"顺手包含"。因为边界点处常常出现退化或特殊情形，和相邻区间的结论可能不同。

**路标 4**：对 $ax^2 + bx + c = 0$ 型含参二次方程，分类顺序是：先 $a = 0$（退化），后 $a \neq 0$（再谈判别式）。**不允许在没有排除 $a = 0$ 的情况下就使用求根公式**，因为求根公式只对 $a \neq 0$ 成立。

**路标 5**：区间端点位置触发器（触发器 4）的处理：将含参函数的极值点表达式 $x_0(a)$ 与区间端点比较，列不等式解出 $a$ 的范围，再分 3 种情形（$x_0 < \text{左端点}$、$\text{左端点} \leq x_0 \leq \text{右端点}$、$x_0 > \text{右端点}$）讨论。

**路标 6**：写完所有情形后，用**"综合以上情形"**一句话总结，并确认各情形的参数范围的并集等于题目给定的参数全集（如 $\mathbb{R}$）。如果并集有缺口，说明漏了某个情形。

**路标 7**：分类讨论的最终答案中，**每种情形的结论必须和条件配对**，不能把结论单独列出而不标注对应的参数范围。高考评分标准中，缺少参数条件标注通常要扣分。

## 七、典型应用例题

### 例 1：含参二次函数的最值问题

**题目**：已知 $f(x) = x^2 - 2ax + 1$（$x \in [0, 1]$），求 $f(x)$ 的最小值（用 $a$ 表示）。

**分析**：$f(x) = (x - a)^2 + 1 - a^2$，顶点为 $x = a$，开口向上。需按顶点 $a$ 与区间 $[0, 1]$ 的相对位置分三类。

**解**：

**当 $a < 0$ 时**，顶点在区间左侧，$f$ 在 $[0,1]$ 上单调递增，最小值在左端点：$f(0) = 1$。

**当 $0 \leq a \leq 1$ 时**，顶点在区间内，最小值在顶点处：$f(a) = 1 - a^2$。

**当 $a > 1$ 时**，顶点在区间右侧，$f$ 在 $[0,1]$ 上单调递减，最小值在右端点：$f(1) = 1 - 2a + 1 = 2 - 2a$。

**综合**：$f(x)$ 的最小值为

$$f_{\min} = \begin{cases} 1, & a < 0 \\ 1 - a^2, & 0 \leq a \leq 1 \\ 2 - 2a, & a > 1 \end{cases}$$

---

### 例 2：含绝对值的不等式

**题目**：解不等式 $|2x - 1| \leq x + 2$。

**分析**：绝对值的零点为 $x = \dfrac{1}{2}$，按此分两类。

**解**：

**当 $x \geq \dfrac{1}{2}$ 时**，$|2x - 1| = 2x - 1$，不等式变为 $2x - 1 \leq x + 2$，解得 $x \leq 3$。结合 $x \geq \dfrac{1}{2}$，得 $\dfrac{1}{2} \leq x \leq 3$。

**当 $x < \dfrac{1}{2}$ 时**，$|2x - 1| = 1 - 2x$，不等式变为 $1 - 2x \leq x + 2$，解得 $x \geq -\dfrac{1}{3}$。结合 $x < \dfrac{1}{2}$，得 $-\dfrac{1}{3} \leq x < \dfrac{1}{2}$。

**综合**：两段取并集，解集为 $-\dfrac{1}{3} \leq x \leq 3$，即 $x \in \left[-\dfrac{1}{3}, 3\right]$。

---

### 例 3：参数分离与分类结合

**题目**：已知关于 $x$ 的方程 $x^2 - 2x + a = 0$ 在区间 $(0, 3)$ 内有两个不等实根，求实数 $a$ 的范围。

**分析**：需同时满足：①有两个不等实根（判别式 $> 0$）；②两根都在 $(0, 3)$ 内（端点条件 + 顶点条件）。

**解**：

设 $f(x) = x^2 - 2x + a$，两根都在 $(0, 3)$ 内需要满足：

（1）$\Delta > 0$：$4 - 4a > 0 \Rightarrow a < 1$；

（2）顶点 $x = 1 \in (0, 3)$：已满足；

（3）$f(0) > 0$：$a > 0$；

（4）$f(3) > 0$：$9 - 6 + a > 0 \Rightarrow a > -3$；

（5）顶点函数值 $f(1) < 0$（保证两根夹住顶点）：$1 - 2 + a < 0 \Rightarrow a < 1$。

取交集：$\{a < 1\} \cap \{a > 0\} \cap \{a > -3\} \cap \{a < 1\} = 0 < a < 1$。

**综合**：$a$ 的范围为 $0 < a < 1$。

## 八、自测题

**第 1 题**：解不等式 $x^2 - (a+2)x + 2a < 0$（参数 $a \in \mathbb{R}$）。

💡 提示：先因式分解：$x^2 - (a+2)x + 2a = (x-2)(x-a)$。然后按 $a$ 与 $2$ 的大小关系分三类：$a < 2$，$a = 2$，$a > 2$。记住，当 $a = 2$ 时，两根重合，不等式 $(x-2)^2 < 0$ 无解。

**第 2 题**：求函数 $f(x) = |x^2 - 1|$ 的单调区间。

💡 提示：$x^2 - 1 = 0$ 的零点为 $x = \pm 1$。分三个区间：$x < -1$（$f = x^2 - 1$，递减）；$-1 \leq x \leq 1$（$f = 1 - x^2$，先增后减，顶点在 $x = 0$）；$x > 1$（$f = x^2 - 1$，递增）。单调递减区间：$(-\infty, -1)$ 和 $(0, 1)$；递增区间：$(-1, 0)$ 和 $(1, +\infty)$。

**第 3 题**：已知 $f(x) = \begin{cases} x + a, & x < 1 \\ ax^2 - 1, & x \geq 1 \end{cases}$ 在 $\mathbb{R}$ 上单调递增，求实数 $a$ 的范围。

💡 提示：需满足三个条件：（1）$x < 1$ 段斜率 $= 1 > 0$（已满足）；（2）$x \geq 1$ 段为开口向上的抛物线（$a > 0$）且单调递增区间要覆盖 $[1, +\infty)$，即顶点 $x = 0 \leq 1$（已满足）；（3）衔接处连续：$\lim_{x \to 1^-} f = 1 + a \leq f(1) = a - 1$，即 $1 + a \leq a - 1$，这给出 $1 \leq -1$，矛盾。说明左段从 $x \to 1^-$ 的极限必须不大于右段在 $x = 1$ 的值：$1 + a \leq a - 1$ 无解……重新审题：单调递增要求分段函数在 $x=1$ 处也不下降，即 $\lim_{x \to 1^-}(x+a) \leq f(1)$，即 $1+a \leq a(1)^2 - 1 = a - 1$，无解。说明无论 $a$ 取何值，该函数不能在 $\mathbb{R}$ 上单调递增（此题无解，也是一类典型的"无解情形"）。（若题目改为 $x \geq 1$ 段为 $ax + 1$，则有解 $a \geq 1$，同学可自行验证。）

**第 4 题**：已知方程 $|x - a| = x + 2$ 有解，求 $a$ 的范围。

💡 提示：分两类讨论绝对值。**当 $x \geq a$ 时**：$x - a = x + 2$，得 $-a = 2$，$a = -2$，此时任意 $x \geq -2$ 均为解，有解条件：$a = -2$ 且存在 $x \geq a = -2$（成立）；**当 $x < a$ 时**：$-(x-a) = x + 2$，得 $2x = a - 2$，$x = \dfrac{a-2}{2}$，需满足 $x < a$，即 $\dfrac{a-2}{2} < a$，化简得 $a > -2$；综合：$a \geq -2$。

**第 5 题**：设二次函数 $f(x) = x^2 + bx + c$ 满足 $f(1) = 0$ 且 $-1 \leq f(-1) \leq 2$，$0 \leq f(0) \leq 1$，求 $f(2)$ 的范围。

💡 提示：由 $f(1) = 0$：$1 + b + c = 0$，故 $c = -1 - b$。$f(-1) = 1 - b + c = 1 - b + (-1-b) = -2b$；$f(0) = c = -1 - b$。由条件得 $-1 \leq -2b \leq 2$（即 $-1 \leq b \leq \frac{1}{2}$）和 $0 \leq -1-b \leq 1$（即 $-2 \leq b \leq -1$）。取交集：$-1 \leq b \leq -1$，即 $b = -1$，$c = 0$，$f(x) = x^2 - x$，$f(2) = 2$。（若题目数据使得有区间范围，则 $f(2) = 4 + 2b + c$ 用参数范围估计。）
