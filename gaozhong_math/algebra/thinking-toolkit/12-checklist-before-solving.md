# 开题清单（高中版）

> **一例速记**：已知 $f(x) = x^3 - 3ax + 2$ 在 $[0, 2]$ 上最小值为 $-2$，求 $a$。
> 三秒钟的开题扫描：含参（$a$）、求最值、有区间限制、导数题——触发 Q4、Q6、Q7 三问，立即知道要按"顶点在区间内外"分类讨论，用**导数找极值点 + 三点比较法**求最小值，再令最小值 $= -2$ 解出 $a$。
> **这 3 秒的扫描，精准锁定整条解题路线。**

---

## 一、为什么高中题需要"开题 8 问"

初中的开题清单（7 问）聚焦于方程、不等式和简单函数；进入高中之后，题目的复杂度在三个维度同时提升：

1. **含参**的题大量出现，参数影响结构，导致必须分类讨论；
2. **证明题**的地位显著上升，不再只是"求答案"，而是"论证"；
3. **工具的选择空间扩大**：同一道题可能有导数法、不等式法、数形结合法等多种路径，选对了轻松，选错了绕圈。

这 3 个维度的提升，使得"开始算之前想清楚"的价值成倍增加。**高中最常见的错误不是不会算，而是方向选错、情形漏掉、验证缺失**。开题 8 问的目的，就是用一个快速的思维框架，在动笔之前把这三类错误扼杀在摇篮里。

本篇与工具箱 01（结构识别）、02（换元化简）、05（含参讨论）、08（单调极值）、11（分类讨论）高度互联——开题清单是调用所有这些工具的**指挥台**。

---

## 二、开题 8 问

### Q1. 这是什么类型的题？

**为什么问**：题型决定大方向和答案形式。

| 题型 | 关键词 / 标志 | 答案形式 |
|---|---|---|
| 纯运算 / 化简 | "化简"、"求值"（具体数字） | 一个数或代数式 |
| 求最值 | "最大值"、"最小值"、"值域"、"最小正整数" | 一个数（可能含参） |
| 证明 | "证明"、"证"、"试证" | 逻辑推导，末行是待证结论 |
| 含参讨论 | "求 $a$ 的范围"、"讨论 $m$ 取值"、"分情形" | 分情形的参数范围 |
| 存在性 | "是否存在"、"能否找到"、"何时有解" | "存在，此时……" 或 "不存在，因为……" |
| 恒成立 / 某时成立 | "对一切 $x$"、"恒成立"、"至少有一个 $x$" | 参数的充分条件或必要条件区间 |

**口诀**：先框题型，再看答案形式——写"$x = $"还是"$a \in$"还是"证毕"，不同题型写法完全不同。

---

### Q2. 代数式的结构是什么？

**为什么问**：结构决定变形路径。（呼应工具箱 01。）

快速扫描以下结构清单：

| 结构 | 对应操作 |
|---|---|
| $f(x) - f(a)$ | 作差因式分解，或导数定义 |
| $\dfrac{f(x)}{g(x)}$ + 求最值 | 换元 $t = x + c$ 或参数分离 $k = f/g$ |
| $a^2 + b^2$ 型（含三角） | 辅助角公式 $R\sin(\theta + \varphi)$ |
| $\ln f(x)$ 或 $e^{f(x)}$ | 换元 $t = f(x)$，或用基本不等式 $e^x \geq 1+x$ |
| 含 $\sqrt{f(x)}$ | 令 $t = \sqrt{f(x)}$，注意 $t \geq 0$ |
| 参数 $a$ 出现在最高次系数 | 先按 $a = 0$ 分类（触发器 1） |
| 含 $\|f(x)\|$ | 先找零点，按正负分段（触发器 2） |
| $f(n)$ 数列 + 求和 | 是否能错位相减 / 裂项 / 放缩（工具箱 10） |

---

### Q3. 有几个未知量？有几个等量（不等量）关系？

**为什么问**：等量关系数决定方程组是否可解；关系数不够，说明有隐含条件未挖出。

- 方程题：关系数 $\geq$ 未知数个数，才能确定求解；
- 最值题：往往有 $n-1$ 个约束，对 $n$ 个变量求极值（用 Lagrange 乘子法的直觉，高中版本是 "均值不等式 + 等号条件"）；
- 恒成立题：不等式对**所有 $x$** 成立，实际上有无穷多个约束，参数范围来自"对最极端的 $x$ 也成立"。

---

### Q4. 是否含参？如何讨论参数？

**为什么问**：含参题有专门的分析框架，不能当普通题做。（呼应工具箱 05 和工具箱 11。）

遇到含参题，按以下三种策略选一：

| 策略 | 适用情形 | 做法 |
|---|---|---|
| **分类讨论** | 参数影响方程次数、根个数、区间端点位置 | 找分割点，逐情形处理 |
| **参数分离** | 形如 $a > f(x)$ 对某区间上所有 $x$ 成立 | 变为 $a > \max f(x)$，转化为最值问题 |
| **主参反换** | 把 $x$ 视为已知，$a$ 视为变量，将方程看成关于 $a$ 的线性方程 | 通过 $a$ 的表达式分析根的存在性 |

---

### Q5. 是否需要先化简 / 换元？

**为什么问**：预处理做对了，后续计算量减少一半以上。（呼应工具箱 02。）

检查清单：

- 能展开 / 因式分解吗？
- 有复合函数，内层能整体换元吗？（令 $t = $ 内层，注意 $t$ 的范围）
- 含 $\sin^2 x + \cos^2 x = 1$、二倍角、积化和差等三角恒等式可用吗？
- 对数 / 指数可以取对数 / 指数化统一底数吗？
- 含参可以用参数分离，将参数 $a$ 单独放到不等号一侧吗？

---

### Q6. 用哪个工具？

**为什么问**：高中题的工具箱丰富但有重叠，选错工具会走弯路。

| 问题类型 | 首选工具 | 备用工具 |
|---|---|---|
| 证明不等式 $f(x) \geq g(x)$ | 构造 $F = f - g$，用导数证 $F \geq 0$（工具箱 03 + 08） | 直接用基本不等式（均值、柯西） |
| 函数单调区间 | 导数判号（工具箱 08） | 定义法（仅当导数不适用或题目指定时） |
| 求最值（闭区间） | 三点比较法（极值点 + 端点）（工具箱 08） | 图象直觉（验证） |
| 含参最值 | 先分类（工具箱 11），再分情形求三点比较 | 参数分离（工具箱 05） |
| 数列求和 | 错位相减（等比×等差）、裂项（工具箱 10）、放缩 | 归纳猜测 + 数学归纳法 |
| 函数方程 $f(x+y) = f(x)f(y)$ | 代入特殊值推性质（工具箱 06） | — |
| 恒成立 / 某时成立 | 参数分离 → 最值（工具箱 05） | 数形结合（图象法）（工具箱 04） |

---

### Q7. 答案的形式是什么？

**为什么问**：高中答案形式多样，提前确认能避免写出错误格式。

| 题目目标 | 答案形式 | 注意点 |
|---|---|---|
| 求参数范围 | $a \in [c_1, c_2]$ 或 $a > c$ 等 | 端点是开是闭（$<$ 还是 $\leq$） |
| 求函数最值 | 一个数（或含参表达式） | 说明在哪个点取到 |
| 证明不等式 | 逻辑推导链，末行是待证式 | 不能用待证式本身作为推导步骤（循环论证） |
| 求根 / 解集 | 集合或区间，或"无实数根" | 含参时每种情形配一个答案 |
| 存在性 | 先断言存在或不存在，再给出理由 | 若断言不存在，需反证或排尽所有情形 |

---

### Q8. 检验：代入特殊值 / 验证端点 / 反向推回

**为什么问**：很多错误只有在验证时才能发现——漏了一种情形、用错不等号方向、忘记验根。

| 检验方法 | 适用情形 |
|---|---|
| 代入特殊值（$x = 0$，$x = 1$，$a = 0$ 等） | 含参公式、一般不等式的验证 |
| 验证端点 | 区间端点处等号成立的判断；含参分类的边界情形 |
| 反向推回（验增根） | 分式方程、含绝对值方程、含对数方程（真数 $> 0$） |
| 检查各情形并集 | 含参分类讨论结束后，确认参数范围不重不漏 |
| 数形结合验证 | 用函数图象直观判断结论合理性 |

## 三、清单使用示范

**题目**：已知函数 $f(x) = x^3 - 3ax + 2$ 在 $x \in [0, 2]$ 上的最小值为 $-2$，求实数 $a$ 的值。

---

**Q1. 这是什么类型的题？**

> 含参数 $a$，且目标是"已知最小值，反求 $a$"——这是**含参最值题**。答案形式是 $a = $ 某个数（或若干个数）。
>
> 题型初判：需要先求出含 $a$ 的最小值表达式，再令其等于 $-2$，解出 $a$。

---

**Q2. 代数式的结构是什么？**

> $f(x) = x^3 - 3ax + 2$ 是关于 $x$ 的三次多项式。
>
> 注意到 $-3ax$ 项：$a$ 出现在一次项系数上，不影响次数（不需要按 $a = 0$ 退化讨论，但影响极值点位置）。
>
> 结构判断：**含参三次函数 + 闭区间最值**，标准做法是用导数求极值点，再做三点比较。

---

**Q3. 未知量和等量关系？**

> 未知量：$a$（1 个）。
>
> 等量关系：$f(x)$ 在 $[0, 2]$ 上的最小值 $= -2$（1 个约束）。
>
> 1 个未知量、1 个约束——恰好可以确定 $a$（可能有多个解）。

---

**Q4. 含参怎么讨论？**

> $a$ 出现在极值点位置 $x_0$ 的表达式中：$f'(x) = 3x^2 - 3a = 0 \Rightarrow x = \pm\sqrt{a}$（$a > 0$ 时）。
>
> 极值点 $x_0 = \sqrt{a}$ 是否在区间 $[0, 2]$ 内，取决于 $a$ 的大小——这触发**触发器 4（区间端点位置）**。
>
> 分割点：$\sqrt{a} = 0$（即 $a = 0$）和 $\sqrt{a} = 2$（即 $a = 4$）。还需考虑 $a < 0$（无极值点在区间内）。
>
> 分三大类：**$a \leq 0$、$0 < a \leq 4$、$a > 4$。**

---

**Q5. 需要先化简吗？**

> 先求导：$f'(x) = 3x^2 - 3a$。
>
> 令 $f'(x) = 0$：$x^2 = a$，$x = \sqrt{a}$（取正值，因为 $x \in [0, 2]$，负极值点不在区间内）。
>
> 化简已完成，接下来分情形讨论。

---

**Q6. 用哪个工具？**

> 含参最值题：**三点比较法**（工具箱 08 + 工具箱 11）。
>
> 分情形后，在每种情形内，候选点为：极值点 $\sqrt{a}$（如果在 $[0,2]$ 内）+ 两端点 $x = 0$ 和 $x = 2$。
>
> 取三点处函数值的最小值，再令其 $= -2$。

---

**Q7. 答案的形式？**

> 答案是 $a = $ 若干个具体值（因为是等号约束，通常解出有限个 $a$）。
>
> 注意：含参分类讨论结束后，每种情形内的 $a$ 解还需验证是否在该情形的参数范围内（否则舍去）。

---

**Q8. 开始解题，边解边检验。**

> **情形一：$a \leq 0$。**
>
> $f'(x) = 3x^2 - 3a \geq -3a \geq 0$（$x \in [0,2]$），$f$ 在 $[0,2]$ 上单调递增，最小值在左端点：
>
> $$f(0) = 0 - 0 + 2 = 2$$
>
> 令 $f(0) = -2$：$2 = -2$，矛盾。**此情形无解。**

> **情形二：$0 < a \leq 4$。**
>
> 极值点 $x_0 = \sqrt{a} \in (0, 2]$ 在区间内。
>
> $f'(x) < 0$ 当 $x \in (0, \sqrt{a})$（递减），$f'(x) > 0$ 当 $x \in (\sqrt{a}, 2)$（递增），所以 $x_0 = \sqrt{a}$ 是极小值点。
>
> 候选点及函数值：
>
> $$f(0) = 2$$
>
> $$f(\sqrt{a}) = (\sqrt{a})^3 - 3a\sqrt{a} + 2 = a\sqrt{a} - 3a\sqrt{a} + 2 = 2 - 2a\sqrt{a} = 2 - 2a^{3/2}$$
>
> $$f(2) = 8 - 6a + 2 = 10 - 6a$$
>
> 最小值在 $f(0) = 2$ 和 $f(\sqrt{a})$ 之间产生，因为 $f(\sqrt{a}) = 2 - 2a^{3/2} \leq 2 = f(0)$（$a > 0$）。
>
> 还需比较 $f(\sqrt{a})$ 和 $f(2) = 10 - 6a$：
>
> - 当 $a = 4$ 时，$f(2) = 10 - 24 = -14$，$f(\sqrt{4}) = f(2) = -14$，两者相等（$x_0 = \sqrt{4} = 2$ 恰在端点）；
> - 当 $0 < a < 4$ 时，需比较 $2 - 2a^{3/2}$ 与 $10 - 6a$ 的大小，这取决于 $a$ 的值（复杂，先各自令等于 $-2$）。
>
> 令 $f(\sqrt{a}) = -2$：$2 - 2a^{3/2} = -2 \Rightarrow a^{3/2} = 2 \Rightarrow a = 2^{2/3} = \sqrt[3]{4}$。
>
> 验证：$\sqrt[3]{4} \approx 1.587 \in (0, 4]$，且 $f(2) = 10 - 6\sqrt[3]{4} \approx 10 - 9.52 = 0.48 > -2$，所以此时最小值确实是 $f(\sqrt{a}) = -2$（不是端点值）。**解：$a = \sqrt[3]{4}$。**
>
> 令 $f(2) = -2$：$10 - 6a = -2 \Rightarrow a = 2$。
>
> 验证：$a = 2 \in (0,4]$；$f(\sqrt{2}) = 2 - 2(\sqrt{2})^3 = 2 - 4\sqrt{2} \approx 2 - 5.66 = -3.66 < -2$，所以此时最小值是 $f(\sqrt{2}) \approx -3.66 \neq -2$，**$a = 2$ 不满足条件**（最小值在极值点而非端点），舍去。

> **情形三：$a > 4$。**
>
> $\sqrt{a} > 2$，极小值点不在 $[0,2]$ 内，$f$ 在 $[0,2]$ 上单调递减，最小值在右端点：
>
> $$f(2) = 10 - 6a$$
>
> 令 $f(2) = -2$：$10 - 6a = -2 \Rightarrow a = 2$。但 $a = 2 \not> 4$，**此情形无解**。

> **Q8. 综合与检验。**
>
> 只有 $a = \sqrt[3]{4}$ 满足条件。
>
> 验证：$a = \sqrt[3]{4}$，极值点 $x_0 = \sqrt{\sqrt[3]{4}} = 4^{1/6}$，$f(4^{1/6}) = 2 - 2(\sqrt[3]{4})^{3/2} = 2 - 2 \cdot 4^{1/2} \cdot \sqrt[3]{4}^{0} $……直接验算：$a^{3/2} = (\sqrt[3]{4})^{3/2} = 4^{3/6} \cdot \text{...} = 4^{1/2} = 2$，所以 $f(\sqrt{a}) = 2 - 2 \times 2 = -2$ ✓。
>
> **最终答案：$a = \sqrt[3]{4}$。**

## 四、思考路标

**路标 1**：Q1 是开题最重要的一步——**不框清楚题型就动笔，是高中最常见的浪费时间方式之一**。特别要区分"求参数范围"（答案是区间）和"求参数值"（答案是有限个数），两者列方程的方式完全不同。

**路标 2**：Q4（含参）不是孤立的——它直接调用工具箱 11（分类框架）。一旦发现含参，立即问："参数出现在哪里？""它的取值会改变什么？"（次数？极值点位置？根的个数？）找到改变的关键量，就找到了分割点。

**路标 3**：Q6（选工具）是最需要经验的一步。**不确定时，优先选导数**——高中 90% 的函数题用导数都能解决。导数不够时（如纯代数恒等式、数列归纳），再考虑其他工具。不要因为想显得"高级"而用复杂方法，最直接的方法才是最可靠的。

**路标 4**：Q7（答案形式）要在**开始写答案之前**就确认好，而不是等到写完一长串计算再回头检查格式。含参分类讨论的答案必须每种情形配参数范围；存在性题必须先断言再证明；证明题末行必须是待证结论，不能是"显然""如上所示"等含糊表述。

**路标 5**：Q8（检验）不能省。**最容易被忽略的检验**：含参分类讨论后，每个情形内解出的参数值，必须代回验证它确实在该情形的参数范围内；否则这个解是"越界"的，应当舍去。

**路标 6**：证明题的 Q2（结构）特别关键——**要证的式子本身就是结构信息**。见到"证 $f(x) \geq g(x)$"，立刻想到构造 $F = f - g$，证 $F \geq 0$；见到"证 $a_n > 0$"，立刻想到数学归纳法或导数证单调性；见到"证 $\sum a_k < M$"，立刻想到放缩（工具箱 10）。

**路标 7**：Q3（等量关系数）对恒成立题有特殊用法：$f(x) \leq a$ 对所有 $x \in I$ 成立，等价于 $a \geq \max_{x \in I} f(x)$。这把"无穷多个约束"化为"一个最值约束"，将恒成立问题转化为最值问题——这是高考含参恒成立题的标准路线。

**路标 8**：整个 Q1—Q8 的流程，**不要求每次都逐字写出**，但要在脑子里快速过一遍。初学时每题用 2-3 分钟走一遍清单，一个月后就能把它内化为本能；那时看到题目的瞬间，Q1-Q8 的答案会同步涌现，整条解题路线几秒内成形。

## 五、典型应用例题

### 例 1：证明题（构造辅助函数）

**题目**：设 $a > 0$，$a \neq 1$，证明 $a + \dfrac{1}{a} \geq 2$，等号成立当且仅当 $a = 1$。

**Q1** — 证明题，末行需是 $a + \frac{1}{a} \geq 2$。

**Q2** — 结构：$a + \frac{1}{a}$ 型，可用均值不等式直接处理，也可用构造法。

**Q6** — 首选工具：均值不等式（最简）。

**证明**：

由 $a > 0$，均值不等式给出 $a + \dfrac{1}{a} \geq 2\sqrt{a \cdot \dfrac{1}{a}} = 2\sqrt{1} = 2$，等号成立当且仅当 $a = \dfrac{1}{a}$，即 $a = 1$。$\blacksquare$

---

### 例 2：恒成立问题（参数分离）

**题目**：若 $f(x) = x^2 - 2x + k$ 在 $x \in [0, 3]$ 上恒有 $f(x) > 0$，求实数 $k$ 的范围。

**Q1** — 含参恒成立题，答案是 $k$ 的范围（区间）。

**Q4** — 含参，用参数分离策略：$x^2 - 2x + k > 0 \Leftrightarrow k > -(x^2 - 2x) = 2x - x^2$，对所有 $x \in [0,3]$ 成立，即 $k > \max_{x \in [0,3]} (2x - x^2)$。

**Q6** — 求 $g(x) = 2x - x^2 = -(x-1)^2 + 1$ 在 $[0,3]$ 上的最大值：顶点 $x = 1 \in [0,3]$，最大值 $g(1) = 1$。

**Q7** — 答案形式：$k >$ 某数，开区间。

**Q8** — 检验：$k = 2 > 1$，$f(x) = x^2 - 2x + 2 = (x-1)^2 + 1 > 0$ ✓；$k = 1$，$f(1) = 1 - 2 + 1 = 0$，不满足严格大于 ✗。

**结论**：$k > 1$。

### 例 3：求参数值（含参三次最值）

**题目**：已知 $f(x) = x^3 - 3x$（即 $a = 1$ 时的特殊情形），$x \in [-2, 2]$，求其最大值和最小值。（本例不含参，但用作检验 Q1—Q8 流程的完整演练。）

**Q1** — 求最值，答案是两个数。

**Q2** — 三次函数，需求导找极值点。

**Q6** — 三点比较法：求导 $f'(x) = 3x^2 - 3 = 3(x-1)(x+1)$，驻点 $x = \pm 1$，均在 $[-2,2]$ 内。

**Q8** — 三点比较法候选点：$x = -2, -1, 1, 2$（端点 + 驻点）。

$$f(-2) = -8 + 6 = -2, \quad f(-1) = -1 + 3 = 2, \quad f(1) = 1 - 3 = -2, \quad f(2) = 8 - 6 = 2$$

最大值为 $2$（在 $x = -1$ 和 $x = 2$ 处取得），最小值为 $-2$（在 $x = -2$ 和 $x = 1$ 处取得）。

## 六、自测题

**第 1 题**：设 $f(x) = kx - \ln x$ 在 $(0, +\infty)$ 上单调递增，用 Q1—Q8 走一遍，求 $k$ 的范围。

💡 提示：Q1：含参单调性题，答案是 $k$ 的范围。Q2：对数函数结构。Q6：导数判单调。$f'(x) = k - \dfrac{1}{x}$，在 $(0, +\infty)$ 上 $f' \geq 0$ 恒成立等价于 $k \geq \dfrac{1}{x}$ 对所有 $x > 0$ 成立，即 $k \geq \max_{x>0}\dfrac{1}{x}$。注意 $\dfrac{1}{x} \to +\infty$（$x \to 0^+$），所以 $\sup \dfrac{1}{x} = +\infty$，无有限上界。因此无法取 $k$ 使得 $f$ 在整个 $(0, +\infty)$ 上单调递增。（答案：不存在这样的 $k$；若题目改为在 $[1, +\infty)$ 上单调递增，则 $k \geq 1$。）

**第 2 题**：解不等式 $\dfrac{ax + 1}{x - 1} > 0$（参数 $a \in \mathbb{R}$），用 Q1—Q8 走一遍。

💡 提示：Q1：含参不等式，答案按 $a$ 分类写解集。Q2：分式结构。Q4：分类触发，分割点为 $a = -1$（此时分子 $ax+1=0$ 的根 $x = -\frac{1}{a}$ 与分母根 $x = 1$ 关系改变）和 $a = 0$（分子退化为常数）。分三类：$a = 0$（解集 $x > 1$）；$a > 0$（两零点 $\frac{-1}{a}$ 和 $1$，需比较大小：$\frac{-1}{a} < 0 < 1$，解集 $x < \frac{-1}{a}$ 或 $x > 1$）；$a < 0$ 时，$\frac{-1}{a} > 0$，还需看 $\frac{-1}{a}$ 与 $1$ 的大小……自行分小类。

**第 3 题**：已知函数 $g(x) = 2\sin x \cos x + 2\sqrt{3}\cos^2 x$（$x \in \mathbb{R}$），求其最大值及取得最大值时 $x$ 的值。

💡 提示：Q2：$\sin 2x$ 和 $\cos 2x$ 结构。Q5：$g(x) = \sin 2x + \sqrt{3}(1 + \cos 2x) = \sin 2x + \sqrt{3}\cos 2x + \sqrt{3}$，用辅助角公式：$= 2\sin\!\left(2x + \dfrac{\pi}{3}\right) + \sqrt{3}$。Q7：最大值 $= 2 + \sqrt{3}$，当 $2x + \dfrac{\pi}{3} = \dfrac{\pi}{2}$，即 $x = \dfrac{\pi}{12} + k\pi$（$k \in \mathbb{Z}$）时取得。

**第 4 题**：已知 $f(x) = \ln x - x + 1$（$x > 0$），证明 $f(x) \leq 0$，并用 Q1—Q8 框定完整的证明逻辑。

💡 提示：Q1：证明不等式。Q2：$\ln x$ 结构，构造辅助函数 $F(x) = \ln x - x + 1$。Q6：导数判号：$F'(x) = \dfrac{1}{x} - 1 = \dfrac{1-x}{x}$；$F'(x) > 0$（$0 < x < 1$），$F'(x) < 0$（$x > 1$），极大值 $F(1) = 0$；所以 $F(x) \leq 0$ 对所有 $x > 0$ 成立，即 $\ln x \leq x - 1$，即 $\ln x - x + 1 \leq 0$。Q8：边界检验：$x = 1$ 时 $f(1) = 0$ ✓（等号成立）；$x = e$ 时 $f(e) = 1 - e + 1 = 2 - e \approx -0.718 < 0$ ✓。

**第 5 题**：已知 $a > 0$ 且 $a \neq 1$，函数 $f(x) = a^x$ 和 $g(x) = \log_a x$ 的图象在第一象限内有交点，求 $a$ 的范围，并说明 Q1—Q8 中哪几问起了关键作用。

💡 提示：Q1：存在性题（有交点），答案是 $a$ 的范围。Q2：指数 vs 对数，两函数互为反函数（关于 $y = x$ 对称）。Q5：$a^x = \log_a x$ 在第一象限有解，等价于 $y = a^x$ 与 $y = x$ 在第一象限有交点（因为 $a^x = \log_a x \Rightarrow a^x = x$ 或两曲线关于 $y=x$ 交于 $y=x$ 上的点）。切换为：$a^x = x$ 有解（$x > 0$），即 $a = x^{1/x}$（$x > 0$，$x \neq 1$）有解，即 $a$ 在 $x^{1/x}$ 的值域内。$h(x) = x^{1/x}$（$x > 0$）取对数：$\ln h = \frac{\ln x}{x}$，求导令为零得 $x = e$，最大值 $h(e) = e^{1/e}$。所以 $a \in (1, e^{1/e}]$（$a > 1$ 时才在第一象限有交点）。关键问：Q1（存在性）、Q2（结构互换）、Q5（换元化简）、Q6（导数找最大值）。
