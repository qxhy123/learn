# 极限与放缩

> **一例速记**：证明 $\displaystyle\sum_{k=1}^{n} \dfrac{1}{k^2} < 2$。
> 只需一句话：$\dfrac{1}{k^2} < \dfrac{1}{k(k-1)} = \dfrac{1}{k-1} - \dfrac{1}{k}$（$k \geq 2$），右边是裂项，累加之后大量抵消，总和不超过 $1$，再加上 $k=1$ 那项，总和小于 $2$。
> **这就是"放缩 + 裂项"两招组合，高中放缩题的标准套路。**

---

## 一、为什么高中需要"极限意识"

高中阶段不要求用 $\varepsilon$-$\delta$ 语言严格定义极限，但极限的直觉贯穿多个知识点：数列求和的估计、不等式的精确界、函数在边界处的趋势……当一道题要求"证明某个和式小于某个常数"或"说明某个量无限接近但不等于某个值"，本质上都在用极限思想。

高中语境下，极限意识主要体现在两类场合：

1. **数列放缩**：通过不等式估计将难以精确求和的数列放大或缩小为可以精确计算（尤其是裂项求和）的数列；
2. **函数放缩**：利用基本初等函数之间的大小关系（$\sin x < x$、$\ln(1+x) < x$、$e^x > 1+x$ 等）对复杂表达式进行估计。

掌握这套工具的价值在于：遇到形如"证明 $S_n < M$"的题，不需要精确求出 $S_n$，只需找到一个足够好的上界，然后证明这个上界 $\leq M$。

## 二、必须掌握的经典放缩不等式

### 2.1 汇总表

| 不等式 | 成立条件 | 来源 / 记忆方法 |
|---|---|---|
| $\sin x < x$ | $x > 0$ | 单调函数构造：$f(x) = x - \sin x$，$f(0)=0$，$f'>0$ |
| $x - \dfrac{x^3}{6} < \sin x < x$ | $x > 0$ | $\sin x$ 的 Taylor 展开截断（高考不要求推导，但要会用结论） |
| $\ln(1+x) < x$ | $x > 0$ | 构造 $F(x) = x - \ln(1+x)$，$F(0)=0$，$F'>0$ |
| $\dfrac{x}{1+x} < \ln(1+x) < x$ | $x > 0$ | 双侧界（左侧由 $-\ln(1+x) < -\frac{x}{1+x}$ 即 $\ln(1+x) > \frac{x}{1+x}$ 导出） |
| $e^x > 1 + x$ | $x \neq 0$ | 构造 $G(x) = e^x - 1 - x$，$G(0)=0$，极小值为 $0$ |
| $e^x \geq 1 + x$，等号 $x=0$ | $x \in \mathbb{R}$ | 同上，包含等号 |
| $\dfrac{1}{n(n+1)} = \dfrac{1}{n} - \dfrac{1}{n+1}$ | 正整数 $n$ | 裂项恒等式，是**等式**，不是放缩 |
| $\dfrac{1}{n^2} < \dfrac{1}{n(n-1)} = \dfrac{1}{n-1} - \dfrac{1}{n}$ | $n \geq 2$ | 先放大再裂项（两步组合） |
| $\dfrac{1}{n^2} > \dfrac{1}{n(n+1)} = \dfrac{1}{n} - \dfrac{1}{n+1}$ | $n \geq 1$ | 先缩小再裂项（用于证明下界） |

### 2.2 为什么这些不等式成立——统一思路

上表中函数类不等式（前三个）的证明思路完全一致：

**标准套路**：要证 $A(x) < B(x)$（$x > 0$），令 $F(x) = B(x) - A(x)$，验证三点——
1. $F(0) = 0$（边界处等号成立或边界值为 $0$）；
2. $F'(x) > 0$（$x > 0$ 时 $F$ 单调递增）；
3. 由 1 和 2 得 $F(x) > F(0) = 0$，即 $B(x) > A(x)$。

这个套路在工具箱 08（单调性）和工具箱 03（构造法）中均有详述，放缩不等式是两者的综合应用。

## 三、裂项求和——放缩的搭档

### 3.1 裂项的原理

"裂项"是把一个分式拆成两项之差，使得连续求和时大量抵消（望远镜式消去）。

**基本模板**：

$$\frac{1}{n(n+a)} = \frac{1}{a}\left(\frac{1}{n} - \frac{1}{n+a}\right)$$

**最常用的特殊情形**（$a = 1$）：

$$\frac{1}{n(n+1)} = \frac{1}{n} - \frac{1}{n+1}$$

**求和时的抵消**：

$$\sum_{k=1}^{n} \frac{1}{k(k+1)} = \left(1 - \frac{1}{2}\right) + \left(\frac{1}{2} - \frac{1}{3}\right) + \cdots + \left(\frac{1}{n} - \frac{1}{n+1}\right) = 1 - \frac{1}{n+1}$$

### 3.2 放缩 + 裂项的组合策略

| 目标 | 策略 | 放缩方向 |
|---|---|---|
| 证明 $\sum a_k < M$（估计上界） | $a_k < b_k$，$\sum b_k$ 可精确计算且 $< M$ | 往大放 |
| 证明 $\sum a_k > m$（估计下界） | $a_k > c_k$，$\sum c_k$ 可精确计算且 $> m$ | 往小缩 |
| 夹逼法 | $c_k < a_k < b_k$，$\sum b_k$ 与 $\sum c_k$ 都趋向同一极限 | 两侧放缩 |

**关键判断**：选择放缩对象时，优先选择能裂项的形式，即 $\dfrac{1}{n(n \pm 1)}$ 型。

## 四、演示题

**题目**：证明对一切正整数 $n$，有 $\displaystyle\sum_{k=1}^{n} \dfrac{1}{k^2} < 2$。

> **Q1. 识别目标。**
>
> 要证的是一个和式的上界：$S_n = \sum_{k=1}^{n} \frac{1}{k^2} < 2$。精确求出 $S_n$ 是困难的（这在数学史上是著名问题，答案是 $\frac{\pi^2}{6}$，但高中不要求）。所以只需估计——找到一个可以精确求和的上界即可。

> **Q2. 分离第一项，处理余下部分。**
>
> $k = 1$ 时，$\frac{1}{1^2} = 1$。这一项直接保留。
>
> 对 $k \geq 2$，需要处理 $\frac{1}{k^2}$。注意到 $k^2 > k(k-1)$（因为 $k > k-1 > 0$），所以
>
> $$\frac{1}{k^2} < \frac{1}{k(k-1)} \quad (k \geq 2)$$
>
> 这是"往大放"——用 $\frac{1}{k(k-1)}$ 替代 $\frac{1}{k^2}$ 作为上界。

> **Q3. 裂项。**
>
> 对已放大的项，用裂项公式：
>
> $$\frac{1}{k(k-1)} = \frac{1}{k-1} - \frac{1}{k}$$
>
> 因此
>
> $$\sum_{k=2}^{n} \frac{1}{k^2} < \sum_{k=2}^{n} \frac{1}{k(k-1)} = \sum_{k=2}^{n} \left(\frac{1}{k-1} - \frac{1}{k}\right)$$
>
> 这是望远镜求和：
>
> $$= \left(1 - \frac{1}{2}\right) + \left(\frac{1}{2} - \frac{1}{3}\right) + \cdots + \left(\frac{1}{n-1} - \frac{1}{n}\right) = 1 - \frac{1}{n}$$

> **Q4. 合并结论。**
>
> $$S_n = \frac{1}{1^2} + \sum_{k=2}^{n} \frac{1}{k^2} < 1 + \left(1 - \frac{1}{n}\right) = 2 - \frac{1}{n} < 2$$
>
> 所以 $S_n < 2$ 对一切正整数 $n$ 成立。$\blacksquare$

> **Q5. 反思与深化。**
>
> 上面的证明给出了更强的结论：$S_n < 2 - \dfrac{1}{n}$。当 $n$ 很大时，$S_n$ 越来越接近 $2$，但永远小于 $2$——这正是极限为 $\dfrac{\pi^2}{6} \approx 1.645$ 的直观体现（$1.645 < 2$，一致）。
>
> 放缩的"损失"：我们证明的是 $S_n < 2$，而真正的上界是 $\dfrac{\pi^2}{6} < 2$。这个放缩是"够用的"，没有放得太宽（仍然是有限数），也没有放得太紧（不影响结论成立）。

## 五、思考路标

**路标 1**：见到 $\displaystyle\sum \dfrac{1}{k^2}$ 型或 $\displaystyle\sum \dfrac{1}{k(k+a)}$ 型的上界估计，**第一步先分离 $k=1$ 的项**，再对 $k \geq 2$ 或 $k \geq 2$ 的项统一放缩，避免出现分母为 $0$ 的问题（$\frac{1}{k(k-1)}$ 在 $k=1$ 时分母为 $0$）。

**路标 2**：放缩的方向由目标决定。要证**上界**（$< M$），就往大放（$a_k < b_k$）；要证**下界**（$> m$），就往小缩（$a_k > c_k$）。两者方向相反，不能搞混。

**路标 3**：放缩完成后，**检查放大后的求和是否容易计算**。如果放大后仍然难算，说明放缩对象选错了，需要换一个。最理想的目标形式是 $\dfrac{1}{k(k \pm 1)}$，因为它可以直接裂项。

**路标 4**：$\ln(1+x) < x$ 和 $e^x > 1 + x$ 是**万能放缩**，在含 $\ln$ 和 $e$ 的不等式证明中直接调用。它们的共同来源是构造辅助函数 + 导数，但**结论本身要记住，考场上不需要重新推导**。

**路标 5**：裂项恒等式 $\dfrac{1}{n(n+1)} = \dfrac{1}{n} - \dfrac{1}{n+1}$ 是**等式**，不是放缩；而 $\dfrac{1}{n^2} < \dfrac{1}{n(n-1)}$ 才是放缩。用裂项之前，先确认你是在做等式变形还是不等式放缩，两者不能混用。

**路标 6**：夹逼思想——如果一个量 $A_n$ 满足 $L_n \leq A_n \leq U_n$，且 $L_n \to c$ 和 $U_n \to c$（$n \to \infty$），则 $A_n \to c$。高中版本中，这一思想常用于"证明某个量趋近于某常数"的问题，即：把 $A_n$ 两侧都夹住，再分析两侧的极限。

**路标 7**：对于函数类放缩，**先验证边界条件 $F(0) = 0$**（或边界等号成立），再用导数证明 $F$ 在正区间上单调递增。这是"构造 + 单调性"的标准组合，一旦写出 $F(x) = B(x) - A(x)$ 和 $F(0) = 0$，整个证明思路就确定了。

## 六、典型应用例题

### 例 1：用 $e^x > 1 + x$ 证明不等式

**题目**：证明 $e^x \geq 1 + x + \dfrac{x^2}{2}$ 对所有 $x \geq 0$ 成立。

**分析**：直接构造辅助函数。

**证明**：

令 $F(x) = e^x - 1 - x - \dfrac{x^2}{2}$（$x \geq 0$）。

$F(0) = 1 - 1 - 0 - 0 = 0$。

$F'(x) = e^x - 1 - x$。

由 $e^x > 1 + x$（$x > 0$ 时，工具箱基本不等式），有 $F'(x) = e^x - 1 - x > 0$（$x > 0$）。

$F$ 在 $[0, +\infty)$ 上单调递增，且 $F(0) = 0$，所以 $x > 0$ 时 $F(x) > 0$，即

$$e^x \geq 1 + x + \frac{x^2}{2}$$

（$x = 0$ 时两边均为 $1$，等号成立。）$\blacksquare$

---

### 例 2：裂项求数列部分和的精确值

**题目**：已知数列 $\{a_n\}$，$a_n = \dfrac{1}{n^2 + 3n + 2}$，求 $S_n = \displaystyle\sum_{k=1}^{n} a_k$。

**分析**：先因式分解分母，再裂项。

**解**：

$n^2 + 3n + 2 = (n+1)(n+2)$，所以

$$a_n = \frac{1}{(n+1)(n+2)} = \frac{1}{n+1} - \frac{1}{n+2}$$

$$S_n = \sum_{k=1}^{n} \left(\frac{1}{k+1} - \frac{1}{k+2}\right) = \left(\frac{1}{2} - \frac{1}{3}\right) + \left(\frac{1}{3} - \frac{1}{4}\right) + \cdots + \left(\frac{1}{n+1} - \frac{1}{n+2}\right)$$

望远镜消去：

$$S_n = \frac{1}{2} - \frac{1}{n+2} = \frac{n}{2(n+2)}$$

---

### 例 3：用放缩法证明对数不等式

**题目**：已知 $x > 0$ 且 $x \neq 1$，证明 $\ln x < x - 1$。

**分析**：令 $t = x - 1$，则 $t > -1$ 且 $t \neq 0$，目标变为 $\ln(1+t) < t$，这正是工具箱中的基本放缩。

**证明**：

令 $F(x) = x - 1 - \ln x$（$x > 0$）。

$F'(x) = 1 - \dfrac{1}{x} = \dfrac{x-1}{x}$。

- 当 $0 < x < 1$ 时，$F'(x) < 0$，$F$ 单调递减；
- 当 $x > 1$ 时，$F'(x) > 0$，$F$ 单调递增。

$F$ 在 $x = 1$ 处取得极小值（也是全局最小值）：$F(1) = 1 - 1 - \ln 1 = 0$。

所以 $x \neq 1$ 时 $F(x) > 0$，即 $x - 1 > \ln x$，即 $\ln x < x - 1$。$\blacksquare$

## 七、自测题

**第 1 题**：证明 $\displaystyle\sum_{k=1}^{n} \dfrac{1}{k(k+1)} = 1 - \dfrac{1}{n+1}$，并由此说明这个和式小于 $1$。

💡 提示：对每一项用裂项公式 $\dfrac{1}{k(k+1)} = \dfrac{1}{k} - \dfrac{1}{k+1}$，直接做望远镜求和。精确值 $= 1 - \dfrac{1}{n+1} < 1$ 显然成立。

**第 2 题**：用放缩法证明 $\displaystyle\sum_{k=1}^{n} \dfrac{1}{\sqrt{k}} > 2(\sqrt{n+1} - 1)$。

💡 提示：由 $\dfrac{1}{\sqrt{k}} > \dfrac{1}{\sqrt{k+1}} \cdot \dfrac{\sqrt{k+1}}{\sqrt{k}} = \cdots$，试用另一种放缩：$\dfrac{1}{\sqrt{k}} > 2(\sqrt{k+1} - \sqrt{k})$（等价于 $\sqrt{k+1} + \sqrt{k} > 2\sqrt{k}$，即 $\sqrt{k+1} > \sqrt{k}$，成立）。累加后 $\displaystyle\sum_{k=1}^{n} \dfrac{1}{\sqrt{k}} > 2\sum_{k=1}^{n}(\sqrt{k+1}-\sqrt{k}) = 2(\sqrt{n+1}-1)$。

**第 3 题**：已知 $x > 0$，利用 $e^x > 1+x$ 证明 $e^x > \dfrac{x^2}{2} + x + 1$，并说明 $x \to +\infty$ 时 $\dfrac{e^x}{x^2}$ 的趋势（只需给直觉说明，不要求严格证明）。

💡 提示：先用 $e^{x/2} > 1 + \dfrac{x}{2}$（令 $x$ 替换为 $x/2$ 代入基本不等式），然后两边平方：$e^x > \left(1+\dfrac{x}{2}\right)^2 = 1 + x + \dfrac{x^2}{4}$。（注意这只给出 $\dfrac{x^2}{4}$ 系数，与目标 $\dfrac{x^2}{2}$ 有差距——可用例 1 的结论直接得到 $e^x \geq 1 + x + \dfrac{x^2}{2}$。）趋势：$\dfrac{e^x}{x^2} \to +\infty$，指数函数增长远超多项式。

**第 4 题**：已知 $0 < x < 1$，比较 $\ln(1+x)$、$x$ 和 $\dfrac{x}{1-x}$ 的大小，并排列顺序。

💡 提示：（1）由 $\ln(1+x) < x$（$x > 0$）知 $\ln(1+x) < x$；（2）令 $t = \dfrac{x}{1-x} > 0$，则 $\ln(1 + t) < t$，即 $\ln\left(\dfrac{1}{1-x}\right) < \dfrac{x}{1-x}$，即 $-\ln(1-x) < \dfrac{x}{1-x}$，即 $\ln(1+x) - \ln(1-x) < \dfrac{x}{1-x}$……直接用双侧界：$\dfrac{x}{1+x} < \ln(1+x) < x$；当 $0 < x < 1$ 时 $\dfrac{x}{1+x} < x$，且 $x < \dfrac{x}{1-x}$（因为 $1-x < 1$，分母变小使分式变大），所以 $\ln(1+x) < x < \dfrac{x}{1-x}$。

**第 5 题**：设 $a_n = \left(1 + \dfrac{1}{n}\right)^n$，利用 $e^x > 1 + x$ 说明 $a_n < e$ 对所有正整数 $n$ 成立（不要求严格证明，只需给出思路轮廓）。

💡 提示：取对数 $\ln a_n = n \ln\!\left(1 + \dfrac{1}{n}\right)$。由 $\ln(1+x) < x$ 代入 $x = \dfrac{1}{n}$：$\ln\!\left(1+\dfrac{1}{n}\right) < \dfrac{1}{n}$，所以 $\ln a_n = n \cdot \ln\!\left(1+\dfrac{1}{n}\right) < n \cdot \dfrac{1}{n} = 1 = \ln e$。因为 $\ln$ 是严格递增函数，$\ln a_n < \ln e \Rightarrow a_n < e$。
