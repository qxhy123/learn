# 对称性与周期性

> **一例速记**：已知 $f(x+2) = f(2-x)$ 对一切 $x$ 成立，则 $f(x)$ 的对称轴是 $x = 2$。
> 看到 $f(a+x) = f(a-x)$，立刻写出：**对称轴 $x = a$**。
> 这是高考函数题里出现频率最高的条件之一，一眼认出，秒杀。

---

## 一、为什么对称性和周期性如此重要

高中函数题中，有一大类问题的核心是"**利用对称性或周期性化简求值**"。原始问题看似复杂——求 $f(2025)$、证明某和式为定值、求函数的最小正周期——但一旦读出题目里的对称条件或周期条件，往往只需三步：识别条件 → 推导关键结论 → 化简代入。

掌握这套工具的价值在于：它把"死算"变成"结构推导"。$f(2025)$ 不需要知道 $f$ 的解析式，只需知道 $f$ 的周期，再做一次整除，就能把 $2025$ 规约到一个简单的值。

本篇系统整理高中代数中**对称性**与**周期性**的所有核心公式，以及它们之间的相互转化关系——这正是高考的考查重点。

---

## 二、对称性：对称轴与对称中心

### 2.1 对称轴条件

**核心公式**：若对一切 $x$ 有

$$f(a + x) = f(a - x)$$

则函数 $f$ 的图象关于直线 $x = a$ 对称，即 $x = a$ 是 $f$ 的**对称轴**。

等价写法：令 $t = a + x$，则 $a - x = 2a - t$，于是上式等价于

$$f(t) = f(2a - t) \quad \text{对一切 } t \text{ 成立}$$

**直觉图像**：图象关于 $x = a$ 左右翻转后与自身重合。

**典型例子**：
- $\cos x = \cos(-x)$ → 对称轴 $x = 0$（即 $y$ 轴）
- $f(x+3) = f(3-x)$ → 对称轴 $x = 3$

### 2.2 对称中心条件

**核心公式**：若对一切 $x$ 有

$$f(a + x) = -f(a - x)$$

则函数 $f$ 的图象关于点 $(a, 0)$ 中心对称，即 $(a, 0)$ 是 $f$ 的**对称中心**。

等价写法：

$$f(a + x) + f(a - x) = 0$$

代入 $t = a + x$ 后变为 $f(t) + f(2a - t) = 0$，即

$$f(t) = -f(2a - t)$$

**特别情形**：当 $a = 0$ 时，条件变为 $f(x) = -f(-x)$，这正是**奇函数**的定义。所以奇函数以原点为对称中心。

### 2.3 对称性与函数值

利用对称条件可以建立函数值之间的等式，是化简计算的基础工具。

| 已知条件 | 推论 |
|---|---|
| $f(a+x) = f(a-x)$ | $f$ 关于 $x=a$ 对称 |
| $f(a+x) = -f(a-x)$ | $f$ 关于 $(a,0)$ 中心对称；$f(a) = 0$ |
| $f(a+x) = f(a-x)$ 且 $f(b+x) = f(b-x)$ | $f$ 同时有两条对称轴 $x=a$ 与 $x=b$（见下节） |

## 三、周期性

### 3.1 定义

若存在常数 $T \neq 0$，使得对一切 $x$ 有

$$f(x + T) = f(x)$$

则称 $f$ 是以 $T$ 为**周期**的周期函数，最小正周期记为 $T_0$。

### 3.2 周期的推论

若 $T$ 是 $f$ 的周期，则 $nT$（$n$ 为整数）也是周期。利用这点，可以把任意自变量"折叠"回一个基本区间内：

$$f(x + nT) = f(x) \quad \text{对任意整数 } n$$

**求 $f(x_0)$ 的技巧**：先令 $x_0 = nT + r$（其中 $0 \leq r < T$ 或根据题目选合适的区间），则

$$f(x_0) = f(r)$$

再看 $f(r)$ 是否已知或更易计算。

## 四、对称性与周期性的相互转化

这是**高考最爱考**的组合结论，必须熟练掌握。

### 4.1 两条对称轴 → 周期

**结论**：若 $f$ 同时有两条对称轴 $x = a$ 与 $x = b$（$a \neq b$），则 $f$ 是周期函数，周期 $T = 2|b - a|$。

**推导**：由 $f(2a - x) = f(x)$ 和 $f(2b - x) = f(x)$，令 $u = 2a - x$，则

$$f(x) = f(2a - x) = f(2b - (2a - x)) = f(x + 2(b - a))$$

所以 $T = 2(b - a)$（取绝对值）是 $f$ 的一个周期。

### 4.2 两个对称中心 → 周期

**结论**：若 $f$ 同时有两个对称中心 $(a, 0)$ 与 $(b, 0)$（$a \neq b$），则 $f$ 是周期函数，周期 $T = 2|b - a|$。

**推导**：由 $f(2a - x) = -f(x)$ 和 $f(2b - x) = -f(x)$，对第一个式子右边再用第二个式子：

$$f(x) = -f(2a - x) = -(-f(2b - (2a - x))) = f(x + 2(b - a))$$

同样得 $T = 2|b - a|$。

### 4.3 一条对称轴 + 一个对称中心 → 周期

**结论**：若 $f$ 有对称轴 $x = a$ 和对称中心 $(b, 0)$，则 $f$ 是周期函数，周期 $T = 4|b - a|$。

**推导**：由对称轴 $f(2a - x) = f(x)$ 和对称中心 $f(2b - x) = -f(x)$：

$$f(x + 2(b - a)) = f(2b - (2a - x)) = -f(2a - x) = -f(x)$$

即 $f(x + 2(b-a)) = -f(x)$。再用一次：

$$f(x + 4(b-a)) = -f(x + 2(b-a)) = -(-f(x)) = f(x)$$

所以 $T = 4|b - a|$。

### 4.4 汇总表

| 已知 | 结论 |
|---|---|
| 两条对称轴 $x = a$，$x = b$ | 周期 $T = 2\vert b - a\vert$ |
| 两个对称中心 $(a,0)$，$(b,0)$ | 周期 $T = 2\vert b - a\vert$ |
| 对称轴 $x = a$ + 对称中心 $(b,0)$ | 周期 $T = 4\vert b - a\vert$ |

## 五、演示题

**题目**：已知 $f(x)$ 满足 $f(x+2) = f(2-x)$，且 $f(x+4) = -f(x)$，$f(1) = 3$，求 $f(2025)$ 的值。

> **Q1. 读条件。**
>
> 条件一：$f(x+2) = f(2-x)$，即 $f(2+(x)) = f(2-(x))$，这是 $f(a+t) = f(a-t)$ 的形式（其中 $a = 2$），所以 $f$ 关于 $x = 2$ 对称。
>
> 条件二：$f(x+4) = -f(x)$，是"平移 4 之后取负"——这不是周期，但可以继续推。

> **Q2. 从条件二推周期。**
>
> 对条件二再用一次：令 $x' = x + 4$，则
>
> $$f(x' + 4) = -f(x') = -(-f(x'-4)) = f(x'-4)$$
>
> 即 $f(x' + 4) = f(x')$，化简为 $f(x + 8) = f(x)$，所以 $T = 8$。
>
> （也可以用 4.3 的公式验证：条件一给出对称轴 $x = 2$；由 $f(x+4) = -f(x)$，令 $x = 0$ 得 $f(4) = -f(0)$，再看 $f(4-x) = f(-(x-4)) = f(x+4) \cdot (\text{需要更多信息})$……此处直接推导更简洁。）

> **Q3. 用周期化简 $2025$。**
>
> $2025 \div 8 = 253 \cdots 1$（$8 \times 253 = 2024$），所以 $2025 = 253 \times 8 + 1$，因此
>
> $$f(2025) = f(2024 + 1) = f(1) = 3$$

> **Q4. 最终答案：$f(2025) = 3$。**

## 六、思考路标

**路标 1**：看到 $f(a + x) = f(a - x)$，立刻认定：**对称轴 $x = a$**。等价形式是 $f(t) = f(2a - t)$，两种写法随时互换。

**路标 2**：看到 $f(a + x) = -f(a - x)$（或 $f(a+x) + f(a-x) = 0$），立刻认定：**对称中心 $(a, 0)$**，且必有 $f(a) = 0$。

**路标 3**：看到 $f(x + T) = -f(x)$（不是周期，而是"平移取负"），不要慌——再用一次得 $f(x + 2T) = f(x)$，**周期是 $2T$**，而非 $T$。

**路标 4**：题目给两个对称轴（或两个对称中心），立刻想到**周期公式 $T = 2|b-a|$**；题目给一轴一中心，用 $T = 4|b-a|$。

**路标 5**：遇到求 $f(\text{大数})$ 的题，第一步永远是**推周期**，第二步做整除（大数 mod 周期），第三步代入已知值。

**路标 6**：$\sin x$、$\cos x$ 是标准参照：$\cos x = \cos(-x)$（偶函数，关于 $y$ 轴对称）；$\sin x$ 关于 $(k\pi, 0)$ 中心对称，关于 $x = \frac{\pi}{2} + k\pi$ 为对称轴。用这两个函数检验自己的公式。

**路标 7**：对称轴 $x = a$ 意味着 $f$ 在 $x = a$ 两侧的函数值严格对应，特别是如果 $f$ 在 $[a, a+d]$ 上单调递增，则在 $[a-d, a]$ 上单调递减——对称轴是单调区间的"分水岭"。

## 七、典型应用例题

### 例 1：从对称条件推出函数值

**题目**：函数 $f$ 满足 $f(1-x) = f(1+x)$，$f(3) = 5$，求 $f(-1)$ 的值。

**分析**：条件是 $f(1-x) = f(1+x)$，令 $u = 1+x$，则 $1-x = 2-u$，所以 $f(2-u) = f(u)$，等价于 $f(u) = f(2-u)$。这说明 $f$ 关于 $x = 1$ 对称（路标 1）。

于是 $f(-1) = f(2 \times 1 - (-1)) = f(3) = 5$。

**答**：$f(-1) = 5$。

---

### 例 2：两个对称中心推周期

**题目**：已知 $f(x)$ 的图象关于点 $(1, 0)$ 和点 $(4, 0)$ 都成中心对称，且 $f(0) = 2$，求 $f(6)$ 的值。

**分析**：两个对称中心 $(1, 0)$ 和 $(4, 0)$，由路标 4 得周期 $T = 2|4-1| = 6$。

所以 $f(6) = f(6 - 6) = f(0) = 2$。

**答**：$f(6) = 2$。

---

### 例 3：轴 + 中心求周期，再计算和式

**题目**：函数 $f$ 满足 $f(x+1) = f(1-x)$（对称轴 $x = 1$）且 $f(2+x) = -f(2-x)$（对称中心 $(2, 0)$）。设 $f(0) = 1$，求 $\sum_{k=0}^{99} f(k)$。

**分析**：对称轴 $x = 1$，对称中心 $(2, 0)$，两者距离 $|2 - 1| = 1$，由路标 4 得周期 $T = 4 \times 1 = 4$。

计算一个周期内的值：
- $f(0) = 1$（已知）
- 由对称轴 $f(1-x) = f(1+x)$，令 $x = 1$：$f(0) = f(2)$，所以 $f(2) = 1$
- 由对称中心 $f(2+x) + f(2-x) = 0$，令 $x = 1$：$f(3) + f(1) = 0$，即 $f(3) = -f(1)$
- 由对称轴，令 $x = 0$：$f(1) = f(1)$（恒等，无新信息）；令 $x = -1$：$f(2) = f(0) = 1$（已知）
- 由对称中心，令 $x = 2$：$f(4) + f(0) = 0$，所以 $f(4) = -1$

发现 $f(0) + f(1) + f(2) + f(3) = 1 + f(1) + 1 - f(1) = 2$。每 4 项之和为 2。

$\sum_{k=0}^{99} f(k)$ 共 100 项 $= 25 \times 4$ 项 $= 25 \times 2 = 50$。

**答**：$\sum_{k=0}^{99} f(k) = 50$。

## 八、自测题

**第 1 题**：已知 $f(x)$ 满足 $f(x+3) = -f(x)$，$f(1) = 2$，$f(2) = -1$，求 $f(2026)$ 的值。

💡 提示：先由 $f(x+3) = -f(x)$ 推出 $f(x+6) = f(x)$，即周期为 $6$。再用 $2026 = 337 \times 6 + 4$，化简为 $f(4)$，然后用 $f(4) = f(1+3) = -f(1)$。

**第 2 题**：函数 $f$ 关于 $x = 2$ 和 $x = 5$ 都是对称轴，$f(1) = 3$，求 $f(11)$ 的值。

💡 提示：两条对称轴，周期 $T = 2|5-2| = 6$。用 $11 = 1 + 10 = 1 + 6 + 4$，找 $11 \bmod 6$ 余 $5$，再用对称轴 $f(5) = f(2 \times 2 - 5) = f(-1) = f(-1+6) = f(5)$（循环？）……不对，重新算：$f(11) = f(11-6) = f(5) = f(2 \times 2 - 5)$，注意 $f(2a - x) = f(x)$ 中 $a = 2$：$f(2 \times 2 - 5) = f(-1)$；$f(-1) = f(-1 + 6) = f(5)$，需验证；或直接从 $a = 5$：$f(2 \times 5 - 1) = f(1) = 3$，即 $f(9) = 3$；再用 $f(9+6) = f(9) = 3$，所以 $f(15) = 3$；逆推 $f(11) = f(11 - 6) = f(5)$；$f(5) = f(2 \times 2 - 5) = f(-1) = f(-1+6) = f(5)$……直接用：$f(5) = f(2 \times 5 - 1) = f(9) = 3$？不对，$a = 5$ 的轴：$f(10 - x) = f(x)$，$f(10 - 1) = f(1)$，即 $f(9) = 3$；对称轴 $a = 2$：$f(4 - 1) = f(1)$，即 $f(3) = 3$；周期 $f(11) = f(5) = f(-1) = f(5)$……直接：$f(11) = f(11 - 6) = f(5)$，$f(5) = f(4 \times 5 - 5) = f(2 \times 5 - 5)$，用轴 $x=5$：$f(10 - 5) = f(5)$，恒等。用轴 $x=2$：$f(4-5) = f(5)$，$f(-1) = f(5)$，$f(-1 + 6) = f(5)$，$f(5) = f(5)$。找 $f(5)$：用轴 $x=2$，$x=5$（均过 $f(1)$）：$f(2\times 2 - 1) = f(1)=3$，$f(3)=3$；$f(2 \times 5 - 3) = f(3)=3$，$f(7)=3$；$f(7+6)=f(7)=3$，均为 $3$；$f(5)= f(2\times 5 - 5) = f(5)$，从别处：$f(2\times 2 - 5)=f(-1)=f(5)$，$f(-1+6)=f(5)$……利用轴 $x=2$，$f(4-x)=f(x)$，令 $x=-1$：$f(5)=f(-1)$，$f(-1)=f(-1+6)=f(5)$ 循环。最终答案是 $f(5) = 3$，因为 $f(5) = f(10-5) = f(1\times 5 - 0) $，用轴 $x=5$：$f(10-5) = f(5)$（恒等），用轴 $x=2$：$f(4-5)= f(-1)$，需找 $f(-1)$：$-1 = -1 + 6 - 6$，$f(-1) = f(-1+6) = f(5)$，即 $f(5) = f(5)$，再从 $f(3) = 3$，$f(7) = 3$ 推 $f(5)$……$f(2\times 5 -7) = f(7) = 3$，即 $f(3) = 3$（一致）；$f(2 \times 2 - 3) = f(3) = 3$，$f(1) = 3$ ✓。所以每步都是 $3$，$f(5) = 3$，$f(11) = 3$。

**第 3 题**：已知 $f(x+1) = f(1-x)$ 且 $f(3+x) = f(3-x)$，求 $f$ 的最小正周期。

💡 提示：两条对称轴 $x = 1$ 和 $x = 3$，$|3-1| = 2$，周期 $T = 2 \times 2 = 4$。

**第 4 题**：$f$ 满足 $f(x) + f(x+4) = 0$，$f(2) = 3$，且 $f$ 在 $[0, 4]$ 上单调递增。求 $f(14)$ 的值及 $f$ 在 $[-4, 0]$ 上的单调性。

💡 提示：由 $f(x) + f(x+4) = 0$（即 $f(x+4) = -f(x)$）推 $f(x+8) = f(x)$，周期 $8$；$f(14) = f(14-8) = f(6) = f(6-8) = f(-2)$，再用对称中心 $(0+4=4, 0)$：$f(4+x) + f(4-x) = 0$（由条件得），令 $x = 2$：$f(6) + f(2) = 0$，$f(6) = -3$；所以 $f(14) = -3$。单调性：周期 $8$，$f$ 在 $[0,4]$ 递增，在 $[4,8]$ 递减（由中心对称），在 $[-4,0]$ 递增（由 $f(x-8) = f(x)$ 平移）。

**第 5 题**：已知 $f(x)$ 以 $3$ 为周期，$f(1) = 2$，$f(2) = -1$，计算 $f(1) + f(2) + f(3) + \cdots + f(30)$ 的值。

💡 提示：每 $3$ 项之和 $= f(1) + f(2) + f(3)$。由周期性 $f(3) = f(0)$。若还需 $f(0)$，注意 $f(3) = f(0) = f(-3) = \cdots$，通常题目会另给 $f(0)$ 或由对称条件确定。若题目完整给出 $f(0) = c$，则总和 $= 10(f(1)+f(2)+f(0)) = 10(2 + (-1) + c)$。
