# 高级结构识别

> **一例速记**：化简 $\sqrt{x^2 - 6x + 9} + \sqrt{x^2 + 2x + 1}$，新手直接硬算根号；
> 高手一眼认出：两个被开方数分别是 $(x-3)^2$ 和 $(x+1)^2$，
> 原式 $= |x-3| + |x+1|$，按 $x < -1$、$-1 \leq x \leq 3$、$x > 3$ 三段讨论即可。
> **识别结构，比计算本身更重要。**

---

## 一、从初中到高中：结构识别的升级

初中学过的结构识别（见 `chuzhong_algebra/thinking-toolkit/07-structure-recognition.md`）已经掌握了 8 种基本结构：二次三项式、完全平方、平方差、和根式、倒数和、对称式、分式方程、绝对值。

进入高中，代数对象大幅扩展——三角函数、指数对数、数列、参数族函数、抽象函数、复合函数全面登场。结构识别不再局限于初中的"多项式认脸"，而是升级为**跨领域的模式匹配**：看到一个式子，瞬间定位它属于哪类结构，触发对应的处理策略。

高手与普通学生的差距，在高中数学里体现得更为悬殊。高考压轴题的关键往往不在于"计算量"，而在于**能否在 30 秒内识别出核心结构**。一旦认出，后续操作往往是机械的；没认出，即使花 10 分钟暴算也可能绕不出来。

**结构识别的三层能力**：
1. **单式识别**：看到一个代数式，立刻叫出它的名字（完全平方？同角三角？倒数和？）
2. **组合识别**：看到两个结构的组合，判断哪个先处理、哪个后处理
3. **策略触发**：识别完立刻知道用哪种方法（换元？公式？构造辅助函数？）

本篇的任务是把高中代数中最常见的 10 种结构整理成一张速查表，并配以演示题说明识别 → 策略的完整思路链条。

## 二、高中代数 10 种典型结构速查表

| 结构 | 标志特征 | 应对方法 |
|---|---|---|
| 二次三项式 $ax^2+bx+c$ | 三项，含 $x^2$、$x$、常数 | 配方求最值；求根公式；判别式 $\Delta = b^2 - 4ac$ 判根 |
| 完全平方 / 平方差 | $a^2 \pm 2ab + b^2$ 或 $a^2 - b^2$ | 公式正用（因式分解）或逆用（构造平方根） |
| 倒数和 $a + \dfrac{1}{a}$ | 一个量加上自身的倒数 | 基本不等式：$a + \dfrac{1}{a} \geq 2$（$a > 0$）；令 $t = a + \dfrac{1}{a}$ 整体换元 |
| 同角三角 $\sin^2\theta + \cos^2\theta$ | 同一角的正余弦平方组合 | 同角恒等式 $\sin^2\theta + \cos^2\theta = 1$ 替换消元 |
| 和差化积 / 积化和差 | $\sin A \pm \sin B$，$\cos A \pm \cos B$，或 $\sin A \cos B$ 等 | 和差化积：$\sin A + \sin B = 2\sin\dfrac{A+B}{2}\cos\dfrac{A-B}{2}$；积化和差逆用 |
| 等差 / 等比数列 | $a_{n+1} - a_n = d$（等差）；$\dfrac{a_{n+1}}{a_n} = q$（等比） | 通项公式 $a_n = a_1 + (n-1)d$ 或 $a_n = a_1 q^{n-1}$；前 $n$ 项和公式 |
| 二项式 $(a+b)^n$ | $n$ 次幂展开（$n$ 为正整数） | 二项式定理：$(a+b)^n = \displaystyle\sum_{k=0}^{n}\binom{n}{k}a^{n-k}b^k$ |
| 含参函数最值 $f(x, a)$ | 解析式同时含自变量 $x$ 和参数 $a$ | 参数分离：将 $a$ 移到一侧写成 $a = g(x)$ 形式，转化为"直线过点"问题；或对 $a$ 范围分类讨论 |
| 抽象函数关系 $f(x+y) = f(x) + f(y)$ | 函数方程（只给关系式，不给解析式） | 代入特殊值（$x = y = 0$；$y = -x$；$x = y$ 等）逐步推导性质 |
| 复合函数 $f(g(x))$ | 函数嵌套（"大函数套小函数"） | 单调性同增异减；定义域取内层函数使外层有意义的 $x$ 范围；令 $t = g(x)$ 换元后处理外层 |

### 补充说明

**倒数和的两种场景**：$a + \dfrac{1}{a}$ 出现时，若只需要比大小，用基本不等式；若 $a + \dfrac{1}{a}$ 作为已知量给出，令 $t = a + \dfrac{1}{a}$，用整体换元（toolkit 02）快速得到 $a^2 + \dfrac{1}{a^2} = t^2 - 2$，$a^3 + \dfrac{1}{a^3} = t^3 - 3t$。

**抽象函数关系的核心套路**：$f(x+y) = f(x) + f(y)$ 令 $x = y = 0$ 得 $f(0) = 0$；令 $y = -x$ 得 $f(-x) = -f(x)$（奇函数）。这两步几乎是所有抽象函数题的第一步。

**复合函数识别的优先级**：拿到复合函数，先写出内层 $u = g(x)$ 的值域，确认它落在外层 $f$ 的定义域内，再谈单调性。

## 三、演示：结构识别链条还原

### 题目：化简 $\sqrt{x^2 - 6x + 9} + \sqrt{x^2 + 2x + 1}$

> 拿到这道题，我的第一步不是去计算，而是**扫描结构**。
>
> 看被开方数：$x^2 - 6x + 9$。这三项，系数 $1$，一次项 $-6x$，常数 $9$。检查完全平方：$(x - 3)^2 = x^2 - 6x + 9$。完全符合。认出了：这是 $(x-3)^2$。
>
> 再看第二个被开方数：$x^2 + 2x + 1$。$(x+1)^2 = x^2 + 2x + 1$。也是完全平方，即 $(x+1)^2$。
>
> 现在原式变成了：
> $$\sqrt{(x-3)^2} + \sqrt{(x+1)^2}.$$
>
> 关键一步：$\sqrt{a^2} = |a|$，而不是 $a$。这是高中代数里最常见的错误之一——忘记取绝对值。所以：
> $$\sqrt{(x-3)^2} = |x-3|, \quad \sqrt{(x+1)^2} = |x+1|.$$
>
> 原式 $= |x-3| + |x+1|$。
>
> 现在结构换了：这是**两绝对值之和**（toolkit 04 数形结合的绝对值距离模型）。按零点 $x = -1$ 和 $x = 3$ 把数轴分三段：
>
> **当 $x < -1$ 时**：$|x-3| = 3-x$，$|x+1| = -(x+1) = -x-1$，
> $$|x-3| + |x+1| = (3-x) + (-x-1) = 2 - 2x.$$
>
> **当 $-1 \leq x \leq 3$ 时**：$|x-3| = 3-x$，$|x+1| = x+1$，
> $$|x-3| + |x+1| = (3-x) + (x+1) = 4.$$
>
> **当 $x > 3$ 时**：$|x-3| = x-3$，$|x+1| = x+1$，
> $$|x-3| + |x+1| = (x-3) + (x+1) = 2x - 2.$$
>
> 所以原式 $= \begin{cases} 2 - 2x, & x < -1 \\ 4, & -1 \leq x \leq 3 \\ 2x - 2, & x > 3 \end{cases}$。
>
> **结构识别的链条**：完全平方（两处）→ 绝对值 → 分段讨论。每一步都由上一步的结构自然触发。

## 四、思考路标

1. **见根号下有三项多项式** → 第一直觉：尝试配方，看是否是完全平方 $(a \pm b)^2$。不是完全平方时才考虑其他处理（有理化、换元）。特别注意：$\sqrt{f(x)^2} = |f(x)|$，结果含绝对值，不要丢掉绝对值。

2. **见三角函数与平方组合** → 优先考虑同角恒等式 $\sin^2\theta + \cos^2\theta = 1$。若是 $\sin^2\theta - \cos^2\theta$，想到二倍角公式 $\cos 2\theta = \cos^2\theta - \sin^2\theta$；若是 $\sin\theta\cos\theta$，想到 $\sin 2\theta = 2\sin\theta\cos\theta$。

3. **见 $a + \dfrac{1}{a}$ 或 $f(x) + \dfrac{1}{f(x)}$** → 两条路：（a）最值问题用基本不等式，$a + \dfrac{1}{a} \geq 2$（$a>0$）；（b）已知此值求更高次对称式，令 $t = a + \dfrac{1}{a}$，用 $a^2 + \dfrac{1}{a^2} = t^2 - 2$ 递推。

4. **见 $f(x+y) = $ 某函数组合** → 立刻代入三组特殊值：$x = y = 0$ 求 $f(0)$；$y = -x$ 求 $f(-x)$ 的表达式（奇偶性）；$y = x$ 求 $f(2x)$ 的表达式（递推）。这三步能提取绝大多数信息。

5. **见含参最值问题 $\max f(x, a)$ 或"对所有 $x$ 成立的条件"** → 参数分离策略：把含参的不等式改写为 $a > g(x)$（或 $\leq$），则条件等价于 $a$ 与 $g(x)$ 最值的大小关系。恒成立等价于 $a \geq \max g(x)$；存在成立等价于 $a \geq \min g(x)$。

6. **见等差数列的递推式** → 验证是否是 $a_{n+1} - a_n = $ 常数（等差）；若是 $a_{n+1} = pa_n + q$（$q \neq 0$）形式，不是等比，应构造辅助数列（toolkit 03）。见等比数列验证 $\dfrac{a_{n+1}}{a_n} = $ 常数，注意 $a_n \neq 0$ 的前提。

7. **见复合函数 $f(g(x))$ 要求单调性** → 写出"同增异减"：若 $f$ 和 $g$ 同为增函数，则 $f \circ g$ 为增；若异号，则 $f \circ g$ 为减。但要先确认在所讨论的 $x$ 范围内，$g(x)$ 的值域落在 $f$ 的单调区间之内。

8. **见二项展开式求特定项** → 写出通项 $T_{k+1} = \binom{n}{k} a^{n-k} b^k$，令 $k$ 满足"含 $x$ 的次数"条件，求出 $k$ 后代入通项公式。

## 五、典型应用 3 例

### 例 1：同角三角结构识别

**题目**：已知 $\sin\theta + \cos\theta = \dfrac{\sqrt{2}}{2}$，求 $\sin\theta\cos\theta$ 的值，以及 $\sin^3\theta + \cos^3\theta$ 的值。

**思路**：

看到"$\sin\theta + \cos\theta$"作为已知量，立刻识别：这是**对称式**结构，令 $s = \sin\theta + \cos\theta = \dfrac{\sqrt{2}}{2}$，$p = \sin\theta\cos\theta$。

两者的关系：$s^2 = \sin^2\theta + 2\sin\theta\cos\theta + \cos^2\theta = 1 + 2p$（用同角恒等式消去平方和）。

$$p = \frac{s^2 - 1}{2} = \frac{\left(\dfrac{\sqrt{2}}{2}\right)^2 - 1}{2} = \frac{\dfrac{1}{2} - 1}{2} = -\frac{1}{4}.$$

求 $\sin^3\theta + \cos^3\theta$：识别为**立方和结构**：

$$\sin^3\theta + \cos^3\theta = (\sin\theta + \cos\theta)(\sin^2\theta - \sin\theta\cos\theta + \cos^2\theta) = s(1 - p) = \frac{\sqrt{2}}{2} \cdot \left(1 + \frac{1}{4}\right) = \frac{\sqrt{2}}{2} \cdot \frac{5}{4} = \frac{5\sqrt{2}}{8}.$$

**识别链**：$s, p$ 换元 → 同角恒等式 → 立方和公式。全程没有解出 $\theta$ 的具体值。

### 例 2：数列结构识别 + 通项公式

**题目**：数列 $\{a_n\}$ 满足 $a_1 = 1$，$a_{n+1} = 3a_n - 2$，求通项公式。

**思路**：

识别递推式 $a_{n+1} = 3a_n - 2$：这不是等差（差不为常数）也不是等比（比不为常数）。但形如 $a_{n+1} = qa_n + c$（$c \neq 0$），这是**线性递推**结构，标准处理是构造辅助数列（toolkit 03）。

令 $b_n = a_n - k$，要求 $b_{n+1} = 3b_n$（等比），则 $a_{n+1} - k = 3(a_n - k)$，即 $a_{n+1} = 3a_n - 2k$，对比原式得 $2k = 2$，即 $k = 1$。

令 $b_n = a_n - 1$，则 $b_1 = a_1 - 1 = 0$，$b_{n+1} = 3b_n$。

但 $b_1 = 0$ 使得数列 $\{b_n\}$ 是全零数列，即 $b_n = 0$ 对所有 $n$ 成立，故 $a_n = 1$。

**验证**：$a_1 = 1$ ✓；$a_{n+1} = 3 \times 1 - 2 = 1 = a_n$ ✓。

**答**：$a_n = 1$（常数数列）。

此例的结构识别关键：看到线性递推 → 想到构造等比辅助数列（toolkit 03）。

### 例 3：含参函数最值的参数分离

**题目**：若不等式 $x^2 - 2x + a \geq 0$ 对所有 $x \in [0, 3]$ 恒成立，求 $a$ 的范围。

**思路**：

识别结构：**含参恒成立不等式**。应对策略：参数分离。

将不等式变形为 $a \geq 2x - x^2$（把含 $x$ 的部分移到右侧）。

"对所有 $x \in [0, 3]$ 恒成立"等价于 $a \geq \max_{x \in [0,3]}(2x - x^2)$。

令 $g(x) = 2x - x^2 = -(x-1)^2 + 1$，这是开口向下的抛物线（二次三项式结构识别），顶点 $(1, 1)$，在 $[0, 3]$ 上的最大值为 $g(1) = 1$。

故 $a \geq 1$。

**识别链**：含参恒成立 → 参数分离 → 求含 $x$ 表达式在区间上的最大值 → 二次三项式配方求最值。

## 六、自测题

**第 1 题**：化简 $\sqrt{4x^2 - 4x + 1} - \sqrt{4x^2 + 4x + 1}$。

💡 提示：识别两个被开方数：$4x^2 - 4x + 1 = (2x-1)^2$，$4x^2 + 4x + 1 = (2x+1)^2$。原式等于 $|2x-1| - |2x+1|$，分 $x < 0$、$0 \leq x < \dfrac{1}{2}$、$x \geq \dfrac{1}{2}$ 三段讨论。

---

**第 2 题**：已知 $f(x+y) = f(x)f(y)$ 对所有实数 $x, y$ 成立，且 $f(1) = 2$，求 $f(3)$ 和 $f(0)$ 的值。

💡 提示：先代入 $x = y = 0$ 求 $f(0)$（得到 $f(0) = f(0)^2$，注意 $f(0) \neq 0$ 的情形）；再用 $f(x+y) = f(x)f(y)$，令 $y = 1$ 递推 $f(2) = f(1)^2$，$f(3) = f(2)f(1)$。

---

**第 3 题**：设 $x > 0$，求 $f(x) = x + \dfrac{4}{x}$ 的最小值，并指出取最小值时 $x$ 的值。

💡 提示：识别倒数和结构。基本不等式：$x + \dfrac{4}{x} = x + \dfrac{4}{x} \geq 2\sqrt{x \cdot \dfrac{4}{x}} = 2\sqrt{4} = 4$，等号当且仅当 $x = \dfrac{4}{x}$，即 $x = 2$ 时成立。

---

**第 4 题**：数列 $\{a_n\}$ 满足 $a_1 = 2$，$a_{n+1} = 2a_n + 3$，求通项公式。

💡 提示：识别线性递推结构。令 $b_n = a_n + k$，要求 $b_{n+1} = 2b_n$，解出 $k = 3$；构造 $b_n = a_n + 3$，计算 $b_1 = 5$，$b_{n+1} = 2b_n$，得 $b_n = 5 \cdot 2^{n-1}$，回代得 $a_n = 5 \cdot 2^{n-1} - 3$。

---

**第 5 题**：函数 $f(x) = \sin^2 x + \sin x \cos x - \cos^2 x$，化简为 $A\sin(2x + \varphi) + B$ 的形式（其中 $A > 0$），并求 $f$ 的最大值。

💡 提示：识别同角三角结构。利用 $\sin^2 x = \dfrac{1 - \cos 2x}{2}$，$\cos^2 x = \dfrac{1 + \cos 2x}{2}$，$\sin x\cos x = \dfrac{\sin 2x}{2}$，将原式全部用 $\sin 2x$、$\cos 2x$ 表达，然后辅助角公式合并为 $R\sin(2x + \varphi)$ 的形式。
