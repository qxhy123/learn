# 抽象函数

> **一例速记**：$f(x+y) = f(x) + f(y)$，$f(1) = 2$，求 $f(3)$。
> 代入 $x = y = 1$：$f(2) = f(1)+f(1) = 4$。代入 $x = 2, y = 1$：$f(3) = f(2)+f(1) = 6$。**不知道 $f$ 长什么样，只靠代入特殊值一步步推——这就是抽象函数的全部套路。**

---

## 一、抽象函数——高考"送分题"与"送命题"的分水岭

普通函数题会给你明确的解析式，如 $f(x) = x^2 + 1$；而**抽象函数**只给你**函数满足的方程（函数方程）或某些性质**，完全不告诉你 $f(x)$ 的具体形式。

这类题有一个特点：**如果你会套路，一两分钟就能解完；如果不会，怎么想都想不通。** 高考中抽象函数选择、填空题频繁出现，是区分均分答题者和高手的关键战场。

抽象函数的三条命脉：
1. **代入特殊值**：用 $x=0$、$y=0$、$x=y$、$y=-x$ 等简单值，从函数方程提取信息；
2. **推导性质**：从函数方程出发，一步步证明奇偶性、单调性、周期性；
3. **利用性质计算**：用推导出的性质（而非解析式）算出具体函数值。

---

## 二、三类经典抽象函数

| 类型 | 函数方程 | 代表函数 | 核心性质 |
|---|---|---|---|
| **加法型** | $f(x+y) = f(x) + f(y)$ | $f(x) = kx$（柯西方程） | $f(0)=0$；$f$ 是奇函数；$f(n) = nf(1)$（$n \in \mathbb{Z}$） |
| **乘法型** | $f(xy) = f(x) + f(y)$ | $f(x) = \log_a x$（$x>0$） | $f(1)=0$；$f(x)+f(1/x)=0$；$f(x^n) = nf(x)$ |
| **指数型** | $f(x+y) = f(x) \cdot f(y)$ | $f(x) = a^x$（$a>0$） | $f(0)=1$（若 $f$ 不恒为零）；$f(x) > 0$ 恒成立；$f(-x) = 1/f(x)$ |
| **复合型** | $f(x \cdot y) = f(x) \cdot f(y)$ | 幂函数 $f(x) = x^k$ | $f(1) = 1$（若 $f$ 不恒为零）；$f(-x) = \pm f(x)$ |
| **移位型** | $f(x+T) = f(x)$ | 任意周期函数 | 周期为 $T$ |
| **对称型** | $f(a+x) = f(a-x)$ | 关于 $x=a$ 对称的函数 | 图象关于直线 $x=a$ 对称 |

---

## 三、代入特殊值的"万能清单"

面对任何函数方程 $f(\star, \square) = \cdots$，都要机械地尝试以下代入，看哪几条有用：

1. **令 $x = 0, y = 0$** → 得 $f(0)$ 的值
2. **令 $y = 0$**（仅 $x$）→ 化简单变量关系
3. **令 $y = -x$** → 推 $f(0)$ 与 $f(x) + f(-x)$ 的关系（奇偶性）
4. **令 $x = y$** → 得 $f(2x)$ 或 $f(x^2)$ 等对称情形
5. **令 $y = 1$ 或 $y = -1$**（整数步进）→ 推 $f(n) = nf(1)$ 类递推
6. **令 $x = y = t$，再令 $t = $ 具体值** → 凑出所求

这个清单不需要思考，直接挨个试，哪条出信息就用哪条。

## 四、演示题：加法型函数方程

**题目**：已知函数 $f$ 满足 $f(x+y) = f(x) + f(y)$（对所有实数 $x, y$），且 $f(1) = 2$。

(1) 求 $f(0)$；(2) 证明 $f$ 是奇函数；(3) 求 $f(3)$。

> **第 (1) 步：令 $x = y = 0$**
>
> 代入函数方程：$f(0 + 0) = f(0) + f(0)$，即 $f(0) = 2f(0)$，因此 $f(0) = 0$。
>
> 这条结论对所有加法型函数方程都成立：$f(0) = 0$。

> **第 (2) 步：证奇函数，令 $y = -x$**
>
> 代入：$f(x + (-x)) = f(x) + f(-x)$，左边 $= f(0) = 0$，所以 $f(x) + f(-x) = 0$，即 $f(-x) = -f(x)$。
>
> 这正是奇函数的定义。由于 $f(0) = 0$ 也满足，$f$ 是奇函数。

> **第 (3) 步：递推求 $f(3)$**
>
> 令 $x = y = 1$：$f(1+1) = f(1)+f(1) = 2+2 = 4$，所以 $f(2) = 4$。
>
> 令 $x = 2, y = 1$：$f(2+1) = f(2)+f(1) = 4+2 = 6$，所以 $f(3) = 6$。

**答**：$f(0) = 0$，$f$ 是奇函数，$f(3) = 6$。

**推广规律**：$f(n) = nf(1) = 2n$（对整数 $n$）。若再附加 $f$ 在某点单调，则可推出 $f(x) = 2x$ 对全体实数成立。

## 五、演示题：乘法型函数方程

**题目**：$f(xy) = f(x) + f(y)$ 对所有 $x, y > 0$ 成立，$f(2) = 1$。求 $f(8)$，并证明 $f(1) = 0$。

> **求 $f(1)$：令 $x = y = 1$**
>
> $f(1 \cdot 1) = f(1) + f(1)$，即 $f(1) = 2f(1)$，所以 $f(1) = 0$。

> **求 $f(4)$：令 $x = y = 2$**
>
> $f(4) = f(2) + f(2) = 1 + 1 = 2$。

> **求 $f(8)$：令 $x = 4, y = 2$**
>
> $f(8) = f(4) + f(2) = 2 + 1 = 3$。

**规律**：$f(2^n) = n \cdot f(2) = n$，这正是以 $2$ 为底的对数：$f(x) = \log_2 x$。

---

## 六、演示题：奇偶性与单调性的综合推导

**题目**：$f(x)$ 满足 $f(x+2) + f(x) = 0$ 对所有 $x$ 成立，且 $f$ 在 $[0,2]$ 上单调递增。已知 $f(1) = 3$，求 $f(9)$。

> **第一步：发现周期性**
>
> $f(x+2) = -f(x)$，再用一次：$f(x+4) = -f(x+2) = -(-f(x)) = f(x)$。
>
> 所以 $f$ 以 $4$ 为周期！$f(9) = f(9 - 4 \times 2) = f(1) = 3$。

如果题目问 $f(7)$：$f(7) = f(7-4) = f(3)$；再用 $f(3) = f(3-2+2) = -f(3-2) = -f(1) = -3$。

> **关键操作**：从函数方程先推出周期性，再利用周期折叠到已知区间内计算。

---

## 七、推导单调性保序的技巧

若已知 $f$ 满足函数方程且"在某区间上单调"，结合函数方程可以把单调性**搬运**到其他区间。

**例**：$f(x+y) = f(x) + f(y)$，$f$ 在 $(0, +\infty)$ 上单调递增，$f(-3) + f(5) > 0$，求 $f$ 的信息。

> 因为 $f$ 是奇函数（已证），$f(-3) = -f(3)$。原不等式变为 $-f(3) + f(5) > 0$，即 $f(5) > f(3)$。
>
> 因为 $f$ 在 $(0, +\infty)$ 上单调递增，$f(5) > f(3)$ 自然成立（$5 > 3 > 0$）。无矛盾。
>
> 反过来，若问"何时 $f(-x) + f(x-1) > 0$"，化为 "$f(x-1) > f(x)$"，再利用奇函数变形和单调性解不等式。

## 八、思考路标

**路标 1**：见到函数方程 $f(\cdots) = \cdots$，**立刻列出"特殊值代入清单"**（$x=0$, $y=0$, $y=-x$, $x=y$），机械挨个试，哪条给出信息就用。

**路标 2**：加法型 $f(x+y) = f(x)+f(y)$ → 必然有 $f(0) = 0$（令 $x=y=0$）、$f$ 是奇函数（令 $y=-x$）、$f(n) = nf(1)$（递推）。这三条是**基本定理**，背熟。

**路标 3**：乘法型 $f(xy) = f(x)+f(y)$（$x,y > 0$） → 必然有 $f(1) = 0$（令 $x=y=1$），本质是对数函数的特征。

**路标 4**：指数型 $f(x+y) = f(x) \cdot f(y)$ → 必然有 $f(0) = 1$（令 $x=y=0$：$f(0) = f(0)^2$，非零则为 $1$），$f(x) > 0$ 恒成立（$f(x) = f(\frac{x}{2}+\frac{x}{2}) = f(\frac{x}{2})^2 \geq 0$，若为零则 $f \equiv 0$）。

**路标 5**：推导出奇偶性后，用奇偶性**简化后续计算**。例如 $f$ 是奇函数时，$f(x) + f(-x) = 0$ 可以合并负数点的值。

**路标 6**：若函数方程给出 $f(x+T) = f(x)$（或等价形式），先算出**周期 $T$**，再把所求点通过 $f(x) = f(x \bmod T)$ 折叠到基本区间。

**路标 7**：抽象函数题通常不需要求出 $f$ 的解析式——**只推性质，利用性质计算，是最高效路径**。试图"猜出"解析式再验证，往往浪费时间。

## 九、典型应用例题

### 例 1：周期性 + 对称性联合推导

**题目**：函数 $f(x)$ 满足 $f(x+3) = -f(x)$ 对所有实数 $x$ 成立，且 $f(-1) = 2$，求 $f(5) + f(8)$。

**解**：

由 $f(x+3) = -f(x)$ 得 $f(x+6) = -f(x+3) = f(x)$，周期为 $6$。

$f(5) = f(5 - 6) = f(-1) = 2$。

$f(8) = f(8-6) = f(2) = f(-1+3) = -f(-1) = -2$。

$f(5) + f(8) = 2 + (-2) = \boxed{0}$。

---

### 例 2：利用奇偶性与单调性解不等式

**题目**：$f(x)$ 是定义在 $\mathbb{R}$ 上的奇函数，且 $f(x)$ 在 $[0, +\infty)$ 上单调递减。若 $f(a-1) + f(2a-1) > 0$，求 $a$ 的范围。

**解**：

因为 $f$ 是奇函数，$f(a-1) + f(2a-1) > 0 \Leftrightarrow f(2a-1) > -f(a-1) = f(-(a-1)) = f(1-a)$。

$f$ 在 $[0, +\infty)$ 上单调递减，由奇函数性质知 $f$ 在 $(-\infty, 0]$ 上也单调递减，故 $f$ 在 $\mathbb{R}$ 上单调递减。

由 $f(2a-1) > f(1-a)$ 和 $f$ 单调递减，得 $2a - 1 < 1 - a$，即 $3a < 2$，$a < \dfrac{2}{3}$。

**答**：$a \in \left(-\infty, \dfrac{2}{3}\right)$。

---

### 例 3：加法型 + 单调性综合题

**题目**：$f(x)$ 满足 $f(x+y) = f(x) + f(y)$，$f(1) = -2$，且 $f$ 在 $(0, +\infty)$ 上为负值（即 $x > 0 \Rightarrow f(x) < 0$）。解不等式 $f(3-t) > f(2t-3)$。

**解**：

先确认 $f$ 的单调性。取 $x_1 < x_2$，设 $x_2 - x_1 = h > 0$：

$$f(x_2) - f(x_1) = f(x_1 + h) - f(x_1) = f(h) < 0 \quad (\text{因为 } h > 0 \text{ 时 } f(h) < 0).$$

故 $f$ 在 $\mathbb{R}$ 上单调递减。

由 $f(3-t) > f(2t-3)$ 和单调递减，得 $3-t < 2t-3$，即 $t > 2$。

**答**：$t \in (2, +\infty)$。

## 十、自测题

**第 1 题**：$f(x+y) = f(x) + f(y)$，$f(2) = 6$，求 $f(0)$ 和 $f(-4)$。

💡 提示：令 $x=y=0$ 求 $f(0)$；利用 $f$ 是奇函数得 $f(-4) = -f(4)$；递推 $f(4) = 2f(2) = 12$。

**第 2 题**：$f(x)$ 满足 $f(x \cdot y) = f(x) + f(y)$（$x, y > 0$），$f(3) = 1$，求 $f(27) - f\!\left(\dfrac{1}{3}\right)$。

💡 提示：$f(27) = f(3^3) = 3f(3) = 3$；$f(1/3)$：令 $y = 1/3$，$x = 3$ 代入方程，得 $f(1) = f(3) + f(1/3)$，再用 $f(1) = 0$。

**第 3 题**：$f(x)$ 为奇函数，$f(x+2) = f(x) + f(2)$，$f(1) = 3$，求 $f(7)$。

💡 提示：令 $x=0$ 得 $f(2) = f(0) + f(2)$，故 $f(0) = 0$（与奇函数一致）；令 $x=1$ 得 $f(3) = f(1) + f(2)$；但需要先求 $f(2)$：令 $x=y=1$ 代入 $f(x+2)=f(x)+f(2)$ 不直接给 $f(2)$，改用 $f(2) = $ 奇函数 $f(-2) = -f(2)$？注意奇函数 $f(2)+f(-2)=0$，再用方程推导。

**第 4 题**：$g(x)$ 满足 $g(x+y) = g(x) \cdot g(y)$，$g(1) = 2$，$g(x) > 0$ 恒成立，求 $g(3) \cdot g(-1)$ 的值。

💡 提示：$g(0) = 1$（令 $x=y=0$）；$g(2) = g(1)^2 = 4$，$g(3) = g(2) \cdot g(1) = 8$；$g(1) \cdot g(-1) = g(0) = 1$，所以 $g(-1) = 1/2$；最终 $g(3) \cdot g(-1) = 8 \times \frac{1}{2} = 4$。

**第 5 题**：$f(x)$ 在 $\mathbb{R}$ 上是奇函数，且在 $(0, +\infty)$ 上单调递增，$f(2) = 0$。解不等式 $f(x^2 - 2x) < 0$。

💡 提示：$f(x^2-2x) < 0 = f(0)$（因为 $f$ 是奇函数 $\Rightarrow f(0)=0$）；由 $f$ 单调递增且 $f(2)=0$，$f$ 在正半轴上在 $x=2$ 处为零，$x>0$ 时 $f(x) < 0 \Leftrightarrow 0 < x < 2$；整合奇函数，$f(t) < 0 \Leftrightarrow -2 < t < 0$ 或… 分析完整单调性后解 $x^2-2x$ 的范围。
