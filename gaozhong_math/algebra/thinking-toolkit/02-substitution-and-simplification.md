# 换元与化简（高中深化）

> **一例速记**：求 $f(x) = \dfrac{x^2 + 1}{x}$（$x > 0$）的最小值。
> 新手：展开为 $x + \dfrac{1}{x}$，然后卡住了；
> 高手：令 $t = x + \dfrac{1}{x}$，由基本不等式 $t \geq 2$，当 $x = 1$ 时等号成立，最小值为 $\mathbf{2}$。
> **换元的威力不只是降次，更是把陌生结构变成已知套路。**

---

## 一、初中换元的局限与高中的扩展

初中换元（`chuzhong_algebra/thinking-toolkit/01-when-to-substitute.md`）主要处理五类信号：高次幂重复结构、含根号、分式重复块、对称组合、重复括号。换元对象基本局限于多项式和有理式。

进入高中，换元的疆域大幅拓展：

- **三角换元**：把含 $\sqrt{1-x^2}$、$x^2+y^2 = r^2$ 等圆的方程/条件翻译成角度变量，消去根号，释放出三角恒等式的威力。
- **对数换元**：遇到 $\log_a x$ 反复出现时，整体换元为 $t$，将指对数方程化为代数方程。
- **复合函数内层换元**：令 $t = g(x)$，先处理外层 $f(t)$，再将结论翻译回 $x$。
- **整体换元（含倒数）**：见 $\dfrac{x^2+1}{x}$ 或 $x + \dfrac{1}{x}$，整体换元 $t = x + \dfrac{1}{x}$。
- **韦达对称换元**：见关于两根 $x_1, x_2$ 的对称式，令 $s = x_1 + x_2$，$p = x_1 x_2$，用韦达定理快速表达。

换元的本质没有变：**给复杂结构起短名字，让问题在新变量下变简单，最后回代还原**。改变的是换元的"触发模式"——从初中的"多项式重复块"升级为"跨越代数/三角/指对数的结构识别"。

---

## 二、五类高中换元模式详解

### 模式 1：三角换元

**触发信号**：式子中出现 $\sqrt{1 - x^2}$、$\sqrt{r^2 - x^2}$，或者条件 $x^2 + y^2 = r^2$（圆约束）。

**操作**：令 $x = r\sin\theta$（或 $r\cos\theta$），其中 $\theta \in \left[-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right]$（保证 $\cos\theta \geq 0$，使根号处理一致）。

**效果**：

$$\sqrt{r^2 - x^2} = \sqrt{r^2 - r^2\sin^2\theta} = r\sqrt{1 - \sin^2\theta} = r\cos\theta.$$

原来含根号的代数式，换元后变为纯三角表达式，再用三角恒等式化简或利用有界性求最值。

**典型例子**：$x^2 + y^2 = 1$ 时求 $2x + y$ 的最大值 → 令 $x = \cos\theta$，$y = \sin\theta$，则 $2x + y = 2\cos\theta + \sin\theta = \sqrt{5}\sin(\theta + \varphi)$（辅助角公式），最大值为 $\sqrt{5}$。

**注意**：三角换元后要确认 $x$ 的取值范围与 $\theta$ 的范围对应，回代时不需要解出 $\theta$ 的具体值，只需还原 $x$ 的最值即可。

---

### 模式 2：对数换元

**触发信号**：$\log_a x$ 反复出现，或含有形如 $(\log_a x)^2$、$\log_a x + \log_a \dfrac{1}{x}$ 的式子。

**操作**：令 $t = \log_a x$（注意 $x > 0$ 且 $a > 0, a \neq 1$ 的前提）。

**效果**：指对数方程化为关于 $t$ 的代数方程（通常是一次或二次），利用对数单调性将结论翻译回 $x$。

**典型例子**：解方程 $(\log_2 x)^2 - 3\log_2 x + 2 = 0$。令 $t = \log_2 x$，方程变为 $t^2 - 3t + 2 = (t-1)(t-2) = 0$，得 $t = 1$ 或 $t = 2$，回代得 $x = 2$ 或 $x = 4$。

**常见陷阱**：换元后解出 $t$ 时，要检查 $x = a^t > 0$ 是否满足原方程中 $x$ 的限制（如 $x > 1$、$x > 2$）。

---

### 模式 3：复合函数内层换元

**触发信号**：函数形如 $f(g(x))$，需要讨论单调性、定义域或最值，且内外层分离后更容易处理。

**操作**：令 $t = g(x)$，先以 $t$ 为变量分析外层函数 $f(t)$，再将结论通过 $t = g(x)$ 翻译回 $x$。

**效果**：复合函数的单调性分析（同增异减）和定义域问题（内层值域 $\subseteq$ 外层定义域）在换元后变得清晰。

**典型例子**：求 $y = \ln(x^2 - 2x - 3)$ 的定义域和单调递增区间。令 $t = x^2 - 2x - 3$，$y = \ln t$ 要求 $t > 0$，即 $x^2 - 2x - 3 > 0$，解得 $x < -1$ 或 $x > 3$，这是定义域。在此基础上，$y = \ln t$ 关于 $t$ 单调递增，$t = x^2 - 2x - 3 = (x-1)^2 - 4$ 在 $x > 3$ 时递增，故 $y$ 在 $(3, +\infty)$ 上单调递增；在 $x < -1$ 时 $t$ 递减，故 $y$ 在 $(-\infty, -1)$ 上单调递减。

---

### 模式 4：整体换元（含倒数结构）

**触发信号**：式子出现 $x + \dfrac{1}{x}$、$\dfrac{x^2+1}{x}$、$x - \dfrac{1}{x}$，或它们的幂次形式。

**操作**：令 $t = x + \dfrac{1}{x}$（或 $t = x - \dfrac{1}{x}$），利用 $x^2 + \dfrac{1}{x^2} = t^2 - 2$，$x^3 + \dfrac{1}{x^3} = t^3 - 3t$ 递推化简。

**基本不等式联用**：当 $x > 0$ 时，$t = x + \dfrac{1}{x} \geq 2$；当 $x < 0$ 时，$t = x + \dfrac{1}{x} \leq -2$。这确定了 $t$ 的范围。

**典型例子**：若 $x + \dfrac{1}{x} = 3$，求 $x^2 + \dfrac{1}{x^2}$ 和 $x^3 + \dfrac{1}{x^3}$。令 $t = 3$：$x^2 + \dfrac{1}{x^2} = t^2 - 2 = 7$；$x^3 + \dfrac{1}{x^3} = t^3 - 3t = 27 - 9 = 18$。

---

### 模式 5：韦达对称换元

**触发信号**：方程 $ax^2 + bx + c = 0$ 的两根 $x_1, x_2$ 的**对称式**——$x_1 + x_2$、$x_1 x_2$、$x_1^2 + x_2^2$、$\dfrac{1}{x_1} + \dfrac{1}{x_2}$ 等。

**操作**：令 $s = x_1 + x_2 = -\dfrac{b}{a}$，$p = x_1 x_2 = \dfrac{c}{a}$（韦达定理）。所有关于 $x_1, x_2$ 的对称式均可用 $s, p$ 表达：

$$x_1^2 + x_2^2 = s^2 - 2p, \quad x_1^3 + x_2^3 = s^3 - 3sp, \quad \frac{1}{x_1} + \frac{1}{x_2} = \frac{s}{p} \text{（需 } p \neq 0\text{）}.$$

**典型例子**：已知 $x^2 - 5x + 3 = 0$ 的两根为 $x_1, x_2$，求 $\dfrac{x_1}{x_2} + \dfrac{x_2}{x_1}$ 的值。

$s = 5$，$p = 3$；$\dfrac{x_1}{x_2} + \dfrac{x_2}{x_1} = \dfrac{x_1^2 + x_2^2}{x_1 x_2} = \dfrac{s^2 - 2p}{p} = \dfrac{25 - 6}{3} = \dfrac{19}{3}$。

## 三、演示：整体换元求最值

### 题目：求 $f(x) = \dfrac{x^2 + 1}{x}$（$x > 0$）的最小值

> 拿到这道题，先整理式子：
> $$f(x) = \frac{x^2 + 1}{x} = x + \frac{1}{x}.$$
>
> 认出结构：这正是**倒数和**，即"$x$ 加上 $\dfrac{1}{x}$"。
>
> 触发信号：整体换元模式 4。但这道题不需要引入 $t$ 再回代，可以直接用基本不等式处理。
>
> 对 $x > 0$，基本不等式告诉我们：
> $$x + \frac{1}{x} \geq 2\sqrt{x \cdot \frac{1}{x}} = 2\sqrt{1} = 2.$$
>
> 等号成立条件：$x = \dfrac{1}{x}$，即 $x^2 = 1$，因 $x > 0$ 得 $x = 1$。
>
> 验证：$f(1) = \dfrac{1 + 1}{1} = 2$。确实取到了最小值。
>
> **答**：$f(x)$ 的最小值为 $\mathbf{2}$，当 $x = 1$ 时取到。
>
> **注意**：如果 $x$ 的范围不是全体正实数，比如 $x \in (0, 1]$，那么 $f$ 在此区间单调递减（因为 $x = 1$ 是全局最小值点，左侧递减），$f$ 在 $x \in (0, 1]$ 上的最小值仍是 $f(1) = 2$，最大值是极限 $\to +\infty$（$x \to 0^+$）。场景不同，结论要重新分析。

## 四、思考路标

1. **见 $\sqrt{1 - x^2}$ 或条件 $x^2 + y^2 = 1$** → 三角换元是首选：令 $x = \sin\theta$（或 $\cos\theta$），$\theta$ 限制在 $\left[-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right]$（使 $\cos\theta \geq 0$）。换元后用辅助角公式或有界性求最值。

2. **见 $\log_a x$ 出现不止一次（或出现 $(\log_a x)^2$）** → 对数换元：令 $t = \log_a x$，方程化为关于 $t$ 的代数式；解完 $t$ 后，回代 $x = a^t$，别忘检验 $x$ 的范围约束。

3. **见 $f(x + \dfrac{1}{x})$ 或 $f(x - \dfrac{1}{x})$** → 先确定倒数和/差的取值范围（$x > 0$ 时 $x + \dfrac{1}{x} \geq 2$；$x < 0$ 时 $x + \dfrac{1}{x} \leq -2$），令 $t$ 等于整体，转化为 $f(t)$ 的问题，最后检查 $t$ 的范围。

4. **见复合函数讨论单调区间** → 令 $t = g(x)$，先判断 $y = f(t)$ 的单调区间（以 $t$ 为变量），再将 $t$ 的条件翻译回 $x$（解不等式 $g(x) \in $ 对应区间），注意取交集（还要满足定义域）。

5. **见韦达定理 + 对称式问题** → 确认题目给的是哪个方程（注意系数），写出 $s = x_1 + x_2$ 和 $p = x_1 x_2$；对不对称的式子（如 $x_1^2 - x_2^2$），用 $|x_1 - x_2| = \sqrt{s^2 - 4p}$ 展开后化简。

6. **换元后不忘回代**：换元是临时手段，最终答案要用原变量表达。解完关于 $t$ 的方程/不等式后，立刻写"回代：$t = \ldots \Rightarrow x = \ldots$"，养成习惯，避免把 $t$ 当答案提交。

7. **换元的新变量范围**：每次换元都要附加新变量的范围约束。$t = \log_a x$（$x > 0$）无特殊限制；$t = x + \dfrac{1}{x}$（$x > 0$）则 $t \geq 2$；$t = \sin\theta$ 则 $t \in [-1, 1]$。新变量范围如果没写清楚，后面筛解时会出错。

## 五、典型应用 3 例

### 例 1：三角换元求最值

**题目**：已知实数 $x, y$ 满足 $x^2 + y^2 = 4$，求 $3x + 4y$ 的最大值。

**思路**：

条件 $x^2 + y^2 = 4$ 是以原点为圆心、半径为 $2$ 的圆。触发三角换元：令 $x = 2\cos\theta$，$y = 2\sin\theta$（$\theta \in [0, 2\pi)$）。

$$3x + 4y = 6\cos\theta + 8\sin\theta.$$

用辅助角公式：$6\cos\theta + 8\sin\theta = \sqrt{6^2 + 8^2}\sin(\theta + \varphi) = 10\sin(\theta + \varphi)$，其中 $\tan\varphi = \dfrac{6}{8} = \dfrac{3}{4}$。

最大值为 $\mathbf{10}$，当 $\sin(\theta + \varphi) = 1$ 时取到。

---

### 例 2：对数换元解方程

**题目**：解方程 $2(\log_3 x)^2 - 5\log_3 x + 2 = 0$（$x > 0$）。

**思路**：

令 $t = \log_3 x$，方程化为 $2t^2 - 5t + 2 = 0$。

分解因式：$(2t - 1)(t - 2) = 0$，得 $t = \dfrac{1}{2}$ 或 $t = 2$。

回代：$\log_3 x = \dfrac{1}{2} \Rightarrow x = 3^{1/2} = \sqrt{3}$；$\log_3 x = 2 \Rightarrow x = 9$。

两解均满足 $x > 0$，故 $x = \sqrt{3}$ 或 $x = 9$。

---

### 例 3：韦达换元处理对称式

**题目**：方程 $x^2 - 3x - 1 = 0$ 的两根为 $\alpha, \beta$（$\alpha < \beta$），求 $(\alpha - \beta)^2$ 及 $\alpha^3 - 2\alpha^2 + 5\beta - 3$ 的值。

**思路**：

韦达定理：$s = \alpha + \beta = 3$，$p = \alpha\beta = -1$。

$(\alpha - \beta)^2 = (\alpha + \beta)^2 - 4\alpha\beta = 9 - 4(-1) = 13$。

对 $\alpha^3 - 2\alpha^2 + 5\beta - 3$：注意 $\alpha$ 是原方程的根，故 $\alpha^2 = 3\alpha + 1$，$\alpha^3 = \alpha \cdot \alpha^2 = \alpha(3\alpha + 1) = 3\alpha^2 + \alpha = 3(3\alpha + 1) + \alpha = 10\alpha + 3$。

所以 $\alpha^3 - 2\alpha^2 = (10\alpha + 3) - 2(3\alpha + 1) = 4\alpha + 1$。

代入：$\alpha^3 - 2\alpha^2 + 5\beta - 3 = (4\alpha + 1) + 5\beta - 3 = 4\alpha + 5\beta - 2$。

用 $\alpha + \beta = 3$ 表达：$4\alpha + 5\beta = 4\alpha + 5(3 - \alpha) = 15 - \alpha$。

还需 $\alpha$ 的具体值：$\alpha = \dfrac{3 - \sqrt{13}}{2}$（因 $\alpha < \beta$）。

$4\alpha + 5\beta - 2 = 15 - \alpha - 2 = 13 - \dfrac{3 - \sqrt{13}}{2} = \dfrac{26 - 3 + \sqrt{13}}{2} = \dfrac{23 + \sqrt{13}}{2}$。

## 六、自测题

**第 1 题**：已知 $x > 0$，求 $g(x) = x + \dfrac{9}{x}$ 的最小值及取到最小值时 $x$ 的值。

💡 提示：整体换元思路：识别倒数和结构 $x + \dfrac{9}{x}$，用基本不等式 $x + \dfrac{9}{x} \geq 2\sqrt{x \cdot \dfrac{9}{x}} = 6$，等号当 $x = \dfrac{9}{x}$，即 $x = 3$ 时成立。

---

**第 2 题**：解方程 $(\log_2 x)^2 - \log_2 x^3 + 2 = 0$（$x > 0$）。

💡 提示：先化简 $\log_2 x^3 = 3\log_2 x$，令 $t = \log_2 x$，方程化为 $t^2 - 3t + 2 = 0$，因式分解得 $t = 1$ 或 $t = 2$，回代求 $x$。

---

**第 3 题**：已知实数 $a, b$ 满足 $a^2 + b^2 = 1$，求 $2a - b$ 的最大值。

💡 提示：三角换元：令 $a = \cos\theta$，$b = \sin\theta$，$2a - b = 2\cos\theta - \sin\theta$，用辅助角公式合并为 $R\cos(\theta + \varphi)$ 或 $R\sin(\theta + \varphi)$，确定 $R = \sqrt{4+1} = \sqrt{5}$，最大值为 $\sqrt{5}$。

---

**第 4 题**：函数 $y = \log_{\frac{1}{2}}(x^2 - 5x + 6)$ 的单调递增区间是什么？

💡 提示：复合函数内层换元：令 $t = x^2 - 5x + 6$，$y = \log_{1/2} t$ 关于 $t$ 单调递减；$t = (x - \frac{5}{2})^2 - \frac{1}{4}$ 在 $x < \frac{5}{2}$ 时单调递减；"外减内减 = 整体增"，故 $y$ 在 $t > 0$（即 $x < 2$ 或 $x > 3$）与 $x < \frac{5}{2}$ 的交集（即 $x < 2$）上单调递增。
