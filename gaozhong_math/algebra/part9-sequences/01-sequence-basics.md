# 数列的概念与表示

> **一例速记**：  
> **数列** $\{a_n\}$：按一定次序排列的一列数，定义域是 $\mathbb{Z}^+$（或其有限子集）。  
> **通项公式**：$a_n = f(n)$，由 $n$ 直接算出 $a_n$。  
> **递推公式**：$a_{n+1} = g(a_n)$（加初值），由前一项算后一项。  
> **前 $n$ 项和**：$S_n = a_1 + a_2 + \ldots + a_n$，关键关系  
> $$a_n = \begin{cases} S_1, & n = 1 \\ S_n - S_{n-1}, & n \geq 2 \end{cases}$$

---

## 一、数列的概念引入

### 从生活到数学

考察以下几列数：

- $1, 2, 3, 4, 5, \ldots$（正整数列）
- $1, 3, 5, 7, 9, \ldots$（奇数列）
- $2, 4, 8, 16, 32, \ldots$（$2$ 的正整数次幂）
- $1, -1, 1, -1, 1, \ldots$（摆动数列）
- $1, 1, 2, 3, 5, 8, 13, \ldots$（斐波那契数列）

它们都有共同点：**按某种次序**排成一列；**每个位置**对应**唯一一个数**。把这种结构抽象出来便是"数列"。

### 形式定义

**数列**：按照一定次序排列的一列数 $a_1, a_2, a_3, \ldots, a_n, \ldots$ 称为数列，记作 $\{a_n\}$。

其中 $a_n$ 称为数列的**第 $n$ 项**（或称通项），$n$ 称为**项数**或**项的序号**。

**两个核心特征**：
1. **有序**：项的次序不能调换（$1, 2, 3$ 与 $3, 2, 1$ 是不同数列）
2. **可数**：每一项都对应一个正整数下标

**与集合的区别**：集合不强调顺序、不允许重复；数列强调顺序、允许重复（如 $1, 1, 1, \ldots$ 是常数列）。

### 数列即"特殊函数"

由定义可知，数列 $\{a_n\}$ 实质是从 $\mathbb{Z}^+$（或其有限子集 $\{1, 2, \ldots, k\}$）到 $\mathbb{R}$ 的函数：

$$a: \mathbb{Z}^+ \to \mathbb{R}, \quad n \mapsto a_n$$

但其定义域**只能取正整数**，因此其图象是**散点**（不是连续曲线），这是数列与一般函数最本质的差异。

## 二、通项公式与递推公式

### 通项公式

若数列 $\{a_n\}$ 的第 $n$ 项 $a_n$ 可以用关于 $n$ 的式子表示，即

$$a_n = f(n) \quad (n \in \mathbb{Z}^+)$$

则称该式为 $\{a_n\}$ 的**通项公式**。它给出从下标 $n$ 直接计算 $a_n$ 的方法。

**例**：
- $a_n = 2n - 1$ 表示奇数列 $1, 3, 5, 7, \ldots$
- $a_n = 2^n$ 表示 $2, 4, 8, 16, \ldots$
- $a_n = (-1)^{n+1}$ 表示摆动数列 $1, -1, 1, -1, \ldots$

**通项公式不一定唯一**：例如数列 $1, -1, 1, -1, \ldots$ 也可写作 $a_n = \cos[(n-1)\pi]$。但通常取最简形式。

**通项公式不一定存在**：如素数列 $2, 3, 5, 7, 11, 13, \ldots$ 至今没有简洁的通项公式。

### 递推公式

若给定**初值**（如 $a_1$）及**邻项关系**（如 $a_{n+1} = g(a_n)$），也可唯一确定数列，这种表示方式称为**递推公式**。

**例 1**：$a_1 = 1$，$a_{n+1} = a_n + 2$。逐项计算得 $1, 3, 5, 7, \ldots$，即奇数列。

**例 2**：$a_1 = 1$，$a_{n+1} = 2 a_n$。得 $1, 2, 4, 8, 16, \ldots$。

**例 3**（斐波那契）：$a_1 = a_2 = 1$，$a_{n+2} = a_{n+1} + a_n$。得 $1, 1, 2, 3, 5, 8, 13, \ldots$。

**通项 vs 递推**：
- 通项公式是"显式"表示，给 $n$ 直接得 $a_n$。
- 递推公式是"隐式"表示，需要从初值逐步计算。
- 由递推求通项是本部分（第 04 章）的核心任务。

## 三、前 $n$ 项和与 $a_n$ 的关系

### 前 $n$ 项和的定义

**前 $n$ 项和**：

$$S_n = a_1 + a_2 + a_3 + \ldots + a_n = \sum_{k=1}^{n} a_k$$

约定 $S_0 = 0$（空和）。注意 $S_n$ 也是关于 $n$ 的函数。

### 核心关系式

若已知 $\{S_n\}$，可反求 $\{a_n\}$：

$$\boxed{a_n = \begin{cases} S_1, & n = 1 \\ S_n - S_{n-1}, & n \geq 2 \end{cases}}$$

**推导**：由 $S_n = a_1 + \ldots + a_{n-1} + a_n$ 与 $S_{n-1} = a_1 + \ldots + a_{n-1}$ 相减即得 $a_n = S_n - S_{n-1}$（$n \geq 2$）。

但 $n = 1$ 时 $S_0$ 通常没有意义，**必须单独取** $a_1 = S_1$，然后再验证 $S_n - S_{n-1}$ 在 $n = 1$ 时是否与 $S_1$ 一致——若一致则通项公式可合并为一个表达式，若不一致则需分段写。

### 一个完整流程

**给定** $S_n = n^2 + 2n$，求 $a_n$。

**步 1**　$a_1 = S_1 = 1^2 + 2 \cdot 1 = 3$。

**步 2**（$n \geq 2$）：

$$a_n = S_n - S_{n-1} = (n^2 + 2n) - [(n-1)^2 + 2(n-1)] = n^2 + 2n - n^2 + 2n - 1 - 2n + 2 = 2n + 1$$

**步 3**　验证 $n = 1$：$2 \cdot 1 + 1 = 3 = a_1$ ✓，所以可合并：

$$a_n = 2n + 1 \quad (n \in \mathbb{Z}^+)$$

## 四、数列的性质

### 单调性

**递增数列**：对任意 $n \in \mathbb{Z}^+$，$a_{n+1} > a_n$（即 $a_{n+1} - a_n > 0$）。

**递减数列**：对任意 $n$，$a_{n+1} < a_n$。

**常数数列**：所有项相等，$a_n = c$。

**摆动数列**：相邻项符号变化（如 $a_n = (-1)^n$）。

**判断单调性的标准方法**：
- **作差法**：考察 $a_{n+1} - a_n$ 的符号
- **作商法**（当 $a_n > 0$）：考察 $\dfrac{a_{n+1}}{a_n}$ 与 $1$ 的关系

### 有界性

若存在常数 $M$，使所有项满足 $a_n \leq M$，称数列**有上界**；类似定义**有下界**。若上下界都存在，称数列**有界**。

**例**：$a_n = \dfrac{n}{n+1}$（$\dfrac{1}{2}, \dfrac{2}{3}, \dfrac{3}{4}, \ldots$），递增且 $0 < a_n < 1$，有界。

### 周期性

若存在 $T \in \mathbb{Z}^+$ 使 $a_{n+T} = a_n$ 对所有 $n$ 成立，称 $\{a_n\}$ **周期为 $T$**。

**例**：$a_n = \sin\dfrac{n\pi}{2}$ 序列为 $1, 0, -1, 0, 1, 0, -1, 0, \ldots$，周期 $T = 4$。

## 五、典型应用例题

### 例 1：已知 $S_n$ 求 $a_n$

**题目**：数列 $\{a_n\}$ 满足 $S_n = 2n^2 - n$，求通项 $a_n$。

**【思路】** 先用 $S_1$ 算 $a_1$，再用 $S_n - S_{n-1}$ 算 $n \geq 2$ 的通项，最后验证 $n = 1$ 能否合并。

**解**：

$a_1 = S_1 = 2 - 1 = 1$。

当 $n \geq 2$：

$$a_n = S_n - S_{n-1} = (2n^2 - n) - [2(n-1)^2 - (n-1)]$$
$$= 2n^2 - n - 2n^2 + 4n - 2 + n - 1 = 4n - 3$$

验证 $n = 1$：$4 \cdot 1 - 3 = 1 = a_1$ ✓。

**答**：$a_n = 4n - 3$（$n \in \mathbb{Z}^+$）。

---

### 例 2：判断单调性

**题目**：判断数列 $a_n = \dfrac{n}{2^n}$ 的单调性。

**【思路】** 作商法，因 $a_n > 0$。

**解**：

$$\frac{a_{n+1}}{a_n} = \frac{(n+1)/2^{n+1}}{n/2^n} = \frac{n+1}{2n}$$

要判断与 $1$ 的关系：$\dfrac{n+1}{2n} < 1 \Leftrightarrow n + 1 < 2n \Leftrightarrow n > 1$。

故当 $n \geq 2$ 时 $a_{n+1} < a_n$；而 $a_1 = \dfrac{1}{2}, a_2 = \dfrac{2}{4} = \dfrac{1}{2}$，相等。

所以从第 $2$ 项起严格递减，整体是"先平后减"。

**答**：从 $n = 2$ 起递减，且 $a_1 = a_2 = \dfrac{1}{2}$。

---

### 例 3：由数列特征识别通项

**题目**：观察数列 $-\dfrac{1}{2}, \dfrac{1}{4}, -\dfrac{1}{8}, \dfrac{1}{16}, \ldots$ 写出通项公式。

**【思路】** 拆成"符号"+"绝对值"两部分。符号 $-, +, -, +, \ldots$ 用 $(-1)^n$ 表达；绝对值 $\dfrac{1}{2}, \dfrac{1}{4}, \dfrac{1}{8}, \dfrac{1}{16}$ 即 $\dfrac{1}{2^n}$。

**解**：

合成 $a_n = \dfrac{(-1)^n}{2^n} = \left(-\dfrac{1}{2}\right)^n$。

**验证**：$a_1 = -\dfrac{1}{2}$，$a_2 = \dfrac{1}{4}$，$a_3 = -\dfrac{1}{8}$，匹配。

**答**：$a_n = \left(-\dfrac{1}{2}\right)^n$。

## 六、易错点与陷阱

**易错 1：$a_n = S_n - S_{n-1}$ 没验证 $n = 1$**

公式 $a_n = S_n - S_{n-1}$ 只在 $n \geq 2$ 时成立（因 $S_0$ 通常无定义）。算完 $n \geq 2$ 的通项后**必须代入 $n = 1$ 检验**：若与 $S_1$ 一致则合并；否则分段写：

$$a_n = \begin{cases} S_1, & n = 1 \\ S_n - S_{n-1}, & n \geq 2 \end{cases}$$

例如 $S_n = n^2 + 1$，算出 $a_n = 2n - 1$（$n \geq 2$），但 $a_1 = S_1 = 2 \neq 2 \cdot 1 - 1 = 1$，所以必须分段。

**易错 2：把数列当函数处理**

数列的定义域是 $\mathbb{Z}^+$，不是 $\mathbb{R}$。判断单调性时**不能用导数**（虽然辅助函数 $f(x) = \dfrac{x}{2^x}$ 求导可启发思路，但严格证明需用 $a_{n+1} - a_n$ 或 $\dfrac{a_{n+1}}{a_n}$）。

**易错 3：递推公式必须给初值**

只给递推关系 $a_{n+1} = 2a_n + 3$ 而不给 $a_1$，数列不唯一。$k$ 阶递推（如 $a_{n+2} = a_{n+1} + a_n$）需 $k$ 个初值。

**易错 4：观察归纳法不严格**

由"前几项"猜通项只是**找规律**，并非证明。要严格证明通项公式，可用归纳法或回代到递推式验证。

**易错 5：$S_n$ 的下标错位**

$S_n - S_{n-1}$ 是 $a_n$，不是 $a_{n+1}$。下标 $n$ 与 $n - 1$ 之差恰好对应**第 $n$ 项**。

## 七、思路自测题

**自测 1**　已知 $S_n = 3^n - 1$，求 $a_n$，并判断能否合并。

> 💡 提示：$a_1 = S_1 = 2$。$n \geq 2$：$a_n = (3^n - 1) - (3^{n-1} - 1) = 3^n - 3^{n-1} = 2 \cdot 3^{n-1}$。验证 $n = 1$：$2 \cdot 3^0 = 2 = a_1$ ✓，合并为 $a_n = 2 \cdot 3^{n-1}$。

**自测 2**　数列 $a_n = \dfrac{n^2 - 3n + 2}{n+1}$ 是否有最小值？若有，求出第几项。

> 💡 提示：因式分解 $a_n = \dfrac{(n-1)(n-2)}{n+1}$。$a_1 = 0$，$a_2 = 0$，$a_3 = \dfrac{2}{4} = \dfrac{1}{2}$。从 $n = 3$ 起为正且递增（可验证 $a_{n+1} > a_n$），所以最小值为 $0$，在第 $1$ 项和第 $2$ 项取得。

**自测 3**　已知 $a_1 = 2$，$a_{n+1} = a_n + 3$，写出前 $5$ 项，并猜想通项公式。

> 💡 提示：$2, 5, 8, 11, 14$。猜想 $a_n = 3n - 1$。验证：$a_1 = 2 = 3 - 1$ ✓，$a_{n+1} = 3(n+1) - 1 = 3n + 2 = a_n + 3$ ✓。

**自测 4**　判断 $a_n = \dfrac{2n - 1}{n + 1}$ 的单调性，并说明是否有界。

> 💡 提示：作差 $a_{n+1} - a_n = \dfrac{2n+1}{n+2} - \dfrac{2n-1}{n+1} = \dfrac{(2n+1)(n+1) - (2n-1)(n+2)}{(n+2)(n+1)} = \dfrac{3}{(n+2)(n+1)} > 0$，故递增。又 $a_n = 2 - \dfrac{3}{n+1}$，有 $\dfrac{1}{2} \leq a_n < 2$，有界。

**回头看一眼"一例速记"**：

> 数列 = 定义域是正整数的特殊函数；通项是"显式"，递推是"隐式"。  
> $a_n$ 与 $S_n$ 桥梁：$a_n = S_n - S_{n-1}$（$n \geq 2$），$a_1 = S_1$ 必须**单独验证**。  
> 性质三要素：单调（作差或作商）、有界（找上下界）、周期（验证 $a_{n+T} = a_n$）。
