# 由递推关系求通项公式

> **一例速记**：  
> 5 类常见递推 → 5 种构造法：  
> ① $a_{n+1} = a_n + f(n)$ → **累加法**：$a_n = a_1 + \sum_{k=1}^{n-1} f(k)$  
> ② $a_{n+1} = a_n \cdot g(n)$ → **累乘法**：$a_n = a_1 \cdot \prod_{k=1}^{n-1} g(k)$  
> ③ $a_{n+1} = p a_n + q$（$p \neq 1$）→ **待定系数法**：设 $a_n + \lambda = p(a_{n-1} + \lambda)$，解得 $\lambda = \dfrac{q}{p-1}$  
> ④ $a_{n+1} = \dfrac{a_n}{c a_n + d}$ → **取倒数法**：化为 $\dfrac{1}{a_{n+1}} - \dfrac{d}{a_n} \cdot \dfrac{1}{a_n}$ 形式（线性）  
> ⑤ $a_{n+1} = p a_n + q^n$ → **两边除 $q^{n+1}$** 法：构造新数列 $b_n = \dfrac{a_n}{q^n}$

---

## 一、引入：含常数项的一阶线性递推

> **题目**：已知 $a_1 = 1, a_{n+1} = 2a_n + 3$（$n \geq 1$），求通项 $a_n$。

请先停下来想一想：这个递推不是等差（差不是常数）、也不是等比（比不是常数）。如何把它"改造"成我们熟悉的等差或等比数列？

直接列出前几项：$a_1 = 1, a_2 = 5, a_3 = 13, a_4 = 29, a_5 = 61$。差不是常数（$4, 8, 16, 32$），但**差的比**是常数 $2$——这暗示某种"等比结构"潜伏其中。这道题的突破口在于：**给两边同时加一个待定常数 $\lambda$，使得新数列 $\{a_n + \lambda\}$ 是等比数列**。

---

## 二、思维路径还原（解题者的内心独白）

> "看到 $a_{n+1} = 2a_n + 3$，脑子里第一反应：这是 $a_{n+1} = p a_n + q$ 的形式（$p = 2, q = 3, p \neq 1$）。
>
> **第一步：识别类型。** 系数 $p = 2 \neq 1$，常数项 $q = 3 \neq 0$。这正是"一阶线性非齐次递推"的标准型——必须想办法消掉常数项 $q$，让它变成纯齐次（等比）的形式。
>
> **第二步：构造等比。** 关键观察：能不能找一个常数 $\lambda$，使得 $\{a_n + \lambda\}$ 是等比数列？设 $a_{n+1} + \lambda = 2(a_n + \lambda)$，展开右边得 $2a_n + 2\lambda$。
>
> **第三步：与原式对比。** 与原递推 $a_{n+1} = 2a_n + 3$ 对比，要求 $2\lambda - \lambda = 3$，即 $\lambda = 3$。
>
> **第四步：写出等比数列。** 令 $b_n = a_n + 3$，则 $b_{n+1} = 2 b_n$，所以 $\{b_n\}$ 是公比 $q = 2$ 的等比数列。首项 $b_1 = a_1 + 3 = 1 + 3 = 4$。
>
> 故 $b_n = 4 \cdot 2^{n-1} = 2^{n+1}$，所以 $a_n = b_n - 3 = 2^{n+1} - 3$。
>
> **验证。** $n = 1$：$2^2 - 3 = 1$ ✓；$n = 2$：$2^3 - 3 = 5$ ✓；$n = 3$：$2^4 - 3 = 13$ ✓。
>
> **关键反射：** 一阶线性递推 $a_{n+1} = p a_n + q$ 必有 $\lambda = \dfrac{q}{p-1}$ 这个'不动点'——它来自方程 $\lambda = p\lambda + q$。把 $a_n$ 和 $a_{n+1}$ 都减去 $\lambda$（即作平移），消去常数项，就变成纯等比递推 $b_{n+1} = p b_n$。这是'平移变换'的核心。
>
> **快速法：** 心算时可以直接套公式 $\lambda = \dfrac{q}{p-1} = \dfrac{3}{2-1} = 3$，省去推导。但建议第一次自己推一遍，理解'为何是这个 $\lambda$'。"

把这段内心独白读两遍，体会"识别型 → 凑等比 → 解出 $\lambda$ → 写通项"的节奏。

## 三、五类构造法标准操作

下面把五类常见递推的构造方法标准化，每种都先描述场景，再给操作步骤。

### 3.1 累加法（型 ①：$a_{n+1} - a_n = f(n)$）

**适用场景**：递推中 $a_{n+1} - a_n$ 是 $n$ 的函数（而非常数；常数情形是等差数列）。

**操作步骤**：

由 $a_{k+1} - a_k = f(k)$，对 $k = 1, 2, \ldots, n-1$ 累加（叠加法）：

$$\sum_{k=1}^{n-1} (a_{k+1} - a_k) = \sum_{k=1}^{n-1} f(k)$$

左边伸缩展开得 $a_n - a_1$，所以：

$$\boxed{a_n = a_1 + \sum_{k=1}^{n-1} f(k) \quad (n \geq 2)}$$

**典型例**：$a_1 = 1, a_{n+1} = a_n + 2n$，则 $a_n = 1 + \sum_{k=1}^{n-1} 2k = 1 + 2 \cdot \dfrac{(n-1)n}{2} = n^2 - n + 1$。

### 3.2 累乘法（型 ②：$\dfrac{a_{n+1}}{a_n} = g(n)$）

**适用场景**：递推中 $\dfrac{a_{n+1}}{a_n}$ 是 $n$ 的函数（而非常数；常数情形是等比数列）。

**操作步骤**：

由 $\dfrac{a_{k+1}}{a_k} = g(k)$，对 $k = 1, 2, \ldots, n-1$ 累乘：

$$\prod_{k=1}^{n-1} \frac{a_{k+1}}{a_k} = \prod_{k=1}^{n-1} g(k)$$

左边伸缩展开得 $\dfrac{a_n}{a_1}$，所以：

$$\boxed{a_n = a_1 \cdot \prod_{k=1}^{n-1} g(k) \quad (n \geq 2)}$$

**典型例**：$a_1 = 1, a_{n+1} = \dfrac{n+1}{n} a_n$，则 $a_n = 1 \cdot \prod_{k=1}^{n-1} \dfrac{k+1}{k} = \dfrac{2}{1} \cdot \dfrac{3}{2} \cdots \dfrac{n}{n-1} = n$。

### 3.3 待定系数法（型 ③：$a_{n+1} = p a_n + q$，$p \neq 1$）

**适用场景**：一阶线性非齐次递推。

**操作步骤**：

1. 设 $a_n + \lambda = p(a_{n-1} + \lambda)$。
2. 展开右边并与原递推对比：$\lambda p - \lambda = q$，解得 $\lambda = \dfrac{q}{p-1}$。
3. 令 $b_n = a_n + \lambda$，则 $\{b_n\}$ 是公比 $p$ 的等比数列，首项 $b_1 = a_1 + \lambda$。
4. 求出 $b_n = b_1 \cdot p^{n-1}$，再回代得 $a_n = b_n - \lambda$。

**核心心法**：$\lambda$ 是方程 $\lambda = p\lambda + q$ 的解，称为"不动点"——把整个数轴向 $\lambda$ 处平移，递推就变纯等比了。

### 3.4 取倒数法（型 ④：$a_{n+1} = \dfrac{a_n}{c a_n + d}$）

**适用场景**：分式递推，分子是 $a_n$，分母是 $a_n$ 的一次式。

**操作步骤**：

两边取倒数：

$$\frac{1}{a_{n+1}} = \frac{c a_n + d}{a_n} = \frac{d}{a_n} + c$$

令 $b_n = \dfrac{1}{a_n}$，则 $b_{n+1} = d \cdot b_n + c$——又化为型 ③！再用 3.3 的待定系数法。

**特例（$d = 1$）**：若 $a_{n+1} = \dfrac{a_n}{c a_n + 1}$，则 $\dfrac{1}{a_{n+1}} = \dfrac{1}{a_n} + c$，即 $\{1/a_n\}$ 是公差 $c$ 的等差数列！直接得 $\dfrac{1}{a_n} = \dfrac{1}{a_1} + (n-1)c$。

### 3.5 除幂法（型 ⑤：$a_{n+1} = p a_n + q^n$）

**适用场景**：递推右边含 $q^n$ 的指数项。

**操作步骤**：

两边除以 $q^{n+1}$：

$$\frac{a_{n+1}}{q^{n+1}} = \frac{p}{q} \cdot \frac{a_n}{q^n} + \frac{1}{q}$$

令 $b_n = \dfrac{a_n}{q^n}$，则 $b_{n+1} = \dfrac{p}{q} b_n + \dfrac{1}{q}$——又化为型 ③！

**特殊情况**：若 $p = q$，则上式变为 $b_{n+1} = b_n + \dfrac{1}{q}$，是等差数列，更简单。

## 四、方法变形与拓展

### 4.1 含分式的复合型

**例**：$a_1 = 1, a_{n+1} = \dfrac{2 a_n}{a_n + 2}$，求 $a_n$。

**思路**：取倒数：$\dfrac{1}{a_{n+1}} = \dfrac{a_n + 2}{2 a_n} = \dfrac{1}{2} + \dfrac{1}{a_n}$。

令 $b_n = \dfrac{1}{a_n}$，则 $b_{n+1} = b_n + \dfrac{1}{2}$——等差数列，首项 $b_1 = 1$，公差 $\dfrac{1}{2}$，故 $b_n = 1 + (n-1) \cdot \dfrac{1}{2} = \dfrac{n+1}{2}$。

所以 $a_n = \dfrac{2}{n+1}$。

### 4.2 二阶线性递推（特征方程法）

**例**：$a_1 = 1, a_2 = 3, a_{n+2} = 3 a_{n+1} - 2 a_n$，求 $a_n$。

**思路**：这是二阶常系数齐次线性递推 $a_{n+2} = p a_{n+1} + q a_n$。

**操作步骤**：

1. 写**特征方程** $x^2 = 3x - 2$，即 $x^2 - 3x + 2 = 0$。
2. 解得 $x_1 = 1, x_2 = 2$（两根）。
3. 通解为 $a_n = A \cdot 1^n + B \cdot 2^n = A + B \cdot 2^n$。
4. 代入初值定 $A, B$：$a_1 = A + 2B = 1$，$a_2 = A + 4B = 3$，解得 $B = 1, A = -1$。
5. 所以 $a_n = 2^n - 1$。

**思想**：和"一阶用 $\lambda$ 待定"完全一致——把递推看作"特征根"决定的结构。

### 4.3 含 $S_n$ 的递推（$S_n$ 与 $a_n$ 互推）

**例**：$S_n = 2 a_n - 1$，求 $a_n$。

**思路**：利用 $a_n = S_n - S_{n-1}$（$n \geq 2$）：

$$a_n = S_n - S_{n-1} = (2 a_n - 1) - (2 a_{n-1} - 1) = 2 a_n - 2 a_{n-1}$$

整理得 $a_n = 2 a_{n-1}$，即 $\{a_n\}$ 是公比 $2$ 的等比数列。

由 $n = 1$：$S_1 = a_1 = 2 a_1 - 1$，得 $a_1 = 1$。所以 $a_n = 2^{n-1}$。

**关键**：含 $S_n$ 的递推一定要用 $a_n = S_n - S_{n-1}$（注意 $n \geq 2$），单独验证 $n = 1$。

### 4.4 非标准型的先变形

**例**：$a_1 = 2, a_{n+1}^2 = 4 a_n^2$（$a_n > 0$），求 $a_n$。

**思路**：开方（或取对数）。开方得 $a_{n+1} = 2 a_n$（已用 $a_n > 0$），是公比 $2$ 等比，$a_n = 2 \cdot 2^{n-1} = 2^n$。

**取对数策略**：若递推涉及幂指（如 $a_{n+1} = a_n^p$），两边取对数化乘除为加减，再用累加。

## 五、思考路标（条件反射训练）

下面每条都要反复内化，遇到对应场景立刻触发对应方法：

1. **看到 $a_{n+1} - a_n = f(n)$**（差是 $n$ 的函数）→ **累加法**：从 $k = 1$ 累加到 $k = n-1$，注意上下标对齐。

2. **看到 $\dfrac{a_{n+1}}{a_n} = g(n)$**（比是 $n$ 的函数）→ **累乘法**：从 $k = 1$ 累乘到 $k = n-1$，注意每一项不为 $0$。

3. **看到 $a_{n+1} = p a_n + q$（$p \neq 1$）** → **待定系数法**：求 $\lambda = \dfrac{q}{p-1}$，构造 $\{a_n + \lambda\}$ 是公比 $p$ 的等比数列。也可记忆为"找不动点"。

4. **看到 $a_{n+1} = \dfrac{a_n}{c a_n + d}$**（分式型）→ **取倒数**：$\dfrac{1}{a_{n+1}} = \dfrac{d}{a_n} + c$，再视情况用等差或型 ③ 方法。

5. **看到 $a_{n+1} = p a_n + q^n$**（指数项）→ **除以 $q^{n+1}$**：构造 $b_n = \dfrac{a_n}{q^n}$，转化为型 ③。

6. **看到 $a_{n+2} = p a_{n+1} + q a_n$**（二阶线性）→ **特征方程**：解 $x^2 = px + q$，根据根的情况写通解。

7. **看到 $S_n$ 与 $a_n$ 混合的递推** → 用 $a_n = S_n - S_{n-1}$（$n \geq 2$）消 $S_n$，转化为 $a_n$ 与 $a_{n-1}$ 的递推。单独验证 $n = 1$ 的情况。

8. **递推不在标准型** → 先变形：移项、两边开方、两边平方、两边取对、两边取倒，目标是"凑回 5 类标准型之一"。

9. **形如 $a_{n+1} = p a_n + f(n)$（$f$ 非常数也非 $q^n$）** → 这是更一般的情形，可用"试探猜测"（设 $a_n = c \cdot p^n + g(n)$ 的形式，$g(n)$ 与 $f(n)$ 同型）或归纳法。

10. **看到题目只问"前若干项"** → 不要急着求通项，先列前 $3$–$5$ 项找规律（数列归纳法第一步永远是列项）。

## 六、应用例题（5 类构造法演示）

### 例 1：累加法

**题目**：已知 $a_1 = 1$，$a_{n+1} = a_n + 2n + 1$（$n \geq 1$），求 $a_n$。

**【解答】**

由 $a_{k+1} - a_k = 2k + 1$，对 $k = 1, 2, \ldots, n-1$ 累加：

$$a_n - a_1 = \sum_{k=1}^{n-1} (2k + 1) = 2 \cdot \frac{(n-1)n}{2} + (n-1) = n^2 - n + n - 1 = n^2 - 1$$

故 $a_n = 1 + (n^2 - 1) = n^2$。

**验证**：$n = 1$：$1^2 = 1$ ✓；$n = 2$：$1 + 3 = 4 = 2^2$ ✓；$n = 3$：$4 + 5 = 9 = 3^2$ ✓。

$$\boxed{a_n = n^2}$$

> 解题要点：累加法把"差"叠成"和"，伸缩消项后只剩 $a_n - a_1$。注意求和上下限：从 $k=1$ 到 $k = n-1$，共 $n-1$ 项。

---

### 例 2：累乘法

**题目**：已知 $a_1 = 2$，$\dfrac{a_{n+1}}{a_n} = \dfrac{n+2}{n}$（$n \geq 1$），求 $a_n$。

**【解答】**

由 $\dfrac{a_{k+1}}{a_k} = \dfrac{k+2}{k}$，对 $k = 1, 2, \ldots, n-1$ 累乘：

$$\frac{a_n}{a_1} = \prod_{k=1}^{n-1} \frac{k+2}{k} = \frac{3}{1} \cdot \frac{4}{2} \cdot \frac{5}{3} \cdots \frac{n+1}{n-1}$$

观察分子分母的伸缩：分子是 $3, 4, 5, \ldots, n+1$；分母是 $1, 2, 3, \ldots, n-1$。中间 $3, 4, \ldots, n-1$ 都被约掉，剩下：

$$\frac{a_n}{a_1} = \frac{n \cdot (n+1)}{1 \cdot 2} = \frac{n(n+1)}{2}$$

故 $a_n = 2 \cdot \dfrac{n(n+1)}{2} = n(n+1)$。

$$\boxed{a_n = n(n+1) = n^2 + n}$$

> 解题要点：累乘后的连乘式要写出前几项与后几项才能看清"伸缩"模式。当分子分母指标错位时（这里相差 $2$），最终留下首尾的固定项数。

---

### 例 3：待定系数法（型 ③）

**题目**：已知 $a_1 = 3$，$a_{n+1} = 3 a_n - 2$（$n \geq 1$），求 $a_n$。

**【解答】**

**第一步**：识别型 ③：$p = 3, q = -2$。

**第二步**：求不动点 $\lambda = \dfrac{q}{p-1} = \dfrac{-2}{3-1} = -1$。设 $a_n - 1 = b_n$，则递推变形：

$$a_{n+1} - 1 = 3 a_n - 2 - 1 = 3(a_n - 1)$$

即 $b_{n+1} = 3 b_n$，故 $\{b_n\}$ 是公比 $3$ 的等比数列。

**第三步**：首项 $b_1 = a_1 - 1 = 2$，所以 $b_n = 2 \cdot 3^{n-1}$。

**第四步**：回代得 $a_n = b_n + 1 = 2 \cdot 3^{n-1} + 1$。

**验证**：$n = 1$：$2 + 1 = 3$ ✓；$n = 2$：$6 + 1 = 7$，原递推 $a_2 = 3 \cdot 3 - 2 = 7$ ✓。

$$\boxed{a_n = 2 \cdot 3^{n-1} + 1}$$

> 解题要点：$\lambda$ 是不动点（$\lambda = p\lambda + q$ 的解）。这里 $p = 3, q = -2$，$\lambda = 3\lambda - 2 \Rightarrow \lambda = 1$。注意公式 $\lambda = \dfrac{q}{p-1}$ 中的 $q$ 是原递推中的常数项（带符号）。

---

### 例 4：取倒数法（型 ④）

**题目**：已知 $a_1 = 1$，$a_{n+1} = \dfrac{a_n}{2 a_n + 3}$（$n \geq 1$），求 $a_n$。

**【解答】**

**第一步**：两边取倒数（$a_n > 0$ 由数学归纳可得）：

$$\frac{1}{a_{n+1}} = \frac{2 a_n + 3}{a_n} = 2 + \frac{3}{a_n}$$

**第二步**：令 $b_n = \dfrac{1}{a_n}$，则 $b_{n+1} = 3 b_n + 2$——又变成型 ③。

**第三步**：求不动点 $\lambda = \dfrac{2}{3-1} = 1$。设 $c_n = b_n + 1$，则 $c_{n+1} = 3 c_n$，公比 $3$ 的等比数列。

首项 $c_1 = b_1 + 1 = \dfrac{1}{a_1} + 1 = 1 + 1 = 2$，所以 $c_n = 2 \cdot 3^{n-1}$。

**第四步**：回代 $b_n = c_n - 1 = 2 \cdot 3^{n-1} - 1$，再 $a_n = \dfrac{1}{b_n} = \dfrac{1}{2 \cdot 3^{n-1} - 1}$。

$$\boxed{a_n = \frac{1}{2 \cdot 3^{n-1} - 1}}$$

> 解题要点：分式递推一律先"取倒数"——把分式型转为线性型。注意取倒后的递推可能仍是非齐次，需再用一次"不动点"方法。两步组合是高考压轴题的常见套路。

---

### 例 5：除幂法（型 ⑤）

**题目**：已知 $a_1 = 1$，$a_{n+1} = 2 a_n + 3^n$（$n \geq 1$），求 $a_n$。

**【解答】**

**第一步**：右边含 $3^n$。两边除以 $3^{n+1}$：

$$\frac{a_{n+1}}{3^{n+1}} = \frac{2}{3} \cdot \frac{a_n}{3^n} + \frac{1}{3}$$

**第二步**：令 $b_n = \dfrac{a_n}{3^n}$，则 $b_{n+1} = \dfrac{2}{3} b_n + \dfrac{1}{3}$——又是型 ③。

**第三步**：求不动点 $\lambda = \dfrac{1/3}{2/3 - 1} = \dfrac{1/3}{-1/3} = -1$。设 $c_n = b_n - 1$，则 $c_{n+1} = \dfrac{2}{3} c_n$，公比 $\dfrac{2}{3}$ 的等比数列。

首项 $c_1 = b_1 - 1 = \dfrac{a_1}{3} - 1 = \dfrac{1}{3} - 1 = -\dfrac{2}{3}$，所以 $c_n = -\dfrac{2}{3} \cdot \left(\dfrac{2}{3}\right)^{n-1} = -\left(\dfrac{2}{3}\right)^n$。

**第四步**：$b_n = c_n + 1 = 1 - \left(\dfrac{2}{3}\right)^n$，故：

$$a_n = 3^n \cdot b_n = 3^n - 3^n \cdot \left(\frac{2}{3}\right)^n = 3^n - 2^n$$

**验证**：$n = 1$：$3 - 2 = 1$ ✓；$n = 2$：$9 - 4 = 5$，原递推 $a_2 = 2 \cdot 1 + 3 = 5$ ✓。

$$\boxed{a_n = 3^n - 2^n}$$

> 解题要点：除幂法的关键是选对"除数"——通常除以右边指数项的"下一个幂"（这里是 $3^{n+1}$）。除完之后右边的常数项就出现了，转入型 ③ 处理。

## 七、思路自测题

**自测 1**　已知 $a_1 = 2$，$a_{n+1} = a_n + 2^n$（$n \geq 1$），求 $a_n$。

> 💡 提示：$a_{n+1} - a_n = 2^n$ 是 $n$ 的函数，用累加法。$a_n = a_1 + \sum_{k=1}^{n-1} 2^k = 2 + (2^n - 2) = 2^n$。

**自测 2**　已知 $a_1 = 1$，$a_{n+1} = 4 a_n + 3$（$n \geq 1$），求 $a_n$。

> 💡 提示：型 ③，$p = 4, q = 3$。不动点 $\lambda = \dfrac{3}{4-1} = 1$。设 $b_n = a_n + 1$，则 $b_{n+1} = 4 b_n$，公比 $4$ 的等比。首项 $b_1 = 2$，故 $b_n = 2 \cdot 4^{n-1}$，$a_n = 2 \cdot 4^{n-1} - 1$。

**自测 3**　已知 $a_1 = 1$，$\dfrac{a_{n+1}}{a_n} = \dfrac{n}{n+1}$（$n \geq 1$），求 $a_n$。

> 💡 提示：累乘法。$a_n = a_1 \cdot \prod_{k=1}^{n-1} \dfrac{k}{k+1} = 1 \cdot \dfrac{1}{2} \cdot \dfrac{2}{3} \cdots \dfrac{n-1}{n} = \dfrac{1}{n}$。

**自测 4**　已知 $a_1 = 1$，$a_{n+1} = \dfrac{a_n}{1 + 3 a_n}$（$n \geq 1$），求 $a_n$。

> 💡 提示：取倒数 $\dfrac{1}{a_{n+1}} = \dfrac{1 + 3 a_n}{a_n} = \dfrac{1}{a_n} + 3$，即 $\{1/a_n\}$ 是首项 $1$、公差 $3$ 的等差数列。$\dfrac{1}{a_n} = 1 + 3(n-1) = 3n - 2$，故 $a_n = \dfrac{1}{3n-2}$。

**自测 5**　已知 $a_1 = 1, a_2 = 4$，$a_{n+2} = 5 a_{n+1} - 6 a_n$（$n \geq 1$），求 $a_n$。

> 💡 提示：二阶线性。特征方程 $x^2 - 5x + 6 = 0$，根 $x = 2, 3$。通解 $a_n = A \cdot 2^n + B \cdot 3^n$。代入 $a_1 = 2A + 3B = 1$，$a_2 = 4A + 9B = 4$，解得 $A = -\dfrac{1}{2}, B = \dfrac{2}{3}$。故 $a_n = -\dfrac{1}{2} \cdot 2^n + \dfrac{2}{3} \cdot 3^n = -2^{n-1} + 2 \cdot 3^{n-1}$。

> 5 类构造：累加（差为 $n$ 函数）、累乘（比为 $n$ 函数）、待定系数（$pa_n + q$）、取倒数（分式型）、除幂（$pa_n + q^n$）。  
> 核心心法：**化生为熟**——把陌生的递推改造成等差或等比数列。
