# 等差数列

> **一例速记**：  
> **定义**：$a_{n+1} - a_n = d$（常数公差）。  
> **通项**：$a_n = a_1 + (n - 1) d = dn + (a_1 - d)$（关于 $n$ 的**一次函数**）。  
> **求和**：$S_n = \dfrac{n(a_1 + a_n)}{2} = n a_1 + \dfrac{n(n-1)}{2} d$（关于 $n$ 的**二次函数**，$d \neq 0$）。  
> **等差中项**：$2 a_n = a_{n-1} + a_{n+1}$。  
> **关键性质**：$m + n = p + q \Rightarrow a_m + a_n = a_p + a_q$。

---

## 一、概念引入

### 从规律到定义

考察数列：
- $1, 4, 7, 10, 13, \ldots$（每项比前一项大 $3$）
- $20, 17, 14, 11, 8, \ldots$（每项比前一项小 $3$）
- $-5, -5, -5, -5, \ldots$（每项相等，可看作差为 $0$）

它们的共同特征：**相邻两项的差是同一个常数**。这个常数叫做**公差**，记作 $d$。

### 形式定义

**等差数列**：若数列 $\{a_n\}$ 从第二项起，每一项与前一项的差等于同一个常数 $d$，即

$$a_{n+1} - a_n = d \quad (n \in \mathbb{Z}^+)$$

则称 $\{a_n\}$ 为**等差数列**，$d$ 称为**公差**。

**说明**：
- $d > 0$：递增；$d < 0$：递减；$d = 0$：常数列
- 公差是"后项减前项"，方向固定不可颠倒
- 用 $a_1$ 与 $d$ 两个量即可完全确定整个数列

### 三种等价形式

判断 $\{a_n\}$ 是等差数列，常用以下三种等价条件之一：

1. **定义形式**：$a_{n+1} - a_n = d$（$n \geq 1$）
2. **中项形式**：$2 a_n = a_{n-1} + a_{n+1}$（$n \geq 2$）
3. **一次函数形式**：通项 $a_n = An + B$（$A, B$ 为常数）

三者互为充要条件（详见性质部分）。

---

## 二、通项公式与求和公式

### 通项公式

**推导**：由定义 $a_{n+1} - a_n = d$，逐项累加：

$$\begin{aligned}
a_2 &= a_1 + d \\
a_3 &= a_2 + d = a_1 + 2d \\
a_4 &= a_3 + d = a_1 + 3d \\
&\vdots \\
a_n &= a_1 + (n - 1) d
\end{aligned}$$

或严格地累加：$a_n - a_1 = \sum_{k=1}^{n-1}(a_{k+1} - a_k) = (n-1) d$，故

$$\boxed{a_n = a_1 + (n - 1) d}$$

**化简形式**：

$$a_n = a_1 + (n - 1) d = d \cdot n + (a_1 - d)$$

这是关于 $n$ 的**一次函数**形式 $a_n = An + B$，其中 $A = d$，$B = a_1 - d$。**$d \neq 0$ 时**散点在斜率为 $d$ 的直线上；$d = 0$ 时为水平线。

### 求和公式

**倒序相加法**：设 $S_n = a_1 + a_2 + \ldots + a_n$，倒过来写：

$$\begin{aligned}
S_n &= a_1 + a_2 + a_3 + \ldots + a_n \\
S_n &= a_n + a_{n-1} + a_{n-2} + \ldots + a_1
\end{aligned}$$

两式**对位相加**，利用 $a_1 + a_n = a_2 + a_{n-1} = \ldots = a_n + a_1$（共 $n$ 对），得：

$$2 S_n = n (a_1 + a_n)$$

即

$$\boxed{S_n = \frac{n (a_1 + a_n)}{2}}$$

代入 $a_n = a_1 + (n - 1) d$，得**第二种形式**：

$$\boxed{S_n = n a_1 + \frac{n (n - 1)}{2} d}$$

把后者整理为关于 $n$ 的多项式：

$$S_n = \frac{d}{2} n^2 + \left(a_1 - \frac{d}{2}\right) n$$

这是关于 $n$ 的**二次函数**（$d \neq 0$，无常数项），常写作 $S_n = An^2 + Bn$，其中

$$A = \frac{d}{2}, \quad B = a_1 - \frac{d}{2}$$

由此可**反推**：$d = 2A$，$a_1 = A + B$。

---

## 三、关键性质

### 等差中项

若 $a, b, c$ 成等差数列，则 $b$ 称为 $a$ 与 $c$ 的**等差中项**，满足

$$b = \frac{a + c}{2}$$

对数列内部任三项 $a_{n-1}, a_n, a_{n+1}$ 均有 $a_n = \dfrac{a_{n-1} + a_{n+1}}{2}$，即

$$2 a_n = a_{n-1} + a_{n+1}$$

这条性质**反过来也成立**：若数列每三项都满足该关系，则它是等差数列（充要条件）。

### 下标和性质

若 $m + n = p + q$（$m, n, p, q \in \mathbb{Z}^+$），则

$$a_m + a_n = a_p + a_q$$

**证明**：$a_m + a_n = [a_1 + (m-1)d] + [a_1 + (n-1)d] = 2 a_1 + (m + n - 2) d$；同理 $a_p + a_q = 2 a_1 + (p + q - 2) d$。由 $m + n = p + q$ 得二者相等。

**特例**：若 $m + n = 2k$，则 $a_m + a_n = 2 a_k$（$a_k$ 是 $a_m, a_n$ 的等差中项）。

**应用**：$a_1 + a_n = a_2 + a_{n-1} = a_3 + a_{n-2} = \ldots$，是求和公式的逻辑基础。

### 等距子序列性质

**结论**：$S_n, S_{2n} - S_n, S_{3n} - S_{2n}, S_{4n} - S_{3n}, \ldots$ 也成等差数列，其公差为 $n^2 d$。

**推导**：

$$\begin{aligned}
S_n &= a_1 + a_2 + \ldots + a_n \\
S_{2n} - S_n &= a_{n+1} + a_{n+2} + \ldots + a_{2n}
\end{aligned}$$

每一项较前一段对应位置多了 $n \cdot d$（$n$ 步公差），共 $n$ 项，故段差为 $n \cdot n d = n^2 d$。

类似 $S_{3n} - S_{2n}$ 比 $S_{2n} - S_n$ 多 $n^2 d$，故确成等差，公差 $n^2 d$。

### 一次函数与二次函数判据

由通项 $a_n = dn + (a_1 - d)$ 可知：**$\{a_n\}$ 为等差数列 $\Leftrightarrow$ $a_n$ 是关于 $n$ 的一次函数**（或常数函数 $d = 0$）。

由 $S_n = \dfrac{d}{2} n^2 + \left(a_1 - \dfrac{d}{2}\right) n$ 可知：**$\{a_n\}$ 为等差数列 $\Leftrightarrow$ $S_n$ 是关于 $n$ 的二次函数（无常数项）**（$d = 0$ 退化为 $S_n = n a_1$ 一次函数）。

**判据的反向应用**：若题目给出 $S_n = 2 n^2 + 3 n$ 形式，可直接判定 $\{a_n\}$ 为等差，且 $d = 2 \cdot 2 = 4$，$a_1 = 2 + 3 = 5$。

## 四、典型应用例题

### 例 1：求公差与通项

**题目**：已知等差数列 $\{a_n\}$ 中，$a_3 = 7$，$a_7 = 19$，求公差 $d$、$a_1$ 及 $a_{20}$。

**【思路】** 列方程组：$a_3 = a_1 + 2 d$，$a_7 = a_1 + 6 d$，相减消 $a_1$。

**解**：

$$a_7 - a_3 = 4 d \Rightarrow 19 - 7 = 4 d \Rightarrow d = 3$$

由 $a_3 = a_1 + 2 d = 7$：$a_1 = 7 - 6 = 1$。

$$a_{20} = a_1 + 19 d = 1 + 19 \times 3 = 58$$

**答**：$d = 3$，$a_1 = 1$，$a_{20} = 58$。

---

### 例 2：含参等差数列求和

**题目**：等差数列 $\{a_n\}$ 中，$S_{10} = 120$，$S_{20} = 440$，求 $S_{30}$。

**【思路】** 利用等距子序列性质：$S_{10}, S_{20} - S_{10}, S_{30} - S_{20}$ 成等差。

**解**：

设 $A = S_{10} = 120$，$B = S_{20} - S_{10} = 440 - 120 = 320$。

由 $A, B, S_{30} - S_{20}$ 成等差，得

$$2 B = A + (S_{30} - S_{20}) \Rightarrow S_{30} - S_{20} = 2 \times 320 - 120 = 520$$

$$S_{30} = 520 + 440 = 960$$

**答**：$S_{30} = 960$。

**另解验证**：由 $S_n = An^2 + Bn$ 设法。$S_{10} = 100 A + 10 B = 120$，$S_{20} = 400 A + 20 B = 440$。
解得 $A = 1, B = 2$。故 $S_{30} = 900 + 60 = 960$ ✓。

---

### 例 3：反向题——由 $S_n$ 判等差

**题目**：已知数列 $\{a_n\}$ 的前 $n$ 项和 $S_n = 3 n^2 - 2 n$。
(1) 求 $a_n$；(2) 判断 $\{a_n\}$ 是否为等差数列。

**【思路】** (1) 用 $a_n = S_n - S_{n-1}$；(2) 看通项是否为 $n$ 的一次函数 / 用定义验。

**解**：

(1) $a_1 = S_1 = 3 - 2 = 1$。

$n \geq 2$ 时：

$$a_n = S_n - S_{n-1} = (3n^2 - 2n) - [3(n-1)^2 - 2(n-1)] = 3n^2 - 2n - 3n^2 + 6n - 3 + 2n - 2 = 6n - 5$$

验证 $n = 1$：$6 \cdot 1 - 5 = 1 = a_1$ ✓。

故 $a_n = 6n - 5$。

(2) $a_n = 6 n - 5$ 是 $n$ 的一次函数，故 $\{a_n\}$ 是等差数列。公差 $d = 6$（一次项系数），$a_1 = 1$。

**也可由 $S_n$ 形式直接判断**：$S_n = 3 n^2 - 2 n$ 无常数项，是 $n$ 的二次函数（无常数项），故 $\{a_n\}$ 为等差，$d = 2 \times 3 = 6$，$a_1 = 3 + (-2) = 1$。

## 五、易错点与陷阱

**易错 1：通项公式 $(n - 1)$ 写成 $n$**

$a_n = a_1 + (n - 1) d$ 不是 $a_1 + n d$。原因：$a_1$ 已是"第 $1$ 项"，到 $a_n$ 共**走了 $n - 1$ 步**。常见错误是把 $a_5$ 算成 $a_1 + 5 d$（实际应是 $a_1 + 4 d$）。

**易错 2：$S_n$ 二次项系数 $\dfrac{d}{2}$**

由 $S_n = \dfrac{d}{2} n^2 + \left(a_1 - \dfrac{d}{2}\right) n$，二次项系数是 $\dfrac{d}{2}$，**不是 $d$**。反推公差时 $d = 2 \times (\text{二次项系数})$。

**易错 3：$S_n$ 必须无常数项才是等差**

若 $S_n = n^2 + 2 n + 5$（有常数项 $5$），那 $S_0 = 5 \neq 0$，说明该数列**不是从 $n = 1$ 起的等差数列**。这种情形下：
- $a_1 = S_1 = 8$
- $n \geq 2$：$a_n = S_n - S_{n-1} = 2 n + 1$（一次函数）
- 但 $a_1 = 8 \neq 2 \cdot 1 + 1 = 3$，**分段**，整体非等差。

**易错 4：求和公式形式选择**

已知 $a_1, a_n$ 选 $S_n = \dfrac{n(a_1 + a_n)}{2}$（无需求 $d$）；已知 $a_1, d$ 选 $S_n = n a_1 + \dfrac{n(n-1)}{2} d$。

**易错 5：等差中项的对称使用**

$a_n = \dfrac{a_{n-1} + a_{n+1}}{2}$ 中下标对称分布在 $n$ 两侧。常用于"已知三项成等差"列方程。

## 六、思路自测题

**自测 1**　等差数列 $\{a_n\}$ 中，$a_5 = 11$，$a_{10} = 26$，求 $a_{30}$。

> 💡 提示：$a_{10} - a_5 = 5 d = 15 \Rightarrow d = 3$；$a_1 = a_5 - 4 d = 11 - 12 = -1$；$a_{30} = -1 + 29 \times 3 = 86$。

**自测 2**　等差数列 $\{a_n\}$ 的前 $n$ 项和 $S_n = n^2 + 4 n$，求 $a_1, d, a_{10}$。

> 💡 提示：$S_n$ 无常数项、是 $n^2 + 4n$，故 $A = 1, B = 4$；$d = 2 A = 2$，$a_1 = A + B = 5$；$a_{10} = 5 + 9 \times 2 = 23$。

**自测 3**　已知等差数列 $\{a_n\}$ 中 $a_3 + a_8 = 22$，求 $S_{10}$。

> 💡 提示：$a_3 + a_8 = a_1 + a_{10}$（因 $3 + 8 = 1 + 10$）$= 22$；$S_{10} = \dfrac{10(a_1 + a_{10})}{2} = 5 \times 22 = 110$。

**自测 4**　已知等差数列 $\{a_n\}$ 中 $a_1 = -10$，$d = 2$，求使 $S_n$ 最小的 $n$。

> 💡 提示：$S_n = \dfrac{d}{2} n^2 + \left(a_1 - \dfrac{d}{2}\right) n = n^2 - 11 n$，对称轴 $n = \dfrac{11}{2} = 5.5$。$n \in \mathbb{Z}^+$，取 $n = 5$ 或 $6$ 时 $S_n$ 最小。验证：$S_5 = 25 - 55 = -30$，$S_6 = 36 - 66 = -30$，相等。故 $n = 5$ 或 $6$ 时 $S_n$ 最小为 $-30$。

**自测 5**　等差数列 $\{a_n\}$ 中，$S_5 = 30$，$S_{10} = 110$，求 $S_{15}$。

> 💡 提示：$S_5, S_{10} - S_5, S_{15} - S_{10}$ 成等差。设 $A = 30, B = 110 - 30 = 80$，则 $C = 2 B - A = 130$，$S_{15} = 110 + 130 = 240$。
