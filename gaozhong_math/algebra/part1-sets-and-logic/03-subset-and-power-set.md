# 子集、真子集与幂集

第 1 章我们认识了集合的成员关系（元素 $\in$ 集合）；第 2 章学会了集合之间的运算（交、并、补）。本章转向集合之间另一种核心关系：**包含关系**。"$A$ 的每个元素都在 $B$ 中"——这个陈述引出子集的概念，进而推出真子集、集合相等和幂集。这些概念是含参集合讨论的理论基础，也是第 5 章充要条件的集合语言版本。

## 一、概念特征：怎么一眼认出

- **子集**：$A$ 里的每个元素都出现在 $B$ 里（允许 $A = B$）。关键词：$A$ 的元素全部属于 $B$、$A \subseteq B$。
- **真子集**：$A \subseteq B$ 且 $A \neq B$（$B$ 里至少有一个元素不在 $A$ 里）。关键词：$A \subsetneq B$。
- **集合相等**：$A \subseteq B$ 且 $B \subseteq A$（双向包含）。
- **幂集**：集合 $A$ 的所有子集拼起来形成的集合，记 $2^A$。

看到题目问"$B \subseteq A$ 时参数的范围"，立刻想到 $B$ 的每个元素都要在 $A$ 中——这是含参集合的核心题型。

## 二、定义与核心工具

### 1. 子集

设 $A$、$B$ 是两个集合。若 $A$ 的每个元素都是 $B$ 的元素，则称 $A$ 是 $B$ 的**子集**（subset），记作

$$A \subseteq B \quad (\text{读作} \; A \; \text{包含于} \; B \; \text{或} \; B \; \text{包含} \; A).$$

等价表述：$A \subseteq B \iff \forall x,\; x \in A \Rightarrow x \in B$。

**基本性质**：
- **自反性**：$A \subseteq A$（每个集合是自身的子集）；
- **反对称性**：若 $A \subseteq B$ 且 $B \subseteq A$，则 $A = B$；
- **传递性**：若 $A \subseteq B$ 且 $B \subseteq C$，则 $A \subseteq C$；
- $A \cap B \subseteq A \subseteq A \cup B$（交集 $\subseteq$ 各自 $\subseteq$ 并集）。

### 2. 真子集

若 $A \subseteq B$ 且 $A \neq B$，则称 $A$ 是 $B$ 的**真子集**（proper subset），记作

$$A \subsetneq B.$$

等价表述：$A \subsetneq B \iff A \subseteq B$ 且 $\exists x \in B$ 使 $x \notin A$。

注意：$A \subseteq B$ 与 $A \subsetneq B$ 的区别在于是否允许 $A = B$。$\subseteq$ 相当于 $\leq$，$\subsetneq$ 相当于 $<$。

### 3. 空集是任何集合的子集

**命题**：$\varnothing \subseteq A$ 对一切集合 $A$ 成立。

**证明**：子集定义要求"$A$ 的每个元素都在 $B$ 中"。对于 $\varnothing$，它没有任何元素，所以"$\varnothing$ 的每个元素都在 $A$ 中"这一陈述是**空真**（vacuously true）——没有任何反例。因此 $\varnothing \subseteq A$ 成立。

这一结论常常在含参集合题中用到：当参数使得某集合为空集时，$\varnothing \subseteq A$ 恒成立，不能遗漏这种情形。

### 4. 集合相等

两个集合 $A = B$ 当且仅当

$$A = B \iff A \subseteq B \text{ 且 } B \subseteq A.$$

**证明两集合相等的标准方法（双向包含法）**：

1. 证明 $A \subseteq B$：取任意 $x \in A$，证 $x \in B$；
2. 证明 $B \subseteq A$：取任意 $x \in B$，证 $x \in A$。

两步都完成，则 $A = B$。

### 5. 幂集

设 $A$ 是一个集合，$A$ 的所有子集组成的集合称为 $A$ 的**幂集**（power set），记作 $2^A$（有时也记作 $\mathcal{P}(A)$）：

$$2^A = \{B \mid B \subseteq A\}.$$

**子集个数公式**：若 $|A| = n$（$A$ 含 $n$ 个元素），则

$$|2^A| = 2^n.$$

**推导**：$A$ 的每个子集，是由 $A$ 的每个元素决定"选或不选"来确定的。$n$ 个元素每个独立二选一，共 $2^n$ 种方案，对应 $2^n$ 个不同子集。

**注意**：幂集 $2^A$ 本身是一个集合，其元素是集合（是子集）。$A$ 的元素和 $2^A$ 的元素是不同层次的对象。

## 三、推导：为什么这样定义

**为什么子集允许 $A = B$？** 这使得子集关系形成偏序（partial order），满足自反性、反对称性、传递性。若排除等号，则每个集合不再是自身的子集，自反性不成立，破坏了偏序结构的完整性。

**为什么 $\varnothing$ 是任何集合的子集？** 若 $\varnothing \not\subseteq A$，则意味着 $\varnothing$ 中存在某个元素不属于 $A$。但 $\varnothing$ 没有任何元素，这是矛盾的。因此只能承认 $\varnothing \subseteq A$。另一种理解：子集定义是一个全称命题（对所有 $x$，若 $x \in \varnothing$ 则 $x \in A$），空集使前件永假，全称命题空真成立。

**幂集为什么记作 $2^A$？** 因为当 $|A|=n$ 时，$|2^A| = 2^n$。记号 $2^A$ 直观体现了元素个数与指数的关系，同时也可以拓展：$2$ 可以理解为"选或不选"的二元选择。

## 四、典型应用

### 例 1　写出集合的所有子集和真子集

**题目**：写出 $A = \{a, b, c\}$ 的所有子集和所有真子集。

**【思路】** 系统枚举：按元素个数从 $0$ 到 $3$ 分层列举，不重不漏。

**解**：

$|A| = 3$，共 $2^3 = 8$ 个子集。

- 含 $0$ 个元素：$\varnothing$（1 个）
- 含 $1$ 个元素：$\{a\}$，$\{b\}$，$\{c\}$（3 个）
- 含 $2$ 个元素：$\{a,b\}$，$\{a,c\}$，$\{b,c\}$（3 个）
- 含 $3$ 个元素：$\{a,b,c\}$（1 个）

$A$ 的所有子集：$\varnothing$，$\{a\}$，$\{b\}$，$\{c\}$，$\{a,b\}$，$\{a,c\}$，$\{b,c\}$，$\{a,b,c\}$，共 $8$ 个。

$A$ 的真子集：即子集中去掉 $A$ 本身，共 $7$ 个：$\varnothing$，$\{a\}$，$\{b\}$，$\{c\}$，$\{a,b\}$，$\{a,c\}$，$\{b,c\}$。

### 例 2　含参集合中 $B \subseteq A$ 的参数求解

**题目**：设 $A = \{x \mid x^2 - 1 = 0\}$，$B = \{x \mid mx = 1\}$，若 $B \subseteq A$，求实数 $m$ 的所有可能值。

**【思路】** 先求出 $A$。$x^2 - 1 = 0$ → $x = \pm 1$，故 $A = \{-1, 1\}$。

$B$ 是方程 $mx = 1$ 的解集。$B$ 有几个元素取决于 $m$ 的值：
- 若 $m = 0$，方程变为 $0 \cdot x = 1$，即 $0 = 1$，无解，$B = \varnothing$；
- 若 $m \neq 0$，方程有唯一解 $x = \dfrac{1}{m}$，$B = \left\{\dfrac{1}{m}\right\}$。

$B \subseteq A$ 要求 $B$ 的每个元素都在 $A = \{-1, 1\}$ 中。

- 情形 1：$B = \varnothing$。$\varnothing \subseteq A$ 恒成立，对应 $m = 0$。✓
- 情形 2：$B = \left\{\dfrac{1}{m}\right\} \subseteq A = \{-1, 1\}$。则 $\dfrac{1}{m} = -1$ 或 $\dfrac{1}{m} = 1$，即 $m = -1$ 或 $m = 1$。

**解**：$m$ 的所有可能值为 $m \in \{-1, 0, 1\}$。

**【关键提醒】** $B = \varnothing$ 的情形（$m = 0$）必须单独讨论，不能漏掉。这是含参集合题中最常见的失分点。

### 例 3　证明两集合相等（双向包含法）

**题目**：设 $A = \{x \mid x^2 - x - 2 = 0\}$，$B = \{x \mid (x-2)(x+1) = 0\}$，证明 $A = B$。

**【思路】** 先分别求出两个集合的元素，再用双向包含法证明（或直接验证元素相同）。

**解**：

解方程 $x^2 - x - 2 = 0$：因式分解得 $(x-2)(x+1) = 0$，故 $x = 2$ 或 $x = -1$，$A = \{-1, 2\}$。

解方程 $(x-2)(x+1) = 0$：$x = 2$ 或 $x = -1$，$B = \{-1, 2\}$。

由于 $A$ 与 $B$ 含有完全相同的元素，故 $A = B$。

（若需要严格双向包含证明：任取 $x \in A$，则 $x = -1$ 或 $x = 2$，均满足 $(x-2)(x+1) = 0$，故 $x \in B$；反向同理。）

## 五、易错点 & 反例

1. **含参题中必须讨论 $B = \varnothing$ 的情形。**
   反例：例 2 中若忘记 $m = 0$ 的情况，则漏掉了一个合法的 $m$ 值。每道含参子集题，第一个要问的是"$B$ 是否可能为空集？"。

2. **子集 $\subseteq$ 与真子集 $\subsetneq$ 的区别。**
   $A \subseteq A$（成立），但 $A \subsetneq A$（不成立，因为 $A = A$）。若题目问"$A$ 的真子集个数"，应该是 $2^n - 1$（去掉 $A$ 本身）；若问"子集个数"，则是 $2^n$。

3. **$\varnothing$ 是所有集合的子集，但 $\varnothing$ 的元素不是所有集合的元素。**
   $\varnothing \subseteq A$ 恒成立，但不能说"$\varnothing \in A$"（除非 $A$ 的元素中包含空集这个对象，如 $\{\varnothing, 1\}$）。

4. **幂集的元素是集合，不是数。**
   $2^{\{1,2\}} = \{\varnothing, \{1\}, \{2\}, \{1,2\}\}$——每个元素都是一个集合。$1 \in 2^{\{1,2\}}$ 是错误的；$\{1\} \in 2^{\{1,2\}}$ 才是正确的。

5. **集合相等与元素相等。**
   $\{1, 2\} = \{2, 1\}$（相同集合，无序性），但 $1 \neq 2$（不同元素）。集合层面的相等不等于元素层面的相等。

6. **含参子集题的双向约束。**
   若 $A \subseteq B$ 且 $B \subseteq A$，则 $A = B$。在解方程或不等式时，两个方向的约束要联立取交集，不能只用一侧。

## 六、思路自测题

**自测 1**　写出集合 $\{1, 2\}$ 的幂集 $2^{\{1,2\}}$，并写出 $\{1, 2, 3, 4\}$ 的子集个数和真子集个数。

💡 提示：$\{1,2\}$ 有 $2^2 = 4$ 个子集，逐一列举。$\{1,2,3,4\}$ 有 $2^4 = 16$ 个子集，真子集 $16 - 1 = 15$ 个。

**自测 2**　设 $A = \{x \mid x^2 + ax + b = 0\}$，$B = \{0, 1\}$，$B \subseteq A$，求 $a$、$b$ 的值，并写出此时 $A$ 的所有可能的值。

💡 提示：$B \subseteq A$ 意味着 $0 \in A$ 且 $1 \in A$，即 $0$ 和 $1$ 都是方程 $x^2 + ax + b = 0$ 的根。由韦达定理（或直接代入）：$0$ 代入得 $b = 0$；$1$ 代入得 $1 + a = 0$，即 $a = -1$。此时方程 $x^2 - x = 0$，解为 $x = 0$ 或 $x = 1$，$A = \{0, 1\} = B$。也可能 $A$ 更大，但二次方程最多两根，所以 $A = \{0, 1\}$。

**自测 3**　已知集合 $A = \{x \mid 1 \leq x \leq 4\}$，$B = \{x \mid a \leq x \leq a + 1\}$，若 $B \subseteq A$，求实数 $a$ 的范围。

💡 提示：需分两种情形：(1) $B = \varnothing$：$a > a+1$，矛盾，所以 $B$ 不可能为空集（$a \leq a+1$ 恒成立）；(2) $B \neq \varnothing$：需要 $B$ 的左端点 $a \geq 1$ 且右端点 $a+1 \leq 4$，即 $1 \leq a \leq 3$。

**自测 4**　用双向包含法证明：$A = \{x \mid x^2 - 3x + 2 = 0\}$ 与 $B = \{x \mid (x-1)(x-2) = 0\}$ 相等。

💡 提示：先解两个方程，分别得 $A = \{1,2\}$，$B = \{1,2\}$；然后用"任取 $x \in A \Rightarrow x \in B$"和"任取 $x \in B \Rightarrow x \in A$"两步写出严格证明。或者直接说明两方程等价（方程一的因式分解就是方程二），因此解集相同。
