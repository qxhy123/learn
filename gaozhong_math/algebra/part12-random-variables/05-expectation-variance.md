# 随机变量的期望与方差

> **一例速记**：  
> **期望**：$E(X) = \displaystyle\sum_i x_i p_i$（加权平均，反映"中心位置"）。  
> **方差**：$D(X) = \displaystyle\sum_i (x_i - E(X))^2 p_i = E(X^2) - [E(X)]^2$（反映"分散程度"）。  
> **标准差**：$\sigma(X) = \sqrt{D(X)}$（与 $X$ 同单位）。  
> **线性性质**：$E(aX + b) = aE(X) + b$；$D(aX + b) = a^2 D(X)$（注意 $D$ 中常数 $b$ 不影响，$a$ 要**平方**）。  
> **独立性**：若 $X, Y$ 独立，则 $E(XY) = E(X)E(Y)$；$D(X + Y) = D(X) + D(Y)$。

---

## 一、引入：从二项分布的期望方差入手

> **题目**：设 $X$ 服从二项分布 $B(5, 0.4)$。  
> **(1)** 求 $E(X)$ 与 $D(X)$。  
> **(2)** 设 $Y = 3X + 2$，求 $E(Y)$ 与 $D(Y)$。

请先停下来想想：$X$ 是"做 $5$ 次独立试验，每次成功率 $0.4$，成功次数"。

如果你已熟悉二项分布公式，$E(X), D(X)$ 都有现成公式可代。第二步引入了新元素 $Y = 3X + 2$——这是一个**线性变换**后的新随机变量。线性变换会怎样影响期望与方差？这正是本章要建立的"反射"。

---

## 二、思维路径还原（解题者的内心独白）

> "看到 $X \sim B(5, 0.4)$ 求期望方差，第一反应：**直接代二项分布公式**。
>
> **第一步：套公式。**
>
> - $E(X) = np = 5 \times 0.4 = 2$
> - $D(X) = np(1-p) = 5 \times 0.4 \times 0.6 = 1.2$
>
> 直觉验证：每次成功率 $0.4$，做 $5$ 次平均成功 $5 \times 0.4 = 2$ 次——合理。方差 $1.2$，标准差 $\sqrt{1.2} \approx 1.1$，意味着实际成功次数与期望 $2$ 偏离约 $1$——合理。
>
> **第二步：处理线性变换 $Y = 3X + 2$。**
>
> 期望的线性性是无条件成立的：$E(aX + b) = aE(X) + b$。所以：
>
> $$E(Y) = E(3X + 2) = 3 E(X) + 2 = 3 \times 2 + 2 = 8$$
>
> 方差对常数项 $b$"不敏感"（只是把分布整体平移，不改变分散程度），但对系数 $a$ 要**平方**（拉伸 $a$ 倍后，距离的平方变成 $a^2$ 倍）：
>
> $$D(Y) = D(3X + 2) = 3^2 D(X) = 9 \times 1.2 = 10.8$$
>
> **关键反射**：期望中的 $b$ 进去时还是 $b$；方差中的 $b$ 直接消失；系数 $a$ 在期望中是 $a$、在方差中是 $a^2$。
>
> **直觉解释**：想象一组数据 $\{0, 1, 2, 3, 4\}$ 平均 $2$、方差 $2$。
> - 加 $b = 2$ 得 $\{2, 3, 4, 5, 6\}$，平均变 $4$（移动了 $2$），但相邻间距没变，方差仍 $2$。
> - 乘 $a = 3$ 得 $\{0, 3, 6, 9, 12\}$，平均变 $6$（是原来的 $3$ 倍），间距也是原来的 $3$ 倍，方差是 $3^2 = 9$ 倍。
>
> **延伸思考**：如果题目要 $D(2X - 3Y)$（$X, Y$ 独立），用什么？
> - $D(2X - 3Y) = D(2X) + D(-3Y) = 4 D(X) + 9 D(Y)$
> - 注意：独立时 $D(X + Y) = D(X) + D(Y)$；$-3$ 系数平方后是 $9$（不是 $-9$）。
>
> **方法迁移**：所有"线性变换"问题都用 $E(aX + b) = aE(X) + b$、$D(aX + b) = a^2 D(X)$；所有"两独立变量和差"问题都用 $E$ 线性 + $D$ 独立可加（变换后系数要平方）。"

把这段独白读两遍，把"$E$ 线性、$D$ 平方"刻进直觉。

## 三、抽象成方法：期望与方差的完整工具箱

### 3.1 期望的定义与计算

设离散型随机变量 $X$ 的分布列为 $P(X = x_i) = p_i$，则**数学期望**：

$$E(X) = \sum_{i} x_i p_i$$

**几种常见分布的期望**：

| 分布 | 表示 | 期望 |
|------|------|------|
| 两点分布 | $P(X=1) = p$ | $E(X) = p$ |
| 二项分布 | $X \sim B(n, p)$ | $E(X) = np$ |
| 超几何分布 | 上一章 | $E(X) = n \cdot \dfrac{M}{N}$ |
| 正态分布 | $X \sim N(\mu, \sigma^2)$ | $E(X) = \mu$ |

### 3.2 方差的定义与计算

**方差**：

$$D(X) = E[(X - E(X))^2] = \sum_{i} (x_i - E(X))^2 \cdot p_i$$

**简便公式**（极常用）：

$$\boxed{\;D(X) = E(X^2) - [E(X)]^2\;}$$

其中 $E(X^2) = \sum_i x_i^2 p_i$。这个简便公式比"逐项平方差"快得多，是计算方差的**首选**。

**几种常见分布的方差**：

| 分布 | 方差 |
|------|------|
| 两点分布 $P(X=1) = p$ | $D(X) = p(1-p)$ |
| 二项分布 $B(n, p)$ | $D(X) = np(1-p)$ |
| 正态分布 $N(\mu, \sigma^2)$ | $D(X) = \sigma^2$ |

**标准差**：$\sigma(X) = \sqrt{D(X)}$，与 $X$ 单位相同，便于实际比较。

### 3.3 线性变换的性质（核心！）

设 $a, b$ 是常数：

$$\boxed{\;E(aX + b) = aE(X) + b,\qquad D(aX + b) = a^2 D(X)\;}$$

**口诀**：
- $E$ 线性、$b$ 平移、$a$ 缩放
- $D$ 对 $b$"免疫"（平移不改变分散度）、对 $a$ 要"平方"

### 3.4 独立性的性质（重要！）

若 $X, Y$ 独立（即 $P(X = x_i, Y = y_j) = P(X = x_i) P(Y = y_j)$），则：

$$E(XY) = E(X) E(Y)$$

$$D(X + Y) = D(X) + D(Y)$$

$$D(X - Y) = D(X) + D(Y) \quad (\text{注意是 + 而非 -})$$

**警告**：上述对 $D$ 的可加性**仅在独立时成立**！期望的线性性 $E(X + Y) = E(X) + E(Y)$ 则**总成立**（不要求独立）。

### 3.5 高阶用法：$E(X^2)$ 与方差的关系

$$E(X^2) = D(X) + [E(X)]^2$$

求"二阶矩"$E(X^2)$ 时常借助这个等式。

## 四、方法变形：常见解题场景

### 4.1 直接套公式（最易型）

已知分布类型（两点 / 二项 / 超几何 / 正态），直接代公式。

**例**：$X \sim B(10, 0.3)$。$E(X) = 10 \times 0.3 = 3$；$D(X) = 10 \times 0.3 \times 0.7 = 2.1$。

### 4.2 由分布列求期望方差（标准型）

题目给一张分布列，按定义求 $E(X), E(X^2), D(X)$。

**例**：

| $X$ | $1$ | $2$ | $3$ |
|-----|-----|-----|-----|
| $P$ | $0.2$ | $0.5$ | $0.3$ |

$E(X) = 1 \cdot 0.2 + 2 \cdot 0.5 + 3 \cdot 0.3 = 2.1$  
$E(X^2) = 1 \cdot 0.2 + 4 \cdot 0.5 + 9 \cdot 0.3 = 4.9$  
$D(X) = 4.9 - 2.1^2 = 4.9 - 4.41 = 0.49$

### 4.3 线性变换组合（高频考点）

题目给出 $E(X), D(X)$，问 $E(aX + b), D(aX + b)$。直接套上述线性公式。

**例**：$E(X) = 5, D(X) = 4$。则 $E(2X - 3) = 2 \times 5 - 3 = 7$；$D(2X - 3) = 4 D(X) = 16$。

### 4.4 决策问题（综合应用）

实际问题中比较两种方案 / 两支股票 / 两种投资。准则：
- **$E$ 表示"长期平均收益"**——越大越好（理性赌徒选高 $E$）
- **$D$ 表示"风险"**——越大波动越大（保守者选低 $D$）

如：方案甲 $E = 50, D = 100$；方案乙 $E = 45, D = 16$。
- 看期望：甲赚得多
- 看方差：乙更稳定
- 综合判断：取决于风险偏好

### 4.5 利用 $E(X^2) = D(X) + [E(X)]^2$ 间接求二阶矩

求 $E(X^2)$ 而不知道分布列时：先求 $E(X), D(X)$，再用上式。

**例**：$X \sim B(4, 0.5)$。$E(X) = 2$，$D(X) = 1$，故 $E(X^2) = 1 + 2^2 = 5$。

## 五、思考路标（条件反射训练）

下面每条都要反复内化，遇到对应场景立刻触发：

1. **见到"二项 $B(n, p)$"** → 立刻写 $E(X) = np$，$D(X) = np(1-p)$。

2. **见到"超几何 $(N, M, n)$"** → 立刻写 $E(X) = n \cdot \dfrac{M}{N}$（方差公式高考一般不要求）。

3. **见到"两点分布"** → $E(X) = p$，$D(X) = p(1-p)$。

4. **见到"$Y = aX + b$"** → 立刻反应"期望线性、方差平方"：$E(Y) = aE(X) + b$，$D(Y) = a^2 D(X)$。

5. **见到"$D(X + Y)$"** → 先问"独立吗？"独立才能写 $D(X) + D(Y)$；不独立要回头看条件或用分布列硬算。

6. **见到"$E(X^2)$"或"$X^2$ 的期望"** → 用简便公式 $E(X^2) = D(X) + [E(X)]^2$，避免重新算 $\sum x_i^2 p_i$。

7. **见到"哪种方案更好"的决策题** → 同时算 $E$ 与 $D$：高 $E$ 高 $D$ 是"高风险高回报"；低 $E$ 低 $D$ 是"稳健保守"。**先看 $E$，再用 $D$ 区分平局**。

8. **求方差的标准流程** → ① 算 $E(X)$；② 算 $E(X^2)$；③ $D(X) = E(X^2) - [E(X)]^2$。比"逐项平方差"快得多。

9. **常数的期望与方差** → $E(c) = c$，$D(c) = 0$（常数没有"分散度"）。

10. **见"已知 $E(X) = ?, D(X) = ?$，求 $a, b$ 使……"** → 这类反求题用 $E, D$ 联立两个方程。

## 六、应用例题

### 例 1：从分布列求期望方差与线性变换

**题目**：随机变量 $X$ 的分布列如下：

| $X$ | $-1$ | $0$ | $1$ | $2$ |
|-----|------|-----|-----|-----|
| $P$ | $0.2$ | $0.3$ | $0.4$ | $0.1$ |

**(1)** 求 $E(X)$ 与 $D(X)$。

**(2)** 设 $Y = 5X - 2$，求 $E(Y)$ 与 $D(Y)$。

**【解答】**

**(1)**

$$E(X) = (-1) \cdot 0.2 + 0 \cdot 0.3 + 1 \cdot 0.4 + 2 \cdot 0.1 = -0.2 + 0 + 0.4 + 0.2 = 0.4$$

$$E(X^2) = 1 \cdot 0.2 + 0 \cdot 0.3 + 1 \cdot 0.4 + 4 \cdot 0.1 = 0.2 + 0 + 0.4 + 0.4 = 1.0$$

$$D(X) = E(X^2) - [E(X)]^2 = 1.0 - 0.4^2 = 1.0 - 0.16 = 0.84$$

**(2)** 由线性变换性质：

$$E(Y) = E(5X - 2) = 5 E(X) - 2 = 5 \times 0.4 - 2 = 0$$

$$D(Y) = D(5X - 2) = 5^2 D(X) = 25 \times 0.84 = 21$$

> 解题要点：(1) 用简便公式 $D(X) = E(X^2) - [E(X)]^2$；(2) 牢记 $E$ 线性、$D$ 系数平方且常数项消失。

### 例 2：二项分布与线性变换

**题目**：某射手命中目标的概率为 $p = 0.8$，独立射击 $10$ 次，每命中 $1$ 次奖励 $20$ 元，未命中扣 $5$ 元。设奖金为 $Y$ 元。

**(1)** 设命中次数为 $X$，写出 $X$ 的分布、$E(X)$、$D(X)$。

**(2)** 用 $X$ 表示 $Y$，求 $E(Y)$ 与 $D(Y)$。

**【解答】**

**(1)** $X \sim B(10, 0.8)$。

$$E(X) = np = 10 \times 0.8 = 8$$

$$D(X) = np(1-p) = 10 \times 0.8 \times 0.2 = 1.6$$

**(2)** 命中 $X$ 次，奖励 $20X$；未命中 $10 - X$ 次，扣 $5(10 - X)$。故：

$$Y = 20X - 5(10 - X) = 20X - 50 + 5X = 25X - 50$$

由线性变换性质：

$$E(Y) = 25 E(X) - 50 = 25 \times 8 - 50 = 150 \text{ 元}$$

$$D(Y) = 25^2 D(X) = 625 \times 1.6 = 1000$$

> 解题要点：先把实际场景中的"奖金"表达为命中次数 $X$ 的线性函数 $Y = aX + b$，再调用线性变换公式。"$Y = 25X - 50$"是关键中间步骤。

### 例 3：决策问题——比较两种方案

**题目**：某投资者面临两种方案：

- **方案 A**：年化回报率 $X_A$ 的分布列为

| $X_A$ | $0\%$ | $10\%$ | $20\%$ |
|-------|-------|--------|--------|
| $P$ | $0.2$ | $0.6$ | $0.2$ |

- **方案 B**：年化回报率 $X_B$ 的分布列为

| $X_B$ | $-10\%$ | $10\%$ | $30\%$ |
|-------|---------|--------|--------|
| $P$ | $0.3$ | $0.4$ | $0.3$ |

哪种方案"平均收益"更高？哪种"风险"更大？

**【解答】**

**计算期望**（"平均收益"）：

$$E(X_A) = 0 \cdot 0.2 + 0.1 \cdot 0.6 + 0.2 \cdot 0.2 = 0 + 0.06 + 0.04 = 0.10 = 10\%$$

$$E(X_B) = (-0.1) \cdot 0.3 + 0.1 \cdot 0.4 + 0.3 \cdot 0.3 = -0.03 + 0.04 + 0.09 = 0.10 = 10\%$$

期望相等：两个方案的"长期平均回报率"都是 $10\%$。

**计算方差**（"风险"，越大波动越剧烈）：

$$E(X_A^2) = 0 \cdot 0.2 + 0.01 \cdot 0.6 + 0.04 \cdot 0.2 = 0.006 + 0.008 = 0.014$$

$$D(X_A) = 0.014 - 0.10^2 = 0.014 - 0.01 = 0.004$$

$$E(X_B^2) = 0.01 \cdot 0.3 + 0.01 \cdot 0.4 + 0.09 \cdot 0.3 = 0.003 + 0.004 + 0.027 = 0.034$$

$$D(X_B) = 0.034 - 0.10^2 = 0.034 - 0.01 = 0.024$$

**结论**：
- 期望相同：$E(X_A) = E(X_B) = 10\%$，两方案长期收益一样。
- 方差：$D(X_B) = 0.024 > D(X_A) = 0.004$（方案 B 的方差是 A 的 $6$ 倍）。
- 方案 B 风险大得多——可能赚 $30\%$，也可能亏 $10\%$；方案 A 较稳定。

**建议**：保守投资者选 A；风险偏好者可考虑 B。

> 解题要点：决策题先看 $E$（谁的"期望收益"更高），$E$ 相同或相近时再看 $D$（谁更稳定）。本题 $E$ 相等，决策完全由 $D$ 决定。

## 七、思路自测题

**自测 1**　已知离散型随机变量 $X$ 的分布列：

| $X$ | $0$ | $1$ | $2$ | $3$ |
|-----|-----|-----|-----|-----|
| $P$ | $0.1$ | $0.4$ | $0.3$ | $0.2$ |

求 $E(X)$ 和 $D(X)$。

> 💡 提示：$E(X) = 0 \cdot 0.1 + 1 \cdot 0.4 + 2 \cdot 0.3 + 3 \cdot 0.2 = 0.4 + 0.6 + 0.6 = 1.6$；$E(X^2) = 0 + 0.4 + 1.2 + 1.8 = 3.4$；$D(X) = 3.4 - 1.6^2 = 3.4 - 2.56 = 0.84$。

**自测 2**　设 $X \sim B(20, 0.3)$。求 $E(2X + 5)$ 和 $D(3X - 7)$。

> 💡 提示：$E(X) = 6$，$D(X) = 4.2$。$E(2X + 5) = 2 \times 6 + 5 = 17$；$D(3X - 7) = 9 D(X) = 37.8$。

**自测 3**　已知 $E(X) = 3$，$D(X) = 4$。求 $E(X^2)$ 和 $E(2X^2 - 1)$。

> 💡 提示：$E(X^2) = D(X) + [E(X)]^2 = 4 + 9 = 13$。$E(2X^2 - 1) = 2 E(X^2) - 1 = 26 - 1 = 25$（注意：$E$ 是线性，但 $X^2$ 不是简单的 $X$ 的线性，要先求 $E(X^2)$ 再线性）。

**自测 4**　设独立随机变量 $X, Y$，$E(X) = 2, D(X) = 3, E(Y) = -1, D(Y) = 4$。求 $E(X - 2Y)$ 和 $D(X - 2Y)$。

> 💡 提示：$E(X - 2Y) = E(X) - 2 E(Y) = 2 - 2 \times (-1) = 4$（期望线性性，无需独立）。$D(X - 2Y) = D(X) + 4 D(Y) = 3 + 16 = 19$（独立时 $D(X + Y) = D(X) + D(Y)$；$-2$ 的系数平方后是 $4$）。

**自测 5**　甲、乙两人同时进入一项考试，各题分数 $X_甲, X_乙$ 的分布如下：

| $X_甲$ | $80$ | $90$ | $100$ |
|--------|------|------|-------|
| $P$ | $0.3$ | $0.4$ | $0.3$ |

| $X_乙$ | $70$ | $90$ | $110$ |
|--------|------|------|-------|
| $P$ | $0.2$ | $0.6$ | $0.2$ |

若以"平均得分高 / 平均得分相等时分数稳定者"为评判标准，谁应优先入选？

> 💡 提示：$E(X_甲) = 80 \cdot 0.3 + 90 \cdot 0.4 + 100 \cdot 0.3 = 24 + 36 + 30 = 90$；$E(X_乙) = 70 \cdot 0.2 + 90 \cdot 0.6 + 110 \cdot 0.2 = 14 + 54 + 22 = 90$。两人期望同为 $90$。再看方差：$E(X_甲^2) = 6400 \cdot 0.3 + 8100 \cdot 0.4 + 10000 \cdot 0.3 = 1920 + 3240 + 3000 = 8160$，$D(X_甲) = 8160 - 8100 = 60$；$E(X_乙^2) = 4900 \cdot 0.2 + 8100 \cdot 0.6 + 12100 \cdot 0.2 = 980 + 4860 + 2420 = 8260$，$D(X_乙) = 8260 - 8100 = 160$。$D(X_甲) < D(X_乙)$，甲更稳定，**甲优先入选**。
