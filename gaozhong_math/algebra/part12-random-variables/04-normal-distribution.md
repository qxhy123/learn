# 正态分布

> **一例速记**：  
> **定义**：$X \sim N(\mu, \sigma^2)$ 表示 $X$ 服从均值 $\mu$、标准差 $\sigma$ 的正态分布。  
> **密度函数**：$f(x) = \dfrac{1}{\sigma\sqrt{2\pi}}\, e^{-\frac{(x - \mu)^2}{2\sigma^2}}$，钟形曲线，对称轴 $x = \mu$。  
> **$3\sigma$ 法则**：$P(|X - \mu| < \sigma) \approx 0.6826$；$P(|X - \mu| < 2\sigma) \approx 0.9544$；$P(|X - \mu| < 3\sigma) \approx 0.9974$。  
> **标准正态**：$N(0, 1)$（$\mu = 0, \sigma = 1$）。  
> **对称性**：$P(X > \mu + a) = P(X < \mu - a)$（关于 $\mu$ 镜像）。

---

## 一、从离散到连续：密度函数登场

之前讲的离散型随机变量，取值是孤立点 $\{x_1, x_2, \ldots\}$，每个点都有概率 $P(X = x_i)$。

但很多实际变量取值是**连续的**：
- 学生身高（取值充满 $[140, 200]$ cm 等区间）
- 商品质量、零件长度
- 测量误差

对连续变量，"恰好取某个具体值"的概率是 $0$（如恰好身高 $172.000\ldots$ cm 的概率为 $0$），不能用 $P(X = x)$ 描述。要改用**密度函数** $f(x)$，让概率以"区间"为单位呈现：

$$P(a < X < b) = \int_a^b f(x)\, dx \quad (\text{曲线下面积})$$

高中阶段不要求积分计算，只需理解：**密度曲线下、$x$ 轴上、给定区间内的面积 = 该区间的概率**。

**密度函数的两条性质**（类比分布列）：
- $f(x) \geq 0$（非负）
- 曲线下总面积 $= \int_{-\infty}^{+\infty} f(x)\, dx = 1$（归一）

---

## 二、正态分布的定义与图象

### 2.1 定义

若连续型随机变量 $X$ 的密度函数为：

$$f(x) = \frac{1}{\sigma\sqrt{2\pi}}\, \exp\!\left[-\frac{(x - \mu)^2}{2\sigma^2}\right]$$

其中 $\mu \in \mathbb{R}$，$\sigma > 0$ 是常数，则称 $X$ 服从**正态分布**，记作：

$$X \sim N(\mu, \sigma^2)$$

参数解读：
- $\mu$：**均值**（也即期望 $E(X) = \mu$），决定曲线"中心位置"
- $\sigma$：**标准差**（$\sigma^2$ 是方差 $D(X) = \sigma^2$），决定曲线"胖瘦"——$\sigma$ 越小越尖

### 2.2 钟形曲线的性质

1. **关于 $x = \mu$ 对称**：$f(\mu + a) = f(\mu - a)$（左右镜像）。
2. **在 $x = \mu$ 处取最大值** $f(\mu) = \dfrac{1}{\sigma\sqrt{2\pi}}$。
3. **$\sigma$ 越小，曲线越尖**——数据集中在 $\mu$ 附近；$\sigma$ 越大，曲线越平 ——数据分散。
4. **以 $x$ 轴为渐近线**：当 $|x - \mu| \to \infty$ 时，$f(x) \to 0$，但永远不为 $0$。
5. **拐点在 $x = \mu \pm \sigma$**：在 $\mu - \sigma$ 和 $\mu + \sigma$ 处曲线"由凸转凹"。

### 2.3 几何示意（语言描述代图）

想象一座对称的"钟形山"：
- 顶峰在 $x = \mu$
- 两侧对称下降
- "山脚"分别越过 $\mu - \sigma$、$\mu + \sigma$、$\mu - 2\sigma$、$\mu + 2\sigma$ 等关键位置
- 山的"宽窄"由 $\sigma$ 决定

## 三、标准正态与一般正态的关系

### 3.1 标准正态分布

参数取 $\mu = 0, \sigma = 1$ 的情形称为**标准正态分布**，记 $Z \sim N(0, 1)$。密度函数简化为：

$$\varphi(z) = \frac{1}{\sqrt{2\pi}}\, e^{-z^2 / 2}$$

它关于 $z = 0$ 对称，最大值在 $z = 0$ 处为 $\dfrac{1}{\sqrt{2\pi}} \approx 0.399$。

### 3.2 标准化变换

任何 $X \sim N(\mu, \sigma^2)$ 都可以通过**标准化**变成 $N(0, 1)$：

$$Z = \dfrac{X - \mu}{\sigma} \sim N(0, 1)$$

**含义**：把 $X$ 减去均值（中心移到 $0$），再除以标准差（单位变为"$\sigma$"），就得到标准正态变量。

虽然标准化在大学概率课更深入，高中阶段只需知道这种变换的**存在性**——它让任何正态分布的概率都可以查"标准正态表"。

## 四、$3\sigma$ 法则（高频考点）

正态分布有三个**必记**的概率值：

$$\boxed{
\begin{aligned}
P(\mu - \sigma < X < \mu + \sigma) &\approx 0.6826 \\
P(\mu - 2\sigma < X < \mu + 2\sigma) &\approx 0.9544 \\
P(\mu - 3\sigma < X < \mu + 3\sigma) &\approx 0.9974
\end{aligned}
}$$

**含义**：
- 约 $68\%$ 的 $X$ 落在 $\mu$ 周围 $1\sigma$ 范围内
- 约 $95\%$ 落在 $2\sigma$ 范围内
- 约 $99.7\%$ 落在 $3\sigma$ 范围内（"几乎全部"）

### 4.1 区间外概率的转化

考试常考"区间外"概率，要用 $1$ 减去"区间内"：

$$P(|X - \mu| > \sigma) = 1 - 0.6826 = 0.3174$$

$$P(|X - \mu| > 2\sigma) = 1 - 0.9544 = 0.0456$$

$$P(|X - \mu| > 3\sigma) = 1 - 0.9974 = 0.0026$$

由对称性，区间外的概率再均分给左右两侧：

$$P(X > \mu + 2\sigma) = \tfrac{0.0456}{2} = 0.0228$$

$$P(X < \mu - 3\sigma) = \tfrac{0.0026}{2} = 0.0013$$

### 4.2 对称性应用

正态分布关于 $x = \mu$ 对称，故：

$$P(X > \mu + a) = P(X < \mu - a) \quad (\text{镜像})$$

$$P(X > \mu) = P(X < \mu) = 0.5 \quad (\mu \text{ 是中位数})$$

## 五、应用例题

### 例 1：用 $3\sigma$ 法则估算

**题目**：某地区高三学生数学成绩 $X \sim N(85, 25)$（满分 $150$），即 $\mu = 85, \sigma^2 = 25, \sigma = 5$。

**(1)** 估计成绩在 $80$ 至 $90$ 分之间的考生比例。

**(2)** 估计成绩在 $75$ 至 $95$ 分之间的考生比例。

**(3)** 若全区有 $10000$ 名考生，约有多少人成绩在 $70$ 至 $100$ 分之间？

**【解答】**

注意 $\mu = 85$，$\sigma = 5$。

**(1)** $80 = \mu - \sigma$，$90 = \mu + \sigma$。

$$P(80 < X < 90) = P(\mu - \sigma < X < \mu + \sigma) \approx 0.6826$$

约占 $68.26\%$。

**(2)** $75 = \mu - 2\sigma$，$95 = \mu + 2\sigma$。

$$P(75 < X < 95) = P(\mu - 2\sigma < X < \mu + 2\sigma) \approx 0.9544$$

约占 $95.44\%$。

**(3)** $70 = \mu - 3\sigma$，$100 = \mu + 3\sigma$。

$$P(70 < X < 100) \approx 0.9974$$

$10000 \times 0.9974 \approx 9974$ 人。

> 解题要点：先把所给区间的端点用 $\mu \pm k\sigma$ 表示出来，再对照 $3\sigma$ 法则直接读概率。

---

### 例 2：用对称性求"单侧"概率

**题目**：$X \sim N(60, 100)$（即 $\mu = 60, \sigma = 10$）。求：

**(1)** $P(X > 80)$　**(2)** $P(40 < X < 70)$　**(3)** $P(X < 50)$

**【解答】**

注意 $\mu = 60$，$\sigma = 10$。

**(1)** $80 = \mu + 2\sigma$。由 $3\sigma$ 法则及对称性：

$$P(|X - \mu| > 2\sigma) = 1 - 0.9544 = 0.0456 \;\Rightarrow\; P(X > \mu + 2\sigma) = \tfrac{0.0456}{2} = 0.0228$$

$$P(X > 80) \approx 0.0228$$

**(2)** $40 = \mu - 2\sigma$，$70 = \mu + \sigma$。

$$P(40 < X < 70) = P(40 < X < 60) + P(60 < X < 70)$$

由对称性，$P(40 < X < 60) = P(60 < X < 80) = \tfrac{1}{2} \cdot 0.9544 = 0.4772$。

$P(60 < X < 70) = \tfrac{1}{2} \cdot 0.6826 = 0.3413$。

故 $P(40 < X < 70) = 0.4772 + 0.3413 = 0.8185$。

**(3)** $50 = \mu - \sigma$。由对称性：

$$P(X < \mu - \sigma) = P(X > \mu + \sigma) = \tfrac{1 - 0.6826}{2} = 0.1587$$

$$P(X < 50) \approx 0.1587$$

> 解题要点：把每个端点写成 $\mu \pm k\sigma$，再借助 $3\sigma$ 法则和对称性"分块计算"。要熟记"对称两侧各占 $0.5$"和"区间内 / 外的概率互补"。

### 例 3：实际身高分布

**题目**：某校高三男生身高 $X$ 服从正态分布 $N(170, 36)$（cm，$\mu = 170, \sigma = 6$）。

**(1)** 估计身高在 $164$ cm 到 $176$ cm 之间的男生比例。

**(2)** 若全校共有 $1000$ 名高三男生，估计身高超过 $182$ cm 的有多少人？

**【解答】**

**(1)** $164 = 170 - 6 = \mu - \sigma$，$176 = 170 + 6 = \mu + \sigma$。

$$P(164 < X < 176) \approx 0.6826 \;\Rightarrow\; 68.26\%$$

**(2)** $182 = 170 + 12 = \mu + 2\sigma$。

$$P(X > 182) = \tfrac{1 - 0.9544}{2} = 0.0228$$

人数：$1000 \times 0.0228 \approx 23$ 人。

> 解题要点：实际应用题的关键是把"具体数值"转化为"$\mu \pm k\sigma$"形式——只要识别出端点与 $\mu, \sigma$ 的关系，就可以套用 $3\sigma$ 法则。

## 六、易错点与陷阱

**易错 1：$\sigma$ 是标准差，不是方差**

$X \sim N(\mu, \sigma^2)$ 中，**第二个参数是 $\sigma^2$（方差），$\sigma$ 是 $\sigma^2$ 开根号**。如 $N(60, 100)$ 中方差是 $100$，标准差 $\sigma = 10$（不是 $100$）。$3\sigma$ 法则用的是 $\sigma$ 不是 $\sigma^2$！

**易错 2：把 $3\sigma$ 法则的概率值搞混**

$0.6826, 0.9544, 0.9974$——这三个数必须记牢，对应 $\sigma, 2\sigma, 3\sigma$ 区间内的概率。

**易错 3：忘记区间外要除以 $2$**

$P(X > \mu + 2\sigma) = \tfrac{1 - 0.9544}{2}$，要除以 $2$！因为"区间外"包含左右两侧，由对称性各占一半。

**易错 4：忽略 $\mu$ 是中位数**

$P(X > \mu) = P(X < \mu) = 0.5$ 是隐含信息，常用于将复杂区间拆分为"$\mu$ 左侧"和"$\mu$ 右侧"两部分。

**易错 5：把"恰好等于"算成正概率**

对连续型变量，$P(X = a) = 0$（曲线下"线段"面积为 $0$）。所以 $P(X \leq a) = P(X < a)$、$P(X \geq a) = P(X > a)$——区间端点是否闭合不影响概率。

## 七、思路自测题

**自测 1**　$X \sim N(50, 4)$，即 $\mu = 50, \sigma = 2$。求 $P(48 < X < 52)$。

> 💡 提示：$48 = \mu - \sigma$，$52 = \mu + \sigma$，故 $P(48 < X < 52) \approx 0.6826$。

**自测 2**　$X \sim N(100, 25)$，$\mu = 100, \sigma = 5$。已知 $P(X > 110) \approx 0.0228$，问 $P(90 < X < 110)$ 是多少？

> 💡 提示：$110 = \mu + 2\sigma$，$90 = \mu - 2\sigma$，$P(90 < X < 110) \approx 0.9544$；可验证 $0.9544 + 2 \times 0.0228 \approx 1$ ✓。

**自测 3**　$X \sim N(75, 36)$。求 $P(X < 63)$。

> 💡 提示：$\sigma = 6$，$63 = 75 - 12 = \mu - 2\sigma$。由对称性 $P(X < \mu - 2\sigma) = \tfrac{1 - 0.9544}{2} \approx 0.0228$。

**自测 4**　某品牌灯泡寿命 $X$（小时）服从 $N(2000, 10000)$，即 $\mu = 2000, \sigma = 100$。从生产线随机抽 $1000$ 个灯泡，估计寿命在 $1900$ 至 $2200$ 小时之间的有多少个。

> 💡 提示：$1900 = \mu - \sigma$，$2200 = \mu + 2\sigma$。$P(1900 < X < 2200) = P(\mu - \sigma < X < \mu) + P(\mu < X < \mu + 2\sigma)$。利用对称性：$P(\mu - \sigma < X < \mu) = \tfrac{0.6826}{2} = 0.3413$；$P(\mu < X < \mu + 2\sigma) = \tfrac{0.9544}{2} = 0.4772$。和 $= 0.8185$。约 $1000 \times 0.8185 \approx 819$ 个。
