# 变量的相关性与线性回归

> **一例速记**：  
> **相关系数** $r = \dfrac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum (x_i - \bar{x})^2 \cdot \sum (y_i - \bar{y})^2}} \in [-1, 1]$；$|r|$ 越接近 $1$ 相关性越强。  
> **回归方程** $\hat{y} = \hat{b} x + \hat{a}$，其中 $\hat{b} = \dfrac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sum (x_i - \bar{x})^2}$，$\hat{a} = \bar{y} - \hat{b}\bar{x}$。  
> **回归直线必过样本中心 $(\bar{x}, \bar{y})$**。  
> **决定系数** $R^2 = 1 - \dfrac{\sum (y_i - \hat{y}_i)^2}{\sum (y_i - \bar{y})^2}$；$R^2$ 越接近 $1$ 拟合越好。

---

## 一、变量间的相关关系

### 函数关系 vs 相关关系

**函数关系**：两变量满足精确的数学公式（如 $S = \pi r^2$），一个变量唯一确定另一个。

**相关关系**：两变量之间存在某种联系，但不能用确定的函数描述。例如身高与体重——有正相关趋势，但同身高的人体重各异。

**判定相关关系**——最直观的方法是绘制**散点图**：把样本对 $(x_i, y_i)$ 画在直角坐标系上，观察散点的分布形态。

### 散点图的形态

| 散点形态 | 相关性 |
|---------|--------|
| 散点近似沿一条向右上的直线分布 | **正相关**（$r > 0$） |
| 散点近似沿一条向右下的直线分布 | **负相关**（$r < 0$） |
| 散点近似完全在一条直线上 | **完全相关**（$|r| = 1$，即函数关系） |
| 散点分散、无明显趋势 | **不相关**（$r \approx 0$） |
| 散点呈曲线分布 | 非线性相关（线性 $r$ 失效，需非线性模型） |

## 二、相关系数

### 定义

设样本为 $(x_1, y_1), (x_2, y_2), \dots, (x_n, y_n)$，记 $\bar{x} = \dfrac{1}{n}\sum x_i$，$\bar{y} = \dfrac{1}{n}\sum y_i$。**线性相关系数**（Pearson 相关系数）：

$$\boxed{\,r = \dfrac{\sum_{i=1}^{n} (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum_{i=1}^{n} (x_i - \bar{x})^2 \cdot \sum_{i=1}^{n} (y_i - \bar{y})^2}}\,}$$

### 性质

1. **取值范围**：$r \in [-1, 1]$（柯西-施瓦茨不等式保证）。
2. **符号**：$r > 0$ 正相关；$r < 0$ 负相关；$r = 0$ 线性不相关。
3. **强度**：
   - $|r| \in [0.75, 1]$——强相关；
   - $|r| \in [0.30, 0.75)$——中等相关；
   - $|r| \in [0, 0.30)$——弱相关；
   - $|r| = 1$ 当且仅当所有样本点严格在一条直线上（**完全相关**）。
4. **对称性**：$r(x, y) = r(y, x)$，即不分自变量、因变量。

### 简化计算式

将 $(x_i - \bar{x})(y_i - \bar{y})$ 展开整理可得：

$$\sum (x_i - \bar{x})(y_i - \bar{y}) = \sum x_i y_i - n \bar{x}\bar{y}.$$

$$\sum (x_i - \bar{x})^2 = \sum x_i^2 - n \bar{x}^2.$$

这两式在手工计算时极为实用。

## 三、最小二乘法与线性回归方程

### 问题动机

若散点图显示 $y$ 大致随 $x$ 线性变化，我们希望用一条直线 $\hat{y} = b x + a$ 来"拟合"数据，使得预测值 $\hat{y}_i = b x_i + a$ 与实际值 $y_i$ 的总误差最小。

### 最小二乘法

定义残差 $e_i = y_i - \hat{y}_i = y_i - (b x_i + a)$，目标：最小化残差平方和

$$Q(a, b) = \sum_{i=1}^{n} (y_i - b x_i - a)^2.$$

对 $a, b$ 分别求偏导并令其为 $0$（高中阶段直接记结论）：

$$\boxed{\,\hat{b} = \dfrac{\sum_{i=1}^{n} (x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^{n} (x_i - \bar{x})^2},\quad \hat{a} = \bar{y} - \hat{b}\bar{x}.\,}$$

此时直线 $\hat{y} = \hat{b} x + \hat{a}$ 称为 $y$ 关于 $x$ 的**线性回归方程**。

### 关键性质

**回归直线必过样本中心 $(\bar{x}, \bar{y})$**：因为 $\hat{a} = \bar{y} - \hat{b}\bar{x}$，代入有 $\hat{y}(\bar{x}) = \hat{b}\bar{x} + \bar{y} - \hat{b}\bar{x} = \bar{y}$。

**斜率与相关系数的关系**：

$$\hat{b} = r \cdot \dfrac{s_y}{s_x},$$

其中 $s_x, s_y$ 分别是 $x, y$ 的标准差。因此 $\hat{b}$ 与 $r$ 同号。

---

## 四、残差与决定系数 $R^2$

### 残差

预测误差 $e_i = y_i - \hat{y}_i$ 称为第 $i$ 个**残差**。

**残差平方和**：$\text{RSS} = \sum e_i^2 = \sum (y_i - \hat{y}_i)^2$。  
**总变差**：$\text{TSS} = \sum (y_i - \bar{y})^2$。

### 决定系数

$$\boxed{\,R^2 = 1 - \dfrac{\sum_{i=1}^{n} (y_i - \hat{y}_i)^2}{\sum_{i=1}^{n} (y_i - \bar{y})^2} = 1 - \dfrac{\text{RSS}}{\text{TSS}}.\,}$$

**含义**：$R^2$ 表示 $y$ 的总变差中能被回归模型解释的比例。

- $R^2 \in [0, 1]$；
- $R^2 \to 1$：模型几乎解释全部变差，**拟合好**；
- $R^2 \to 0$：模型几乎没解释，**拟合差**；
- 在线性回归（仅一个自变量）下，$R^2 = r^2$。

## 五、典型应用例题

### 例 1：计算回归方程并预测

**题目**：某商店连续 $5$ 天的广告支出 $x$（千元）与销售额 $y$（万元）数据如下：

| $x$ | $1$ | $2$ | $3$ | $4$ | $5$ |
|---|---|---|---|---|---|
| $y$ | $3$ | $4$ | $5$ | $6$ | $7$ |

求 $y$ 关于 $x$ 的线性回归方程，并预测 $x = 8$ 时的销售额。

**【思路】** 先算 $\bar{x}, \bar{y}$，再用公式 $\hat{b}, \hat{a}$。

$\bar{x} = \dfrac{1+2+3+4+5}{5} = 3$，$\bar{y} = \dfrac{3+4+5+6+7}{5} = 5$。

$\sum (x_i - \bar{x})(y_i - \bar{y}) = (-2)(-2) + (-1)(-1) + 0 + 1 \cdot 1 + 2 \cdot 2 = 4 + 1 + 0 + 1 + 4 = 10$。

$\sum (x_i - \bar{x})^2 = 4 + 1 + 0 + 1 + 4 = 10$。

$\hat{b} = \dfrac{10}{10} = 1$，$\hat{a} = 5 - 1 \times 3 = 2$。

故回归方程：$\hat{y} = x + 2$。

**预测** $x = 8$：$\hat{y} = 8 + 2 = 10$（万元）。

**答**：$\hat{y} = x + 2$；预测销售额为 $10$ 万元。

### 例 2：判断相关性强度

**题目**：测得 $4$ 个样本点 $(1, 2), (2, 4), (3, 5), (4, 9)$，求 $r$，判断相关性。

**【思路】** 算 $\bar{x}, \bar{y}$ 与三项之和。

$\bar{x} = \dfrac{1+2+3+4}{4} = 2.5$，$\bar{y} = \dfrac{2+4+5+9}{4} = 5$。

$\sum (x_i - \bar{x})(y_i - \bar{y})$：
$(1 - 2.5)(2 - 5) + (2 - 2.5)(4 - 5) + (3 - 2.5)(5 - 5) + (4 - 2.5)(9 - 5)$
$= (-1.5)(-3) + (-0.5)(-1) + 0 + 1.5 \times 4$
$= 4.5 + 0.5 + 0 + 6 = 11$.

$\sum (x_i - \bar{x})^2 = 2.25 + 0.25 + 0.25 + 2.25 = 5$.

$\sum (y_i - \bar{y})^2 = 9 + 1 + 0 + 16 = 26$.

$r = \dfrac{11}{\sqrt{5 \times 26}} = \dfrac{11}{\sqrt{130}} \approx \dfrac{11}{11.40} \approx 0.965$.

**结论**：$r \approx 0.965 \in (0.75, 1]$，强正相关。

**答**：$r \approx 0.965$，$x$ 与 $y$ 强正相关。

---

### 例 3：拟合优度比较

**题目**：用同一组数据 $(x_i, y_i), i = 1, \dots, 6$ 拟合两个模型：

- 模型 A：$\hat{y} = 1.2 x + 0.8$，残差平方和 $\text{RSS}_A = 1.5$；
- 模型 B：$\hat{y} = 1.0 x + 1.2$，残差平方和 $\text{RSS}_B = 4.0$。

总变差 $\text{TSS} = \sum (y_i - \bar{y})^2 = 25$。哪个模型拟合更好？

**【思路】** 用 $R^2 = 1 - \dfrac{\text{RSS}}{\text{TSS}}$ 比较。

$R^2_A = 1 - \dfrac{1.5}{25} = 1 - 0.06 = 0.94$.

$R^2_B = 1 - \dfrac{4.0}{25} = 1 - 0.16 = 0.84$.

**结论**：$R^2_A > R^2_B$，模型 A 解释了 $94\%$ 的变差，模型 B 解释了 $84\%$，模型 A 拟合更好。

**答**：模型 A 拟合更好（$R^2_A = 0.94 > R^2_B = 0.84$）。

## 六、易错点与陷阱

**易错 1：混淆相关与因果**

$r$ 大只表明两变量"同步变化"，**不等于**一个导致另一个。例如冰淇淋销量与溺水率都受夏季气温影响而相关，但冰淇淋不会导致溺水。

**易错 2：相关系数 $r$ 与回归斜率 $\hat{b}$ 不要混用**

$r$ 是无量纲的相关性指标（$\in [-1, 1]$）；$\hat{b}$ 是回归直线斜率（量纲为 $\dfrac{y\text{单位}}{x\text{单位}}$）。两者同号，但数值含义不同。

**易错 3：忽略"回归直线过样本中心"**

许多题目利用这一点节省计算：已知 $\bar{x}, \bar{y}, \hat{b}$，可直接得 $\hat{a} = \bar{y} - \hat{b}\bar{x}$；反之，已知方程 $\hat{y} = \hat{b}x + \hat{a}$ 与 $\bar{x}$，可立刻得 $\bar{y} = \hat{b}\bar{x} + \hat{a}$。

**易错 4：超出样本范围外推**

回归方程是在样本 $x$ 范围内拟合的，若 $x$ 远超出训练范围，预测可能严重失真。例题 1 中 $x = 8$ 超出原数据范围 $[1, 5]$，预测应注明"外推存在风险"。

**易错 5：$R^2$ 接近 $1$ 不等于关系一定是线性**

非线性关系（如二次曲线）若用直线强行拟合，可能仍得到不低的 $R^2$，但散点图会暴露出系统性偏差。**优先看散点图判断线性是否合适**，再看 $R^2$。

## 七、思路自测题

**自测 1**　已知线性回归方程 $\hat{y} = 2x - 1$，且 $\bar{x} = 3$，求 $\bar{y}$。

> 💡 提示：回归直线必过 $(\bar{x}, \bar{y})$，代入得 $\bar{y} = 2 \times 3 - 1 = 5$。

**自测 2**　$5$ 组数据 $(x_i, y_i)$ 满足 $\sum (x_i - \bar{x})(y_i - \bar{y}) = -8$，$\sum (x_i - \bar{x})^2 = 4$，$\bar{x} = 2$，$\bar{y} = 7$。求回归方程。

> 💡 提示：$\hat{b} = \dfrac{-8}{4} = -2$；$\hat{a} = 7 - (-2) \times 2 = 11$。回归方程：$\hat{y} = -2x + 11$。

**自测 3**　观测 $6$ 个样本点求得 $r = -0.85$。如何描述 $x$ 与 $y$ 的关系？

> 💡 提示：$r$ 为负 → 负相关；$|r| = 0.85 > 0.75$ → 强相关。结论：$x$ 与 $y$ 存在强的负相关关系，即 $x$ 增大时 $y$ 倾向减小。

**自测 4**　某回归模型 $\text{RSS} = 12$，$\text{TSS} = 60$。求 $R^2$，并解释。

> 💡 提示：$R^2 = 1 - \dfrac{12}{60} = 1 - 0.2 = 0.8$。该模型解释了 $y$ 总变差的 $80\%$，未解释的 $20\%$ 归因于随机误差或未纳入的变量。
