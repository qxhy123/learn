# 直线综合应用

> **一例速记**：  
> 含参直线 $ax + (1-a)y + 1 = 0$：令 $a = 0$、$a = 1$ 分别得两条特殊直线，其余情形提取公因子后合并。  
> 点 $P(x_0, y_0)$ 在直线 $l: Ax + By + C = 0$ 的哪一侧：代入 $Ax_0 + By_0 + C$ 看符号。  
> 点 $P$ 关于直线 $l$ 的对称点 $P'$：$l$ 是 $PP'$ 的垂直平分线，即 $PP'$ 中点在 $l$ 上且 $PP' \perp l$。

---

## 一、含参直线的讨论

### 1. 为什么要分类讨论

当直线方程中含参数 $a$（或 $m$、$k$ 等）时，直线的斜率、截距随 $a$ 变化，有时直线退化为竖线（$k$ 不存在），有时某种形式失效。必须针对使方程"形式改变"的参数临界值逐一讨论。

**常见触发讨论的情形**：
- 斜率公式中分母含 $a$，需讨论分母是否为 $0$
- 方程中 $y$ 的系数含 $a$，系数为 $0$ 时直线垂直 $y$ 轴
- 方程中 $x$ 的系数含 $a$，系数为 $0$ 时直线垂直 $x$ 轴

### 2. 含参一般式的完整讨论

**例型**：讨论直线 $l: ax + (1-a)y + 1 = 0$ 的方程，随 $a$ 的变化情况。

**分析**：$y$ 的系数为 $1-a$，当 $1-a = 0$ 即 $a = 1$ 时，$y$ 系数为 $0$，方程退化；$x$ 的系数为 $a$，当 $a = 0$ 时，$x$ 系数为 $0$，需单独检查。

**情形 1：$a = 0$**

代入得 $0 \cdot x + 1 \cdot y + 1 = 0$，即 $y = -1$。

这是一条**平行于 $x$ 轴**的水平线，斜率为 $0$，$y$ 轴截距为 $-1$。

**情形 2：$a = 1$**

代入得 $1 \cdot x + 0 \cdot y + 1 = 0$，即 $x = -1$。

这是一条**平行于 $y$ 轴**的竖线，斜率不存在，$x$ 轴截距为 $-1$。

**情形 3：$a \neq 0$ 且 $a \neq 1$**

$y$ 系数 $1-a \neq 0$，可以解出 $y$，化为斜截式：

$$y = -\frac{a}{1-a} x - \frac{1}{1-a} = \frac{a}{a-1} x + \frac{1}{a-1}$$

斜率 $k = \dfrac{a}{a-1}$，$y$ 轴截距 $b = \dfrac{1}{a-1}$。

**另一角度——过定点**：将方程改写为：

$$ax + (1-a)y + 1 = 0 \implies a(x - y) + (y + 1) = 0$$

此方程对所有 $a$ 均成立，当且仅当：

$$x - y = 0 \quad \text{且} \quad y + 1 = 0$$

解得 $y = -1$，$x = -1$，即**所有这族直线（对任意 $a$）均过定点 $(-1, -1)$**。

> 这是含参直线族的重要技巧：将方程整理为 $a \cdot f(x,y) + g(x,y) = 0$ 的形式，令 $f = 0$、$g = 0$ 联立，所得点即为族中所有直线共同经过的定点。

### 3. 含参讨论的规范步骤

1. 找出使各系数为零的参数临界值
2. 逐一代入临界值，写出对应直线方程并描述其几何形态
3. 讨论其余参数范围下的一般情形（通常化斜截式）
4. 若题目要求，额外讨论过定点或公共交点

## 二、直线与点的位置关系

### 1. 点是否在直线上

**结论**：点 $P(x_0, y_0)$ 在直线 $Ax + By + C = 0$ 上，当且仅当 $Ax_0 + By_0 + C = 0$。

验证方法：将点坐标直接代入方程左边，结果为 $0$ 则在线上，不为 $0$ 则不在线上。

### 2. 点在直线的哪一侧

**结论**：设直线 $l: Ax + By + C = 0$。对平面上不在 $l$ 上的两点 $P_1(x_1, y_1)$ 和 $P_2(x_2, y_2)$：

- 若 $(Ax_1 + By_1 + C)$ 与 $(Ax_2 + By_2 + C)$ **同号**，则 $P_1, P_2$ 在 $l$ 的**同侧**
- 若两者**异号**，则 $P_1, P_2$ 在 $l$ 的**两侧**

**实际操作**：只需将点坐标代入 $Ax + By + C$，看得到的值是正数还是负数。正值对应直线一侧，负值对应另一侧。

**例**：判断点 $A(1, 2)$ 和 $B(3, -1)$ 是否在直线 $l: 2x - y - 3 = 0$ 的同侧。

代入 $A$：$2(1) - 2 - 3 = -3 < 0$

代入 $B$：$2(3) - (-1) - 3 = 4 > 0$

两值异号，故 $A, B$ 在直线 $l$ 的**两侧**。

## 三、对称问题

### 1. 点关于点对称

**定义**：点 $P'$ 是点 $P$ 关于点 $A(a, b)$ 的对称点，意味着 $A$ 是线段 $PP'$ 的中点。

**公式**：设 $P(x_0, y_0)$，$A(a, b)$，则 $P'(x', y')$ 满足：

$$\frac{x_0 + x'}{2} = a, \quad \frac{y_0 + y'}{2} = b$$

解得：

$$x' = 2a - x_0, \quad y' = 2b - y_0$$

**例**：求点 $P(3, -1)$ 关于点 $A(1, 2)$ 的对称点。

$$x' = 2(1) - 3 = -1, \quad y' = 2(2) - (-1) = 5$$

故对称点 $P'(-1, 5)$。

### 2. 点关于直线对称

**条件**：点 $P'$ 是点 $P$ 关于直线 $l$ 的对称点，必须同时满足：

1. **$PP'$ 的中点在 $l$ 上**（中点条件）
2. **$PP' \perp l$**（垂直条件）

**求法步骤**：

设 $P(x_0, y_0)$，直线 $l: Ax + By + C = 0$（斜率 $k_l = -A/B$），设对称点 $P'(x', y')$。

**步骤 1（垂直条件）**：$PP'$ 的斜率与 $l$ 的斜率互为负倒数：

$$\frac{y' - y_0}{x' - x_0} = \frac{B}{A} \quad \text{（即 } k_{PP'} = \frac{B}{A}\text{，与 }k_l = -\frac{A}{B}\text{ 互为负倒数）}$$

**步骤 2（中点条件）**：中点 $M\!\left(\dfrac{x_0+x'}{2},\, \dfrac{y_0+y'}{2}\right)$ 在 $l$ 上：

$$A \cdot \frac{x_0 + x'}{2} + B \cdot \frac{y_0 + y'}{2} + C = 0$$

联立步骤 1、步骤 2 两个方程，解出 $x', y'$。

**公式（直接套用）**：

$$x' = x_0 - \frac{2A(Ax_0 + By_0 + C)}{A^2 + B^2}, \quad y' = y_0 - \frac{2B(Ax_0 + By_0 + C)}{A^2 + B^2}$$

### 3. 直线关于点对称

**方法**：直线 $l: Ax + By + C = 0$ 关于点 $Q(a, b)$ 的对称直线 $l'$，可将 $l$ 的方程中 $(x, y)$ 全部替换为 $(2a - x,\ 2b - y)$，展开化简即为 $l'$ 的方程。

**原理**：$l'$ 上的点 $(x, y)$ 关于 $Q$ 的对称点 $(2a-x, 2b-y)$ 必然在 $l$ 上，代入 $l$ 的方程，再整理即得 $l'$ 的方程。

**例**：求直线 $l: 3x - y + 2 = 0$ 关于点 $Q(1, 0)$ 的对称直线。

将 $x \to 2(1) - x = 2 - x$，$y \to 2(0) - y = -y$ 代入：

$$3(2 - x) - (-y) + 2 = 0 \implies 6 - 3x + y + 2 = 0 \implies 3x - y - 8 = 0$$

故对称直线 $l': 3x - y - 8 = 0$。

注意：$l$ 与 $l'$ 斜率相同（均为 $3$），这是正确的——关于点对称不改变直线方向。

### 4. 直线关于直线对称

**两直线 $l_1$ 关于 $l_0$ 对称**，求 $l_1$ 的对称直线 $l_2$，基本思路：

**方法一（两点法）**：在 $l_1$ 上取两个点 $P_1, P_2$，分别求它们关于 $l_0$ 的对称点 $P_1', P_2'$（用"点关于直线对称"方法），过 $P_1', P_2'$ 的直线即为 $l_2$。

**方法二（交点 + 一点法）**：若 $l_1$ 与 $l_0$ 相交于点 $T$，则 $T$ 也在 $l_2$ 上（交点关于自身对称仍为自身）。只需再在 $l_1$ 上取一点，求其关于 $l_0$ 的对称点，过该点与 $T$ 即可确定 $l_2$。

**注意**：若 $l_1 \parallel l_0$，则 $l_2$ 也平行于 $l_0$，且 $l_1$ 与 $l_2$ 关于 $l_0$ 等距（用两平行线距离公式计算）。

## 四、与函数、不等式的结合

### 1. 含参不等式恒成立 → 直线与函数图象位置

**基本思想**：不等式 $f(x, a) > 0$ 对所有 $x \in D$ 恒成立，等价于曲线（直线）$y = g(x, a)$ 在某一区域中不与某曲线相交或始终在其某侧。

**标准转化路径**：

1. 将不等式改写为 $a \cdot p(x) > q(x)$ 或 $a > h(x)$（对 $\forall x \in D$）的形式
2. 转化为"直线 $y = a$（水平线）在函数 $y = h(x)$ 图象上方"
3. 等价于 $a > \max_{x \in D} h(x)$

**含参直线的恒成立**：若不等式形如 $ax + by + c > 0$ 对某集合中所有参数均成立，可将其视为"直线族"始终不穿过某特定区域的条件。

### 2. 直线与曲线的位置关系

**直线 $l: y = kx + b$ 与抛物线 $y = x^2$ 的位置**：

联立 $kx + b = x^2$，即 $x^2 - kx - b = 0$，用判别式 $\Delta = k^2 + 4b$：

- $\Delta > 0$：两个交点（相交）
- $\Delta = 0$：恰好一个切点（相切）
- $\Delta < 0$：无交点（相离）

**一般方法**：将直线方程代入曲线方程，消去一个变量，得到关于另一变量的方程，根据该方程的实数解个数判断位置关系。

### 3. 斜率 k 表示"变化率"

直线斜率是两点连线的"斜率"，在与函数结合时，常被解释为：

$$k_{AB} = \frac{f(x_2) - f(x_1)}{x_2 - x_1}$$

这就是函数 $f$ 在区间 $[x_1, x_2]$ 上的**平均变化率**。利用这一解释，可将"斜率最大 / 最小"转化为"平均变化率极值"问题，常见于切线斜率、最优化等综合题。

## 五、典型应用例题

### 例 1：含参直线的完整讨论

**题目**：直线 $l$ 过点 $A(-1, 2)$，斜率为 $k$。若直线 $l$ 与直线 $m: 2x - y + 3 = 0$ 平行，求 $k$；若 $l$ 与 $m$ 垂直，求 $l$ 的方程。再讨论当 $k$ 取何值时，$l$ 与 $m$ 的交点在 $x$ 轴下方。

**【思路】** 平行条件：$k_l = k_m$；垂直条件：$k_l \cdot k_m = -1$；交点 $y$ 坐标需用联立方程解出，再对条件 $y < 0$ 解不等式。

**解**：

直线 $m$ 的斜率 $k_m = 2$。

**（1）$l \parallel m$**：$k = k_m = 2$。验证截距：$l: y - 2 = 2(x + 1) \Rightarrow y = 2x + 4$，截距 $b_l = 4 \neq 3 = b_m$（从 $m: y = 2x + 3$ 读出），平行确认。

**（2）$l \perp m$**：$k \cdot 2 = -1 \Rightarrow k = -\dfrac{1}{2}$。

$l$ 的方程：$y - 2 = -\dfrac{1}{2}(x + 1) \Rightarrow x + 2y - 3 = 0$。

**（3）交点在 $x$ 轴下方（$y < 0$）**：

$l$ 过 $A(-1, 2)$，方程为 $y - 2 = k(x + 1)$，即 $y = kx + k + 2$。

与 $m: y = 2x + 3$ 联立：

$$kx + k + 2 = 2x + 3 \implies (k-2)x = 1 - k$$

**情形 1**：$k = 2$（$l \parallel m$，无交点，此情形排除）。

**情形 2**：$k \neq 2$，解得 $x = \dfrac{1-k}{k-2}$，代入 $m$ 得：

$$y = 2 \cdot \frac{1-k}{k-2} + 3 = \frac{2(1-k) + 3(k-2)}{k-2} = \frac{k - 4}{k - 2}$$

要求 $y < 0$，即 $\dfrac{k-4}{k-2} < 0$，解得 $2 < k < 4$。

**答**：$l \parallel m$ 时 $k = 2$；$l \perp m$ 时方程为 $x + 2y - 3 = 0$；交点在 $x$ 轴下方时 $k \in (2, 4)$。

### 例 2：点关于直线的对称

**题目**：求点 $P(4, 3)$ 关于直线 $l: x - 2y + 1 = 0$ 的对称点 $P'$，并求直线 $PP'$ 的方程。

**【思路】** 设 $P'(x', y')$，利用中点在 $l$ 上、$PP' \perp l$ 两个条件联立求解。

**解**：

直线 $l$ 的斜率 $k_l = \dfrac{1}{2}$，故 $PP'$ 的斜率 $k_{PP'} = -2$（负倒数）。

**中点条件**：设 $M = \left(\dfrac{4+x'}{2},\, \dfrac{3+y'}{2}\right)$，$M$ 在 $l$ 上：

$$\frac{4+x'}{2} - 2 \cdot \frac{3+y'}{2} + 1 = 0 \implies (4+x') - 2(3+y') + 2 = 0 \implies x' - 2y' = 0 \quad \cdots (1)$$

**垂直条件**：$\dfrac{y' - 3}{x' - 4} = -2$，即 $y' - 3 = -2(x' - 4)$，整理得：

$$2x' + y' = 11 \quad \cdots (2)$$

由 $(1): x' = 2y'$，代入 $(2)$：$4y' + y' = 11 \Rightarrow y' = \dfrac{11}{5}$，$x' = \dfrac{22}{5}$。

故对称点 $P'\!\left(\dfrac{22}{5},\, \dfrac{11}{5}\right)$。

**直线 $PP'$**：过 $P(4, 3)$，斜率 $-2$：

$$y - 3 = -2(x - 4) \implies 2x + y - 11 = 0$$

**验证**：代入 $P$：$8 + 3 - 11 = 0$ ✓；代入 $P'$：$\dfrac{44}{5} + \dfrac{11}{5} - 11 = \dfrac{55}{5} - 11 = 0$ ✓。

### 例 3：含参不等式与直线位置综合

**题目**：设直线族 $l_a: (2a-1)x - ay + 3 = 0$（$a \in \mathbb{R}$）。

（1）证明所有这族直线过同一定点，并求该定点坐标。  
（2）若点 $Q(m, 1)$ 在直线 $l_a$ 上方（即代入 $l_a$ 左端大于 $0$）对所有实数 $a$ 均成立，求 $m$ 的范围。

**【思路】** 将方程整理为关于 $a$ 的线性式，令系数全为零得定点；(2) 整理为关于 $a$ 的不等式恒成立，分析。

**解（1）**：

整理：$(2a-1)x - ay + 3 = 0 \implies a(2x - y) + (-x + 3) = 0$。

要使此式对所有 $a$ 成立，需：

$$2x - y = 0 \quad \text{且} \quad -x + 3 = 0$$

解得 $x = 3$，$y = 6$，即定点 $T(3, 6)$。

**验证**：将 $(3, 6)$ 代入 $l_a$：$(2a-1)(3) - a(6) + 3 = 6a - 3 - 6a + 3 = 0$ ✓，对所有 $a$ 均成立。

**解（2）**：

将 $Q(m, 1)$ 代入 $l_a$ 左端：

$$(2a-1)m - a(1) + 3 = a(2m - 1) + (-m + 3)$$

要求此式对所有 $a \in \mathbb{R}$ 均大于 $0$，则关于 $a$ 的一次函数（或常数）必须对所有 $a$ 大于 $0$。

若 $a$ 的系数 $2m - 1 \neq 0$，则该式是关于 $a$ 的一次函数，随 $a \to \pm\infty$ 可取任意大或任意小的值，不可能对所有 $a$ 均大于 $0$。

故必须 $a$ 的系数为 $0$，即 $2m - 1 = 0 \Rightarrow m = \dfrac{1}{2}$。

此时常数项 $-m + 3 = -\dfrac{1}{2} + 3 = \dfrac{5}{2} > 0$ ✓。

**答**：$m = \dfrac{1}{2}$（唯一值）。

## 六、易错点汇总

**易错 1：含参讨论遗漏特殊值**

含参方程 $ax + by + c = 0$ 中，若 $b$ 含参数（如 $b = 1-a$），必须单独验证使 $b = 0$ 的参数值。遗漏此情形会导致结论不完整——垂直于 $y$ 轴的直线用斜截式无法表示，必须写出 $x = \text{常数}$ 的形式。

**易错 2：点在直线"上方"混淆"上方"的方向**

"点 $(x_0, y_0)$ 在直线 $Ax + By + C = 0$ 上方"并不等于 $Ax_0 + By_0 + C > 0$——"上方"指 $y$ 坐标更大的一侧，而代入符号的正负与 $B$ 的符号有关。若 $B > 0$，代入值大于 $0$ 确实对应"上方"；若 $B < 0$，则代入值大于 $0$ 对应"下方"。务必先确定哪个符号对应哪侧，或用具体点验证。

**易错 3：点关于直线对称时漏写两个条件之一**

求对称点必须同时用到：① $PP'$ 中点在 $l$ 上；② $PP' \perp l$。只用其中一个条件会得到不定方程组（一个方程含两个未知数），无法唯一确定 $P'$。两个条件缺一不可。

**易错 4：直线关于点对称时套错替换公式**

直线 $l$ 关于点 $(a, b)$ 的对称直线，是将 $l$ 的方程中 $(x, y)$ 替换为 $(2a - x, 2b - y)$，而非 $(x - a, y - b)$ 或其他变体。常见错误是替换时加减号搞错，导致对称结果偏移。

**易错 5：含参不等式恒成立时忽略线性系数为零的特殊情形**

当不等式整理为 $a \cdot f(x) + g(x) > 0$ 要求对所有 $a$ 恒成立时，必须令 $a$ 的系数 $f(x) = 0$，再检查常数项 $g(x)$ 是否满足条件。直接用"所有 $a$ 均大于 $0$"的逻辑而不讨论系数是否为零，是最常见的错误路径。

## 七、思路自测题

**自测 1**　直线 $l: (2-a)x + (a+1)y - 3 = 0$ 对所有实数 $a$ 均表示同一点的直线族。求该族直线的公共定点坐标，并分别写出 $a = 2$ 和 $a = -1$ 时的直线方程。

> 提示：整理为 $a(-x + y) + (2x + y - 3) = 0$，令 $-x + y = 0$ 且 $2x + y - 3 = 0$，解得 $x = 1, y = 1$，定点 $(1, 1)$。当 $a = 2$：$3y - 3 = 0 \Rightarrow y = 1$；当 $a = -1$：$3x - 3 = 0 \Rightarrow x = 1$。

**自测 2**　求点 $P(-2, 4)$ 关于直线 $l: 3x + 4y - 5 = 0$ 的对称点 $P'$。

> 提示：$l$ 斜率 $-3/4$，$PP'$ 斜率 $4/3$。设 $P'(x', y')$，垂直条件：$\frac{y'-4}{x'+2} = \frac{4}{3}$；中点条件：$3 \cdot \frac{-2+x'}{2} + 4 \cdot \frac{4+y'}{2} - 5 = 0$，联立解得 $P'(2, -4/5 \cdot \ldots)$。完整计算：$(x', y') = (x_0 - \frac{2A\Delta}{A^2+B^2}, y_0 - \frac{2B\Delta}{A^2+B^2})$，其中 $\Delta = 3(-2)+4(4)-5 = -6+16-5 = 5$，$A^2+B^2=25$，故 $x' = -2 - \frac{2 \cdot 3 \cdot 5}{25} = -2 - \frac{6}{5} = -\frac{16}{5}$，$y' = 4 - \frac{2 \cdot 4 \cdot 5}{25} = 4 - \frac{8}{5} = \frac{12}{5}$，即 $P'\!\left(-\frac{16}{5},\, \frac{12}{5}\right)$。

**自测 3**　判断点 $A(0, 0)$、$B(2, 3)$ 是否在直线 $l: x - y + 1 = 0$ 的同侧，并指出各点在哪一侧。

> 提示：代入 $A$：$0 - 0 + 1 = 1 > 0$；代入 $B$：$2 - 3 + 1 = 0$，$B$ 恰在直线上！严格来说 $B$ 在直线上，不在任何一侧。将 $B$ 改为 $(2, 4)$：代入得 $2 - 4 + 1 = -1 < 0$，与 $A$ 异号，两点在直线两侧。

**自测 4**　直线 $l_1: 2x - y + 1 = 0$ 关于直线 $l_0: x = 1$ 的对称直线 $l_2$ 的方程是什么？

> 提示：$l_0: x = 1$ 是竖线，关于竖线 $x = a$ 的对称把 $x$ 替换为 $2a - x = 2(1) - x = 2 - x$，$y$ 不变。代入 $l_1$：$2(2-x) - y + 1 = 0 \Rightarrow 4 - 2x - y + 1 = 0 \Rightarrow 2x + y - 5 = 0$。故 $l_2: 2x + y - 5 = 0$。

**回头看"一例速记"**：

> 含参直线：整理为 $a \cdot f(x,y) + g(x,y) = 0$，令 $f = 0$ 且 $g = 0$ 得定点；特殊参数值单独讨论。  
> 点与直线位置：代入方程左端看符号正负，同号同侧，异号两侧；$B$ 的正负决定"正值"对应哪一侧。  
> 对称点：中点在线上 + 连线垂直，两条件缺一不可。  
> 含参恒成立：令 $a$ 的系数为零，再验证常数项。
