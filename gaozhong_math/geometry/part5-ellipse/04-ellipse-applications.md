# 椭圆综合应用

> **一例速记**：
>
> **含参椭圆**：先确定参数范围（$a > b > 0$，$a^2 = b^2 + c^2$），再代入已知条件求解。
>
> **参数方程**：椭圆 $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$ 上的点可以写成 $(a\cos\theta, b\sin\theta)$，利用辅助角公式求 $ax + by$ 型的最值。
>
> **实际应用**：天体轨道是椭圆（开普勒第一定律），太阳位于一个焦点；椭圆反射性质——从一个焦点发出的光线经椭圆反射后汇聚到另一个焦点。

---

## 一、含参椭圆的方程确定

含参椭圆问题的核心，是从已知的几何量（离心率、通径、顶点、焦点等）出发，求出 $a^2$ 和 $b^2$，进而写出标准方程。

### 1.1 基本关系

| 量 | 公式 | 说明 |
|----|------|------|
| 焦距 | $2c$，$c = \sqrt{a^2 - b^2}$ | $c > 0$，$c < a$ |
| 离心率 | $e = c/a$ | $e \in (0,1)$ |
| 通径 | $l = 2b^2/a$ | 过焦点垂直长轴的弦长 |
| 焦半径（右焦点） | $\|PF_2\| = a - ex_P$ | $P(x_P, y_P)$ 在椭圆上 |
| 焦半径（左焦点） | $\|PF_1\| = a + ex_P$ | 同上 |

### 1.2 含参方程的确定步骤

**通用步骤**：
1. 判断焦点在 $x$ 轴还是 $y$ 轴（看已知条件中的对称性）；
2. 设 $a^2 = m$，$b^2 = n$（$m > n > 0$，焦点在 $x$ 轴时）；
3. 将已知条件转化为关于 $m, n$ 的方程组；
4. 解方程组，验证 $m > n > 0$。

**常见已知量的代数表达**：

- **已知离心率** $e_0$：$c/a = e_0$，即 $c = ae_0$，$b^2 = a^2 - c^2 = a^2(1 - e_0^2)$；需另一条件定 $a$。
- **已知通径** $l_0$：$2b^2/a = l_0$，即 $b^2 = al_0/2$；需另一条件。
- **已知焦点** $(\pm c_0, 0)$：$c = c_0$ 已知；需另一条件（如顶点或椭圆上一点）。
- **已知顶点** $(\pm a_0, 0)$ 或 $(0, \pm b_0)$：$a = a_0$（或 $b = b_0$）已知；需另一条件。

### 1.3 典型情形

**情形 A：已知离心率 + 椭圆上一点**

若 $e = e_0$，点 $P(x_P, y_P)$ 在椭圆上：

- $e = c/a = e_0 \Rightarrow c = ae_0 \Rightarrow b^2 = a^2(1-e_0^2)$；
- 代入 $\dfrac{x_P^2}{a^2} + \dfrac{y_P^2}{b^2} = 1$，解出 $a^2$，再求 $b^2$。

**情形 B：已知两个焦点 + 离心率**

焦点给出 $c$，离心率给出 $a = c/e$，则 $b^2 = a^2 - c^2$。

**情形 C：已知通径 + 离心率**

$2b^2/a = l_0$ 且 $e = c/a$，联立：$b^2 = a^2 - c^2 = a^2(1-e^2)$，代入通径方程：$2a(1-e^2) = l_0$，解出 $a$，再求 $b^2$。

## 二、椭圆与圆 / 直线综合

### 2.1 椭圆与圆综合

**题型**：椭圆上的点到圆（或圆上的点到椭圆中心）的距离极值。

**方法**：将椭圆参数化为 $(a\cos\theta, b\sin\theta)$，把距离平方写为关于 $\theta$ 的函数，再求极值。

**典型问题**：椭圆 $\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}=1$ 上的点 $P$ 到圆 $x^2+y^2=r^2$ 的最近/最远距离。

- 先求 $|OP|$ 在椭圆上的最值：参数化 $|OP|^2 = a^2\cos^2\theta + b^2\sin^2\theta = b^2 + (a^2-b^2)\cos^2\theta$；
- $\theta = 0, \pi$ 时 $|OP|_{\max} = a$；$\theta = \pi/2, 3\pi/2$ 时 $|OP|_{\min} = b$；
- $P$ 到圆的最近距离 $= |OP|_{\min} - r = b - r$（若 $b > r$）；最远距离 $= |OP|_{\max} + r = a + r$。

### 2.2 椭圆与直线综合

这类题通常综合两种能力：确定椭圆方程（含参），然后处理直线与椭圆的交点问题。

**解题顺序**：
1. 先由含参条件确定椭圆方程；
2. 再用代入消元 + 韦达定理处理直线相交问题；
3. 最后计算目标量（面积、弦长、比例等）。

## 三、椭圆参数方程与最值

### 3.1 参数方程

椭圆 $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$ 的参数方程为：

$$x = a\cos\theta, \quad y = b\sin\theta \qquad (\theta \in [0, 2\pi))$$

$\theta$ 称为**离心角**（不是椭圆上的极角）。

**验证**：$\dfrac{(a\cos\theta)^2}{a^2} + \dfrac{(b\sin\theta)^2}{b^2} = \cos^2\theta + \sin^2\theta = 1$，成立。

### 3.2 用参数方程求线性最值

**问题形式**：在椭圆 $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$ 上，求 $px + qy$ 的最大值和最小值（$p, q$ 为常数）。

**方法**（辅助角公式）：

$$px + qy = p\cdot a\cos\theta + q\cdot b\sin\theta$$

这是形如 $A\cos\theta + B\sin\theta$ 的表达式，最大值为 $\sqrt{A^2 + B^2}$，最小值为 $-\sqrt{A^2+B^2}$。

$$\max(px+qy) = \sqrt{(pa)^2 + (qb)^2}, \quad \min(px+qy) = -\sqrt{(pa)^2+(qb)^2}$$

**记忆**：$pa$ 和 $qb$ 分别是 $p, q$ 乘以对应半轴长，最值 = 这两项的"向量长度"。

### 3.3 用参数方程求距离最值

**问题形式**：椭圆上的点 $P$ 到定点 $Q(x_Q, y_Q)$ 的最近 / 最远距离。

$$|PQ|^2 = (a\cos\theta - x_Q)^2 + (b\sin\theta - y_Q)^2$$

展开后得关于 $\theta$ 的三角函数式，用辅助角公式或对 $\theta$ 求导求极值。

## 四、实际应用

### 4.1 天体轨道（开普勒第一定律）

**结论**：行星绕太阳运动的轨道是椭圆，太阳位于椭圆的一个**焦点**上（不是中心）。

**计算应用**：
- 已知轨道长半轴 $a$、短半轴 $b$，可求近日距（最近距离）= $a - c$，远日距（最远距离）= $a + c$，其中 $c = \sqrt{a^2-b^2}$；
- 离心率 $e$ 越接近 $1$，轨道越"扁"（近日远日差距越大）；$e$ 越接近 $0$，轨道越接近圆。

**典型数据（地球轨道近似）**：$a \approx 1.496 \times 10^8$ km，$e \approx 0.0167$。

### 4.2 椭圆截面

**应用背景**：斜切圆柱（或圆锥）得到椭圆截面。

**计算场景**：已知圆柱半径 $r$、切面倾斜角 $\alpha$，截面椭圆短半轴 $= r$，长半轴 $= r/\cos\alpha$。

**建模方法**：建立以截面中心为原点、长轴为 $x$ 轴的坐标系，写出椭圆方程，再求截面面积 $= \pi ab = \pi r \cdot r/\cos\alpha = \pi r^2/\cos\alpha$。

### 4.3 椭圆的光学反射性质

**结论**：从椭圆一个焦点 $F_1$ 发出的光线，经椭圆边界（视为镜面）反射后，必然汇聚到另一个焦点 $F_2$。

**几何原理**：椭圆上任意一点 $P$，切线是 $PF_1$ 和 $PF_2$ 的角平分线的法线（即入射角 = 反射角）。等价地，$PF_1$ 和 $PF_2$ 关于椭圆在 $P$ 点的切线对称。

**应用**：碎石波治疗仪（冲击波从一个焦点发出，经椭球面反射聚焦到肾结石所在的另一个焦点）；椭圆形会议室的"窃听"效应（声音在焦点处最响）。

## 五、典型应用例题

### 例 1：参数化求最值

**题目**：椭圆 $\dfrac{x^2}{4} + y^2 = 1$ 上的点 $P$，求 $P$ 到点 $Q(1, 0)$ 的最近距离和最远距离。

**【思路】** 参数化 $P = (2\cos\theta, \sin\theta)$，建立 $|PQ|^2$ 关于 $\theta$ 的表达式，求极值。

**解**：

设 $P = (2\cos\theta, \sin\theta)$，则：

$$|PQ|^2 = (2\cos\theta - 1)^2 + \sin^2\theta$$

$$= 4\cos^2\theta - 4\cos\theta + 1 + \sin^2\theta$$

$$= 4\cos^2\theta - 4\cos\theta + 1 + (1 - \cos^2\theta)$$

$$= 3\cos^2\theta - 4\cos\theta + 2$$

令 $u = \cos\theta \in [-1, 1]$，令 $f(u) = 3u^2 - 4u + 2$。

$f'(u) = 6u - 4 = 0 \Rightarrow u = 2/3$（在 $[-1,1]$ 内）。

- $f(2/3) = 3 \times 4/9 - 4 \times 2/3 + 2 = 4/3 - 8/3 + 2 = 2/3$（最小值）；
- $f(-1) = 3 + 4 + 2 = 9$；$f(1) = 3 - 4 + 2 = 1$。

故 $|PQ|^2$ 最小值为 $2/3$，最大值为 $9$。

$$|PQ|_{\min} = \sqrt{\frac{2}{3}} = \frac{\sqrt{6}}{3}, \qquad |PQ|_{\max} = 3$$

注意 $Q(1, 0)$ 是椭圆的右焦点（$c = \sqrt{4-1} = \sqrt{3}$，$F_2 = (\sqrt{3}, 0)$，$Q = (1,0)$ 不是焦点，所以不能直接用焦半径公式）。

$$\boxed{|PQ|_{\min} = \frac{\sqrt{6}}{3}, \quad |PQ|_{\max} = 3}$$

> 解题要点：参数化后 $|PQ|^2$ 变成关于 $u = \cos\theta$ 的二次函数，再在 $u \in [-1,1]$ 上求极值，比直接求导更清晰。要对端点和内部极值点都求值，取最大 / 最小。

### 例 2：含参椭圆的确定

**题目**：椭圆 $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$（$a > b > 0$）的离心率为 $\dfrac{\sqrt{3}}{2}$，且椭圆过点 $A(1, 1)$，求椭圆方程。

**【思路】** 离心率给出 $a, b, c$ 的比例关系；再由点在椭圆上列第二个方程。

**解**：

**第一步**：由离心率。

$$e = \frac{c}{a} = \frac{\sqrt{3}}{2} \implies c = \frac{\sqrt{3}}{2}a \implies c^2 = \frac{3}{4}a^2$$

$$b^2 = a^2 - c^2 = a^2 - \frac{3}{4}a^2 = \frac{a^2}{4}$$

**第二步**：代入点 $A(1,1)$。

$$\frac{1}{a^2} + \frac{1}{b^2} = 1$$

代入 $b^2 = a^2/4$：

$$\frac{1}{a^2} + \frac{4}{a^2} = 1 \implies \frac{5}{a^2} = 1 \implies a^2 = 5, \quad b^2 = \frac{5}{4}$$

**验证**：$a^2 = 5 > b^2 = 5/4 > 0$，$c^2 = 15/4$，$e = \sqrt{15/4}/\sqrt{5} = \sqrt{15}/(2\sqrt{5}) = \sqrt{3}/2$，正确。

椭圆方程：

$$\boxed{\dfrac{x^2}{5} + \dfrac{4y^2}{5} = 1}$$

即 $\dfrac{x^2}{5} + \dfrac{y^2}{5/4} = 1$。

> 解题要点：含参椭圆问题的关键是把离心率条件转化为 $b^2$ 与 $a^2$ 的关系（这里 $b^2 = a^2/4$），再代入第二个条件解出 $a^2$。整个流程只有两个方程解两个未知数，不要绕弯子。

### 例 3：实际应用——椭圆拱桥

**题目**：某椭圆形拱桥，拱桥的跨度（水平宽度）为 $20$ 米，拱顶（最高点）距水面 $6$ 米。现距桥中轴 $5$ 米处有一船经过，求该处水面以上的净高度（精确到 $0.01$ 米）。

**【思路】** 以水面与中轴的交点为原点建系，椭圆长半轴 $a = 10$，短半轴（向上）$b = 6$，求 $x = 5$ 处的椭圆纵坐标。

**解**：

建立坐标系：以拱桥中心（水面处）为原点，水平方向为 $x$ 轴，竖直向上为 $y$ 轴。

椭圆方程：

$$\frac{x^2}{100} + \frac{y^2}{36} = 1 \quad (a = 10, b = 6)$$

在 $x = 5$ 处：

$$\frac{25}{100} + \frac{y^2}{36} = 1 \implies \frac{y^2}{36} = \frac{3}{4} \implies y^2 = 27 \implies y = 3\sqrt{3} \approx 5.20 \text{ 米}$$

（取正值，表示拱桥在水面以上的高度。）

$$\boxed{\text{净高} \approx 5.20 \text{ 米}}$$

> 解题要点：建系时注意"中心"在水面（不在拱顶），长半轴是水平方向 $a = 10$，短半轴是竖直方向 $b = 6$。建好系后代入 $x = 5$ 求 $y$ 即可，计算很直接。

## 六、易错点汇总

**易错 1：焦点位置判断错误**

椭圆标准方程 $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$ 中，$a^2$ 和 $b^2$ 哪个大，焦点就在哪个轴上（$a^2 > b^2$ 时焦点在 $x$ 轴，$b^2 > a^2$ 时焦点在 $y$ 轴）。初学者常把"$x^2$ 系数小则焦点在 $x$ 轴"记反——系数是 $1/a^2$，系数小意味着 $a^2$ 大，焦点在 $x$ 轴。最稳妥的记法：看**分母**，大分母对应的轴是长轴，焦点在长轴上。

**易错 2：离心率含参时 $e \in (0,1)$ 忘记验证**

含参椭圆问题中，解出 $a, b, c$ 后，必须验证 $e = c/a \in (0,1)$（等价于 $a > c > 0$，即 $a^2 > c^2$，即 $b^2 > 0$）。若参数取某些值导致 $b^2 \leq 0$，则该情形不存在椭圆，需剔除。

**易错 3：参数方程中 $\theta$ 不是极角**

椭圆参数方程 $x = a\cos\theta, y = b\sin\theta$ 中的 $\theta$ 是**离心角**，不是极坐标中的极角（$\theta$ 与 $\arctan(y/x)$ 不同）。在用参数方程求几何量时，不要把 $\theta$ 当作几何角度理解，只当作代数参数处理。

**易错 4：弦长公式与焦半径公式混用**

弦长公式适用于一般直线与椭圆相交；焦半径公式 $|PF| = a \pm ex_P$ 适用于椭圆上的点到焦点的距离。两类公式不要混用——比如不能用"$a - ex_P$"算椭圆上点到一条任意直线的距离。

**易错 5：含参问题中斜率不存在的情形未讨论**

对"设直线斜率为 $k$"的含参问题，若题目没有明确说明斜率存在，必须单独验证竖直线（$x = t$）是否满足条件。例如"过点 $P$ 的直线与椭圆相切"，可能有竖直切线（$x = \pm a$ 处）；过焦点的弦中，垂直于长轴的通径（$x = \pm c$）也是一种特殊情形。

## 七、自测题

**自测 1**　已知椭圆的通径长为 $3$，离心率为 $\dfrac{1}{2}$，求椭圆标准方程（焦点在 $x$ 轴）。

> 提示：$2b^2/a = 3$，$e = c/a = 1/2$，$b^2 = a^2 - c^2 = a^2(1-1/4) = 3a^2/4$。代入通径：$2 \times 3a^2/4 / a = 3$，$3a/2 = 3$，$a = 2$，$b^2 = 3$，$c = 1$。椭圆：$\dfrac{x^2}{4} + \dfrac{y^2}{3} = 1$。

**自测 2**　椭圆 $\dfrac{x^2}{4} + y^2 = 1$ 上的点 $P$，$P$ 到 $x$ 轴的距离的最大值是多少？$|OP|$ 的最大值和最小值分别是多少？

> 提示：$P = (2\cos\theta, \sin\theta)$，到 $x$ 轴距离 $= |\sin\theta|$，最大值 $= 1$（当 $\theta = \pi/2$）。$|OP|^2 = 4\cos^2\theta + \sin^2\theta = 3\cos^2\theta + 1$，最大值 $= 4$（$\theta=0$），最小值 $= 1$（$\theta = \pi/2$）。故 $|OP|_{\max} = 2$，$|OP|_{\min} = 1$。

**自测 3**　椭圆 $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$（$a > b > 0$），两焦点为 $F_1(-c,0)$，$F_2(c,0)$。椭圆上一点 $P$ 满足 $|PF_1| = \dfrac{3}{2}a$，求 $|PF_2|$ 和 $|F_1F_2|$（用 $a, e$ 表示）。

> 提示：由椭圆定义 $|PF_1| + |PF_2| = 2a$，故 $|PF_2| = 2a - \dfrac{3}{2}a = \dfrac{a}{2}$。$|F_1F_2| = 2c = 2ae$。需验证 $P$ 存在：$|PF_i| \geq a - c$（最小焦半径）。$|PF_2| = a/2 \geq a - c$ 要求 $c \geq a/2$，即 $e \geq 1/2$。$|PF_1| = 3a/2 \leq a + c$ 要求 $c \geq a/2$，同样 $e \geq 1/2$。故当 $e \geq 1/2$ 时 $P$ 存在。

**自测 4**　建筑设计中，某半椭圆拱门宽 $4$ 米（即长轴 $= 4$，$a = 2$），在距中轴 $1$ 米处，拱门的高度为 $\dfrac{3\sqrt{3}}{2}$ 米，求此拱门的方程，并计算拱门在距中轴 $\sqrt{2}$ 米处的高度。

> 提示：以中轴底部为原点建系，椭圆方程 $\dfrac{x^2}{4} + \dfrac{y^2}{b^2} = 1$（取上半椭圆，$y \geq 0$）。代入 $(1, \dfrac{3\sqrt{3}}{2})$：$\dfrac{1}{4} + \dfrac{27/4}{b^2} = 1$，$\dfrac{27}{4b^2} = \dfrac{3}{4}$，$b^2 = \dfrac{27}{3} = 9$，$b = 3$。拱门方程：$\dfrac{x^2}{4} + \dfrac{y^2}{9} = 1$（$y \geq 0$）。在 $x = \sqrt{2}$ 处：$\dfrac{2}{4} + \dfrac{y^2}{9} = 1$，$y^2 = \dfrac{9}{2}$，$y = \dfrac{3\sqrt{2}}{2} \approx 2.12$ 米。
