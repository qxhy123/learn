## D.11 [中档] Part 3/02

**题目回顾**：直线 $l_1$：$2x - y + 3 = 0$，直线 $l_2$ 过点 $(1, -1)$ 且与 $l_1$ 平行，直线 $l_3$ 过点 $(1, -1)$ 且与 $l_1$ 垂直。分别写出 $l_2, l_3$ 的方程。

**思路**（→ toolkit/06 位置分类）

$l_1$ 的斜率 $k_1 = 2$。平行直线斜率相同；垂直直线斜率互为负倒数，即 $k_\perp = -\dfrac{1}{k_1} = -\dfrac{1}{2}$。利用点斜式写出方程，再化为一般式验证不重合。

**解答**

**求 $l_2$（过 $(1,-1)$，斜率 $= 2$）**

$$l_2: y - (-1) = 2(x - 1) \implies y + 1 = 2x - 2 \implies 2x - y - 3 = 0$$

（旁注：与 $l_1$ 比较：$2x-y+3=0$ vs $2x-y-3=0$，截距不同，确实平行不重合。）

**求 $l_3$（过 $(1,-1)$，斜率 $= -\dfrac{1}{2}$）**

$$l_3: y + 1 = -\frac{1}{2}(x - 1) \implies 2y + 2 = -(x - 1) \implies x + 2y + 1 = 0$$

**答案**

$$l_2: \boxed{2x - y - 3 = 0}, \quad l_3: \boxed{x + 2y + 1 = 0}$$

**总结** 平行 → 同斜率换截距；垂直 → 斜率取负倒数。两种类型均用点斜式，化一般式后对比原方程验证不重合。另需注意：若直线斜率不存在（竖直线），则需单独讨论，本题 $l_1$ 斜率为 $2$，不涉及此情形。

**常见错误提示**：平行时容易忘记验证"不重合"。若点 $(1,-1)$ 在 $l_1$ 上，则过点且斜率相同的直线就是 $l_1$ 本身，不算平行。本题验证：将 $(1,-1)$ 代入 $l_1$：$2(1)-(-1)+3=6\neq 0$，故点不在 $l_1$ 上，所求 $l_2$ 确与 $l_1$ 平行不重合。

## D.12 [中档] Part 3/03

**题目回顾**：已知直线 $l$：$y = kx + 2$ 与直线 $m$：$3x - y + 1 = 0$ 平行，求 $k$；若 $l$ 与 $m$ 垂直，求 $k$。

**思路**（→ toolkit/06 位置分类）

将 $m$ 化为斜截式，读出其斜率 $k_m$，再令 $k = k_m$（平行）或 $k \cdot k_m = -1$（垂直）。注意平行条件要排除重合。

**解答**

直线 $m$：$y = 3x + 1$，故 $k_m = 3$。

**平行**：$k = k_m = 3$，但需验证两直线不重合——$l$：$y=3x+2$ 与 $m$：$y=3x+1$ 截距不同，确实平行。

$$k = \boxed{3}$$

**垂直**：$k \cdot 3 = -1$，得 $k = -\dfrac{1}{3}$。

$$k = \boxed{-\dfrac{1}{3}}$$

**总结** 同一题型：读斜率 → 平行令相等（验非重合）→ 垂直令乘积为 $-1$。

**方法拓展**：若直线以一般式 $Ax+By+C=0$ 给出，则其斜率为 $-A/B$（$B\neq 0$）。与之平行的直线为 $Ax+By+C'=0$（$C'\neq C$），垂直的直线为 $Bx-Ay+C''=0$。本题 $m$：$3x-y+1=0$ 中 $A=3, B=-1$，平行方向系数不变，垂直方向交换并变号：$(-1)x-3y+C''=0$，即 $x+3y+C''=0$，对应斜率 $-1/3$，与前述结果一致。

## D.13 [中档] Part 3/04

**题目回顾**：求点 $P(3, -2)$ 到直线 $l$：$4x - 3y + 1 = 0$ 的距离；求两平行线 $l_1$：$x + 2y - 1 = 0$ 与 $l_2$：$x + 2y + 4 = 0$ 之间的距离。

**思路**（→ toolkit/06 位置分类）

**点到直线距离公式**：$d = \dfrac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}$。

**平行线间距**：在任一直线上取一点，代入点到直线距离公式；或利用截距差法 $d = \dfrac{|C_1 - C_2|}{\sqrt{A^2+B^2}}$（系数 $A, B$ 须相同）。

**解答**

**点 $P$ 到 $l$ 的距离**

$$d = \frac{|4\cdot 3 + (-3)\cdot(-2) + 1|}{\sqrt{4^2 + (-3)^2}} = \frac{|12 + 6 + 1|}{\sqrt{16+9}} = \frac{19}{5}$$

（旁注：分子 $= |12+6+1| = 19$，分母 $= 5$。）

**$l_1$ 与 $l_2$ 间距**

两直线系数 $A=1, B=2$，$C_1 = -1$，$C_2 = 4$（注意统一符号：$x+2y+C=0$，$l_1$ 的 $C=-1$，$l_2$ 的 $C=4$）。

$$d = \frac{|(-1) - 4|}{\sqrt{1^2 + 2^2}} = \frac{5}{\sqrt{5}} = \sqrt{5}$$

**答案**

点到直线距离：$\boxed{\dfrac{19}{5}}$；平行线距离：$\boxed{\sqrt{5}}$

**总结** 两公式同源，平行线间距是"用一个常数差除以法向量模"。要求 $A, B$ 系数先统一。

**典型错误**：使用平行线间距公式时，两方程须先化为同 $A, B$ 系数形式。若 $l_1$：$2x+4y-2=0$ 与 $l_2$：$x+2y+4=0$，则须将 $l_1$ 化为 $x+2y-1=0$（除以 $2$），再用 $|{-1}-4|/\sqrt{5}=\sqrt{5}$，与本题结果相同——实际上 $l_1$ 即为 $x+2y-1=0$，无需化简。

## D.14 [中档] Part 3/05

**题目回顾**：直线 $l$：$ax + by = 1$ 过点 $(2, 3)$ 且在两坐标轴上的截距相等（截距均非零），求 $l$ 的方程（分类讨论）。

**思路**（→ toolkit/04 参数化）

"截距相等"有两层含义：（1）$x$ 截距 $= y$ 截距（均为 $t \neq 0$）；（2）两截距均为 $0$ 对应过原点（但题目说均非零）。
用截距式 $\dfrac{x}{t} + \dfrac{y}{t} = 1$ 即 $x + y = t$ 过点 $(2,3)$ 求 $t$；另外注意斜率 $= -1$ 的直线 $x + y = t$ 也满足截距相等但须验证截距非零。

**解答**

**情形 1：$x$ 轴截距 $= y$ 轴截距 $= t$（$t \neq 0$）**

截距式：$\dfrac{x}{t} + \dfrac{y}{t} = 1$，即 $x + y = t$。

代入点 $(2,3)$：$t = 2 + 3 = 5$。

方程为 $x + y = 5$，即 $\boxed{x + y - 5 = 0}$。

验证：$x$ 轴截距 $= 5$，$y$ 轴截距 $= 5$，均非零。✓

**情形 2：截距均为零（过原点）**

题目明确"截距均非零"，排除此情形。

（旁注：若不限制非零，则需讨论 $l$ 是否可能为 $y = x$ 型过原点，此处跳过。）

**答案**

$$l: \boxed{x + y - 5 = 0}$$

**补充讨论**：若题目去掉"截距均非零"的条件，则需增加一种情形——截距均为 $0$（直线过原点）。过原点且过点 $(2,3)$ 的直线斜率为 $3/2$，方程为 $y = \dfrac{3}{2}x$，此时 $x$ 轴截距和 $y$ 轴截距均为 $0$，也满足"截距相等"。因此去掉限制条件后共有两个答案：$x+y-5=0$ 和 $y=\dfrac{3}{2}x$。

**总结** 截距相等且非零 → 直线斜率为 $-1$，截距式代入已知点；注意附加条件排除过原点情形。分类讨论是这类题型的核心思路。

## D.15 [中档] Part 3/06

**题目回顾**：直线 $l_1$：$y = 2x + 3$ 与直线 $l_2$：$y = 2x - 1$ 关于某直线 $l_3$ 对称，$l_3$ 平行于 $x$ 轴。求 $l_3$ 的方程。

**思路**（→ toolkit/07 几何最值）

两条平行线关于 $l_3$ 对称，意味着 $l_3$ 是这两条平行线的"中轴线"（平分线间距）。$l_3 \parallel x$ 轴，即 $l_3$：$y = c$，只需找两直线的"中间截距"。

**解答**

$l_1$ 的 $y$ 轴截距为 $3$，$l_2$ 的 $y$ 轴截距为 $-1$。

对称轴 $l_3$ 平行 $x$ 轴，所以它的方程形如 $y = c$，其中 $c$ 是两截距的平均值：

$$c = \frac{3 + (-1)}{2} = 1$$

故 $l_3$：$y = 1$。

**验证**：$l_3$ 与 $l_1$ 间距 $= \dfrac{|3-1|}{\sqrt{1+4}} = \dfrac{2}{\sqrt{5}}$；$l_3$ 与 $l_2$ 间距 $= \dfrac{|-1-1|}{\sqrt{5}} = \dfrac{2}{\sqrt{5}}$。等距，故 $l_3$ 是对称轴。✓

**关系**：$l_3$ 与 $l_1, l_2$ 均平行，且 $l_3$ 到 $l_1$ 的距离等于 $l_3$ 到 $l_2$ 的距离，均为 $\dfrac{2\sqrt{5}}{5}$。

**答案**

$$l_3: \boxed{y = 1}$$

**总结** 两平行线关于平行 $x$ 轴的直线对称 → 中轴 $y$ 值取两直线 $y$ 截距的平均。

**方法推广**：若两平行线斜率不为 $0$（如 $y=kx+b_1$ 和 $y=kx+b_2$，$k\neq 0$），对称轴平行于两直线，则对称轴方程为 $y=kx+\dfrac{b_1+b_2}{2}$。若对称轴平行于 $y$ 轴，则对称轴 $x=\dfrac{x_{切距1}+x_{切距2}}{2}$，取 $x$ 轴截距的平均值。本题 $l_3 \parallel x$ 轴，对应 $k=0$ 的特例，直接取 $y$ 截距平均即可。

## D.16 [中档] Part 4/01

**题目回顾**：将方程 $x^2 + y^2 - 6x + 4y - 3 = 0$ 化为标准形式，求圆心和半径；判断点 $A(4, -2)$ 是在圆内、圆上还是圆外。

**思路**（→ toolkit/06 位置分类）

配方法化标准式：$(x-a)^2 + (y-b)^2 = r^2$。点与圆位置关系：计算点到圆心距离 $d$，与 $r$ 比较。

**解答**

**配方**

$$x^2 - 6x + y^2 + 4y = 3$$

$$(x-3)^2 - 9 + (y+2)^2 - 4 = 3$$

$$(x-3)^2 + (y+2)^2 = 16$$

（旁注：$(-6/2)^2 = 9$，$(4/2)^2 = 4$，右边 $= 3 + 9 + 4 = 16$。）

圆心 $C(3, -2)$，半径 $r = 4$。

**点 $A(4,-2)$ 的位置**

$$|CA| = \sqrt{(4-3)^2 + (-2-(-2))^2} = \sqrt{1 + 0} = 1 < 4 = r$$

故点 $A$ 在圆**内**。

**答案**

圆心 $\boxed{(3, -2)}$，半径 $\boxed{4}$；点 $A$ 在圆 $\boxed{\text{内}}$。

**总结** 配方三步：移常数 → 两组各配完全平方 → 右边加补偿。点位判断：$|CA|<r$ 内，$=r$ 上，$>r$ 外。

**快捷判断点位置**：也可直接将点代入圆方程左端（移项到左边后）：
$$x^2 + y^2 - 6x + 4y - 3$$
将 $A(4,-2)$ 代入：$16 + 4 - 24 - 8 - 3 = -15 < 0$。结果为负说明点在圆内（左端 $< 0$ ↔ 距圆心距离的平方小于 $r^2$）。这个方法比算圆心距更快，但只适用于标准系数（$x^2, y^2$ 系数均为 $1$）的圆方程。

## D.17 [中档] Part 4/02

**题目回顾**：已知圆 $C$：$x^2 + y^2 + 2x - 4y + a = 0$ 是合法圆（$r > 0$），求 $a$ 的范围；当 $a = -4$ 时，求圆心、半径，以及原点到圆的距离。

**思路**（→ toolkit/04 参数化、→ toolkit/06 位置分类）

将一般式 $x^2+y^2+Dx+Ey+F=0$ 的合法条件写为 $D^2+E^2-4F > 0$，即 $r^2 = \dfrac{D^2+E^2-4F}{4} > 0$。再分两步：先求参数范围，再代入具体值。

**解答**

**配方**

$$(x+1)^2 - 1 + (y-2)^2 - 4 + a = 0$$

$$(x+1)^2 + (y-2)^2 = 5 - a$$

合法圆条件 $r^2 = 5 - a > 0$，即：

$$a < 5$$

**当 $a = -4$ 时**

$$(x+1)^2 + (y-2)^2 = 9$$

圆心 $C(-1, 2)$，半径 $r = 3$。

原点 $O(0,0)$ 到圆心距离：

$$|OC| = \sqrt{(-1)^2 + 2^2} = \sqrt{1+4} = \sqrt{5}$$

（旁注：$\sqrt{5} < 3 = r$，故原点在圆内。）

**答案**

$a$ 的范围：$\boxed{a < 5}$；圆心 $\boxed{(-1, 2)}$，半径 $\boxed{3}$；原点到圆心距离 $\boxed{\sqrt{5}}$（原点在圆内）。

**总结** 含参圆的合法条件通过配方后"$r^2>0$"直接得到；圆内外判断步骤：先算圆心距，再比较半径。

**一般公式**：圆 $x^2+y^2+Dx+Ey+F=0$ 是合法圆当且仅当 $D^2+E^2-4F>0$，此时圆心为 $\left(-\dfrac{D}{2},-\dfrac{E}{2}\right)$，半径 $r=\dfrac{\sqrt{D^2+E^2-4F}}{2}$。本题 $D=2, E=-4, F=a$，合法条件 $4+16-4a>0 \Rightarrow a<5$，与配方结果完全一致。记住这个判别式可以节省配方时间。

## D.18 [中档] Part 4/03

**题目回顾**：直线 $l$：$x - y + 1 = 0$ 与圆 $C$：$x^2 + y^2 - 2x - 4y = 0$ 的位置关系；若相交，求弦长。

**思路**（→ toolkit/06 位置分类、→ toolkit/07 几何最值）

先对圆配方求圆心和半径；再求圆心到直线的距离 $d$，与 $r$ 比较（$d < r$ 相交，$d = r$ 相切，$d > r$ 相离）；相交时弦长 $= 2\sqrt{r^2 - d^2}$。

**解答**

**配方求圆**

$$(x-1)^2 - 1 + (y-2)^2 - 4 = 0$$

$$(x-1)^2 + (y-2)^2 = 5$$

圆心 $C(1, 2)$，半径 $r = \sqrt{5}$。

**圆心到直线的距离**

$$d = \frac{|1 - 2 + 1|}{\sqrt{1^2 + (-1)^2}} = \frac{|0|}{\sqrt{2}} = 0$$

（旁注：$d = 0 < \sqrt{5} = r$，直线过圆心，位置关系为相交。）

**弦长**

$$|AB| = 2\sqrt{r^2 - d^2} = 2\sqrt{5 - 0} = 2\sqrt{5}$$

即直线过圆心，弦为直径。

**答案**

位置关系：$\boxed{\text{相交（直线过圆心）}}$；弦长：$\boxed{2\sqrt{5}}$（即直径）。

**总结** 判断直线与圆位置关系的流程：配方 → 读圆心半径 → 算圆心到直线距离 → 与 $r$ 比较。弦长公式 $2\sqrt{r^2-d^2}$ 是勾股定理的直接应用。

**几何意义**：本题直线恰好过圆心（$d=0$），因此弦为直径，弦长 $= 2r = 2\sqrt{5}$。这是弦长的最大值——对于固定的圆，所有弦中直径最长。若直线不过圆心，弦长 $2\sqrt{r^2-d^2}$ 随 $d$ 增大而减小，当 $d\to r$ 时弦长趋于 $0$（退化为切线）。

## D.19 [中档] Part 4/04

**题目回顾**：过点 $P(2, 3)$ 作圆 $C$：$x^2 + y^2 = 5$ 的切线，求切线方程（讨论切线是否存在斜率的情形）。

**思路**（→ toolkit/04 参数化、→ toolkit/06 位置分类）

先判断点 $P$ 在圆内还是圆外（决定切线是否存在）。设切线斜率为 $k$，利用"切线 ⟺ 圆心到切线距离等于半径"求 $k$；也要讨论斜率不存在（竖直线）的情形。

**解答**

**判断点 $P$ 的位置**

$$|CP|^2 = 2^2 + 3^2 = 4 + 9 = 13 > 5$$

故 $P(2,3)$ 在圆外，有两条切线。

**情形 1：切线斜率存在，设为 $k$**

切线方程：$y - 3 = k(x - 2)$，即 $kx - y + (3 - 2k) = 0$。

圆心 $O(0,0)$ 到切线距离等于 $r = \sqrt{5}$：

$$\frac{|k \cdot 0 - 0 + (3 - 2k)|}{\sqrt{k^2 + 1}} = \sqrt{5}$$

$$\frac{(3-2k)^2}{k^2+1} = 5$$

$$9 - 12k + 4k^2 = 5k^2 + 5$$

$$k^2 + 12k - 4 = 0$$

（旁注：整理得 $k^2 + 12k - 4 = 0$，判别式 $\Delta = 144 + 16 = 160 > 0$，有两实数根。）

$$k = \frac{-12 \pm \sqrt{160}}{2} = -6 \pm 4\sqrt{10}$$

Hmm，此根较复杂，重新核验：

$(3-2k)^2 = 5(k^2+1)$
$9 - 12k + 4k^2 = 5k^2 + 5$
$0 = k^2 + 12k - 4$

$k = \dfrac{-12 \pm \sqrt{144+16}}{2} = \dfrac{-12 \pm 4\sqrt{10}}{2} = -6 \pm 2\sqrt{10}$

（旁注：$\sqrt{160} = 4\sqrt{10}$，故 $k = -6 \pm 2\sqrt{10}$。）

对应两条切线方程（代入点斜式）：

$$y - 3 = (-6 + 2\sqrt{10})(x-2), \quad y - 3 = (-6-2\sqrt{10})(x-2)$$

**情形 2：斜率不存在（竖直线 $x = 2$）**

检验：圆心到 $x = 2$ 的距离 $= 2 \neq \sqrt{5}$，故 $x=2$ 不是切线，排除。

**答案**

切线共两条：

$$\boxed{y - 3 = (-6 + 2\sqrt{10})(x-2)} \quad \text{和} \quad \boxed{y - 3 = (-6 - 2\sqrt{10})(x-2)}$$

（斜率不存在的竖直线 $x=2$ 不是切线。）

**总结** 过圆外一点作切线：先判断点在圆外 → 设斜率列距离方程 → 解方程；切记讨论斜率不存在（竖直线）的情形并验证。

**另一种思路——切线长公式**：设圆心 $O$，过圆外点 $P$ 的切线切圆于点 $T$，则切线长 $|PT| = \sqrt{|PO|^2 - r^2}$。本题 $|PO|^2 = 13$，$r^2=5$，切线长 $= \sqrt{8} = 2\sqrt{2}$。利用切线长可以快速求切线长度，但求切线方程仍需设斜率列方程。

**注意**：斜率方程 $k^2+12k-4=0$ 的根 $k=-6\pm 2\sqrt{10}$ 是无理数，说明两切线方向较"斜"。如果圆和点的数据给得"整"，则 $k$ 通常是有理数，遇到无理数结果时应检查是否题目设计使然，而非计算错误。

## D.20 [中档] Part 4/04

**题目回顾**：圆 $C_1$：$x^2 + y^2 = 9$ 与圆 $C_2$：$(x-3)^2 + (y-4)^2 = 4$。判断两圆的位置关系。

**思路**（→ toolkit/06 位置分类）

两圆位置关系由圆心距 $|C_1C_2|$ 与两半径 $r_1, r_2$ 的大小关系决定：
- $|C_1C_2| > r_1 + r_2$：外离
- $|C_1C_2| = r_1 + r_2$：外切
- $|r_1 - r_2| < |C_1C_2| < r_1 + r_2$：相交
- $|C_1C_2| = |r_1 - r_2|$：内切
- $|C_1C_2| < |r_1 - r_2|$：内含

**解答**

圆 $C_1$：圆心 $C_1(0,0)$，$r_1 = 3$。

圆 $C_2$：圆心 $C_2(3,4)$，$r_2 = 2$。

圆心距：

$$|C_1C_2| = \sqrt{3^2 + 4^2} = \sqrt{9+16} = 5$$

比较：

$$r_1 + r_2 = 3 + 2 = 5, \quad |r_1 - r_2| = |3 - 2| = 1$$

$$|C_1C_2| = 5 = r_1 + r_2$$

（旁注：圆心距恰好等于两半径之和，为**外切**。）

**答案**

两圆**外切**，圆心距 $|C_1C_2| = \boxed{5} = r_1 + r_2$。

**总结** 两圆关系五分类，核心数据：圆心距 $d$、两半径 $r_1, r_2$。"恰等于和/差"是边界情形（切），须精确计算圆心距（勾股定理）。

**完整判断流程**（背诵）：设 $d = |C_1C_2|$，$r_1 \geq r_2$：
- $d > r_1 + r_2$：外离（两圆无公共点，各在对方外部）
- $d = r_1 + r_2$：外切（一个公共点，在两圆心连线上，在两圆之间）
- $|r_1-r_2| < d < r_1+r_2$：相交（两个公共点）
- $d = r_1 - r_2$（$r_1>r_2$）：内切（一个公共点，在两圆心连线延长线上）
- $d < r_1 - r_2$：内含（无公共点，小圆在大圆内部）
- $d = 0$ 且 $r_1 = r_2$：同心同径（重合）

本题 $d=5=r_1+r_2=5$，为外切。

## D.21 [中档] Part 4/05

**题目回顾**：圆 $C_1$：$x^2 + y^2 + 2x - 4 = 0$ 与圆 $C_2$：$x^2 + y^2 - 4x + 2y = 0$ 交于两点，求公共弦所在直线的方程。

**思路**（→ toolkit/06 位置分类）

两圆方程相减，消去 $x^2 + y^2$ 项，得到公共弦所在直线方程（这是"根轴"法的直接应用）。

**解答**

两方程相减（$C_1 - C_2$）：

$$(x^2 + y^2 + 2x - 4) - (x^2 + y^2 - 4x + 2y) = 0$$

$$2x - 4 - (-4x + 2y) = 0$$

$$2x - 4 + 4x - 2y = 0$$

$$6x - 2y - 4 = 0$$

化简：$3x - y - 2 = 0$。

（旁注：验证：将两圆方程的交点均满足此方程；此直线即根轴，也就是公共弦所在直线。）

**验证合法性（两圆确实相交）**

$C_1$：$(x+1)^2+(y-0)^2=5$，圆心 $(-1,0)$，$r_1=\sqrt{5}$。

$C_2$：$(x-2)^2+(y+1)^2=5$，圆心 $(2,-1)$，$r_2=\sqrt{5}$。

圆心距 $= \sqrt{9+1} = \sqrt{10}$。

$|r_1-r_2|=0 < \sqrt{10} < 2\sqrt{5} = r_1+r_2$。确实相交。✓

**答案**

公共弦所在直线：$\boxed{3x - y - 2 = 0}$

**总结** 求两圆公共弦直线的万能法：两方程相减即可，无需求交点坐标。这是根轴公式的应用，前提是两方程 $x^2, y^2$ 系数均为 $1$。

**公共弦的另一用途**：公共弦所在直线（根轴）垂直于两圆心连线。本题两圆心 $C_1(-1,0)$，$C_2(2,-1)$，连线方向向量为 $(3,-1)$；公共弦直线 $3x-y-2=0$ 的法向量为 $(3,-1)$，与连线方向相同，即公共弦确实垂直于圆心连线。✓ 这可以作为计算正确性的几何验证。

**弦长补充**：已知公共弦所在直线 $3x-y-2=0$，若需求弦长，可取圆 $C_1$ 计算圆心到公共弦的距离 $d_1 = \dfrac{|3(-1)-0-2|}{\sqrt{10}} = \dfrac{5}{\sqrt{10}} = \dfrac{\sqrt{10}}{2}$，弦长 $= 2\sqrt{r_1^2-d_1^2} = 2\sqrt{5-\frac{10}{4}} = 2\sqrt{\frac{10}{4}} = \sqrt{10}$。

## D.22 [中档] Part 3+4

**题目回顾**：直线 $l$：$y = kx + 1$ 恒过点 $(0, 1)$。求 $l$ 被圆 $C$：$x^2 + y^2 - 4x + 3 = 0$ 截得弦长最大时 $k$ 的值，以及最大弦长。

**思路**（→ toolkit/07 几何最值、→ toolkit/04 参数化）

弦长 $= 2\sqrt{r^2 - d^2}$，弦长最大 $\iff$ $d$ 最小（$d$ 为圆心到直线的距离）。将 $d$ 对 $k$ 求最值，或直接判断：当圆心到直线距离最小（即圆心到定点连线与直线垂直）时弦最长。特别地，若直线过圆心，则 $d=0$，弦为直径，是最大弦。

**解答**

**配方求圆**

$$(x-2)^2 - 4 + y^2 + 3 = 0 \implies (x-2)^2 + y^2 = 1$$

圆心 $C(2, 0)$，半径 $r = 1$。

**弦长与 $d$ 的关系**

弦长 $= 2\sqrt{1 - d^2}$（因 $r=1$）。弦长最大 $\iff d$ 最小 $\iff d = 0$（若可能）。

**检验直线 $l$ 能否过圆心 $C(2,0)$**

直线 $y = kx + 1$ 过 $(2,0)$：$0 = 2k + 1$，故 $k = -\dfrac{1}{2}$。

（旁注：此时 $d = 0$，弦为直径，是最长弦。）

**最大弦长**

$$|AB|_{\max} = 2r = 2 \times 1 = 2$$

**答案**

当 $k = \boxed{-\dfrac{1}{2}}$ 时弦长最大，最大弦长 $= \boxed{2}$（即直径）。

**总结** 弦长最值问题：弦长最大 ↔ 圆心到直线距离最小。若动直线过定点，检验圆心到定点的连线方向，令直线沿该方向（即过圆心）时 $d=0$，弦为直径。

**推广**：若定点在圆内（如本题，点 $(0,1)$ 在圆 $(x-2)^2+y^2=1$ 内还是外？$(0-2)^2+1^2=5>1$，故在圆外！确认 $k=-1/2$ 是使直线过圆心的斜率），则所有过该定点的直线都与圆相交，弦长随 $k$ 变化；若直线无法过圆心（定点不在圆上所有直线经过的圆心连线上），则需用微积分或对称性找最小 $d$。本题定点 $(0,1)$ 与圆心 $(2,0)$ 的连线斜率为 $\dfrac{0-1}{2-0}=-\dfrac{1}{2}=k$，正是求得的 $k$，验证无误。

## D.23 [中档] Part 3+4

**题目回顾**：直线 $l$：$(2m+1)x + (m+1)y - 3m - 2 = 0$（$m \in \mathbb{R}$）。证明 $l$ 恒过一个定点，求该定点；求 $l$ 关于原点对称的直线方程（用 $m$ 表示）。

**思路**（→ toolkit/04 参数化）

**恒过定点法**：将方程按 $m$ 整理为 $m \cdot (\cdots) + (\cdots) = 0$，令两括号同时为零，解方程组得定点。

**关于原点对称**：若直线 $l$ 的方程为 $f(x,y)=0$，则关于原点对称的直线 $l'$ 是将直线上每点 $(x,y)$ 替换为 $(-x,-y)$ 得到的，即 $f(-x,-y)=0$。

**解答**

**第一部分：求定点**

整理按 $m$ 分组：

$$(2m+1)x + (m+1)y - (3m+2) = 0$$

$$m(2x + y - 3) + (x + y - 2) = 0$$

要对一切 $m$ 成立，须：

$$\begin{cases} 2x + y - 3 = 0 \\ x + y - 2 = 0 \end{cases}$$

第一式减第二式：$x = 1$；代入第二式：$y = 1$。

定点为 $(1, 1)$。

**验证**：代入原方程：$(2m+1)\cdot 1 + (m+1)\cdot 1 - 3m - 2 = 2m+1+m+1-3m-2 = 0$。✓

**第二部分：关于原点对称的直线**

将原方程中 $(x, y)$ 换为 $(-x, -y)$：

$$(2m+1)(-x) + (m+1)(-y) - 3m - 2 = 0$$

$$-(2m+1)x - (m+1)y - 3m - 2 = 0$$

两边乘以 $-1$：

$$(2m+1)x + (m+1)y + 3m + 2 = 0$$

**答案**

定点：$\boxed{(1, 1)}$；关于原点对称的直线：$\boxed{(2m+1)x + (m+1)y + 3m + 2 = 0}$。

**总结** 恒过定点：按参数 $m$ 分组 → 两组系数分别为零 → 解方程组。关于原点对称：方程中 $(x,y)\to(-x,-y)$，整理即得。

**几何意义**：方程 $m(2x+y-3)+(x+y-2)=0$ 表示过两直线 $2x+y-3=0$ 和 $x+y-2=0$ 交点的直线族（对一切 $m$）。两直线的交点即为定点。

**关于原点对称的几何含义**：直线 $l$ 关于原点对称的直线 $l'$，是将 $l$ 上每一点 $(x,y)$ 映射到 $(-x,-y)$，即以原点为中心旋转 $180°$。所以 $l'$ 恒过定点 $(-1,-1)$（$(1,1)$ 关于原点的对称点），这可以快速验证：令 $m=0$：$l'$：$x+y+2=0$，代入 $(-1,-1)$：$-1-1+2=0$。✓

## D.24 [中档] Part 4/06

**题目回顾**：已知圆上三点为 $A(1, 0)$，$B(0, 1)$，$C(0, -1)$，求过这三点的圆的方程，并求圆心到直线 $AB$ 的距离。

**思路**（→ toolkit/06 位置分类、→ toolkit/07 几何最值）

由三点确定一个圆的方法：设一般式 $x^2 + y^2 + Dx + Ey + F = 0$，代入三点建方程组解 $D, E, F$；或利用几何法——$BC$ 是竖直线段，中垂线为 $y=0$（$x$ 轴），$AC$ 的中垂线也可求，两中垂线交点即圆心。

**解答**

**方法：一般式代点**

设圆方程 $x^2 + y^2 + Dx + Ey + F = 0$。

代入 $A(1,0)$：$1 + D + F = 0$ $\quad \cdots (1)$

代入 $B(0,1)$：$1 + E + F = 0$ $\quad \cdots (2)$

代入 $C(0,-1)$：$1 - E + F = 0$ $\quad \cdots (3)$

$(2)+(3)$：$2 + 2F = 0 \Rightarrow F = -1$。

$(2)-(3)$：$2E = 0 \Rightarrow E = 0$。

由 $(1)$：$D = -1 - F = -1 - (-1) = 0$。

圆方程：$x^2 + y^2 - 1 = 0$，即 $x^2 + y^2 = 1$。

圆心 $(0,0)$，半径 $r=1$。

**圆心到直线 $AB$ 的距离**

直线 $AB$：过 $A(1,0)$ 和 $B(0,1)$，方程为 $x + y - 1 = 0$。

$$d = \frac{|0 + 0 - 1|}{\sqrt{1^2 + 1^2}} = \frac{1}{\sqrt{2}} = \frac{\sqrt{2}}{2}$$

（旁注：这也是 $AB$ 弦的半弦长对应的圆心距，$|AB| = 2\sqrt{r^2 - d^2} = 2\sqrt{1 - 1/2} = \sqrt{2}$，符合 $AB$ 为正方形边长。）

**答案**

圆方程：$\boxed{x^2 + y^2 = 1}$；圆心到直线 $AB$ 的距离：$\boxed{\dfrac{\sqrt{2}}{2}}$。

**总结** 三点定圆 → 一般式代点，三方程三未知数。结合弦长公式，圆心到弦的距离可验证计算结果。

**几何法**：$B(0,1)$ 与 $C(0,-1)$ 关于 $x$ 轴对称，故圆心在 $BC$ 的垂直平分线 $y=0$（即 $x$ 轴）上。圆心在 $x$ 轴上，设为 $(a,0)$。到 $A(1,0)$ 距离 $= |a-1|$，到 $B(0,1)$ 距离 $= \sqrt{a^2+1}$。令两距离相等：$(a-1)^2 = a^2+1 \Rightarrow a^2-2a+1=a^2+1 \Rightarrow a=0$。故圆心为原点 $(0,0)$，半径 $= |OA| = 1$，与代数法一致。几何法在点具有明显对称性时更快。

## D.25 [中档] Part 3+4

**题目回顾**：设直线 $y = x + c$（$c$ 为实数）与圆 $x^2 + y^2 = 4$ 相交，求 $c$ 的取值范围；当直线与圆相交时，设弦长为 $l$，用 $c$ 的表达式写出 $l$。

**思路**（→ toolkit/04 参数化、→ toolkit/06 位置分类、→ toolkit/07 几何最值）

直线与圆相交的充要条件：圆心到直线距离 $d < r$（严格小于）。将 $d$ 用参数 $c$ 表示，解不等式得 $c$ 范围。弦长公式 $l = 2\sqrt{r^2 - d^2}$ 给出 $l$ 关于 $c$ 的表达式。

**解答**

圆心 $O(0,0)$，半径 $r = 2$。

直线 $l$：$x - y + c = 0$。

**圆心到直线距离**

$$d = \frac{|0 - 0 + c|}{\sqrt{1^2 + (-1)^2}} = \frac{|c|}{\sqrt{2}}$$

**相交条件**

$$d < r \implies \frac{|c|}{\sqrt{2}} < 2 \implies |c| < 2\sqrt{2}$$

$$\boxed{-2\sqrt{2} < c < 2\sqrt{2}}$$

**弦长 $l$ 的表达式**

$$l = 2\sqrt{r^2 - d^2} = 2\sqrt{4 - \frac{c^2}{2}} = 2\sqrt{\frac{8 - c^2}{2}} = \sqrt{2(8-c^2)} = \sqrt{16 - 2c^2}$$

（旁注：$4 - \dfrac{c^2}{2} = \dfrac{8-c^2}{2}$，故 $l = 2\cdot\dfrac{\sqrt{8-c^2}}{\sqrt{2}} = \sqrt{2}\cdot\sqrt{8-c^2} = \sqrt{16-2c^2}$。）

**验证边界**：当 $|c| = 2\sqrt{2}$ 时 $d = r$，弦长为 $0$（相切，退化），排除。当 $c = 0$ 时 $d = 0$，$l = \sqrt{16} = 4 = 2r$（过圆心为直径），正确。

**答案**

$c$ 的取值范围：$\boxed{-2\sqrt{2} < c < 2\sqrt{2}}$；弦长：$l = \boxed{\sqrt{16 - 2c^2}}$。

**总结** 含参直线与圆相交问题的标准三步：① 圆心到直线距离公式（含参数 $c$）；② 令 $d < r$ 解不等式；③ 弦长公式代入化简。是 toolkit/04+06+07 的综合运用。

**弦长关于 $c$ 的单调性分析**：

$$l(c) = \sqrt{16 - 2c^2}, \quad c \in (-2\sqrt{2},\ 2\sqrt{2})$$

- 当 $c=0$ 时，$l=4$（最大，直线过圆心为直径）；
- 当 $|c| \to 2\sqrt{2}$ 时，$l \to 0$（直线趋于与圆相切）；
- $l$ 关于 $c=0$ 对称，关于 $c$ 的函数为偶函数，即同一弦长对应 $c$ 与 $-c$ 两条直线（它们关于 $y$ 轴对称）。

此弦长公式可以直接给出"使弦长 $=$ 某定值"时 $c$ 的取值：$\sqrt{16-2c^2}=l_0 \Rightarrow c=\pm\sqrt{\dfrac{16-l_0^2}{2}}$（需 $0\leq l_0 \leq 4$）。
