## 模型 1：向量分解模型

**触发条件**

题面出现"用 $\vec{a}, \vec{b}$ 表示 $\vec{c}$"，或几何图形中需要把某段向量转化为已知向量的线性组合；题目含基底、菱形、正三角形、平行四边形等结构，要求用两个基向量表达其他向量；涉及三角形中的共线或特定比例分割。

**核心思路**

选定一组不共线的基底 $\{\vec{e_1}, \vec{e_2}\}$（通常是题目给出的 $\vec{a}, \vec{b}$），利用向量加减法和数乘，把目标向量沿"路径"拆分。路径拆分的关键：**找中间节点，把长路径切成可识别的短段**。

**关键步骤**

1. 确定基底：从题目中认定两个不共线的已知向量（通常显式给出）。
2. 路径拆分：$\overrightarrow{AC} = \overrightarrow{AB} + \overrightarrow{BC}$（三角形法则逐段走），或 $\overrightarrow{AC} = \overrightarrow{OC} - \overrightarrow{OA}$（同起点相减）。
3. 代入已知比例：若 $M$ 是 $AB$ 中点，则 $\overrightarrow{AM} = \dfrac{1}{2}\overrightarrow{AB}$；若 $P$ 分 $AB$ 为 $2:1$，则 $\overrightarrow{AP} = \dfrac{2}{3}\overrightarrow{AB}$。
4. 整理为 $\lambda_1\vec{e_1} + \lambda_2\vec{e_2}$ 的形式，对比系数若需要求参数则利用唯一表示定理（系数唯一）。

**示意（路径图）**

```
      B ——— M（中点）
     /       \
    A ——————— C
              |
   目标：表示 AM、CM 等
   路径：AM = AB + BM = AB + ½BC
```

**典型题**

设 $\vec{a}, \vec{b}$ 是两个不共线向量，$\overrightarrow{AB} = 2\vec{a} + \vec{b}$，$\overrightarrow{BC} = -\vec{a} + 3\vec{b}$，$M$ 为 $AC$ 中点，用 $\vec{a}, \vec{b}$ 表示 $\overrightarrow{BM}$。

> **一句话指引**：$\overrightarrow{BM} = \overrightarrow{BA} + \overrightarrow{AM} = -\overrightarrow{AB} + \dfrac{1}{2}\overrightarrow{AC}$，其中 $\overrightarrow{AC} = \overrightarrow{AB}+\overrightarrow{BC}$；代入整理得 $\overrightarrow{BM} = \dfrac{1}{2}\vec{a} + 2\vec{b}$。

**关联章节**：Part 1/04（基底坐标）、Part 2/02（三点共线与分点）

## 模型 2：数量积"三用途"

**触发条件**

题目要求求两向量（或两直线、两线段）的夹角；需要判断两向量（或两线段）是否垂直；需要求某方向上的投影长度；已知模和角反推内积，或已知内积反推角度。

**核心思路**

数量积 $\vec{a} \cdot \vec{b} = |\vec{a}||\vec{b}|\cos\theta = x_1 x_2 + y_1 y_2$ 连接几何（角度、长度）和代数（坐标乘积）两个世界。三种用法对应三种场景，选择依据：**已知坐标优先代入坐标公式；已知模和角优先用几何公式；需要判垂直直接令内积为零**。

**三用途速查**

| 用途 | 触发关键词 | 操作 |
|------|-----------|------|
| **① 求夹角** | "两向量夹角"、"角 $\theta$" | $\cos\theta = \dfrac{\vec{a}\cdot\vec{b}}{|\vec{a}||\vec{b}|}$，再用反三角函数 |
| **② 判垂直** | "互相垂直"、"成直角" | 令 $\vec{a}\cdot\vec{b}=0$，解参数 |
| **③ 求投影** | "在…方向上的分量"、"投影" | 投影 $= \dfrac{\vec{a}\cdot\vec{b}}{|\vec{a}|}$（$\vec{b}$ 在 $\vec{a}$ 上的射影，有正负） |

**关键步骤**

1. 确认向量的坐标或几何关系。
2. 计算 $\vec{a}\cdot\vec{b}$（坐标法或几何法）。
3. 选对应公式代入，注意夹角范围 $[0°, 180°]$。
4. 若结果是 $\cos\theta$ 的值，判断符号确定锐钝。

**典型题**

已知 $|\vec{a}| = 2$，$|\vec{b}| = 3$，$\vec{a} \cdot \vec{b} = -3$，求 $\vec{a}$ 与 $\vec{b}$ 的夹角。

> **一句话指引**：$\cos\theta = \dfrac{-3}{2 \times 3} = -\dfrac{1}{2}$，故 $\theta = 120°$。

**关联章节**：Part 2/01（数量积）

## 模型 3：三点共线 + 分点比

**触发条件**

题目出现"$A, B, C$ 三点共线"、"$C$ 在线段 $AB$ 上"、"$P$ 将 $\overrightarrow{AB}$ 分成 $m:n$"；涉及重心、内心等特殊点的坐标；需要证明某点在某直线上。

**核心思路**

三点共线的向量条件：$C$ 在直线 $AB$ 上 $\Leftrightarrow$ $\exists t \in \mathbb{R}$，$\overrightarrow{OC} = (1-t)\overrightarrow{OA} + t\overrightarrow{OB}$（系数之和为 $1$）。分点比公式给出坐标表达。两类问题都归结为"**找系数，用唯一性**"。

**关键公式**

$$\text{三点共线：} \overrightarrow{AC} = t\,\overrightarrow{AB} \Leftrightarrow \overrightarrow{OC} = (1-t)\overrightarrow{OA} + t\overrightarrow{OB}$$

$$\text{分点坐标（}\overrightarrow{AP}:\overrightarrow{PB} = \lambda:1\text{）：} P = \left(\frac{x_A + \lambda x_B}{1+\lambda},\; \frac{y_A + \lambda y_B}{1+\lambda}\right)$$

**关键步骤**

1. 设 $\overrightarrow{AC} = t\,\overrightarrow{AB}$（或用 $\overrightarrow{OC} = \lambda\overrightarrow{OA}+(1-\lambda)\overrightarrow{OB}$）。
2. 将目标向量用基底展开，比较两边 $\vec{e_1}, \vec{e_2}$ 系数（唯一表示定理）。
3. 解出参数 $t$（或 $\lambda$），代回得坐标或比值。
4. 若题目是坐标形式，可直接代入分点公式解方程。

**典型题**

$A(1,2)$，$B(4,5)$，$P(2,3)$，判断 $P$ 是否在线段 $AB$ 上，若在，求分点比 $\overrightarrow{AP}:\overrightarrow{PB}$。

> **一句话指引**：$\overrightarrow{AP} = (1,1)$，$\overrightarrow{AB} = (3,3)$，故 $\overrightarrow{AP} = \dfrac{1}{3}\overrightarrow{AB}$，$P$ 在线段内，比值 $= 1:2$。

**关联章节**：Part 2/02（三角形应用）、Part 1/04（坐标）

## 模型 4：直线方程选择树

**触发条件**

题目要求写出直线方程，已知条件可能是：两点、一点+斜率、一点+平行/垂直条件、截距信息，或题目含参需要讨论斜率存在性。

**核心思路**

5 种方程形式各有最优适用场景；盲目使用一种形式会导致漏解（尤其是遗漏竖直线）。选择树的判断顺序：**斜率是否存在 → 已知哪些信息 → 选最简形式**。

**选择树（决策流程）**

```
是否可能存在竖直线（x = c）？
├── 是 → 先单独讨论竖直情形，再讨论有斜率情形
└── 否 → 斜率存在
         ├── 已知斜率 k + 一点 (x₀,y₀) → 点斜式 y-y₀ = k(x-x₀)
         ├── 已知斜率 k + y 截距 b  → 斜截式 y = kx + b
         ├── 已知两点 → 两点式（或算出 k 再用点斜式）
         ├── 已知 x 截距 a + y 截距 b → 截距式 x/a + y/b = 1
         └── 通用 / 竖直线 → 一般式 Ax + By + C = 0
```

**易错场景：含参直线**

若题目说"直线过 $(1,2)$ 且与 $\cdots$ 平行"，直接设斜率 $k$ 写点斜式；但若说"直线过 $(1,2)$ 和 $(1, 5)$"，发现两点 $x$ 坐标相同，则为竖直线 $x = 1$，斜率不存在，不能套点斜式。

**关键步骤**

1. 检查题目是否可能有竖直线（$x$ 坐标是否可能相同）。
2. 按选择树确定最优形式。
3. 代入已知条件，整理化简。
4. 有参数时分类：有斜率 / 无斜率（$k$ 不存在）。

**典型题**

过点 $(2, 3)$ 且斜率为 $-1$ 的直线方程。

> **一句话指引**：已知点 + 斜率，直接点斜式：$y - 3 = -1(x-2)$，即 $x + y - 5 = 0$。

**关联章节**：Part 3/02（5 种直线方程）

## 模型 5：直线位置关系判别

**触发条件**

题目给出两直线（或一直线与坐标轴），要求判断平行 / 垂直 / 相交，或含参数时求使两直线平行 / 垂直的参数值；涉及直线系（过某点的直线族）的讨论。

**核心思路**

两种形式（斜截式、一般式）各有其判别公式；含参时要先确认两种形式是否一致，防止漏掉斜率不存在的情形。**判别平行必须同时验证非重合**。

**双判别速查**

| 形式 | 平行 | 垂直 | 重合 |
|------|------|------|------|
| 斜截式 $y=k_i x+b_i$ | $k_1=k_2, b_1 \ne b_2$ | $k_1 k_2 = -1$ | $k_1=k_2, b_1=b_2$ |
| 一般式 $A_i x+B_i y+C_i=0$ | $\dfrac{A_1}{A_2}=\dfrac{B_1}{B_2}\ne\dfrac{C_1}{C_2}$ | $A_1A_2+B_1B_2=0$ | 三比值均相等 |

**含参题目步骤**

1. 若两直线均为一般式，列比例关系方程组；先解"相等"条件，再验证"不重合"。
2. 若含参数在系数处，注意可能导致系数为 $0$（退化为平行坐标轴的特殊情形）需单独检验。
3. 最终验证：将参数代回原方程，确认结论。

**典型题**

$l_1: ax + 2y - 1 = 0$ 与 $l_2: x + (a-1)y + 1 = 0$ 平行，求 $a$。

> **一句话指引**：平行条件 $\dfrac{a}{1} = \dfrac{2}{a-1} \ne \dfrac{-1}{1}$；解 $a(a-1)=2$，即 $a^2-a-2=0$，$(a-2)(a+1)=0$，$a=2$ 或 $a=-1$；代入验证 $a=-1$ 时两直线重合（$y$ 截距相等），排除；故 $a=2$。

**关联章节**：Part 3/03（直线位置关系）

## 模型 6：距离公式速算

**触发条件**

题目要求求点到直线的距离、两平行直线之间的距离，或求某条直线与圆相切时的条件（$d = r$），或涉及三角形面积（底 × 高 / 2，其中高用点到底边的距离表达）。

**核心思路**

距离公式是"点到直线"型的标准操作；两平行线距离是其特例（用一条线上任意点代入另一条的距离公式）。**先统一直线方程为一般式 $Ax+By+C=0$，再套公式**，不要临时推导。

**公式速查**

$$\text{点 } P(x_0,y_0) \text{ 到 } Ax+By+C=0:\quad d = \frac{|Ax_0+By_0+C|}{\sqrt{A^2+B^2}}$$

$$\text{两平行线 } Ax+By+C_1=0 \text{ 与 } Ax+By+C_2=0:\quad d = \frac{|C_1-C_2|}{\sqrt{A^2+B^2}}$$

**操作陷阱与处理**

| 陷阱 | 处理方法 |
|------|----------|
| 两平行线 $A,B$ 系数不同（如 $2x+y+1=0$ 与 $4x+2y+3=0$） | 化简为 $A,B$ 相同（除以公因子）再套公式 |
| 求三角形面积时高未知 | 以底边长为已知，用点到底边距离算高 |
| 过圆外一点的切线 | 条件 $d = r$，其中 $d$ 用点到（设的）切线距离表达 |

**典型题**

点 $P(3, 1)$ 到直线 $4x - 3y + 5 = 0$ 的距离。

> **一句话指引**：$d = \dfrac{|4 \times 3 - 3 \times 1 + 5|}{\sqrt{16+9}} = \dfrac{|12-3+5|}{5} = \dfrac{14}{5}$。

**关联章节**：Part 3/04（距离）

## 模型 7：圆方程双形式

**触发条件**

题目给出圆心和半径（或等价信息）要求写圆方程；给出一般方程要求求圆心半径；需要判断某方程是否表示圆（含判别条件）；过三点求圆方程；讨论轨迹是否为圆。

**核心思路**

标准形式与一般形式互相转化；从一般形式出发必须**配方**才能读出圆心半径。判断是否为圆的关键是判别式 $D^2+E^2-4F > 0$。

**双形式对照**

| | 标准形式 | 一般形式 |
|--|---------|---------|
| 方程 | $(x-a)^2+(y-b)^2=r^2$ | $x^2+y^2+Dx+Ey+F=0$ |
| 圆心 | $(a, b)$ | $\left(-\dfrac{D}{2}, -\dfrac{E}{2}\right)$ |
| 半径 | $r$ | $r = \dfrac{\sqrt{D^2+E^2-4F}}{2}$ |
| 是圆的条件 | $r > 0$ | $D^2+E^2-4F > 0$ |
| 配方关系 | $a = -\dfrac{D}{2}$，$b = -\dfrac{E}{2}$，$r^2 = a^2+b^2-F$ | 展开标准式得 $D=-2a$，$E=-2b$，$F=a^2+b^2-r^2$ |

**关键步骤（一般式 → 标准式）**

1. 把 $x^2, x$ 项配方：$x^2+Dx = \left(x+\dfrac{D}{2}\right)^2 - \dfrac{D^2}{4}$。
2. 把 $y^2, y$ 项配方：$y^2+Ey = \left(y+\dfrac{E}{2}\right)^2 - \dfrac{E^2}{4}$。
3. 整理右端：$r^2 = \dfrac{D^2+E^2}{4} - F$，验证 $r^2 > 0$。

**典型题**

方程 $x^2+y^2-6x+4y-3=0$ 表示的圆，求圆心和半径。

> **一句话指引**：配方 $(x-3)^2+(y+2)^2=16$，圆心 $(3,-2)$，半径 $r=4$。

**关联章节**：Part 4/01（圆的方程）

## 模型 8：直线与圆"3+1"

**触发条件**

题目给出直线和圆，要求判断位置关系（相离 / 相切 / 相交）；求弦长；求切线方程；讨论直线过某点时的各种情况（含参数）；给出弦长反求直线参数。

**核心思路**

"3"是三种位置（$d > r$ / $d = r$ / $d < r$），"1"是弦长公式（$2\sqrt{r^2-d^2}$）。**圆心到直线的距离 $d$ 是核心量**，一旦求出 $d$ 就能判断位置关系并求弦长。联立求交点适合求切点坐标，但求弦长优先用几何公式，避免繁琐代数。

**操作流程**

```
直线 l，圆 C（圆心 O，半径 r）
         ↓
求圆心 O 到直线 l 的距离 d
         ↓
 d > r ——相离（无公共点）
 d = r ——相切（一个切点）
 d < r ——相交（两个交点），弦长 = 2√(r²-d²)
```

**切线方程两类**

| 类型 | 方法 |
|------|------|
| 过圆上点 $P(x_0,y_0)$ | 直接用公式：$(x_0-a)(x-a)+(y_0-b)(y-b)=r^2$ |
| 过圆外点 $Q$ | 设切线斜率 $k$（讨论竖直情形），由 $d=r$ 列方程解 $k$，注意两解 |

**典型题**

圆 $x^2+y^2=25$ 与直线 $3x-4y+m=0$ 相切，求 $m$。

> **一句话指引**：圆心 $(0,0)$ 到直线距离 $d = \dfrac{|m|}{5} = 5$，故 $|m|=25$，$m=\pm 25$。

**关联章节**：Part 4/02（直线与圆）

## 模型 9：圆与圆 5 种位置

**触发条件**

题目给出两圆（或两圆方程），要求判断位置关系；求公切线数；求公共弦方程；讨论含参时两圆位置关系的变化；已知外切 / 内切条件求参数。

**核心思路**

两圆位置完全由圆心距 $d = |C_1 C_2|$ 与半径 $r_1, r_2$（约定 $r_1 \ge r_2$）的大小关系决定。**先求两圆心坐标和半径，再算圆心距，再对号入座**。

**五种位置完整表**

| 位置 | 条件 | 公切线数 | 记忆口诀 |
|------|------|----------|----------|
| 外离 | $d > r_1 + r_2$ | 4 | "远离四切线" |
| 外切 | $d = r_1 + r_2$ | 3 | "外切三切线" |
| 相交 | $|r_1-r_2| < d < r_1+r_2$ | 2 | "相交两切线" |
| 内切 | $d = |r_1-r_2|$（$d \ne 0$） | 1 | "内切一切线" |
| 内含 | $d < |r_1-r_2|$ | 0 | "内含零切线"（含同心圆 $d=0$） |

**公共弦方程**（相交时）：两圆方程相减，消去 $x^2, y^2$ 项：

$$(D_1-D_2)x + (E_1-E_2)y + (F_1-F_2) = 0$$

**关键步骤**

1. 将两圆化为标准形式，读出圆心和半径。
2. 算圆心距 $d = \sqrt{(a_1-a_2)^2+(b_1-b_2)^2}$。
3. 计算 $r_1+r_2$ 和 $|r_1-r_2|$，与 $d$ 比较。
4. 对号入座，得出结论。

**典型题**

圆 $C_1: x^2+y^2=4$（圆心 $(0,0)$，$r_1=2$）与圆 $C_2: (x-3)^2+y^2=1$（圆心 $(3,0)$，$r_2=1$），判断位置。

> **一句话指引**：$d = 3$，$r_1+r_2 = 3$，故 $d = r_1+r_2$，两圆**外切**，公切线 3 条。

**关联章节**：Part 4/03（圆与圆）

## 模型 10：异面直线夹角"综合 vs 向量"

**触发条件**

题目给出空间两直线，要求求异面直线所成的角（或证明两直线异面）；几何体（长方体、四棱柱、正三棱锥）中求两条棱的夹角；坐标系已建立时用向量法；无坐标系时用综合法平移。

**核心思路**

异面直线夹角 $\theta \in (0°, 90°]$（取锐角或直角，不取钝角）。两种方法：综合法平移找公共起点；向量法用方向向量内积取绝对值。**建了坐标系就用向量法；没有坐标系（或坐标不方便）就用综合法找平行线**。

**两种方法对比**

| | 综合法 | 向量法 |
|--|--------|--------|
| **前提** | 不需坐标 | 已有或便于建坐标系 |
| **核心操作** | 平移一条直线使两线相交（取公共方向的向量） | 设两直线方向向量 $\vec{u}, \vec{v}$，算 $\cos\theta$ |
| **角度处理** | 两相交直线夹角取锐角（若钝角取补角） | $\cos\theta = \dfrac{|\vec{u}\cdot\vec{v}|}{|\vec{u}||\vec{v}|}$（绝对值自动取锐角） |
| **优点** | 直观，不需建坐标系 | 计算系统，不依赖几何直觉 |

**向量法关键公式**

$$\cos\theta = \frac{|\vec{u} \cdot \vec{v}|}{|\vec{u}||\vec{v}|} \quad \theta \in \left(0°, 90°\right]$$

**典型题**

正方体 $ABCD$-$A_1B_1C_1D_1$，求异面直线 $AB_1$ 与 $A_1D$ 的夹角。

> **一句话指引（向量法）**：设棱长 $1$，建系，$\vec{AB_1} = (1,0,1)$，$\vec{A_1D} = (-1,1,0)$；$\cos\theta = \dfrac{|(-1+0+0)|}{\sqrt{2}\cdot\sqrt{2}} = \dfrac{1}{2}$，故 $\theta = 60°$。

**关联章节**：Part 8/02（异面直线）

## 模型 11：线面垂直判定

**触发条件**

题目要求证明"直线 $\perp$ 平面"（或等价地"$AB \perp$ 面 $\alpha$"）；题目已知直线垂直于平面的某两条相交直线；使用坐标向量法求法向量，再判定直线是否为法向量方向；三棱锥、长方体中求高（从顶点作底面垂线）。

**核心思路**

"线面垂直判定定理"要求：**一条直线与平面内两条相交直线都垂直**，则该直线垂直于平面。这是最常用的综合法判定方式。向量法则通过法向量完成判定：线的方向向量与面的法向量平行，即线面垂直。

**综合法步骤**

```
目标：证 l ⊥ α
     ↓
在 α 内找两条相交直线 m₁, m₂
     ↓
证 l ⊥ m₁  AND  l ⊥ m₂
     ↓
由判定定理 → l ⊥ α  ✓
```

**向量法步骤**

1. 建立空间直角坐标系。
2. 求平面 $\alpha$ 的法向量 $\vec{n}$（令 $\vec{n} \cdot \vec{v_1} = 0$，$\vec{n} \cdot \vec{v_2} = 0$，$\vec{v_1}, \vec{v_2}$ 是平面内两不平行向量，解方程组）。
3. 设直线 $l$ 的方向向量 $\vec{u}$，若 $\vec{u} \parallel \vec{n}$（即 $\vec{u} = k\vec{n}$），则 $l \perp \alpha$。

**典型题**

四棱柱 $ABCD$-$A_1B_1C_1D_1$，底面 $ABCD$ 是菱形，$\angle ABC = 60°$，$AA_1 \perp$ 底面，$M$ 是 $BB_1$ 中点。证明 $A_1C \perp$ 平面 $A_1MB_1$。

> **一句话指引**：建坐标，设 $A_1$ 原点，求出 $\overrightarrow{A_1C}$；在平面 $A_1MB_1$ 内取两向量，验证 $\overrightarrow{A_1C}$ 与两者均垂直即可。

**关联章节**：Part 8/03（线面关系）

## 模型 12：二面角 3 步法

**触发条件**

题目出现"二面角 $A$-$BC$-$D$ 的大小"；需要求两平面的夹角；题目给出两平面方程（坐标系已建）要求求二面角；已知二面角的余弦值反求几何量。

**核心思路**

二面角的大小 $\in [0°, 180°]$，由两个半平面确定。**找到棱（公共边）是关键第一步**；在两半平面内各作一条垂直于棱的射线，这两条射线的夹角就是二面角的平面角。向量法更高效：求两平面的法向量，利用法向量夹角（注意补角关系）。

**3 步法（综合 / 作图）**

```
Step 1：找棱
    确认两个半平面的公共边（棱）

Step 2：作平面角
    在棱上取任一点 P（或利用棱的端点），
    在两半平面内各作 ⊥ 棱的射线 PA, PB

Step 3：计算
    ∠APB 即为二面角的平面角，
    用余弦定理或向量 PA·PB 计算
```

**向量法（坐标系已建）**

$$\cos\theta_{\text{法}} = \frac{\vec{n_1}\cdot\vec{n_2}}{|\vec{n_1}||\vec{n_2}|} \quad \text{（法向量夹角）}$$

注意：法向量夹角可能等于二面角，也可能等于其补角（$\pi - $ 二面角），需结合图形方向判断。若法向量都朝"外侧"，法向量夹角通常等于二面角的补角；须根据题意确认。

**关键步骤（向量法）**

1. 建坐标系（通常以棱的端点为原点，使棱与坐标轴对齐）。
2. 分别求两平面的法向量 $\vec{n_1}, \vec{n_2}$（各解一个 $2 \times 3$ 线性方程组）。
3. 计算 $\cos\theta = \dfrac{\vec{n_1}\cdot\vec{n_2}}{|\vec{n_1}||\vec{n_2}|}$。
4. 判断实际二面角是 $\theta$ 还是 $\pi - \theta$（结合图形中法向量指向）。

**典型题**

正三棱锥 $P$-$ABC$，底面边长为 $2$，高为 $\sqrt{2}$，求二面角 $P$-$AB$-$C$ 的大小。

> **一句话指引**：建系，求平面 $PAB$ 的法向量 $\vec{n_1}$ 和平面 $ABC$（水平面）的法向量 $\vec{n_2} = (0,0,1)$；算 $\cos\theta$，得二面角。

**关联章节**：Part 8/04（面面关系）
