## 模型 1：向量分解模型

**触发条件**

题面出现"用 $\vec{a}, \vec{b}$ 表示 $\vec{c}$"，或几何图形中需要把某段向量转化为已知向量的线性组合；题目含基底、菱形、正三角形、平行四边形等结构，要求用两个基向量表达其他向量；涉及三角形中的共线或特定比例分割。

**核心思路**

选定一组不共线的基底 $\{\vec{e_1}, \vec{e_2}\}$（通常是题目给出的 $\vec{a}, \vec{b}$），利用向量加减法和数乘，把目标向量沿"路径"拆分。路径拆分的关键：**找中间节点，把长路径切成可识别的短段**。

**关键步骤**

1. 确定基底：从题目中认定两个不共线的已知向量（通常显式给出）。
2. 路径拆分：$\overrightarrow{AC} = \overrightarrow{AB} + \overrightarrow{BC}$（三角形法则逐段走），或 $\overrightarrow{AC} = \overrightarrow{OC} - \overrightarrow{OA}$（同起点相减）。
3. 代入已知比例：若 $M$ 是 $AB$ 中点，则 $\overrightarrow{AM} = \dfrac{1}{2}\overrightarrow{AB}$；若 $P$ 分 $AB$ 为 $2:1$，则 $\overrightarrow{AP} = \dfrac{2}{3}\overrightarrow{AB}$。
4. 整理为 $\lambda_1\vec{e_1} + \lambda_2\vec{e_2}$ 的形式，对比系数若需要求参数则利用唯一表示定理（系数唯一）。

**示意（路径图）**

```
      B ——— M（中点）
     /       \
    A ——————— C
              |
   目标：表示 AM、CM 等
   路径：AM = AB + BM = AB + ½BC
```

**典型题**

设 $\vec{a}, \vec{b}$ 是两个不共线向量，$\overrightarrow{AB} = 2\vec{a} + \vec{b}$，$\overrightarrow{BC} = -\vec{a} + 3\vec{b}$，$M$ 为 $AC$ 中点，用 $\vec{a}, \vec{b}$ 表示 $\overrightarrow{BM}$。

> **一句话指引**：$\overrightarrow{BM} = \overrightarrow{BA} + \overrightarrow{AM} = -\overrightarrow{AB} + \dfrac{1}{2}\overrightarrow{AC}$，其中 $\overrightarrow{AC} = \overrightarrow{AB}+\overrightarrow{BC}$；代入整理得 $\overrightarrow{BM} = \dfrac{1}{2}\vec{a} + 2\vec{b}$。

**关联章节**：Part 1/04（基底坐标）、Part 2/02（三点共线与分点）

## 模型 2：数量积"三用途"

**触发条件**

题目要求求两向量（或两直线、两线段）的夹角；需要判断两向量（或两线段）是否垂直；需要求某方向上的投影长度；已知模和角反推内积，或已知内积反推角度。

**核心思路**

数量积 $\vec{a} \cdot \vec{b} = |\vec{a}||\vec{b}|\cos\theta = x_1 x_2 + y_1 y_2$ 连接几何（角度、长度）和代数（坐标乘积）两个世界。三种用法对应三种场景，选择依据：**已知坐标优先代入坐标公式；已知模和角优先用几何公式；需要判垂直直接令内积为零**。

**三用途速查**

| 用途 | 触发关键词 | 操作 |
|------|-----------|------|
| **① 求夹角** | "两向量夹角"、"角 $\theta$" | $\cos\theta = \dfrac{\vec{a}\cdot\vec{b}}{|\vec{a}||\vec{b}|}$，再用反三角函数 |
| **② 判垂直** | "互相垂直"、"成直角" | 令 $\vec{a}\cdot\vec{b}=0$，解参数 |
| **③ 求投影** | "在…方向上的分量"、"投影" | 投影 $= \dfrac{\vec{a}\cdot\vec{b}}{|\vec{a}|}$（$\vec{b}$ 在 $\vec{a}$ 上的射影，有正负） |

**关键步骤**

1. 确认向量的坐标或几何关系。
2. 计算 $\vec{a}\cdot\vec{b}$（坐标法或几何法）。
3. 选对应公式代入，注意夹角范围 $[0°, 180°]$。
4. 若结果是 $\cos\theta$ 的值，判断符号确定锐钝。

**典型题**

已知 $|\vec{a}| = 2$，$|\vec{b}| = 3$，$\vec{a} \cdot \vec{b} = -3$，求 $\vec{a}$ 与 $\vec{b}$ 的夹角。

> **一句话指引**：$\cos\theta = \dfrac{-3}{2 \times 3} = -\dfrac{1}{2}$，故 $\theta = 120°$。

**关联章节**：Part 2/01（数量积）

## 模型 3：三点共线 + 分点比

**触发条件**

题目出现"$A, B, C$ 三点共线"、"$C$ 在线段 $AB$ 上"、"$P$ 将 $\overrightarrow{AB}$ 分成 $m:n$"；涉及重心、内心等特殊点的坐标；需要证明某点在某直线上。

**核心思路**

三点共线的向量条件：$C$ 在直线 $AB$ 上 $\Leftrightarrow$ $\exists t \in \mathbb{R}$，$\overrightarrow{OC} = (1-t)\overrightarrow{OA} + t\overrightarrow{OB}$（系数之和为 $1$）。分点比公式给出坐标表达。两类问题都归结为"**找系数，用唯一性**"。

**关键公式**

$$\text{三点共线：} \overrightarrow{AC} = t\,\overrightarrow{AB} \Leftrightarrow \overrightarrow{OC} = (1-t)\overrightarrow{OA} + t\overrightarrow{OB}$$

$$\text{分点坐标（}\overrightarrow{AP}:\overrightarrow{PB} = \lambda:1\text{）：} P = \left(\frac{x_A + \lambda x_B}{1+\lambda},\; \frac{y_A + \lambda y_B}{1+\lambda}\right)$$

**关键步骤**

1. 设 $\overrightarrow{AC} = t\,\overrightarrow{AB}$（或用 $\overrightarrow{OC} = \lambda\overrightarrow{OA}+(1-\lambda)\overrightarrow{OB}$）。
2. 将目标向量用基底展开，比较两边 $\vec{e_1}, \vec{e_2}$ 系数（唯一表示定理）。
3. 解出参数 $t$（或 $\lambda$），代回得坐标或比值。
4. 若题目是坐标形式，可直接代入分点公式解方程。

**典型题**

$A(1,2)$，$B(4,5)$，$P(2,3)$，判断 $P$ 是否在线段 $AB$ 上，若在，求分点比 $\overrightarrow{AP}:\overrightarrow{PB}$。

> **一句话指引**：$\overrightarrow{AP} = (1,1)$，$\overrightarrow{AB} = (3,3)$，故 $\overrightarrow{AP} = \dfrac{1}{3}\overrightarrow{AB}$，$P$ 在线段内，比值 $= 1:2$。

**关联章节**：Part 2/02（三角形应用）、Part 1/04（坐标）

## 模型 4：直线方程选择树

**触发条件**

题目要求写出直线方程，已知条件可能是：两点、一点+斜率、一点+平行/垂直条件、截距信息，或题目含参需要讨论斜率存在性。

**核心思路**

5 种方程形式各有最优适用场景；盲目使用一种形式会导致漏解（尤其是遗漏竖直线）。选择树的判断顺序：**斜率是否存在 → 已知哪些信息 → 选最简形式**。

**选择树（决策流程）**

```
是否可能存在竖直线（x = c）？
├── 是 → 先单独讨论竖直情形，再讨论有斜率情形
└── 否 → 斜率存在
         ├── 已知斜率 k + 一点 (x₀,y₀) → 点斜式 y-y₀ = k(x-x₀)
         ├── 已知斜率 k + y 截距 b  → 斜截式 y = kx + b
         ├── 已知两点 → 两点式（或算出 k 再用点斜式）
         ├── 已知 x 截距 a + y 截距 b → 截距式 x/a + y/b = 1
         └── 通用 / 竖直线 → 一般式 Ax + By + C = 0
```

**易错场景：含参直线**

若题目说"直线过 $(1,2)$ 且与 $\cdots$ 平行"，直接设斜率 $k$ 写点斜式；但若说"直线过 $(1,2)$ 和 $(1, 5)$"，发现两点 $x$ 坐标相同，则为竖直线 $x = 1$，斜率不存在，不能套点斜式。

**关键步骤**

1. 检查题目是否可能有竖直线（$x$ 坐标是否可能相同）。
2. 按选择树确定最优形式。
3. 代入已知条件，整理化简。
4. 有参数时分类：有斜率 / 无斜率（$k$ 不存在）。

**典型题**

过点 $(2, 3)$ 且斜率为 $-1$ 的直线方程。

> **一句话指引**：已知点 + 斜率，直接点斜式：$y - 3 = -1(x-2)$，即 $x + y - 5 = 0$。

**关联章节**：Part 3/02（5 种直线方程）

## 模型 5：直线位置关系判别

**触发条件**

题目给出两直线（或一直线与坐标轴），要求判断平行 / 垂直 / 相交，或含参数时求使两直线平行 / 垂直的参数值；涉及直线系（过某点的直线族）的讨论。

**核心思路**

两种形式（斜截式、一般式）各有其判别公式；含参时要先确认两种形式是否一致，防止漏掉斜率不存在的情形。**判别平行必须同时验证非重合**。

**双判别速查**

| 形式 | 平行 | 垂直 | 重合 |
|------|------|------|------|
| 斜截式 $y=k_i x+b_i$ | $k_1=k_2, b_1 \ne b_2$ | $k_1 k_2 = -1$ | $k_1=k_2, b_1=b_2$ |
| 一般式 $A_i x+B_i y+C_i=0$ | $\dfrac{A_1}{A_2}=\dfrac{B_1}{B_2}\ne\dfrac{C_1}{C_2}$ | $A_1A_2+B_1B_2=0$ | 三比值均相等 |

**含参题目步骤**

1. 若两直线均为一般式，列比例关系方程组；先解"相等"条件，再验证"不重合"。
2. 若含参数在系数处，注意可能导致系数为 $0$（退化为平行坐标轴的特殊情形）需单独检验。
3. 最终验证：将参数代回原方程，确认结论。

**典型题**

$l_1: ax + 2y - 1 = 0$ 与 $l_2: x + (a-1)y + 1 = 0$ 平行，求 $a$。

> **一句话指引**：平行条件 $\dfrac{a}{1} = \dfrac{2}{a-1} \ne \dfrac{-1}{1}$；解 $a(a-1)=2$，即 $a^2-a-2=0$，$(a-2)(a+1)=0$，$a=2$ 或 $a=-1$；代入验证 $a=-1$ 时两直线重合（$y$ 截距相等），排除；故 $a=2$。

**关联章节**：Part 3/03（直线位置关系）

## 模型 6：距离公式速算

**触发条件**

题目要求求点到直线的距离、两平行直线之间的距离，或求某条直线与圆相切时的条件（$d = r$），或涉及三角形面积（底 × 高 / 2，其中高用点到底边的距离表达）。

**核心思路**

距离公式是"点到直线"型的标准操作；两平行线距离是其特例（用一条线上任意点代入另一条的距离公式）。**先统一直线方程为一般式 $Ax+By+C=0$，再套公式**，不要临时推导。

**公式速查**

$$\text{点 } P(x_0,y_0) \text{ 到 } Ax+By+C=0:\quad d = \frac{|Ax_0+By_0+C|}{\sqrt{A^2+B^2}}$$

$$\text{两平行线 } Ax+By+C_1=0 \text{ 与 } Ax+By+C_2=0:\quad d = \frac{|C_1-C_2|}{\sqrt{A^2+B^2}}$$

**操作陷阱与处理**

| 陷阱 | 处理方法 |
|------|----------|
| 两平行线 $A,B$ 系数不同（如 $2x+y+1=0$ 与 $4x+2y+3=0$） | 化简为 $A,B$ 相同（除以公因子）再套公式 |
| 求三角形面积时高未知 | 以底边长为已知，用点到底边距离算高 |
| 过圆外一点的切线 | 条件 $d = r$，其中 $d$ 用点到（设的）切线距离表达 |

**典型题**

点 $P(3, 1)$ 到直线 $4x - 3y + 5 = 0$ 的距离。

> **一句话指引**：$d = \dfrac{|4 \times 3 - 3 \times 1 + 5|}{\sqrt{16+9}} = \dfrac{|12-3+5|}{5} = \dfrac{14}{5}$。

**关联章节**：Part 3/04（距离）

## 模型 7：圆方程双形式

**触发条件**

题目给出圆心和半径（或等价信息）要求写圆方程；给出一般方程要求求圆心半径；需要判断某方程是否表示圆（含判别条件）；过三点求圆方程；讨论轨迹是否为圆。

**核心思路**

标准形式与一般形式互相转化；从一般形式出发必须**配方**才能读出圆心半径。判断是否为圆的关键是判别式 $D^2+E^2-4F > 0$。

**双形式对照**

| | 标准形式 | 一般形式 |
|--|---------|---------|
| 方程 | $(x-a)^2+(y-b)^2=r^2$ | $x^2+y^2+Dx+Ey+F=0$ |
| 圆心 | $(a, b)$ | $\left(-\dfrac{D}{2}, -\dfrac{E}{2}\right)$ |
| 半径 | $r$ | $r = \dfrac{\sqrt{D^2+E^2-4F}}{2}$ |
| 是圆的条件 | $r > 0$ | $D^2+E^2-4F > 0$ |
| 配方关系 | $a = -\dfrac{D}{2}$，$b = -\dfrac{E}{2}$，$r^2 = a^2+b^2-F$ | 展开标准式得 $D=-2a$，$E=-2b$，$F=a^2+b^2-r^2$ |

**关键步骤（一般式 → 标准式）**

1. 把 $x^2, x$ 项配方：$x^2+Dx = \left(x+\dfrac{D}{2}\right)^2 - \dfrac{D^2}{4}$。
2. 把 $y^2, y$ 项配方：$y^2+Ey = \left(y+\dfrac{E}{2}\right)^2 - \dfrac{E^2}{4}$。
3. 整理右端：$r^2 = \dfrac{D^2+E^2}{4} - F$，验证 $r^2 > 0$。

**典型题**

方程 $x^2+y^2-6x+4y-3=0$ 表示的圆，求圆心和半径。

> **一句话指引**：配方 $(x-3)^2+(y+2)^2=16$，圆心 $(3,-2)$，半径 $r=4$。

**关联章节**：Part 4/01（圆的方程）

## 模型 8：直线与圆"3+1"

**触发条件**

题目给出直线和圆，要求判断位置关系（相离 / 相切 / 相交）；求弦长；求切线方程；讨论直线过某点时的各种情况（含参数）；给出弦长反求直线参数。

**核心思路**

"3"是三种位置（$d > r$ / $d = r$ / $d < r$），"1"是弦长公式（$2\sqrt{r^2-d^2}$）。**圆心到直线的距离 $d$ 是核心量**，一旦求出 $d$ 就能判断位置关系并求弦长。联立求交点适合求切点坐标，但求弦长优先用几何公式，避免繁琐代数。

**操作流程**

```
直线 l，圆 C（圆心 O，半径 r）
         ↓
求圆心 O 到直线 l 的距离 d
         ↓
 d > r ——相离（无公共点）
 d = r ——相切（一个切点）
 d < r ——相交（两个交点），弦长 = 2√(r²-d²)
```

**切线方程两类**

| 类型 | 方法 |
|------|------|
| 过圆上点 $P(x_0,y_0)$ | 直接用公式：$(x_0-a)(x-a)+(y_0-b)(y-b)=r^2$ |
| 过圆外点 $Q$ | 设切线斜率 $k$（讨论竖直情形），由 $d=r$ 列方程解 $k$，注意两解 |

**典型题**

圆 $x^2+y^2=25$ 与直线 $3x-4y+m=0$ 相切，求 $m$。

> **一句话指引**：圆心 $(0,0)$ 到直线距离 $d = \dfrac{|m|}{5} = 5$，故 $|m|=25$，$m=\pm 25$。

**关联章节**：Part 4/02（直线与圆）

## 模型 9：圆与圆 5 种位置

**触发条件**

题目给出两圆（或两圆方程），要求判断位置关系；求公切线数；求公共弦方程；讨论含参时两圆位置关系的变化；已知外切 / 内切条件求参数。

**核心思路**

两圆位置完全由圆心距 $d = |C_1 C_2|$ 与半径 $r_1, r_2$（约定 $r_1 \ge r_2$）的大小关系决定。**先求两圆心坐标和半径，再算圆心距，再对号入座**。

**五种位置完整表**

| 位置 | 条件 | 公切线数 | 记忆口诀 |
|------|------|----------|----------|
| 外离 | $d > r_1 + r_2$ | 4 | "远离四切线" |
| 外切 | $d = r_1 + r_2$ | 3 | "外切三切线" |
| 相交 | $|r_1-r_2| < d < r_1+r_2$ | 2 | "相交两切线" |
| 内切 | $d = |r_1-r_2|$（$d \ne 0$） | 1 | "内切一切线" |
| 内含 | $d < |r_1-r_2|$ | 0 | "内含零切线"（含同心圆 $d=0$） |

**公共弦方程**（相交时）：两圆方程相减，消去 $x^2, y^2$ 项：

$$(D_1-D_2)x + (E_1-E_2)y + (F_1-F_2) = 0$$

**关键步骤**

1. 将两圆化为标准形式，读出圆心和半径。
2. 算圆心距 $d = \sqrt{(a_1-a_2)^2+(b_1-b_2)^2}$。
3. 计算 $r_1+r_2$ 和 $|r_1-r_2|$，与 $d$ 比较。
4. 对号入座，得出结论。

**典型题**

圆 $C_1: x^2+y^2=4$（圆心 $(0,0)$，$r_1=2$）与圆 $C_2: (x-3)^2+y^2=1$（圆心 $(3,0)$，$r_2=1$），判断位置。

> **一句话指引**：$d = 3$，$r_1+r_2 = 3$，故 $d = r_1+r_2$，两圆**外切**，公切线 3 条。

**关联章节**：Part 4/03（圆与圆）

## 模型 10：异面直线夹角"综合 vs 向量"

**触发条件**

题目给出空间两直线，要求求异面直线所成的角（或证明两直线异面）；几何体（长方体、四棱柱、正三棱锥）中求两条棱的夹角；坐标系已建立时用向量法；无坐标系时用综合法平移。

**核心思路**

异面直线夹角 $\theta \in (0°, 90°]$（取锐角或直角，不取钝角）。两种方法：综合法平移找公共起点；向量法用方向向量内积取绝对值。**建了坐标系就用向量法；没有坐标系（或坐标不方便）就用综合法找平行线**。

**两种方法对比**

| | 综合法 | 向量法 |
|--|--------|--------|
| **前提** | 不需坐标 | 已有或便于建坐标系 |
| **核心操作** | 平移一条直线使两线相交（取公共方向的向量） | 设两直线方向向量 $\vec{u}, \vec{v}$，算 $\cos\theta$ |
| **角度处理** | 两相交直线夹角取锐角（若钝角取补角） | $\cos\theta = \dfrac{|\vec{u}\cdot\vec{v}|}{|\vec{u}||\vec{v}|}$（绝对值自动取锐角） |
| **优点** | 直观，不需建坐标系 | 计算系统，不依赖几何直觉 |

**向量法关键公式**

$$\cos\theta = \frac{|\vec{u} \cdot \vec{v}|}{|\vec{u}||\vec{v}|} \quad \theta \in \left(0°, 90°\right]$$

**典型题**

正方体 $ABCD$-$A_1B_1C_1D_1$，求异面直线 $AB_1$ 与 $A_1D$ 的夹角。

> **一句话指引（向量法）**：设棱长 $1$，建系，$\vec{AB_1} = (1,0,1)$，$\vec{A_1D} = (-1,1,0)$；$\cos\theta = \dfrac{|(-1+0+0)|}{\sqrt{2}\cdot\sqrt{2}} = \dfrac{1}{2}$，故 $\theta = 60°$。

**关联章节**：Part 8/02（异面直线）

## 模型 11：线面垂直判定

**触发条件**

题目要求证明"直线 $\perp$ 平面"（或等价地"$AB \perp$ 面 $\alpha$"）；题目已知直线垂直于平面的某两条相交直线；使用坐标向量法求法向量，再判定直线是否为法向量方向；三棱锥、长方体中求高（从顶点作底面垂线）。

**核心思路**

"线面垂直判定定理"要求：**一条直线与平面内两条相交直线都垂直**，则该直线垂直于平面。这是最常用的综合法判定方式。向量法则通过法向量完成判定：线的方向向量与面的法向量平行，即线面垂直。

**综合法步骤**

```
目标：证 l ⊥ α
     ↓
在 α 内找两条相交直线 m₁, m₂
     ↓
证 l ⊥ m₁  AND  l ⊥ m₂
     ↓
由判定定理 → l ⊥ α  ✓
```

**向量法步骤**

1. 建立空间直角坐标系。
2. 求平面 $\alpha$ 的法向量 $\vec{n}$（令 $\vec{n} \cdot \vec{v_1} = 0$，$\vec{n} \cdot \vec{v_2} = 0$，$\vec{v_1}, \vec{v_2}$ 是平面内两不平行向量，解方程组）。
3. 设直线 $l$ 的方向向量 $\vec{u}$，若 $\vec{u} \parallel \vec{n}$（即 $\vec{u} = k\vec{n}$），则 $l \perp \alpha$。

**典型题**

四棱柱 $ABCD$-$A_1B_1C_1D_1$，底面 $ABCD$ 是菱形，$\angle ABC = 60°$，$AA_1 \perp$ 底面，$M$ 是 $BB_1$ 中点。证明 $A_1C \perp$ 平面 $A_1MB_1$。

> **一句话指引**：建坐标，设 $A_1$ 原点，求出 $\overrightarrow{A_1C}$；在平面 $A_1MB_1$ 内取两向量，验证 $\overrightarrow{A_1C}$ 与两者均垂直即可。

**关联章节**：Part 8/03（线面关系）

## 模型 12：二面角 3 步法

**触发条件**

题目出现"二面角 $A$-$BC$-$D$ 的大小"；需要求两平面的夹角；题目给出两平面方程（坐标系已建）要求求二面角；已知二面角的余弦值反求几何量。

**核心思路**

二面角的大小 $\in [0°, 180°]$，由两个半平面确定。**找到棱（公共边）是关键第一步**；在两半平面内各作一条垂直于棱的射线，这两条射线的夹角就是二面角的平面角。向量法更高效：求两平面的法向量，利用法向量夹角（注意补角关系）。

**3 步法（综合 / 作图）**

```
Step 1：找棱
    确认两个半平面的公共边（棱）

Step 2：作平面角
    在棱上取任一点 P（或利用棱的端点），
    在两半平面内各作 ⊥ 棱的射线 PA, PB

Step 3：计算
    ∠APB 即为二面角的平面角，
    用余弦定理或向量 PA·PB 计算
```

**向量法（坐标系已建）**

$$\cos\theta_{\text{法}} = \frac{\vec{n_1}\cdot\vec{n_2}}{|\vec{n_1}||\vec{n_2}|} \quad \text{（法向量夹角）}$$

注意：法向量夹角可能等于二面角，也可能等于其补角（$\pi - $ 二面角），需结合图形方向判断。若法向量都朝"外侧"，法向量夹角通常等于二面角的补角；须根据题意确认。

**关键步骤（向量法）**

1. 建坐标系（通常以棱的端点为原点，使棱与坐标轴对齐）。
2. 分别求两平面的法向量 $\vec{n_1}, \vec{n_2}$（各解一个 $2 \times 3$ 线性方程组）。
3. 计算 $\cos\theta = \dfrac{\vec{n_1}\cdot\vec{n_2}}{|\vec{n_1}||\vec{n_2}|}$。
4. 判断实际二面角是 $\theta$ 还是 $\pi - \theta$（结合图形中法向量指向）。

**典型题**

正三棱锥 $P$-$ABC$，底面边长为 $2$，高为 $\sqrt{2}$，求二面角 $P$-$AB$-$C$ 的大小。

> **一句话指引**：建系，求平面 $PAB$ 的法向量 $\vec{n_1}$ 和平面 $ABC$（水平面）的法向量 $\vec{n_2} = (0,0,1)$；算 $\cos\theta$，得二面角。

**关联章节**：Part 8/04（面面关系）

## 模型 13：椭圆七大性质

**触发条件**

题目给出椭圆方程，要求利用顶点、焦点、离心率、通径等性质；或要求求某焦半径、判断点是否在椭圆内外；或需要利用 $e$ 的范围来分析椭圆形状。

**核心思路**

椭圆的七大性质是解所有椭圆题的基础工具包。关键量之间的换算链：$a\to c\to b\to e\to$ 通径。掌握"一大三中（$a$ 最大，$b,c$ 居中）"的量级关系，并记住焦半径公式的"加减规律"（左加右减，焦点轴向外为加）。

**关键步骤**

1. 由方程读出 $a^2,b^2$，判断焦轴（大分母所在项），计算 $c^2=a^2-b^2$。
2. 写出焦点坐标、顶点坐标、离心率 $e=c/a\in(0,1)$。
3. 计算通径 $=2b^2/a$；焦半径 $|PF_1|=a+ex_0$，$|PF_2|=a-ex_0$（$x$ 轴焦轴）。
4. 判断点 $P(x_0,y_0)$ 与椭圆的关系：代入 $\dfrac{x_0^2}{a^2}+\dfrac{y_0^2}{b^2}$ 与 $1$ 比较。

**典型题**

椭圆 $\dfrac{x^2}{25}+\dfrac{y^2}{16}=1$，求焦点坐标、离心率、通径长，以及点 $P(3,\tfrac{16}{5})$ 到两焦点的距离。

> **一句话指引**：$a=5,b=4,c=3$，焦点 $(\pm3,0)$，$e=3/5$，通径 $=32/5$；$|PF_1|=5+\tfrac{3}{5}\times3=\tfrac{34}{5}$，$|PF_2|=5-\tfrac{9}{5}=\tfrac{16}{5}$，验证 $\tfrac{34}{5}+\tfrac{16}{5}=10=2a$。

**关联章节**：Part 5/01（椭圆定义方程）、Part 5/02（七大性质）

## 模型 14：椭圆中点弦点差法

**触发条件**

题目给出椭圆上弦的中点坐标（或设弦中点为 $(x_0,y_0)$），要求求弦所在直线方程；或题目给出过某特定点的弦，要求证明中点轨迹或求中点坐标。

**核心思路**

"点差法"的本质：椭圆上两点 $(x_1,y_1)$，$(x_2,y_2)$ 都满足椭圆方程，两式相减后利用中点坐标代换，直接得到斜率公式，**无需求解联立方程组**，大幅简化运算。这是椭圆题中最高频的技巧之一。

**关键步骤**

1. 设两交点均满足椭圆方程：$\dfrac{x_1^2}{a^2}+\dfrac{y_1^2}{b^2}=1$ 与 $\dfrac{x_2^2}{a^2}+\dfrac{y_2^2}{b^2}=1$。
2. 两式相减：$\dfrac{x_1^2-x_2^2}{a^2}+\dfrac{y_1^2-y_2^2}{b^2}=0$。
3. 因式分解：$\dfrac{(x_1+x_2)(x_1-x_2)}{a^2}+\dfrac{(y_1+y_2)(y_1-y_2)}{b^2}=0$。
4. 代入中点 $x_1+x_2=2x_0$，$y_1+y_2=2y_0$，整理得斜率 $k=-\dfrac{b^2x_0}{a^2y_0}$。
5. 由点斜式写出弦方程，再验证 $\Delta>0$ 确认两交点存在。

**典型题**

椭圆 $\dfrac{x^2}{4}+\dfrac{y^2}{3}=1$，以 $(1,1)$ 为中点的弦所在直线方程。

> **一句话指引**：$k=-\dfrac{3\times1}{4\times1}=-\dfrac{3}{4}$，直线 $y-1=-\dfrac{3}{4}(x-1)$，即 $3x+4y-7=0$（再验 $\Delta>0$）。

**关联章节**：Part 5/03（直线椭圆位置）、Part 5/04（中点弦）

## 模型 15：双曲线渐近线与 4 种位置

**触发条件**

题目给出双曲线和直线，要求判断位置关系（含"只有一个交点"的平行渐近线情形）；要求写出过某点且与渐近线平行的直线；涉及渐近线与直线相交点的讨论；已知双曲线和直线求交点个数。

**核心思路**

双曲线与直线的位置关系比椭圆多一种"平行渐近线单交点"的特殊情形，必须在讨论中单独列出。渐近线本身是双曲线的"极限"——点越来越靠近但永不到达；过渐近线上的点作平行渐近线的直线，恰好只与双曲线有一个交点。

**4 种位置详解**

| 位置 | 条件 | 注意 |
|------|------|------|
| 相离 | $\Delta<0$ | 无实数交点 |
| 相切 | $\Delta=0$ | 一个切点，直线斜率 $\ne\pm b/a$ |
| 两交点同支 | $\Delta>0$，韦达 $x_1x_2>0$ | 同侧 |
| 两交点异支 | $\Delta>0$，韦达 $x_1x_2<0$ | 异侧 |
| **单交点（平行渐近线）** | 直线斜率 $=\pm b/a$，联立后退化为一次方程 | $\Delta$ 失效，单独讨论 |

**关键步骤**

1. 读出双曲线参数 $a,b$，写出渐近线 $y=\pm\dfrac{b}{a}x$。
2. 若直线斜率 $k\ne\pm b/a$，代入双曲线方程得二次方程，用 $\Delta$ 和韦达定理判断。
3. 若直线斜率 $k=\pm b/a$（平行渐近线），联立得一次方程（如 $Ax=B$），解出唯一交点。

**典型题**

双曲线 $x^2-\dfrac{y^2}{4}=1$ 与直线 $y=2x-1$ 的交点个数。

> **一句话指引**：$a=1,b=2$，渐近线 $y=\pm2x$；直线斜率 $k=2=b/a$，平行渐近线，联立 $x^2-\dfrac{(2x-1)^2}{4}=1$ 化简，$x^2-x^2+x-\tfrac{1}{4}=1$，即 $x=\tfrac{5}{4}$，**只有一个交点**。

**关联章节**：Part 6/01（双曲线定义方程）、Part 6/03（直线双曲线位置）

## 模型 16：抛物线焦点弦三大性质

**触发条件**

题目给出过焦点的弦（"焦点弦"），要求求弦长；或给出弦长和与焦点距离的关系；或题目中出现 $\dfrac{1}{|AF|}+\dfrac{1}{|BF|}$ 这类调和式；或用到 $y_1y_2=-p^2$ 等焦点弦的代数性质。

**核心思路**

抛物线焦点弦的三大性质来源于焦半径公式 $|PF|=x_0+p/2$，通过韦达定理将弦端点的 $x_1,x_2$ 用焦距、斜率等参数表达。三条性质形成一个"工具包"，根据题目已知条件选用最合适的性质，常常可以绕过繁琐代数。

**三大性质快速推导**

以 $y^2=2px$ 为例，过焦点 $F(\tfrac{p}{2},0)$ 的弦两端 $A(x_1,y_1)$，$B(x_2,y_2)$：

联立直线 $x=my+\tfrac{p}{2}$（处理斜率不存在情形）代入 $y^2=2px$，得 $y^2-2pmy-p^2=0$：

$$y_1+y_2=2pm,\quad y_1y_2=-p^2$$

由 $x_i=\dfrac{y_i^2}{2p}$，得 $x_1x_2=\dfrac{y_1^2y_2^2}{4p^2}=\dfrac{p^4}{4p^2}=\dfrac{p^2}{4}$。

| 性质 | 公式 | 用途 |
|------|------|------|
| **弦长** | $|AB|=x_1+x_2+p$ | 已知斜率求弦长 |
| **调和关系** | $\dfrac{1}{|AF|}+\dfrac{1}{|BF|}=\dfrac{2}{p}$ | 含倒数和 |
| **乘积** | $x_1x_2=\dfrac{p^2}{4}$，$y_1y_2=-p^2$ | 含积的表达式 |

**典型题**

抛物线 $y^2=8x$，过焦点的弦 $|AB|=10$，求 $\dfrac{1}{|AF|}+\dfrac{1}{|BF|}$。

> **一句话指引**：$p=4$，$\dfrac{2}{p}=\dfrac{1}{2}$，故 $\dfrac{1}{|AF|}+\dfrac{1}{|BF|}=\dfrac{1}{2}$（与弦长无关，直接由调和关系性质得到！）

**关联章节**：Part 7/02（焦半径）、Part 7/03（焦点弦性质）

## 模型 17：圆锥曲线统一离心率 $e$

**触发条件**

题目给出离心率 $e$ 的范围，要求判断曲线类型；或将圆、椭圆、抛物线、双曲线统一对比分析；或题目以离心率为参数，讨论不同取值对应不同曲线。

**核心思路**

三类圆锥曲线可以用统一焦点-准线定义：到定点（焦点）距离与到定直线（准线）距离之比等于常数 $e$。$e$ 的取值范围唯一确定曲线类型，这是将分散知识点统一的"元公式"。

**统一定义与 $e$ 分类**

$$\frac{|PF|}{d(P,\text{准线})} = e$$

| $e$ 的范围 | 曲线类型 | 特征 |
|-----------|----------|------|
| $e=0$ | 圆 | 焦点即圆心，准线在无穷远 |
| $0<e<1$ | 椭圆 | 扁率随 $e$ 增大而增大 |
| $e=1$ | 抛物线 | 焦点-准线等距 |
| $e>1$ | 双曲线 | $e$ 越大，开口越大 |

**各类曲线 $e$ 公式汇总**

| 曲线 | $e$ 公式 | $e$ 范围 |
|------|---------|---------|
| 椭圆 | $e=c/a$，$c^2=a^2-b^2$ | $(0,1)$ |
| 抛物线 | $e=1$ | 固定 |
| 双曲线 | $e=c/a$，$c^2=a^2+b^2$ | $(1,+\infty)$ |
| 等轴双曲线 | $e=\sqrt{2}$（$a=b$） | 特殊值 |

**典型题**

已知圆锥曲线的离心率 $e=\dfrac{\sqrt{5}}{2}$，判断曲线类型并说明理由。

> **一句话指引**：$e=\sqrt{5}/2>1$，故为双曲线；$c/a=\sqrt{5}/2$，$c^2/a^2=5/4>1$，与 $c^2=a^2+b^2$ 一致。

**关联章节**：Part 5（椭圆）、Part 6（双曲线）、Part 7（抛物线）

## 模型 18：空间建系 4 步

**触发条件**

题目给出空间几何体（三棱锥、四棱柱、正三棱锥、长方体等），要求用向量法计算角度、距离或体积；或题目中存在明显的直角关系可以利用。

**核心思路**

"会建系就成功一半"——建系是空间向量法的关键前置步骤。正确的建系能使所有顶点坐标整数化，大幅简化后续计算；错误的建系会导致坐标分数化甚至计算错误。4 步流程确保建系准确无误。

**4 步建系流程**

```
Step 1 选原点
    优先选几何体的直角顶点（三棱两两垂直处）
    或底面中心（正三棱锥）

Step 2 定三轴
    令三条互相垂直的方向为 x,y,z 轴
    通常：长→x，宽→y，高→z
    正三棱锥：底面长→x，⊥底面→z，由右手定则确定 y

Step 3 写坐标
    逐点列出每个顶点的 (x,y,z)
    利用边长、角度关系计算具体数值

Step 4 验证
    核对：两相邻顶点距离 = 已知边长
    核对：三轴方向向量两两点积 = 0
```

**常见建系示例**

| 几何体 | 建系位置 | $z$ 轴方向 |
|--------|---------|-----------|
| 长方体 $a\times b\times h$ | 底面直角顶点 $A$ | 沿高 $h$ 向上 |
| 正三棱柱，底边 $a$，高 $h$ | 底面某顶点 | 沿侧棱向上 |
| 三棱锥（底面直角，侧高垂直底面） | 直角顶点 | 沿侧高 |

**典型题**

正三棱锥 $P$-$ABC$，底面边长 $2$，高 $\sqrt{3}$，以底面中心 $O$ 为原点建系，写出各顶点坐标。

> **一句话指引**：底面正三角形外接圆半径 $r=\tfrac{2}{\sqrt{3}}$，$A(\tfrac{2}{\sqrt{3}},0,0)$，$B(-\tfrac{1}{\sqrt{3}},1,0)$，$C(-\tfrac{1}{\sqrt{3}},-1,0)$，$P(0,0,\sqrt{3})$。

**关联章节**：Part 9/01（空间向量坐标）、Part 9/03（建系规范）

## 模型 19：法向量求法

**触发条件**

题目要求求某平面的法向量（作为后续计算二面角、点面距离的前置步骤）；或题目中需要利用法向量判断两平面的平行/垂直关系；建立坐标系后已知平面内两向量，需要垂直于两者的方向向量。

**核心思路**

法向量是空间向量法中最核心的"中间工具"——求出法向量后，二面角、线面角、点面距离全部可以直接套公式计算。求法向量的标准方法是"两个条件两个方程"，令其中一个分量为 $1$ 以减少自由度，快速解出另外两个分量。

**关键步骤**

1. 在目标平面内取两个**不平行**的向量 $\vec{v_1}=(a_1,b_1,c_1)$，$\vec{v_2}=(a_2,b_2,c_2)$（通常由平面内两条边求差得到）。
2. 设法向量 $\vec{n}=(x,y,z)$，建立方程组：
$$\begin{cases}a_1x+b_1y+c_1z=0\\a_2x+b_2y+c_2z=0\end{cases}$$
3. 令 $z=1$（若 $z$ 解方向退化，换令 $x=1$ 或 $y=1$）；
4. 解前两个未知数，写出法向量（不唯一，取最简整数形式）。
5. 验证：$\vec{n}\cdot\vec{v_1}=0$ 且 $\vec{n}\cdot\vec{v_2}=0$。

**典型题**

已知 $A(0,0,0)$，$B(2,0,0)$，$C(1,\sqrt{3},0)$，$D(1,\tfrac{\sqrt{3}}{3},\tfrac{2\sqrt{6}}{3})$，求平面 $ABD$ 的法向量。

> **一句话指引**：$\vec{AB}=(2,0,0)$，$\vec{AD}=(1,\tfrac{\sqrt{3}}{3},\tfrac{2\sqrt{6}}{3})$；设 $\vec{n}=(x,y,z)$，得 $2x=0\Rightarrow x=0$；$y+\tfrac{2\sqrt{6}}{3\cdot\tfrac{\sqrt{3}}{3}}\cdot z\cdot\tfrac{\sqrt{3}}{3}=0$，令 $z=\tfrac{\sqrt{3}}{2}$，解出 $y$，最终取整数倍化简。

**关联章节**：Part 9/03（建系）、Part 9/04（三类角）、Part 9/05（三类距离）

## 模型 20：二面角法向量法（同指 vs 异指）

**触发条件**

题目要求求二面角的大小（即两半平面所成角）；题目给出两平面的法向量，要求判断两平面位置关系；求解过程中已经得到两法向量，需判断计算所得角是二面角本身还是其补角。

**核心思路**

法向量求夹角公式 $\cos\theta=\dfrac{\vec{n_1}\cdot\vec{n_2}}{|\vec{n_1}||\vec{n_2}|}$ 给出的是两法向量的夹角，但此夹角未必等于二面角——取决于两法向量的指向是"同侧"还是"异侧"。**判断规则**：若两法向量均指向二面角内侧（或均指向外侧），则法向量夹角 $\theta$ 与二面角互补（$\angle=\pi-\theta$）；若一内一外，则 $\angle=\theta$。

**同指 vs 异指判断法（图示辅助）**

```
二面角  A-l-B  （l 为棱，A、B 为两半平面上的点）

情形 1：两法向量均"朝外"（背离二面角内部）
         二面角 = π - (法向量夹角)

情形 2：两法向量一朝内一朝外
         二面角 = 法向量夹角
```

**实用判断法**：取二面角内部任一点 $Q$，判断 $\overrightarrow{n_i}\cdot\overrightarrow{Q_i P}$ 的符号（$P$ 为法向量起点）——若乘积为负，说明法向量朝外；若为正，说明朝内。或直接估算：当计算结果 $\cos\theta<0$ 时，实际二面角可能是钝角（正确）或可能需要取 $\pi-\theta$（需图形确认）。

**典型题**

正三棱锥 $P$-$ABC$，底面边长 $2$，高 $\sqrt{2}$，求二面角 $P$-$AB$-$C$ 的余弦值。

> **一句话指引**：建坐标，求平面 $PAB$ 法向量 $\vec{n_1}$，底面 $ABC$ 法向量 $\vec{n_2}=(0,0,1)$；计算 $\cos\theta=\vec{n_1}\cdot\vec{n_2}/(|\vec{n_1}||\vec{n_2}|)$；再判断 $\vec{n_1}$ 是否指向二面角内侧（看 $C$ 点与 $\vec{n_1}$ 的关系），确定二面角是 $\theta$ 还是 $\pi-\theta$。

**关联章节**：Part 8/04（二面角定义）、Part 9/04（三类角）、Part 9/05（法向量求法）

## 模型 21：韦达定理 + 设而不求

**触发条件**

题目要求求弦中点轨迹、弦长表达式，或涉及两交点的对称关系；题目含"两点 $A,B$ 在曲线上，$P$ 为中点"类型；需要用两点之积、两点之和的表达式表达某几何量（如斜率、距离）。

**核心思路**

"设而不求"是圆锥曲线综合题的核心策略：**不必解出** $x_1,x_2$ 的具体值，只需通过韦达定理得到 $x_1+x_2$ 和 $x_1x_2$，再将题目的几何条件转化为这两个量的代数表达式，从而消去参数得到结论。这个技巧将求解二次方程的难度降至最低，且天然保持了两根的对称性。

**操作模板**

```
设直线 l: y=kx+m（或 x=ny+t）
代入曲线方程，整理为：Ax²+Bx+C=0
韦达定理：x₁+x₂=-B/A，x₁x₂=C/A
（验证 Δ=B²-4AC>0）
将条件（中点/距离/斜率等）用 x₁+x₂, x₁x₂ 表达
化简求解，得到 k 或 m 的值（或其关系）
```

**常用代换公式**

| 几何量 | 用 $x_1+x_2,x_1x_2$ 表达 |
|--------|--------------------------|
| 中点横坐标 | $x_0=\dfrac{x_1+x_2}{2}$ |
| 弦长（已知斜率 $k$） | $|AB|=\sqrt{1+k^2}\cdot\sqrt{(x_1+x_2)^2-4x_1x_2}$ |
| $(x_1-x_2)^2$ | $(x_1+x_2)^2-4x_1x_2$ |
| $y_1y_2$（设 $y_i=kx_i+m$） | $k^2x_1x_2+km(x_1+x_2)+m^2$ |

**典型题**

椭圆 $\dfrac{x^2}{2}+y^2=1$，直线 $l$ 斜率为 $1$，与椭圆交于 $A,B$ 两点，$|AB|=2$，求直线方程。

> **一句话指引**：设 $y=x+m$，代入得 $3x^2+4mx+2m^2-2=0$；韦达：$x_1+x_2=-4m/3$，$x_1x_2=(2m^2-2)/3$；弦长 $=\sqrt{2}\cdot\sqrt{(x_1+x_2)^2-4x_1x_2}=2$，代入解 $m^2=1$，$m=\pm1$。

**关联章节**：Part 10/01（综合五套路）、Part 5/04（椭圆联立）

## 模型 22：定点问题套路

**触发条件**

题目出现"证明直线 $l$ 恒过某定点"；或题目给出含参（如斜率 $k$ 或截距 $m$）的直线与曲线，要求证明存在某定点使得直线始终过该点；或题目反过来给出定点要求求直线的参数范围。

**核心思路**

定点问题的本质：直线方程含参数（如 $k$），但存在一组固定的 $(x_0,y_0)$ 使得无论参数取何值，点 $(x_0,y_0)$ 始终在直线上。**分离参数法**是标准解法：将直线方程改写为关于参数的一次式，令参数的系数和常数项均为 $0$，解出定点坐标。

**分离参数法模板**

设直线含参数 $k$：$y = f(k) \cdot x + g(k)$

改写为：$k \cdot A(x,y) + B(x,y) = 0$

这对所有 $k$ 成立 $\Leftrightarrow$ $A(x,y)=0$ 且 $B(x,y)=0$，联立解出定点 $(x_0,y_0)$。

**操作步骤**

1. 设直线方程（含斜率参数 $k$ 或其他参数）。
2. 代入椭圆/双曲线方程，用韦达定理表达中点或其他条件。
3. 将结论方程整理为 $k\cdot[\cdots]+[\cdots]=0$ 的形式。
4. 令两个括号各自为 $0$，联立解方程组得定点坐标 $(x_0,y_0)$。
5. 验证：将 $(x_0,y_0)$ 代回直线方程，确认对任意参数成立。

**典型题**

椭圆 $\dfrac{x^2}{4}+\dfrac{y^2}{3}=1$，过点 $A(1,0)$ 的直线与椭圆交于 $M,N$，$P$ 为 $MN$ 中点，证明直线 $OP$ 过定点。

> **一句话指引**：设 $MN$ 斜率为 $k$，用中点弦点差法得 $OP$ 斜率 $=-\dfrac{3}{4}\cdot\dfrac{1}{k_{MN}}$；$OP$ 过 $O(0,0)$，方程为 $y=-\dfrac{3x_0}{4y_0}\cdot x$；利用 $P$ 在线 $AM$ 上代入，化简后提取 $k$ 的系数，令为零，得定点 $(\tfrac{4}{1},0)$（具体值依椭圆而定）。

**关联章节**：Part 10/04（3 定问题）、Part 5/04（中点弦）

## 模型 23：轨迹方程 5 方法

**触发条件**

题目要求求"动点 $P$ 的轨迹方程"；动点满足某几何条件（距离之和/差、比值、角度等）；题目给出参数方程要求化为普通方程；或题目给出已知点的运动轨迹，要求求相关点的轨迹。

**核心思路**

轨迹题的本质：找到动点 $P(x,y)$ 坐标满足的**等价**代数关系。5 种方法各有适用场景，实际解题中常组合使用。关键判断：条件是否符合圆锥曲线定义（优先用定义法）；是否有参数可消去（用参数法）；是否有"相关点"代换关系（用相关点法）。

**5 种方法速查**

| 方法 | 适用场景 | 操作要点 |
|------|---------|---------|
| **① 直接法** | 条件直接给出 $x,y$ 的关系 | 整理化简即得方程 |
| **② 定义法** | 距离和/差、到焦距/准线比值 | 先判断曲线类型，直接写标准方程 |
| **③ 几何条件法** | 中点、平行、斜率乘积等 | 向量化，建坐标，列方程化简 |
| **④ 参数法** | 用参数 $t$ 表达 $x(t),y(t)$ | 消去 $t$（平方和或代入），写出 $x,y$ 关系 |
| **⑤ 相关点法** | "已知 $Q$ 的轨迹，求 $P$ 的轨迹"类型 | 设 $P(x,y)$，用 $P$ 的坐标表达 $Q$ 的坐标，代入 $Q$ 的方程 |

**注意事项**

- 求出轨迹方程后必须**说明范围**（排除不满足原始条件的点）。
- 参数法消去参数后，检查参数范围是否对 $x,y$ 有限制（如 $x>0$）。
- 相关点法中，$P$ 与 $Q$ 的关系必须是**一一对应**（有唯一性），才能得到完整轨迹。

**典型题**

$A(-2,0)$，$B(2,0)$ 为定点，动点 $P$ 满足 $|PA|+|PB|=6$，求 $P$ 的轨迹方程。

> **一句话指引**：$|PA|+|PB|=6=2a>|AB|=4$，符合椭圆定义，$a=3$，$c=2$，$b^2=5$，轨迹为 $\dfrac{x^2}{9}+\dfrac{y^2}{5}=1$（去掉使分母为零的点，但此题无退化点）。

**关联章节**：Part 10/03（轨迹方法）、Part 5/01（椭圆定义）

## 模型 24：立体几何"综合 vs 向量"切换

**触发条件**

题目涉及立体几何，需要在"综合（传统）法"与"向量（坐标）法"之间选择；或题目要求"用两种方法证明"；或解题过程中意识到当前方法进入死局，需要切换方法。

**核心思路**

两种方法各有优势，在一道题中可以混用。切换的时机判断：若当前方法陷入辅助线过多、条件不好利用的困境，立即切换另一种方法。综合法适合**逻辑推理型**（平行、垂直的传递）；向量法适合**计算型**（角度、距离的数值）。

**方法对比速查**

| 维度 | 综合法 | 向量（坐标）法 |
|------|--------|--------------|
| **核心工具** | 定理（线面/面面平行垂直判定） | 法向量、点积、向量坐标 |
| **优势** | 证明平行/垂直逻辑清晰，无需建坐标 | 计算角度/距离直接套公式，不依赖几何直觉 |
| **劣势** | 数值计算（角度、距离）繁琐 | 建坐标出错则全盘皆输；条件简单时过度工程化 |
| **主要用途** | 证明存在性、线面/面面关系 | 求线线角、线面角、二面角、点面距离、异面线距 |

**混用策略（推荐）**

```
阶段 1：综合法
    利用已知条件推导出关键垂直/平行关系
    （如：证明某线段⊥底面）

阶段 2：建坐标系
    以阶段 1 已证的垂直关系为依据，建立直角坐标系
    （垂直关系多则坐标整数多，计算简洁）

阶段 3：向量法
    求法向量、法向量夹角、点面距离等数值结果
```

**典型题**

四棱锥 $P$-$ABCD$，底面 $ABCD$ 为矩形，$PA\perp$ 底面，$PA=AB=1$，$BC=2$，求二面角 $P$-$BC$-$D$ 的余弦值。

> **一句话指引**：综合：$PA\perp$ 底面已知（无需证），建系 $A$ 为原点，$AB$ 方向 $x$，$AD$ 方向 $y$，$AP$ 方向 $z$；各点坐标为 $A(0,0,0)$，$B(1,0,0)$，$C(1,2,0)$，$D(0,2,0)$，$P(0,0,1)$；向量法求平面 $PBC$ 和平面 $DBC$ 的法向量，点积得余弦。

**关联章节**：Part 8/03（线面关系）、Part 8/04（面面关系）、Part 9/04（三类角）、Part 10/05（综合策略）
