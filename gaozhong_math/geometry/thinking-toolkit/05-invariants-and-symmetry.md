# 几何中的不变量与对称

> **一例速记**：在椭圆 $\dfrac{x^2}{4} + y^2 = 1$ 上找一点 $P$，使 $|PA| + |PB|$ 最大，其中 $A(2, 0)$、$B(-2, 0)$。
> 注意 $A$、$B$ 关于 $y$ 轴对称且都在 $x$ 轴上，椭圆关于 $y$ 轴对称——**最值点必在 $y$ 轴上**。所求点为 $(0, \pm 1)$，最大值为 $2\sqrt{5}$。
> **看到对称的图形 + 对称的条件，立刻找对称轴 / 对称中心，把问题降维到对称轴上。**

---

## 一、为什么对称是几何题的"第一直觉"

几何里有一类问题，看上去要解析、要求导、要联立方程，但只要识破图形或条件中的"对称性"，就可以省下一大半计算。这种思维不是技巧，而是几何题最底层的"直觉"。

对称性的核心思想是：**变换前后保持不变的量，叫做不变量；图形若在某变换下与自身重合，则称图形具有该变换的对称性**。一旦发现某条对称轴或对称中心，所有"求最值 / 求轨迹 / 求位置"的问题都可以利用对称在"半个图"或"对称轴上"先做，再镜像出整体答案。

本篇系统整理高中几何里的三类核心变换——**轴对称、中心对称、平移与旋转**——以及它们对应的"不变量清单"和"识别套路"。掌握这套工具后，看到正多边形、圆、椭圆、等腰三角形，你的第一反应应当是"找对称轴"。

---

## 二、三类基本变换与各自的不变量

### 2.1 轴对称（关于直线 $\ell$ 反射）

把图形按某条直线 $\ell$ 翻转，得到新的图形。如果新图形与原图形完全重合，则称图形关于 $\ell$ **轴对称**，$\ell$ 称为**对称轴**。

**不变量**：长度、角度、面积、点到对称轴的距离。

**变化量**：方向感（左右翻转）、有向角度（取反）、向量在垂直于轴方向上的分量（取反）。

**核心结论**：若 $P'$ 是 $P$ 关于 $\ell$ 的对称点，则
- $|PP'|$ 被 $\ell$ 垂直平分；
- 对于直线 $\ell$ 上任意一点 $Q$，恒有 $|PQ| = |P'Q|$。

这个"$|PQ| = |P'Q|$"是反射法（光路最短法）的根基，下一篇 07 中会专题展开。

### 2.2 中心对称（关于点 $O$ 旋转 $180°$）

把图形绕某点 $O$ 旋转 $180°$，若与自身重合，则称图形关于 $O$ **中心对称**，$O$ 称为**对称中心**。

**不变量**：长度、角度、面积、点到对称中心的距离。

**核心结论**：若 $P'$ 是 $P$ 关于 $O$ 的对称点，则
- $O$ 是 $PP'$ 的中点：$\vec{OP} = -\vec{OP'}$；
- 对应坐标公式：若 $O = (x_0, y_0)$，$P = (x, y)$，则 $P' = (2x_0 - x,\, 2y_0 - y)$。

中心对称是"图形围着中心点转半圈不变"，比轴对称更强（任何中心对称图形若想再具备轴对称，对称轴必过对称中心）。

### 2.3 平移与旋转

平移是把图形整体沿某向量 $\vec{v}$ 移动一段距离；旋转是绕某点转动一个角度。这两种变换的**不变量**完全一致：

| 变换 | 不变量 | 变化量 |
|---|---|---|
| 平移（向量 $\vec{v}$） | 长度、角度、方向、面积 | 位置（坐标加 $\vec{v}$） |
| 旋转（中心 $O$，角度 $\theta$） | 长度、角度、面积、到 $O$ 的距离 | 方向（整体转 $\theta$） |

旋转对称是某些图形的"专属"：正三角形有 $120°$ 旋转对称，正方形有 $90°$ 旋转对称，正 $n$ 边形有 $\dfrac{360°}{n}$ 旋转对称，圆有任意角度旋转对称（也称连续对称）。

## 三、常见几何图形的对称性速查表

| 图形 | 对称轴 | 对称中心 | 旋转对称 |
|---|---|---|---|
| 等腰三角形 | 顶角平分线（1 条）| 无 | 无 |
| 等边三角形 | 3 条中线（高、角平分线重合）| 无 | $120°$ |
| 矩形 | 2 条（过对边中点）| 中心点 | $180°$ |
| 菱形 | 2 条对角线 | 中心点 | $180°$ |
| 正方形 | 4 条 | 中心点 | $90°$ |
| 正 $n$ 边形（$n$ 偶）| $n$ 条 | 中心 | $\dfrac{360°}{n}$ |
| 正 $n$ 边形（$n$ 奇）| $n$ 条 | 无 | $\dfrac{360°}{n}$ |
| 圆 | 任意过圆心的直线 | 圆心 | 任意角度 |
| 椭圆 $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$ | $x$ 轴、$y$ 轴 | 原点 | 无（$a\neq b$）|
| 双曲线 $\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 1$ | $x$ 轴、$y$ 轴 | 原点 | 无 |
| 抛物线 $y^2 = 2px$ | $x$ 轴 | 无 | 无 |

**记忆口诀**：**圆万能，椭双两轴一心，抛只一轴**。

## 四、如何识别对称性

### 4.1 从图形特征识别

**等腰 / 等边 / 正多边形 / 圆 / 椭圆**——这些图形天然就有对称性，看到它们就要默念"对称轴在哪里"。

### 4.2 从条件识别

题目里若出现以下表述，必有对称：

- "$A$、$B$ 关于 $\ell$ 对称"；
- "点 $A$、$B$ 关于点 $O$ 对称"；
- "弦 $AB$ 被某直径平分"——则 $AB$ 与该直径垂直（圆的对称性）；
- "点 $P$ 在直线 $\ell$ 上"且"$A$、$B$ 与 $\ell$ 对称"——三点共线问题转化为反射。

### 4.3 从代数表达式识别

代数式或方程的对称性反映图形的对称性：

- $f(x, y) = f(-x, y)$ → 关于 $y$ 轴对称；
- $f(x, y) = f(x, -y)$ → 关于 $x$ 轴对称；
- $f(x, y) = f(-x, -y)$ → 关于原点对称；
- $f(x, y) = f(y, x)$ → 关于直线 $y = x$ 对称。

例：椭圆方程 $\dfrac{x^2}{4} + y^2 = 1$，把 $x$ 换成 $-x$ 方程不变（$y$ 轴对称）；把 $y$ 换成 $-y$ 方程也不变（$x$ 轴对称）；同时换 $x$、$y$ 的符号方程也不变（原点中心对称）。

## 五、利用对称简化的三种典型套路

### 5.1 套路 A：只算"半个图"

椭圆 / 双曲线 / 圆等具有轴对称的曲线，**所有最值 / 极值问题，可以只在第一象限（或某半平面）内研究**，再由对称推广。

例：在椭圆 $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$ 上，找离焦点 $F_1(-c, 0)$ 最远的点。由椭圆对称性，最远点必在 $x$ 轴上（即长轴端点），取 $x = a$ 时距离 $a + c$，取 $x = -a$ 时距离 $a - c$，故最远点为 $(a, 0)$。

### 5.2 套路 B：对称简并

等腰三角形中，**顶角平分线 = 底边中线 = 底边上的高 = 外接圆从顶点出发的直径所在线**——四线合一。直接利用这点，能省去"先证某线平分某角，再证某线垂直某边"的繁琐步骤。

等边三角形中**重心 = 内心 = 外心 = 垂心**——四心合一。任何一个三角形里需要找其中之一，都可以直接由"对称中心"读出。

### 5.3 套路 C：对称使最值点落到对称轴上

若问题在某变换下对称（图形 + 目标函数都对称），则最值点要么是对称轴上的点，要么是关于对称轴成对出现的点。这条规则在"求 $|PA| + |PB|$ 最大 / 最小"或"求外切 / 内切问题"中极常用。

**判据**：若 $A$、$B$ 关于某轴 $\ell$ 对称，目标函数 $f(P)$ 也关于 $\ell$ 对称，则极值点必在 $\ell$ 上（或对称分布）。

## 六、演示题

**题目**：在椭圆 $\dfrac{x^2}{4} + y^2 = 1$ 上找一点 $P$，使到 $A(2, 0)$、$B(-2, 0)$ 的距离之和 $|PA| + |PB|$ 最大。

> **Q1. 读图形和条件。**
>
> 椭圆 $\dfrac{x^2}{4} + y^2 = 1$，半长轴 $a = 2$，半短轴 $b = 1$，关于 $x$ 轴、$y$ 轴均对称。$A(2, 0) = (a, 0)$ 是右顶点，$B(-2, 0) = (-a, 0)$ 是左顶点——**两点都在椭圆的长轴上**，且关于原点（也即关于 $y$ 轴）对称。

> **Q2. 找对称。**
>
> $A$、$B$ 关于 $y$ 轴对称；椭圆也关于 $y$ 轴对称；目标函数 $f(P) = |PA| + |PB|$ 在"$P$ 沿 $y$ 轴翻折"下不变（因为 $A$、$B$ 也跟着互换，和不变）。所以**最值点必在 $y$ 轴上**或对称出现。

> **Q3. 在 $y$ 轴上找。**
>
> $y$ 轴上椭圆的点为 $(0, \pm 1)$，两点关于 $x$ 轴对称。算其中之一即可，取 $P = (0, 1)$：
>
> $$|PA| = \sqrt{(0-2)^2 + (1-0)^2} = \sqrt{4 + 1} = \sqrt{5}$$
>
> $$|PB| = \sqrt{(0+2)^2 + (1-0)^2} = \sqrt{4 + 1} = \sqrt{5}$$
>
> $$|PA| + |PB| = 2\sqrt{5}$$

> **Q4. 验证：这真的是最大吗？**
>
> 注意到 $A = (2, 0)$ 恰好是椭圆的右顶点（焦点候选）。但实际上焦点是 $F_1(-\sqrt{3}, 0)$、$F_2(\sqrt{3}, 0)$（因为 $c = \sqrt{a^2 - b^2} = \sqrt{3}$），$A$、$B$ 不是焦点。所以椭圆的"焦半径之和 $= 2a$"在这里不直接适用。
>
> 但仍可比较：当 $P$ 沿椭圆滑动时，$|PA| + |PB|$ 的值是连续变化的；由对称性，极大极小都在 $y$ 轴或 $x$ 轴上取得。验证 $x$ 轴上的点：$P = (\pm 2, 0)$，此时 $|PA| + |PB| = 0 + 4 = 4$ 或 $4 + 0 = 4$。$2\sqrt{5} \approx 4.47 > 4$。
>
> 由椭圆方程，参数化 $P = (2\cos\theta, \sin\theta)$，则
>
> $$|PA|^2 = (2\cos\theta - 2)^2 + \sin^2\theta = 4(\cos\theta - 1)^2 + \sin^2\theta$$
>
> 展开并用 $\sin^2 + \cos^2 = 1$：$= 4\cos^2\theta - 8\cos\theta + 4 + 1 - \cos^2\theta = 3\cos^2\theta - 8\cos\theta + 5$。
>
> 同理 $|PB|^2 = 3\cos^2\theta + 8\cos\theta + 5$。
>
> 设 $u = |PA|$、$v = |PB|$，则 $u^2 + v^2 = 6\cos^2\theta + 10$，$uv = \sqrt{(3\cos^2\theta + 5)^2 - 64\cos^2\theta}$，$(u + v)^2 = u^2 + v^2 + 2uv$。当 $\cos\theta = 0$（即 $P$ 在 $y$ 轴上）时，$u + v = 2\sqrt{5}$；当 $\cos\theta = \pm 1$（即 $P$ 在 $x$ 轴上）时，$u + v = 4$。函数在 $\cos\theta = 0$ 处取最大。

> **Q5. 最终答案：$|PA| + |PB|$ 的最大值为 $2\sqrt{5}$，在 $P = (0, \pm 1)$ 处取得。**

## 七、思考路标

**路标 1**：看到正多边形、圆、椭圆、双曲线、抛物线、等腰三角形——立刻在脑中标出对称轴和对称中心。这是几何题的"看图第一动作"。

**路标 2**：看到"$A$、$B$ 关于 $\ell$ 对称"这种条件，不要把它当作多余信息——它是**几乎所有距离最值题的关键**。把它和反射法（套路 C）绑定记忆。

**路标 3**：代数式 $f(x, y)$ 的对称识别：把 $x$ 换 $-x$、把 $y$ 换 $-y$、把 $x$ 和 $y$ 互换——分别对应 $y$ 轴对称、$x$ 轴对称、关于 $y = x$ 对称。看到含 $x^2$、$y^2$、$|x|$、$x^2 + y^2$ 等"偶次结构"，多半有对称。

**路标 4**：等腰三角形的"四线合一"和等边三角形的"四心合一"必须秒答。看到等腰，立即想"顶角平分线 = 中线 = 高"；看到等边，立即想"重心 = 内心 = 外心 = 垂心"。

**路标 5**：椭圆 / 双曲线题里凡是涉及"两焦点"的，**永远先想第一定义** $|PF_1| + |PF_2| = 2a$（椭圆）或 $||PF_1| - |PF_2|| = 2a$（双曲线）——这是利用对称性的最强工具。

**路标 6**：圆的对称性最强（任意过圆心的直线都是对称轴）。圆上的最值问题，往往就是"找圆心 $\to$ 投影 / 连心线"。看到圆，立刻找圆心。

**路标 7**：写解答时，"由对称性，只需考虑 $x \geq 0$（或第一象限）"是合法且常用的省力表述。但**用此句之前必须先说清楚对称轴是什么**，否则会被扣分。

## 八、典型应用例题

### 例 1：用轴对称简化距离和最小

**题目**：直线 $\ell: x - y + 1 = 0$，点 $A(0, 2)$、$B(3, -1)$ 在 $\ell$ 同侧。在 $\ell$ 上找一点 $P$ 使 $|PA| + |PB|$ 最小。

**分析**：$A$、$B$ 同侧，$P$ 在 $\ell$ 上——这是反射法的标准场景。作 $A$ 关于 $\ell$ 的对称点 $A'$，由路标 2，$|PA| = |PA'|$，故 $|PA| + |PB| = |PA'| + |PB| \geq |A'B|$。最小值就是 $|A'B|$。

求 $A'$：$A(0, 2)$ 关于 $\ell: x - y + 1 = 0$ 的对称点。法向量方向 $(1, -1)$，$A$ 到 $\ell$ 的距离为 $\dfrac{|0 - 2 + 1|}{\sqrt{2}} = \dfrac{1}{\sqrt{2}}$。$A'$ 在垂直方向上距 $A$ 为 $\dfrac{2}{\sqrt{2}} = \sqrt{2}$，对称坐标公式给出 $A' = (1, 1)$（可直接验证 $\dfrac{(0+1)}{2} - \dfrac{(2+1)}{2} + 1 = \dfrac{1}{2} - \dfrac{3}{2} + 1 = 0$ ✓，且 $A A'$ 的斜率 $= \dfrac{1 - 2}{1 - 0} = -1$ 与 $\ell$ 斜率 $1$ 垂直 ✓）。

$|A'B| = \sqrt{(3-1)^2 + (-1-1)^2} = \sqrt{4 + 4} = 2\sqrt{2}$。

**答**：$|PA| + |PB|$ 的最小值为 $2\sqrt{2}$。

---

### 例 2：等腰对称简化中线问题

**题目**：等腰三角形 $\triangle ABC$ 中 $AB = AC = 5$，$BC = 6$。求 $BC$ 边上中线的长度。

**分析**：等腰 $\triangle ABC$，$BC$ 边上的中线由路标 4 同时是 $BC$ 边上的高。设中点为 $M$，则 $AM \perp BC$，$|BM| = 3$。

在直角 $\triangle ABM$ 中：$|AM|^2 + |BM|^2 = |AB|^2$，即 $|AM|^2 + 9 = 25$，$|AM| = 4$。

**答**：中线长为 $4$。

---

### 例 3：椭圆对称推焦点弦性质

**题目**：椭圆 $\dfrac{x^2}{25} + \dfrac{y^2}{16} = 1$ 的左、右焦点为 $F_1$、$F_2$，过 $F_1$ 的弦 $AB$ 满足 $|AB| = 6$。求 $\triangle ABF_2$ 的周长。

**分析**：椭圆第一定义（路标 5）：对椭圆上任意点 $P$，$|PF_1| + |PF_2| = 2a = 10$。

对 $A$、$B$ 分别用第一定义：
- $|AF_1| + |AF_2| = 10$
- $|BF_1| + |BF_2| = 10$

两式相加：$(|AF_1| + |BF_1|) + (|AF_2| + |BF_2|) = 20$。

而 $|AF_1| + |BF_1| = |AB| = 6$（因 $A$、$B$、$F_1$ 共线，$F_1$ 在弦上）。

故 $|AF_2| + |BF_2| = 14$。

$\triangle ABF_2$ 周长 $= |AB| + |AF_2| + |BF_2| = 6 + 14 = 20 = 4a$。

**答**：周长为 $20$。

（顺带得到结论：椭圆过焦点 $F_1$ 的弦构成的 $\triangle ABF_2$，周长恒为 $4a$——对称性带来的不变量。）

## 九、自测题

**第 1 题**：在直线 $y = x$ 上找一点 $P$，使 $|PA| + |PB|$ 最小，其中 $A(2, 0)$、$B(0, 3)$。

💡 提示：$A$、$B$ 在 $y = x$ 同侧（验证：$0 - 2 = -2 < 0$、$3 - 0 = 3 > 0$，实际是异侧——这种情况下直接连 $AB$ 与 $\ell$ 交点即为 $P$，最小值 $= |AB| = \sqrt{4 + 9} = \sqrt{13}$）。若题目改为同侧，则用路标 2 的反射法。

**第 2 题**：判断曲线 $x^2 - 2xy + y^2 + 1 = 0$ 的对称性。

💡 提示：把 $x$ 与 $y$ 互换，方程变为 $y^2 - 2yx + x^2 + 1 = 0$，与原式相同——**关于 $y = x$ 对称**。把 $x \to -x$、$y \to -y$，$(-x)^2 - 2(-x)(-y) + (-y)^2 + 1 = x^2 - 2xy + y^2 + 1$ 与原式相同——**也关于原点对称**。

**第 3 题**：等边 $\triangle ABC$ 边长为 $6$，$P$ 为内一点使 $|PA| = |PB|$。证明 $P$ 在某条对称轴上，并求 $|PA| + |PB| + |PC|$ 的最小值。

💡 提示：$|PA| = |PB|$ 说明 $P$ 在 $AB$ 的中垂线上；该中垂线恰是 $\triangle ABC$ 的一条对称轴（也是 $CC$ 边上的中线）。在该对称轴上，$P$ 到 $A$、$B$ 等距，所以最小值就是"$P$ 到 $A$、$B$、$C$ 的等距和"。这是著名的费马点问题——对于内角均小于 $120°$ 的三角形，费马点处三条线段对相邻两边的夹角均为 $120°$。等边三角形的费马点 = 中心，距三顶点距离均为 $\dfrac{2}{\sqrt 3} \cdot \dfrac{a}{2} \cdot \sqrt{3}$ 之类，直接：到顶点距离 $= \dfrac{a}{\sqrt 3} = \dfrac{6}{\sqrt 3} = 2\sqrt 3$。和 $= 3 \cdot 2\sqrt 3 = 6\sqrt 3$。

**第 4 题**：双曲线 $\dfrac{x^2}{9} - \dfrac{y^2}{16} = 1$ 的左、右焦点为 $F_1$、$F_2$。$P$ 是双曲线右支上一点，且 $|PF_1| = 8$。求 $|PF_2|$。

💡 提示：双曲线第一定义 $||PF_1| - |PF_2|| = 2a = 6$；$P$ 在右支，故 $|PF_1| > |PF_2|$，$|PF_1| - |PF_2| = 6$，$|PF_2| = 2$。

**第 5 题**：在圆 $x^2 + y^2 = 4$ 上找一点 $P$ 使 $|PA|$ 最大，其中 $A(3, 4)$。

💡 提示：圆的对称性 + 路标 6——最值点必在 $OA$ 连线上。$|OA| = \sqrt{9 + 16} = 5$，$r = 2$。$P$ 在 $OA$ 延长线（远离 $A$ 那侧）与圆的交点取 $|PA|$ 最大 $= |OA| + r = 7$；$P$ 在 $OA$ 同侧靠近 $A$ 的交点取 $|PA|$ 最小 $= |OA| - r = 3$。
