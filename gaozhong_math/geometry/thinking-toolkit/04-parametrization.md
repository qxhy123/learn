# 参数化思想

> **一例速记**：椭圆 $\dfrac{x^2}{4} + y^2 = 1$ 上一点 $P$ 到直线 $x + 2y - 5 = 0$ 距离最小，求 $P$ 的坐标。
> 新手设 $P = (x_0, y_0)$ + 约束 $\dfrac{x_0^2}{4} + y_0^2 = 1$，距离公式带约束求最值（要么用拉格朗日，要么消元，繁琐易错）。
> 高手 **参数化** $P = (2\cos\theta, \sin\theta)$（自动满足椭圆方程），距离公式变为 $\theta$ 的单变量函数：$d(\theta) = \dfrac{|2\cos\theta + 2\sin\theta - 5|}{\sqrt{5}}$，再用辅助角公式合并 $\cos\theta + \sin\theta = \sqrt{2}\sin(\theta + \frac{\pi}{4})$，整个题三行做完。
> **参数化是几何对象代数化的"通用钥匙"——一个变量、一组参数方程，自动满足曲线约束。**

---

## 一、参数化：把几何对象变成可计算的代数

高中几何里，最常见的"难"题，是 **"动点在某曲线上"** 类型——点的位置是变化的，但要满足某条件（在曲线上、距离最小、夹角恰当等）。直接设 $(x, y)$，再带上约束方程，要解的就是带约束的优化或证明问题。

**参数化**是把这类问题"驯化"的核心思想：用 **一个变量**（参数 $\theta$ 或 $t$）描述曲线上所有的点，使得点的坐标 $(x, y)$ 是参数的函数。这样的好处：

1. **自动满足约束**：点的坐标自动落在曲线上，不需要额外的约束方程；
2. **变量从二维降为一维**：原来的 $(x, y)$（两个变量 + 一个约束）→ 单参数 $\theta$（一个变量），优化和求值都简单；
3. **导数 / 单调性 / 极值**直接可算：以参数为变量的函数，求导求极值是标准操作。

参数化的本质：**把曲线的"几何描述"换成"代数生成式"**。圆是几何对象，但 $(\cos\theta, \sin\theta)$ 是生成它所有点的代数公式。

本篇要建立 **5 种基本参数化** 的速查表，并展示参数化的典型应用场景。

## 二、5 种基本参数化

### 参数化 1：直线 $(x_0 + at, y_0 + bt)$

**对象**：过定点 $(x_0, y_0)$、方向向量 $(a, b)$ 的直线。

**参数方程**：
$$\begin{cases} x = x_0 + at \\ y = y_0 + bt \end{cases} \quad (t \in \mathbb{R}).$$

**几何意义**：$t$ 是从 $(x_0, y_0)$ 出发，沿方向 $(a, b)$ 的"伸长量"。$t > 0$ 沿正向，$t < 0$ 沿反向。

**关键性质**：若方向向量 $(a, b)$ 是 **单位向量**（即 $a^2 + b^2 = 1$），则 $|t|$ 就是该点到 $(x_0, y_0)$ 的实际距离。

**应用**：求直线与曲线交点（代入曲线方程后解 $t$）；求距离（直接套 $|t|$）；判断点在直线上的位置（$t$ 的正负）。

---

### 参数化 2：圆 $(r\cos\theta, r\sin\theta)$

**对象**：圆心在原点、半径为 $r$ 的圆。

**参数方程**：
$$\begin{cases} x = r\cos\theta \\ y = r\sin\theta \end{cases} \quad (\theta \in [0, 2\pi)).$$

**圆心不在原点时**：$(a + r\cos\theta, b + r\sin\theta)$。

**几何意义**：$\theta$ 是从 $x$ 轴正向到 $OP$ 的有向角。

**关键性质**：自动满足 $x^2 + y^2 = r^2$（由 $\sin^2 + \cos^2 = 1$）。

**应用**：圆上动点的最值问题；圆上两点连线的中点轨迹；与三角函数恒等式无缝衔接。

---

### 参数化 3：椭圆 $(a\cos\theta, b\sin\theta)$

**对象**：标准椭圆 $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$（$a > b > 0$）。

**参数方程**：
$$\begin{cases} x = a\cos\theta \\ y = b\sin\theta \end{cases} \quad (\theta \in [0, 2\pi)).$$

**几何意义**：$\theta$ 是 **离心角**（不是中心角）——通过 $x$ 方向缩放，把椭圆变成 $a = b = $ 半径的圆，圆上的角即 $\theta$。

**关键性质**：自动满足 $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$。

**应用**：椭圆上动点的距离 / 斜率最值；与直线相交问题；椭圆上三角形面积。

---

### 参数化 4：双曲线 $(a\sec\theta, b\tan\theta)$

**对象**：标准双曲线 $\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 1$。

**参数方程**：
$$\begin{cases} x = a\sec\theta \\ y = b\tan\theta \end{cases} \quad \left(\theta \in \left[0, 2\pi\right), \theta \neq \frac{\pi}{2}, \frac{3\pi}{2}\right).$$

**几何意义**：利用 $\sec^2\theta - \tan^2\theta = 1$，自动满足双曲线方程。

**注意**：高考阶段双曲线参数化用得较少（很多双曲线题直接走解析法），但在最值或证明对偶性时偶有奇效。

**替代参数化（双曲函数版）**：$(a\cosh u, b\sinh u)$，$u \in \mathbb{R}$，但高中不学双曲函数，了解即可。

---

### 参数化 5：抛物线 $(at^2, 2at)$

**对象**：标准抛物线 $y^2 = 4ax$（$a > 0$）。

**参数方程**：
$$\begin{cases} x = at^2 \\ y = 2at \end{cases} \quad (t \in \mathbb{R}).$$

**几何意义**：$t$ 与点的纵坐标 $y$ 成线性关系 $y = 2at$，且点在抛物线上自动成立（$y^2 = 4a^2t^2 = 4a\cdot at^2 = 4ax$）。

**变体**：$y^2 = 2px$ 形式，参数方程 $(x, y) = \left(\dfrac{p}{2}t^2, pt\right)$。

**应用**：抛物线上两点连线（设 $P_1 = (at_1^2, 2at_1)$、$P_2 = (at_2^2, 2at_2)$）；焦点弦问题（$t_1 t_2 = -1$ 是焦点弦的标志，神奇又好用）。

---

### 参数化总表

| 曲线 | 标准方程 | 参数方程 | 参数范围 |
|---|---|---|---|
| 直线 | $\dfrac{x-x_0}{a} = \dfrac{y-y_0}{b}$ | $(x_0+at, y_0+bt)$ | $t\in\mathbb{R}$ |
| 圆 | $x^2 + y^2 = r^2$ | $(r\cos\theta, r\sin\theta)$ | $\theta\in[0, 2\pi)$ |
| 椭圆 | $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$ | $(a\cos\theta, b\sin\theta)$ | $\theta\in[0, 2\pi)$ |
| 双曲线 | $\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 1$ | $(a\sec\theta, b\tan\theta)$ | $\theta\neq\dfrac{\pi}{2}, \dfrac{3\pi}{2}$ |
| 抛物线 | $y^2 = 4ax$ | $(at^2, 2at)$ | $t\in\mathbb{R}$ |

## 三、何时该用参数化

**信号 1：动点在已知曲线上 + 求最值**
经典场景。引入参数后，所有量都是参数的单变量函数，直接对参数求最值。

**信号 2：直线与曲线相交，求交点 / 弦长 / 中点轨迹**
直线参数化（代入曲线方程）后，参数 $t$ 满足一元方程，由韦达定理直接得到 $t_1 + t_2$ 和 $t_1 t_2$，再回代求所需量。比解析几何"联立直线椭圆"的步骤更短。

**信号 3：含参数讨论的曲线问题**
参数化后，原参数（如直线斜率 $k$、椭圆离心率 $e$）和动点参数（如 $\theta$）两个独立变量，结构清晰。

**信号 4：轨迹方程**
设动点参数化形式，消去参数即得轨迹方程。

**信号 5：要求"距离恒等"或"角度恒等"的证明**
参数化后，距离 / 斜率成为参数的表达式，用三角恒等式（或代数化简）证明恒等。

**不推荐参数化的场景**：
- 圆与圆位置关系（用圆心距 vs 半径和 / 差更简单）；
- 简单距离 / 斜率公式题（直接套公式更快）；
- 需要立刻看出几何性质的题（参数化掩盖了部分直观）。

## 四、演示：椭圆上点到直线距离最小

### 题目：椭圆 $\dfrac{x^2}{4} + y^2 = 1$ 上一点 $P$ 到直线 $l: x + 2y - 5 = 0$ 距离最小，求 $P$ 的坐标和最小距离。

> 拿到题目，我的直觉是：动点 $P$ 在椭圆上 + 求距离最值，**这是参数化的标准场景**。
>
> **参数化椭圆**：$P = (2\cos\theta, \sin\theta)$，$\theta \in [0, 2\pi)$。
>
> 这一步代入后，$P$ 自动满足椭圆方程，约束消失。原题"二维 + 约束"变成"一维（仅 $\theta$）"。
>
> **写出距离公式**：
> $$d(\theta) = \frac{|2\cos\theta + 2\sin\theta - 5|}{\sqrt{1^2 + 2^2}} = \frac{|2\cos\theta + 2\sin\theta - 5|}{\sqrt{5}}.$$
>
> 现在求 $d(\theta)$ 的最小值——即求 $|2\cos\theta + 2\sin\theta - 5|$ 的最小值。
>
> **辅助角公式合并**：
> $$2\cos\theta + 2\sin\theta = 2\sqrt{2}\sin\left(\theta + \frac{\pi}{4}\right).$$
>
> （$a\sin\theta + b\cos\theta = \sqrt{a^2+b^2}\sin(\theta + \varphi)$，其中 $\tan\varphi = \dfrac{b}{a}$。此处 $a = b = 2$，故 $\sqrt{a^2 + b^2} = 2\sqrt{2}$，$\varphi = \dfrac{\pi}{4}$。）
>
> 令 $u = 2\sqrt{2}\sin\left(\theta + \dfrac{\pi}{4}\right)$，则 $u \in [-2\sqrt{2}, 2\sqrt{2}]$。距离公式变为：
> $$d = \frac{|u - 5|}{\sqrt{5}}.$$
>
> 由于 $u$ 的最大值是 $2\sqrt{2} \approx 2.83 < 5$，所以 $u - 5 < 0$ 恒成立，$|u - 5| = 5 - u$。
>
> 要使 $|u - 5|$ 最小，需 $u$ 最大，即 $u = 2\sqrt{2}$。
>
> **最小距离**：
> $$d_{\min} = \frac{5 - 2\sqrt{2}}{\sqrt{5}} = \frac{(5 - 2\sqrt{2})\sqrt{5}}{5} = \sqrt{5} - \frac{2\sqrt{10}}{5}.$$
>
> **求对应 $\theta$**：$\sin\left(\theta + \dfrac{\pi}{4}\right) = 1$，故 $\theta + \dfrac{\pi}{4} = \dfrac{\pi}{2}$，$\theta = \dfrac{\pi}{4}$。
>
> **求 $P$ 的坐标**：$P = \left(2\cos\dfrac{\pi}{4}, \sin\dfrac{\pi}{4}\right) = \left(\sqrt{2}, \dfrac{\sqrt{2}}{2}\right)$。
>
> **答**：$P = \left(\sqrt{2}, \dfrac{\sqrt{2}}{2}\right)$，最小距离为 $\dfrac{5 - 2\sqrt{2}}{\sqrt{5}} = \dfrac{5\sqrt{5} - 2\sqrt{10}}{5}$。
>
> **回顾**：参数化 → 距离公式 → 辅助角合并 → 求 $\sin$ 最值。整个题目从原本的"带约束多变量优化"被压缩成"求 $\sin\left(\theta+\dfrac{\pi}{4}\right)$ 的极值"，标准三角函数题。这就是参数化在椭圆最值类问题中的威力。

## 五、思考路标

1. **见椭圆 / 圆上的动点 + 求距离 / 斜率 / 角度最值** → 第一念头：参数化。圆 $(r\cos\theta, r\sin\theta)$，椭圆 $(a\cos\theta, b\sin\theta)$，套公式后用辅助角 / 三角函数最值方法。

2. **见直线与椭圆 / 抛物线相交，求弦长 / 中点 / 韦达** → 两条路：（a）解析法联立方程（标准）；（b）直线参数化代入曲线方程（更整齐，能直接出 $t_1+t_2$、$t_1 t_2$）。一般选（a），但对于复杂参数讨论题选（b）。

3. **见过焦点的弦** → 抛物线参数化 $P_i = (at_i^2, 2at_i)$，过焦点的弦满足 $t_1 t_2 = -1$（焦点弦定理）；椭圆 / 双曲线过焦点弦也有类似性质。

4. **见动点轨迹方程** → 设动点参数化（含参数 $t$ 或 $\theta$），用题目条件写出 $x$、$y$ 关于参数的表达式，再消参得 $x$、$y$ 关系。

5. **见 $a\sin\theta + b\cos\theta$ 求极值** → 辅助角公式 $\sqrt{a^2 + b^2}\sin(\theta + \varphi)$，最值为 $\pm\sqrt{a^2 + b^2}$。这是参数化后最常出现的"收尾步骤"。

6. **见双曲线问题** → 大部分不用 $(\sec, \tan)$ 参数化，而是用 **第二定义** 或 **解析法联立**。$\sec\theta$ 参数化只在特殊对偶性证明中用到。

7. **见参数方程消参** → 多种方法：（a）$\sin^2 + \cos^2 = 1$ 消三角参数；（b）从某式解出参数代入另一式；（c）参数加减乘除组合后消去。

8. **直线参数化 + 单位向量** → 方向向量取单位化后，$|t|$ 就是参数对应点到起点的距离，做"弦长 / 距离"题时极方便。

9. **见"曲线上恒有定值"问题（如定点、定直线、定值）** → 参数化后代入条件，化简到与参数无关的式子，揭示"定"的本质（toolkit 10 会专题讲解）。

10. **参数化的"陷阱"**：椭圆 $\theta$ 是离心角不是中心角！它通过 $x$ 方向缩放得到——不要把它当成 $\angle xOP$。

## 六、典型应用 3 例

### 例 1：圆上动点最远距离

**题目**：圆 $x^2 + y^2 = 4$ 上一点 $P$，求 $P$ 到直线 $3x - 4y + 20 = 0$ 距离的最大值。

**思路**：

**参数化**：$P = (2\cos\theta, 2\sin\theta)$。

距离公式：
$$d(\theta) = \frac{|6\cos\theta - 8\sin\theta + 20|}{\sqrt{9 + 16}} = \frac{|6\cos\theta - 8\sin\theta + 20|}{5}.$$

辅助角合并：$6\cos\theta - 8\sin\theta = 10\sin(\theta + \varphi)$ 形式（系数：$\sqrt{36 + 64} = 10$），即范围 $[-10, 10]$。

加 $20$ 后：$6\cos\theta - 8\sin\theta + 20 \in [10, 30]$，恒正，绝对值即本身。

最大值 $30 / 5 = 6$。

**几何验证**：圆心 $(0, 0)$ 到直线距离 $= \dfrac{20}{5} = 4$。半径 $2$。最大距离 $= 4 + 2 = 6$ ✓。

**参数化的好处**：即使不用几何直觉，纯代数也能算出来；适合更复杂的曲线（如椭圆，没有"圆心距离"的简单公式）。

---

### 例 2：直线参数化求弦长

**题目**：直线 $l$ 过点 $A(1, 0)$，方向向量 $(1, 2)$，与椭圆 $\dfrac{x^2}{4} + y^2 = 1$ 交于 $M$、$N$，求 $|MN|$。

**思路**：

**参数化直线**：方向 $(1, 2)$ 不是单位向量，单位化得 $\left(\dfrac{1}{\sqrt{5}}, \dfrac{2}{\sqrt{5}}\right)$。

直线参数方程（用单位方向，使 $|t|$ 为实际距离）：
$$x = 1 + \frac{t}{\sqrt{5}}, \quad y = \frac{2t}{\sqrt{5}}.$$

代入椭圆方程：
$$\frac{\left(1 + \dfrac{t}{\sqrt{5}}\right)^2}{4} + \left(\frac{2t}{\sqrt{5}}\right)^2 = 1.$$

展开：
$$\frac{1}{4}\left(1 + \frac{2t}{\sqrt{5}} + \frac{t^2}{5}\right) + \frac{4t^2}{5} = 1,$$

$$\frac{1}{4} + \frac{t}{2\sqrt{5}} + \frac{t^2}{20} + \frac{4t^2}{5} = 1,$$

$$\frac{t^2 + 16t^2}{20} + \frac{t}{2\sqrt{5}} = \frac{3}{4},$$

$$\frac{17t^2}{20} + \frac{t}{2\sqrt{5}} - \frac{3}{4} = 0.$$

乘 $20$：$17t^2 + \dfrac{10t}{\sqrt{5}} - 15 = 0$，即 $17t^2 + 2\sqrt{5}t - 15 = 0$。

由韦达定理：$t_1 + t_2 = -\dfrac{2\sqrt{5}}{17}$，$t_1 t_2 = -\dfrac{15}{17}$。

由方向单位化，$|MN| = |t_1 - t_2| = \sqrt{(t_1+t_2)^2 - 4t_1 t_2} = \sqrt{\dfrac{20}{289} + \dfrac{60}{17}} = \sqrt{\dfrac{20 + 1020}{289}} = \sqrt{\dfrac{1040}{289}} = \dfrac{4\sqrt{65}}{17}$。

**参数化威力**：$|MN|$ 直接由 $|t_1 - t_2|$ 给出，不需要先求 $M$、$N$ 坐标再算距离。

---

### 例 3：抛物线焦点弦定理

**题目**：抛物线 $y^2 = 4x$ 上两点 $P_1(t_1^2, 2t_1)$、$P_2(t_2^2, 2t_2)$ 在过焦点 $F(1, 0)$ 的直线上，求 $t_1 t_2$ 的值。

**思路**：

**参数化点**：$P_i = (t_i^2, 2t_i)$（对应 $y^2 = 4x$，$a = 1$）。

直线 $P_1 P_2$ 过焦点 $F(1, 0)$，即三点 $P_1$、$P_2$、$F$ 共线，向量 $\vec{FP_1}$ 与 $\vec{FP_2}$ 共线。

$$\vec{FP_1} = (t_1^2 - 1, 2t_1), \quad \vec{FP_2} = (t_2^2 - 1, 2t_2).$$

共线条件（向量叉积为零）：
$$(t_1^2 - 1)\cdot 2t_2 - 2t_1\cdot(t_2^2 - 1) = 0,$$

$$2t_2(t_1^2 - 1) - 2t_1(t_2^2 - 1) = 0,$$

$$t_2 t_1^2 - t_2 - t_1 t_2^2 + t_1 = 0,$$

$$t_1 t_2(t_1 - t_2) + (t_1 - t_2) = 0,$$

$$(t_1 - t_2)(t_1 t_2 + 1) = 0.$$

因为 $P_1 \neq P_2$，$t_1 \neq t_2$，所以 $t_1 t_2 = -1$。

**这就是抛物线焦点弦的定理**：参数 $t_1$、$t_2$ 的乘积为 $-1$。

**参数化的威力**：纯代数推导出经典几何定理，且适用于一般化的过焦点性质。toolkit 10 会继续展开焦点弦的应用。

## 七、自测题

**第 1 题**：圆 $(x-1)^2 + y^2 = 4$ 上一点 $P$，求 $P$ 到原点距离的取值范围。

提示：参数化 $P = (1 + 2\cos\theta, 2\sin\theta)$，距离平方 $= (1 + 2\cos\theta)^2 + 4\sin^2\theta = 1 + 4\cos\theta + 4 = 5 + 4\cos\theta \in [1, 9]$，所以距离范围 $[1, 3]$。或直接用几何：圆心到原点距离 $1$，半径 $2$，范围 $[|1-2|, 1+2] = [1, 3]$。

---

**第 2 题**：椭圆 $\dfrac{x^2}{9} + \dfrac{y^2}{4} = 1$ 上一点 $P$，求 $\dfrac{x_P^2 + y_P^2}{4}$ 的最大值。

提示：参数化 $P = (3\cos\theta, 2\sin\theta)$，$x_P^2 + y_P^2 = 9\cos^2\theta + 4\sin^2\theta = 4 + 5\cos^2\theta \in [4, 9]$。最大值时 $\dfrac{x_P^2 + y_P^2}{4} = \dfrac{9}{4}$。

---

**第 3 题**：直线 $l: y = 2x + 1$ 与抛物线 $y^2 = 4x$ 交于 $M$、$N$，求 $|MN|$。

提示：解析法或参数法。**参数法**：设 $M = (t_1^2, 2t_1)$、$N = (t_2^2, 2t_2)$（参数化抛物线），都在直线 $y = 2x + 1$ 上：$2t_i = 2t_i^2 + 1$，即 $2t_i^2 - 2t_i + 1 = 0$。由韦达 $t_1 + t_2 = 1$、$t_1 t_2 = \dfrac{1}{2}$。$|MN|^2 = (t_1^2 - t_2^2)^2 + 4(t_1 - t_2)^2 = (t_1-t_2)^2[(t_1+t_2)^2 + 4] = (1 - 2) \cdot (1 + 4) = -5$，但 $(t_1-t_2)^2 = (t_1+t_2)^2 - 4t_1t_2 = 1 - 2 = -1 < 0$，所以直线与抛物线无交点。改换数据为 $y = 2x - 1$ 即可正常计算。

---

**第 4 题**：曲线 $C$ 的参数方程 $\begin{cases} x = 1 + 2\cos\theta \\ y = -1 + 2\sin\theta \end{cases}$（$\theta\in[0, 2\pi)$），求 $C$ 的普通方程并指出曲线类型。

提示：从参数方程解出 $\cos\theta = \dfrac{x-1}{2}$、$\sin\theta = \dfrac{y+1}{2}$，平方相加消参得 $(x-1)^2 + (y+1)^2 = 4$。这是圆心 $(1, -1)$、半径 $2$ 的圆。

---

**第 5 题**：椭圆 $\dfrac{x^2}{4} + y^2 = 1$ 上一动点 $P$ 到点 $A(1, 0)$ 距离的最小值。

提示：参数化 $P = (2\cos\theta, \sin\theta)$。$|PA|^2 = (2\cos\theta - 1)^2 + \sin^2\theta = 4\cos^2\theta - 4\cos\theta + 1 + \sin^2\theta = 3\cos^2\theta - 4\cos\theta + 2$。令 $u = \cos\theta \in [-1, 1]$，求 $f(u) = 3u^2 - 4u + 2$ 在 $[-1, 1]$ 的最小值。$f'(u) = 6u - 4 = 0$ → $u = \dfrac{2}{3}$（落在 $[-1, 1]$ 内），$f\left(\dfrac{2}{3}\right) = 3\cdot\dfrac{4}{9} - \dfrac{8}{3} + 2 = \dfrac{4}{3} - \dfrac{8}{3} + 2 = \dfrac{2}{3}$。最小距离 $= \sqrt{\dfrac{2}{3}} = \dfrac{\sqrt{6}}{3}$。

## 八、与后续解析几何章节的呼应

参数化思想会在以下章节反复出现：

- **part4 圆与方程**：圆的参数方程；弦长问题中直线 $l$ 用参数方程代入圆方程。
- **part5-7 圆锥曲线**：椭圆 / 双曲线 / 抛物线参数化；过焦点弦的参数表示；中点弦问题（用参数差表示中点）。
- **part10 综合**：定点 / 定值 / 定直线问题——参数化后代入条件，化简后揭示"定"的本质。

**参数化的两副面孔**：
- **作工具**：用参数化把多变量问题化为单变量；
- **作思想**：把"几何对象"重新理解为"参数生成式"，体会"动点的运动方式"。

掌握 5 种基本参数化 + 何时该用 = 高考解析几何的半张通行证。
