# 辅助线思维

> **一例速记**：在四边形 $ABCD$ 中证 $AC^2 + BD^2 = AB^2 + BC^2 + CD^2 + DA^2 - 4MN^2$（其中 $M$、$N$ 分别是 $AC$、$BD$ 的中点）。
> 看到"中点"，立刻想到 **作中位线 / 连中点**；看到"两对角线"，立刻想到 **平移凑平行四边形**。
> 作辅助线 $MN$，再用中线长公式（$\triangle$ 中线公式）+ 平行四边形对角线公式联立——题目就迎刃而解。
> **辅助线是几何的"开门钥匙"——见到某种特征图形，立刻条件反射地想到对应的辅助线。**

---

## 一、辅助线：几何思维的扳手

初中几何已经接触过常见的辅助线：连线、延长、作平行 / 垂直、过点作高等。进入高中，图形更复杂、定理更繁多，辅助线的运用也变得更系统化。

辅助线的本质是 **"补图"**：原图缺少某个特征（比如缺一条边、缺一个直角、缺一个等腰三角形），我们人为加上它，让题目原本看不见的关系显形。

高手与新手的差距，在辅助线这件事上特别悬殊。新手盯着原图发呆，想不出突破口；高手见到"两个中点"立刻连成中位线，见到"梯形"立刻平移腰，见到"角平分线"立刻截取等长。

**这种"见 X 想 Y"的条件反射，是本篇要训练的核心能力。**

辅助线的三层思考：
1. **触发**：图形中的哪个特征触发了哪条辅助线？
2. **构造**：辅助线如何添加（连 / 延 / 平 / 垂 / 截）？
3. **效果**：辅助线添加后，激活了哪个定理 / 公式 / 性质？

## 二、10 种典型辅助线

| 编号 | 名称 | 触发信号 | 添加方式 | 激活的工具 |
|---|---|---|---|---|
| 1 | **延长 / 倍长** | 见线段中点 | 延长中线一倍至点 $E$，使 $DE = AD$ | 构造平行四边形 → 用对边相等 |
| 2 | **截取** | 见角平分线 / 等角 | 在长边上截取与短边等长 | 构造全等三角形 |
| 3 | **平移** | 见梯形 / 含平行线 | 过顶点平移腰 / 对角线 | 凑出平行四边形 / 三角形 |
| 4 | **旋转** | 见正三角形 / 正方形 / 等腰直角 | 把一段绕特殊点旋转 $60°$ / $90°$ | 构造全等 / 共线 |
| 5 | **中位线** | 见两中点 | 连两中点 | 中位线定理（平行 + 长度一半） |
| 6 | **对称** | 见角 / 镜面问题 | 关于角平分线作对称点 | 把折线变直线（最短路径） |
| 7 | **作高 / 垂线** | 见斜边 / 求面积 / 求距离 | 过点向对边作垂线 | 直角三角形 / 投影 |
| 8 | **连圆心** | 见圆中弦 / 切线 | 连圆心到弦中点 / 切点 | 垂径定理 / 切线垂直半径 |
| 9 | **延切线 / 割线** | 见圆外点 | 过点作切线 / 割线 | 切线长定理 / 圆幂定理 |
| 10 | **作平行线 / 投影** | 见相似 / 比例 / 立体几何 | 过点作已知方向的平行线 | 相似三角形 / 截距 / 共面 |

### 三种"高级"辅助线（高中独有）

**辅 11：作切线 / 切点弦**（圆与圆锥曲线综合）——见圆外点到圆有切线问题，连切点 + 圆心 + 外点形成直角三角形。

**辅 12：作准线 / 焦点弦**（圆锥曲线）——见椭圆 / 双曲线 / 抛物线问题，连焦点 + 准线 + 弦的端点投影，利用第二定义 $\dfrac{r}{d} = e$。

**辅 13：建系（隐式辅助线）**（解析几何）——为复杂图形建立坐标系，本质是把"几何辅助"换成"代数辅助"。toolkit 01 提到过：综合法卡住 → 切换到解析 / 向量。

| 正方形 | 旋转 $90°$ / 连对角线 | 等距旋转 / 直角等腰 |

## 四、演示：四边形中线公式

### 题目：在四边形 $ABCD$ 中，证明 $AC^2 + BD^2 = AB^2 + BC^2 + CD^2 + DA^2 - 4MN^2$，其中 $M$、$N$ 分别是对角线 $AC$、$BD$ 的中点。

> 拿到这道题，左边是两条对角线的平方和，右边是四条边的平方和减去 $4MN^2$。$M$、$N$ 是对角线中点——这是关键线索。
>
> 我立刻问：**"中点"信号 → 联想什么辅助线？** —— 中位线（辅 5）、倍长中线（辅 1）。
>
> 我先用 **向量法**试一下（高中阶段处理"距离平方"最优雅的工具）。
>
> 设 $\vec{a} = \vec{OA}$、$\vec{b} = \vec{OB}$、$\vec{c} = \vec{OC}$、$\vec{d} = \vec{OD}$（$O$ 为任意原点）。
>
> 对角线中点的位置向量：
> $$\vec{OM} = \frac{1}{2}(\vec{a} + \vec{c}), \quad \vec{ON} = \frac{1}{2}(\vec{b} + \vec{d}).$$
>
> 计算 $|MN|^2$：
> $$\vec{MN} = \vec{ON} - \vec{OM} = \frac{1}{2}[(\vec{b} + \vec{d}) - (\vec{a} + \vec{c})] = \frac{1}{2}(\vec{b} - \vec{a} + \vec{d} - \vec{c}).$$
>
> $$|MN|^2 = \frac{1}{4}|\vec{b} - \vec{a} + \vec{d} - \vec{c}|^2.$$
>
> 看着复杂，先放着。同时计算两条对角线：
> $$|AC|^2 = |\vec{c} - \vec{a}|^2, \quad |BD|^2 = |\vec{d} - \vec{b}|^2,$$
>
> 四条边：
> $$|AB|^2 = |\vec{b}-\vec{a}|^2, \quad |BC|^2 = |\vec{c}-\vec{b}|^2, \quad |CD|^2 = |\vec{d}-\vec{c}|^2, \quad |DA|^2 = |\vec{a}-\vec{d}|^2.$$
>
> 把四条边平方和展开：
> $$\sum (\text{边})^2 = 2|\vec{a}|^2 + 2|\vec{b}|^2 + 2|\vec{c}|^2 + 2|\vec{d}|^2 - 2(\vec{a}\cdot\vec{b}+\vec{b}\cdot\vec{c}+\vec{c}\cdot\vec{d}+\vec{d}\cdot\vec{a}).$$
>
> 两条对角线平方和：
> $$|AC|^2 + |BD|^2 = |\vec{a}|^2 + |\vec{c}|^2 - 2\vec{a}\cdot\vec{c} + |\vec{b}|^2 + |\vec{d}|^2 - 2\vec{b}\cdot\vec{d}.$$
>
> 计算 $4|MN|^2$：
> $$4|MN|^2 = |\vec{b}-\vec{a}+\vec{d}-\vec{c}|^2 = |(\vec{b}+\vec{d}) - (\vec{a}+\vec{c})|^2.$$
>
> 展开：
> $$= |\vec{b}+\vec{d}|^2 - 2(\vec{a}+\vec{c})\cdot(\vec{b}+\vec{d}) + |\vec{a}+\vec{c}|^2.$$
>
> 把所有平方和、点积代入，比对系数。最后整理得：
> $$AB^2 + BC^2 + CD^2 + DA^2 - 4MN^2 = AC^2 + BD^2.$$
>
> 证毕。$\square$
>
> **回顾**：这道题的关键辅助线是 **"连中点 $M$、$N$"**（辅 5 中位线思想的推广）。看到对角线中点，立刻想到设位置向量 → 中点公式 → 向量平方展开。向量法把"添辅助线"的几何工作变成了"加一个向量"的代数工作，效果一致。

## 五、思考路标

1. **见线段中点** → 三条路：（a）倍长中线（辅 1），延长至原长的两倍构造平行四边形；（b）连另一中点形成中位线（辅 5）；（c）向量法设位置向量取中点 $= \dfrac{1}{2}(\vec{a}+\vec{b})$。

2. **见角平分线** → 在长边上截取与短边等长（辅 2），构造全等三角形。或者作角平分线为轴的对称，把图形折叠（辅 6）。

3. **见梯形** → 平移腰（辅 3）：过短边端点作另一腰的平行线，把梯形拆为平行四边形 + 三角形。或平移对角线：过一顶点作另一对角线的平行线，凑出三角形。

4. **见两条平行线 / 两条相等线段** → 平移（辅 3）。平移后通常能凑出平行四边形或全等三角形。

5. **见正三角形 / 正方形 / 等腰直角三角形** → 旋转（辅 4）。正三角形绕顶点转 $60°$ 能"自映射"；正方形转 $90°$；等腰直角转 $90°$。利用旋转的等距性证明线段相等。

6. **见圆中弦** → 连圆心到弦中点（辅 8），激活垂径定理：$r^2 = d^2 + (\text{半弦})^2$，其中 $d$ 是圆心到弦的距离。

7. **见圆的切线** → 连切点和圆心（辅 8），激活"切线垂直半径"。圆外一点 $P$ 引切线，连切点 $T$ 和圆心 $O$，$\triangle PTO$ 是直角三角形（$\angle OTP = 90°$）。

8. **见立体几何二面角** → 在棱上取一点 $P$，分别在两个半平面内作棱的垂线（辅 14 高级版）。二面角的平面角 = 这两条垂线的夹角。或用向量法的法向量夹角，更机械化（toolkit 11）。

9. **见三角形求面积** → 作高（辅 7），底高公式 $S = \dfrac{1}{2}ah$；或用三角法 $S = \dfrac{1}{2}ab\sin C$；或用海伦公式 $S = \sqrt{s(s-a)(s-b)(s-c)}$（$s$ 半周长）。

10. **见对称问题（如反射、最短路径）** → 作对称（辅 6）：关于轴作对称点，把折线变成直线，"将军饮马"问题的核心。

## 六、典型应用 3 例

### 例 1：倍长中线证三角形不等式

**题目**：在 $\triangle ABC$ 中，$AD$ 是 $BC$ 边上的中线，证明 $AD < \dfrac{1}{2}(AB + AC)$。

**思路**：

**辅助线**：延长 $AD$ 至 $E$，使 $DE = AD$（倍长中线，辅 1）。连接 $BE$。

由 $D$ 是 $BC$ 中点、$DE = AD$，知 $BDCE$ 是平行四边形（对角线互相平分），故 $BE = AC$、$BE \parallel AC$。

在 $\triangle ABE$ 中，由三角形两边之和大于第三边：
$$AE < AB + BE = AB + AC.$$

而 $AE = 2AD$，故 $2AD < AB + AC$，即 $AD < \dfrac{1}{2}(AB + AC)$。$\square$

**辅助线效果**：倍长中线 → 凑平行四边形 → 把 $AD$ 的"半身"变成 $AE$ 的"全身"，可以直接套三角不等式。

---

### 例 2：作圆心 + 垂径定理求弦长

**题目**：圆 $O: x^2 + y^2 = 25$，直线 $l: 3x + 4y - 10 = 0$ 与圆相交于 $A$、$B$，求 $|AB|$。

**思路**：

**辅助线**：从圆心 $O(0, 0)$ 向直线 $l$ 作垂线，垂足为 $H$（辅 7 + 辅 8）。

圆心到直线的距离：
$$d = \frac{|3\cdot 0 + 4\cdot 0 - 10|}{\sqrt{3^2 + 4^2}} = \frac{10}{5} = 2.$$

半径 $r = 5$。由垂径定理，$H$ 是弦 $AB$ 的中点，且 $OH \perp AB$。在直角 $\triangle OHA$ 中：
$$|HA|^2 = r^2 - d^2 = 25 - 4 = 21,$$
故 $|HA| = \sqrt{21}$，$|AB| = 2|HA| = 2\sqrt{21}$。

**辅助线效果**：作 $OH \perp AB$ → 直角三角形 → 勾股直接出答案。这是直线圆位置关系的固定套路，**任何弦长问题都走这条路**。

---

### 例 3：作高 + 平移构造对称——将军饮马（高中复习版）

**题目**：点 $A(1, 3)$、$B(4, 2)$，在 $x$ 轴上找点 $P$，使 $|PA| + |PB|$ 最小，求 $P$ 的坐标。

**思路**：

**辅助线**：作 $A$ 关于 $x$ 轴的对称点 $A'(1, -3)$（辅 6 对称）。

连 $A'B$ 与 $x$ 轴的交点即为最小化的 $P$（折线 $A \to P \to B$ 等长于折线 $A' \to P \to B$，且 $A'$、$P$、$B$ 共线时长度最短）。

直线 $A'B$ 的方程：过 $(1, -3)$ 和 $(4, 2)$，斜率 $k = \dfrac{2 - (-3)}{4 - 1} = \dfrac{5}{3}$，
$$y - 2 = \frac{5}{3}(x - 4), \quad y = \frac{5}{3}x - \frac{14}{3}.$$

令 $y = 0$：$0 = \dfrac{5}{3}x - \dfrac{14}{3}$，$x = \dfrac{14}{5}$。

故 $P\left(\dfrac{14}{5}, 0\right)$。

**辅助线效果**：作对称点 → 把"折线长"问题变为"直线长"问题。这是几何"最短路径"的标志性套路。

## 七、自测题

**第 1 题**：在 $\triangle ABC$ 中，$AB = AC$，$D$ 是底边 $BC$ 上一点。证明：$AD^2 = AB^2 - BD\cdot DC$。

提示：辅助线作底边上的高 $AE$（辅 7）。利用等腰三角形三线合一（$E$ 是 $BC$ 中点），$BD\cdot DC = BD\cdot DC$，结合勾股 $AD^2 = AE^2 + DE^2 = AB^2 - BE^2 + (BE - BD)^2$，展开化简。

---

**第 2 题**：在梯形 $ABCD$ 中，$AB \parallel CD$，$AB = 6$，$CD = 4$，对角线 $AC \perp BD$，求梯形高 $h$ 与 $AC^2 + BD^2$ 的关系。

提示：辅 3 平移对角线：过 $A$ 作 $AE \parallel BD$ 交 $CD$ 延长线于 $E$。则 $ABDE$ 是平行四边形，$AE = BD$，$DE = AB = 6$。$\triangle ACE$ 中 $\angle CAE = 90°$（因 $AC \perp BD$ 且 $AE \parallel BD$），所以 $AC^2 + AE^2 = CE^2 = (4+6)^2 = 100$。即 $AC^2 + BD^2 = 100$。

---

**第 3 题**：圆 $x^2 + y^2 - 4x - 2y + 1 = 0$ 上一点到原点距离最大值是多少？

提示：先把圆化为标准形 $(x-2)^2 + (y-1)^2 = 4$，圆心 $C(2, 1)$、半径 $r = 2$。**辅助线**：连圆心与原点（辅 8 的变体）。$|OC| = \sqrt{4+1} = \sqrt{5}$，最大距离 $= |OC| + r = \sqrt{5} + 2$。

---

**第 4 题**：正方形 $ABCD$ 中，$E$ 在 $BC$ 上，$F$ 在 $CD$ 上，$AE \perp AF$。证明 $BE + DF = EF$（提示：旋转法）。

提示：辅 4 旋转。把 $\triangle ABE$ 绕 $A$ 旋转 $90°$，使 $AB$ 转到 $AD$ 位置，$B$ 转到 $D$，$E$ 转到点 $E'$（$DE' = BE$）。由 $AE \perp AF$ 与旋转角 $90°$ 配合，$A$、$E'$、$F$ 共线，故 $E'F = E'D + DF = BE + DF$，又 $AE' = AE$，$\angle E'AF = \angle EAF$（实际上 $E'$、$A$、$E$ 共构成直角），结合全等 $\triangle AEF \cong \triangle AE'F$ 得 $EF = E'F = BE + DF$。

---

**第 5 题**：在三棱锥 $P\text{-}ABC$ 中，$PA \perp$ 底面 $ABC$，$\triangle ABC$ 为正三角形，$PA = AB = 2$。求二面角 $P\text{-}BC\text{-}A$ 的大小。

提示：辅助线先取 $BC$ 中点 $D$，连 $AD$、$PD$（辅 7 + 二面角的平面角定义）。由 $\triangle ABC$ 正三角形，$AD \perp BC$；由 $PA \perp$ 底面，$PD$ 在底面的投影是 $AD$，故 $PD \perp BC$（三垂线定理）。所以 $\angle PDA$ 是二面角 $P\text{-}BC\text{-}A$ 的平面角。$AD = \sqrt{3}$（正三角形边长 $2$ 的高），$\tan\angle PDA = \dfrac{PA}{AD} = \dfrac{2}{\sqrt{3}} = \dfrac{2\sqrt{3}}{3}$。
