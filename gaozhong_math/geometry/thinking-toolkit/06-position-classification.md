# 位置关系的分类讨论框架

> **一例速记**：讨论直线 $y = kx + 1$ 与圆 $x^2 + y^2 - 4x + 3 = 0$ 的位置关系。
> 圆心 $(2, 0)$，半径 $1$。圆心到直线距离 $d = \dfrac{|2k - 0 + 1|}{\sqrt{k^2 + 1}} = \dfrac{|2k + 1|}{\sqrt{k^2 + 1}}$。
> 比较 $d$ 与 $r = 1$：$d < 1$ 相交，$d = 1$ 相切，$d > 1$ 相离。
> **"$d$ vs $r$" 是直线与圆位置关系的速答工具——看到这类题，立刻摆距离公式。**

---

## 一、位置关系题的共同结构

高中几何里，"位置关系"题占了相当大的篇幅：

- 两条直线的位置关系（平行 / 相交 / 重合 / 垂直）；
- 直线与圆的位置关系（相离 / 相切 / 相交）；
- 圆与圆的位置关系（外离 / 外切 / 相交 / 内切 / 内含）；
- 直线与圆锥曲线的位置关系（无交 / 切 / 两交 / 单交特殊情形）；
- 立体几何中线 / 面之间的位置关系（平行 / 相交 / 异面 / 垂直）。

每一类题都有自己的"判别公式"和"分类清单"。本篇把所有这些清单列在一起，给出**统一的分类讨论框架**：

**第一步**：列出所有可能位置；
**第二步**：找出判别量（斜率、距离、判别式、向量）；
**第三步**：用判别量给每种位置一个等价条件；
**第四步**：若题目含参，对参数分类讨论，写出每种情形对应的结论。

## 二、直线 vs 直线

设两条直线
$$\ell_1: A_1 x + B_1 y + C_1 = 0, \quad \ell_2: A_2 x + B_2 y + C_2 = 0$$
或在斜率存在时
$$\ell_1: y = k_1 x + b_1, \quad \ell_2: y = k_2 x + b_2$$

### 2.1 位置关系清单

| 位置 | 几何含义 | 斜率判据 | 一般式判据 |
|---|---|---|---|
| **相交** | 恰有一个公共点 | $k_1 \neq k_2$ | $A_1 B_2 - A_2 B_1 \neq 0$ |
| **平行** | 无公共点 | $k_1 = k_2$，$b_1 \neq b_2$ | $A_1 B_2 = A_2 B_1$，$A_1 C_2 \neq A_2 C_1$ |
| **重合** | 完全重合（无穷多公共点）| $k_1 = k_2$，$b_1 = b_2$ | $A_1 : A_2 = B_1 : B_2 = C_1 : C_2$ |
| **垂直**（特殊相交） | 夹角 $90°$ | $k_1 \cdot k_2 = -1$ | $A_1 A_2 + B_1 B_2 = 0$ |

### 2.2 注意斜率不存在的情形

如果其中一条直线斜率不存在（即垂直于 $x$ 轴的 $x = a$ 形式），不能直接用 $k_1 \cdot k_2 = -1$，要单独讨论：

- 若 $\ell_1: x = a$（$k_1$ 不存在），则 $\ell_2 \parallel \ell_1 \Leftrightarrow \ell_2: x = b$（$b \neq a$）；
- $\ell_2 \perp \ell_1 \Leftrightarrow \ell_2: y = c$（即水平线）；
- $\ell_2 \perp \ell_1$ 的另一描述：$\ell_2$ 的斜率为 $0$。

**用一般式 $A_1 A_2 + B_1 B_2 = 0$ 判断垂直可以避开"斜率是否存在"的讨论**，这是常用的简化技巧。

## 三、直线 vs 圆

设直线 $\ell: Ax + By + C = 0$，圆 $C: (x - a)^2 + (y - b)^2 = r^2$。

### 3.1 位置关系清单（用 $d$ vs $r$）

设圆心到直线的距离
$$d = \frac{|Aa + Bb + C|}{\sqrt{A^2 + B^2}}$$

| 位置 | 公共点数 | 判据 |
|---|---|---|
| **相离** | $0$ | $d > r$ |
| **相切** | $1$ | $d = r$ |
| **相交** | $2$ | $d < r$ |

### 3.2 备选判据：联立 + 判别式

把直线方程代入圆方程，得 $x$（或 $y$）的二次方程，判别式 $\Delta$：
- $\Delta > 0$：相交；
- $\Delta = 0$：相切；
- $\Delta < 0$：相离。

**两种方法比较**：

| 方法 | 优势 | 劣势 |
|---|---|---|
| **$d$ vs $r$** | 计算少，几何意义清晰 | 圆心和半径必须先求出 |
| **$\Delta$ 法** | 自动求交点坐标，适合后续算弦长 | 计算量较大 |

通常先用 $d$ vs $r$ 判断位置，再用 $\Delta$ 法或代入直线方程算具体交点。

### 3.3 弦长公式

若直线 $\ell$ 与圆 $C$ 相交（$d < r$），交点为 $P$、$Q$，则
$$|PQ| = 2\sqrt{r^2 - d^2}$$
（半弦长 = $\sqrt{r^2 - d^2}$，弦的"勾股关系"——$r$ 为斜边，$d$ 为一条直角边，半弦长为另一条）。

## 四、圆 vs 圆

设两圆 $C_1: (x - a_1)^2 + (y - b_1)^2 = r_1^2$、$C_2: (x - a_2)^2 + (y - b_2)^2 = r_2^2$，圆心距
$$d = \sqrt{(a_1 - a_2)^2 + (b_1 - b_2)^2}$$

### 4.1 位置关系清单（5 种关系）

| 位置 | 公共点数 | 圆心距判据 |
|---|---|---|
| **外离** | $0$ | $d > r_1 + r_2$ |
| **外切** | $1$ | $d = r_1 + r_2$ |
| **相交** | $2$ | $|r_1 - r_2| < d < r_1 + r_2$ |
| **内切** | $1$ | $d = |r_1 - r_2|$（$r_1 \neq r_2$）|
| **内含** | $0$ | $d < |r_1 - r_2|$ |

**特殊**：$d = 0$ 且 $r_1 = r_2$，两圆**同心且重合**。

**记忆口诀**（5 种关系按 $d$ 由大到小）：**离 = 切 ＞ 交 ＞ 切（内）＞ 含**——`d` 从 $r_1 + r_2$ 一直减到 $0$，依次穿过 $r_1 + r_2$、$|r_1 - r_2|$ 两道分界线。

### 4.2 图形直觉

把 $d$ 从大到小变化的过程想象成"两圆从分离到内含"的连续动画：

- 起初两圆很远，$d$ 大，**外离**；
- $d$ 减到等于 $r_1 + r_2$，两圆"刚刚碰到"，**外切**；
- $d$ 再减，两圆开始**相交**；
- $d$ 减到等于 $|r_1 - r_2|$，小圆"贴在大圆内壁"，**内切**；
- $d$ 再减，小圆完全在大圆内部，**内含**；
- $d = 0$，若 $r_1 = r_2$ 则重合，否则同心。

## 五、直线 vs 圆锥曲线

直线与椭圆 / 双曲线 / 抛物线相交问题统称为"直线与圆锥曲线的位置关系"。一般做法：**联立方程，得二次方程，看判别式 $\Delta$**。

### 5.1 一般步骤

设直线 $\ell: y = kx + m$，圆锥曲线方程 $F(x, y) = 0$。代入得
$$F(x, kx + m) = 0$$
通常化为 $x$ 的二次方程 $ax^2 + bx + c = 0$。

- $\Delta = b^2 - 4ac > 0$：两个交点；
- $\Delta = 0$：一个交点（切线 / 特殊情形）；
- $\Delta < 0$：无交点。

### 5.2 双曲线的"单交点"陷阱

对椭圆和抛物线，二次方程的系数 $a$ 通常 $\neq 0$。但**对双曲线和抛物线**，会出现"代入后方程退化为一次方程"的情形：

- **双曲线 $\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 1$ 与渐近线方向平行的直线**：联立后 $x^2$ 项被消去，方程降阶为一次，恰好一个交点（但不是切线）；
- **抛物线 $y^2 = 2px$ 与 $x$ 轴平行的直线**：代入得 $y$ 的一次方程，恰好一个交点。

所以判断直线与圆锥曲线的位置关系时，**必须先判断二次项系数 $a$ 是否为零**，再决定是用 $\Delta$ 法还是按一次方程处理。

### 5.3 完整判别流程

```
联立得形如 ax^2 + bx + c = 0
├── a = 0：方程退化为一次 bx + c = 0
│   ├── b ≠ 0：恰一个解，一个交点（非切线情形）
│   └── b = 0：c = 0 时直线在曲线上（实际上不出现），c ≠ 0 时无解
└── a ≠ 0：标准二次方程
    ├── Δ > 0：两个交点
    ├── Δ = 0：一个交点（切线）
    └── Δ < 0：无交点
```

## 六、立体几何中的位置关系（简表）

详见 toolkit 09《空间几何想象力》。这里给出速查表：

### 6.1 直线 vs 直线（空间）

| 位置 | 描述 |
|---|---|
| 共面 - 相交 | 同一平面内、有唯一公共点 |
| 共面 - 平行 | 同一平面内、无公共点 |
| 共面 - 重合 | 完全重合 |
| **异面** | 不在同一平面内、无公共点 |

### 6.2 直线 vs 平面

| 位置 | 公共点数 |
|---|---|
| 平行 | $0$ |
| 直线在平面内 | 无穷多（直线属于平面）|
| 相交 | $1$ |

### 6.3 平面 vs 平面

| 位置 | 法向量关系 | 判据 |
|---|---|---|
| 平行 | $\vec{n_1} \parallel \vec{n_2}$ | 法向量共线 |
| 重合 | $\vec{n_1} \parallel \vec{n_2}$ + 有公共点 | 同上且共点 |
| 相交 | $\vec{n_1}$ 与 $\vec{n_2}$ 不共线 | 法向量夹角即二面角的余角 |

## 七、演示题

**题目**：讨论直线 $y = kx + 1$ 与圆 $C: x^2 + y^2 - 4x + 3 = 0$ 的位置关系（$k$ 为实参数）。

> **Q1. 整理圆的标准方程。**
>
> 配方：$x^2 - 4x + y^2 + 3 = 0$，$(x - 2)^2 + y^2 = 4 - 3 = 1$。
>
> 所以圆心 $C = (2, 0)$，半径 $r = 1$。

> **Q2. 选用 $d$ vs $r$ 法。**
>
> 圆心到直线 $kx - y + 1 = 0$ 的距离
>
> $$d = \frac{|k \cdot 2 - 0 + 1|}{\sqrt{k^2 + (-1)^2}} = \frac{|2k + 1|}{\sqrt{k^2 + 1}}$$
>
> 比较 $d$ 与 $r = 1$。

> **Q3. 列出三种情形。**
>
> **情形一：$d < 1$**——相交。即 $\dfrac{|2k + 1|}{\sqrt{k^2 + 1}} < 1$，两边平方（合法，因均非负）：
>
> $$(2k + 1)^2 < k^2 + 1$$
> $$4k^2 + 4k + 1 < k^2 + 1$$
> $$3k^2 + 4k < 0$$
> $$k(3k + 4) < 0$$
>
> 即 $-\dfrac{4}{3} < k < 0$。
>
> **情形二：$d = 1$**——相切。$(2k + 1)^2 = k^2 + 1$，即 $3k^2 + 4k = 0$，$k(3k + 4) = 0$，$k = 0$ 或 $k = -\dfrac{4}{3}$。
>
> **情形三：$d > 1$**——相离。$3k^2 + 4k > 0$，$k < -\dfrac{4}{3}$ 或 $k > 0$。

> **Q4. 综合结论。**
>
> - 当 $k < -\dfrac{4}{3}$ 或 $k > 0$ 时，直线与圆**相离**；
> - 当 $k = -\dfrac{4}{3}$ 或 $k = 0$ 时，直线与圆**相切**；
> - 当 $-\dfrac{4}{3} < k < 0$ 时，直线与圆**相交**。

> **Q5. 验证 $k = 0$ 的情形。**
>
> $k = 0$ 时直线为 $y = 1$，是水平线。圆心 $(2, 0)$ 到 $y = 1$ 的距离 $= 1 = r$，确实相切。验证通过。

## 八、思考路标

**路标 1**：所有位置关系题的第一步是**写出标准方程**：圆要配方成 $(x-a)^2 + (y-b)^2 = r^2$，直线要看是否考虑斜率不存在的情形。**不化标准方程不读题**。

**路标 2**：直线与圆，**首选 $d$ vs $r$ 法**——算一次距离，三种情形立即出。除非要求交点坐标，否则不要轻易用联立法。

**路标 3**：圆与圆的 **5 种位置关系**必须背熟：外离、外切、相交、内切、内含——对应 $d$ 与 $r_1 + r_2$、$|r_1 - r_2|$ 的 5 种相对位置。考试常考"含参圆与定圆的位置关系讨论"，所有 5 种都要点到。

**路标 4**：直线与圆锥曲线，必查**二次项系数是否为零**。双曲线和抛物线最容易掉这个坑——"代入后方程退化"对应特殊的"单交点"情形（如双曲线渐近线方向、抛物线与对称轴平行的直线），不是切线！

**路标 5**：含参的位置关系题，标准书写为"**当 $[\text{参数条件}]$ 时，位置是 [\text{...}]**"，最后写综合。**禁止**把不同情形混在一起描述。

**路标 6**：写 $d$ 与 $r$（或 $d$ 与 $r_1 \pm r_2$）的比较不等式时，**先平方再开式**比"直接讨论绝对值"少一步，但要确认两边均非负。

**路标 7**：对于"直线与圆相交的弦长"问题，直接用公式 $|PQ| = 2\sqrt{r^2 - d^2}$（路标 3 + 弦长公式），不要再去联立解二次方程。这是节省一半计算的关键。

**路标 8**：立体几何里的"位置关系"判别**优先用法向量** $\vec{n_1}$、$\vec{n_2}$：平行看法向量是否共线，垂直看法向量内积是否为 $0$——这是空间向量法的核心套路。

## 九、典型应用例题

### 例 1：两直线平行 / 垂直的含参讨论

**题目**：已知直线 $\ell_1: ax + 2y + 6 = 0$、$\ell_2: x + (a - 1)y + (a^2 - 1) = 0$。求 $a$ 使 $\ell_1 \parallel \ell_2$，并求 $a$ 使 $\ell_1 \perp \ell_2$。

**分析**：用一般式判据避开斜率讨论。

**$\ell_1 \parallel \ell_2$**：$A_1 B_2 - A_2 B_1 = 0$ 且 $A_1 C_2 - A_2 C_1 \neq 0$。

$a(a - 1) - 2 \cdot 1 = a^2 - a - 2 = (a - 2)(a + 1) = 0$，得 $a = 2$ 或 $a = -1$。

验证 $A_1 C_2 \neq A_2 C_1$：
- $a = 2$：$2 \cdot 3 \neq 1 \cdot 6$ → $6 = 6$ 不成立（重合），舍。
- $a = -1$：$-1 \cdot 0 \neq 1 \cdot 6$ → $0 \neq 6$ 成立。$a = -1$ 时 $\ell_1 \parallel \ell_2$。

**$\ell_1 \perp \ell_2$**：$A_1 A_2 + B_1 B_2 = 0$。

$a \cdot 1 + 2(a - 1) = 3a - 2 = 0$，$a = \dfrac{2}{3}$。

**答**：$\ell_1 \parallel \ell_2$ 当且仅当 $a = -1$；$\ell_1 \perp \ell_2$ 当且仅当 $a = \dfrac{2}{3}$。

### 例 2：两圆位置关系的 5 种情形分类

**题目**：圆 $C_1: x^2 + y^2 = 1$ 与圆 $C_2: (x - 3)^2 + y^2 = r^2$（$r > 0$）。讨论它们的位置关系随 $r$ 的变化。

**分析**：$C_1$ 半径 $r_1 = 1$，圆心 $(0, 0)$；$C_2$ 半径 $r_2 = r$，圆心 $(3, 0)$。圆心距 $d = 3$。

按路标 3 分 5 种：

- **外离**：$d > r_1 + r_2$，即 $3 > 1 + r$，$r < 2$；
- **外切**：$3 = 1 + r$，$r = 2$；
- **相交**：$|r - 1| < 3 < r + 1$。后一不等式 $r > 2$；前一不等式 $|r - 1| < 3$ 即 $-2 < r < 4$（已知 $r > 0$，等价 $0 < r < 4$）。综合：$2 < r < 4$；
- **内切**：$3 = |r - 1|$。$r - 1 = 3$ 即 $r = 4$，或 $1 - r = 3$ 即 $r = -2$（舍）。即 $r = 4$；
- **内含**：$3 < |r - 1|$，由 $r > 0$，$r - 1 > 3$ 得 $r > 4$（$1 - r > 3$ 即 $r < -2$ 舍）。

**综合**：

| $r$ 范围 | 位置 |
|---|---|
| $0 < r < 2$ | 外离 |
| $r = 2$ | 外切 |
| $2 < r < 4$ | 相交 |
| $r = 4$ | 内切 |
| $r > 4$ | 内含 |

### 例 3：直线与双曲线的单交点情形

**题目**：判断直线 $y = x + 1$ 与双曲线 $\dfrac{x^2}{4} - \dfrac{y^2}{4} = 1$ 的位置关系。

**分析**：双曲线的渐近线为 $y = \pm x$。直线 $y = x + 1$ 的斜率 $= 1$，**与渐近线 $y = x$ 平行**——这是路标 4 的典型陷阱情形。

代入：$\dfrac{x^2}{4} - \dfrac{(x + 1)^2}{4} = 1$，即 $x^2 - (x + 1)^2 = 4$，$-2x - 1 = 4$，$x = -\dfrac{5}{2}$。

代入直线得 $y = -\dfrac{3}{2}$。**恰一个交点 $\left(-\dfrac{5}{2}, -\dfrac{3}{2}\right)$**——但这不是切线！因为联立后方程退化为一次方程（$x^2$ 项被消去），代表"直线与双曲线相交于一点且不切"。

**答**：直线与双曲线相交于一点，但不是切线（因为直线与一条渐近线平行）。

## 十、自测题

**第 1 题**：判断直线 $\ell_1: 3x + 4y - 5 = 0$ 与直线 $\ell_2: 6x + 8y + 3 = 0$ 的位置关系。

💡 提示：$A_1 B_2 - A_2 B_1 = 3 \cdot 8 - 6 \cdot 4 = 0$，且 $A_1 C_2 - A_2 C_1 = 3 \cdot 3 - 6 \cdot (-5) = 9 + 30 = 39 \neq 0$，所以**平行**。

**第 2 题**：已知直线 $\ell: y = kx - 2k + 3$ 与圆 $C: x^2 + y^2 = 25$ 的位置关系，求实数 $k$ 的范围使两者相离。

💡 提示：先观察 $\ell$ 恒过定点（令 $k$ 项分离）：$y - 3 = k(x - 2)$，恒过 $(2, 3)$。该定点到原点距离 $= \sqrt{4 + 9} = \sqrt{13} < 5 = r$，所以定点**在圆内**，任何过该定点的直线都与圆相交。**$\ell$ 永不与圆相离**——本题无解。

**第 3 题**：圆 $C_1: x^2 + y^2 = 4$ 和圆 $C_2: x^2 + y^2 - 8x + 12 = 0$ 的位置关系？

💡 提示：$C_2$ 配方 $(x - 4)^2 + y^2 = 4$，$r_2 = 2$。$C_1$ 圆心 $(0,0)$、$r_1 = 2$。$d = 4$。$r_1 + r_2 = 4 = d$，所以**外切**。

**第 4 题**：判断直线 $y = 2x$ 与抛物线 $y^2 = 4x$ 的位置关系，并求交点。

💡 提示：代入 $(2x)^2 = 4x$，$4x^2 - 4x = 0$，$4x(x - 1) = 0$，$x = 0$ 或 $x = 1$。两个交点 $(0, 0)$、$(1, 2)$。**相交于两点**。

**第 5 题**：直线 $\ell: kx - y + 2k = 0$ 与椭圆 $\dfrac{x^2}{9} + \dfrac{y^2}{4} = 1$ 的位置关系随 $k$ 如何变化？

💡 提示：$\ell$ 恒过 $(-2, 0)$（令 $k = 0$ 项分离）。该点代入椭圆：$\dfrac{4}{9} + 0 = \dfrac{4}{9} < 1$，**在椭圆内**。所以过 $(-2, 0)$ 的所有直线（含斜率不存在的 $x = -2$）都与椭圆相交于两点。**对任意 $k$ 都相交于两点**。
