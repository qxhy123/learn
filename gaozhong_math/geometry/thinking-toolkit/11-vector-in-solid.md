# 立体几何中的向量法

> **一例速记**：正方体 $ABCD$-$A_1B_1C_1D_1$ 求二面角 $A_1$-$BD$-$D_1$。
> 三秒钟启动流程：① 以 $D$ 为原点，三条相邻边为 $x, y, z$ 轴（**正交三边送到嘴边**）② 设边长为 $1$ ③ 写出所有关键点坐标 ④ 平面 $A_1BD$ 法向量 $\vec{n_1}$，平面 $D_1BD$ 法向量 $\vec{n_2}$ ⑤ $\cos\theta = \cos\langle \vec{n_1}, \vec{n_2}\rangle$，看图判正负。
> **这就是立体几何的"通用收割机"——能解决线线角、线面角、二面角、距离的所有标准问题。**

---

## 一、为什么向量法是立体几何的"通用钥匙"

立体几何的解题方法主要有两种：

| 方法 | 综合法 | 向量法 |
|---|---|---|
| 工具 | 几何图形 + 三角形相似 / 全等 / 余弦定理 | 空间坐标系 + 向量公式 |
| 长处 | 用直观，过程简洁，分数高 | 流程标准，几乎不需要"灵感" |
| 短处 | 需要"看出"辅助线 / 平移 / 投影 | 计算量大，容易写错坐标 |
| 适用 | 图象简洁、关系明显 | 任何带有"两两垂直三条边"的图象 |

**向量法的核心价值**：把空间问题**机械化**——只要建得对坐标系，剩下的就是套公式。**对高考来说，向量法是"保底"方法**——综合法看不出来时，建系一上来就能拿大半分。

本篇与工具箱 01（向量法 = 四把剑之一）、08（向量两副面孔）、09（空间想象力）、11（立体几何向量法 = 本篇）紧密相连——这是空间向量在立体几何中的应用核心。

## 二、建系 4 步法

### Step 1：找正交三边

**目标**：找三条**两两垂直**的边，作为 $x, y, z$ 轴。

| 常见场景 | 三条正交边 |
|---|---|
| 长方体 / 正方体 | 一顶点出发的三条相邻棱（送分） |
| 直三棱柱（底面为直角三角形） | 直角顶点出发的两条直角边 + 侧棱 |
| 一条侧棱 $\perp$ 底面（如"墙角型"四棱锥） | 侧棱 + 底面两条互垂的边 |
| 三棱锥某顶点处有 3 条两两垂直的棱 | 这 3 条棱直接是 $x, y, z$ 轴 |
| 圆锥 / 圆柱（轴竖直） | 底面两条互垂的直径 + 轴 |

**当题目不直接给"正交三边"时，需要先**用线面垂直定理**证明出三条互垂的线**——这是建系的前置工作。

### Step 2：设单位长度

**目标**：写下具体的坐标值，便于计算。

**通用做法**：
- 题目给出具体长度（如棱长为 $2$）：直接用。
- 题目只给"正方体棱长 $a$"：设 $a = 1$（不影响角度计算，因为角与长度无关）。距离计算需要保留 $a$。
- 题目带参数（如 $AB = 2, AD = \lambda$）：保留 $\lambda$，最后再带入。

### Step 3：求关键点坐标

**目标**：把所有关键点的坐标写出来。

**技巧**：
- 顶点先写：原点、$x, y, z$ 轴方向上的点。
- 用向量加法 / 数乘求其他点。
- 中点：$M = \dfrac{1}{2}(A + B)$。
- 三等分点 / 重心：用向量运算 $\vec{OG} = \dfrac{1}{3}(\vec{OA}+\vec{OB}+\vec{OC})$。

### Step 4：套公式求结果

**目标**：根据题目所求（线线角 / 线面角 / 二面角 / 距离），套用对应公式。

公式见第三节"四大公式"。

## 三、四大核心公式

### 公式 1：线线角

**定义**：两条直线的夹角范围 $\left(0, \dfrac{\pi}{2}\right]$。

**公式**：

$$\cos\theta = |\cos\langle \vec{a}, \vec{b}\rangle| = \frac{|\vec{a} \cdot \vec{b}|}{|\vec{a}| \cdot |\vec{b}|}$$

**关键**：**取绝对值**——因为方向向量本身可正可负，但直线夹角必须为锐角或直角。

### 公式 2：线面角

**定义**：直线与平面的夹角是"直线方向"与"在平面上的投影"之间的角，范围 $\left[0, \dfrac{\pi}{2}\right]$。

**公式**：

$$\sin\theta = |\cos\langle \vec{l}, \vec{n}\rangle| = \frac{|\vec{l} \cdot \vec{n}|}{|\vec{l}| \cdot |\vec{n}|}$$

其中 $\vec{l}$ 是直线方向向量，$\vec{n}$ 是平面法向量。

**为什么是 $\sin$**：直线与法向量的夹角加上线面角等于 $\dfrac{\pi}{2}$，所以两者的角的 $\sin$ 互换 $\cos$。

### 公式 3：二面角

**定义**：两个半平面沿公共棱构成的角，范围 $[0, \pi]$。

**公式**：

$$\cos\theta = \cos\langle \vec{n_1}, \vec{n_2}\rangle = \frac{\vec{n_1} \cdot \vec{n_2}}{|\vec{n_1}| \cdot |\vec{n_2}|}$$

其中 $\vec{n_1}, \vec{n_2}$ 分别是两半平面的法向量。

**关键**：**不取绝对值**！计算出的 $\cos\theta$ 可正可负，对应锐角或钝角。要**看图判断**二面角是锐角还是钝角：

- 若两法向量"指向相同的一侧"（都向外或都向内）：二面角与 $\langle \vec{n_1}, \vec{n_2}\rangle$ 互补，即二面角 $= \pi - \langle \vec{n_1}, \vec{n_2}\rangle$。
- 若两法向量"指向相反的一侧"：二面角等于 $\langle \vec{n_1}, \vec{n_2}\rangle$。

**实用口诀**：算出 $\cos\theta$ 后，**看图判正负**——题目图示中的二面角是锐角还是钝角，再决定最终 $\cos\theta$ 取正还是取负。

### 公式 4：点到平面距离

**公式**：

$$d = \frac{|\vec{AP} \cdot \vec{n}|}{|\vec{n}|}$$

其中 $A$ 是平面上任一点（已知），$P$ 是待求距离的点，$\vec{n}$ 是平面法向量。

**几何意义**：$\vec{AP}$ 在 $\vec{n}$ 方向上的投影长度（取绝对值）就是 $P$ 到平面的距离。

## 四、四大公式速查表

| 求什么 | 公式 | 取绝对值？ | 关键说明 |
|---|---|---|---|
| 线线角 | $\cos\theta = \dfrac{\vert \vec{a}\cdot \vec{b}\vert }{\vert \vec{a}\vert \vert \vec{b}\vert }$ | **是** | 夹角范围 $(0, \pi/2]$ |
| 线面角 | $\sin\theta = \dfrac{\vert \vec{l}\cdot \vec{n}\vert }{\vert \vec{l}\vert \vert \vec{n}\vert }$ | **是** | 用 $\sin$ 不是 $\cos$ |
| 二面角 | $\cos\theta = \dfrac{\vec{n_1}\cdot \vec{n_2}}{\vert \vec{n_1}\vert \vert \vec{n_2}\vert }$ | **否** | 看图判正负 |
| 点到平面距离 | $d = \dfrac{\vert \vec{AP}\cdot \vec{n}\vert }{\vert \vec{n}\vert }$ | **是** | 距离非负 |

## 五、法向量求法（核心技巧）

**目标**：给定平面内两个不共线向量 $\vec{a}, \vec{b}$，求法向量 $\vec{n} = (x, y, z)$。

**方法**：设 $\vec{n} = (x, y, z)$。由 $\vec{n} \perp \vec{a}$ 和 $\vec{n} \perp \vec{b}$ 得方程组：

$$\begin{cases} \vec{n} \cdot \vec{a} = 0 \\ \vec{n} \cdot \vec{b} = 0 \end{cases}$$

这是关于 $x, y, z$ 的两个方程，含 3 个未知数——有一个自由度。**赋值法**：选一个分量取定值（如 $z = 1$ 或 $z = $ 公倍数），解出另外两个。

**示例**：设 $\vec{a} = (1, 0, 1)$，$\vec{b} = (1, 1, 0)$。

$$\begin{cases} x + z = 0 \\ x + y = 0 \end{cases}$$

赋 $z = 1$：由第一式 $x = -1$；由第二式 $y = 1$。所以 $\vec{n} = (-1, 1, 1)$。

**验证**：$\vec{n}\cdot \vec{a} = -1 + 0 + 1 = 0$ ✓，$\vec{n}\cdot \vec{b} = -1 + 1 + 0 = 0$ ✓。

**技巧**：若题目有对称性（如 $\vec{a}, \vec{b}$ 互换法向量不变），选最对称的赋值。若赋值导致某分量为 $0$ 的"特殊"情形，换一个分量赋值。

## 六、演示题：二面角（建系标准流程）

**题目**：正方体 $ABCD$-$A_1B_1C_1D_1$ 棱长为 $1$，求二面角 $A_1$-$BD$-$D_1$ 的大小。

---

> **Step 1. 建系（找正交三边）**：以 $D$ 为原点，$\vec{DA}, \vec{DC}, \vec{DD_1}$ 分别为 $x, y, z$ 轴正方向。这是长方体送分建系。
>
> **Step 2. 设单位长度**：棱长 $= 1$。
>
> **Step 3. 求关键点坐标**：
> - $D = (0, 0, 0)$
> - $A = (1, 0, 0)$
> - $B = (1, 1, 0)$
> - $C = (0, 1, 0)$
> - $A_1 = (1, 0, 1)$
> - $D_1 = (0, 0, 1)$
>
> 棱 $BD$ 的方向向量：$\vec{DB} = (1, 1, 0)$。
>
> **Step 4a. 求平面 $A_1BD$ 的法向量 $\vec{n_1}$**：
>
> 平面内取两向量 $\vec{DB} = (1,1,0)$ 和 $\vec{DA_1} = (1, 0, 1)$。
>
> 设 $\vec{n_1} = (x, y, z)$：
>
> $$\begin{cases} x + y = 0 \\ x + z = 0 \end{cases}$$
>
> 赋 $x = 1$：$y = -1, z = -1$。所以 $\vec{n_1} = (1, -1, -1)$。
>
> **Step 4b. 求平面 $D_1BD$ 的法向量 $\vec{n_2}$**：
>
> 平面内取两向量 $\vec{DB} = (1,1,0)$ 和 $\vec{DD_1} = (0, 0, 1)$。
>
> 设 $\vec{n_2} = (x, y, z)$：
>
> $$\begin{cases} x + y = 0 \\ z = 0 \end{cases}$$
>
> 赋 $x = 1$：$y = -1, z = 0$。所以 $\vec{n_2} = (1, -1, 0)$。
>
> **Step 4c. 计算 $\cos\langle \vec{n_1}, \vec{n_2}\rangle$**：
>
> $$\vec{n_1} \cdot \vec{n_2} = 1 \cdot 1 + (-1)(-1) + (-1) \cdot 0 = 2$$
>
> $$|\vec{n_1}| = \sqrt{1 + 1 + 1} = \sqrt{3}, \quad |\vec{n_2}| = \sqrt{1 + 1 + 0} = \sqrt{2}$$
>
> $$\cos\langle \vec{n_1}, \vec{n_2}\rangle = \frac{2}{\sqrt{3} \cdot \sqrt{2}} = \frac{2}{\sqrt{6}} = \frac{\sqrt{6}}{3}$$
>
> **Step 4d. 看图判正负**：
>
> 二面角 $A_1$-$BD$-$D_1$：观察这个角的实际形状——$A_1$ 与 $D_1$ 都在 $BD$ 的同侧（上方），$A_1 B D$ 是斜向上的平面，$D_1 B D$ 是竖直的平面。这两个平面的夹角是锐角（一个偏向 $A_1$ 方向，一个偏向 $D_1$ 方向，两个法向量同时背向夹角内部）。
>
> 因此二面角 $= \langle \vec{n_1}, \vec{n_2}\rangle$，$\cos\theta = \dfrac{\sqrt{6}}{3}$。
>
> **最终答案**：二面角 $A_1$-$BD$-$D_1 = \arccos\dfrac{\sqrt{6}}{3}$。

## 七、思考路标

**路标 1**：**建系前先找"两两垂直的三条边"**——这是建系的第一动作，也是最容易出错的地方。长方体 / 正方体送分，**直接以一顶点为原点**；带"侧棱垂直底面"的题，立即以侧棱足为原点，侧棱方向为 $z$ 轴，底面两条互垂的边为 $x, y$ 轴。若没有现成的正交三边，先用线面垂直定理"证出"两条垂直关系，再建系。

**路标 2**：**坐标写错是向量法的最大杀手**——建好系后，**至少写 3 遍坐标**：第一次列出所有顶点，第二次用向量加法验证（如 $\vec{AB} = B - A$），第三次代入公式前再核对一次。每错一个坐标，后面所有计算都白做。

**路标 3**：**法向量赋值要"漂亮"**——求法向量时，赋值的选择影响计算量。**优先赋值给"出现次数最多"的分量**（如方程组中 $z$ 出现两次，就赋 $z = 1$）。**避免赋值导致 $\vec{n}$ 为零向量**——验证 $\vec{n} \neq \vec{0}$ 后再用。

**路标 4**：**线线角、线面角"取绝对值"；二面角"看图判正负"**——这是 4 大公式的差异核心，**必须记牢**。
- 线线角：$|\cdot|$ → 锐角或直角；
- 线面角：用 $\sin$（不是 $\cos$）+ $|\cdot|$ → 范围 $[0, \pi/2]$；
- 二面角：不加 $|\cdot|$ → 可能是钝角，**看图判**；
- 距离：$|\cdot|$ → 非负。

**路标 5**：**二面角的"看图判正负"是失分重灾区**——计算 $\cos\langle \vec{n_1}, \vec{n_2}\rangle$ 后，必须看实际图形判断二面角是锐角还是钝角。**判断技巧**：观察两个半平面的"朝向"——若两法向量都"朝外"（指向二面角的外部），则二面角 = $\pi - \langle\vec{n_1},\vec{n_2}\rangle$；若两法向量"一朝外一朝内"，则二面角 = $\langle\vec{n_1}, \vec{n_2}\rangle$。**保底做法**：算出 $\cos\theta$ 的绝对值，再根据图判断该取正还是取负。

**路标 6**：**点到平面距离 = 任一连线的投影**——公式 $d = \dfrac{|\vec{AP}\cdot \vec{n}|}{|\vec{n}|}$ 中，$A$ **可以是平面上任意一点**——选最容易写坐标的那个（如平面是 $ABC$，选 $A$ 最方便）。这是节省时间的关键。

**路标 7**：**向量法 vs 综合法的切换决策**——
- 题目带"两两垂直三边"（长方体、正方体、墙角型）→ **直接建系**，向量法快。
- 题目给"明显的相似 / 全等 / 平移"关系 → **综合法**更简洁。
- 复合型题（一部分容易看几何，一部分难看）→ 综合 + 向量混合：用综合法找到关键关系（如垂直、平行），用向量法完成最后的角度 / 距离计算。
- **考试保底**：拿不准时，建系 + 向量法。流程标准，能拿大部分分。

**路标 8**：**建系的"等价选择"**——同一道题，原点的选择不唯一。**坐标越简单越好**：让尽量多的点的坐标为 $0$（在轴上）。**口诀**：原点选在"几条垂直边的交点"处，让三个轴沿着已知边方向。如果建系后坐标都很丑（多个分数 / 根号），考虑换一个原点重新建系。

## 八、典型应用例题

### 例 1：线线角

**题目**：长方体 $ABCD$-$A_1B_1C_1D_1$ 中，$AB = 4, AD = 3, AA_1 = 5$。求异面直线 $A_1C$ 与 $BD_1$ 所成角的余弦值。

**思路**：建系 + 向量法。以 $A$ 为原点，$\vec{AB}, \vec{AD}, \vec{AA_1}$ 为 $x, y, z$ 轴。

坐标：
- $A = (0, 0, 0)$，$C = (4, 3, 0)$
- $A_1 = (0, 0, 5)$，$B = (4, 0, 0)$，$D_1 = (0, 3, 5)$

方向向量：
- $\vec{A_1 C} = (4, 3, -5)$
- $\vec{BD_1} = (-4, 3, 5)$

计算：
$$\vec{A_1C} \cdot \vec{BD_1} = -16 + 9 - 25 = -32$$
$$|\vec{A_1C}| = \sqrt{16+9+25} = \sqrt{50} = 5\sqrt{2}$$
$$|\vec{BD_1}| = \sqrt{16+9+25} = 5\sqrt{2}$$

$$\cos\theta = \frac{|-32|}{5\sqrt{2} \cdot 5\sqrt{2}} = \frac{32}{50} = \frac{16}{25}$$

**答案**：异面直线 $A_1 C$ 与 $BD_1$ 所成角的余弦值为 $\dfrac{16}{25}$。

---

### 例 2：线面角

**题目**：正三棱柱 $ABC$-$A_1B_1C_1$ 的底面边长为 $2$，侧棱长为 $\sqrt{3}$。求侧面对角线 $AB_1$ 与底面 $ABC$ 所成角。

**思路**：建系。底面正三角形 $ABC$，取 $A$ 为原点。设 $A = (0, 0, 0)$，$B = (2, 0, 0)$，$C = (1, \sqrt{3}, 0)$。$A_1 = (0, 0, \sqrt{3})$，$B_1 = (2, 0, \sqrt{3})$。

$\vec{AB_1} = (2, 0, \sqrt{3})$。底面 $ABC$ 的法向量 $\vec{n} = (0, 0, 1)$。

$$\sin\theta = \frac{|\vec{AB_1} \cdot \vec{n}|}{|\vec{AB_1}| \cdot |\vec{n}|} = \frac{|\sqrt{3}|}{\sqrt{4+0+3} \cdot 1} = \frac{\sqrt{3}}{\sqrt{7}} = \frac{\sqrt{21}}{7}$$

**答案**：$\sin\theta = \dfrac{\sqrt{21}}{7}$，$\theta = \arcsin\dfrac{\sqrt{21}}{7}$。

---

### 例 3：点到平面距离

**题目**：正方体 $ABCD$-$A_1B_1C_1D_1$ 棱长为 $1$。求点 $A$ 到平面 $BDD_1B_1$ 的距离。

**思路**：以 $D$ 为原点。$A = (1, 0, 0)$，$B = (1, 1, 0)$，$D = (0, 0, 0)$，$D_1 = (0, 0, 1)$，$B_1 = (1, 1, 1)$。

平面 $BDD_1B_1$ 内取两向量：$\vec{DB} = (1, 1, 0)$，$\vec{DD_1} = (0, 0, 1)$。

法向量 $\vec{n} = (x, y, z)$：

$$\begin{cases} x + y = 0 \\ z = 0 \end{cases}$$

赋 $x = 1$：$y = -1, z = 0$。$\vec{n} = (1, -1, 0)$。

$\vec{DA} = (1, 0, 0)$。

$$d = \frac{|\vec{DA} \cdot \vec{n}|}{|\vec{n}|} = \frac{|1 + 0 + 0|}{\sqrt{1+1+0}} = \frac{1}{\sqrt{2}} = \frac{\sqrt{2}}{2}$$

**答案**：$A$ 到平面 $BDD_1B_1$ 的距离为 $\dfrac{\sqrt{2}}{2}$。

**几何验证**：平面 $BDD_1B_1$ 是正方体的"对角面"（含两条棱 $DD_1$ 和 $BB_1$），它截正方体得一个 $\sqrt{2} \times 1$ 的矩形。$A$ 到这个矩形所在平面的距离 = 正方形 $ABCD$ 中 $A$ 到对角线 $BD$ 的距离 $= \dfrac{\sqrt{2}}{2}$ ✓。

## 九、自测题

**第 1 题**：长方体 $ABCD$-$A_1B_1C_1D_1$ 中，$AB = 2, AD = 1, AA_1 = 1$。求 $A_1B$ 与平面 $ABCD$ 所成角的正弦值。

提示：以 $A$ 为原点。$A=(0,0,0), B=(2,0,0), A_1=(0,0,1)$。$\vec{A_1 B}=(2,0,-1)$，底面法向量 $\vec{n}=(0,0,1)$。$\sin\theta=\frac{|\vec{A_1B}\cdot \vec{n}|}{|\vec{A_1B}|}=\frac{1}{\sqrt{4+0+1}}=\frac{1}{\sqrt{5}}=\frac{\sqrt{5}}{5}$。

**第 2 题**：正四棱锥 $P$-$ABCD$ 中，底面边长为 $2$，侧棱长为 $\sqrt{6}$。求侧棱 $PA$ 与底面 $ABCD$ 所成角。

提示：底面中心 $O$ 是 $P$ 的投影。$OA = \frac{1}{2} AC = \sqrt{2}$。$PA = \sqrt{6}$。$\sin\theta = \frac{PO}{PA}$，先求 $PO = \sqrt{PA^2 - OA^2} = \sqrt{6-2}=2$。$\sin\theta=\frac{2}{\sqrt{6}}=\frac{\sqrt{6}}{3}$。也可建系：$O=(0,0,0)$，$A=(\sqrt{2},0,0)$，$P=(0,0,2)$，$\vec{AP}=(-\sqrt{2},0,2)$，底面法向量 $(0,0,1)$。$\sin\theta=\frac{|2|}{\sqrt{2+0+4}}=\frac{2}{\sqrt{6}}=\frac{\sqrt{6}}{3}$。

**第 3 题**：在正方体 $ABCD$-$A_1B_1C_1D_1$ 中，求二面角 $D$-$A_1B$-$A$ 的余弦值。

提示：以 $A$ 为原点，棱长 $1$。$A=(0,0,0), B=(1,0,0), D=(0,1,0), A_1=(0,0,1)$。棱 $A_1B$ 方向 $\vec{A_1 B}=(1,0,-1)$。平面 $A_1 BD$ 取向量 $\vec{A_1 B}=(1,0,-1), \vec{A_1 D}=(0,1,-1)$，法向量 $\vec{n_1}=(1,1,1)$（由 $\begin{cases}x-z=0\\y-z=0\end{cases}$ 赋 $z=1$）。平面 $A_1 BA$ 取向量 $\vec{A_1 B}=(1,0,-1), \vec{A_1 A}=(0,0,-1)$，法向量 $\vec{n_2}=(x,y,z)$ 由 $\begin{cases}x-z=0\\-z=0\end{cases}$ 得 $x=z=0$，$y$ 任意 → $\vec{n_2}=(0,1,0)$。$\cos\langle \vec{n_1},\vec{n_2}\rangle=\frac{1}{\sqrt{3}\cdot 1}=\frac{\sqrt{3}}{3}$。看图：二面角 $D$-$A_1 B$-$A$ 是锐角 → $\cos\theta=\frac{\sqrt{3}}{3}$。

**第 4 题**：正方体 $ABCD$-$A_1B_1C_1D_1$ 棱长为 $1$，求点 $C_1$ 到平面 $A_1BD$ 的距离。

提示：以 $D$ 为原点。$A_1=(1,0,1), B=(1,1,0), D=(0,0,0), C_1=(0,1,1)$。平面 $A_1 BD$ 取向量 $\vec{DA_1}=(1,0,1), \vec{DB}=(1,1,0)$，法向量 $\vec{n}=(x,y,z)$ 由 $\begin{cases}x+z=0\\x+y=0\end{cases}$ 赋 $x=1$ → $y=-1, z=-1$，$\vec{n}=(1,-1,-1)$。$\vec{DC_1}=(0,1,1)$。$d=\frac{|0-1-1|}{\sqrt{3}}=\frac{2}{\sqrt{3}}=\frac{2\sqrt{3}}{3}$。

**第 5 题**：三棱锥 $P$-$ABC$ 中，$PA \perp$ 平面 $ABC$，$PA = AC = 2$，$AB = 1$，$\angle BAC = 90°$。求二面角 $P$-$BC$-$A$ 的正切值。

提示：以 $A$ 为原点，$\vec{AB}, \vec{AC}, \vec{AP}$ 为 $x, y, z$ 轴。$A=(0,0,0), B=(1,0,0), C=(0,2,0), P=(0,0,2)$。棱 $BC$ 方向 $\vec{BC}=(-1,2,0)$。平面 $PBC$ 法向量：用 $\vec{BP}=(-1,0,2), \vec{BC}=(-1,2,0)$，法向量 $\vec{n_1}=(x,y,z)$ 由 $\begin{cases}-x+2z=0\\-x+2y=0\end{cases}$ 赋 $z=1$ → $x=2, y=1$，$\vec{n_1}=(2,1,1)$。平面 $ABC$ 法向量 $\vec{n_2}=(0,0,1)$。$\cos\theta=\frac{1}{\sqrt{6}\cdot 1}=\frac{\sqrt{6}}{6}$。$\sin\theta=\sqrt{1-\frac{1}{6}}=\sqrt{\frac{5}{6}}=\frac{\sqrt{30}}{6}$。$\tan\theta=\frac{\sqrt{30}/6}{\sqrt{6}/6}=\frac{\sqrt{30}}{\sqrt{6}}=\sqrt{5}$。
