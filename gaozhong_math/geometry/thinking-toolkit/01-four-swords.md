# 几何题的四把剑：综合 / 解析 / 向量 / 三角

> **一例速记**：在 $\triangle ABC$ 中，$AB = c$，$AC = b$，$\angle BAC = \alpha$，求 $\vec{AB} \cdot \vec{AC}$。
> 综合法：纯几何投影，$\vec{AB} \cdot \vec{AC} = |\vec{AC}|\cdot|\vec{AB}|\cos\alpha = bc\cos\alpha$。
> 解析法：建系 $A=(0,0)$、$B=(c,0)$、$C=(b\cos\alpha, b\sin\alpha)$，$\vec{AB}\cdot\vec{AC} = c\cdot b\cos\alpha + 0 = bc\cos\alpha$。
> 向量法：直接套定义 $\vec{AB}\cdot\vec{AC} = |\vec{AB}||\vec{AC}|\cos\langle\vec{AB},\vec{AC}\rangle = bc\cos\alpha$。
> 三角法：利用余弦定理变形 $|\vec{BC}|^2 = |\vec{AB}|^2 + |\vec{AC}|^2 - 2\vec{AB}\cdot\vec{AC}$ 反解。
> **一道题，四把剑都能砍——选哪把决定速度。**

---

## 一、从初中到高中：几何方法的升级

初中几何只有一把剑——**综合法**：靠观察图形、添加辅助线、运用全等相似与圆的性质做严密推理。这把剑在初中所向披靡，但进入高中就显得吃力。

高中几何的对象迅速扩展：平面向量、解析几何（直线、圆、椭圆、双曲线、抛物线）、立体几何、空间向量。这些对象既可以用纯几何推理（综合法），又可以转译为代数运算（解析、向量、三角）。**几何题不再只有一条路，而是四条路并存**。

高手与新手的区别，往往不在"能不能做出来"，而在 **"30 秒内选对方法"**。选错了，10 分钟暴算可能绕不出来；选对了，一两步就能直击答案。

**几何方法的四把剑**：

1. **综合法**：纯几何推理（全等、相似、圆幂、共圆、平行垂直）
2. **解析法**：建立坐标系，把几何对象代数化
3. **向量法**：用向量加减、数乘、数量积代替几何关系
4. **三角法**：用边角关系（正弦、余弦定理、三角恒等式）

本篇先把四把剑的"性格"摆清楚——各自的适用场景、优势、劣势，以及最关键的**切换信号**：什么情况下应该放下这把剑、换另一把。

## 二、四把剑速查表

| 剑名 | 核心工具 | 典型适用 | 优势 | 劣势 |
|---|---|---|---|---|
| **综合法** | 全等 / 相似 / 圆性质 / 共线共圆 / 三角形心 | 平面图形证明题；圆 / 切线 / 弦的性质；构图巧妙的题 | 论证严谨、不掉精度；步骤优美 | 依赖辅助线 / 经验；卡住时无路可退 |
| **解析法** | 坐标系 + 方程 | 含坐标 / 圆锥曲线 / 含参讨论 / 距离最值 | 步骤明确、易代数化；不依赖灵感 | 运算量大；可能化简到吐 |
| **向量法** | 加减 / 数乘 / 数量积 / 向量共线 | 平面 / 空间向量；立体几何线面角 / 二面角 | 避免空间想象；可机械计算 | 建系不直观时步骤多；需选恰当基底 |
| **三角法** | 正弦定理 / 余弦定理 / 三角恒等式 | 解三角形；边角关系；含 $\sin\cos$ 最值 | 公式直接套用；与三角函数无缝衔接 | 化简易错；要小心多解 |

### 各把剑的"杀手锏"

**综合法的杀手锏**：圆的相关性质（直径所对圆周角、切线垂直半径、圆幂定理）；三角形的特殊线（角平分线 / 中线 / 高 / 中垂线）；位似与相似。这些是综合法的"硬通货"，纯代数推不出来。

**解析法的杀手锏**：含参讨论（建系后代数化处理参数最简洁）；轨迹方程（动点条件直接转方程）；圆锥曲线综合（韦达定理 + 联立 + 化简的固定套路）。

**向量法的杀手锏**：立体几何（线线角 / 线面角 / 二面角 / 距离统统化为向量公式）；判断共线共面（向量共线 / 共面定理）；力学物理类向量。

**三角法的杀手锏**：三角形的边角关系（已知两边一角或两角一边求其余）；含 $\sin\theta$ 或 $\cos\theta$ 的最值；与三角函数图象 / 周期相关的几何问题。

## 三、切换信号：什么时候应该换剑

**信号 1：综合法卡住超过 5 分钟 → 试向量**
辅助线想不出来，转用向量。设几个基底向量，把图中所有线段写成基底的线性组合，要证的关系往往会变成"两个向量是否成正比 / 内积是否为零"的代数判定。

**信号 2：图形不规则 / 含坐标 / 含参数 → 解析法**
题目本身已经给出坐标系，或图形含参数（如 "$k$ 为何值时…"），果断建系。直线圆 / 圆锥曲线题几乎默认走解析法。

**信号 3：三维难想象 → 向量法**
立体几何只要能建立坐标系（最常见：直三棱柱 / 正方体 / 长方体 / 直角面），向量法就是首选。即使是不规则四面体，只要找到三条不共面的边作基底，也能写成向量。

**信号 4：含 $\sin\cos$ 或解三角形 → 三角法**
出现"$\sin A + \cos A$"、"已知 $a$、$b$、$\angle C$ 求 $c$"、"求面积 $S = \dfrac{1}{2}ab\sin C$"等显式三角符号，正弦 / 余弦定理直接套用。

**信号 5：综合 + 解析联用**
高考压轴题常有"综合法先证一个几何性质 → 解析法再算具体值"的混合策略。例如"先证 PA、PB 关于某直线对称（综合），再求 $PA \cdot PB$ 的值（解析）"。

**信号 6：向量 ↔ 解析的镜像关系**
向量法本质是"不画坐标系的解析法"。如果向量法步骤太多，就建系 → 把向量分解成坐标，转为解析法。两者随时可以互翻。

## 四、演示：一题四解

### 题目：在 $\triangle ABC$ 中，$AB = c$，$AC = b$，$\angle BAC = \alpha$，求 $\vec{AB} \cdot \vec{AC}$。

> 看到这道题，目标是计算 $\vec{AB} \cdot \vec{AC}$。题目给出的已知量是两条边的长度和夹角。我现在脑子里有四种工具，我把它们逐一试一遍，看看哪把剑最快。
>
> **第一把：向量法（直接套定义）**
>
> 向量数量积的定义就是 $\vec{a} \cdot \vec{b} = |\vec{a}||\vec{b}|\cos\theta$，其中 $\theta$ 是两向量的夹角。
>
> $\vec{AB}$ 与 $\vec{AC}$ 的夹角恰好是 $\angle BAC = \alpha$（两向量都从 $A$ 出发）。
>
> 所以：
> $$\vec{AB} \cdot \vec{AC} = |\vec{AB}| \cdot |\vec{AC}| \cdot \cos\alpha = c \cdot b \cdot \cos\alpha = bc\cos\alpha.$$
>
> **一步到答案**。
>
> **第二把：解析法（建系）**
>
> 我把 $A$ 放在原点，$AB$ 放在 $x$ 轴正方向。
>
> - $A = (0, 0)$
> - $B = (c, 0)$
> - $C = (b\cos\alpha, b\sin\alpha)$（因为 $\angle BAC = \alpha$，$|AC| = b$）
>
> 则 $\vec{AB} = (c, 0)$，$\vec{AC} = (b\cos\alpha, b\sin\alpha)$。
>
> $$\vec{AB} \cdot \vec{AC} = c \cdot b\cos\alpha + 0 \cdot b\sin\alpha = bc\cos\alpha.$$
>
> 答案一样，但多了"建系 + 写坐标"两步。
>
> **第三把：综合法（几何投影）**
>
> 数量积的几何意义是 **"一个向量的模 $\times$ 另一向量在它方向上的投影"**。$\vec{AC}$ 在 $\vec{AB}$ 方向上的投影是 $|\vec{AC}|\cos\alpha = b\cos\alpha$。所以：
>
> $$\vec{AB} \cdot \vec{AC} = |\vec{AB}| \cdot (b\cos\alpha) = bc\cos\alpha.$$
>
> 综合法对"投影"这一几何意义直接利用，最简洁。
>
> **第四把：三角法（用余弦定理反解）**
>
> 注意到 $\vec{BC} = \vec{AC} - \vec{AB}$，则
> $$|\vec{BC}|^2 = |\vec{AC} - \vec{AB}|^2 = |\vec{AC}|^2 - 2\vec{AC}\cdot\vec{AB} + |\vec{AB}|^2.$$
>
> 由余弦定理，$|\vec{BC}|^2 = b^2 + c^2 - 2bc\cos\alpha$。两式相等：
> $$b^2 + c^2 - 2bc\cos\alpha = b^2 - 2\vec{AC}\cdot\vec{AB} + c^2,$$
> 解得 $\vec{AC}\cdot\vec{AB} = bc\cos\alpha$。
>
> 步骤最多，但展示了向量与三角的桥梁——余弦定理。
>
> **小结**：这道题四把剑都能解，速度从快到慢为 **综合（投影） ≈ 向量（定义） < 解析（建系） < 三角（绕弯）**。选剑的原则：**已知 / 求量越接近哪把剑的标配，就用哪把**。这道题给的是"两边一角"，正是向量数量积定义的标配，所以向量法最快。

## 五、思考路标

1. **见纯平面几何证明题** → 第一念头：综合法。先看图找全等 / 相似 / 共圆 / 平行垂直等关系。若 5 分钟内找不到突破口，立刻换向量或解析。

2. **见已建好坐标系 / 含坐标 / 含参数** → 解析法默认。建系策略：让题目对象（圆心 / 顶点 / 中点）落在原点或坐标轴上，让出现的对称性最大化。

3. **见立体几何求线面角 / 二面角 / 距离** → 向量法首选。建系思路：找三条互相垂直的边（正方体 / 长方体 / 直棱柱通常有现成的）作为坐标轴；若没有，找一组不共面的基底。

4. **见 $\sin\theta$、$\cos\theta$ 显式出现 / 已知两边一角求边或面积** → 三角法首选。正弦定理 $\dfrac{a}{\sin A} = 2R$；余弦定理 $a^2 = b^2 + c^2 - 2bc\cos A$；面积 $S = \dfrac{1}{2}ab\sin C$ 是三大常用公式。

5. **见圆 / 椭圆 / 双曲线 / 抛物线** → 解析法 + 参数化（toolkit 04）。圆锥曲线有标准方程，建系后直接代入，遇到弦长用韦达定理 + $|AB|=\sqrt{1+k^2}|x_1-x_2|$。

6. **见动点 / 轨迹方程** → 解析法。设动点 $(x, y)$，把题目的几何条件翻译为 $x, y$ 的方程，化简后即为轨迹方程。

7. **见两向量是否共线 / 三点是否共线 / 四点是否共面** → 向量法。共线判据 $\vec{a} = \lambda\vec{b}$；共面判据 $\vec{c} = \lambda\vec{a} + \mu\vec{b}$。比综合法更机械化、易写。

8. **综合法卡住** → 立刻问：能否设基底用向量？能否建系用解析？高考压轴题往往刻意设置成"综合法极难、解析法暴力可推"，会切换的考生赚到时间。

## 六、典型应用 3 例

### 例 1：综合法首选——证明三角形垂心存在

**题目**：在 $\triangle ABC$ 中，证明三条高交于一点（垂心）。

**思路**：

设 $\triangle ABC$ 的高 $AD$（$D \in BC$）、$BE$（$E \in AC$）交于 $H$。要证 $CH \perp AB$。

考虑 $\vec{AH}\cdot\vec{BC}$ 和 $\vec{BH}\cdot\vec{AC}$（两条高的垂直条件）：
$$\vec{AH}\cdot\vec{BC} = 0, \quad \vec{BH}\cdot\vec{AC} = 0.$$

展开 $\vec{BC} = \vec{AC} - \vec{AB}$、$\vec{AC} = \vec{BC} + \vec{AB}$，整理可推出 $\vec{CH}\cdot\vec{AB} = 0$，即 $CH \perp AB$。

**选剑分析**：这道题综合法（用辅助线、相似）也能证，但向量法（用数量积 $= 0$ 表示垂直）最简洁，**因为"垂直"恰好是数量积的标配场景**。

---

### 例 2：解析法首选——含参直线过定点

**题目**：直线 $l: (2k+1)x + (k-1)y - 3k = 0$（$k \in \mathbb{R}$）必过哪个定点？

**思路**：

把含 $k$ 的项分离：$k(2x + y - 3) + (x - y) = 0$。

这是关于 $k$ 的恒等式，须对任意 $k$ 都成立，故两个系数同时为零：
$$\begin{cases} 2x + y - 3 = 0 \\ x - y = 0 \end{cases}$$

联立解得 $x = 1$、$y = 1$。

**答**：定点 $(1, 1)$。

**选剑分析**：纯解析法。含参直线过定点是直线方程的固定套路——**含参分离 → 系数都为零**。综合法 / 向量法在此无优势。

---

### 例 3：向量法首选——立体几何二面角

**题目**：正方体 $ABCD\text{-}A_1B_1C_1D_1$，棱长 $1$，求二面角 $A_1\text{-}BD\text{-}C$ 的余弦值。

**思路**：

以 $D$ 为原点，$DA$、$DC$、$DD_1$ 为 $x$、$y$、$z$ 轴建系：
- $A = (1, 0, 0)$，$B = (1, 1, 0)$，$C = (0, 1, 0)$，$A_1 = (1, 0, 1)$。

二面角 $A_1\text{-}BD\text{-}C$ 的棱是 $BD$，方向 $\vec{BD} = (-1, -1, 0)$。

在棱 $BD$ 上取一点（如 $D$ 或中点），分别向两个半平面取向量：
- 半平面 1（含 $A_1$）的法向量需垂直 $\vec{BD}$ 且在该半平面内：取 $\vec{DA_1} = (1, 0, 1)$，投影到与 $BD$ 垂直的方向。

更简洁的做法：分别求两个半平面的**法向量**，二面角的余弦 = 法向量夹角的余弦（或其相反数，看方向）。

平面 $A_1BD$ 的法向量：$\vec{DA_1} \times \vec{DB} = (1, 0, 1) \times (1, 1, 0) = (-1, 1, 1)$。

平面 $CBD$ 的法向量：$\vec{DC} \times \vec{DB} = (0, 1, 0) \times (1, 1, 0) = (0, 0, -1)$。

$$\cos\theta = \frac{(-1, 1, 1)\cdot(0, 0, -1)}{|(-1, 1, 1)| \cdot |(0, 0, -1)|} = \frac{-1}{\sqrt{3}\cdot 1} = -\frac{\sqrt{3}}{3}.$$

二面角的余弦值为 $\dfrac{\sqrt{3}}{3}$（取绝对值，结合图形判定锐二面角）。

**选剑分析**：立体几何二面角是向量法最大的主场。综合法要找棱上的点、作两个半平面内垂直棱的射线、再算夹角，工序繁多；向量法只需建系、算法向量、求夹角，完全机械化。

## 七、自测题

**第 1 题**：在 $\triangle ABC$ 中，已知 $a = 2$，$b = \sqrt{3}$，$\angle C = \dfrac{\pi}{6}$，求 $c$。

提示：识别"两边一角求边"——三角法（余弦定理）首选。$c^2 = a^2 + b^2 - 2ab\cos C = 4 + 3 - 2\cdot 2\cdot\sqrt{3}\cdot\dfrac{\sqrt{3}}{2} = 7 - 6 = 1$，故 $c = 1$。

---

**第 2 题**：已知点 $A(1, 2)$、$B(3, -1)$，求线段 $AB$ 的中点坐标和长度。

提示：解析法。中点 $M = \left(\dfrac{1+3}{2}, \dfrac{2-1}{2}\right) = (2, \dfrac{1}{2})$；长度 $|AB| = \sqrt{(3-1)^2 + (-1-2)^2} = \sqrt{4+9} = \sqrt{13}$。

---

**第 3 题**：在正方体 $ABCD\text{-}A_1B_1C_1D_1$ 中，求异面直线 $AB_1$ 与 $A_1D$ 的夹角余弦。

提示：向量法首选。建系（$D$ 为原点，$DA$、$DC$、$DD_1$ 为坐标轴），$A = (1,0,0)$、$B_1 = (1,1,1)$、$A_1 = (1,0,1)$、$D = (0,0,0)$，$\vec{AB_1} = (0,1,1)$，$\vec{A_1D} = (-1,0,-1)$。$\cos\theta = \dfrac{|(0)(−1)+(1)(0)+(1)(−1)|}{\sqrt{2}\cdot\sqrt{2}} = \dfrac{1}{2}$。

---

**第 4 题**：在 $\triangle ABC$ 中，$D$ 是 $BC$ 中点，证明 $\vec{AD} = \dfrac{1}{2}(\vec{AB} + \vec{AC})$。

提示：向量法。$D$ 是中点意味着 $\vec{BD} = \vec{DC}$，则 $\vec{AD} = \vec{AB} + \vec{BD} = \vec{AB} + \dfrac{1}{2}\vec{BC} = \vec{AB} + \dfrac{1}{2}(\vec{AC} - \vec{AB}) = \dfrac{1}{2}\vec{AB} + \dfrac{1}{2}\vec{AC}$。

---

**第 5 题**：圆 $C: (x-2)^2 + (y-1)^2 = 5$ 上是否存在点到原点距离最大？若存在，求该距离。

提示：解析法 + 几何意义（toolkit 03）。圆心 $C(2, 1)$，$|OC| = \sqrt{5}$，半径 $r = \sqrt{5}$，所以原点到圆上点的最大距离 $= |OC| + r = 2\sqrt{5}$。
