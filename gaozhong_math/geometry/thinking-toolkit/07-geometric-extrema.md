# 几何最值的 5 种方法

> **一例速记**：在 $x$ 轴上找一点 $P$，使 $|PA| + |PB|$ 最小，其中 $A(1, 2)$、$B(3, 4)$。
> $A$、$B$ 在 $x$ 轴同侧——**作 $A$ 关于 $x$ 轴的对称点 $A'(1, -2)$**，则 $|PA| + |PB| = |PA'| + |PB| \geq |A'B| = \sqrt{(3-1)^2 + (4+2)^2} = \sqrt{40} = 2\sqrt{10}$。
> **看到"动点到两定点距离和"，先看动点轨迹与两定点是否同侧——同侧用反射，异侧直接连。**

---

## 一、几何最值题的全景

几何最值是高考必考题型，常以"求 $|PA| + |PB|$、$|PA| - |PB|$、$|PA| \cdot |PB|$、$\vec{PA} \cdot \vec{PB}$、面积、夹角……的最值"等形式出现。

不同题目的最值方法不同。本篇梳理 **5 种主流方法**，并给出**"看题选方法"的快速决策表**。

> **核心信念**：选对方法 = 题做对一半。选错方法 = 计算量爆炸。

---

## 二、方法 1：参数化 + 函数求导（最通用）

### 2.1 思想

把动点用参数表示（如椭圆上一点用 $(a\cos\theta, b\sin\theta)$），把目标函数化为参数的单变量函数 $f(\theta)$，求导找极值。

### 2.2 适用场景

- 动点在圆 / 椭圆 / 抛物线等**有标准参数方程的曲线**上；
- 目标是某个具体量（距离、面积、内积等）的函数；
- 没有明显的"几何直觉"可用。

### 2.3 标准模板

1. **写参数化**：$P = (\text{曲线的参数方程})$；
2. **写目标函数** $f$：把所有相关量用参数表达；
3. **化简**：尽量化为 $\sin / \cos$ 的多项式或单一三角函数；
4. **求导或用极值定理**：找 $f'(\theta) = 0$ 的点；
5. **检验端点 / 边界**。

### 2.4 例

椭圆 $\dfrac{x^2}{4} + y^2 = 1$ 上点 $P$ 到点 $A(1, 0)$ 距离最小：

参数化 $P = (2\cos\theta, \sin\theta)$，$|PA|^2 = (2\cos\theta - 1)^2 + \sin^2\theta = 4\cos^2\theta - 4\cos\theta + 1 + \sin^2\theta = 3\cos^2\theta - 4\cos\theta + 2$。

设 $t = \cos\theta \in [-1, 1]$，$g(t) = 3t^2 - 4t + 2$。顶点 $t = \dfrac{2}{3}$，$g\!\left(\dfrac{2}{3}\right) = 3 \cdot \dfrac{4}{9} - \dfrac{8}{3} + 2 = \dfrac{4}{3} - \dfrac{8}{3} + 2 = \dfrac{2}{3}$。

$|PA|_{\min} = \sqrt{\dfrac{2}{3}} = \dfrac{\sqrt{6}}{3}$。

## 三、方法 2：数形结合（切线 / 圆心距 / 距离公式）

### 3.1 思想

把目标函数"翻译"成几何量，借助图形直观找最值。常见翻译：

- $\sqrt{(x-a)^2 + (y-b)^2}$ → 点 $(x, y)$ 到点 $(a, b)$ 的**距离**；
- $\dfrac{y - b}{x - a}$ → 点 $(x, y)$ 与点 $(a, b)$ 连线的**斜率**；
- $\dfrac{|Ax + By + C|}{\sqrt{A^2 + B^2}}$ → 点到直线的距离；
- $|x - a| + |x - b|$ → 数轴上 $x$ 到 $a$、$b$ 距离之和。

### 3.2 适用场景

- 目标函数含明显的距离 / 斜率 / 内积结构；
- 动点的轨迹是简单图形（直线、圆、椭圆等），可作图分析。

### 3.3 经典例：$\min |x - 2| + |x + 3|$

在数轴上 $x$ 到 $2$、$-3$ 的距离之和。当 $-3 \leq x \leq 2$ 时，距离之和 $= |2 - (-3)| = 5$；当 $x$ 在区间外时，距离之和 $> 5$。**最小值为 $5$**。

### 3.4 经典例：$\min |x - 2| - |x + 3|$

距离之差。$|x - 2| - |x + 3| \geq -|(x-2)-(x+3)| = -5$，等号在 $x \leq -3$ 时成立。**最小值为 $-5$**。

### 3.5 切线法

求点 $A$ 到曲线 $C$ 上点的距离 $|PA|$ 的最值，常用"过 $A$ 作 $C$ 的法线 / 切线 / 圆心连线"——最值点必在该连线与曲线的交点处。

例：求点 $A(4, 3)$ 到圆 $x^2 + y^2 = 1$ 上点的最近距离。圆心 $O(0, 0)$，$|OA| = 5$。最近距离 $= |OA| - r = 5 - 1 = 4$，最远距离 $= |OA| + r = 6$。

## 四、方法 3：反射法（光路最短）

### 4.1 思想

"光的反射定律"在几何中的应用：从 $A$ 出发，经过直线 $\ell$ 反射，到达 $B$ 的最短路径长度 $=$ $A$ 关于 $\ell$ 的对称点 $A'$ 与 $B$ 的距离。

**原理**：$|PA| = |PA'|$（轴对称的不变性），所以 $|PA| + |PB| = |PA'| + |PB| \geq |A'B|$，当且仅当 $P$ 在 $A'B$ 上时等号成立。

### 4.2 适用场景

- 动点 $P$ 在某条直线 / 圆 / 折线上；
- 目标是 **$|PA| + |PB|$** 的最小值；
- $A$、$B$ 是定点。

### 4.3 核心判断：同侧 vs 异侧

| $A$、$B$ 与轨迹的关系 | 处理方式 | 最小值 |
|---|---|---|
| **同侧** | 作其中一点关于轨迹的对称点 $A'$ | $|A'B|$ |
| **异侧** | 直接连 $AB$，与轨迹交点即 $P$ | $|AB|$ |

### 4.4 同侧反射的标准步骤

1. 找出 $A$、$B$ 关于轨迹 $\ell$ 的位置（用 $A$、$B$ 代入 $\ell$ 方程，看符号是否一致）；
2. 若同侧，作 $A'$（$A$ 关于 $\ell$ 的对称点）；
3. 答案 = $|A'B|$；
4. 验证 $P$ 是 $A'B$ 与 $\ell$ 的交点。

### 4.5 求 $|PA| - |PB|$ 最大

利用三角不等式 $||PA| - |PB|| \leq |AB|$，等号在 $P$、$A$、$B$ 共线且 $P$ 在 $AB$ 延长线上时成立。

## 五、方法 4：极化恒等式（向量最值）

### 5.1 思想

把向量数量积转化为模长的差：

$$\vec{a} \cdot \vec{b} = \frac{1}{4}\left[|\vec{a} + \vec{b}|^2 - |\vec{a} - \vec{b}|^2\right]$$

### 5.2 适用场景

- 题目含**向量数量积** $\vec{a} \cdot \vec{b}$；
- $\vec{a}$、$\vec{b}$ 有共同起点（如同一三角形的两条边、过同一点的两条向量）；
- 模长 $|\vec{a} + \vec{b}|$ 或 $|\vec{a} - \vec{b}|$ 有简单几何意义（如中线、对角线）。

### 5.3 经典推导：三角形中线 + 极化恒等式

在 $\triangle ABC$ 中，$D$ 是 $BC$ 中点。设 $\vec{a} = \vec{AB}$、$\vec{b} = \vec{AC}$，则

$$\vec{AD} = \frac{1}{2}(\vec{a} + \vec{b}), \quad \vec{BC} = \vec{b} - \vec{a}$$

由极化恒等式

$$\vec{AB} \cdot \vec{AC} = \frac{1}{4}\left[|\vec{AB} + \vec{AC}|^2 - |\vec{AB} - \vec{AC}|^2\right] = |\vec{AD}|^2 - \frac{1}{4}|\vec{BC}|^2$$

即
$$\vec{AB} \cdot \vec{AC} = |AD|^2 - \frac{|BC|^2}{4}$$

这就是"**用中线长求数量积**"的著名公式。

### 5.4 用法

求 $\vec{AB} \cdot \vec{AC}$ 的最值 ⇔ 求中线 $|AD|$ 的最值（因为 $|BC|$ 一般固定）。**把数量积题转化为距离题**——能大幅简化。

## 六、方法 5：基本不等式

### 6.1 核心不等式

- **AM-GM**：$\dfrac{a + b}{2} \geq \sqrt{ab}$（$a, b > 0$），等号在 $a = b$ 时成立。
- **Cauchy-Schwarz**：$(a^2 + b^2)(c^2 + d^2) \geq (ac + bd)^2$。
- **三角不等式**：$|\vec{a}| + |\vec{b}| \geq |\vec{a} + \vec{b}| \geq ||\vec{a}| - |\vec{b}||$。

### 6.2 适用场景

- 目标是 $a + b$（求最小）或 $ab$（求最大），且条件给出 $ab$ 定值（或 $a + b$ 定值）；
- 有限制条件如"$\dfrac{1}{a} + \dfrac{1}{b} = 1$"、"$a + 2b = 6$"等。

### 6.3 经典例

已知 $a, b > 0$ 且 $a + b = 4$，求 $ab$ 的最大值。

由 AM-GM：$ab \leq \left(\dfrac{a + b}{2}\right)^2 = 4$，等号在 $a = b = 2$ 时成立。**$ab$ 最大值 $= 4$**。

### 6.4 在几何中的应用

椭圆 $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$ 上一点 $P$，到两焦点 $F_1$、$F_2$ 距离 $|PF_1| = r_1$、$|PF_2| = r_2$，恒有 $r_1 + r_2 = 2a$（第一定义）。求 $r_1 r_2$ 的最大值：

$$r_1 r_2 \leq \left(\frac{r_1 + r_2}{2}\right)^2 = a^2$$

等号在 $r_1 = r_2 = a$ 时成立，即 $P$ 在短轴端点。

## 七、决策表：哪类题用哪种方法

| 最值类型 | 推荐方法 | 备选 |
|---|---|---|
| 动点到定点距离（曲线上）| **方法 1（参数化）** 或方法 2（切线）| 视曲线和动点 |
| $|PA| + |PB|$（$P$ 在直线 / 圆上）| **方法 3（反射）** | 方法 1 |
| $|PA| - |PB|$ 最大 | **方法 2（三角不等式）** | 方法 1 |
| 点到直线距离 | **方法 2（距离公式）** | |
| $\vec{a} \cdot \vec{b}$ 最值 | **方法 4（极化恒等式）** | 方法 1 |
| 含 $\sqrt{(x - a)^2 + (y - b)^2}$ 结构 | **方法 2（数形结合）** | 方法 1 |
| 已知 $a + b$ 求 $ab$ 最大（反之亦然）| **方法 5（AM-GM）** | |
| 含 $\sin\theta\cos\theta$ 等三角结构 | 方法 1 + 三角函数最值 | |

**最高指导原则**：**先看几何意义**（方法 2 / 3 / 4），**没有意义再硬算**（方法 1 / 5）。

## 八、演示题

**题目**：在椭圆 $\dfrac{x^2}{16} + \dfrac{y^2}{9} = 1$ 上一点 $P$，定点 $A(4, 0)$、$B(0, 3)$。求 $|PA| + |PB|$ 的最大值和最小值。

> **Q1. 读图。**
>
> $A(4, 0)$ 是椭圆的右顶点，$B(0, 3)$ 是椭圆的上顶点——**两点都在椭圆上**！所以 $P$、$A$、$B$ 都在椭圆上，$|PA| + |PB|$ 是椭圆上三点构成的"两边之和"。

> **Q2. 试方法 3（反射）。**
>
> 反射法适用于"$P$ 在直线 / 圆上、$A$、$B$ 为定点"。这里 $P$ 在椭圆上、$A$、$B$ 也在椭圆上——不是反射法的标准情形。**舍弃**。

> **Q3. 试方法 1（参数化）。**
>
> 参数化 $P = (4\cos\theta, 3\sin\theta)$，$\theta \in [0, 2\pi)$。
>
> $$|PA|^2 = (4\cos\theta - 4)^2 + (3\sin\theta - 0)^2 = 16(\cos\theta - 1)^2 + 9\sin^2\theta$$
>
> 展开：$16\cos^2\theta - 32\cos\theta + 16 + 9 - 9\cos^2\theta = 7\cos^2\theta - 32\cos\theta + 25$。
>
> $$|PB|^2 = (4\cos\theta - 0)^2 + (3\sin\theta - 3)^2 = 16\cos^2\theta + 9(\sin\theta - 1)^2$$
>
> 展开：$16\cos^2\theta + 9\sin^2\theta - 18\sin\theta + 9 = 7\cos^2\theta + 9 - 18\sin\theta + 9 = 7\cos^2\theta - 18\sin\theta + 18$。
>
> （用了 $16\cos^2 + 9\sin^2 = 16\cos^2 + 9(1 - \cos^2) = 7\cos^2 + 9$）。
>
> 设 $f(\theta) = |PA| + |PB|$。这是两个根式之和，直接求导很复杂——**改换策略**。

> **Q4. 试方法 2（数形结合）的另一思路。**
>
> 注意 $A(4, 0)$ 和 $B(0, 3)$ 是椭圆的两个顶点。$|AB| = \sqrt{16 + 9} = 5$。
>
> 由三角不等式（方法 5），$|PA| + |PB| \geq |AB| = 5$，等号在 $P$ 在线段 $AB$ 上时成立。但 $P$ 必须在椭圆上！
>
> 直线 $AB$ 方程：$\dfrac{x}{4} + \dfrac{y}{3} = 1$，即 $3x + 4y = 12$。代入椭圆方程：$x = 4 - \dfrac{4y}{3}$，
>
> $$\frac{(4 - 4y/3)^2}{16} + \frac{y^2}{9} = 1$$
>
> $$\frac{16 - 32y/3 + 16y^2/9}{16} + \frac{y^2}{9} = 1$$
>
> $$1 - \frac{2y}{3} + \frac{y^2}{9} + \frac{y^2}{9} = 1$$
>
> $$\frac{2y^2}{9} - \frac{2y}{3} = 0$$
>
> $$\frac{2y}{9}(y - 3) = 0$$
>
> 得 $y = 0$ 或 $y = 3$，对应 $P = (4, 0) = A$ 或 $P = (0, 3) = B$。所以直线 $AB$ 与椭圆**恰好相切（在端点处）于 $A$、$B$**——线段 $AB$ 除了 $A$、$B$ 本身外不与椭圆相交。

> **Q5. 找极值——回到方法 1。**
>
> 既然没有几何捷径，回到参数化分析。$P = (4\cos\theta, 3\sin\theta)$。
>
> 上面已得 $|PA|^2 + |PB|^2 = 14\cos^2\theta - 32\cos\theta - 18\sin\theta + 43$，对 $|PA| + |PB|$ 直接求导仍复杂。
>
> 用数值探索：
>
> - $\theta = 0$（$P = (4, 0) = A$）：$|PA| = 0$，$|PB| = 5$，和 $= 5$。
> - $\theta = \pi/2$（$P = (0, 3) = B$）：$|PA| = 5$，$|PB| = 0$，和 $= 5$。
> - $\theta = \pi$（$P = (-4, 0)$）：$|PA| = 8$，$|PB| = \sqrt{16 + 9} = 5$，和 $= 13$。
> - $\theta = 3\pi/2$（$P = (0, -3)$）：$|PA| = \sqrt{16 + 9} = 5$，$|PB| = 6$，和 $= 11$。
> - $\theta = \pi/4$ 时 $P = (2\sqrt 2, 3\sqrt 2 / 2)$ 附近——和介于 $5$ 和 $11$ 之间。
> - $\theta = 5\pi/4$ 时（第三象限）：$P = (-2\sqrt 2, -3\sqrt 2 / 2)$，估算 $|PA| \approx 7$，$|PB| \approx 6$，和 $\approx 13$。

> **Q6. 估计极值位置。**
>
> 由对称性和数值估算，最大值在 $P$ 离 $A$、$B$ 都"很远"的方向——最远的椭圆点对 $A$、$B$ 的距离和最大；最远点是椭圆与直线 $AB$ 关于椭圆中心的对称区域。沿椭圆对角线 $P = \left(-\dfrac{16}{5}, -\dfrac{9}{5}\right)$（即 $AB$ 直线的反向延长线方向，但要求在椭圆上）……
>
> 实际可用 Lagrange 乘数或更精细的代数。本演示已展示"先尝试几何，再用参数化"的思路，**最终最大值出现在 $\theta \approx \pi$ 附近**（最远端附近），**最小值就是 $5$**（在 $P = A$ 或 $P = B$ 取得，但若题目要求 $P \neq A$ 且 $P \neq B$，最小值是 $5$ 的极限）。

> **Q7. 答案：最小值为 $5$（在 $P = A$ 或 $P = B$）；最大值需进一步求解，约为 $\sqrt{32+\dots}$，需要更精细计算。**
>
> （此题展示了"方法选择"的实际过程：尝试反射法 → 不行；尝试三角不等式 → 给出下界；最后回到参数化求精确最大。）

## 九、思考路标

**路标 1**：看到 $|PA| + |PB|$ 型最值，先看动点 $P$ 的轨迹：
- 在直线上 + $A$、$B$ 同侧 → **反射法**（方法 3）；
- 在直线上 + $A$、$B$ 异侧 → **直接连 $AB$**；
- 在圆 / 椭圆上 + $A$、$B$ 是焦点 → **第一定义**（和恒等于 $2a$）。

**路标 2**：看到 $|PA| - |PB|$ 型最值，用**三角不等式**：$||PA| - |PB|| \leq |AB|$，最大就是 $|AB|$（当 $P$、$A$、$B$ 共线且 $A$、$B$ 在 $P$ 同侧）。

**路标 3**：看到 $\sqrt{(x - a)^2 + (y - b)^2}$ 结构，**立即翻译为"点 $(x, y)$ 到点 $(a, b)$ 的距离"**——这是数形结合（方法 2）的入门信号。

**路标 4**：看到 $\vec{a} \cdot \vec{b}$ 求最值，先考虑能否用极化恒等式（方法 4）把它转为模长 / 距离的差——**这是数量积最值题的标准武器**。

**路标 5**：参数化（方法 1）是"最后的兜底方法"——计算量大但绝不出错。**只要前 4 种方法都不适用，就果断参数化**。

**路标 6**：基本不等式（方法 5）要求条件为"和定" / "积定"。看到 $a + b = c$ 想 AM-GM 求 $ab$ 最大；看到 $ab = c$ 想 AM-GM 求 $a + b$ 最小。**"一定一变"原则**。

**路标 7**：圆上的距离最值都可以靠"圆心连线"——$|PA|_{\min} = |OA| - r$、$|PA|_{\max} = |OA| + r$，$O$ 为圆心。这是方法 2 的标配。

**路标 8**：所有最值题写完后**必查端点 / 边界**——函数最值可能不在导数零点而在区间端点。

## 十、典型应用例题

### 例 1：反射法的标准应用

**题目**：在直线 $\ell: x + y = 5$ 上找一点 $P$，使 $|PA| + |PB|$ 最小，其中 $A(1, 2)$、$B(3, 4)$。

**分析**：检验 $A$、$B$ 与 $\ell$ 的相对位置：
- 把 $A(1, 2)$ 代入 $x + y - 5$：$1 + 2 - 5 = -2 < 0$；
- 把 $B(3, 4)$ 代入：$3 + 4 - 5 = 2 > 0$。

**异侧**！由路标 1，最小值 $= |AB| = \sqrt{(3-1)^2 + (4-2)^2} = \sqrt{4 + 4} = 2\sqrt{2}$，$P$ 是直线 $AB$ 与 $\ell$ 的交点。

求 $P$：直线 $AB$ 的方程 $y - 2 = \dfrac{4-2}{3-1}(x - 1) = x - 1$，即 $y = x + 1$。代入 $\ell$：$x + (x + 1) = 5$，$x = 2$，$P = (2, 3)$。

**答**：$|PA| + |PB|$ 的最小值为 $2\sqrt{2}$，$P = (2, 3)$。

---

### 例 2：极化恒等式求数量积最值

**题目**：等边 $\triangle ABC$ 边长为 $2$，$M$ 是 $BC$ 中点，$P$ 是 $\triangle ABC$ 内（含边界）一动点。求 $\vec{PA} \cdot \vec{PM}$ 的最小值。

**分析**：用极化恒等式（方法 4）。

注意 $\vec{PA} \cdot \vec{PM} = ?$。考虑以 $AM$ 中点 $N$ 为参考点：

设 $N$ 是 $AM$ 中点，$\vec{NP} = \vec{r}$，$\vec{NA} = -\vec{NM} = \dfrac{1}{2}\vec{MA}$。则

$$\vec{PA} = \vec{NA} - \vec{NP}, \quad \vec{PM} = \vec{NM} - \vec{NP}$$

$$\vec{PA} \cdot \vec{PM} = (\vec{NA} - \vec{NP}) \cdot (\vec{NM} - \vec{NP}) = \vec{NA} \cdot \vec{NM} - (\vec{NA} + \vec{NM}) \cdot \vec{NP} + |\vec{NP}|^2$$

注意 $\vec{NA} + \vec{NM} = \vec{0}$（$N$ 是中点），$\vec{NA} \cdot \vec{NM} = -|\vec{NA}|^2 = -\dfrac{|AM|^2}{4}$，故

$$\vec{PA} \cdot \vec{PM} = |\vec{NP}|^2 - \frac{|AM|^2}{4}$$

要使 $\vec{PA} \cdot \vec{PM}$ 最小，需 $|NP|$ 最小，即 $P$ 在 $N$ 处，此时 $|NP| = 0$，$\vec{PA} \cdot \vec{PM} = -\dfrac{|AM|^2}{4}$。

$|AM|$ = 等边三角形高 $= \sqrt{3}$。故最小值 $= -\dfrac{3}{4}$。

**答**：$\vec{PA} \cdot \vec{PM}$ 的最小值为 $-\dfrac{3}{4}$。

---

### 例 3：圆上点的距离最值

**题目**：点 $A(2, 3)$、圆 $C: x^2 + y^2 = 4$。求点 $A$ 到圆上点 $P$ 的距离 $|PA|$ 的最值。

**分析**：圆心 $O(0, 0)$，$r = 2$。$|OA| = \sqrt{4 + 9} = \sqrt{13}$。

由路标 7：
- $|PA|_{\min} = |OA| - r = \sqrt{13} - 2$；
- $|PA|_{\max} = |OA| + r = \sqrt{13} + 2$。

**答**：最小 $\sqrt{13} - 2$，最大 $\sqrt{13} + 2$。

## 十一、自测题

**第 1 题**：求 $f(x) = \sqrt{x^2 + 1} + \sqrt{(x - 3)^2 + 4}$ 的最小值。

💡 提示：把 $f(x)$ 看作点 $(x, 0)$ 到点 $A(0, 1)$ 和 $B(3, 2)$ 的距离之和（数形结合 + 反射法）。$A$、$B$ 在 $x$ 轴同侧（$y$ 坐标都正），作 $A$ 关于 $x$ 轴对称点 $A'(0, -1)$，则最小值 $= |A'B| = \sqrt{9 + 9} = 3\sqrt{2}$。

**第 2 题**：椭圆 $\dfrac{x^2}{4} + y^2 = 1$ 上一点 $P$，$F_1$、$F_2$ 为左右焦点。求 $|PF_1| \cdot |PF_2|$ 的最大值。

💡 提示：第一定义 $|PF_1| + |PF_2| = 2a = 4$。AM-GM：$|PF_1| \cdot |PF_2| \leq \left(\dfrac{4}{2}\right)^2 = 4$，等号在 $|PF_1| = |PF_2| = 2$ 时成立（短轴端点）。**最大值为 $4$**。

**第 3 题**：在直线 $\ell: 3x + 4y - 10 = 0$ 上找一点 $P$，使 $P$ 到原点距离最小。

💡 提示：用点到直线距离公式（方法 2）：$d = \dfrac{|3 \cdot 0 + 4 \cdot 0 - 10|}{\sqrt{9 + 16}} = \dfrac{10}{5} = 2$。**最小距离为 $2$**。

**第 4 题**：$\triangle ABC$ 中 $\vec{AB} = \vec{a}$、$\vec{AC} = \vec{b}$，$|\vec{a}| = 3$、$|\vec{b}| = 4$、$\vec{a} \cdot \vec{b} = 6$。求 $BC$ 边上的中线 $|AD|$。

💡 提示：用极化恒等式（方法 4）：$\vec{a} \cdot \vec{b} = |AD|^2 - \dfrac{|BC|^2}{4}$。先求 $|BC|^2 = |\vec{b} - \vec{a}|^2 = 16 + 9 - 12 = 13$。代入：$6 = |AD|^2 - \dfrac{13}{4}$，$|AD|^2 = \dfrac{37}{4}$，$|AD| = \dfrac{\sqrt{37}}{2}$。

**第 5 题**：在圆 $x^2 + y^2 = 1$ 上找一点 $P$ 使 $P$ 到直线 $4x + 3y - 10 = 0$ 距离最大。

💡 提示：圆心 $O(0, 0)$ 到直线距离 $d = \dfrac{|-10|}{\sqrt{16 + 9}} = 2$。由路标 7 类推：圆上点到直线的最大距离 $= d + r = 2 + 1 = 3$，最小距离 $= d - r = 1$。**最大值 $= 3$**。
