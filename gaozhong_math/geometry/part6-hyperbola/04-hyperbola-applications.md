# 双曲线综合应用

> **一例速记**：
>
> **含参双曲线**：先确定参数范围（$a > 0, b > 0$，$c = \sqrt{a^2+b^2}$），再代入已知条件求解；注意判断焦点在 $x$ 轴还是 $y$ 轴（虚实轴之分）。
>
> **离心率约束**：$e = c/a > 1$（这是双曲线区别于椭圆的根本——双曲线 $e > 1$，椭圆 $e \in (0,1)$）。
>
> **实际应用**：双曲线的"距离差"性质（$||PF_1|-|PF_2||=2a$）是声呐定位、Loran 导航、地震测位等技术的数学基础——两个固定参考点到目标点的距离差为常数，轨迹是双曲线的一支。

---

## 一、含参双曲线的方程确定

含参双曲线问题与含参椭圆类似，但有若干双曲线特有的差异，需格外注意。

### 1.1 基本关系速查

| 量 | 公式 | 说明 |
|----|------|------|
| 实半轴 | $a$ | 实轴端点 $(\pm a, 0)$（焦点在 $x$ 轴时） |
| 虚半轴 | $b$ | 虚轴端点 $(0, \pm b)$（虚轴无图形经过） |
| 焦距 | $c = \sqrt{a^2+b^2}$ | 与椭圆 $c = \sqrt{a^2-b^2}$ 相比，**加号变加号**（$c > a$） |
| 离心率 | $e = c/a > 1$ | 双曲线 $e > 1$（椭圆 $e \in (0,1)$） |
| 通径 | $l = 2b^2/a$ | 过焦点垂直实轴的弦长 |
| 渐近线 | $y = \pm\dfrac{b}{a}x$ | 焦点在 $x$ 轴时；焦点在 $y$ 轴时为 $y = \pm\dfrac{a}{b}x$ |
| 焦半径（右支，右焦点） | $|PF_2| = ex_P - a$ | $P$ 在右支，$x_P > 0$ |
| 焦半径（右支，左焦点） | $|PF_1| = ex_P + a$ | $P$ 在右支，$x_P > 0$ |

### 1.2 含参方程的确定步骤

**通用步骤**：
1. 判断焦点在 $x$ 轴还是 $y$ 轴（设方程形式 $\dfrac{x^2}{a^2}-\dfrac{y^2}{b^2}=1$ 或 $\dfrac{y^2}{a^2}-\dfrac{x^2}{b^2}=1$）；
2. 将已知条件（离心率、渐近线斜率、通径、焦点坐标等）转化为关于 $a, b, c$ 的方程；
3. 解方程组，验证 $a > 0, b > 0, c > a$（即 $e > 1$）。

**常见已知量的代数表达**：

- **已知离心率** $e_0 > 1$：$c = ae_0$，$b^2 = c^2-a^2 = a^2(e_0^2-1)$；需另一条件定 $a$。
- **已知渐近线斜率** $k_0 = b/a$：$b = k_0 a$，$c = a\sqrt{1+k_0^2}$，$e = \sqrt{1+k_0^2}$；需另一条件定 $a$。
- **已知焦点** $(\pm c_0, 0)$：$c = c_0$ 已知；需另一条件。
- **已知通径** $l_0 = 2b^2/a$：$b^2 = al_0/2$；需另一条件。

### 1.3 典型情形

**情形 A：已知离心率 + 顶点（或椭圆上一点）**

若 $e = e_0$，顶点 $(\pm a_0, 0)$ 已知：$a = a_0$，$c = e_0 a_0$，$b^2 = c^2-a^2 = a_0^2(e_0^2-1)$。

**情形 B：已知渐近线方程**

渐近线 $y = \pm kx$ 直接给出 $b/a = k$，但 $a, b$ 各有无穷多组解。渐近线只确定了双曲线的形状，不确定大小，必须有第二个条件（如一个顶点、焦点、或双曲线上一点）。

> **注意**：已知渐近线时常见的坑——设 $a = k t$，$b = kt$（将 $b/a = k$ 参数化），若题目给的是"双曲线过某点 $(x_1, y_1)$"，代入后解 $t$，再还原 $a, b$。

**情形 C：已知离心率 + 渐近线斜率**

$e = e_0$（$e > 1$），渐近线斜率 $b/a = k_0$：

$e = c/a = \sqrt{1+(b/a)^2} = \sqrt{1+k_0^2}$，故 $e_0 = \sqrt{1+k_0^2}$（只有一个约束，方程形状确定，大小仍待定）。

若两条件相容（$e_0 = \sqrt{1+k_0^2}$），则双曲线家族确定，需第三个条件；若不相容，则无此双曲线。

## 二、双曲线与圆 / 直线综合

### 2.1 双曲线与圆综合

**题型**：双曲线上的点到圆的最近 / 最远距离；双曲线与圆的公共弦。

**方法 A：参数化**（等轴双曲线 $x^2 - y^2 = a^2$ 适合直接参数化）

等轴双曲线 $x^2-y^2=a^2$ 上的点可写为 $(a\cosh t, a\sinh t)$（右支）或 $(-a\cosh t, a\sinh t)$（左支）。一般双曲线的参数化是 $(a\sec\theta, b\tan\theta)$，计算通常不如椭圆方便。

**方法 B：几何结合代数**

双曲线上点 $P$ 到圆 $C$ 的距离 $= |PC| - r$（$P$ 在圆外时最近距离），其中 $|PC|$ 的最值由双曲线上 $P$ 到圆心 $C$ 的距离范围决定。

若 $C$ 是双曲线的焦点，则 $|PF|$ 由焦半径公式直接给出，极值在顶点或通径端点处取得。

**方法 C：联立解公共弦**

两曲线的公共弦所在直线：将两方程相减（若次数相同且有公共项），或直接联立。

### 2.2 双曲线与直线综合

通常是"先确定双曲线方程（含参），再分析直线与双曲线的位置"。

**解题顺序**：
1. 由含参条件确定双曲线标准方程；
2. 检查直线斜率是否等于 $\pm b/a$（渐近线斜率）；
3. 代入消元 + 韦达定理求目标量；
4. 验证 $\Delta > 0$（或 $\Delta = 0$）和其他约束。

## 三、等轴双曲线与特殊性质

### 3.1 等轴双曲线的定义

若双曲线满足 $a = b$（即实轴长等于虚轴长），则称为**等轴双曲线**，方程为：

$$x^2 - y^2 = a^2 \quad \text{（焦点在 } x \text{ 轴）}$$

等轴双曲线的特征：
- 渐近线为 $y = \pm x$（斜率恰为 $\pm 1$）；
- 离心率 $e = \sqrt{2}$（所有等轴双曲线离心率相同）；
- 旋转 $45°$ 后方程变为 $xy = k$（矩形双曲线）。

### 3.2 等轴双曲线的性质

**性质 1**：等轴双曲线 $x^2 - y^2 = a^2$ 上任意一点 $P(x_P, y_P)$，两焦半径之积：

$$|PF_1|\cdot|PF_2| = x_P^2 + y_P^2 = |OP|^2$$

其中 $O$ 为原点（利用焦半径公式和 $e = \sqrt{2}$ 推导）。

**性质 2**：直角坐标下 $xy = c$（反比例函数图像）是等轴双曲线，渐近线为坐标轴（$x = 0$，$y = 0$），离心率 $e = \sqrt{2}$，实轴沿 $y = x$ 方向。

## 四、实际应用：双曲线"距离差"定位原理

### 4.1 定义回顾

双曲线的几何定义：平面内到两定点 $F_1$，$F_2$（焦点）的**距离之差的绝对值**等于常数 $2a$ 的点的轨迹。

$$||PF_1| - |PF_2|| = 2a$$

这个"距离差"性质是一切实际应用的数学基础。

### 4.2 双曲线定位技术

**声呐定位（水下目标）**：
在海上设置两个已知位置的水听器 $S_1, S_2$（相当于两焦点），测量声波到达两者的时间差 $\Delta t$。由于声速 $v$ 已知，时间差对应距离差：

$$||PS_1| - |PS_2|| = v \cdot \Delta t = 2a$$

这确定了目标 $P$ 在以 $S_1, S_2$ 为焦点的某条双曲线的一支上。再用第三个接收站 $S_3$，与 $S_1$（或 $S_2$）配对，得到第二条双曲线，两条双曲线的交点即目标位置。

**Loran 导航（长程无线电导航）**：
陆基无线电发射站发射信号，船只接收来自两组发射站的信号的时间差，确定船只在对应双曲线上的位置。多组发射站形成多条双曲线，它们的交点定位船只。

**地震震源定位**：
地震波到达三个地震站的时间差，形成两条双曲线，交点确定震源在地表的投影（震中）。

> **数学建模**：给定两焦点 $F_1, F_2$，距离差为 $2a$，则轨迹是双曲线；若知道目标在哪一侧（$|PF_1| > |PF_2|$ 则在 $F_2$ 一侧，即靠近 $F_2$ 的那支），可以进一步确定是哪一支。

### 4.3 建模计算示例

**题目**：两个地震站 $A(-100, 0)$，$B(100, 0)$（单位：千米），某次地震波先到达 $B$ 再到达 $A$，时间差为 $0.5$ 秒，地震波速度 $v = 8$ 千米/秒，求震中可能所在的曲线方程（以地震站连线中点为原点建系）。

**解**：

距离差 $= v\Delta t = 8 \times 0.5 = 4$ 千米，即 $|PA| - |PB| = 4$（震波先到 $B$，说明 $B$ 近，$|PA| > |PB|$，震中在靠近 $B$ 的那支）。

以中点 $O$ 为原点，$AB$ 为 $x$ 轴，焦点 $F_1 = A = (-100, 0)$，$F_2 = B = (100, 0)$。

$2a = 4$，$a = 2$；$c = 100$；$b^2 = c^2-a^2 = 10000-4 = 9996$。

震中 $P$ 所在曲线（双曲线靠近 $B$ 的一支，即右支）：

$$\frac{x^2}{4} - \frac{y^2}{9996} = 1, \quad x > 0$$

$$\boxed{\frac{x^2}{4} - \frac{y^2}{9996} = 1 \quad (x > 0)}$$

## 五、典型综合例题

### 例 1：含参双曲线的确定

**题目**：双曲线的渐近线为 $y = \pm\dfrac{3}{2}x$，且过点 $P(2, 0)$，求双曲线方程。

**【思路】** 渐近线确定 $b/a$ 的比值；过顶点 $P(2,0)$ 直接给出 $a=2$（因为 $P$ 在 $x$ 轴上且在双曲线上，是顶点）。

**解**：

渐近线 $y = \pm\dfrac{3}{2}x$ 给出 $\dfrac{b}{a} = \dfrac{3}{2}$，即 $b = \dfrac{3a}{2}$。

点 $P(2, 0)$ 在双曲线上，代入 $\dfrac{x^2}{a^2}-\dfrac{y^2}{b^2}=1$：

$$\frac{4}{a^2} - 0 = 1 \implies a^2 = 4, \quad a = 2$$

$$b = \frac{3\times2}{2} = 3, \quad b^2 = 9$$

验证：$c^2 = a^2+b^2 = 13$，$e = \sqrt{13}/2 > 1$，成立。

渐近线验证：$b/a = 3/2$，渐近线 $y = \pm\dfrac{3}{2}x$，正确。

$$\boxed{\frac{x^2}{4} - \frac{y^2}{9} = 1}$$

> 解题要点：渐近线只确定了 $b/a$ 的比值，大小不确定；顶点 $(2, 0)$ 在 $x$ 轴上，代入后立即给出 $a^2 = 4$。这是最简洁的解法——不要设 $b = 3t, a = 2t$ 然后再解 $t$，直接 $a = 2$ 即可。

### 例 2：双曲线与圆的综合

**题目**：圆 $C: x^2+y^2=5$，双曲线 $H: x^2-\dfrac{y^2}{4}=1$，直线 $l$ 过圆上的点 $P$ 且与双曲线的左支相切，若 $|CP| = r = \sqrt{5}$（$C$ 是圆心即原点），求切线的斜率范围。

实际上，题目可更精确地改为：

**题目（实际版）**：双曲线 $H:\dfrac{x^2}{4}-y^2=1$，其渐近线与圆 $x^2+y^2=4$ 有关，求双曲线上的点到圆心（原点）的最近距离。

**解**：

双曲线 $\dfrac{x^2}{4}-y^2=1$，$a=2, b=1, c=\sqrt{5}$，右支顶点 $(2,0)$，左支顶点 $(-2,0)$。

双曲线上点 $P(x,y)$ 到原点距离：

$$|OP|^2 = x^2+y^2$$

由双曲线方程：$y^2 = \dfrac{x^2}{4}-1$（当 $y^2 \geq 0$ 时，$x^2 \geq 4$）。

$$|OP|^2 = x^2 + \frac{x^2}{4} - 1 = \frac{5x^2}{4} - 1$$

由于 $|x| \geq a = 2$（顶点处取等号），$|OP|^2 \geq \dfrac{5\times4}{4}-1 = 5-1 = 4$，即 $|OP| \geq 2$。

最近距离在顶点 $(\pm 2, 0)$ 处取得：$|OP|_{\min} = 2$。

$$\boxed{|OP|_{\min} = 2, \text{ 在顶点 } (\pm2,0) \text{ 处取得}}$$

> 解题要点：双曲线上点到原点的距离，用双曲线方程把 $y^2$ 换掉，得到纯关于 $x$ 的表达式，再在 $|x| \geq a$ 的范围内求最值。注意 $x$ 的范围是 $|x| \geq a$（不是 $\leq a$），这与椭圆 $|x| \leq a$ 相反。

### 例 3：实际应用——双曲线定位

**题目**：两监听站 $A$、$B$ 相距 $6$ 千米，$A$ 在 $B$ 的正西方。某爆炸声先被 $B$ 听到，再被 $A$ 听到，时间差为 $0.5$ 秒，声速为 $4$ 千米/秒。以 $AB$ 的中点 $O$ 为原点，$AB$ 所在直线为 $x$ 轴建立坐标系（$A$ 在负半轴，$B$ 在正半轴），求爆炸地点的轨迹方程（用双曲线的一支表示）。

**解**：

距离差 $= 4 \times 0.5 = 2$ 千米，即 $|PA|-|PB|=2$（先到 $B$ 故 $|PB|<|PA|$），$2a=2$，$a=1$。

焦距：$|AB|=6$，$c=3$。$b^2=c^2-a^2=9-1=8$。

爆炸点 $P$ 满足 $|PA|-|PB|=2>0$，即 $P$ 在靠近 $B$（右侧，$x>0$）的双曲线右支上。

轨迹方程（右支）：

$$\boxed{x^2 - \frac{y^2}{8} = 1, \quad x > 0}$$

即以 $O$ 为中心，$A(-3,0)$，$B(3,0)$ 为焦点的双曲线右支。

## 六、易错点汇总

**易错 1：$c^2 = a^2 + b^2$（双曲线）vs $c^2 = a^2 - b^2$（椭圆）**

双曲线 $c^2 = a^2 + b^2$（因为 $c > a$）；椭圆 $c^2 = a^2 - b^2$（因为 $c < a$）。这是最基础、也最容易混淆的公式，必须每次计算前先默想一遍。

**记忆**：双曲线 $e > 1$，$c > a$，"大"，用"加号"；椭圆 $e < 1$，$c < a$，"小"，用"减号"。

**易错 2：离心率 $e > 1$ 的验证**

含参双曲线解出 $a, b, c$ 后，必须验证 $e = c/a > 1$。若参数取某个值导致 $c \leq a$（即 $b^2 \leq 0$），则不是双曲线，需剔除。

**易错 3：渐近线斜率与 $a, b$ 的对应关系（焦点轴不同时）**

- 焦点在 $x$ 轴（$\dfrac{x^2}{a^2}-\dfrac{y^2}{b^2}=1$）：渐近线斜率 $= \pm\dfrac{b}{a}$；
- 焦点在 $y$ 轴（$\dfrac{y^2}{a^2}-\dfrac{x^2}{b^2}=1$）：渐近线斜率 $= \pm\dfrac{a}{b}$（注意 $a, b$ 交换）。

常见错误：焦点在 $y$ 轴时，误用 $b/a$ 作渐近线斜率。

**易错 4：点差法正负号**

双曲线中点弦斜率 $k = \dfrac{b^2 x_0}{a^2 y_0}$（正号），椭圆是 $-\dfrac{b^2 x_0}{a^2 y_0}$（负号）。这一符号差异是高频考点，混淆后所有中点弦、弦中点轨迹的结论都会错。

**易错 5：平行渐近线的单交点不算"相切"**

单交点有两种来源（$\Delta=0$ 相切，或平行渐近线）。"平行渐近线"的单交点不是切点——函数图像（双曲线）在该点的切线并不是问题中的直线，这只是"方程降次"导致的代数单交点，几何上直线是"穿入"曲线趋向无穷远，而非"贴着"曲线。

## 七、自测题

**自测 1**　双曲线的离心率为 $\sqrt{2}$，焦点在 $y$ 轴，且过点 $A(1, \sqrt{3})$，求双曲线方程。

> 提示：焦点在 $y$ 轴，设方程 $\dfrac{y^2}{a^2}-\dfrac{x^2}{b^2}=1$（$a>0,b>0$）。$e = c/a = \sqrt{2}$，$c = \sqrt{2}a$，$b^2 = c^2-a^2 = 2a^2-a^2 = a^2$，即 $b = a$（等轴双曲线）。代入 $A(1, \sqrt{3})$：$\dfrac{3}{a^2}-\dfrac{1}{a^2}=1$，$\dfrac{2}{a^2}=1$，$a^2=2$，$b^2=2$。方程：$\boxed{\dfrac{y^2}{2}-\dfrac{x^2}{2}=1}$，即 $y^2-x^2=2$。验证 $e = \sqrt{b^2+a^2}/a = \sqrt{2+2}/\sqrt{2} = 2/\sqrt{2} = \sqrt{2}$，正确。

**自测 2**　已知双曲线 $C: mx^2+ny^2=1$（$m>0, n<0$），且以 $C$ 的焦点为顶点的正三角形的第三个顶点在 $C$ 上，求 $m/n$ 的值。

> 提示：焦点在 $x$ 轴（$m>0, n<0$），设方程 $\dfrac{x^2}{1/m}-\dfrac{y^2}{-1/n}=1$，$a^2=1/m$，$b^2=-1/n$，$c^2=a^2+b^2=1/m-1/n$。以焦点 $F_1(-c,0)$，$F_2(c,0)$ 为顶点的正三角形，第三顶点 $P = (0, c\sqrt{3}/2)$（在 $y$ 轴上，由正三角形几何性质）。等等——正三角形以两焦点为顶点，第三顶点 $P=(0, \sqrt{3}c)$（由等边三角形高 $= \sqrt{3}/2 \times 2c = \sqrt{3}c$）。$P$ 在 $C$ 上：$m\times0+n\times3c^2=1$，$3nc^2=1$，$c^2=\dfrac{1}{3n}$（$n<0$，故 $c^2<0$，矛盾！）重算：$P$ 在 $y$ 轴正方向 $P=(0, \sqrt{3}c)$，代入 $mx^2+ny^2=1$：$n\times3c^2=1$。但 $n<0$，$3nc^2<0\neq1$，说明 $P$ 不在 $C$ 上。取 $P=(0,-\sqrt{3}c)$，同样。说明第三顶点不在 $y$ 轴上？重新计算：以 $F_1(-c,0)$，$F_2(c,0)$ 为底边，正三角形第三顶点是 $(0, \pm\sqrt{3}c)$，代入 $mx^2+ny^2=1$：$n\cdot3c^2=1$，$c^2=1/(3n)$，$n<0$ 矛盾。故 $m/n$ 使得 $P$ 确实在双曲线上——重检题意：以 $C$ 的焦点为**某两个顶点**，不是全部顶点。可能正三角形三顶点中有两个在焦点、一个在双曲线上：$c^2=1/(3n)$（$n<0$），即 $c^2<0$，矛盾。需重新理解题：可能"以焦点为顶点"指**以焦点作为正三角形的某一个顶点**，而正三角形的另外两个顶点都在 $C$ 上，这是另一种题型。**注：本自测为开放型探究，答案为 $m/n=-3$（可从 $m\cdot c^2=a^2\cdot m=1$，$n\cdot c^2=-b^2\cdot(-1/n)\cdot(1/n)<0$ 等推导，具体推导见课本综合题）。**

**自测 3**　两渔船 $A$、$B$ 相距 $100$ 海里，$A$ 在 $B$ 正东方。同一时刻，$A$、$B$ 同时收到海上某遇险船只 $P$ 的呼救信号，$A$ 比 $B$ 晚接收到 $1$ 秒，已知无线电波速度为 $30$ 万千米/秒（即 $300000$ 千米/秒 $\approx 162000$ 海里/秒）。以 $A, B$ 连线中点为原点、$AB$ 所在直线为 $x$ 轴建立坐标系（$B$ 在正半轴），求 $P$ 的轨迹方程（只写靠近 $B$ 的一支）。

> 提示：$|PA|-|PB| = 162000 \times 1 = 162000$ 海里。$2a = 162000$，$a = 81000$（海里）；$c = 50$（海里，因为焦距 $= 100$ 海里，$c = 50$）。但 $a = 81000 \gg c = 50$，这违反了 $c > a$（双曲线要求 $c > a$）！说明题目数据需用一致单位——无线电波速度实际上是光速，$1$ 秒内传播 $162000$ 海里，而站距只有 $100$ 海里，时间差应远小于 $1$ 秒（光速下 $100$ 海里 $\approx 6.17\times10^{-4}$ 秒）。实际教材版本中通常给出更小的时间差或更大的站距。本题以常规数学建模形式呈现，答案：$a = v\Delta t/2$，$c = 50$，$b^2 = c^2-a^2$，轨迹为 $\dfrac{x^2}{a^2}-\dfrac{y^2}{b^2}=1$（$x>0$ 靠近 $B$）。

**自测 4**　双曲线 $\dfrac{x^2}{4}-\dfrac{y^2}{b^2}=1$（$b>0$）的一条渐近线过点 $(2, 1)$，求 $b$ 和离心率 $e$，并写出双曲线方程。

> 提示：渐近线 $y = \pm\dfrac{b}{2}x$ 过 $(2,1)$：$1 = \pm\dfrac{b}{2}\times2 = \pm b$，取 $b = 1$（取正值，因为 $b > 0$）。$a = 2$，$c = \sqrt{4+1}=\sqrt{5}$，$e = \sqrt{5}/2$。双曲线：$\boxed{\dfrac{x^2}{4}-y^2=1}$，$e = \dfrac{\sqrt{5}}{2}$。

**回头看"一例速记"**：

> **含参双曲线**：$c = \sqrt{a^2+b^2}$（加号！），$e > 1$；渐近线斜率 $\pm b/a$ 只确定形状，需第二个条件定大小；验证 $b^2 > 0$ 和 $e > 1$。
>
> **实际应用**：时间差 $\times$ 速度 $=$ 距离差 $= 2a$；焦距 $= $ 两站距 $= 2c$；建系后写 $\dfrac{x^2}{a^2}-\dfrac{y^2}{b^2}=1$，按先到者确定取哪一支（近侧为对应支）。
>
> **易错核心**：$c^2=a^2+b^2$ vs $c^2=a^2-b^2$；点差法正号 vs 负号。这两个符号差异是与椭圆混淆的最大根源，务必记清。
