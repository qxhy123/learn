# 有理数

数是数学的基础语言。从自然数出发，人类一步步扩展数的概念：引入 $0$，引入负整数，引入分数……这些拓展都有一个共同目的：让更多的运算"有结果可说"。本节我们系统整理有理数的结构，建立数轴、相反数和绝对值这三个核心工具，为后续所有运算奠基。

## 一、概念特征：怎么一眼认出

**有理数**是可以写成 $\dfrac{p}{q}$（$p, q$ 为整数，$q \neq 0$）形式的数。这一大类数包含：

- **整数**：$\ldots, -3, -2, -1, 0, 1, 2, 3, \ldots$（可看作 $q = 1$ 的特殊分数）
  - **正整数**（自然数中的非零部分）：$1, 2, 3, \ldots$
  - **零**：$0$（既不是正数也不是负数）
  - **负整数**：$-1, -2, -3, \ldots$
- **分数**（含有限小数、循环小数）：$\dfrac{1}{2}, -\dfrac{3}{4}, 0.6, 0.\overline{3} = \dfrac{1}{3}, \ldots$

用集合关系表示为：

$$\text{正整数} \cup \{0\} \cup \text{负整数} = \text{整数} \subset \text{有理数}$$

$$\text{整数} \cup \text{分数} = \text{有理数}$$

一个口诀：**有理数 = 整数 + 分数**；有限小数和循环小数都是有理数；无限不循环小数（如 $\sqrt{2}, \pi$）不是有理数（下一章专讲）。

## 二、定义与核心工具

### 1. 数轴

数轴是把数"图形化"的利器。规定数轴有三个要素：

- **原点**：表示数 $0$ 的点，记作 $O$；
- **正方向**：通常朝右，用箭头标出；
- **单位长度**：相邻两整数点之间的距离。

三要素缺一不可——缺少单位长度，则无法确定各数的位置。

**基本事实**：每一个有理数都对应数轴上**唯一的一点**；数轴上的每一点，也唯一对应一个数（暂时只说有理数，后续引入无理数后结论仍成立）。正数的点在原点右边，负数的点在原点左边，零在原点。

### 2. 相反数

若两个数**绝对值相等、符号相反**，则互称**相反数**。数 $a$ 的相反数记作 $-a$。

性质：
$$a + (-a) = 0$$

即一对相反数之和为零。$0$ 的相反数是 $0$ 自身（$-0 = 0$）。

**注意**：$-a$ 的符号不一定是负的！若 $a < 0$，则 $-a > 0$。例如 $a = -3$ 时，$-a = -(-3) = 3 > 0$。

### 3. 绝对值

数 $a$ 的**绝对值** $|a|$ 表示数轴上 $a$ 对应的点到原点的**距离**。

$$|a| = \begin{cases} a, & a \geq 0 \\ -a, & a < 0 \end{cases}$$

绝对值的基本性质：
- $|a| \geq 0$（绝对值恒非负）；
- $|a| = 0 \Leftrightarrow a = 0$；
- $|-a| = |a|$；
- $|a| = |-a|$（相反数的绝对值相等）。

### 4. 比较大小

**数轴法**：在数轴上，右边的数总比左边的数大。

**符号法**：
- 正数 $>$ $0$ $>$ 负数；
- 两正数：绝对值大的那个更大；
- 两负数：绝对值大的那个反而更小（离原点更远但在负方向）；
- 一正一负：正数更大。

## 三、推导：为什么这样定义

**为什么要有负数？** 用正整数描述"往东走 3 步"，但无法描述"往西走 3 步"和两者的抵消——引入负数后，设东为正，西为 $-3$，合计 $3 + (-3) = 0$，完美。

**为什么绝对值用分段定义？** 距离是一个非负量。正数本身就表示"偏右多少"，距离就是它自己；负数表示"偏左多少"，距离是它的相反数，所以需要取 $-a$。两种情况合并，得到分段表达式。

**为什么要数轴？** 数轴提供了"数和几何位置之间的一一对应"，把抽象的数与可视的长度/方向绑定，使得"比较大小"变成"谁在谁右边"，使得"绝对值"变成"到原点距离"。这种几何化思维贯穿初中代数全程。

**为什么 $-a$ 不一定是负数？** $-a$ 只是"$a$ 的相反数"的符号表达，并不带有具体符号。$a$ 是什么号，$-a$ 就是相反的号；当 $a$ 本身是负数时，$-a$ 自然是正数。许多错误正是把 $-a$ 理解成"负号后面加字母"而产生的。

## 四、典型应用

### 例 1　绝对值的直接计算

计算 $|-3|$，$|0|$，$-|-5|$。

【思路】直接代入绝对值定义。$-3 < 0$，所以 $|-3| = -(-3)$；$0 \geq 0$，所以 $|0| = 0$；$|-5| = 5$，再取相反数。

**解**：
$$|-3| = -(-3) = 3, \quad |0| = 0, \quad -|-5| = -5.$$

注意 $-|-5|$ 中先算绝对值 $|-5| = 5$，再加负号得 $-5$；这和 $|-5|$ 的结果 $5$ 不同。

### 例 2　含根号的大小比较

比较 $-3.5$，$-\dfrac{7}{2}$，$-\sqrt{13}$ 的大小。

【思路】三者都是负数，比绝对值大小，绝对值更大的数反而更小。先把三者都化为小数估算：$3.5 = 3.5$，$\dfrac{7}{2} = 3.5$，$\sqrt{13} \approx 3.606$。因此绝对值从小到大：$3.5 = 3.5 < 3.606$，三个负数从大到小就反过来。

**解**：
$$|-3.5| = 3.5, \quad \left|-\dfrac{7}{2}\right| = 3.5, \quad |-\sqrt{13}| = \sqrt{13} \approx 3.606.$$
由于三者均为负数，绝对值越大则数越小，故
$$-3.5 = -\dfrac{7}{2} > -\sqrt{13}.$$

### 例 3　绝对值方程（绝对值非负性的应用）

已知 $|a - 2| + |b + 3| = 0$，求 $a$，$b$。

【思路】绝对值恒非负，两个非负数之和为 $0$，则每个必须各自为 $0$。这是绝对值最常用的"零和"推断技巧，也是结构识别的典型模式：看到"几个非负量之和 $= 0$"立即分拆。

**解**：
由 $|a - 2| \geq 0$ 且 $|b + 3| \geq 0$，两者之和为 $0$ 要求
$$|a - 2| = 0 \quad \text{且} \quad |b + 3| = 0.$$
由此得 $a - 2 = 0$，$b + 3 = 0$，即
$$a = 2, \quad b = -3.$$

## 五、易错点 & 反例

1. **$|a|$ 恒非负，绝对值不可能为负数。**
   错误写法：$|x| = -3$ 有解（$x = -3$）。事实上 $|x| = -3$ 无解，因为绝对值不可能是负数。

2. **$-a$ 不一定是负数。**
   反例：$a = -5$ 时，$-a = 5 > 0$。常见失误是看到 $-a$ 就认为它是负数，或者看到 $|{-a}|$ 就写成 $-a$（当 $a < 0$ 时 $-a > 0$，$|-a| = -a$，不能再加负号）。

3. **两负数比较大小，绝对值大的反而更小。**
   反例：$-5$ 和 $-3$，$|-5| > |-3|$，但 $-5 < -3$（在数轴上 $-5$ 更靠左）。

4. **$0$ 没有正负，不是正数也不是负数。**
   错误说法："$0$ 是正数"或"$0$ 是非负数里最小的正数"——$0$ 就是 $0$，它是整数、有理数，但不是正数或负数。

5. **数轴三要素缺一不可。**
   常见漏掉"单位长度"这一要素，只画一条有原点和方向的线——这样画出来的不是"数轴"，而只是"数射线"，不足以唯一确定每个数的位置。

6. **在数轴上用 $\bullet$（实心点）标记整数点。** 描数轴上某点时，应画实心点 $\bullet$ 而非空心圆或叉号，与后续不等式的开/闭区间端点记号保持一致。

## 六、思路自测题

1. 写出下列各数的相反数和绝对值：$-6$，$\dfrac{3}{4}$，$0$，$-(-2)$。  
   💡 提示：先判断每个数的实际值（注意 $-(-2) = 2$），再分别取相反数（添或去负号）和绝对值（取非负值）。

2. 在数轴上，点 $A$ 表示 $-4$，点 $B$ 表示 $1.5$。(1) 用 $\bullet$ 在数轴上标出 $A$、$B$；(2) 求 $A$、$B$ 两点之间的距离；(3) 写出数轴上到 $A$ 距离等于 $3$ 的所有点的坐标。  
   💡 提示：距离 $= |(-4) - 1.5|$；第 (3) 问设坐标为 $x$，令 $|x - (-4)| = 3$，分两种情形。

3. 比较大小，在 $\square$ 内填 $>$、$<$ 或 $=$：  
   (1) $-\dfrac{5}{3} \;\square\; -\dfrac{7}{4}$；　(2) $-|{-3}| \;\square\; -(-3)$；　(3) $|-2.1| \;\square\; |2.1|$。  
   💡 提示：(1) 通分比较绝对值，两负数绝对值大者更小；(2) 先分别算出两边的值再比较；(3) 相反数的绝对值相等。

4. 已知 $|a + 1| + |2b - 4| = 0$，求 $a^2 + b^2$ 的值。  
   💡 提示：两个非负量之和为 $0$，则各自为 $0$，先求出 $a$、$b$，再代入计算 $a^2 + b^2$。
