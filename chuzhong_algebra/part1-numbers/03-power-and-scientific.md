# 乘方与科学记数法

上一章把乘方作为运算法则之一带过。本章深化乘方的结构——理解底数、指数、幂三者的关系，掌握负底数的符号规律——并学习用乘方表示极大或极小数字的标准方式：科学记数法。这一工具在物理、天文、化学中无处不在。

## 一、概念特征：怎么一眼认出

- **乘方**：重复乘法的简写，$a^n$ 表示 $n$ 个 $a$ 相乘。
- **科学记数法**：$a \times 10^n$，其中 $1 \leq |a| < 10$，$n$ 为整数。
- **有效数字**：从左边第一个非零数字开始，到最后一位数字为止的所有数字。
- **近似数**：经过四舍五入等方式得到的与精确值接近的数。

一眼识别科学记数法的两条标准：①系数 $a$ 必须满足 $1 \leq |a| < 10$；②$10$ 的指数 $n$ 是整数（可正可负可零）。不满足任意一条都不是标准科学记数法。

## 二、定义与法则

### 1. 乘方的三要素

$$a^n = \underbrace{a \cdot a \cdots a}_{n \text{ 个 } a}$$

- $a$：**底数**（被乘的数）
- $n$：**指数**（乘的次数，正整数）
- $a^n$：$a$ 的 $n$ 次**幂**

特别地：$a^1 = a$，$a^2$ 读作"$a$ 的平方"，$a^3$ 读作"$a$ 的立方"。

### 2. 负底数的符号规律

当底数 $a < 0$ 时：

$$(-a)^{\text{偶次}} > 0, \qquad (-a)^{\text{奇次}} < 0.$$

具体来说：负数的**偶次**幂为正，**奇次**幂为负。正数的任何次幂为正，$0$ 的任何正整数次幂为 $0$。

$$(-2)^4 = 16 > 0, \qquad (-2)^3 = -8 < 0.$$

关键区别（再次强调）：

$$-a^n = -(a^n) \neq (-a)^n \quad (\text{一般地})$$

### 3. 科学记数法

将一个数 $N$ 写成

$$N = a \times 10^n, \quad 1 \leq |a| < 10, \quad n \in \mathbb{Z}.$$

**大数（$|N| \geq 10$）的转换**：$n =$ 整数部分的位数 $- 1$（即把小数点向左移 $n$ 位使系数落入 $[1, 10)$）。

$$32{,}000{,}000 = 3.2 \times 10^7 \quad (n = 7, \text{ 整数部分 8 位}, 8-1=7)$$

**小数（$0 < |N| < 1$）的转换**：$n$ 为负数，$|n|$ 等于从小数点到第一个非零数字经过的位数（含该非零数字前的全部 $0$）。

$$0.0000058 = 5.8 \times 10^{-6} \quad (n = -6, \text{ 小数点后 5 个 0 再到 5})$$

**还原**：$a \times 10^n$ 中，$n > 0$ 将小数点右移 $n$ 位，$n < 0$ 将小数点左移 $|n|$ 位。

### 4. 有效数字与精确度

**有效数字**：从左边第一个非零数字起，到末位的所有数字（包括末位的 $0$）。

- $3.20 \times 10^4$：有效数字为 $3, 2, 0$，共 $3$ 位（末尾 $0$ 有意义，表示精确到百位）。
- $2.05 \times 10^4$：有效数字为 $2, 0, 5$，共 $3$ 位（中间 $0$ 也是有效数字）。

**精确到某位**：用四舍五入保留到指定位置，精确位之后的数字根据下一位决定进退。

## 三、推导：为什么这样规定

**为什么负偶次幂为正？** 乘法法则：两个负数相乘得正，两对负数相乘仍然得正……偶数个负因数两两消去符号，最终结果为正。奇数个负因数则"多出一个"，结果为负。这是乘法符号法则的直接推论，不需要额外记忆。

**为什么科学记数法要求 $1 \leq |a| < 10$？** 这是唯一性的保证：若允许 $|a| \geq 10$，则 $30 = 3 \times 10^1 = 30 \times 10^0$ 等多种写法并存，失去"标准"意义；若允许 $|a| < 1$，则 $0.3 \times 10^2 = 3 \times 10^1$，也有重复。限定系数在 $[1, 10)$ 内，与 $10$ 的整数次幂配合，每个正数有唯一的科学记数法表示。

**为什么大数的 $n =$ 位数 $- 1$？** 一个 $k$ 位整数的范围是 $[10^{k-1}, 10^k)$，将其除以 $10^{k-1}$ 后恰好落入 $[1, 10)$，所以系数 $= N / 10^{k-1}$，$n = k - 1$。例如 $3{,}200{,}000$ 有 $7$ 位，$n = 6$：$3{,}200{,}000 = 3.2 \times 10^6$。

**为什么末尾的 $0$ 是有效数字？** $3.20 \times 10^4 = 32{,}000$，末尾 $0$ 表明这个数精确到了百位（$32{,}000$ 精确，而非 $32{,}100$ 四舍五入来的）。若只写 $3.2 \times 10^4$，则只精确到千位。末尾的 $0$ 传递着测量精度信息，不能随意省略。

## 四、典型应用

### 例 1　大数化为科学记数法

将 $3{,}200{,}000$ 化为科学记数法。

【思路】数出整数部分位数：$3{,}200{,}000$ 是 7 位数，故 $n = 7 - 1 = 6$。系数 $= 3{,}200{,}000 \div 10^6 = 3.2$，满足 $1 \leq 3.2 < 10$。

**解**：
$$3{,}200{,}000 = 3.2 \times 10^6.$$

### 例 2　小数化为科学记数法

将 $0.0000058$ 化为科学记数法。

【思路】从小数点出发向右数，跳过全部 $0$ 到第一个非零数字 $5$，经过了 $6$ 位（含 $5$ 前面的 5 个 $0$，再加 $5$ 本身前移一位），故 $n = -6$。系数取 $5.8$，满足 $1 \leq 5.8 < 10$。

**解**：
$$0.0000058 = 5.8 \times 10^{-6}.$$

验证：$5.8 \times 10^{-6} = 5.8 \div 10^6 = 0.0000058$。$\checkmark$

### 例 3　有效数字的识别

指出 $2.05 \times 10^4$ 的有效数字，并说明该数精确到哪一位。

【思路】有效数字从第一个非零数字起，$2.05$ 中三个数字 $2, 0, 5$ 均为有效数字（注意中间的 $0$ 不能跳过）。还原为普通数：$2.05 \times 10^4 = 20{,}500$，末位是个位（$5$ 后没有更多数字），精确到个位（十位？——因为 $20{,}500$ 末位 $0$ 不确定是不是有效的，科学记数法里 $2.05$ 的末位 $5$ 对应的是百位），重新数位：$2.05 \times 10^4 = 20500$，$5$ 在百位，$0$ 在十位，$0$ 在个位；科学记数法末位 $5$ 对应 $10^4 \times 0.05 = 10^4 / 20 = 500$，即精确到百位。

**解**：
$2.05 \times 10^4$ 的有效数字为 $2$、$0$、$5$，共 $3$ 位。还原：$2.05 \times 10^4 = 20{,}500$，其中 $5$ 处于**百位**，故该近似数精确到**百位**。

## 五、易错点 & 反例

1. **科学记数法系数 $a$ 必须满足 $1 \leq |a| < 10$，不能大于等于 $10$ 或小于 $1$。**
   反例：$32 \times 10^5$ 不是科学记数法（$32 \geq 10$），应写成 $3.2 \times 10^6$；$0.32 \times 10^7$ 不是科学记数法（$0.32 < 1$），同样应写成 $3.2 \times 10^6$。

2. **小数化科学记数法时，$n$ 是负数，且 $|n|$ 等于小数点右移到系数首位所经过的步数。**
   反例：$0.005 = 5 \times 10^{-3}$，有人误写为 $5 \times 10^{3}$（符号搞反）。记忆方法：小数 $< 1$，要把系数"放大"，需要 $10^n$ 中 $n < 0$ 才能"缩小回去"。

3. **$-a^n$ 和 $(-a)^n$ 含义不同，不可混淆。**
   反例：$-2^4 = -16$，$(-2)^4 = 16$；$-2^3 = -8$，$(-2)^3 = -8$（奇次时恰好相等，但原因不同）。不要因偶然相等而认为两者总是一样。

4. **有效数字中，中间的 $0$ 是有效数字，末尾的 $0$ 也是有效数字，只有最前面的 $0$ 不是。**
   反例：$0.0305$ 的有效数字是 $3, 0, 5$（共 $3$ 位），最前面两个 $0$ 不算；$30500$（精确到十位）的有效数字是 $3, 0, 5, 0, 0$（共 $5$ 位，末两个 $0$ 有意义）。科学记数法能消除歧义：$3.050 \times 10^4$ 明确表示 $4$ 位有效数字。

5. **正数的乘方结果恒正，但指数为 $0$ 是特殊情形（$a^0 = 1$，$a \neq 0$），初中先记结论。**

## 六、思路自测题

   💡 提示：数出整数位数（或小数点后至首个非零数字的位数）来确定 $n$ 的值；注意 (3) 中负号写在系数前，$a = -3.8$，$n$ 仍按位数规则确定。

2. 将下列科学记数法还原为普通数：(1) $3.07 \times 10^5$；(2) $6 \times 10^{-4}$；(3) $1.5 \times 10^{-2}$。  
   💡 提示：$n > 0$ 时小数点右移 $n$ 位；$n < 0$ 时小数点左移 $|n|$ 位；不足时用 $0$ 补位。

3. 指出 $4.020 \times 10^3$ 的有效数字个数，并判断它精确到哪一位。  
   💡 提示：系数 $4.020$ 中所有数字均为有效数字（末尾 $0$ 不能省略）；还原后定位末位数字所在数位。

4. 比较大小：$(-3)^4$ 与 $-3^4$；$(-2)^5$ 与 $(-2)^6$。并思考：负数的偶次幂与奇次幂的正负规律。  
   💡 提示：分别计算 $(-3)^4 = 81$，$-3^4 = -81$，$(-2)^5 = -32$，$(-2)^6 = 64$；归纳符号规律：偶次幂为正，奇次幂为负。
