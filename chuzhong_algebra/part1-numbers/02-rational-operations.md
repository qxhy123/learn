# 有理数的运算

引入负数之后，加减乘除就不再是小学那套"正数世界"里的简单规则了。我们需要重新定义每种运算对符号的处理方式，并规定"先算谁后算谁"。本节把有理数的加、减、乘、除、乘方和混合运算法则系统梳理，并通过例题展示常见陷阱。

## 一、概念特征：怎么一眼认出

有理数运算涉及两类问题：

- **符号问题**：结果是正是负？
- **大小问题**：结果的绝对值是多少？

绝大多数错误都出在符号处理上——两个负号相消了吗？括号里的每项都变号了吗？这是本章最需要警惕的地方。

## 二、定义与运算法则

### 1. 加法法则

**同号相加**：结果取相同的符号，绝对值相加。

$$(-3) + (-5) = -(3+5) = -8$$

**异号相加**：结果取绝对值**较大**的那个数的符号，绝对值相减（大减小）。

$$(-7) + 4 = -(7-4) = -3 \qquad 7 + (-4) = +(7-4) = 3$$

**一数与零相加**：结果等于那个数本身，$a + 0 = a$。

**加法运算律**：
- 交换律：$a + b = b + a$
- 结合律：$(a + b) + c = a + (b + c)$

### 2. 减法法则

**减去一个数等于加上这个数的相反数**：

$$a - b = a + (-b)$$

减法统一转化为加法，不再单独处理符号。例如：

$$(-2) - (-5) = (-2) + 5 = 3$$

### 3. 乘法法则

**同号相乘得正，异号相乘得负**；绝对值相乘。

$$(-3) \times (-4) = +12, \qquad (-3) \times 4 = -12.$$

**多个数相乘**：
- 负因数个数为**偶数** $\Rightarrow$ 积为正；
- 负因数个数为**奇数** $\Rightarrow$ 积为负；
- 有一个因数为 $0$ $\Rightarrow$ 积为 $0$。

$$(-1)^{2026} = +1 \quad (\text{偶数个} -1), \qquad (-1)^{2025} = -1 \quad (\text{奇数个} -1).$$

**乘法运算律**：
- 交换律：$a \cdot b = b \cdot a$
- 结合律：$(a \cdot b) \cdot c = a \cdot (b \cdot c)$
- 分配律：$a \cdot (b + c) = a \cdot b + a \cdot c$

### 4. 除法法则

**除法化为乘法**：除以一个数等于乘以这个数的倒数（$b \neq 0$）：

$$a \div b = a \times \frac{1}{b}$$

符号规律与乘法完全相同：同号得正，异号得负。

**特别注意**：$a \div 0$ 无意义（除数不能为 $0$）；$0 \div a = 0$（$a \neq 0$）。

除法**没有**结合律：$(12 \div 4) \div 2 = 3 \div 2 = \dfrac{3}{2}$，但 $12 \div (4 \div 2) = 12 \div 2 = 6$，两者不等。

### 5. 乘方

$$a^n = \underbrace{a \cdot a \cdots a}_{n \text{ 个}}$$

其中 $a$ 是**底数**，$n$ 是**指数**，$a^n$ 叫做 $a$ 的 $n$ 次**幂**。

**关键区别**：
$$(-a)^n \neq -a^n \quad (\text{一般情况下})$$

- $(-a)^n$ 是先取相反数再乘方；
- $-a^n$ 是先乘方再取相反数（即 $-(a^n)$）。

### 6. 混合运算顺序

$$\text{括号} \to \text{乘方} \to \text{乘除} \to \text{加减}$$

同级运算从左到右依次进行。括号从内到外逐层消去。

## 三、推导：为什么这么定义

**为什么负负得正？** 从分配律出发：

$$(-1) \times [1 + (-1)] = (-1) \times 0 = 0.$$

展开左边：$(-1) \times 1 + (-1) \times (-1) = -1 + (-1) \times (-1) = 0$，

因此 $(-1) \times (-1) = 1$。一般地，$(-a)(-b) = ab$。

**为什么减法等于加上相反数？** 加减互逆：$5 - 3 = 2$ 是因为 $3 + 2 = 5$。若要让 $5 - (-3)$ 也满足"减法是加法的逆运算"，则需要 $5 - (-3) = x$ 使得 $(-3) + x = 5$，解得 $x = 8 = 5 + 3$。即减去 $-3$ 等于加上 $3$，也就是加上 $(-3)$ 的相反数。

**为什么乘方先于乘除？** 历史约定，但有其合理性：$a^n$ 是乘法的缩写，"更紧密"地绑定底数，所以比"散开"的乘除优先。这和括号表示"更紧密的绑定"是同一逻辑。

**为什么 $a \div 0$ 无意义？** 若 $a \div 0 = q$，则应有 $0 \times q = a$。但 $0 \times q = 0 \neq a$（$a \neq 0$），矛盾；若 $a = 0$，则 $0 \times q = 0$ 对任意 $q$ 成立，$q$ 不唯一，也无意义。故除数不能为零。

## 四、典型应用

### 例 1　基础混合运算

计算 $-3^2 + (-2)^3 \times \left(-\dfrac{1}{2}\right)^2$。

【思路】严格按照"乘方 $\to$ 乘除 $\to$ 加减"的顺序。首先区分 $-3^2$ 和 $(-3)^2$：题目是 $-3^2$，即 $-(3^2) = -9$，不加括号时指数只作用于底数 $3$。

**解**：
$$-3^2 + (-2)^3 \times \left(-\dfrac{1}{2}\right)^2$$
$$= -9 + (-8) \times \dfrac{1}{4}$$
$$= -9 + (-2)$$
$$= -11.$$

### 例 2　分配律简便计算

计算 $-\dfrac{1}{6} \times \left(-\dfrac{1}{12} + \dfrac{1}{4} - \dfrac{1}{2}\right)$。

【思路】括号内通分化简后再乘，或直接用分配律把 $-\dfrac{1}{6}$ 乘进去——两种路径均可，但分配律在此更简洁，因为三个分数与 $\dfrac{1}{6}$ 相乘后均能化整。

**解**（分配律路径）：
$$-\dfrac{1}{6} \times \left(-\dfrac{1}{12} + \dfrac{1}{4} - \dfrac{1}{2}\right)$$
$$= \left(-\dfrac{1}{6}\right) \times \left(-\dfrac{1}{12}\right) + \left(-\dfrac{1}{6}\right) \times \dfrac{1}{4} + \left(-\dfrac{1}{6}\right) \times \left(-\dfrac{1}{2}\right)$$
$$= \dfrac{1}{72} - \dfrac{1}{24} + \dfrac{1}{12}$$
$$= \dfrac{1}{72} - \dfrac{3}{72} + \dfrac{6}{72} = \dfrac{4}{72} = \dfrac{1}{18}.$$

### 例 3　含绝对值的混合运算

计算 $|{-2}| - (-3)^2 \div \left(-\dfrac{3}{2}\right) \times (-1)^5 + (-4)$。

【思路】分步处理：先算绝对值和各乘方，再做乘除，最后加减。特别注意 $(-3)^2 = 9$，$(-1)^5 = -1$，乘除从左到右：先除再乘。

**解**：
$$|{-2}| - (-3)^2 \div \left(-\dfrac{3}{2}\right) \times (-1)^5 + (-4)$$
$$= 2 - 9 \div \left(-\dfrac{3}{2}\right) \times (-1) + (-4)$$
$$= 2 - 9 \times \left(-\dfrac{2}{3}\right) \times (-1) + (-4)$$
$$= 2 - 6 \times (-1) + (-4)$$
$$= 2 - (-6) + (-4)$$
$$= 2 + 6 - 4 = 4.$$

## 五、易错点 & 反例

1. **$-3^2 = -9$，不是 $9$。**
   负号在乘方外面时，先算乘方再取负：$-3^2 = -(3^2) = -9$。而 $(-3)^2 = 9$，因为负数自乘两次，两个负号相消。这是最高频的错误之一。

2. **$(-3)^2 \neq -3^2$。**
   反例：$(-3)^2 = 9$，$-3^2 = -9$，两者相差 $18$。在题目中不加括号的乘方，指数只绑定紧邻的底数（正数或带括号的整体），负号不在其内。

3. **除以 $0$ 无意义，不能约分。**
   反例：$\dfrac{0}{0}$ 并非等于 $1$；$\dfrac{a}{0}$ 不是 $\infty$，在初中代数中直接判定"无意义"。

4. **除法没有结合律，不能随意移动除号。**
   反例：$24 \div 6 \div 2 = 4 \div 2 = 2$，但 $24 \div (6 \div 2) = 24 \div 3 = 8$。连续除法必须从左到右，或全部先转化为乘倒数再结合。

5. **去括号时括号前有负号，括号内每项都要变号，不能只变第一项。**
   反例：$-(a - b + c) = -a + b - c$（三项均变号），不是 $-a - b + c$（仅变第一项）。

6. **多个负数相乘，负因数的个数决定符号，与数的大小无关。**
   反例：$(-1)^{100} = 1$（偶数个 $-1$），$(-1)^{101} = -1$（奇数个 $-1$），与 $1$ 的大小无关。
