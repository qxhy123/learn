# 平方根与立方根

"开方"是乘方的逆运算，就像减法是加法的逆运算一样。知道 $3^2 = 9$，那么"9 的平方根是 3"是很自然的；知道 $2^3 = 8$，那么"8 的立方根是 2"也顺理成章。但开方有一个特殊之处：同一个数可能有两个平方根，甚至没有实数范围内的平方根。弄清楚这些细节，是本节最重要的任务。

## 一、图形特征：怎么一眼认出

- **平方根**出现在"已知面积求边长"之类的情形里，例如正方形面积为 $a$，边长 $x$ 满足 $x^2 = a$，$x$ 就是 $a$ 的平方根。
- **算术平方根**是根号 $\sqrt{\phantom{a}}$ 直接覆盖的非负结果，例如 $\sqrt{9} = 3$（不是 $-3$）。
- **立方根**出现在"已知体积求棱长"之类的情形里，例如正方体体积为 $a$，棱长 $x$ 满足 $x^3 = a$，$x$ 就是 $a$ 的立方根，记作 $\sqrt[3]{a}$。

## 二、定义与运算法则

### 1. 平方根

**定义**：若 $x^2 = a$，则 $x$ 叫做 $a$ 的**平方根**（也叫**二次方根**）。

- **正数**有两个平方根，互为相反数，写作 $\pm\sqrt{a}$（读作"正负根号 $a$"）。例如 $9$ 的平方根是 $3$ 和 $-3$，即 $\pm\sqrt{9} = \pm 3$。
- **$0$** 的平方根只有一个，就是 $0$。
- **负数没有平方根**（在实数范围内）。因为任何实数的平方都 $\geq 0$，不可能等于负数。

### 2. 算术平方根

**定义**：正数 $a$ 的两个平方根中，**非负的那一个**叫做 $a$ 的**算术平方根**，记作 $\sqrt{a}$。

$$
\sqrt{a} \geq 0 \quad (a \geq 0)
$$

特别地，$\sqrt{0} = 0$。

**关键性质**：

$$
(\sqrt{a})^2 = a \quad (a \geq 0)
$$

$$
\sqrt{a^2} = |a| \quad (\text{对任意实数 } a)
$$

第二条性质是易错重灾区：$\sqrt{a^2}$ **不一定等于 $a$**，而是等于 $|a|$。当 $a < 0$ 时，$\sqrt{a^2} = -a > 0$。

### 3. 立方根

**定义**：若 $x^3 = a$，则 $x$ 叫做 $a$ 的**立方根**（也叫**三次方根**），记作 $\sqrt[3]{a}$，读作"三次根号 $a$"。

**与平方根的重要区别**：

| | 平方根 | 立方根 |
| :--- | :--- | :--- |
| 正数 | 两个（$\pm\sqrt{a}$） | 一个（正数） |
| $0$ | 一个（$0$） | 一个（$0$） |
| 负数 | **没有** | **有一个**（负数） |

因为奇次方保号：正数的奇次方仍为正，负数的奇次方仍为负。所以负数也有立方根，且立方根是负数。例如：

$$
\sqrt[3]{-27} = -3, \quad \text{因为 } (-3)^3 = -27
$$

**关键性质**：

$$
(\sqrt[3]{a})^3 = a \quad (\text{对任意实数 } a)
$$

$$
\sqrt[3]{a^3} = a \quad (\text{对任意实数 } a)
$$

注意，立方根处不需要绝对值符号，因为立方根和原数同号。

## 三、推导：为什么 $\sqrt{a^2} = |a|$ 而不是 $a$

设 $a$ 是任意实数。$a^2 \geq 0$，所以 $\sqrt{a^2}$ 有意义。按算术平方根的定义，$\sqrt{a^2}$ 是 $a^2$ 的**非负**平方根，即：

$$
\sqrt{a^2} = \text{（某个非负数，且其平方等于 } a^2\text{）}
$$

当 $a \geq 0$：$\sqrt{a^2} = a$（本身非负，吻合）。

当 $a < 0$：$a$ 本身是负数，不能直接作为非负平方根；$-a > 0$ 才是非负的，而且 $(-a)^2 = a^2$，所以 $\sqrt{a^2} = -a$。

综合两种情形，恰好是绝对值的定义：$|a| = \begin{cases} a, & a \geq 0 \\ -a, & a < 0 \end{cases}$。

因此 $\sqrt{a^2} = |a|$，这不是约定，而是由算术平方根的"非负性"推导出来的必然结论。

类比：$\sqrt[3]{a^3} = a$ 则是因为立方根对正负数都能取到，且 $x^3$ 是严格单调的，所以"$a^3$ 的立方根就是 $a$"不需要绝对值。

## 四、典型应用

### 例 1　直接计算平方根和立方根

求下列各式的值：$\sqrt{81}$，$\pm\sqrt{0.25}$，$\sqrt[3]{-27}$，$\sqrt[3]{0.125}$。

【思路】先判断是正数/零/负数，再按定义直接开方；对算术平方根只取非负值。

**解**：

$$
\sqrt{81} = 9 \quad (\text{因为 } 9^2 = 81,\; 9 \geq 0)
$$

$$
\pm\sqrt{0.25} = \pm 0.5 \quad (\text{因为 } 0.5^2 = 0.25)
$$

$$
\sqrt[3]{-27} = -3 \quad (\text{因为 } (-3)^3 = -27)
$$

$$
\sqrt[3]{0.125} = 0.5 \quad (\text{因为 } 0.5^3 = 0.125)
$$

### 例 2　解方程：区分"平方根"和"算术平方根"

(1) 解方程 $x^2 = 9$。　　(2) 解方程 $\sqrt{x} = 3$。

【思路】(1) 求 9 的所有平方根（包括负的那个）。(2) $\sqrt{x}$ 表示算术平方根，本身已经 $\geq 0$，所以方程 $\sqrt{x} = 3$ 只有一个解，且只需两边平方即可。

**解**：

(1) $x^2 = 9$ 的解是 9 的所有平方根：

$$
x = \pm\sqrt{9} = \pm 3
$$

(2) $\sqrt{x} = 3$。两边平方：$(\sqrt{x})^2 = 3^2$，即 $x = 9$。

验证：$\sqrt{9} = 3$ ✓（注意，因为 $\sqrt{x} \geq 0$ 而 $3 > 0$，方程有解；若右端是负数则无解。）

两题对比：$x^2 = 9$ 有**两**个解，$\sqrt{x} = 3$ 只有**一**个解，根本原因在于 $\sqrt{x}$ 强制取非负值。

### 例 3　化简含绝对值的根式

化简：(1) $\sqrt{(-5)^2}$，(2) $\sqrt{(x-3)^2}$（$x$ 为实数），(3) $\sqrt[3]{(-2)^3}$。

【思路】用性质 $\sqrt{a^2} = |a|$，$\sqrt[3]{a^3} = a$。注意 (2) 中 $x - 3$ 可正可负，须用绝对值；(3) 立方根不需要绝对值。

**解**：

(1) $\sqrt{(-5)^2} = |-5| = 5$。（直接 $= -5$ 是错的，因为算术平方根 $\geq 0$。）

(2) $\sqrt{(x-3)^2} = |x - 3|$。

若 $x \geq 3$，则 $|x-3| = x - 3$；若 $x < 3$，则 $|x-3| = 3 - x$。

(3) $\sqrt[3]{(-2)^3} = -2$。（立方根无需绝对值，$(-2)^3 = -8$，$\sqrt[3]{-8} = -2$。）

## 五、易错点 & 反例

**1. 把"平方根"和"算术平方根"混淆**

$9$ 的平方根是 $\pm 3$（两个），而 $\sqrt{9} = 3$（只是算术平方根，仅一个）。说"$\sqrt{9} = \pm 3$"是错误的。

**2. $\sqrt{a^2} = a$（忘记绝对值）**

反例：令 $a = -4$，则 $a^2 = 16$，$\sqrt{a^2} = \sqrt{16} = 4 \neq -4$。正确写法：$\sqrt{a^2} = |a| = |-4| = 4$。

**3. 认为负数也有平方根**

$\sqrt{-4}$ 在实数范围内无意义。注意与立方根区分：$\sqrt[3]{-8} = -2$ 是有意义的，因为 $(-2)^3 = -8$。

**4. 立方根公式也加绝对值**

$\sqrt[3]{a^3} = a$，**不需要绝对值**。例如 $\sqrt[3]{(-3)^3} = -3$（不是 $3$）。如果写成 $|\ldots|$ 就错了。

**5. 根号内的数"开完了"才算结果**

$\sqrt{2}$ 不等于 $1.4$ 或 $1.41$，而是一个无理数。只有完全平方数（$1, 4, 9, 16, 25, \ldots$）的算术平方根才是整数。

## 六、思路自测题

1. 填空：$16$ 的平方根是 \_\_\_\_，$16$ 的算术平方根是 \_\_\_\_；$-8$ 的立方根是 \_\_\_\_，$\sqrt[3]{64}$ = \_\_\_\_。  
   💡 提示：平方根有两个（$\pm 4$），算术平方根只取正的（$4$）；负数有立方根（$-2$）；$\sqrt[3]{64} = 4$ 因为 $4^3 = 64$。

2. 化简：(1) $\sqrt{49}$，(2) $\sqrt{(-7)^2}$，(3) $-\sqrt{0.04}$，(4) $\sqrt[3]{-125}$。  
   💡 提示：(2) 用 $\sqrt{a^2} = |a| = |-7| = 7$；(3) 先求 $\sqrt{0.04} = 0.2$ 再取负。

3. 解方程：(1) $x^2 = 36$，(2) $x^2 = -1$，(3) $x^3 = -64$。  
   💡 提示：(1) 两个解 $x = \pm 6$；(2) 负数无平方根，方程无实数解；(3) $x = \sqrt[3]{-64} = -4$，只有一个解。

4. 判断：若 $a < 0$，则 $\sqrt{a^2}$ 等于什么？$\sqrt[3]{a^3}$ 等于什么？  
   💡 提示：$\sqrt{a^2} = |a| = -a$（因为 $a < 0$ 所以 $-a > 0$）；$\sqrt[3]{a^3} = a$（立方根与原数同号）。两个结论完全不同。
