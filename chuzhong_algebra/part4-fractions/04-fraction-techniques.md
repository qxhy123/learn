# 分式化简技巧

> **一例速记**：  
> 分式化简的 4 大武器：① 因式分解 + 约分 ② 通分合并 ③ 整体换元 ④ 裂项相消  
> **见分式 + 多项式 → 先因式分解，约分能省 90% 的计算。**

---

## 一、引入：一道"看起来很吓人"的题

> **题目**：化简 $\dfrac{x^2-1}{x^2-4x+3} \cdot \dfrac{x-3}{x+1}$。

请先停下来试一试。不借助技巧，你可能会把所有东西都展开，然后想办法约分——很容易搞乱符号，算半天也不确定对不对。

**结果其实等于 $1$。**

这道题如果你一眼看出因式分解，5 秒内手算完成。如果你展开硬算，可能要 2 分钟还不敢确定答案。

这就是"分式化简技巧"的意义：**不是让你算得更快，而是让你找到正确的入手点，避免无效计算。**

---

## 二、思维路径还原（解题者的内心独白）

> 拿到 $\dfrac{x^2-1}{x^2-4x+3} \cdot \dfrac{x-3}{x+1}$，先看整体结构：两个分式相乘，分子分母都是多项式——这是因式分解 + 约分的信号。
>
> **第一步：分解所有分子和分母。**
>
> $x^2 - 1$：两个完全平方相减，平方差 → $(x+1)(x-1)$。
>
> $x^2 - 4x + 3$：三项二次式，找两数积 = $3$、和 = $-4$：$-1$ 和 $-3$，恰好。所以 $x^2-4x+3 = (x-1)(x-3)$。（用十字相乘验证：$(x-1)(x-3) = x^2-4x+3$，正确。）
>
> $x-3$ 和 $x+1$ 已经是一次式，不能再分解。
>
> **第二步：把所有因子写进一个大分式里。**
>
> $$\frac{(x+1)(x-1)}{(x-1)(x-3)} \cdot \frac{x-3}{x+1} = \frac{(x+1)(x-1)(x-3)}{(x-1)(x-3)(x+1)}$$
>
> **第三步：约分。**
>
> 分子和分母都有 $(x+1)$、$(x-1)$、$(x-3)$，全部约掉。
>
> $$= 1$$
>
> 耗时：10 秒。
>
> 关键反射：**分式乘法题 → 立刻因式分解全部分子分母 → 集中约分 → 再相乘**。绝不先乘后分解，那是在给自己制造麻烦。

---

## 三、抽象成方法：4 大化简技巧

### 技巧一：因式分解 + 约分（最常用）

**适用场景**：分式乘除，或单个分式约分。

**操作步骤**：
1. 对每个分子、分母独立进行因式分解（提公因式 → 公式法 → 十字相乘）。
2. 把所有因子排列清楚（可以写在一条大分式里）。
3. 消去分子分母中相同的因式（约分）。
4. 剩余部分相乘，即为结果。

**为什么有效**：因式分解把多项式变成"乘积形式"，约分本质上是 $\dfrac{A \cdot C}{B \cdot C} = \dfrac{A}{B}$，只有乘积形式才能约分，加减形式不能。

**常见陷阱**：$\dfrac{x+2}{x+3}$ 中的 $x$ **不能**约掉——$x+2$ 和 $x+3$ 是和的形式，不是乘积，没有公因式。

---

### 技巧二：通分合并（加减化简）

**适用场景**：多个分式相加减，需要合并成一个分式。

**操作步骤**：
1. 分解各分母，找**最简公分母（LCD）**：取每个因式的最高次幂之积。
2. 各分式通分（分子分母同乘补足因式）。
3. 合并分子（注意减法要加括号，防止符号错误）。
4. 化简分子，约分到最简。

**最简公分母的确定**：

| 各分母 | 最简公分母 |
|---|---|
| $x$，$x+1$ | $x(x+1)$ |
| $x-1$，$(x-1)^2$ | $(x-1)^2$ |
| $x^2-1$，$x+1$ | $x^2-1 = (x+1)(x-1)$ |
| $x$，$x-1$，$x(x-1)$ | $x(x-1)$ |

**关键**：最简公分母包含所有分母，但不多余——不是把所有分母直接相乘（那会引入重复因式）。

---

### 技巧三：整体换元（高次分式简化）

**适用场景**：方程或表达式中，某个复杂的分式结构**重复出现**两次或以上，或以"一个分式 + 其倒数"的形式出现。

**操作步骤**：
1. 识别重复的分式结构，令其为新变量 $t$（注意限定 $t$ 的范围）。
2. 用 $t$ 改写整个表达式，得到关于 $t$ 的简单方程或代数式。
3. 对 $t$ 求解或化简。
4. **回代**：把 $t$ 还原回原变量，得出最终结果。

**例**：化简 $\dfrac{x+1}{x-1} + \dfrac{x-1}{x+1}$。

令 $t = \dfrac{x+1}{x-1}$，则 $\dfrac{x-1}{x+1} = \dfrac{1}{t}$，原式 = $t + \dfrac{1}{t} = \dfrac{t^2+1}{t}$。

回代 $t = \dfrac{x+1}{x-1}$：$\dfrac{t^2+1}{t} = \dfrac{\left(\frac{x+1}{x-1}\right)^2+1}{\frac{x+1}{x-1}} = \dfrac{(x+1)^2+(x-1)^2}{(x+1)(x-1)} = \dfrac{2x^2+2}{x^2-1}$。

（也可不换元，直接通分，结果一致。换元对"重复结构更多"的题更有优势。）

---

### 技巧四：裂项相消（求和化简）

**适用场景**：形如 $\dfrac{1}{n(n+1)}$ 或 $\dfrac{1}{n(n+k)}$ 的分式求和，项数多时普通通分极繁，裂项可使大量项相消。

**核心公式**：

$$\frac{1}{n(n+1)} = \frac{1}{n} - \frac{1}{n+1}$$

更一般地：$\dfrac{1}{n(n+k)} = \dfrac{1}{k}\left(\dfrac{1}{n} - \dfrac{1}{n+k}\right)$。

**操作步骤**：
1. 把每项用裂项公式拆成两个简单分式之差。
2. 把所有项展开列出，相邻项消去（前一项的"后半"与后一项的"前半"互消）。
3. 只剩下第一项的"前半"和最后一项的"后半"，直接计算。

**为什么有效**：裂项后得到"望远镜式"（telescoping）求和，大量中间项抵消，只剩首尾两项。

## 四、方法变形

### 变形 1：繁分式（分母含分式）化简

**繁分式**是分子或分母本身也是分式的表达式，例如：

$$\frac{1 - \dfrac{1}{x}}{1 + \dfrac{1}{x}}$$

**策略**：找"内层分式"的公分母，上下同乘，消去内层分式。

$$\frac{1 - \frac{1}{x}}{1 + \frac{1}{x}} \times \frac{x}{x} = \frac{x - 1}{x + 1}$$

一步化为普通分式，再根据需要继续约分。

更复杂的繁分式：$\dfrac{\frac{1}{a} + \frac{1}{b}}{\frac{1}{a} - \frac{1}{b}}$，内层公分母为 $ab$，上下同乘 $ab$，得 $\dfrac{b+a}{b-a}$。

### 变形 2：化简后代入求值

**题型**：化简一个含 $x$ 的分式表达式，然后代入给定的 $x$ 值求数值。

**正确顺序**：先化到最简，**再代入**——绝不边算边代，否则中间结果膨胀，极易出错。

**例**：化简 $\dfrac{x^2-6x+9}{x^2-9}$，当 $x=-1$ 时求值。

因式分解：$x^2-6x+9=(x-3)^2$，$x^2-9=(x+3)(x-3)$，约分得 $\dfrac{x-3}{x+3}$。

代入 $x=-1$：$\dfrac{-1-3}{-1+3} = \dfrac{-4}{2} = -2$。

若先代入再化简，原式分子 $=(-1)^2-6(-1)+9=16$，分母 $=(-1)^2-9=-8$，商为 $-2$——结果相同但计算量更大。

### 变形 3：条件代入（已知整体，求另一整体）

**题型**：题目给 $x + \dfrac{1}{x} = k$（或类似整体条件），求 $x^2 + \dfrac{1}{x^2}$、$x^3+\dfrac{1}{x^3}$ 等。

**策略**：利用公式法（平方、立方恒等式），用已知整体直接表示目标量，不解出 $x$。

$$x^2 + \frac{1}{x^2} = \left(x + \frac{1}{x}\right)^2 - 2 = k^2 - 2$$

## 五、思考路标（条件反射训练）

每一条，读到"看到就秒反应"的程度：

1. **见分式 + 多项式**（加减乘除均可）→ **先因式分解全部分子分母，再约分**，绝不先展开乘。
2. **见异分母分式相加减** → **通分**：找最简公分母（LCM），按"最高次幂"取，不是直接相乘。
3. **见重复的分式结构**（同一分式出现两次或以"分式 + 其倒数"形式出现）→ **整体换元**，令 $t = $ 该分式。
4. **见 $\dfrac{1}{n(n+1)}$ 或 $\dfrac{1}{n(n+k)}$ 求和** → **裂项**：$\dfrac{1}{n(n+1)} = \dfrac{1}{n} - \dfrac{1}{n+1}$，展开后逐项消去。
5. **见繁分式**（分母里还有分式）→ **上下同乘内层公分母**，一步消去内层分母。
6. **化简后求值** → **化到最简再代值**，不要边化边代，避免中途膨胀。
7. **见 $\frac{A}{B}$ 不能约分** → 检查：$A$ 和 $B$ 是"和"的形式还是"积"的形式？只有积才能约，和不能约。
8. **结果要化最简** → 化简完后检查分子分母是否还有公因式，有则继续约。

## 六、应用例题

### 例 1　通分合并得 0

化简 $\dfrac{1}{x-1} + \dfrac{1}{x+1} - \dfrac{2x}{x^2-1}$。

**【思路】** 注意 $x^2-1=(x+1)(x-1)$，最简公分母 LCD = $x^2-1$。

$$\frac{1}{x-1} = \frac{x+1}{x^2-1}, \quad \frac{1}{x+1} = \frac{x-1}{x^2-1}$$

$$\text{原式} = \frac{(x+1) + (x-1) - 2x}{x^2-1} = \frac{x+1+x-1-2x}{x^2-1} = \frac{0}{x^2-1} = 0$$

**答**：原式 $= 0$（$x \neq \pm 1$）。

**点评**：三项通分后分子恰好全部抵消，结果为 $0$。这类"化简为 0"是中考常见考点，一旦看到三个分式分母中有两个简单、一个是前两者之积，立刻通分。

---

### 例 2　化简后代入求值

化简 $\dfrac{x^2-6x+9}{x^2-9}$，并在 $x = -1$ 时求其值。

**【思路】** 因式分解：

$$x^2 - 6x + 9 = (x-3)^2, \quad x^2 - 9 = (x+3)(x-3)$$

$$\text{原式} = \frac{(x-3)^2}{(x+3)(x-3)} = \frac{x-3}{x+3} \quad (x \neq 3, x \neq -3)$$

代入 $x = -1$：

$$\frac{-1-3}{-1+3} = \frac{-4}{2} = -2$$

**答**：原式化简为 $\dfrac{x-3}{x+3}$，当 $x=-1$ 时值为 $-2$。

---

### 例 3　裂项求和

计算 $\dfrac{1}{1 \times 2} + \dfrac{1}{2 \times 3} + \dfrac{1}{3 \times 4} + \cdots + \dfrac{1}{9 \times 10}$。

**【思路】** 每项都是 $\dfrac{1}{n(n+1)}$ 形式，裂项：

$$\frac{1}{n(n+1)} = \frac{1}{n} - \frac{1}{n+1}$$

展开各项：

$$\left(\frac{1}{1}-\frac{1}{2}\right) + \left(\frac{1}{2}-\frac{1}{3}\right) + \left(\frac{1}{3}-\frac{1}{4}\right) + \cdots + \left(\frac{1}{9}-\frac{1}{10}\right)$$

相邻项消去（望远镜效应）：中间项两两消去，只剩首尾：

$$= \frac{1}{1} - \frac{1}{10} = 1 - \frac{1}{10} = \frac{9}{10}$$

**答**：原式 $= \dfrac{9}{10}$。

**推广**：$\displaystyle\sum_{k=1}^{n} \frac{1}{k(k+1)} = 1 - \frac{1}{n+1} = \frac{n}{n+1}$。

## 七、思路自测题

**自测 1**（☆）

化简 $\dfrac{x^2-4}{x^2+4x+4}$。

> 💡 提示：$x^2-4 = (x+2)(x-2)$，$x^2+4x+4 = (x+2)^2$，约掉公因式 $(x+2)$，结果为 $\dfrac{x-2}{x+2}$（$x \neq -2$）。

---

**自测 2**（☆☆）

化简 $\dfrac{1}{x(x+1)} + \dfrac{1}{(x+1)(x+2)} + \dfrac{1}{(x+2)(x+3)}$。

> 💡 提示：三项都用裂项公式 $\dfrac{1}{n(n+1)} = \dfrac{1}{n} - \dfrac{1}{n+1}$ 展开，得 $\left(\dfrac{1}{x} - \dfrac{1}{x+1}\right) + \left(\dfrac{1}{x+1} - \dfrac{1}{x+2}\right) + \left(\dfrac{1}{x+2} - \dfrac{1}{x+3}\right)$，中间项消去，结果为 $\dfrac{1}{x} - \dfrac{1}{x+3} = \dfrac{3}{x(x+3)}$。

---

**自测 3**（☆☆）

化简繁分式 $\dfrac{x - \dfrac{x}{x+1}}{1 + \dfrac{1}{x+1}}$。

> 💡 提示：内层分母为 $x+1$，上下同乘 $(x+1)$：分子 $= x(x+1) - x = x^2$，分母 $= (x+1)+1 = x+2$，结果为 $\dfrac{x^2}{x+2}$（$x \neq -1$，$x \neq -2$）。

---

**自测 4**（☆☆）

化简 $\dfrac{x^2+x}{x^2-2x+1} \div \dfrac{x^2+2x+1}{x^2-1}$。

> 💡 提示：因式分解：$x^2+x = x(x+1)$，$x^2-2x+1 = (x-1)^2$，$x^2+2x+1 = (x+1)^2$，$x^2-1 = (x+1)(x-1)$。除法变乘法，取倒数后一起约分，结果为 $\dfrac{x}{(x+1)(x-1)}$（即 $\dfrac{x}{x^2-1}$，$x \neq 0$，$x \neq \pm 1$）。

---

**自测 5**（☆☆☆）

已知 $x - \dfrac{1}{x} = 2$，求 $x^2 + \dfrac{1}{x^2}$ 和 $x^4 + \dfrac{1}{x^4}$。

> 💡 提示：对已知条件两边平方：$\left(x - \dfrac{1}{x}\right)^2 = x^2 - 2 + \dfrac{1}{x^2} = 4$，故 $x^2 + \dfrac{1}{x^2} = 6$；再对 $6$ 两边平方（利用完全平方）：$\left(x^2 + \dfrac{1}{x^2}\right)^2 = x^4 + 2 + \dfrac{1}{x^4} = 36$，故 $x^4 + \dfrac{1}{x^4} = 34$。

**回头看一眼"一例速记"**：

> 4 大武器：① 因式分解 + 约分 ② 通分合并 ③ 整体换元 ④ 裂项相消。  
> 见分式题，第一反应：**因式分解！** 能约分的约，不能约的再想通分。  
> 如果现在你看到 $\dfrac{x^2-1}{x^2-4x+3} \cdot \dfrac{x-3}{x+1}$ 能立刻说出"先分解，约掉三个因式，结果是 1"——本章，你拿下了。
