# 二次函数的应用

> **一例速记**：
>
> 应用题的核心是**建立二次函数关系**：拱桥/几何问题先建坐标系，利润问题先写出利润 $=$ 单价差 $\times$ 销量，面积/周长问题用约束条件消元——统一化为 $y = ax^2 + bx + c$，再配方求顶点，检验定义域，得到最值。

---

## 一、引入：一道生活中的数学题

> 一座拱桥（弧形桥洞）的跨度（两端点水平距离）为 $20$ 米，桥洞中央最高处距水面 $4$ 米。请建立坐标系，求桥洞曲线的函数解析式，并求距中央 $6$ 米处的桥洞高度。

先想一想：建坐标系时把原点放哪里最好？函数的形式是什么？

---

## 二、思维路径还原（解题者的内心独白）

> 桥洞是一段抛物线，开口向下（因为两端低，中间高）。要求解析式，需要知道几个特殊点。
>
> **建坐标系策略**：把**顶点（最高点）放在原点** $O(0, 0)$ —— 这样对称轴就是 $y$ 轴，顶点式 $y = ax^2$ 最简洁（$h = 0, k = 0$）。
>
> 桥洞两端：跨度 $20$ 米，中央是原点，两端横坐标分别为 $\pm 10$；高度从水面算，水面在 $y = -4$（因为顶点在水面上方 $4$ 米），所以两端点坐标为 $(-10, -4)$ 和 $(10, -4)$。
>
> **设顶点式**：$y = ax^2$（因为顶点在原点）。
>
> **代入端点** $(10, -4)$：
> $$-4 = a \cdot 100 \implies a = -\frac{1}{25}$$
>
> **解析式**：$y = -\dfrac{1}{25}x^2$。
>
> **求距中央 $6$ 米处高度**——"距中央 $6$ 米"即 $x = 6$（或 $x = -6$，对称）：
> $$y = -\frac{1}{25} \cdot 36 = -\frac{36}{25} = -1.44$$
>
> 意思是该处比顶点低 $1.44$ 米，即距水面高度为 $4 - 1.44 = 2.56$ 米。
>
> **关键反射确立**：拱桥/隧道题 → 建坐标系（顶点放原点）→ 写顶点式 → 代入端点 → 解 $a$。

## 三、抽象成方法

### 二次函数应用的三类经典题型

**类型一：拱桥 / 隧道 / 喷泉**

- **特征**：给出弧形的跨度（宽度）和中央高度，或若干点的位置
- **策略**：
  1. 建立直角坐标系（顶点放原点或对称轴为 $y$ 轴）
  2. 用顶点式或一般式设解析式
  3. 代入已知点求系数
  4. 用解析式回答"某位置的高度"等问题

**类型二：利润 / 销售最值**

- **特征**：单价、数量、利润之间的关系，其中"数量随单价变化"是线性关系
- **策略**：
  1. 设单价（或某增量）为 $x$，用线性关系写出数量 $Q$ 的表达式
  2. 利润 $W = (\text{售价} - \text{成本}) \times \text{数量}$
  3. 展开化简得二次函数 $W(x)$
  4. 配方求最大值，检验 $x$ 的实际约束（定义域）

**类型三：几何最值（含动点）**

- **特征**：用固定长度（篱笆、绳子等）围成几何图形，求面积/周长最值；或含动点的几何量
- **策略**：
  1. 设动量（如一段边长）为 $x$，用约束条件（总长度固定）表示其他边
  2. 面积或目标量 $= f(x)$，整理为二次函数
  3. 配方求顶点，得最大/最小值
  4. 验证 $x$ 的有效范围（定义域）

### 求最值的标准流程

1. **建函数关系**：将问题中的目标量（利润、面积等）表示为某变量 $x$ 的函数 $y = ax^2 + bx + c$
2. **判断开口方向**：$a > 0$ 开口向上有最小值，$a < 0$ 开口向下有最大值
3. **求顶点**：配方法 $y = a(x - h)^2 + k$，顶点为 $(h, k)$，最值为 $k$（当 $x = h$ 时取到）
4. **检验定义域**：若顶点 $x = h$ 在定义域内，最值就是 $k$；若 $h$ 在定义域外，最值在离 $h$ 最近的端点处取到

## 四、方法变形

### 变形 1：坐标系的原点选择

不同的原点设置会影响计算复杂度：

- **顶点在原点**：对称轴为 $y$ 轴，用 $y = ax^2$，代入最方便（只剩一个系数 $a$）
- **对称轴为 $y$ 轴但顶点不在原点**：用 $y = ax^2 + k$，两个系数
- **其他任意放置**：用一般式或顶点式，代入更多点

**原则**：优先让对称轴落在 $y$ 轴上，或让顶点在原点，使方程最简。

### 变形 2：利润题中的变量选择

设增加的单价为变量（而非总单价），有时方程更简洁：

"比原价每提高 $t$ 元，销量减少 $n$ 件" → 设提价为 $t$，则单价为 $(p_0 + t)$，销量为 $(Q_0 - nt)$，利润为

$$W = (p_0 + t - c) \cdot (Q_0 - nt)$$

展开后是关于 $t$ 的二次函数。

### 变形 3：定义域端点处取最值

若顶点对应的 $x$ 值不在实际有意义的范围内，则最值在端点处取到：

- 顶点 $h < x_{\min}$（顶点在定义域左侧）：在定义域内函数单调增，最小值在 $x_{\min}$，最大值在 $x_{\max}$
- 顶点 $h > x_{\max}$（顶点在定义域右侧）：在定义域内函数单调减，最小值在 $x_{\max}$，最大值在 $x_{\min}$

**务必画草图或分析单调性**，再确定最值位置。

## 五、思考路标（条件反射训练）

读每一条，练到"看到就秒反应"：

1. **见拱桥/抛物形曲线题** → 建坐标系（顶点在原点或对称轴为 $y$ 轴），用顶点式或 $y = ax^2$，代端点求 $a$。

2. **见利润/销售类题** → 利润 $=$ 单价利润 $\times$ 数量，两者乘积展开为二次函数，再求最大值。

3. **见"用篱笆围矩形"或"固定总量分配"** → 设一段为 $x$，用总量约束写出另一段，乘积面积是二次函数，求最大值。

4. **见最大值问题** → 确认 $a < 0$（开口向下），最大值 $= k$（顶点处），前提是顶点在有效范围内。

5. **见最小值问题** → $a > 0$（开口向上），最小值在顶点；若定义域是闭区间，也要检查端点。

6. **检验定义域** → 应用题中变量总有实际约束（如 $x > 0$，$x < 某上限$），务必确认最值点在约束范围内，否则取最近的端点值。

7. **建模时** → 把要求的目标量（面积、利润……）写成关于自变量的显式函数，再一步步化简，不要跳步。

## 六、应用例题

### 例 1　拱桥问题

一座拱桥的桥洞（截面呈抛物线形，开口向下），跨度为 $20$ 米，最高处距水面 $4$ 米。以**水面上的桥洞顶点正下方的水面点**为原点，水面为 $x$ 轴，竖直方向为 $y$ 轴建立坐标系（即顶点在 $(0, 4)$）。

（1）求桥洞抛物线的解析式；

（2）距中央水平距离 $6$ 米处，桥洞离水面的高度是多少？

（3）一艘宽 $14$ 米、最高处距水面 $3$ 米的船能否通过？

**【思路】** 用顶点式，顶点为 $(0, 4)$；端点在水面（$y = 0$），横坐标为 $\pm 10$。

**解**：

**（1）** 顶点 $(0, 4)$，设 $y = a(x - 0)^2 + 4 = ax^2 + 4$。

代入端点 $(10, 0)$：

$$0 = 100a + 4 \implies a = -\frac{1}{25}$$

解析式为 $\boxed{y = -\dfrac{1}{25}x^2 + 4}$（$-10 \leq x \leq 10$）。

**（2）** 代入 $x = 6$：

$$y = -\frac{36}{25} + 4 = -1.44 + 4 = 2.56 \text{ 米}$$

**（3）** 船宽 $14$ 米，即船需要通过宽度 $14$ 米的空间，船的两侧 $x = \pm 7$。

$$y\big|_{x=7} = -\frac{49}{25} + 4 = -1.96 + 4 = 2.04 \text{ 米}$$

在 $x = \pm 7$ 处，桥洞高度为 $2.04$ 米 $< 3$ 米，**船无法通过**。

（若要通过，需要在宽度 $14$ 米范围内桥洞高度均 $\geq 3$ 米。实际最低处在两边缘 $x = \pm 7$，高度仅 $2.04$ 米，不满足条件。）

### 例 2　利润最大化问题

某商品的进价为每件 $50$ 元。调查表明，当销售单价为 $60$ 元时，每月销量为 $500$ 件；销售单价每提高 $1$ 元，每月销量减少 $10$ 件。设销售单价为 $x$ 元（$x > 50$），求：

（1）每月利润 $W$（元）关于 $x$ 的函数关系式；

（2）每月利润最大时的销售单价及最大利润。

**【思路】** 利润 $=$ 单件利润 $\times$ 销量；销量是关于 $x$ 的线性函数。

**解**：

**（1）** 单件利润为 $(x - 50)$ 元。

当单价为 $x$ 元时，比 $60$ 元提高了 $(x - 60)$ 元，销量减少 $10(x - 60)$ 件，故销量为

$$Q = 500 - 10(x - 60) = 500 - 10x + 600 = 1100 - 10x \text{（件）}$$

月利润：

$$W = (x - 50) \cdot (1100 - 10x)$$

展开：

$$W = 1100x - 10x^2 - 55000 + 500x = -10x^2 + 1600x - 55000$$

**定义域**：$Q > 0$ 要求 $1100 - 10x > 0$，即 $x < 110$；且 $x > 50$。所以 $50 < x < 110$。

**（2）** 对 $W$ 配方：

$$W = -10(x^2 - 160x) - 55000 = -10(x - 80)^2 + -10 \cdot (-6400) - 55000$$
$$W = -10(x - 80)^2 + 64000 - 55000 = -10(x - 80)^2 + 9000$$

顶点为 $(80, 9000)$，$a = -10 < 0$，开口向下，有最大值。

$x = 80 \in (50, 110)$，顶点在定义域内，故

$$W_{\max} = 9000 \text{ 元，此时单价 } x = 80 \text{ 元}$$

**答**：每月利润最大时，销售单价定为 $\boxed{80}$ 元，最大月利润为 $\boxed{9000}$ 元。

### 例 3　几何最值——篱笆围矩形

用 $100$ 米长的篱笆，一面靠墙（墙足够长，不用篱笆），围成一个矩形菜地。设垂直于墙的一边长为 $x$ 米，求菜地面积 $S$ 的最大值。

**【思路】** 三边用篱笆：两条垂直于墙的边 + 一条平行于墙的边 $= 100$；平行墙的边 $= 100 - 2x$；面积 $= x(100 - 2x)$。

**解**：

设垂直于墙的边长为 $x$ 米，则平行墙的边长为 $(100 - 2x)$ 米。

**定义域**：$x > 0$ 且 $100 - 2x > 0$，即 $0 < x < 50$。

面积：

$$S = x(100 - 2x) = 100x - 2x^2 = -2x^2 + 100x$$

配方：

$$S = -2(x^2 - 50x) = -2\left(x - 25\right)^2 + -2 \cdot (-625) = -2(x - 25)^2 + 1250$$

顶点 $(25, 1250)$，$a = -2 < 0$，有最大值。

$x = 25 \in (0, 50)$，顶点在定义域内，故

$$S_{\max} = 1250 \text{ 平方米，此时 } x = 25 \text{ 米}$$

此时平行墙的边 $= 100 - 50 = 50$ 米，矩形尺寸为 $25 \times 50$ 米。

**答**：垂直于墙的边长为 $25$ 米时，菜地面积最大，最大面积为 $\boxed{1250}$ 平方米。

## 七、自测题

**自测 1**（☆）

一座拱桥，跨度为 $16$ 米，最高处距水面 $8$ 米。以顶点为原点，水平方向为 $x$ 轴，向上为 $y$ 轴正方向建立坐标系，求抛物线解析式；并计算距中央 $4$ 米处的桥高。

> 💡 提示：顶点在原点，开口向下，设 $y = ax^2$；端点为 $(\pm 8, -8)$；代 $(8, -8)$：$-8 = 64a$，得 $a = -\frac{1}{8}$；解析式 $y = -\frac{1}{8}x^2$。$x = 4$ 时 $y = -2$，即距顶点 $2$ 米，距水面 $8 - 2 = 6$ 米。

---

**自测 2**（☆☆）

某商品每件成本 $30$ 元，当售价为 $40$ 元时月销量为 $200$ 件。售价每提高 $1$ 元，月销量减少 $5$ 件。求月利润最大时的售价。

> 💡 提示：设售价为 $x$ 元，销量 $= 200 - 5(x - 40) = 400 - 5x$，利润 $W = (x - 30)(400 - 5x) = -5x^2 + 550x - 12000$；顶点 $x = 55$（代入验证定义域）；最大利润在 $x = 55$ 元时取到。

---

**自测 3**（☆☆）

用 $60$ 米篱笆围成三面靠墙（三面不需篱笆）的矩形（即只有一面需要篱笆），错了——改成：用 $60$ 米篱笆围成一个矩形，四面都需要篱笆，但其中一面已有一段 $10$ 米的墙可利用。设矩形的宽为 $x$ 米，长为 $y$ 米，建立 $S$ 关于 $x$ 的函数，求面积最大值。

> 💡 提示：若矩形长 $y$、宽 $x$，篱笆总长 $= 2x + 2y - 10 = 60$（其中一条长边有 $10$ 米已有墙），即 $2x + 2y = 70$，故 $y = 35 - x$；$S = xy = x(35 - x) = -x^2 + 35x$；顶点 $x = 17.5$，$S_{\max} = 306.25$ 平方米。

---

**自测 4**（☆☆）

某种产品，生产 $x$ 百件（$1 \leq x \leq 6$）时的总成本为 $(x^2 - 4x + 5)$ 万元，每百件售价为 $3$ 万元，求生产多少百件时利润最大，最大利润是多少？

> 💡 提示：总收入 $= 3x$ 万元，利润 $W = 3x - (x^2 - 4x + 5) = -x^2 + 7x - 5 = -(x - \frac{7}{2})^2 + \frac{29}{4}$；顶点 $x = 3.5$，但 $x$ 须为整数（百件），比较 $x = 3$ 和 $x = 4$：$W(3) = -9 + 21 - 5 = 7$，$W(4) = -16 + 28 - 5 = 7$；最大利润均为 $7$ 万元（$x = 3$ 或 $x = 4$ 百件时）。

**自测 5**（☆☆☆）

矩形 $ABCD$ 中，$AB = 12$，$BC = 8$。点 $E$ 在 $AB$ 上，点 $F$ 在 $CD$ 上，$AE = DF = x$（$0 < x < 12$）。连接 $BF$ 和 $CE$，四边形 $BFCE$ 是什么形状？求其面积关于 $x$ 的函数，并求面积最大值。

> 💡 提示：$AE = DF = x$，则 $EB = 12 - x$，$FC = 12 - x$；$BF$ 和 $CE$ 均连接同侧，$BFCE$ 是等腰梯形。面积 $S_{BFCE} = S_{矩形} - S_{\triangle AEF} - \cdots$——用大矩形面积减去四角三角形面积，$S_{BFCE} = 12 \times 8 - x \cdot 8 = 96 - 8x$（实际是梯形，需仔细算）。正确做法：$BFCE$ 的两底为 $BE = 12 - x$ 和 $CF = 12 - x$（等长），高 $= BC = 8$，故 $S = (12-x) \times 8$，关于 $x$ 是线性函数（此题转为检验学生是否会识别特殊情况）。若改为 $AE \neq DF$，才会出现二次函数。
