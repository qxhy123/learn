# 二次函数的待定系数法

> **一例速记**：
>
> 看到"求二次函数解析式"——**先看已知什么**：有顶点选顶点式，有 $x$ 轴交点选交点式，只有普通三点选一般式。设对形式，代入已知，解出系数，验证收工。

---

## 一、引入：一道需要选择的题

> 已知二次函数图象与 $x$ 轴交于 $(1, 0)$ 和 $(-3, 0)$，且过点 $(0, -6)$，求函数解析式。

先停下来想：这道题给了哪些信息？两个 $x$ 轴交点 + 一个普通点——这三个条件，用哪种形式的二次函数设元最省力？

---

## 二、思维路径还原（解题者的内心独白）

> 题目给了 $x$ 轴上两个交点 $(1, 0)$ 和 $(-3, 0)$，还有一个额外的点 $(0, -6)$。
>
> **分析已知条件**：两个 $x$ 轴交点已知，额外点已知——共三个条件。
>
> **选择哪种形式？**
> - 一般式 $y = ax^2 + bx + c$：三个未知量 $a, b, c$，代三点，要解三元方程组。可以，但麻烦。
> - 顶点式 $y = a(x-h)^2 + k$：需要知道顶点坐标，题目没给。
> - **交点式** $y = a(x - x_1)(x - x_2)$：已知 $x$ 轴交点 $x_1 = 1$，$x_2 = -3$，直接套入形式，只剩一个未知量 $a$，代第三点一步解出。
>
> **毫无疑问选交点式**，因为 $x$ 轴交点已知，两个 $x_1, x_2$ 都有了，只剩一个 $a$ 要求。
>
> **第一步：设**——$y = a(x - 1)(x - (-3)) = a(x - 1)(x + 3)$。
>
> **第二步：代点**——代入 $(0, -6)$（即 $x = 0, y = -6$）：
>
> $$-6 = a(0 - 1)(0 + 3) = a \cdot (-1) \cdot 3 = -3a$$
>
> 所以 $a = 2$。
>
> **第三步：写解析式**——
> $$y = 2(x - 1)(x + 3) = 2(x^2 + 2x - 3) = 2x^2 + 4x - 6$$
>
> **第四步：验证**——代入 $(1, 0)$：$y = 2(1)^2 + 4(1) - 6 = 0$ ✓；代入 $(-3, 0)$：$y = 2(9) - 12 - 6 = 0$ ✓；代入 $(0, -6)$：$y = -6$ ✓。
>
> **关键反射确立**：见到 $x$ 轴两个交点 → 交点式，设元立刻少两个，只剩 $a$，代一个点即可。

---

## 三、抽象成方法

### 待定系数法的本质

**待定系数法**：先按函数类型写出通式（系数暂时待定），再利用已知的点或条件建立方程，解出待定的系数。

二次函数有三种形式，根据题目的已知条件，**选择待定系数最少的形式**效率最高。

### 三种形式选用规则

| 已知条件 | 最快选用 | 待定系数 | 需要多少个点 |
|---|---|---|---|
| 任意三个点（无特殊位置） | **一般式** $y = ax^2 + bx + c$ | $a, b, c$ 三个 | 3 个点 |
| 顶点 $(h, k)$ + 一个普通点 | **顶点式** $y = a(x - h)^2 + k$ | 只有 $a$ | 1 个额外点 |
| 两个 $x$ 轴交点 $x_1, x_2$ + 一个普通点 | **交点式** $y = a(x - x_1)(x - x_2)$ | 只有 $a$ | 1 个额外点 |

### 待定系数法的 4 步流程

**第一步——设**：根据已知信息选对形式，写出含待定系数的通式。

**第二步——代**：将已知点（坐标）代入通式，每个点建立一个方程。有几个待定系数，就需要代几个有效的点。

**第三步——解**：解方程或方程组，求出所有待定系数。

**第四步——写**：将系数代回通式，写出完整解析式；代入已知点验证。

## 四、方法变形

### 变形 1：一般式——三点三方程

当题目给出三个任意点（没有特殊位置），用一般式 $y = ax^2 + bx + c$，代三点得三元一次方程组：

$$\begin{cases} ax_1^2 + bx_1 + c = y_1 \\ ax_2^2 + bx_2 + c = y_2 \\ ax_3^2 + bx_3 + c = y_3 \end{cases}$$

解这个方程组求出 $a, b, c$。

**注意**：若题目暗示 $c$（纵截距，即图象过 $(0, y_0)$），代入 $x = 0$ 直接得 $c = y_0$，方程组降为二元，计算大幅简化。

### 变形 2：顶点式——顶点在前

已知顶点 $(h, k)$，立即写出顶点式 $y = a(x - h)^2 + k$。此时 $a$ 是唯一待定系数，只需代入**一个额外的已知点**即可求出 $a$。

**常见陷阱**：顶点 $(h, k)$ 中的 $h$ 对应 $(x - h)$，符号切勿搞错。顶点 $(2, -3)$ 对应 $y = a(x - 2)^2 - 3$，不是 $y = a(x + 2)^2 + 3$。

### 变形 3：混合条件

有时题目给出"对称轴 + 一个交点 + 一个普通点"等混合信息。对称轴为 $x = h$ 时，顶点横坐标为 $h$，但顶点纵坐标 $k$ 未知——此时顶点式仍有两个待定量 $a$ 和 $k$，需要两个点。

**策略**：整理已知条件，数清楚有多少个方程可以建立，确保方程数 $\geq$ 待定系数数。

## 五、思考路标（条件反射训练）

读每一条，练到"看到就秒反应"：

1. **见"求二次函数解析式"** → 先分析已知条件是什么类型（顶点/交点/普通点），选最省力的形式设元。

2. **见"$x$ 轴上两个交点"** → **交点式**！直接把 $x_1, x_2$ 填进去，只剩一个 $a$，代第三个点一步解决。

3. **见"顶点"（最高点/最低点，或写作"顶点为 $(h, k)$"）** → **顶点式** $y = a(x - h)^2 + k$！顶点坐标代进形式，同样只剩 $a$。

4. **见"任意三个普通点"（无顶点无交点信息）** → **一般式**，三点建三方程，解三元方程组。优先找有没有 $x = 0$ 的点（纵截距）来简化计算。

5. **代入点时** → 坐标的 $x$ 值代入函数的 $x$，$y$ 值代入函数值，别弄反了。

6. **解出系数后** → 必须验证（代回原题所有已知点），特别是一般式解方程组时，容易算错一步导致整体错误。

7. **最后检查** → 二次函数要求 $a \neq 0$；交点式隐含 $\Delta \geq 0$（若算出来 $a = 0$，说明选错了形式或题目有误）。

## 六、应用例题

### 例 1　一般式——普通三点

已知二次函数经过 $(0, 1)$、$(1, 0)$、$(2, 3)$，求函数解析式。

**【思路】** 三个普通点，无顶点无 $x$ 轴交点信息，选一般式。注意 $(0, 1)$ 是纵截距，直接得 $c = 1$。

**解**：

设 $y = ax^2 + bx + c$。

代入 $(0, 1)$：

$$1 = a \cdot 0 + b \cdot 0 + c \implies c = 1$$

代入 $(1, 0)$：

$$0 = a + b + 1 \implies a + b = -1 \quad \cdots \text{①}$$

代入 $(2, 3)$：

$$3 = 4a + 2b + 1 \implies 4a + 2b = 2 \implies 2a + b = 1 \quad \cdots \text{②}$$

② $-$ ①：$a = 2$。

代回①：$2 + b = -1$，得 $b = -3$。

因此解析式为 $\boxed{y = 2x^2 - 3x + 1}$。

**验证**：代入 $(0, 1)$：$1$ ✓；代入 $(1, 0)$：$2 - 3 + 1 = 0$ ✓；代入 $(2, 3)$：$8 - 6 + 1 = 3$ ✓。

---

### 例 2　顶点式——顶点已知

已知二次函数顶点为 $(2, -3)$，且过点 $(0, 5)$，求函数解析式。

**【思路】** 顶点已知 → 顶点式 $y = a(x - 2)^2 - 3$，代入额外点求 $a$。

**解**：

设 $y = a(x - 2)^2 - 3$（顶点 $(2, -3)$，符号对应）。

代入 $(0, 5)$（即 $x = 0, y = 5$）：

$$5 = a(0 - 2)^2 - 3 = 4a - 3$$

$$4a = 8 \implies a = 2$$

因此解析式为 $y = 2(x - 2)^2 - 3$。

展开：$y = 2(x^2 - 4x + 4) - 3 = 2x^2 - 8x + 8 - 3 = \boxed{2x^2 - 8x + 5}$。

**验证**：代入 $(0, 5)$：$0 - 0 + 5 = 5$ ✓；顶点 $x = 2$：$y = 2(4) - 16 + 5 = 8 - 16 + 5 = -3$ ✓。

---

### 例 3　交点式——两个 $x$ 轴交点

已知二次函数与 $x$ 轴交于 $(1, 0)$ 和 $(-3, 0)$，且过点 $(0, -6)$，求函数解析式。

**【思路】** 两个 $x$ 轴交点 → 交点式，代第三点求 $a$（同引入题完整解答）。

**解**：

设 $y = a(x - 1)(x + 3)$（其中 $x_1 = 1, x_2 = -3$）。

代入 $(0, -6)$：

$$-6 = a(0 - 1)(0 + 3) = a(-1)(3) = -3a$$

$$a = 2$$

因此解析式为 $y = 2(x - 1)(x + 3)$。

展开：$y = 2(x^2 + 2x - 3) = \boxed{2x^2 + 4x - 6}$。

**验证**：代入 $(1, 0)$：$2 + 4 - 6 = 0$ ✓；代入 $(-3, 0)$：$2(9) - 12 - 6 = 0$ ✓；代入 $(0, -6)$：$-6$ ✓。

## 七、自测题

**自测 1**（☆）

已知二次函数过 $(0, 2)$、$(-1, 0)$、$(2, 0)$，求函数解析式。

> 💡 提示：两个 $x$ 轴交点 $(-1, 0)$ 和 $(2, 0)$ → 交点式 $y = a(x + 1)(x - 2)$；代 $(0, 2)$：$2 = a(1)(-2)$，得 $a = -1$；解析式为 $y = -(x + 1)(x - 2) = -x^2 + x + 2$。

---

**自测 2**（☆）

已知二次函数顶点为 $(-1, 4)$，且过原点 $(0, 0)$，求函数解析式。

> 💡 提示：顶点式 $y = a(x + 1)^2 + 4$；代 $(0, 0)$：$0 = a(1) + 4$，得 $a = -4$；解析式为 $y = -4(x + 1)^2 + 4 = -4x^2 - 8x$。

---

**自测 3**（☆☆）

已知二次函数过 $(1, 6)$、$(2, 11)$、$(-1, 6)$，求函数解析式，并指出对称轴。

> 💡 提示：三个普通点，用一般式；注意 $f(1) = f(-1) = 6$，说明 $x = 1$ 和 $x = -1$ 关于对称轴对称，对称轴为 $x = 0$，即 $b = 0$。设 $y = ax^2 + c$（$b = 0$），代两不同点：$6 = a + c$，$11 = 4a + c$；解得 $a = \frac{5}{3}$，$c = \frac{13}{3}$。

---

**自测 4**（☆☆）

已知抛物线过点 $(3, 0)$，对称轴为 $x = 1$，且过点 $(0, -6)$，求函数解析式。

> 💡 提示：对称轴 $x = 1$，顶点横坐标为 $1$，设顶点式 $y = a(x - 1)^2 + k$；利用过 $(3, 0)$：$0 = 4a + k$；利用过 $(0, -6)$：$-6 = a + k$；两式相减：$6 = 3a$，$a = 2$，$k = -8$；解析式为 $y = 2(x-1)^2 - 8 = 2x^2 - 4x - 6$。
