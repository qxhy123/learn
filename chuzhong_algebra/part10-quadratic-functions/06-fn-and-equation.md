# 二次函数与一元二次方程的关系

> **一例速记**：
>
> **抛物线与 $x$ 轴交点的横坐标 = 方程 $ax^2 + bx + c = 0$ 的根**。判别式 $\Delta$ 同时决定方程根的个数与图象交点个数。代数与几何在这里完全对应，两个语言描述同一件事。

---

## 一、引入题

> 已知抛物线 $y = x^2 - 4x + 3$，问：
> 1. 它与 $x$ 轴有几个交点？交点坐标是什么？
> 2. 用图象判断，不等式 $x^2 - 4x + 3 > 0$ 的解集是什么？

先停下来想：求抛物线与 $x$ 轴的交点，和解一元二次方程，有什么联系？

---

## 二、思维路径还原（解题者的内心独白）

> 求抛物线与 $x$ 轴的交点，就是求"抛物线上 $y = 0$ 的那些点"。
>
> **代数翻译**：把 $y = 0$ 代入 $y = x^2 - 4x + 3$，得到方程 $x^2 - 4x + 3 = 0$。
>
> 求这个一元二次方程的解，就得到了交点的横坐标。
>
> **解方程**：$x^2 - 4x + 3 = (x - 1)(x - 3) = 0$，所以 $x = 1$ 或 $x = 3$。
>
> **几何含义**：抛物线与 $x$ 轴交于 $(1, 0)$ 和 $(3, 0)$ 两点。
>
> **再深一步想**：方程有没有实数解，等价于抛物线有没有与 $x$ 轴的交点。用判别式检验：
> $$\Delta = (-4)^2 - 4 \cdot 1 \cdot 3 = 16 - 12 = 4 > 0$$
> $\Delta > 0$ → 方程有两个不相等的实数根 → 抛物线与 $x$ 轴有**两个**交点。
>
> 三种情形：
> - $\Delta > 0$：方程有 $2$ 个不等实数根 → 抛物线与 $x$ 轴 **2 个交点**
> - $\Delta = 0$：方程有 $1$ 个重根（两根相等）→ 抛物线与 $x$ 轴 **1 个切点**（相切）
> - $\Delta < 0$：方程没有实数根 → 抛物线与 $x$ 轴 **无交点**
>
> **再想不等式 $x^2 - 4x + 3 > 0$**：它问"什么 $x$ 使函数值 $y > 0$"。$y > 0$ 就是"抛物线在 $x$ 轴上方的部分"。抛物线开口向上（$a = 1 > 0$），与 $x$ 轴交于 $x = 1$ 和 $x = 3$。那么在 $x < 1$ 或 $x > 3$ 时，抛物线在 $x$ 轴上方（$y > 0$）；在 $1 < x < 3$ 时，抛物线在 $x$ 轴下方（$y < 0$）。
>
> **关键反射**：
> - 抛物线与 $x$ 轴的关系 = 一元二次方程根的情况——代数与几何完全对应
> - $y > 0$ 的 $x$ 范围 = 抛物线在 $x$ 轴上方的 $x$ 范围——这就是用图象解不等式的原理
> - 看到 $\Delta$，同时想：方程根的个数 + 图象交点个数——两种语言一起记

---

## 三、抽象成方法

### 核心对应关系（代数 ↔ 几何）

这是本章的灵魂。以下七行对应关系要烂熟于心：

| 二次函数（几何语言） | 一元二次方程或不等式（代数语言） |
|---|---|
| $y = ax^2 + bx + c$ 与 $x$ 轴**交点的横坐标** | 方程 $ax^2 + bx + c = 0$ 的**实数根** |
| 抛物线与 $x$ 轴有 **2 个交点** | $\Delta > 0$，方程有 **2 个不等实数根** |
| 抛物线与 $x$ 轴有 **1 个切点**（相切） | $\Delta = 0$，方程有 **1 个重根**（两根相等） |
| 抛物线与 $x$ 轴**无交点** | $\Delta < 0$，方程**无实数根** |
| 抛物线在 $x$ 轴**上方**的 $x$ 范围 | 不等式 $ax^2 + bx + c > 0$ 的**解集** |
| 抛物线在 $x$ 轴**下方**的 $x$ 范围 | 不等式 $ax^2 + bx + c < 0$ 的**解集** |
| 两抛物线（或抛物线与直线）的**交点** | 两方程**联立**（消去 $y$）所得方程的**解** |

### 用图象解一元二次不等式

**前提**：设 $ax^2 + bx + c = 0$ 的两根为 $x_1 < x_2$（$\Delta > 0$ 时）。

**规律**（$a > 0$，开口向上）：

$$ax^2 + bx + c > 0 \quad \Leftrightarrow \quad x < x_1 \text{ 或 } x > x_2$$

$$ax^2 + bx + c < 0 \quad \Leftrightarrow \quad x_1 < x < x_2$$

**规律**（$a < 0$，开口向下）：

$$ax^2 + bx + c > 0 \quad \Leftrightarrow \quad x_1 < x < x_2$$

$$ax^2 + bx + c < 0 \quad \Leftrightarrow \quad x < x_1 \text{ 或 } x > x_2$$

**记忆口诀**：开口向上时，$y > 0$ 在两侧，$y < 0$ 在中间；开口向下时反之。

### 判别式的双重含义

判别式 $\Delta = b^2 - 4ac$ 同时告诉我们两件事：

1. **方程（代数）**：$\Delta > 0$ → 两不等实根；$\Delta = 0$ → 两等实根（重根）；$\Delta < 0$ → 无实数根
2. **图象（几何）**：$\Delta > 0$ → 抛物线与 $x$ 轴两个交点；$\Delta = 0$ → 相切一点；$\Delta < 0$ → 无交点

## 四、方法变形

### 变形 1：抛物线与水平直线 $y = m$ 的交点

求抛物线 $y = ax^2 + bx + c$ 与水平直线 $y = m$ 的交点，等价于解方程：

$$ax^2 + bx + c = m \quad \Leftrightarrow \quad ax^2 + bx + (c - m) = 0$$

交点个数由 $\Delta' = b^2 - 4a(c - m)$ 的符号决定。

**特别情形**：$m = 0$ 就是抛物线与 $x$ 轴的交点（标准情形）。

### 变形 2：抛物线与一次函数的交点

求抛物线 $y = ax^2 + bx + c$ 与直线 $y = kx + b_0$ 的交点，联立两方程，消去 $y$：

$$ax^2 + bx + c = kx + b_0 \quad \Rightarrow \quad ax^2 + (b - k)x + (c - b_0) = 0$$

这是一个新的一元二次方程，其判别式决定两图象的交点个数（0、1 或 2 个）。

### 变形 3：韦达定理的几何意义

若 $ax^2 + bx + c = 0$ 的两根为 $x_1, x_2$（$\Delta > 0$），则由韦达定理：

$$x_1 + x_2 = -\frac{b}{a}, \quad x_1 \cdot x_2 = \frac{c}{a}$$

**几何意义**：
- $x_1 + x_2 = -\dfrac{b}{a}$：两交点横坐标之和等于对称轴横坐标的两倍（对称轴 $x = -\dfrac{b}{2a}$）
- $x_1 \cdot x_2 = \dfrac{c}{a}$：两交点横坐标之积，符号取决于 $c$ 和 $a$ 的符号

**应用**：不求出具体根，也能判断两根的正负关系（如 $x_1 x_2 > 0$ 说明两根同号）。

## 五、思考路标（条件反射训练）

读每一条，练到"看到就秒反应"：

1. **见"抛物线与 $x$ 轴的交点"** → 立刻翻译为"解方程 $ax^2 + bx + c = 0$"；交点横坐标 $=$ 方程的根。

2. **见判别式 $\Delta$** → 同时想两件事：一是方程根的个数（$>0$ 两根，$=0$ 重根，$<0$ 无实根），二是图象与 $x$ 轴交点的个数（同样的三种情形）。

3. **见不等式 $ax^2 + bx + c > 0$（或 $< 0$）** → 画（或想象）抛物线，找到它与 $x$ 轴交点，判断"上方"还是"下方"的 $x$ 范围——即图象法解不等式。

4. **见"抛物线与直线 $y = kx + b$ 的交点"** → 联立消 $y$，化为一个新的一元二次方程，用 $\Delta$ 判断交点数。

5. **见"两函数图象交点"** → 想到"联立方程组，消 $y$，得一元方程，求根"。

6. **数形结合是二次函数压轴题的核心**：任何时候代数推导遇到困难，都可以转换为几何图形来辅助判断；反之，几何直觉也可以转化为代数计算——两种语言灵活切换。

7. **含参数的 $\Delta$ 问题** → 把 $\Delta$ 整理为含参数的代数式，再解不等式（如 $\Delta > 0$）求参数范围。

## 六、应用例题

### 例 1　基础——求抛物线与 $x$ 轴交点

求抛物线 $y = x^2 - 4x + 3$ 与 $x$ 轴的交点坐标，并用判别式判断交点个数。

**【思路】** 令 $y = 0$，解方程；同时计算 $\Delta$ 验证交点个数。

**解**：

**判别式**：$\Delta = (-4)^2 - 4 \times 1 \times 3 = 16 - 12 = 4 > 0$

$\Delta > 0$，故抛物线与 $x$ 轴有**两个**交点。

**求交点**：令 $y = 0$：

$$x^2 - 4x + 3 = 0$$

因式分解：$(x - 1)(x - 3) = 0$

$$x = 1 \quad \text{或} \quad x = 3$$

交点坐标为 $\boxed{(1,\, 0)}$ 和 $\boxed{(3,\, 0)}$。

---

### 例 2　不等式应用——图象法解不等式

解不等式 $x^2 - 4x + 3 > 0$。

**【思路】** 先求方程 $x^2 - 4x + 3 = 0$ 的根，再根据图象（开口向上）判断 $y > 0$ 的 $x$ 范围。

**解**：

由例 1，$x^2 - 4x + 3 = 0$ 的根为 $x_1 = 1$，$x_2 = 3$。

抛物线 $y = x^2 - 4x + 3$ 开口向上（$a = 1 > 0$），与 $x$ 轴交于 $x = 1$ 和 $x = 3$。

图象分析：
- $x < 1$ 或 $x > 3$ 时，抛物线在 $x$ 轴**上方**，即 $y > 0$
- $1 < x < 3$ 时，抛物线在 $x$ 轴**下方**，即 $y < 0$
- $x = 1$ 或 $x = 3$ 时，$y = 0$（交点处）

不等式 $x^2 - 4x + 3 > 0$ 的解集为 $\boxed{\{x \mid x < 1 \text{ 或 } x > 3\}}$。

**追加**：解不等式 $x^2 - 4x + 3 < 0$ 的解集为 $\{x \mid 1 < x < 3\}$（两交点之间）。

---

### 例 3　含参问题——用 $\Delta$ 求参数范围

已知二次函数 $y = x^2 + (2k - 1)x + k^2$，其图象与 $x$ 轴有两个不同的交点，求实数 $k$ 的取值范围。

**【思路】** "与 $x$ 轴有两个不同交点" = "方程有两个不等实数根" = $\Delta > 0$。列不等式解 $k$。

**解**：

"图象与 $x$ 轴有两个不同交点"等价于方程 $x^2 + (2k - 1)x + k^2 = 0$ 有两个不等实数根，即

$$\Delta > 0$$

计算判别式：

$$\Delta = (2k - 1)^2 - 4 \cdot 1 \cdot k^2$$

展开：

$$\Delta = 4k^2 - 4k + 1 - 4k^2 = -4k + 1$$

由 $\Delta > 0$：

$$-4k + 1 > 0 \implies k < \frac{1}{4}$$

因此，$k$ 的取值范围为 $\boxed{k < \dfrac{1}{4}}$。

**验证**：取 $k = 0$：$y = x^2 - x$，$\Delta = 1 > 0$ ✓（两个交点 $x = 0, 1$）；取 $k = 1$：$\Delta = -4 + 1 = -3 < 0$（无交点）✓。

## 七、自测题

**自测 1**（☆）

判断抛物线 $y = 2x^2 - 3x + 1$ 与 $x$ 轴的交点个数，并求交点坐标。

> 💡 提示：$\Delta = 9 - 8 = 1 > 0$，有两个交点；令 $y = 0$：$2x^2 - 3x + 1 = 0$，$(2x - 1)(x - 1) = 0$，$x = \frac{1}{2}$ 或 $x = 1$；交点 $\left(\frac{1}{2}, 0\right)$ 和 $(1, 0)$。

---

**自测 2**（☆）

用图象法解不等式 $2x^2 - 3x + 1 < 0$。

> 💡 提示：由自测 1，$y = 2x^2 - 3x + 1$ 开口向上，与 $x$ 轴交于 $x = \frac{1}{2}$ 和 $x = 1$；$y < 0$ 在两交点之间，解集为 $\left\{x \;\middle|\; \dfrac{1}{2} < x < 1\right\}$。

---

**自测 3**（☆☆）

抛物线 $y = x^2 - mx + 4$ 与 $x$ 轴**只有一个**交点，求 $m$ 的值。

> 💡 提示："只有一个交点"即 $\Delta = 0$；$\Delta = m^2 - 16 = 0$，得 $m = 4$ 或 $m = -4$。当 $m = 4$ 时，唯一交点为 $x = 2$，即 $(2, 0)$；当 $m = -4$ 时，唯一交点为 $x = -2$，即 $(-2, 0)$。

---

**自测 4**（☆☆）

已知抛物线 $y = x^2 - 2x - 3$ 与直线 $y = x - 1$，求两图象的交点坐标。

> 💡 提示：联立，消 $y$：$x^2 - 2x - 3 = x - 1$，即 $x^2 - 3x - 2 = 0$……等等，检查：$x^2 - 2x - 3 - (x - 1) = x^2 - 3x - 2 = 0$；$\Delta = 9 + 8 = 17$，$x = \frac{3 \pm \sqrt{17}}{2}$（两个交点）。若要整数交点，可改题目，例如直线 $y = 2x + 1$：$x^2 - 2x - 3 = 2x + 1 \Rightarrow x^2 - 4x - 4 = 0$，$\Delta = 32$，仍非整数；或直线 $y = x - 1$ 改为 $y = -x + 1$：$x^2 - 2x - 3 = -x + 1 \Rightarrow x^2 - x - 4 = 0$。建议用原题：$x = \frac{3 \pm \sqrt{17}}{2}$，对应交点 $\left(\frac{3+\sqrt{17}}{2},\, \frac{1+\sqrt{17}}{2}\right)$ 和 $\left(\frac{3-\sqrt{17}}{2},\, \frac{1-\sqrt{17}}{2}\right)$。

---

**自测 5**（☆☆☆）

已知抛物线 $y = x^2 - (k + 2)x + k$ 与 $x$ 轴的两个交点横坐标之积为正数，且之和为负数，求 $k$ 的取值范围。

> 💡 提示：设两根为 $x_1, x_2$；由韦达定理，$x_1 x_2 = \frac{c}{a} = k$，$x_1 + x_2 = k + 2$。条件：$x_1 x_2 > 0$ 即 $k > 0$；$x_1 + x_2 < 0$ 即 $k + 2 < 0$，即 $k < -2$。两个条件 $k > 0$ 且 $k < -2$ 无法同时满足，所以**不存在**这样的 $k$（说明题目所描述的情形无解）。此题训练联合条件分析的能力。若改为"积为负、和为正"，则 $k < 0$ 且 $k + 2 > 0$，即 $-2 < k < 0$，有解。
