# 整式的加减

整式的加减本质上只做两件事：**识别同类项**，然后**合并**。听起来简单，但"去括号变号"和"正确识别同类"是最容易出错的地方。本章把这两个核心操作拆开，分别讲透，最后通过综合例题演练。

## 一、概念特征：怎么一眼认出

整式加减的核心问题是：哪些项可以"合并"？

**同类项**：所含**字母完全相同**，且**每个字母的指数也完全相同**的项，互为同类项。

直观记忆：**字母骨架一模一样，系数不同没关系**。

| 是同类项？ | 理由 |
| :--------: | :-- |
| $3x^2y$ 与 $-5x^2y$ | 字母骨架均为 $x^2y$，是同类项 |
| $2xy$ 与 $2yx$ | $xy = yx$（乘法交换），字母骨架相同，是同类项 |
| $3x^2$ 与 $3x$ | $x$ 的指数不同（$2$ vs $1$），不是同类项 |
| $4xy^2$ 与 $4x^2y$ | $x,y$ 的指数分别交换了，不是同类项 |
| $-7$ 与 $5$ | 都是常数项（零次单项式），是同类项 |

## 二、定义与运算法则

### 1. 合并同类项

**法则**：合并同类项，只需把系数相加，字母（及其指数）不变。

$$a x^m y^n + b x^m y^n = (a + b) x^m y^n$$

例如：
$$3x^2 - 5x^2 + 2x^2 = (3 - 5 + 2)x^2 = 0 \cdot x^2 = 0$$

**注意**：合并后系数为 $0$ 时，整项消失，不要保留 $0x^2$。

### 2. 去括号法则

括号前有**加号**：去掉括号，括号内各项符号**不变**。

$$a + (b - c) = a + b - c$$

括号前有**减号**：去掉括号，括号内各项符号**全部变号**（正变负，负变正）。

$$a - (b - c) = a - b + c$$

**记忆口诀**：加号括号原样写，减号括号全取反。

### 3. 添括号规则

添括号是去括号的逆运算：

- 括号前用加号：括号内各项符号**不变**。
- 括号前用减号：括号内各项符号**全部变号**。

例如：$a - b + c = a - (b - c)$

### 4. 整式加减的一般步骤

1. 去括号（按加减号规则变号）
2. 识别并合并同类项
3. 按降幂排列写出结果

## 三、推导：为什么这样运算

### 为什么"去减号括号要变号"？

本质是分配律：

$$a - (b - c) = a + (-(b - c)) = a + (-b + c) = a - b + c$$

减号可以看作"乘以 $-1$"，分配给括号内每一项，所以每项都变号。

### 为什么合并同类项时字母不变？

以 $3x^2 + 5x^2$ 为例，字母 $x^2$ 是"单位"：

$$3x^2 + 5x^2 = (3 + 5) \cdot x^2 = 8x^2$$

这与 $3$ 个苹果 $+$ $5$ 个苹果 $= 8$ 个苹果完全一样——"单位"（$x^2$ / 苹果）不参与加减，只有系数（个数）相加。

**但 $3x + 5x^2$ 不能合并**，就像 $3$ 个苹果和 $5$ 个梨不能直接相加说"$8$ 个苹果"一样——"单位"不同。

## 四、典型应用

### 例 1　合并同类项

合并同类项：$3x^2 - 5x^2 + 2x^2$。

【思路】三项的字母骨架都是 $x^2$，直接系数相加。

**解**：

$$3x^2 - 5x^2 + 2x^2 = (3 - 5 + 2)x^2 = 0 \cdot x^2 = 0$$

结果为 $0$，原式三项恰好互相抵消。

### 例 2　含去括号的化简

化简：$(2a - 3b) - (a - 2b + c) + (3a + b)$。

【思路】先去括号（注意第二个括号前是减号，各项变号），再合并同类项。

**解**：

第一步，去括号：

$$= 2a - 3b - a + 2b - c + 3a + b$$

第二步，识别同类项并合并（$a$ 类：$2a - a + 3a$；$b$ 类：$-3b + 2b + b$；$c$ 类：$-c$）：

$$= (2 - 1 + 3)a + (-3 + 2 + 1)b - c$$

$$= 4a + 0 \cdot b - c$$

$$= 4a - c$$

注意 $b$ 的系数恰好为 $0$，$b$ 项消失。

### 例 3　化简求值

化简 $3(x^2 + 2x) - (x^2 - x + 1)$，并当 $x = -1$ 时求值。

【思路】先去括号并化简（第一个括号前系数 $3$ 用分配律展开），得到最简形式，再代入 $x = -1$。

**解**：

第一步，展开去括号：

$$3x^2 + 6x - x^2 + x - 1$$

第二步，合并同类项（$x^2$ 类：$3x^2 - x^2$；$x$ 类：$6x + x$；常数类：$-1$）：

$$= 2x^2 + 7x - 1$$

第三步，代入 $x = -1$：

$$2(-1)^2 + 7(-1) - 1 = 2 \times 1 + (-7) - 1 = 2 - 7 - 1 = -6$$

## 五、易错点 & 反例

**易错点 1：减号括号内的项没有全部变号**

错误：
$$5x - (3x - 2) = 5x - 3x - 2 = 2x - 2$$

正确：
$$5x - (3x - 2) = 5x - 3x + 2 = 2x + 2$$

$-2$ 在括号内，前面是减号，$-2$ 变为 $+2$。

**易错点 2：同类项识别错误——字母顺序无关**

$2xy$ 与 $3yx$ 是同类项（$xy = yx$，乘法交换律），但 $2xy^2$ 与 $3x^2y$ **不是**同类项（$x, y$ 的指数分别为 $1,2$ 与 $2,1$，骨架不同）。

**易错点 3：系数为 $1$ 或 $-1$ 时漏写**

$-x^2$ 的系数是 $-1$，合并时 $3x^2 + (-x^2) = 3x^2 - x^2 = 2x^2$，不是 $3x^2 - x = (3-1)x^2 = 2x^2$（此处 $-x^2$ 与 $-x$ 混淆）。

**易错点 4：带系数括号前用分配律**

$2(x + 3) \neq 2x + 3$（漏乘）。正确：$2(x + 3) = 2x + 6$。

**易错点 5：常数项忘记合并**

$x^2 + 3 - 5 + 2x^2$：常数 $3$ 与 $-5$ 是同类项，应合并为 $-2$，结果是 $3x^2 - 2$，不是 $3x^2 + 3 - 5$（忘记合并）。

## 六、思路自测题

1. 合并同类项：$5ab^2 - 3ab^2 - 2ab^2 + ab^2$。  
   💡 提示：四项字母骨架相同，系数相加：$(5-3-2+1)ab^2$，注意第四项系数为 $+1$。

2. 去括号并化简：$4x^2 - (3x^2 - 2x + 1) + (x^2 + x)$。  
   💡 提示：第二个括号前是减号，各项变号；第三个括号前是加号，各项不变。合并后各同类项。

3. 化简 $(3m - 2n) + 2(n - m)$，然后当 $m = 2, n = -1$ 时求值。  
   💡 提示：先用分配律展开 $2(n - m) = 2n - 2m$，去括号后合并 $m$ 项与 $n$ 项，最后代入求值。

4. 已知 $A = 3x^2 - x + 2$，$B = x^2 + 2x - 1$，求 $A - 2B$。  
   💡 提示：$A - 2B = A - 2B$，先用分配律展开 $2B$，再用 $A - 2B$ 的形式去括号计算，注意 $2B$ 整体括号前是减号。
