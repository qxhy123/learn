# 一次函数的应用

一次函数 $y = kx + b$ 不只是一个代数公式——它是描述现实世界中**匀速变化**关系的数学语言。只要两个量之间存在"每增加 1 个单位，另一量固定增加（或减少）某数"的规律，就能用一次函数建模。掌握这一工具，行程、销售、计价这类看似不同的问题，本质上都是同一套方法。

## 一、应用题的 4 种主要类型

### 类型 1：行程问题

路程 = 速度 × 时间，即 $s = vt$。当速度 $v$ 恒定（匀速运动），路程 $s$ 是时间 $t$ 的**正比例函数** $s = vt$（斜率 $= v$，截距 $= 0$）。

若初始时已有一段路程 $s_0$（起点不在原点），则 $s = vt + s_0$，这是一般一次函数。

**坐标轴含义**：
- 横轴：时间 $t$（单位：时、分、秒等）
- 纵轴：路程 $s$（或距离 $d$）
- 斜率 $k = v$（速度）：图象越陡，速度越大
- $s$-$t$ 图象中，水平线段表示**静止**（速度为 $0$）

### 类型 2：销售问题

销量 $y$ 通常是售价 $p$ 的一次函数（价格上涨 → 销量下降，斜率为负）：

$$y = kp + b \quad (k < 0)$$

利润 $W = (\text{售价} - \text{成本}) \times \text{销量}$，展开后往往是关于 $p$ 的二次函数（初中阶段简化为已知一次关系后的线性计算）。

### 类型 3：分段一次函数（通讯费 / 出租车计价）

分段一次函数的特点：**在不同区间内各自是一次函数**，每段有不同的斜率（收费标准）。

出租车计价的典型结构：
$$\text{费用} = \begin{cases} \text{起步价}, & 0 < x \leq d_0 \\ \text{起步价} + k(x - d_0), & x > d_0 \end{cases}$$

其中 $d_0$ 是起步距离，$k$ 是超出部分的每公里单价。

### 类型 4：图象读题（看图说话）

给出 $y$-$x$ 图象，要求：
1. **读关键点**：截距（$x = 0$ 时的 $y$ 值）、交轴点、折点
2. **计算斜率**：$k = \dfrac{y_2 - y_1}{x_2 - x_1}$（取图上两个已知点）
3. **写解析式**：用待定系数法代入关键点求 $k, b$

## 二、关键技能：建立一次函数模型

### 建模步骤

**第一步：认清两个量**——确定哪个是自变量（$x$），哪个是因变量（$y$），并注明单位。

**第二步：判断是否是一次函数**——检验是否满足"$x$ 每变化 1 个单位，$y$ 固定变化 $k$ 个单位"，若是，斜率 $k = \dfrac{\Delta y}{\Delta x}$ 是常数。

**第三步：求解析式**——用两个已知条件（两点，或一点 + 斜率）用待定系数法求出 $k, b$。

**第四步：用解析式解题**——代入求值、求不等式的解、求交点。

**第五步：检验实际意义**——自变量范围是否合理（如时间 $\geq 0$，人数为正整数）。

### 从图象读取斜率

已知直线上两点 $A(x_1, y_1)$ 和 $B(x_2, y_2)$：

$$k = \frac{y_2 - y_1}{x_2 - x_1}$$

特别地：
- 若已知 $y$ 轴截距 $(0, b)$ 和另一点 $(x_1, y_1)$：$k = \dfrac{y_1 - b}{x_1}$
- 若图象经过原点，则 $b = 0$，只需一个点即可确定斜率

## 三、典型应用

### 例 1　行程图象题

甲乙两人从同一地点出发骑车，$s$-$t$ 图象（路程-时间）显示：甲的图象经过 $(0, 0)$ 和 $(2, 30)$；乙的图象经过 $(0, 0)$ 和 $(3, 30)$。

（1）求甲乙各自的速度；（2）出发后多少小时甲比乙多走 $10$ 千米？

【分析】图象过原点说明均是正比例函数，斜率即速度。

**解**：

设甲的路程为 $s_\text{甲}$，乙的路程为 $s_\text{乙}$，时间为 $t$（小时）。

**（1）求速度**：

甲图象经过 $(0,0)$ 和 $(2, 30)$：

$$k_\text{甲} = \frac{30 - 0}{2 - 0} = 15 \text{（千米/小时）}$$

$$s_\text{甲} = 15t$$

乙图象经过 $(0,0)$ 和 $(3, 30)$：

$$k_\text{乙} = \frac{30 - 0}{3 - 0} = 10 \text{（千米/小时）}$$

$$s_\text{乙} = 10t$$

甲的速度为 $15$ 千米/小时，乙的速度为 $10$ 千米/小时。

**（2）甲比乙多走 $10$ 千米**：

$$s_\text{甲} - s_\text{乙} = 15t - 10t = 5t = 10$$

$$t = 2 \text{（小时）}$$

出发后 $2$ 小时，甲比乙多走 $10$ 千米。

**验证**：$s_\text{甲}(2) = 30$，$s_\text{乙}(2) = 20$，差为 $10$ 千米 ✓

### 例 2　销售题

某商品每件成本 $20$ 元，售价 $p$ 元时月销量 $y = -10p + 500$（件）。

（1）售价 $p = 30$ 元时月销量是多少？（2）要使月销量不低于 $200$ 件，售价最高定为多少元？（3）写出月利润 $W$ 关于售价 $p$ 的函数关系式，并判断其类型。

【分析】月利润 = （售价 $-$ 成本）× 月销量。

**解**：

已知 $y = -10p + 500$，成本为 $20$ 元/件。

**（1）** 代入 $p = 30$：

$$y = -10 \times 30 + 500 = -300 + 500 = 200 \text{（件）}$$

售价 $30$ 元时月销量为 $\mathbf{200}$ 件。

**（2）** 月销量不低于 $200$ 件，即 $y \geq 200$：

$$-10p + 500 \geq 200$$

$$-10p \geq -300$$

$$p \leq 30$$

又售价须高于成本，$p > 20$，因此 $20 < p \leq 30$。

售价最高定为 $\mathbf{30}$ 元。

**（3）** 月利润：

$$W = (p - 20) \cdot y = (p - 20)(-10p + 500)$$

展开：

$$W = -10p^2 + 500p + 200p - 10000 = -10p^2 + 700p - 10000$$

这是关于 $p$ 的**二次函数**（不是一次函数）。实际应用中，当题目限定销量是 $p$ 的一次函数时，利润关于 $p$ 是二次函数——初中阶段若简化为"固定销量"，则利润才是线性的。

### 例 3　分段函数——出租车计价

某城市出租车计价规则：$3$ 千米（含 $3$ 千米）以内起步价 $8$ 元；超过 $3$ 千米的部分，每千米 $2$ 元。

（1）写出费用 $C$（元）关于行驶路程 $x$（千米）的函数关系式；（2）行驶 $7$ 千米需要付多少元？（3）若支付了 $18$ 元，行驶了多少千米？

**解**：

**（1）** 分两段讨论：

$$C = \begin{cases} 8, & 0 < x \leq 3 \\ 8 + 2(x - 3), & x > 3 \end{cases}$$

化简第二段：$8 + 2x - 6 = 2x + 2$。

$$\boxed{C = \begin{cases} 8, & 0 < x \leq 3 \\ 2x + 2, & x > 3 \end{cases}}$$

**（2）** $x = 7 > 3$，用第二段：

$$C = 2 \times 7 + 2 = 16 \text{（元）}$$

行驶 $7$ 千米需付 $\mathbf{16}$ 元。

**（3）** $C = 18$，先判断属于哪一段：第一段最大值为 $8$，$18 > 8$，故在第二段：

$$2x + 2 = 18$$

$$2x = 16$$

$$x = 8 \text{（千米）}$$

行驶了 $\mathbf{8}$ 千米。

**检验**：$x = 8 > 3$ ✓，代入 $C = 2(8) + 2 = 18$ ✓

## 四、易错点与提醒

**易错点 1：图象读取坐标不准确**

从图象读取斜率时，要选取**坐标都是整数**的"整点"，避免读取不精确的中间点。斜率 $= \dfrac{\Delta y}{\Delta x}$，分子分母都要仔细计算符号。

**易错点 2：分段函数的分界点归属**

"不超过 3 千米"是 $x \leq 3$（含等号），"超过 3 千米"是 $x > 3$（不含等号）。题目中的"含"与"不含"直接决定端点归哪一段，写错会导致分界点处函数值不连续（出现两个值）。

**易错点 3：忽略实际意义的限制**

销量不能是负数（$y \geq 0$），时间不能是负数（$t \geq 0$），路程不能为零（$x > 0$）。求出解析式后，务必补充自变量的合理范围。

**易错点 4：混淆"路程-时间图"与"速度-时间图"**

$s$-$t$ 图中斜率代表速度；速度-时间图（$v$-$t$ 图）中面积代表路程。两者含义不同，注意看清纵轴标签。

## 五、自测题

**题 1**　甲从 $A$ 地出发向 $B$ 地行进，$s$-$t$ 图象（路程-时间）经过 $(0, 0)$、$(4, 60)$ 两点。求甲的速度，并写出 $s$ 关于 $t$ 的函数关系式。

> 💡 提示：图象过原点，$k = 60 \div 4 = 15$（千米/小时），$s = 15t$。

**题 2**　某商品每件进价 $15$ 元。根据市场调查，售价 $p$ 元时日销量 $y = -5p + 200$（件，$p > 15$）。当 $p = 35$ 元时，日销量是多少件？

> 💡 提示：代入 $p = 35$：$y = -5 \times 35 + 200 = 25$ 件。

**题 3**　某移动套餐：月租 $20$ 元，赠送 $100$ 分钟通话；超出后每分钟 $0.2$ 元。写出月费 $C$（元）关于通话时间 $t$（分钟）的函数关系式（分段）。

> 💡 提示：$t \leq 100$ 时 $C = 20$；$t > 100$ 时 $C = 20 + 0.2(t - 100)$，化简得 $C = 0.2t$。

**题 4**　一次函数图象经过 $A(1, 5)$ 和 $B(3, 9)$。（1）求解析式；（2）若某实际问题中自变量 $x \in [0, 5]$，求对应的 $y$ 的范围。

> 💡 提示：$k = \dfrac{9-5}{3-1} = 2$，代入 $A$：$5 = 2 + b$，$b = 3$，$y = 2x + 3$。$x \in [0,5]$ 时 $y \in [3, 13]$（$k > 0$，单调递增）。
