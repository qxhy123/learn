# 配方法解一元二次方程

> **一例速记**：  
> $x^2 + 6x - 7 = 0$ → $x^2 + 6x = 7$ → $x^2 + 6x + 9 = 16$ → $(x+3)^2 = 16$ → $x = 1$ 或 $x = -7$。  
> **配方三步：移项 → 加"一次项系数一半的平方" → 开方**。  
> 见 $x^2 + bx$ → 立刻想"加 $\left(\dfrac{b}{2}\right)^2$，凑出 $\left(x + \dfrac{b}{2}\right)^2$"。

---

## 一、引入题

> **题目**：解方程 $x^2 + 6x - 7 = 0$。

先停下来，试试用上一章的方法。

用**因式分解法**：寻找两个整数，乘积为 $-7$，和为 $6$。试 $7$ 和 $-1$：$7 \times (-1) = -7$ ✓，$7 + (-1) = 6$ ✓。

$$x^2 + 6x - 7 = (x + 7)(x - 1) = 0 \quad \Rightarrow \quad x = 1 \text{ 或 } x = -7$$

这道题恰好能分解，但**许多方程的系数凑不出整数因子对**——比如 $x^2 + 6x + 2 = 0$，乘积为 $2$、和为 $6$ 的整数对根本不存在。

**问题**：有没有一种方法，不依赖因式分解是否"凑巧能分解"，而是对**所有**一元二次方程都通用？

有——这就是**配方法**。

---

## 二、思维路径还原（解题者的内心独白）

> "$x^2 + 6x - 7 = 0$ —— 我先试因式分解：需要两数积为 $-7$、和为 $6$，试了一下正好有 $(x+7)(x-1)=0$。但我现在不用那条路，我要练习配方。
>
> 看这个方程：有 $x^2$ 项和 $x$ 项，还差一个常数让 $x^2 + 6x + \square$ 变成完全平方。
>
> 完全平方的形态是 $(x + p)^2 = x^2 + 2px + p^2$。对比 $x^2 + 6x$，中间项系数是 $6 = 2p$，所以 $p = 3$，缺少的常数是 $p^2 = 9$。
>
> **关键动作**：把常数项 $-7$ 先移到右边，让左边只剩 $x^2 + 6x$；然后两边同时加 $9$。
>
> 第一步，移项：$x^2 + 6x = 7$。
>
> 第二步，两边加 $9$：$x^2 + 6x + 9 = 7 + 9 = 16$。
>
> 第三步，左边折叠：$x^2 + 6x + 9 = (x+3)^2$，所以 $(x+3)^2 = 16$。
>
> 这下可以直接开平方了：$x + 3 = \pm 4$。
>
> 两路：$x + 3 = 4$ → $x = 1$；$x + 3 = -4$ → $x = -7$。
>
> **验证**：$1^2 + 6 \times 1 - 7 = 0$ ✓；$(-7)^2 + 6 \times (-7) - 7 = 49 - 42 - 7 = 0$ ✓。
>
> **关键反射**：见 $x^2 + bx$，立刻想"加 $\left(\dfrac{b}{2}\right)^2$"。这不是技巧，是肌肉记忆。这个动作背后的逻辑是：把 $x^2 + bx + \left(\dfrac{b}{2}\right)^2$ 折叠成 $\left(x + \dfrac{b}{2}\right)^2$，右边等量补偿。"

把这段内心独白读两遍，感受每一步判断是如何自然出现的。配方法的难点不在计算，在于**为什么加那个数**、**加了之后左边能折叠成什么**——这两个"为什么"清楚了，方法就记住了。

## 三、抽象成方法

### 配方法三步流程（$x^2$ 系数为 1 时）

设方程为 $x^2 + bx + c = 0$，按以下三步操作：

**第一步：移项**

把常数项移到右边：

$$x^2 + bx = -c$$

**第二步：配方**

两边同时加上**一次项系数一半的平方** $\left(\dfrac{b}{2}\right)^2$：

$$x^2 + bx + \left(\frac{b}{2}\right)^2 = -c + \left(\frac{b}{2}\right)^2$$

左边恰好折叠成完全平方：

$$\left(x + \frac{b}{2}\right)^2 = \frac{b^2}{4} - c$$

**第三步：开方解**

设右边为 $d = \dfrac{b^2}{4} - c$：

- 若 $d > 0$：$x + \dfrac{b}{2} = \pm\sqrt{d}$，解出两个不相等的实数根
  $$x = -\frac{b}{2} \pm \sqrt{d}$$
- 若 $d = 0$：$x + \dfrac{b}{2} = 0$，两根相等，$x = -\dfrac{b}{2}$（重根）
- 若 $d < 0$：实数范围内无解（在初中阶段，负数不能开平方）

### 当 $a \neq 1$ 时

方程 $ax^2 + bx + c = 0$（$a \neq 0$，$a \neq 1$）：

**先两边除以 $a$**，化二次项系数为 $1$：

$$x^2 + \frac{b}{a}x + \frac{c}{a} = 0$$

再按上述三步配方。

**为什么要先除以 $a$？** 配方的核心是"识别 $x^2 + (\text{某系数})x$ 中一次项系数的一半"，这只在二次项系数为 $1$ 时容易操作。先化为 $1$ 再配方，步骤最清晰。

### 配方法完整公式（帮助理解，不需死记）

直接对 $ax^2 + bx + c = 0$ 配方到底，会得到：

$$\left(x + \frac{b}{2a}\right)^2 = \frac{b^2 - 4ac}{4a^2}$$

这正是下一章**求根公式**的推导来源。先学会配方，求根公式就不再神秘。

## 四、方法变形

### 变形 1：配方求二次函数最值

二次函数 $y = x^2 + bx + c$ 配成**顶点式**：

$$y = \left(x + \frac{b}{2}\right)^2 + \left(c - \frac{b^2}{4}\right)$$

因为完全平方 $\left(x + \dfrac{b}{2}\right)^2 \geq 0$，所以：

- **最小值**为 $c - \dfrac{b^2}{4}$，当 $x = -\dfrac{b}{2}$ 时取到
- 对于 $y = -x^2 + bx + c$（开口向下），类似配方后得**最大值**

这是 part10 二次函数的核心内容，在这里提前体会。

### 变形 2：配方证明不等式

要证 $x^2 - 4x + 5 > 0$ 对一切实数 $x$ 成立：

$$x^2 - 4x + 5 = (x^2 - 4x + 4) + 1 = (x-2)^2 + 1$$

因为 $(x-2)^2 \geq 0$，所以 $(x-2)^2 + 1 \geq 1 > 0$。

**结论**：$x^2 - 4x + 5 > 0$ 恒成立。

配方将"任意 $x$ 的不等式"化为"完全平方非负"的基本性质，是一种强有力的代数工具。

### 变形 3：完全平方公式逆用（折叠识别）

配方的核心操作是"折叠"：把 $A^2 + 2AB + B^2$ 识别为 $(A+B)^2$。

| 看到左边 | 折叠为 |
|----------|--------|
| $x^2 + 6x + 9$ | $(x+3)^2$ |
| $x^2 - 4x + 4$ | $(x-2)^2$ |
| $x^2 + bx + \left(\frac{b}{2}\right)^2$ | $\left(x+\frac{b}{2}\right)^2$ |
| $4x^2 - 12x + 9$ | $(2x-3)^2$ |

**练习眼力**：见到形如"$x^2 + (\text{偶数})x + \text{某正数}$"，先检验最后一项是不是一次项系数一半的平方，如果是，立刻折叠。

### 变形 4：含参数的二次方程

解方程 $x^2 + 4x + m = 0$（$m$ 为参数）：

配方：$(x+2)^2 = 4 - m$

- 当 $4 - m > 0$，即 $m < 4$：两个不相等实数根 $x = -2 \pm \sqrt{4-m}$
- 当 $4 - m = 0$，即 $m = 4$：重根 $x = -2$
- 当 $4 - m < 0$，即 $m > 4$：无实数根

配方后右边出现 $4 - m$，这正是用来分析参数的"判别量"，与下一章判别式 $\Delta$ 直接对应。

## 五、思考路标（条件反射训练）

下面每一条都要读到"不用想，看到就知道该干什么"的程度：

1. **见一元二次方程且一次项系数是偶数** → 优先配方（加 $\left(\dfrac{b}{2}\right)^2$，避免出现分数）。
2. **见 $x^2 + bx$（缺常数项部分）** → 立刻想"加 $\left(\dfrac{b}{2}\right)^2$，凑成 $\left(x + \dfrac{b}{2}\right)^2$"。
3. **见 $ax^2 + bx + c = 0$ 且 $a \neq 1$** → 第一步是两边除以 $a$，不要直接配方。
4. **见二次函数 $y = ax^2 + bx + c$** → 需要最值时，配方变顶点式 $a(x+p)^2 + q$。
5. **见"证明 $f(x) > 0$"** → 先配方，变成"$(\cdots)^2 + (\text{正数})$"，利用平方非负。
6. **见因式分解不行且系数含小数或分数** → 配方比猜因子更稳，但若系数复杂，求根公式更快。
7. **配方完成后右边为负** → 实数范围内无解；不要强行开方，要明确写"无实数根"。

## 六、应用例题

**例 1**　用配方法解方程 $x^2 - 4x - 5 = 0$。

**【思路】** $x^2$ 系数为 $1$，一次项系数 $-4$ 是偶数，适合配方。移项，然后加 $\left(\dfrac{-4}{2}\right)^2 = 4$。

**第一步（移项）**：

$$x^2 - 4x = 5$$

**第二步（配方）**：两边加 $4$：

$$x^2 - 4x + 4 = 5 + 4 = 9$$

$$\left(x - 2\right)^2 = 9$$

**第三步（开方解）**：

$$x - 2 = \pm 3$$

$$x = 2 + 3 = 5 \quad \text{或} \quad x = 2 - 3 = -1$$

**答**：$x = 5$ 或 $x = -1$。

**验证**：$5^2 - 4 \times 5 - 5 = 25 - 20 - 5 = 0$ ✓；$(-1)^2 - 4(-1) - 5 = 1 + 4 - 5 = 0$ ✓。

---

**例 2**　用配方法解方程 $2x^2 - 8x + 3 = 0$。

**【思路】** $x^2$ 系数为 $2 \neq 1$，先两边除以 $2$，化为二次项系数为 $1$ 的方程。

两边除以 $2$：

$$x^2 - 4x + \frac{3}{2} = 0$$

**第一步（移项）**：

$$x^2 - 4x = -\frac{3}{2}$$

**第二步（配方）**：一次项系数 $-4$，一半是 $-2$，平方是 $4$，两边加 $4$：

$$x^2 - 4x + 4 = -\frac{3}{2} + 4 = \frac{5}{2}$$

$$(x - 2)^2 = \frac{5}{2}$$

**第三步（开方解）**：

$$x - 2 = \pm\sqrt{\frac{5}{2}} = \pm\frac{\sqrt{10}}{2}$$

$$x = 2 \pm \frac{\sqrt{10}}{2} = \frac{4 \pm \sqrt{10}}{2}$$

**答**：$x = \dfrac{4 + \sqrt{10}}{2}$ 或 $x = \dfrac{4 - \sqrt{10}}{2}$。

**注意**：$\sqrt{\frac{5}{2}} = \sqrt{\frac{10}{4}} = \frac{\sqrt{10}}{2}$，有理化分母不要忘。

---

**例 3**　求 $y = x^2 - 6x + 11$ 的最小值，并说明在何处取到。

**【思路】** 这是二次函数求最值问题。把 $y = x^2 - 6x + 11$ 配方成顶点式。

$$y = x^2 - 6x + 11$$

$$= (x^2 - 6x + 9) - 9 + 11 \quad \text{（凑完全平方，同时补偿 $-9$）}$$

$$= (x - 3)^2 + 2$$

因为 $(x-3)^2 \geq 0$，所以 $y = (x-3)^2 + 2 \geq 2$。

当 $x = 3$ 时，$(x-3)^2 = 0$，$y$ 取到最小值 $2$。

**答**：$y$ 的最小值为 $2$，当 $x = 3$ 时取到。

**呼应**：顶点坐标为 $(3, 2)$——这正是二次函数抛物线的顶点，我们将在 part10 中系统讨论。

## 七、思路自测题

做题之前，先在脑中过一遍第五节的路标，再动笔。

**自测 1**　用配方法解方程 $x^2 + 8x + 7 = 0$。

> 💡 提示：移项得 $x^2 + 8x = -7$，加 $\left(\dfrac{8}{2}\right)^2 = 16$，两边加 $16$，得 $(x+4)^2 = 9$，开方得 $x + 4 = \pm 3$。

**自测 2**　用配方法解方程 $x^2 - 3x - 4 = 0$。

> 💡 提示：一次项系数 $-3$ 是奇数，加 $\left(\dfrac{-3}{2}\right)^2 = \dfrac{9}{4}$，右边变为 $4 + \dfrac{9}{4} = \dfrac{25}{4}$，$(x - \dfrac{3}{2})^2 = \dfrac{25}{4}$，$x - \dfrac{3}{2} = \pm\dfrac{5}{2}$。

**自测 3**　用配方法解方程 $3x^2 + 6x - 1 = 0$。

> 💡 提示：先两边除以 $3$，得 $x^2 + 2x - \dfrac{1}{3} = 0$；移项加 $1$，得 $(x+1)^2 = \dfrac{4}{3}$。注意有理化：$\sqrt{\dfrac{4}{3}} = \dfrac{2\sqrt{3}}{3}$。

**自测 4**　用配方证明：对一切实数 $x$，$x^2 + x + 1 > 0$。

> 💡 提示：配方得 $x^2 + x + 1 = \left(x + \dfrac{1}{2}\right)^2 + \dfrac{3}{4}$；完全平方 $\geq 0$，加 $\dfrac{3}{4} > 0$，故恒 $> 0$。

**自测 5**　求函数 $y = -x^2 + 4x - 1$ 的最大值。

> 💡 提示：先提负号：$y = -(x^2 - 4x) - 1 = -(x^2 - 4x + 4) + 4 - 1 = -(x-2)^2 + 3$；因为 $-(x-2)^2 \leq 0$，所以 $y \leq 3$；当 $x = 2$ 时取到最大值 $3$。

> $x^2 + 6x - 7 = 0$ → 移项 $x^2 + 6x = 7$ → 加 $9$，得 $(x+3)^2 = 16$ → $x = 1$ 或 $-7$。
