# 韦达定理（根与系数关系）

> **一例速记**：  
> $ax^2 + bx + c = 0$ 两根 $x_1, x_2$：$x_1 + x_2 = -\dfrac{b}{a}$，$x_1 x_2 = \dfrac{c}{a}$。**不解方程**就能用根的对称表达式计算任意由两根构成的对称量。

---

## 一、引入：一道看似要解方程的题

> **题目**：已知 $x^2 + 3x - 5 = 0$ 的两根为 $x_1$，$x_2$，求 $x_1^2 + x_2^2$ 的值。

先停下来，思考你会怎么做。

用求根公式当然可以：

$$x = \frac{-3 \pm \sqrt{9 + 20}}{2} = \frac{-3 \pm \sqrt{29}}{2}$$

然后 $x_1^2 + x_2^2 = \left(\dfrac{-3 + \sqrt{29}}{2}\right)^2 + \left(\dfrac{-3 - \sqrt{29}}{2}\right)^2$……

展开计算，两项中的交叉项正好抵消，最终会得到一个整数。**但这个过程复杂且容易出错。**

有没有更优雅的路？

---

## 二、思维路径还原（解题者的内心独白）

> 题目给了方程 $x^2 + 3x - 5 = 0$，问 $x_1^2 + x_2^2$。
>
> **错误思路的问题**：用求根公式解出 $x_1, x_2$ 之后，两个含根号的数分别平方再相加——计算量大，根号里 $\sqrt{29}$ 又不是整数，乘开之后极易算错。
>
> **换个角度看问题**：$x_1^2 + x_2^2$ 有什么特点？交换 $x_1$ 和 $x_2$，结果不变——这叫**两根的对称式**。  
> 对称式的关键性质：它一定能用 $x_1 + x_2$ 和 $x_1 x_2$ 这两个量来表达。
>
> **韦达定理来了**：不需要知道 $x_1, x_2$ 各是多少，只需要知道它们的和与积：  
> $x_1 + x_2 = -\dfrac{3}{1} = -3$，$x_1 x_2 = \dfrac{-5}{1} = -5$。  
> （$a = 1$，$b = 3$，$c = -5$，直接读系数。）
>
> **代数恒等式来搭桥**：$x_1^2 + x_2^2 = (x_1 + x_2)^2 - 2x_1 x_2$  
> 代入：$= (-3)^2 - 2 \times (-5) = 9 + 10 = 19$。
>
> **19，整数，干净利落。**
>
> **关键反射确立**：见到"$x_1, x_2$ 是方程的根，求关于两根的某个对称量"——立刻写韦达两式，然后用代数恒等式转化，**绝不先解方程**。

## 三、抽象成方法

### 韦达定理（Vieta's Theorem）

设 $ax^2 + bx + c = 0$（$a \neq 0$）有两个实数根 $x_1, x_2$（即 $\Delta = b^2 - 4ac \geq 0$），则：

$$\boxed{x_1 + x_2 = -\frac{b}{a}, \quad x_1 x_2 = \frac{c}{a}}$$

**推导**（由求根公式直接验证）：

$$x_1 + x_2 = \frac{-b + \sqrt{\Delta}}{2a} + \frac{-b - \sqrt{\Delta}}{2a} = \frac{-2b}{2a} = -\frac{b}{a}$$

$$x_1 \cdot x_2 = \frac{-b + \sqrt{\Delta}}{2a} \cdot \frac{-b - \sqrt{\Delta}}{2a} = \frac{(-b)^2 - (\sqrt{\Delta})^2}{4a^2} = \frac{b^2 - (b^2 - 4ac)}{4a^2} = \frac{4ac}{4a^2} = \frac{c}{a}$$

**记忆口诀**：和等于 $-\dfrac{b}{a}$（注意负号！），积等于 $\dfrac{c}{a}$（直接是 $c/a$，无负号）。

### 常用对称表达式变形（必背）

以下四个恒等式是韦达定理的标准配套工具：

**变形 1**（平方和）：
$$x_1^2 + x_2^2 = (x_1 + x_2)^2 - 2x_1 x_2$$

推导：$(x_1 + x_2)^2 = x_1^2 + 2x_1 x_2 + x_2^2$，两边减去 $2x_1 x_2$ 即得。

**变形 2**（差的平方）：
$$(x_1 - x_2)^2 = (x_1 + x_2)^2 - 4x_1 x_2$$

推导：$(x_1 - x_2)^2 = x_1^2 - 2x_1 x_2 + x_2^2 = (x_1^2 + x_2^2) - 2x_1 x_2$，代入变形 1。

（注意：$|x_1 - x_2| = \sqrt{(x_1-x_2)^2} = \dfrac{\sqrt{\Delta}}{|a|}$，可直接用 $\Delta$。）

**变形 3**（倒数和）：
$$\frac{1}{x_1} + \frac{1}{x_2} = \frac{x_1 + x_2}{x_1 x_2}$$

推导：通分得 $\dfrac{x_2 + x_1}{x_1 x_2}$。**使用前提**：$x_1 \neq 0$，$x_2 \neq 0$，即 $x_1 x_2 \neq 0$，即 $c \neq 0$。

**变形 4**（三次方和）：
$$x_1^3 + x_2^3 = (x_1 + x_2)^3 - 3x_1 x_2 (x_1 + x_2)$$

推导：利用因式分解 $x_1^3 + x_2^3 = (x_1 + x_2)(x_1^2 - x_1 x_2 + x_2^2) = (x_1 + x_2)\big[(x_1 + x_2)^2 - 3x_1 x_2\big]$。

## 四、方法变形

### 变形 1：含参题——判断根的符号

当方程含参数，题目要求"两根均为正数"或"两根异号"时，联合韦达定理与判别式：

**两正根**的充要条件：

$$\begin{cases} \Delta \geq 0 \\ x_1 + x_2 > 0 \\ x_1 x_2 > 0 \end{cases}$$

三个条件缺一不可：$\Delta \geq 0$ 保证有实数根；$x_1 + x_2 > 0$ 排除两根一正一负或两根均负；$x_1 x_2 > 0$ 确保两根同号（结合和为正，确认两根均正）。

**两异号根**的充要条件：

$$x_1 x_2 < 0$$

积为负意味着一正一负，此时 $(x_1 - x_2)^2 > 0$ 自动成立，$\Delta > 0$ 也自动保证，**无需另外验 $\Delta$**。

### 变形 2：构造方程

已知两个数的**和** $s$ 与**积** $p$，构造以这两数为根的一元二次方程：

$$t^2 - st + p = 0$$

这是韦达定理的"逆用"：根与系数关系反过来，由根构造方程。

**例**：以 $2 + \sqrt{3}$ 和 $2 - \sqrt{3}$ 为根：和 $= 4$，积 $= (2)^2 - (\sqrt{3})^2 = 1$，方程为 $t^2 - 4t + 1 = 0$。

### 变形 3：因式分解关联

韦达定理给出了二次多项式的**因式分解标准形式**：

$$ax^2 + bx + c = a(x - x_1)(x - x_2)$$

展开右边：$a(x^2 - (x_1 + x_2)x + x_1 x_2) = ax^2 - a(x_1+x_2)x + ax_1 x_2$，与左边对比系数，正是韦达关系。这将韦达定理与因式分解统一起来。

## 五、思考路标（条件反射训练）

每一条，读到"看到就秒反应"的程度：

1. **见"$x_1, x_2$ 是方程的根"** → 立刻写下两式：$x_1 + x_2 = -\dfrac{b}{a}$，$x_1 x_2 = \dfrac{c}{a}$，**不解方程**。

2. **见问"两根的对称表达式"**（$x_1^2+x_2^2$，$\dfrac{1}{x_1}+\dfrac{1}{x_2}$，$(x_1-x_2)^2$，……）→ 韦达 + 恒等式变形，**绝不先求根**。

3. **见 $x_1^2 + x_2^2$** → $(x_1+x_2)^2 - 2x_1 x_2$，立刻用变形 1。

4. **见"两根均正"** → $\Delta \geq 0$，$x_1 + x_2 > 0$，$x_1 x_2 > 0$，**三条件一个不能少**。

5. **见"两根异号"** → $x_1 x_2 < 0$ 即可，$\Delta > 0$ 自动成立，无需另验。

6. **含参题 + 韦达** → 先写 $x_1 + x_2 = f(m)$，$x_1 x_2 = g(m)$，联立判别式条件，解关于 $m$ 的不等式组。

7. **见 $\dfrac{1}{x_1} + \dfrac{1}{x_2}$** → 先确认 $x_1 x_2 = c/a \neq 0$（即 $c \neq 0$），再用变形 3。

8. **见"构造方程"（已知和积）** → $t^2 - (\text{和})t + (\text{积}) = 0$，韦达逆用。

## 六、应用例题

### 例 1　平方和（引入题完整解答）

已知 $x^2 + 3x - 5 = 0$ 的两根为 $x_1$，$x_2$，求 $x_1^2 + x_2^2$。

**【思路】** $x_1^2 + x_2^2$ 是对称式，用韦达 + 变形 1。

**解**：

由韦达定理，$a = 1$，$b = 3$，$c = -5$：

$$x_1 + x_2 = -3, \quad x_1 x_2 = -5$$

$$x_1^2 + x_2^2 = (x_1 + x_2)^2 - 2x_1 x_2 = (-3)^2 - 2 \times (-5) = 9 + 10 = \boxed{19}$$

---

### 例 2　含参题：两正根条件

方程 $x^2 - 4x + k = 0$ 的两根均为正数，求 $k$ 的范围。

**【思路】** 两正根 → 三个条件联立，解 $k$。

**解**：

$a = 1$，$b = -4$，$c = k$。韦达定理给出：

$$x_1 + x_2 = 4, \quad x_1 x_2 = k$$

列三条件：

$$\begin{cases} \Delta = 16 - 4k \geq 0 \\ x_1 + x_2 = 4 > 0 \quad \text{（自动满足）} \\ x_1 x_2 = k > 0 \end{cases}$$

由第一条：$k \leq 4$；由第三条：$k > 0$。

取交集：$\boxed{0 < k \leq 4}$。

**验证边界**：$k = 4$ 时 $\Delta = 0$，$x_1 = x_2 = 2 > 0$，满足"两正根"；$k \to 0^+$ 时一根趋于 0，仍满足正根条件。

---

### 例 3　构造方程

以 $2 + \sqrt{3}$ 和 $2 - \sqrt{3}$ 为根，构造一元二次方程。

**【思路】** 求两根的和与积，用韦达逆用构造。

**解**：

$$\text{和} = (2 + \sqrt{3}) + (2 - \sqrt{3}) = 4$$

$$\text{积} = (2 + \sqrt{3})(2 - \sqrt{3}) = 4 - 3 = 1$$

由韦达逆用，方程为：

$$t^2 - 4t + 1 = 0$$

**验证**：$\Delta = 16 - 4 = 12 > 0$，求根 $t = \dfrac{4 \pm \sqrt{12}}{2} = 2 \pm \sqrt{3}$，与题设一致。
