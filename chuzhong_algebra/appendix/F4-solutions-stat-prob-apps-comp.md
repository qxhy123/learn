### D.60 ☆☆

【思路】方差比较稳定性——方差小者更稳定

**解答**：

甲：10.1、10.0、9.9、10.1、9.9，均值 $= \dfrac{10.1+10.0+9.9+10.1+9.9}{5} = 50.0/5 = 10.0$。

甲方差：$\dfrac{(0.1)^2+(0)^2+(-0.1)^2+(0.1)^2+(-0.1)^2}{5} = \dfrac{0.01+0+0.01+0.01+0.01}{5} = \dfrac{0.04}{5} = 0.008$。

乙方差：$\dfrac{(0.2)^2+(-0.2)^2+(0.1)^2+(-0.1)^2+(0)^2}{5} = \dfrac{0.04+0.04+0.01+0.01+0}{5} = \dfrac{0.10}{5} = 0.02$。

甲方差 $0.008 <$ 乙方差 $0.02$，甲机器更稳定。

**答案**：甲方差 $0.008$，乙方差 $0.02$；**甲机器**生产质量更稳定。

### D.80 ☆☆

【思路】频率分布表 + 加权平均 + 调整后均值方程 + 中位数区间

**解答**：

数据：$[0,2)$: 10 人，$[2,4)$: 25 人，$[4,6)$: 35 人，$[6,8)$: 20 人，$[8,10]$: 10 人，共 100 人。

**(1)** $\bar{x} = 1\times0.10+3\times0.25+5\times0.35+7\times0.20+9\times0.10 = 0.1+0.75+1.75+1.4+0.9 = 4.9$（小时）。

**(2)** 调整：10 人从 $[0,2)$ 移入 $[6,8)$，新均值 $x$：原贡献 $10 \times 1 = 10$（用中值 1），新贡献 $10 \times 7 = 70$（进入 $[6,8)$ 用中值 7）。

$x = \dfrac{100 \times 4.9 - 10 + 70}{100} = \dfrac{490 - 10 + 70}{100} = \dfrac{550}{100} = 5.5$（小时）。

**(3)** 调整后：$[0,2)$: 0 人，$[2,4)$: 25，$[4,6)$: 35，$[6,8)$: 30，$[8,10]$: 10。

总 100 人，中位数为第 50、51 个的平均。前三段累计：0+25+35=60，前两段：0+25=25。第 50 个在 $[4,6)$ 内（第 26 到 60 个），故中位数在 **$[4,6)$**。

**答案**：(1) 平均阅读时间 **4.9 小时**；(2) $x = 5.5$ 小时；(3) 中位数落在 $[4,6)$ 区间。

### D.67 ☆☆

【思路】直线与坐标轴交点 + 三角形面积

**解答**：

$y = kx+4$：

- 与 $x$ 轴：令 $y=0$，$x = -\dfrac{4}{k}$，$A\left(-\dfrac{4}{k}, 0\right)$；
- 与 $y$ 轴：令 $x=0$，$y=4$，$B(0,4)$；
- 与 $x=2$：$y = 2k+4$，$C(2, 2k+4)$。

$\triangle OBC$：$O(0,0)$，$B(0,4)$，$C(2,2k+4)$。

底 $OB = 4$，$C$ 到 $y$ 轴距离（$C$ 的横坐标）$= 2$，面积 $= \dfrac{1}{2} \times 4 \times 2 = 4$。

但题设面积为 6：$4 \neq 6$，说明三角形 $OBC$ 面积计算应用向量叉积或坐标公式：

$S = \dfrac{1}{2}|x_O(y_B - y_C)+x_B(y_C-y_O)+x_C(y_O-y_B)| = \dfrac{1}{2}|0 \cdot (4-(2k+4))+0 \cdot ((2k+4)-0)+2 \cdot (0-4)|$

$= \dfrac{1}{2}|{-8}| = 4$。

面积恒为 4，与 $k$ 无关，无法等于 6。

重解：题中三角形可能是 $\triangle ABC$：$A(-\frac{4}{k},0)$，$B(0,4)$，$C(2,2k+4)$。

$S_{\triangle ABC} = \dfrac{1}{2}|(-\frac{4}{k})(4-(2k+4))+0((2k+4)-0)+2(0-4)|$

$= \dfrac{1}{2}\left|\left(-\dfrac{4}{k}\right)(-2k)+2(-4)\right| = \dfrac{1}{2}|8-8| = 0$？

再算：$A$、$B$、$C$ 三点若共线则面积为 0，它们均在直线 $y=kx+4$ 上（$A$ 的纵坐标 $y=0$，$B$ 纵坐标 $y=4$，$C$ 纵坐标 $y=2k+4$，均在直线上），三点共线，面积为 0，不合。

**重读题目**：$C$ 是直线与 $x=2$ 的交点，三角形 $OBC$ 面积为 6（$O$ 为原点）。

$O(0,0)$，$B(0,4)$，$C(2,2k+4)$，用公式：

$S = \dfrac{1}{2}|x_B y_C - x_C y_B| = \dfrac{1}{2}|0 \cdot (2k+4) - 2 \cdot 4| = \dfrac{1}{2} \cdot 8 = 4$。

仍为 4。若面积为 6，则 $C$ 为与 $y$ 轴的交点（$B$ 是与 $x$ 轴交点）：重设 $B$ 为 $x$ 轴交点 $(-\frac{4}{k},0)$，$C$ 为 $y$ 轴交点 $(0,4)$：

$\triangle OBC$：$O(0,0)$，$B(-\frac{4}{k},0)$，$C(0,4)$。底 $OB = \frac{4}{|k|}$，高 $= 4$（$C$ 的纵坐标）：$S = \dfrac{1}{2} \times \dfrac{4}{|k|} \times 4 = \dfrac{8}{|k|} = 6 \Rightarrow |k| = \dfrac{4}{3}$，$k = \pm\dfrac{4}{3}$。

**答案**：$k = \dfrac{4}{3}$ 或 $k = -\dfrac{4}{3}$（按 $\triangle OAB$ 面积为 6 解释）。

### D.70 ☆☆

【思路】等边三角形动点 + 函数表达

**解答**：

等边三角形 $ABC$ 边长 6，$P$ 从 $A$ 沿 $AB$ 运动，$AP = x$，$PE \perp AB$，$E$ 在 $BC$ 上。

在等边三角形中，$PE$ 的计算：设 $A$ 在左，$B$ 在右，$C$ 在上（高 $= 3\sqrt{3}$）。令 $A(0,0)$，$B(6,0)$，$C(3,3\sqrt{3})$，$P(x,0)$（$0 \leq x \leq 6$）。

$PE \perp AB$（即垂直于 $AB$），故 $E$ 在 $x = x_P = x$ 处的 $BC$ 上。

$BC$：从 $B(6,0)$ 到 $C(3,3\sqrt{3})$，参数式 $(6-3t, 3\sqrt{3}t)$，$t \in [0,1]$；或直线方程：斜率 $= \dfrac{3\sqrt{3}-0}{3-6} = -\sqrt{3}$，$y-0 = -\sqrt{3}(x-6)$，即 $y = -\sqrt{3}(x-6) = -\sqrt{3}x + 6\sqrt{3}$。

$E$ 横坐标为 $x$（$3 \leq x \leq 6$，$E$ 在 $BC$ 上需 $P$ 在 $B$ 和中点之间），$y_E = -\sqrt{3}x+6\sqrt{3} = \sqrt{3}(6-x)$。

$PE = y_E - 0 = \sqrt{3}(6-x)$（$3 \leq x \leq 6$，$E$ 在 $BC$；$0 \leq x \leq 3$ 时 $E$ 在 $AC$ 上，$AC$：$y = \sqrt{3}x$，$y_E = \sqrt{3}x$，$PE = \sqrt{3}x$）。

$PE = \begin{cases} \sqrt{3}x & 0 \leq x \leq 3 \\ \sqrt{3}(6-x) & 3 \leq x \leq 6 \end{cases}$，最大在 $x=3$，$PE_{\max} = 3\sqrt{3}$。

**答案**：$PE = \begin{cases} \sqrt{3}x & 0 \leq x \leq 3 \\ \sqrt{3}(6-x) & 3 \leq x \leq 6 \end{cases}$；$x=3$ 时 $PE$ 取最大值 $3\sqrt{3}$。

**(3)** 前 $n-1$ 行共 $\dfrac{(n-1)n}{2}$ 个奇数，第 $n$ 行第一个数是第 $\dfrac{n(n-1)}{2}+1$ 个奇数（奇数列为 $1,3,5,\ldots,2k-1$，第 $k$ 个为 $2k-1$）：

$a_n = 2\left(\dfrac{n(n-1)}{2}+1\right)-1 = n(n-1)+2-1 = n^2-n+1$。

验证：$a_1=1\checkmark$，$a_2=3\checkmark$，$a_3=7\checkmark$，$a_4=13\checkmark$，$a_5=21\checkmark$。

**答案**：(1) 第 5 行：21,23,25,27,29，$S_5=125$；(2) $S_n=n^3$；(3) $a_n = n^2-n+1$。

### E.38 ☆☆☆

【思路】"抛物三角形"验证 + 面积计算 + 参数方程

**解答**：

**(1)** $A(0,0)$，$B(2,4)$，$C(-1,1)$ 均在 $y=x^2$ 上。

是否共线：直线 $AB$ 斜率 $= \dfrac{4-0}{2-0}=2$，直线 $AC$ 斜率 $= \dfrac{1-0}{-1-0}=-1$，斜率不同，不共线，构成抛物三角形。

面积（用坐标公式）：$S = \dfrac{1}{2}|x_A(y_B-y_C)+x_B(y_C-y_A)+x_C(y_A-y_B)| = \dfrac{1}{2}|0(4-1)+2(1-0)+(-1)(0-4)| = \dfrac{1}{2}|0+2+4| = 3$。

**(2)** $P(t,t^2)$，$Q(-t,t^2)$，$R(0,0)$（$x=0$ 时 $y=0$）。

$|PQ| = 2t$（底边），$R$ 到 $PQ$ 的距离（$PQ$ 为水平线 $y=t^2$）$= t^2-0 = t^2$。

$S = \dfrac{1}{2} \times 2t \times t^2 = t^3$。

**(3)** $t^3 = 8 \Rightarrow t = 2$。

**答案**：(1) 三点不共线，面积 $= 3$；(2) $S=t^3$；(3) $t=2$。

### E.39 ☆☆☆

【思路】折叠重叠面积计算 + 方程建立

**解答**：

**(1)** 折线平行于宽边（长 $b$）：沿中轴折叠，重叠区域为宽 $\dfrac{a}{2}$、高 $b$ 的矩形，$S = \dfrac{a}{2} \times b = \dfrac{ab}{2}$。

**(2)** $a=8$，$b=6$，折线与长边（8）成 45°角，重叠为等腰直角三角形，直角边 $x$。

折叠时，对折重合区域的直角边需满足：折叠后两部分完全重叠区为等腰直角三角形，直角边长 $x$，$x \leq b = 6$（宽方向约束），$x \leq \dfrac{a}{2} = 4$（半长方向）。故 $x \leq 4$。

方程建立：折叠后每半边的投影需吻合。以折线过中心（长 4，宽 3）为基础，45° 折线斜向，重叠区等腰直角三角形直角边 $x$：

$S = \dfrac{1}{2}x^2$，此面积的约束条件可由几何关系建立。若折线过中心且与长边成 45°，则重叠三角形的直角边 $x = b = 6$（若 $b < a/2$ 时受宽限制，即 $x = 6$）但需 $x \leq 4$，取 $x = 4$，$S = \dfrac{1}{2}(16) = 8$。

**(3)** 折法 (1)：$S = \dfrac{8\times6}{2} = 24$；折法 (2)：$S = 8$。折法 (1) 面积更大。

**答案**：(1) $S = \dfrac{ab}{2}$；(2) $x = \min(b, a/2) = 4$，$S = 8$ 平方厘米；(3) 折法 (1) 重叠面积更大（24 > 8）。

### E.40 ☆☆☆

【思路】梯形中内接矩形面积 + 二次函数最大值

**解答**：

梯形：上底 20，下底 40，高 30，两腰对称。下底中点为原点，$S$（右腰上端）坐标 $(10, 30)$，下底右端 $(20, 0)$。

右腰直线：过 $(20,0)$ 和 $(10,30)$，斜率 $= \dfrac{30-0}{10-20} = -3$，$y = -3(x-20) = -3x+60$。

矩形 $PQRS$，$PQ$ 在下底，$PQ = 2x$（$0<x<20$），$P(-x,0)$，$Q(x,0)$。

$S$、$R$ 在两腰上，高 $h$：$R(x,h)$ 在右腰，$h = -3x+60$（当 $x \leq 20$）。

**(1)** $h = -3x+60$（需 $h > 0$：$x < 20$，满足 $0<x<20$）。

**(2)** 面积 $S = 2x \cdot h = 2x(-3x+60) = -6x^2+120x$。

**(3)** $S = -6(x^2-20x) = -6(x-10)^2+600$，最大值 **600 平方米**（$x=10$，$h=-30+60=30$，但 $h=30$ 等于梯形高，矩形填满——$PQ=20$，$h=30$，验证：当 $x=10$，矩形宽 $2\times10=20$，但上底宽 20，恰好覆盖整个上底，合法）。

**答案**：(1) $h = -3x+60$；(2) $S = -6x^2+120x$；(3) $S_{\max} = 600$ 平方米（$x=10$，$h=30$）。
