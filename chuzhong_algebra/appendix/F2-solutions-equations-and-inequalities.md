## C 组基础题（☆）——Part 5 一次方程

---

**C.24** ☆

【思路】解一元一次方程——去括号、移项、合并同类项、系数化为 1

**解答**：

$$3(x-2) - 2(1-x) = 5$$
$$3x - 6 - 2 + 2x = 5$$
$$5x - 8 = 5$$
$$5x = 13$$
$$x = \frac{13}{5}$$

**答案**：$x = \dfrac{13}{5}$

---

**C.25** ☆

【思路】代入法解二元一次方程组——将已表达出的变量代入另一个方程

**解答**：

由第一个方程 $y = 2x - 1$，代入第二个方程 $3x + y = 9$：

$$3x + (2x - 1) = 9 \Rightarrow 5x = 10 \Rightarrow x = 2$$

代回：$y = 2(2) - 1 = 3$

**答案**：$x = 2$，$y = 3$

---

**C.26** ☆

【思路】加减法解二元一次方程组——将第二个方程乘以适当倍数使一个变量系数相同，再加减消元

**解答**：

$\begin{cases} 2x + 3y = 7 \quad \cdots(1)\\ x - y = 1 \quad \cdots(2) \end{cases}$

$(2) \times 3$：$3x - 3y = 3 \quad \cdots(3)$

$(1) + (3)$：$5x = 10 \Rightarrow x = 2$

代入 $(2)$：$2 - y = 1 \Rightarrow y = 1$

**答案**：$x = 2$，$y = 1$

**C.27** ☆

【思路】一元一次方程应用——设未知量，根据题意列等量关系

**解答**：

设女生 $x$ 人，则男生 $(x + 3)$ 人。

$$x + (x + 3) = 45 \Rightarrow 2x = 42 \Rightarrow x = 21$$

男生：$21 + 3 = 24$ 人。

**答案**：女生 21 人，男生 24 人

---

**C.28** ☆

【思路】行程问题——同向行驶，速度差乘以时间等于距离差

**解答**：

设 $t$ 小时后乙超前甲 16 km。甲行驶 $4t$ km，乙行驶 $12t$ km。

$$12t - 4t = 16 \Rightarrow 8t = 16 \Rightarrow t = 2$$

**答案**：$t = 2$ 小时

## C 组基础题（☆）——Part 6 一元二次方程

---

**C.29** ☆

【思路】直接开平方法——$(x-a)^2 = b$ 时，$x - a = \pm\sqrt{b}$

**解答**：

$$(x-3)^2 = 16 \Rightarrow x - 3 = \pm 4$$

$x - 3 = 4 \Rightarrow x = 7$；$x - 3 = -4 \Rightarrow x = -1$

**答案**：$x = 7$ 或 $x = -1$

---

**C.30** ☆

【思路】因式分解法——将方程左端分解为两个一次因式之积，令每个因式为零

**解答**：

$$x^2 - 5x + 6 = 0 \Rightarrow (x-2)(x-3) = 0$$

$x - 2 = 0 \Rightarrow x = 2$；$x - 3 = 0 \Rightarrow x = 3$

**答案**：$x = 2$ 或 $x = 3$

---

**C.31** ☆

【思路】配方法——将方程化为 $(x-a)^2 = b$ 的形式，再开平方

**解答**：

$$x^2 - 4x - 1 = 0$$
$$x^2 - 4x = 1$$
$$x^2 - 4x + 4 = 1 + 4$$
$$(x-2)^2 = 5$$
$$x - 2 = \pm\sqrt{5}$$
$$x = 2 \pm \sqrt{5}$$

**答案**：$x = 2 + \sqrt{5}$ 或 $x = 2 - \sqrt{5}$

---

**C.32** ☆

【思路】求根公式——$x = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}$，代入 $a=2$，$b=-3$，$c=-2$

**解答**：

$2x^2 - 3x - 2 = 0$，$a=2$，$b=-3$，$c=-2$。

$$\Delta = (-3)^2 - 4(2)(-2) = 9 + 16 = 25$$

$$x = \frac{3 \pm 5}{4}$$

$x_1 = \dfrac{3+5}{4} = 2$；$x_2 = \dfrac{3-5}{4} = -\dfrac{1}{2}$

**答案**：$x = 2$ 或 $x = -\dfrac{1}{2}$

**C.33** ☆

【思路】判别式 $\Delta = b^2 - 4ac$：$\Delta > 0$ 两不等实根，$\Delta = 0$ 两相等实根，$\Delta < 0$ 无实根

**解答**：

$x^2 - 4x + 5 = 0$，$a=1$，$b=-4$，$c=5$。

$$\Delta = (-4)^2 - 4(1)(5) = 16 - 20 = -4 < 0$$

$\Delta < 0$，故方程无实数根。

**答案**：方程无实数根（$\Delta = -4 < 0$）

【思路】不等式应用——设折扣为 $n$ 折，则售价为 $200 \times \dfrac{n}{10}$，列不等式

**D.20** ☆☆

【思路】含参方程组解的情形讨论——用行列式判断：唯一解（$a^2 \neq 1$），无解或无穷多解（$a^2 = 1$，再区分 $a=1$ 和 $a=-1$）

**解答**：

方程组系数行列式 $D = a \cdot a - 1 \cdot 1 = a^2 - 1$。

**情形 1：$a^2 \neq 1$，即 $a \neq \pm 1$**——唯一解。

由 $(1) - (2)$：$(a-1)x - (1-a)y = 0 \Rightarrow (a-1)(x+y) = 0$。

若 $a \neq 1$，$x + y = 0$，即 $y = -x$，代入 $(1)$：$ax - x = 3 \Rightarrow x(a-1) = 3 \Rightarrow x = \dfrac{3}{a-1}$，$y = -\dfrac{3}{a-1}$。

**情形 2：$a = 1$**——两方程化为 $x + y = 3$，即同一方程，有无穷多解。

**情形 3：$a = -1$**——两方程化为 $-x + y = 3$ 和 $x - y = 3$，即 $x - y = -3$ 与 $x - y = 3$，矛盾，无解。

**答案**：
- $a \neq \pm 1$ 时：唯一解 $x = \dfrac{3}{a-1}$，$y = -\dfrac{3}{a-1}$
- $a = 1$ 时：无穷多解（$x + y = 3$ 的全部解）
- $a = -1$ 时：无解

**D.22** ☆☆

【思路】判别式分类讨论——当 $k=0$ 时方程不是二次方程，需单独讨论；$k \neq 0$ 时用 $\Delta \geq 0$

**解答**：

**当 $k = 0$ 时**：方程为 $2x + 1 = 0$，有唯一实根 $x = -\dfrac{1}{2}$，满足"有两个实数根"的要求（一元一次方程有一个实根，此处按题意是否要求严格两个实根需看题目，通常 $kx^2$ 中 $k=0$ 不是二次方程）。

$k \neq 0$ 且 $k \leq 1$，即 $k < 0$ 或 $0 < k \leq 1$。

**答案**：$k < 0$ 或 $0 < k \leq 1$（若要求是二次方程则 $k \neq 0$，且 $k \leq 1$）

**D.23** ☆☆

【思路】韦达定理——$\alpha + \beta = 5$，$\alpha\beta = 3$，通过代数恒等式构造所求表达式

**解答**：

方程 $x^2 - 5x + 3 = 0$，由韦达定理：$\alpha + \beta = 5$，$\alpha\beta = 3$。

**(1)** $\alpha^2 + \beta^2 = (\alpha+\beta)^2 - 2\alpha\beta = 25 - 6 = 19$

**(2)** $(\alpha-\beta)^2 = (\alpha+\beta)^2 - 4\alpha\beta = 25 - 12 = 13$

**(3)** $\dfrac{1}{\alpha} + \dfrac{1}{\beta} = \dfrac{\alpha+\beta}{\alpha\beta} = \dfrac{5}{3}$

**答案**：(1) $19$；(2) $13$；(3) $\dfrac{5}{3}$

**D.25** ☆☆

【思路】韦达定理 + 整数根条件——设两整数根为 $p, q$，利用韦达定理得 $p+q=k+2$，$pq=2k$，消去 $k$ 找整数解

**解答**：

方程 $x^2 - (k+2)x + 2k = 0$，设两根为 $p, q$（整数）。

由韦达定理：$p + q = k + 2$，$pq = 2k$。

从第一式：$k = p + q - 2$，代入第二式：

$$pq = 2(p + q - 2) \Rightarrow pq - 2p - 2q + 4 = 0 \Rightarrow (p-2)(q-2) = 0$$

故 $p = 2$ 或 $q = 2$。

不妨设 $p = 2$，则 $k = 2 + q - 2 = q$，故任意整数 $q$ 均可。

但需验证方程 $x^2 - (q+2)x + 2q = 0$ 确实以 $2, q$ 为整数根：$(x-2)(x-q) = x^2-(2+q)x+2q$ 成立。

因此，$k = q$ 可取任意整数，但题目问的是"整数 $k$ 的所有可能值"——实际上此分解说明方程可因式分解为 $(x-2)(x-k)=0$，两根为 $2$ 和 $k$。

对任意整数 $k$，方程有两个整数根 $2$ 和 $k$。故**所有整数 $k$ 均满足条件**。

若题目希望两根**不同**，则 $k \neq 2$，答案为除 $k=2$ 外的所有整数（$k=2$ 时两根相同，均为 $2$，也是整数根，故实际上所有整数 $k$ 都成立）。

**答案**：所有整数 $k$ 均满足条件（方程必有整数根 $2$，另一根为 $k$）

**D.26** ☆☆

【思路】分式方程化二次方程——乘以公分母 $x^2-1=(x-1)(x+1)$，化为整式方程后解，注意验根

**解答**：

$\dfrac{x+1}{x-1} - \dfrac{x-1}{x+1} = \dfrac{4x}{x^2-1}$，公分母为 $(x-1)(x+1)$。

两边乘以 $(x-1)(x+1)$（需 $x \neq \pm 1$）：

$$(x+1)^2 - (x-1)^2 = 4x$$
$$(x^2+2x+1) - (x^2-2x+1) = 4x$$
$$4x = 4x$$

此为恒等式，说明对任意 $x \neq \pm 1$ 均成立。

**答案**：$x$ 为任意实数，但 $x \neq \pm 1$（即解集为 $\mathbb{R} \setminus \{-1, 1\}$）

**D.27** ☆☆

【思路】不等式各端运算——利用不等式的加法、乘法性质，对每部分分别推导范围

**解答**：

已知 $-2 < x < 3$。

**(1)** 求 $3x - 1$ 的范围：

$-2 < x < 3 \Rightarrow -6 < 3x < 9 \Rightarrow -7 < 3x - 1 < 8$

**(2)** 求 $-2x + 5$ 的范围：

$-2 < x < 3 \Rightarrow 4 > -2x > -6 \Rightarrow 9 > -2x + 5 > -1$

即 $-1 < -2x + 5 < 9$

**(3)** $x^2 - 1$：$x$ 可为负，不能直接对 $x^2$ 的范围作简单估计。当 $x \in (-2, 3)$ 时，$x^2 \in [0, 9)$（当 $x=0$ 时取最小值 $0$，当 $x \to 3$ 时趋近 $9$），故 $x^2 - 1 \in [-1, 8)$。精确地：$x^2$ 在 $x \in (-2, 3)$ 的最小值为 $0$（$x=0$），最大值趋近于 $\max(4, 9) = 9$（$x \to 3$），所以 $x^2 \in [0, 9)$，$x^2 - 1 \in [-1, 8)$。

**答案**：(1) $-7 < 3x-1 < 8$；(2) $-1 < -2x+5 < 9$；(3) $x^2-1 \in [-1, 8)$（需分析 $x^2$ 在区间上的最值）

**D.29** ☆☆

【思路】含参不等式分类讨论——参数在不等号两侧时需按参数正负分情况讨论变号问题

**解答**：

不等式 $ax > a^2 + 1$。

**情形 1：$a > 0$**——除以 $a$（正数，不变号）：

$$x > \frac{a^2+1}{a} = a + \frac{1}{a}$$

$$x < \frac{a^2+1}{a}$$

**答案**：
- $a > 0$：解集 $x > a + \dfrac{1}{a}$
- $a = 0$：无解
- $a < 0$：解集 $x < \dfrac{a^2+1}{a}$

**D.30** ☆☆

【思路】不等式组整数解个数——先求解集，再分析其中包含恰好 3 个整数所需的 $a$ 的范围

**解答**：

解集为 $2a - 1 < x \leq 3$。

区间 $(2a-1, 3]$ 内的整数：从 $\lceil 2a \rceil$ 到 $3$（含3）。

若恰好 3 个整数解，则这 3 个整数为 $1, 2, 3$（即 $x = 1, 2, 3$）。

需要：$0 < 2a - 1 \leq 1$（使最小整数恰为 $1$），即 $1 < 2a \leq 2$，$\dfrac{1}{2} < a \leq 1$。

验证：若 $a = 1$，解集为 $(1, 3]$，整数解为 $2, 3$（只有 2 个）——不满足。

重新分析：3 个整数解为 $\{1, 2, 3\}$ 要求 $2a-1 < 1$（含1）且 $2a-1 \geq 0$（不含0），即 $0 \leq 2a-1 < 1$，$\dfrac{1}{2} \leq a < 1$。

- $a = \dfrac{1}{2}$：解集 $(0, 3]$，整数解 $1, 2, 3$（3个）。✓
- $a < \dfrac{1}{2}$：如 $a=0$，解集 $(-1, 3]$，整数解 $0, 1, 2, 3$（4个）。✗
- $a = 1$：解集 $(1, 3]$，整数解 $2, 3$（2个）。✗

精确条件：$0 \leq 2a - 1 < 1$，即 $\dfrac{1}{2} \leq a < 1$，整数 $a$ 只有 $a = 0$ ... 

题目要求整数 $a$，故 $a \in \left[\dfrac{1}{2}, 1\right)$ 内的整数为空集？重检：$a$ 为整数，$\dfrac{1}{2} \leq a < 1$ 无整数。

换个思路：整数 $a$ 满足 $2a - 1 < -1$（含-1到3，即4个整数）不满足；$-1 \leq 2a-1 < 0$（含0到3，4个）不满足。

需要恰好3个整数解 $\{1,2,3\}$：$0 \leq 2a-1 < 1 \Rightarrow \dfrac{1}{2} \leq a < 1$，无整数 $a$。

需要恰好3个整数解 $\{2,3,??\}$：若包含负整数，则需更大的范围……

重新：3个整数解可以是 $\{1,2,3\}$（需 $0 \leq 2a-1<1$），或 $\{0,1,2,3\}$ 有4个，或整数解为 $\{2,3\}$ 只有2个。

若整数解为 $\{1,2,3\}$：$0 \leq 2a-1 < 1 \Rightarrow \dfrac{1}{2} \leq a < 1$，整数 $a$ 无解。

若题目的"整数 $a$"在范围 $0 \leq 2a-1 < 1$ 内，则无整数解——说明此题整数解个数为3对整数 $a$ 无解？

更可能的情况：题目要求 $a$ 为整数，解集 $(2a-1, 3]$ 有恰好3个整数解。

- $a = 0$：$(−1, 3]$，整数 $0,1,2,3$——4个
- $a = 1$：$(1, 3]$，整数 $2,3$——2个
- $a = -1$：$(-3, 3]$，整数 $-2,-1,0,1,2,3$——6个

因此整数 $a$ 中不存在恰好3个整数解的情形，除非允许边界恰好为整数被排除。

若 $a$ 不限整数，则需 $0 \leq 2a-1 < 1$，即 $\dfrac{1}{2} \leq a < 1$。

**答案**：$\dfrac{1}{2} \leq a < 1$（在此范围内 $2a-1 \in [0,1)$，解集内整数解恰为 $1, 2, 3$，共3个）

**D.32** ☆☆

【思路】二元一次方程组建模（行程）——设速度或路程为未知量，利用相遇时同向路程关系列方程

**解答**：

设乙的路程为 $s$ km，则甲的路程为 $s + 20$ km，且 $s + (s+20) = AB$ 为总距离。

另外，甲速度是乙的 $\dfrac{4}{3}$ 倍，相遇时间相同，故路程之比等于速度之比：

$$\frac{s+20}{s} = \frac{4}{3} \Rightarrow 3(s+20) = 4s \Rightarrow 3s + 60 = 4s \Rightarrow s = 60$$

AB 总距离：$60 + 80 = 140$ km。

**答案**：AB 两城相距 140 km

**D.33** ☆☆

【思路】面积问题建立一元二次方程——设缩减宽度 $x$，新花圃面积为原来的一半

**解答**：

新花圃尺寸：长 $(12-2x)$ m，宽 $(8-2x)$ m。

面积减少一半，即新面积为原来的一半：

$$(12-2x)(8-2x) = \frac{1}{2} \times 12 \times 8 = 48$$

$$4(6-x)(4-x) = 48 \Rightarrow (6-x)(4-x) = 12$$

$$24 - 10x + x^2 = 12 \Rightarrow x^2 - 10x + 12 = 0$$

$$x = \frac{10 \pm \sqrt{100-48}}{2} = \frac{10 \pm \sqrt{52}}{2} = 5 \pm \sqrt{13}$$

由于 $0 < x < 4$（宽度不超过 $8/2=4$），$\sqrt{13} \approx 3.6$：

- $x = 5 - \sqrt{13} \approx 1.4$（满足）
- $x = 5 + \sqrt{13} \approx 8.6$（不满足）

**答案**：$x = 5 - \sqrt{13} \approx 1.4$ m

**D.35** ☆☆

【思路】判别式 + 韦达定理 + 不等式联立——两正实根要求：$\Delta \geq 0$（有实根），两根之和 $> 0$，两根之积 $> 0$

**解答**：

方程 $x^2 - 2ax + a + 2 = 0$，由韦达定理：$x_1 + x_2 = 2a$，$x_1 x_2 = a + 2$。

两个正实根的条件：

① $\Delta \geq 0$：$4a^2 - 4(a+2) \geq 0 \Rightarrow a^2 - a - 2 \geq 0 \Rightarrow (a-2)(a+1) \geq 0 \Rightarrow a \leq -1$ 或 $a \geq 2$

② $x_1 + x_2 > 0$：$2a > 0 \Rightarrow a > 0$

③ $x_1 x_2 > 0$：$a + 2 > 0 \Rightarrow a > -2$

取交集：①②③同时满足 $\Rightarrow a \geq 2$

**答案**：$a \geq 2$

**D.36** ☆☆

【思路】含参方程 + 两根均大于 0 的条件——同 D.35，需三个条件联立（$\Delta \geq 0$，两根之和 $> 0$，两根之积 $> 0$）

**解答**：

方程 $x^2 - 2mx + m^2 - 1 = 0$，由韦达定理：$x_1 + x_2 = 2m$，$x_1 x_2 = m^2 - 1$。

① $\Delta \geq 0$：$4m^2 - 4(m^2-1) = 4 \geq 0$，恒成立。

② $x_1 + x_2 > 0$：$2m > 0 \Rightarrow m > 0$

③ $x_1 x_2 > 0$：$m^2 - 1 > 0 \Rightarrow m > 1$ 或 $m < -1$

取交集（$m > 0$ 且（$m > 1$ 或 $m < -1$））$\Rightarrow m > 1$

**答案**：$m > 1$

**E.16** ☆☆☆

【思路】增长率方程建立 + 利润率计算——设涨价比例为 $x$，写出今年进价、售价、利润的表达式，列方程

**解答**：

设涨价比例为 $x$（$x > 0$，$x$ 为小数形式）。

去年：进价 200 元，售价 250 元，利润 $250 - 200 = 50$ 元。

今年：进价 $200(1+x)$ 元，售价 $250(1+x)$ 元，利润：

$$250(1+x) - 200(1+x) = 50(1+x)$$

**(1)** 今年利润比去年提高 25 元：

$$50(1+x) - 50 = 25 \Rightarrow 50x = 25 \Rightarrow x = 0.5$$

**(2)** $x = 0.5$，即涨价 50%。

今年：进价 300 元，售价 375 元，利润 75 元。

**(3)** 今年利润率 $= \dfrac{75}{300} = 25\% < 30\%$，合法。

**答案**：(1) 方程 $50(1+x) - 50 = 25$；(2) $x = 0.5$，即涨价 50%；(3) 今年利润率为 25%，不超过 30%，合法

**E.17** ☆☆☆

【思路】分段函数建模 + 比较两方案费用——分别写出两方案关于人数 $n$ 的函数，令费用相等求临界点，再确定各区间的优劣

**解答**：

**(1)** 方案 A：$y_A = 30n$（$n \geq 1$）

方案 B：
$$y_B = \begin{cases} 25n & (1 \leq n \leq 50) \\ 25 \times 50 + 18(n-50) = 18n + 350 & (n > 50) \end{cases}$$

**(2)** 令 $y_A = y_B$：

当 $n \leq 50$：$30n = 25n \Rightarrow 5n = 0 \Rightarrow n = 0$（无意义）

当 $n > 50$：$30n = 18n + 350 \Rightarrow 12n = 350 \Rightarrow n = \dfrac{350}{12} \approx 29.2$（不满足 $n > 50$）

实际上，当 $n > 50$ 时：$y_B = 18n + 350$，$y_A = 30n$，令相等：$n \approx 29.2$，矛盾。

即 $n > 50$ 时，$y_B < y_A$ 恒成立（因为 $18n + 350 < 30n \Leftrightarrow 350 < 12n \Leftrightarrow n > 29.2$，在 $n > 50$ 的范围内恒成立）。

$n \leq 50$ 时，$y_B = 25n < 30n = y_A$，方案B更便宜。

故两方案费用**从不相等**（方案B始终更便宜）。

但当 $n$ 较小时，若不凑整：令 $30n = 18n + 350$，$n \approx 29.2$，即约 $30$ 人时两方案相当，但此时 $n < 50$，方案B收 $25 \times 30 = 750$，方案A收 $30 \times 30 = 900$，方案B依然便宜。

更准确理解：$1 \leq n \leq 50$ 时 B 总比 A 便宜；$n > 50$ 时 B 更便宜（超过部分每人只需 18 元）。

**(3)** $n = 80$：$y_A = 30 \times 80 = 2400$ 元；$y_B = 18 \times 80 + 350 = 1440 + 350 = 1790$ 元

选方案B，节省 $2400 - 1790 = 610$ 元。

**答案**：(1) $y_A = 30n$；$y_B = \begin{cases}25n & n \leq 50 \\ 18n+350 & n > 50\end{cases}$；(2) 方案B始终比方案A便宜，不存在相同费用的人数；(3) 应选方案B，省 610 元

**E.19** ☆☆☆

【思路】增长率方程建立——设年增长率 $x$，两年后产量为 $100(1+x)^2$，列方程求解；再建立三年方程判断正实数解

**解答**：

**(1)** 设年增长率为 $x$，两年后：

$$100(1+x)^2 = 144$$

**(2)** $(1+x)^2 = 1.44 \Rightarrow 1+x = 1.2$（取正值）$\Rightarrow x = 0.2$，即年增长率 20%。

**(3)** 三年后产量达 200 万件：

$$100(1+x)^3 = 200 \Rightarrow (1+x)^3 = 2$$

**答案**：(1) $100(1+x)^2 = 144$；(2) $x = 20\%$；(3) 方程 $100(1+x)^3 = 200$ 有正实数解 $x = \sqrt[3]{2}-1 \approx 26\%$

**E.20** ☆☆☆

【思路】二次函数最大值——建立利润关于售价的二次函数，求顶点即最大利润

**解答**：

**(3)** 定价不超过 70 元，即 $x \leq 70$：

**E.22** ☆☆☆

【思路】行程问题——设速度，由路程/速度=时间，利用"货车比轿车晚1小时到"列方程

**解答**：

**(3)** 设相遇时间为 $t$ 小时，相遇时两车路程之和为 240 km：

$$60t + 80t = 240 \Rightarrow 140t = 240 \Rightarrow t = \frac{12}{7}$$

货车行驶路程（距甲地）：$60 \times \dfrac{12}{7} = \dfrac{720}{7} \approx 102.9$ km

**答案**：(1) 方程 $\dfrac{320}{v} - \dfrac{240}{v} = 1$；(2) 轿车 80 km/h，货车 60 km/h；(3) 相遇处距甲地约 $\dfrac{720}{7} \approx 102.9$ km

**E.23** ☆☆☆

$$80 \leq p \leq 100$$

**E.25** ☆☆☆

【思路】方程组求单价 + 整数最优化 + 不等式求最大 $p$

**解答**：

**(1)** 设 A 每件 $a$ 元，B 每件 $b$ 元：

$$\begin{cases} 3a + 5b = 290 \\ 5a + 2b = 240 \end{cases}$$

从第一式：$b = \dfrac{290-3a}{5}$，代入第二式：

$$5a + 2 \cdot \dfrac{290-3a}{5} = 240 \Rightarrow 25a + 580 - 6a = 1200 \Rightarrow 19a = 620 \Rightarrow a = \frac{620}{19}$$

注意：若 $a$ 非整数，可能题目意图是整数解，检验：$5 \times \dfrac{620}{19} + 2b = 240 \Rightarrow b = \dfrac{240 \times 19 - 3100}{38} = \dfrac{4560-3100}{38} = \dfrac{1460}{38}$，也非整数。

重检题目：$3a+5b=290$，$5a+2b=240$。

$(1) \times 2 - (2) \times 5$：$6a+10b-25a-10b = 580-1200 \Rightarrow -19a=-620 \Rightarrow a=\dfrac{620}{19}$，确非整数。

若确为整数，则 $19 | 620$，$620 = 19 \times 32 + 12$，不整除。可能题目数据略有调整，按题目原意求：$a = \dfrac{620}{19}$，$b = \dfrac{290 - 3 \times 620/19}{5} = \dfrac{290 \times 19 - 1860}{95} = \dfrac{5510-1860}{95} = \dfrac{3650}{95} = \dfrac{730}{19}$。

若改用 $3a+5b=290$，$5a+2b=240$（可能原题为 $3a+5b=275$，$5a+2b=250$ 等），按题目直接计算：$a \approx 32.6$，$b \approx 38.5$。

**按整数意图，设 $a = 30$，$b = 40$（满足 $3\times30+5\times40=90+200=290\checkmark$，$5\times30+2\times40=150+80=230\neq240$）**，故原题数据不给整数解。

采用代数解：$a = \dfrac{620}{19} \approx 32.6$，$b = \dfrac{730}{19} \approx 38.4$。

**(2)** 购买 A 数量是 B 的两倍：设 B 买 $n$ 件，A 买 $2n$ 件，总件数 $3n$，总费用 $\leq 1000$：

$$2n \cdot a + n \cdot b = n(2a+b) \leq 1000$$
$$n \leq \frac{1000}{2a+b} = \frac{1000}{2 \times 620/19 + 730/19} = \frac{1000}{(1240+730)/19} = \frac{19000}{1970} \approx 9.64$$

故 $n \leq 9$，总件数最多 $3 \times 9 = 27$ 件。

**(3)** A 降价 $p\%$，B 涨价 $p\%$，3件A+5件B费用不超过300元：

$$3a(1-p\%) + 5b(1+p\%) \leq 300$$

代入 $3a = 290 - 5b$（从第一方程）：

$$（290-5b)(1-p\%) + 5b(1+p\%) \leq 300$$
$$(290-5b) - (290-5b)p\% + 5b + 5bp\% \leq 300$$
$$290 + p\%(-290+5b+5b) \leq 300$$
$$290 + p\%(10b-290) \leq 300$$
$$p\%(10b-290) \leq 10$$

代入 $b = 730/19$：$10b - 290 = 7300/19 - 290 = (7300-5510)/19 = 1790/19$，

$$p\% \leq \frac{10}{1790/19} = \frac{190}{1790} = \frac{19}{179} \approx 10.6\%$$

故 $p$ 的最大整数值为 **10**。

**答案**：(1) $a = \dfrac{620}{19} \approx 32.6$ 元，$b = \dfrac{730}{19} \approx 38.4$ 元；(2) 最多 27 件；(3) $p$ 的最大整数值为 10
