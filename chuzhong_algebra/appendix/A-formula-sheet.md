## Part 1 数

### 1.1 有理数基本概念 `(part1/01)`

- **相反数**：$a$ 的相反数是 $-a$；$a + (-a) = 0$；$-(-a) = a$。
- **绝对值**：$|a| = a$（$a \geq 0$）；$|a| = -a$（$a < 0$）；$|-a| = |a|$。
- **数轴三要素**：原点、正方向、单位长度。数轴上两点距离 $= |a - b|$。

### 1.2 有理数运算法则 `(part1/02)`

- **加法**：同号相加取相同符号，绝对值相加；异号相加取绝对值较大者符号，绝对值相减。
- **减法**：$a - b = a + (-b)$（减去一个数等于加上这个数的相反数）。
- **乘法**：同号得正，异号得负；$|ab| = |a||b|$。
- **除法**：$a \div b = a \cdot \dfrac{1}{b}$（$b \neq 0$）；同号得正，异号得负。
- **乘方**：$(-a)^n = a^n$（$n$ 为偶数）；$(-a)^n = -a^n$（$n$ 为奇数）。
- **运算顺序**：乘方 → 乘除 → 加减；有括号先算括号。

### 1.3 幂与科学记数 `(part1/03)`

- **科学记数法**：$a \times 10^n$，其中 $1 \leq |a| < 10$，$n$ 为整数。
- 如 $3\,800\,000 = 3.8 \times 10^6$；$0.0038 = 3.8 \times 10^{-3}$。

### 1.4 实数与无理数 `(part1/04)`

- **实数分类**：有理数（整数 + 分数）+ 无理数（无限不循环小数）= 实数。
- 常见无理数：$\sqrt{2}$，$\sqrt{3}$，$\pi$，$\sqrt[3]{5}$。
- 实数运算：有理数的四则运算法则对实数全部成立。

### 1.5 平方根与立方根 `(part1/05)`

- **算术平方根**：$\sqrt{a} \geq 0$，$(\sqrt{a})^2 = a$（$a \geq 0$）。
- **平方根**：$x^2 = a$（$a > 0$）的解为 $x = \pm\sqrt{a}$；$a = 0$ 时唯一解 $x = 0$；$a < 0$ 无实数根。
- **立方根**：$\sqrt[3]{a}$ 与 $a$ 同号；$(\sqrt[3]{a})^3 = a$；$\sqrt[3]{-a} = -\sqrt[3]{a}$。

### 1.6 二次根式性质 `(part1/06，part1/07)`

- **定义域**：$\sqrt{a}$ 有意义当且仅当 $a \geq 0$。
- **化简性质**：$\sqrt{a^2} = |a|$；$\sqrt{ab} = \sqrt{a}\cdot\sqrt{b}$（$a,b \geq 0$）；$\sqrt{\dfrac{a}{b}} = \dfrac{\sqrt{a}}{\sqrt{b}}$（$a \geq 0$，$b > 0$）。
- **最简根式条件**：① 被开方数无完全平方因数；② 无分母含根号；③ 无分数形式。
- **加减运算**：先化为最简根式，再合并同类根式（被开方数相同方可合并）。
- **乘法**：$\sqrt{a} \cdot \sqrt{b} = \sqrt{ab}$；$(m\sqrt{a})(n\sqrt{b}) = mn\sqrt{ab}$。
- **有理化分母**：$\dfrac{1}{\sqrt{a}} = \dfrac{\sqrt{a}}{a}$；$\dfrac{1}{\sqrt{a}+\sqrt{b}} = \dfrac{\sqrt{a}-\sqrt{b}}{a-b}$（共轭乘以分子分母）。

## Part 2 整式

### 2.1 单项式与多项式 `(part2/01)`

- **单项式**：数或字母的乘积（含单个数或字母）。系数 × 字母部分。
- **次数**：单项式中所有字母指数之和；常数单项式次数为 0（0 除外）。
- **多项式次数**：各项次数中最高次数。

### 2.2 整式加减 `(part2/02)`

- **同类项**：字母相同且指数相同。合并同类项：系数相加，字母及指数不变。
- **去括号**：括号前 $+$ 号，括号内各项不变；括号前 $-$ 号，括号内各项变号。

### 2.3 幂运算六条法则 `(part2/03)`

$$a^m \cdot a^n = a^{m+n} \tag{同底相乘加指数}$$

$$\frac{a^m}{a^n} = a^{m-n} \quad (a \neq 0) \tag{同底相除减指数}$$

$$(a^m)^n = a^{mn} \tag{幂的乘方}$$

$$(ab)^n = a^n b^n \tag{积的乘方}$$

$$\left(\frac{a}{b}\right)^n = \frac{a^n}{b^n} \quad (b \neq 0) \tag{商的乘方}$$

$$a^0 = 1 \quad (a \neq 0); \quad a^{-n} = \frac{1}{a^n} \quad (a \neq 0) \tag{零次/负次幂}$$

### 2.4 整式乘法三类 `(part2/04)`

- **单项式 × 单项式**：系数相乘，同底幂相加指数。
- **单项式 × 多项式**：单项式乘以多项式每一项（分配律）：$a(b + c) = ab + ac$。
- **多项式 × 多项式**：每项乘每项，再合并同类项：$(a+b)(c+d) = ac + ad + bc + bd$。

### 2.5 完全平方与平方差公式 `(part2/05)`

$$\boxed{(a+b)^2 = a^2 + 2ab + b^2}$$

$$\boxed{(a-b)^2 = a^2 - 2ab + b^2}$$

$$\boxed{(a+b)(a-b) = a^2 - b^2}$$

**识别要点**：见 $(\cdot)^2$ → 完全平方；见 $(\cdot+\cdot)(\cdot-\cdot)$ → 平方差。

**三项扩展**：$(a+b+c)^2 = a^2+b^2+c^2+2ab+2bc+2ca$。

### 2.6 整式除法 `(part2/06)`

- **单项式 ÷ 单项式**：系数相除，同底幂相减指数。
- **多项式 ÷ 单项式**：每项分别除以该单项式。

### 2.7 公式逆用（因式变形）`(part2/07)`

- $a^2 - b^2 = (a+b)(a-b)$（平方差逆用）。
- $a^2 \pm 2ab + b^2 = (a \pm b)^2$（完全平方逆用）。

## Part 3 因式分解

### 3.1 提公因式法 `(part3/01)`

$$ma + mb + mc = m(a + b + c)$$

步骤：找各项公因式（含系数最大公因数 + 各变量最低次数）→ 提出 → 括号内为原式除以公因式。

### 3.2 公式法 `(part3/02)`

- **平方差**：$a^2 - b^2 = (a+b)(a-b)$。
- **完全平方**：$a^2 + 2ab + b^2 = (a+b)^2$；$a^2 - 2ab + b^2 = (a-b)^2$。

### 3.3 十字相乘法 `(part3/03)`

用于 $x^2 + (p+q)x + pq = (x+p)(x+q)$ 型。

$$\begin{array}{c|c} x & p \\ x & q \end{array} \Rightarrow x^2 + (p+q)x + pq$$

对 $ax^2 + bx + c$：左列填 $a_1, a_2$（$a_1 a_2 = a$），右列填 $c_1, c_2$（$c_1 c_2 = c$），使交叉乘积之和 $a_1 c_2 + a_2 c_1 = b$。

### 3.4 分组分解法 `(part3/04)`

将多项式分组，使各组之间出现公因式，再提取公因式。

### 3.5 因式分解决策树 `(part3/05)`

```
拿到多项式
  ↓
有无公因式？→ 有：先提公因式
  ↓（提完后）
两项？→ 平方差公式
三项？→ 完全平方 或 十字相乘
四项及以上？→ 分组分解
  ↓
检验：展开验证是否还原
```

## Part 4 分式

### 4.1 分式基本性质 `(part4/01)`

- **定义**：$\dfrac{A}{B}$，$B$ 含字母，$B \neq 0$。
- **基本性质**：$\dfrac{A}{B} = \dfrac{AC}{BC}$（$C \neq 0$）；$\dfrac{AC}{BC} = \dfrac{A}{B}$（$C \neq 0$）。
- **最简分式**：分子分母无公因式。

### 4.2 分式四则运算 `(part4/02)`

$$\frac{A}{B} \times \frac{C}{D} = \frac{AC}{BD}$$

$$\frac{A}{B} \div \frac{C}{D} = \frac{A}{B} \times \frac{D}{C} = \frac{AD}{BC} \quad (C \neq 0)$$

$$\frac{A}{B} + \frac{C}{B} = \frac{A+C}{B} \quad \text{（同分母直接加减分子）}$$

$$\frac{A}{B} + \frac{C}{D} = \frac{AD + BC}{BD} \quad \text{（通分后加减）}$$

### 4.3 分式方程三步走与验根 `(part4/03)`

**三步走**：
1. 确定最简公分母 $M$，方程两边同乘 $M$（去分母，变整式方程）。
2. 解整式方程，求出 $x$ 的值。
3. **验根**：将解代入原方程分母，检验分母是否为 0；使分母为 0 的解是**增根**，必须舍去。

**增根判定**：令各分母 = 0，得到的 $x$ 值若与解相同，则为增根。

### 4.4 分式化简技巧 `(part4/04)`

- 先因式分解分子分母，再约分（即寻找公因式消去）。
- 注意 $a - b = -(b - a)$，灵活处理相反因式。

## Part 5 一次方程

### 5.1 等式基本性质 `(part5/01)`

- **等式性质 1**：等式两边加（减）同一个数，等式仍成立：$a = b \Rightarrow a \pm c = b \pm c$。
- **等式性质 2**：等式两边乘（除以）同一个非零数，等式仍成立：$a = b \Rightarrow ac = bc$（$c \neq 0$）。

### 5.2 解一元一次方程五步 `(part5/01)`

1. 去分母（各项乘以各分母的最简公倍数）。
2. 去括号（先外后内，注意符号）。
3. 移项（把含未知数的项移到一边，常数项移到另一边，移项变号）。
4. 合并同类项。
5. 系数化为 1（两边除以未知数的系数）。

### 5.3 二元一次方程组：代入消元法 `(part5/02，part5/03)`

从一个方程中用含另一个未知数的表达式代入，代换到另一方程，化为一元一次方程求解。

### 5.4 二元一次方程组：加减消元法 `(part5/03)`

将两方程适当乘以系数，使某一未知数的系数相等（或相反），相加或相减消去该未知数。

### 5.5 含参方程三步 `(part5/05)`

1. 整理方程，将含 $x$ 的项移到一边，常数移到另一边，得 $(k\text{-系数}) \cdot x = \text{常数}$。
2. 分情况：系数 $= 0$ 时，方程无解或无穷多解；系数 $\neq 0$ 时，$x = \dfrac{\text{常数}}{\text{系数}}$。
3. 检验：将结果或特殊值代回，确认解的情形。

## Part 6 一元二次方程

### 6.1 四种解法 `(part6/01–04)`

| 方法 | 适用情形 | 要点 |
|------|----------|------|
| 直接开平方法 | 可化为 $x^2 = k$ 型（$k \geq 0$） | $x = \pm\sqrt{k}$ |
| 因式分解法 | 左边能分解为两因式积，右边 = 0 | 某因式 = 0 即可 |
| 配方法 | 通用；推导求根公式的基础 | 两边加 $\left(\dfrac{b}{2a}\right)^2$ |
| 求根公式法 | 通用 | 代入公式 $x = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}$ |

### 6.2 求根公式 `(part6/04)`

$$\boxed{x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}} \quad (a \neq 0)$$

### 6.3 判别式三情形 `(part6/04)`

设 $\Delta = b^2 - 4ac$，对 $ax^2 + bx + c = 0$（$a \neq 0$）：

$$\Delta > 0 \Rightarrow \text{有两个不相等的实数根}$$

$$\Delta = 0 \Rightarrow \text{有两个相等的实数根（重根）}\ x_{1,2} = -\dfrac{b}{2a}$$

$$\Delta < 0 \Rightarrow \text{无实数根}$$

### 6.4 韦达定理与变形公式 `(part6/05)`

设 $ax^2 + bx + c = 0$ 的两根为 $x_1, x_2$：

$$\boxed{x_1 + x_2 = -\frac{b}{a}, \quad x_1 x_2 = \frac{c}{a}}$$

**四个变形公式**（$s = x_1+x_2$，$p = x_1 x_2$）：

$$x_1^2 + x_2^2 = s^2 - 2p$$

$$(x_1 - x_2)^2 = s^2 - 4p$$

$$\frac{1}{x_1} + \frac{1}{x_2} = \frac{s}{p} \quad (p \neq 0)$$

$$x_1^3 + x_2^3 = s^3 - 3ps$$

## Part 7 不等式

### 7.1 不等式三大性质 `(part7/01)`

- **性质 1**（加减不变号）：$a > b \Rightarrow a + c > b + c$；$a > b \Rightarrow a - c > b - c$。
- **性质 2**（乘正不变号）：$a > b$，$c > 0 \Rightarrow ac > bc$；$c > 0 \Rightarrow \dfrac{a}{c} > \dfrac{b}{c}$。
- **性质 3**（乘负变号）：$a > b$，$c < 0 \Rightarrow ac < bc$；$c < 0 \Rightarrow \dfrac{a}{c} < \dfrac{b}{c}$。

> **关键**：乘以（或除以）**负数**时，不等号方向翻转。

### 7.2 解一元一次不等式 `(part7/02)`

步骤与解方程类似（去分母、去括号、移项、合并），最后**系数为负时翻转不等号**。解集用数轴或区间表示。

### 7.3 不等式组四种情形（同大取大等）`(part7/03)`

设两不等式解集分别为 $x > a$ 和 $x > b$（$a < b$）：

| 情形 | 不等式组 | 解集 |
|------|----------|------|
| 同向大 | $x > a$ 且 $x > b$（$a < b$） | $x > b$（取较大端点） |
| 同向小 | $x < a$ 且 $x < b$（$a < b$） | $x < a$（取较小端点） |
| 反向有交 | $x > a$ 且 $x < b$（$a < b$） | $a < x < b$ |
| 反向无交 | $x > b$ 且 $x < a$（$a < b$） | 无解（空集） |

口诀：**同大取大，同小取小，大小取中，大于小于取空**。

## Part 8 一次函数

### 8.1 一次函数基本性质 `(part8/02)`

$$y = kx + b \quad (k \neq 0)$$

- $k > 0$：$y$ 随 $x$ 增大而增大（**增函数**），图象从左下到右上倾斜。
- $k < 0$：$y$ 随 $x$ 增大而减小（**减函数**），图象从左上到右下倾斜。
- $b > 0$：与 $y$ 轴正半轴相交；$b < 0$：与 $y$ 轴负半轴相交；$b = 0$：过原点。

### 8.2 象限判断表 `(part8/02)`

| $k$ 的符号 | $b$ 的符号 | 经过象限 |
|-----------|-----------|---------|
| $k > 0$ | $b > 0$ | 一、二、三 |
| $k > 0$ | $b < 0$ | 一、三、四 |
| $k < 0$ | $b > 0$ | 一、二、四 |
| $k < 0$ | $b < 0$ | 二、三、四 |

特殊：$b = 0$ 时过原点，经一、三（$k>0$）或二、四（$k<0$）象限。

### 8.3 待定系数法 `(part8/03)`

已知两点 $(x_1, y_1)$ 和 $(x_2, y_2)$，设 $y = kx + b$，代入两点坐标，解关于 $k, b$ 的方程组。

$$\begin{cases} y_1 = kx_1 + b \\ y_2 = kx_2 + b \end{cases} \Rightarrow k = \frac{y_1 - y_2}{x_1 - x_2}, \quad b = y_1 - kx_1$$

### 8.4 一次函数与方程组的几何意义 `(part8/05)`

二元一次方程组的解 = 两条直线的交点坐标。
- 唯一解 ↔ 两直线相交（$k_1 \neq k_2$）。
- 无穷多解 ↔ 两直线重合（$k_1 = k_2, b_1 = b_2$）。
- 无解 ↔ 两直线平行（$k_1 = k_2, b_1 \neq b_2$）。

## Part 9 反比例函数

### 9.1 反比例函数性质 `(part9/01，part9/02)`

$$y = \frac{k}{x} \quad (k \neq 0, x \neq 0)$$

- $k > 0$：图象在一、三象限，$x$ 增大时 $y$ 减小（各象限内均为减函数）。
- $k < 0$：图象在二、四象限，$x$ 增大时 $y$ 增大（各象限内均为增函数）。
- 图象关于原点中心对称，是双曲线。
- 不经过 $x$ 轴、$y$ 轴（渐近线）。

### 9.2 $|k|$ 的几何意义 `(part9/02)`

- **矩形面积**：过双曲线上任一点 $P(x_0, y_0)$，向两坐标轴作垂线，形成的矩形面积 $= |k|$（即 $|x_0||y_0| = |k|$）。
- **三角形面积**：过 $P(x_0, y_0)$ 作坐标轴平行线，与坐标轴围成的直角三角形面积 $= \dfrac{1}{2}|k|$。

## Part 10 二次函数

### 10.1 三种形式 `(part10/02)`

| 形式名称 | 表达式 | 直接可读信息 |
|---------|--------|------------|
| 一般式 | $y = ax^2 + bx + c$（$a \neq 0$） | 与 $y$ 轴交点 $(0, c)$ |
| 顶点式 | $y = a(x-h)^2 + k$ | 顶点 $(h, k)$，对称轴 $x = h$ |
| 交点式 | $y = a(x-x_1)(x-x_2)$ | 与 $x$ 轴交点 $(x_1, 0)$，$(x_2, 0)$ |

**三式互化**：顶点式展开 → 一般式；一般式配方 → 顶点式；一般式令 $y=0$ 求根 → 交点式。

### 10.2 对称轴与顶点公式 `(part10/03)`

$$\text{对称轴}：x = -\frac{b}{2a}$$

$$\text{顶点}：\left(-\frac{b}{2a},\ c - \frac{b^2}{4a}\right) = \left(-\frac{b}{2a},\ \frac{4ac - b^2}{4a}\right)$$

- $a > 0$：开口向上，顶点为**最小值**点；$a < 0$：开口向下，顶点为**最大值**点。
- $|a|$ 越大，抛物线越"瘦"；$|a|$ 越小，抛物线越"胖"。

### 10.3 $\Delta$ 与抛物线交点 `(part10/06)`

令 $y = 0$，得 $ax^2 + bx + c = 0$，其判别式 $\Delta = b^2 - 4ac$：

- $\Delta > 0$：抛物线与 $x$ 轴**两个交点**。
- $\Delta = 0$：抛物线与 $x$ 轴**一个交点**（切点），切点即顶点，$x = -\dfrac{b}{2a}$。
- $\Delta < 0$：抛物线与 $x$ 轴**无交点**。

### 10.4 含参最值与铅垂高法 `(part10/07，part10/08)`

- **含参最值**：设对称轴 $x = -\dfrac{b}{2a}$，分类讨论定义域（或区间）与对称轴的位置关系，分别计算端点值与顶点值，取最大（小）值。
- **铅垂高法**：函数图象上点到 $x$ 轴（或某水平线）的纵向距离，常用于计算面积或最值；面积 = $\dfrac{1}{2} \times$ 底 $\times$ 纵向高。

## Part 11 统计

### 11.1 抽样方法 `(part11/01)`

- **系统抽样**：等间距抽取（如每隔 $k$ 个取一个）。
- **分层抽样**：按比例从各层中抽取。
- **随机抽样**（简单）：每个个体被抽中的概率相等。

### 11.2 四种统计图 `(part11/02)`

| 图表类型 | 特点 | 适用场景 |
|---------|------|---------|
| 条形图 | 用矩形长度表示频率/数量 | 比较各类别大小 |
| 扇形图 | 用扇形面积表示占比（角度正比于比例） | 展示整体结构 |
| 折线图 | 连线反映变化趋势 | 展示随时间的变化 |
| 频率分布直方图 | 纵轴为频率/组距，面积 = 频率 | 展示连续数据分布 |

### 11.3 平均数、中位数、众数 `(part11/03)`

- **平均数**：$\bar{x} = \dfrac{x_1 + x_2 + \cdots + x_n}{n}$（加权平均：$\bar{x} = \dfrac{\sum f_i x_i}{\sum f_i}$）。
- **中位数**：数据排序后位于正中间的值（偶数个取中间两数的均值）；不受极端值影响。
- **众数**：出现次数最多的数据值；可能不唯一；只与频率有关。

### 11.4 方差公式 `(part11/04)`

$$\boxed{s^2 = \frac{1}{n}\sum_{i=1}^n (x_i - \bar{x})^2 = \frac{1}{n}\sum x_i^2 - \bar{x}^2}$$

- 方差越大，数据越分散；方差越小，数据越集中。
- **标准差**：$s = \sqrt{s^2}$（与数据同单位，更直观）。

## Part 12 概率

### 12.1 古典概型 `(part12/01)`

$$\boxed{P(A) = \frac{m}{n}}$$

其中 $n$ 为样本空间（所有等可能结果）的总数，$m$ 为事件 $A$ 包含的结果数。

- 基本性质：$0 \leq P(A) \leq 1$；必然事件 $P = 1$；不可能事件 $P = 0$。
- 互斥事件（不能同时发生）：$P(A \cup B) = P(A) + P(B)$。
- 对立事件：$P(\bar{A}) = 1 - P(A)$。

### 12.2 列表法与树状图 `(part12/02)`

- **列表法**：适用于两步独立操作，行列分别列出各自结果，格内逐一填写组合。
- **树状图**：每步操作对应一层分支，末端节点数 = 总结果数 $n$；满足题意的末端节点数 = $m$。
- 原则：**不重不漏**，保证样本空间完整。

### 12.3 频率估计概率 `(part12/03)`

$$P(A) \approx \frac{\text{事件 A 发生的频数}}{\text{总试验次数}}$$

试验次数越大，频率越接近概率（大数定律）。

## Part 14 综合题型

### 14.1 四类综合题型概览 `(part14/01–06)`

| 题型 | 核心模型 | 关键策略 |
|------|----------|---------|
| 函数综合（一次/反比/二次） | 多函数联立、交点、共存点 | 数形结合，联立方程 |
| 二次函数与几何 | 坐标表示线段/面积，抛物线上点的坐标 | 用坐标表示长度，面积铅垂高法 |
| 存在性/最值问题 | 参数分类讨论，端点与顶点比较 | 设参数，分情况讨论 |
| 动点/运动问题 | 设时间或距离为变量，建立函数关系 | 明确运动规律，分段建模 |
| 新定义/创新题 | 读懂定义，代入验证 | 先用具体数检验，再抽象化 |
| 分段/绝对值综合 | 分段函数、绝对值方程图象解法 | 按分段点分区间逐段讨论 |

## Thinking-Toolkit 10 篇核心要点

### T1 何时换元 `(toolkit/01)`

- **触发信号**：方程有"重复块"（$x^2$ 反复出现、含根号、分式 + 倒数、对称组合）。
- **操作**：令新变量 = 整体 → 解新方程 → **回代还原** → 检验范围（$y = x^2 \Rightarrow y \geq 0$）。
- **三步口诀**：给整体起名 → 解名字的方程 → 把名字换回来。

### T2 何时配方 `(toolkit/02)`

- **触发信号**：需要求顶点/最值、判断根的个数、解一元二次方程（系数非整数或十字相乘不便）。
- **操作**：$ax^2 + bx = a\left(x + \dfrac{b}{2a}\right)^2 - \dfrac{b^2}{4a}$，即两边加 $\left(\dfrac{b}{2a}\right)^2$ 配成完全平方。

### T3 判别式与韦达定理 `(toolkit/03)`

- $\Delta = b^2 - 4ac$：正 → 两不等实根，零 → 两相等实根，负 → 无实根。
- 韦达：$x_1+x_2 = -\dfrac{b}{a}$，$x_1 x_2 = \dfrac{c}{a}$；见对称式 → 用韦达 + 恒等式，**不解方程**。

### T4 设元的艺术 `(toolkit/04)`

- **直接设**：设问题所求为 $x$；**间接设**：设中间量，把其他量用它表示；**设参**：设辅助参数，建立方程组。
- **设元三问**：设谁？用什么表示其他量？得到几个方程够用吗？

### T5 整体思想 `(toolkit/05)`

- 见条件是**组合式**（如 $x+\frac{1}{x} = 3$），目标也是组合式 → 整体代入或整体平方，不解单独变量。
- 常用：$x^2+\frac{1}{x^2} = \left(x+\frac{1}{x}\right)^2 - 2$。
- 函数图象中见 $y = a(x-h)^2+k$ → 整体看平移，不展开。

### T6 算两次思想 `(toolkit/06)`

- 同一量用**两种不同方式**表达，令两式相等，得到等量关系。
- 典型场景：面积算两次（铅垂高法）；路程/时间关系；计数双重计算。

### T7 结构识别 `(toolkit/07)`

- 见复杂式子 → 优先寻找已知公式结构（完全平方、平方差、立方和差）。
- 识别信号：两个完全平方数 ± 两倍乘积项 → 完全平方；两个平方数相减 → 平方差。

### T8 参数与含参讨论 `(toolkit/08)`

- 含参方程先整理为"系数 × $x$ = 常数"，再分情况：系数 = 0 时无解/无穷多解；系数 ≠ 0 时解唯一。
- 含参不等式：先解出 $x$，讨论参数使系数为正/负时不等号方向。

### T9 数形结合 `(toolkit/09)`

- 方程（组）的解 ↔ 图象交点坐标；不等式的解集 ↔ 区间段。
- $y = f(x)$ 与 $y = g(x)$ 交点个数 = 方程 $f(x) = g(x)$ 的实数解个数。
- 对称轴 $x = a$ ↔ 图象关于直线 $x = a$ 对称。

### T10 开题前的自检清单 `(toolkit/10)`

1. **读题**：题目给了什么？问的是什么？有无隐含条件？
2. **识模型**：这道题最像哪个模板？（换元/配方/韦达/整体/数形结合？）
3. **设元**：设谁为未知数？约束条件是什么？
4. **建模**：写出方程（组）或不等式（组）。
5. **求解 + 检验**：解完后代回原题，检验是否满足所有条件（含分母 $\neq 0$、增根等）。
