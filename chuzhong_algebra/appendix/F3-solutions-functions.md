## Part 8 一次函数

### C.38 ☆

【思路】函数定义域——分母不为零

**解答**：

函数 $y = \dfrac{1}{x-2}$ 的分母 $x - 2 \neq 0$，即 $x \neq 2$。

**答案**：自变量 $x$ 的取值范围为 $x \neq 2$（即 $x \in \mathbb{R}$ 且 $x \neq 2$）。

### C.39 ☆

【思路】一次函数斜率截距与增减性

**解答**：

$y = -2x + 3$ 是一次函数，$k = -2$（斜率），$b = 3$（纵截距）。

因为 $k = -2 < 0$，所以 $y$ 随 $x$ 的增大而减小，函数单调递减。

**答案**：斜率 $k = -2$，纵截距 $b = 3$；函数在 $\mathbb{R}$ 上单调递减。

---

### C.40 ☆

【思路】待定系数法——两点确定一次函数

**解答**：

设 $y = kx + b$，将 $(1, 5)$ 和 $(3, 9)$ 代入：

$$\begin{cases} k + b = 5 \\ 3k + b = 9 \end{cases}$$

两式相减：$2k = 4$，得 $k = 2$；代入得 $b = 3$。

**答案**：$y = 2x + 3$。

### C.41 ☆

【思路】象限判断——$k$ 与 $b$ 的符号

**解答**：

$k > 0$：函数递增，图象从左下到右上。$b < 0$：纵截距在 $x$ 轴下方（$y$ 轴截距为负），则图象与 $y$ 轴的交点在原点下方。

- 图象向右上倾斜，与 $y$ 轴的交点在负半轴；
- 因此图象经过**第一、二、四象限**（不过第三象限）。

**答案**：图象经过第一、二、四象限。

### C.42 ☆

【思路】一次函数建模——匀速行驶

**解答**：

出发时距目的地 240 km，速度 60 km/h，则 $y = 240 - 60x$（$0 \leq x \leq 4$）。

令 $y = 0$：$240 - 60x = 0 \Rightarrow x = 4$。

**答案**：$y = 240 - 60x$（$0 \leq x \leq 4$）；到达目的地需 **4 小时**。

### D.37 ☆☆

【思路】待定系数法 + 象限判断

**解答**：

设 $y = kx + b$，由 $(1, 3)$ 和 $(-2, -3)$ 列方程组：

$$\begin{cases} k + b = 3 \\ -2k + b = -3 \end{cases}$$

相减：$3k = 6$，得 $k = 2$；代入得 $b = 1$，故 $y = 2x + 1$。

象限判断：$k = 2 > 0$，$b = 1 > 0$：纵截距在正半轴，图象经过**第一、二、三象限**（不过第四象限）。

**答案**：$y = 2x + 1$；图象经过第一、二、三象限。

### D.38 ☆☆

【思路】一次函数图象 = 方程组几何意义

**解答**：

方程组 $\begin{cases} 2x - y = 1 \\ x + y = 5 \end{cases}$，其解即为两直线 $y = 2x - 1$ 与 $y = -x + 5$ 的交点坐标。

两式相加：$3x = 6 \Rightarrow x = 2$；代入得 $y = 3$。

交点为 $(2, 3)$；两直线斜率 $k_1 = 2$，$k_2 = -1$，不平行也不垂直（$k_1 k_2 = -2 \neq -1$），相交于一点。

**答案**：交点坐标 $(2, 3)$；方程组的解与两直线的交点重合，即 $(2, 3)$。

### D.39 ☆☆

【思路】含参一次函数——象限与增减性联立不等式

**解答**：

函数 $y = (a-1)x + (2a-1)$。

条件一：图象与 $y$ 轴交点在 $x$ 轴上方，即 $b = 2a - 1 > 0 \Rightarrow a > \dfrac{1}{2}$。

条件二：函数值随 $x$ 增大而减小，即 $k = a - 1 < 0 \Rightarrow a < 1$。

联立：$\dfrac{1}{2} < a < 1$。

**答案**：$a$ 的取值范围为 $\dfrac{1}{2} < a < 1$。

### D.40 ☆☆

【思路】反比例函数 $k$ 值 + 与一次函数求第二交点

**解答**：

**(1)** 将 $(2, 3)$ 代入 $y = \dfrac{k}{x}$：$k = 2 \times 3 = 6$，故 $y = \dfrac{6}{x}$。

**(2)** 将 $(2, 3)$ 代入 $y = x + b$：$3 = 2 + b \Rightarrow b = 1$，故直线为 $y = x + 1$。

联立 $y = \dfrac{6}{x}$ 与 $y = x + 1$：$\dfrac{6}{x} = x + 1 \Rightarrow x^2 + x - 6 = 0 \Rightarrow (x+3)(x-2) = 0$。

故 $x = -3$ 或 $x = 2$（已知），另一交点 $x = -3$，$y = -3 + 1 = -2$，即 $(-3, -2)$。

**答案**：$k = 6$；$b = 1$；另一交点为 $(-3, -2)$。

### D.55 ☆☆

【思路】一次函数零点与截距条件推参数

**解答**：

当 $x < 2$ 时 $y > 0$，说明函数在 $x = 2$ 处值为 0 或负，且 $x = 2$ 恰好是零点（临界条件最严格时 $y(2) = 0$，结合过 $(-1, 4)$ 可精确定 $k$、$b$）。

先由点 $(-1, 4)$：$4 = -k + b$。

"$x < 2$ 时 $y > 0$"意味着零点恰为 $x = 2$（一次函数在 $x = 2$ 处 $y = 0$）：$0 = 2k + b$。

两式：$-k + b = 4$ 且 $2k + b = 0$。相减：$-3k = 4 \Rightarrow k = -\dfrac{4}{3}$；$b = -2k = \dfrac{8}{3}$。

验证：$x < 2$ 时 $k < 0$，函数递减，而零点在 $x = 2$，因此 $x < 2$ 时 $y > 0$，符合。

**答案**：$k = -\dfrac{4}{3}$，$b = \dfrac{8}{3}$，$y = -\dfrac{4}{3}x + \dfrac{8}{3}$。

### D.57 ☆☆

【思路】手拉手模型——一次函数与反比例函数切点条件

**解答**：

$y_1 = 2x + 1$ 与 $y_2 = \dfrac{k}{x}$（$x > 0$）只有一个公共点，联立：

$$2x + 1 = \dfrac{k}{x} \Rightarrow 2x^2 + x - k = 0$$

在 $x > 0$ 内只有一个实数根，即判别式 $\Delta = 0$ 或正根唯一。

$\Delta = 1 + 8k = 0 \Rightarrow k = -\dfrac{1}{8}$（此时 $x = -\dfrac{1}{4} < 0$，不在 $x > 0$ 内，不合）。

当 $\Delta > 0$ 时有两实根，需恰好一个正根：$x = 0$ 时 $2(0) + 0 - k = -k$，令 $x > 0$ 只有一解，即方程 $2x^2 + x - k = 0$ 正根唯一。

两根之积 $= -\dfrac{k}{2}$，两根之和 $= -\dfrac{1}{2}$（和为负）。若 $k > 0$，积 $< 0$，两根异号，则 $x > 0$ 恰好一根，满足条件。若 $k < 0$，积 $> 0$，两根同号，且和 $< 0$，两根均负，无正根，矛盾。

故 $k > 0$ 时恰好一个正根（不受 $\Delta = 0$ 限制）；另需 $k \neq 0$，$k > 0$ 即可。

但题目说"只有一个公共点"，$k > 0$ 均满足。检查 $k = 0$：退化为常函数，不是反比例。

综合：$k > 0$ 均满足，但通常此类题期望唯一值——重审：和为 $-\dfrac{1}{2} < 0$，积为 $-\dfrac{k}{2}$，正根唯一要求积 $< 0$，即 $k > 0$。故 **$k > 0$ 时恰好一个公共点**（无特定值）。

若题意为"相切"（重合）：$\Delta = 1 + 8k = 0 \Rightarrow k = -\dfrac{1}{8}$，但重根 $x = -\dfrac{1}{4} < 0$，不合。

故结论：$k$ 的值为任意 $k > 0$，函数在 $x > 0$ 恰好一个公共点。

**答案**：$k > 0$（任意正数）时，两函数在 $x > 0$ 上恰好一个公共点。

## Part 9 反比例函数

### C.43 ☆

【思路】反比例函数图象象限与增减性

**解答**：

图象在第一、三象限，说明 $k > 0$。

在第一象限（$x > 0$，$y > 0$）：随 $x$ 增大，$y = \dfrac{k}{x}$ 减小（单调递减）。

在第三象限（$x < 0$，$y < 0$）：随 $x$ 增大（从负数向 $0$ 趋近），$y$ 也增大趋向 $-\infty$——即在各象限内分别单调递减。

**答案**：$k > 0$；在第一象限和第三象限内，$y$ 随 $x$ 的增大而减小（各象限内单调递减）。

### C.44 ☆

【思路】反比例函数 $k$ 值求解

**解答**：

将 $(-2, 3)$ 代入：$k = x \cdot y = (-2) \times 3 = -6$，故 $y = \dfrac{-6}{x}$。

当 $x = 6$：$y = \dfrac{-6}{6} = -1$。

**答案**：$k = -6$；当 $x = 6$ 时，$y = -1$。

### C.45 ☆

【思路】反比例函数矩形面积——$k$ 的几何意义

**解答**：

点 $P(a, b)$ 在 $y = \dfrac{6}{x}$ 上，故 $ab = 6$。

以 $OP$ 为对角线，两边平行坐标轴的矩形，其面积 $= |a| \times |b| = ab = 6$（因 $a > 0$，$b = \dfrac{6}{a} > 0$）。

**答案**：矩形面积为 **6**（等于 $|k|$）。

### D.41 ☆☆

【思路】反比例函数 $|k|$ 几何意义——矩形面积

**解答**：

$P(a, b)$ 在 $y = \dfrac{k}{x}$（$k > 0$）上，故 $ab = k$（$a > 0$，$b > 0$）。

以 $OP$ 为对角线、两边平行坐标轴的矩形，顶点为 $(0,0)$、$(a,0)$、$(a,b)$、$(0,b)$。

矩形面积 $S = a \times b = ab = k$。

**答案**：矩形面积恒等于 $k$，即 $S = k$，与点 $P$ 的具体位置无关。

### D.42 ☆☆

【思路】反比例函数含参——象限与大小比较

**解答**：

**(1)** 图象在第二、四象限，则 $k = m - 2 < 0 \Rightarrow m < 2$。

**(2)** 设 $x_1 = -3 < x_2 = -1 < 0$，$k = m - 2$：

- 若 $m - 2 > 0$（即 $m > 2$）：$y = \dfrac{m-2}{x}$，$k > 0$，图象在第三象限内单调递减。在第三象限，$x_1 < x_2 < 0$，$y_1 = \dfrac{m-2}{-3} < \dfrac{m-2}{-1} = y_2$（负数绝对值更大），即 $y_1 < y_2$。

- 若 $m - 2 < 0$（即 $m < 2$）：$k < 0$，在第三象限内，$y > 0$，$y_1 = \dfrac{m-2}{-3} > \dfrac{m-2}{-1} = y_2$（分子负，分母绝对值更大时商绝对值更小），即 $y_1 > y_2$。

**答案**：(1) $m < 2$；(2) $m > 2$ 时 $y_1 < y_2$，$m < 2$ 时 $y_1 > y_2$（$m = 2$ 不是反比例函数）。

### D.52 ☆☆

【思路】反比例函数面积分割——$k$ 几何意义推广

**解答**：

$P(a, b)$ 在 $y = \dfrac{6}{x}$（$x > 0$）上，故 $ab = 6$，$a > 0$，$b > 0$。

过 $P$ 向 $x$ 轴作垂线，垂足 $M(a, 0)$；向 $y$ 轴作垂线，垂足 $N(0, b)$。

$\triangle OMP$（底 $OM = a$，高 $PM = b$）面积 $= \dfrac{1}{2}ab = 3$。

$\triangle ONP$（底 $ON = b$，高 $PN = a$）面积 $= \dfrac{1}{2}ab = 3$。

两三角形面积之和 $= 3 + 3 = 6$。

**答案**：面积之和为 **6**（与 $P$ 的具体坐标无关）。

### D.44 ☆☆

【思路】三种形式互化——利用对称轴和点

**解答**：

对称轴 $x = 1$，过 $(0, 3)$ 和 $(3, 3)$（关于 $x=1$ 对称，因 $0$ 和 $2$ 关于 $x=1$ 对称，但 $3$ 与 $-1$ 关于 $x=1$ 对称，这里 $x=0$ 和 $x=2$ 对称……验证：$\frac{0+2}{2}=1$ 且 $(0,3)$ 和 $(2,3)$，但题给第二点是 $(3,3)$）。

重算：设 $y = a(x-1)^2 + k$，由 $(0, 3)$：$3 = a + k$；由 $(3, 3)$：$3 = 4a + k$。

相减：$3a = 0 \Rightarrow a = 0$，矛盾（不是二次函数）。

重核：顶点式 $y = a(x-1)^2 + m$，$(0,3)$：$a + m = 3$；$(3,3)$：$4a + m = 3$。

$3a = 0 \Rightarrow a = 0$，矛盾。说明对称轴 $x=1$ 时 $(0,3)$ 和 $(2,3)$ 才是对称点，$(3,3)$ 不对称于 $(0,3)$。

换设一般式：$y = ax^2 + bx + c$，对称轴 $x = -\dfrac{b}{2a} = 1 \Rightarrow b = -2a$。

过 $(0,3)$：$c = 3$。过 $(3,3)$：$9a + 3b + 3 = 3 \Rightarrow 9a + 3(-2a) = 0 \Rightarrow 3a = 0$，仍矛盾。

说明题目中过 $(0,3)$ 和 $(3,3)$ 且对称轴 $x=1$ 的二次函数不存在（$(0,3)$关于$x=1$的对称点是$(2,3)$，与$(3,3)$矛盾）。重读题目：题给"对称轴为 $x=1$，过 $(0,3)$ 和 $(3,3)$"——应理解为题中的第二个点是 $(3, 3)$，但验算发现矛盾，可能题意是 $(0, 3)$ 和 $(2, 3)$（即对称点对）。

按 $(0,3)$ 与 $(2,3)$ 处理：$y = a(x-1)^2 + m$，$a + m = 3$，另需一个约束——设过 $(3,3)$ 是指过 $(0,3)$（$y$轴截距为 3）：则 $c = 3$，即 $a(0-1)^2 + m = a + m = 3$，仍需另一点。

重新取题意：对称轴 $x=1$，过点 $(0,3)$，另设 $y(3)$ 可用韦达方法——设两根关于 $x=1$ 对称。此处按照 $(0,3)$ 和 $(3,3)$ 的字面，用一般式：

$y = ax^2 - 2ax + c$，$(0,3)\Rightarrow c=3$；$(3,3)\Rightarrow 9a - 6a + 3 = 3 \Rightarrow 3a = 0$，无解。

**结论**：题目中点 $(3,3)$ 可能是笔误，应为 $(3, 6)$。按 $(0,3)$ 和 $(3,6)$：$c=3$；$9a-6a+3=6 \Rightarrow 3a=3 \Rightarrow a=1$，$b=-2$。

$y = x^2 - 2x + 3 = (x-1)^2 + 2$。

三种形式：一般式 $y = x^2 - 2x + 3$；顶点式 $y = (x-1)^2 + 2$；（无实数零点，无交点式）。

**答案**（按修正点 $(3,6)$）：$y = x^2 - 2x + 3 = (x-1)^2 + 2$；顶点 $(1,2)$，与 $x$ 轴无交点（$\Delta = 4 - 12 < 0$）。

**答案**：(1) $C(t, -\dfrac{t^2}{4}+4)$，$D(-t,-\dfrac{t^2}{4}+4)$；(2) $S = -\dfrac{t^3}{2}+8t$；(3) $S_{\max} = \dfrac{64\sqrt{3}}{9}$（$t=\dfrac{4\sqrt{3}}{3}$，宽 $\dfrac{8\sqrt{3}}{3}$，高 $\dfrac{8}{3}$）。

### E.29 ☆☆☆

【思路】韦达定理 + 弦长公式 + 中点坐标

**解答**：

联立 $y=x^2-2x-3$ 与 $y=x+a$：$x^2-3x-3-a=0$。

**(1)** $x_1+x_2 = 3$，$x_1 x_2 = -3-a$。$\Delta = 9+4(3+a) = 21+4a > 0 \Rightarrow a > -\dfrac{21}{4}$。

**(2)** 弦长 $|MN|$：直线斜率 1，$|MN| = \sqrt{1+1^2} \cdot |x_1-x_2| = \sqrt{2} \cdot \sqrt{(x_1+x_2)^2-4x_1x_2} = \sqrt{2}\sqrt{9+4(3+a)} = \sqrt{2}\sqrt{21+4a} = \sqrt{2(21+4a)}$。

**(3)** 中点横坐标 $= \dfrac{x_1+x_2}{2} = \dfrac{3}{2}$，与 $a$ 无关，恒为 $\dfrac{3}{2}$，故条件"中点横坐标为 $\dfrac{3}{2}$"对任意满足 $a > -\dfrac{21}{4}$ 的 $a$ 均成立。（题目可能是要中点纵坐标为某值）。

若题意为"中点纵坐标为 $\dfrac{3}{2}$"：中点纵 $= \dfrac{y_1+y_2}{2} = \dfrac{(x_1+a)+(x_2+a)}{2} = \dfrac{3+2a}{2} = \dfrac{3}{2} \Rightarrow 3+2a = 3 \Rightarrow a = 0$。

**答案**：(1) $x_1+x_2=3$，$x_1x_2=-3-a$；$a > -\dfrac{21}{4}$；(2) $|MN| = \sqrt{2(21+4a)}$；(3) 中点横坐标恒为 $\dfrac{3}{2}$（与 $a$ 无关）；若为中点纵坐标 $\dfrac{3}{2}$ 则 $a = 0$。

### E.30 ☆☆☆

【思路】抛物线顶点与等腰三角形判断 + 等面积点

**解答**：

**(1)** $y = x^2-6x+5 = (x-3)^2-4$，顶点 $C(3,-4)$；令 $y=0$：$(x-1)(x-5)=0$，$A(1,0)$，$B(5,0)$。

**(2)** $|AC|=\sqrt{(3-1)^2+(−4)^2}=\sqrt{4+16}=\sqrt{20}$，$|BC|=\sqrt{(5-3)^2+(−4)^2}=\sqrt{20}$，$|AC|=|BC|$，故 $\triangle ABC$ 是等腰三角形（$CA=CB$）。

**(3)** 底 $|AB|=4$，等面积要求 $D(0, d)$ 使 $S_{\triangle ABD} = S_{\triangle ABC}$。

$S_{\triangle ABC} = \dfrac{1}{2} \times 4 \times 4 = 8$（$C$ 到 $AB$ 距离 $=|{-4}|=4$）。

$S_{\triangle ABD} = \dfrac{1}{2} \times 4 \times |d| = 8 \Rightarrow |d| = 4 \Rightarrow d = 4$ 或 $d = -4$。

$D(0,4)$ 或 $D(0,-4)$。

**答案**：(1) $A(1,0)$，$B(5,0)$，$C(3,-4)$；(2) 等腰三角形（$CA=CB=2\sqrt{5}$）；(3) $D(0,4)$ 或 $D(0,-4)$。

### E.31 ☆☆☆

【思路】抛物线平移 + 与坐标轴交点 + 过原点条件

**解答**：

**(1)** $y = x^2-4x+3$，向右移 $m$（$x \to x-m$）：$y=(x-m)^2-4(x-m)+3 = x^2-(2m+4)x+m^2+4m+3$。

**(2)** 与 $y$ 轴交点：令 $x=0$，$y = m^2+4m+3$，有交点即 $y$ 可取任意实数，只需 $m^2+4m+3$ 为实数（恒成立）。但题意为"在 $y$ 轴上有实际交点（存在）"，对抛物线来说令 $x=0$ 总有 $y$ 值，故恒有 $y$ 轴交点。

若题意为"与 $y$ 轴正半轴交"：$m^2+4m+3 > 0 \Rightarrow (m+1)(m+3)>0 \Rightarrow m<-3$ 或 $m>-1$，与 $m > 0$ 联立：$m > 0$（已满足）。故所有 $m > 0$ 均有 $y$ 轴正截距。

**(3)** 过原点：令 $x=0, y=0$：$m^2+4m+3=0 \Rightarrow (m+1)(m+3)=0 \Rightarrow m=-1$ 或 $m=-3$，均为负，不满足 $m>0$。

无正数 $m$ 使 $C'$ 过原点。

若题意不限 $m > 0$（对一般平移）：$m = -1$ 或 $m = -3$，即向左移 1 或向左移 3。

**答案**：(1) $y = (x-m)^2-4(x-m)+3$；(2) 所有 $m > 0$ 时 $C'$ 与 $y$ 轴均有交点；(3) $m = -1$ 或 $m = -3$（向左移，不满足 $m > 0$；若允许 $m < 0$ 则有解）。

### E.32 ☆☆☆

【思路】抛物线顶点与零点 + 铅垂高法求三角形面积最大值

**解答**：

**(1)** $y = \dfrac{1}{2}x^2-2x = \dfrac{1}{2}x(x-4)$，零点 $A(0,0)$，$B(4,0)$；顶点 $x=2$，$y = 2-4 = -2$，$V(2,-2)$。

**(2)** $P(x_0, y_0)$ 在抛物线上（$0 < x_0 < 4$），$AB$ 在 $x$ 轴，距离 $d = |y_0| = \left|\dfrac{1}{2}x_0^2 - 2x_0\right|$。

在 $0 < x_0 < 4$：$y_0 = \dfrac{1}{2}x_0(x_0-4) < 0$，故 $d = 2x_0 - \dfrac{1}{2}x_0^2$。

**(3)** $S_{\triangle PAB} = \dfrac{1}{2} \times 4 \times d = 2d = 2\left(2x_0-\dfrac{x_0^2}{2}\right) = 4x_0 - x_0^2 = -(x_0-2)^2+4$。

最大在 $x_0 = 2$，$S_{\max} = 4$，$P(2,-2) = V$。

**答案**：(1) $V(2,-2)$，$A(0,0)$，$B(4,0)$；(2) $d = 2x_0 - \dfrac{x_0^2}{2}$；(3) $S_{\max}=4$（$P=V(2,-2)$）。

### E.34 ☆☆☆

【思路】含参二次函数——对称轴、判别式、根均大于 1 的三条件

**解答**：

$f(x) = x^2-2(a-1)x+a^2-5$。

**(1)** 对称轴 $x = a-1$。

**(2)** 两不等实根：$\Delta = 4(a-1)^2 - 4(a^2-5) = 4(a^2-2a+1-a^2+5) = 4(6-2a) > 0 \Rightarrow a < 3$。

- $\Delta > 0$：$a < 3$；

联立 $a < 3$，$a > 2$，$a > 1+\sqrt{3} \approx 2.73$：$1+\sqrt{3} < a < 3$。

**答案**：(1) $x = a-1$；(2) $a < 3$；(3) $1+\sqrt{3} < a < 3$。

### E.35 ☆☆☆

【思路】抛物线与直线围成面积——高度函数 + 弦长积分思路

**解答**：

**(1)** 联立 $y = 2x+3$ 与 $y = x^2+1$：$x^2+1 = 2x+3 \Rightarrow x^2-2x-2=0$...

重算：$x^2-2x+1-3 = 0$，$x^2-2x-2=0$，$x = 1 \pm \sqrt{3}$，$A(1-\sqrt{3}, 2(1-\sqrt{3})+3) = (1-\sqrt{3}, 5-2\sqrt{3})$，$B(1+\sqrt{3}, 5+2\sqrt{3})$。

**(2)** $P(t, t^2+1)$，直线 $l: 2x-y+3=0$，距离 $d = \dfrac{|2t-(t^2+1)+3|}{\sqrt{5}} = \dfrac{|-t^2+2t+2|}{\sqrt{5}} = \dfrac{-t^2+2t+2}{\sqrt{5}}$（$A$ 到 $B$ 之间抛物线在直线下方，$-t^2+2t+2 > 0$ 在此范围）。

**(3)** 面积 $= \int_{1-\sqrt{3}}^{1+\sqrt{3}} \left[(2x+3)-(x^2+1)\right]dx = \int_{1-\sqrt{3}}^{1+\sqrt{3}}(-x^2+2x+2)dx$

$= \left[-\dfrac{x^3}{3}+x^2+2x\right]_{1-\sqrt{3}}^{1+\sqrt{3}}$。

令 $u = 1+\sqrt{3}$，$v = 1-\sqrt{3}$，$u-v = 2\sqrt{3}$，$u+v=2$，$uv = -2$：

$\int_v^u (-x^2+2x+2)dx = \left[-\dfrac{x^3}{3}+x^2+2x\right]_v^u$。

上界：$-\dfrac{(1+\sqrt{3})^3}{3}+(1+\sqrt{3})^2+2(1+\sqrt{3})$。

$(1+\sqrt{3})^2 = 4+2\sqrt{3}$，$(1+\sqrt{3})^3 = (1+\sqrt{3})(4+2\sqrt{3}) = 4+2\sqrt{3}+4\sqrt{3}+6 = 10+6\sqrt{3}$。

上界 $= -\dfrac{10+6\sqrt{3}}{3}+(4+2\sqrt{3})+2(1+\sqrt{3}) = -\dfrac{10+6\sqrt{3}}{3}+6+4\sqrt{3} = \dfrac{-(10+6\sqrt{3})+18+12\sqrt{3}}{3} = \dfrac{8+6\sqrt{3}}{3}$。

类似，下界 $= \dfrac{8-6\sqrt{3}}{3}$（对称性）。

面积 $= \dfrac{8+6\sqrt{3}}{3} - \dfrac{8-6\sqrt{3}}{3} = \dfrac{12\sqrt{3}}{3} = 4\sqrt{3}$。

**答案**：(1) $A(1-\sqrt{3}, 5-2\sqrt{3})$，$B(1+\sqrt{3}, 5+2\sqrt{3})$；(2) $d = \dfrac{-t^2+2t+2}{\sqrt{5}}$；(3) 围成面积 $= 4\sqrt{3}$。
