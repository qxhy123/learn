## C 组基础题（☆）——Part 1 数

---

**C.1** ☆

【思路】有理数混合运算——先算指数，再按乘除、加减顺序计算

**解答**：

$$-3^2 + (-2)^3 \times \left(-\frac{1}{2}\right)^2$$

注意 $-3^2 = -(3^2) = -9$，$(-2)^3 = -8$，$\left(-\dfrac{1}{2}\right)^2 = \dfrac{1}{4}$。

$$= -9 + (-8) \times \frac{1}{4} = -9 + (-2) = -11$$

**答案**：$-11$

---

**C.2** ☆

【思路】绝对值定义 + 相反数定义——分正负两种情况

**解答**：

由 $|a| = 5$，得 $a = 5$ 或 $a = -5$。

相反数 $b = -a$，故 $a + b = a + (-a) = 0$。

无论 $a$ 取何值，$a + b$ 恒等于 $0$。

**答案**：$a + b = 0$（所有情况下均成立）

---

**C.3** ☆

【思路】科学记数法：$a \times 10^n$，其中 $1 \leq |a| < 10$；近似值按精确度要求四舍五入

**解答**：

$0.000045 = 4.5 \times 10^{-5}$。

精确到百分位（即小数点后第二位）：$4.5 \times 10^{-5} = 0.000045$，保留到百分位为 $0.000045 \approx 0.000045$。

注意"百分位"是 $0.01$ 位，$0.000045$ 到百分位为 $0.00$（保留两位小数）$\approx 0.00$。

更清楚地：$0.000045$ 精确到百分位（$10^{-2}$）为 $0.00$（因为万分位才有非零数字）。

**答案**：科学记数法为 $4.5 \times 10^{-5}$；精确到百分位的近似值为 $0.00$

---

**C.4** ☆

【思路】平方根定义：若 $x^2 = a$（$a \geq 0$），则 $x = \pm\sqrt{a}$；算术平方根取正值

**解答**：

$x^2 = 16 \Rightarrow x = \pm 4$，即 $x = 4$ 或 $x = -4$。

$16$ 的算术平方根为 $+\sqrt{16} = 4$（算术平方根唯一且非负）。

**答案**：$x = \pm 4$；$16$ 的算术平方根为 $4$

---

**C.5** ☆

【思路】立方根性质：$\sqrt[3]{a^3} = a$，可正可负

**解答**：

$$\sqrt[3]{-27} + \sqrt[3]{8} = \sqrt[3]{(-3)^3} + \sqrt[3]{2^3} = -3 + 2 = -1$$

**答案**：$-1$

---

**C.6** ☆

【思路】实数大小比较——将无理数平方后与有理数平方比较

**解答**：

$\sqrt{5}$ 与 $2$ 比较：$(\sqrt{5})^2 = 5 > 4 = 2^2$，由于两者均为正数，故 $\sqrt{5} > 2$。

数轴上：$2 < \sqrt{5} < 3$（因为 $2^2=4 < 5 < 9=3^2$），$\sqrt{5}$ 在 $2$ 与 $3$ 之间，更靠近 $2$（因 $5-4=1 < 9-5=4$）。

**答案**：$\sqrt{5} > 2$；数轴上 $\sqrt{5}$ 位于 $2$ 与 $3$ 之间，约在 $2.2$ 处

---

**C.7** ☆

【思路】二次根式化简——将被开方数分解出完全平方因子，再合并同类根式

**解答**：

$$\sqrt{12} = \sqrt{4 \times 3} = 2\sqrt{3}, \quad \sqrt{27} = \sqrt{9 \times 3} = 3\sqrt{3}$$

$$\sqrt{12} - \sqrt{3} + \sqrt{27} = 2\sqrt{3} - \sqrt{3} + 3\sqrt{3} = (2 - 1 + 3)\sqrt{3} = 4\sqrt{3}$$

**答案**：$4\sqrt{3}$

---

**C.8** ☆

【思路】根式乘除运算——利用 $\sqrt{a} \times \sqrt{b} = \sqrt{ab}$，$\dfrac{\sqrt{a}}{\sqrt{b}} = \sqrt{\dfrac{a}{b}}$

**解答**：

$$\sqrt{6} \times \sqrt{10} \div \sqrt{15} = \sqrt{6 \times 10} \div \sqrt{15} = \sqrt{60} \div \sqrt{15} = \sqrt{\frac{60}{15}} = \sqrt{4} = 2$$

**答案**：$2$

**C.10** ☆

$$(3x^2 - 2x + 1) - (x^2 + 3x - 4)$$
$$= 3x^2 - 2x + 1 - x^2 - 3x + 4$$

## C 组基础题（☆）——Part 4 分式

---

**C.20** ☆

【思路】分式化简——分子分母各自因式分解，再约去公因式

**解答**：

$$\frac{x^2 - 4}{x^2 - 4x + 4} = \frac{(x+2)(x-2)}{(x-2)^2} = \frac{x+2}{x-2} \quad (x \neq 2)$$

**答案**：$\dfrac{x+2}{x-2}$（$x \neq 2$）

---

**C.21** ☆

【思路】分式除法——除以一个分式等于乘以它的倒数，再约分

**解答**：

$$\frac{x^2-1}{x} \div \frac{x+1}{x^2} = \frac{x^2-1}{x} \times \frac{x^2}{x+1} = \frac{(x+1)(x-1)}{x} \times \frac{x^2}{x+1}$$
$$= \frac{(x-1) \cdot x^2}{x} = x(x-1) \quad (x \neq 0, x \neq -1)$$

**答案**：$x(x-1)$（即 $x^2 - x$）

---

**C.22** ☆

【思路】分式加减——通分取最简公分母 $(x-1)(x+1)$，再相加化简

**解答**：

$$\frac{2}{x-1} + \frac{3}{x+1} = \frac{2(x+1)}{(x-1)(x+1)} + \frac{3(x-1)}{(x-1)(x+1)}$$
$$= \frac{2x+2+3x-3}{(x-1)(x+1)} = \frac{5x-1}{x^2-1}$$

**答案**：$\dfrac{5x-1}{x^2-1}$（$x \neq \pm 1$）

---

**C.23** ☆

【思路】分式方程——去分母化整式方程，解后必须验根（检查分母是否为零）

**解答**：

方程：$\dfrac{3}{x-2} = \dfrac{1}{x+1}$

去分母（两边乘 $(x-2)(x+1)$）：

$$3(x+1) = 1 \cdot (x-2)$$
$$3x + 3 = x - 2$$
$$2x = -5$$
$$x = -\frac{5}{2}$$

**验根**：$x = -\dfrac{5}{2}$ 时，$x - 2 = -\dfrac{9}{2} \neq 0$，$x + 1 = -\dfrac{3}{2} \neq 0$，分母不为零，$x = -\dfrac{5}{2}$ 是原方程的解。

**答案**：$x = -\dfrac{5}{2}$

## D 组中档题（☆☆）——Part 1–4（D.1–D.18）

**D.1** ☆☆

【思路】绝对值与二次根式化简——$\sqrt{a^2} = |a|$，再根据各量的正负展开绝对值

**解答**：

首先，$\sqrt{3} \approx 1.732$，故 $\sqrt{3} - 2 < 0$，$1 - \sqrt{3} < 0$。

$$\sqrt{(\sqrt{3}-2)^2} = |\sqrt{3}-2| = 2 - \sqrt{3}$$

$$|1-\sqrt{3}| = \sqrt{3} - 1$$

$$\text{原式} = (2 - \sqrt{3}) + (\sqrt{3} - 1) = 1$$

**答案**：$1$

**D.2** ☆☆

【思路】科学记数 + 实数大小比较——统一转化为十进制小数后比较

**解答**：

$a = 3.2 \times 10^{-3} = 0.0032$

$b = 0.0035$

$c = \sqrt{0.0001} = \sqrt{10^{-4}} = 10^{-2} = 0.01$

比较：$0.0032 < 0.0035 < 0.01$，即 $a < b < c$。

**答案**：$a < b < c$，即 $3.2 \times 10^{-3} < 0.0035 < \sqrt{0.0001}$

---

**D.3** ☆☆

【思路】二次根式混合运算——先用平方差公式处理乘积，再处理除法部分，最后合并

**解答**：

第一部分：$(\sqrt{6}+\sqrt{2})(\sqrt{6}-\sqrt{2}) = (\sqrt{6})^2 - (\sqrt{2})^2 = 6 - 2 = 4$

第二部分：
$$\frac{\sqrt{18}-\sqrt{8}}{\sqrt{2}} = \frac{3\sqrt{2} - 2\sqrt{2}}{\sqrt{2}} = \frac{\sqrt{2}}{\sqrt{2}} = 1$$

$$\text{原式} = 4 - 1 = 3$$

**答案**：$3$

---

**D.4** ☆☆

【思路】绝对值不等式几何意义——$|x+1|$ 表示 $x$ 到 $-1$ 的距离，$|x-3|$ 表示 $x$ 到 $3$ 的距离，两距离之和等于 $4$ 即 $|-1-3|=4$，所以满足条件的点恰好在 $[-1, 3]$ 上

**解答**：

数轴上，$|x+1|$ 是 $x$ 与 $-1$ 的距离，$|x-3|$ 是 $x$ 与 $3$ 的距离。

两点 $-1$ 与 $3$ 之间的距离为 $3 - (-1) = 4$。

- 若 $x$ 在 $[-1, 3]$ 内：$|x+1| + |x-3| = (x+1) + (3-x) = 4$，等式成立。
- 若 $x > 3$：$|x+1| + |x-3| = (x+1)+(x-3) = 2x-2 > 4$，不满足。
- 若 $x < -1$：$|x+1| + |x-3| = -(x+1)+(3-x) = 2-2x > 4$，不满足。

故满足条件的 $x$ 的范围为 $-1 \leq x \leq 3$。

**答案**：$-1 \leq x \leq 3$

**D.5** ☆☆

【思路】完全平方公式链式推导——由 $x + \dfrac{1}{x} = 3$ 构造 $\left(x+\dfrac{1}{x}\right)^2$ 和 $\left(x^2+\dfrac{1}{x^2}\right)^2$

**解答**：

**第一步**：求 $x^2 + \dfrac{1}{x^2}$

$$\left(x + \frac{1}{x}\right)^2 = x^2 + 2 + \frac{1}{x^2} = 9$$

$$x^2 + \frac{1}{x^2} = 9 - 2 = 7$$

**第二步**：求 $x^4 + \dfrac{1}{x^4}$

$$\left(x^2 + \frac{1}{x^2}\right)^2 = x^4 + 2 + \frac{1}{x^4} = 49$$

$$x^4 + \frac{1}{x^4} = 49 - 2 = 47$$

**答案**：$x^2 + \dfrac{1}{x^2} = 7$；$x^4 + \dfrac{1}{x^4} = 47$

**D.6** ☆☆

【思路】整式乘法换元化简——令 $t = 2a - b$，将乘积转化为 $(t+1)(t-1) - t^2 + 4a^2$

**解答**：

令 $t = 2a - b$，则：

**D.7** ☆☆

**D.10** ☆☆

**D.12** ☆☆

**D.13** ☆☆

【思路】分式四则混合——括号内通分后合并，再除以后面的分式（转乘法）

$$\left(\frac{1}{x+1} - \frac{1}{x-1}\right) \div \frac{2}{x^2-1}$$

**D.14** ☆☆

【思路】分式方程 + 验根——乘以公分母 $x^2-4 = (x-2)(x+2)$，化为整式方程后解，再验根

**解答**：

方程：$\dfrac{x}{x-2} - \dfrac{3}{x+2} = \dfrac{16}{x^2-4}$，公分母为 $(x-2)(x+2)$。

两边乘以 $(x-2)(x+2)$：

$$x(x+2) - 3(x-2) = 16$$
$$x^2 + 2x - 3x + 6 = 16$$
$$x^2 - x - 10 = 0$$

用求根公式：$x = \dfrac{1 \pm \sqrt{1+40}}{2} = \dfrac{1 \pm \sqrt{41}}{2}$

**验根**：$x = \dfrac{1 \pm \sqrt{41}}{2}$ 均不等于 $\pm 2$（因为若 $x=2$：$\dfrac{1+\sqrt{41}}{2} \approx 3.7 \neq 2$；若 $x=-2$：同理），故两个解均有效。

**答案**：$x = \dfrac{1 + \sqrt{41}}{2}$ 或 $x = \dfrac{1 - \sqrt{41}}{2}$

**D.15** ☆☆

【思路】增根的定义——增根是使分母为零的值，将增根代入方程（转为整式方程后）验证其满足整式方程

**解答**：

方程 $\dfrac{x+a}{x-2} = \dfrac{3}{x-2}$ 的增根必须使分母 $x-2 = 0$，即增根为 $x = 2$。

将 $x = 2$ 代入去分母后的整式方程 $x + a = 3$：

$$2 + a = 3 \Rightarrow a = 1$$

**验证**：当 $a=1$ 时，原方程为 $\dfrac{x+1}{x-2} = \dfrac{3}{x-2}$，去分母得 $x+1=3$，解得 $x=2$，但 $x=2$ 使分母为零，确为增根。

**答案**：$a = 1$

**D.16** ☆☆

【思路】有理化分母——利用 $(\sqrt{3}+\sqrt{2})(\sqrt{3}-\sqrt{2})=1$ 化简每个分数，再合并

**解答**：

$$\frac{1}{\sqrt{3}+\sqrt{2}} = \frac{\sqrt{3}-\sqrt{2}}{(\sqrt{3})^2-(\sqrt{2})^2} = \sqrt{3}-\sqrt{2}$$

$$\frac{1}{\sqrt{3}-\sqrt{2}} = \frac{\sqrt{3}+\sqrt{2}}{(\sqrt{3})^2-(\sqrt{2})^2} = \sqrt{3}+\sqrt{2}$$

$$\text{原式} = (\sqrt{3}-\sqrt{2}) + (\sqrt{3}+\sqrt{2}) - \frac{2}{\sqrt{3}}$$
$$= 2\sqrt{3} - \frac{2\sqrt{3}}{3} = \frac{6\sqrt{3} - 2\sqrt{3}}{3} = \frac{4\sqrt{3}}{3}$$

**答案**：$\dfrac{4\sqrt{3}}{3}$

**D.17** ☆☆

【思路】整式求值换元——先对 $a^3 - a^2b - ab^2 + b^3$ 因式分解，再代入已知条件

**解答**：

因式分解：

$$a^3 - a^2b - ab^2 + b^3 = a^2(a-b) - b^2(a-b) = (a^2-b^2)(a-b) = (a+b)(a-b)^2$$

已知 $a - b = 2$，$ab = -3$，则：

$$(a+b)^2 = (a-b)^2 + 4ab = 4 + 4(-3) = -8$$

注意 $(a+b)^2 = -8 < 0$ 说明实数范围内无解？重新核查：

$(a-b)^2 = 4$，$(a+b)^2 = (a-b)^2 + 4ab = 4 + 4 \times (-3) = 4 - 12 = -8$

这表明 $a+b$ 没有实数值——但题目给出实数 $a, b$ 满足这两个条件，需重新检验。

注意：$a-b=2$，$ab=-3$，则 $a, b$ 是 $t^2 - (a+b)t - 3 = 0$ 的两根，判别式 $\Delta = (a+b)^2 + 12$。由 $a - b = 2$，设 $a = b+2$，则 $b(b+2) = -3$，即 $b^2 + 2b + 3 = 0$，$\Delta = 4 - 12 = -8 < 0$，说明 $a, b$ 为复数。

题目可能在复数意义下成立，或仅求代数值。按代数推导：

$$(a+b)(a-b)^2 = (a+b) \times 4$$

需要 $a+b$ 的值：由 $a = b+2$，$b^2+2b+3=0$，$(b+1)^2=-2$，$b = -1 \pm \sqrt{2}i$（复数），$a+b = 2b+2 = 2(-1 \pm \sqrt{2}i)+2 = \pm 2\sqrt{2}i$。

对于实数题，可能题目条件有误，或用另一思路：直接代入：

$(a+b)(a-b)^2$，$(a-b)^2 = 4$，还需 $a+b$。

若题目条件确实如此，则结果为 $4(a+b)$，$a+b = \pm 2\sqrt{2}i$（复数），在实数范围内此条件矛盾。

重新解读：可能 $ab = -3$ 下 $a, b$ 为实数意味着 $a - b = 2$ 且 $ab = -3$，实际上 $a, b$ 是实数（因为方程 $t^2 - St - 3 = 0$ 对任意实数 $S$ 判别式为 $S^2 + 12 > 0$ 恒有两个实根）。关键是我之前计算 $(a+b)^2$ 时用错了公式。

正确：$(a+b)^2 = (a-b)^2 + 4ab = 4 + 4(-3) = -8$？

这说明不存在实数 $a, b$ 同时满足 $a-b=2$ 且 $ab=-3$？验证：设 $a=b+2$，$b(b+2)=-3$，$b^2+2b+3=0$，$\Delta=4-12=-8<0$，确无实数解。

题目可能有笔误，但按代数推导，结论：$(a+b)(a-b)^2 = (a+b) \cdot 4$。若认为 $a+b$ 可由其他方式求得，则用韦达定理类推导：$a+b$无法由 $a-b=2, ab=-3$ 确定为实数。

**按标准解题流程给出因式分解结果**：

$$a^3 - a^2b - ab^2 + b^3 = (a+b)(a-b)^2 = (a+b) \times 4$$

若题目条件为 $a-b=2$，$ab=3$（正3），则 $(a+b)^2=(a-b)^2+4ab=4+12=16$，$a+b=\pm 4$，结果为 $\pm 16$。

**以 $ab=3$ 重新计算**（最可能的题目意图）：

$a+b = \pm 4$，$(a+b)(a-b)^2 = \pm 4 \times 4 = \pm 16$。

**答案**：$\pm 16$（若 $ab = 3$）；若条件如题目所给 $ab = -3$，则注意两实数无法同时满足 $a-b=2$ 且 $ab=-3$，结论为 $(a+b)(a-b)^2 = 4(a+b)$，需额外信息确定 $a+b$ 的值。

> **备注**：本题最可能的出题意图是 $ab = -3$，$a, b$ 为复数代入代数计算，此时因式分解给出 $(a+b)(a-b)^2 = 4(a+b)$，而 $a+b$ 在复数域下为 $\pm 2\sqrt{2}i$。若改为 $ab = 3$，则有实数解。

**D.18** ☆☆

【思路】因式分解 + 整式求值——由 $x^2 - 3x + 1 = 0$ 推出 $x \neq 0$，两边除以 $x$ 得 $x + \dfrac{1}{x}$，再利用完全平方

**解答**：

由 $x^2 - 3x + 1 = 0$，$x \neq 0$（否则代入得 $1 = 0$ 矛盾），两边除以 $x$：

$$x - 3 + \frac{1}{x} = 0 \Rightarrow x + \frac{1}{x} = 3$$

$$x^2 + \frac{1}{x^2} = \left(x + \frac{1}{x}\right)^2 - 2 = 9 - 2 = 7$$

**答案**：$7$
